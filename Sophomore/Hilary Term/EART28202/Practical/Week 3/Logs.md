# **ON  LOGARITHMS**

- The logarithm of a number _x_ in base _b_ is the number such that _x = b_<sup>_n_</sup> _,_

_e.g.,_ log3(81) _=_ 4   since 3<sup>4</sup> = 81

_e.g.,_ log10(100) _=_ 2   since 10<sup>2</sup> = 100

- The most widely used bases, _b_ , are

10, 2, and

e ® 2.71828 _..._ , defined because _d_ loge ( _x_ ) / _dx_ = 1/ _x ;  “_ loge” is usually written as _“_ ln”

- To convert from base _k_ to base _b_ use

log _b_ ( _x_ )   =   log _k_ ( _x_ ) / log _k_ ( _b_ ) NB. ln (10) = 2.302585....]

• The impact made by logarithms when they were discovered in the 17th century was similar to the impact made by the invention of the computer − they simplify calculations and so made it possible to attempt analyses that involved many more complex calculations than had been practical before. Thus multiplications are reduced to additions, divisions to subtractions, and raising a number to a power to a multiplication, all because

log ( _mn_ )   =   log ( _m_ )  +  log ( _n_ ) log ( _m_ / _n_ )   =   log ( _m_ )  -  log ( _n_ ) log ( _m_<sup>_n_</sup> )   = _n_ log ( _m_ )

• For example, 2532.174 × 86491.221 can be determined by looking up the log of 2532.174 and the log of 86491.221, adding the two together, and then looking up the antilog. Special booklets of tables were created to allow one to look up the log and antilog of any number. Just 35 years ago these tables used to be a commonplace part of the schoolboy's kit.
