## 二、核心概念

### 2.1 屈曲的两个必要条件（Slide 3）

1. **被折叠层必须比围岩（matrix）更能干（competent）**，即黏度更高。
2. **层界面上必须存在小的不规则性**，作为褶皱的**成核点**。notes pane 原话："Without these there is nothing to kick the folding off."

流变学铺垫（notes pane）：黏度 = **剪应力/剪应变速率**；地质时间尺度上岩石会流动，可视为黏性流体。黏度与剪力无关者称 **Newtonian viscous（线性黏性）**；岩石通常**剪切变稀（shear-thinning）**，属非牛顿流体；剪切变稠在地质环境中不出现。

### 2.2 单层屈曲（Slide 4–6）

理论做法：给单层叠加不同波长的小正弦扰动，找**放大最快**的那个——它成为**主波长（dominant wavelength）**。结论（公式见第三节）：

- **λ 随层厚 d 线性增大**。野外检验：同一露头薄层波长短、厚层波长长。
- **黏度比越大 → 放大越快、层的加厚越少**（"加厚"指未被屈曲吸收的那部分平行层缩短）。
- **褶皱的影响随远离折叠层迅速消失，约一个波长外可忽略**。→ 这是后面"影响区 zone of influence"的来源。
- 屈曲形成的层近似 **Class 1B（平行褶皱）**。

黏度比值得测的原因：若知道岩层成分，黏度比可反推**变形条件**（温度、变形速率）。讲义坦言目前理论尚不足以给出可靠定量估计，但定性洞察可行。

### 2.3 例外：被折叠的 pinch-and-swell（Slide 7）

若层已有**颈缩–膨大**结构，变形集中在薄处，**控制波长的是薄处间距而非层厚**。注意：**已 boudinaged 的层，波长不受布丁宽度控制**。

构造意义：这种几何允许论证**两期变形**（先平行层伸展，后褶皱）；但讲义提醒二者未必是独立事件，**也可能是同一次渐进变形（progressive deformation）的早、晚阶段**。识别标志：**褶皱一翼明显比另一翼厚**。

### 2.4 多层屈曲（Slide 8–10）

按能干层间距由近到远：

| 情形 | 条件 | 结果 |
|---|---|---|
| **有效单层 effective single layer** | 能干层很近 | 集体表现为一厚单层 → **长波长** |
| **谐和褶皱 harmonic** | 稍远，且层厚与间距变化不大 | 公式引入 N（能干层数） |
| **多谐褶皱 polyharmonic** | 能干层厚度/黏度比差异显著 | 出现**多个波长**，但服从某**控制层** |
| **不谐褶皱 disharmonic** | 间距 > 影响区（约一个波长） | 各层**独立**折叠 |
| **肠状褶皱 ptygmatic** | 不能干层远厚于能干层 | 波长/层厚关系规则，但**轴面方位变化极大**；翼常向自身卷回 |

### 2.5 调节构造（Slide 11–12）

关键力学事实：**抗屈曲能力正比于层厚的三次方（t³）**。因此**异常厚的层控制整个多层体**——波长由厚层决定，其余各层被迫迁就。那些过早起褶、翼长不合最终形态的层，必须调整；为此形成的构造统称**调节构造（accommodation structures）**：**龙骨状铰（keel-like hinge / hinge collapse）**、**铰部逆冲越顶**、**铰部逆断层**、**翼部布丁化**。

> notes pane 记了一个反向情形：**尖棱褶皱（chevron fold）**形成时，是**厚层的形状被一叠薄层控制**——因为尖棱褶皱中给定缩短量下的翼倾角依赖层厚。

### 2.6 各向异性岩石的屈曲（Slide 13–18）

第二条建模路线：把多层体当作**统计均一但力学各向异性**的连续介质。这里"各向异性"指**抗剪能力与抗压能力不同**；典型岩石是薄层互层体或具强**穿透性组构**（如板岩劈理）者。

**只有这条路线才能解释的特征**：① 翼部**非常平直**的褶皱；② **轴面斜交原始层理**的褶皱——**即使主压缩方向就沿层理**；③ **膝折带（kink bands）**。

**膝折带**具 **Class 2（相似褶皱）几何**，但铰是**角状**的，因此**等倾线方法不可用**，必须直接标注角度与尺寸参数。用这些参数可反推缩短量、体积变化与应力方位。

**各向异性度与加载角的联合控制**给出一个反直觉结论：

> **布丁化与伸展型膝折带可以由"垂直层面的压缩"产生——并非只能由主动的平行层伸展造成。**

讲义预先解释了表观矛盾：假设方块在竖直方向不能膨胀，垂直层理压缩时岩层试图沿层理伸展，若不允许，就等价于层内产生了压应力。

**构造价值**：膝折带是**常见的造山晚期构造**，因对主变形信息量小而被戏称 **"fag-end"（烟屁股）构造**；**但**更大尺度的类膝折褶皱（如箱状褶皱 box fold）说明这种样式**可以有超出 "fag-end" 的意义**。

### 2.7 屈曲褶皱的一生（Slide 19–22）

| 阶段 | 内容 |
|---|---|
| 1 **前屈曲缩短** | 折叠前层先均匀缩短加厚；缩短量取决于变形条件与黏度比。**也可能靠逆冲而非均匀缩短实现翼部加厚** |
| 2 **成核 initiation** | 层内不规则性触发。若能干层足够远则各层独立起褶，直到控制层开始屈曲迫使其余层调整（→ 调节构造）；若无控制层则整体屈曲 |
| 3 **放大 → 锁死 locking up** | 层相对压缩方向旋转，最终进入不利方位 → 停止屈曲 |
| 4 **后屈曲压扁 post-buckle flattening** | 继续缩短使褶皱**被动**生长：振幅增大、翼间角减小，"基质+层"整体加厚 |

**主动屈曲只在阶段 2、3；阶段 4 是被动生长。** 锁死可以**提前发生**：若岩石应变硬化，或有利变形的因素（如孔隙流体）被移除。

**后屈曲压扁对等倾线分类的改造**——把 Class 1 的分类真正用起来：

- 后屈曲压扁：**Class 1B → 1C**；等倾线分析可**定量评估压扁量**。
- 多层体可能是：能干层 **1B** + 不能干夹层 **3**；继续缩短时不能干层保持 3，能干层变 **1C**。
- **平行轴面方向**的压缩：**Class 1B → 1A**（常见于收缩变形幕晚期，岩体被逆冲到早期褶皱之上时）。

### 2.8 弯曲（Slide 23）

弯曲褶皱是**响应相邻岩体变形而在几何上必然出现的褶皱**：**颈褶皱**（布丁之间）、**断弯褶皱 fault-bend folds**（上盘越过倾角变化的断层，如逆冲坡道）、**披覆褶皱 drape folds**（盖层响应基底断裂）、**强力侵入体/底辟周围的褶皱**、**差异压实褶皱**。共同点：**非均匀的力横跨层理施加**。

### 2.9 被动褶皱（Slide 24）

- 折叠层只是**标志带**，单纯记录所在岩体的变形；典型产出在**岩层进入剪切带**处。
- 原始平行边的层被动折叠 → **Class 2 相似褶皱**（铰部加厚、翼部极度减薄）。
- ⭐ **关键判据**：层与围岩的**力学性质差异很小**时放大最显著 → **被动褶皱在高级变质岩中更突出**。（与屈曲要求大能干性差异**正好相反**。）

### 2.10 三种褶皱机制（Slide 25–30）

**(a) 弯滑 / 弯流**——类比"压一叠纸"，各张纸彼此滑动。

- **滑动量：拐点最大，向铰部递减，铰部为零。**
- **层面内无畸变** → 推论：**躺在滑动面内的化石保持不变形**（其他机制做不到）。
- 滑动面通常是层面或劈理。**滑动面很密、剪切均匀分布 = 弯流；滑动面间距较大 = 弯滑。**
- **次生特征**：① 滑动面上**高角度斜交铰**的线理（沟槽，更常见是晶体纤维；讲义称 slickolites，见勘误表）；② **雁列张裂脉**指示滑动指向——**两翼指向相反**（背形铰左侧右行、右侧左行），**离铰越远 S 形越明显**（滑动位移向拐点增大）。
- **赤平投影签名**：因层内无畸变，与褶皱轴成 α 角的先存线理折叠后**仍成 α 角** → 线理摊布在**绕褶皱轴的小圆（small circle）**上。

**(b) 切向纵向应变（TLS）**——类比"沿长度压一块橡皮"。

- **外弧受拉伸、内弧受压缩，之间是变形相互抵消的中和面（neutral surface）**。
- **变形量：铰部最大，向拐点递减，拐点为零。**（**与弯滑正好相反！**）
- **次生特征**：**外弧**张裂隙（常被脉体充填）；**内弧**劈理加强或**共轭逆冲**。
- **赤平投影签名**：线理摊布在**一个扇形区（sector）**内，位置取决于它在折叠层中的深度。

**(c) 剪切褶皱**——类比"剪一副扑克牌"，**剪切面平行轴面**，产生 **Class 2** 褶皱。

- **重要限定**：讲义明说它 **"is not believed to be a real folding mechanism"**，但是分析 Class 2 褶皱的**极好近似**。
- **赤平投影签名**：线理被摊布在一条**大圆（great circle）**上。**该大圆与剪切面（轴面）的交点 = 构造 a 方向（tectonic a-direction）**；若褶皱由断层剪切造成，**这就是断层滑移矢量（slip vector）**。
- notes pane 罕见地用了"必须掌握"的口吻：测量线理进入断层带的方位，求其大圆与断层面大圆的交点，即得滑移矢量——"a major focus of the exercises in more than one of our practical classes… ought to become very familiar with this technique"。**本周 `SolnGneissFault` 就是它的第一次实战。**

### 2.11 非圆柱状褶皱（Slide 31–34）

- **穹丘（periclines）与分叉铰**：褶皱沿轴**生长并消亡**或**分叉**；常见**雁列排列的长条形穹丘**（扎格罗斯山脉）。**间距 < 约半个波长者可能连接；> 此值则可能重叠并彼此锁死。** → 结论：不仅要描述剖面几何，**还要描述平面分布**。
- **鞘褶皱（sheath folds）**：铰线在轴面内弯曲**超过 90°**；常伴强烈拉伸线理；成因是层平行剪切下初始不规则性的**被动放大**；剪切带特征构造（Class 4）。辨析：鞘褶皱 = **弯曲铰线 + 近平面轴面**；**多斜褶皱（polyclinal）** = **平直铰线 + 弯曲轴面**。
- **软沉积褶皱**：未固结、水饱和沉积物很弱，能响应驱动力方向的微小改变 → **高度非圆柱状**，复杂到做完整几何描述已无意义。

### 2.12 叠加褶皱与干涉型式（Slide 35–41）

**再褶皱褶皱**：两期及以上变形的产物**都是非圆柱状**的，唯一例外是两期**共轴且共面**。

> **关键方法论**：可借助**每期折叠所伴随的协调小构造**来解开——因为**第二期折叠虽能改变第一期褶皱的几何，却无法改变第一期小构造的不对称性**。（接续 Class 1 的 S/Z 与倒向 vergence。）

**符号约定**：F1/F2 = 一期/二期褶皱；S0/S1/S2 = 层理/一期/二期劈理（轴面）；D1/D2 = 变形幕；L1/L2 = 线理。

**四种干涉型式**（按两期褶皱的**轴**与**轴面姿态**分类）：

| 型式 | 两期褶皱轴 | 姿态 | 平面图案 |
|---|---|---|---|
| **Type 0** | **共轴** | **共面** | 无新图案，第二期只**强化**第一期 |
| **Type 1** | **⊥（90°）** | **两者皆直立**，轴面互成 90° | **穹–盆（dome and basin）**，"蛋盒" |
| **Type 2** | **⊥（90°）** | **一平卧、一直立** | **新月 / 蘑菇（dome-crescent-mushroom）** |
| **Type 3** | **≈ 共轴** | **一平卧、一直立** | **波状（convergent–divergent）** |

**Type 3 的重要警告**（Slide 39 notes）：F1 与 F2 近共轴但 S1、S2 差异极大 → 近平直的 F1 铰 + 弯曲的 S1，这就是**多斜褶皱**；而**多斜褶皱可以在单次变形事件中形成**，因此：

> **看到 Type 3 干涉型式，并不自动意味着经历了两期褶皱事件。**

**现实世界**：上述型式以"每期褶皱都是圆柱状"为前提；若一期或两期本身非圆柱状，图案会复杂得多。

### 3.1 单层屈曲主波长公式

$$\lambda = 2\pi d \left[\frac{\eta_L}{6\,\eta_M}\right]^{1/3}$$

| 符号 | 含义 |
|---|---|
| **λ** | 放大最快的扰动波长 = 褶皱**主波长** |
| **d** | **能干层的层厚** |
| **η_L** | **层（layer）**的黏度 |
| **η_M** | **基质（matrix）**的黏度 |
| **6** | 理论推导给出的无量纲常数（在**分母**，与 η_M 相乘） |
| **1/3** | 黏度比取**立方根** |

**读法与推论**：

1. **λ ∝ d（线性）**：层厚翻倍，波长翻倍。
2. **λ ∝ (η_L/η_M)^(1/3)**：**波长对黏度比不敏感**——黏度比变 8 倍，波长才变 2 倍。**这正是"从 λ、d 反推黏度比"难以做到定量精确的原因。**
3. **η_L > η_M** 是屈曲的前提，故比值 > 1；**分子是层、分母是基质，不能倒。**
4. 📎 背景补充：**（我做的代数变形）** 实测的是 λ/d，反解得
   $$\frac{\eta_L}{\eta_M} = 6\left(\frac{\lambda}{2\pi d}\right)^3$$
   讲义只给正向公式，并说"这类方程最有用的解释之一是有可能从实测 λ 和 d 反推层/基质黏度比"。

**适用条件（Slide 4 notes 明列）**：(a) 层与基质均为**牛顿黏性**；(b) 层的**自重无影响**；(c) **不存在未被屈曲吸收的平行层缩短**（层不加厚）；(d) 是**剖面平面内的二维分析**（无物质进出该平面）。更复杂的模型可放松这些假设。

### 3.2 多层（谐和褶皱）修正公式

$$\lambda = 2\pi d \left[\frac{N\,\eta_L}{6\,\eta_M}\right]^{1/3}$$

**N = 层组中能干层的数目**，**乘在 η_L 上**。推论：N 层能干层的波长是单层的 **N^(1/3)** 倍（8 层 → 翻倍）。适用条件：能干层稍分开、层厚与间距变化不大。

### 3.3 抗屈曲能力

$$\text{resistance to buckling} \propto t^3$$

**层厚三次方律**——厚层控制整个多层体的根源。层厚翻倍，抗屈曲能力 8 倍。**指数是 3，不是 2。**

### 3.4 Practical 的伸展应变公式（`Cover.md` 第 5 题）

$$e = \frac{\Delta L}{L_0}$$

**ΔL** = 沿**平行岩墙张开方向**的测线上**岩墙的总厚度**；**L₀ = 测线总长 − ΔL**，即**岩墙侵位前的原始长度**。⚠️ **分母是原始长度，不是现今总长。**

### 5.5 第 4 问：褶皱与断层的关系

两条互补证据：

1. **"cleavage parallel to mylonitic foliation implying a genetic relationship between the two"**——沉积岩中的**轴面劈理**（定义轴面 040/30SE）与片麻岩中的**糜棱面理**（040/30SE）**平行** → **下盘的褶皱是在逆冲过程中形成的**。
2. **"gneisses not folded implying final stages of thrusting after fold in metasediments formed"**——上盘片麻岩**未被折叠** → **逆冲的最后阶段晚于褶皱形成**。

**综合**：褶皱与逆冲属**同一次渐进变形**——褶皱在逆冲过程中于下盘发育（故共享轴面方位），而逆冲的最终增量晚于褶皱定型（故上盘未卷入）。**这正呼应 Slide 7 notes 关于"两阶段可以是同一次渐进变形的早、晚期"的说法。**

### 5.6 第 5 问：岩墙的几何与伸展量

**观察 → 推论**：岩墙切穿褶皱与断层、且未变形 → **晚于全部变形**；⚠️ **倾角未知**；各标志的**错开（cut-offs）**关系显示位移**垂直岩墙边界** → **岩墙沿垂直边界的方向张开**；**冷凝边对称排列** → 数目 = 注入次数，且每次注入沿先存岩墙中心贯入。

**计算**：① 画一条**平行岩墙张开方向**（垂直岩墙走向）的测线；② 量**所有岩墙厚度之和 = ΔL**；③ 测线总长 − ΔL = **L₀**；④ **e = ΔL/L₀**。⚠️ 分母是 L₀，题面已写死。

## 六、易错点 / 重点难点

### 6.1 概念

| 易错点 | 正确表述 |
|---|---|
| **把"类型"和"机制"混为一谈** | Buckling / Bending / Passive folding 是**类型**（按载荷方向）；Flexural slip-flow / TLS / Shear folding 是**机制**（按内部变形方式）。屈曲与弯曲**都**通过弯滑/弯流或 TLS 实现 |
| ⭐ **弯滑与 TLS 的应变分布记反** | **弯滑：滑动量在拐点最大、铰部为零**；**TLS：应变在铰部最大、拐点为零**。**完全相反** |
| **外弧/内弧的应力状态记反** | **外弧（凸侧）拉张**→张裂隙/张脉；**内弧（凹侧）压缩**→劈理加强/共轭逆冲。记忆：弯一根橡皮筋，外侧被拉长 |
| **误以为中和面是层的几何中面** | 中和面是**变形相互抵消**的面。考试按讲义定义答 |
| **黏度比分子分母搞反** | **η_L（层）在分子，η_M（基质）在分母**；屈曲要求 η_L > η_M，比值 > 1 |
| ⭐ **屈曲与被动褶皱对能干性差异的要求记反** | **屈曲需要大的能干性差异**；**被动褶皱的放大在差异很小时最显著**（故在高级变质岩中更突出）。**正好相反** |
| **认为剪切褶皱是真实机制** | 讲义明说它 "is not believed to be a real folding mechanism" |
| **认为布丁化只能由平行层伸展造成** | Slide 16：**布丁化与伸展型膝折带可由层法向压缩产生** |
| **认为 Type 3 = 两期变形** | Slide 39 notes 明确警告：多斜褶皱**可在单次变形中形成** |
| **对膝折带用等倾线分析** | 膝折带是 **Class 2 几何但铰角状 → 等倾线不适用**，须直接标角度与尺寸 |
| **pinch-and-swell 与 boudinage 混淆** | **pinch-and-swell 层**：波长由**薄处间距**控制（不是层厚）；**boudinage 层**：波长**不**由布丁宽度控制 |

### 6.2 公式

| 易错点 | 正确表述 |
|---|---|
| 指数写成 1/2 或 1 | 黏度比指数是 **1/3（立方根）** |
| 常数 6 漏掉或放错 | 6 在**分母**、与 η_M 相乘：`[η_L/(6η_M)]^(1/3)`；**不是** `[η_L/η_M]^(1/3)/6`，也不是 `[6η_L/η_M]^(1/3)` |
| 2π 写成 π 或 2 | 前系数是 **2π** |
| 多层公式 N 放错位置 | **N 乘在 η_L 上（分子）**，不是乘在括号外或 d 上 |
| 抗屈曲能力指数 | **∝ t³**，不是二次方 |
| 应变 e 的分母 | **L₀ = 测线总长 − ΔL**（原始长度），不是现今总长 |

### 6.3 劈理（Class 1 内容，Practical 天天用）

| 易错点 | 正确表述 |
|---|---|
| ⭐ **劈理折射方向判反** | **更能干的岩层中，劈理与层理夹角更大**；不能干层中劈理更接近平行层理。抓手：**软层"随大流"，劈理躺平贴着层理；硬层"不合作"，劈理硬顶着层理** |
| 用劈理折射判顶底方向搞反 | 正粒序层向顶部黏土升高 → **越靠近层顶劈理越接近平行层理** |
| 忘了折射改变的是倾角 | "changes dip (but not strike)" |
| 把劈理扇当成劈理折射 | **扇**是同一岩性内绕褶皱的收敛/发散排布；**折射**是穿岩性界面时的突变 |
| 把 transecting cleavage 当成扇 | 那是**转换压缩**下劈理**系统斜交轴面**，另一回事 |

### 6.4 干涉型式（最需空间想象）

⚠️ **最常见错误：Type 1 与 Type 2 弄反。** 两者**褶皱轴关系完全相同（都 90°）**，区别**只在轴面姿态**：**都直立 = Type 1（规则蛋盒）**；**一平卧一直立 = Type 2（新月/蘑菇）**。
⚠️ **第二常见：Type 2 与 Type 3 弄反。** 两者**姿态关系完全相同（一平卧一直立）**，区别**只在褶皱轴**：**轴正交 = Type 2**；**轴共轴 = Type 3**。
**口诀：轴定"闭不闭"，面定"匀不匀"。**
