Assessed Practical. Set: 28/4/26 submit in person 5/5/26 after the practical.

Deep-marine core logging exercise.

Submit sedimentary logs encompassing deep-marine facies types.

At least 5 metres in total (i.e., 5 m total length of logs submitted). Can be more than one section, but please separate them or draw on different sheets. Try to include several facies, e.g. turbidites, debrites, slumps, etc.

Include description and interpretation of the facies you identify, along these lines:

Facies 1 (insert name)

Grain type and composition:

Insert description

Grain size

Insert description

Sedimentary structures

Insert description

Colour

Insert description

Biological structures and content (traces fossils, body fossils)

Insert description

Interpretation of facies

You can use expanded logs or diagrams to support your work.

Logging sheets are available on Canvas.

Approximate marking scheme:

Logs 80%

Facies scheme 20%

No need to write anything beyond the observations and interpretations on the logging sheets, and the facies scheme you devise (can be written on the back of logging sheets).
