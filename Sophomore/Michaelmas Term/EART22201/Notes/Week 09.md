## 二、核心概念

### 1. 为什么要研究侵入体

- **数量**：讲义的全球岩浆产量清单——**约 35% 被喷出（extruded），约 65% 被侵入（intruded）**。transcript：绝大部分岩浆从未到达地表，"those solidified magmas are ultimately what formed **the first continental crust**"。
- **经济**：绝大部分**铂族元素（PGE：Pt、Pd、Rh）**来自镁铁质侵入体；绝大部分**铜**来自硅质侵入体。
- **"化石记录"**：讲义用三分图表示岩浆储存方式——(a) **深部单一大岩浆房**、地壳储存有限；(b) 主要储存于**上地壳岩床群**；(c) 储存于**下地壳岩床群**。火山灾害建模必须知道**岩浆储存在深还是浅（随成分如何变）**、**上升通道快还是慢、中途是否滞留**；活火山下面看不见，只能靠被剥蚀出露的古侵入体标定（"the past is the key to the present"）。
- **流体通道**：侵入体几何常受**先存地质结构**约束；侵位过程**压裂围岩、提高渗透率**，但**固结后的侵入体本身渗透率很低**——它同时是"通道"与"隔板"，直接关系到油气储层、**CCS**、地热与成矿。transcript：岩浆不过是一种高黏度流体，其流动原理可外推到热液系统与 CCS。

### 2. 侵入体的形态术语（考点：会认名词）

| 类别 | 名称 | 定义 |
|---|---|---|
| **不规则形** | **岩基 Batholith** | 大型，地表出露面积 **>100 km²** |
| | **岩株 Stock** | 小型，**<100 km²** |
| **规则形** | **岩盖 Laccolith** | 平的一面朝下（平底），穹隆状 |
| | **岩盆 Lopolith** | 平的一面朝上（平顶），盆（碗）状 |
| **板状** | **岩墙 Dyke** | 近**直立**，**切穿**先存岩层；可延伸数十至数百 km |
| | **岩床 Sill** | 近**水平**，与先存岩层**整合（conformable）** |

⚠️ 讲义把 laccolith 写成 "flat side down, **bowl shape**"、lopolith 写成 "flat side up, **dome shape**"，形状词与标准定义相反或极易误读，见勘误表。**口诀**：laccolith 像蘑菇（底平顶鼓，顶起上覆地层）；lopolith 像碟子（顶平底凹，因下沉成盆）。

transcript 划重点："**The key ones you really need to remember are sills and dykes**"，并点出 **dyke 是把岩浆从深部输送到浅部的主通道**。📎 老师给了 batholith 的操作性定义——"**multiple plutons of granite all in the same area**"，即岩基由多个岩体复合而成，非一次注入。

### 3. 侵入体的冷却与固结构造

**（1）冷凝边与粒度梯度。** "**Grain size increases with distance from the contact**"，对**所有形状与尺度**的侵入体都成立。物理成因：粒度由**冷却速率**（严格说是过冷度 ΔT 控制的成核率/生长率之比）决定——贴着冷围岩处过冷度最大，成核率远高于生长率，得到大量细小晶体；越往内冷得越慢，晶体少而大。transcript：Palisades 规模的冷凝边"不足以快到形成玄武质玻璃"，但仍是极细粒的。**冷凝边最重要的用途是它代表母岩浆（parental melt）的成分**——来不及分异就凝住了。这是全周反复使用的推理支点。

**（2）柱状节理。** 节理在**固结之后**形成（冷缩开裂）；柱体**常六边形**，边数 **3–8**；**冷却越快柱体越窄**；柱体**垂直于冷却面**。课堂问答见第四段。

**（3）穿切关系定相对年龄。** 区域尺度岩墙群：二叠—石炭纪（蓝）→ 晚石炭世（绿）→ 古近纪（粉）；露头尺度：浅灰**辉长岩** → 白色**伟晶质花岗岩** → 黑色**粗玄岩**。读图规则（transcript）：穿切接触处，**连续不断的那一条最年轻**。

### 4. 辉长岩与粗玄岩：薄片里看什么

**辉长岩 = 慢冷的玄武岩**，必要矿物完全一致：

- **必要矿物（essential）**：**单斜辉石（普通辉石 augite）+ 斜长石（高 Ca）**——与玄武岩相同。
- **特征矿物（type minerals，可能有也可能没有）**：**拉斑质辉长岩**——氧化物（磁铁矿、尖晶石），普通辉石中可见**薄的易变辉石出溶片晶**；**碱性辉长岩**——霞石* + 氧化物。（*本单元不考霞石类岩石。）
- **粒度与结构**：粗粒；**堆晶（cumulate）、填隙（interstitial）、辉绿（ophitic）、包含（poikilitic）**。
- **中粒等价物 = 粗玄岩 dolerite**（美国文献常称 **diabase**）。

**最重要的构造判据**（讲义与 transcript 双重强调）：

> **典型辉长岩为 plag + cpx ± ol，无含水矿物 → 干岩浆**（洋中脊、洋岛）。
> **含角闪石（hornblende）→ 湿岩浆 → 必定是俯冲带背景。**

### 5. 大型镁铁质岩浆房的封闭体系分离结晶：Skaergaard

**设定**（transcript）：把"**一大桶玄武质岩浆**"侵入地壳、**封起来**，让它进行**封闭体系分离结晶**——物质不进不出。**冷却几何**：**从顶向下、从底向上、从两侧向内**同时结晶，三个结晶前锋最后相遇于**夹心层（sandwich horizon）**——**最后几滴残余熔体**的所在。

📎 三个方向的产物在文献中分别称 Upper Border Series、Layered Series、Marginal Border Series；Practical 的 "Lower/Upper Layered Series" 属第二类。材料本身只给了 "crystallises from the bottom up" 这一假设。

**三种层理（本周核心对比，必考）：**

| 类型 | 定义 | 可否观察 | 成因 |
|---|---|---|---|
| **模式层理 modal layering** | **矿物的模式比例**随高度变化 | **能看见**（手标本、薄片） | 结晶相组合与比例随温度改变 |
| **隐层理 cryptic layering** | **每种矿物自身的成分**随高度变化 | **看不见**，必须测化学成分 | 固溶体矿物随熔体演化连续变成分（相图控制） |
| **韵律层理 rhythmic layering** | 重复出现的层状图案 | 能看见 | "**岩浆沉积**"：层底富**致密铁镁矿物**（橄榄石、辉石），层顶富**密度低、富硅的斜长石**——**正粒序** |

Skaergaard 的隐层理：底部 **An65 斜长石 / Fo65 橄榄石 / 富 Mg 单斜辉石** → 顶部 **An30 斜长石 / Fo0 橄榄石（纯铁橄榄石）/ 富 Fe 单斜辉石**；三套模式组合见第三段 §6。transcript："矿物成分**按相图变化**；薄片里看不出来，所以叫 cryptic——**cryptic 是因为看不见，但有化学数据就能测出来**。"

📎 背景补充：为什么"往上越富 Fe / 富 Na"？这正是 EART26201 W03–W04 的固溶体相图结论。Ab–An 与 Fo–Fa 都是完全固溶体，**高温端元分别是 An 与 Fo**；分离结晶把早期富 Ca、富 Mg 的晶体移出体系，残余熔体持续富 Fe、富 Na、富不相容元素，因此越晚结晶（越靠夹心层）的矿物越"演化"。

**磷灰石为什么是晚期标志？** Ca₅(PO₄)₃(F,Cl,OH) 只有在熔体**磷浓度足够高**时才饱和；P 是强不相容元素，只有分离结晶到很晚、残余熔体大幅减少后才富集到饱和。**见到磷灰石 = 演化熔体 = 侵入体上部。**

### 6. 堆晶结构（cumulate texture）

**物理前提**：镁铁质岩浆**黏度低**，晶体能沉降。四步：(1) **自形晶体**在熔体中**自由漂浮**生长；(2) **致密晶体沉降**到底部堆积；(3) 矿物在堆积体**孔隙**中结晶；(4) 形成 **cumulus（堆晶相）+ intercumulus（粒间相）**。

**薄片判据（讲义原文）**：**堆晶相**——自形晶体构成**互相接触的骨架**、有**优选方位**、可被另一矿物**完全包围**；**粒间相**——**他形**晶体充填孔隙、**有时呈光性连续（optical continuity）**、可**完整包裹**其他自形矿物。

📎 "光性连续"是判断粒间相最好用的一招：转动物台时，被斜长石隔开的几块辉石**同时消光、同时变亮**，说明它们是同一颗巨晶（oikocryst）的不同截面——这就是 **poikilitic（包含结构）**；若被包裹者为斜长石板条、包裹者为普通辉石，则专称 **ophitic（辉绿结构）**。

**关键限定**："we **only** find this texture in the products of **mafic** intrusions"——花岗岩里没有堆晶结构。

### 7. 辉石出溶：冷却速率的温度计

讲义把出溶结构定为**慢冷指示器**：**慢冷 → 一代薄片晶**；**超慢冷 → 厚的或团块状（blebby）片晶，和/或"反式易变辉石（inverted pigeonite）"（两代不同方向的片晶）**。三种典型晶体：**均一普通辉石** → **普通辉石 + 薄的易变辉石片晶** → **原为易变辉石、现为斜方辉石的晶体 + 厚的普通辉石片晶**。

Practical 的对称规则：**富 Ca 的 cpx 出溶薄的贫 Ca opx 片晶；贫 Ca 的 opx 出溶薄的富 Ca cpx 片晶**；极慢冷时形成 **inverted pigeonite**——**寄主斜方辉石中含两代、两个不同方向的普通辉石片晶**。

📎 机制来自 EART26201 L4 的 **Di–En 溶线（solvus）**：高温时富 Ca 与贫 Ca 辉石互溶为一相，降到溶线以下后单相不稳定，通过**固态扩散**分离为两相，片晶沿特定晶面析出以最小化界面应变能。**片晶厚度反映扩散时间**：冷得越慢、扩散距离越长、片晶越粗。"Inverted pigeonite" 还多一层信息：易变辉石（单斜、贫 Ca）低温下相变为斜方辉石，**相变改变了晶体学取向**，故两代片晶方向不同。

### 8. 小型镁铁质侵入体：Palisades Sill

**参数**：三叠纪（~200 Ma），与**泛大陆裂解**的大规模裂谷作用有关；**美国东海岸**；**厚约 300 m**；顶底围岩均为三叠系沉积岩。

| 层位（自下而上） | 岩性与矿物 | 意义 |
|---|---|---|
| **底部冷凝边** | 极细粒 | **最能代表母熔体成分** |
| **富橄榄石层** | **20–25% 橄榄石** + plag + augite + 氧化物；**堆晶结构** | 见下文"破绽" |
| **正常粗玄岩** | plag + augite + 氧化物 | 粒度**向上变粗** |
| **夹心层 sandwich horizon** | 除 plag + cpx 外：**高达 30% 石英**、少量**角闪石与黑云母**、**蠕英石 myrmekite** | 最演化的残余熔体 |
| **正常粗玄岩** | | 粒度**向下变粗** |
| **顶部冷凝边** | 极细粒 | |

*蠕英石 myrmekite = 斜长石晶体内部细小的石英"蠕虫状"连晶*；transcript：正交偏光下"像黑白的虫子长在一起"，"你不会经常见到，但万一在 practical 里见到，要知道有这么个东西"。

**夹心层为什么怪？** 最后几滴熔体里堆积了所有**未能进入硅酸盐矿物的不相容元素**，且仍剩**足够的溶解水**，因此能结晶少量**角闪石与黑云母**，并出现**石英**与石英—长石连晶。

**模式层理与主量元素的验证**：**MgO wt.%** 在顶、底最高（最原始）、**夹心层最低**；**斜长石模式含量**在富橄榄石层很低，出该层后**向夹心层递增**。二者都符合**封闭体系分离结晶**。

**隐层理揭穿的破绽（本周最精彩的推理链）：**

1. 用**冷凝边**全岩成分**计算**与之平衡的斜长石/橄榄石成分——相当原始；
2. 富橄榄石层**正上方**与顶冷凝边**正下方**的正常粗玄岩：**富钙斜长石 + 富镁橄榄石** ✓；
3. 越靠夹心层：**斜长石越钠、橄榄石越铁** ✓，夹心层本身最极端 ✓；
4. **但富橄榄石层不对**——讲义："Olivines in the olivine-rich layer are **too iron-rich** to have crystallized early from the Palisades Sill magma."（若属自身分离结晶，它应最原始，甚至比正上方的更富镁。）
5. **结论**：这些橄榄石**不属于封闭体系分离结晶史**，必须由**第二次熔体注入**带入。两阶段模型：阶段一——侵位、形成冷凝边；阶段二——在岩床底部注入一小批来自更深处的**富橄榄石晶浆（olivine-rich slurry）**。

**方法论要点**（老师原话）："we can learn quite a lot about how large intrusions are fed by looking at **disruptions to the cryptic layering**."——**隐层理的不连续 = 补给事件的指纹。**

### 9. 硅质侵入体：花岗岩与花岗质岩类

**定义与产状**：花岗岩与花岗质岩类是**安山岩、英安岩、流纹岩的中—粗粒等价物**；是**大陆地壳中最丰富的岩石类型**；主要形成于**大陆弧**与**陆陆碰撞带**。

**"granite" 的两种用法**（transcript 澄清）：**宽松用法**——任何主要由**碱性长石 + 斜长石 + 石英**组成的粗粒岩石；**严格用法**——**QAP 图上那个特定的 granite 区**。

**两种成因**：(1) 镁铁质岩浆的**极度分离结晶**（"pretty unusual"，对应 **M 型**，真 M 型罕见）；(2) **熔融先存地壳岩石**——"**by far the most common way**"，且**被熔的地壳是什么味道，出来的花岗岩就是什么味道**。

| 类型 | 源区 | 典型构造背景 | 铝饱和度 | 特征矿物 |
|---|---|---|---|---|
| **S 型**（sedimentary） | 熔融**沉积**成因地壳 | 陆陆**碰撞带**（喜马拉雅） | **过铝质 peraluminous** | **富 Al 型**：白云母、堇青石、红柱石、石榴石、黑云母、电气石 |
| **I 型**（igneous） | 熔融**火成**成因地壳 | **大陆边缘/大陆弧**（美国西部） | **偏铝质 metaluminous** | **富 Ca 型**：角闪石、辉石、黑云母 |
| **A 型**（anorogenic） | **非造山**、**干**条件熔融**下地壳** | **大陆裂谷**（澳大利亚东南） | **过碱质 peralkaline** | **富 Na-K 型**：霓石、钠闪石、富 Fe 黑云母 |
| **M 型** | 地幔来源熔体的广泛分离结晶 | — | — | 真 M 型罕见 |

老师明确划重点："**S-type and I-type are the two that you should worry about for this unit.**"

**铝饱和度的化学因果链（本周最需讲透的一条）**——讲义只给结论，推导来自 transcript：花岗质岩浆中含量高的其他元素是 **Na、K、Ca**。**沉积岩在化学风化中特别容易丢失 Ca 和 Na**（长石水解，Ca²⁺、Na⁺ 随水流失，Al 留在黏土里）→ 源区已被"剥掉"Ca、Na → 这些元素**进不了熔体、也进不了结晶矿物** → 相对过量的 Al 只能结晶**富铝矿物** → **过铝质、S 型**。反之，**火成岩丢失的 Ca、Na 少得多** → 可进入熔体与矿物 → 结晶**富 Ca 矿物** → **偏铝质、I 型**。

> **共同点**：S 型与 I 型**都能**结晶**黑云母**。**区别**：**S 型几乎总含白云母；I 型通常含角闪石或辉石之一。** 讲义的反向判据：**S 型 NOT hornblende；I 型 NOT muscovite or tourmaline。**

**为什么花岗岩里没有堆晶结构**：(1) 自形晶体自由漂浮生长；(2) **高硅岩浆黏度太高，晶体沉降无法发生** → **底部没有晶体堆积**；(3) 其余岩浆就地固结 → **早期自形晶体随机分布**。结论：**"No cumulus in granites."** 花岗岩的典型结构称 **granitic texture**（粒度大致均一、互相镶嵌、多为半自形—他形）。

### 10. 三类花岗岩的薄片鉴定清单

**所有花岗岩的必要矿物（缺一不可，且要估模式比例做 QAP 分类）：斜长石（高 Na）、碱性长石、石英**——与**流纹岩**相同；粗粒、**粒状（granular）结构**。三个公共观察点：**石英**——新鲜、未蚀变（与长石区分的第一眼特征）；**碱性长石**——**简单双晶 = 正长石**、**格子（交叉影线）双晶 = 微斜长石**，常见**条纹长石 perthite 出溶片晶**与**尘状绢云母化**；**斜长石**——**聚片双晶**。

| | **S 型** | **I 型** | **A 型** |
|---|---|---|---|
| 特征矿物 | **白云母**、**电气石**、黑云母及其他**富 Al 矿物**（堇青石） | **角闪石**、黑云母及其他**富 Ca 矿物** | **碱性辉石**（霓石）、**碱性闪石**（钠闪石）、**富 Fe 黑云母** |
| 禁止项 | **不含角闪石** | **不含白云母或电气石** | — |
| 黑云母多色晕 | **常见** | **较 S 型少见** | — |
| 石英/长石 | — | — | **碱性长石极多、石英极少** |
| 关键单矿物特征 | **电气石**：PPL 有色且多色，**中等突起、无解理**；**白云母**：无色云母，干涉色亮（绿松石、粉、橙） | **角闪石**：PPL 呈**褐色和/或绿色**多色性 | **霓石**：PPL **特征蓝绿色多色性**；**钠闪石**：强多色性、**深墨蓝色** |

📎 Reference Guide 口径：钠质辉石与钠质闪石"强烈着色且多色性强，典型颜色是**草绿、蓝绿、深墨蓝**"——在以无色矿物为主的花岗岩薄片里极醒目，**看到深蓝绿色的链状硅酸盐就该想到 A 型**。多色晕的物理成因见第四段。

### 11. 花岗质岩浆中的水

讲义两句：**在任意给定压力下，流纹质（花岗质）岩浆能溶解的水都比玄武质岩浆多**；**在 600–700 °C 处 H₂O 溶解度的快速下降可导致大量 H₂O 出溶**（此句可疑，见勘误表）。transcript：这是一张**压力 vs 溶解水含量**图，在任一压力下**玄武质在其固相线温度附近能溶的水远少于同等条件的流纹质**，原因是**熔体中硅的聚合（polymerization）**。

**三个后果**：(1) 花岗质/流纹质岩浆**更容易结晶含水矿物**；(2) **喷发驱动力更大**——水出溶成气泡、膨胀聚并 → **强爆发式喷发**（Week 10 展开）；(3) 若流体未喷出而形成**热液系统**，则是**溶解并富集工业金属的绝佳机制**——花岗质岩浆周围常见**铜、金**矿脉。

📎 背景补充：硅在熔体中形成 SiO₄ 四面体聚合网络，H₂O 以 OH⁻ 形式**打断桥氧**：Si–O–Si + H₂O → 2(Si–OH)。富硅、高聚合度的流纹质熔体桥氧多、可断位点多，故**溶解度更高**；这也是水能急剧降低流纹质熔体黏度的原因（Week 10）。至于"600–700 °C 溶解度骤降"，更常规的表述是 **second boiling（二次沸腾）**：花岗质岩浆冷却时结晶的是**无水矿物**，水被排斥进不断减少的残余熔体，最终**达到水饱和而析出独立流体相**——这正是热液系统与斑岩型矿床的机制。

### 12. 花岗岩的结构：从露头到手标本

**（1）包体与捕虏体。** **Enclave** 是**厘米到米级**、其**岩性/成分/粒度**与寄主花岗岩对比的包体，四类：**围岩捕虏体（xenolith）**，常由岩体**顶部的顶蚀作用 stoping** 带入；**残余体（restite）**，岩浆生成后**未熔融的残余物**；**同源包体（cognate inclusion）**，**同一岩浆更早分异阶段结晶的火成物质**；**复合捕虏体**，含两种以上对比性岩性。野外观察经验见第四段。

**（2）巨晶与面理。** **碱性长石巨晶（megacryst）**的物理前提：**碱性长石在硅质岩浆中成核率低、生长速率高**。两条路径：(1) 碱性长石**最先成核**，在其他矿物结晶前已长得很大；(2) 所有矿物**大致同时成核**，但碱性长石**长得最快**。⚠️ 由此得到重要警告——**在花岗岩里，大 ≠ 早**：晶体大小差异可能反映"何时开始长"，也可能反映"长得多快"。

**面理（foliation）**：花岗岩**黏度太高，无法形成堆晶结构或韵律层理**，但仍可产生矿物定向：(1) **同结晶剪切**——新岩浆注入把已形成的晶体推挤成优选方位；(2) **结晶后构造变形**——面理通常**垂直于最大主应力方向**发育。

### 13. 构造背景一：陆陆碰撞带的 S 型花岗岩（喜马拉雅）

| | **Trans-Himalayan batholith** | **High Himalayan leucogranites** |
|---|---|---|
| 构造背景 | **大陆弧**：特提斯洋向亚洲之下**俯冲** | **陆陆碰撞**：侵入到正在变质的岩石中 |
| 年龄 | ~**130–55 Ma** | ~**25–15 Ma** |
| 类型 | 主要 **I 型**，**钙碱性（calc-alkaline）**特征 | **全部 S 型** |
| 同位素 | — | **⁸⁷Sr/⁸⁶Sr 与沉积（地壳）源区一致** |

**为什么碰撞带能熔？**（transcript 的重点澄清，讲义没写）碰撞带**没有明显外来热输入**。但：(1) **加厚地壳**这个动作本身就把物质**埋深、加热**；(2) **陆壳富含放射性生热元素（U 等）**，加厚后**放射性生热总量成倍增加**；(3) 二者叠加**足以把地壳推过熔点**。老师明确对比："我们**不是**靠地幔部分熔融供热，而是靠其他机制引入足够的热来熔化先存岩石。"

**淡色花岗岩（leucogranite）**："leuco 即浅色/白色"。珠峰剖面：**峰顶灰岩**，其下一套**（变质）泥岩**，泥岩熔融产生花岗质岩浆；山壁上可同时看到**黑色 restite**与**浅色花岗岩**。矿物学：**大量白云母 + 堇青石 + 电气石**，有时还有**继承自沉积源区的石榴石**——**富铝矿物来自富铝沉积物的熔融**。

**熔融反应**见第三段 §7。transcript 的机制：变质泥岩富含**白云母**，白云母晶格含**水**；加热到一定程度水被逼出；**给岩石加水就降低固相线温度**——与俯冲带给地幔橄榄岩加水**完全同理**。降压路径对应**山脉被剥蚀**。产物 **⁸⁷Sr/⁸⁶Sr 高**，与陆壳熔融一致。

### 14. 构造背景二：大陆边缘的 I 型花岗岩（美国西部 Cordilleran）

**实例**：北美板块之下俯冲的**大陆弧**背景——**Sierra Nevada 岩基 ~114–87 Ma**、**Idaho 岩基 ~98–53 Ma**；岩性为 **I 型的英云闪长岩、花岗闪长岩与花岗岩**；成因是**熔融下地壳中贫 Al、富 Ca 的火成岩**，因此结晶**贫 Al、富 Ca 的特征矿物**。

**复合环带岩体**——Yosemite 的 **Tuolumne Intrusive Series** 五期：(a) **石英闪长岩** → (b) **花岗闪长岩** → (c) **斑状花岗闪长岩** → (d-1) **花岗闪长岩** → (d-2) **花岗斑岩**。**规律：岩体内部通常比外部更年轻、更长英质。** transcript 的图像化解释：像**气球式膨胀**，新成分从中心注入、把先前部分向外推，形成**放射状成分"地层"**与复杂穿切关系；成分从富斜长石、贫碱性长石的**闪长质**向**真正的花岗岩**演化（QAP 图上从 P 角向 Q–A 方向迁移）。

**I 型岩浆的四步生成模型（讲义）**：(1) **地幔楔中湿橄榄岩部分熔融**产生**镁铁质岩浆**；(2) 它**在下地壳结晶**成**辉长岩与闪长岩**（造出偏镁铁质的下地壳）；(3) **后续热镁铁质岩浆注入**使这些**火成成因下地壳部分熔融**，产生中性与演化岩浆；(4) 这些岩浆**上升到上地壳形成岩基**（途中继续分离结晶）。

**两类证据**：**分离结晶**——**环带岩体代表分异各阶段**，早期是英云闪长岩、晚期是花岗岩；**陆壳熔融/混染**——**⁸⁷Sr/⁸⁶Sr 随离岩浆弧的距离增大而升高**，指示陆壳同化程度更高。transcript 归纳：**越靠地幔端，同位素越像地幔；越靠地壳端，越像地壳**；因此**大陆边缘花岗岩的化学变化范围比碰撞带大得多**——多了一个来自地幔楔的**原生火成组分**。

### 15. 应用落点：Sierra Nevada 与加州淘金热（1848–49）

Sierra Nevada 岩基**赋存脉型金矿**，金产于**石英脉、断层与剪切带**中（著名的 **"the mother lode"** 主矿脉）。机制分工：**花岗质岩浆提供热的、富硅的热液流体**；流体**从地壳别处溶解、搬运并浓缩金**到断层控制的脉体中；**金的最终来源**被认为是**如今增生到北美板块上的古大洋地体**，原始成矿很可能发生在**类似黑烟囱的海底喷口**。老师末句："现在这些地方**尤其在找铜**。"

📎 这条"岩浆提供热与流体、围岩提供金属、构造提供通道与圈闭"的三要素模型，是 EART26001 能源与资源里**造山型金矿**与**斑岩型铜矿**的通用框架。

## 三、公式与图表

### 1. 铝饱和度（Alumina Saturation）

> **alumina saturation = molar ratio of Al₂O₃ to (Na₂O + K₂O + CaO)**（讲义原文）

- **符号与单位**：全岩主量元素氧化物，分析值通常为 **wt.%**，但**必须先除以各自分子量换算成摩尔数**再作比（Al₂O₃ 101.96、Na₂O 61.98、K₂O 94.20、CaO 56.08 g/mol）。
- **适用条件**：用于**长英质岩石**的化学分类；**需要全岩化学分析**——薄片本身给不出这个比值，只能通过**特征矿物**间接判断。

| 判据 | 名称 | 类型 | 特征矿物 |
|---|---|---|---|
| Al₂O₃ > Na₂O+K₂O+CaO | **过铝质 peraluminous** | **S 型** | 白云母、堇青石、红柱石、石榴石、黑云母 |
| Na₂O+K₂O < Al₂O₃ < Na₂O+K₂O+CaO | **偏铝质 metaluminous** | **I 型** | 角闪石、辉石、黑云母 |
| Al₂O₃ < Na₂O+K₂O | **过碱质 peralkaline** | **A 型** | 霓石、钠闪石 |

> 📎 背景补充：文献通用记法为 **ASI = A/CNK = molar Al₂O₃/(CaO+Na₂O+K₂O)**，配合 **A/NK**，画成 A/CNK–A/NK 二元图（Shand 图）：**ASI>1 过铝；ASI<1 且 A/NK>1 偏铝；A/NK<1 过碱**。⚠️ 讲义该页在 md 中已被压成残缺表格（混入游离的 "CaO"、"riebeckite"），坐标轴与分区线全部丢失，上表中间行的不等式为补充。

### 2. 干涉色与双折射率（Practical Part 1 直接考）

> **Γ = d × Δn**

- **Γ**：**光程差（retardation）**，单位 **nm**，决定看到的干涉色；**d**：薄片厚度，标准 **30 µm = 30000 nm**；**Δn**：**双折射率**，无量纲，**最大值只在特定切面出现**。
- **Michel-Lévy 图读法**：横轴 Δn（或 Γ），纵轴薄片厚度 d，图内为色带，自原点发散的每条斜线对应一个 Δn。**沿 d = 30 µm 的水平线找到观察到的最高干涉色，横向读出 Δn**。色序界线每 **550 nm** 一级：一级 0–550、二级 550–1100、三级 1100–1650 nm。

| 矿物 | Δn（材料给值） | Γ = 30000 × Δn | 材料给的干涉色 |
|---|---|---|---|
| **镁橄榄石 forsterite** | **0.035** | **1050 nm** | "second-order sensitive tint (pink)"（⚠️ 见勘误表） |
| **铁橄榄石 fayalite** | **0.052** | **1560 nm** | **三级粉红** |

**用途**：**橄榄石越富铁，Δn 越高，最高干涉色越高** → 可半定量判断 Fo 值。⚠️ **关键限定**：干涉色**同时取决于切向**，所以**只有"最高干涉色"才携带成分信息**——必须扫过整张薄片、看很多颗橄榄石再取最高值。

📎 对照值（Reference Guide）：**橄榄石 Δn = 0.035–0.052（可达三级）**；**普通辉石 Δn = 0.018–0.033（最多二级）**——这也是二者的定量区分依据。

### 3. 斜长石消光角法测成分（Reference Guide 标准操作）

**图件**：横轴 = **斜长石成分（An mol%，An₀→An₁₀₀）**，纵轴 = **最大消光角（°）**；曲线在低 An 端为**负角度**，随 An 增大穿过 0° 单调上升。

**操作规程**：(1) 找**双晶面转到 N–S 时两组双晶灰度相同**的晶体，其左右消光角 **a 与 a′ 应相差几度以内**；(2) 转动物台分别测 a、a′；(3) 若二者相差过大则**弃用此晶体**；(4) 取 **(a+a′)/2**；(5) **多测几颗，取最高值**投曲线读 An。

⚠️ **固有局限**：**无法区分正负消光角**——15° 既可能是 −15°（**钠长石**）也可能是 +15°（**奥长石**），需另用**贝克线法（Becke Line Test）测折射率**区分。

**Practical 9 实测**：EG4381 **~35° → ~An60（拉长石 labradorite）**；EG4314 **~25° → ~An40（中长石 andesine）**。

📎 命名区间：An0–10 钠长石、10–30 奥长石、30–50 **中长石**、50–70 **拉长石**、70–90 培长石、90–100 钙长石——与材料给的命名一致 ✓。

### 4. QAP(F) 三角图与 Streckeisen 镁铁质三角图

**QAPF 图件描述**：**上下相对的两个三角形**。上三角顶点 **Q（石英）**，下三角底顶点 **F（似长石 foid）**，共用的两个顶点是 **A（碱性长石，左）** 与 **P（斜长石，右）**。**一块岩石不可能同时含石英与似长石**，因此只落在上三角（QAP，硅饱和）或下三角（APF）之一。**本单元只用 QAP。**

**步骤**：估计 Q、A、P 模式百分比 → **归一化到 100%** → 投点得**根名（root name）** → 再用**特征矿物**细分（如 "biotite muscovite granite"，**最不丰富者写在最前**）。

**分区读法**（transcript）：**granite（狭义）**= Q、A、P 三者比例大致相当；**碱长花岗岩 alkali granite** ≈ 50% A + 50% Q、几乎无 P（靠 Q–A 边）；**英云闪长岩 tonalite** ≈ 主要 Q + P、几乎无 A（靠 Q–P 边）；沿 A→P 方向、石英下降依次为 **syenite → monzonite → diorite/gabbro**。

⚠️ 实操提醒："these differences can be difficult to estimate in a thin section **because of the coarse grain size. But nevertheless, have a go.**"——粗粒岩石一个视域装不下代表性比例，须**多视域扫**或**举起薄片对光看整体**。Reference Guide 另附**模式比例目估对照图版**，可显著减少系统性高估。

**Streckeisen 镁铁质三角图**（Reference Guide）：超镁铁质岩（>90% 铁镁矿物）用 **ol–opx–cpx**；镁铁质岩用 **plg–px–ol**，落在阴影区者再用 **plg–cpx–opx–hbl** 细分。**本周用法**：判断辉长岩是 **plag+cpx±ol**（干，MOR/OIB）还是 **plag+cpx+hbl**（湿，俯冲带）。

### 5. 岩浆含水量—压力图

横轴 = **溶解水含量（wt.%）**，纵轴 = **压力**（≈深度）；图上有**玄武质**与**流纹质**两条溶解度曲线（各取在其固相线温度附近）。**读法**：在任一压力水平线上，流纹质曲线对应的水含量**明显大于**玄武质 → **同样深度，花岗质岩浆能"装"更多水**。

### 7. 地壳熔融反应式

> **有流体**：**mu + qz + plag + H₂O → melt**，**F ≈ 0.4**
> **无流体**：**mu + qz + plag → melt**，**F ≈ 0.12**

- **mu** 白云母、**qz** 石英、**plag** 斜长石；**F = 熔体分数（melt fraction）**，无量纲 0–1。
- **含义**：有自由水相时熔体产率**高得多（40% vs 12%）**；无流体时全部水只能来自**白云母脱水**，产率受限。
- **适用条件**：泥岩/变泥岩的部分熔融，即 **S 型花岗岩的生成反应**；**加热**（地壳加厚 + 放射性生热）**和/或降压**（造山带剥蚀）均可触发。

### 1. 柱状节理的完整课堂问答（讲义只有三句话）

有同学问：为什么有些柱状节理是"**colonnade（下部规则大柱）+ entablature（上部不规则细柱）**、上面什么都没有"，而另一些的 entablature 是**夹在中间**的？老师的回答（并坦承 "I'm not au fait with the math"）：

- 取决于**岩浆成分、侵入体厚度、冷却方式**三者；
- **熔岩流**：顶面靠**对流**向空气散热，冷得**相对快**，来不及形成规整柱体 → 顶部呈**很不规则的冷却结构**；
- **从底向上冷却**走的是与地面的**传导**；**土壤导热性差**，所以**自底向上的冷却速率比自顶向下慢**——这决定了柱体"建筑结构"的上下差异；
- 但这又取决于厚度：**几十米厚的熔岩流**与**只有个位数米厚**的表现不同；
- **岩床（sill）**：顶、底两个冷却前锋**在中间相遇** → **不规则的 entablature 被夹在中间**；
- 总规律：**冷却速率↑ → 柱体边数↓（6→5→4）、直径↓、规则性↓**。

### 3. 多色晕（pleochroic halo）的虚拟显微镜演示（讲义完全没有）

老师现场切到 virtual microscope 演示一颗黑云母：

1. 转动物台，**黑云母本身多色**：一个方向**红棕色**，另一个方向**麦秆黄**；
2. **关键**：黑云母里的**深色圆斑本身也是多色的**——一个方向**灰蒙蒙（dusty grey）**，另一个方向**墨黑（inky black）**；
3. 另一例中可见，**每个圆斑正中央都有一颗极小的白色矿物包体**——那是**锆石（zircon）**；
4. **成因链**：**锆石能把铀纳入晶格 → 铀衰变释放 α 粒子 → α 粒子损伤周围黑云母晶格 → 形成"辐射损伤晕"**；
5. **地质含义**：说明熔的是**含锆石、铀含量高的沉积岩** → **多色晕在 S 型花岗岩中特别常见**；
6. 两句补充：这些岩石**不会让你受到辐射**（浓度极低）；有时看不到锆石包体，只是**锆石太小、薄片没切到**。

📎 背景补充：**锆石是最耐风化的重矿物之一**，因此在沉积岩中富集；它又是 **U-Pb 定年**的主力矿物，原因同样是容纳 U 而排斥 Pb。所以"薄片里的多色晕"其实是"这块地壳曾经过沉积循环"的可视化指纹。

### 4. 花岗岩露头上的野外观察经验（讲义只列了名词）

- **捕虏体边缘是圆化的**——老师反复指的重点。推理：**脆性破裂应给出棱角边缘，而这些棱角已经不见了** → 说明捕虏体**已开始溶解进花岗质岩浆**；有时能看到反应"正在进行中"。

#### 综合解释题（核心推理）

**题**：EG4381 与 EG4314 一个来自 **Lower Layered Series（500 m）**、一个来自 **Upper Layered Series（2000 m）**，假定自下而上结晶，哪个是哪个？

**答：EG4381 = 下部；EG4314 = 上部。** 两条独立判据：
1. **隐层理**：EG4381 斜长石**更钙质（An60 > An40）**、橄榄石**更镁质（二级 < 三级）** → **结晶更早、来自更镁铁质的液体** → 侵入体**下部**。
2. **晚期矿物**：EG4314 含**磷灰石**，只在**磷浓度足够高的晚期**才结晶 → 侵入体**上部、近夹心层**。

### Part 2：花岗岩薄片

#### S 型：Cornubian Batholith（英格兰西南）

**背景**：**复合的、过铝质的 S 型**岩体；多为**黑云母花岗岩**，但**丰富的白云母指示其过铝质性质**；部分成分**极度分异**，**B、Li、F 浓度高**，可含**富 Li/F 白云母、黄玉（富 F）、电气石（富 B）**；部分地点**热液蚀变强烈**。

**薄片 14911 / 14910（Land's End）**

| 观察 | 解释 |
|---|---|
| 三种无色硅酸盐：**碱性长石、斜长石、石英** | 花岗岩的三种必要矿物 |
| 碱性长石呈**微条纹（micro-perthitic）** | **相对较慢的冷却速率**（出溶需扩散时间） |

| 石英**波状消光**或**开始重结晶为亚晶** | **两者都是变形的证据** |
| 其他原生矿物：**黑云母含大量锆石包体（带多色晕）**，常见**柱状磷灰石**与**板状钛铁矿**，部分含**黄玉** | S 型的典型副矿物组合 |
| 次生矿物：**堇青石的自形假象**（方形/矩形到六边形，原为岩浆成因堇青石，现完全被细粒黏土与绢云母取代）；**白云母与电气石为常见晚期热液矿物** | 形态保留 + 成分被替换 = 假象 |

📎 背景补充：**正环带**指**核部高温成分、边部低温成分**（斜长石即核 An 高、边 An 低），反映单调冷却；**振荡环带**成分反复来回，最常见于**俯冲带火山岩**，反映反复补给/减压。深成花岗岩出现**正环带**是合理的。

#### I 型与 A 型

**背景**：**I 型 Donegal（爱尔兰西北）**——Newer Caledonian Series，侵入 **Dalradian 变质岩**，**加里东造山**期；**390–410 Ma**；与 **Iapetus 洋闭合期的洋岩石圈俯冲**有关；含英云闪长岩、花岗闪长岩、花岗岩，另有**闪辉正煌岩（appinite）**小侵入体。**A 型 Skye 的 Eastern Red Hills**——Hebridean Tertiary igneous province 晚期，**57–55 Ma**，与**北大西洋张开**有关；构造与化学上属**过碱质 A 型**，但⚠️**碱质富集不强，矿物学上与偏铝质 I 型非常相似**（重要应试提醒：别指望在这片里找到霓石或钠闪石）。

**薄片 16265（Ardara pluton）或 M2（Beinn an Dubhaich, Skye）**——两片都要看，**结构差异很大**。

- **无色硅酸盐**：**石英、斜长石、碱性长石**；**斜长石模式含量略高于 S 型**；QAPF 结果取决于估值，**可能是 granite 也可能是 granodiorite**。
- **两种镁铁矿物**：**角闪石**（多色性**深绿—中绿—黄**）与**黑云母**（**绿褐色——I 型花岗质岩的特征**，区别于 **S 型的麦秆黄褐色**）。**注意不含白云母等富铝矿物。**
- **16265 专项**：尝试识别**原生岩浆成因的绿帘石与榍石**；注意**镁铁矿物的强烈优选方位**——岩浆在**膨胀应力场（inflationary stress field）**下结晶所致，**黑云母垂直于主压应力方向排列**；该方位**举起薄片对光看比在显微镜下看更清楚**。
- **M2 专项**：可能见少量绿帘石；**长石呈尘状、广泛蚀变为黏土矿物** → **由水造成** → 说明**存在活跃的热液系统**（很可能**同时含大气降水与相当比例的岩浆水**）。

⭐ **核心鉴定推理链（考试须写清）**：**观察**绿褐色角闪石 + 绿褐色黑云母、**无白云母无电气石** → **富 Ca 型特征矿物、无富 Al 型** → **偏铝质** → **I 型，源自火成成因下地壳的部分熔融，构造背景为俯冲相关的大陆边缘/大陆弧**。

**薄片 16272（Appinite, Ardara pluton）**

- **产状定序**：以**小侵入体**出现在岩体**边缘**，也作为**主岩体内的包体** → **比外围的花岗闪长岩结晶更早**（纯产状推理：作为包体存在 = 更老）。
- **命名**：名自苏格兰阿盖尔的 **Appin**；按 QAPF"**可能是角闪石闪长岩**"。
- **成因判据**：**闪辉正煌岩是镁铁质深成岩，因此必由地幔熔融形成，而非地壳熔融。**
- **主要矿物**：**绿褐色多色性角闪石**最丰富；**填隙状斜长石（广泛绢云母化）**；**填隙的石英与方解石**；低含量的磁铁矿、白云母、黑云母、磷灰石、绿帘石。

## 六、易错点 / 重点难点

1. **三种层理张冠李戴（头号考点）**：**modal = 比例，看得见**；**cryptic = 单矿物成分，看不见、要测**；**rhythmic = 重复层序，底富致密铁镁矿物、顶富斜长石（正粒序）**。抓手：**crypt-（隐秘）= 藏起来的成分信息**。

2. **cumulus vs cumulate**：**cumulate texture（堆晶结构）**是结构名；**cumulus / intercumulus phase** 是该结构里的两类矿物角色。**花岗岩里绝对不能写 cumulate texture。**

3. **粒间相 ≠ 后期蚀变产物**：intercumulus 矿物是**原生岩浆矿物**，只是**结晶得晚、充填孔隙**故呈他形。真正的次生矿物（蛇纹石、绢云母、绿泥石、黏土）**不参与岩石定名**。

4. **出溶片晶厚度与冷速的方向**：**冷却越慢 → 扩散时间越长 → 片晶越厚**。⚠️ Practical 原文写 "proportional to the cooling rate" 却又写 "slower cooling produces thicker lamellae"，**自相矛盾**，正确的是**反比**（见勘误表）。**记结论不记那句话。**

5. **inverted pigeonite 的三层信息**：寄主现在是**斜方辉石**；它**曾经是易变辉石**；有**两代、两个方向**的普通辉石片晶 → **超慢冷 + 经历过相变**。别简单当成"厚片晶"。

6. **测斜长石消光角的三个陷阱**：(a) **切面必须合格**（双晶面 N–S 时两组双晶灰度相同、a≈a′），否则读数无效；(b) **必须多颗取最大值**，单颗必然偏低；(c) **正负角度不可区分**，15° 可能是钠长石也可能是奥长石，需**贝克线法**定夺。

7. **干涉色只有"最高值"有意义**：橄榄石干涉色随切向变化很大，随便挑一颗读出的颜色**没有成分含义**。同理，区分 opx 与 cpx 时要选**只显示一组解理迹、干涉色最高**的晶体测消光角。

8. **蠕英石 ≠ 显微文象连晶**：**myrmekite** 是**斜长石内部**的**石英**蠕虫状连晶；**granophyric/graphic** 是**石英 + 碱性长石**的连晶。两者都出现在最演化的残余熔体里，但**主体矿物不同**。

9. **S 型 vs I 型用"排除法"比"确认法"可靠**：**白云母或电气石 → S 型**；**角闪石或辉石 → I 型**。**黑云母两者都有，不能单独作判据**——但**颜色可以**：**I 型偏绿褐，S 型偏麦秆黄褐**；**多色晕在 S 型中更常见**。

10. **A 型的"名实不符"陷阱**：教科书上 A 型 = 过碱质 + 霓石/钠闪石，但 Practical 警告 **Skye 的 Eastern Red Hills"碱质富集不强，矿物学上与偏铝质 I 型非常相似"**——**构造/化学分类 ≠ 薄片里看得到的矿物学**。

11. **化学风化因果链别记反**：**沉积岩丢 Ca、Na → 相对富 Al → 过铝质 → 富 Al 矿物 → S 型**；**火成岩丢得少 → Ca、Na 保留 → 偏铝质 → 富 Ca 矿物 → I 型**。

12. **花岗岩里"大晶体 = 先结晶"是错的**：碱性长石**成核率低、生长速率高**，巨晶可能只是**长得快**。这与 Reference Guide 的通用规则"大晶体先长"存在张力，**花岗岩要特别小心**。

13. **碰撞带的热源不是地幔**：是**加厚导致的埋深加热 + 陆壳放射性生热**，不要写成"地幔上涌供热"。

14. **加水熔融的方向别记反**：**加水 → 降低固相线 → 熔融**。而白云母提供水的方式是**脱水（dehydration）**，不是"引入外来水"。

15. **冷凝边的两个作用别混**：**粒度上**它最细；**成分上**它代表**母熔体**——所有"用冷凝边反算平衡矿物成分"的推理都建立在这一点上。

16. **QAP 分类的实操困难要承认**：粗粒岩石一个视域装不下代表性比例，**标准答案本身就写"可能是 granite 也可能是 granodiorite"**——答题时要**写出你的模式估计值**让判据可追溯，而不是只给一个岩石名。
