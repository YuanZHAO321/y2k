## 二、核心概念

### 2.1 熔融发生在哪里？（What melts?）

- 大多数岩浆在**地壳内**的岩浆房、岩床（sill）、岩墙（dyke）中冷却结晶；部分被输送到地表喂养火山喷发。
- **分离结晶（fractional crystallization）**产生化学成分与矿物组合各异的火成岩；**结晶速率**产生不同的火成结构（这两条是 W4 的结论）。
- **地球绝大部分岩浆的最终源区是硅酸盐地幔的部分熔融（partial melting of the silicate mantle）**。
- 在某些情况下，也可以由**地壳岩石**部分熔融产生岩浆（详见 W8–W9）。

课堂原话把逻辑顺序讲得很清楚：上周讲岩浆的结晶，但结晶之前还有一步——你得先有岩浆；地球喷出岩浆的**体积主体**来自硅酸盐地幔的熔融；因此要理解熔体成分，就必须先理解地幔的性质与成分。

### 2.2 地幔是橄榄岩（peridotite）

**超镁铁质岩（ultramafic rocks）**：镁铁质矿物（ol + cpx + opx）含量 >90% 的岩石。

**橄榄岩的矿物组合 = ol + cpx + opx + 一个含铝相（Al-bearing phase）**。这是本周最需要背下来的一句话。

**分类（Streckeisen 超镁铁质岩三角图，见 Reference Guide p.11）**：以 ol、opx、cpx 三个端元作三角图。

- **橄榄岩（peridotite）**：ol > 40%。课堂反复强调这个 40% 门槛。
  - **纯橄岩（dunite）**：几乎全是橄榄石（ol > 90%）
  - **方辉橄榄岩（harzburgite）**：ol + opx，cpx 很少
  - **二辉橄榄岩（lherzolite）**：ol + opx + cpx 三者都有可观比例
  - **异剥橄榄岩（wehrlite）**：ol + cpx，opx 很少
- **辉石岩（pyroxenite）**：ol < 40%（含 orthopyroxenite / websterite / clinopyroxenite 等）

📎 背景补充：上面 dunite/wehrlite/websterite 等具体分区名称与百分比界线来自 Reference Guide 引用的 Streckeisen (1973) 分类图，本周讲义与转写只明确出现了 peridotite、lherzolite、harzburgite、dunite、clinopyroxenite 五个名字。分区的确切几何请以实习手册 p.11 的原图为准。

**为什么分类重要？** 因为**模式矿物学（modal mineralogy）直接记录了这块地幔有没有被熔过**——这是 2.7 节的内容。

### 2.3 地幔矿物的成分：接近富 Mg 端元

地幔矿物的成分都靠近其固溶体的**富镁端元**。定量指标是**镁值（Mg-number, Mg#）**：

```
Mg# = Mg²⁺ / (Mg²⁺ + Fe²⁺)   ≈ 90–92（地幔矿物）
```

典型地幔橄榄石成分为 **Fo₉₂**（镁橄榄石 92 mol%）。

Week 3 的提醒（讲义原文列出）：
- 橄榄石 Olivine：**Mg₂SiO₄**（forsterite 镁橄榄石）
- 斜方辉石 Orthopyroxene：**Mg₂Si₂O₆**（enstatite 顽火辉石）
- 单斜辉石 Clinopyroxene：**CaMgSi₂O₆**（diopside 透辉石）

📎 背景补充：Mg# 按惯例是**摩尔比**（用氧化物重量百分比换算成摩尔数后再算），并且通常乘以 100 表示成 90–92 这样的整数。用本周讲义给出的二辉橄榄岩全岩成分自检：MgO 41.41 wt.% ÷ 40.30 = 1.028 mol；FeO 7.59 wt.% ÷ 71.84 = 0.1057 mol；Mg# = 1.028/(1.028+0.1057) × 100 = **90.7**——与"90–92"和 Fo₉₂ 完全自洽。

### 2.4 含铝相随压力变化（本周最考的一条）

橄榄岩里那个"第四个矿物"是什么，**由压力决定**：

| 压力范围 | 稳定的含铝相 | 化学式 | 备注 |
|---|---|---|---|
| 0 < P < 0.8 GPa | **斜长石 Plagioclase** | CaAl₂Si₂O₈ | 斜长石橄榄岩在自然界**很罕见**，因为这个压力区间通常被地壳占据；课堂明说"本单元你不会看到任何一个" |
| 0.8 < P < 2 GPa | **尖晶石 Spinel** | MgAl₂O₄ | 课堂给出对应深度约 **20–50/60 km** |
| P > 2 GPa | **石榴石 Garnet** | Mg₃Al₂Si₃O₁₂ | 课堂给出对应深度 **> 60 km** |
| （不受压力控制） | **金云母 Phlogopite** | KMg₃AlSi₃O₁₀(OH)₂ | 黑云母固溶体的富 Mg 端元；**指示含水地幔（hydrous mantle）** |

这条规律的用法是**反过来读**：在薄片里看到什么含铝相，就能反推这块地幔来自多深。这是 Practical 5 的核心判据之一。

📎 背景补充：为什么高压偏爱石榴石？因为 Al 在石榴石中处于 **[6] 八面体配位**、整个结构堆积更致密（石榴石密度 ~3.6 g/cm³），而斜长石中 Al 处于 **[4] 四面体配位**、架状结构疏松（~2.7 g/cm³），尖晶石居中。压力总是选择摩尔体积更小的相（Le Chatelier 原理），所以随深度增加依次是 plag → spinel → garnet。这段推理材料未给出，是把 W1/W3 的配位数概念接到本周的桥。

### 2.5 本周的三个"新/复习"矿物光性

#### 石榴石 Garnet（复习自 Week 3）
- 岛状硅酸盐；地幔石榴石通常是 **Mg₃Al₂Si₃O₁₂（镁铝榴石 pyrope）–Fe₃Al₂Si₃O₁₂（铁铝榴石 almandine）** 的固溶体
- 立方晶系 → **光学各向同性**
- **PPL**：**粉色（pinkish）**；**很高突起（very high relief）**；常见**裂纹（fractures）**；**无解理**
- **XP**：**各向同性——永远消光（always in extinction）**

#### 尖晶石 Spinel（本周新矿物，Blackboard Week 5 有新的造岩矿物视频）
- **氧化物（非硅酸盐）**，立方晶系，**MgAl₂O₄**；地幔尖晶石通常是 **MgAl₂O₄–FeAl₂O₄** 固溶体
- **PPL**：**颜色很深（常为红、棕、绿）**，有时接近**不透明**；**不多色性（not pleochroic）**；**高突起**；**无解理**
- **XP**：**各向同性——永远消光**；**无环带**
- **鉴定逻辑（讲义原文两条判别）**：
  - 与**石榴石**区分 → 看**颜色**：石榴石粉红，尖晶石深棕或深绿（课堂说这是"最容易的办法"）
  - 与**其他强着色矿物**区分 → 看**正交偏光下的各向同性消光**（有色但永远全黑，只有等轴矿物做得到）
- 产出：超镁铁质火成岩（橄榄岩）、镁铁质火成岩（玄武岩、辉长岩）

#### 尖晶石族（spinel group）的晶体化学
通式 **AB₂O₄**（氧化物，非硅酸盐，立方）：
- **A = 二价阳离子 M²⁺**：Mg²⁺、Fe²⁺、Mn²⁺、Zn²⁺、Ni²⁺ —— **四面体 [4] 配位**
- **B = 三价阳离子 M³⁺**：Al³⁺、Fe³⁺、Cr³⁺（讲义还列了 Ti，见勘误表）—— **八面体 [6] 配位**
- 尖晶石族成分与固溶体范围极广，但**结构完全相同**——这就是"族"的定义。它们是各种变质岩和火成岩中常见的**副矿物（accessory minerals）**。

#### 磁铁矿 Magnetite
- **Fe₃O₄**，氧化物（非硅酸盐），立方（属尖晶石族）
- 产于**各种镁铁质、中性、演化的火成岩**中
- **PPL**：**不透明（opaque）**——这就是最主要的鉴定依据；发育好的晶体可显**等轴立方自形（equant cubic habit）**
- **XP**：各向同性——永远消光（实际上不透明矿物在 XP 下同样全黑）

📎 背景补充：Fe₃O₄ 写成 Fe²⁺Fe³⁺₂O₄ 更能看出它是尖晶石族成员（A 位 Fe²⁺、B 位 Fe³⁺）。磁铁矿是**反尖晶石（inverse spinel）**结构——一半 Fe³⁺ 跑到了四面体位、Fe²⁺ 与另一半 Fe³⁺ 占八面体位，这是它具强磁性的结构原因。材料未讲这一层。

### 2.6 我们怎么知道地幔是什么做的？

三条证据链：

**(1) 间接的地球物理观测。** 上地幔与下地幔的**地震波速度（seismic velocity）与橄榄石+辉石的实测波速非常吻合**——这是"地幔由橄榄石和辉石构成"的一个有力指示。（课堂原话：我们不能亲自去看，但可以用地球物理成像手段理解是什么赋予了它这些特征性质。）

**(2) 直接的地质样品。** 三种把地幔岩石送到地表的机制（下一节详述）。

**(3) 岩石学实验（petrological experiments）。** 讲义列出但未展开。

#### 三种地幔样品来源

**(a) 地幔捕虏体（mantle xenoliths）**
- 定义：被上升岩浆携带到地表的**地幔岩石碎块**。
- 词源（课堂补充）：xenolith 是希腊语，意思是 **"stranger rock"（陌生的石头）**——它不属于携带它的那团岩浆。它们是从**火山通道壁（conduit walls）**上被撕下来、卷入岩浆、随喷发带到地表的。
- 携带者是**金伯利岩（kimberlite）岩浆**：形成于地幔深部，**上升极快（讲义 10–40 m/s；课堂说 40 m/s 以上）**，像钻头一样"钻"出致密的地幔岩块并把它们运到地表。
- **经济意义**：金伯利岩中的地幔捕虏体是**金刚石的重要来源**。

**(b) 造山带橄榄岩（orogenic peridotites）**
- 由**大型逆冲断层（major thrust faults）**折返（exhume）到地表。
- 例子：意大利阿尔卑斯的 **Ivrea–Verbano Zone**；瑞士阿尔卑斯 **Adula nappe**。
- 阿尔卑斯造山带橄榄岩是**尖晶石二辉橄榄岩（spinel lherzolite）**，**常含金云母（phlogopite）**。

**(c) 蛇绿岩橄榄岩（ophiolite peridotites）**
- **蛇绿岩（ophiolite）**：被**仰冲（obducted）**到陆壳之上的**大洋岩石圈切片**。
- 地幔橄榄岩位于蛇绿岩剖面的**最底部**，在地壳岩石之下。
- **岩石学 Moho（petrologic Moho）**与**地震 Moho（seismic Moho）**位置不同：岩石学 Moho 分隔的是"**经历过熔融的地幔岩石**"与"**由岩浆结晶形成的地壳岩石**"。
- 蛇绿岩中可以同时出现**地幔橄榄岩**与**地壳橄榄岩**（后者是堆晶成因）。
- 蛇绿岩橄榄岩**常被强烈蛇纹石化（serpentinized）**。例：挪威 **Leka 蛇绿岩杂岩**。
- 岩性以 **harzburgite 和 dunite** 为主。

### 2.7 饱满地幔 vs 亏损地幔

| | **饱满地幔 fertile mantle** | **亏损地幔 depleted mantle** |
|---|---|---|
| 熔融历史 | 未经历（或极少经历）过先前熔融 | 已经历过熔融 |
| 矿物组合 | ol + cpx + opx + 含铝相 | ol + opx；**不含或极少含 cpx 与含铝相** |
| 不相容元素 | **仍然存在** | **已被过去的熔融事件"洗"走** |
| 典型岩性 | **lherzolite（二辉橄榄岩）** | **harzburgite（方辉橄榄岩）/ dunite** |
| 典型样品 | 造山带橄榄岩、（尖晶石/石榴石）二辉橄榄岩捕虏体 | 蛇绿岩橄榄岩 |

**为什么可以这样判断？** 因为在三元相图上（见第三节），无论平衡熔融还是分离熔融，**第一个耗尽的矿物永远是 cpx**。所以：
- 看到还有**可观比例 cpx** 的地幔岩石 → 它没被熔过多少 → **饱满**
- 看到基本只有 **ol + opx** 的地幔岩石 → 它是熔融之后的**固体残余（residue）** → **亏损**

**地球化学表述**：熔融时**不相容元素（incompatible elements）**优先进入熔体并随熔体离开，因此残余固体中不相容元素被剥离；饱满地幔里这些元素还留在橄榄岩本身之中。

**构造归位**：洋壳在**洋中脊**生成，其物质正是这些地幔岩石熔出来的；所以**洋中脊之下的地幔已被先前熔融所亏损**，那些熔体上去形成了洋壳——这解释了为什么蛇绿岩底部的橄榄岩是 harzburgite 而不是 lherzolite。

### 2.8 原生熔体（primary melt）与原始熔体（primitive melt）

- **液体演化线（liquid line of descent, LLD）**：一组通过**分离结晶**彼此关联的岩浆成分连成的轨迹（W4 与 Practical 4 已学）。**LLD 上斜率的改变指示结晶矿物组合的改变**。
- **原生熔体（primary melt）**：**直接来自地幔**的熔体，**MgO 含量很高**，**没有（或极少）经历过分离结晶**。位于 LLD 的**最末端（最未演化的一端）**。
- **原始熔体（primitive melt）**：MgO 含量高，但**不一定是 primary**——它可能已经经历了一点分离结晶。这是一个更宽松的词，包含 primary 但不限于它。
- 课堂给的识别口诀：原生熔体 **SiO₂ ≈ 50 wt.%**，**"铁证（dead ringer）"是 MgO 高，常在 10 wt.% 左右**。
- **本周的关键结论：所有原生熔体都是玄武岩（The primary melts are all basalts）。** 这条被 W6 讲义原样引用为 recap。

### 2.9 相容与不相容元素

- **不相容元素（incompatible elements）**：熔融时**优先分配进熔体**。本周点名的例子：**Al、Ti**（还有 K、Na、P 等）。
- **相容元素（compatible elements）**：熔融时**优先保留在残余固体**中。本周点名的例子：**Mg**（还有 Ni、Cr 等）。
- 直接后果：**原生熔体相对起始地幔富集不相容元素**；**残余固体相对起始地幔亏损不相容元素**。

### 2.10 原生熔体成分取决于 P、T、F

**P = 压力，T = 温度，F = 熔体分数（melt fraction）**。讲义给出的实验数据点：

| 体系 | 条件 | 熔体分数 F | 产物 |
|---|---|---|---|
| 石榴石橄榄岩 @ 2 GPa | 1450 °C | 1% | **碱性玄武岩 alkali basalt** |
| 石榴石橄榄岩 @ 2 GPa | 1500 °C | 16% | **拉斑玄武岩 tholeiitic basalt** |
| 尖晶石橄榄岩 @ 1 GPa | 1350 °C | 15% | **碱性玄武岩** |
| 尖晶石橄榄岩 @ 1 GPa | 1450 °C | 20–30% | **拉斑玄武岩** |

归纳成两条（讲义原文）：
- **拉斑玄武岩**：**较浅**的熔融 + **较大**的部分熔融程度（典型 **15–30%**）
- **碱性玄武岩**：**较深**的熔融 + **较低**的部分熔融程度（典型 **< 10%**）

**触发熔融的三种方式**（讲义最后一页仅给了符号，W6–W8 展开）：**−ΔP（减压熔融）、+ΔT（增温熔融）、+ΔH₂O（加水熔融/降低固相线）**。

📎 背景补充：这三个符号对应三种构造背景——洋中脊与地幔柱靠**绝热减压（decompression）**，地幔柱额外贡献 **+ΔT**，俯冲带靠**板片脱水加入 H₂O 使地幔固相线大幅下降**。材料本周只给了符号没有配文字，这三条对应关系是后续几周的主线，先记下。

## 三、公式与图表

### 3.1 镁值 Mg-number

```
Mg# = Mg²⁺ / (Mg²⁺ + Fe²⁺)
```

| 符号 | 含义 | 单位 | 说明 |
|---|---|---|---|
| Mg²⁺ | 镁离子的**摩尔量**（阳离子数或摩尔数） | mol（无量纲比值） | 由 MgO wt.% ÷ 40.30 得到 |
| Fe²⁺ | **二价**铁离子的摩尔量 | mol | 由 FeO wt.% ÷ 71.84 得到；**Fe³⁺ 不计入** |

- **适用条件**：用于矿物（如橄榄石、辉石）或全岩；必须用**摩尔比**而非重量比；必须只用 **FeO（Fe²⁺）**，若分析给的是 Fe₂O₃ᵀ 需要先换算。
- **典型数值**：**地幔矿物 Mg# ≈ 90–92**；地幔橄榄石 = **Fo₉₂**；玄武岩全岩 Mg# 通常 ~45–70（越低越演化）。
- **物理意义**：Mg# 越高越"原始"。因为 Fe²⁺ 比 Mg²⁺ 更不相容（更愿进熔体），熔融会让残余固体的 Mg# 升高、结晶会让残余熔体的 Mg# 降低。

📎 背景补充：Fo 值与 Mg# 在橄榄石中是同一个数——Fo = 100 × Mg/(Mg+Fe)，所以 Fo₉₂ 就是 Mg# 92。这条对应关系材料未明写但被隐含使用。

### 3.2 熔融反应式

**平衡熔融（equilibrium melting）的三段反应**（讲义原文，未配平）：

```
1)  ol + cpx + opx → L      （在三元共结点 E 发生；直到 cpx 耗尽）
2)  ol + opx → L            （沿共结线 cotectic 反向上行；直到 opx 耗尽）
3)  ol → L                  （最后剩纯橄榄石）
最终熔体成分 = 起始固体成分（回到出发点 x）
```

**分离熔融（fractional melting）的三段反应**（讲义原文）：

```
1)  ol + cpx + opx → L      （三元共结点 E；cpx 耗尽后 melting stops）
2)  ol + opx → L            （二元共结点 B；opx 耗尽后 melting stops）
3)  ol → L                  （纯橄榄石熔点）
最终熔体成分 = 纯橄榄石成分
```

**两者的关键差别（课堂总结原话）**：
- 平衡熔融产生**连续变化（a continuum）的一系列熔体成分**；
- 分离熔融产生**三个离散的"快照"**——三种成分明确的熔体（三元共结成分、二元共结成分、纯橄榄石成分），熔融在三个分立的阶段中进行，中间要**停下来等温度升到下一个共结温度**。

### 3.3 超镁铁质岩分类三角图（Streckeisen 1973，Reference Guide p.11）

**怎么读这张图**：
- **三个顶点**：**ol（橄榄石）**、**opx（斜方辉石）**、**cpx（单斜辉石）**。三者体积百分比重新归一到 100%。
- **一个顶点 = 该矿物 100%**；**该顶点的对边 = 该矿物 0%**。这一句是全部三角图读图的根本（课堂原话："这个角是 100% 橄榄石，这条边是 0% 橄榄石"）。
- **读某个点的 ol 含量**：从该点向 ol 的对边作平行线族，用**杠杆法则（lever rule）**量距离——离对边越远、ol 越多。
- **ol = 40% 的那条水平线**是 **peridotite / pyroxenite 的分界**：线以上（靠 ol 顶点）是橄榄岩，线以下是辉石岩。
- 橄榄岩区内部再按 opx : cpx 的比例细分：靠近 ol 顶点 = **dunite**；偏 opx 一侧 = **harzburgite**；中间 = **lherzolite**；偏 cpx 一侧 = **wehrlite**。
- **读结论的方式**：把你在薄片里目测的模式含量归一后打点，落在哪个分区就叫什么名字；然后把这个名字翻译成**熔融历史**（lherzolite → 饱满；harzburgite/dunite → 亏损）。

### 3.4 ol–cpx–opx 三元相图（本周核心图，必须能自己画）

**它究竟是什么。** 课堂讲得非常细，值得完整复原：

- 真实的三元相图是**三维构造**：底面是那个成分三角形（ol–opx–cpx），**竖直方向（第三维）是温度 T**。我们在纸上画的三角图是它的**俯视投影**。Canvas 上老师放了一个 **3D 模型**供自己旋转把玩。
- **三条棱各自是一个简单的二元共结相图**：横轴是两个纯端元之间的成分，纵轴是温度；两端是两个纯矿物的熔点（一个高、一个中），中间凹下去的最低点是**二元共结点（binary eutectic）**。
- **加进第三个矿物后**，原来的"熔融曲线"变成了**熔融曲面（melting surface）**——也就是**液相面（liquidus surface）**。
- 原来的二元共结点变成了一条**"河谷"（老师的比喻：像一条指向下坡的河谷）**，这就是**共结线（cotectic boundary）**。
- 所有共结线交汇于一点，那是全图**温度最低的点**——**三元共结点（ternary eutectic）E**。

**图上的分区（讲义与板书用色）**：
- **绿色区 = ol + L（橄榄石 + 液体）**
- **顶部区 = cpx + L**
- **狭长的蓝色条带 = opx + L**
- 每个阴影面都是"该端元矿物与液体可以共存"的曲面，可以理解为那个矿物的熔化温度面。

**共结线上的箭头**：分隔各场的线上画有箭头，**箭头指向温度下降的方向**，最终都指向 E。

**怎么判断某条共结线上是哪两个相 + 液体共存？** 课堂给的操作法：**看这条线两侧分别是什么场**。例如一条线左边是 ol + L（绿）、右边是 opx + L（蓝），那么**仅在这条线上**，ol + opx + L 三者可以同时共存。

**共结线延伸到三角形边上的交点**，就是二维情形下那两个端元的**二元共结点**位置。

**三元共结点 E 的性质**：在 E 的确切温度上，**ol + opx + cpx + L 四相化学平衡共存**。课堂点明："如果你要用 Gibbs 相律，这是一个**不变点（invariant point）**。"低于此温度液体消失、全部变固体；高于此温度固体消失、全部变液体。

📎 背景补充：Gibbs 相律 **F = C − P + 2**（C = 组分数，P = 相数，F = 自由度）。这里 C = 3（ol、opx、cpx 三个组分），在三元共结点 P = 4（三个固相 + 液相）。若考虑 P（压力）与 T 两个变量则 F = 3 − 4 + 2 = 1；若**固定压力**（相图通常画在恒压下），用简化式 F = C − P + 1 = 3 − 4 + 1 = **0**，即**不变点**——温度和液相成分都被完全钉死。老师说的"invariant point"就是这个意思。这一步推导材料只给了结论。

**如何在图上表示地幔橄榄岩的熔融（课堂完整推演）**：

1. **定起点 x**：地幔橄榄岩约含 40–50% 橄榄石。用杠杆法则在 ol 顶点与其对边之间量出 40% 的位置，起始成分点 **x** 放在比这更靠 ol 顶点一点的地方。老师说"放哪儿都无所谓，这个练习都能work"。
2. **加热到最低温度点**：全图最低温是 **E**，所以熔融必然从 E 开始，反应是 **ol + cpx + opx → L**。
3. **固体残余往哪走？** 关键推理：**如果我们从 x 中不断抽走成分为 E 的液体，那么剩下的固体成分必须沿着 E→x 的连线方向、直接远离 E 移动。**（这是质量守恒的必然结果——液体、固体、总成分三点必须共线，且总成分点 x 始终在液–固两点之间。）课堂用蓝笔画的就是这条"固体演化方向"。
4. **哪个矿物先耗尽？** 沿这条线一路走，会**先撞到三角形的某条边**。那条边正是 **cpx = 0%** 的边（因为 x 相对于 E 而言 cpx 不足）。所以 **cpx 先耗尽**。
5. **接下来的分岔就在于平衡还是分离。**

**平衡熔融路径**（讲义 + 课堂）：
- cpx 耗尽后需要新反应 **ol + opx → L**。图上唯一能让 ol + opx + L 三者共存的地方是 **ol–opx 之间的那条共结线**。
- 因为共结线上的箭头指向降温方向，要继续熔融就必须**升温**，因此**液体成分沿共结线"倒着"（向高温方向）演化**。
- 同时用杠杆法则（连结线 tie line）追踪固体：固体成分朝 **ol 顶点**方向移动。
- 当固体到达 **100% ol 顶点**时，**opx 耗尽**。
- 最后反应 **ol → L**：固体成分不再变（只剩一种矿物，化学成分固定），只是量在减少；液体则不断加入橄榄石组分，**最终回到起始成分 x**。
- **结论：平衡熔融的最终液体成分 = 起始固体成分。** 因为"桶里"什么都没进也没出，只是从 100% 固体变成了 100% 液体。

**分离熔融路径**（讲义 + 课堂）：
- 起点和第一步完全相同：在 E 发生 ol + cpx + opx → L，固体沿同一方向远离 E，直到 **cpx 耗尽**。
- **但此时所有熔体都已经离开系统**，桶里只剩固体 ol + 固体 opx，**固液之间没有化学交换**。
- 于是**三元体系被降维成二元体系**，而且**熔融必须停止**，直到温度升到 **ol–opx 二元共结点 B 的温度**。
- 在 B 发生 **ol + opx → L**，液体成分就是 B 点成分（一个固定值）。
- opx 耗尽后，**二元体系再降维成一元体系**，熔融**再次停止**，直到温度达到**纯橄榄石的熔点**，此时 **ol → L**。
- **结论：分离熔融的最终液体成分 = 纯橄榄石成分。** 整个过程产生**三种成分明确的液体**：E 成分、B 成分、纯 ol 成分。

📎 背景补充：真实的 Fo–Di–En（或 Fo–Di–SiO₂）体系里，镁橄榄石与顽火辉石之间是**包晶（peritectic）**关系而非简单共结（Fo + L → En，EART26201 W04 的 Fo–Qz 包晶就是这个），所以真实的地幔熔融路径比本周这张"纯共结"三元图复杂。本周的图是**教学简化模型**，Practical 5 第 4 题也承认了它的局限。这一层材料未提，但知道它可以避免以后被真实相图搞混。

### 3.5 液体演化线 LLD 图（FeO–MgO）

**坐标轴**：横轴 **MgO wt.%（0–12）**，纵轴 **FeO wt.%（0–18）**。

**怎么读**：
- 图上一串点是**由分离结晶彼此关联的一系列岩浆成分**。
- **斜率的改变 = 结晶矿物组合的改变**（讲义标注了一段 "ol + cpx" 的区段）。
- **分离结晶的进行方向是从右往左**（课堂原话：MgO 从高到低）。因为 Mg 是相容元素，优先进入结晶出来的橄榄石和辉石，残余熔体的 MgO 越来越低。
- **原生熔体位于最右端**（MgO 最高、尚未开始结晶的那一端）。**考试若问"在这张图上画出分离结晶的方向"，答案是从右指向左。**

### 3.6 地幔橄榄岩 vs 原生熔体的主量元素表（讲义原表）

| wt.% | Lherzolite peridotite | Primary melt 1 | Primary melt 2 | Primary melt 3 |
|---|---|---|---|---|
| SiO₂ | 45.62 | 49.16 | 51.02 | 46.59 |
| TiO₂ | 0.20 | 2.29 | 2.03 | 2.26 |
| Al₂O₃ | 2.55 | 13.33 | 13.49 | 15.19 |
| FeO | 7.59 | 10.89 | 11.02 | 12.55 |
| MnO | 0.13 | 0.16 | 0.17 | 0.18 |
| MgO | **41.41** | **10.41** | **8.42** | **8.74** |
| CaO | 1.90 | 10.93 | 10.30 | 10.02 |
| Na₂O | 0.19 | 2.15 | 2.10 | 3.01 |
| K₂O | 0.12 | 0.51 | 0.40 | 0.96 |
| P₂O₅ | 0.03 | 0.16 | 0.26 | 0.29 |

**逐项怎么读（考试要能口头复述）**：
- **MgO：41 → 8–10**。断崖式下降。**Mg 是相容元素**，绝大部分留在残余橄榄岩里。课堂原话："橄榄岩约 40 wt.% MgO，原生熔体约 8–10 wt.%"。
- **TiO₂：0.20 → ~2.0–2.3**（约 10 倍）、**Al₂O₃：2.55 → 13–15**（约 5–6 倍）、**Na₂O：0.19 → 2–3**（约 10–15 倍）、**K₂O：0.12 → 0.4–1.0**、**P₂O₅：0.03 → 0.16–0.29**。这些全是**不相容元素**，被强烈富集进熔体。
- **CaO：1.90 → ~10**。Ca 主要赋存在 cpx 里，而 cpx 是第一个被熔掉的矿物，所以 Ca 大量进入熔体。
- **SiO₂：45.6 → 46.6–51.0**。变化不大，但足以把超镁铁质（<45）推进镁铁质（45–52）区间——**产物是玄武岩**。
- **FeO：7.6 → 10.9–12.6**。Fe²⁺ 比 Mg²⁺ 略不相容，所以熔体的 Fe/Mg 比明显高于源岩。
- **一句话结论**：**橄榄岩富相容元素、原生熔体富不相容元素；三个原生熔体全都是玄武岩。**

### 3.7 Al₂O₃ vs TiO₂ 图（地幔岩石 vs 原生熔体）

**坐标轴**：横轴 **TiO₂ wt.%（0–0.8）**，纵轴 **Al₂O₃ wt.%（0–15+）**。

**图上的点群**：
- **右上角**：**原生熔体（primary melts）**——Al₂O₃ 与 TiO₂ 都最高。
- **中部**：**lherzolite（二辉橄榄岩）**——起始地幔成分。
- **左下角，沿"残余固体"趋势线依次是**：**harzburgite → dunite**——Al₂O₃ 与 TiO₂ 都越来越低。

**怎么读结论**：
- **Al 和 Ti 都是不相容元素**。地幔二辉橄榄岩部分熔融时，它们优先进入熔体相。
- 因此**原生熔体相对起始地幔成分富集不相容元素**；
- **熔融后残留的固体相对起始地幔成分亏损不相容元素**。
- **从 lherzolite → harzburgite → dunite 的连线，就是熔融程度递增的方向**——这张图把 2.7 节的矿物学判据（cpx 多不多）翻译成了地球化学判据（Al、Ti 高不高），两者互相印证。

### 4.2 关于矿物学的口头强调

- **"最重要的一句话（the really important thing to take away）：地幔是橄榄岩做的。"** 老师把它称为"一种非常简单的岩石"：ol + opx + cpx + 一个含铝相。

### 4.3 关于地幔样品的口头补充

- **xenolith 的词源**：希腊语 "stranger rock"（陌生的石头）。它**不属于**携带它的岩浆，是从**通道壁**上被撕下来、卷入岩浆、随喷发带出来的。
- **上升速率是怎么算出来的**（讲义只给数字，课堂给了推理）：人们反推"要把这么致密的岩块从 60 km 以上的火山通道里一路顶到地表，需要多快的上升速度"，得到的量级是 **40 m/s 以上**。**所以这是一类非常特殊、上升极快的岩浆**——这才是它能搬运致密地幔碎块的原因。
- **蛇绿岩下周详讲**："我们下周会更详细地看蛇绿岩和洋壳结构。"（对应 W6 讲义。）

### 4.4 ★ "Compare and contrast" 答题法（本周最重要的考试提示）

老师专门花了一大段讲这类题怎么答，值得逐条记：

- **本课程典型的考题形式就是"compare and contrast A 与 B"。**
- **错误做法**：把 A 全写一遍，再把 B 全写一遍，然后就结束——"那只是一道 describe 题，你描述了 A 也描述了 B。"
- **正确做法**：老师用了一个刻意荒唐的类比——"compare and contrast 你的大学宿舍和你不在学校时住的地方"。正常人的回答会是："**两处都有地方睡觉，但其中一个比另一个好得多，因为……**"，然后列一串理由。
- **关键句**："当你看到 compare and contrast，这道题的着力点不是把你知道的关于 A 和 B 的一切都写下来。它是**筛选信息并进行批判性分析（selecting information and critically analyzing it）**——这些岩石有什么共同点，又在哪些方面不同？"
- **答题结构建议**：先建立**共同点**（说明它们同属一类），再逐条列**差异**，且每条差异都要**说明判据**（"我们怎么知道？"）。

### 4.5 ★ 课堂共建的标准答案：三类地幔样品的 compare & contrast

老师让全班先小组讨论五分钟，然后逐条汇总。这实质上就是一份**考题范例答案**，务必背下来。

**对比对象**：① 地幔捕虏体（xenoliths）、② 洋壳底部的地幔岩石（蛇绿岩橄榄岩）、③ 大陆碰撞带中出露的地幔岩石（造山带橄榄岩）。

**共同点（similarities）**：
1. **它们都是橄榄岩**——按定义**橄榄石 > 40%**，加上 cpx 和 opx。
2. **结构上的相似**：都是**粗粒（coarse grained）**。
3. **★ 结构都不能告诉我们结晶顺序**。老师明说：**地幔岩石是上周（W4）"看包裹关系与结构关系判断结晶顺序"那套方法的例外**。"地幔岩石在很多方面都很复杂，但结晶顺序不是你能从薄片里轻易看出来的东西。"
4. **它们都必须靠某种不寻常的机制才能被带到地表**——我们通常不会在地表遇到地幔岩石，所以必须有一个搬运机制，无论是拳头大小的碎块还是一整片被逆冲折返的地幔切片。

**差异（differences）**：
1. **搬运机制不同**（捕虏体靠金伯利岩快速上升 / 造山带靠逆冲折返 / 蛇绿岩靠仰冲）。
2. **★ 形成压力不同，判据是含铝相**：
   - **捕虏体**可以含**石榴石** → **P > 2 GPa**，深度 **> 60 km**（三者中最深）
   - **造山带橄榄岩**主要是**尖晶石**相
   - **蛇绿岩橄榄岩**也主要是**尖晶石**相
3. **★ 只有捕虏体一系可能含金刚石**：金刚石需要 **> 80–100 km** 的深度，"这就是为什么世界上的钻石矿都分布在这些搬运这种特定地幔岩石的**金伯利岩管（kimberlite pipes）**周围"。
4. **★ 含水性不同（反直觉点）**：
   - **造山带橄榄岩常含金云母（phlogopite）** → 可以是**含水/水化的**。老师解释：金云母"基本上就是黑云母，只是更富镁"，是**把水以结构形式束缚在晶格里**的矿物之一。
   - **捕虏体橄榄岩有时也能见到金云母。**
   - **蛇绿岩橄榄岩是干的——我们在这里找不到金云母。**
   - **反直觉的地方**：有学生指出蛇绿岩橄榄岩位于洋壳底部、有大量次生水（蛇纹石化）。老师肯定这是"一个非常有意思的点"，并澄清：**尽管它们有很多次生水，洋壳中真正的橄榄岩其实相当"干"**——这里区分的是**原生含水矿物（金云母）**与**次生蚀变（蛇纹石）**，两者不是一回事。
5. **★ 铬透辉石（chrome diopside）只见于捕虏体**："在捕虏体橄榄岩里我们能找到这种不寻常的矿物，叫铬透辉石，我们其实**只在相当高压的橄榄岩里**才找得到它。"
6. **变形结构不同**：**造山带与蛇绿岩橄榄岩**可以带有与**地幔切片仰冲/构造侵位**相关的**变形结构**；捕虏体一般看不到这类结构。
7. **★ 模式比例不同 → 岩石名不同**：
   - 捕虏体、造山带 → 写作 **garnet lherzolite / spinel lherzolite**（"lherzolite 这个词用来表示三种矿物比例都不错"）
   - 蛇绿岩 → 写作 **spinel harzburgite**，因为**单斜辉石的模式比例非常低**，主要由 ol + opx 组成（仍然是橄榄岩）。
8. **饱满 vs 亏损**（老师在讲完熔融后又回到这张对比表补上）：
   - **捕虏体与造山带橄榄岩 → 通常是 lherzolite → 饱满（fertile）**，没有经历大量先前的熔体抽取。
   - **蛇绿岩橄榄岩 → 亏损（depleted）**。理由链：洋壳在**洋中脊**生成（一年级学过），那些地壳物质正是这些地幔岩石熔出来的，所以**洋中脊之下的地幔已被先前熔融事件亏损**。
9. **共同点补充**：三者都**可以（或曾经）发生部分熔融，产物都是玄武质的**。

### 4.6 关于三元相图的口头讲解要点

（推演过程已在 3.4 完整复原，此处只补口头强调的"元信息"。）

- **先确认前置知识**：老师专门问"你们在 chemistry of the Earth（地球化学）里已经学过二元相图了吧？"——**默认你已经掌握 EART26201 的二元共结相图**，本周不再重讲基础。
- **★ 刻意的简化**："为了这个练习，我们假设这块岩石**不含任何含铝相**。这把一个四维问题简化成了三维问题，光是这样就已经够烧脑了。"—— **考试答题时如果被问到这张图的局限，第一条就写"它忽略了含铝相"。**
- **3D 模型在 Canvas 上**："你可以自己去玩一玩，用这个图说服自己上面这些点是对的。"
- **共结线（cotectic）的定义**：这只是我们用来表示"**两个相加上液体可以同时在这条线上共存**"的一个词。判断是哪两个相的方法就是**看线的两侧**。
- **三元共结点是不变点**："如果你要做 Gibbs 相律，那是一个 invariant point。低于这个温度你抹掉液体，一切变成固体；升高温度一切熔化，所有固相消失。"
- **"平衡"与"分离"在熔融里和在结晶里做的是同一件事**："those words equilibrium and fractional do the same work in a melting reaction as they would in a crystallization reaction." —— **直接把 W4 的概念平移过来即可。**
- **平衡熔融的"锅"比喻**：**一切都留在锅里**。可以造液体，但液体留在锅里，因此能与周围的固相发生化学交换。0% 熔融时锅里全是固体；10% 熔融时锅里 90% 固体 + 10% 液体；100% 熔融时全是液体。**但每一个快照，锅的全岩化学成分都完全相同。**
- **分离熔融的"锅"比喻**：**每造出一滴液体，它就离开锅**（自然界中可以想象成液体的**浮力上升**）。锅的体积随熔融进行而变小，锅的化学成分随熔融进行而改变；**每次移走一滴液体，锅就重新变回 100% 固体**。因此**液体与残余固体之间没有化学交换**——液体一旦生成就离开系统，"从此对我们这个练习而言就隐形了"。
- **固相演化方向的推理**（这是最容易被跳过、也最该理解的一步）："如果我们熔化地幔岩石、抽走成分为三元共结点 E 的液体，那么**剩下的固体必须朝正对着远离 E 的方向演化**。"
- **降维的说法**：分离熔融时 cpx 耗尽后，"我们把三元体系**降维成了二元体系**，在系统达到 ol–opx 二元共结点温度之前，我们**不能再进行任何熔融**"；opx 耗尽后再从二元降成**一元（unary）**体系。**"melting stops"这个说法在分离熔融里出现了两次——记住熔融是分段暂停的。**
- **在纸上现场画二元图**：老师建议把 ol–opx 那条边的二元相图单独画出来（固相区 ol + opx 在下、OPX + L 与 ol + L 两个场在上、中间是二元共结点），然后"**用你在地球化学课上学到的所有原理**去把剩下的熔融方程推完"。

### 4.7 关于饱满/亏损与原生熔体的口头补充

- **判据的推理路径**（老师自问自答）："我们该找什么证据来判断一块地幔岩石是饱满还是亏损？我们看到在平衡和分离两种情形下，熔化一块正常地幔橄榄岩时，**第一个耗尽的相都是单斜辉石**。所以如果我看到一块含有相当大比例 cpx 的地幔岩石，我会把它描述成**饱满地幔**——因为如果那块岩石经历过大量熔融，大部分 cpx 早就被熔掉了。"
- **岩石名 = 熔融历史的速记**："lherzolite 通常描述一块**还剩下可观比例 cpx** 的岩石，所以 lherzolite 是**饱满地幔**的良好指示；而 harzburgite **剩下的 cpx 非常少**，我们看的是**经历过先前熔融事件**的地幔。"
- **★ 原生熔体的"铁证"**："它们大约有 **50 wt.% 的二氧化硅**，但**真正的铁证（the dead ringer）是它们的 MgO 含量高，常在 10 wt.% 左右**。"
- **★ LLD 图上的考点**："如果让你在这张图上画出分离结晶进行的方向，**是从右往左**；原生熔体就是**最右边、在任何结晶发生之前的那些点**。"
- **primitive 是提前打的预告**："这是接下来几周你会听我用的另一个词……它们**包含 primary 但不限于 primary**，可以经历过一点点分离结晶。这只是给接下来内容打个招呼。"
- **收尾的"quick and dirty compare and contrast"**（老师自己示范了一遍答题）："**橄榄岩比原生熔体更富相容元素，而原生熔体更富不相容元素。**" —— 这就是一句合格的 compare-and-contrast 结论句的样子。

### 5.2 ★ 最重要的红字警告：不要试图判断地幔岩石的结晶顺序

实习手册用一整个加粗标题强调：**"Don't try to interpret the order of crystallization in mantle rocks!"**

理由链（手册原文）：
1. 地球的地幔是**固体**。地幔岩石通过**部分熔融**产生玄武质熔体。
2. **亏损地幔岩石 = 部分熔体被抽走之后剩下的残余（residue）**；**饱满地幔岩石 = 尚未经历显著熔融**。
3. 整个地幔上一次全熔是在 **~4.4 Ga**，这个早期冥古宙**岩浆洋（magma ocean）**在 **~4.2 Ga** 前已完全冷却固结。
4. 过去 ~4 Ga 中，原始的结晶结构已被**固态过程**完全改造覆盖，包括**塑性变形（plastic deformation）、扩散（diffusion）、重结晶（recrystallization）、奥斯特瓦尔德熟化（Ostwald ripening）**。
5. 因此**判断地幔岩石的结晶顺序既无用也无意义**。

**应该看什么？** **多边形结构（polygonal texture）与颗粒间约 120° 的三联点（triple junctions）**。成因：这种几何**使晶界的表面自由能最小化**；但它需要**长时间的固态扩散与重结晶**才能形成——所以它本身就是"这块岩石在地幔里待了极久"的证据。

⚠️ 注意这与 Reference Guide p.4–5 的通用流程（"Use the texture to determine the order of crystallization as far as possible"）**冲突**——地幔岩石是那条通则的**明确例外**，课堂上老师也单独强调了这一点。

### 5.3 Part 1（75 分钟）：手标本与薄片中的地幔岩石

四个样品，每个约 15 分钟；做笔记、素描，估计**模式矿物学（modal mineralogy）**。**75 分钟后即使没看完也必须进入 Part 2。**

#### A. 蛇绿岩样品

**背景**：蛇绿岩是没有在俯冲带被回收、反而被逆冲到陆壳之上而保存下来的**大洋岩石圈切片**。典型蛇绿岩层序**底部是地幔橄榄岩**，它正是那些结晶形成洋壳的玄武质岩浆的**源区**——**所以蛇绿岩底部的橄榄岩必然经历过部分熔融**。

**样品 NC1（New Caledonia 新喀里多尼亚）**

| 观察到的特征 | 推理 | 结论 |
|---|---|---|
| 两种主要原生矿物：橄榄石 + 斜方辉石；橄榄石**大范围蚀变为淡绿色蛇纹石**；opx 含**单斜辉石出溶片晶（exsolution lamellae）**；少量尖晶石，PPL 下**深红棕色** | ol 与 opx 为主、cpx 极少（仅以出溶片晶形式存在，不算独立模式相） | 落在三角图 **ol–opx 边附近** → **方辉橄榄岩 harzburgite** |
| 分类与构造背景是否一致？ | 蛇绿岩底部的地幔橄榄岩已经历部分熔融；harzburgite 正是从 lherzolite 中抽走部分熔体后剩下的**残余** | **一致（Yes）** |

**变形证据（题目问"什么证据表明它被构造改造/tectonised"）**：
1. **弯曲的 opx，形状像"眼球构造（augens）"**，被蛇纹石包卷（wrapped around）。手标本上也能看到这种 augen 结构。（手册注明 augen 其实是**变质岩术语**。）
2. **橄榄石似被拉长并破碎成亚晶粒（subgrains）**——但因蛇纹石化太强烈，这一点**不总是容易看出来**。

**变形的成因**：很可能发生在**大洋岩石圈仰冲到陆壳之上（obduction）**的过程中。

**蛇纹石化的水从哪来？** 最可能是**海水**——那么蛇纹石化发生在**蛇绿岩侵位到陆壳之前或之中**。侵位之后**大气降水（meteoric water）**循环可造成进一步蚀变，但**单靠这一项无法解释本样品蛇纹石化的规模**。

📎 背景补充：opx 中的 cpx 出溶片晶是**固溶体随降温出溶**的记录（W3 的 isomorphism / exsolution 概念、EART26201 W04 的 Ab–Or 溶线出溶是同一类现象）：高温时 Ca 可以较多地进入斜方辉石结构，降温后溶解度下降，Ca 富集相（透辉石质 cpx）沿特定晶面析出成片晶。材料只说了"含有出溶片晶"这一现象。

#### B. 金伯利岩中的地幔捕虏体

**样品 BT2 或 15565（Kimberley, South Africa；BT2 有手标本）**

| 观察到的特征 | 推理 | 结论 |
|---|---|---|
| 四种主要硅酸盐矿物；手标本上颜色对比极清楚；肉眼在薄片上能挑出**一个粉色矿物**和**一个绿色矿物** | **粉色 + 高突起 + 各向同性 → 石榴石**；**瓶绿色 cpx → 铬透辉石（chrome diopside，高 Cr 致色）** | 四相 = **橄榄石、单斜辉石、斜方辉石、石榴石** |
| 石榴石作为含铝相 | garnet 稳定于 **P > 2 GPa** | **石榴石二辉橄榄岩 garnet lherzolite** |
| 两个样品都含**少量金云母**（浅棕色云母，外观酷似黑云母） | 金云母富 K₂O 与 H₂O | 指示**含水地幔**，且这些组分若熔融会强烈进入液相 |

**"这可能是饱满地幔的样品吗？"→ 是（Yes）。** 标准答案的论证：
- **"饱满"意味着该岩石先前没有（或极少）经历部分熔融**，因此它**还能够**部分熔融产生玄武质液体。
- 熔体抽走后剩下的残余称为**亏损地幔**，矿物种类更少（**通常只有 ol 和 opx**）。
- BT2/15565 含 **cpx、石榴石、以及少量金云母**——**如果这块岩石发生熔融，这些矿物全都会被消耗掉**。所以它们的存在本身就证明它还没被熔过。

**样品 S.115（无手标本）**

| 观察到的特征 | 推理 | 结论 |
|---|---|---|
| cpx 为**铬透辉石**，因高 Cr 呈**特征绿色** | 铬透辉石常见于地幔捕虏体 | cpx ✓ |
| **近乎不透明**的矿物 | 强着色近不透明 + 各向同性 → **尖晶石**（对照磁铁矿：磁铁矿是**完全不透明**） | **尖晶石**（含铝相）→ **0.8–2.0 GPa** |
| 含**大颗粒金云母**（浅棕色云母；是 **phlogopite–biotite 固溶体的富 Mg、贫 Fe 端元**） | 金云母**富 K₂O 与 H₂O**，两者在熔融时都会强烈分配进液相 | **金云母的存在是"饱满地幔"的良好证据** |
| 另两个主要矿物 | — | **橄榄石、斜方辉石** |
| **最终命名** | | **金云母尖晶石二辉橄榄岩 phlogopite spinel lherzolite** |

**铬透辉石的化学式**（手册原文）：纯透辉石是 **CaMgSi₂O₆**；铬透辉石写作 **Ca(Mg,Cr)Si₂O₆**，即**部分 Mg 被 Cr 替代**。铬透辉石在地幔捕虏体中很常见。（关于这个式子的电价平衡问题见勘误表。）

**"S.115 相对 15565/BT2 的来源深度说明了什么？"（标准答案的完整推理链，考试范例）**：
1. S.115 的含铝相是**尖晶石**；BT2/15565 的含铝相是**石榴石**。
2. **石榴石稳定于比尖晶石更高的压力。**
3. 所以 **S.115 必然来自比 BT2/15565 更低的压力**。
4. 可以说 S.115 来自**尖晶石稳定域，即 ~0.8–2.0 GPa**。
5. **要得到更精确的压力估计，需要额外的地球化学信息**，例如使用 **Al-in-opx 压力计（Al-in-opx barometer）**。

📎 背景补充：Al-in-opx 压力计的原理是斜方辉石中 Al 的溶解度随压力和温度系统变化（在石榴石或尖晶石共存的橄榄岩中，Al 在 opx 里的含量对 P 敏感），因此测出 opx 的 Al 含量即可反算压力。这个方法名字在材料里出现但未解释。

#### C. 造山带橄榄岩

**样品 O32B（Finero，意大利）**

| 观察到的特征 | 推理 | 结论 |
|---|---|---|
| 手标本（较大那块）中一种**深色、有光泽的硅酸盐矿物勾画出明显的面理（foliation）** | 深色片状、有光泽、定向排列 | **金云母 phlogopite** |
| 薄片中橄榄石含**变形纹（deformation lamellae）**，产生**斑块状消光（patchy extinction）** | 固态塑性变形的记录 | 与"造山带橄榄岩由构造逆冲折返"一致 |
| **深棕色、各向同性**的矿物 | 强着色 + 各向同性 | **尖晶石** |
| 另两个主要硅酸盐矿物 | **PPL 下淡绿色 → 单斜辉石**；**PPL 下很淡的棕灰色 → 斜方辉石** | **cpx + opx** |

综合：ol + opx + cpx + spinel + phlogopite → **金云母尖晶石二辉橄榄岩**（与讲义"阿尔卑斯造山带橄榄岩是尖晶石二辉橄榄岩、常含金云母"完全对应）。

📎 背景补充：Reference Guide p.16 给出的 opx / cpx 区分要点可以补齐这里的判据链——**消光角是最常用的判别手段**（斜方辉石**平行消光**，单斜辉石**斜消光**，测量时要选只显示**单条解理迹**且干涉色最高的晶体）；**颜色**（cpx 可能粉至棕色并可能多色性，opx 通常无色不多色，唯一例外是顽火辉石有微弱但很特征的**淡粉–淡绿多色性**）；**干涉色**（opx 一级低干涉色，多数 cpx 二级）；**双晶**（opx **从不**双晶，cpx 可能有）。本实习答案里"pale green vs very pale brown-grey"用的是颜色判据，可以再用消光角复核。

**第 2 题：岩石 15565/BT2 发生部分熔融。随着熔体被抽出，固体残余的成分将如何变化？哪个矿物会最先被消耗？该矿物耗尽时残余的成分是什么？**

**第 4 题：用这张简单的三元相图理解地幔熔融反应，有什么优点和弱点？**

**优点（Strengths）**：
- 三元相图**使用简单，且非常强大**。
- **它很好地解释了亏损地幔岩石所观察到的矿物学**（为什么残余是 harzburgite/dunite 而不是别的）。

### 5.5 加分薄片（Bonus thin sections）

**BF2（Bultfontein, South Africa）**
- 背景：**多数金伯利岩是碎屑状（fragmental）岩石**；这一片**无论矿物学还是结构上都不是典型金伯利岩**，它来自一个与真正金伯利岩伴生的**小岩床（sill）**。
- 三种主要矿物，其中两种是**非硅酸盐**：
  - **钙钛矿 perovskite（CaTiO₃）**：棕色、各向同性、方形。
  - **第二种非硅酸盐 = 方解石 calcite**。**判据：高突起 + 极高双折射率（淡粉/淡绿，也可能看起来像沙棕色）。**
  - **它说明了什么？** 方解石是碳酸盐矿物 CaCO₃；碳酸盐最可能的来源是**溶解在金伯利岩岩浆中的 CO₂**。**这告诉我们金伯利岩岩浆极度富挥发分（extremely volatile-rich）**。（金伯利岩的 H₂O 含量也很高，但**这一点没有保存在矿物记录中**。）
- **结构**：整体为**斑状（porphyritic）**。橄榄石晶形**有自形（euhedral）、有半自形（subhedral）、也有浑圆的（rounded）**。
  - **浑圆形态的解释**：这些晶体**与金伯利岩岩浆不处于化学平衡**，被**部分熔蚀/再溶解（partially resorbed）**了。
  - 许多橄榄石是**捕虏晶（xenocrysts）**：直接来自地幔，在金伯利岩岩浆钻穿地幔与岩石圈上升的途中被卷入。
  - 橄榄石有**蛇纹石反应边**。**水从哪来？** 蛇纹石化是橄榄石与**含水流体**反应的产物，**这些流体来自金伯利岩岩浆本身**（对比 NC1：那里的水来自**海水**——两题必须区分开）。

**15562（Kimberley, South Africa）**
- 这是金伯利岩中的一个**捕虏体**。岩石类型是**榴辉岩（eclogite）**，其**全岩化学成分与玄武岩相同**。
- **榴辉岩由玄武岩的高压变质作用形成**；金伯利岩中的榴辉岩结核被认为来自**俯冲并变质了的玄武质洋壳**。
- 两种主要矿物：**Cpx + 石榴石**（其中一种有**反应边**）。深绿色、方形、各向同性的矿物是**尖晶石**。
- **关键的洞察（手册原话）**："注意，这**正是饱满二辉橄榄岩部分熔融时被消耗掉的那两个矿物**。"

**把 BF2 与 15562 点到三元图上，与其他地幔岩石比较：**
- **BF2 落在橄榄石顶点**；**15562 落在单斜辉石顶点**。
- 它们**看起来与本次实习的其他地幔样品差别很大**。在橄榄岩分类图上它们像**单矿物岩**（BF2 会被叫成 **dunite**，15562 会被叫成 **clinopyroxenite**）——
- **但这是因为这张三元图不包含这些岩石中其他矿物的信息**（BF2 的钙钛矿与方解石、15562 的石榴石都没有位置可放）。**这是"分类图必须选对"的绝佳反面教材。**

### 5.6 评分要点与常见错误

- **必须选对分类方案**：超镁铁质岩用 **ol–opx–cpx 三角图（Streckeisen 1973）**，不要用 QAPF、也不要用 TAS（TAS 需要地球化学分析数据，薄片给不了）。
- **模式含量估计**要用 Reference Guide 末尾的**模式比例估算图版（chart for estimating modal proportions）**，并且要**归一化到 100%** 再打点。
- **命名格式**：**类型矿物（type minerals）写在前、按丰度由低到高排列**，根名在后。例：**phlogopite spinel lherzolite**（不是 "lherzolite with phlogopite and spinel"）。
- **不要把次生矿物写进岩石名**：蛇纹石是**次生矿物（secondary）**，NC1 仍然叫 harzburgite 而不是"蛇纹石橄榄岩"（那是变质岩名）。同理**尖晶石在很多情况下是副矿物**，但在地幔橄榄岩中它作为**指示压力的含铝相**被写进名字里。
- **不要判断结晶顺序**（见 5.2）。
- **薄片描述顺序**（Reference Guide p.4）：原生大晶体 → 原生小晶体 → 副矿物 → 次生矿物。
- **素描要求**（Reference Guide p.3）：画大（约 10 cm）、**必须有比例尺**（用透明尺在显微镜下估视野）、**不要写 "×10"/"×20"**（那只说明物镜倍数，不等于图的比例）、用线宽/阴影/颜色表现细节、素描里要出现你在描述中提到的所有矿物与结构特征。

## 六、易错点 / 重点难点

1. **★ "地幔岩石不能判断结晶顺序"是本课通则的明确例外。** W4 与 Reference Guide 教你"用结构判断结晶顺序"，但地幔岩石的原始结晶结构在 ~4 Ga 的固态变形、扩散、重结晶、Ostwald 熟化中被完全抹掉了。看到地幔薄片，要找的是 **120° 三联点的多边形结构**，不是包裹关系。这是老师和实习手册**两处独立强调**的点，几乎一定考。

2. **★ 混淆"原生（primary）"与"原始（primitive）"。** primary = 直接来自地幔、**没有**经历分离结晶；primitive = MgO 高但**可能**经历过一点分离结晶。**primary ⊂ primitive**。

3. **★ 混淆"饱满/亏损"与"富镁/贫镁"。** 饱满/亏损说的是**不相容元素**和 **cpx 的有无**，不是 Mg 含量。亏损地幔（harzburgite）的 Mg# 其实**更高**，因为 Fe 比 Mg 更不相容、被熔体带走了。

4. **★ 蛇绿岩橄榄岩"干"这件事。** 它被强烈蛇纹石化，看上去满是水，但那是**次生蚀变（海水）**；它的**原生矿物组合里没有金云母**，所以在"原生含水性"的意义上它是干的。造山带橄榄岩才是原生含水的（含金云母）。**这是老师专门澄清的反直觉点。**

5. **★ 石榴石与尖晶石的区分只能靠颜色。** 两者都是立方、都各向同性、都高突起、都无解理。**石榴石粉红、尖晶石深棕/深绿。**别指望用消光或干涉色分开它们。

6. **★ 尖晶石与磁铁矿的区分。** 尖晶石**强着色但仍透光**（可能"接近"不透明）；磁铁矿**完全不透明**。两者在 XP 下都全黑，所以判据全在 PPL。

7. **★ 平衡熔融与分离熔融的最终产物完全不同。** 平衡：最终液体 = **起始固体成分**（因为没有任何东西进出锅）。分离：最终液体 = **纯橄榄石成分**（因为前面的液体都跑了）。中间过程：平衡是**连续**的液体成分谱；分离是**三个离散快照**，并且**中间熔融会两次停止**（等待升温到下一个共结温度）。

8. **★ 固体演化方向的推理容易背反。** 记住："**抽走 E 成分的液体 → 残余沿 E→x 延长线、直接远离 E**"。想不起来就回到质量守恒：液–总–固三点必须共线，总成分点 x 在中间。

9. **共结线上的箭头指的是温度下降方向**（指向 E）。**熔融时液体成分沿共结线"逆着箭头"向高温方向走**，因为要继续熔融必须升温。很多人会把方向弄反。

10. **含铝相 ↔ 压力的三档界线必须背准**：plag < **0.8 GPa** < spinel < **2 GPa** < garnet；对应深度 spinel ≈ 20–60 km、garnet > 60 km；金刚石还要更深（课堂给 > 80–100 km）。

11. **金云母不是压力指示矿物，是含水性指示矿物。** 别把它塞进"含铝相随压力变化"那张表的逻辑里去（尽管讲义把它排在同一页）。

12. **cpx 永远第一个熔完**，这是把"矿物学观察"翻译成"熔融历史"的唯一钥匙。lherzolite（有 cpx）= 饱满；harzburgite（几乎无 cpx）= 亏损。

13. **拉斑 vs 碱性玄武岩的方向别记反**：**拉斑 = 浅 + 高熔融程度（15–30%）**；**碱性 = 深 + 低熔融程度（<10%）**。

14. **LLD 图上分离结晶方向是从右往左**（MgO 从高到低），原生熔体在最右端。

15. **三元图的局限要能背出来**：忽略含铝相（garnet/spinel）与含水相（phlogopite），而这些相都参与真实的熔融反应。答"advantages and weaknesses"题时先说它简单强大、能解释亏损地幔矿物学，再说它的简化。

16. **"Compare and contrast" 不等于"分别描述"。** 必须有**共同点段落 + 差异段落**，且每条都要给**判据**。这是老师花了大段课时教的答题结构。

17. **蛇纹石化的水源要分情况**：NC1（蛇绿岩）→ **海水**（侵位前/中），侵位后大气降水可加剧但不足以解释全部；BF2（金伯利岩岩床）→ **岩浆自身的含水流体**。同一道"水从哪来"的问题，两个样品答案不同。

18. **地震 Moho ≠ 岩石学 Moho。** 岩石学 Moho 分隔的是"熔融过的地幔岩"与"岩浆结晶成的地壳岩"；蛇绿岩里可以同时有**地幔橄榄岩**和**地壳（堆晶）橄榄岩**，别把底部所有超镁铁岩都当成地幔。

| lever rule | 杠杆法则 | 由相图上的连结线读取相的比例 |
