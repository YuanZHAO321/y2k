## 二、核心概念

### 2.1 熔融发生在哪里

多数岩浆在**地壳内**的岩浆房、岩床、岩墙中冷却结晶，部分被输送到地表喂养喷发。**分离结晶**产生成分与矿物组合各异的火成岩，**结晶速率**产生不同结构（W4 结论）。**地球绝大部分岩浆的最终源区是硅酸盐地幔的部分熔融**；某些情况下也可由**地壳岩石**熔融产生岩浆（W8–W9）。

### 2.2 地幔是橄榄岩

**超镁铁质岩（ultramafic rock）**：镁铁矿物（ol+cpx+opx）> 90%。

**核心句：地幔的矿物组合 = ol + cpx + opx + 一个含铝相。**

**Streckeisen (1973) 超镁铁质岩三角分类**（Reference Guide p.11）：三顶点为 ol、opx、cpx。**橄榄岩（peridotite）ol > 40%**（课堂反复强调这个门槛），内部再分**纯橄岩 dunite**（ol 近 100%）、**方辉橄榄岩 harzburgite**（ol+opx，cpx 很少）、**二辉橄榄岩 lherzolite**（三者比例都可观）、**异剥橄榄岩 wehrlite**（ol+cpx，opx 很少）；**ol < 40% 为辉石岩 pyroxenite**。

📎 背景补充：dunite/wehrlite/websterite 的具体百分比界线来自 Reference Guide 引用的 Streckeisen 分类图；本周讲义与转写只明确出现 peridotite、lherzolite、harzburgite、dunite、clinopyroxenite 五个名字，分区几何以手册原图为准。

**为什么分类重要**：模式矿物学直接记录这块地幔有没有被熔过（见 2.6）。

### 2.3 地幔矿物成分接近富 Mg 端元

```
Mg# = Mg²⁺ / (Mg²⁺ + Fe²⁺)  ≈ 90–92（地幔矿物）
```
典型地幔橄榄石为 **Fo₉₂**。Week 3 提醒的纯 Mg 端元：橄榄石 **Mg₂SiO₄**（forsterite）、斜方辉石 **Mg₂Si₂O₆**（enstatite）、单斜辉石 **CaMgSi₂O₆**（diopside）。

### 2.4 含铝相随压力变化（最考的一条）

| 压力 | 含铝相 | 化学式 | 备注 |
|---|---|---|---|
| 0–0.8 GPa | **斜长石 plagioclase** | CaAl₂Si₂O₈ | 罕见（该压力区间通常被地壳占据）；课堂明说本单元不会看到 |
| 0.8–2 GPa | **尖晶石 spinel** | MgAl₂O₄ | 课堂给深度约 **20–50/60 km** |
| > 2 GPa | **石榴石 garnet** | Mg₃Al₂Si₃O₁₂ | 课堂给深度 **> 60 km** |
| （与压力无关） | **金云母 phlogopite** | KMg₃AlSi₃O₁₀(OH)₂ | 黑云母固溶体富 Mg 端元；**指示含水地幔** |

用法是**反过来读**：薄片里看到哪个含铝相，就能反推地幔来源深度——这是 Practical 5 的核心判据。

📎 背景补充：高压偏爱石榴石的原因是摩尔体积。石榴石中 Al 为 **[6] 八面体配位**、结构致密（~3.6 g/cm³），斜长石中 Al 为 **[4] 四面体配位**、架状结构疏松（~2.7 g/cm³），尖晶石居中。压力总是选择摩尔体积更小的相，故 plag → spinel → garnet。这一推理材料未给。

### 2.5 本周三个矿物的光性与晶体化学

**石榴石 Garnet**（W3 复习）：地幔者为 **Mg₃Al₂Si₃O₁₂（pyrope）–Fe₃Al₂Si₃O₁₂（almandine）** 固溶体，立方 → 各向同性。**PPL**：粉色、**很高突起**、常见裂纹、**无解理**。**XP**：各向同性，**永远消光**。

**尖晶石 Spinel**（本周新矿物，Blackboard Week 5 有新视频）：**氧化物（非硅酸盐）**、立方、**MgAl₂O₄**；地幔者为 MgAl₂O₄–FeAl₂O₄ 固溶体。**PPL**：**强着色（常红、棕、绿），可近乎不透明**；**不多色性**；高突起；无解理。**XP**：各向同性，永远消光；**无环带**。产于橄榄岩、玄武岩、辉长岩。
- **与石榴石区分 → 看颜色**（石榴石粉红，地幔尖晶石深棕/深绿）；**与其他强着色矿物区分 → 看 XP 下的各向同性消光**（有色却永远全黑，只有等轴矿物做得到）。

**尖晶石族**：通式 **AB₂O₄**。**A = M²⁺**（Mg²⁺、Fe²⁺、Mn²⁺、Zn²⁺、Ni²⁺）占**四面体 [4]**；**B = M³⁺**（Al³⁺、Fe³⁺、Cr³⁺）占**八面体 [6]**。成分范围极广而**结构完全相同**——这就是"族"的定义。它们是各种火成岩与变质岩中常见的**副矿物**。

**磁铁矿 Magnetite**：**Fe₃O₄**，氧化物、立方，产于各种镁铁质—中性—演化火成岩。**PPL：不透明**（主要判据）；发育好者呈**等轴立方自形**。XP 全黑。

📎 背景补充：Fe₃O₄ 写作 Fe²⁺Fe³⁺₂O₄ 更能看出它属尖晶石族；它是**反尖晶石（inverse spinel）**结构——一半 Fe³⁺ 占四面体位，这是其强磁性的结构原因。材料未讲。

### 2.6 我们怎么知道地幔的组成

三条证据链：**(1) 间接地球物理**——上/下地幔的**地震波速与橄榄石+辉石实测值高度吻合**；**(2) 直接地质样品**（下述三种）；**(3) 岩石学实验**（讲义列出未展开）。

**(a) 地幔捕虏体 xenoliths**：被上升岩浆携带到地表的地幔碎块，从**火山通道壁**撕下卷入。携带者是**金伯利岩岩浆**：源于地幔深部、**上升极快（讲义 10–40 m/s）**，像钻头一样带出致密岩块。**经济意义：金刚石的重要来源。**

**(b) 造山带橄榄岩 orogenic peridotites**：由**大型逆冲断层**折返。例：意大利阿尔卑斯 **Ivrea–Verbano Zone**、瑞士 **Adula nappe**。阿尔卑斯者为**尖晶石二辉橄榄岩，常含金云母**。

**(c) 蛇绿岩橄榄岩 ophiolite peridotites**：**仰冲（obducted）**到陆壳之上的大洋岩石圈切片，地幔橄榄岩位于剖面**最底部**。**岩石学 Moho** 分隔"**经历过熔融的地幔岩**"与"**由岩浆结晶形成的地壳岩**"，与**地震 Moho** 位置不同；蛇绿岩中可同时有地幔橄榄岩与地壳橄榄岩。常被**强烈蛇纹石化**（例：挪威 Leka 蛇绿岩），岩性以 **harzburgite 与 dunite** 为主。

### 2.7 饱满 vs 亏损地幔

| | **饱满 fertile** | **亏损 depleted** |
|---|---|---|
| 熔融历史 | 未（或极少）经历熔融 | 已经历熔融 |
| 矿物组合 | ol+cpx+opx+含铝相 | ol+opx；**无或极少 cpx 与含铝相** |
| 不相容元素 | 仍然存在 | 已被过去熔融剥离 |
| 典型岩性 | **lherzolite** | **harzburgite / dunite** |
| 典型样品 | 造山带橄榄岩、二辉橄榄岩捕虏体 | 蛇绿岩橄榄岩 |

**判断依据**：三元图上无论平衡还是分离熔融，**第一个耗尽的矿物永远是 cpx**。所以有可观 cpx → 饱满；只剩 ol+opx → 熔融后的**残余（residue）** → 亏损。**地球化学表述**：不相容元素随熔体离开，残余因此被剥离。**构造归位**：洋壳在洋中脊由地幔熔融生成，故**洋中脊之下的地幔已被先前熔融亏损**——这解释了蛇绿岩底部为何是 harzburgite。

### 2.8 原生熔体 vs 原始熔体

- **液体演化线 LLD**：一组由**分离结晶**彼此关联的岩浆成分轨迹（W4/Practical 4）。**斜率改变 = 结晶矿物组合改变。**
- **原生熔体 primary melt**：**直接来自地幔**、MgO 很高、**未经（或极少经）分离结晶**，位于 LLD 最未演化的一端。
- **原始熔体 primitive melt**：MgO 高但**不一定 primary**，可能已有少量分离结晶。**primary ⊂ primitive。**
- 识别口诀（课堂）：**SiO₂ ≈ 50 wt.%，"铁证"是 MgO 高、常约 10 wt.%**。
- **关键结论：所有原生熔体都是玄武岩**（被 W6 原样引用为 recap）。

### 2.9 相容与不相容元素

**不相容元素**熔融时优先进入熔体（本周例：**Al、Ti**，及 Na、K、P）；**相容元素**优先保留在残余固体（本周例：**Mg**）。后果：**原生熔体相对源区富集不相容元素，残余固体相对源区亏损不相容元素。**

### 2.10 原生熔体成分取决于 P、T、F

**P 压力、T 温度、F 熔体分数。** 讲义实验数据：

| 体系 | 条件 | F | 产物 |
|---|---|---|---|
| 石榴石橄榄岩 @ 2 GPa | 1450 °C | 1% | **碱性玄武岩** |
| 石榴石橄榄岩 @ 2 GPa | 1500 °C | 16% | **拉斑玄武岩** |
| 尖晶石橄榄岩 @ 1 GPa | 1350 °C | 15% | **碱性玄武岩** |
| 尖晶石橄榄岩 @ 1 GPa | 1450 °C | 20–30% | **拉斑玄武岩** |

归纳：**拉斑玄武岩 = 较浅 + 较高熔融程度（15–30%）**；**碱性玄武岩 = 较深 + 较低熔融程度（<10%）**。

触发熔融的三种方式（讲义末页只给符号）：**−ΔP、+ΔT、+ΔH₂O**。

📎 背景补充：三者分别对应洋中脊/地幔柱的**绝热减压**、地幔柱额外的**增温**、俯冲带板片脱水使地幔**固相线大幅下降**。材料本周只给符号未配文字。

## 三、公式与图表

### 3.1 镁值 Mg#

`Mg# = Mg²⁺/(Mg²⁺+Fe²⁺)`。符号均为**摩尔量**（MgO wt.% ÷ 40.30；FeO wt.% ÷ 71.84），**Fe³⁺ 不计入**，若分析给 Fe₂O₃ᵀ 需先换算。无量纲。典型值：**地幔矿物 90–92**（即比值 ×100），玄武岩全岩约 45–70（越低越演化）。物理意义：Fe²⁺ 比 Mg²⁺ 更不相容，故熔融抬高残余固体 Mg#、结晶降低残余熔体 Mg#。

📎 背景补充：用讲义自己的二辉橄榄岩数据自检——MgO 41.41/40.30 = 1.028 mol，FeO 7.59/71.84 = 0.1057 mol，Mg# = 90.7，与"90–92"和 Fo₉₂ 完全自洽。橄榄石中 Fo 值即 Mg#。

### 3.2 熔融反应式

**平衡熔融**（讲义原文，未配平）：
```
① ol + cpx + opx → L   （三元共结点 E；至 cpx 耗尽）
② ol + opx → L         （沿共结线上行；至 opx 耗尽）
③ ol → L
最终熔体成分 = 起始固体成分
```
**分离熔融**：
```
① ol + cpx + opx → L   （E；cpx 耗尽 → melting stops）
② ol + opx → L         （二元共结点 B；opx 耗尽 → melting stops）
③ ol → L
最终熔体成分 = 纯橄榄石成分
```
**关键差别（课堂原话）**：平衡熔融产生**连续变化的一系列熔体成分**；分离熔融产生**三个离散快照**，熔融分三阶段进行，**中间要停下来等温度升到下一个共结温度**。

### 3.3 超镁铁质岩分类三角图怎么读

- 三顶点 **ol、opx、cpx**，体积百分比归一到 100%。
- **一个顶点 = 该矿物 100%；其对边 = 该矿物 0%**（课堂原话）。这是全部三角图读图的根本。
- 读某点的 ol 含量：向 ol 对边作平行线，用**杠杆法则**量距离，离对边越远 ol 越多。
- **ol = 40% 那条线是 peridotite / pyroxenite 分界**；橄榄岩区内再按 opx:cpx 分为 dunite / harzburgite / lherzolite / wehrlite。
- **读结论**：打点定名 → 把名字翻译成熔融历史（lherzolite → 饱满；harzburgite/dunite → 亏损）。

### 3.4 ol–cpx–opx 三元相图（本周核心，必须能自己画）

**它是什么。** 真实的三元相图是**三维构造**：底面是 ol–opx–cpx 成分三角形，**竖直方向是温度**；纸上的三角图是其**俯视投影**（Canvas 上有 3D 模型可旋转）。

- **三条棱各是一个二元共结相图**：两端是两个纯端元的熔点（一高一中），中间凹下去的最低点是**二元共结点**。
- 加入第三个矿物后，熔融曲线变成**熔融曲面（液相面 liquidus surface）**；原来的二元共结点变成一条**共结线（cotectic）**——老师的比喻是"**像一条指向下坡的河谷**"。
- 所有共结线交汇于全图**温度最低点**：**三元共结点 E**。

**分区**（讲义配色）：**绿色 = ol + L**；**顶部 = cpx + L**；**狭长蓝条 = opx + L**。每个阴影面是"该端元矿物与液体共存"的曲面。

**共结线上的箭头指向温度下降方向**，最终都指向 E。**判断某条共结线上是哪两相 + 液体？看线的两侧是什么场**（课堂给的操作法）。共结线**延伸到三角形边上的交点，就是二维情形下的二元共结点**。

**E 的性质**：在 E 的确切温度上 **ol + opx + cpx + L 四相平衡共存**。课堂点明"这是一个**不变点 invariant point**"：低于此温度液体消失全变固体，高于此温度固体消失全变液体。

📎 背景补充：Gibbs 相律 **F = C − P + 2**。这里 C = 3、E 点 P = 4；相图通常画在**恒压**下，用 F = C − P + 1 = 3 − 4 + 1 = **0**，即不变点——温度与液相成分被完全钉死。这一步材料只给结论。

**课堂完整推演**：

1. **定起点 x**：地幔橄榄岩约 40–50% 橄榄石。用杠杆法则量出 40% 位置，把 x 放在比它更靠 ol 顶点一点处（老师："放哪儿都无所谓，这个练习都能 work"）。
2. **加热**：全图最低温是 E，熔融必从 E 开始，反应 **ol + cpx + opx → L**。
3. **固体往哪走**：**从 x 中抽走成分为 E 的液体，剩下的固体必须沿 E→x 的延长线、直接远离 E 移动**。（质量守恒：液–总–固三点共线，总成分 x 在中间。）
4. **谁先耗尽**：沿此线走会先撞到 **cpx = 0% 那条边** → **cpx 先耗尽**。
5. 之后分岔：

**平衡熔融**：cpx 耗尽后新反应 **ol + opx → L**，图上唯一能三者共存处是 **ol–opx 共结线**。因箭头指向降温方向，要继续熔融就得**升温**，故**液体成分沿共结线倒着（向高温）演化**；同时用连结线追踪固体，固体朝 **ol 顶点**移动。固体到达 100% ol 时 **opx 耗尽**，最后 **ol → L**：固体成分不再变（只剩一种矿物），液体不断加入橄榄石组分，**最终回到起始成分 x**。**结论：最终液体 = 起始固体成分**——桶里没进也没出，只是从 100% 固体变成 100% 液体。

**分离熔融**：第一步相同，直到 cpx 耗尽。**但此时所有熔体已离开系统**，桶里只剩固体 ol + opx，**固液间无化学交换**。于是**三元体系降维成二元**，**熔融必须停止**，直到温度升到 **ol–opx 二元共结点 B 的温度**，发生 **ol + opx → L**（液体成分固定为 B）。opx 耗尽后**再降维成一元**，熔融**再次停止**，直到达纯橄榄石熔点，**ol → L**。**结论：最终液体 = 纯橄榄石成分**；全过程产生**三种成分明确的液体**（E、B、纯 ol）。

📎 背景补充：真实的 Fo–Di–En 体系中镁橄榄石与顽火辉石是**包晶（peritectic）**关系而非简单共结（对应 EART26201 W04 的 Fo–Qz 包晶），故真实熔融路径比这张"纯共结"图复杂。本周的图是**教学简化模型**（Practical 第 4 题也承认其局限）。

### 3.5 液体演化线 LLD 图（FeO–MgO）

**横轴 MgO wt.%（0–12），纵轴 FeO wt.%（0–18）。** 图上一串点是由**分离结晶**关联的岩浆成分；**斜率改变 = 结晶矿物组合改变**（讲义标注了一段 "ol + cpx" 区段）。**分离结晶方向是从右往左**（MgO 由高到低，因 Mg 相容、优先进入结晶相）；**原生熔体位于最右端**。**考点：若问"画出分离结晶的方向"，答从右指向左。**

### 4.3 ★「Compare and contrast」答题法（本周最重要的考试提示）

老师专门花大段课时讲这类题：

- **本课程典型考题形式就是 "compare and contrast A 与 B"。**
- **错误做法**：把 A 全写一遍再把 B 全写一遍——"那只是一道 describe 题"。
- **正确做法**：老师用了刻意荒唐的类比——"compare and contrast 你的大学宿舍与你不在学校时住的地方"。正常回答是"**两处都有地方睡觉，但其中一个比另一个好得多，因为……**"，然后列一串理由。
- **关键句**："看到 compare and contrast，这道题的着力点不是把你知道的一切都写下来，而是**筛选信息并进行批判性分析**——这些岩石有什么共同点，又在哪些方面不同？"
- **结构建议**：先建立**共同点**，再逐条列**差异**，每条差异都要**说明判据**。

### 4.4 ★ 课堂共建的标准答案：三类地幔样品对比

对比对象：① 捕虏体、② 洋壳底部地幔岩石（蛇绿岩）、③ 大陆碰撞带出露的地幔岩石（造山带）。这实质上就是一份**考题范例答案**。

**共同点**：
1. **都是橄榄岩**——按定义 **ol > 40%**，加 cpx 与 opx。
2. 都**粗粒**。
3. **★ 结构都不能告诉我们结晶顺序**。老师明说：**地幔岩石是 W4"看包裹关系判断结晶顺序"那套方法的例外**——"地幔岩石在很多方面都很复杂，但结晶顺序不是你能从薄片里轻易看出来的。"
4. **都必须靠某种不寻常的机制被带到地表**——无论是拳头大小的碎块，还是一整片被逆冲折返的地幔切片。

**差异**：
1. **搬运机制不同**（金伯利岩快速上升 / 逆冲折返 / 仰冲）。
2. **★ 形成压力不同，判据是含铝相**：捕虏体可含**石榴石** → **P > 2 GPa、深度 > 60 km**（三者中最深）；造山带与蛇绿岩橄榄岩主要是**尖晶石**相。
3. **★ 只有捕虏体一系可能含金刚石**：需 **> 80–100 km** 深度，"这就是为什么世界上的钻石矿都分布在这些**金伯利岩管**周围"。
4. **★ 含水性不同（反直觉点）**：**造山带橄榄岩常含金云母** → 可含水（老师："金云母基本上就是黑云母，只是更富镁"，把水以**结构形式束缚在晶格**里）；**捕虏体有时也能见到**；**蛇绿岩橄榄岩是干的——找不到金云母**。有学生指出蛇绿岩底部有大量次生水，老师肯定这是"非常有意思的点"并澄清：**尽管有很多次生水，洋壳中真正的橄榄岩其实相当干**——这里区分的是**原生含水矿物（金云母）**与**次生蚀变（蛇纹石）**。
5. **★ 铬透辉石只见于捕虏体**："我们其实只在相当高压的橄榄岩里才找得到它。"
6. **变形结构不同**：造山带与蛇绿岩橄榄岩可带有与**仰冲/构造侵位**相关的变形结构，捕虏体一般没有。
7. **★ 模式比例不同 → 岩石名不同**：捕虏体、造山带写作 **garnet / spinel lherzolite**（"lherzolite 表示三种矿物比例都不错"）；蛇绿岩写作 **spinel harzburgite**，因为**cpx 模式比例非常低**。
8. **饱满 vs 亏损**（讲完熔融后补充）：**捕虏体与造山带 → lherzolite → 饱满**；**蛇绿岩 → 亏损**。理由链：洋壳在**洋中脊**生成（一年级学过），地壳物质正是这些地幔岩石熔出来的，所以洋中脊之下的地幔已被先前熔融亏损。
9. **共同点补充**：三者都可发生部分熔融，**产物都是玄武质的**。

### 4.5 关于三元相图的口头"元信息"

（推演已在 3.4 复原，此处只补讲义没有的提示。）

- **先确认前置**："你们在地球化学里已经学过二元相图了吧？"——**默认你掌握 EART26201 的二元共结相图**，本周不重讲基础。
- **★ 刻意的简化**："为了这个练习，我们假设这块岩石**不含任何含铝相**。这把四维问题简化成三维，光是这样就已经够烧脑了。"——**答"这张图的局限"时第一条就写这个。**
- **共结线的定义**：只是表示"**两个相加液体可以在这条线上同时共存**"的词；**判断是哪两相就看线两侧**。
- **"平衡"与"分离"在熔融与结晶中做的是同一件事**——直接把 W4 的概念平移。
- **平衡熔融的"锅"比喻**：**一切留在锅里**，液体能与固相化学交换。0%/10%/100% 熔融时锅里分别是全固 / 90%固+10%液 / 全液，**但每个快照锅的全岩化学成分都完全相同**。
- **分离熔融的"锅"比喻**：**每造出一滴液体它就离开锅**（自然界中即液体的**浮力上升**）。锅的体积与化学成分随熔融改变，**每次移走一滴液体锅就重新变回 100% 固体**；因此**液固之间没有化学交换**，液体"从此对我们这个练习而言就隐形了"。
- **降维的说法**："我们把三元体系**降维成二元体系**，在达到 ol–opx 二元共结点温度之前**不能再进行任何熔融**"；opx 耗尽后再降成**一元（unary）**。**"melting stops"在分离熔融里出现了两次。**
- **现场画二元图**：老师建议把 ol–opx 那条边的二元相图单独画出来（下方固相区 ol+opx，上方 opx+L 与 ol+L 两个场，中间二元共结点），然后"**用你在地球化学课上学到的所有原理**把剩下的熔融方程推完"。

### 4.6 关于饱满/亏损与原生熔体

- **判据的推理路径**（老师自问自答）："我们看到在平衡和分离两种情形下，熔化正常地幔橄榄岩时**第一个耗尽的相都是 cpx**。所以如果我看到含相当大比例 cpx 的地幔岩石，我会说它是**饱满**的——因为如果它经历过大量熔融，大部分 cpx 早就被熔掉了。"
- **岩石名 = 熔融历史的速记**："lherzolite 是**饱满地幔**的良好指示；harzburgite 剩下的 cpx 非常少，看的是**经历过先前熔融事件**的地幔。"
- **★ 原生熔体的"铁证"**："约 **50 wt.% SiO₂**，但**真正的铁证（the dead ringer）是 MgO 高、常在 10 wt.% 左右**。"
- **★ LLD 考点**："如果让你画出分离结晶进行的方向，**是从右往左**；原生熔体就是**最右边、任何结晶发生之前**的那些点。"
- **primitive 是提前打的预告**："这是接下来几周你会听我用的另一个词……它**包含 primary 但不限于 primary**。"
- **收尾示范了一句合格的对比结论**："**橄榄岩比原生熔体更富相容元素，而原生熔体更富不相容元素。**"

### 5.1 目的与参考页

**Reference Guide 用到的页**：**p.11** 超镁铁质岩分类命名；**p.2–4** 火成岩系统描述指南。

### 5.2 ★ 红字警告：不要判断地幔岩石的结晶顺序

手册用整个加粗标题强调 **"Don't try to interpret the order of crystallization in mantle rocks!"** 理由链：地幔是**固体**；亏损地幔 = 部分熔体被抽走后的**残余**，饱满地幔 = 尚未显著熔融；整个地幔上一次全熔在 **~4.4 Ga**，该冥古宙**岩浆洋**在 **~4.2 Ga** 前已完全固结；过去 ~4 Ga 中原始结晶结构已被**塑性变形、扩散、重结晶、Ostwald 熟化**等固态过程完全改造。

**应该看什么**：**多边形结构与约 120° 三联点**。成因是**最小化晶界表面自由能**，但需要**长时间固态扩散与重结晶**——所以它本身就是"这块岩石在地幔里待了极久"的证据。

⚠️ 这与 Reference Guide p.4 的通则（"用结构尽可能判断结晶顺序"）**冲突**；地幔岩石是该通则的**明确例外**，老师也单独强调过。

### 5.3 Part 1（75 分钟）：四个样品

每个约 15 分钟，做笔记、素描、估计**模式矿物学**；**75 分钟后即使没看完也必须进入下一部分**。

**A. 蛇绿岩样品 NC1（New Caledonia）**

蛇绿岩底部的地幔橄榄岩正是结晶形成洋壳的玄武质岩浆的源区，**所以它必然经历过部分熔融**。

| 观察 | 推理 | 结论 |
|---|---|---|
| 两种主要原生矿物 ol + opx；橄榄石**大范围蚀变为淡绿色蛇纹石**；opx 含 **cpx 出溶片晶**；少量尖晶石，PPL **深红棕色** | ol 与 opx 为主，cpx 极少（仅以出溶片晶存在，不算独立模式相） | 落在三角图 ol–opx 边附近 → **方辉橄榄岩 harzburgite** |
| 与构造背景是否一致 | harzburgite 正是从 lherzolite 抽走部分熔体后剩下的**残余** | **一致** |

**变形（tectonised）证据**：(1) **弯曲的 opx，形状像"眼球构造 augens"**（手册注明这其实是变质岩术语），被蛇纹石包卷，手标本上也能看到；(2) **橄榄石似被拉长并破碎成亚晶粒**，但因蛇纹石化太强烈不总是容易看出。**成因**：很可能发生在**大洋岩石圈仰冲到陆壳（obduction）**过程中。

**蛇纹石化的水从哪来**：最可能是**海水**，则蛇纹石化发生在**侵位之前或之中**；侵位后**大气降水**循环可加剧，但**单靠这一项无法解释本样品蛇纹石化的规模**。

📎 背景补充：opx 中的 cpx 出溶片晶是**固溶体随降温出溶**的记录（同 W3 的 exsolution、EART26201 W04 的 Ab–Or 溶线出溶）：高温时较多 Ca 可进入斜方辉石结构，降温后溶解度下降，透辉石质相沿特定晶面析出。材料只陈述了现象。

**B. 金伯利岩中的捕虏体**

**BT2 / 15565（Kimberley, 南非）**：四种主要硅酸盐；肉眼即可在薄片上挑出**一个粉色**和**一个绿色**矿物 → **粉色+高突起+各向同性 = 石榴石**；**瓶绿色 cpx = 铬透辉石**（高 Cr 致色）。四相 = **ol、cpx、opx、garnet** → 石榴石为含铝相（P > 2 GPa）→ **石榴石二辉橄榄岩 garnet lherzolite**。两样品都含**少量金云母**（浅棕色云母，酷似黑云母）。

**"这可能是饱满地幔吗？"→ 是。** 论证：饱满 = 先前没有（或极少）部分熔融，因此**还能够**熔融产生玄武质液体；残余称亏损地幔，矿物更少（**通常只有 ol 与 opx**）；BT2/15565 含 **cpx、石榴石、少量金云母**——**若这块岩石熔融，这些矿物全都会被消耗掉**。它们的存在本身就证明它还没被熔过。

**S.115（无手标本）**：

| 观察 | 推理 | 结论 |
|---|---|---|
| cpx 为**铬透辉石**，高 Cr 致**特征绿色** | 常见于地幔捕虏体 | cpx ✓ |
| **近乎不透明**的矿物 | 强着色近不透明 + 各向同性 → 尖晶石（对照：磁铁矿**完全不透明**） | **尖晶石** → 0.8–2.0 GPa |
| **大颗粒金云母**（phlogopite–biotite 固溶体的**富 Mg、贫 Fe 端元**） | 富 **K₂O 与 H₂O**，两者熔融时强烈分配进液相 | **金云母的存在是"饱满地幔"的良好证据** |
| 另两个主要矿物 | — | **ol、opx** |
| 命名 | | **金云母尖晶石二辉橄榄岩 phlogopite spinel lherzolite** |

**铬透辉石化学式**（手册原文）：纯透辉石 CaMgSi₂O₆，铬透辉石写作 **Ca(Mg,Cr)Si₂O₆**（部分 Mg 被 Cr 替代）。见勘误表。

**"S.115 相对 BT2/15565 的深度说明什么？"（标准答案的完整推理链，考试范例）**：① S.115 含铝相是**尖晶石**，BT2/15565 是**石榴石**；② **石榴石稳定于比尖晶石更高的压力**；③ 故 **S.115 来自更低压力**；④ 即**尖晶石稳定域 ~0.8–2.0 GPa**；⑤ **要更精确的压力估计需要额外地球化学信息**，例如 **Al-in-opx 压力计**。

📎 背景补充：Al-in-opx 压力计的原理是——在与石榴石或尖晶石共存的橄榄岩中，Al 在斜方辉石里的溶解度随 P、T 系统变化，故测出 opx 的 Al 含量即可反算压力。材料出现了名字但未解释。

**C. 造山带橄榄岩 O32B（Finero, 意大利）**

| 观察 | 结论 |
|---|---|
| 较大手标本中**深色、有光泽的硅酸盐勾画出明显面理（foliation）** | **金云母 phlogopite** |
| 薄片中橄榄石含**变形纹**，产生**斑块状消光** | 固态塑性变形，与"由构造逆冲折返"一致 |
| **深棕色、各向同性**的矿物 | **尖晶石** |
| **PPL 淡绿色 → cpx**；**PPL 很淡的棕灰色 → opx** | cpx + opx |

综合 → **金云母尖晶石二辉橄榄岩**，与讲义"阿尔卑斯造山带橄榄岩是含金云母的尖晶石二辉橄榄岩"完全对应。

📎 背景补充：Reference Guide p.16 可补齐 opx/cpx 判据链——**消光角是最常用手段**（opx **平行消光**、cpx **斜消光**，须选只显示**单条解理迹**且干涉色最高的晶体）；**颜色**（cpx 可粉至棕并可能多色，opx 通常无色不多色，唯一例外是顽火辉石有微弱但很特征的**淡粉–淡绿多色性**）；**干涉色**（opx 一级低，多数 cpx 二级）；**双晶**（opx **从不**双晶，cpx 可能有）。本实习用的是颜色判据，可用消光角复核。

### 5.4 Part 2（30 分钟）：三元相图上的地幔熔融

把四个样品按观察到的模式含量**点到 ol–opx–cpx 三元图上并标注**。**期望图形**：**NC1 落在（靠近）三角形底边**（几乎无 cpx），**另外三个落在三角形中部**。做完要找 demonstrator 核对。

**Q1｜S.115 部分熔融，写出熔融反应，第一批熔体成分是什么？**
熔融发生在**三元共结点**；反应 **Olv + Cpx + Opx → L**；第一批熔体成分**就等于三元共结点成分：6% olv, 69% cpx, 24% opx**（原文数值，合计见勘误表）。**判据**：全图最低温点是 E，只要三种固相都在场，熔融必从此开始，**液体成分被钉死在 E，与起始成分无关**。

**Q2｜15565/BT2 部分熔融，残余成分怎么变？哪个矿物先耗尽？耗尽时残余是什么？**
**残余沿"直接远离三元共结点"的方向演化**；**cpx 最先被消耗**；耗尽后残余**只含 ol 与 opx**；ol:opx 比例取决于你估计的模式含量，但**你应该发现残余成分与样品 NC1 相当接近**。
—— 这是本次实习的点睛之笔：它把一块**饱满地幔（garnet lherzolite）**通过图解操作变成了一块**亏损地幔（harzburgite）**，而后者就在你手上（NC1），理论—观察闭环。

**Q3｜哪个饱满橄榄岩熔融后残余最像 NC1？**
**取决于你自己的模式含量估计**（开放题，评分看推理是否自洽）。

**Q4｜这张简单三元图的优点与弱点？**
**优点**：使用简单且非常强大；**很好地解释了亏损地幔岩石所观察到的矿物学**。
**弱点**：**简化了真实地幔的矿物学**；**不显示含铝相（garnet、spinel）与含水相（phlogopite），而这些矿物全都会参与熔融反应**。（课堂版说法：假设不含含铝相，是为把四维问题降成三维。）

### 5.5 加分薄片

**BF2（Bultfontein, 南非）**：**多数金伯利岩是碎屑状岩石**，这一片矿物学与结构都不典型，来自与真正金伯利岩伴生的**小岩床**。三种主要矿物，两种是**非硅酸盐**：**钙钛矿 perovskite（CaTiO₃）**（棕色、各向同性、方形）与**方解石 calcite**——**判据：高突起 + 极高双折射（淡粉/淡绿，也可能像沙棕色）**。方解石意味着碳酸盐，最可能来自**溶解在金伯利岩岩浆中的 CO₂**，说明**金伯利岩岩浆极度富挥发分**（H₂O 也很高，但**未保存在矿物记录中**）。**结构为斑状**；橄榄石**有自形、有半自形、也有浑圆的**——**浑圆形态说明它们与岩浆不平衡、被部分熔蚀（resorbed）**；许多橄榄石是**捕虏晶 xenocrysts**（直接来自地幔，在岩浆钻穿地幔与岩石圈时被卷入），带**蛇纹石反应边**，**水来自金伯利岩岩浆自身**（对比 NC1 的**海水**——两题答案必须区分）。

**15562（Kimberley, 南非）**：金伯利岩中的**捕虏体**，岩石类型是**榴辉岩 eclogite**，**全岩化学成分与玄武岩相同**；榴辉岩由**玄武岩的高压变质**形成，金伯利岩中的榴辉岩结核被认为来自**俯冲并变质了的玄武质洋壳**。两种主要矿物：**cpx + 石榴石**（其一有反应边）；深绿色方形各向同性者为尖晶石。**关键洞察（手册原话）**："注意，这正是**饱满二辉橄榄岩部分熔融时被消耗掉的那两个矿物**。"

**把两者点到三元图上**：**BF2 落在橄榄石顶点，15562 落在单斜辉石顶点**，看起来与其他样品差别很大——在橄榄岩分类图上像**单矿物岩**（BF2 → dunite，15562 → clinopyroxenite）——**但这是因为该三元图不包含它们其他矿物的信息**（BF2 的钙钛矿与方解石、15562 的石榴石都没有位置）。**这是"分类图必须选对"的绝佳反面教材。**

### 5.6 评分要点与常见错误

- **选对分类方案**：超镁铁质岩用 **ol–opx–cpx 三角图**，不要用 QAPF，也不要用 TAS（TAS 需要地球化学分析，薄片给不了）。
- **模式含量**用 Reference Guide 末尾的**估算图版**，并**归一化到 100%** 再打点。
- **命名格式**：**类型矿物在前、按丰度由低到高排列**，根名在后。例：**phlogopite spinel lherzolite**。
- **次生矿物不写进岩石名**：蛇纹石是次生的，NC1 仍叫 harzburgite；而尖晶石在地幔橄榄岩中作为**指示压力的含铝相**被写进名字。
- **不要判断结晶顺序**（见 5.2）。
- **描述顺序**：原生大晶体 → 原生小晶体 → 副矿物 → 次生矿物。
- **素描要求**：画大（约 10 cm）、**必须有比例尺**（用透明尺在镜下估视野）、**不要写 "×10"/"×20"**（那只是物镜倍数，不等于图的比例）、描述里提到的矿物与结构都要出现在图上。

## 六、易错点 / 重点难点

1. **★ 地幔岩石不能判断结晶顺序**——这是本课通则的明确例外（老师与实习手册两处独立强调，几乎一定考）。要找的是 **120° 三联点的多边形结构**，不是包裹关系。
2. **★ primary vs primitive**：primary = 直接来自地幔、**未经**分离结晶；primitive = MgO 高但**可能**经历过少量分离结晶。**primary ⊂ primitive。**
3. **★ 饱满/亏损 ≠ 富镁/贫镁**：说的是**不相容元素与 cpx 的有无**。亏损地幔（harzburgite）的 Mg# 其实**更高**，因为 Fe 比 Mg 更不相容、被熔体带走了。
4. **★ 蛇绿岩橄榄岩"干"**：它被强烈蛇纹石化，但那是**次生蚀变（海水）**；**原生矿物组合里没有金云母**，故在原生含水性意义上是干的。造山带橄榄岩才是原生含水的。
5. **★ 石榴石与尖晶石只能靠颜色分**：两者都立方、都各向同性、都高突起、都无解理。**石榴石粉红、尖晶石深棕/深绿。**
6. **★ 尖晶石 vs 磁铁矿**：尖晶石**强着色但仍透光**（可"近乎"不透明），磁铁矿**完全不透明**。判据全在 PPL。
7. **★ 平衡与分离熔融的产物完全不同**：平衡最终液体 = **起始固体成分**（锅里没进没出）；分离最终液体 = **纯橄榄石成分**。过程上平衡是**连续谱**，分离是**三个离散快照**且中间**熔融两次停止**等待升温。
8. **★ 固体演化方向易背反**：记「**抽走 E 成分的液体 → 残余沿 E→x 延长线直接远离 E**」；想不起来就回到质量守恒（液–总–固三点共线，x 在中间）。
9. **共结线箭头指温度下降方向**（指向 E），但**熔融时液体沿共结线逆着箭头向高温走**（要继续熔融必须升温）。很多人弄反。
10. **含铝相 ↔ 压力界线必须背准**：plag < **0.8 GPa** < spinel < **2 GPa** < garnet；spinel ≈ 20–60 km，garnet > 60 km；金刚石更深。
11. **金云母不是压力指示矿物，是含水性指示矿物**——别塞进"含铝相随压力变化"的逻辑里（尽管讲义排在同一页）。
12. **cpx 永远第一个熔完**——这是把矿物学观察翻译成熔融历史的唯一钥匙。
13. **拉斑 vs 碱性别记反**：**拉斑 = 浅 + 高熔融程度（15–30%）**；**碱性 = 深 + 低熔融程度（<10%）**。
14. **LLD 上分离结晶方向从右往左**，原生熔体在最右端。
15. **三元图的局限要能背**：忽略含铝相与含水相，而它们都参与真实熔融反应。答优缺点题时先说简单强大、能解释亏损地幔矿物学，再说简化。
16. **"Compare and contrast" ≠ 分别描述**：必须有**共同点段 + 差异段**，每条都给**判据**。
17. **蛇纹石化的水源分情况**：NC1（蛇绿岩）→ **海水**；BF2（金伯利岩岩床）→ **岩浆自身的含水流体**。同一问题两个答案。
18. **地震 Moho ≠ 岩石学 Moho**：后者分隔"熔融过的地幔岩"与"岩浆结晶成的地壳岩"；蛇绿岩里可同时有**地幔橄榄岩**与**地壳（堆晶）橄榄岩**，别把底部所有超镁铁岩都当地幔。
