## 二、核心概念

### 2.1 结晶发生的场所与描述岩浆的术语

结晶既发生在**喷出环境（extrusive environments）**，例如地表的熔岩流；也发生在**侵入环境（intrusive environments）**，例如地壳内的岩床（sill）。讲义用一张示意图对照二者。

描述一块正在结晶的岩浆／已凝固的岩石，需要区分四个层次的对象（讲义 "Some terminology"）：

| 状态 | 组分 | 说明 |
|---|---|---|
| 熔融态 Molten | **magma（岩浆）** | 熔体 + 晶体 + 气泡的总和 |
| | **melt（熔体）** | 只指液体部分 |
| | **crystals（晶体）**、**bubbles（气泡）** | 悬浮／溶出的固相与气相 |
| 结晶态 Crystalline | **whole rock（全岩）** | 凝固后的整体 |

老师提醒：这套区分「你们在后面的实习里会一直用」，magma 与 melt 混用是常见的表述错误。

### 2.2 成核（nucleation）：从液体里长出第一个稳定晶核

**成核是「一个稳定新晶体的形成」，是结晶的起点。** 讲义给出的物理图像是 Gibbs 自由能的两项竞争：

- 一个晶核的**总自由能 ΔG_T = 表面能 ΔG_s + 体积能 ΔG_V**。
- 随着晶核半径 r 增大，ΔG_T 先**升高**，达到极大值后再**下降**。
- 这个极大值对应的半径叫**临界半径 r_c（critical radius）**；对应的自由能垒叫 **ΔG\*，即形成一个稳定晶核所需的活化能（activation energy）**。
- 晶体一旦长到 r_c 就**稳定**了；小于 r_c 的晶核**既可能继续长大，也可能被熔体重新吸收（resorbed back into the melt）**。

> 📎 **背景补充：** 讲义没有写出 ΔG_s 与 ΔG_V 的符号约定，但这是理解曲线形状的关键。表面能项 ΔG_s ∝ +4πr²γ（γ 为固—液界面能，恒为正，随 r² 增长）；体积能项 ΔG_V ∝ −(4/3)πr³·Δg_v（在过冷条件下 Δg_v > 0，故此项为负，随 r³ 增长）。小半径时 r² 项占优 → ΔG_T 上升；大半径时 r³ 项占优 → ΔG_T 下降。令 dΔG_T/dr = 0 可解出 r_c = 2γ/Δg_v，并有 ΔG\* = 16πγ³/(3Δg_v²)。由于 Δg_v 随过冷度 ΔT 增大而增大，**过冷度越大，r_c 越小、能垒 ΔG\* 越低，成核越容易**——这正是下文 N–ΔT 曲线上升段的物理原因。此外，本课只讨论了均质成核（homogeneous nucleation）；自然界中晶体更常在已有晶体、气泡壁或围岩碎屑表面发生**非均质成核（heterogeneous nucleation）**，因为现成的界面大幅降低了 γ 的代价。

### 2.3 平衡结晶 vs 分离结晶 vs 封闭体系

讲义用三排「熔体百分比 / 结晶百分比」的卡通图对比：

- **平衡结晶（equilibrium crystallization）**：冷却过程中，已结晶的晶体**始终与残余熔体保持化学平衡**并可持续反应交换。图上标注为 100% melt / 0% cryst → 90/10 → 50/50 → 20/80，**晶体留在体系内**。
- **分离结晶（fractional crystallization）**：晶体一旦形成就**立即被移出体系**（沉降、堆晶、壁面附着等），不再与残余熔体反应。图上四格都标 **100% melt**，但结晶度依次为 0%、10%、50%、80%——即「我们只关心剩下的液体」。
- **封闭体系结晶（closed system crystallization）**：与平衡结晶同一组数字（90/10、50/50、20/80），强调**物质总量不进不出**。

老师在课上没有再展开推导，理由是「你们在 Principles of Geochemistry 已经学过」，但**强烈要求每人准备好两三句话的标准定义**：什么是平衡结晶、什么是分离结晶、二者的区别——这是明确的口头考试提示。

关键推论（后面 LLD 一节要用）：**分离结晶下，相容元素（compatible elements）被结晶矿物「隔离」并随晶体离开体系，残余熔体中浓度下降；不相容元素（incompatible elements）因为离子半径太大或电荷太高而进不了结晶矿物，在熔体中不断富集。**

### 2.4 鲍文反应系列（Bowen's reaction series）

讲义给出的图是经典的双分支结构，温度自 **~1250 °C** 降到 **~750 °C**：

- **不连续分支（discontinuous branch，左）**：olivine → pyroxene → amphibole → biotite（讲义在 biotite 附近打星号，注为 \*muscovite、\*K-feldspar）。
- **连续分支（continuous branch，右）**：**钙质斜长石（Ca-rich plagioclase）→ 钠质斜长石（Na-rich plagioclase）**，为连续固溶体。
- 两支在低温端汇合，依次是 **K-feldspar → muscovite → quartz**。
- 温度轴左侧同时标注岩浆类型：**~1250 °C（komatiite）→ Mafic（basalt）→ Intermediate（andesite）→ Silicic（rhyolite）~750 °C**。

**老师口头补充的核心洞见（讲义上没有）：** 沿着鲍文反应系列往下走，结晶出来的矿物**硅酸盐结构越来越复杂**——正硅酸盐（orthosilicates，橄榄石）→ 单链硅酸盐（single-chain，辉石）→ 双链硅酸盐（double-chain，角闪石）→ 层状硅酸盐（sheet，云母）→ 架状硅酸盐（framework，石英）。**唯一的例外是斜长石**：它是架状硅酸盐，却「基本在什么岩石里都结晶」，可以与橄榄石这种最简单的结构共结晶；其特殊性在于**成分随温度连续变化**（基性岩中富钙、酸性岩中富钠）。

讲义给出三个「模式矿物学随岩浆演化变化」的例子（这是 ILO 中「qualitatively describe how modal mineralogy changes」的落点）：

| 岩浆 | 结晶组合 |
|---|---|
| 基性岩浆 1 | ~10% 橄榄石 + ~50% 辉石（普通辉石 augite）+ ~40% 斜长石（钙质） |
| 基性岩浆 2 | ~50% 辉石（augite）+ ~50% 斜长石（钙质） |
| 中性岩浆 3 | ~10% 角闪石（普通角闪石 hornblende）+ ~10% 黑云母 + ~5% 辉石 + ~30% 斜长石（钠质）+ ~25% 石英 + ~20% 钾长石 |

**⚠️ 讲义原文的警告（考点）：** *"A note of caution: Bowen's Reaction Series doesn't necessarily predict the order of crystallization in a magma. Need to look at the thin section!"* —— 鲍文反应系列**不必然预测**某一具体岩浆中的结晶顺序，必须看薄片。Practical Reference Handout 也重复了这一点：「在多数火成体系中多种矿物同时结晶，所以鲍文反应系列通常不是判断结晶顺序的好证据。」

### 2.5 过冷度、成核率与生长率：粒度的控制因素

**核心关系式：粒度 ∝ 晶体生长率 G / 成核率 N。**

**过冷度（degree of undercooling / supercooling）ΔT** 定义为体系温度低于液相线（liquidus）的度数。老师现场解释的物理直觉（讲义上没有）：

- **ΔT ≈ 1 °C**：几乎无法成核，也许只能成一个核；但体系仍然很热，**元素在液体中扩散容易**，原料输送顺畅，那一个晶体可以长得**很大**。
- **ΔT ≈ 100 °C**：成核很容易，可以同时成核大量晶体；但**扩散困难**，元素来不及输运到晶体边界，晶体**长不大**。

由此得到三种结局（讲义 Gill 2010 Fig. 2.3.1）：

| 环境 | N 与 G 的关系 | 结果 |
|---|---|---|
| 深成（plutonic），散热慢 | **G >> N** | 粗粒结构（coarse-grained） |
| 火山（volcanic），散热快 | **N >> G** | 细粒结构（fine-grained） |
| 极快冷却／瞬时淬火 | **N 和 G ≈ 0** | 玻璃（glass） |

> ⚠️ 讲义专门提示：**符号 G 既用于晶体生长率（crystal growth rate），也用于吉布斯自由能（Gibbs free energy）**，只能靠上下文区分。老师在课上又口头重复了一遍。

### 2.6 熔体聚合度、扩散与「为什么玄武岩玻璃比流纹岩玻璃难做」

成核和生长都要求**阳离子能在硅酸盐熔体中扩散**。讲义（Best 2006 Fig. 4.2）与老师的口头展开：

- **SiO₂ 是高度聚合（highly polymerised）的结构**。熔体中 SiO₂ 越多，聚合度越高，其他非硅阳离子越难移动。
- 图中的液体 B ≈ 把石英加热熔融的产物：键变柔软了，但**仍保留大量聚合骨架** → 类比**流纹岩**，极其黏稠、高硅、阳离子难迁移。
- 图中的液体 C ≈ 含 Ca、Mg，每个 Ca/Mg 配两个 SiO₄ 四面体单元：这些阳离子**打断（depolymerise）**硅酸盐骨架 → 类比**玄武岩**（约 50% SiO₂、50% 其他阳离子），黏度显著低于 B。

推论链条（老师明确串起来的）：
**高硅 → 高聚合 → 高黏度 → 扩散困难 → 难成核、难生长 → 容易成玻璃。** 所以流纹质熔岩流里常见**黑曜岩（obsidian）**。
**低硅 → 去聚合 → 低黏度（液相线温度下"像金黄糖浆 golden syrup"）→ 扩散容易 → 只需很小的过冷度就能大量成核 → 必须极端快淬才能得到玄武玻璃。**

> 📎 **背景补充：** 讲义与转写都只做了定性对比，没给黏度数值。作为量级参考：液相线温度附近的**玄武质熔体黏度约 10¹–10² Pa·s**，而**流纹质熔体可达 10⁵–10⁸ Pa·s**，相差 4–7 个数量级；水（20 °C）约 10⁻³ Pa·s。这解释了为什么玄武岩形成流动的熔岩流，而流纹岩常形成穹丘与厚而短的流。

玄武玻璃的天然产地（老师给出的实例）：**海底喷发（枕状玄武岩 pillow basalt）**、**冰下喷发（subglacial eruption）**——后者的机理与前者相同，只是围压来自冰而非海水；以及**次生（subaerial）喷泉状喷发**中被抛入空中、与空气快速淬冷的物质。

### 2.7 边界层与骸晶／树枝状生长

这是本周最精彩的机理链条，主要来自课堂讲述 + 讲义 Gill (2010) Fig. 5.10：

1. 晶体生长时会把自己**不要的**元素排出到紧邻的熔体中，形成一层成分被改造的**边界层（boundary layer）**。同时，它**需要的**元素在边界层中被消耗殆尽（depleted melt）。
2. 例：正在生长的斜长石不要 Mg，Mg 就在其周围堆积；同时边界层里的 Ca、Na、Al（斜长石想要的成分）被抽干。
3. 这层耗尽层**抑制晶面（faces）上的继续沉积**。
4. 晶体的对策：**从棱角（corners）向外长出树枝状尖刺（dendritic spikes）**，因为角部相对单位晶体表面积能接触到更大体积的熔体；尖刺**穿透**耗尽的边界层，伸进成分新鲜的熔体中。
5. 一级尖刺（primary spikes）还可以再生出二级尖刺（secondary spikes）。
6. 结果就是**骸晶（skeletal）／树枝状（dendritic）／羽状（feathery）结构**：外形看似自形，但晶体内部有空洞。讲义实例：**Apollo 12 月海玄武岩（mare basalt）中的淬火橄榄石结构**；以及 Shea et al. (2015) 关于**夏威夷 Kilauea 橄榄石中磷（P）化学环带**的研究。

**这种结构只在岩浆冷却极快时出现**，是判断冷却速率的直接证据。

### 2.8 火成结构（igneous textures）与结晶顺序

讲义与 Practical Reference Handout 共同覆盖的结构术语：

- **斑状结构（porphyritic）**：**双峰粒度分布**——大的**斑晶（phenocrysts）**嵌在细粒**基质（groundmass）**中。斑晶通常**自形（euhedral）**，因为它们在岩浆房里「自由漂浮、不碰到任何东西」，能慢慢长成理想晶形；基质则是喷出地表后快速冷却的产物。若斑晶嵌在玻璃中，则用 **vitrophyric（玻基斑状）**；基质能看清晶体时用 **aphanitic**。
- **聚斑结构（glomeroporphyritic）**：斑晶在岩浆房中**聚集黏结成团（glomerocrysts）**后再一起喷出；形成过程称 **synneusis**。安山岩中常见。
- **嵌晶结构（poikilitic）**：许多**矿物 A 的小晶体被一个矿物 B 的大晶体完全包裹**。被包者称 **chadacrysts（"被容纳的晶体"）**，包裹者称 **oikocryst（"房子晶体"）**。讲义实例：橄榄石（olv）被斜方辉石（opx）大晶体包裹。**结晶顺序判读：A 先于 B。**
- **辉绿（间粒）结构 ophitic**：poikilitic 的特例，特指**随机取向的斜长石板条（laths）被大普通辉石（augite）完全包裹**，典型见于**辉绿岩（dolerite）与辉长岩（gabbro）**。
- **次辉绿结构 sub-ophitic**：斜长石只被辉石**部分**包裹；辉石填充在较大斜长石之间的空隙——也可以描述为**填隙结构（interstitial texture）**，老师用沉积岩的「孔隙（pore space）」作类比。
- **粒序结构 seriate**：晶体大小呈**连续、渐变**的范围（而非双峰或三峰）。
- **等粒／不等粒（equigranular / inequigranular）**。

**辉绿结构的两种成因（讲义明确说「你不需要从薄片里判断这个」）：**
- (a) 斜长石与单斜辉石**同时成核**，但 cpx 生长更快，把慢长的斜长石包了进去。结晶顺序：**1. Plag + cpx（同时）**。
- (b) 斜长石**先成核**，cpx 后成核，但 cpx 长得快并包裹之。结晶顺序：**1. Plag；2. Plag + cpx**。
- 二者的终态差别只体现在**被包裹晶体的粒度分布**上，「除非做统计检验，否则很难分辨」。要点是：**成核顺序与生长速率共同决定最终结构。**

**判断结晶顺序的三条证据链（综合讲义与 Reference Guide p.3–4）：**
1. **包裹关系**：被包裹的矿物较老，包裹它的矿物较新（矿物包裹体、chadacryst/oikocryst 都算）。
2. **晶形**：早结晶的矿物一般**自形**；晚结晶的必须绕开已有晶体生长，因而**半自形（subhedral）／他形（anhedral）**。
3. **同一矿物的大小**：同一种矿物既有大晶体又有小晶体时，**大的先长**（前提是假设生长速率相同）。

**「没看到」也是有用的观察**（老师强调）：如果 A 和 B 之间**看不到**任何包裹关系，可以解释为二者**同时**从同一液体中生长；如果既见 A 包 B 又见 B 包 A，那也说明二者大致同时生长。

### 2.9 岩石描述与分类框架

讲义给的框架图：

```
火成岩描述  =  矿物学的（mineralogical）  +  结构的（textural）
              · 模式矿物学 modal mineralogy      · 矿物的形状与分布
                                                 · 粒度 grain size
                                                 · 颜色 colour
                                                 · 矿物定向 alignment
                                                 · 结晶顺序
      ↓
火成岩分类  =  岩石学的（petrological，基于矿物学+结构观察）
              或 化学的（chemical，基于岩石化学分析）
```

**粒度**：讲义强调「**在粒度不均一的岩石中，用基质（groundmass）的粒度决定这块岩石用细粒名还是粗粒名**」。这条规则直接决定了岩石名：细粒 → basalt / andesite / rhyolite；粗粒 → gabbro / diorite / granite。

**色率（colour index）**：用浅色（felsic）与深色（mafic）矿物的比例描述，从 **leucocratic（浅色，如白云母花岗岩）** 到 **holomelanocratic（全深色，如辉石岩 pyroxenite）**。颜色与岩浆成分相关（玄武岩=基性、黑曜岩=长英质），但**讲义警告：细粒岩石往往比其成分应有的颜色更深**。

**矿物学分类的信息采集清单**（讲义给出的八栏描述表格，是薄片描述的标准模板）：
`矿物 + 模式含量 | 大小、习性、形状 | 突起、颜色、多色性、解理 | 干涉色、消光类型 | 双晶、环带、出溶 | 蚀变？ | 结构关系 | 定名`

讲义给的示范行（矿物 A，40%）：「1–2 mm 斑晶，自形板状；<0.1 mm 基质，自形针状 | 低突起、无色、无解理 | 低一级干涉色，相对晶棱斜消光 | 聚片双晶（multiple lamellar twinning），大斑晶显示同心环带，无出溶 | 最大晶体核部有些浑浊蚀变 | → **斜长石 Plagioclase**」。

> **关键方法论（讲义原文）：先描述矿物，再鉴定矿物**（"Describe minerals first, then identify"）。同时必须区分**原生矿物（primary，从岩浆结晶而来）**与**次生矿物（secondary，岩石蚀变形成）**。

**定性分类的三类矿物（讲义 + Reference Guide）：**
- **Essential minerals（必需矿物）**：由根名（root name）**隐含**。例：「granite」这个名字就告诉你岩石含石英 + 斜长石 + 碱性长石。
- **Type minerals（型矿物）**：**不被**根名隐含，因此要写进岩石名里做修饰词。若有多个，**含量最少的写在最前面**（例：biotite muscovite granite，即黑云母 < 白云母）。讲义补充：「岩石名里出现超过两个型矿物是不寻常的」。
- **Essential + type = major minerals（主要矿物）**。
- **Accessory minerals（副矿物）**：占比很小（通常 <5%），**不进岩石名**。常见：不透明氧化物、磷灰石（apatite）。
- **Secondary minerals（次生矿物）**：岩浆完全结晶**之后**形成，可充填空隙或交代原生矿物，**不进岩石名**。讲义实例：**蛇纹石（serpentine）交代橄榄石、绿泥石（chlorite）交代黑云母、绢云母（sericite，黏土矿物）交代斜长石、杏仁状玄武岩（amygdaloidal basalt）**中沸石类充填气孔。

### 2.10 相容／不相容元素与液体演化线（liquid line of descent）

- **相容元素（compatible）**：容易被结晶矿物「吸收隔离（sequestered）」。例：**Mg 在橄榄石和单斜辉石中相容；Ca 在单斜辉石和斜长石中相容**。分离结晶进行时，其在**残余熔体**中的浓度**下降**。
- **不相容元素（incompatible）**：因**离子太大或电荷太高**而难以进入结晶矿物，在熔体中**富集**。例：**K** 进不了橄榄石、进不了单斜辉石、进不了角闪石，**但进得了黑云母**——所以玄武质熔体结晶初期 K 一直在液体里积累，**直到演化到流纹质端元、黑云母／白云母开始加入结晶组合，K 才开始被拉进固相**。

**液体演化线（liquid line of descent, LLD）** 的定义（老师专门澄清）：这里的 "descent" 是「**血统／世系**」意义上的 descent（parent–child），**不是「向下」的意思**。它指一系列由同一母岩浆通过结晶分异派生出来的液体成分的轨迹。

**核心几何法则：**
> **结晶某矿物 = 从熔体中按该矿物的成分比例抽走其化学组分 ⇒ 若该矿物成分固定，则熔体成分必然沿着「远离该矿物成分点」的直线演化。**

这是本周最重要的可操作技能，详见第三节图解。

## 三、公式与图表

### 3.1 成核的自由能公式

$$\Delta G_T = \Delta G_s + \Delta G_V$$

| 符号 | 含义 | 单位 | 说明 |
|---|---|---|---|
| ΔG_T | 晶核的**总**吉布斯自由能变 | J（或 J/mol） | 曲线先升后降 |
| ΔG_s | **表面能**项 | J | 正值，∝ r²，阻碍成核 |
| ΔG_V | **体积能**项 | J | 过冷条件下为负，∝ r³，驱动成核 |
| r_c | **临界半径** | m（实际为 nm 量级） | ΔG_T 的极大值位置 |
| ΔG\* | **活化能**（成核能垒） | J | ΔG_T 在 r_c 处的值 |

**图的读法（讲义 "Nucleation" 图）：** 横轴 = 晶核半径 r；纵轴 = 自由能变化。三条曲线：ΔG_s（向上开口的正曲线）、ΔG_V（向下的负曲线）、二者之和 ΔG_T（先升后降的驼峰）。驼峰顶点的横坐标是 r_c，纵坐标是 ΔG\*。**r < r_c 的区域标 "not stable"（晶核可能长大也可能被熔体重新溶解）；r > r_c 的区域标 "stable"（继续长大反而降低自由能，因此不可逆地长大）。**

> 📎 **背景补充：** 讲义未给单位与典型数值。硅酸盐熔体中临界晶核半径 r_c 通常在 **1–10 nm** 量级，即几十到几百个原子；这正是为什么成核事件在实验中难以直接观测，也是为什么非均质成核（在已有界面上成核）在自然界占主导。

### 3.2 粒度与 N、G 的关系

$$\text{grain size} \propto \frac{G}{N}$$

- **G**：晶体生长率（crystal growth rate），单位可写作 m/s 或 mm/day（晶体线尺寸增长速率）。
- **N**：成核率（nucleation rate），单位为 个/(m³·s)。
- **适用条件**：定性关系，用于比较不同冷却环境；讲义未给定量常数。

**N–G vs ΔT 曲线的读法（Gill 2010 Fig. 2.3.1；这是本周必考图之一）：**

- **横轴：过冷度 ΔT（degree of undercooling）**，从 0（液相线温度）向右／向下增大。
- **纵轴：速率**（成核率 N 与生长率 G 各一条曲线）。
- **N 曲线（讲义中为黑色）**：ΔT = 0 附近**为零**——必须先过冷到一定程度才会开始结晶；随后**迅速上升到极大值**；再往后因为冷却太快、扩散被冻结，**又下降**，最终在极大过冷度下**被完全抑制**，得到非晶质（amorphous）固体即玻璃。
- **G 曲线**：在**较小的过冷度**处达到峰值（峰位比 N 的峰位更靠近 ΔT = 0），然后**迅速衰减**。
- **三个读图区间：**
  1. **小 ΔT（慢冷）**：G 相对高、N 低 → **G >> N** → **粗粒（深成岩）**。
  2. **中—大 ΔT（快冷）**：N 高、G 低 → **N >> G** → **细粒（火山岩）**。
  3. **极大 ΔT（瞬时淬火）**：N → 0 且 G → 0 → **玻璃**。

### 3.3 鲍文反应系列图的读法

- **纵轴：温度**，顶部 ~1250 °C，底部 ~750 °C。
- **左支（不连续系列）**：olivine → pyroxene → amphibole → biotite。称「不连续」是因为随温度下降，晶体结构**跳变**为另一种矿物（相邻两项之间是包晶式反应关系）。
- **右支（连续系列）**：Ca-rich plagioclase → Na-rich plagioclase。称「连续」是因为只是同一固溶体内**成分连续变化**（An → Ab）。
- **两支下方汇合**：K-feldspar → muscovite → quartz（讲义在 muscovite、K-feldspar 前标了星号）。
- **右侧对应的岩浆／岩石类型**：komatiite（~1250 °C）→ mafic (basalt) → intermediate (andesite) → silicic (rhyolite)（~750 °C）。
- **读结论的方式**：给定一块岩石的矿物组合，可以定位它在系列上的大致位置，从而推断其岩浆演化程度；**但不能直接读出该岩石中矿物结晶的先后**（讲义明确警告）。

### 3.4 QAPF 三角图与定量分类（Worked example 3）

**QAPF = Quartz–Alkali feldspar–Plagioclase–Feldspathoid。**

- **三角形的三个顶点**（无似长石的情况用 QAP 三角）：顶点 **Q = 石英**，左下角 **A = 碱性长石**，右下角 **P = 斜长石**。
- **使用步骤（Reference Guide p.9）：**
  1. 测（或目估）模式矿物学，估出 Q、A、P、F 的百分比。
  2. **若无似长石**：把 Q、A、P **归一化到 100%**，投在 QAP 三角上。
  3. **若无石英**：把 A、P、F 归一化到 100%，投在 APF 三角上。
  4. **一块岩石不可能同时含石英和似长石**（silica saturated vs undersaturated 互斥）。本课不研究含似长石的岩石。
  5. QAP(F) 只给**根名**；再用型矿物加修饰。

**Worked example 3（讲义原始数据与归一化结果）：**

| 矿物 | 原始模式含量 | 归一化到 QAP=100% |
|---|---|---|
| 碱性长石（正长石 orthoclase） | 15% | **19%** |
| 斜长石 plagioclase | 35% | **44%** |
| 石英 quartz | 30% | **37%** |
| 黑云母 biotite | 20% | （不参与 QAP 归一化） |

验算：Q+A+P = 15+35+30 = 80；30/80 = 37.5% → 37%；15/80 = 18.75% → 19%；35/80 = 43.75% → 44%。✔ 讲义数字自洽。

投图落在 **Q ≈ 20–60%、P/(A+P) ≈ 65–90%** 的区间 → **granodiorite（花岗闪长岩）**；黑云母作为型矿物加在前面 → **biotite granodiorite（黑云母花岗闪长岩）**。

**其余三角图的分工**（讲义预告）：**超镁铁质岩三角图（ol–opx–cpx，Streckeisen 1973）→ Week 5**；**花岗岩类 QAPF → Week 9**。Reference Guide p.8 还给了基性岩三角图（plg–px–ol 与 plg–cpx–opx–hbl，Streckeisen 1967）。

### 3.5 简单矿物学分类的两个 Worked example

**Worked example 1：**
- 粒度：有各种大小的斑晶 + **细粒基质** → **必须用细粒（喷出岩）根名**。
- 矿物：**橄榄石**（basalt 的 **type mineral**）、**单斜辉石 + 钙质斜长石**（basalt 的 **essential minerals**）。
- 定名：**basalt → olivine basalt（橄榄玄武岩）**。

**Worked example 2：**
- 粒度：粗粒 → **必须用粗粒（深成岩）根名**。
- 矿物：碱性长石（微斜长石 microcline）、钠质斜长石、石英 → **granite / granodiorite 的 essential minerals**；白云母、黑云母 → **type minerals**；磷灰石（apatite）→ **副矿物，不进岩石名**。
- 定名：**granite → biotite muscovite granite**（白云母 > 黑云母，故含量最少的 biotite 写在最前）。

### 3.8 变异图（variation diagram）

- **定义**：展示一**套（suite）**火成岩中主量（或微量）元素丰度如何变化的图。
- **x 轴的选择原则**：选一个**能追踪岩浆通过结晶作用发生成分演化**的元素或氧化物。
  - **SiO₂ 作 x 轴**：适用于成分跨度从玄武岩到流纹岩的岩套。此时**结晶从左向右进行**（SiO₂ 增加）。
  - **MgO 作 x 轴**：适用于 SiO₂ 变化很小的**玄武质岩套**。此时**结晶从右向左进行**（MgO 减少）。
- **y 轴**：任意其他氧化物。
- **读结论**：看趋势是否随 x 系统变化；**趋势线出现折点（change in gradient）= 结晶矿物组合发生了变化**。

讲义给的两个示例：SiO₂ vs 各氧化物（起点为空心圆，结晶自左向右：CaO 下降、Na₂O 上升、MgO 下降）；MgO vs TiO₂（结晶自右向左：TiO₂ 先上升，然后**转折下降**——老师留下的问题就是「为什么不是一条直线？是什么造成这个明显的转折？能不能定量？」，答案在 Practical 中揭晓）。

### 3.9 液体演化线的图解法（本周最核心的图，务必掌握）

**图的构造：** 一张 x–y 二元成分图。讲义用的是 **x 轴 = SiO₂ wt.%，y 轴 = MgO wt.%**（Practical 中改用 **x 轴 = MgO，y 轴 = FeO**，原理完全相同）。图上同时投**熔体（岩石全岩）成分**与**矿物成分**。讲义标出的矿物成分点：

| 矿物 | 讲义给的化学式 | 在 SiO₂–MgO 图上的位置 |
|---|---|---|
| 橄榄石 Olivine | Mg₂SiO₄ | 低 SiO₂、**极高 MgO** |
| 斜长石 Plagioclase | CaAl₂Si₂O₈ | 中等 SiO₂、**MgO ≈ 0** |
| 普通辉石 Augite | MgCaSi₂O₆（见勘误表） | 高 SiO₂、中等 MgO |

**四步推理（讲义 + 转写完整还原）：**

**① 一种矿物结晶（橄榄石）。** 相图上：液体 L1 降到液相线温度 T1 开始结晶橄榄石；继续冷却到 T2、T3，依次结晶出成分逐渐**更富铁**的橄榄石，液体成分依次为 L1 → L2 → L3。投到 SiO₂–MgO 图上：**结晶抽走了橄榄石的化学组分，所以液体成分沿着「橄榄石成分点 → L1」的延长线、直接远离橄榄石移动**（L1 → L2 → L3 三点共线且背离橄榄石）。

**② 换成斜长石结晶。** 同理，液体成分**直接远离斜长石成分点**移动。
**关键对比：** 抽走橄榄石时 MgO 下降；换成抽走斜长石（几乎不含 Mg）时，**残余液体中的 MgO 反而会重新上升**。因此 LLD 上出现一个**明显的折点**。
> **判据（考点）：LLD 上出现坡度变化 ⇒ 正在结晶的矿物或矿物组合发生了改变。**

**③ 两种矿物同时结晶（橄榄石 + 斜长石）。** 自然界通常不是「关掉一个、打开另一个」，而是「**再加入一个**」。做法：
1. 用一组实测岩石成分**拟合一条趋势线**；
2. 把趋势线**向后（向高 MgO 方向）反向延长（back-projection）**；
3. 在图上画出橄榄石—斜长石之间的**连接线（tie line）**；
4. **反向延长线与 tie line 的交点**告诉我们两件事：**(a)** 这条轨迹**确实可以**由结晶这两种矿物产生；**(b)** 用**杠杆定律（lever rule）**可以算出两种矿物的结晶比例。讲义示例结果：**40% 橄榄石 + 60% 斜长石**。

> 📎 **背景补充：** 讲义引用杠杆定律但没写公式（因为默认已在 EART26201 学过）。在成分连线 ol–plag 上，若交点为 X，则
> **ol 的比例 = |X−plag| / |ol−plag|**，**plag 的比例 = |X−ol| / |ol−plag|**
> ——即某端元的比例等于**对面那一段**长度占全长的比值（「离得越近，占得越多」）。长度可沿任一坐标轴度量（用 MgO 或 FeO 都行，结果应一致）。

**④ 三种矿物（橄榄石 + 斜长石 + 单斜辉石）。** 画出三条 tie line 得到一个**三角形**，并把三角形内部涂色。把 LLD 反向延长后：

- 若它**穿过 ol–plag tie line** → 可以由 ol + plag 产生，比例可用杠杆定律算。
- 若它**也穿过 plag–cpx tie line** → 也可以由 plag + cpx 产生，比例同样可算。
- 若它**穿过三角形内部区域** → 也可以由三种矿物共同产生，**但这张图无法确定三者的比例**（三个未知数、一个约束）。
- 若它**不穿过 ol–cpx tie line** → **绝不可能**由 ol + cpx 的组合产生。
- 它也**不可能**由任何**单一**矿物产生（单矿物结晶要求 LLD 直指该矿物点）。

**结论（讲义原文）：** 这个图解法给出**三个可能的答案 + 一族错误答案**。要在三者中定夺，需要 **(a)** 再画一张 y 轴换成 CaO 的图，或 **(b)** **看薄片**——如果岩石里有大量橄榄石和斜长石但没有单斜辉石，那结晶组合大概就是 ol + plag。

### 4.2 实操技巧（薄片观察经验）

配套的判读逻辑：色率不仅能在手标本上做，**在薄片上也能做**——看**低突起无色矿物**与**较高突起的镁铁质矿物**各占多少比例；举起来对光时深色矿物会自己跳出来。这条技巧在 Practical 2 的 93-2/R342A 玄武岩题里被直接考到（"hold the thin section up to the light and notice that it contains light and dark regions"）。

野外场景的现实感：老师说「你在野外、大雨倾盆、求生欲迅速消失的时候」，那些**最简单的观察**——粒度、颜色——才是能真正记录下来的东西。所以**再显然也要记录**。

### 4.3 一个课堂互动问答（重要的概念澄清）

老师展示斑状结构（自形斑晶 + 细粒基质）后问：**「这是侵入岩还是喷出岩，为什么？」**

学生答：基质是细粒的。老师确认并延伸：

> 「我们**按较细的粒度、也就是基质的粒度**来给岩石分类。所以尽管我们有些矿物是在可以称为**深成环境**的地方长大的，这块岩石本身是**细粒的、喷出的**。因此要给它命名时，我们去 Practical Reference Handout 里找**喷出岩**的名字：**basalt 而不是 gabbro，rhyolite 而不是 granite**。」

**推论（老师明说）：你给一块火成岩的名字，必然携带了它粒度的信息。**

**深层含义：** 一块岩石里的不同矿物可以在**完全不同的环境和时间尺度**上生成。斑晶在岩浆房里慢慢自由生长（自由漂浮、不碰到别的晶体 → 理想晶形），然后**被携带着一起喷出**，基质在地表快速冷却时才结晶。

### 4.4 Diamond Light Source 同步辐射实验（讲义只有图，全部解说来自课堂）

老师展示了她课题组在**牛津附近的 Diamond Light Source 同步辐射光源**做的实验：

- **做法**：取一个**极小的玄武质粉末胶囊**，加热到熔融，然后冷却，用 **X 射线原位实时观察结晶过程**。
- **视野尺度**：约 **2 mm**。
- **观察结果**：**单斜辉石晶体从胶囊侧壁向内、从顶部向下生长**——因为侧壁与顶部是与空气接触、冷却最快的位置。整个实验只跑了**几个小时**，说明这种晶体生长**相当快**。
- **后续分析**：把实验产物切片，在**扫描电镜（SEM）**下观察，图像比例尺 **50 μm**。
- **关键发现（这是 2.7 节边界层机理的直接证据）**：单斜辉石晶体大量吸收了 Mg；旁边的**斜长石不要 Mg**，于是 **Mg 在正在生长的斜长石周围堆积成一层化学边界层**，因为 Mg 来不及从晶体边界扩散走。
- **老师的推理**：这层边界层**本应阻止斜长石继续生长**（周围被 Mg 堵死，缺少斜长石想要的 Ca、Na、Al）。晶体的对策就是**从角上长树枝状尖刺穿透边界层**。
- **一句话总结（值得背）**：「**结晶的动力学过程可以影响晶体生长所处的、非常局部的化学环境。**」

### 4.5 枕状玄武岩内部结构的完整解说（讲义只有两张图）

这是讲义完全没有、但极适合作为论述题素材的一段：

1. 枕状玄武岩外侧有一层**玻璃质外壳（glassy rind）**——与海水接触、极快冷却的岩浆。
2. 但它**不是瞬间淬死**的，还**保留一点柔性**，所以可以「想象这些枕头**像气球一样充胀**，直到玻璃壳变得太僵硬，于是**必须形成一个新的气球**」——这就是枕状构造的成因。
3. **玻璃壳对内部起热绝缘作用**，于是枕体内部存在**冷却速率的梯度**：边缘极快，内部较慢。
4. **可预测的结果**：**边缘是玻璃，向核部晶体粒度逐渐变粗**。这一梯度**可以在薄片中观察到**。
5. 薄片中的具体现象：视野里**较大的晶体是在深部岩浆房里预先长成的**；喷出到海底后的结晶产生了**羽状（feathery）的极细小晶体席**；而且这些细小晶体**以预先存在的晶体为模板成核生长**；此外还有**完全没有晶体的纯净玻璃区**。

> 这段几乎是 Practical 2（93-2/R342A 玄武岩）的标准答案预演，务必与 Practical 内容对读。

### 4.6 结构 → 岩浆系统结构的升级解释链

老师把结构从「一个名词」升级成「岩浆管道系统的探针」：

- **斑状（双峰粒度）** = 一个岩浆房长出大晶体 → 被扰动 → 喷发 → 双峰粒度分布。
- **三峰粒度** = 加一个岩浆房：从 1 号房带来大晶体，进入 2 号房继续长大，同时**成核出一批新的中等大小晶体**，再喷发 → 大、中、细基质三档。
- **粒序（seriate）结构** = 一个**复杂的管道系统（plumbing system）**，岩浆**持续上升→停滞→上升→停滞**，一路**增量式结晶**，产生**近乎连续的晶体粒度分布**。
- **诊断意义**：「这开始告诉你，这是一个**很简单的岩浆系统**，还是**地下有相当多的复杂性**在发生。」
- 老师补充：seriate 在**二维薄片中很难识别**（Reference Guide 亦如此注明）。

### 4.7 关于结晶顺序的两点微妙澄清

1. **「假设所有矿物的生长速率相同」**：由「大的先长、小的后长」推结晶顺序，前提是 **"This is assuming that everything has the same growth rate."** ——老师明确点出这个隐含假设。
2. **互相包裹 = 同时结晶**：「你可能同时看到 A 被 B 包、也看到 B 被 A 包，那就说明**它们大概是同时生长的**。」
3. **允许「无法判断」也是答案**：老师在总结时说，可以用结构观察来推断结晶顺序，「**或者用结构观察来说明：我们无法判断结晶顺序**」——这在考试作答中是被接受的、甚至是被鼓励的诚实回答。
4. **观察本身是核心技能**："But seeing, observing, and noting, and sketching is the key thing here."

### 4.8 术语的语源吐槽（帮助记忆）

- **chadacryst**（被包裹的小晶体）= 「a crystal that's been contained」被容纳的晶体。
- **oikocryst**（包裹别人的大晶体）= 「a crystal that is kind of housing other things」当房东的晶体（希腊语 oikos = 房子）。
- 老师原话：「早期的岩石学家喜欢从拉丁语和希腊语里挑词。**这很烦人，但我们只能忍着**。」
- **phenocrystic** 与 **porphyritic** 可以**互换使用**，都指「有大斑晶嵌在某种基质中」。

### 4.9 化学分类的实验室现实

老师详细描述了化学分析的流程（讲义只列了「expensive / time-consuming」两条）：

> 取手标本 → **压碎成细颗粒** → **研磨成细粉** → 要么**直接分析粉末**（如 XRF），要么**用各种酸消解溶解成溶液**，再**过质谱仪**。

**代价**：贵、耗时、且**丢失岩石的结构信息**。**收益**：定量成分数据、**任何粒度的岩石都适用**——这正是矿物学分类对「极细粒或玻璃质岩石」束手无策时的补救手段。

### 4.10 一处老师的当场自我更正（重要！）

在解释过冷度时老师先说：「当 ΔT 等于零时，我们处在这块岩石的 **solidus（固相线）**，也就是熔点。」紧接着又说：「如果我们把它冷却到 **solidus，抱歉，是 liquidus（液相线）**以下 100 度……」

**以后者为准：ΔT = 0 对应的是液相线（liquidus），即液体开始结晶的温度。** 讲义的 N–G 曲线图与 Practical 答案（"the magma was only a few degrees cooler than its liquidus temperature"）都以 liquidus 为基准。

**Q3｜在 x 轴上画箭头表示分离结晶的方向，并评述趋势。**
**答案：SiO₂ 随分离结晶进行而增加 → 箭头从左指向右。** FeO 含量**线性上升**直到 SiO₂ 略超过 50 wt.%，然后**急剧转折：FeO 随 SiO₂ 增加而下降**。两段趋势**都不完全是直线**。

**Q4｜趋势的突变意味着什么？其他氧化物如何变化？**
**答案（核心判据，与讲义 3.9 完全对应）：**
> **趋势的改变必然指示结晶矿物组合发生了变化。** 换句话说，每一段趋势对应结晶一种（或一组）不同的矿物；**或者，同样的矿物在结晶，但比例不同**。

其他氧化物：
- **Na₂O、K₂O 上升** → Na、K **没有**被结晶矿物吸收（不相容）。
- **CaO 下降** → Ca **被吸收进结晶矿物**（**最可能是 cpx 与斜长石**）。
- **TiO₂ 上升到 ~2 wt.% 后下降** → 说明**一种吸收 Ti 的矿物在 SiO₂ 达到 ~55 wt.% 时开始结晶**。
- **Al₂O₃ 在结晶过程中相对恒定。**

**三个顶点的坐标（MgO, FeO）：ol (46.3, 13.9)、cpx (17.7, 7.1)、plag (0.2, 0.6)。**

**Q8｜对 MgO ≈ 10 → 5 wt.% 区间的岩浆成分做线性最佳拟合，用它预测可能的结晶矿物组合。**
**答案：** 该趋势的**反向延长线（back-projection）与 plag–cpx tie line 及 plag–ol tie line 相交，并穿过三角形内部；但不与 cpx–ol tie line 相交。** 因此结晶组合可以是以下三者之一：
- **橄榄石 + 斜长石**
- **斜长石 + 单斜辉石**
- **橄榄石 + 斜长石 + 单斜辉石**

**信息不足以判定哪一个正确，但最可能的答案是三矿物组合。**

> 📎 **背景补充（我用 Table 1/2 的数字验算了这个结论）：** 取样品 2 (MgO 10.31, FeO 9.38) 与样品 6 (MgO 5.42, FeO 14.73) 定义趋势，斜率约 **−1.09**（FeO 随 MgO 减少而增加）。把该线向高 MgO 方向延长：在 MgO = 17.7 处 FeO ≈ 1.3，远低于 cpx 的 7.1 与 plag–ol 连线的 5.65，说明它已经**从三角形下方穿出**，故必然在 MgO 10–17.7 之间**先后穿过 plag–ol 与 plag–cpx 两条连线**，而**永远达不到 ol–cpx 连线**（后者在高 MgO 端 FeO 高达 13.9，而延长线在此处已是大负值）。✔ 与答案完全一致。

**Q9｜MgO ≈ 5 → 0 wt.% 的那段趋势能否由这三种矿物的任意组合解释？**

**Q12｜苦橄岩的 MgO 都 > 11 wt.%，而冰岛测到的最富 MgO 的玄武质熔体只有 ~11 wt.% MgO。分离结晶（移除晶体）总是使 MgO 下降，所以苦橄岩不可能由分离结晶产生。那是什么过程？**
**答案（本次实习最重要的概念反转）：**
> 如果不是**移除**晶体，那就必然是**加入**晶体。**晶体堆积与卷入（crystal accumulation and entrainment）**——正在喷发的岩浆在喷出前**从岩浆房底部捡起晶体**，或在上升途中**从老岩浆房里捡起晶体**。要解释苦橄岩的成分，**被加入的晶体必须是富 MgO 的矿物**。

**Q13｜预测苦橄岩中斑晶的丰度与种类。**
**答案：** 穿过四个苦橄岩点的趋势线**穿过 ol–cpx 与 plag–ol 两条 tie line，并穿过三角形中央**。所以岩浆「捡起」的晶体组合可以是：
- **橄榄石 + 斜长石**
- **橄榄石 + 单斜辉石**
- **橄榄石 + 斜长石 + 单斜辉石**

**共同点：所有可能的堆积组合都包含橄榄石**——这与「必须堆积富 Mg 矿物」的要求一致。
**结论：苦橄岩是含有高比例橄榄石斑晶的玄武质岩石，±一些 cpx 和／或斜长石。**

### 5.2 Part 2（15 分钟）：矿物结构观察（标本 93-2 或 R342A 玄武岩）

这是把 2.5–2.7 节的机理**直接映射到实物**的练习。

**① 手标本：** 应看到**两种不同的斑晶矿物嵌在玻璃质基质中**。
**答案：斑晶是橄榄石与斜长石；手标本的结构是玻璃质的（glassy）。**

**② 上镜前先对光看：** 薄片含**浅色与深色区域**，也能看到斑晶。（← 呼应 4.2 节老师的 top tip。）

**③ 浅色部分的基质鉴定（完整推理链）：**
> **看到什么** → 单偏光（PPL）下基质呈**浅棕色**；**正交偏光（XPL）下全消光、各向同性（isotropic）**。
> **判定为什么** → **玻璃（glass）**，因为玻璃是**非晶质固体（amorphous solid）**，因而具有**各向同性的光学性质**。
> **意味着什么** → **玄武岩玻璃只在冷却速率极快时才能形成。**

**④ 两种硅酸盐斑晶的形态与生长环境（完整推理链）：**
> **看到什么** → **橄榄石典型为自形（euhedral）**；**斜长石典型为板状板条（tabular laths）**。
> **判定** → 近乎完美的晶形说明矿物是在熔体中**自由、无阻碍地生长**的；斑晶**最可能生长在岩浆房中**。
> **N 与 G 的比值** → 斑晶形成时 **G > N**。这发生在**过冷度很小**的条件下，即岩浆只比其**液相线温度**低几度。**成核率低 → 形成的晶体少；但生长率中—高 → 任何成核的晶体都能长到很大。**

**⑤ 骸晶（skeletal）橄榄石：** 浅色部分的一些矿物具**骸晶形态**，成因是**晶棱的生长速率快于晶面（crystal edges grow faster than the faces）**。要求画出一个骸晶橄榄石的素描。（← 对应 2.7 节的边界层—树枝状尖刺机理。）

**⑥ 羽状边（feathery rims）（完整推理链）：**
> **看到什么** → 向薄片中心移动，斑晶周围出现**棕色的边（brown rims）**，由**放射状羽毛状晶体**组成，它们是在玄武质熔体**快速冷却期间在斑晶上成核**的。
> **判定** → **G << N**，对应**极高的过冷度**——岩浆温度**骤降到液相线以下几十度**。**成核率极高 → 大量晶体形成；生长率极低 → 晶体保持很小。**

**⑦ 推测形成环境（本题是完整的证据—推论链，强烈建议背下结构）：**
> 1. 薄片和手标本中**玻璃的厚度**只能由**快速冷却**产生。
> 2. **没有气孔（vesicles）** → 说明**气体没有从岩浆中逸出**。
> 3. 因此它**必然是在围压（confining pressure）下喷发的——最可能在水下**。（**不可能在空气中，否则会有气孔。**）
> 4. **最可能的构造环境是洋中脊（mid-ocean ridge）**。**冰下喷发（subglacial eruption）也会产生类似结构。**

> 📎 **背景补充（光性判据速查，据 Reference Guide p.16）：** 本题要在同一张片子里同时认出橄榄石与普通辉石时，最有用的三条判据是——**① 解理与裂理**：橄榄石有**不规则的弯曲裂纹**、解理罕见；普通辉石在**延长切面上一组解理、在基底切面上两组近垂直（≈87°/93°）解理**。**② 双折射率**：橄榄石 **0.035–0.052（可达三级干涉色）**；普通辉石 **0.018–0.033（至多二级）**。**③ 消光角**：橄榄石自形晶相对晶面**平行消光**；普通辉石相对解理**斜消光**。此外橄榄石**极易蚀变**为蛇纹石（无色）或伊丁石（红棕色），普通辉石则更抗蚀变；PPL 下橄榄石**无色**，普通辉石**可能呈淡粉—棕色或灰色**。

### 5.4 常见错误与评分要点（综合三部分）

1. **箭头方向搞反**（Q3 vs Q5/6）：SiO₂ 图上结晶从**左→右**，MgO 图上结晶从**右→左**。答案文本专门加括号强调这一差异，说明这是**已知的高频失分点**。
2. **忘记 back-projection 是「反向」**：分离结晶诊断必须把趋势线**朝晶体成分方向（高 MgO 端）反向延长**，而不是顺着液体演化方向延长。
3. **只给一个答案**：Q8 的正确作答是**三个可能组合 + 一句「信息不足以判定，但最可能是三矿物组合」**。只写一个组合会失分；只写「不能确定」而不列出三个可能也会失分。
4. **忘记「不可能」的答案**：Q8 还应说明**不与 ol–cpx tie line 相交**（→ 排除 ol+cpx），以及**任何单一矿物都不可能**。
5. **Q10 只说「富铁矿物」不够**：必须**结合 TiO₂ 的同步转折**，才能从 magnetite 与 ilmenite 中**倾向 ilmenite**。这是把两条独立证据交叉印证的示范。
6. **Q12 的方向性反转**：分离结晶**只能让 MgO 下降**，所以高 MgO 的苦橄岩**必须**用「加入晶体」解释，不能用「更原始的熔体」搪塞（因为冰岛实测最富 Mg 的熔体只有 ~11 wt.% MgO）。
7. **薄片题必须写完整证据链**：「看到 X（观察）→ 因此 Y（判定）→ 说明 Z（解释）」。Part 2 的每一小题都是这个三段式，评分也按此给分。
8. **不要用 "×10" 标注比例尺**（Reference Guide 明文禁止），必须给出**实际长度的比例尺**。
9. **素描要与文字描述一一对应**：描述中提到的每一种矿物、每一个结构特征，都必须在素描中出现并被标注。
10. **粒度决定根名**：R93 是中粒 → dolerite/gabbro；93-2 是玻璃质基质 → basalt。**这条规则在两个 Part 里各考了一次。**

## 六、易错点 / 重点难点

**1. 「From solid to liquid」的方向问题。**
讲义小节标题写的是 "From solid to liquid"，老师在课上也照着念了。但本节讨论的是**结晶（crystallization）**，方向应是**从液到固（liquid → solid）**。不要被标题误导（已记入勘误表）。

**2. G 的两种含义。**
**G = Gibbs free energy（吉布斯自由能）** vs **G = crystal growth rate（晶体生长率）**。讲义与老师都特别警告。判断方法：出现在 ΔG_T = ΔG_s + ΔG_V 语境 → 自由能；出现在 G/N 比值或 N–G 曲线语境 → 生长率。

**3. ΔT = 0 的基准是液相线，不是固相线。**
老师口误后当场更正。**过冷度 = 液相线温度 − 实际温度。**

**4. 粒度 ∝ G/N，不是 ∝ G 也不是 ∝ 1/N。**
- 慢冷：G >> N → 少而大 → **粗粒**
- 快冷：N >> G → 多而小 → **细粒**
- 瞬时淬火：N, G → 0 → **玻璃**
注意「玻璃」不是「无限细粒」，而是**成核被彻底抑制**。

**5. 为什么玄武玻璃比流纹玻璃「难做」——逻辑不要反。**
高硅 → 高聚合 → 高黏 → **难扩散** → **难成核** → **容易成玻璃**。所以是**流纹质容易成玻璃**（obsidian 常见），**玄武质需要极端淬火**（水下、冰下）才能成玻璃。学生常凭「玄武岩喷得快」的印象反着记。

**6. 鲍文反应系列 ≠ 结晶顺序。**
讲义与 Reference Guide 双重警告。多数火成体系中**多种矿物同时结晶**，**必须看薄片的结构证据**（包裹关系、晶形、大小）才能定结晶顺序。

**7. 岩石名的根名由「基质／较细的粒度」决定。**
含大自形斑晶但基质细粒 → 仍然是**喷出岩名（basalt / rhyolite）**，不是 gabbro / granite。斑晶在深部长成不改变这一点。

**8. essential / type / accessory / secondary 四类矿物的区分。**
- essential：**被根名隐含**，不写进名字。
- type：**不被根名隐含**，**写进名字**，且**含量最少的排最前**。
- accessory：<5%，**不写进名字**（磷灰石、不透明氧化物）。
- secondary：**岩浆完全结晶后**才形成，**不写进名字**（蛇纹石、绿泥石、绢云母、沸石）。
易错：把磷灰石写进岩石名；把蛇纹石当作原生矿物统计到模式矿物学里。

**9. QAP 归一化。**
投 QAP 三角前**必须把 Q、A、P 三者归一化到 100%**，把黑云母等镁铁质矿物排除在外。Worked example 3 中 15/35/30 → 19/44/37 就是这一步。**忘记归一化会投错分区。**

**10. LLD 上「坡度改变」的唯一解释。**
**= 结晶矿物组合改变**（换矿物，或同样的矿物但比例改变）。不要解释成「冷却速率改变」「岩浆混合」等——在本课的图解框架里，标准答案就是矿物组合改变。

**11. 分离结晶用「反向延长」，晶体堆积用「正向」。**
- **移除晶体**（分离结晶）→ 液体**远离**矿物成分点 → 要找矿物就得**反向延长**。
- **加入晶体**（堆积／卷入）→ 岩石成分**朝向**矿物成分点移动 → 苦橄岩落在**高 MgO 一侧**。
这两者在同一张 FeO–MgO 图上方向相反，是 Practical 4 的核心考点。

**12. 三角图解法的能力边界。**
它能给出**三个可能组合 + 一族不可能组合**，但**当三种矿物同时结晶时无法定出比例**。要定夺必须**补另一张图（如 y 轴换 CaO）或看薄片**。写答案时必须把这条局限性说出来。

**13. 变异图 x 轴的选择。**
- 岩套跨度大（玄武岩→流纹岩）→ 用 **SiO₂**。
- 岩套只有玄武质（SiO₂ 变化小）→ 用 **MgO**。
选错 x 轴会导致所有点挤成一团，看不出趋势。

**14. 铁与水的分析实务。**
表格里 FeO 与 Fe₂O₃ 只有一栏有数、H₂O 常缺，**是正常的**，不是数据缺失错误。总量（Total）常按**干基**计算。

**15. 「没有观察到」也是证据。**
看不到互相包裹 → 可解释为**同时结晶**；既见 A 包 B 又见 B 包 A → 也是**同时结晶**。承认「无法判断结晶顺序」是被接受的答案。

**16. 「没有气孔」这条负面证据的分量。**
Part 2 中「无气孔 ⇒ 气体未逸出 ⇒ 在围压下喷发 ⇒ 水下（或冰下）」是一条完整的推理链，**比「看到玻璃」本身信息量更大**——玻璃只告诉你冷得快，气孔的有无才区分水下与陆上。
