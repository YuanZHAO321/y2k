## 二、核心概念

### 2.1 原生熔体、原始熔体与分异熔体（Primary / Primitive / Fractionated melt）

- **原生熔体 primary melt**：直接来自地幔部分熔融、**未经历（或极少经历）分离结晶**的熔体。MgO 很高。
- **原始熔体 primitive melt**：MgO 高，但**不保证**是原生的——它可能已经历了一定程度的分离结晶。
- **分异熔体 fractionated melt**：经历了明显分离结晶，Mg/Fe 比低。

三者的判据是**化学平衡**：原生熔体的 Mg/Fe 应当与**地幔橄榄石处于化学平衡**（可预测的高 Mg/Fe）；分异熔体则不再平衡（Mg/Fe 偏低）。

**液体演化线（Liquid Line of Descent, LLD）**：把一组由分离结晶彼此关联的岩浆成分画在氧化物–氧化物图上（讲义用的是 FeO wt.% vs MgO wt.%），连成的轨迹。**LLD 上的斜率折点 = 结晶矿物组合发生了改变**（例如从只结晶 ol 变成 ol + cpx）。这是从地球化学数据反推结晶顺序的核心工具。

### 2.2 拉斑玄武岩 vs 碱性玄武岩（Tholeiitic vs Alkali basalt）

原生熔体的"口味"由**熔融条件**决定：

| 熔融体系 | 压力 | 温度 | 熔融程度 | 产物 |
|---|---|---|---|---|
| 石榴石橄榄岩 garnet peridotite | 2 GPa | 1450 °C | 1% | 碱性玄武岩 |
| 石榴石橄榄岩 | 2 GPa | 1500 °C | 16% | 拉斑玄武岩 |
| 尖晶石橄榄岩 spinel peridotite | 1 GPa | 1350 °C | 15% | 碱性玄武岩 |
| 尖晶石橄榄岩 | 1 GPa | 1450 °C | 20–30% | 拉斑玄武岩 |

**规律：碱性玄武岩 = 更深、更低熔融程度（讲义写"通常 <10%"）；拉斑玄武岩 = 更浅、更高熔融程度（通常 15–30%）。**

> 📎 背景补充：物理原因是**不相容元素（Na、K）在低熔融程度下被高度富集**。熔融程度 F 越小，1/F 越大，Na₂O + K₂O 在熔体中的浓度越高，于是在 TAS 图上落到碱性区。深度增大还会压制 SiO₂ 活度，进一步把成分推向硅不饱和一侧。

**第三类：钙碱性玄武岩（calc-alkaline basalt）**——在 TAS 图上**无法**与拉斑玄武岩区分开，需要别的判据（如 AFM 图、FeO*/MgO 演化趋势）；常见于俯冲带，Week 8 再讲。

### 2.3 必要矿物 vs 型矿物（Essential vs Type minerals）

这是本课分类体系的骨架概念（Reference Guide p.6–7 有完整说明）：

- **必要矿物 essential minerals**：由岩石根名（root name）**隐含**的矿物，**一定存在**。玄武岩的必要矿物 = **单斜辉石（普通辉石 augite）+ 高钙斜长石（Ca-rich plagioclase）**。
- **型矿物 type minerals**：并非根名隐含，**有些岩石有、有些没有**；写进岩石名里（多个时按含量从少到多列在前面）。玄武岩的型矿物：橄榄石、氧化物（磁铁矿）、（碱性玄武岩中）霞石、（石英拉斑玄武岩中）石英。
- **副矿物 accessory**（通常 <5%，不进名字，如磷灰石、不透明氧化物）与**次生矿物 secondary**（岩浆完全结晶后形成，如蛇纹石、绿泥石、沸石）都不进岩石名。

**关键推理链（考试常考）**：必要矿物"一定存在"指的是**至少存在于基质（groundmass）中**，不一定作为斑晶。所以即便玄武岩基质细到看不清是什么矿物，你**依然可以断言**它由 cpx + plag 组成——这是"由分类定义反推观察"的合法推理。

### 2.4 薄片中能否区分拉斑与碱性玄武岩？

讲义给了一张完整对照表，结论是：**通常非常困难，可靠区分需要地球化学数据。** 各矿物的差别：

| 矿物 | 拉斑玄武岩 | 碱性玄武岩 |
|---|---|---|
| 斜长石 | 必要，基质中恒有；可为斑晶 | 同左 |
| 单斜辉石（普通辉石） | 必要，基质中恒有；作斑晶**罕见**；PPL 下通常**淡色或无色** | 必要，基质中恒有；可作斑晶（不总是）；PPL 下**可强烈着色（粉褐色）** |
| 橄榄石 | 橄榄拉斑玄武岩中可作斑晶和/或基质（不总有） | 可作斑晶和/或基质（不总有） |
| 氧化物（如磁铁矿） | 可在基质中；作斑晶罕见 | 可在基质中；**有时**作斑晶 |
| 霞石 | **绝不出现** | 可作斑晶或基质（不总有） |
| 石英 | 石英拉斑玄武岩基质中可有；**石英绝不与橄榄石共生** | **绝不出现** |

> 📎 背景补充：碱性玄武岩中辉石的粉褐色来自 **Ti³⁺/Ti⁴⁺ 替代**（钛普通辉石 titanaugite）。碱性岩浆硅不饱和，Ti 更容易进入辉石的 M1 位置并伴随 Al 进入四面体位（Tschermak 替代），产生颜色和多色性。这条是"晶体化学 → 光性"的典型例子，正是 ILO 3 要考的。
>
> 📎 背景补充："石英绝不与橄榄石共生"的化学根据是反应 `Mg₂SiO₄ (Fo) + SiO₂ (Qz) → 2 MgSiO₃ (En)`。只要体系里同时有 SiO₂ 和橄榄石，它们就会反应生成斜方辉石，所以两者不能平衡共存。这也是"硅饱和度"概念的基础。

### 2.5 霞石（Nepheline）——本周唯一的新矿物

- **化学式**：Na₃(Na,K)(Al₄Si₄O₁₆)，即端元 NaAlSiO₄–KAlSiO₄ 固溶体，理想式常写 Na₃K(Al₄Si₄O₁₆)。
- **类别**：**似长石（feldspathoid）**，**架状硅酸盐（framework/tectosilicate）**，**六方晶系（hexagonal）**。最常见的似长石矿物。
- **晶体化学**：[SiO₄]⁴⁻ 四面体与 [AlO₄]⁵⁻ 四面体（均为 **[4] 配位**）交替连接构成三维骨架；骨架空腔中填入 **K⁺（[9] 配位，占大空腔）** 与 **Na⁺（[8] 配位，占小空腔）**。
- **产出**：广泛见于**硅不饱和（silica-undersaturated）**的镁铁质、中性、演化火成岩中。

**光性（讲义列出）**：

| PPL | XP |
|---|---|
| 无色 | 一级低干涉色 |
| 低—中等突起 | 平行（直）消光 |
| 六方解理（弱） | 双晶不常见 |
| 六方板状或柱状习性；可见六边形切面；可有云雾状蚀变 | — |

**与长石的区分要点**：**六方柱状习性 + 缺乏双晶**（斜长石有聚片双晶、碱性长石常有卡氏双晶或条纹结构）。

> 📎 背景补充：霞石结构可以理解为**"填充型鳞石英（stuffed derivative of tridymite）"**——把鳞石英的 SiO₂ 骨架中一半 Si⁴⁺ 换成 Al³⁺，为平衡电荷，把 Na⁺/K⁺ 塞进骨架的六方孔道。这正好解释了为什么它是六方的、为什么 K 的配位数（9）比 Na（8）大：鳞石英骨架中有大小两种孔道。
>
> 📎 背景补充：霞石一级低干涉色对应双折射率约 0.003–0.005，光性符号**一轴负（uniaxial negative）**；折射率约 1.53–1.55，略高于树胶（1.54），故突起很低。讲义只给了定性描述，未给数值。**注意：讲义明确说"本单元不研究含霞石的岩石"，霞石的相关视频是 Blackboard Week 6 文件夹里的额外资源。**

### 2.6 绝热减压熔融（Adiabatic decompression melting）

**绝热过程（adiabatic process）的定义**：系统与环境之间**不发生热量交换**的过程。

**为什么地幔平时不熔？** 常态下地球的**地温曲线（geotherm）温度低于橄榄岩固相线（peridotite solidus）**，因此地幔应当是固态的，不发生熔融。要产生火山活动，必须有一种机制把岩石送到固相线之上。

**三种机制（Best 2006 Fig. 11.1 的三个扰动箭头）**：把一个位于固相线正下方的潜在源岩（图上的黑三角）移到固相线之上，有三条路：

1. **–ΔP（减压）**：压力降低，跨过**干固相线**——洋中脊。
2. **+ΔT（升温）**：温度升高，跨过干固相线——地幔柱（Week 7）。
3. **+ΔH₂O（加水）**：**固相线本身向低温方向下移**（变成"湿固相线"，注意不是水饱和固相线），把岩石纳入"液体 + 晶体"稳定域——俯冲带（Week 8）。

**洋中脊的具体过程（这是考试要求能画的 P–T 图）**：

1. 常态：岩石圈（lithosphere，刚性传导层）+ 软流圈（asthenosphere，对流层），固态橄榄岩静止不动。
2. 洋中脊处发生**拉张**，**岩石圈减薄（lithospheric thinning）**。
3. 软流圈物质得以**绝热上升（ascend adiabatically）**——没有加热，只有减压。
4. **岩石圈底部的温度基本不变**，但对流地温曲线随对流地幔区域扩大**向上延伸**，于是**地温曲线在浅部变陡**。
5. 继续减薄，岩石圈几乎减到零，**地温曲线与固相线相交**，浅部发生部分熔融。

**必须记牢的一句话**：**我们改变的是地温曲线，不是固相线。**（转写原话："Thin the lithosphere, change the geotherm. We do **not** change the solidus."）这与俯冲带（改变固相线）形成对照。

### 2.7 地幔位温（Mantle potential temperature, T_p）

**定义**：地幔若沿绝热线上升且**不发生熔融**，到达地表时所具有的温度。即把**对流地温曲线（convective geotherm）向上外推到地表**所读出的温度。这是一个"虚拟温度"，是比较不同地幔区域热状态的标准量。

- **常态地幔 T_p ≈ 1280 °C。**
- **MORB 的典型喷发温度 ≈ 1100 °C。**

**为什么喷发温度总是低于 T_p？** 因为**熔融潜热（latent heat of melting）**要消耗热量。地幔一旦越过固相线开始熔融，体系就不再沿"固体绝热线（solid adiabat）"上升，而是沿一条更陡（温度下降更快）的路径上升。因此**喷发温度恒低于地幔位温**，两者差值可观（本例约 180 °C）。

### 2.8 洋壳层序（Stratigraphy of the oceanic crust）

**证据来源（三条，考试要能列出）**：
1. **地球物理**：地震波速与岩石类型、矿物组成相关。
2. **钻孔岩心（drill cores）**：洋壳的直接样品。
3. **蛇绿岩（ophiolites）**：碰撞过程中**仰冲（obducted）**到大陆岩石圈之上的洋岩石圈切片，可以直接走上去逐层观察（Week 5 已讲）。

**自上而下的理想层序**：

| 层 | 岩性 | 成因 / 粒度控制 |
|---|---|---|
| 沉积物 | — | 覆盖层 |
| **喷出层** | 枕状玄武岩 pillow basalt | 海水**淬火**，极快冷却，部分成玻璃，其余极细粒 |
| **席状岩墙群** | 辉绿岩 dolerite / 玄武岩 | 供岩通道网络，中等冷却速率 → **中等粒度** |
| **块状辉长岩** massive gabbro | 辉长岩 | 岩浆房固结残余，4–6 km 深，缓慢冷却 → 粗粒 |
| **堆晶辉长岩** cumulate gabbro | 堆晶 plag + cpx + ol | 密度沉降堆积 |
| ——— **地震莫霍 seismic Moho** ——— | | |
| **堆晶超镁铁岩** cumulate ultramafics | 主要为橄榄石 | 早期结晶的致密橄榄石沉底 |
| ——— **岩石学莫霍 petrologic Moho** ——— | | |
| 橄榄岩（方辉橄榄岩 harzburgite） | 地幔岩 | 部分熔融的**残余（restite）** |

**两个莫霍的区别（老师特别强调）**：

- **地震莫霍**：地震波速的显著跃变面，本质上分开的是**含斜长石的岩石**与**不含斜长石的岩石**。
- **岩石学莫霍**：分开**地幔岩石**与**地壳岩石**；换个说法——分开**"被熔融过的岩石"**与**"由熔体结晶形成的岩石"**。

**堆晶超镁铁岩是"麻烦制造者"**：它不含斜长石，所以地震上看像地幔；但它是由熔体结晶来的，所以岩石学上属于地壳。地球物理学家和岩石学家会把界线画在不同位置——这就是为什么需要两个定义。

### 2.9 扩张速率对洋壳结构的控制

| 类别 | 全扩张速率（mm/yr） |
|---|---|
| 快 Fast | >100 |
| 中 Medium | 55–100 |
| 慢 Slow | <55 |
| 超慢 Ultra-slow | <20 |

- **快速扩张脊**（如东太平洋海隆 East Pacific Rise）：岩浆供应连续、通量大，形成**上述理想、连续的层序**——教科书里画的蛇绿岩层序最接近快速扩张脊。
- **慢速扩张脊**（如 Reykjanes Ridge）：上涌慢 → 绝热减压速率低 → **熔体产量按体积计更少**；相当一部分伸展由**正断层（normal faulting）**吸收。结果是地壳内部"一团混乱"，岩墙和枕状熔岩**沿脊不连续**，层序不完整。

### 2.10 MORB：为什么它不是原生岩浆

**镁指数（Mg#）**是核心判据（见第三节公式）。老师展示了东太平洋海隆 **3000 多个样品**的 Mg# 直方图：

- 灰色条带 = 与地幔橄榄石**化学平衡**的熔体应有的 Mg# 区间。
- 实测 MORB 的峰值**不落在**灰条带上，而是偏低。

**推论链**：MORB 与地幔橄榄石不平衡 → **MORB 不可能是原生熔体** → 它们在喷发前必然经历了一定程度的**分离结晶**。
**进一步推论**：Mg# 峰值**又高又窄、非常均一** → 所有这些岩浆经历的分离结晶量**大致相同** → 系统是一个**良好缓冲的开放系统（well-buffered open system）**：原生熔体注入 → 分离结晶 → 玄武岩喷出，如此反复。

**为什么必须是开放系统？** 如果是封闭系统，成分会沿**鲍文反应序列**持续演化，最终变成安山岩 → 流纹岩 → 全部固结。而 MORB 成分如此单调均一，说明必须不断有新熔体注入 + 不断喷发排出。

### 2.11 结晶顺序取决于成分与压力

**（a）固定压力（1 atm ≈ 0.001 GPa），成分不同 → 顺序不同**（讲义 & Practical Q8）：

- 成分 A：L → ol；L → ol + plag；L → ol + cpx + plag
- 成分 B：L → ol；L → ol + cpx；L → ol + cpx + plag

**（b）固定成分，压力不同 → 顺序不同**：

- **高压**：plag → plag + cpx → ol + cpx + plag
- **低压**：ol → ol + plag → ol + cpx + plag
- 中压：介于两者之间（讲义留作自测题，材料未给答案）

**关键结论（讲义总结页）**：**几乎所有 MORB 中，橄榄石都先于斜长石结晶——这指示 MORB 的结晶发生在低压。**

**同样重要的告诫**：仅凭薄片**无法**判断你观察到的结晶顺序差异是"起始成分不同"造成的还是"压力不同"造成的，必须有额外信息。

### 2.12 洋壳如何建造？两个端元模型

| 模型 | 内容 | 能解释什么 | 问题 |
|---|---|---|---|
| **大岩浆房 / "辉长岩冰川" gabbro glacier** | 脊轴之下有一个长期存在的大岩浆房，反复补给 + 结晶（well-buffered open system） | 完美解释 MORB 成分的近乎均一 | **地球物理探测很少发现**这种长期存在的大型地壳岩浆房；可能只在东太平洋海隆成立 |
| **叠置熔体透镜 / 席状岩床 sheeted sills** | 部分固结的地壳中存在**瞬时（transient）熔体透镜**，垂向叠置、由岩墙连接 | 解释蛇绿岩露头中下地壳与地幔段复杂的野外接触关系；暗示地幔岩浆供应是**脉冲式而非连续**的 | 对成分均一性的解释不如前者直接 |

**共识与分歧**：所有人都同意"蛇绿岩 + 钻孔岩心"是解决问题的关键材料；但哪个模型更接近真实世界，**至今没有定论**——这是一个活跃的科研前沿。慢速扩张脊（如 Reykjanes Ridge）几乎肯定不适用 gabbro glacier 模型。

## 三、公式与图表

### 3.1 镁指数 Mg#

$$
\mathrm{Mg\#} = \frac{\mathrm{Mg^{2+}}}{\mathrm{Mg^{2+}} + \mathrm{Fe^{2+}}} \times 100
$$

| 符号 | 含义 | 单位 / 注意 |
|---|---|---|
| Mg²⁺ | 熔体（或岩石）中镁的**摩尔量**（cation mole） | 无量纲；必须用摩尔数，不能直接用 wt.% |
| Fe²⁺ | **二价**铁的摩尔量 | 必须是 Fe²⁺，不是全铁 FeO*；Fe³⁺ 不参与 |
| Mg# | 镁指数 | 0–100 |

**适用条件与典型数值**：
- Mg# 本质是 Mg/Fe 比的归一化表达，用来度量岩浆的"原始程度"。**Mg# 越高越原始。**
- 地幔橄榄石约为 Fo₉₀（Mg# ≈ 90）；与之平衡的原生熔体 Mg# 明显低于橄榄石（因为 Mg 优先留在固相）。
- 分离结晶（结晶橄榄石、辉石这些富 Mg 相）会使残余熔体 **Mg# 下降**。
- 讲义原话："MORB 成分与地幔橄榄石不处于化学平衡，因此喷出的 MORB 不可能是原生熔体。"

> 📎 背景补充：材料没有给"平衡灰条带"的具体数值和算法。标准做法是用 **Fe–Mg 交换分配系数** $K_D^{\mathrm{ol-melt}} = \dfrac{(X_{\mathrm{Fe}}/X_{\mathrm{Mg}})^{\mathrm{ol}}}{(X_{\mathrm{Fe}}/X_{\mathrm{Mg}})^{\mathrm{melt}}} \approx 0.30$（Roeder & Emslie 1970）。若地幔橄榄石为 Fo₉₀，则平衡熔体的 Mg# ≈ 68–73。典型 MORB 的 Mg# 大约在 55–60，明显偏低——这正是"必须经历过分离结晶"的定量依据。**这段是补充，讲义只给了定性的"灰条带"。**

### 3.2 TAS 图（Total Alkali–Silica，全碱–硅图）

- **横轴**：SiO₂ 含量（wt.%）
- **纵轴**：Na₂O + K₂O 总和（wt.%）
- **一条关键分界线**把图分成**碱性（alkaline）**上区与**亚碱性 / 拉斑（sub-alkaline / tholeiitic）**下区。
- **怎么读结论**：在**同一 SiO₂ 含量**下，**碱含量高 → 碱性玄武岩；碱含量低 → 拉斑（亚碱性）玄武岩**。老师原话："碱性玄武岩碱含量高，顾名思义。"
- **细分**：拉斑玄武岩可细分为**橄榄拉斑玄武岩（olivine tholeiite）**与**石英拉斑玄武岩（quartz tholeiite）**（这一步靠 CIPW 标准矿物计算，不在 TAS 图上）；碱性玄武岩有时按 K₂O 含量细分。
- **重要局限**：**钙碱性玄武岩在 TAS 图上无法与拉斑玄武岩分开。**
- Reference Guide p.11 还给出 SiO₂ 的粗分：<45 wt.% 超镁铁质；45–52 镁铁质；53–62 中性；>63 长英质。
- **MORB 几乎总是落在拉斑（亚碱性）区。**

> 注意：Reference Guide 的 SiO₂ 分档在 52 与 53 之间留有 1 wt.% 的空隙（52–53 无归属），原文如此。

### 3.3 P–T 图：地温曲线与固相线（本周必须会画）

**坐标轴**：横轴温度 T（°C，向右增大），纵轴压力 P 或深度（**向下增大**，注意这是地质学惯例，坐标原点在左上角）。

**图上的线**：
1. **干橄榄岩固相线（dry peridotite solidus）**：一条向右下倾斜的曲线，代表开始熔融的温度随压力上升而升高。
2. **常态地幔地温曲线（ambient mantle geotherm）**：浅部（岩石圈）陡峭——这是**传导**段；深部（软流圈）近乎线性且梯度很小——这是**对流（绝热）**段。**常态下这条线整条位于固相线的低温一侧 → 不熔。**
3. **洋中脊地温曲线（mid-ocean ridge geotherm）**：岩石圈减薄后，传导段缩短、对流段向浅部延伸，**曲线在浅部变陡并向高温方向移动**，最终**与固相线相交**；相交以上的浅部区域即为部分熔融区。
4. **固体绝热线（solid adiabat）**：对流地温曲线向地表的直线外推；它与地表（P = 0）的交点读数即 **T_p**。
5. **实际熔体上升路径**：一旦越过固相线，路径偏离固体绝热线，向低温一侧弯（消耗熔融潜热），所以到地表时的温度（≈1100 °C）低于 T_p（≈1280 °C）。

**怎么读结论**：**地温曲线与固相线的交点深度 = 熔融开始的深度；交点以上、地温曲线与固相线之间夹的面积 ∝ 熔融量。**（后半句是常用推论，讲义未明说。📎 背景补充。）

### 3.4 Best (2006) Fig. 11.1：三种熔融扰动

- **图上元素**：横轴温度、纵轴压力；一条**干固相线**、一条被水下压的**湿固相线（"wet" solidus，不是水饱和）**；黑三角 = 位于固相线正下方的潜在源岩。
- **三个箭头**：
  - **–ΔP**（竖直向上）：减压 → 跨过干固相线。**红色箭头，本周主角。这个过程完全由减压驱动，不需要加入任何热量。**
  - **+ΔT**（水平向右）：升温 → 跨过干固相线。
  - **+ΔH₂O**：不移动源岩，而是**把固相线本身向低温方向拉**，使源岩落入"液体 + 晶体"稳定域。
- 讲义明确说这张图与前面的 P–T 图**信息相同，只是换一种可视化方式**。

### 3.5 Fo–Di–An 三角相图（本周与 Practical 的核心图，必须彻底掌握）

**这是 1 个大气压下的玄武岩液相面（basalt liquidus surface）图。**

**三个顶点（纯端元矿物组分）**：

| 顶点 | 缩写 | 化学式 | 代表的真实矿物 |
|---|---|---|---|
| 钙长石 Anorthite | An | CaAl₂Si₂O₈ | 斜长石 plagioclase |
| 透辉石 Diopside | Di | CaMgSi₂O₆ | 单斜辉石 clinopyroxene |
| 镁橄榄石 Forsterite | Fo | Mg₂SiO₄ | 橄榄石 olivine |

**图上有什么**：
- **三条边** = 三个二元系统，每条边上有一个**二元共结点（binary eutectic）**：Fo–Di 之间一个、Di–An 之间一个、An–Fo 之间一个。
- **三条共结线（cotectic boundary）**：从三个二元共结点出发、伸向图内的曲线，像**"陡壁深谷的谷底"**。它们把图分成三个**初晶区（primary phase field）**：Fo + L 区、Di + L 区、An + L 区。（还有一个 spinel 尖晶石小区，Practical 明确说可以忽略。）
- **三角共结点 E（ternary eutectic）**：三条共结线交汇处，**全图温度最低点**，本图为 **1270 °C**。
- **等温线（temperature contours）**：液相面被等温线勾出，像地形图的等高线。**箭头指向降温方向。**

**读图的五条规则（Practical 的 "Important take-away points"）**：
1. 该图是**液相面的地图**，**只能表示液体成分**（固体成分不在图上移动）。
2. 成分按三角顶点相的比例作图（模态百分比，三者和为 100%）。
3. 温度由等温线和降温箭头表示。
4. **结晶过程中，液体只能向降温方向移动。**
5. **最后一滴液体一定在三角共结点 E。**

**结晶路径的推导方法（三步）**：
1. **落在哪个初晶区** → 第一个结晶的矿物。反应写作 L → （该矿物）。
2. **液体成分沿"从该矿物顶点出发、经过原始成分点"的直线，朝**远离**该矿物顶点的方向移动**（因为结晶消耗了做该矿物所需的成分）。用直尺连"矿物顶点—液体点"再向外延长即可。
3. 撞上**共结线**后，第二个矿物加入，反应变为 L → A + B；液体**沿共结线向降温方向（即朝 E）移动**——不能往反方向，因为那要升温。到达 **E** 后第三个矿物加入，L → Fo + Di + An，成分**不再变化**，直到最后一滴液体耗尽。

**每条共结线上的反应**：例如分隔 An+L 区与 Fo+L 区的那条线，其上处处发生 L → An + Fo。同理另外两条。

**平衡结晶 vs 分离结晶的区别（图上怎么体现）**：
- **平衡结晶**：晶体始终与液体保持接触反应，**体系总成分不变**——最终固体成分 = 起始成分 x。
- **分离结晶**：每生成一个晶体就把它移出体系，液体沿上述路径演化，**最后一滴液体的成分 = 三角共结点成分**。
- **熔融方向**：把所有箭头反过来即可。老师强调"平衡结晶是平衡熔融的严格逆过程，但**分离结晶不是分离熔融的严格逆过程**"（Practical 原文）。

### 3.6 结晶顺序随压力变化的 P–T 相图

- **坐标**：横轴温度 T（约 1000–1300 °C 范围），纵轴压力 P（0 至约 1 GPa；讲义给出换算 **1 GPa ≈ 30 km**）。
- **图的两端**：**右侧 = 100% 液体（L）**；**左侧 = 100% 固体（S）**。中间是液体与不同晶体组合平衡共存的区域，由若干条界线分隔。
- **怎么读**：在某个固定压力上画一条水平线，**从右向左（降温方向）**走，每穿过一条界线就有一个新矿物加入结晶组合。
  - 高压水平线：先进入 plag + L，再 plag + cpx + L，再 ol + cpx + plag + L，最后全固结。→ **plag → plag + cpx → ol + cpx + plag**
  - 低压水平线：→ **ol → ol + plag → ol + cpx + plag**
- **结论**：**MORB 中橄榄石先于斜长石结晶 ⇒ 低压结晶。**

### 3.7 洋壳年龄图与层序柱状图

- **洋壳年龄图**：全球洋底按年龄着色。**最年轻的洋壳在洋中脊轴部**（脊轴对称条带），**最老的洋壳在被动大陆边缘**。老师点名：目前已知**最老的洋岩石圈在地中海**；另外美洲东岸、非洲西岸也有老洋壳。
- **层序柱状图**：见 2.8 表，左侧常并排画**地震波速剖面**，用波速跃变标出地震莫霍位置。

### 3.8 Mg# 直方图（东太平洋海隆 3000+ 样品）

- **横轴**：Mg#；**纵轴**：样品频数。
- **图上元素**：一条竖直的**灰色条带** = 与地幔橄榄石平衡的熔体应有的 Mg# 区间；一个**又高又窄的实测频数峰**。
- **怎么读结论**：峰**不与灰带重叠且偏低** → 非原生；峰**窄** → 分离结晶程度高度一致 → 缓冲良好的开放系统。

### 3.9 斜长石成分–消光角曲线（Reference Guide p.17 图）

- **横轴**：斜长石成分（mol.% An，0 = 钠长石 albite，100 = 钙长石 anorthite）。
- **纵轴**：**{010} 对称带内的最大消光角**（°）。
- **曲线形态**：从 An₀ 附近的负角出发，随 An 增大**先降到 0 再持续上升**，在高 An 端达到最大。
- **怎么读**：把测得的消光角在纵轴上找到，水平拉到曲线，再向下读 An 值。
- **关键陷阱**：**无法区分正负消光角**。例如 15° 既可能是 −15°（钠长石 albite）也可能是 +15°（奥长石 oligoclase）；要分辨必须用别的光学方法，如**贝克线法（Becke line test）测折射率**。
- **读数精度**：Practical 说允许 **±2 mol.% An** 的读图误差。

**材料给出的标定点（可当作校验）**：55° → An₈₆；41.5° → An₇₃；33.5° → An₆₁。

### 4.2 讲课时补充的概念澄清与观察经验

**（1）如何在极细粒基质中"看出"cpx + plag——本周最实用的薄片技巧**

老师完整讲了这条推理链：玄武岩是细粒岩石，基质太细时**即使换高倍物镜也没用**，因为"什么都只是稍微太小了一点"。但是：

> **在正交偏光（XP）下，玄武岩基质呈现一种"斑点状（speckly）"外观，而且这种斑点常常是白色与橙色相间的。白色是斜长石的低干涉色，橙色是单斜辉石的一级干涉色。**

所以即使无法逐颗鉴定，看到"白 + 橙斑点"就足以判断基质由 cpx + plag 组成，**因而这是一块玄武岩**。老师把这称为"**你知道必须有的必要矿物**"与"**你能看到的东西**"之间的桥梁——"你其实可以**预测**你会看到什么，哪怕你看不清基质里究竟是什么"。

**（2）玄武岩的典型斑晶相**

- 典型斑晶：**橄榄石 + 斜长石**。
- **单斜辉石作为斑晶相是可能的，但要罕见得多**（这与讲义表格一致）。
- 可能看到三者全有、只有橄榄石、或只有斜长石，均处于细粒基质中；PPL 下基质可能相当暗。

**（3）绝热减压的机制细节**

老师逐帧讲了 P–T 图的演化，有几点讲义没写清：
- 岩石圈是"**传导的刚性部分**"，软流圈是"**对流的部分**"——这是区分两条地温曲线段的物理依据。
- **岩石圈底部的温度基本保持不变**，变的是对流段向上延伸的范围，所以"地温曲线变得**在浅一点的地方更陡一点**"。
- 反复强调：**"我们不改变固相线，不改变熔融温度。"**
- 关于 T_p："这是一个**虚构的温度（fictional temperature）**"——强调它是外推量而非实测量。老师还说"下周还会再用到它，所以这周务必把这个术语弄熟"（Week 7 用 T_p 判别地幔柱的热异常）。
- "adiabatic decompression melting 这几个关键词你们应该**熟到把它纹在胳膊上**。"（老师原话，说明这是必考点。）

**（4）洋壳层序讲授中的补充**

- **最老的洋岩石圈目前在地中海**（讲义没有这条）。
- **岩墙群 = 供岩网络（feeder network）**，把岩浆从岩浆房送到地表喷口。
- **粒度由冷却速率控制，而枕状玄武岩、辉绿岩岩墙、辉长岩三者"化学上其实相当接近"**——"主要差别不是化学，而是最终岩石的粒度"。辉长岩在 **4–6 km** 深处缓慢冷却 → 粗粒；枕状玄武岩对着冷海水淬火 → 部分成玻璃，其余极细粒；**辉绿岩是中间粒度——"不像辉长岩那么粗，也不像玄武岩那么细；晶体小，但大到你能在薄片里看出它们是什么"**。
- **堆晶（cumulate）的成因过程**：岩浆房中结晶出致密的橄榄石 → **密度沉降（density settling）**到岩浆房底部 → 固结。堆晶辉长岩含堆晶斜长石 + 单斜辉石 + 橄榄石；堆晶超镁铁岩主要由橄榄石组成。
- **方辉橄榄岩是"部分熔融之后的剩饭（leftovers）"**；堆晶超镁铁岩则是"这些熔体结晶的最早产物"。一个是**残余**，一个是**产物**——这正是岩石学莫霍的定义依据。
- 老师对两个莫霍的总结："取决于你是地球物理学家还是岩石学家，你会把这条界线画在**略微不同的地方**。"

**（5）枕状熔岩的野外与薄片观察经验**

- 枕状熔岩像**气球一样膨胀（inflate）**，外表淬火成暗色壳，内部炽热岩浆对着海水极快冷却。
- 横截面上看是**伞状（umbrella-shaped）**的枕体一个叠一个。
- **放射状冷却节理（radial cooling joints）垂直于冷却面**——**"如果你想知道枕体的边缘在哪儿，就看这些节理"**。这是一条实用的野外定向判据。
- **玻璃**在 PPL 下呈**半透明褐色（translucent brown）**，是完全没能成核的区域。老师展示的图是从枕体边缘到内部的横切面：**边缘 = 淬火玻璃；靠内 = 细小基质晶体网络**，两者对比强烈。
- **气孔（vesicles）识别**：形状可为圆球状（好认）也可为拉长、不规则形；**PPL 下无色，可能显得有点"灰扑扑"（那是把薄片粘在载玻片上的胶）；XP 下全消光（isotropic）**——因为它们本质上是薄片里的**孔洞、空隙**。

**（6）三角相图的现场推演（老师用尺子演示）**

老师在课上现场推了两条路径：
- 第一条：起始成分靠图下部，**约 1650 °C** 时（原话，见勘误）与液相面相交，落在 **Fo + L 区**；L → Fo；液体沿"远离 Fo"方向演化，撞上 **Fo–Di 共结线**；不能继续原方向前进，"**因为那意味着升温、给系统加热**"；于是沿共结线向降温方向走：L → Fo + Di；到达 E：L → Fo + Di + An，直到最后一滴液体耗尽。
- 第二条（图上标 **X1**）：同样先 L → Fo，但这次撞上的是 **Fo–An 共结线**：L → Fo + An；最后同样在 E：L → Fo + An + Di。
- **方法完全一样，得到的结晶顺序不同**——这是"结晶顺序取决于起始成分"的图解证明。
- 老师安慰："这段讲得很快，实习课上你们还有机会再看一遍，别担心，来问我。"

**（7）一个明确的"做不到"**

> **"你能否仅凭薄片中观察到的结晶顺序判断，它是起始成分不同造成的，还是压力不同造成的？答案是不能——没有额外信息你判断不了。但你应该意识到这些复杂因素会相互作用，产生不同的结晶顺序。"**

这是一条重要的**认识论边界**，考试写"构造背景/结晶条件解释"时要注意不要过度断言。

**（8）关于大岩浆房模型的批判性讨论**

- 教科书上的经典图：脊轴处有枕状熔岩、席状岩墙群、**一个巨大的岩浆房**、下面是橄榄岩；远离脊轴，岩浆房变小变冷。
- 老师的论证："这个模型必须是**开放系统**，否则我们会预期成分沿**鲍文反应序列**演化，最终得到安山岩、然后流纹岩，然后整个东西固结。但因为 MORB 成分如此均一，这个系统必须是开放的：底部注入新熔体 → 发生喷发 → 再注入 → 再喷发……如此往复，**成分被维持得非常稳定**。"——"这是对 MORB 成分为何如此单调（monotonous）的一个相当优雅的解释。"
- **但是**："问题在于我们并没有找到多少证据支持脊轴之下存在这种岩浆房。人们做过地球物理调查，**很少发现为脊轴供岩的、永久性的大型地壳岩浆房**。**唯一可能成立的地方大概是东太平洋海隆**，其他地方都看不到。"
- 取而代之看到的是**瞬时熔体透镜（transient melt lenses）**，暗示**地幔的岩浆供应不是连续的，而是脉冲式（punctuated）事件**。蛇绿岩序列中那些**颜色较浅的、离散叠置的透镜状固结岩浆体**就是证据。"整个地壳并不是一大缸液体，而是这些**叠置的岩床（stacked sills）**，岩浆必须一级一级往上穿过这一串熔体透镜。"
- 术语：老师把大岩浆房模型称作 **"gabbro glacier model"（辉长岩冰川模型）**——**这个术语讲义上没有，只在转写里出现**。
- 适用性判断：gabbro glacier **可能**适用于东太平洋海隆这样的**极快速扩张脊**，但**绝对不适用**于像**冰岛以南的 Reykjanes Ridge** 这样的慢速扩张脊；后者需要**席状岩床模型**——小的、叠置的岩浆房 + 更瞬时的熔体供应。
- 结语与职业建议："这仍然是一个重大科学问题……如果你对火成岩岩石学感兴趣，这可能是你未来地质生涯可以切入的方向之一。"

**（9）慢速扩张脊的力学补充**

转写里给了讲义没有的因果链：**扩张速率慢 → 地幔上涌慢 → 绝热减压速率低 → 按体积计熔体产量少 → 相当部分的伸展由正断层吸收 → 层序不连续、地壳内部构造复杂**。老师直言："我们大部分时候会假定处理的是快速扩张的情形，**因为那对我们来说最容易思考**。"

### Part 1（15 分钟）：由薄片测定斜长石成分

**需要参考 Practical Reference Handout p.27**（本课 md 版 Reference Guide 中该内容在 p.17，见勘误表）。

**方法原理**：斜长石成分可由**两组双晶之间的消光角**测出。要测得准，**晶体必须处于非常特定的取向：{010} 双晶面必须恰好垂直于薄片平面**。取向正确的晶体有两条可检验的性质：

1. **当双晶面在十字丝上呈 N–S 取向时，两组双晶显示相同的浅灰干涉色**；
2. **把一组双晶转到消光所需的顺时针角度，与把另一组转到消光所需的逆时针角度，两者之差必须 <5°。**

老师坦言：在真实薄片里找到合适晶体"要看很久、要反复试错"，所以本题用**合成例子和数据**先把方法练熟。

**Q：下列斜长石晶体哪些取向合适？**

| 晶体 | 答案 | 判据 |
|---|---|---|
| Crystal 1 | **YES** | 双晶在 N–S 取向时呈**同一深浅的灰色**——是好候选。 |
| Crystal 2 | **NO** | 双晶在 N–S 取向时**灰色深浅不等**。 |
| Crystal 3 | **YES（理想）** | 双晶在 N–S 取向时灰色相同，且**顺时针与逆时针旋转大致相等的角度即可清晰消光**。 |
| Crystal 4 | **NO** | 中央虽有一条双晶面，但**双晶灰色深浅不等**；而且**晶体有环带（zoned）**，很难确定唯一的消光角。**这套光学方法在环带斜长石上效果很差。** |

**Q：下列消光角对哪些可用？**

| 序号 | 测值 | 判定 | 平均角 | 成分 |
|---|---|---|---|---|
| i | 53° 与 57° | **可用** | 55° | **An₈₆** |
| ii | 42° 与 41° | **可用** | 41.5° | **An₇₃** |
| iii | 55° 与 38° | **不可用** | — | 两值相差 **>5°** |
| iv | 32° 与 35° | **可用** | 33.5° | **An₆₁** |
| v | 21° 与 27° | **不可用** | — | 两值相差 **>5°**（差 6°） |

**读图精度**：允许 **±2 mol.% An** 的不确定度。

**推理链总结**：*双晶灰色对称 + 正反消光角之差 <5° → 取向合格 → 取两角平均 → 查 An–消光角曲线 → 得 An 值*。

> ⚠️ **注意 Reference Guide 与本题的衔接**：Reference Guide p.17 的操作步骤第 6 条说"**多测几颗晶体，用你测到的最高消光角来定成分**"（因为不同晶体取向不同，只有恰好落在对称带上的那颗给出真值，其余都偏小）。本题让你对**每一对**合格读数各算一个成分，是在练方法；若这些读数全部来自同一颗/同一薄片的斜长石，**最终答案应取最高值 An₈₆**。

### Part 2（45 分钟）：在三角相图上解读玄武岩结晶

**开场说明（原文要点）**：上周（W5）用三角相图描述**地幔熔融**，本周聚焦**结晶**，逻辑非常相似。**记住：平衡结晶是平衡熔融的严格逆过程，但分离结晶不是分离熔融的严格逆过程。**

**图的设定**：1 atm 下的玄武岩液相面；三组分为 An（斜长石）、Di（单斜辉石）、Fo（橄榄石）；等温线示液相面温度；**固相线未画出**；**尖晶石区可忽略**。

**Q1. 成分 x 的 Fo、Di、An 模态百分比？**
**答：22% Fo，53% Di，25% An。** 用**杠杆法则**读出。**允许 ±5% 的舍入误差。**

**Q2. 成分 x 从 1500 °C 冷却，何时到达液相线？**
**答：x 落在 1400 与 1500 °C 等温线之间，约 1430 °C。** 关键理解：任何温度高于 1430 °C 的 x 成分熔体是**完全液态**；从 1500 冷到 1430 °C 的过程中**成分不变，因为什么都还没结晶**；**结晶只在到达液相线温度后才开始**。

**Q3. x 到达液相线后 Fo 开始结晶（L → Fo）。随 Fo 结晶，熔体中 Mg、Ca、Al 浓度如何变化？**
**答：Fo 是富镁橄榄石 Mg₂SiO₄。Fo 结晶把 Mg 从熔体中移走 → Mg 浓度下降；Ca 与 Al 不进入橄榄石 → 它们在熔体中的浓度上升。**
（这题是把"图上箭头方向"翻译成"元素行为"，是理解相图物理意义的关键一步。）

**Q4. 结晶路径在什么温度改变？此时已结晶了多少百分比的熔体？**
- 箭头从 x 出发、沿"回指 Fo"的直线**背离 Fo** 移动。**箭头大体"下坡"穿过等温线，但注意箭头并不垂直于等温线。**
- **答：路径在撞上共结线（图上红色高亮）时改变，位置接近 1300 °C 等温线，约 1320 °C。**
- **答：此时原始熔体已结晶 14%。**
- **计算方法（题目提示）**：用杠杆法则；需要作一条**同时通过"结晶矿物成分点（Fo 顶点）""原始总成分点 x""路径转折时的液体成分点"**的构造线，在这条线上量取线段比。

**Q5. 共结线上发生什么？降温方向在哪边？**
- 共结相边界处 **Di 加入结晶组合**，新反应 **L → Fo + Di**。
- **Fo–Di 共结线像一条陡壁深谷的谷底，冷却中的液体被陡壁限制、只能顺谷下行（沿降温方向）。**
- **答：降温箭头指向三角共结点 E。**

**Q6. 液体到达 E（1270 °C）时发生什么？写出反应式。**
**答：An 开始结晶。共结反应为 L → Fo + Di + An。**

**Q7. 共结反应持续到最后一滴液体耗尽（期间液体成分不变，因为结晶矿物混合物的成分与液体相同）。最终固结的玄武岩含哪些矿物？（a）平衡结晶 /（b）分离结晶下的模态比例？**
- **最终固体含 Fo + Di + An。**
- **(a) 平衡结晶**：最终固体成分 = 起始熔体 x = **22% Fo，53% Di，25% An**（同 Q1）。
- **(b) 分离结晶**：最终固体成分 = 共结点成分 = **8% Fo，49% Di，43% An**。
- **允许 ±5% 舍入误差。**

**Q8. 用相同步骤描述成分 y 的结晶路径，其结晶顺序与 x 有何不同？**

成分 y 的结晶序列：
1. 橄榄石单相区：**L → Fo**；熔体成分**直接背离 Fo** 演化。
2. 撞上 **Fo–An 共结线**：新反应 **L → Fo + An**；熔体沿共结边界向**降温方向**演化。
3. 到达三角共结点：**L → Fo + Di + An**；反应持续到液体耗尽。

**对比结论**：
- **x 的结晶顺序：ol → ol + cpx → ol + cpx + plag**
- **y 的结晶顺序：ol → ol + plag → ol + cpx + plag**

**Important take-away points（原文五条，务必背下）**：
1. 该图是**液相面的地图**，**只能显示液体成分**。
2. 成分按三角顶点各相的比例作图。
3. 温度由**等温线**和**降温箭头**表示。
4. **结晶过程中，液体只能向降温方向移动。**
5. **最后结晶的液体一定位于三角共结点 E。**

| **结晶顺序**的解释 | **4** |
| 岩石的**命名与岩石学分类** | **4** |
| 该岩石可能形成的**构造背景**解释 | **6** |

**答案必须至少包含一张标注完整的图，展示岩石的矿物学与结构。**

#### 老师给出的通用反馈（"最常见的改进建议"）——这一段等于评分细则

1. **画比例尺（scale bar）。只写 "x4"（或物镜倍数）信息量不够。**
2. **画整齐。尽量画出真实的晶形，而不是示意性的团块。**
3. **用线条粗细表示突起（relief）。**
4. 可用颜色突出关键特征。
5. **素描画大一点**——大图更易看清、通常包含更多细节，因而**通常得分更高**。
6. **标注所有重要矿物与结构。若某特征对解释很重要，它就必须标在图上。**
7. **如果不认识某个矿物，就描述它的光性。**即使鉴定错了，**光性描述（或结构描述）本身仍可拿高分**。
8. **利用矿物共生知识预测基质矿物**（例如：玄武岩的基质里应当有 cpx 和斜长石）。
9. **一定要给出模态比例估算**——这一项经常被忘掉，但它是有分的。
10. **结晶顺序：写"无法判断结晶顺序"是可以的**——只要给出理由，这本身是一个有效的解释，照样给分。

#### 关于"构造背景"题的专门说明（本周最高频失分点）

> **最常见的错误是把"volcanic（火山的）"或"plutonic（深成的）"写成构造背景——这是不对的，因为岩浆在任何构造背景下都可以喷出或侵入。**
> "构造背景"问的是：你认为这个岩浆形成于**洋中脊、热点、俯冲带，还是其他岩浆活动场所**？然后你必须**用观察来论证**。

**老师给的范例答案（值得整段背下来当模板）**：

> 情形：一块玄武岩薄片，**玻璃质基质、无气孔**。
> "这块玄武岩很可能形成于**洋中脊**。它的**玻璃质基质指示极快速冷却**，但它**没有气孔**，说明它是在**足以阻止气泡出溶的压力下喷发的**。这暗示是**水下喷发**，且水**足够冷、足够深**，以致不会发生**射汽岩浆（phreatomagmatic）爆发式喷发**。这些条件正见于洋中脊。"

**老师的宽容声明**："本单元现在还没讲完所有构造环境下的岩浆形成与喷发……**即使构造背景判断错了，只要能说明你的解释是如何被观察支撑的，你依然可以拿高分。**"

> 📎 背景补充：这个范例的推理骨架值得抽象出来记：**冷却速率（粒度/玻璃）→ 喷发环境（水下/陆上）→ 压力与挥发分（气孔有无）→ 构造背景**。反过来，若薄片里**气孔发育**，就说明喷发压力低（浅水或陆上），洋中脊（水深数千米）的可能性下降。

### 附加数字资源（Bonus digital resources）

#### A. 手标本（三件，来自洋壳的不同部位）

**A1. 深海枕状玄武岩（Deep sea pillow basalt）**
- **Q：有什么证据说明这块岩石冷却很快？** → **非常细粒**；并且枕体外缘有**玻璃质外壳（glassy rind）**的痕迹（那些**暗色发亮的斑块**）。**玄武岩玻璃只有在熔体被极快淬火时才形成。**
- **Q：气孔代表什么？** → **从玄武质熔体中出溶（exsolved）出来的气泡，主要是 H₂O 蒸气。** **（不是被困住的海水汽化形成的气泡——这是一个明确点名的误解。）**

**A2. 辉长岩（Gabbro）**
- **Q：有哪些矿物？** → **斜长石（白色）+ 单斜辉石**（新鲜锯切面上呈**黑色**，风化面上呈**灰褐绿色**）。**可能还有其他次要矿物，只是在手标本上不易看到。**
- **Q：冷却多快，证据？** → **中等到缓慢冷却；证据是粗粒。**
- **Q：来自块状辉长岩还是片理化（foliated）辉长岩？** → **可能是块状辉长岩，因为手标本上看不到片理或矿物定向排列的证据。**

**A3. 蛇纹石化方辉橄榄岩（Serpentinized harzburgite）**
- **Q：流体流经过这块岩石的证据？** → **脉体（veins）**指示流体流动通道。**那条斜长石脉原本是熔体脉，但流体也可能沿此流动。**那许多约 **80° 交角**的细线很可能是流体流动通道。
- **Q：原生矿物是什么？** → 它是方辉橄榄岩，所以原生矿物是**橄榄石 + 斜方辉石**。**绿色橄榄石在手标本上已看不见，因为全部蚀变成了蛇纹石。黑色蛇纹石使岩石呈云母状、片状、发亮的外观。亮金色斑块是斜方辉石。**
- **Q：它来自岩石学莫霍之上还是之下？** → **之下。岩石学莫霍分开地幔岩与地壳岩；这是地幔岩，所以必然来自岩石学莫霍之下。**

#### B. 虚拟露头（两处枕状玄武岩）

对象：**旧金山湾枕状玄武岩** 与 **华盛顿州哥伦比亚河玄武岩枕状熔岩**。

- **Q：能否分辨单个枕体？** → 旧金山那处有**一个清晰的枕体形态**；哥伦比亚河的枕体**边界不清、较难辨认**，但确实形成**块状体（blocky masses）**。
- **Q：枕体边缘有快速冷却的证据吗？没有的话为什么？**
  - 旧金山：**黑色玻璃壳大部分已消失，但仍有一圈明显的细粒外缘。**
  - 哥伦比亚河：**枕体风化严重，边缘无玻璃保存；虚拟露头分辨率也不足以判断有无细粒边缘。**
  - **为何玻璃常不保存？** → **玄武岩玻璃极易蚀变与侵蚀：在适当条件下很容易蚀变为细粒黏土矿物，而这些又很容易被风化掉。所以在风化露头中玄武岩玻璃很少保存。**
- **Q：两处露头都强烈破裂，节理取向有什么特点？** → **这些是冷却节理，垂直于冷却面形成，因此呈放射状取向。在哥伦比亚河的虚拟露头上看得最清楚。**

#### C. 薄片（三片）

> **前置说明（原文）：这三片都不是洋中脊玄武岩，但它们都展示了你应当能够识别和描述的玄武岩关键特征。**

**C1. Basalt, Staffa（斯塔法岛玄武岩）**
- 先看手标本：**风化外表很容易被误认成砂岩。**
- **Q：基质中能识别出哪些矿物？**
  - 基质**非常细**。
  - **小的斜长石长条（laths）容易辨认。**
  - **单斜辉石最好靠 XPL 下的浅橙色干涉色识别（而且它一定是 cpx，因为它是玄武岩的必要矿物）。**
  - **异常之处：基质里还有小的橄榄石。**
  - 有些斑块在 PPL 下呈**黑/灰扑扑**——**这些不是玻璃，只是矿物太小无法鉴定**。
  - 有些**绿褐色黏糊状斑块**，尤其沿那条水平脉分布——**这是热液蚀变形成的次生矿物蒙脱石（smectite）**。
- **Q：结构是什么？** → **无斑晶，因此结构为 aphyric（无斑）；基质为 holocrystalline（全晶质，完全由晶体组成）。**

**推理链**：*细粒 + 斜长石长条 + XPL 浅橙色干涉色的相 → 必要矿物 cpx + plag 齐备 → 玄武岩；无斑晶 → aphyric；无玻璃 → holocrystalline。*

**C2. S339 01 Basalt**
- **Q：结构？** → **全晶质（holocrystalline）。不是完全的间隙结构（interstitial），因为所有组成矿物都有发育良好的晶形，没有哪个像是在填充间隙空间。有些地方可以看到 cpx 围绕早先形成的斜长石生长——这种结构最好描述为亚辉绿结构（sub-ophitic）。**
- **Q：能对结晶顺序作何解释？（Rotation 2 有帮助）**
  - 观察：**橄榄石被 cpx 完全包裹**；**斜长石与磁铁矿被橄榄石完全或部分包裹**；**斜长石被 cpx 部分包裹**。
  - 更大范围内：**有一些斜长石斑晶**，基质斜长石有发育良好的**板状（tabular）**习性。
  - 解释：**斜长石斑晶最先生长；基质矿物大约同时结晶。**
  - **可能的结晶顺序：plag → plag + ol + mgt → plag + ol + mgt + cpx。**
- **Q：有次生蚀变的证据吗？（Rotation 1 有帮助）** → **有——橄榄石沿晶体边缘和穿过晶体的弯曲裂纹发生蚀变，但蚀变不广泛。**

**推理链（包裹关系判年龄）**：*A 被 B 包裹 → A 比 B 老*（Reference Guide p.4–5 的原则："当一个矿物围绕另一个生长时，被包围的更老，包围者更年轻"）。因此 mgt/plag（被 ol 包裹）早于 ol，ol（被 cpx 包裹）早于 cpx。

**C3. Porphyritic olivine basalt, Mauritius（毛里求斯斑状橄榄玄武岩）**
- **Q：斑晶矿物是什么？** → **橄榄石与单斜辉石。**
- **Q：斑晶矿物与基质矿物相同吗？** → **不同：基质含斜长石、cpx 和磁铁矿，但没有橄榄石。橄榄石必定在基质形成之前就已结束结晶。**
- **Q：可能的冷却史与证据？** → **两个截然不同的冷却阶段。自形至半自形（euhedral to subhedral）的斑晶在岩浆房中自由漂浮生长，处于缓慢冷却条件（低成核率、高生长率）；细粒基质在快速冷却中形成（高成核率、低生长率），很可能是在火山喷发之后。**

**推理链（回扣 Week 4）**：*晶形自形 + 粒度大 → 低成核率高生长率 → 慢冷；粒度细 → 高成核率低生长率 → 快冷；两者并存 → 两阶段冷却史（岩浆房 + 喷发）。*

#### D. 总结性解释题

- **Q：这三片薄片中有哪一片保存了瞬时淬火的证据？** → **没有。它们都不是玻基斑状（vitrophyric），基质中都没有玻璃——尽管基质晶体很小，它们都是全晶质的。**
- **Q：三片中哪一片冷却最快，为什么？** → **基质最细的那片冷得最快。老师的看法：毛里求斯斑状玄武岩略细一些，且基质晶体比 Staffa 玄武岩更呈针状/羽状（acicular/feathery），所以它的冷却速率可能更快——不过这两个样品差别不大。亚辉绿结构的那片（S339）基质粗得多，所以冷却更慢。**

> 📎 背景补充：**针状/羽状（acicular / feathery / skeletal）晶形本身就是快速冷却的独立判据**，与粒度互相印证。Reference Guide p.13 对 **skeletal（骸晶）**的定义是"呈枝状、树状形态并含内部空腔，常保持整体自形轮廓；形成于极快速生长条件"。这是 Week 4 成核–生长动力学在结构上的直接表现。

## 六、易错点 / 重点难点

**1. "必要矿物"不等于"一定能看到"。**
必要矿物 = 一定**存在**（至少在基质中），不是一定**可辨认**。玄武岩基质细到看不清时，正确写法是"基质由 cpx + plag 组成（据必要矿物定义推断，XPL 下白 + 橙斑点支持这一判断）"，而不是"基质矿物不可鉴定"。这是老师反复强调的得分点，也写进了 Part 3 的通用反馈第 8 条。

**2. 构造背景 ≠ 侵入/喷出。**
把 "volcanic"/"plutonic" 当成构造背景是本题最常见的错误。构造背景只有：**洋中脊 / 热点（地幔柱）/ 俯冲带 / 其他岩浆活动场所**。

**3. "我们改变的是地温曲线，不是固相线"（洋中脊）；俯冲带才是"改变固相线"。**
这两者一旦混淆，整套熔融机制的逻辑就崩了。–ΔP 和 +ΔT 移动的是**岩石在 P–T 空间中的位置**；+ΔH₂O 移动的是**固相线本身**。

**4. 喷发温度 < 地幔位温，原因是熔融潜热，不是"上升途中散热"。**
本课的机制是**绝热**的（不与外界换热），温度下降来自**内部消耗的熔融潜热**，绝不能写成"上升过程中冷却/散热"。

**5. 地震莫霍 vs 岩石学莫霍。**
- 地震莫霍：波速跃变，实质分开**含斜长石 / 不含斜长石**。
- 岩石学莫霍：分开**地幔岩（熔融残余）/ 地壳岩（熔体结晶产物）**。
- **堆晶超镁铁岩夹在两者之间**：地震上像地幔，岩石学上属地壳。这是最爱考的细节。

**6. 三角相图上液体成分演化方向别搞反。**
结晶某矿物 → 液体成分沿"该矿物顶点 — 当前液体点"的连线**背离该顶点**移动。作图时把尺子压在**顶点和液体点**上再向外延长，不要凭感觉画。同时记住**箭头不垂直于等温线**（Practical Q4 特意提醒）。

**7. 液相面图只能画液体成分。**
不要试图在图上"移动固体成分点"。固体成分要么是顶点（纯端元），要么用杠杆法则在构造线上取。

**8. 平衡结晶 vs 分离结晶的"最终固体成分"。**
- 平衡结晶：最终固体成分 = **起始总成分**。
- 分离结晶：最终（最后结晶的）固体成分 = **共结点成分**；液体在共结点耗尽。
> 注意措辞的细致：分离结晶下"最终固体"指的是**由最后那批液体结晶出来的岩石**；早期被移走的堆晶体成分与之不同。答题时按 Practical 给的口径写（= 共结点成分）即可，但要理解这一层含义。

**9. 斜长石消光角法的三重陷阱。**
- 取向不合格（双晶灰度不等 / 正反角相差 >5°）→ **必须丢弃**。
- **环带斜长石不适用**这一方法。
- **正负消光角无法区分**：15° 可能是 −15°（钠长石）也可能是 +15°（奥长石），需要贝克线法测折射率来分辨。
- 跨多颗晶体时用**最大值**，不是平均值（Reference Guide 步骤 6）；一对 a 与 a′ 之间才用平均。

**10. 橄榄石 vs 普通辉石（Reference Guide p.16，最常混淆的一对）。**

| 特征 | 橄榄石 | 普通辉石 |
|---|---|---|
| 颜色（PPL） | 无色 | *可能淡粉—褐色*或灰色 |
| 裂理与解理 | *不规则弯曲裂纹*，常伴蚀变；解理罕见 | 长条切面上一组解理，*基面切面上两组近垂直解理* |
| 双折射率 | 0.035–0.052，可达三级色 | 0.018–0.033，可达二级色 |
| 消光角 | 自形晶相对晶面**平行消光** | *相对解理斜消光* |
| 蚀变 | *易蚀变*为蛇纹石（无色）或伊丁石（红褐色） | 更耐蚀变 |

（斜体为最具诊断性的特征。）

**11. 斜方辉石 vs 单斜辉石（Reference Guide p.16）。**
- **消光角是最常用判据**：要选**只显示一组解理迹线**、且显示**最高干涉色**的晶体来测。
- 颜色：cpx 可粉—褐色、可有多色性；opx 通常无色不多色。**唯一例外是顽火辉石（enstatite）**，有时呈**弱但很特征的淡粉—淡绿多色性**。
- 干涉色：opx **一级低干涉色**；多数 cpx 更高，典型**二级**。
- 双晶：**opx 从不发育双晶**；cpx 可以有。

**12. 气孔不是"被困住的海水汽化气泡"。**
气孔是从熔体中**出溶**的挥发分（主要 H₂O 蒸气）。这条被 Practical 明确用括号点名纠正。

**13. 玻璃 vs "太小认不出的晶体"。**
Staffa 薄片里 PPL 下黑/灰扑扑的斑块**不是玻璃**。判据是 XPL：**玻璃全消光（各向同性），细晶集合体仍有斑点状干涉色**。这也是判断"是否 vitrophyric / hypocrystalline"的唯一可靠办法。

**14. MORB 不是原生岩浆。**
这是本周的招牌结论，必须能完整复述证据链：Mg# 直方图峰值不落在与地幔橄榄石平衡的区间 → 非原生 → 必经分离结晶；峰窄 → 分离结晶程度一致 → 缓冲良好的开放系统。

**15. "橄榄石先于斜长石结晶 = 低压结晶"这个箭头方向别记反。**
高压：**plag 先**；低压：**ol 先**。MORB 是 ol 先 → 低压。

**16. 无法用薄片区分"成分效应"与"压力效应"。**
写解释时要留出这层不确定性；老师明确说过答案是"不能"。

**17. 石英与橄榄石绝不共生；霞石绝不出现在拉斑玄武岩中。**
这两条"绝不"是判据性的，可用来一票否决某些分类结论。
