## 二、核心概念

### 1. 成矿的"五问"框架（本课贯穿始终的骨架）

讲义 slide 2 用一张热液系统示意图（间歇泉，Trewin 2005）提出了五个必须回答的问题，老师在录音里逐条展开：

| 问题 | 英文 | 含义 |
|---|---|---|
| ① 源 | **source** | 元素从哪来？（围岩、岩浆、海水……） |
| ② 搬运 | **transport** | 什么介质把元素带走？→ 流体 |
| ③ 通道 | **transport pathway** | 流体沿什么路径走？→ 断层、裂隙、孔隙网络 |
| ④ 空间 | **space for enrichment** | 新加入的物质放在哪？必须**创造空间** |
| ⑤ 沉淀 | **precipitation mechanism** | 什么机制让元素从流体里析出？ |

老师原话："**这，一言以蔽之，就是资源地质学的全部**（all of this, in a nutshell, really, is what resource geology is all about）"。**这五个问题是本课所有后续矿床类型的答题模板**——考试碰到"解释某类矿床的成因"，按这五条组织答案基本不会跑题。

### 2. 温度：地温梯度（geothermal gradient）

- **定义**：温度随深度的增加率，dT/dz，单位 °C/km（也写 °C/m）。
- **本质**：地球内部热（放射性衰变 + 原始余热）向地表的**传导散失**，梯度大小由热流（heat flow）与岩石热导率共同决定。
- **构造背景差异是本讲的重点**（讲义 slide 5 图）：
  - **克拉通（craton）**——前寒武纪的大陆古老核心，**因为老所以冷**（老师："as a consequence of it being very old, it's also very cold"），梯度最低，**~10 °C/km**。
  - **裂谷（rift，图中为 Rio Grande rift）**——大量热量上涌，伴随火山活动，热流高，梯度最高，**~35 °C/km 甚至更高**。
  - 中间还有两条曲线（**~15 和 ~25 °C/km**），标注为 Phanerozoic 与 Archean。
- 两个端元之间可以有任意梯度值。

> 📎 背景补充：全球平均大陆地温梯度常引用 **25–30 °C/km**，但这是"平均"值，稳定盆地往往 20–25，克拉通 10–15，弧后与裂谷可达 40–60，洋中脊局部可达数百 °C/km。Practical 2 算出的 Cheshire Basin ~20 °C/km 属于稳定盆地的正常范围，**低于全球平均并不代表算错了**。

- **传热方式**（录音中出现，讲义未明写）：
  - **传导（conduction）**：热量通过岩石骨架传递，是"背景地温梯度"的成因。
  - **对流（convection）**：流体被加热→浮力上升→冷却→下沉，形成**热对流环（thermal convection cell）**。对流对成矿远比传导重要，因为它同时搬运**热**和**溶解的元素**。

### 3. 压力：静岩 vs 静水（本周最核心的一对概念）

**（a）静岩压力 / 围压（lithostatic pressure / confining stress）**
- 定义：上覆**岩石柱**的重量施加的载荷压力（overburden / load pressure）。
- 性质：**均匀（uniform）**，各方向相等。
- 讲义取平均岩石密度 **2.5 g/cm³**，对应梯度 **25 kPa/m**。
- 老师强调这是"**干岩石**、不含流体时的压力增长"。

**（b）静水压力（hydrostatic pressure）**
- 定义：上覆**连通流体柱**的重量施加的压力。老师用潜艇作类比：作用在海底潜艇上的就是上方水柱的重量。
- 讲义取流体密度 **1 g/cm³**，对应梯度 **10 kPa/m**。
- 关键前提：**孔隙流体自地表向下连通**（即孔隙水可以自由排出）。

**（c）二者构成的"三角区"——本讲的图像化核心**
老师用了一个非常好记的说法：静水与静岩两条线**围出一个三角形空间**（"we are creating a space between hydrostatic and lithostatic"）。
- 一个端元：压力**完全由流体**承担 → 静水线。
- 另一个端元：压力**完全由干岩石**承担 → 静岩线。
- **现实中两者都不可能**："there will probably never be an entirely dry rock, and there will never be just fluid"。
- 因此**真实地下的压力演化曲线必然落在这个三角形之内**，讲义图上标为 "Typical subsurface fluids" 的那条居中曲线。

**（d）超压（overpressure）**
- 定义：孔隙流体压力**高于同深度静水压力**的部分，`超压 = 实测地层压力 − 静水压力`。
- 在 P–z 图上表现为：实测点**向右偏离静水线、向静岩线靠拢**。
- **成因**（Practical discussion 明确给出两条 + 录音给出一条）：
  1. **不排水压实 / 欠压实（undercompaction）**——存在不渗透层，孔隙流体无法排出，于是流体开始承担一部分本该由岩石骨架承担的载荷。
  2. **烃类充注（hydrocarbon charging）**——油气进入孔隙，增加孔隙压力。
  3. **断层封闭导致流体聚集**（录音）——流体向一条不活动、封闭的断层运移，无法继续上升，在断层附近堆积并累积压力。
- **上限**：压力上升到**等于静岩压力**时，岩石破裂。老师："lithostatic really is where the rocks then start to break."

**（e）断层阀循环（fault-valve cycle）——录音中最精彩的一段**
这是把"压力"与"流体运移"和"地震"串起来的机制：
```
流体向封闭断层聚集 → 孔隙压力从静水向静岩爬升
        → 达到静岩 → 岩石破裂、断层活动（=地震）
        → 断层张开，流体沿断层快速逃逸 → 压力骤降
        → 断层重新封闭 → 循环重启
```
老师明确指出这解释了"**地震、断层活动与流体运移之间的相互作用**"，并且**这正是元素从地壳一处向另一处进行质量迁移（mass transfer）的机制之一**。

### 4. 孔隙度（porosity）与渗透率（permeability）

**孔隙度 φ**
- 定义：岩石中**能储存流体的任何空间**——"storage capacity of a rock"。
- `φ = 孔隙体积 Vp / 岩石总体积 Vb`，以**分数或百分数**表示，**无量纲**。
- 可被水、CO₂、油、气充填。

**渗透率 k**
- 定义：**流体通过岩石运移的能力**（ability of a fluid to move through a rock），取决于**孔隙网络的类型与连通性**。
- 单位：**m²** 或 **达西 D（Darcy）**。
- 老师用薄片照片讲解（讲义只有图无字）：蓝色 = 孔隙，灰色 = 砂岩颗粒，孔隙之间的**窄通道叫孔喉（pore throat）**。黄色箭头是流体必须走的路径。
  - **路径越"曲折（tortuous）"→ 渗透率越低**；路径越直 → 渗透率越高。
- **关键**：孔隙度大 ≠ 渗透率大（详见第六节易错点）。

**随埋深的演化**
- 录音明确：浅部地壳有孔隙、有渗透率；**随深度增加，由于上覆载荷（overburden load），孔隙空间趋于闭合**，孔隙度与渗透率大幅降低。
- 后果（非常重要）：**深部地壳中，断层与裂隙几乎是流体运移的唯一通道**（"faults and fractures are really gonna be your only mechanism to move fluids around"）。这就把"变形"和"流体流动"两个主题焊在了一起。

### 5. 岩石变形（deformation）——为什么它属于"地下环境"

**（a）三轴应力（triaxial stress）**
- 上覆岩石给的是**均匀**载荷；但**板块构造使力在地壳中横向传递（lateral transmission of tectonic forces）**，再加上重力，实际产生的是**差异应力/三轴应力（differential / triaxial stress）**。
- **应力（stress）= 单位面积上施加的力**。
- 三个主应力向量：**σ₁ > σ₂ > σ₃**（最大、中间、最小）。讲义图中红箭头 = σ₁，蓝箭头 = σ₃，σ₂ 垂直于二者（垂直于幻灯片平面）。
- **应变（strain）= 岩石对应力的反应**，例如断层的形成。
- 应力类型：**张性（tensional）、压性（compressional）、剪切（shear）**——一年级已学，用于断层成因。

**（b）脆性 vs 韧性（brittle vs ductile）**
应力—应变曲线（讲义图）：
- 起始段为**弹性变形（elastic）**：卸载后回弹到原状，直到**弹性极限（elastic limit）**。
- 越过弹性极限进入**韧性变形（ductile）**：卸载后**残留永久应变（permanent strain）**。
- 继续加载最终**破裂（fracture）**。

| | 脆性材料 | 韧性材料 |
|---|---|---|
| 弹性段 | **长** | 短 |
| 韧性段 | **很短**，很快破裂 | **长** |
| 条件 | 低温、低围压、**高应变速率** | 高温、高围压、**低应变速率** |
| 地壳位置 | **浅部地壳** | **深部地壳** |
| 典型构造 | **断层（fault）** | **褶皱（fold）** |

**（c）浅部脆性变形对成矿的意义**
讲义原文：**"Brittle deformation in shallow crust via faults, fractures, joints, veins, and cleavage, which allow fluid flow and mineral precipitation"**——断层、裂隙、节理、脉、劈理**既是流体通道又是矿物沉淀的场所**。

**（d）用应力方位预测流体通道（录音重点推导，见第四节）**
- 与某个主应力**垂直**的面上只有**正应力（normal stress）**、没有剪应力 → **不可能滑动**，但**可以被拉开**形成**裂隙（fracture）**。
- 与主应力**斜交**的面上有剪切分量 → 形成**断层（fault）**，两侧岩块相对滑动。
- **裂隙被矿物充填后即为脉（vein）**。老师特别说："vein 这个词会在后面的课里反复出现。"

### 6. 流体运移的驱动力（大尺度）

| 驱动方式 | 机制 | 典型场景 |
|---|---|---|
| **重力驱动（gravity-driven）** | 隆升区（山地、有降雨）储存的**势能**形成**水力头（hydraulic head）**，流体自高地向低地大范围流动 | 山前盆地、造山带前陆 |
| **构造侧向挤压（lateral tectonic forces）** | 构造力把流体从地壳一部分挤向另一部分 | **造山运动**期间 |
| **热对流（convection-driven）** | 冷流体因浮力下沉 → 深部加热 → 上升 → 地表/海底排放 → 冷却 → 再循环，形成**对流环** | **海底热液系统**（冷海水进入洋壳，加热后在海底喷出） |
| **断层阀（超压驱动）** | 见上文 3(e) | 深部低孔渗地壳、地震活动带 |

### 7. 如何创造"空间"（课堂互动，讲义完全没有）

老师提问："除了张开裂隙并充填之外，还有什么机制能在地下**创造空间**？"
- 有学生答"**侵蚀（erosion）**"——**被否定**：侵蚀是**地表过程**，2 km 深处不适用。
- **正确答案：溶蚀（dissolution）**。许多地下流体是**腐蚀性（corrosive）**的；当**流体成分与围岩之间存在不平衡（disequilibrium）**时，流体会**溶解、腐蚀围岩**，从而腾出空间。**热流体尤其如此**。

→ 所以"造空间"至少两条路：**① 张裂隙/断层（力学）② 溶蚀（化学）**。

### 8. 地壳中的流体类型（讲义 slide 16 + 录音）

| 大类 | 具体类型 | 说明 |
|---|---|---|
| **岩浆（magma）** | 熔融岩石 | 本身就是一种"流体"，是富集矿物的重要机制 |
| **水溶液流体（aqueous fluids）** | **岩浆出溶（exsolution from magma）** | 岩浆含挥发分，主要是 H₂O，还有 CO₂、SO₂ 等；把水从岩浆中赶出来即得水溶液流体 |
| | **区域变质流体（regional metamorphic fluids）** | 矿物相变脱水释放大量流体（下周详讲） |
| | **建造水/同生水（connate / formation water）** | 沉积盆地流体的**统称**，是多来源的**混合**：地表水、矿物溶解、岩浆流体……本质是**高盐卤水（saline brines）**；讲义特别点出**蒸发岩脱水/溶解产生的卤水** |
| | **海水（seawater）** | 可沿断层进入地壳 |
| | **大气水/雨水（meteoric water）** | 地表淡水 |
| **烃类流体（hydrocarbon fluids）** | 油、气 | 后续石油周详讲 |

### 9. 资源矿床的分类方案（讲义 slide 17）

思路：**把岩石三分（火成/变质/沉积）平移到矿床分类上**。

| 矿床类别 | 定义 | 同生/后生 |
|---|---|---|
| **火成/岩浆（Igneous / Magmatic）** | 与岩浆形成、冷却、结晶相关的作用 | **同生（syngenetic）** |
| **岩浆热液（Magmatic-hydrothermal）** | 从**熔体派生的**水溶液流体中沉淀 | **后生（epigenetic）** |
| **热液（Hydrothermal）** | 从各种来源（火成、变质、地表）的热液中沉淀 | **后生** |
| **沉积（Sedimentary）** | 沉积物形成过程中的作用 | **同生** |
| **表生与次生富集（Surficial and supergene）** | 地表流体形成；或已有矿床的地表改造 | **后生** |

三个必须背下来的定义（讲义直接给）：
- **Hydrothermal**：thermal energy contained in water（水中所含的热能）。
- **Syngenetic**：formed at the same time as host rock（与围岩同时形成）。
- **Epigenetic**：formed after host rock（晚于围岩形成）。

**为什么用"热液"顶替"变质"这一格？**（录音解释，讲义没写）
岩石分类里有"变质岩"，但矿床分类里**没有对应的"变质矿床"**。取而代之的是"热液矿床"，理由是：热液携带热能，**既能搬运物质（mass transfer），又能溶解、沉淀、蚀变围岩**——这在功能上**等价于变质作用**。因此热液成为矿床分类的**第三大类**。

### 10. 岩浆作用与矿床（Lecture 3 前半，本节课已讲）

**（a）先要有熔体**：地幔是**固态**的，"正常"地温梯度**不与地幔固相线（solidus）相交**，不会自动产生熔体。四种触发**部分熔融（partial melting）**的机制：① **地幔异常高温**（热点、洋中脊 MOR）；② **减压熔融（decompression melting）**，地壳/岩石圈减薄；③ **加水（water addition）**，俯冲带；④ **造山增厚与加热**。

**（b）结晶与分异**：按**鲍文反应系列（Bowen's reaction series）**，熔点最高者最先结晶。镁铁质熔体先结晶**橄榄石** → 橄榄石下沉 → 残余熔体 Fe、Mg 减少、SiO₂ 增加 → 转与**辉石**平衡 → …… → 最终到**石英**；右支为长石系列（Ca-长石 → Na-长石）。**核心结论：结晶过程中熔体与晶体的成分持续变化（分异）**。

**（c）Stokes 定律与堆晶**：晶体沉降速度决定能否形成堆晶层（公式见第三节）。**橄榄石沉降快**、在岩浆房底部堆积成**堆晶（cumulate）**——这是**层状侵入体中 Cr、PGE 富集的物理基础**（两周后详讲）。

**（d）元素分配的两把钥匙**
1. **地球化学亲和性（geochemical affinity）**：**亲铁 siderophile**（与金属/铁）、**亲硫 chalcophile**（与硫）、**亲石 lithophile**（与硅酸盐）。讲义柱状图：**Cr、Ni、Pt、Au** 高度富集于**玄武质（镁铁质）熔体**（亲铁/亲硫）；**Li、U、F、Th** 富集于**流纹质（长英质）熔体**（亲石）。
2. **相容性（compatibility）**：由**分配系数（distribution coefficient）**控制，取决于**离子电荷与半径**。**相容元素**优先进晶体 → Ni、Au、Cr、PGE，早期结晶即被带走；**不相容元素**优先留熔体 → **U**（本课重点），留到最晚期 → 富集于**花岗岩**。

**（e）火成矿床概览（讲义 slide 25）**

| 作用 | 矿床类型 |
|---|---|
| 爆发式火山作用（volatile-rich magma） | **金刚石金伯利岩（kimberlite）** |
| 结晶分异 + 岩浆混合 | **层状侵入体中的 Cr、PGE** |
| 熔体不混溶（melt immiscibility） | **Ni–Cu 矿床** |
| 晚期结晶 + 元素不相容 | **花岗岩中的 Sn、U、Th** |

## 三、公式与图表

### A. 地温梯度

$$\text{地温梯度} = \frac{dT}{dz} = \frac{T_2 - T_1}{z_2 - z_1}\quad [^\circ\mathrm{C/km}]$$

- 若已知地表温度 $T_0$，则任意深度温度：$T(z) = T_0 + G \cdot z$。
- Practical 中把 $T_0 = 11.5\ ^\circ$C 作为"强制过地表点"的约束——这一点很重要，因为只用两个井底点算斜率，会**系统性低估**梯度（见第五节）。

**典型量级速查表**

| 构造背景 | 梯度 | 来源 |
|---|---|---|
| 克拉通 craton | **~10 °C/km** | 讲义 slide 5 |
| 图中另两条曲线 | **~15 / ~25 °C/km** | 讲义 slide 5（标注 Phanerozoic / Archean，见勘误表） |
| Rio Grande 裂谷 | **~35 °C/km 或更高** | 讲义 + 录音 |
| Cheshire Basin（实测） | **~20 °C/km** | Practical 2 |
| 📎 全球大陆平均 | 📎 **25–30 °C/km** | 📎 背景补充 |

> 📎 背景补充：热传导的物理基础是**傅里叶定律** $q = -k\,\dfrac{dT}{dz}$，其中 $q$ 为热流密度（mW/m²），$k$ 为热导率（W·m⁻¹·K⁻¹）。**在热流 $q$ 相同的情况下，热导率低的岩层（如页岩、蒸发岩以外的泥岩）梯度更陡，热导率高的岩层（如盐岩）梯度更缓**——这是"盐丘冷却效应"的由来。讲义未涉及此式，但它解释了为什么同一盆地不同层段梯度可以不同。

### B. 压力

**静岩压力（lithostatic）**
$$P_{lith} = \rho_{rock}\, g\, z$$
- 讲义取 $\rho_{rock} = 2.5\ \mathrm{g/cm^3}$（"地球上地壳岩石的平均密度"）
- 核算：$2500 \times 9.81 = 24{,}525\ \mathrm{Pa/m} \approx$ **25 kPa/m** ✓（讲义标注正确）
- 即 **≈ 24.5 MPa/km**

**静水压力（hydrostatic）**
$$P_{hyd} = \rho_{fluid}\, g\, z$$
- 讲义取 $\rho_{fluid} = 1.0\ \mathrm{g/cm^3}$
- 核算：$1000 \times 9.81 = 9{,}810\ \mathrm{Pa/m} \approx$ **10 kPa/m** ✓
- 即 **≈ 9.8 MPa/km**
- Practical 用的是 $\rho = 1.1\ \mathrm{g/cm^3}$（**地层卤水偏咸，密度大于淡水**）→ **10.8 MPa/km**

**单位换算总表（务必背熟，是本周最易失分处）**

| 量 | 静水 (ρ=1.0) | 静水 (ρ=1.1) | 静岩 (ρ=2.3) | 静岩 (ρ=2.5) |
|---|---|---|---|---|
| kPa/m | 9.81 | 10.79 | 22.56 | 24.52 |
| **MPa/km** | **9.8** | **10.8** | **22.6** | **24.5** |
| kg/cm² 每 km | 100 | 110 | 230 | 250 |
| 📎 bar/km | 📎 98 | 📎 108 | 📎 226 | 📎 245 |
| 📎 psi/ft | 📎 0.433 | 📎 0.476 | 📎 0.997 | 📎 1.083 |

- **1 kg/cm² = 98,066.5 Pa = 0.0980665 MPa ≈ 0.098 MPa**（Practical 明确给出）
- 📎 背景补充：1 bar = 10⁵ Pa = 0.1 MPa；1 atm = 1.01325 bar；1 psi = 6.895 kPa。钻井工程中常记：**淡水静水梯度 ≈ 0.433 psi/ft，静岩梯度 ≈ 1 psi/ft**——与上表完全自洽，可用来交叉验算。

**"÷10" 换算因子的来龙去脉**（Practical discussion 给了公式但没给推导，这里补上）
$$P\ [\mathrm{kg/cm^2}] = \frac{z\ [\mathrm{m}] \times \rho\ [\mathrm{g/cm^3}]}{10}$$
推导：高 $z$ 米 = $100z$ cm 的柱体，截面 1 cm²，则质量 $= \rho \times 100z$ 克 $= 0.1\rho z$ 千克。故单位面积上的重量为 $0.1\rho z\ \mathrm{kg/cm^2} = \rho z/10$。**这个因子纯粹来自 m→cm 与 g→kg 的换算，与 $g$ 无关**（因为 kg/cm² 是"重量/面积"而非严格的 SI 压力）。

> 📎 背景补充 —— **有效应力（effective stress）**：讲义与录音都没有明确写出这个概念，但它是把"压力"和"变形"连起来的关键，且几乎必然出现在后续油气/储层内容中。太沙基（Terzaghi）有效应力原理：
> $$\sigma' = \sigma_{total} - P_{fluid}$$
> 即**岩石骨架真正承担的应力 = 总应力（≈静岩） − 孔隙流体压力**。这解释了本周两个现象：
> ① **超压 = 流体替岩石骨架分担了载荷** → 有效应力降低 → 骨架不被压实 → **欠压实（undercompaction）与异常高孔隙度得以保留**；
> ② **孔隙压力升至静岩时 $\sigma' \to 0$，岩石失去抗剪能力而破裂**——正是录音里"断层阀"的物理内核（水力压裂 hydrofracturing 也是同一原理）。

### C. 达西定律（📎 背景补充）

> 📎 背景补充：讲义只给出渗透率的**单位**（m² 或 Darcy），没有给出定义式。渗透率的定义来自**达西定律**：
> $$Q = \frac{k A}{\mu}\cdot\frac{\Delta P}{L} \qquad\text{或}\qquad v = -\frac{k}{\mu}\,\frac{dP}{dl}$$
> $Q$ 流量、$A$ 截面积、$\mu$ 流体黏度、$\Delta P/L$ 压力梯度、$k$ 渗透率。
> **1 Darcy ≈ 0.987 × 10⁻¹² m² ≈ 10⁻¹² m²**；油气储层常用 **毫达西 mD**。经验分级：<1 mD 极差（致密），1–10 mD 差，10–100 mD 中等，100–1000 mD 好，>1 D 极好。
> 注意 $k$ 只描述**岩石**的性质（与流体无关），流体的影响通过 $\mu$ 单列——这也是为什么同一块岩石对气的"流动能力"看起来比对油好。

### D. 孔隙度

$$\phi = \frac{V_p}{V_b} = \frac{\text{孔隙体积}}{\text{岩石总体积}}$$
无量纲，以分数或 % 表示。

> 📎 背景补充 —— **孔隙度—深度衰减**：录音只定性说了"随深度增加，孔隙空间趋于闭合"。定量上常用 **Athy 指数衰减律**：
> $$\phi(z) = \phi_0\, e^{-cz}$$
> $\phi_0$ 为地表初始孔隙度（砂岩 ~40%，泥岩 ~60–70%），$c$ 为压实系数（砂岩约 0.27–0.4 km⁻¹，泥岩更大约 0.5–0.8 km⁻¹）。含义：**泥岩比砂岩压实得快得多**——这正是"不渗透泥岩层封住流体、造成超压"的成因基础，与 Practical 结论 (a) 直接呼应。
> 渗透率随孔隙度的下降更快（常近似 $k \propto \phi^3$ 量级，Kozeny–Carman），所以**深部渗透率的崩塌比孔隙度的崩塌剧烈得多**，这正是"深部只能靠断层裂隙输导流体"的定量理由。

### E. Stokes 定律（讲义 slide 20）

$$V = \frac{(\rho_1 - \rho)\times g \times d^2}{18 \times \mu}$$

讲义给的参数与结果：

| 项 | 值 |
|---|---|
| 玄武质熔体密度 ρ | 2.65 g/cm³ |
| 熔体黏度 μ | 500 poise |
| 橄榄石 ρ₁ | 3.3 g/cm³ |
| 长石 ρ₁ | 2.6 g/cm³ |
| 晶体粒径 d | 5 mm |
| **橄榄石 V** | **1.8 × 10⁻² cm/s** |
| **长石 V** | **1.4 × 10⁻³ cm/s** |

**逐项核算**（CGS 单位：g、cm、s；1 poise = 1 g·cm⁻¹·s⁻¹，g = 981 cm/s²）：
- 橄榄石：$\Delta\rho = 3.3-2.65 = +0.65$；$d = 0.5$ cm
  $V = \dfrac{0.65 \times 981 \times 0.25}{18\times500} = \dfrac{159.4}{9000} = 1.77\times10^{-2}\ \mathrm{cm/s}$ ✓ 与讲义一致
- 长石：$\Delta\rho = 2.6-2.65 = \mathbf{-0.05}$
  $V = \dfrac{-0.05\times981\times0.25}{9000} = \mathbf{-1.36\times10^{-3}}\ \mathrm{cm/s}$ ——**数值大小与讲义一致，但符号为负**

**⚠️ 关键理解**：长石密度**小于**熔体密度，所以 $\Delta\rho < 0$，**长石不是沉降而是上浮（flotation）**！讲义只写了绝对值，容易被误读成"长石也沉降、只是慢一点"。老师口头也只说"橄榄石沉降速度比长石快得多"。**这个符号问题恰恰是斜长石堆晶（如 Bushveld 的斜长岩层）能出现在岩浆房上部的原因**，两周后讲层状侵入体时会用到。

**记忆要点**：$V \propto \Delta\rho$，$V \propto d^2$（**粒径的平方**，故粒径影响最大），$V \propto 1/\mu$。

  - 该区**左侧 = 纯固体岩石**；**区内 = 岩石 + 熔体共存**；**右侧 = 全部为熔体**。
  - **核心结论**："正常"地温梯度（craton、Phanerozoic 那几条）**不与该熔融区相交** → 不会自发产生岩浆。
  - **加水后，固相线大幅左移（向低温方向）**，熔融区平移到地温梯度能够相交的位置 → **俯冲带产生岩浆**。左移的幅度取决于加水量。

- **超压如何"看图识别"**（考试答题模板）：
  1. 把实测地层压力点画在同一张图上；
  2. 浅部点若**落在静水线上或紧贴其右** → 正常压力（normally pressured）；

  4. 偏离量的水平距离 = 超压值；
  5. 点若**逼近静岩线** → 接近破裂压力，钻井极度危险。
- **断层阀循环在此图上的轨迹**：从静水线出发，**沿水平方向向右爬升**至静岩线 → 破裂 → **水平方向瞬间跳回**静水线附近 → 重新爬升，形成**锯齿形（sawtooth）路径**。

### 1. 间歇泉（geyser）：贯穿全课的"热液系统总模型"
老师用冰岛式间歇泉把成矿全过程串了一遍，这是**理解后续所有热液矿床的母模型**：

> "间歇泉在地表喷出热水，那只是一整套**管道系统（plumbing system）的顶部**而已。"

完整链条：
1. **冷水从地表进入**地壳；
2. 因**浮力（buoyancy）**（冷、密度大）**下沉**；
3. 深部遇到**热源**——可以是**火山侵入体，也可以是一个花岗岩体**；
4. 水被加热 → 因浮力**上升**；
5. 上升途中，**热水有能力溶解地壳中的某些元素**（示意图上写的是 SiO₂，"但可以是任何元素"）；
6. 溶解后被**搬运**至浅部；
7. 只要有**沉淀机制**，元素就从流体中析出进入围岩 → **形成矿床**，且浓度远高于原始背景值。

**"hydrothermal"一词的字面来源**：**hydro（水）+ thermal（热）= 水中所储存的热能**。老师反复强调这个词源，因为它同时解释了热液为什么能"搬"（流动）又能"改"（溶解/沉淀/蚀变）。

### 2. 实例：北威尔士铜矿（North Wales copper deposit）
老师展示了一张手标本/露头照片：**所有绿色的部分都是含铜矿物**，是通过上述机制在**一个非常具体的位置**被浓缩起来的，并且已被人类开采。用来说明"这不是理论——地壳的质量迁移是真实可见的"。

### 3. "质量迁移（mass transfer）"是本课的核心动词
老师原话："我们处理的是**物质从地壳的一部分向另一部分的质量迁移**（a mass transfer of material from one part of the crust to the other），而这种质量迁移在很大程度上**依赖流体**。"

### 4. 关于地温梯度的口头强调
- **"克拉通因为老，所以冷"**——这是个因果链：老 → 放射性生热元素已大量衰变 + 岩石圈厚而稳定 → 热流低 → 梯度低。
- **"裂谷因为有大量热量可用，包括火山活动，所以热流高、梯度高"**。
- 两端元之间可以有连续变化的任意值。

### 5. 关于压力的口头强调（讲义上完全没有的关键句）
- **潜艇类比**：作用在海底潜艇上的是**上方水柱的重量**——这就是静水压力。
- **"绝不会有完全干燥的岩石，也绝不会有纯粹的流体"**（there will probably never be an entirely dry rock, and there will never be just fluid）→ **真实条件永远介于两个端元之间**。这句话是判断超压题目的思维起点。
- **"静岩压力就是岩石开始破裂的地方"**（lithostatic really is where the rocks then start to break）——**这是一条可以直接写进答卷的判据**。

### 6. 孔喉与曲折度（讲义只有图、无一字文字说明）
- 薄片照片解读：**蓝色 = 孔隙**、**灰色 = 砂岩颗粒**、**孔隙之间的窄通道 = 孔喉（pore throat）**、**黄色箭头 = 流体必须走的路径**。
- **"路径越曲折（tortuous），流动能力越低"**；直线路径 = 高渗透率，迂回路径 = 低渗透率。
- 这句话是把"孔隙度"与"渗透率"区分开的**最直观的物理图像**：**渗透率不由孔隙的多少决定，而由孔隙之间怎么连决定**。

### 7. 为什么垂直于主应力的面上不能滑动（课堂纸张演示）
这是本节课**唯一一段真正的推导**，讲义只有图：
- 取一个**垂直于 σ₃ 的面**：面上只受**正应力（normal stress）**，**没有剪切分量**。
- 因此**沿这个面无法移动任何东西——"物理上不可能"**（it's not possible, physically impossible）。
- **要产生滑动，面必须与主应力斜交**（oriented at an angle）→ 这就是断层的方位约束。
- **但是**——老师拿两张纸演示：双手作 σ₁ 水平挤压，σ₃ 最小 → 两张纸之间会**被撑开一个空隙**。也就是说，**这个不能滑动的面，却可以被张开**，形成**透镜状的裂隙（fracture）**。
- **"没有任何位移，纯粹是把空间打开而已"**（there's no movement, it's just you're opening up space）。
- **裂隙一旦被流体中沉淀的矿物充填 → 脉（vein）**。老师特别提示：**"vein 这个词会在接下来的课里反复出现。"**

**这段推导的意义**（老师自己点明）：**我们可以用最基本的岩石变形物理学，去预测流体在地下如何运移**——至少在小尺度上。断层与裂隙是流体运移的关键。

### 8. 深部：孔渗关闭，断层裂隙成为唯一通道
"在浅部我们有孔隙度、有渗透率；越往深，由于上覆载荷，这些都会大幅降低，开放孔隙倾向于被压闭。这时**断层与裂隙就真的是你搬运流体的唯一机制了**。"

→ **这一句是理解"深部热液脉状矿床为什么都沿构造分布"的钥匙。**

### 9. 断层阀循环与地震（讲义上只有一张无字图）
完整口述见第二节 3(e)。老师的收尾定位很重要：

> "这就是**地震、断层活动与流体运移之间存在相互作用**的一种方式……对于**预测流体行为、预测元素质量迁移的机制**非常重要。"

### 10. 课堂互动：如何在深部创造空间？
- 老师提问后，有学生答 **erosion（侵蚀）**。
- **老师明确否定**："侵蚀显然不是在深部……**侵蚀是地表过程**。但在深部，比如说 2 km 深，特别是有流体、有热流体参与的时候……"
- **正确答案：溶蚀（dissolution）**。"许多这类流体是**腐蚀性的（corrosive）**，它们会**溶解掉一部分岩石**。如果**流体成分与围岩之间存在不平衡（disequilibrium）**，流体就会腐蚀、溶解围岩。**当流体又热又暖时尤其如此**。"
- 结论：**造空间至少两条路——张裂隙成脉（力学）+ 溶蚀（化学）**。

> 这是一个**典型的口试/简答题**：Name two mechanisms by which space is created in the subsurface for mineral precipitation. 答案就是这两条，且**"侵蚀"是明确的错误答案**。

### 11. 关于流体分类的口头补充
- **建造水/同生水（connate / formation water）**："是沉积盆地中流体的一个**总括性术语（overarching term）**，代表**许多不同来源的混合**——地表水、其它矿物的溶解、岩浆流体、出溶的岩浆流体……**它就是沉积盆地里高盐、非常咸的流体的混合体**。"
- **海水**："可以**沿断层**进入地壳。"
- **岩浆本身就是一种流体**："molten rock is one type of fluid"。
- 岩浆中溶解的**主要挥发分是水**，其次是 CO₂、SO₂ 及其它气体。

### 12. 为什么矿床分类中"热液"取代了"变质"
见第二节第 9 点。老师的原话逻辑：热液流体**既能搬运物质，又能溶解、沉淀、蚀变岩石，这等价于变质作用中发生的事**（equivalent to what happens in metamorphic processes），所以**"热液成为资源矿床非常重要的第三大类"**。

### 13. 关于加水熔融的额外因果（讲义只列了机制名）
- **加水的效果 = 把熔融区（固相线）向低温方向平移**，平移幅度取决于加水量 → 地温梯度得以与之相交 → **产生熔体**。
- **老师额外点出的"副产品"**：既然水被加进了地壳并进入熔体，**这就解释了为什么熔体本身含水作为挥发分**——而这又是下周"岩浆出溶热液"的前提。**这是一条完整的因果链，值得整条记下来。**

### 14. Bowen 系列的口头版本
"橄榄石先结晶 → **下沉到底部** → 熔体因此**Fe、Mg 变少、SiO₂ 变多** → 于是熔体转而与**辉石**平衡 → 辉石在更低温结晶 → 如此往复直到**石英**。整个过程中，**熔体和晶体的成分都在持续变化**。"

### 15. Stokes 定律与堆晶的因果收束
"把这些数字代入 Stokes 定律……**5 mm 的橄榄石沉降速度远高于长石**……最终产物就是：粉色的是熔体（液体部分），其余全是**在熔体底部堆积起来的固体晶体，即堆晶（cumulate）**。"
→ **"正因为有沉降和 Stokes 定律控制的堆晶作用，才可能在岩浆房底部富集矿石矿物"**——两周后讲层状侵入体（Bushveld 型 Cr、PGE）时直接调用。

### 16. 老师明确的"记住这个"提示（等于考试提示）
- **"记住这些关于元素亲和性的基本概念——这张 lithophile vs chalcophile vs siderophile 的图——以及相容性的概念。这些是我们整门课都会反复回来用的概念。"**
- **"vein 这个词会一遍又一遍地出现。"**
- 铀被单独点名：**"U 是不相容元素，会在熔体中留存很久"**——后面铀矿周会直接用到。

**成因解释**（与讨论文件一致）
- **(a) 不渗透层阻止了流体排出 → 欠压实（undercompaction）**：孔隙水来不及排出，替岩石骨架分担了上覆载荷（即 📎 有效应力降低）。
- **(b) 烃类充注（charging by hydrocarbon）**：这本来就是一口**气井（gas well）**，油气进入孔隙会抬高孔隙压力。
- 我补充的支持证据：2500–3000 m 段梯度回落到 ~9.8 MPa/km（近静水），说明该段孔隙流体在**内部是连通**的（同一压力隔间/compartment 内按流体密度梯度增压），这正是"被顶部封隔层封闭的独立超压隔间"的特征。

**题干中"2.3 g/cm³"的正确理解**（易被误读）
instructions 写："The value of 2.3 g/cm³ is assumed to be the maximum overpressure that can be encountered before rupture." 严格说这句话表述有误（2.3 g/cm³ 是密度不是压力，见勘误表）。**正确含义是：用 2.3 g/cm³ 算出的静岩（破裂）压力，是岩石破裂之前孔隙压力所能达到的上限**——与讲义"静岩就是岩石开始破裂的地方"是同一句话。

### 评分/答题要点（我的归纳）
1. **画图**：一张图上必须同时有 **实测点、静水线、静岩线** 三条，纵轴深度**向下**，横轴压力。
2. **单位换算**：题目两次强调 "Mind the conversion!"，`/10` 因子和 `1 kg/cm² = 98,066.5 Pa` 是**明确的得分点**。
3. **地温梯度必须强制过地表温度**，并说明为什么。
4. **必须识别出折点位置**（温度题在 ~3500 m，压力题在 1500–2000 m），并给出**地质解释**（断层/热流；封隔层/烃类充注），而不只是报数字。
5. **把结果与"含义"连起来**：温度题 → 地热潜力；压力题 → 钻井安全（泥浆密度）与油气封闭性。

## 六、易错点 / 重点难点

### 1. 静岩压力 ≠ 静水压力，且二者不可混用
| | 静岩 lithostatic | 静水 hydrostatic |
|---|---|---|
| 承压介质 | **岩石柱** | **连通流体柱** |
| 密度 | 2.3–2.7 g/cm³ | 1.0–1.1 g/cm³ |
| 梯度 | ~22–26 MPa/km | ~9.8–10.8 MPa/km |
| 别名 | 围压 confining stress、上覆压力 overburden | 正常地层压力 |
| 物理意义 | 压力上限 / **破裂条件** | 压力下限 / **正常压力基线** |

- **同深度静岩约为静水的 2.5 倍**（用讲义的 2.5 vs 1.0）。
- **超压的分母永远是静水，不是静岩**：`超压 = 实测 − 静水`。
- **写 "confining pressure" 时指的是静岩，不是流体压力**——这是最常见的术语混用。

### 2. 超压的误判
- ❌ 只看到"压力随深度增加"就说超压——压力本来就随深度增加。**必须与同深度的静水线比较**。
- ❌ 只看单点绝对值。应看 **实测/静水比值** 或 **等效流体密度（10P/z）**，才能跨深度比较。
- ❌ 忽略折点。**超压的诊断特征是压力—深度曲线上出现"斜率突变 + 向右偏移"**，而不是任一深度的高读数。
- ⚠️ 别把 **实测 > 静岩** 当成正常结果——那意味着岩石早该破裂了。若算出这种结果，**先怀疑单位换算**。
- ⚠️ 也存在**欠压（underpressure）**：实测低于静水（抽采枯竭、隆升冷却）。本周材料未涉及，但概念上是超压的镜像。

### 3. 单位与量级——本周失分重灾区
- **kg/cm² 与 MPa**：`1 kg/cm² = 0.098 MPa ≈ 0.1 MPa`。粗算时"kg/cm² 除以 10 得 MPa"是安全的近似。
- **`/10` 因子只在 `kg/cm² = ρ·z/10` 这个式子里成立**（ρ 用 g/cm³、z 用 m）。**换成 Pa 就必须老老实实用 $P=\rho g z$（SI 单位）**，两套不能混。
- **地温梯度**：`°C/km` 还是 `°C/m`？ 25 °C/km = 0.025 °C/m。**答案落在 10–40 的量级才是 °C/km**；如果算出 0.02 而写成 °C/km，或算出 20 而写成 °C/m，都是量级错误。
- **深度别忘了换算**：`24 °C / 1515 m` 得到 0.0158 °C/m，写成 °C/km 必须 ×1000 = 15.8。
- **kbar 与 GPa**：1 kbar = 0.1 GPa = 100 MPa。讲义图 1 的 18 kbar = 1.8 GPa。

### 4. 孔隙度 vs 渗透率——概念不可互换
- **孔隙度 = 体积比（无量纲，储存能力）**；**渗透率 = 流动能力（m² 或 Darcy）**。
- **二者不总是正相关**！经典反例：
  - **泥岩/页岩**：孔隙度可高达 30–50%，但**孔喉极细、连通极差 → 渗透率极低**（这正是它能当**盖层/压力封隔层**、造成超压的原因）。
  - **浮岩/火山渣**：孔隙度极高，但气孔**彼此不连通** → 渗透率低。
  - **裂缝性致密灰岩/花岗岩**：基质孔隙度可能只有 1–2%，但**裂缝网络使渗透率极高**。
- 记忆句：**"孔隙度看有多少房间，渗透率看门有多宽、走廊通不通。"** 老师的原话版本是**"曲折度（tortuosity）"**。
- ⚠️ 还要区分**总孔隙度（total）与有效孔隙度（effective，即连通的那部分）**——只有有效孔隙度才与渗透率相关。📎 此区分为背景补充，讲义未提。

### 5. 脆性/韧性的条件容易记反
- **脆性 = 低 T、低围压、高应变速率、浅部 → 断层**
- **韧性 = 高 T、高围压、低应变速率、深部 → 褶皱**
- 注意**应变速率的方向是相反的**（脆性对应"高"应变速率）——这一项最容易记反。

### 6. 断层 vs 裂隙的力学区别（本周独特考点）
- **断层（fault）**：面与主应力**斜交**，有**剪切分量**，两侧岩块**有位移**。
- **裂隙（fracture）**：面**垂直于 σ₃**，只有**正应力、无剪切**，**没有位移**，只是**被拉开的空隙**。
- **脉（vein）= 被矿物充填的裂隙**，不是断层。
- ❌ 常见错误："裂隙是小断层"——**不是**，二者的力学成因根本不同。

### 7. "创造空间"的错误答案
- ❌ **侵蚀（erosion）**——地表过程，深部不适用（课堂上被明确否定）。
- ✅ 张开裂隙/断层（力学）+ 溶蚀（化学，腐蚀性热流体与围岩不平衡）。

### 8. Stokes 定律的符号
- $\Delta\rho = \rho_{crystal} - \rho_{melt}$，**正值下沉、负值上浮**。
- 讲义给的长石 1.4×10⁻³ cm/s 实际是**负值**（长石 2.6 < 熔体 2.65）→ **长石上浮**。别背成"长石缓慢下沉"。
- $V \propto d^2$——**粒径翻倍，速度变 4 倍**，粒径的影响远大于密度差。

### 9. 相容/不相容 与 亲石/亲铁/亲硫 是两套独立的分类
- **亲和性（affinity）**：决定元素**倾向于哪一类熔体/相**（硅酸盐 / 金属铁 / 硫化物）。
- **相容性（compatibility）**：决定元素在**结晶过程中进晶体还是留熔体**，由分配系数（电荷 + 半径）控制。
- 两者会给出一致的结论（如 U：亲石 + 不相容 → 富集在最晚期的长英质熔体/花岗岩），但**不是同一个概念**，答题时不能互相替换。

### 10. 同生（syngenetic）vs 后生（epigenetic）
- **同生 = 与围岩同时形成**（火成矿床、沉积矿床）
- **后生 = 晚于围岩形成**（热液矿床、岩浆热液矿床、表生矿床）
- 这两个词在后续每一周的矿床描述中都会出现，**必须张口就来**。
