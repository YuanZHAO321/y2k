## 二、核心概念

### 2.1 石油是什么：有机地球化学基础

石油是**多种有机化合物的混合物**，主体是简单与复杂烃类，另含 S、O、N 及少量金属。讲义给出四大组分及其含量区间（**这组数字要背**）：

| 组分 | 英文 | 通式 / 结构 | 含量 |
|---|---|---|---|
| 环烷烃（"环烷"） | Cycloalkanes / Naphthenes | 一个或多个碳环 + H，Cₙ H₂ₙ | **30–60%** |
| 烷烃（"石蜡"） | Alkanes / Paraffins | C–C 单键直链 + H，Cₙ H₂ₙ₊₂ | **15–60%** |
| 芳烃 | Arenes / Aromatic hydrocarbons | 苯环（C₆H₆）+ 可能连接的其他烃基 | **3–30%** |
| 沥青质 | Asphaltenes | 含 C, H, N, O, S, V, Ni 的复杂有机物，C:H ≈ 1:1.2 | 其余 |

讲义用一张**三端元三角图**（Arenes–Alkanes–Cycloalkanes 三个 100% 顶点）表示不同原油的组成落点。

**相态与 API 度。** 地表与地下的相态取决于各化合物的沸点，故分为气、轻质油、中质油、重质油、沥青。原油按**美国石油学会重度（API Gravity）**分类：

| °API | 比重 SG | 密度 kg/m³ | 分类界线 |
|---|---|---|---|
| 8 | 1.014 | 1012 | 沥青 |
| 9 | 1.007 | 1005 | |
| **10** | 1.000 | 998 | **= 水** |
| 15 | 0.966 | 964 | 重质油（heavy） |
| 20 | 0.934 | 932 | |
| **22** | — | — | **重/中界线** |
| 25 | 0.904 | 902 | 中质油（medium） |
| **30** | 0.876 | 874 | **中/轻界线** |
| 40 | 0.825 | 823 | 轻质油（light） |
| 50 | 0.780 | 778 | |

**规律**：API 度**越低** → 比重越大 → 碳链越长 → 黏度越高 → 越难开采 → 越需**裂化（cracking）**才能商用；API 度**越高**（及天然气）→ 黏度低 → 易开采 → 用途多、所需裂化少。

> 📎 背景补充：讲义未给 API 定义式。**°API = 141.5 / SG(60 °F) − 131.5**。我按此式逐行核算了讲义表格：20°→0.9340 ✓、30°→0.8762 ✓、40°→0.8251 ✓、50°→0.7796 ✓、8°→1.0143 ✓；密度列 = SG × 998 kg/m³ 也吻合（0.934×998 = 932.1 ✓）。**该表内部完全自洽。** "10 °API = 水"是定义的直接推论（SG=1 时 API=10），记这一条比背整表省力。

**用途。** 家庭与工业燃料、塑料、医药原料——石油不只是燃料，更是**整个化工体系的原料**，这在讨论能源转型时是关键论点。

### 2.2 石油系统（Petroleum System）——本周骨架

老师把整节课组织成"石油系统的要素与过程"，**必背结构**：

**必要要素（necessary elements）：**
1. **源岩（source rock）**——有机质在此沉积富集
2. **储层（reservoir rock）**——孔隙且渗透，烃类最终储存处，也是钻井目标
3. **盖层（seal rock）**——不渗透，把烃类封在地下
4. **上覆岩层（overburden）**——提供把有机质"煮"成油气所需的压力与温度

**必要过程（necessary processes）：**
1. **圈闭形成（trap formation）**
2. **生烃（generation of hydrocarbons by maturation）**
3. **运移与在圈闭中聚集（migration and accumulation）**

老师反复强调的一句话：**这些要素与过程必须全部到位，石油系统才"working"**；而且**必须按正确的时间顺序发生**（见 §3.4 事件图与"关键时刻"）。

> 📎 背景补充：中文教材常把这套要素概括为"**生（源）—储—盖—圈—运—保**"六字诀。讲义的四要素三过程与之基本对应，只是把"保存（preservation）"隐含在圈闭与盖层的有效性里；不过老师在讲事件图时确实把 preservation 单独列为图上的一行。

### 2.3 源岩：有机质的生产与保存

**定义：TOC（total organic carbon，总有机碳）≥ 1% 的岩石就是源岩。** 老师把这个门槛说了两遍，是硬考点。

有机质来源（讲义）：**蛋白质**（动物组织、酶）、**碳水化合物**（动物组织）、**脂类**（藻类、花粉、孢子）、**木质素**（植物组织）。

**能否富集取决于三组竞争因素**（讲义引 Walters 2017）：

**(1) 生物生产力（biological productivity）——正面因素。** 核心机制是光合作用：
> 6CO₂ + 6H₂O → C₆H₁₂O₆ + 6O₂

向右 = **碳固定（C fixation）= 生产力**；向左 = **碳氧化 = 呼吸、再矿化（remineralization）、燃烧**。老师一句话结论：**要让这个平衡尽量往右。** 讲义用海洋叶绿素图（红 = 高）+ 陆地植被指数图说明分布；南美东、西两岸近海叶绿素都高——沿岸带是有机质生产的热点。**上升流（upwelling）**：离岸风把表层水吹走、深层水上涌补充，上涌水**富含营养盐**，驱动强烈的初级生产力（南美西岸、非洲西南岸）。

**(2) 保存（preservation）——决定性因素。** 有氧条件下有机质极易被氧化再矿化，**光有生产力不够，必须隔绝氧气**，因此沉积物的**氧化还原条件（redox conditions）**是关键。两种造缺氧机制：
- **氧最小带（oxygen minimum zone, OMZ）**：上升流带的高生产力本身耗氧，在水柱中形成极低氧的带——**高生产力与低氧在同一地点叠加**，保存潜力最高（美洲西岸、阿拉伯—波斯湾、非洲西岸）。
- **受限盆地（restricted basin）**：**海槛（sill）**部分或完全隔断盆地与外海 → 水体交换受限；淡水注入形成低密度表层水，与下部高盐水**密度分层（stratification）** → 底层贫氧水被困住 → 缺氧（**黑海、波罗的海、地中海**）。老师提醒：**不是只有开阔大洋才有源岩**，受限盆地同样重要。

**(3) 沉积稀释（sediment dilution）——负面因素。** 黏土、砂等非生物碎屑同时沉积会稀释有机质，使 TOC 达不到 1%；源岩因而多发育在碎屑输入低、水动力弱的环境。

**判断源岩的三问**：产得多吗？保得住吗（缺氧否）？被稀释了吗？

### 2.4 成熟（Maturation）：从有机质到油气

关键驱动是**埋藏带来的温度升高**（上覆岩层增加 → 压力升高 + 温度升高）。**讲义与老师给出的温度分带（必背，考试高频）**：

| 温度区间 | 阶段 | 过程与产物 |
|---|---|---|
| **< 40–80 °C** | **成岩作用 Diagenesis** | 有机质经厌氧与非生物作用分解，失去 H₂O、CH₄、CO₂、O → 形成**干酪根（kerogen）**；**尚未生成液态油气** |
| **> 40–80 °C** | 干酪根开始裂解 | 干酪根本身开始分解 |
| **100–150 °C** | **生油窗 Oil window**（属于 Catagenesis 后生作用） | C–C 键断裂，长链断成短链（如 C34 → C3 …）→ **生成液态油** |
| **150–200 °C** | **生气窗 Gas window** | 链继续变短，并**脱氢**，最终剩下 CH₄ → **天然气** |
| **> 200 °C** | **过成熟 Overmature** | 只剩纯碳 → **石墨**；岩石被"煮过头"，一无所有 |

> 📎 背景补充（务必与讲义区分）：**讲义给的 100–150 °C / 150–200 °C 是本课的教学口径，考试按这个答。** 但国际文献常用的区间略宽且偏低：生油窗约 **60–160 °C**（很多教材写 60–120 °C 为主生油期），凝析油/湿气约 150–180 °C，干气窗可延伸到 200 °C 以上。差异来自"温度—时间可以互换"——低温 + 长时间与高温 + 短时间可以达到同样的成熟度（见 §3.5 TTI）。**若考题问区间，写讲义数字；若问"为什么不同文献数字不同"，答时间—温度补偿效应。**

> 📎 背景补充：讲义只在图题里出现了 "Catagenesis" 一词，没有展开完整的三阶段命名。标准命名是：**Diagenesis（成岩，生物气/干酪根形成）→ Catagenesis（后生，生油 + 湿气）→ Metagenesis（变生，干气 + 石墨化）**。

**干酪根类型（Van Krevelen 分类）——本周最高频考点之一：**

| 类型 | 母质来源 | 化学特征 | 沉积环境 | 主要产物 | 实例 |
|---|---|---|---|---|---|
| **I 型** | 藻类（algae） | 富脂类（脂肪、油、蜡），**H/C 最高、O/C 最低** | **陆相/湖相**（continental, lakes） | **主要生油** | 油页岩，如始新统 **Green River Fm.** |
| **II 型** | 藻类 + 浮游动/植物（zoo-/phytoplankton） | 富脂类，中等 H/C | **海相** | **油 + 气** | 侏罗系 **Kimmeridge Clay** |
| **III 型** | 陆生高等植物 | **腐殖型（humic）**：木质素、单宁、纤维素，H/C 低、O/C 高 | 三角洲/沼泽 | **主要生气** | **煤（coals）** |

老师强调的两条规律：
1. 三种干酪根**起点不同**，但成熟过程**都脱氧脱氢**，故在 Van Krevelen 图上**都朝左下角收敛**，终点同为石墨。
2. 口诀：**藻类 = 油，陆生植物 = 气，海相混合 = 油气兼有**；I 型湖相、II 型海相、III 型陆源。

> 📎 背景补充：材料**未讲 IV 型干酪根**。IV 型（惰性组 inertinite）是再循环/氧化过的有机质，H/C < 0.5，**基本不生烃**。
> 📎 背景补充：材料**完全没有提到镜质体反射率 Ro（vitrinite reflectance）**——最常用的成熟度指标：未成熟 Ro < 0.5–0.6%；**生油窗 Ro ≈ 0.6–1.35%**；湿气/凝析 1.35–2.0%；干气 2.0–3.0%；过成熟 > 3%。本课不太可能考细节，但论述时提一句能加分。

### 2.5 排烃与运移（Expulsion & Migration）

老师的因果链：
1. **同一套温压条件既生烃也排烃**——压力驱动烃类**排出（expulsion）**源岩，此区域即**"厨房"（kitchen area）**；
2. 排出后在**浮力（buoyancy）**作用下向上运移；
3. 沿**渗透的输导层（carrier beds）**（如砂岩层）运移；
4. 直到遇上**不渗透盖层 + 上凸构造** → 停止、聚集；
5. **若无圈闭，烃类一路升至地表散失到大气中。**

> 📎 背景补充：材料把排烃与运移讲成一个连续过程，未用标准术语。正规区分：**初次运移（primary migration）**＝从源岩内部排出进入输导层；**二次运移（secondary migration）**＝在输导层/储层中沿浮力方向的长距离流动；三次运移＝圈闭破坏后的再运移。
> 📎 背景补充：材料未讲**毛细管压力（capillary pressure）**，但它是盖层封闭的物理核心。烃柱浮力产生的向上压差 Δp = (ρ_w − ρ_o)·g·h；盖层可承受的最大压差为**排替压力**，由最大连通孔喉半径经 p_c = 2σcosθ / r 决定。**盖层封闭的本质不是"零渗透"，而是孔喉太细、毛细管阻力大于烃柱浮力**；当 h 超过临界值盖层被"顶穿"——这正解释了老师说的 "seals may leak"。

### 2.6 盖层（Seal）

**定义（老师原话的意思）：储层之上任何不渗透的岩性，阻止烃类继续向上浮升。** 典型岩性：**页岩、泥岩、蒸发岩（盐）**。

**渗漏（leakage）与油苗（seeps）**：现实中盖层常常不完美，**裂缝与断层**会让烃类继续上漏到地表。老师给了两个例子：
- **陆上油苗**：野外露头层状岩石中的裂缝里渗出黑色沥青质物质；
- **海上油膜（slicks）**：烃类穿过海底、经水柱到达海面形成油膜，**可由卫星影像探测**。

**双重意义（老师明确点出，是很好的考点）**：渗漏一方面是坏消息（说明封闭失效），另一方面**是绝好的勘探线索**——它证明地下确实有在工作的石油系统，勘探者只需要去找**没有漏**的地方。讲义因此把"airborne detection of surface seeps"列为勘探手段之一。

### 2.7 储层（Reservoir）

**定义：既有孔隙度（porosity，储集能力）又有渗透率（permeability，流动能力）的沉积岩。** 老师强调这是**两个独立的性质，缺一不可**。

**沉积环境**（决定原生孔隙）：湖相（lacustrine）、河流相（fluvial）、风成（aeolian）、浅海（shallow marine）、深海（deep marine）。主要岩性是**砂岩**与**石灰岩**。薄片下的判读：砂岩薄片中白色为石英颗粒、**蓝色（染色环氧树脂）为孔隙**；灰岩薄片中棕色为颗粒、蓝色为孔隙。

**孔隙网络类型（讲义配图 + 老师逐个讲解，必背分类）：**

**原生孔隙（primary porosity）**——反映沉积时的原始状况（沉积环境、水动力能量）：
- **粒间孔（interparticle）**：颗粒之间的孔隙（图示比例尺 2 mm）
- **粒内孔（intraparticle）**：颗粒内部的孔隙，老师用一个**腹足类壳（gastropod shell）**举例——生物原来居住的房室现在是空的、充气的（2 mm）

**次生孔隙（secondary porosity）**——反映后期成岩作用（胶结、压实、溶解）：
- **铸模孔（mouldic）**：颗粒（如**鲕粒 ooid**）被整体溶解留下的模子（0.5 mm）
- **晶间孔（intercrystalline）**：晶体之间的孔（0.2 mm）
- **溶洞/晶洞孔（vuggy）**：颗粒与基质被无规则溶解形成的不规则大孔（0.5 mm）
- **裂缝孔（fracture）**：裂缝**既造孔隙也造渗透率**——老师特别强调"沿裂缝让流体流动是非常容易的"，所以裂缝对渗透率的贡献往往比对孔隙度的贡献重要得多

> 📎 背景补充：材料点到了"cementation, compaction, dissolution"这三个成岩过程但没展开。要点：**压实（compaction）**随埋深机械减孔（颗粒重排、点接触→线接触→缝合接触），是浅部主控；**胶结（cementation）**用石英次生加大、方解石、白云石等填充孔隙，是深部主控；**溶解（dissolution）**（常与有机质成熟释放的有机酸和 CO₂ 有关）反过来创造次生孔隙。三者共同决定"储层质量随深度的演化"。

### 2.8 圈闭（Trap）

**定义：储层与盖层组成的一个上凸（convex-up）组合，阻止烃类继续上升到地表。**

**圈闭内部结构（术语必须精确，老师专门花时间讲了一页 nomenclature）：**
- 自上而下按密度分层：**气顶（gas cap）→ 油层（oil zone）→ 水层（water zone / aquifer）**。原因：气最轻在顶，水最重在底。
- **溢出点（spill point）**：圈闭能容纳烃类的最低点；低于此点的流体会**溢出（spill over）**到下一个构造去。
- **闭合度（closure）**：构造最高点与溢出点之间的**垂直距离**——它决定了这个圈闭最多能装多高的烃柱。
- **油水界面（OWC, oil–water contact）**：讲义的测井图上标出了 OWC。

**圈闭分类（考试必背两大类）：**

**A. 构造圈闭（structural traps）**——由岩石变形造成：
1. **背斜（anticline）**：最经典。讲义/老师的例子是**逆冲断层相关的背斜**（thrust-related fold）——侧向挤压（如造山带）使岩层变形，断层下盘地层连续，上盘（hanging wall）形成背斜，油气聚在背斜顶部。
2. **掀斜断块（tilted fault blocks）**：伸展**断层**分割的断块，每个断块内都是"多孔砂岩 + 上覆页岩"的组合；油气聚在断块顶部的三角形区域内——**顶上是同一断块内的页岩，侧向是断层另一侧断块的页岩**，形成侧向封堵。这就是**断层封闭性（fault seal）**的实例。
3. **盐相关圈闭（salt domes / salt diapirs）**：地下盐层在上覆负荷下、因**密度倒转产生的浮力**而向上流动，形成盐丘/盐底辟。盐是不渗透岩性，可在盐"伞盖（canopy）"之下形成圈闭。

**B. 地层圈闭（stratigraphic traps）**——由沉积作用本身造成，不需要变形：
1. **河道砂体（channel sand）**：曲流河河道充填的砂体（多孔），河岸两侧是细粒页岩/泥岩；河道被埋覆后，砂体被页岩**完全包裹**，自成一个封闭单元。
2. **不整合圈闭（unconformity trap）**：下部倾斜地层 → 时间间断（不整合面）→ 上覆水平泥岩；油气被封堵在**不整合面之下**。

老师的结论：**预测这些结构需要构造地质学 + 沉积学 + 地层学的综合**，而且我们看不见地下，只能靠地表数据重建——所以**预测圈闭是石油勘探中最难的一环**。

### 2.9 保存与"时序"问题

老师用一个反例讲透了保存的本质：**如果烃类生成并运移的时候圈闭还没形成，烃类就会一路跑到地表散失，什么都留不下。** 因此石油系统各要素**不仅要齐全，还要按正确的顺序出现**——这就引出了事件图与**关键时刻（critical moment）**（详见 §3.4）。

> 📎 背景补充：材料没有系统讲"破坏因素"。除时序错配外，常见的保存破坏还包括：**抬升剥蚀**（圈闭被剥开、压力降低导致脱气）、**生物降解（biodegradation）**（浅埋、温度 < 约 80 °C 时细菌选择性消耗正构烷烃，使原油变重变稠、API 度下降——**油砂/焦油砂就是这样形成的**）、**水洗（water washing）**、**盖层被断层错断**、**过成熟裂解成气**。这也解释了为什么加拿大 Athabasca 油砂是重质、低 API 的。

### 2.10 勘探（Exploration）

老师给的是一条**从大到小、从便宜到昂贵**的漏斗式流程：

**第一步：区域背景（regional context）**
- 理解全球/区域**沉积格局**，预测源岩与储层可能分布在哪里；
- 找盆地边缘**露头（outcrop）**——地下的目标层在盆地边缘往往出露地表，可直接观察和刻画。老师的例子：**阿曼（Oman）**内陆是大型油气产区、一切都在地下，但向东至海岸带这些层位出露地表，可做露头研究。
- **沉积分析**：如摩洛哥/西北非的岩相分布图（蓝色 = 灰岩、绿色 = 泥灰岩与细粒碳酸盐、黄色 = 砂岩即潜在储层）；
- **构造分析**：断层与背斜的方位与样式，用于预测地下可能的圈闭走向。

**第二步：地球物理（geophysics）**
- **地震（seismic）**：给出地下大尺度构造、盆地沉积充填史、断层与背斜、盐层的识别——**核心用途是识别圈闭**；
- **磁法与重力/密度测量**：刻画地下的**构造格架（structural grain）**；
- **航空油苗探测**（尤其海上油膜）。

**第三步：钻井（drilling）**——"唯一能真正证实有没有聚集的手段"
- 井提供的是地下的**一维视图（1D view）**；
- 常规井深/井长可达 **< 8 km**；
- 可垂直钻，也可**水平钻（horizontal drilling / 'geosteering' 地质导向）**；
- 取心（core）：直接看岩石、测**孔隙度与渗透率**；
- **电缆测井（wireline logging）**：把探头（sonde）下入井中、上提时连续记录地层物性。讲义测井图上的道有：**自然伽马 GR（区分砂岩与页岩，接上周铀/放射性内容）、井径 caliper、密度 RHOB、中子孔隙度 NLIM、有效孔隙度 PHIE、深浅电阻率 R55/R25（识别烃类）、含水饱和度 SW、泥质含量 VSH**，并标出了 **Forties** 层与 **OWC**。

### 2.11 生产（Production）与产业结构

- 地面/海上设施：生产井、管线；海上平台（例：埃及）与陆上生产设施（例：英国南部 **Wytch Farm** 油田）。
- **规模感**：老师把阿尔及利亚的一个气田轮廓叠在伦敦地图上——**油气田的平面尺度与一座大城市相当**。
- **最小化环境足迹**：事前的**环境影响评价（EIA）**、**海底（subsea）远程作业**（海面只有一个设施，海底靠管线与无人潜器 ROV 运维）、**水平钻井**（一个井场控制大面积储层）。
- **持续的地质/油藏研究**：生产期间数据不断进来，用于**更新地下地质模型**。
- **常规资源开采**：一次采油（primary recovery，自然能量自流）或二次采油（secondary，注水/注气）。
- **非常规资源（unconventional）**：**油页岩/页岩气（"压裂 fracking"）、焦油砂（tar sands）**。（讲义仅列出名称，**老师课上没有展开讲非常规**——考试若考细节，需另找材料。）
- **公司结构**：
  - **上游 UPSTREAM**：勘探（A）、油田开发（B）、生产（C）、油砂开采（D）、沥青提取（E）、天然气液化 LNG（F）、LNG 再气化（G）、气制液 GTL（H）；
  - **下游 DOWNSTREAM**：炼油（J）、石化产品（K）、生物燃料（L）、贸易（M）、零售（N）、供应与分销、B2B 销售、CO₂ 排放管理；
  - **新能源**：风、太阳能、地热、**CCS（碳捕集与封存）**、风电（I）。

### 2.12 储量的所有权与能源转型

**讲义给出的储量所有权结构（重要且反直觉）：**
- **88% 由主权国家拥有**；
- "自由市场"公司只能接触 **16%**；
- **6%** 由俄罗斯新兴公司持有（"准自由市场 quasi-free"）；
- **即使是全球最大的上市石油公司 Exxon，也只能接触全世界不到 1% 的石油。**
- **IOC（国际石油公司/"majors"）**：股东所有、跨国经营，常与 NOC 合作——Exxon、Shell、BP、Chevron、Total；
- **NOC（国家石油公司）**：政府所有——Saudi Aramco、Sonangol、PDO（阿曼）、PDVSA（委内瑞拉）。

（⚠️ 这组百分比加起来超过 100%，见文末勘误表。）

**环境与社会（讲义 + 老师的双层论述，论述题模板）：**

**层次一：产业活动本身的环境影响。** 一切工业活动都有环境影响，且通常是负面的：产生有毒物质、破坏环境、噪声、伤害野生动物、**也伤害在设施上工作的人（这是危险的工作）**。潜在危害"enormous"——以 **2010 年墨西哥湾事故**为例。正因如此，石油工业在 **HSE（健康、安全、环境）**方面受到极严格监管；讲义还给出一个值得注意的观点：**坏的 HSE 实践对生意本身也是坏事，所以石油工业在安全与环保实践上常常走在政府前面。**

**层次二：使用产品造成的影响——全球变暖。** 生产与燃烧石油打破了自然碳循环的平衡；老师用近百年大气 CO₂ 浓度曲线说明这一点。但同时：
- 化石燃料**不会一夜消失**，只能**逐步淘汰（phased out）**，因为整个工业经济模型高度依赖它们；
- 它们**仍然相对便宜**，是许多发展中国家**脱贫**的手段；
- 讲义补了一条老师没说的：石油生产与出口也**常常伴随腐败**。

## 三、公式与图表

### 3.1 埋藏史曲线（Burial history plot / burial graph）——本周核心图件

这是本周必须能**画、能读、能解释**的图（周四实习就练这个）。

**图的构造：**
- **横轴：时间（geological time）**，通常**从左向右由老到新**，右端为现今（0 Ma）；
- **纵轴：深度（depth，向下为正，即深度向下增加）**，通常从 0 到几千米；
- 图中每一条线代表**一个地层单元的顶（或底）面随时间的埋深轨迹**。一条线从"位于地表（深度 = 0）"开始，随着上覆新地层不断叠加而向下、向右延伸。

**如何读斜率——这是最容易读错的地方：**
- 曲线上任一点的**斜率 = 沉降/埋藏速率（subsidence / burial rate，单位 m/Myr）**；
- **陡（接近垂直）= 快速埋藏**；**缓（接近水平）= 埋藏停滞**；
- **水平段**代表沉积间断/不整合（无净沉积）；
- **曲线向上折返**代表**抬升与剥蚀（uplift & erosion）**——深度变浅。
- ⚠️ **斜率读的是"速率"，不是"深度"**。深度要在纵轴上读点的位置，速率要看线的倾斜程度。

**如何叠加温度信息：**
- 在图上叠加**等温线（isotherms）**——用地温梯度把深度换算成温度，得到若干条近水平的线（如 100 °C 线、150 °C 线、200 °C 线）；
- 常把 **100–150 °C 之间的条带涂成"生油窗"，150–200 °C 之间的条带涂成"生气窗"**（本课口径）；
- **源岩曲线与生油窗条带的交点，就是该源岩"开始生油"的地质时刻**；穿出生油窗下界进入生气窗的时刻，就是开始生气的时刻。
- 若地温梯度随时间变化（如裂谷期高热流），等温线在图上就不是水平直线，而会随时间起伏。

**"厨房（kitchen）"概念：**
老师给的定义——**源岩在平面上已经进入生油/生气窗、正在生烃的那片区域**。厨房是烃类的产地；储层与圈闭必须与厨房之间有有效的输导层连通，否则再好的圈闭也是空的（"圈闭没充注"）。同一套源岩在盆地中心可能已在厨房里，在盆地边缘却还未成熟。

**这张图能回答的勘探问题：**
1. 源岩**何时**进入生油窗？（→ 与圈闭形成时间对比，检验时序）
2. 源岩**现在**处于什么成熟阶段？（未成熟 / 生油 / 生气 / 过成熟）
3. 是否曾经历过**抬升**而使生烃"停摆"？
4. 储层达到最大埋深时孔隙度还剩多少？

### 3.2 孔隙度公式与孔隙度—深度衰减曲线

**实习用到的四个基本式（讲义原文）：**

- 圆柱体积：**V = π r² h**（cm³）
- 密度：**ρ = M / V**（g/cm³）
- 孔隙体积：**V_pore = V_bulk − V_grain**
- 孔隙度：**φ = V_pore / V_bulk**（以百分数或分数表示）

其中**颗粒体积由颗粒密度求得**：**V_grain = M / ρ_grain**（讲义任务清单里写了"using the grain density provided, calculate the grain volume"，但公式区漏掉了这一条式子，见勘误表）。

把两式合并可得一个**更好用的等价式**：
> **φ = 1 − ρ_bulk / ρ_grain**

（推导：φ = (V_b − M/ρ_g)/V_b = 1 − (M/V_b)/ρ_g = 1 − ρ_b/ρ_g。）实习中用这个式子一步到位，比逐项算体积快得多，也不易出错。

> 📎 背景补充：讲义没给**孔隙度随深度衰减**的定量表达。经典的指数衰减关系（Athy 定律）为：
> **φ(z) = φ₀ · e^(−c·z)**
> φ₀ 为地表（初始）孔隙度，c 为压实系数（km⁻¹），z 为埋深。常用参数（Sclater & Christie, 1980）：**砂岩 φ₀ ≈ 0.49、c ≈ 0.27 km⁻¹；页岩 φ₀ ≈ 0.63、c ≈ 0.51 km⁻¹；白垩 φ₀ ≈ 0.70、c ≈ 0.71 km⁻¹**。
> **关键结论：页岩的 c 约为砂岩的两倍，即页岩压实快得多。** 这解释了两件事：(1) 泥岩很快失去孔渗成为**盖层**，而砂岩在几千米深处仍保有可观孔隙度成为**储层**；(2) 泥岩快速压实会把孔隙水挤出，是初次运移的驱动之一。
> **算例**：砂岩埋到 3 km：φ = 0.49 × e^(−0.27×3) = 0.49 × 0.4449 ≈ **21.8%**；页岩同深度：0.63 × e^(−0.51×3) = 0.63 × 0.2165 ≈ **13.6%**（且渗透率相差多个数量级）。

> 📎 背景补充：**孔隙度与渗透率不是一回事**。渗透率由**达西定律**定义：**Q = −(k·A/μ)·(dP/dx)**，k 单位为达西（D）或毫达西（mD），1 D ≈ 0.987 μm²。工业上粗略标准：k < 1 mD 为致密，1–10 mD 差，10–100 mD 中等，> 100 mD 好。**高孔隙度不保证高渗透率**——白垩、浮石、粒内孔发育的灰岩都可以很"孔"却不"渗"，因为孔隙彼此不连通或孔喉太细。这是本周最经典的易错点。

### 3.3 Van Krevelen 图（H/C vs O/C）

老师描述的图（讲义引 Selley 1998）：
- **横轴：O/C 原子比**；**纵轴：H/C 原子比**；两者都向右/向上增大。
- 三条演化路径分别从 **I 型（左上：H/C 最高、O/C 最低）**、**II 型（居中）**、**III 型（右下：H/C 低、O/C 高）**出发；
- 成熟过程**依次脱去 O（先）与 H（后）**，因此三条路径**都朝左下角收敛**，终点是纯碳（石墨）。
- **判别用法**：拿到一个未知样品的 H/C 与 O/C，看它落在哪条路径上 → 判定干酪根类型 → 预测它生油还是生气。
- ⚠️ 注意：**沿路径向左下移动 = 成熟度增加**，而**路径之间的差别 = 母质类型的差别**。两个方向不能混。

> 📎 背景补充：这张图叫 **Van Krevelen diagram**（材料中未出现这个名字，只描述了它）。实验室里常用**热解（Rock-Eval pyrolysis）**得到的 **HI（氢指数）vs OI（氧指数）**"改进 Van Krevelen 图"代替，因为 HI/OI 测起来比元素分析快。

### 3.4 石油系统事件图（Petroleum system events chart）

老师专门讲了这张图（并预告"下周做练习"）：
- **横轴：地质时间**；
- **纵轴：石油系统的各个要素与过程逐行排列**——源岩、储层、盖层、上覆层、圈闭形成、生烃/运移/聚集、**保存（preservation）**；
- 每一行用**横条（bar）**标出该要素/过程**在什么时间区间发生**（讲义配色：生成—运移用红色条，圈闭形成用橙色条）；
- 最后标出**关键时刻（critical moment）**：**烃类大量生成—排出—运移的那个时刻**。
- **判读规则（考点）：圈闭必须在关键时刻之前（或之时）就已形成**，否则烃类无处可聚。同理，盖层必须在关键时刻前就位、储层必须在关键时刻前沉积并仍保有孔渗。
- 把埋藏史曲线与事件图配合使用：**埋藏史曲线告诉你关键时刻是什么时候，事件图告诉你那个时候其他要素齐不齐。**

### 3.5 其他公式

**光合作用/碳循环平衡（讲义原文）：**
> 6CO₂ + 6H₂O ⇌ C₆H₁₂O₆ + 6O₂
> 向右：碳固定（生产力）；向左：碳氧化（呼吸、再矿化、燃烧）

**由地温梯度估算生油窗深度（📎 背景补充，材料未给）：**
> T(z) = T_surface + G·z，G 为地温梯度（典型 25–30 °C/km）
> 取 T_surface = 10 °C、G = 30 °C/km：100 °C 对应 z = (100−10)/30 = **3.0 km**；150 °C 对应 **4.67 km**。
> 取 G = 25 °C/km：分别为 **3.6 km** 与 **5.6 km**。
> **结论：按本课口径，生油窗大致对应 3–5 km 埋深**（裂谷/高热流盆地更浅，克拉通/低热流盆地更深）。这是把埋藏史曲线上的深度与温度串起来的钥匙。

**时间—温度指数 TTI（📎 背景补充，材料未提）：** Lopatin 方法把成熟度写成 **TTI = Σ Δt_n · 2ⁿ**，其中温度每升高 10 °C，反应速率翻倍（n 为 10 °C 温度区间的编号）。它的意义是：**成熟度是温度与时间的联合函数**——古老的盆地在较低温度下同样能生油。这正是不同教材给出的生油窗温度不一致的根本原因。

**储量估算（📎 背景补充，材料未涉及）：**
> **STOIIP = A · h · φ · (1 − S_w) / B_o**
> A 面积，h 有效厚度，φ 孔隙度，S_w 含水饱和度，B_o 地层体积系数；**可采储量 = STOIIP × 采收率 RF**（常规油田 RF 通常 20–40%）。
> 单位换算：**1 bbl（桶）= 158.99 L ≈ 0.159 m³**，即 **1 m³ ≈ 6.29 bbl**；**boe** = 桶油当量（约 5,800 立方英尺天然气 ≈ 1 boe）。做题时注意 bbl 与 m³ 差约 6.3 倍，混用会错一个数量级级别的量。

## 五、Practical 要点

本周有两个实习（外加一份质量很差的讨论稿）。

### 5.1 Practical 8 — 孔隙度测定（Porosity determination）

**核心目的**：孔隙度是岩石与沉积物的基本属性，**它衡量一个颗粒状固体储存流体（气或液）的能力，因而决定储层（油气储层或含水层）的容量**。

**定义（讲义原文）**：
> **孔隙度 = 孔隙体积 / (孔隙体积 + 固体体积)**，以百分数或分数表示
> 注意分母 = 孔隙 + 固体 = **总体积（bulk volume）**，所以等价于 φ = V_pore / V_bulk。

**学习目标**：(1) 解释估算总孔隙度的方法；(2) 描述一种简单的分析技术、撰写结果并做科学解释。

**材料（3–4 人一组）**：两块岩心柱塞（core plug）——**红色砂岩**与**白色石灰岩**；一瓶**100% 石英松散砂**；塑料烧杯；**卡尺（calipers）**；天平。

**任务 1：岩心柱塞的孔隙度（六步法）**
1. 用卡尺量直径与长度，按 **V = πr²h** 算**总体积 V_bulk**；
2. 称重得 **M**；
3. 算**体积密度 ρ_bulk = M / V_bulk**；
4. 用**给定的颗粒密度 ρ_grain**算**颗粒体积 V_grain = M / ρ_grain**；
5. 算**孔隙体积 V_pore = V_bulk − V_grain**；
6. 算**孔隙度 φ = V_pore / V_bulk**。

**任务 2：松散砂的孔隙度**
1. 称空容器重量；
2. 装满松散砂，称重后**减去容器重量**得净砂重；
3. 算容器的**总体积 V_bulk**（即砂样的堆积体积）；
4. 算 ρ_bulk；5. 由 ρ_grain 得 V_grain；6. 得 V_pore；7. 得 φ。

**记录表列**：Sample | Weight | Bulk Volume | Grain volume | Grain density | Pore volume | Porosity。

> 📎 背景补充：材料中没有给出实测数据（`porosity discussion.md` 的 OCR 几乎不可读，见 §5.3），因此我自编一组**典型数值做算例，用于验证流程与检查量级**——数值为我拟设，**不是实习实测值**：
>
> **(a) 砂岩柱塞**：直径 2.54 cm（1 英寸标准柱塞）→ r = 1.27 cm；长 h = 5.00 cm。
> V_bulk = π × 1.27² × 5.00 = π × 1.6129 × 5.00 = **25.34 cm³**
> 称重 M = 55.0 g → ρ_bulk = 55.0 / 25.34 = **2.171 g/cm³**
> 取 ρ_grain（石英）= 2.65 g/cm³ → V_grain = 55.0 / 2.65 = **20.75 cm³**
> V_pore = 25.34 − 20.75 = **4.59 cm³** → **φ = 4.59 / 25.34 = 18.1%**
> 用捷径式校验：φ = 1 − 2.171/2.65 = 1 − 0.8193 = **18.1%** ✓ 两法一致。
>
> **(b) 松散砂**：容器体积 250 cm³，净砂重 400 g。
> ρ_bulk = 400/250 = **1.60 g/cm³**；V_grain = 400/2.65 = **150.9 cm³**；V_pore = 250 − 150.9 = **99.1 cm³** → **φ = 39.6%**
>
> **量级对照（判断自己算得对不对）**：**松散未固结砂 φ ≈ 35–45%**（理论上等径球体最紧密堆积 φ = 25.9%、最松散立方堆积 φ = 47.6%，天然分选砂落在两者之间）；**固结砂岩 φ ≈ 5–25%**；**石灰岩 φ 变化极大（1%–30%+）**，取决于成岩改造。若你算出砂岩 φ > 40% 或松散砂 φ < 20%，一定是哪一步弄反了。

**这个实习"说明了什么"——写讨论时的四条结论：**
1. **松散砂 φ 远高于砂岩 φ**：差值就是**压实与胶结**在成岩过程中损失掉的孔隙度。这是"沉积物 → 岩石"过程最直观的量化证据。
2. **砂岩与石灰岩的 φ 可能接近，但成因完全不同**：砂岩以**原生粒间孔**为主；石灰岩往往是**次生孔**（铸模孔、溶孔、晶间孔）主导，因为碳酸盐矿物易溶易胶结，成岩改造强烈。
3. **本方法测的是"总孔隙度（total porosity）"**，包含**孤立、不连通**的孔隙；油气工业真正关心的是**有效孔隙度（effective porosity）**（连通孔隙），也就是测井图上的 PHIE 道。**总孔隙度 ≥ 有效孔隙度**——尤其在粒内孔发育的灰岩中差别很大。
4. **孔隙度不等于渗透率**：本实习完全没有测渗透率，因而**不能仅凭 φ 判断储层好坏**。

**主要误差来源（讨论段落必写）**：卡尺量径/量长的读数误差（φ 对 V_bulk 很敏感，直径误差被平方放大）、岩心端面不平整、样品未完全干燥（残余水使质量偏大 → φ 偏低）、**颗粒密度取值是否合适**（砂岩若含长石/岩屑/黏土，真实 ρ_grain 不等于石英的 2.65；石灰岩应取方解石 2.71，若取错 2.65 会系统性低估 φ）、松散砂的堆积密度受装填方式（是否敲实）影响很大。

### 5.2 Practical 8B — 埋藏史曲线练习（Burial graph exercise）

**背景（材料原文的要点）**：富有机质源岩在埋藏过程中随压力与温度升高而成熟；**烃类勘探的一个关键环节，就是确定源岩在何时、何地达到了允许有机质成熟的条件——即何时进入生油窗与生气窗**。这可以用**埋藏史曲线**重建，该图表示**一段岩石柱随时间的深度与温度历史**。（材料引 Gluyas 2004；另配一张地质图与一口井的位置，"colors not identical"提示图例配色与地质图不完全对应。）

**作图步骤（材料原文的四步法，务必按顺序）：**

**Step 1**：从**最年轻的单元（I）**开始。用它的**底界年龄（20 Myr）**确定**该单元当时位于地表的时刻** → 画出线段 **A–B**。**在这个时间区间内，其下所有单元的埋藏速率相同**，因此**画一组平行线（C–D 等）**。

**Step 2**：对**下一个单元（II）**，用它的**底界年龄（30 Myr）**确定它位于地表的时刻 → 画线段 **E–C**。同理，其下所有单元在该区间内埋藏速率相同 → 再画一组平行线。

**Steps 3–4**：**系统地重复同一原则，逐步向更老的时间回溯**，直到最老单元。

**这个算法为什么成立（理解比记步骤重要）：**
- 一个地层单元的底面**在它开始沉积的那一刻位于地表**（深度 = 0），这给了每条曲线一个**已知的起点**；
- 在任一时间区间内，**上覆增加的沉积厚度对下面所有层是相同的**（不考虑差异压实与剥蚀），所以**同一时间区间内所有曲线的斜率相同 → 画平行线**；
- 于是整张图就是由若干"斜率相同的线段束"拼接而成，斜率在每个单元的底界年龄处发生转折。

**怎么从图上读出生油窗时间（本练习的最终目的）：**
1. 用地温梯度把 100 °C 与 150 °C 换算成深度，在图上画两条等温（等深）线，之间即**生油窗条带**；
2. 找到**源岩单元**对应的那条曲线；
3. **该曲线与 100 °C 线的交点在横轴上的读数 = 源岩开始生油的地质时刻**；与 150 °C 线的交点 = 离开生油窗、进入生气窗的时刻；
4. **两个交点之间的横轴跨度 = 生油窗持续的时长**；
5. 把这个时刻拿去与**圈闭形成时间**对比 → 判断该石油系统能否成藏（这就是下周事件图练习的"关键时刻"分析）。

> 📎 背景补充（材料未说明的三个作图细节）：(1) **不整合/剥蚀段**要画成向上折返的线，且被剥蚀掉的厚度需要额外估计（常用镜质体反射率或声波时差反推）；(2) 严格的埋藏史恢复要做**去压实（decompaction）**校正——因为现今厚度小于沉积时的原始厚度；(3) 若地温梯度随时间变化（裂谷期高、坳陷期低），等温线不是水平线。本练习按材料的简化口径处理即可。

## 六、易错点 / 重点难点

1. **干酪根类型与产物的对应（最高频）**
   - **I 型 = 藻类 = 湖相/陆相 = 主要生油**（Green River Fm.）
   - **II 型 = 藻类+浮游生物 = 海相 = 油和气**（Kimmeridge Clay）
   - **III 型 = 陆生高等植物 = 腐殖质 = 主要生气**（煤）
   - **易错点**：很多人把"陆生植物"直觉地和"油"联系起来。**记反向口诀：植物长在陆上 → 木质素 → 煤 → 气；藻类长在水里 → 脂类 → 油。** 另注意 **I 型是"陆相"（湖）但母质是藻类**——"陆相"指沉积环境，不是指陆生植物，这两个"陆"字最容易混。

2. **温度分带的数字（本课口径必须精确）**
   - **成岩/干酪根形成：< 40–80 °C；生油窗：100–150 °C；生气窗：150–200 °C；过成熟（石墨）：> 200 °C。**
   - **易错点 A**：把生油窗写成 60–120 °C。那是常见文献口径，**本课考试请写 100–150 °C**（见 §2.4 的背景补充）。
   - **易错点 B**：把"干酪根形成"和"生油"混为一谈。**< 80 °C 只形成干酪根，还没有一滴油**；油是干酪根在更高温度下裂解的产物。
   - **易错点 C**：把 200 °C 以上写成"还能生气"。**> 200 °C 只剩石墨，是过成熟**。

3. **孔隙度 vs 渗透率——本周头号概念混淆**
   - **孔隙度 = 储存能力（storage capacity）**；**渗透率 = 流动能力（flow capacity）**。老师原话就是这样并列的。
   - **高孔不一定高渗**（孔隙不连通、孔喉太细）；**低孔也可以高渗**（裂缝性储层，孔隙度只有百分之几却能高产）。
   - **储层必须两者兼具**，答题时不能只写"多孔"。

4. **原生孔隙 vs 次生孔隙**
   - **原生 = 沉积时就有 = 粒间孔 + 粒内孔**，由沉积环境与水动力能量控制；
   - **次生 = 后期成岩造出来的 = 铸模孔、晶间孔、溶洞孔、裂缝孔**，由溶解/胶结/破裂控制。
   - **易错点**：把"粒内孔（intraparticle，如腹足壳的房室）"误判为次生孔——它是沉积时就存在的**原生**孔；而把"铸模孔（mouldic，颗粒被溶掉）"误判为原生——它是溶解造成的**次生**孔。**判据是"这个空腔是随岩石一起形成的，还是后来挖出来的"。**

5. **埋藏史曲线的斜率读法**
   - **斜率 = 埋藏/沉降速率，不是深度**。陡 = 埋得快；缓/水平 = 埋藏停滞或间断；向上折 = 抬升剥蚀。
   - 深度必须在**纵轴上读点的位置**。
   - 另一个易错点：**横轴时间方向**——地质图件通常左老右新（现今在右端 0 Ma），读交点年龄前先确认轴向。

6. **盖层（seal）与圈闭（trap）不是一回事**
   - **盖层是一种岩性（不渗透的岩石）**；**圈闭是一种几何形态（储层 + 盖层构成的上凸组合）**。
   - **只有盖层没有圈闭**：烃类会沿盖层底面继续侧向上倾运移，最终从盖层边缘逃逸；
   - **只有几何没有盖层**：背斜再完美也漏光。
   - 典型错答："盐是一种圈闭"——**盐是一种盖层岩性**；**盐丘（salt dome）**才是圈闭。

7. **溢出点与闭合度**
   - **闭合度 = 构造最高点到溢出点的垂直距离**，决定圈闭的最大容量；
   - 易错：把闭合度说成"背斜的宽度"或"构造的埋深"。
   - 溢出点以下的流体会**溢到下一个构造**去——这解释了为什么一条构造带上的多个圈闭常常"从下往上依次充满"。

8. **"源储盖圈运保"六要素缺一不可 + 时序必须正确**
   - 论述题只答"有源岩有储层"必失分。**必须答全：源岩（且已成熟）、运移通道、储层、盖层、圈闭、保存**；
   - **更高一层的得分点是时序**：老师专门强调——若烃类生成运移时**圈闭尚未形成**，油气就跑光了。这就是**关键时刻（critical moment）**的意义。

9. **API 度的方向不要记反**
   - **API 度高 = 密度低 = 轻质油 = 好开采、用途多**；**API 度低 = 密度高 = 重质油/沥青 = 黏、难采、需裂化**。
   - **10 °API 就是水的密度**（这是定义的推论，可当作锚点）；界线：**< 22 重质，22–30 中质，> 30 轻质**。
   - 注意术语：**API gravity 是"重度"，不是"密度"**（讲义里 "API density" 的说法不规范，见勘误表）。

10. **TOC 门槛**：**源岩 = TOC ≥ 1%**。老师说了两遍，是硬性数字。

11. **上升流水体的性质**：上涌的深层水**富营养盐但贫氧**。老师口误说成"oxygen rich"——不要跟着记错。**正是因为它贫氧 + 高生产力耗氧，才在其上形成氧最小带（OMZ），才有利于有机质保存。**

12. **生产力 ≠ 源岩**：高生产力只是必要条件之一。**必须同时满足：高生产力 + 缺氧保存 + 低碎屑稀释。** 三缺一都成不了源岩——这是本周最容易被简化答错的因果链。
