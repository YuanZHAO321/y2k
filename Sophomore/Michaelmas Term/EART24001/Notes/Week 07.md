## 二、核心概念

**1. 圆形数据（circular data）为何特殊。** 其定义域是圆而非直线，**0° 与 360° 等价**，故算术平均无意义。讲义反例：001° 与 359° 都近乎正北，算术平均 (1+359)/2 = 180° 却是正南。因此**角度平均必须借助三角函数**（sin、cos 以 360° 为周期）：把角度还原成单位向量、相加后取合向量方向。

**2. 单向 vs 双向数据。** 单向（unidirectional）数据带指向，如交错层理前积面倾向、槽模指向端；双向（bidirectional）数据只定义一条**流线（line of flow）**，如砾石长轴、波痕脊、沟槽槽线，此时 020° 与 200° 是同一观测。讲义规定：双向数据"上述公式仍适用，但**必须先把数据校正到流线的同一端**"。本周正是示范：`2a` 表中 `pl/pl dir` 记录 scours / furrows 的**流线**，另设 `direction` 列给出 N/E/SE/W/NW/SW ——**这就是判端结果**，来自野外对侵蚀构造不对称形态的判读。

> 📎 背景补充：不判端直接合成，方向相反的观测互相抵消，会得出"无优势方向"的假结论。通用做法是**倍角法**：角度 ×2 后合成、平均方向再 ÷2，使 θ 与 θ+180° 自动等价。本周走的是人工判端路线。

**3. 玫瑰图（rose diagram）= 圆形直方图。** 讲义定义：按 *x*° 宽分箱（**360/x 须为整数**），每箱画成 *x*° 宽扇形，**半径正比于该箱数据个数**。两个考点：① **箱宽敏感**——讲义给了经验式（原文为图片，转换后丢失），式中 *R* 是数据极差（通常 360°，若数据只落在有限角度区间可更小），*n* 是数据个数；② **半径标度造成失真**（原文）：半径正比于频数会"视觉上**夸大高频数**，因为人眼对扇形的印象正比于**面积**，而面积正比于**半径平方**；视觉准确的表示法是让半径正比于**频数的平方根**"。这正是两张答案图的差别——`2c-SolnAll.md` 是 "**frequency** rose diagram"，`3-Comments.md` 是 "**root frequency** rose diagram"，并排给出就是要学生看出观感差异。

**4. 平均方向与集中度。** 单位向量之和为**合向量（resultant vector）**，其方向即**平均方向 θ̄**，其长度 **R** 衡量**集中度**（全一致则 R = n，全散乱则 R → 0）；标准化 **R̄ = R/n** ∈ [0,1]；**圆形方差 = 1 − R̄**，**0 表示所有方向完全相同**，越大越散。

**5. 古流向与去倾斜校正。** 古流向指示沉积物**搬运方向**，进而约束物源位置与古地理格局，前提是**测得方向必须先旋转回沉积时的水平状态**；不校正得到的是"沉积信号 + 构造信号"的混合物。本周倾伏角在 4°–35° 之间，如 138(N) 点 furrows 现测 **35/112**，去倾斜后为水平的 **111°**。

## 三、公式与图表

### 1. 向量合成求平均方向

设方向角 θ₁…θₙ（方位角，自北顺时针）：

```
x_i = sin θ_i （东分量）      y_i = cos θ_i （北分量）
x_r = Σ sin θ_i              y_r = Σ cos θ_i
θ̄  = arctan ( x_r / y_r )
```

注意讲义约定：**x 是正弦（东）分量、y 是余弦（北）分量**，与数学课 (cos, sin) 的习惯相反，因为地质方位自**北**起算、**顺时针**为正。

### 2. 象限判定（讲义明列，必背）

用度数时 `arctan` 返回 **−90°–+90°**，而答案须在 **0°–360°**：

| x_r | y_r | 真实象限 | 加上 |
|---|---|---|---|
| + | + | 000–090（NE） | **0°** |
| + | − | 090–180（SE） | **180°** |
| − | − | 180–270（SW） | **180°** |
| − | + | 270–360（NW） | **360°** |

> 📎 背景补充：编程时直接用 `atan2(x_r, y_r)`（东分量在前）再对 360 取模即可；手算必须查此表。

### 3. 合向量长度与圆形方差

```
R = ( x_r² + y_r² )^(1/2)
R̄ = R / n                         （集中度，0–1）
circular variance = 1 − R/n = 1 − R̄
```

> 📎 背景补充：**Rayleigh 检验**。材料只给方差、未给显著性检验，但方差本身无法回答"优势方向是真实存在还是随机涨落"。标准工具为 Rayleigh test（H₀ = 圆周均匀分布）：`Z = n R̄²`，`p ≈ exp[√(1+4n+4(n²−R²)) − (1+2n)]`。代入本周结果：BdE（n=6, R̄=0.955）Z=5.5, p≈0.001；Lau（n=7, 0.948）Z=6.3, p≈0.0003；Asse（n=12, 0.602）Z=4.3, p≈0.01——均显著。但 25 条合并（R̄=0.165）Z=0.68、**p≈0.51 完全不显著**，从统计上印证了老师"必须按层位分组"的讲评。

### 4. 玫瑰图作法（文字详述）

1. **判类型**：双向数据先统一到同一端（本周靠 `direction` 列）。
2. **定箱宽 x**，使 360/x 为整数（常用 10°/20°/30°/45°），起点取 000°，区间 [0,20)、[20,40)…；**数频数**。
3. **定半径标度**：频数标度（简单但夸大高频）或 **√频数标度（优先）**。
4. **画刻度环**：同心圆并标注频数值（答案图为 2、4、6）；用 √ 标度时刻度环**不等间距**（半径比 √2:√4:√6 = 1.41:2:2.45）。
5. **逐箱画扇形**：圆心为顶点、张角 x°、方位落于该箱、半径由第 3 步定。
6. **必备标注**：N 箭头、方位刻度、半径刻度含义、n、图例。
7. **多组叠加**：题 (d) 要求三单元同图不同色（答案图 Asse/Lau/BdE 三色），以便一眼看出优势方向随层位变化。`2c-SolnAll` 还在图上标出**褶皱轴 10/165** 的方位，用来检查古流向峰与构造走向有无虚假相关。

> 📎 背景补充：讲义丢失的经验分箱式几乎可以肯定是 Sturges 规则的圆形版 **bin width ≈ R/(1 + 3.322 log₁₀ n)**；n=25、R=360° 得约 64°，n=12 得约 79°，但受 360/x 为整数约束实际取便利值。答案图方位刻度每 20° 一格，用 **20° 分箱**可使各组最大箱频数落在 4–5，与图上 2/4/6 刻度环吻合，故本笔记以 20° 复现。

### 5. 去倾斜（unfolding）的赤平投影作法 —— 本周最重要的操作

**关键认识：褶皱轴水平时只需绕走向线转一次；褶皱轴倾伏时必须两步旋转，否则有系统性偏差。** 本周褶皱轴倾伏 10°，单步法复算与标准答案相差 3°–15°（笔者验证）。

- **准备**：把所有层面投成**极点（poles to bedding）**。若为圆柱状褶皱（cylindrical fold），极点落在一个大圆（**π-circle**）上，**该大圆的极点即褶皱轴**——这就是题 (a) 的做法。
- **第一步——把褶皱轴转平**：绕一条**水平的、垂直于褶皱轴倾伏向**的轴旋转，旋转量 = 褶皱轴倾伏角。操作上转动描图纸使褶皱轴落到网的 E–W 直径上，沿该直径移到基圆。**同一次旋转必须施加于图上全部要素**（每个层面极点、每条古流线），各沿所在**小圆**移动相同度数。
- **第二步——绕已水平的褶皱轴把层面转平**：把褶皱轴摆到网的 N–S 或 E–W 直径作旋转轴，**逐条分别处理**——把该点的层面极点沿小圆转到中心（层面变水平），转多少度、朝哪边转，就把**同一点的古流线转多少度、朝同一边转**。
- **读数与自检**：古流线转完后应落在**基圆**上（它本躺在层面内），读出方位再按 `direction` 判端即得**未旋转古流向**；偏离基圆 1–2° 属野外取整误差，偏差大则说明配对搞错。

> 📎 背景补充：为什么必须两步？绕走向线的单次旋转只在褶皱轴水平时才等价于去褶皱。褶皱轴倾伏时现今产状是"褶皱 + 整体倾伏"的复合结果；先把轴转平即剥离倾伏那一份，剩下的才是纯粹绕水平轴的褶皱作用。

**几何描述要点**：褶皱轴 10/165 → **缓倾伏（gently plunging）、向 SSE**；翼间角 62° → 按 Fleuty 分类属 **close fold（30°–70°）**；轴面近直立、走向约 165–170°；两翼倾角高度不对称（35°/70°/中间翼 85°W 且倾向相反），呈不对称、可能含倒转翼的形态。**不整合之上褶皱轴 10/165、之下 22/160，二者不同**，说明不整合之下的单元在不整合形成前已经历一期独立变形，其后与上覆地层一起被第二期褶皱叠加——这即任务 ⑥ 的答案方向。

## 六、易错点 / 重点难点

1. **对圆形数据取算术平均**——根本错误（001° 与 359° 平均得 180° 正南，正确答案 000°）。必须向量合成。
2. **象限判错**：`arctan` 只返回 −90°–+90°，**必须**按 x_r、y_r 符号加 0°/180°/360°；且 x 是**正弦（东）**、y 是**余弦（北）**分量，勿写反。手算最常见失分点。
3. **玫瑰图半径用频数**造成视觉夸大（观感 ∝ 面积 ∝ 半径²）。优先 **√频数**标度，此时刻度环**不等间距**。
4. **单向与双向数据混用**：双向数据不先判端就合成，正反相消，得出"无优势方向"的假结论。
5. **忘做去倾斜校正**：直接拿现测 pl/pl dir 当古流向；本周倾伏角 4°–35°，误差可达数十度。
6. **褶皱轴倾伏时只做一次旋转**：仅绕走向线转平层面只在轴水平时正确，本周单步法与答案偏差 3°–15°，**必须两步**；且每次旋转须**同时施加于全部要素**（漏转古流线最常见）。
7. **把所有数据合并统计**：合并 25 条 → 328°/方差 0.83，Rayleigh p≈0.51 完全不显著；分层位后三组均极显著。**先分组、再统计。** 同理须交代 n 与地点分布，防止**观测偏倚**造出假峰。
8. **混淆"褶皱轴倾伏向"与"轴面走向"**——仅在轴水平或轴面直立时相等。
9. **混淆 profile plane 与普通竖直剖面**：前者**垂直于褶皱轴**，只有其上的翼间角是真值，其余都是视角度。
