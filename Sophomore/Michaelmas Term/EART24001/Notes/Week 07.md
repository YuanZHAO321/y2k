## 二、核心概念

### 1. 圆形数据（circular data）为什么特殊

方向数据是以**角度**表达的，其定义域是一个圆而不是一条直线：**0° 与 360° 是同一个方向**。因此普通的算术平均没有意义。讲义给的反例极其干净：

> 一个方位 001°，一个方位 359°，两者都近乎正北；算术平均 (1 + 359)/2 = 180°，得到的却是正南。

结论：**角度的平均必须借助三角函数**（因为 sin、cos 以 360° 为周期，天然满足 0° ≡ 360°），做法是把每个角度还原成**单位向量**，向量相加后再取合向量的方向。

### 2. 单向数据（unidirectional）与双向数据（bidirectional）

- **单向数据**：本身带有明确的指向。例如交错层理（cross-bedding）前积面的倾向、槽模（flute cast）的指向端、冲刷构造（scours）的水流方向。可直接用于 0°–360° 的向量运算。
- **双向数据**：只定义一条**线**（line of flow），不定义指向哪一端。例如砾石长轴（clast long axis）、波痕脊（ripple crest）、沟槽（furrows）的槽线。此时 020° 与 200° 是同一个观测。

讲义原文对此有一条明确规定：

> 若方向数据是双向的而非单向的（例如是"流线"而非"流向"），上述公式**仍然适用，但必须先把数据统一校正到流线的同一端**。

> 📎 背景补充：如果双向数据不做"统一到同一端"的处理就直接做向量合成，方向相反的两个观测会互相抵消，合向量长度趋近于 0，得到"没有优势方向"的假结论。常见的严谨做法是"倍角法"（doubling method）：把每个角度 ×2 后做向量合成，求得的平均方向再 ÷2，这样 θ 与 θ+180° 倍角后完全重合，自动等价。本周材料没有介绍倍角法，采用的是"人工判端"的路线——见下一条。

**本周实例正是双向数据的处理示范**：`2a-Solution2025.md` 的表格里，`pl/pl dir`（plunge / plunge direction，倾伏角/倾伏向）记录的是**流线**（scours、furrows 是侵蚀构造，几何上是线状凹槽），而单独有一列 `direction` 给出 N / E / SE / W / NW / SW —— **这一列就是"判端"的结果**，来自野外对侵蚀构造不对称形态的判读（哪一端陡、哪一端渐灭）。有了这一列，双向数据就被还原成了单向数据，可以直接做统计。

### 3. 玫瑰图（rose diagram）

玫瑰图 = **圆形直方图（circular histogram）**。讲义定义：

- 把数据按 *x*° 宽度分箱（bin），要求 **360 / x 为整数**，从 0° 一直排到 360°；
- 每个箱画成一个 *x*° 宽的**扇形（segment）**，扇形**半径正比于该箱内数据个数**。

两个关键提醒（都是本周的考点）：

**(a) 分箱宽度敏感**。玫瑰图长什么样强烈依赖 bin width 的选择，讲义给了一个经验公式（原文中该公式是图片，md 转换后丢失），公式中 *R* 是数据的**极差**（range，通常是 360°，但若数据只落在有限角度区间内则可以更小），*n* 是数据个数。

> 📎 背景补充：讲义提到的经验式几乎可以肯定是 Sturges 规则的圆形数据版本：**bin width ≈ R / (1 + 3.322 log₁₀ n)**。代入本周数据：n = 25、R = 360° 得约 64°；n = 12 得约 79°。但由于 360/x 必须为整数，实际会取 60°、45°、30° 或 20° 等便利值。答案图（`2c-SolnAll.md`、`3-Comments.md`）上的方位刻度是每 20° 一格，用 **20° 分箱**能使各组的最大箱频数落在 4–5，与图上标注的 2 / 4 / 6 半径圈完全吻合，因此本笔记以 20° 作为复现分箱。

**(b) 半径标度会造成视觉失真**。讲义原文：

> 当扇形半径正比于频数时，图会在视觉上**夸大高频数**。因为人眼对扇形的印象正比于它的**面积**，而面积正比于**半径的平方**，不是半径。视觉上准确的表示法是让**半径正比于频数的平方根**。

这正是本周两张答案图的差别：`2c-SolnAll.md` 标题是 "**frequency** rose diagram"（频数玫瑰图），`3-Comments.md` 标题是 "**root frequency** rose diagram"（**平方根**频数玫瑰图）。**老师给出这两张图并排，就是要学生看出同一批数据在两种标度下的观感差异。**

### 4. 平均方向与集中度

- **平均方向（mean direction, θ̄）**：所有单位向量相加得到的**合向量（resultant vector）**的方向。
- **合向量长度 R**：衡量数据的**集中度（concentration）**。若所有方向完全一致，n 个单位向量首尾相接得到长度 n 的合向量；若方向完全散乱互相抵消，R → 0。
- **标准化合向量长度 R̄ = R / n**，范围 0–1。
- **圆形方差（circular variance）= 1 − R̄**，范围 0–1，**0 表示所有方向完全相同**（讲义原文）。注意这与普通方差方向相反：**数值越大越散**。

### 5. 古流向（palaeocurrent）与去倾斜校正（unfolding）

古流向指示**沉积物搬运方向**，进而约束**物源区位置、古地理格局与盆地充填演化**。但有一个前提：

> **测得的方向必须先旋转回沉积当时的水平状态才有意义。**

地层被褶皱倾斜后，原本水平的流线也随之被旋转。若不校正，得到的"古流向"混合了沉积信号与构造信号，完全不可信。本周的 Barrême 数据就是活教材：例如 138(N) 号点的 furrows 现在量到 **35/112**（倾伏 35°），去倾斜后是水平方向 **111°**——倾伏角从 35° 归零，方位也变了。

## 三、公式与图表

**本段是本周笔记的重心。**

### 1. 向量合成求平均方向

设 n 个方向角为 θ₁, θ₂, … θₙ（方位角，从北顺时针起算）。把每个角化为单位向量，其分量为：

```
x_i = sin θ_i        （东分量 East）
y_i = cos θ_i        （北分量 North）
```

合向量（resultant vector）的分量为：

```
x_r = Σ sin θ_i
y_r = Σ cos θ_i
```

平均方向：

```
θ̄ = arctan ( x_r / y_r )
```

> 注意讲义的记号约定：**x 是正弦（东）分量，y 是余弦（北）分量**——与数学课上 (cos, sin) 的习惯相反，因为地质方位角是从**北**起算、**顺时针**为正。

### 2. 象限判定（讲义明确列出，必背）

角度用度数（而非弧度）时，`arctan` 返回值落在 **−90° 到 +90°**，而真实答案必须落在 **0°–360°**。讲义给出的修正规则（依 x_r、y_r 的正负号）：

| x_r 符号 | y_r 符号 | 真实方位所在象限 | 加上 |
|---|---|---|---|
| 正 (+) | 正 (+) | 000°–090°（NE） | **0°** |
| 正 (+) | 负 (−) | 090°–180°（SE） | **180°** |
| 负 (−) | 负 (−) | 180°–270°（SW） | **180°** |
| 负 (−) | 正 (+) | 270°–360°（NW） | **360°** |

> 📎 背景补充：用编程或计算器时，直接调用 `atan2(x_r, y_r)`（注意参数顺序是"东分量在前、北分量在后"）再对 360 取模，即可一步到位，无需查表。手算时讲义这张表是必须的。

### 3. 合向量长度与圆形方差

```
R  = ( x_r² + y_r² )^(1/2)          合向量长度
R̄  = R / n                          标准化合向量长度（集中度），0 ≤ R̄ ≤ 1
circular variance = 1 − R / n = 1 − R̄     圆形方差，0 ≤ CV ≤ 1
```

- CV = 0 → 所有方向完全相同（R̄ = 1）；
- CV → 1 → 方向完全均匀散布，无优势方向。

> 📎 背景补充：**显著性检验（Rayleigh test）**。材料只给了圆形方差，没有给检验。但只看方差无法回答"这个平均方向到底是不是真的存在优势方向，还是随机涨落"。标准工具是 **Rayleigh 检验**，零假设 H₀ = 数据在圆周上均匀分布。统计量
> ```
> Z = n R̄²  = R² / n
> p ≈ exp[ √(1 + 4n + 4(n² − R²)) − (1 + 2n) ]
> ```
> 代入本周分组结果：BdE（n=6, R̄=0.955）→ Z=5.5, p≈0.001；Lau（n=7, R̄=0.948）→ Z=6.3, p≈0.0003；Asse（n=12, R̄=0.602）→ Z=4.3, p≈0.01——三者都在 5% 水平显著。但把 25 个数据合在一起（R̄=0.165）→ Z=0.68, **p≈0.51，完全不显著**。这从统计上印证了 `3-Comments.md` 的第 (2) 条讲评：**合并统计毫无意义，必须按层位分组。**

### 4. 玫瑰图的具体画法（文字详述）

1. **确定数据类型**。单向数据直接用；双向数据先统一到同一端（本周靠 `direction` 列判端）。
2. **确定分箱宽度 x**，满足 360/x 为整数（常用 10°、20°、30°、45°）。参照 Sturges 式，再根据数据量与视觉效果微调。分箱**起点**建议取 000°，即箱区间为 [0,20)、[20,40)…
3. **数频数**。把每个方向落入对应箱，统计计数。
4. **定半径标度**。
   - 频数标度：半径 ∝ 频数（简单，但夸大高频）。
   - **平方根频数标度：半径 ∝ √频数**（面积才与频数成正比，视觉准确）——**优先用这个**。
5. **画同心圆刻度环**。在圆内画若干标注了频数值的同心圆（答案图上是 2、4、6）。注意：若用 √ 标度，这些环**不等间距**（2、4、6 对应半径比 √2 : √4 : √6 = 1.41 : 2 : 2.45）。
6. **逐箱画扇形**：以圆心为顶点，画一个张角为 x°、方位落在该箱区间、半径由第 4 步决定的扇形。
7. **必备标注**：正北 N 箭头、方位刻度（每 20°/30° 一格）、半径刻度含义与数值、n（数据个数）、图例。
8. **多组数据叠加**：本周题目 (d) 要求把三个单元的数据画在同一张玫瑰图上、**每个单元用不同颜色**（答案图上 Asse / Lau / BdE 三色）。这样一眼就能看出优势方向随层位的变化。
9. 可在图上叠加辅助信息：答案图 `2c-SolnAll.md` 在玫瑰图上另外标出了**褶皱轴（fold axis）10/165** 的方位，用来检查古流向优势方向与构造走向有没有虚假的相关性。

### 5. 去倾斜（unfolding / unrotating）的赤平投影作法

**这是本周最重要的操作技能。** 目标：把被褶皱的地层连同其上的古流向线一起转回沉积时的水平状态。

**关键认识：如果褶皱轴是水平的，只需绕走向线一次旋转；但如果褶皱轴是倾伏的（plunging fold），必须做两步旋转，否则结果会有系统性偏差。** 本周 Barrême 数据的褶皱轴倾伏 10°，若只做一次"绕走向线转回"，各点误差可达 3–15°（笔者复核验证）。

**标准两步法（two-stage unfolding）**：

- **准备**：在赤平投影网（stereonet）上，把所有层面（bedding）投成**极点（poles to bedding）**。若地层被一个圆柱状褶皱（cylindrical fold）变形，这些极点会落在一个**大圆（π-circle）**上；**这个大圆的极点就是褶皱轴（fold axis）**。这就是题 (a) 的做法。
- **第一步——把褶皱轴转平**。绕一条**水平的、与褶皱轴倾伏向垂直**的轴旋转，旋转量等于褶皱轴的倾伏角。操作上：转动描图纸使褶皱轴落到网的 E–W 直径上，然后沿该直径把它移到基圆（primitive circle）上，移动量 = 倾伏角。**同一次旋转必须施加到图上所有要素**（每个层面极点、每条古流向线）——它们各自沿所在的**小圆（small circle）**移动相同的度数。
- **第二步——绕（现已水平的）褶皱轴把层面转平**。把褶皱轴摆到网的 N–S 或 E–W 直径上作为旋转轴，然后**逐条记录分别处理**：对每一个测点，把它的层面极点沿小圆转到中心（垂直），转多少度、朝哪边转，就把**同一测点的古流向线转多少度、朝同一边转**。
- **读数**：古流向线转完后应当落在**基圆上**（因为它本来就躺在层面内，层面转平了它自然变水平）。基圆上的位置读出的方位，加上"判端"结果（`direction` 列），就是**未旋转的古流向（unrotated palaeocurrent direction）**。
- **自检**：若旋转后的线没落在基圆上而偏进网内 1–2°，说明野外记录的线并不严格躺在记录的层面内（测量取整误差），可接受；偏差很大则说明配对搞错了。

> 📎 背景补充：为什么必须两步？绕走向线的一次旋转只在褶皱轴水平时才等价于"去褶皱"。褶皱轴倾伏时，地层的现今产状是"先褶皱、后整体倾伏（或先倾伏后褶皱）"的复合结果；先把轴转平，就把倾伏这一份变形剥离出去，剩下的才是纯粹的绕水平轴的褶皱作用。这与 W4 判断褶皱几何、以及"是否需要 unfolding 才能比较褶皱前的线理"是同一个逻辑。

### 老师讲评（`3-Comments.md`）——四条「Interpretative pointers」

这是本周最有价值的一份材料：它是老师对学生作业的点评，直接透露了**评分看什么**。四条原文如下，逐条展开：

**(1) 当心观测偏倚（observer bias）——某些层位或某些点采集的数据特别多。**
本周数据就有这个问题：25 个数据里，locality 12 一个点就贡献了 5 个，138(N) 一个点贡献了 4 个，11–12 贡献 3 个。这几个点纯粹因为露头好、数据多，就会在玫瑰图上形成假的"优势峰"。**呈现时应说明每个方向峰背后有几个独立地点**，必要时按地点取平均后再统计（每个地点算一票）。

**(2) 按层位（stratigraphic position）分析数据——水流方向随时间变化。**
这条直接对应本周最重要的数值结果：分单元统计得到 BdE 357°、Lau 132°、Asse 288°，方差都很小（0.05、0.05、0.40）；而全部 25 个混在一起是 328°、方差 0.83——**混合统计是垃圾**。老师要的结论是"古流向随层位系统性改变"，而不是一个总平均。

**(3) 按地点（locality）分析数据——水流方向随空间变化，并把结果标在地图上。**
即：不要只交一张玫瑰图，还应做**分点的小玫瑰图叠在地图上对应位置**，看有没有空间上的系统性（例如向盆地中心汇聚、或沿盆缘发散）。

**(4) 时刻记住这个古流向指示器是怎么形成的。**
本周用的是 **erosive features on the base of beds**（层底侵蚀构造）：scours（冲刷槽）、furrows（沟槽）。这类构造由**底部流（沉积物重力流／浊流）冲刷下伏沉积面**形成，记录的是**单次事件流的局部流向**，不一定等于长期主水系方向；而且它是**线状**构造，本身只给流线，指向要靠不对称形态判读——判端可能出错。不同类型的指示器（交错层理、波痕、槽模、砾石排列）代表的时间尺度和可靠性都不一样，解释时不能混为一谈。

### handout 强调的作图与计算约定

- 分箱宽度 x 必须满足 **360/x 为整数**。
- **优先用平方根频数标度**做玫瑰图。
- 双向数据要**先统一到流线同一端**才能套公式。
- 象限修正表（见第三段）**必须逐项检查符号**，这是手算最常出错的一步。
- 延伸阅读（handout 列出）：Borradaile, G. (2003) *Statistics of Earth Science Data*, Springer；Sanderson & Peacock (2020) *Making rose diagrams fit-for-purpose*, Earth-Science Reviews 201, 103055.

5. 在图上画出**褶皱轴迹（fold axial traces）**并完整标注。

7. 然后做古流向部分（即题 1）。

**关于问题 2 的答案**（材料未给出文字答案，以下为标准解答）：

> 📎 背景补充：褶皱轴是一条**位于轴面之内**的直线。一条位于某平面内的直线，其**走向线上的投影方位（trend）等于该平面的走向**，仅当以下两种情形之一成立：(i) 该直线水平（倾伏角 = 0，此时它本身就是走向线）；(ii) 该平面直立（倾角 = 90°，此时平面内所有直线的 trend 都等于走向）。本题两个条件都不满足——褶皱轴是**倾伏的**，轴面是**倾斜的**——所以褶皱轴在轴面内有一个非零的**侧伏角（pitch / rake）**，它的倾伏向必然偏离轴面走向。两者的差值随侧伏角增大、随轴面倾角减小而增大。

**关于问题 6**（不整合之下的几何）：见下一题的推论——不整合之下的单元记录了**比不整合之上多一期的褶皱**，两者褶皱轴不同（22/160 vs 10/165），故不整合之下的地层在不整合形成之前就已被变形。

## 六、易错点 / 重点难点

1. **对圆形数据取算术平均**——最根本的错误。001° 与 359° 的算术平均是 180°（正南），而正确答案是 000°（正北）。必须走向量合成。
2. **象限判错**。`arctan(x_r/y_r)` 只返回 −90°–+90°，**必须**按 x_r、y_r 的符号加 0°/180°/360°。手算时最常见的失分点。特别注意 x 是**正弦（东）分量**、y 是**余弦（北）分量**，别写反。
3. **玫瑰图半径用频数**导致视觉夸大高频数（观感 ∝ 面积 ∝ 半径²）。应优先用**√频数**标度；用 √ 标度时刻度环**不等间距**，别画成等距。
4. **单向与双向数据混用**。双向数据（线状：furrows、砾石长轴、波痕脊）不先统一到同一端就做向量合成，正反相消，得出"无优势方向"的假结论。本周材料靠 `direction` 列判端解决。
5. **忘做去倾斜校正**。直接拿现今测到的 pl/pl dir 当古流向，得到的是"沉积信号 + 构造信号"的混合物。本周所有数据的倾伏角都在 4°–35° 之间，不校正的误差可达数十度。
6. **褶皱轴倾伏时只做一次旋转**。仅绕走向线把层面转平，只有在褶皱轴水平时才正确。本周褶皱轴倾伏 10°，用单步法复算会与标准答案系统性偏差 3–15°（笔者验证）。**必须两步：先转平褶皱轴，再绕褶皱轴转平层面。**
7. **旋转时只转了一部分要素**。赤平投影上的旋转必须**同时施加于图上所有相关要素**，且每个点沿各自的小圆移动相同度数。漏转古流线是最常见的操作错误。
8. **把所有数据合并统计**。本周最重要的解释性陷阱：合并 25 条得到 328°/方差 0.83，Rayleigh 检验 p ≈ 0.51 完全不显著；分层位后三组都极显著。**先分组、再统计。**
9. **忽视观测偏倚**。单一露头贡献 5 条数据会在玫瑰图上造出假峰。要交代 n 与地点分布。
10. **混淆"褶皱轴的倾伏向"与"轴面的走向"**。二者只在褶皱轴水平或轴面直立时才相等。
11. **剖面（profile plane）与横剖面（cross-section）混淆**。profile plane 按定义**垂直于褶皱轴**，只有在这个面上量出的翼间角才是真翼间角；任意方向的竖直剖面量出来的都是视角度。
