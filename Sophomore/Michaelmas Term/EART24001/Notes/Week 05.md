## 二、核心概念

**断层定义**：岩体中有可观察位移的破裂面。完整描述其几何需三要素：

- **(a) 断层面产状**：走向/倾角（strike/dip）或倾角/倾向（dip/dip direction）。
- **(b) 滑距向量（slip vector）的方位与大小**。slip vector 定义为**连接断层面两侧原本重合两点的连线**。方位用**倾伏角/倾伏向（plunge/plunge direction）**或断层面内的**侧伏角（pitch）**；大小可用向量的模，也可用**走滑 + 倾滑**两分量——讲义要求"最好两种都给"。
- **(c) 运动方向感**：走滑用 **dextral 右旋 / sinistral 左旋**，倾滑用 **normal 正断 / reverse 逆断**，**两个分量都要各自注明**。

**上盘与下盘**：讲义配图给出 hanging wall（上盘）/ footwall（下盘）。
📎 背景补充：断层面**之上**为上盘、**之下**为下盘；上盘降 = 正断，上盘升 = 逆断（缓倾者称 thrust）。**直立断层（`/V`）无上下盘之分**，故 `Q2Soln` 写 "East/West side of fault"、`JuxtapositionEG` 写 "up to north"，而不写 normal/reverse。

📎 背景补充——分类与图面表现：正断层常造成**地层缺失**、上盘侧新地层出露变宽；逆断层/逆冲常造成**地层重复**、老地层被推到新地层之上；纯走滑界线水平错移但两盘出露宽度不变；斜滑（oblique-slip）兼具两者。

### ⚠️ 头号警告：错移 ≠ 走滑

讲义强调：**图上界线沿断层被错开，并不意味着滑距向量有走滑分量**——倾斜地层被纯倾滑断层切断，平面上照样产生视错移（apparent offset）。判别法则（配图中 `40°`、`70°` 两条界线的场景）：两条**产状不同**的界线视错移量**不同** ⟹ 有**倾滑**分量；视错移量**相同** ⟹ **无倾滑**分量（纯走滑）。原理：倾滑造成的视错移依赖被错界线产状（界线越缓，同样 throw 造成的水平错移越大），走滑造成的则与产状无关；"错移量随界线产状而变"就是倾滑分量的指纹。

### 分离量（Separation）

讲义：若**只**有断层产状 + **一条**已知产状界面的视错移，则**无法确定滑距向量**，但可描述 separation。**strike separation 走向分离**即视错移，在水平面内量；其余均定义在**包含断层倾向的铅直平面**内——**throw 垂直断距**、**heave 水平断距**、**hade 余倾角**、**dip separation 倾向分离**、**vertical separation 铅直分离**、**stratigraphic separation 地层分离**（跨断层缺失/重复的地层厚度）；两盘称 **upthrown / downthrown block**。

**截交线（cut-off line）**——讲义原话：目标界面与断层面的交线，**共两条**（两盘各一），**它们在图面上的间距就是 heave**。这句是本周所有作图的枢纽。

📎 背景补充：**separation ≠ slip**。separation 只是"界面被切成两半后的间距"；slip 要求找到**原本同一个点**的两个像，必须靠**穿刺点（piercing point）**——这就是断层面剖面存在的全部理由。

**冗余术语**（讲义自称 redundant）：**strike fault**（走向 ∥ 地层走向）、**dip fault**（走向 ∥ 地层倾向）、**bedding plane fault**（∥ 层面，走向断层特例）。

## 三、公式与图表

> 本段是本周笔记的重心。

### A. 角度—分量换算

设净滑距 `S`、滑距向量在断层面内的侧伏角 `r`（pitch，自走向线量起）、断层倾角 `δ`。

| 公式 | 含义 |
|---|---|
| `倾滑 D = S·sin r`；`走滑 L = S·cos r`；`S = √(D²+L²)` | 滑距向量在断层面内的分解 |
| `throw T = D·sin δ`；`heave H = D·cos δ` | 倾滑分量的铅直/水平投影 |
| **`T = H·tan δ` ⟺ `H = T / tan δ`** | throw 与 heave 由断层倾角联系（核心式） |
| `dip separation = T/sin δ = H/cos δ` | 沿断层面倾向量取 |
| `hade = 90° − δ`；`sin(plunge) = sin r · sin δ` | 余倾角；侧伏角→倾伏角 |

📎 背景补充：上表只有"截交线间距 = heave"与各术语名称出自讲义，**公式本身讲义未列**，为标准关系式，此处补齐。

**用材料数字验算**：`JuxtapositionEG` 530 ft / 58°（直立断层 ⟹ pitch = plunge）→ 530·sin58° = **449 ft** ✓、530·cos58° = **281 ft** ✓；`Q2Soln` C 409 m / 70° → **384 m** ✓、**140 m** ✓。
📎 由 `Q1soln-1` 反算（材料未给）：383 m / 57° → throw ≈ 321 m、heave ≈ 209 m；1140 m / 11° → throw ≈ **217 m**、heave ≈ **1119 m**（缓倾逆冲：滑距巨大而 throw 很小）。

### B. 图法一：在断层面上画地层等高线（求断层产状）

讲义只有一句：**"Obtained by drawing stratum contours on the fault"**。📎 展开如下：

1. 找**断层线与地形等高线的交点**——断层线是断层面与地形面的交线，故它与 `h` m 地形等高线的交点即断层面上高程 `h` 的点。
2. 同高程各交点连成直线 = 断层面的 `h` m 等高线。
3. 多做几条（100/200/300…），必**平行等间距**（断层面为平面）。
4. 其走向 = **断层走向**；相邻两条高差 Δh、图上间距 d ⟹ `tan δ = Δh/d` = **断层倾角**；倾向指向高程降低侧。
5. 若断层线在图上是**不受地形影响的直线**，则断层面**直立**，记 `/V`（本周题目全部如此）。

### C. 图法二：求截交线与 heave

📎 讲义只给结论，构造过程为重建：① 两盘**分别**画各自地层的等高线（`300E`/`300W` 后缀即区分盘别）；② **同一高程**的"地层等高线 × 断层面等高线"的交点，即该界面与断层面在该高程的交点；③ 不同高程的这类交点连起来 = 该盘的**截交线**；④ 另一盘同法得第二条；⑤ 两条截交线的图面间距 = **heave**，再由 `T = H·tan δ` 得 **throw**。

### D. 图法三：纯倾滑断层——作平行断层倾向的铅直剖面（Q1 用法）

讲义：断层为**纯倾滑**且**被错界线走向接近断层走向**时，作一条**平行断层倾向**的铅直剖面即可量出滑距大小，此时**滑距向量方位 = 断层的倾角/倾向**。剖面方位必须与断层严格对应：`153/57SW`（倾向 243）→ 剖面 `063/V`；`176/11W`（倾向 266）→ 剖面 `086/V`。
📎 若地层走向与断层走向斜交，铅直剖面量到的是**视断距**而非真滑距。

### E. 图法四：纯走滑断层——直接量图

讲义：纯走滑断层的滑距大小**就是视错移量本身**（需对地形造成的界线偏移作改正），方位 = 断层走向。`Q2Soln` B 批注补充：**直接量图即可、不必作剖面；但若两条截交线位于不同地形高程，需作三角改正**。

### F. 图法五（本周新技术）：断层面剖面 / 并置剖面

讲义对**一般情形（斜滑断层及走向不配合的倾滑断层）**给出的唯一解法：作**断层面剖面**——**在断层面这个平面内**作的剖面，**把上盘与下盘画在同一张剖面上**。

**步骤**（以 `JuxtapositionEG` 为例：地形完全平坦、高程 200 ft；断层 `120/V`；脉 `070/V`；另一条接触界线倾角 `30°`）：

1. **画剖面框**：走向 = 断层走向（`120/V`，两端标 W、E），纵轴为高程（100–500 ft）。断层直立时剖面即真实铅直平面，**无需任何展开变换**。
2. **投地形线**：地形平坦 200 ft ⟹ 剖面上是一条 200 ft 水平线（图注 "topography"）。
3. **投截交点**：地图上各界面与断层线的交点，按沿断层走向的距离投到地形线上，得四点 `vein(N)`、`vein(S)`、`contact(N)`、`contact(S)`。
4. **画各条截交线**：直立的脉与直立断层面的交线是**铅直线**（两盘各一条竖线）；倾斜界线的交线是**斜线**，斜率 = 该界面在断层面方向的视倾角（图注两处 `30°`）。
5. **找穿刺点**：每盘上"脉的截交线 × 界线的截交线"= 一个点，两盘各一个，**断层活动前本是同一点**。
6. **连线 = 滑距向量**：线段长度 = **净滑距**，与水平线夹角 = **侧伏角**（直立断层时即倾伏角）。本例读出 **58°、530 ft**，倾伏向 300。
7. **分解**：水平分量 = **走滑**、铅直分量 = **倾滑**（图注 "strike-slip"/"dip-slip"/"slip vector" 即标在此三角形上）→ 449 ft（up to north）、281 ft（dextral）。

📎 **为什么必须两条不平行界面**：一条界面的截交线只是**线**，两盘两条线只能给出某方向的分离量；两条不平行界面相交才产生**点**，有点才有真 slip。故本周题目都同时给"一条脉 + 一条地层界线"。

**脉的张开量修正**：`JuxtapositionEG` 与 `Q2Soln` A 都特别注明——脉体有宽度、是张开充填的，两盘对应必须**假设张开方向**（默认**垂直于脉壁张开**），否则解不唯一。这是采分点，须写出。

📎 **倾斜断层的断层面剖面怎么画**：把断层面沿走向"摊平"到纸面——横轴取沿断层走向的真实距离，纵轴取**沿断层面倾斜坡面的距离**（非高程）；高程 `h` 在剖面上是水平线，相邻高程 Δh 两线间距 = `Δh / sin δ`。截交点由"地层等高线 × 同高程断层面等高线"投影而来。摊平后量得的长度即断层面内**真长度**，夹角即 **pitch**，再用 `sin(plunge) = sin r·sin δ` 换算倾伏角。

### G. 📎 并置图（juxtaposition diagram / Allan diagram）

📎 背景补充：讲义只把它当求滑距的工具，但同一张图在油气/水文中另有读法，称 **Allan 图**，是"并置"一词的真正来源。

**画法**：在 F 做出的断层面剖面上，① 用一种颜色画出**下盘所有地层**的截交线，得到一组条带（每条 = 该层在断层面上的出露范围）；② 用另一种颜色把**上盘所有地层**的截交线画在**同一张剖面上**（即讲义强调的 "showing both the hanging wall and the footwall on the same section"）；③ 断层面被划成许多区块，每块对应"下盘某层 ↔ 上盘某层"的贴靠。

**读法**：**砂 ↔ 砂** 重叠区 → 储层连通、断层**不封闭**；**砂 ↔ 泥/页岩** → **并置封闭（juxtaposition seal）**，可成断层圈闭；把重叠区连片即可判断油气能否沿断层侧向逸散、**溢出点（spill point）**在哪。
**限制**：即使砂—砂并置，断层带内的**断层泥（fault gouge）**或**泥岩涂抹（shale smear）**仍可能封闭；反之涂抹不连续则封闭失效。并置分析给出的是**必要条件而非充分条件**，工程上还需 SGR 等指标。

## 四、课堂补充

> **本周无 transcript**（本课整门 10 周均无录音转写）。本段内容全部来自 `HandoutFault.md` 正文与三份答案图件的图注。

**讲义强调的注意事项与评分要点**

1. **描述滑距必须"两种方式都给"**。答案写法即范本：`Fault: 020/V; slip vector 70/020, 409 m; Dip-slip: 384 m (down to E); Strike-slip: 140 m (sinistral)`——**断层产状、滑距向量（方位+大小）、倾滑（大小+方向感）、走滑（大小+方向感）四段齐全**，缺一段即扣分。
2. **方向感措辞随断层产状变**：倾斜断层写 normal/reverse（`Q1soln-1` 两问均写 reverse）；直立断层无上下盘，改写 **"down to E"、"up to north"**——对直立断层写 normal/reverse 属不规范。
3. **分量为零也要显式写出**：`Q1soln-1` 两问与 `Q2Soln` A 均写 `strike-slip: 0 m`，B 写 `Dip-slip: 0 m`。
4. **必须写出所作假设**：涉及脉/岩脉时写明"假设垂直脉壁张开"，两份材料都单列此句。
5. **能省剖面时要说明理由**：`Q2Soln` B 示范——纯走滑可直接量图、剖面不必要，但须补"若截交线高程不同则需三角改正"。判断出"不必作剖面"本身是得分点，但前提要写明。
6. **判断方向感靠三维想象**：讲义原话——判断 normal/reverse、dextral/sinistral "不可避免地需要在脑中构建什么运动方向能产生观察到的视错移"，并建议**先求滑距向量方位、再回头判方向感**，顺序反了极易出错。

**作图约定**（由答案图注反推）：断层线比地层界线**更粗**，剖面上同样加粗区分；两盘地层等高线**分别绘制并标注盘别**（`300E`、`100W`、`500W`）；每张剖面必须标方位（`Section: 063/V`、`Fault plane section: 153/V`）与两端方位字母（NW–SE / NE–SW / W–E），纵轴标高程刻度；断层面剖面须标明哪侧是哪盘（"East/West side of fault"、"vein(N)"、"contact(S)"）；滑距分解三角形上要标出 **strike-slip、dip-slip、slip vector** 三条边。

## 五、Practical 要点

### 示例题（`JuxtapositionEG.md`）

**条件**：地形完全平坦、高程 200 ft；比例尺 0–500 ft；断层 `120/V`；脉 `070/V`（两盘同）；另一条接触界线倾 `30°`（两盘均标）；两者均被错开。
**要求**：作断层面剖面，求 (a) 净滑距；(b) 倾滑分量大小与方向感（南/北升降）；(c) 走滑分量大小与方向感（左/右旋）；(d) 滑距向量的倾伏角/倾伏向。
**解法**：照第三节 F 的 7 步。剖面取 `120/V`，地形为 200 ft 水平线；两盘脉各画一条**铅直**截交线、界线各画一条 `30°` 斜截交线；两盘各得一穿刺点；连线量得 58°、530 ft。
**答案**：`Fault: 120/V; slip vector 58/300, 530 ft; Dip-slip: 449 ft (up to north); Strike-slip: 281 ft (dextral)`。**必写假设**：脉的张开方向。

### Q1（`Q1soln-1.md`）——纯倾滑断层，铅直剖面法

**题干**：两幅地图各示一条**纯倾滑**断层；在每幅图上作**平行于断层倾向**的铅直剖面，求断层产状及滑距向量的方位、大小与运动方向感。
**给定**：等高线以米计，比例尺 0–500 m；剖面高程刻度 100–500 m；图上多处标 `11°`；地层等高线按盘标注（`400E`、`300E`、`100W`…）。
**解法**：① 由断层线与地形等高线交点作**断层面等高线**，得断层产状；② 两盘**分别**画地层等高线；③ 沿**断层倾向**布剖面线；④ 投影后量两条截交线沿断层面的距离 = 倾滑分量，因题设纯倾滑，**净滑距 = 倾滑分量**、滑距方位 = **断层倾角/倾向**；⑤ 看哪盘上升定 normal/reverse。

| 剖面 | 断层产状 | 滑距向量 | 倾滑 | 走滑 |
|---|---|---|---|---|
| `Section: 063/V` | `153 / 57SW` | `57 / 243`，**383 m** | 383 m（**reverse**） | 0 m |
| `Section: 086/V` | `176 / 11W` | `11 / 266`，**1140 m** | 1140 m（**reverse**） | 0 m |

（md 中两组数据并列、对应关系已丢失；按几何唯一反推：走向 153 / SW 倾 → 倾向 243 → 剖面 063；走向 176 / W 倾 → 倾向 266 → 剖面 086。）
**要点**：第二条是**倾角仅 11° 的低角度逆冲**，净滑距 1140 m 而 throw 仅约 217 m（📎 见三-A），易被"断距很大"的直觉误导。

### Q2（`Q2Soln.md`）——三条直立断层，断层面剖面法

**总条件**：`FAULT EXERCISES`；等高线以米计；比例尺 0–500 m；A/B/C 三题**断层均直立（/V）**；每题都给一条**直立岩脉（dyke, /V）**作第二标志面。

- **A**：岩脉 `063/V`，地层倾 `30°`，等高线标 `300E`、`100`–`400`。剖面 `Fault plane section: 153/V`（NW–SE，两侧标 West/East side of fault）。
  答案：`Fault: 153/V; slip vector: 90°, 267 m; Dip-slip: 267 m (down to E); Strike-slip: 0 m`。滑距**倾伏 90°**（纯铅直），故无倾伏向；直立断层写 "down to E"。**必写假设**：材料原注"只有假设岩脉的张开方向才能解此题（此处假设垂直脉壁张开）"。
- **B**：岩脉 `105/V` 或 `133/V`（md 把 B、C 图注混排，无法唯一分辨）；等高线含 `400E`、`400W`、`500W`。剖面 `Fault plane section: 156/V`（NW–SE）。
  答案：`Fault: 156/V; slip vector: 0/156, 600 m; Dip-slip: 0 m; Strike-slip: 600 m (dextral)`。滑距**倾伏 0°**（纯水平），沿走向 156 右旋 600 m。批注：直接量图即可，不必作剖面，但截交线高程不同时需三角改正。
- **C**：另一条岩脉；地层倾角标 `62°`（图注出现四次）。剖面 `Fault plane section: 020/V`（NE–SW），图上标出 dip-slip / strike-slip 分解三角形。
  答案：`Fault: 020/V; slip vector 70/020, 409 m; Dip-slip: 384 m (down to E); Strike-slip: 140 m (sinistral)`。本题为**斜滑断层**，两分量均不为零，必须靠断层面剖面的两个穿刺点求解（验算：409·sin70°=384、409·cos70°=140 ✓）。技术含量最高。

**三题的设计逻辑**：A 纯倾滑 → B 纯走滑 → C 斜滑，把讲义的"三种情形"逐一落地。

## 六、易错点 / 重点难点

1. **上盘/下盘判反**。断层面之上为上盘、之下为下盘；先把断层倾向画对再判断。**直立断层无上下盘**，写 normal/reverse 即错，须写 "down to E"/"up to north"。
2. **throw 与 net slip 混淆**。throw 只是**铅直分量**，net slip 是三维向量的模，只有直立断层 + 纯倾滑时二者相等（Q2 A：267 m）。Q1 那条 11° 逆冲最说明问题：净滑距 1140 m，throw 仅约 217 m。
3. **看到水平错移就断言走滑**。**倾斜地层被纯倾滑断层错开，平面上照样有水平错移**；判据是"两条产状不同的界线视错移是否相同"。Q1 两题正是"看似走滑、实为纯倾滑逆断层"的标准反例。
4. **separation 与 slip 混为一谈**。只有一条界面时量得再准也只是 separation；求 slip 必须有**两条互不平行的标志面**产生穿刺点。
5. **忘记脉/岩脉的张开方向假设**（材料两处单列强调，是采分点）；**纯走滑时忘记地形改正**（`Q2Soln` B 批注指出截交线高程不同时直接量图有误差）。
6. **剖面方位取错**。纯倾滑的铅直剖面**平行断层倾向**（153/57SW → 063/V）；断层面剖面**沿断层走向**（断层 153/V → 剖面 153/V）。两者差 90°，混用会得到完全错误的数值。
7. **📎 并置分析忽略断层泥**。只做砂—泥并置图不够：断层泥/泥岩涂抹可让砂—砂并置处仍封闭，涂抹不连续则"看似封闭"的构造也渗漏——并置图只给**必要条件**。
8. **📎 漏判断层造成的地层缺失/重复**。走向正断层常致**缺失**，逆断层常致**重复**；同一套地层在剖面方向重复出现，应先怀疑逆断层或褶皱，而非新增地层单位。
