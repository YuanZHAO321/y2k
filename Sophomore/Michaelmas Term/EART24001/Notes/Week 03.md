## 一、本周主题

全课主线是**如何在二维图幅上表达并解读三维地质结构**。W1–W2 打地基：产状的两种写法、地层等高线（strike line = stratum contour）、由零星露头补全地质图。从本周起进入**逐类构造攻克**：不整合（W3）→ 褶皱（W4）→ 断层（W5）→ 侵入体与事件序列（W8）；中途 W6–W7 插入赤平投影与方向数据统计，W9–W10 在真实图幅上综合。

**不整合是逐类构造的第一类**，选它打头很合理：它几何上最简单——不整合面上下各是一套产状均一的地层，各自都能用 W1–W2 的老工具独立处理，新东西只有一条：**两套地层等高线要分开画、再叠加起来读**。也就是把已学工具用两遍，再解释两遍之间的地质含义（时间缺失、构造事件）。

对应 ILO 2（识别不整合并与地形造成的露头形态区分）、ILO 3（据图分析三维几何）、ILO 5（用切割关系组装事件序列）。讲义标题为 **THE GEOMETRY OF UNCONFORMITIES (1)/(2)**，分两块：按不整合面**自身几何**分类、按地层与不整合面的**方位关系**分类。实习仅一道 Q1，含 5 小问，是"全流程"综合题。

## 二、核心概念

### 2.1 定义（讲义原文）

> An **unconformity** is a surface of contact separating younger sedimentary rocks from older igneous, metamorphic or sedimentary rocks, along which there is evidence of a significant time-break (**hiatus**) in the geologic record due to erosion and/or a break in the sedimentation.

三个必备要件：①它是一个**接触面**，因此和普通层面一样可量产状、可画等高线；②面上为**较年轻的沉积岩**，面下为较老的火成／变质／沉积岩；③存在**显著时间缺失（hiatus）**，成因为**剥蚀和／或沉积间断**（"and/or"，不可写成 and）。讲义脚注特别区分：整合层序中单个层面代表的**短暂**间断叫 **diastem**，不是 hiatus。

### 2.2 两套分类体系

讲义明说依据有二：**(a)** 不整合面的形状及两侧岩层方位——强调**不整合的几何**；**(b)** 岩层与不整合面的方位关系——在**沉积层序分析**中有意义。二者非替代关系：(a) 回答"什么类型、经历了什么构造事件"，(b) 回答"海平面／沉积中心怎么移动"。**地质图题主要用 (a)。**

### 2.3 体系 (a)：按不整合几何分类

| 类型 | 讲义定义要点 | 图面表现 |
|---|---|---|
| **角度不整合 angular unconformity** | 新沉积物覆于**已倾斜或褶皱**的老岩层剥蚀面上；含义是倾斜／褶皱发生在不整合代表的时间间断内 | 上下两套**产状不同**，不整合面**截切**下伏层面 |
| **平行不整合 parallel unconformity** | 面两侧岩层方位相同（同倾角同倾向） | 上下产状一致 |
| ├ **disconformity 假整合** | 不整合面本身是**可见的、起伏不规则**的剥蚀面（如埋藏古地形 buried landscape） | 界面呈起伏侵蚀面 |
| └ **paraconformity 沉积间断** | 界面不可见，**只能靠记录缺失**（如缺失生物带）识别 | 图上与普通层面无异 |
| **非整合 nonconformity** | 新沉积物覆于老的**火成岩或变质岩**之上；同义 heterolithic unconformity | 面下为侵入／变质基底 |

> 📎 背景补充：中文常把 disconformity 直译"平行不整合"，但讲义把 **parallel unconformity 当上位概念**，disconformity 与 paraconformity 是其两个下位型，答题须跟随此层级。另外四型在平面图上的**可判别性差别极大**：角度不整合最易（两组界线走向不同、被一条线截断）、非整合次之（面下无层理）；disconformity 只能靠不整合面**起伏且不平行于层面**的等高线形态看出；**paraconformity 在地质图上根本判不出来**，必须靠古生物或年代学证据。

### 2.4 体系 (b)：地层与不整合面的方位关系

**(A) Lapout 尖灭**：**(A1) Toplap 顶超**——面**之下**的地层向面减薄尖灭；**(A2) Baselap 底超**——面**之上**的地层向面减薄尖灭，含 **(A2a) Onlap** 与 **(A2b) Downlap**。

**(B1) 就老地层而言**：**B1a Erosional truncation 剥蚀削截**——不整合面是切入下伏地层的剥蚀面（如河道底面）；**B1b Toplap 顶超**——面以**原始倾斜层**（如三角洲前积层 foresets）被截断为标志，通常源于**不沉积＋轻微剥蚀**（与 B1a 的区别：削截以剥蚀为主）；**B1c Concordance 协调**——面与下伏层面平行。

**(B2) 就新地层而言**：**B2a Onlap 上超（= overlap 超覆）**——新地层近水平、不整合面倾斜，依次更年轻的地层依次覆于面上；成因是更年轻地层横向范围更大而超覆先前沉积物，经典对应**海平面相对上升（海侵 transgression）**。讲义在此括注 **overstep unconformity**：以类似方式产生，表现为**依次更新的岩层覆于下伏层序中依次更老的成员之上**，但作为描述**不含沉积学意义**。**B2b Downlap 下超**——新地层倾斜、沿下倾方向向面尖灭；**B2c Concordance**——面与上覆层面平行。

**(B3) 就上覆地层的后退而言**：**B3a Offlap 退覆**——上覆各层横向范围依次变小；**B3b Basinward shift**——offlap 的分级跳跃式变体。

> 📎 背景补充：**onlap 与 overstep 是本周最易混的一对**，剖面画出来几乎一样，区别在观察对象：onlap 看**上盘**（一套地层依次向面尖灭，有海侵含义）；overstep 看**下盘**（同一个上覆单元横向坐落在越来越老的下伏单元上，纯几何描述）。**地质图上看到的几乎总是 overstep**——因为图上能直接读出"e 一会儿压在 d 上、一会儿压在 a 上"。

### 2.5 不整合面本身也是一个地质面

> 📎 背景补充：这是本周作图的**总钥匙**，讲义未明说但整道 Q1 建立于此。不整合面是有产状的真实界面，因此：可量走向倾角（如 090/1.5 S）；**可画地层等高线**，画法与任何层面相同；它与**地形面**的交线 = 不整合在图上的**出露界线**；它与**下伏各层面**的交线 = **次露头线（subcrop line）**。
> 一句话：**有不整合的图 = 两张普通图叠在一起**，中间用不整合面这把"剪刀"裁开；上面那张只在面之上有效，下面那张只在面之下有效。

### 2.6 不整合代表的时间与事件

> 📎 背景补充：任一角度不整合至少读出**五步事件**（ILO 5 标准答法）：①下伏地层由老到新依次沉积 → ②下伏地层**变形**（倾斜／褶皱）——由上下**产状差**证明 → ③**抬升＋剥蚀**——由不整合面截切下伏层面（削截／overstep）证明 → ④重新沉降／海侵，上覆地层沉积 → ⑤上覆地层后期轻微掀斜，再剥蚀至今日地形。时间缺失量＝下伏最新单元顶部与上覆最老单元底部的年龄差；**本周材料无年龄数据，无法量化**。

## 三、公式与图表

讲义正文只给分类学，作图方法全部由答案图注反推，本节除引用数字外方法部分均为 📎 背景补充。

### 3.1 地层等高线基本公式（W1–W2 复习）

倾斜面上可画的水平线叫 **strike line（= stratum contour）**，其方位角即**走向**；**倾角**在垂直走向方向上量。

$$s = \frac{\Delta h}{\tan\delta}$$

$s$＝相邻两条地层等高线的**图上水平间距**，$\Delta h$＝二者**高程差**，$\delta$＝倾角。反求产状：量 $s$ 与 $\Delta h$ 得 $\delta=\arctan(\Delta h/s)$；等高线方位即走向，**高程增大方向为上倾**，反向即倾向。

代入 Q1 两个答案自检：13° → $s=100/\tan13°=433$ ft（≈0.43 个 1000 ft 比例尺条）；1.5° → $s=100/\tan1.5°=3819$ ft（≈3.8 个比例尺条）。**两族等高线图上间距相差近 9 倍、走向差 60°**——这就是角度不整合在图面上最直观的量化表现。

### 3.2 真厚度

$$t = v\cos\delta \qquad t = w\sin\delta$$

$t$＝真厚度（垂直层面量），$v$＝该单元顶底两面的地层等高线**高程差**，$w$＝水平地面上沿倾向的**露头宽度**。

用答案自检：unit c 真厚度 485 ft → $v=485/\cos13°=498\approx500$ ft；unit b 95 ft → $v=97.5\approx100$ ft。说明 c 顶底相差 5 个等高距、b 相差 1 个，与 100 ft 等高距体系完全自洽，**反过来验证 13° 这个读数是对的**。

### 3.3 视倾角（画剖面必用）

$$\tan\alpha = \tan\delta\cdot\cos\theta$$

$\alpha$＝剖面上的**视倾角**，$\theta$＝剖面线方位与倾向的夹角。Q1 剖面为 **060/V**（方位 060，V＝垂直剖面）：
- 下伏 13/240：倾向 240 与剖面 060–240 **共线**，$\theta=0°$，$\alpha=13°$ —— 剖面显示**真倾角**。出题人**故意把剖面线放在下伏地层的倾向线上**，使剖面上量到的即真厚度。
- 上覆 1.5/180：$\theta=60°$，$\alpha=\arctan(\tan1.5°\times0.5)=0.75°$ —— 剖面上几乎完全水平。

这解释了答案图注上 **"true thicknesses (along line of section)"** 的措辞：对 a–d 是真厚度，对 e、f 严格说是视厚度，但 1.5° 下差别不可分辨。

### 3.4 不整合图幅的标准作图流程（📎 背景补充）

**0 识别不整合**：找一条**横切**另一组地层界线的界线；等价判据是**同一个上覆单元在不同地点分别压在不同的下伏单元上**（overstep）。务必先把"真截切"与"地形造成的露头弯曲"分开（ILO 2 原话）——地形弯曲不改变界线的走向趋势，截切会。

**1 为不整合面画地层等高线**：不整合面＝**面之上最老单元的底面**（本题 base of e）。找该界线与**地形等高线**的全部交点，交点高程＝地形等高线高程，把**等高程交点连成直线**即得一条地层等高线；连出 2 条即可读产状。

**2 为不整合面之下的一个界面画等高线**（本题 base of b）：做法相同，但只能用**下伏地层出露区**的交点。答案图上该族标注 **−600 ~ +400 ft**（11 条），说明该面在东北端出露于 400 ft、向西南潜入海平面下 600 ft。

**3 叠加**：两族画在同一张图上，**分色／分线型**，各自标注 "base of b"、"base of e"（答案图正是如此）。

**4 求次露头线**：两族中**数值相同的两条线的交点**同时位于两个面上且高程相同，故位于**两面的交线**上；把同值交点连起来即得 base of b 与不整合面的交线。含义：**线的一侧不整合面正下方是 b，另一侧是 a**。对 base of c、base of d 重复，即得完整的**不整合面之下的地质图（subcrop map）**——这才是回答"e 分别压在哪些单元上"的正规做法。

**5 求不整合的出露界线**：不整合面等高线与**同值的地形等高线**的交点，连线即得。

**6 判断盖层去留**：不整合面**低于**地形面处，e、f 保存；**高于**地形面处，盖层已被剥掉，出露 a–d。本题不整合面近水平且高程落在地形起伏范围内，结果是**盖层残留在高地、老地层出露于谷地与海岸带**。

> 📎 背景补充：这种被剥蚀切成互不相连的年轻残片叫 **outlier**；反之被年轻地层包围的老地层露头叫 **inlier**。答案图注中 "e f"、"f e" 出现在多处互不相邻位置，正是典型 outlier 分布。

**7 绘剖面**：①沿 A–B 读地形等高线交点，先画**地形剖面线**；②把不整合面等高线与 A–B 的交点按高程投到剖面上连成直线（平面故为直线）；③同法投出 base of b/c/d；④**所有下伏界面必须终止于不整合面**，绝不穿过；⑤上覆 e、f 平行于不整合面叠加，终止于地形剖面线；⑥标注左 SW／右 NE、方位 **060/V**、比例尺条、**"vertical = horizontal scale"**。

**8 绘地层柱**：按真厚度**按比例**自下（老）而上（新）叠画 a→f，**d 与 e 之间用波状线**表示不整合，旁注各单元真厚度。

## 五、Practical 要点

本周仅一道 **Q1 — UNCONFORMITIES**，配两份答案图。**辨析：soln1 与 soln2 不是两问，而是同一题的两张答卷**——soln1 是**已作答的地质图**（含 5 小问题干与图上作答），soln2 是**第 (4) 问的 A–B 剖面 + 第 (5) 问的真厚度结果**。

**题干（soln1 原文）**：(1) 在图上标出不整合；(2) 不整合**之下**与**之上**的地层产状各是多少？两种格式都要写；(3) 由倾向确定单元的层序；(4) 沿 A–B 作准确剖面；(5) 按比例作地层柱并给出各单元真厚度。

**给定条件（由答案反推）**：海岸区地质图，等高线单位英尺，比例尺条 1000 ft，北箭头，含海域；出露 6 个单元 **a–f**；剖面线端点 A（西南）、B（东北），方位 060。**图上不给任何产状符号**——所有产状须自行用地层等高线求出，这是本题难点。

**(1) 圈出不整合**：单元 **e** 在不同位置分别与 **d、c、b、a** 直接接触，即同一单元横向压在依次更老的单元上（**overstep**），且 e、f 界线走向与 a–d 明显不同。故不整合面＝**base of e**，位于 **d 与 e 之间**。

**(2) 产状**：不整合**之下**（以 base of b 为代表）**150/13 SW ＝ 13/240**；不整合**之上**（即 base of e）**090/1.5 S ＝ 1.5/180**。求法见 3.4 第 1–2 步。**两套产状之差（走向差 60°、倾角差 11.5°）就是"角度不整合"的定量证据**，也是第 (1) 问的答案依据。

**(3) 层序**：单斜中**沿倾向依次变新**。下伏倾向 240 → 自东北向西南 **a → b → c → d**；上覆倾向 180 → 自北向南 **e → f**。全序列由老到新：**a, b, c, d ‖ e, f**（‖ 为不整合）。

**(4) 剖面（060/V）**：见 3.4 第 7 步。因 060 与倾向 240 共线，a–d 在剖面上显示**真倾角 13°**、向图左（SW）倾；e、f 视倾角仅 0.75°，近水平。a–d 各界线止于不整合面；不整合面在剖面上是一条近水平直线，其上依次 e（100′）、f。纵轴 0–800′，等比例尺。

**(5) 地层柱与真厚度**：按比例作柱，d 与 e 之间画波状不整合线。结果 **f 140′(min) — e 100′ — ≈不整合≈ — d 640′(min) — c 485′ — b 95′ — a 330′(min)**。下伏 a–d 合计 **≥1550 ft**，上覆 e–f 合计 **≥240 ft**。

> 📎 背景补充（题目未问，但 ILO 5 与期末常延伸）：**事件序列** = a→b→c→d 依次沉积 → 掀斜至 13/240 → 抬升剥蚀，形成近水平剥蚀面并削截 d 及更老单元（产生 overstep）→ 重新沉降，e、f 沉积 → 上覆套轻微掀斜至 1.5/180 → 抬升剥蚀至今日地形，e、f 仅残留为高地上的 outlier。

## 六、易错点 / 重点难点

1. **把两套地层等高线混作一套**——本周头号错误。两族**走向不同、间距不同、含义不同**，必须分色分族并逐条标注所属界面；一旦在交叉密集处串线，subcrop line、出露界线、剖面全盘皆错。
2. **剖面上把下伏单元画穿了不整合面**。下伏地层顶部已被剥掉，剖面上必须**硬止于不整合线**；同理下伏地层的等高线不能延伸到面之上去解释那里的露头。
3. **削截关系判反**。判据是"**谁被谁截断**"——被截断的一方**更老**。本题 d 顶被削截，故 d 老于 e。检查手段：看**同一单元是否横跨多个下伏单元**，横跨者必为上覆。
4. **事件序列先后排错**，常把"倾斜"放到不整合之后。正解：下伏倾 13°、上覆仅 1.5°，说明 **13° 中约 11.5° 发生在不整合之前**，只有 1.5° 是两套共同经历的后期掀斜——**产状差＝不整合期间的变形量**。
5. **产状写法不合规**：走向写 330（应 150）、dip direction 折算成 060（应 240）、漏写倾向字母、只答一种格式。
6. **厚度漏写 "minimum"**，或把 vertical thickness 当真厚度（少乘 $\cos\delta$）。13° 时误差仅 2.6% 容易蒙混，倾角 40°–50° 时误差极大，务必养成用 $t=v\cos\delta$ 的习惯。
7. **视倾角当真倾角**。只有剖面线**平行于倾向**时剖面上量到的才是真值；本题下伏套恰好满足（060∥240），上覆套并不满足（θ=60°）。
8. **onlap 与 overstep 混用**进而错误推断海侵；**disconformity 与 paraconformity 混淆**（前者界面可见、后者不可见）。
9. **把地形造成的露头弯曲误判为构造截切**（ILO 2 点名的错误）：地形弯曲不改变界线整体走向趋势且与等高线形态相关（"V"字法则），构造截切表现为走向突变与界线终止。
10. **把 1.5° 当成水平**。倾角虽小，但在 10000 ft 量级图幅上高差可达数百英尺，足以决定 e、f 何处保存何处被剥蚀。

## 七、本周术语表

| 英文 | 中文 | 要点 |
|---|---|---|
| unconformity | 不整合 | 分隔较新沉积岩与较老岩体、存在显著时间缺失的接触面 |
| hiatus | 时间间断 | 不整合代表的**显著**记录缺失 |
| diastem | 层间微间断 | 整合层序中单个层面代表的**短暂**间断，非不整合 |
| angular unconformity | 角度不整合 | 新沉积物覆于**已倾斜／褶皱**老岩层的剥蚀面上 |
| parallel unconformity | 平行不整合 | 面两侧产状**相同**；含 disconformity 与 paraconformity |
| disconformity | 假整合（可见剥蚀面型） | 界面为**可见、起伏**的剥蚀面（埋藏古地形） |
| paraconformity | 沉积间断（隐蔽型） | 界面不可见，仅靠**记录缺失**识别 |
| nonconformity | 非整合 | 新沉积物覆于老的**火成岩或变质岩**上；同义 heterolithic unconformity |
| lapout | 尖灭 | 地层向不整合面减薄尖灭的统称 |
| toplap | 顶超 | 面**之下**地层向面尖灭；或原始倾斜层被截断（不沉积为主） |
| baselap | 底超 | 面**之上**地层向面尖灭；含 onlap、downlap |
| onlap / overlap | 上超 / 超覆 | 近水平新层依次覆于倾斜不整合面；对应**海侵** |
| downlap | 下超 | 倾斜新层沿下倾方向向面尖灭 |
| offlap | 退覆 | 上覆各层横向范围依次变小 |
| basinward shift | 向盆地迁移 | offlap 的分级跳跃式变体 |
| erosional truncation | 剥蚀削截 | 不整合面切入下伏地层 |
| concordance | 协调（平行） | 不整合面与上／下层面平行 |
| overstep | 超覆不整合／截超 | 依次更新的岩层覆于依次更老的下伏成员上；**无沉积学含义** |
| strike line / stratum contour | 走向线／地层等高线 | 倾斜面上的水平线，方位角即走向 |
| strike / dip / dip direction | 走向／倾角／倾向 | 走向三位数取 000–180；倾角一至两位；倾向三位且不折算 |
| apparent dip | 视倾角 | $\tan\alpha=\tan\delta\cos\theta$；即 pitch |
| true thickness | 真厚度 | $t=v\cos\delta=w\sin\delta$ |
| subcrop (line) | 次露头（线） | 不整合面正下方的地质分布；两族等高线同值交点连线求得 |
| outlier / inlier | 外露层／内露层 | 孤立的年轻残片／被年轻地层包围的老地层露头 |
| homocline | 单斜 | 产状均一的地层序列，沿倾向变新 |
| cross-section 060/V | 垂直剖面（方位 060） | 本课程剖面标注格式，V＝vertical |
