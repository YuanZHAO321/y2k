## 二、核心概念：褶皱与断层叠加时的图面判据对照表

📎 **背景补充：本节几乎全部为补充内容。** 本周材料只给出了答案数值和一句「It is not possible to say, based on the map, which came first - folding or faulting」，并未给出判据清单。以下对照表是我把 W3–W5、W8 的规则整合成的速查表，供考前直接用。

### 2.1 断层切割褶皱 vs 褶皱变形断层（时序判据）

📎 **背景补充：**

| 判据 | 断层**后于**褶皱（断层切褶皱） | 断层**先于**褶皱（褶皱把断层也弯了） |
|---|---|---|
| **断层线本身是否被弯曲** | 断层迹线为直线 / 平滑；在断层上画地层等高线是**直、平行、等距**的 → 断层面是**平面** | 断层迹线随褶皱波形而**弯折**；断层上的等高线**不平行、不等距** → 断层面已被弯成**曲面** |
| **断层面产状是否随位置变** | 全图只有**一个**断层产状 | 断层产状在**背形翼与向形翼上不同** |
| **褶皱轴迹是否被错断** | 轴迹（axial trace）在断层两侧**错开**，错距与滑移矢量一致 | 轴迹**连续穿过**断层，不被错开（因为褶皱后生成） |
| **两盘褶皱要素是否可对比** | 两盘褶皱轴产状**相同**（同一次褶皱被切开），只是位置平移 | 两盘褶皱轴产状仍相同，但断层的**倾角/走向**两侧不同 |

**核心一句话：判据的钥匙是「断层线本身是否被弯曲」。** 断层是平面 → 它形成时周围已经不再变形，即断层晚于褶皱（或至少未被该次褶皱改造）；断层是曲面 → 它被后来的褶皱一起卷进去了。

📎 **本周 Q1 的特殊性（推断）：** 材料明确写「无法判断孰先孰后」。我的推断理由是——本题褶皱轴为 **0/100**（走向近 E–W、水平），断层走向 **090**，两者仅差约 10°，**近乎共轴**。这种情况下：(i) 若断层后生成，它平面地切过褶皱，图上表现为地层界线沿断层错开；(ii) 若断层先生成，随后被一个轴向与它几乎平行、且**极为平缓（内翼角 147°）**的褶皱改造，断层面只会被轻微倾斜、仍近似平面，图面几乎看不出差别。两种情形产生的图案在本图精度下不可区分，故答案是「不能判断」。**材料未说明理由，此处为推断。**

### 2.2 地层重复（repetition）的两种成因

📎 **背景补充：**

| | **褶皱造成的重复** | **逆断层造成的重复** |
|---|---|---|
| 对称性 | 关于某条线**镜像对称**（S1-S2-S3-S2-S1），这条对称轴就是**轴迹** | **不对称**：同一套层序沿一条界线**平移叠置**，无镜像关系 |
| 倾向 | 对称轴两侧地层**倾向相反**（背形：相背倾；向形：相向倾） | 界线两侧地层倾向、倾角**基本一致** |
| 分界线性质 | 是一条**虚拟的轴迹**，不是岩性界线，两侧岩性连续 | 是一条**真实的断层面**，可在其上画地层等高线 |
| 新老关系 | 背形核部**最老**、向形核部**最新** | 上盘（hanging wall）把**较老**地层推到较新地层之上 |

**实操钥匙：先找对称性。** 在图上横切构造走一条测线，把出露的地层单元按顺序抄下来，如果读出 `a-b-c-b-a` 这种回文，几乎一定是褶皱，回文中心即轴迹；如果读出 `a-b-c | a-b-c`，则是断层（或不整合）重复。

### 2.3 地层缺失（omission）的两种成因

📎 **背景补充：**

| | **正断层造成的缺失** | **不整合造成的缺失** |
|---|---|---|
| 界线形态 | 一条**较直/规则**的线，可在其上画出直、平行、等距的地层等高线（平面） | 常是**不规则起伏**的面（古地形），等高线弯曲不规则 |
| 两侧产状 | 两侧地层产状**相同**（同一构造被切断） | 角度不整合下伏地层产状与上覆**不同**（下伏被褶皱/倾斜） |
| 缺失的层位 | 缺失的**层数沿断层走向大致恒定** | 缺失层位**横向变化**（overstep：越往一侧上覆层压在越老的层上） |
| 界线与地层的关系 | 断层**同时切断**上下盘的所有界线 | 不整合面**只截断**下伏地层，上覆地层与之**平行/上超** |
| 岩性证据 | 可能有断层角砾（fault breccia）、擦痕 | 常有**底砾岩（basal conglomerate）**、风化壳 |

### 2.4 走向错移 ≠ 走滑（本课反复强调的陷阱）

W5 讲义原文：「the offset of a contact along a fault shown on a map does **not** imply that there was a strike-slip component to the slip vector」。

判别法（W5 原文）：
- 图上**两条走向不同**的界线，被同一条断层错开**不同的视错距** → 滑移矢量有**倾滑分量**；
- 两条走向不同的界线，视错距**相同** → 滑移矢量**无倾滑分量**（纯走滑）。

📎 **背景补充：** 本周 Q1 正是「纯倾滑断层却在图上造成明显水平错移」的标准例子——答案 `34/000；120 m (normal)`，滑移矢量的倾伏向 000 与断层倾向完全一致，说明**零走滑分量**，但图上界线依然左右错开，那是因为地层本身倾斜、断层造成高程升降后界线的出露位置随之横移。

## 三、公式与图表（本课几何关系总汇 + 剖面构建流程）

📎 **背景补充：本节的公式清单与流程描述均为整合补充**，本周材料只提供了可供验算的数值答案。为了让公式有「抓手」，我在每条公式后都用本周的真实数字做了验算。

### 3.1 由地层等高线求倾角

$$\tan\delta = \frac{\Delta h}{d}$$

- $\Delta h$：相邻两条地层等高线（stratum contour / strike line）的**高差**；
- $d$：这两条线在图上的**垂直间距换算成的实地水平距离**；
- $\delta$：该面的**真倾角**（true dip）；倾向垂直于地层等高线，指向**高程降低**的一侧。

📎 **本周验算（比例尺 1:40000，等高距按 100 m）：**
- 缓翼 δ = 14° → $d = 100/\tan 14° = 401$ m → 图上约 **1.0 cm**；
- 陡翼 δ = 19° → $d = 100/\tan 19° = 290$ m → 图上约 **0.73 cm**；
- 断层 δ = 34° → $d = 100/\tan 34° = 148$ m → 图上约 **0.37 cm**。

这组数字的用处：作图时如果你画出来的等高线间距明显偏离上述量级，说明连线连错了。

### 3.2 断距三兄弟：throw / heave / dip-slip

对**纯倾滑断层**，滑移矢量长度 $|S|$、断层倾角 $\delta$：

$$\text{throw（落差，垂直分量）} = |S|\sin\delta$$
$$\text{heave（平错，水平分量）} = |S|\cos\delta$$
$$\boxed{\text{heave} = \frac{\text{throw}}{\tan\delta}}$$

📎 **本周 Q1 验算：** $|S| = 120$ m，$\delta = 34°$
- throw $= 120\sin34° = 67.1 \approx$ **67 m**
- heave $= 120\cos34° = 99.5 \approx$ **100 m**
- 校验：$67.1/\tan34° = 99.5$ ✓

W5 讲义还给了一族相关术语（**separation** 家族）：strike separation（= 图上视错距）、dip separation、vertical separation、stratigraphic separation、hade（= 90° − dip，从竖直起算的倾角）。**cut-off line** 是目标界面与断层面的交线，上盘、下盘各一条，**两条 cut-off line 在图上的间距就是 heave**。

### 3.3 滑移矢量的分解（一般斜滑情形）

设滑移矢量在断层面内的 pitch 为 $p$：

$$\text{dip-slip 分量} = |S|\sin p,\qquad \text{strike-slip 分量} = |S|\cos p$$
$$|S| = \sqrt{(\text{dip-slip})^2+(\text{strike-slip})^2}$$

📎 **本周 EPQ2 验算：** 断层 `000/V`（竖直），滑移矢量 `71/180`，$|S| = 329$ ft
- dip-slip $= 329\sin71° = 311.1 \approx$ **311 ft** ✓（材料答案 311 ft，down to W）
- strike-slip $= 329\cos71° = 107.1 \approx$ **107 ft** ✓（材料答案 107 ft，sinistral）
- 反查：$\sqrt{311^2+107^2} = 328.9 \approx$ **329 ft** ✓
- $\tan71° = 2.90$，而 $311/107 = 2.907$ ✓

### 3.4 pitch 与 plunge 的换算

$$\sin(\text{plunge}) = \sin(\text{dip of plane}) \times \sin(\text{pitch})$$

- W6 的做法是在赤平网上量：把面画成大圆，从走向端沿大圆数进 pitch 度得点，再把该点转到 E–W 线上读 plunge。
- 📎 **本周 EPQ2 的特例：** 断层竖直（dip = 90°），$\sin90° = 1$，故 **plunge = pitch = 71°**。这就是为什么在竖直断层的断层面剖面上，可以**直接用量角器量出滑移矢量的倾伏角**，不必再上赤平网。竖直断层是最省事的一类，考试常拿来出题。

### 3.5 视倾角与真倾角

$$\tan\delta_{app} = \tan\delta \times \sin\theta$$

$\theta$ 为**剖面线走向与该面走向之间的夹角**。$\theta = 90°$ 时视倾角 = 真倾角；$\theta = 0°$ 时视倾角 = 0。

📎 **本周 Q1 验算：** 剖面 A–B 的产状是 `000/V`（走向 000 的竖直面）。
- 对**断层**（走向 090）：$\theta = 90°$ → 剖面上画的 34° 就是**真倾角**，滑移矢量可直接量。这正符合 W5 讲义那条规则——「纯倾滑断层且被错断界线走向与断层接近时，沿**断层倾向方向**作垂直剖面即可求得滑移矢量」。
- 对**褶皱翼**（走向 100）：$\theta = 100°$，$\sin100° = 0.985$ → 14° 的翼在剖面上画成 **13.8°**，19° 的翼画成 **18.7°**。差别不到 0.5°，作图上可忽略，但**必须知道它在原理上是视倾角**。

### 3.6 真厚度换算

📎 **背景补充：** 三种常用情形——
1. 地形平坦、露头宽度 $w$（垂直走向量）：$t = w\sin\delta$；
2. 用地层等高线：上、下界面同一高程的等高线之间的水平距 $x$ → $t = x\sin\delta$；上、下界面在同一垂线上的高差 $v$ → $t = v\cos\delta$；
3. W9 的 Marlborough 题就是这个套路：分别在 Middle Chalk 上、下界面画等高线，再量厚度；材料还提醒厚度会横向变化——**判据是上、下界面的等高线不严格平行/等距**。

### 3.7 **综合垂直剖面的构建流程（本课最核心的操作规程）**

📎 **背景补充：以下八步流程为整合补充**，本周材料只呈现了成品剖面（`Q1soln2`），并未列出步骤。但成品图上的每一项细节都反过来印证了这些步骤。

**第 0 步 — 定剖面产状与比例。** 在图上量出 A→B 的方位，写成剖面标题，本周是 **`000/V`**（走向 000 的竖直剖面）。**明确标注哪端是 N、哪端是 S**（本周剖面标了 A、B 与南北）。选比例：`Q1soln2` 明确写 **horizontal scale = vertical scale**，即**垂直放大率 = 1**。
> ⚠️ 只要剖面要用来**量角度或量滑移矢量长度**，垂直放大率**必须是 1**，否则量出来的倾角和滑移量全是错的。W9 那种为了「看清楚」而用 ×5 垂直放大的剖面，只能用于**图示**，不能用于**测量**。

**第 1 步 — 画地形剖面（topographic profile）。** 沿 A–B 把纸边（或坐标纸）压在剖面线上，逐条地形等高线在纸边上打点并记高程，转到剖面坐标系上，连成平滑地形曲线。本周剖面纵轴 0–1000 m。

**第 2 步 — 投影地质界线与断层的**出露点**。** 沿同一条剖面线，把地质界线（砂岩/泥岩接触面、泥岩/砾岩接触面）和断层迹线与剖面线的交点也打到纸边上，投到地形曲线**上**的对应位置。

**第 3 步 — 用地层等高线定倾角，不要目测。** 在每个出露点处，按该处**地层等高线**给出的产状确定倾角；若剖面线不垂直于走向，先用 3.5 的公式换成**视倾角**再画。本周：断层画 34°（真=视），褶皱翼画约 14° 与 19°。

**第 4 步 — 向深部延展界面。** 假设界面在剖面深度范围内**保持平面**（除非等高线显示它弯曲），把每条界线按定好的倾角向下延伸。褶皱部分则按「两翼 + 转折端」的形态连接，**转折端要圆滑，不能画成尖角**（除非确证是尖棱褶皱）。

**第 5 步 — 处理断层。** 先把断层面按 34°N 画到底，再分别在上盘、下盘把地层画完；**上盘、下盘的同一界面在断层面上必须错开一个等于 throw 的高差**（本周 throw ≈ 67 m）。断层两侧的地层不能画成连续的。

**第 6 步 — 检查地层厚度守恒。** 同一地层在剖面上任何位置、任一盘、任一褶皱翼上的**垂直于层面的厚度必须一致**（除非题目告诉你厚度变化）。这是最有效的自查手段：厚度变了，说明某处倾角或界线位置画错了。

**第 7 步 — 补齐规范要素。** 参照 W9 Cover 的明确要求：
(a) 标题写明剖面产状（strike/dip）；(b) 标出两端方位；(c) 水平与垂直比例尺；(d) **按比例画的地层柱（stratigraphic column）**含颜色与字母图例；(e) 剖面上各岩性单元的着色与字母。本周剖面用了 **a = Grit（最老）、b = Mudstone、c = Sandstone（最新）**。
（**注意**：地层新老由此确定 —— 砾岩最老、砂岩最新。判断背形/向形与背斜/向斜时要用到。）

**第 8 步 — 界面延伸到地形面以上。** W9 明确要求把界面**用虚线延伸到地形面之上**（表示被剥蚀掉的部分）以及地形面之下。本周剖面纵轴到 1000 m 而地形最高约 900 m，正是为了容纳这段虚线。

### 3.8 **断层面剖面（fault plane section / juxtaposition section）的构建流程**

📎 **背景补充：以下为流程整合补充**，本周 `EPQ2soln` 只给出成品图与最终数值。这是求**斜滑（oblique-slip）**滑移矢量的通用方法（W5 讲义原文：「the magnitude and orientation of the slip vector must be obtained by drawing a fault plane (juxtaposition) section, that is, a cross-section drawn **in the plane of the fault** showing **both the hanging wall and the footwall on the same section**」）。

1. **在断层两侧分别给每个被错断的界面画地层等高线**（本题是两条 vein：A 090/60S、B 090/70N，断层两侧各有一套）。
2. **求 cut-off line 上的点**：某界面的第 $h$ 米等高线与**断层迹线**的交点，就是该界面 cut-off line 上高程为 $h$ 的一个点。两个点即可定出一条 cut-off line。
3. **建立断层面坐标系**：横轴 = 沿断层走向的距离，纵轴 = 高程。断层竖直时（`000/V`），这个"面"就是一个真正的竖直 N–S 剖面，长度不失真，**可以直接量**。
4. **把四条 cut-off line 都画上去**：vein A(E)、vein A(W)、vein B(E)、vein B(W)。因为断层走向 000 且竖直、而两条 vein 走向 090（与断层正交），vein 与断层的交线**倾伏方向就在 N–S 方向、倾伏角等于 vein 的真倾角**：
   - vein B (090/70N) → cut-off line 倾伏 **70° 向 N**；
   - vein A (090/60S) → cut-off line 倾伏 **60° 向 S**。
5. **求两个刺穿点（piercing points）**：东盘上 A(E) 与 B(E) 的交点、西盘上 A(W) 与 B(W) 的交点。这两点在断裂前原本是**同一个点**。
6. **连接两个刺穿点 = 滑移矢量**。量它的长度（→ 329 ft）、量它与走向线的夹角（→ pitch 71°，因断层竖直故 plunge 也是 71°），读方向（→ 倾伏向 180）。
7. **分解**：竖直分量 = dip-slip = 311 ft；水平分量 = strike-slip = 107 ft。
8. **判断运动方向**：西盘相对东盘**向下且向南** → dip-slip 为 **down to the W**；strike-slip 为 **sinistral（左行）**（站在东盘朝西看，对面的西盘向你的左手边即南方移动）。

## 五、Practical 要点

### Q1 — FOLDS AND FAULTS EXERCISE

**两份答案的关系（辨析）：**
- `Q1soln1` = **题面 + 带答案批注的地图**（标题页写着「A」，图上有 500/800/B、南北向、Sandstone/Mudstone/Grit 图例、300–900 m 地形等高线，以及在图边写上的全部答案）。
- `Q1soln2` = **答案的第二张纸：沿 A–B 的垂直剖面**，外加把 `Q1soln1` 上的几何答案**重抄一遍**作汇总，并追加那句「无法判断孰先孰后」。
→ 二者不是两问，而是**同一题的两张答案图（图 + 剖面）**。

**给了什么条件（从答案反推）：** 一张 1:40000 地形图，等高线间距覆盖 300–900 m；三个岩性单元 Grit（a，最老）、Mudstone（b）、Sandstone（c，最新）；沙泥岩接触面在若干山谷中出露并呈 V 字形；一条断层迹线；一条 A–B 剖面线（A 在南、B 在北，走向 000）。题目声明该断层是**纯倾滑断层（pure dip-slip fault）**。

#### 1. 褶皱部分

| 问 | 解法步骤 | 答案 |
|---|---|---|
| **(a) 两翼产状** | ① 用 V 字法则读各山谷中砂/泥岩界线 V 尖的指向，定出**大致倾向**；② 在砂岩–泥岩接触面上画地层等高线：把界线与同一条地形等高线的所有交点连起来，连线要尽量**直、平行、等距**；③ 由等高线走向读 strike，由 $\tan\delta=\Delta h/d$ 读 dip | **100/14N** 与 **100/19S** |
| **(b) 轴迹与背形/向形** | 两翼倾向**相背**处 → **背形（antiform）**；倾向**相向**处 → **向形（synform）**。轴迹画在两组等高线走向发生"翻转"的位置，沿走向 100 延伸 | 交替出现的背形/向形轴迹（题面用复数 folds、axial traces，说明图上不止一个褶皱）📎 *推断：呈近等间距的褶皱列* |
| **(c) 褶皱轴** | 两翼的交线即褶皱轴。两翼走向相同（都是 100）→ 交线水平 → 倾伏角 0 | **0/100**（倾伏 0°、走向 100）→ **非倾伏褶皱 non-plunging** |

**衍生的两项（答案里另给）：**
- **Bisector（→ 轴面）：`100/88N`**。📎 验算：两翼一个向 N 倾 14°、一个向 S 倾 19°，在 N–S 剖面上两翼线方向分别为 −14° 与 +19°；147° 那个夹角的平分线指向近乎正下方偏 N，约 **87.5°**，与答案 88°N 吻合 ✓。按 W4 分类，轴面倾角 88° 属 **upright（直立）**。
- **Interlimb angle：147°**。📎 验算：$180° - 14° - 19° = 147°$ ✓。按 W4 分类（180°–120° 为 gentle）属 **gentle（开阔/平缓褶皱）**。

**完整的一句话描述（考试要求的表述）：** 📎 *这是一组**直立、平缓、非倾伏**的圆柱状褶皱，褶皱轴 0/100，轴面 100/88N，内翼角 147°。*

#### 2. 断层部分

| 问 | 解法步骤 | 答案 |
|---|---|---|
| **(a) 断层面产状** | 在**断层迹线**上画地层等高线（做法与地层界面完全一样：断层迹线与地形等高线的交点，同高程者相连），读 strike 与 dip | **090/34N** |
| **(b) 滑移矢量大小** | 因为是纯倾滑断层、且剖面 A–B（`000/V`）恰好**平行于断层倾向**，所以在剖面上量出的错距就是真实滑移量。作法：按 §3.7 的八步画出剖面，在剖面上量同一界面在上、下盘的两个 cut-off 点之间的距离 | **120 m** |
| **(c) 滑移矢量方位与运动性质** | 纯倾滑 → 滑移矢量的倾伏角/倾伏向 **= 断层的倾角/倾向**；由地层错动方向判断上盘（北盘，因断层向 N 倾）相对下降 | **34/000；正断层（normal）**，北盘下降 |

📎 **派生数值（材料未给，可自行算出，考试常追问）：** throw ≈ **67 m**，heave ≈ **100 m**（见 §3.2）。

#### 3. 时序问题

**答案：不能判断褶皱与断层孰先孰后（原文：It is not possible to say, based on the map, which came first – folding or faulting）。** 理由见 §2.1 的推断段。

### EPQ2 — Faults: extra practice question 2

**「EPQ」是什么？** 从文件标题原文「**Faults: extra practice question 2**」可确认，**EPQ = Extra Practice Question（课后额外练习题）第 2 题**，**不是** Exam Paper Question。课程大纲也提到「Accompanying all classes there will be **extra practice exercises** – there is no assessment requirement to do them but they are designed to be helpful」。这道题原属 **W5 断层**单元，放在 W10 作为综合复习。

**给了什么条件：** 一张以**英尺**为单位的地形图（等高线 300、400、500 ft；比例尺条 0–500 ft）；**两条岩脉（veins）**：**vein A = 090/60S**、**vein B = 090/70N**（两条产状在断层两侧各标一次，说明两侧产状相同、未被旋转）；**一条竖直断层 = `000/V`**，把两条脉都错开了。

**问什么：**
- (a) 画一张**断层面剖面（fault plane section）**表示断层上的位移；
- (c) dip-slip 分量的大小与方向（down to W 还是 down to E）；
- (d) strike-slip 分量的大小与方向（sinistral 还是 dextral）；
- (e) 滑移矢量的倾伏角/倾伏向。
（**注**：材料中的小题编号从 (a) 直接跳到 (c)，缺 (b)，见文末勘误表。）

**解法步骤：** 完全按 §3.8 的八步走。关键在于本题是**两条产状不同的面被同一条断层错开**——这正是 W5 讲义强调的、能唯一确定滑移矢量的条件（单靠一条界面只能给出 separation，给不出 slip）。

**答案要点与数值：**

| 项 | 数值 | 校验 |
|---|---|---|
| 断层产状 | **000/V** | 竖直 → hade = 0，heave = 0 |
| 滑移矢量 | **71/180，329 ft** | 竖直断层 → plunge = pitch = 71° |
| dip-slip 分量 | **311 ft，down to the W** | $329\sin71° = 311$ ✓ |
| strike-slip 分量 | **107 ft，sinistral（左行）** | $329\cos71° = 107$ ✓ |

📎 **补充理解：** 竖直断层没有上盘/下盘之分，所以运动性质**不能**说 normal/reverse，只能说「**down to the W**」（西侧下降）——答案正是这么写的。这一点常被忽略。同理，竖直断层的 dip-slip 分量就等于 **throw**（落差），而 **heave = 0**。

📎 **构图细节（从答案图注反推）：** 剖面图注写「S vein B (E) vein A (E) N / 500 vein B (W) / 400 / vein A (W) / 300 / 200 / 100 / slip vector」——即剖面**左端为 S、右端为 N**，纵轴 100–500 ft；四条 cut-off line 分别标 (E)/(W) 区分东西两盘；`slip vector` 是连接两个刺穿点的那条线。**在断层面剖面上必须同时画出两盘**，否则无从求刺穿点。

## 六、易错点 / 重点难点

### 6.1 本周（综合题）特有的易错点

1. **上手顺序错。** 📎 *推荐顺序（补充）：*
   ① 先读**图例与地层柱**，把新老关系搞清楚（本周：Grit 最老 → Mudstone → Sandstone 最新）；
   ② **先分层、再找断层**：用 V 字法则 + 地层等高线把**未被断层切断的一侧**的地层产状先解出来；
   ③ 用地层重复的**对称性**锁定褶皱轴迹（找回文 `a-b-c-b-a`）；
   ④ 再回头处理断层（在断层迹线上画等高线求产状，再求滑移）；
   ⑤ 最后作剖面、写时序。
   **反过来做（先纠结断层）通常会卡死**，因为断层的滑移量必须靠已知产状的界面才能求。
2. **把地形 V 当成褶皱转折端**（或反之）。W4 的 `Vshaped` 讲义专门警告：「Since folding may also produce similarly shaped outcrop patterns, when locating fold axial traces on maps it is important to pay attention to this **topographically produced effect**」。判据：地形 V 只出现在**河谷**处且随谷线走；褶皱转折端**不依赖地形**，两侧倾向相反。
3. **误以为图上有错移就有走滑。** 见 §2.4。本周 Q1 就是纯倾滑却有明显错移的例子。
4. **忘了 pitch/plunge 的区别。** 竖直面上二者相等（EPQ2），倾斜面上不等，必须用赤平网或公式换算。
5. **时序问题硬猜。** 证据不足时必须写「不能判断」并说明理由。
6. **剖面用了垂直放大还去量角度/量滑移量。** 要量数值的剖面必须 VE = 1。

### 6.2 📎 **背景补充：全课十周高频易错点速查清单（考前过一遍）**

> 以下清单是我对 W1–W10 全部材料的整合，**不是本周材料原文**。

**A. 产状记法（W1）**
- [ ] 走向/倾向/倾伏向写**三位数**，倾角/倾伏角写一两位数；倾向与倾伏向**绝不折算到 000–180**。走向/倾角式必须附倾向方位（`030/40SE`）。
- [ ] pitch 必须注明从走向线的**哪一端**量起（`37NE on 030/40SE`），最终要换算成倾伏角/倾伏向；pitch 形式上等同于视倾角。
- [ ] **永远写清楚这个面或线是什么**（S0 层理、S1 劈理、F1 褶皱轴、断层面……）。

**B. 地层等高线（W1–W2、W9）**
- [ ] 只能在**界线与同高程地形等高线的交点**处画，两个约束缺一不可；每画一条就标高程。
- [ ] 理想平面的等高线**直、平行、等距**；天然界面**只是近似**如此（W9 原文），不要为求"好看"牺牲交点。倾向垂直于等高线、指向高程降低一侧。

**C. 不整合（W3）**
- [ ] 角度不整合 / 平行不整合（disconformity 有可见侵蚀面、paraconformity 只靠化石带缺失识别）/ 非整合（下伏为火成岩或变质岩）三类要分清。
- [ ] 角度不整合意味着**下伏地层的褶皱或倾斜发生在时间间断之内**。
- [ ] overstep（上覆层依次压在越来越老的下伏层上，无沉积学含义）≠ onlap（上超，通常对应海侵）。
- [ ] 不整合造成的缺失**横向变化**；正断层造成的缺失**沿走向稳定**。

**D. 褶皱（W4）**
- [ ] **antiform/synform（按闭合方向）与 anticline/syncline（按核部新老）是两套词**，地层倒转时二者可以不一致。
- [ ] 完整描述要**四项**：褶皱轴、轴面、两翼产状、内翼角，缺一丢分；**bisector ≠ axial plane**（仅两翼等厚时相等）。
- [ ] 分级要背：倾伏 0–10 non-plunging / 10–30 gently / 30–60 moderately / 60–80 steeply / 80–90 vertical；内翼角 180–120 gentle / 120–70 open / 70–30 close / 30–0 tight / 0 isoclinal；轴面 0–10 recumbent / 10–30 gently-inclined / 30–60 moderately-inclined / 60–80 steeply-inclined / 80–90 upright。
- [ ] V 字法则六种情形要能默画（缓倾指上游且比等高线尖、水平则平行等高线、陡倾指下游、与河床同坡或直立则无 V）。

**E. 断层（W5、W10）**
- [ ] 完整描述要**三项**：断层面产状 + 滑移矢量（方位与大小）+ 运动指向（走滑与倾滑分量都要说）。
- [ ] **separation ≠ slip**：只有一条被错断界面时只能给 separation；求 slip 需**两条产状不同的界面**，或已知是纯倾滑/纯走滑。
- [ ] 纯倾滑 → 滑移矢量方位 = 断层倾角/倾向，沿倾向作垂直剖面即可；纯走滑 → 方位 = 断层走向，量视错距（扣除地形效应）；斜滑 → **必须**作断层面剖面，两盘同图。
- [ ] **竖直断层不说 normal/reverse**，说「down to the W/E」；hade = 90° − dip。

**F. 赤平投影（W6–W7）**
- [ ] 面画**大圆**、线画**点**，极点与大圆差 90°；数 pitch 从**指定那一端**沿大圆起数。
- [ ] 读 plunge 先把点**转到 E–W 线**再从**外圈**往里数；最后**把描图纸转回正北**再读倾伏向。

**G. 侵入体与事件序列（W8）**
- [ ] **从老到新编号**，**每条都写出证据**（W8 原话：evidence should be made explicit），并附定量信息（产状、断距）。
- [ ] 证据不足时明说（如「Unit A 的倾角未知，不能排除晚期掀斜」）；剥蚀也是事件，「侵蚀到现今地形」通常是最后一条。

**H. 剖面与制图规范（W9、W10）**
- [ ] 标题写剖面产状、两端标方位、水平与垂直两个比例尺、按比例的地层柱与图例、剖面本体着色 + 字母；界面用**虚线**延伸到地形面之上。
- [ ] 要量数值 → VE = 1；只为图示可放大但须注明倍数（W9：垂直 1:10000 ÷ 水平 1:50000 = **×5**）。
- [ ] **厚度守恒**是最好用的自查；单位（m / ft）与比例尺看清再动笔。
