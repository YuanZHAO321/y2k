## 一、这门课在整个学位里的位置

### 1.1 它是什么

EART24001 是 10 学分、Level 5、Semester 1 的**纯技能课**，由 Stephen Covey-Crump 负责。它的性质从课时结构就能看出来：**lecture 只有 10 小时，practical classes & workshops 有 30 小时**，且 unit spec 开宗明义——"The unit is delivered primarily through a set of 'hands-on', map-based exercises."

这意味着它**不是一门知识课**。全课真正要背的"知识"只有三张形容词分级表（褶皱倾伏、层间角、轴面倾角）、不整合的四型分类、侵入体的十几个名词，其余全部是**手上功夫**：会不会画地层等高线、会不会转描图纸、会不会把三维几何投到一张纸上并再读回来。这也解释了为什么材料词数这么少而作图量这么大。

五条 ILO 里，**ILO 1–4 是"会做"，ILO 5 是"会写"**：

| ILO | 内容 | 本课对应的工具 |
|---|---|---|
| 1 | 由有限露头与产状信息在地形图上定出地质接触界线位置 | 地层等高线（§2.2）、三点法（§2.4） |
| 2 | 识别不整合、褶皱、断层、侵入体，**并与地形造成的露头形态区分** | V 字法则（§2.3）、构造判读手册（§三） |
| 3 | 由图面信息分析三维几何 | 全部工具 |
| 4 | 用垂直剖面与赤平投影图表达构造几何 | 剖面构建（§2.5）、赤平投影（§2.6） |
| 5 | 用切割关系组装有证据支撑的事件序列 | 事件序列四步法（§3.4） |

**ILO 5 只在期末 practical exam 中考**（W8 是它唯一的正式训练），这是全课最容易被忽视的一块。

### 1.2 它为什么排在大二学习顺序的第 2 位

📎 **背景补充（以下排序理由为本总纲的整合判断，非课程材料原文）：**

### 2.1 工具一：产状的两套记录法及换算

**是什么。** 面（plane）与线（lineation）在空间中的方位。W1 的 Handout 是全课**唯一一份纯"约定"型讲义**，后面九周所有产状数字都用这套写法。

**面的两套记法（讲义明确要求两套都会，实习课两套都会出现）：**

| 记法 | 例子 | 格式硬性要求 |
|---|---|---|
| **走向 + 倾角** strike and dip | `030/40SE` | 走向写**三位数**且在前，习惯化到 000°–180°；倾角写一至两位；**必须注明倾斜的大致方向**（SE） |
| **倾角 + 倾向** dip and dip direction | `40/120` | 倾角写一至两位且在前；倾向写**三位数**，且**绝不可**折算到 000°–180° |

**换算。** 倾向 = 走向 ± 90°，取指向下坡的那一个。示例：走向 030、向 SE 倾 → 030 + 90 = 120 → `40/120`；`043/14 NW` → 043 − 90 = 313 → `14/313`；`120/6 SW` → 120 + 90 = 210；`095/3 N` → 095 − 90 = 005；`015/24 W` → 015 + 270 = 285。

📎 **为什么走向取半圈、倾向取全圈**：走向线是**双向**的（030° 与 210° 是同一条线），故约定只取半圆内那个数以免一面两写；倾向是**单向**的（只往一边倒），必须允许 000–360 全圈。这正是讲义 *"must not be converted"* 的理由。同理 `030/40` 不写 SE 就有歧义（可能倒向 120° 也可能倒向 300°），必然扣分；而 `40/120` 因倾向已是全圈方位，本身无歧义。

**线的两套记法：**

- **倾伏 + 倾伏向** plunge / plunge direction，如 `23/060`：倾伏角一至两位在前，倾伏向三位在后，同样不折算。
- **侧伏（pitch / rake）**，如 `37NE on 030/40SE`：量角器**贴在含该线的那个面上**量出的、线与走向线的夹角。**必须同时写出**（a）侧伏角**及从走向线哪一端起量**（NE 还是 SW），（b）**所依附平面的产状**——`40°NE` 单独毫无意义。

> **Handout 的硬性规定**：*"Linear data should ultimately be expressed as plunge and plunge direction"*——野外常记侧伏，**但最终必须换算成倾伏 + 倾伏向**，且讲义指定用赤平投影来做。这是 W1 埋给 W6 的伏笔。

**直立面的专用写法 `/V`**：`090/V`（直立岩层）、`030/V`（走向 030 的铅垂剖面）、`000/V`、`153/V`。这是本课记垂直面的统一写法，剖面的方位标注也用它。

**必须写清"这是什么面 / 什么线"。** Handout 用整行加粗强调：***ALWAYS specify what the plane or line is.*** 速记：面用 **S**（`S0` 层理、`S1` 第一期劈理）；线须注明成因（`S1/S0 23/246` 交面线理、`L1 23/328` 拉伸线理、`F1 23/246` 褶皱轴）。

**什么时候用**：每一次写下产状时。这是全课扣分最密集、也最容易避免的地方。

### 2.2 工具二：地层等高线（stratum contour / strike line）

这是**全课真正的技术核心**，十周里有七周直接依赖它。

**本质（一句话）**：一条地层等高线 = **该地质界面与某一高程水平面的交线**。它是"层面的等高线"，与地形等高线（"地面的等高线"）完全平行地类比。W1 Handout 把 *strike line* 与 *stratum contour* **直接划了等号**。

**三条必须理解到"能自己推出来"的性质：**

1. **形状与间距**：若层面**均匀倾斜**（uniformly dipping，即为一个平面），它与一系列等间距水平面的交线，必然是一组**互相平行、等间距的直线**，方向即走向方向。倾角越陡间距越小，水平层面间距无穷大。
2. **地形交点定露头**：地质界面出露在地表的位置 = "层面"与"地面"两个曲面的交线；在图上等价于——**地层等高线与相同高程的地形等高线的交点**。把同值交点顺次连成光滑曲线，即接触界线的出露轨迹。
3. **可向任意方向外推**（含地面之上、之下）。W2 的 `Q1soln` 连高于全图最高地形、根本不出露的 900 m 线都画了；`Q3soln1` 保留了 `sea` 至 `1400´` 的整串标注——**构造线须画到图幅边界**。

**怎么画（标准五步）：**

1. **把条件译成"界面上的已知高程点"**：① 露头 × 地形等高线（界线与 h 米地形等高线的交点，其在界面上的高程即 h）；② 钻孔：**界面高程 = 孔口标高 − 该界面在孔中的深度**（孔口标高由孔位所踩的地形等高线读出）。
2. **定出第一条地层等高线**：把**同高程**的两个以上点用**直线**相连；只有一个点时须另给产状（过该点画走向方位的直线）。
3. **算间距并等距外推**：$d = \Delta h / \tan\delta$，**必须经比例尺换成图上长度**，向倾向侧递减、反侧递增，**每条线两端都标高程**。
4. **取同值交点连成迹线**：地层等高线 h 与地形等高线 h 的交点，顺次连成光滑曲线。
5. **判上下、涂阴影、填岩性**。

**怎么读（反用）：** 量相邻两条的**垂直**间距 d 与高程差 Δh → $\delta = \arctan(\Delta h / d)$；等高线方位即走向；**高程数值降低的方向即倾向**。

📎 **两条最要命的作图推论：**
- **地层等高线的高程间隔必须与地形等高线一致**（或为其整数倍并落在同一组高程值上），否则根本找不到同值交点。W1 三题分别用 15 m、10 m、50 m，都是跟着地形图走的；W2 的 Q2③ 因 3.5° 时 10 m 间距超出图幅而改用 5 m 间距。
- **一张网格可供多个界面共用**：若各界面在同一点的高程差都是等高距的整数倍，则它们的地层等高线**落在同一族平行线上**，只是标号差几格。W1 Ex3 的 `450/600` 双标注（同一条线既是下界面 450 m 线又是上界面 600 m 线）与 W2 Q3 的"画一次网格、挂七套标签"都是这个技巧。

**结构上下与阴影（口诀 + 推导）**：**下伏单元出露在界线迹线的"上倾（up-dip）"一侧。** 📎 推导：沿下倾方向走，界面高程持续下降而地面大体不变，地面处于界面之上 → 出露上覆单元；沿上倾方向走，界面爬到地面之上（已剥蚀）→ 出露下伏单元。特例：**水平面**迹线即某条地形等高线，阴影打低处；**直立面**无结构上下之分，W2 `Q2soln1` 明写 *either side of contact could be shaded*。

**什么时候用**：W1、W2、W3（两套分绘）、W4（每翼一套）、W5（**画在断层面上**、两盘分绘）、W8（岩墙两壁分绘、断层两盘分绘）、W9（真实图幅）、W10。**这是本课的通用语言。**

📎 **W9 的容差修正（真实图幅）**：`Cover.md` 原文——*"perfectly planar surfaces have stratum contours which are straight, parallel, and equidistant, the surfaces encountered in nature are rarely perfectly planar and so have stratum contours which are only **approximately** straight, parallel, and equidistant."* 这句话**既允许放松容差，又要求不得画出尖锐折点**。W9 给出的三条法则：① 地层等高线只能在"地形等高线也穿过界线"处穿过地质界线；② 只能在"地质界线也穿过地形等高线"处穿过该条地形等高线；③ 尽可能直或平缓弯曲，**no sharp kinks**。第 1、2 条是同一几何事实的镜像表述，写成两条是为了**双向检查**——正向确认线经过了所有该经过的交点，反向确认它没在不该穿越处穿越。

### 2.3 工具三：V 字法则（Rule of V's）

**是什么。** 均匀倾斜面横穿河谷时形成 V 字形露头图案，**V 尖的指向与尖锐程度取决于倾斜**，故可用来快速估计倾向与倾角量级。

**五（六）种情形的完整判据：**

| 情形 | V 尖指向 | 与地形等高线的 V 相比 | 地层等高线间距 |
|---|---|---|---|
| **水平** horizontal | 上游 | **完全重合 / 平行** | 无穷大 |
| **向上游倾** dip upstream | 上游 | **更钝** blunter | 有限 |
| **向下游缓倾**（δ < 河床坡降） | 上游 | **更尖** sharper | 较大 |
| **倾角 = 河床坡降** | **无 V**（沿谷底成直线） | — | — |
| **向下游陡倾**（δ > 河床坡降） | **下游** | — | 较小 |
| **直立** vertical | **无 V**（界线为不受地形影响的直线） | — | 0（重合） |

**几何证明（📎 30 秒可重推，比死背可靠）。** 设河向南流，谷地 $z_g = a y + b x^2$（y 向北 = 上游，x = 0 为谷轴，$\tan\theta_{\text{stream}} = a$）。地形等高线 $y = (h - bx^2)/a$ 顶点朝北 → **地形等高线的 V 恒指上游**。设界面走向 090、$d = \tan\delta$，令 $z_b = c \mp d y$，代入 $z_g = z_b$ 得迹线

$$y = \frac{c - b x^2}{a \pm d}$$

（上游倾取 $+d$，下游倾取 $-d$。）**记忆锚点就是这个分母**：
- 上游倾 → $a+d$ 变大 → V 仍指上游但**更钝**；
- 下游缓倾（$d < a$）→ $a-d$ 变小 → V 仍指上游但**更尖**；
- $d = a$ → 分母为 0，退化成 $bx^2 = c$ 两条平行直线 → **无 V**；
- 下游陡倾（$d > a$）→ 分母变号，顶点成极小值 → **V 翻向下游**；
- 直立 → 迹线为直线，无 V。

📎 **本质上更简单的说法**：出露线永远出现在"地层等高线高程 = 地形等高线高程"的交点上。直立岩层的地层等高线彼此重合成一条直线，故出露不受地形影响；水平岩层的地层等高线"就是"某条地形等高线，故出露与等高线重合。

**本课里 V 字法则的两个用途（W4 明示）：**
1. **快速目估倾向**——`EgExSoln` 图上明写 *"approximate dip direction given by veeing"*；W10 的 HINT 更直白：*"use the V-ing of the contacts in the valleys to determine the approximate orientation of the stratum contours **before** trying to draw them"*。**先用 V 字法则定大致倾向，再动手连等高线**，不要盲连。这是被示范的解题顺序。
2. **找轴迹前先排除地形造成的 V**——W4 Handout 原文：*"Since folding may also produce similarly shaped outcrop patterns, when locating fold axial traces on maps it is important to pay attention to this topographically produced effect."* **先学会"这个 V 是地形造成的"，才有资格判断"那个 V 是褶皱造成的"**——这是 W2 通向 W4 的伏笔，`Q2soln2` 在 W4 被原样重印正是为此。

**什么时候用**：每一张图幅的**起手式**，以及作图后的自检。

### 2.4 工具四：三点法与钻孔数据定产状

**三点法（three-point problem）。** 📎 W1 Ex2 的标准解法，材料只给答案未给步骤：

已知同一平面上三个已知平面位置与高程的点 $P_1(h_1) > P_2(h_2) > P_3(h_3)$：

1. 连接**最高点 $P_1$ 与最低点 $P_3$**；
2. 在这条直线上按高程**线性内插**出高程等于 $h_2$ 的点 $Q$，内插比例 $\dfrac{P_1Q}{P_1P_3} = \dfrac{h_1-h_2}{h_1-h_3}$；
3. 连接 $Q$ 与 $P_2$——两点高程相同，故 $QP_2$ 就是高程 $h_2$ 的地层等高线，其方位角即**走向**；
4. 过 $P_1$、$P_3$ 作平行线，量相邻两条的**垂直**距离 $d$，代入 $\tan\delta = \Delta h / d$ 求倾角；
5. 倾向朝**高程数值减小**的一侧；
6. 按 $\Delta h$ 等间距向两侧平行外推，铺满全图。

📎 **代数验算法**：设 $z = Ax + By + C$，则 $\delta = \arctan\sqrt{A^2+B^2}$，倾向 = 向量 $(-A,-B)$ 的方位角。可用来自检图上读数。

**多点推广（W2 Q1）**：露头散布时，在每处能看到界线的露头取点、读其所踩地形等高线值，把**同高程**的点用**直线**相连即得一条地层等高线；至少做两条，**检查是否平行**（平行才可继续），再量垂距求倾角。

**钻孔数据。** 转换只有一步却极易错：

> **界面高程 = 孔口标高（collar elevation） − 该界面在孔中的深度。**

📎 钻孔给出的已知点**全在同一条铅垂线上**，故**单孔无法定产状**，必须另给倾角或另有两点。钻孔垂直，故孔中量到的是**垂直厚度**而非真厚度。

**起手式（W2 Q3 范例，完整序列见 §六）**：某界面在孔中的深度恰为 0 时，孔口点就**正落在该界线的露头上**，过该点沿走向的直线直接就是这个界面的孔口高程等高线。

⚠️ **两个头号陷阱**：①"700–800 ft 灰岩"不是高程 700–800，而是 **−300 至 −400 ft**，差 1100 ft——**先写"高程 = 孔口标高 − 深度"再动笔**；②深度标为 *Above X* 的单元（已剥蚀的熔岩）**极易漏掉**，漏掉会导致下倾侧少画一个岩性带。

**什么时候用**：图上只给露头点、不给产状符号时（W1 Ex2、W2 Q1、W3 Q1 全图不给任何产状符号）；给了钻孔时（W2 Q3）。

### 2.5 工具五：剖面构建（cross-section）

**总流程八步**（📎 由 W2/W3/W4/W8/W9/W10 各答案图反推整合）：

**第 0 步 — 定剖面产状与比例。** 量出剖面线方位，写成 `方位/V` 作标题（如 `060/V`、`093/V`、`000/V`、`030/V`），**标明两端方位**（左 SW / 右 NE 之类）。**尽量让剖面垂直于走向或垂直于褶皱轴**——垂直走向时视倾角 = 真倾角，可直接画；垂直褶皱轴时该剖面即 profile plane，量到的层间角才是真值。

> ⚠️ **垂直放大（vertical exaggeration, VE）**：只要剖面要用来**量角度或量滑距长度**，**VE 必须 = 1**（图注写 `vertical = horizontal scale`）。VE ≠ 1 时 $\tan\delta_{\text{drawn}} = \text{VE} \cdot \tan\delta_{\text{app}}$，且厚度、层间角、轴面倾角在图上**全部失真**。W9 的 Marlborough 剖面 VE = 52360/10000 = **5.236**，使 1° 的真倾角在剖面上呈现为约 **5.8°**——那种剖面**只能用于图示，不能用于测量**，且标题必须写明真产状与放大率。

**第 1 步 — 画地形剖面。** 纸边压在剖面线上，逐条地形等高线打点记高程，转到剖面坐标系连成平滑曲线。

**第 2 步 — 投影出露点。** 沿同一纸边把各地质界线、断层迹线与剖面线的交点也打上，投到地形曲线**上**。

**第 3 步 — 用地层等高线定倾角，不要目测；必要时换算视倾角。**

$$\tan\alpha = \tan\delta \cdot \sin\beta = \tan\delta \cdot \cos\varphi$$

$\beta$ = 剖面方向与**走向**的夹角，$\varphi$ = 剖面方向与**倾向**的夹角。检验：$\beta = 90°$ → $\alpha = \delta$；$\beta = 0°$ → $\alpha = 0$。**恒有 $\alpha \le \delta$：任何斜切剖面上量到的倾角都偏小。**

📎 图上的几何意义：把地层等高线延伸到剖面线上，读出剖面线与相邻两条地层等高线交点之间的距离 $d'$，则 $\tan\alpha = \Delta h / d'$——因为 $d' = d/\sin\beta \ge d$，视倾角自然小于真倾角。

**第 4 步 — 向深部延展。** 除非等高线显示界面弯曲，否则按平面向下延伸；褶皱按"两翼 + 转折端"连接，**转折端要圆滑**（除非确证是尖棱褶皱）。

**第 5 步 — 处理截切面，顺序有讲究。** **先画截切者、再画被截者**：不整合先画（它截断下伏单位），然后其下的褶皱序列，最后其上的盖层。**所有下伏界面必须硬止于不整合面，绝不穿过。** 断层：先把断层面按其倾角画到底，再分别画上、下盘的地层；**同一界面在断层两侧必须错开一个等于 throw 的高差**，两侧地层绝不能画成连续。

**第 6 步 — 厚度守恒检查（最有效的自查）。** 同一地层在任一盘、任一褶皱翼上的**垂直层面厚度必须一致**。厚度变了 → 某处倾角或界线位置画错了。

**第 7 步 — 补齐规范要素**（W9 `Cover.md` 的 (a)–(e) 是最像评分表的一段）：(a) 标题写剖面**产状**；(b) 标明哪端 NW、哪端 SE；(c) **水平 + 垂直两个比例尺**；(d) **按比例绘制的地层柱**，含各单元颜色与字母代号；(e) 剖面本身也须**着色**并附字母代号图例。

**第 8 步 — 界面用虚线延伸到地形面之上**（表示已被剥蚀的部分）以及之下。**被剥蚀的背形拱顶不画虚线，等于没表现出褶皱，是失分点。**

**真厚度换算（剖面与地层柱都要用，公式见 §五 #4、#5）**：$t_{\text{vert}}$ 是**同一图上位置顶底面地层等高线的高程差**——**地层等高线给的永远是铅直高差**。W4 `SectSoln` 的三个换算式是直接证据：`conglomerate : 99.6 m (= 100 cos 4.8°)`、`grit : 282 m (= 300 cos 20°)`、`siltstone : 188 m (= 200 cos 20°)`——**换算过程必须写出，不能只给结果数字。**

📎 **反向读法**：从 cos 里的角度值可以反推该单元的层序位置——`conglomerate` 用 cos 4.8°（= 下不整合的倾角）说明它**直接覆于下不整合面之上且与之平行**；`grit`、`siltstone` 用 cos 20° 说明它们属于**不整合之下被褶皱的老序列**。

**"最小厚度"规范。** 凡顶面或底面被不整合、断层或图幅边界**截断**、或被现代地形剥蚀的单元，厚度**只能写 `~X m min`**，写成确定值是错的。W3 的六个单元里 f、d、a 三项都加了 `minimum`——**这张表本身就是最强证据链**：a 未见底、d 未见顶、f 未见顶，精确指出**不整合面位于 d 与 e 之间**。

**什么时候用**：W2 Q3(c)、W3 Q1(4)、W4 SectSoln、W6 Ex1 第 3 题、W8 Q5、W9 第 3 题、W10 Q1——**几乎每一道大题的最后一问。**

### 2.6 工具六：赤平投影（stereographic projection）

**是什么。** 📎 把要研究的面或线**平移到参考球球心**与球面相交，再把球面上的交迹投影到过球心的水平面（`plane of projection`）上。因为地质构造向下延伸，约定**只取下半球**（lower-hemisphere projection）。成果图叫 **stereogram**，外边界叫 **primitive circle（基圆）**，代表水平面，圆心代表垂直方向。

**核心对应关系（记忆锚点：面 = 弧，线 = 点）：**

| 对象 | 投影 | 性质 |
|---|---|---|
| **面** | **大圆（great circle）**圆弧 | 水平面 → 基圆本身；垂直面 → 一条直径；倾角越大弧越靠近直径。**弧的凸出方向指向倾向。** |
| **面的法线** | **极点（pole）**一个点 | 与大圆在同一 E–W 直径上**相隔 90°**；极点在**大圆凸出方向的反侧**；极点倾伏 = 90° − 倾角。**水平面极点在圆心，垂直面极点在基圆上。** |
| **线** | **一个点** | 同一个数字串 `50/260` 既可能是面也可能是线，**必须靠标注说明** |

**两种网，绝不能混用：**

| 网 | 材料原文 | 性质 | 用途 |
|---|---|---|---|
| **Wulff 吴氏网** | WULFF (equal angle) | **等角**，保角，小圆仍是真圆 | **量角、求交线、旋转复原**等一切几何作图（W6） |
| **Lambert / Schmidt 网** | LAMBERT (equal area) | **等面积**，不保角，点密度不畸变 | **方向数据统计与密度等值线图**（W7） |

**四套基本作图（①–④ 逐字忠于讲义）：**

**① 标面：走向 + 倾角**（例 `060/30SE`）
1. 描图纸压网，**在描图纸上标出北点**；
2. 沿网**周边**数出走向 060°，作记号；
3. **转动描图纸**使记号落到网的 **N 或 S 点**；
4. 沿 **E–W 线向内**数出倾角 30°，画出大圆——**转回北朝北时大圆应朝倾向一侧凸出**；
5. 从大圆起沿 E–W 线**再数 90°**得极点；
6. **转回北朝北**，注明产状读数。

**② 标面：倾角 + 倾向**（例 `50/260`）：同上，但第 3 步转动使**倾向记号**落到 **E–W 线**上，第 4 步**必然从倾向记号那一端**向内数倾角——**不会数错方向**，这是"倾角/倾向"记法在赤平投影上更省事的地方。

**③ 标线：倾伏 + 倾伏向**——讲义原文：*"This procedure is the same as plotting planes which are specified as dip and dip direction, except that a point is plotted rather than the great circle."* 与 ② 完全相同，只在第 4 步把"画大圆"改成"画一个点"。

**④ 由面 + 侧伏角求线**（例 `40°NE on 060/30SE`）
1. 描图纸压网标北点；
2. **先把该面的大圆画出来**；
3. **沿这条大圆**、**从侧伏角指定的那一端起**（NE 端）数出 40°，打点。**侧伏必须沿大圆弧本身量，不能沿直线量、也不能沿周边量**——大圆弧就是"那个斜面"，量角器只能贴着它走；
4. 把该点**转到 E–W 线**上，从周边向内数出**倾伏角**（18°）；
5. 转回北朝北，读**倾伏向**（095°），注记 `18/095`。

> **讲义算例即最好的反例**：`40°NE on 060/30SE`（侧伏 40°）换算出来是 **`18/095`（倾伏只有 18°）**——**侧伏 40° ≠ 倾伏 40°，两者相差 22°。**

**⑤ 📎 由两个面求交线（交面线理 / 褶皱轴）**：分别画出两个面的大圆 → **两圆交点**即交线的投影点 → 转到 E–W 线数倾伏角，转回读倾伏向。**等价做法**：两个面的**极点**决定一个大圆（**π 圆**），该大圆的极点就是交线；**多组层理数据时用后者更稳**（W7 题 1(a) 即由 25 个层面极点拟合 π 圆求出褶皱轴 `10/165`）。

**⑥ 📎 量夹角**：
- **两条线的夹角**：转描图纸使两点落到**同一条大圆**上，沿该大圆数两点之间的度数；
- **两个面的夹角** = **两个极点之间的夹角**；其**补角**是另一侧的角——褶皱的**层间角**要取"跨过褶皱轴面那一侧"的，别取反；
- **视倾角**：画出该面的大圆，再画出剖面方向的**垂直面**（如 `093/V`，一条过圆心的直径），**两者的交点**即剖面上看到的视倾线，转到 E–W 线读出的倾伏角就是视倾角。

**⑦ 📎 旋转复原（rotation / untilting）**：把**旋转轴**转到网的 **N–S 位置**（水平轴则落在周边 N、S 两点上）→ 网上的**小圆**即各点绕该轴的运动轨迹 → 每个点**沿它所在的小圆**移动指定度数（所有点**同角度、同转向**）→ 点移出基圆则从对径处折回 → 转回北朝北读新产状。

> **旋转量与转向的定法**：用"把某个面扳平"来定——如层理 `130/50E`，旋转轴取其**走向线 130**（水平），旋转量取其**倾角 50°**，转向取"使该层理的**极点移到圆心**"的那一边。**极点是否精确落到圆心，是检验旋转做对没有的硬指标。**

**讲义反复强调的三件事**（在 `3-`、`4-`、`5-`、`6-` 四份讲义中逐字重复，显然是评分点）：**① 第 1 步永远是标北点**（北点没标 = 后面所有转回操作全部失效）；**② 最后一步永远是转回北朝北并注记**（不转回直接读方位角读到的是"假方位"）；**③ 只转描图纸，不转投影网。**

📎 **作图约定（从答案图注反推）**：面注记为"名称 : 产状"（`bedding at B : 170/70E`）；线注记为"名称 + 倾伏/倾伏向"（`scours at B 70/087`）；垂直面写 `方位/V`；**量出的过程角度一律标在图上**；双向线的方位写成"主值 (对向值)"（`340° (160°)`）；多步旋转题要给每个点编号 1、2、3 标出各阶段位置，并**分格画出 Step 1 / 2 / 3 三张网**。

**什么时候用**：一切"角度问题"——两面夹多少度、线在面上什么位置、褶皱轴指向哪里、把倾斜地层扳平后线理指向哪里。这些用图幅几乎无法解决。**W6–W7 是全课唯一一次"换工具"**：图上不再有位置信息，只剩方向信息。

### 2.7 工具七：方向数据统计（W7）

**为什么圆形数据（circular data）特殊。** 定义域是圆而非直线，**0° 与 360° 等价**，故算术平均无意义。讲义反例：001° 与 359° 都近乎正北，算术平均 (1+359)/2 = **180° 却是正南**。因此角度平均**必须借助三角函数**。

**向量合成求平均方向：**

```
x_i = sin θ_i （东分量）      y_i = cos θ_i （北分量）
x_r = Σ sin θ_i              y_r = Σ cos θ_i
θ̄  = arctan ( x_r / y_r )
```

⚠️ 讲义约定：**x 是正弦（东）分量、y 是余弦（北）分量**，与数学课 (cos, sin) 的习惯相反——因为地质方位自**北**起算、**顺时针**为正。

**象限判定表（讲义明列，必背）**。`arctan` 只返回 −90°–+90°，答案须在 0°–360°：

| x_r | y_r | 真实象限 | 加上 |
|---|---|---|---|
| + | + | 000–090（NE） | **0°** |
| + | − | 090–180（SE） | **180°** |
| − | − | 180–270（SW） | **180°** |
| − | + | 270–360（NW） | **360°** |

📎 编程时直接用 `atan2(x_r, y_r)`（东分量在前）再对 360 取模；**手算必须查此表**，这是最常见的失分点。

**集中度与圆形方差：**

$$R = \sqrt{x_r^2 + y_r^2}, \qquad \bar R = R/n \in [0,1], \qquad \text{circular variance} = 1 - \bar R$$

**0 表示所有方向完全相同**，越大越散。

**单向 vs 双向数据。** 单向（unidirectional）带指向（交错层理前积面倾向、槽模指向端）；双向（bidirectional）只定义一条**流线**（砾石长轴、波痕脊、沟槽槽线），此时 020° 与 200° 是同一观测。讲义规定：双向数据"公式仍适用，但**必须先把数据校正到流线的同一端**"。W7 靠野外对侵蚀构造不对称形态的判读填 `direction` 列（N/E/SE/W/NW/SW）来判端。📎 通用替代做法是**倍角法**：角度 ×2 后合成、平均方向再 ÷2，使 θ 与 θ+180° 自动等价。**不判端直接合成，方向相反的观测互相抵消，会得出"无优势方向"的假结论。**

**玫瑰图（rose diagram）= 圆形直方图。** 作法六步：① 判类型、双向先判端；② **定箱宽 x 使 360/x 为整数**（常用 10°/20°/30°/45°），起点取 000°，数频数；③ 定半径标度；④ 画刻度环并标注频数值；⑤ 逐箱画扇形（圆心为顶点、张角 x°、半径由第 3 步定）；⑥ 必备标注：N 箭头、方位刻度、半径刻度含义、n、图例。

> ⚠️ **半径标度造成的失真（讲义原文）**：半径正比于频数会"视觉上**夸大高频数**，因为人眼对扇形的印象正比于**面积**，而面积正比于**半径平方**；视觉准确的表示法是让半径正比于**频数的平方根**"。用 √ 标度时**刻度环不等间距**（半径比 √2:√4:√6 = 1.41:2:2.45）。W7 两张答案图并排给出 "frequency" 与 "root frequency" 两版，就是要学生看出观感差异。

**去倾斜（unfolding）校正——本工具与赤平投影的接合点。**

> **关键认识：褶皱轴水平时只需绕走向线转一次；褶皱轴倾伏时必须两步旋转，否则有系统性偏差。**

- **准备**：所有层面投成**极点**；若为柱状褶皱，极点落在一个大圆（**π 圆**）上，**该大圆的极点即褶皱轴**。
- **第一步——把褶皱轴转平**：绕一条**水平的、垂直于褶皱轴倾伏向**的轴旋转，旋转量 = 褶皱轴倾伏角。**同一次旋转必须施加于图上全部要素**（每个层面极点、每条古流线），各沿所在小圆移动相同度数。
- **第二步——绕已水平的褶皱轴把层面转平**：**逐条分别处理**——把该点的层面极点沿小圆转到中心，转多少度、朝哪边转，就把**同一点的古流线转多少度、朝同一边转**。
- **自检**：古流线转完后应落在**基圆**上（它本躺在层面内）；偏离 1–2° 属野外取整误差，偏差大则说明配对搞错。

📎 **为什么必须两步**：绕走向线的单次旋转只在褶皱轴水平时才等价于去褶皱。褶皱轴倾伏时现今产状是"褶皱 + 整体倾伏"的复合结果；先把轴转平即剥离倾伏那一份，剩下的才是纯粹绕水平轴的褶皱作用。

**复原顺序的铁律（W6 Ex1 第 5 题）**：**构造复原必须从最年轻的事件倒着做。** W6 的三步复原是范例——Step 1 untilt C（去掉最年轻的区域掀斜）→ Step 2 remove fold plunge（去掉褶皱倾伏）→ Step 3 untilt A and B（展平两翼）。📎 若先展平褶皱再去掀斜，答案会不同且错误（实测差约 6°，且 C 根本无解）。

**什么时候用**：古流向分析、任何"一批产状/线理"的统计与复原；W7 的 Barrême 盆地题是完整范例。

## 三、构造类型判读手册

### 3.1 不整合（unconformity）

**定义（讲义原文）**：*An unconformity is a surface of contact separating younger sedimentary rocks from older igneous, metamorphic or sedimentary rocks, along which there is evidence of a significant time-break (**hiatus**) in the geologic record due to erosion and/or a break in the sedimentation.*

三个必备要件：①它是一个**接触面**（因此和普通层面一样可量产状、可画等高线）；②面上为**较年轻的沉积岩**，面下为较老的火成/变质/沉积岩；③存在**显著时间缺失（hiatus）**，成因为**剥蚀和/或沉积间断**（"and/or"，不可写成 and）。讲义脚注特别区分：整合层序中单个层面代表的**短暂**间断叫 **diastem**，不是 hiatus。

**两套分类体系（讲义明说分工）**：**(a) 按不整合几何**——回答"什么类型、经历了什么构造事件"，**地质图题主要用这套**；**(b) 按地层与不整合面的方位关系**——在沉积层序分析中有意义，回答"海平面/沉积中心怎么移动"。

**体系 (a)：**

| 类型 | 定义要点 | 图面表现与可判别性 |
|---|---|---|
| **角度不整合** angular | 新沉积物覆于**已倾斜或褶皱**的老岩层剥蚀面上 | 上下两套**产状不同**、面**截切**下伏层面；📎 **最易判** |
| **平行不整合** parallel | 面两侧岩层方位相同（上位概念） | 上下产状一致 |
| ├ **disconformity** 假整合 | 界面是**可见的、起伏不规则**的剥蚀面（埋藏古地形） | 📎 只能靠不整合面**起伏且不平行于层面**的等高线形态看出 |
| └ **paraconformity** | 界面不可见，**只能靠记录缺失**（如缺失生物带）识别 | 📎 **在地质图上根本判不出来**，必须靠古生物或年代学证据 |
| **非整合** nonconformity | 新沉积物覆于老的**火成岩或变质岩**之上 | 📎 面下无层理，次易判 |

📎 中文常把 disconformity 直译"平行不整合"，但讲义把 **parallel unconformity 当上位概念**、disconformity 与 paraconformity 是其两个下位型，答题须跟随此层级。

**体系 (b) 要点**：**lapout 尖灭**（toplap 顶超 / baselap 底超，后者含 onlap 与 downlap）；就老地层而言有 erosional truncation 剥蚀削截 / toplap / concordance；就新地层而言有 **onlap 上超**（近水平新层依次覆于倾斜面上，对应**海侵 transgression**）/ downlap / concordance；就后退而言有 offlap 退覆 / basinward shift。

> ⚠️ **讲义刻意设置的陷阱**：**overstep**（超覆不整合）被放在 onlap 条目里括注并强调 *"**has no depositional significance**"*——它表现为**依次更新的岩层覆于下伏层序中依次更老的成员之上**，但作为描述**不含沉积学意义**。**不要因为图上看到 overstep 就推断海侵。**
>
> 📎 **onlap 与 overstep 是本课最易混的一对**，剖面画出来几乎一样，区别在观察对象：**onlap 看上盘**（一套地层依次向面尖灭，有海侵含义）；**overstep 看下盘**（同一个上覆单元横向坐落在越来越老的下伏单元上，纯几何描述）。**地质图上看到的几乎总是 overstep**——因为图上能直接读出"e 一会儿压在 d 上、一会儿压在 a 上"。

**总钥匙（📎 W3 作图的核心，讲义未明说但整道 Q1 建立于此）**：**不整合面本身也是一个有产状的真实界面。** 因此可量走向倾角、**可画地层等高线**（画法与任何层面相同）；它与**地形面**的交线 = 不整合在图上的**出露界线**；它与**下伏各层面**的交线 = **次露头线（subcrop line）**。

> **一句话：有不整合的图 = 两张普通图叠在一起，中间用不整合面这把"剪刀"裁开；上面那张只在面之上有效，下面那张只在面之下有效。**

**作图要点：**
1. **识别**：找一条**横切**另一组地质界线的界线；等价判据是**同一个上覆单元在不同地点分别压在不同的下伏单元上**（overstep）。务必先把"真截切"与"地形造成的露头弯曲"分开（ILO 2 原话）——**地形弯曲不改变界线的走向趋势，截切会**。
2. **不整合面 = 面之上最老单元的底面**（W3 即 base of e）。
3. **两族地层等高线分色/分线型，各自标注所属界面**（`base of b`、`base of e`）——一旦在交叉密集处串线，subcrop line、出露界线、剖面全盘皆错。
4. **求次露头线**：两族中**数值相同的两条线的交点**同时位于两个面上且高程相同，故位于两面的交线上；把同值交点连起来即得。对每个下伏界面重复，即得完整的 **subcrop map**——这才是回答"e 分别压在哪些单元上"的正规做法。
5. **判断盖层去留**：不整合面**低于**地形面处盖层保存，**高于**地形面处盖层已剥掉。📎 被剥蚀切成互不相连的年轻残片叫 **outlier**；被年轻地层包围的老地层露头叫 **inlier**。
6. **剖面上下伏地层一律硬止于不整合面。**

**事件序列（📎 任一角度不整合至少读出五步，ILO 5 标准答法）**：①下伏地层由老到新依次沉积 → ②下伏地层**变形**（由上下**产状差**证明）→ ③**抬升 + 剥蚀**（由不整合面截切下伏层面证明）→ ④重新沉降/海侵，上覆地层沉积 → ⑤上覆地层后期轻微掀斜，再剥蚀至今日地形。

> **产状差 = 不整合期间的变形量。** W3 下伏 13°、上覆 1.5° → **13° 中约 11.5° 发生在不整合之前**，只有 1.5° 是两套共同经历的后期掀斜。

### 3.2 褶皱（fold）

**柱状褶皱（cylindrical fold）——全部作图法的地基。** 讲义原文：一个曲面若其形状**可由一条直线保持自身平行地平移而生成**，即为柱状褶皱面，这条直线称为**褶皱轴**。重要性质：**在任意一组互相平行的剖面上，褶皱形态都相同**。

📎 这条性质使得：(a) 可把图上不同位置测到的产状当成同一褶皱的翼合并处理；(b) 只画一条剖面代表整个构造；(c) 用"两翼平面的交线"求褶皱轴。真实褶皱只在有限范围内近似柱状——**这就是答案里必须注明产状测自图幅哪一部分的原因**（`(NW part of map)`、`(N and NW parts of map)`）。

**基本几何要素**：轴面（axial plane，含褶皱轴且在剖面面上连接相邻各层最大曲率点的面）、枢纽（hinge）、翼（limb）、褶皱轴（fold axis）、**剖面面（profile plane，垂直于褶皱轴的平面——只有在这个面上量的层间角才是真值）**、层间角（interlimb angle）、轴迹（axial trace，📎 轴面与地形面的交线）、倾伏（plunge）。

> **必须记住的严格表述（讲义原文）**：*"If the beds on each limb are of the same thickness the axial plane bisects the interlimb angle; if the beds on each limb are of different thickness, it does not."*
> **即：「轴面 = 层间角平分面」只在两翼等厚时成立。** 答案写 `Axial plane: 150/V (= bisector)` 或 `Bisector : 100/88N (→ axial plane)`，**括号就是在向阅卷人声明自己用了哪种方法并默认了等厚条件**。

**背形/向形 vs 背斜/向斜（最爱考的定义）**——两套**互相独立**的判据：

- **形态判据（几何）**：闭合方向朝上 = **背形 antiform**；朝下 = **向形 synform**。只看弯曲方向。
- **年代判据（地层）**：核部最老 = **背斜 anticline**；核部最新 = **向斜 syncline**。只看年代。

四种组合：`anticlinal antiform`、`synclinal synform`（正常），`anticlinal synform`、`synclinal antiform`（**地层已倒转**）。📎 **口诀：能确定地层新老顺序时才可用 anticline/syncline；只知形状时只能说 antiform/synform。** `EgExSoln` 原文问的正是 *"Is the fold an antiform or a synform?"*——用词刻意，答成 anticline 就答错了题。

**完整描述一个柱状褶皱需要四项（讲义原文，标准答案模板）：**
1. **褶皱轴的方位**（plunge / plunge direction）
2. **轴面的产状**（strike / dip）
3. **每一翼的代表性产状**
4. **层间角**

答案严格按这个顺序列出：`Limbs : Fold axis : Axial plane : Interlimb angle :`——**缺一项扣一项。**

**三张形容词分级表（需要背）：**

| 褶皱轴倾伏 | 术语 | | 层间角 | 术语 | | 轴面倾角 | 术语 |
|---|---|---|---|---|---|---|---|
| 0–10° | non-plunging | | 180–120° | gentle | | 0–10° | recumbent |
| 10–30° | gently-plunging | | 120–70° | open | | 10–30° | gently-inclined |
| 30–60° | moderately-plunging | | 70–30° | close | | 30–60° | moderately-inclined |
| 60–80° | steeply-plunging | | 30–0° | tight | | 60–80° | steeply-inclined |
| 80–90° | vertical | | 0° | isoclinal | | 80–90° | upright |

**图面判据：怎么在地质图上认出褶皱**（📎 讲义未系统给出，从答案反推）：
1. **地层重复的对称性**：沿穿越线出现 `… d c b a b c d …` 的**镜像回文** → 褶皱；
2. **核部年代**：回文中心最老 → 背斜；最新 → 向斜；
3. **两翼产状**：倾向**相背离** = 背形；**相对** = 向形；
4. **倾伏褶皱的鼻状闭合**；
5. **等高线相关性检验**：出露带的 V 若**与地形等高线的 V 同步弯折**，多半是地形假象。

**褶皱面上的地层等高线为什么会折转（作图的关键）**：柱状褶皱面 = 两块平面拼成 → **每一翼上地层等高线仍是一组等间距平行直线**，但两翼方向不同；**同一高程的两条等高线（一翼一条）必然相交于一点，这个交点就是该高程处的枢纽点**（枢纽线同时属于两翼）。

**作图六步：**
1. 描出接触面的出露线；
2. 标出出露线与每条地形等高线的全部交点；
3. ⚠️ **同高程的交点通常多于两个，必须先判断哪些点属于同一翼**——**用 V 字法则目估的倾向来分组**（`approximate dip direction given by veeing` 就是干这个的）；
4. **每一翼内部同高程点连成直线**；检查是否互相平行、间距是否等距——**若不平行/不等距，说明分组错了**；
5. **延长两翼的同高程等高线使其相交**，交点即枢纽点；各高程的枢纽点连起来 → **轴迹**（轴面直立时是一条直线）；
6. 读出四项答案。

**由两翼产状求褶皱轴**：**褶皱轴 = 两翼平面的交线**（两翼都含褶皱轴）。做法：① 赤平网上两大圆的交点；② 视倾角公式手算；③ **对称褶皱的捷径**——两翼倾角相等时，轴的**倾伏向 = 两翼倾向的角平分线方向**；④ 由轴迹上相邻两枢纽点（高差 CI）的图上实距 L，$\tan(\text{plunge}) = \text{CI}/L$。

> **特例：两翼走向完全相同（倾向相反）时，褶皱轴必然水平，倾伏向 = 走向。** W4 `MapSoln` 的 `0/150`、W10 Q1 的 `0/100` 都是这样来的。

**由两翼产状求轴面**：两翼倾角相等（对称褶皱）→ **轴面直立**，走向 = 褶皱轴的倾伏向（或其反方向）；两翼倾角不等 → 轴面倾斜，其产状 = 层间角的平分面（**且仅在两翼等厚时**），一般用赤平网求。📎 **另一条不依赖等厚假设的独立途径**：定出两条不同层位接触面的轴迹，把它们在剖面上的枢纽点连起来，即得轴面在剖面上的迹线。

**层间角**：必须在**剖面面**内量。轴面直立、两翼倾向相反时 $\text{interlimb} = 180° - \delta_1 - \delta_2$。若两翼**倾向相同**（有一翼已倒转），此式不成立，必须画图或用立体网。

**倾伏褶皱的鼻状闭合（📎 最容易记反，给推导而非死记）**：设褶皱轴向南倾伏、地形近似平坦。**背形**：脊线高程沿轴向南降低——北端脊线高于地面（拱顶已剥蚀，两翼出露线分得很开）；南端脊线低于地面（整个拱在地下、不出露）；中间两条出露线**汇合闭合**。故——

> **口诀：背形「尖」向倾伏；向形「开」向倾伏。**（背形鼻状尖端指向倾伏方向，核部老地层向上倾方向敞开；向形闭合尖端指向倾伏的反方向。）

⚠️ **轴迹直/曲与倾伏是两件事**：轴面**直立**时轴迹在图上是直线；轴面**倾斜**时轴迹本身也服从 V 字法则、**会随地形弯折**。倾伏影响的不是轴迹直/曲，而是**出露带是否收口成鼻状**。

### 3.3 断层（fault）

**完整描述断层几何须三要素（讲义要求）：**
- **(a) 断层面产状**：strike/dip 或 dip/dip direction。
- **(b) 滑距向量（slip vector）的方位与大小**。定义为**连接断层面两侧原本重合两点的连线**；方位用倾伏角/倾伏向或面内侧伏角；大小可用向量的模，也可用**走滑 + 倾滑**分量——**讲义要求最好两种都给**。
- **(c) 运动方向感**：走滑用 **dextral 右旋 / sinistral 左旋**，倾滑用 **normal 正断 / reverse 逆断**，**两个分量各自都要注明**。

**答案格式即评分范本**：`Fault: 020/V; slip vector 70/020, 409 m; Dip-slip: 384 m (down to E); Strike-slip: 140 m (sinistral)`——**断层产状、滑距向量（方位 + 大小）、倾滑（大小 + 方向感）、走滑（大小 + 方向感）四段齐全，缺一段即扣分。分量为零也要显式写出**（`strike-slip: 0 m`）。

> ⚠️ **直立断层无上下盘之分**，故**不能写 normal/reverse**，改写 **"down to E"、"up to north"、"down to the W"**。同理直立断层的 dip-slip 分量就等于 **throw**，而 **heave = 0**。

**⚠️ 头号警告：错移 ≠ 走滑。** 讲义原文：图上界线沿断层被错开，*"does **not** imply that there was a strike-slip component to the slip vector"*——**倾斜地层被纯倾滑断层切断，平面上照样产生视错移**。

> **判别法则（讲义原文）**：图上**两条产状不同**的界线，被同一条断层错开的视错移量**不同** ⟹ 有**倾滑**分量；**相同** ⟹ **无倾滑**分量（纯走滑）。
> 📎 原理：倾滑造成的视错移**依赖被错界线的产状**（界线越缓，同样 throw 造成的水平错移越大）；走滑造成的与产状无关。

**Separation ≠ Slip（本周第二个核心区分）。** separation 只是"界面被切成两半后的间距"；slip 要求找到**原本同一点**的两个像。讲义指出：若**只**有断层产状 + **一条**已知产状界面的视错移，则**无法确定滑距向量**，只能描述 separation：**strike separation**（= 视错移，水平面内量）、**throw**、**heave**、**hade**、**dip separation**、**vertical separation**、**stratigraphic separation**（跨断层缺失/重复的地层厚度）。

**截交线（cut-off line）——所有作图的枢纽**：目标界面与断层面的交线，**两盘各一条**；**图面上两条截交线的间距就是 heave**。

**穿刺点（piercing point）**：两条**不平行**截交线的交点，两盘各一个。📎 **为何必须两条不平行界面**：一条界面的截交线只是**线**，两盘两条线只能给出某方向的分离量；两条不平行界面相交才产生**点**，有点才有真 slip。故题目都同时给"一条脉 + 一条地层界线"或"两条岩脉"。

**五种图法（按情形选）：**

| 情形 | 方法 | 关键 |
|---|---|---|
| **求断层面产状** | 在**断层迹线**上画地层等高线 | 断层线与地形等高线的交点，同高程者连直线；若断层线是**不受地形影响的直线**，断层面**直立**，记 `/V` |
| **求 heave / throw** | 两盘**分别**画地层等高线（标盘别 `300E`/`100W`）→ 同高程的"地层等高线 × 断层面等高线"交点 → 连成截交线 → 两条截交线间距 = heave → $T = H\tan\delta$ | 两盘绝不可混点 |
| **纯倾滑断层** | 作一条**平行断层倾向**的铅直剖面 | 剖面方位须与断层严格对应（`153/57SW` → 剖面 `063/V`）；此时**滑距向量方位 = 断层的倾角/倾向** |
| **纯走滑断层** | **直接量图**（视错移量本身），方位 = 断层走向 | 不必作剖面，但**若两条截交线位于不同地形高程，需作三角改正** |
| **斜滑（一般情形）** | **断层面剖面 / 并置剖面** | 见下 |

**断层面剖面（fault plane / juxtaposition section）——本课最有技术含量的一招。** 讲义定义：**在断层面这个平面内**作的剖面，**把上盘与下盘画在同一张剖面上**。七步：

1. **画剖面框**：走向 = 断层走向（标题写 `Fault plane section: 153/V`），纵轴为高程。**断层直立时剖面即真实铅直平面，无需展开变换。**
2. **投地形线**。
3. **投截交点**：地图上各界面与断层线的交点，按沿断层走向的距离投到地形线上。
4. **画各条截交线**：直立面与直立断层面的交线是**铅直线**；倾斜界线的交线是**斜线**，斜率 = 该界面在断层面方向的视倾角。
5. **找穿刺点**：每盘上"脉的截交线 × 界线的截交线"= 一点，两盘各一个，**断层活动前本是同一点**。
6. **连线 = 滑距向量**：长度 = 净滑距，与水平线夹角 = 侧伏角（直立断层时即倾伏角）。
7. **分解**：水平分量 = 走滑、铅直分量 = 倾滑，在图上标出 **strike-slip / dip-slip / slip vector** 三条边。

📎 **倾斜断层的断层面剖面怎么画**：把断层面沿走向"摊平"到纸面——横轴取沿断层走向的真实距离，纵轴取**沿断层面倾斜坡面的距离**（非高程）；高程 h 在剖面上是水平线，相邻高程 Δh 两线间距 = $\Delta h/\sin\delta$。摊平后量得的长度即断层面内**真长度**，夹角即 **pitch**，再用 $\sin(\text{plunge}) = \sin r \sin\delta$ 换算倾伏角。

**必写的假设**：涉及脉/岩脉时，脉体有宽度、是张开充填的，两盘对应必须**假设张开方向**（默认**垂直脉壁张开**），否则解不唯一。材料两处单列此句——**这是采分点。**

📎 **并置图（juxtaposition / Allan diagram）的另一重读法**：在断层面剖面上用两色分别画出下盘与上盘所有地层的截交线，断层面被划成许多区块，每块对应"下盘某层 ↔ 上盘某层"的贴靠。**砂 ↔ 砂**重叠 → 储层连通、断层**不封闭**；**砂 ↔ 泥/页岩** → **并置封闭（juxtaposition seal）**，可成断层圈闭。⚠️ **限制**：砂—砂并置处若发育**断层泥（fault gouge）**或**泥岩涂抹（shale smear）**仍可能封闭，反之涂抹不连续则封闭失效——并置图给出的是封闭的**必要条件而非充分条件**。讲义只把它当求滑距的工具，未展开这层油气/水文意义。

### 3.4 侵入体与事件序列（W8）

**两分与通名。** 火成岩体可**喷出**或**侵入**。讲义明确：**喷出单元（熔岩流、火山碎屑）几何上完全按沉积单元处理**，只是横向厚度变化更大。**Pluton** = 侵入岩体通称；**Composite** = 多期且成分不同；**Multiple** = 多期但成分相同。

**图面判读的两个分类维度（讲义）**：**(a) 形状**——*parallel-sided*（板状）或 *more complex shape*；**(b) 边界相对围岩层理的方位**——切穿者 **discordant**，大体平行者 **concordant**。

> 📎 **本课最重要的图面推论**：**concordant 岩体在图面上与地层无异**——可给它画 strike lines、遵守 V 字法则、用与地层相同的方法求真厚度；**discordant 岩体必须独立求产状**，其两壁是与围岩无关的一对平面。这正是"沉积接触面"与"岩墙**另外**画 strike lines"分开出题的原因。

| 板状（parallel-sided） | 整合性 | 判据 |
|---|---|---|
| **Sill 岩床** | concordant | 席状体；持续向上阶跃者称 **transgressive sill**；原型 Great Whin Sill |
| **Dyke 岩墙** | discordant | 切穿层理；常成 **swarm**（parallel 或 radial） |
| **Cone-sheet 锥状岩席** | — | 弧形出露、接触面**向内**倾 |
| **Ring dyke 环状岩墙** | — | 近圆形出露、接触面**直立至陡向外**倾 |

📎 cone-sheet 与 ring dyke 图面都是弧形环带，**唯一区别在倾向**。判别办法：给弧形接触面画 strike lines，看等高线值朝圆心方向是降是升。

| 复杂形状 | 整合性 | 判据 |
|---|---|---|
| **Batholith 岩基** | discordant, composite | **>100 km²**、**无可观察的底**；见于造山带核部 |
| **Stock 岩株** | discordant | **<100 km²**；严格义近圆/椭圆、**<20 km²** |
| **Boss 岩瘤** | discordant | 圆形、**<25 km²**、接触面**陡** |
| **Cupola 岩穹凸起** | — | 自大侵入体伸出，但**图面上与主体隔离** |
| **Plug 岩栓** | discordant | 近圆直立供岩通道；剥蚀出露后称 **volcanic neck**（法语 puy） |
| **Diatreme 火山管** | discordant | **胡萝卜形**、陡**向内**倾侧壁、深 1–2 km、充填**角砾** |
| **Laccolith 岩盖** | **concordant** | 穹丘状，**上拱上覆层、底面近平**；叠置者 cedar-tree laccolith |
| **Lopolith 岩盆** | **concordant** | **碟状、向上凹**；如 Bushveld complex |
| **Phacolith 岩鞍** | **concordant** | **凹凸相间**，源于褶皱围岩；叠置组称 saddle reefs |

📎 **速记**：laccolith / lopolith / phacolith **都是 concordant**，图面按地层处理，区别只是弯曲方向；batholith / stock / boss / plug / diatreme **都是 discordant**，表现为切断一切地层界线、不遵守 V 字法则的不规则块体。

**定年判据工具箱**（材料实际动用 ①–⑥，📎 ⑦–⑨ 为补充）：
① **切割关系**（切者新）；② **未被错断**（不整合面 strike lines 在断层两侧间距相同、未被错开 → 不整合晚于断层）；③ **不整合 = 一次抬升 + 剥蚀间断**；④ **截切的构造花纹**；⑤ **变质/褶皱的选择性**（只有某单元被变质；某单元被褶皱而断层未被褶皱）；⑥ **现今产状反推掀斜**（现今直立的矿脉与断层，若原本直立，则必晚于造成倾斜的掀斜）；📎 ⑦ **接触变质晕**（有晕 → 侵入体晚于被烤围岩）；📎 ⑧ **捕虏体（xenolith）**——被包者老；📎 ⑨ **烘烤边/冷凝边**。

**事件序列的书写规范（`HandSequence` 的两条硬规范，评分直接依据）：**
1. **格式**——写成"措辞简练的一组 **bullet points，编号以指明先后**"，不是散文；**方向统一 oldest → youngest**（标题写死 *Sequence of events (oldest to youngest)*）。**写反即使内容全对也扣分。**
2. **证据**——**推断每一步所用证据一般都要写在相应条目中，任何定量几何信息也要写出来**。示范：*"6. Faulting（断层错开 C 中褶皱翼但未影响 B；走向 NW–SE，视位移显示为纯倾滑，NE 盘下降）"*——括号里既有证据又有定量几何。**无证据的条目基本不给分。**

**两个"诚实"要点：**
- 讲义原话——若**没有地形和/或各面方位信息，构造几何无法严格描述**；
- **保留不确定性**是高分点。`SeqSoln` 第 (3) 步是最佳范例：*"Tilting［此位置假定矿脉与断层原本直立；若非如此，掀斜只能约束在 (1) 之后、(6) 之前］"*——**"假设 + 假设失效后的约束区间"这种写法**，以及 W10 的 *"It is not possible to say, based on the map, which came first – folding or faulting"*，都是**证据不足时的正确答案**，不是硬猜。

**📎 可复用的四步法：** ① **清点**——列出所有地层单元 + 侵入体 + 构造面（不整合、断层、褶皱轴面）+ 剥蚀面，一个不漏；② **两两判先后**——谁切谁、谁被截断、谁被变质/褶皱/错断而另一个没有；③ **排序**成全序，无直接接触关系者位置不唯一，**必须明说约束区间**；④ **自洽检查**——复述一遍确认不与任何约束矛盾，并检查"沉积—抬升剥蚀—再沉积"物理闭合（**每个不整合上下都要有对应的抬升剥蚀事件**）。

⚠️ **抬升剥蚀与其上沉积是两个事件，绝不能合并成"不整合"一条**；**"剥蚀至现今地形"永远是最后一条**。W8 答案九步中有**两步**是剥蚀。

### 3.5 ★易混对照表（本节最该带进考场的部分）

📎 **以下四张表为本总纲对 W3–W5、W8、W10 判据的整合，非某一份材料的原文。**

#### (1) 褶皱重复 vs 逆断层重复地层

| | **褶皱造成的重复** | **逆断层造成的重复** |
|---|---|---|
| **对称性** | 关于某条线**镜像对称**（`a-b-c-b-a` 回文），这条对称轴就是**轴迹** | **不对称**：同一套层序沿一条界线**平移叠置**，读出 `a-b-c \| a-b-c`，无镜像关系 |
| **两侧倾向** | 对称轴两侧地层**倾向相反**（背形相背倾、向形相向倾） | 界线两侧地层倾向、倾角**基本一致** |
| **分界线性质** | 是一条**虚拟的轴迹**，不是岩性界线，**两侧岩性连续** | 是一条**真实的断层面**，**可在其上画地层等高线** |
| **新老关系** | 背形核部**最老**、向形核部**最新** | 上盘把**较老**地层推到较新地层之上 |
| **实操钥匙** | 横切构造走一条测线，把出露单元按顺序抄下来，**先找对称性** | 同左；找到断层后在其迹线上画等高线求产状 |

#### (2) 正断层缺失 vs 不整合缺失

| | **正断层造成的缺失** | **不整合造成的缺失** |
|---|---|---|
| **界线形态** | 一条**较直/规则**的线，其上可画出**直、平行、等距**的地层等高线（平面） | 常是**不规则起伏**的面（古地形），等高线弯曲不规则（disconformity 尤其如此） |
| **两侧产状** | 两侧地层产状**相同**（同一构造被切断） | **角度不整合**下伏地层产状与上覆**不同** |
| **缺失层位** | 缺失的**层数沿断层走向大致恒定** | 缺失层位**横向变化**（overstep：越往一侧上覆层压在越老的层上） |
| **与地层的关系** | 断层**同时切断**上下盘的所有界线 | 不整合面**只截断下伏地层**，上覆地层与之**平行/上超** |
| **岩性证据** | 断层角砾（fault breccia）、擦痕 | **底砾岩（basal conglomerate）**、风化壳 |

#### (3) 断层切褶皱 vs 褶皱变形断层

| 判据 | **断层后于褶皱**（断层切褶皱） | **断层先于褶皱**（褶皱把断层也弯了） |
|---|---|---|
| **断层线本身是否被弯曲**（★钥匙） | 断层迹线为直线/平滑；断层上的等高线**直、平行、等距** → 断层面是**平面** | 断层迹线随褶皱波形**弯折**；断层上的等高线**不平行、不等距** → 断层面已被弯成**曲面** |
| **断层面产状是否随位置变** | 全图只有**一个**断层产状 | 断层产状在**背形翼与向形翼上不同** |
| **褶皱轴迹是否被错断** | 轴迹在断层两侧**错开**，错距与滑距向量一致 | 轴迹**连续穿过**断层，不被错开 |
| **两盘褶皱要素** | 两盘褶皱轴产状**相同**，只是位置平移 | 两盘褶皱轴产状仍相同，但断层的倾角/走向两侧不同 |

**核心一句话：钥匙是"断层线本身是否被弯曲"。** 断层是平面 → 它形成时周围已不再变形；断层是曲面 → 它被后来的褶皱一起卷进去了。

📎 **W10 Q1 为何答"不能判断"**：褶皱轴 `0/100`（水平、走向近 E–W）与断层走向 `090` **仅差约 10°，近乎共轴**，且褶皱**极为平缓**（层间角 147°）。(i) 若断层后生成，它平面地切过褶皱；(ii) 若断层先生成、随后被一个轴向与它几乎平行且极平缓的褶皱改造，断层面只会被轻微倾斜、**仍近似平面**。两种情形在本图精度下**不可区分**。（材料只给结论，未给理由；此推断为本总纲补充。）

#### (4) 岩床 vs 熔岩流（本课最经典陷阱）

| | **岩床 sill** | **熔岩流 lava flow** |
|---|---|---|
| **图面表现** | concordant，产状随围岩——**两者图面完全一样，无法靠图面区分** | 同左 |
| **★烘烤边/冷凝边（决定性证据）** | **上下两侧围岩都有烘烤边**；**两壁都有冷凝边** | **只有底面有烘烤边**（上表面当时暴露于地表，上覆地层是后来沉积的） |
| **上表面特征** | 无 | 常有**气孔、枕状构造、风化面、火山碎屑夹层** |
| **捕虏体** | 可含**上覆地层**的 xenolith | 不可能含上覆地层碎块 |
| **年代含义** | **可比上覆层年轻得多** | **是地层的一部分**，上覆层必比它新 |

**附：岩墙 vs 断层（同样极易混）**——📎 **岩墙是有厚度的岩性体**（两条平行接触线夹一种岩石，两侧地层**不错动、可对接**）；**断层是一个面**（一条线，两侧地层**被错开**）。W8 图幅上两者并存：辉绿岩（有宽度、`24/285`）与断层（一条线、直立、错开一切）。

**附：侵入体与褶皱/掀斜的先后**——📎 **随围岩一起弯曲的岩床早于褶皱；笔直切过整个褶皱的岩墙晚于褶皱。**

## 四、通用解题流程

> 面对一张**陌生图幅**的标准作业顺序。每一步标出用到 §二 的哪件工具。W10 材料只给成品答案，未列步骤；📎 **本节流程为整合重建**，但答案图上的每一项细节都反过来印证了它。

### Step 0 — 读图（3 分钟，别跳过）
**读图例与地层柱**，把新老关系搞清楚（W8 图例特意写 *"not in stratigraphic order"*，层序必须自己推）→ **确认北方向**（⚠️ W9 专门提醒 *"North is oblique to the edges of the paper"*，量角器必须对齐 N 箭头，不能用图纸边缘）→ **确认比例尺与单位**（W10 同一周两题一 m 一 ft）→ **确认等高距** → 找出所有**已给的产状符号**（真实图幅上是免费的验算数据）。
> **工具**：§2.1 产状记法。

### Step 1 — 识别要素，判断构造类型
清点图上有几类界线：地质接触面、断层线、不整合面、侵入体边界。**先用 V 字法则（§2.3）目估各接触面的倾向**——这是被示范的解题入口（W4 `approximate dip direction given by veeing`、W10 HINT `use the V-ing ... before trying to draw them`）。
用 §3.5 的四张对照表判断：**重复是褶皱还是逆断层？缺失是正断层还是不整合？** ⚠️ 同时排除"地形造成的露头弯曲"（ILO 2 的核心）——**均匀倾斜的平面在崎岖地形上照样会剧烈弯曲甚至形成 V 字，不代表有构造。判据：只要地层等高线仍是等间距平行直线，构造就是单斜的。**
> **工具**：§2.3 V 字法则、§三 判读手册。

### Step 2 — 从"最干净"的一块入手求产状
**先分层、再找断层**：选一处**未被断层切断、未被不整合截切**的地层界线，用 §2.2 画地层等高线求产状；若图上不给产状符号则用 §2.4 三点法/多点法；若给钻孔则用"高程 = 孔口标高 − 深度"。
> ⚠️ **反过来做（先纠结断层）通常会卡死**，因为断层的滑距必须靠已知产状的界面才能求。
> **工具**：§2.2 地层等高线、§2.4 三点法与钻孔。

### Step 3 — 逐个构造展开
- **有不整合** → 上下两套**分色分族**各画一套地层等高线（§3.1），求 subcrop line，判盖层去留；
- **有褶皱** → 用 V 字法则分翼 → 每翼一套地层等高线 → 延长求枢纽点 → 连成轴迹 → 求**四要素**（§3.2）；两翼产状可直接送上赤平网求交线（§2.6 ⑤）；
- **有断层** → 在**断层迹线**上画地层等高线求断层产状 → 两盘**分绘**地层等高线（标盘别）→ 求截交线与 heave → 按纯倾滑/纯走滑/斜滑选图法（§3.3）；
- **有侵入体** → 先判 concordant / discordant；discordant 者**只用同一盘的同一壁**画 strike lines（§3.4）。
> **工具**：§2.2、§2.3、§2.6、§三 各节。

### Step 4 — 上赤平网处理角度问题
凡涉及"两面夹角、两面交线、pitch↔plunge 换算、剖面方向的视倾角、旋转复原"，一律上网（§2.6）。⚠️ **几何作图用 Wulff（等角）网，统计用 Schmidt（等面积）网，绝不混用。**
> **工具**：§2.6 赤平投影、§2.7（若涉及一批数据）。

### Step 5 — 求厚度
每个单元用 $t = t_{\text{vert}}\cos\delta = w\sin\delta$（§2.5）；**顶或底被截断者只能写 `~X m min`**；**换算式必须写在图上**；**注明测量位置**（`(NW part of map)`）。
> **工具**：§2.5 剖面构建中的厚度换算。

### Step 6 — 作剖面
按 §2.5 的八步走。**选剖面线时尽量垂直走向或垂直褶皱轴**；要量数值则 **VE = 1**；先画截切面再画被截者；**厚度守恒自查**；补齐 (a)–(e) 五项规范；地形面之上用**虚线**补出被剥蚀部分。
> **工具**：§2.5 剖面构建；视倾角换算见 §五 公式 3。

### Step 7 — 写事件序列
按 §3.4 的四步法：清点 → 两两判先后 → 排全序 → 自洽检查。**编号 bullet、oldest → youngest、每条附证据与定量几何、证据不足时明说"不能判断"并给约束区间。**
> **工具**：§3.4 定年判据工具箱 + 事件序列规范。

### Step 8 — 交卷前的六项核查
1. **过程线是否全部留在卷面**（辅助线、内插线、倾角小三角形、量取标记——**它们就是过程分**，W1–W2 答案连不出露的地层等高线都保留）；
2. **中间量与算式是否写在图边**（`x = 15/tan 11° = 77 m`、`B—394 m—A`、`= 300 cos 20°`）；
3. **产状是否用双记法给出**（`043/14 NW or 14/313`——多份答案严格给出等号两边，**只写一种直接失分**）；
4. **颜色/线型是否在 key 中注明**（W9 题面第 1、2 题各提醒一次"mark the colour in the key"，**重复两次的要求必是给分点**）；
5. **阴影/涂色是否画了、是否画对侧**（下伏单元 = 上倾侧；直立面两侧皆可但须写明理由）；
6. **剖面是否标了方位、两端方位字母、两个比例尺、VE 约定、地层柱与图例**。

## 七、易错点总表

> 整合十周。W10 笔记已有一份全课清单，本表以之为基础扩充并按**概念混淆 / 作图操作 / 计算换算 / 呈现规范**重新分类。

### A. 概念混淆

| # | 易错点 | 判据 / 纠正 |
|---|---|---|
| A1 | **走向与倾向混淆** | `090/11S` 中 090 是**走向**、S 是倾向方向。速记：**三位数在前 = 走向记法；一两位数在前 = 倾角记法** |
| A2 | **侧伏（pitch）与倾伏（plunge）混淆** | 侧伏在**面内**从走向线量，倾伏在**铅垂面内**从水平线量。讲义算例：`40°NE on 060/30SE` 的倾伏只有 **18°**。**判据：plunge ≤ dip 恒成立**，算出的倾伏若大于该面倾角一定错了 |
| A3 | **真倾角与视倾角混用** | 只有剖面**垂直走向**（或平行倾向）时量到的才是真值；否则须用 $\tan\alpha=\tan\delta\sin\beta$ |
| A4 | **背斜/向斜 与 背形/向形 混用** | 前者**年代**判据（核部新老），后者**形态**判据（闭合方向）。无年代信息时**只能**说 antiform/synform |
| A5 | **轴面直接当成层间角平分面** | 讲义明说**只有两翼等厚时成立**。要么核实等厚，要么像答案那样写明 `(= bisector)` 声明假设 |
| A6 | **separation 与 slip 混为一谈** | 只有一条界面时量得再准也只是 separation；求 slip 必须有**两条互不平行的标志面**产生穿刺点 |
| A7 | **看到水平错移就断言走滑** | 倾斜地层被纯倾滑断层错开照样有水平错移。判据：两条**产状不同**的界线视错移是否相同 |
| A8 | **上盘/下盘判反；直立断层写 normal/reverse** | 断层面**之上**为上盘。**直立断层无上下盘**，只能写 "down to E" 之类 |
| A9 | **throw 与 net slip 混淆** | throw 只是**铅直分量**。11° 逆冲的例子最说明问题：净滑距 1140 m，throw 仅约 217 m |
| A10 | **onlap 与 overstep 混用**，进而错误推断海侵 | overstep **无沉积学含义**（讲义刻意设的陷阱）；**地质图上看到的几乎总是 overstep** |
| A11 | **disconformity 与 paraconformity 混淆** | 前者界面**可见且起伏**，后者**不可见**、只靠记录缺失识别（**地质图上根本判不出来**） |
| A12 | **把地形起伏造成的弯曲误判为构造** | ILO 2 的核心。**只要地层等高线仍是等间距平行直线，构造就是单斜的**；地形弯曲不改变界线的走向趋势 |
| A13 | **把地形 V 当成褶皱转折端**（或反之） | 地形 V 只出现在**河谷**处且随谷线走；褶皱转折端**不依赖地形**，两侧倾向相反 |
| A14 | **岩床与熔岩流混淆** | 见 §3.5(4)：**岩床上下两侧都有烘烤边，熔岩流只有底面有** |
| A15 | **把岩墙当断层** | 岩墙是**有厚度的岩性体**（两侧地层不错动、可对接）；断层是**一个面**（两侧地层被错开） |
| A16 | **对圆形数据取算术平均** | 001° 与 359° 平均得 180° 正南。**必须向量合成** |
| A17 | **单向与双向数据混用** | 双向数据不先判端就合成，正反相消，得出"无优势方向"的假结论 |
| A18 | **混淆"褶皱轴倾伏向"与"轴面走向"** | 仅在轴水平或轴面直立时相等；否则轴在轴面内有非零侧伏角 |
| A19 | **混淆 profile plane 与普通竖直剖面** | 前者**垂直于褶皱轴**，只有其上的层间角是真值 |
| A20 | **上半球 / 下半球混用** | 本课全部**下半球**。算出"向上"（负倾伏）必须取对径方向改成向下的等价线 |
| A21 | **Wulff 网与 Schmidt 网混用** | 几何作图用 **Wulff（等角）**，统计用 **Schmidt（等面积）**；两网外观相近，拿错则角度全错 |
| A22 | **鼻状闭合方向记反** | **背形尖端指向倾伏方向；向形尖端指向倾伏的反方向**（记推导别记结论） |

### B. 作图操作

| # | 易错点 | 纠正 |
|---|---|---|
| B1 | **倾斜方向记反**（W1 最致命） | Map A/B 专门放大这个错误。**画完自检：高程数值是否朝倾向那一侧递减？** |
| B2 | **地层等高线高程标错、标反或漏标** | **每条线两端都要写数字**，画完从一端数到另一端核对 |
| B3 | **地层等高线间隔与地形等高线不一致** | 必须落在同一组高程值上，否则找不到同值交点 |
| B4 | **把地形等高线当地层等高线**（或反之） | 地层等高线**直、等距、平行**；地形等高线**弯、疏密不均**。作图用不同线型；W9 尤其致命（1° 倾角下界线蜿蜒得几乎和地形等高线一样）——**你画出来的若也弯弯曲曲，一定错了** |
| B5 | **同高程点连线时把两翼/两盘/两壁的点连到一起** | 画褶皱地层等高线最常见的失败。解法：**先用 V 字法则分翼**；断层两盘分绘并标盘别（`300E`/`100W`）；岩墙**只用同一盘的同一壁** |
| B6 | **V 尖方向判反** | 不背口诀：先画地形等高线的 V（永远指上游），再定地层等高线取交点连线；要背就背分母 $(a\pm d)$ |
| B7 | **在极缓倾角下随便取交点** | 界线与地形等高线**近乎平行**时交点位置极不确定。**优先选二者以较大角度相交处，近平行处宁可放弃** |
| B8 | **在被第四系覆盖处误取界线点** | 真实 BGS 图上覆盖处的基岩界线为**虚线（推断位置）**，不可作控制点 |
| B9 | **忘记内插** | W9 C 点下界面是 **186 m**，不是任何一条等高线的标注值 |
| B10 | **忘记标北点 / 忘记转回北朝北**（赤平投影最高频低级错误） | 四份讲义首尾两步逐字重复这两件事 |
| B11 | **走向/倾角记法中数错 E 侧还是 W 侧** | 补救：画完先转回北朝北看**弧凸向哪边**（应凸向倾向） |
| B12 | **侧伏没沿大圆弧量** | 必须**贴着大圆弧**走，不能沿直线或沿周边量 |
| B13 | **旋转复原时各点移动量或转向不一致** | 所有点**沿各自小圆、同向、同角度**移动；出基圆从对径折回。**检验标准：作为依据的极点是否精确落到圆心** |
| B14 | **复原顺序颠倒** | **必须从最年轻的事件倒着做**；先展平褶皱再去掀斜会得到错误答案 |
| B15 | **褶皱轴倾伏时只做一次旋转** | 必须**两步**；且每次旋转须**同时施加于全部要素**（漏转古流线最常见） |
| B16 | **剖面上把下伏单元画穿了不整合面** | 下伏地层必须**硬止于不整合线** |
| B17 | **剖面两侧地层画成连续** | 同一界面在断层两侧必须错开一个等于 throw 的高差 |
| B18 | **不画被剥蚀拱顶的虚线** | 不画等于没表现出褶皱 |
| B19 | **外推超出合理范围** | "均匀倾斜"只是题给假设，遇断层、褶皱、不整合即失效 |
| B20 | **徒手画平行线** | 本课最典型的失分来源。用平行尺/三角板；分规 + 比例尺条量距；量角器定走向 |
| B21 | **忽略"北方向与图纸边缘斜交"** | W9 专门加了提醒。**量角器必须对齐 N 箭头** |
| B22 | **上手顺序错**（综合题） | 读图例 → 先分层 → 找对称性锁轴迹 → 再处理断层 → 最后剖面与时序。**先纠结断层通常会卡死** |
| B23 | **量角时数错格 / 量在错的大圆上** | Wulff 网 2° 细格与 10° 粗格混排。先数到最近的 10° 粗格再补细格，量完用 $\sin(\text{plunge})=\sin\delta\sin(\text{pitch})$ 粗算核对 |

### C. 计算换算

| # | 易错点 | 纠正 |
|---|---|---|
| C1 | **忘记按比例尺换算** | $d = \Delta h/\tan\delta$ 算出的是**实地米数**。把 174 m 直接画成 174 mm 是常见事故 |
| C2 | **量 x 时没垂直走向** | 斜量必低估倾角 |
| C3 | **比例尺换算出错，倾角差一个数量级** | W9：14.7 mm ↔ 实地 772 m；误当 14.7 m 或 147 m，倾角会变成 45° 或 5.8° |

| C5 | **钻孔深度与孔口标高混淆** | "700–800 ft 灰岩"实为高程 **−300 至 −400 ft**，差 1100 ft |
| C6 | **漏掉深度为 0 的 "Above X" 单元** | 会导致一侧少画一个岩性带 |
| C7 | **走向 ± 90 取错符号** | 043 的 NW 是 **313** 不是 133；120 的 SW 是 **210** 不是 030 |
| C8 | **剖面方位取错** | 纯倾滑的铅直剖面**平行断层倾向**（`153/57SW` → `063/V`）；断层面剖面**沿断层走向**（`153/V`）。**两者差 90°** |
| C9 | **象限判错**（方向统计） | `arctan` 只返回 −90°–+90°，必须按符号加 0°/180°/360°；且 **x 是正弦（东）、y 是余弦（北）**，勿写反 |
| C10 | **把所有数据合并统计** | 合并 25 条 → 328°/方差 0.83，Rayleigh p≈0.51 完全不显著；**先分组、再统计** |

> **一句话总结全课**：这门课教的不是十种孤立的图幅技法，而是**同一件事的十次演练——把三维几何压成二维、再从二维读回三维**。压下去靠的是"地层等高线 = 界面的等高线"这一条，读回来靠的是"同值交点定露头"这一条；剖面是把它画出来，赤平投影是把位置丢掉只留角度。**面对任何一张陌生图幅，永远是同一个顺序：读图例定新老 → V 字法则定倾向 → 从最干净的一块画地层等高线 → 逐个构造展开 → 角度问题上网 → 作剖面 → 写带证据的事件序列。这套顺序本身，才是这门课真正的考点。**
