## 一、本周主题

本周练的是**地球科学家最基础、也最"手上功夫"的一项技能：拿一块没有标签的矿物手标本，只靠肉眼 + 简单工具（指甲、铜币、小刀、玻璃、手术刀、条痕板），在几分钟内把它定名**。手段是系统测定一组**物理性质 (physical properties)**——晶习 (habit)、解理 (cleavage) / 断口 (fracture)、颜色 (colour) 与条痕 (streak)、硬度 (hardness)——每一条性质都是矿物**内部原子结构与化学成分的外部表现**，因此这套流程本质上是"**用宏观现象反推微观结构**"。

在 EART11300 十周实践课（Week 1、2、4、5、6、7、8、9、10、11，无 Week 3）中，本周是**岩石学/矿物学实操链条的第一环**：
- **Week 8（本周）**：矿物在手标本中的鉴定 → 认识组成岩石的"零件"；
- **Week 9**：岩石在手标本中的鉴定 (Rocks in hand specimen) → 把"零件"组装成岩石类型判读；
- 后续野外与制图工作则建立在"能认矿物、能认岩石"之上。

因此本周的定位是**基石课**：没有矿物鉴定能力，岩石鉴定、野外记录、显微镜下薄片观察全都无从谈起。讲义也明确指出，**解理在偏光显微镜的薄片 (thin section) 观察中同样是极有价值的鉴定性质**——本周学的东西会一路用到高年级。

本周的可迁移技能有三条：
1. **系统性观察**：不凭第一印象（尤其不能凭颜色）下结论，而是按固定顺序把一组独立性质测完再综合判断；
2. **定性分级的自觉**：perfect / good / moderate / poor 这类主观分级要敢用、也要知道它只是定性，不必纠结边界；
3. **知道每条性质的可靠性排序**：解理 > 硬度 > 条痕 > 晶习 > 颜色（颜色最不可靠，讲义反复强调 "must be used as a diagnostic property with some care"）。

## 二、核心概念

### 2.1 什么是矿物 (What is a mineral?)（Video 1）

**矿物的完整定义——五个要件，缺一不可：**

| # | 要件（英文） | 中文 | 说明 |
| --- | --- | --- | --- |
| 1 | **Naturally-occurring** | 天然产出 | 实验室合成的不算（人造金刚石不是矿物） |
| 2 | **Inorganic** | 无机 | 讲义给出的操作性判据是"**不含碳 (does not contain carbon)**" |
| 3 | **Solid** | 固体 | 液态、气态不算 |
| 4 | **With characteristic chemical composition (either fixed, or varying within specific limits)** | 具有特征化学成分（固定，或在特定范围内变化） | 允许**类质同象替代 (solid solution)**，如石榴子石 (Ca,Mg,Fe)₃Al₂Si₃O₁₂ 中 Ca/Mg/Fe 可互换，但替代范围有限 |
| 5 | **Crystalline structure** | 具晶体结构（原子长程有序排列） | **这是与玻璃的分界线** |

Video 1 的示例：CaF₂ 萤石 (fluorite)；自形石榴子石（铁铝榴石 almandine）晶体；宝石级透辉石 (diopside) 晶体（呈 prismatic habit，淡绿色）；抛光的宝石级橄榄石 (olivine) 晶体；橄榄岩 (peridotite) 中的橄榄绿色橄榄石（镁橄榄石 forsterite）；绿泥石片岩 (chlorite schist) 中呈十二面体 (dodecahedral form) 的自形铁铝榴石**变斑晶 (porphyroblast)**；退变质榴辉岩 (altered eclogite) 中带角闪石 (hornblende) 退变边的铁铝榴石变斑晶。

**什么是岩石 (rock)？**
- **Naturally-occurring solid mass of minerals**（天然产出的矿物固体集合体）；
- 可由**单一矿物**组成，也（更常见地）由**多于一种矿物**组成。
- 例：**石英岩 (quartzite)** = 石英晶体的集合体（单矿物岩）；**花岗岩 (granite)** = 石英 + 其他矿物（多矿物岩）。

**Video 1 的两道思考题（务必掌握，是典型考点）：**

**Q1：冰 (H₂O) 是矿物吗？**
> **是。** 逐条对照定义：① 天然产出 (occurs in nature) ✓；② 固体 ✓；③ 无机——它不含碳 ✓；④ 化学成分固定 (H₂O) ✓；⑤ 有晶体结构——**证据是雪花具有漂亮的对称形态 (beautifully symmetrical snowflakes)，若无晶体结构就不会有这种对称性** ✓。

**Q2：火山玻璃 (volcanic glass) 是矿物、岩石，还是都不是？**
> **都不是（严格意义上）。**
> - **不是矿物**：因为它**没有晶体结构 (does not have a crystalline structure)**。玻璃本质上是**过冷液体 (super-cooled liquid)**，原子排列是**不规则的 (irregular atomic structure)**。
> - **技术上也不是岩石**：因为岩石定义为"矿物的集合体"，而玻璃不是矿物。
> - **但**：岩石**允许含有玻璃**，只要玻璃是天然产出的。示例：夏威夷的**"贝利泪滴" (Pele's tears)**。

> **理解要点**：这道题的价值在于把"晶体 (crystalline) vs 非晶质 (amorphous)"这条线钉死。后面硬度一节还会用到同一条原理——**石英比玻璃硬，正是因为规则晶体结构中原子堆积更紧密**。

### 2.2 晶习 (Crystal habit)（Video 2 + 讲义）

#### 2.2.1 定义与成因

- **定义**：**晶面的组合与相对发育程度 (the combination and relative development of crystal faces)** 称为该晶体的**晶习 (habit)**。
- **成因（两个来源，务必都答出）**：
  1. **部分取决于晶体结构 (crystal structure)**——即矿物内部原子排列的内在属性；
  2. **也取决于晶体生长的方式 (the way the crystal has grown)**——某些晶面得以优先发育 (allowing some faces to develop preferentially)。
- **推论**：因为晶习受**外部生长条件**影响，所以**同一矿物可以有不同晶习**（方解石、重晶石就是典型），这使得晶习作为鉴定依据**不如解理可靠**（见 2.3.1）。

#### 2.2.2 晶习术语表（六个基本词 + massive）

| 英文 | 中文 | 形态描述 |
| --- | --- | --- |
| **equant** | 等轴状 / 粒状 | 三个方向尺寸大致相等（如立方体、球状） |
| **tabular** | 板状 | 一个方向明显变薄，但仍有明显厚度（像板砖 / 书本） |
| **platy** | 片状 | 极薄的片（像纸张、云母片） |
| **prismatic** | 柱状 | 中等程度伸长 (moderately elongate) |
| **acicular** | 针状 | 针形 (needle-shaped)，强烈伸长 |
| **fibrous** | 纤维状 | 纤维状，伸长程度最大 |
| **massive** | 块状 | **紧密的互锁晶体集合体，各晶粒之间无明显界线** (compact mass of interlocking crystals with no clear division between individual grains) |

#### 2.2.3 晶习分类图的两条轴（关键：这张图怎么读）

讲义与视频反复出现的那张图有**两个正交的变化方向**：

```
                       ← Decreasing thickness (厚度递减) →

  Greater          equant  ────────►  tabular  ────────►  platy
  elongation         │                   │
  (伸长增大)          ▼                   ▼
      │           prismatic  ──────►  tabular/platy
      │              │
      ▼              ▼
   acicular  ─────  (更强伸长)
      │
      ▼
   fibrous
```

- **纵向（Greater elongation）**：equant → prismatic → acicular → fibrous，**一个方向越来越长**；
- **横向（Decreasing thickness）**：equant → tabular → platy，**一个方向越来越薄**；
- 中间存在过渡格（如 tabular/platy、prismatic 与 tabular 之间），因此**边界模糊时选最接近的词即可**。

#### 2.2.4 Video 2 的六个实例（每个都要能说出"为什么"）

**① 萤石 Fluorite, CaF₂ → equant**
- 萤石晶体的**理想形态是立方体 (cube)** → 三轴等长 → **equant**。
- **结构原因（重要）**：萤石的晶习与其晶体结构相关——**立方体晶面上原子密度高 (the cube faces contain a high density of atoms)**。
- **普适规律**：**晶体上最显著发育的晶面，通常是原子密度最高的那些面** (It is typically the case that the most prominent faces of a crystal are those with the highest density of atoms)。

**② 云母 Mica → platy（偶尔 tabular）**
- 产出：**花岗岩 (granites) 与变质泥岩 (metamorphosed mudstones) 中的常见矿物**。
- **结构原因（本周最经典的"结构→性质"推理，必须能完整复述）**：
  - 云母结构由**层 (layers)** 组成，层内的键**短而强 (short and strong)**——具体是**两层 Si–O 四面体夹一层 Mg 或 Al** (2 sheets of Si-O tetrahedra sandwiching a sheet of Mg or Al)；
  - 这些层之间由**大的钾离子 (large potassium ions) 层**隔开；
  - **钾键合弱 (weakly bonded)** → 云母在**垂直层的方向生长慢 (slow growth perpendicular to the layers)** → 晶体极薄；
  - **平行层的方向原子更密、成键更快 (bonds form faster)** → **快速生长 (rapid growth in all directions within the layer)** → 形成大片状晶体。
  - 合起来 = **platy habit**。
- **同一结构还解释了云母的一组完全解理**（见 2.3.4 ②）——**一因两果，考试爱考**。

**③ 方解石 Calcite, CaCO₃ → prismatic 与 tabular（晶习可变）**
- 产出：**沉积岩——石灰岩 (limestone)**；**变质石灰岩——大理岩 (marble)**。
- **在不同条件下以不同晶习结晶 (crystallises with different habits under different conditions)**；视频里的示例可以用花哨的术语，也可以简单地说 **prismatic 和 tabular**。

**④ 重晶石 Barite, BaSO₄ → tabular（常见晶习）**
- 产出：**石灰岩中的脉 (veins in limestones)** 中常见。
- 晶习同样可变 (variable habit)，但**常见的一种是板状 tabular**。

**⑤ 石榴子石 Garnet, (Ca,Mg,Fe)₃Al₂Si₃O₁₂ → equant（永远是 equant）**
- 产出：**高级变质岩 (high-grade metamorphic rocks)** 中常见。
- **关键区分点**：石榴子石因不同晶面的相对发育程度不同，会长出**不同的外形 (different shapes)**（立方体状、十二面体、二十四面体…），**但晶习始终是 equant**。
- **教学意义**："shape（具体形状）"与"habit（晶习类别）"不是一回事——**形状可以变，晶习不变**。

**⑥ 石英 Quartz, SiO₂ → prismatic**
- 当石英**在开放空间中自由生长 (allowed to grow freely in an open space)** 时会形成特征晶习，例如在**有热液循环的岩石裂隙中 (in a fracture in a rock through which hot fluids are circulating)**。
- 该晶习为 **prismatic**（六方柱 + 锥面的经典石英晶体）。

### 2.3 解理与断口 (Cleavage and fracture)（Video 3 + 讲义）

#### 2.3.1 定义与原理（为什么解理能反映内部结构）

- **定义**：许多矿物倾向于**沿特定平面平滑地破裂 (break smoothly along particular planes)**。
- **原理（必须能说清）**：这与**内部原子结构 (internal atomic structure)** 有关——它是**跨越这些平面的键强较弱 (weaker bond strength across these planes)** 的外在表现。
- **几何约束**：**解理面总是平行于可能的（或实际存在的）晶面** (Cleavage planes are always parallel to possible (or actual) crystal faces)。与晶面一样，解理面**与晶体的内部对称性相关 (related to the crystal's internal symmetry)**。

#### 2.3.2 解理为什么比晶形更好用（核心论断）

> **Cleavage is more useful as a diagnostic property than crystal shape, since it is not affected by the external conditions which determine crystal shape.**

- 晶形（晶习）受**外部生长条件**控制 → 同种矿物可以长得不一样；
- 解理由**内部键强**控制 → **对同一矿物永远一致**；
- **唯一的限制 (the only limitation)** 是**颗粒的大小 (the size of the grains)**——颗粒太小就看不出解理。
- **延伸价值**：解理在**偏光显微镜下观察薄片 (thin sections)** 时是**极其有价值的鉴定性质** (extremely valuable diagnostic property)。

#### 2.3.3 解理的描述维度

解理的完整描述需要**三个维度**：

1. **方向数 (number of directions)**：可以是 **1、2、3、4 或 6** 个方向（也可能完全没有解理）；
2. **质量 (quality)**：定性分为 **perfect（完全）> good（好）> moderate（中等）> poor（差）**；
   - **perfect** → 矿物**极易沿解理面劈开 (will easily split along the cleavage planes)**；
   - **poor** → **不易劈开 (won't split easily)**；
   - 讲义明确安慰："这些术语只是定性的，**如果拿不准该说 good 还是 perfect，不用担心** (don't worry if you are not sure)"。
3. **解理面之间的夹角关系 (angular relationship between cleavage planes)**：如 2 组解理是 90° 还是非 90°。

**没有解理时 → 断口 (fracture)：**
- 无解理的矿物破裂时形成**断口**，可以是
  - **不规则断口 (irregular)**，或
  - **贝壳状断口 (conchoidal)**——产生**特征性的弯曲表面 (characteristically curved surfaces)**，**就像碎玻璃一样 (as with broken glass)**；Video 3 补充定义："conchoidally = 具有弯曲表面和同心纹，像贝壳上的生长纹 (curved surfaces and concentric lines like growth rings on a shell)"。

#### 2.3.4 解理方向数与角度的完整对照表（本周最重要的表之一）

**注意：表中术语指的是"等效解理面 (equivalent cleavage planes)"**——即由对称性相互关联的一组解理面。

| 解理方向数 | 名称 (Description) | 破裂后的形态 | 图上编号 | 本周实例 |
| --- | --- | --- | --- | --- |
| **0** | No cleavage（无解理） | 破裂成**无平坦表面的不规则块体** (irregular masses with no flat surfaces) | — | **quartz 石英、garnet 石榴子石、pyrite 黄铁矿** |
| **1** | **Basal cleavage** 底面解理 | 沿**平坦的片 (flat sheets)** 劈开 | A | **biotite 黑云母、muscovite 白云母** |
| **2 at 90°** | **Prismatic cleavage** 柱状解理 | 伸长体，**横截面为矩形 (rectangular cross sections)** | B | **feldspar 长石**（另有一组与其成 90° 的**差解理 (poor cleavage)**，仔细看或许能见到） |
| **2 not at 90°** | **Prismatic cleavage** 柱状解理 | 伸长体，**横截面为平行四边形 (parallelogram cross sections)** | C | （角闪石/辉石类的经典特征；本周标本无） |
| **3 at 90°** | **Cubic cleavage** 立方解理 | 破裂成**立方体 (cubes)** | D | **galena 方铅矿 (M8)** |

| **4** | **Octahedral cleavage** 八面体解理 | 破裂成**八面体 (octahedra)** | F | **fluorite 萤石** |
| **6** | **Dodecahedral cleavage** 十二面体解理 | 破裂成**十二面体 (dodecahedra)** | G | （本周标本无） |

#### 2.3.5 Video 3 的五个实例（含"为什么"）

**① 萤石 Fluorite, CaF₂ — 4 组完全解理（八面体解理）**
- 左图是**立方体萤石晶体**，右图是**萤石的解理碎块**；
- 可以看到它有**四组等效的完全解理，平行于八面体的面** (four equivalent perfect cleavages parallel to the faces of an octahedron)；
- **原因**：萤石沿**键合最弱的平面 (planes where the bonding is weakest)** 破裂，几何上**相当于把立方体的角切掉 (equivalent to cutting off the corners on the model)**——立方体切掉 8 个角就得到八面体。结构模型中**绿色 = Ca，红色 = F**。
- **对应图上的 F。**
- **认知冲击点**：**晶体外形是立方体，解理却是八面体**——晶形与解理可以完全不同，这正是"解理反映内部键强、晶形反映生长条件"的最好证明。

**② 云母 Mica — 1 组完全解理（底面解理）**
- **Mica has one perfect cleavage**，对应图上的 **A**；
- **原因**：从结构模型可见，**K⁺ 离子与相邻阳离子之间键合弱 (weakly bonded to neighbouring cations)**，因此**解理就发生在含 K⁺ 的层内 (the cleavage occurs in the layers containing the K⁺ ions)**。
- **注意**：这与 2.2.4 ② 中解释 platy habit 的是**同一个结构特征**（弱 K 层）——**弱键层既让它长成片状，又让它沿该层劈开**。

**③ 方解石 Calcite, CaCO₃ — 3 组完全解理（菱面体解理）**
- **Calcite has three equivalent perfect cleavages parallel to the faces of a rhombohedron**，对应图上的 **E**；
- **重要提醒**：**解理菱面体 (cleavage rhombohedron) 与有时发育出来的菱面体晶面 (rhombohedral faces) 是不同的** ——两者形状类似但不是一回事，不要混为一谈。

**④ 重晶石 Barite, BaSO₄ — 两套"非等效"解理（进阶概念）**
- 重晶石有**两套非等效的解理 (two non-equivalent sets of cleavages)**：
  - 第一套：**1 组完全解理 (one perfect cleavage)**；
  - 第二套：**2 组"很好"的解理，彼此成 78°，且这一套与第一套垂直 (two very good cleavages at 78° to each other and perpendicular to the first set)**。
- 因此**它同时属于表中的两个类别**——因为表中每个图示只表示**一组等效解理**（即由对称性相互关联的解理）。所以它 = 类别"1"（对应 A）+ 类别"2 not at 90°"（对应 C）。
- **实操要点（非常有用）**：绘图上的解理线画在**晶体内部**，表示**解理是晶体内部的裂纹 (cracks inside the crystal)**；照片里也能看到这些内部裂纹。
  > **"看到晶体内部有成组的平行裂纹，是判断你正在看解理的极好线索" (Seeing sets of parallel cracks inside the crystal is very useful for telling you that you are looking at cleavage.)**

**⑤ 石英 Quartz, SiO₂ — 无解理**
- **Quartz has no cleavage**；
- **原因**：石英是**"架状"结构 ("framework" structure)**，**不存在键合弱的平面 (no planes across which the bonding is weak)**；且**键合以共价键为主 (mainly covalent)，本身就强 (inherently strong)**；
- 因此石英**呈贝壳状断口 (fractures conchoidally)，像玻璃一样**；
- **反向判据（很实用）**：**无解理意味着你在石英晶体里永远看不到细密的平行裂纹**，而重晶石、方解石这类矿物里则应当看得到。

### 2.4 颜色与条痕 (Colour and streak)（Video 4 + 讲义）

#### 2.4.1 颜色的物理原理

- **颜色的产生**：矿物给人的颜色印象来自**对白光中某些波长的优先吸收 (preferential absorption of certain wavelengths from white light)**，因此我们看到的是**互补色 (complementary colour)**。
- **警告（讲义原话，务必记住）**：颜色虽然是**给人第一印象最强烈的性质 (makes the most immediate impact)**，但其**成因复杂 (its causes are complex)**，**必须相当谨慎地用作鉴定性质 (must be used as a diagnostic property with some care)**。

#### 2.4.2 颜色的四类成因

| 成因类型 | 机制 | 实例 |
| --- | --- | --- |
| **① 本征致色 (intrinsic colour)** | 由**化学成分本身**决定，尤其是**必需元素 (essential) 含 Ti、V、Cr、Mn、Fe、Ni、Co、Cu** 的矿物 | 橄榄石因含 **Fe** 而呈绿色；黑云母因含 **Fe²⁺** 而黑 |
| **② 杂质致色 (impurities)** | 矿物本身基本无色，但天然晶体因**微量杂质**而显色；**同一矿物的体色因杂质的种类与含量而变化极大** | **fluorite、quartz** 是典型；紫水晶、黄水晶、蔷薇石英 |
| **③ 晶格缺陷 (defects in the crystal lattice)** | 缺陷（含"色心"）造成选择性吸收 | 烟水晶 (smoky quartz)、紫水晶 (amethyst) |
| **④ 表面/光学效应** | 表面氧化形成**虹彩薄膜或锖色 (iridescent film or tarnish)**；或内部反射/衍射造成**变彩 (play of colours / schiller)** | **chalcopyrite 黄铜矿**的锖色；**labradorite 拉长石**的 schiller；**opal 蛋白石**的 opalescence |

#### 2.4.3 条痕 (Streak)——把"体色"变成"可靠的颜色"

- **定义**：矿物**粉末的颜色**。
- **原理**：**本征致色的矿物在被研成粉末时会呈现特征颜色（即条痕）**；而**大多数其他矿物在粉末状态下基本无色（即条痕为白色）**，其晶体的颜色只是杂质造成的假象。所以**条痕比体色可靠得多**。
- **操作方法**：把矿物**在未上釉的瓷板上划一道 (drawing the mineral across an unglazed porcelain plate)**。
- **⚠ 适用限制（极易被忽略的考点）**：**只有当矿物比瓷板软时才有效，即 H < 6½** (only works if the mineral is softer than the plate, H < 6½)。硬度 ≥ 6½ 的矿物（石英 7、黄玉 8、刚玉 9 等）划不出条痕，反而会把瓷板划伤。

#### 2.4.4 特殊光学现象

- **变彩 / 晕彩 (play of colours) 或称 schiller（席勒效应）**：由**极微小的片状包体或其他不连续面（如双晶）造成的内部反射** (internal reflection from minute platy inclusions or other discontinuities such as twinning)。
  - 在**某些长石变种**中可见；
  - **展示标本**：那块**抛光的大块拉长石 (labradorite feldspar) 晶体**——其 schiller 是由晶体内部**亚显微的周期性纹层结构 (submicroscopic periodic lamellar structure)** 使光**发生衍射 (diffract)** 造成的；这些**纹层 (lamellae) 是矿物从高温冷却时发生的出溶作用 (exsolution) 产生的**。
- **蛋白石光彩 (opalescence)**：出现在**蛋白石 (opal)** 中时叫这个名字；蛋白石由**极微小的非晶质 SiO₂ 小球 (minute spheres of amorphous SiO₂)** 组成。
- **锖色 / 晕色 (tarnish)**：**表面氧化 (surface oxidation)** 形成的虹彩薄膜，如**黄铜矿 (chalcopyrite)**。

#### 2.4.5 Video 4 的颜色实例

- **橄榄石 (olivine) 呈绿色是因为含 Fe**（本征致色）；
- **石英本征无色 (intrinsically colourless)**，但可因杂质呈色，如**紫水晶 amethyst (Fe²⁺)** 与**黄水晶 citrine (Fe³⁺)**；
- 视频还给出两个颜色专题视频链接：**Garnet**、**Amethyst (quartz)**。

> **⚠ 材料内部的一处不一致（值得留意）**：Video 4 写 "amethyst (Fe²⁺) and citrine (Fe³⁺)"；而答案讲义写 "citrine (yellow) 由 **Fe** 致色"、"amethyst 中是 **Si⁴⁺ + e⁻ → Fe³⁺**（色心机制）"、"smoky quartz 中是 **Si⁴⁺ + e⁻ → Al³⁺**"。**答案讲义的表述更细致（强调色心 colour centres）**，考试时按讲义版本答更稳：**紫水晶与烟水晶的颜色涉及"杂质离子 + 缺失电子（色心）"的组合**。

#### 2.4.6 色心 (colour centres)

- 讲义原文：有时杂质会伴随一个**缺失的电子 (a missing electron)**，以维持**电荷平衡 (charge balance)**，例如：
  - **紫水晶 (amethyst)**：Si⁴⁺ + e⁻ → **Fe³⁺**
  - **烟水晶 (smoky quartz)**：Si⁴⁺ + e⁻ → **Al³⁺**
- **这些缺失的电子就叫"色心" (colour centres)。**
- 展示的石英晶体颜色变化即源于极少量杂质：**黄水晶 citrine (Fe，黄色)**、**蔷薇石英 rose quartz (Ti, Fe, Mn)**。

### 2.5 硬度 (Hardness)（Video 4 + 讲义）

#### 2.5.1 定义与原理

- **定义**：**抗刻划的能力 (resistance to scratching)**。
- **是有用的鉴定性质 (useful diagnostic property)**。
- **物理基础**：**硬度取决于键密度 (bond density)**；
- **⚠ 各向异性**：**硬度在矿物内部可以随方向变化 (can vary with direction in a mineral)**，因为**不同方向上键的数目与强度不同 (different numbers and strengths of bonds in different directions)**。（蓝晶石 kyanite 是教科书级例子；本周只需知道这条原理。）

#### 2.5.2 摩氏硬度计 (Mohs' Scale of Hardness, 1812)

- **本质**：这是一个**定性 (qualitative) 的相对标度**——**每一个矿物都能刻划硬度比它低的矿物** (each mineral is capable of scratching the minerals with lower hardness)。
- **它不是线性的**：只表示"谁能划谁"的顺序，不表示硬度差的倍数。

| --- | --- |

#### 2.5.4 ⚠ 硬度测定最经典的陷阱

> **如果你用较软的矿物去划较硬的矿物，软矿物会在硬矿物表面留下一道粉末痕迹 (powder trail)，看上去就像它把硬矿物划伤了。**

**破解办法**：**用手指擦掉 / 吹掉痕迹**，若痕迹消失 → 那只是粉末，没有真正的刻痕；若擦不掉、且能用指甲感觉到凹槽 → 才是真正的划痕。

#### 2.5.5 为什么石英比玻璃硬？（讲义思考题的标准答案）

> **问**：为什么你那块看起来像玻璃的石英晶体，硬度比真正的玻璃高不少（石英 H=7，窗玻璃 H=5½）？
>
> **答（原文直译）**：**石英更硬，是因为其规则晶体结构 (regular crystal structure) 中的原子比玻璃的不规则结构 (irregular structure) 中堆积得更紧密 (more closely packed)。**

- 与 Video 1 的"火山玻璃不是矿物"一题**呼应**：晶体 vs 非晶质的区别不只是定义问题，**它有可测量的物理后果**——原子密堆 → 键密度高 → 硬度高。

### 3.2 鉴定流程图（拿到一块未知手标本按什么顺序做）

> **原则：先做无损、最可靠的观察，再做有损的破坏性测试；先用"不受生长条件影响"的性质（解理、硬度），最后才用"最不可靠"的性质（体色）。**

```
【第 0 步】看清楚它是不是"单一矿物"
   ├─ 是矿物集合体/岩石？→ 先分出各组分再逐个鉴定
   └─ 是单晶或单一矿物碎块 → 继续

【第 1 步】光泽 (lustre)——只需一眼，把矿物砍成两大类
   ├─ 金属光泽 (metallic) → 走"金属矿物分支"：优先测【条痕】+【比重手感】
   │      · 条痕绿黑 + 淡黄铜色 + 硬(刀划不动) → pyrite FeS₂
   │      · 条痕绿黑 + 黄铜色 + 软(刀可划) + 虹彩锖色 → chalcopyrite CuFeS₂
   │      · 条痕铅灰 + 极沉 + 立方解理 → galena PbS
   └─ 非金属光泽 (non-metallic：玻璃/珍珠/树脂/土状) → 走"非金属分支"

【第 2 步】解理 vs 断口（本周最重要的一步）
   观察方法：转动标本让光反射
   ├─ 有平坦、反光如镜的面 → 数【解理方向数】+ 量【夹角】
   │      · 1 个方向、能撕成薄片          → 云母类 mica（进第 3 步分黑白）
   │      · 2 个方向 @ 90°、矩形横截面     → feldspar（长石）
   │      · 2 个方向 ≠ 90°（~56°/124°）   → hornblende（角闪石）
   │      · 2 个方向 ≈ 87°/93°            → pyroxene（辉石，如 diopside）
   │      · 3 个方向 @ 90°、破成立方体     → galena / halite
   │      · 3 个方向 ≠ 90°、破成菱面体     → calcite / dolomite（第 4 步用 HCl 分）
   │      · 4 个方向、破成八面体           → fluorite
   └─ 无平坦面、破成不规则碎块或贝壳状断口 → quartz / garnet / pyrite / olivine / opal
          （注意：晶体内部若完全看不到成组平行裂纹，强烈支持"无解理"）

【第 3 步】硬度 (hardness)——用工具序列逐级逼近
   指甲(2–2½) → 铜币(3½–4) → 钢刀(5+) / 窗玻璃(5½) → 钢手术刀(6½)
   做法：先用最软的试，划得动就停；划不动换更硬的
   ⚠ 每划一次都要【擦掉粉末】再确认是否有真正的凹槽
   典型分界：
      · 指甲能划          → H ≤ 2½（talc, gypsum, mica 边缘, galena 2.5）
      · 指甲不行、铜币能划 → H ≈ 3（calcite）
      · 铜币不行、刀能划   → H ≈ 4–5（fluorite 4, apatite 5）
      · 刀不行、手术刀能划 → H ≈ 6（orthoclase feldspar）
      · 手术刀也划不动、且能划玻璃 → H ≥ 7（quartz, garnet, topaz…）

【第 4 步】条痕 (streak)——仅当 H < 6½ 时可做
   在未上釉瓷板上划：金属矿物必做（最可靠）；非金属矿物多为白色，信息量低

【第 5 步】特征化学/物理测试 (diagnostic tests)
   · 稀 HCl：剧烈起泡 → calcite（碳酸盐）；粉末才起泡 → dolomite
   · 磁铁：强磁性 → magnetite
   · 手感比重：明显偏沉 → galena(7.6) / barite(4.5) / 金属硫化物
   · 透明薄片压在字上：出现双影 → calcite 的强双折射 (double refraction)
   · 咸味：halite（本周未涉及，但属经典手段）

【第 6 步】颜色与晶习——最后才用，且只作辅助
   · 颜色：只在"本征致色"矿物上可信（olivine 绿、biotite 黑、malachite 绿…）
   · 晶习：只在晶体自由生长、保留晶面时才有意义
   · 特殊光学效应：schiller（labradorite）/ opalescence（opal）/ tarnish（chalcopyrite）

【第 7 步】交叉检验
   把所有观测值与候选矿物的全套性质对照，必须【条条都对得上】才定名；
   有一条明显矛盾 → 回到第 2 步重新数解理
```

### 3.3 "结构 → 性质"的因果链总图（本周的思想主线）

```
                        矿物的内部原子结构 + 化学成分
                                    │
        ┌───────────────┬───────────┼───────────────┬────────────────┐
        ▼               ▼           ▼               ▼                ▼
   原子面密度         键的强弱      键密度        致色元素/杂质      对称性
   (atom density)   (bond strength) (bond density)  (chromophores)   (symmetry)
        │               │           │               │                │
        ▼               ▼           ▼               ▼                ▼
    最发育的晶面      弱键面 →     抗刻划能力      选择性吸收波长    解理面平行于
    → 【晶习 habit】  【解理       → 【硬度        → 【颜色 colour   可能的晶面
                      cleavage】     hardness】      / 条痕 streak】
        │                                                            │
        └──────────── 但晶习还受【生长条件】影响 → 可变、不可靠 ◄──────┘
                      解理只受【内部键强】控制 → 恒定、可靠
```

**这张图能回答本周几乎所有"为什么"型问题：**
- 为什么萤石常见立方体？→ 立方面原子密度最高。
- 为什么云母是片状？→ 层内强键快速生长、垂直层方向弱 K 键慢速生长。
- 为什么云母有一组完全解理？→ 同一层弱 K 键。
- 为什么萤石晶形是立方体但解理是八面体？→ 晶形由生长条件+面密度决定，解理由弱键面决定，两者不必一致。
- 为什么石英无解理？→ 架状结构 + 强共价键，不存在弱键面。
- 为什么石英比玻璃硬？→ 晶体结构原子堆积更紧密 → 键密度更高。

### 4.3 老师在演示时反复强调的手法与经验

**① 关于标本本身的重要提醒（讲义 + 课堂）**
- 发给你的 5 块标本**都是单晶**（偶尔是 2–3 个互锁晶体），**但都不是完整晶体**——它们是**用锤子把大晶体砸碎得到的 (obtained by smashing up larger crystals with a hammer)**；
- **因此你几乎看不到任何真正的晶面 (unlikely to see any crystal faces)**；
- **但是**：如果矿物有解理，**被锤子砸时就会沿解理面裂开**（因为那是晶体结构中的**薄弱面 planes of weakness**）；
- **所以这些标本的部分或全部表面其实就是解理面**；
- **怎么认出解理面？**——**它们是平坦的、能很好地反射光的表面 (flat surfaces that reflect the light well)**。**转动标本对着光看反光**，这是本周最核心的手上动作。
- **本次练习的做法**：**只看那 4 块有解理的矿物，并把它们的解理面当作晶面来定晶习**；剩下那块**无解理的会像玻璃一样碎成不规则碎片 (breaks into irregular fragments like pieces of glass)**。
- 讲义提前剧透了标本构成：**你的 5 块里有 4 块有解理（其中 1 块的解理不如其他清楚），1 块无解理。**

**② 判断"是不是解理"的两条实操判据**
- **判据 A（表面）**：平坦且**镜面般反光**的面 = 解理面。云母的 sketchfab 模型转动时"**光会像镜子一样反射 (light reflecting off it like a mirror)**"，就是**完全解理**的表现。
- **判据 B（内部，更可靠）**：**看晶体内部有没有成组的平行裂纹 (sets of parallel cracks inside the crystal)**——Video 3 在讲重晶石时强调："**看到晶体内部的平行裂纹组，对于告诉你'你正在看的是解理'非常有用**"。反过来，**石英内部永远看不到这种细密平行裂纹**，这是"无解理"的正面证据。
- 讲义也提到：**方解石的 sketchfab 模型上"如果仔细看解理面，会看到晶体内部的解理裂纹"，那正是你用锤子敲它时会裂开的位置——敲开后它会变成"一个更小的自己" (a smaller version of itself)**。这句话极形象地说明了**菱面体解理的自相似性**。

**③ 数解理方向的正确方法（老师用方解石模型示范，极易数错）**
> 方解石解理碎块**有 6 个面，但只有 3 个解理方向**。
> - **顶面和底面取向相同 → 算 1 个方向**；
> - **前面和后面取向相同 → 算 1 个方向**；
> - **左右两个侧面取向相同 → 算 1 个方向**；
> - 合计 **3 个解理方向**。
>
> **判断角度**：因为每个面的形状是**平行四边形 (parallelogram) 而不是矩形 (rectangle)**，所以**这些方向之间不是 90°** → 归入"3 not at 90°，菱面体解理"。

- **这是本周最容易失分的操作细节**：**平行的两个面只算一个方向**；面的**形状（矩形 vs 平行四边形）直接告诉你夹角是不是 90°**。

**④ 关于展示标本上"看不到解理"的困难与对策**
- 讲义提醒："**对某些展示矿物来说这不容易，因为你能看到的大多数表面是晶面 (crystal faces)，所以你需要在晶体内部寻找平面状的裂纹 (planar cracks inside the crystal)**"。
- 换句话说：**发育良好的完整晶体反而不好数解理**（外面是晶面），**碎块反而好数**（外面就是解理面）。

**⑤ 关于云母颜色的动手小实验**
- 老师直接让你**动手撕 (try it…)**：
  - 撕下黑云母的薄层 → **要么仍是黑的，要么变成棕色且透明**，取决于你能撕多薄；
  - 撕下白云母的薄层 → **无色（因而透明）**。
- **结论**：**黑云母黑，是因为含 Fe²⁺；白云母不含铁。** 这是一个**用最简单的动作直接读出化学成分**的漂亮例子。
- **补充**：**黑云母中 Fe 的含量是可变的——Fe 越多，颜色越深**；**白云母也可能含杂质而略带一点颜色**。

**⑥ 关于长石颜色的"读裂隙"技巧**
- 老师提示：**你会发现长石的颜色不均匀，靠近贯穿晶体的小裂隙处更粉 (looks more pink adjacent to little fractures running through the crystal)**；
- **解读**：这说明**Fe²⁺ 杂质氧化为 Fe³⁺ 的程度不均匀**——**流体沿裂隙渗入 → 局部氧化更充分 → 更红/更粉**。
- **可迁移的思维**：**颜色的空间分布本身就是信息**（记录了流体—岩石相互作用的路径），不要只记"长石是粉色的"。

**⑦ Sketchfab 三维模型清单（复习时可直接打开转动着看）**
讲义为 5 块标本各配了 3D 模型链接（sketchfab.com），并逐个说明该看什么：

## 五、Practical 要点

### 5.1 本次 practical 的结构与目标

**四个板块，依次推进：Crystal habit → Cleavage → Colour → Hardness → 未知矿物 A–M 鉴定。**

前四个板块的作用是**在已知答案的标本上练手**（你自己的 5 块 + 展示标本），最后一个板块是**独立实战**（未知的 A–M）。这是典型的"**先带练、后放手**"实践课设计。

### 5.2 板块一：Crystal habit —— 逐题答案与判断依据

**任务**：用晶习图给你的 **4 块有解理的矿物**、以及展示的 **fluorite、calcite、garnet、quartz、pyrite (M5)**（**galena, M8 会更难，因为多数标本含几个互锁晶体**）指定晶习术语。

| 矿物 | **答案（晶习）** | 判断依据 |
| --- | --- | --- |
| **biotite**（你的 5 块之一） | **platy** | 极薄的片；层内强键快速生长、垂直层向弱 K 键慢速生长 |
| **muscovite**（你的 5 块之一） | **platy** | 同上，云母结构决定 |
| **calcite**（你的 5 块之一） | **tabular 或 prismatic**（**会因你标本的具体形状而不同**） | 你的标本是解理碎块，形状随机；方解石本身晶习就可变 |
| **feldspar**（你的 5 块之一） | **可能太不规则，说不上来 (probably too irregular to say)** | 长石解理为 good 而非 perfect，砸碎后形状不规整 → **答"说不出"是可以接受的答案** |
| **fluorite**（展示） | **equant** | 理想晶形为立方体；立方面原子密度最高 |
| **calcite**（展示） | **可变——多数最接近 prismatic，也可能是 tabular 或 equant** | 方解石在不同条件下以不同晶习结晶 |
| **garnet**（展示） | **equant** | 外形可以千变万化，但晶习恒为 equant |
| **quartz**（展示） | **prismatic** | 自由生长时形成的特征柱状晶习 |
| **pyrite (M5)**（展示） | **equant** | 立方晶系，立方体/五角十二面体外形 |
| **galena (M8)**（展示） | **equant** | 立方解理、立方晶形；**难点在于多为互锁晶体，需先分辨出单个晶体再判断** |

**要点提炼**：
1. **同一矿物在"你的碎块"上与"展示晶体"上可以给出不同晶习答案**（如 calcite），因为碎块反映的是解理形态而非生长形态；
2. **"太不规则说不出来"是合法答案**——不要硬凑一个术语；
3. **equant 是最常见的答案**（fluorite、garnet、pyrite、galena 四个都是），因为它们都是**等轴晶系 (cubic)** 矿物。

### 5.3 板块二：Cleavage —— 逐题答案与判断依据

#### 题 1：把你的 4 块有解理的矿物按解理好坏排序

> **答案（从最好到最差）：**
> **biotite、muscovite（并列最好）> calcite > feldspar**

**判断依据**：
- **biotite / muscovite**：1 组 **perfect** 底面解理，**能撕成极薄的片**，反光如镜 → 最好；
- **calcite**：3 组 **perfect** 解理（讲义说方解石"generally defined as having 'perfect' cleavage"），但因为是 3 个方向且不像云母那样能撕成片，**手感上不如云母那么"极致"** → 次之；
- **feldspar**：2 组 **good** 解理 + 1 组 **poor** 解理 → 最差（这就是讲义开头说的"**其中一块的解理不如其他清楚 (one isn't as clear as the others)**"）。

#### 题 2：你的 5 块中有 2 块与展示矿物相同，是哪两块？

> **答案：quartz 和 calcite。**

**判断依据**：展示矿物列表是 fluorite、calcite、garnet、quartz、pyrite、galena；你的 5 块是 biotite、muscovite、calcite、feldspar、quartz → **交集就是 calcite 与 quartz**。
**这题的教学意图**：让你**把"漂亮的完整晶体"与"丑陋的碎块"对应起来**——同一矿物的两种面貌，**碎块上看解理，晶体上看晶习**。

#### 题 3：用表格与图判定各矿物的解理类型

| 矿物 | **解理方向数与角度** | **名称** | 破裂形态 | 质量 |
| --- | --- | --- | --- | --- |
| **quartz、garnet、pyrite** | **0** | 无解理 | 不规则块体，无平坦面 | — |
| **biotite、muscovite** | **1** | **Basal 底面解理** | 沿平坦片劈开 | **perfect** |
| **feldspar** | **2，成 90°**（**另有一组与之成 90° 的 poor 解理，仔细看也许能见到**） | **Prismatic 柱状解理** | 伸长体，**矩形**横截面 | **good** |
| **galena** | **3，成 90°** | **Cubic 立方解理** | 破成**立方体** | perfect |
| **calcite** | **3，非 90°** | **Rhombohedral 菱面体解理** | 破成**菱面体** | **perfect** |
| **fluorite** | **4** | **Octahedral 八面体解理** | 破成**八面体** | perfect |

**⚠ 关于长石的那条"第三组 poor 解理"**：讲义写的是"there is also another, poor, cleavage at 90° to these"——即除了那 2 组互成 90° 的 good 解理外，**还有第三组与它们成 90° 的差解理**，**你也许能看到**。这解释了为什么长石的解理"最不好认"。

#### 题 4（判读性）：各矿物解理的结构原因

- **fluorite 八面体解理**：沿键合最弱的面裂 = **把立方体的角切掉**；
- **mica 一组完全解理**：**K⁺ 与相邻阳离子键合弱**，解理就发生在含 K⁺ 的层里；
- **calcite 菱面体解理**：3 组等效完全解理平行于菱面体面；**注意解理菱面体 ≠ 有时发育的菱面体晶面**；
- **barite 双套解理**：1 组 perfect + 2 组 very good（78°，与第一组垂直）——**"非等效"意味着它们不由对称性相联系，要分开数**；
- **quartz 无解理**：**架状结构 + 强共价键**，没有弱键面 → **贝壳状断口**。

### 5.4 板块三：Colour —— 逐题答案与判断依据（"完成矿物鉴定"）

**讲义的推理链（这是本周最漂亮的一段"顺藤摸瓜"，务必能复述）：**

**第 1 步：分出两块云母。**
> "你会发现你的矿物中有 **2 块晶习和解理相同（platy + 1 组完全解理）**，但**颜色差别很大**：一块是**黑色**，另一块是**银色**。"

**第 2 步：用"撕薄片"实验定成分。**
> 撕黑的那块 → **仍是黑色，或呈棕色且透明**（取决于撕多薄）；
> 撕银的那块 → **无色透明**。
> **结论：黑的那块黑是因为含 Fe²⁺；无色的那块不含铁。**

**第 3 步：定名。**
> 两块都属于**云母族 (mica group)**：
> - **黑云母 Biotite：K(Mg,Fe)₃[AlSi₃]O₁₀(OH)₂** —— **Fe 含量可变，Fe 越多颜色越深**；
> - **白云母 Muscovite：KAl₂[AlSi₃]O₁₀(OH)₂** —— **可含杂质而略带一点颜色**。

**第 4 步：剩下 3 块（透明或半透明，白色/浅灰/橙粉色调；粉末皆无色）。**

| 标本特征 | **定名** | 化学式 | 颜色成因（答案要点） |
| --- | --- | --- | --- |
| **没有解理的那块** | **石英 Quartz** | **SiO₂** | **纯石英完全无色透明，像玻璃**；石英中**可能有少量杂质，但不常见**；**"乳白石英 milky quartz" 很常见，白色由微小流体包裹体 (tiny fluid inclusions) 造成** |
| 3 组非 90° 解理、可能带粉色 | **方解石 Calcite** | **CaCO₃** | **纯净时无色；含流体包裹体时白色**；**任何粉色都来自铁**——**Fe²⁺ 可置换晶体结构中的 Ca²⁺**，**之后可能氧化为 Fe³⁺ 而呈铁锈色** |
| 2 组 90° 解理、粉色不均匀 | **长石 Feldspar**（**最接近你标本的端元是正长石 orthoclase KAlSi₃O₈**，成分可变） | **KAlSi₃O₈** | **粉色源自铁杂质**；**颜色不均匀，靠近小裂隙处更粉** → 指示 **Fe²⁺ → Fe³⁺ 的氧化程度不一** |

**第 5 步：观察展示标本上的颜色现象。**
- **拉长石 (labradorite) 抛光大晶体的 schiller（变彩）**：由晶体中**亚显微的周期性纹层结构**使光**衍射**造成；**纹层由矿物自高温冷却时的出溶作用 (exsolution) 产生**。
- **展示的石英晶体的颜色变化**：由**极少量杂质**造成，例如
  - **黄水晶 citrine（黄色）：Fe**；
  - **蔷薇石英 rose quartz：Ti、Fe、Mn**；
  - **有时杂质伴随一个缺失的电子以维持电荷平衡**：**紫水晶 amethyst：Si⁴⁺ + e⁻ → Fe³⁺**；**烟水晶 smoky quartz：Si⁴⁺ + e⁻ → Al³⁺**；**这些缺失的电子称为色心 (colour centres)**。

### 5.5 板块四：Hardness —— 操作步骤与逐题答案

**操作步骤：**
1. **先用硬度标本盒 (hardness set) 与摩氏标度，确认（标定）手上各工具的硬度，包括你的指甲**；
2. **再用这些已标定的工具，测定/复核你的 5 块矿物和未知矿物 A–M 的硬度**；
3. **⚠ 不要去划展示用的漂亮标本。**

**答案（工具硬度标定结果）：**

| 工具 | **硬度** |
| --- | --- |
| **fingernail 指甲** | **2 – 2½** |
| **copper coin 铜币** | **3½ – 4** |
| **steel knife 钢刀** | **5+** |

## 六、易错点 / 重点难点

### 6.1 易混淆矿物成对区分表（"哪一条性质能一击区分"）

| 易混对 | 相似之处 | **一击区分的性质** | 具体做法与判据 |
| --- | --- | --- | --- |
| **石英 quartz vs 方解石 calcite** | 都可无色透明/白色；都是本周你的标本 | **解理 + 硬度** | 石英**无解理**（不规则/贝壳状断口，H=7，划得动玻璃）；方解石**3 组非 90° 完全解理**（菱面体，H=3，铜币可划）。补充绝招：**滴稀 HCl，方解石剧烈起泡** |
| **石英 quartz vs 长石 feldspar** | 都是浅色造岩硅酸盐，玻璃光泽 | **解理** | 石英**无解理**、断口贝壳状、常无色透明；长石**2 组 90° 解理**、有平坦反光面、常呈粉/白色。**硬度也差一级：7 vs 6（手术刀 6½ 划得动长石、划不动石英）** |
| **黑云母 biotite vs 白云母 muscovite** | 晶习都是 **platy**、都有 **1 组完全解理**、硬度都约 2.5–3 | **颜色 + 撕薄片实验** | 黑云母**黑**，撕成薄片后**仍黑或棕色透明**（含 **Fe²⁺**）；白云母**银色**，撕成薄片后**无色透明**（不含 Fe） |
| **方解石 calcite vs 萤石 fluorite** | 都可无色/浅色透明，都有良好解理 | **解理方向数 + 硬度** | 方解石 **3 组非 90°（菱面体）**，**H=3**；萤石 **4 组（八面体）**，**H=4**。加做 HCl：方解石起泡、萤石不起泡 |
| **方解石 calcite vs 白云石 dolomite** | 都是碳酸盐，都是菱面体解理，硬度接近 | **与稀 HCl 的反应方式** | 方解石**整块即剧烈起泡**；白云石**必须磨成粉末才明显起泡**（或需加热的酸）。**这是碳酸盐鉴定的标准判据** |
| **方铅矿 galena vs 磁铁矿 magnetite** | 都是深色、金属光泽、手感重 | **磁性 + 解理 + 条痕** | 方铅矿**无磁性**、**3 组 90° 立方解理**、条痕**铅灰**、SG 7.6、H=2.5（很软）；磁铁矿**强磁性**、**无解理**、条痕**黑**、H≈6 |
| **黄铁矿 pyrite vs 黄铜矿 chalcopyrite** | 都是黄铜色金属光泽硫化物 | **硬度** | 黄铁矿 **H=6–6.5，小刀划不动**；黄铜矿 **H=3.5–4，小刀轻易划动**，且表面常有**虹彩锖色 (tarnish)**、颜色更偏金黄 |
| **黄铁矿 pyrite vs 自然金 gold** | 都是金黄色金属光泽（"愚人金"） | **硬度 + 延展性 + 条痕** | 黄铁矿硬而脆，**条痕绿黑**；金极软 (H≈2.5)、**可锤成片（延展性）**、**条痕金黄** |
| **石榴子石 garnet vs 橄榄石 olivine** | 都无明显解理、硬度都高、都产于变质/超镁铁岩 | **颜色 + 晶形 + 产状** | 石榴子石多**深红/棕红**、常有**自形等轴晶形（十二面体）**、产于**高级变质岩**；橄榄石**橄榄绿**、多为**粒状无晶形**、产于**橄榄岩/玄武岩** |
| **辉石 pyroxene（如 diopside）vs 角闪石 hornblende** | 都是深色柱状、2 组解理 | **解理夹角** | 辉石 **≈87°/93°（近直角）**；角闪石 **≈56°/124°（明显斜交）**。**这是薄片与手标本上的经典判据** |
| **重晶石 barite vs 方解石/长石** | 都可白色、都有解理 | **手感比重** | 重晶石 **SG=4.5**，**同样大小明显更沉**（BaSO₄ 含重元素 Ba）；方解石 2.71、长石 2.6 |
| **玻璃 glass vs 石英 quartz** | 都无色透明、都呈贝壳状断口 | **硬度（+ 是否为晶体）** | 石英 **H=7 能划玻璃**；玻璃 **H=5½ 划不动石英**。**根本原因：晶体结构原子密堆 vs 玻璃不规则结构** |
| **蛋白石 opal vs 石英 quartz** | 成分都是 SiO₂ 系 | **是否为晶体 + 硬度 + 乳光** | 蛋白石**非晶质**（严格说不是矿物）、**H≈5.5–6.5 较软**、有 **opalescence**；石英**晶质**、H=7 |

### 6.2 概念上最容易搞混的六组区别

**① 晶习 (habit) vs 晶形 (shape)**
- **石榴子石可以长成很多不同形状 (shapes)，但晶习永远是 equant**；
- **habit 是一个分类术语（六选一），shape 是具体几何形态**。

**② 晶面 (crystal face) vs 解理面 (cleavage plane)**
- 都平坦、都反光，**极易混淆**；
- **区别**：解理面是**破裂**产生的（对应内部弱键面），晶面是**生长**产生的；
- **实操判别**：解理面**成组平行、在晶体内部有对应的平行裂纹**；晶面通常**成套按晶体对称性排列、表面可能有生长纹**；
- 讲义的巧妙处理：因为你的标本是砸碎的、**表面基本都是解理面**，所以练习中**允许把解理面当晶面来判晶习**。

**③ 解理菱面体 vs 菱面体晶面（方解石专属陷阱）**
- Video 3 明确警告："**The cleavage rhombohedron is different from the rhombohedral faces that are sometimes developed**"——**两者形状相似但成因不同、取向也不同**，不要把长成的菱面体晶面当成解理。

**④ 晶形与解理可以完全不一样（萤石专属）**
- **萤石晶体外形是立方体，解理却是八面体**；
- 如果你默认"立方晶形 → 立方解理"，在萤石上必错。
- **正确的因果**：晶形 ← 生长条件 + 面原子密度；解理 ← 弱键面位置。

**⑤ 等效解理 (equivalent) vs 非等效解理 (non-equivalent)**
- 解理表中的每一行/每张图代表**一组由对称性相联系的等效解理面**；
- **重晶石有两套非等效解理**，所以它**同时属于两个类别**；
- **数解理时要先问：这些面是不是由对称性等价的？** 不等价的要分开计数。

**⑥ 体色 (body colour) vs 条痕 (streak)**
- 体色受杂质、缺陷、表面氧化左右，**极不可靠**；
- 条痕是**粉末的颜色**，反映**本征成分**，**可靠得多**；
- **但条痕只在 H < 6½ 时可测**。

### 6.3 操作上的坑（做实验时最容易犯的错）

| # | 坑 | 后果 | 正确做法 |
| --- | --- | --- | --- |
| 1 | **粉末痕迹当划痕** | 硬度判高 | 每次划完**擦掉粉末**，确认有无真凹槽；必要时用指甲摸 |
| 2 | **平行的两个面数成两个解理方向** | 方解石数成 6 个方向 | **取向相同的面只算 1 个方向**（方解石 6 面 = 3 方向） |
| 3 | **不转动标本看反光就下结论** | 漏掉解理面 | **对着光转动标本**，找"平坦且镜面反光"的面 |
| 4 | **只看外表面，不看晶体内部** | 完整晶体上判不出解理 | **在晶体内部找成组平行裂纹 (planar cracks inside)** |
| 5 | **凭颜色定名** | 萤石/石英颜色千变万化，必错 | 颜色**最后用**、且只在本征致色矿物上信 |
| 6 | **用硬度 ≥ 6½ 的矿物划条痕板** | 划不出条痕、还刮伤瓷板 | **先估硬度，H < 6½ 才做条痕** |
| 7 | **拿工具去划展示标本** | 损坏系藏标本（专业素养失分） | **只测自己的 5 块和 A–M** |
| 8 | **默认 A–M 每个答案只出现一次** | 漏判重复标本 | 题目明说"**may be more than one sample of some minerals**" |
| 9 | **忘记没有 I 号** | 答案整体串行 | **A–M 去掉 I，共 12 个** |
| 10 | **不先标定工具就直接测未知** | 硬度尺度不准 | **先用硬度盒确认指甲/铜币/刀/玻璃/手术刀的硬度** |
| 11 | **在"habit"上非要给出一个词** | 强答造成错误 | **"too irregular to say"（太不规则说不出）是合法答案**（如你的长石） |
| 12 | **把火山玻璃/蛋白石当矿物** | 定义题失分 | **无晶体结构 → 不是矿物** |

### 6.4 考试中最可能考的知识点（按可能性排序）

1. **矿物的 5 条定义 + 冰/火山玻璃两道判断题**（几乎必考，答题要**逐条对照定义**）；
2. **解理方向数—角度—名称—破裂形态的对照表**（0/1/2@90/2≠90/3@90/3≠90/4/6，及各自代表矿物）；
3. **摩氏硬度 1–10 的十个矿物**（顺序不能错）**+ 五种工具的硬度值**；
4. **"为什么解理比晶形更可靠"**（答：不受决定晶形的外部条件影响，只受内部键强控制；唯一限制是颗粒大小）；
5. **云母的结构 → platy habit + 1 组 perfect cleavage** 的双重解释（弱 K 层）；
6. **萤石：立方晶形 vs 八面体解理**（切角模型）；
7. **石英无解理的原因**（架状结构、强共价键、无弱键面）+ **贝壳状断口的定义**；
8. **石英为什么比玻璃硬**（晶体结构原子更密堆）；
9. **条痕的原理与 H < 6½ 的限制**；
10. **色心 (colour centres) 的两个例子**（amethyst: Si⁴⁺+e⁻→Fe³⁺；smoky quartz: Si⁴⁺+e⁻→Al³⁺）；
11. **labradorite 的 schiller 成因**（出溶纹层 → 光衍射）；**opal 的 opalescence 成因**（非晶质 SiO₂ 微球）；
12. **你的 5 块标本的名称 + 化学式 + 解理 + 颜色成因**（biotite / muscovite / calcite / feldspar(orthoclase) / quartz）——**化学式必须写全写准**。

| **porphyroblast** | 变斑晶 | 变质岩中显著大于基质的晶体（如石榴子石变斑晶） |
| **cleavage** | 解理 | 矿物沿特定平面平滑破裂的性质，反映跨该平面的键强较弱 |
| **cleavage plane** | 解理面 | 解理产生的平坦面；总是平行于可能的（或实际的）晶面 |
| **basal cleavage** | 底面解理 | 1 个解理方向，沿平坦片劈开（云母） |
| **prismatic cleavage** | 柱状解理 | 2 个解理方向（90° → 矩形截面；非 90° → 平行四边形截面） |
| **cubic cleavage** | 立方解理 | 3 个成 90° 的解理方向，破成立方体（galena） |
| **rhombohedral cleavage** | 菱面体解理 | 3 个非 90° 的解理方向，破成菱面体（calcite） |
| **octahedral cleavage** | 八面体解理 | 4 个解理方向，破成八面体（fluorite） |
| **dodecahedral cleavage** | 十二面体解理 | 6 个解理方向，破成十二面体 |
| **equivalent cleavage planes** | 等效解理面 | 由晶体对称性相互联系的一组解理面；解理分类表中的每一类指的都是等效面 |
| **perfect / good / moderate / poor** | 完全 / 好 / 中等 / 差 | 解理质量的定性分级；perfect 极易劈开，poor 不易劈开 |
| **fracture** | 断口 | 无解理时的破裂面，可为不规则或贝壳状 |
| **conchoidal fracture** | 贝壳状断口 | 弯曲表面带同心纹，像贝壳生长纹；石英与玻璃的特征 |
| **planes of weakness** | 薄弱面 | 晶体结构中键合最弱的面，即解理面的位置 |
| **framework structure** | 架状结构 | 石英的结构类型，三维强共价骨架，无弱键面 → 无解理 |
| **colour** | 颜色（体色） | 白光中某些波长被优先吸收后看到的互补色；成因复杂，须谨慎使用 |
| **streak** | 条痕 | 矿物粉末的颜色，在未上釉瓷板上划出；只适用于 H < 6½ 的矿物 |
| **unglazed porcelain plate** | 未上釉瓷板（条痕板） | 测条痕的工具，硬度约 6½ |
| **complementary colour** | 互补色 | 被吸收波长的补色，即我们看到的颜色 |
| **impurities** | 杂质 | 造成本无色矿物显色的微量元素（如石英中的 Fe、Ti、Mn） |
| **colour centre** | 色心 | 为维持电荷平衡而伴随杂质出现的缺失电子，造成颜色（amethyst、smoky quartz） |
| **tarnish** | 锖色 / 晕色 | 表面氧化形成的虹彩薄膜（chalcopyrite） |
| **play of colours / schiller** | 变彩 / 席勒效应 | 微小片状包体或不连续面（如双晶、出溶纹层）内部反射/衍射造成的色彩变幻（labradorite） |
| **opalescence** | 蛋白光 / 乳光 | 蛋白石中因微小非晶质 SiO₂ 小球造成的变彩 |
| **exsolution** | 出溶（作用） | 矿物自高温冷却时分离出成分不同的纹层；labradorite schiller 的成因 |
| **lamellae** | 纹层 / 叶片 | 亚显微的周期性层状构造，使光发生衍射 |
| **hardness** | 硬度 | 抗刻划能力；取决于键密度，可随方向变化 |
| **Mohs' Scale of Hardness** | 摩氏硬度计（1812） | 用 10 种标准矿物建立的定性相对硬度标度，每个矿物能划动比它软的 |
| **bond density** | 键密度 | 单位体积/面积上化学键的数量与强度，硬度的物理基础 |
| **powder trail** | 粉末痕迹 | 软矿物在硬矿物表面留下的粉末，易被误判为划痕 |
| **hand specimen** | 手标本 | 可以拿在手上用肉眼与简单工具观察的岩矿标本 |
| **thin section** | 薄片 | 磨到约 30 μm 的岩石片，用偏光显微镜观察；解理在其中是重要鉴定性质 |
| **solid solution** | 固溶体 / 类质同象 | 成分在特定范围内连续变化（如 garnet 中 Ca–Mg–Fe 互换） |
| **fluid inclusions** | 流体包裹体 | 晶体中包裹的微小流体，造成 milky quartz 与白色方解石 |
| **quartz** | 石英 | SiO₂，H=7，无解理、贝壳状断口，prismatic 晶习 |
| **calcite** | 方解石 | CaCO₃，H=3，3 组非 90° 完全解理，遇稀 HCl 起泡 |
| **feldspar / orthoclase** | 长石 / 正长石 | KAlSi₃O₈，H=6，2 组 90° good 解理，粉色源自 Fe 杂质氧化 |
| **biotite** | 黑云母 | K(Mg,Fe)₃[AlSi₃]O₁₀(OH)₂，黑色因含 Fe²⁺，platy，1 组完全解理 |
| **muscovite** | 白云母 | KAl₂[AlSi₃]O₁₀(OH)₂，银色，薄片无色透明（不含 Fe） |
| **mica group** | 云母族 | 层状硅酸盐，两层 Si–O 四面体夹一层 Mg/Al，层间为弱键合的 K⁺ |
| **fluorite** | 萤石 | CaF₂，H=4，立方晶形但 4 组八面体解理 |
| **garnet** | 石榴子石 | (Ca,Mg,Fe)₃Al₂Si₃O₁₂，equant，无解理，高级变质岩常见 |
| **almandine** | 铁铝榴石 | 富 Fe 的石榴子石端元，深红色 |
| **pyrite** | 黄铁矿 | FeS₂，金属光泽、equant、无解理、条痕绿黑，H=6–6.5 |
| **galena** | 方铅矿 | PbS，铅灰色金属光泽，3 组 90° 立方解理，SG 7.6 极重 |
| **barite** | 重晶石 | BaSO₄，tabular，两套非等效解理（1 perfect + 2 very good @78°），比重大 |
| **labradorite** | 拉长石 | 斜长石族，以强烈 schiller 变彩著称 |
| **opal** | 蛋白石 | 非晶质 SiO₂，具 opalescence，严格意义上不满足矿物定义 |
| **chalcopyrite** | 黄铜矿 | CuFeS₂，黄铜色带虹彩锖色，H=3.5–4，小刀可划 |
| **olivine / forsterite** | 橄榄石 / 镁橄榄石 | (Mg,Fe)₂SiO₄，橄榄绿因含 Fe，产于橄榄岩 (peridotite) |
| **diopside** | 透辉石 | CaMgSi₂O₆，淡绿色，prismatic 晶习，辉石族 |
| **hornblende** | 角闪石 | 深色柱状，2 组 56°/124° 解理；可作为石榴子石的退变边 |
| **quartzite** | 石英岩 | 由石英晶体集合体组成的单矿物岩 |
| **granite** | 花岗岩 | 由石英 + 其他矿物组成的多矿物岩 |
| **peridotite** | 橄榄岩 | 富含橄榄石的超镁铁质岩 |
| **eclogite** | 榴辉岩 | 高压变质岩，含石榴子石 + 绿辉石 |
| **chlorite schist** | 绿泥石片岩 | 含绿泥石的片岩，可含石榴子石变斑晶 |
| **Pele's tears** | 贝利泪滴 | 夏威夷的火山玻璃小滴；既非矿物也非严格意义上的岩石 |
| **talc / gypsum / apatite / topaz / corundum / diamond** | 滑石 / 石膏 / 磷灰石 / 黄玉 / 刚玉 / 金刚石 | 摩氏硬度 1、2、5、8、9、10 的标准矿物 |

---

> **本周一句话总结**：**矿物的每一条可观测物理性质，都是其内部原子结构与化学成分的外显——解理告诉你弱键面在哪，硬度告诉你键有多密，条痕告诉你成分里有什么，晶习告诉你它是怎么长大的；鉴定的艺术，就是按"可靠性从高到低"的顺序把这些线索一条条收集起来，直到只剩一个候选者。**
