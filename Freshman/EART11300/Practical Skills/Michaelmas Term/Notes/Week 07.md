## 二、核心概念

### 2.1 树木密度 (tree density) 与"无样方法"

**定义**：单位面积上的树木株数，标准单位是**株/公顷 (trees per hectare, trees ha⁻¹)**。

**为什么林业/生态调查常用"无样方法 (plotless method)"而不是画样方**：
- 在密林里拉绳、圈定一个准确的 20 m × 20 m 样方非常费时，且边界上的树"算不算"永远有争议（边界效应 boundary effect）；
- 无样方法只需在地上定一个**点 (station / point)**，量几个**点到树的距离**即可，速度快、装备少（一把卷尺 + 指北针）。

**本周用的估计式**（讲义原文给出，源自上周的公式）：

```
每个测站的密度  D = 1 / d²        （单位：株 / m²）
其中 d = 该测站 4 个距离的算术平均值（单位：m）
```

**【补充】这就是经典的 point-centred quarter method (PCQ，点四分法，Cottam & Curtis 1956)**：
- 在测站上用**两条互相垂直的轴**把周围空间划成 **4 个象限 (quarters)**；
- 在**每个象限内**量"测站中心 → 该象限内**最近**一棵符合条件的树"的距离，得到 4 个距离；
- 讲义的 worked example 恰好给了 4 个距离（1.20 / 0.45 / 0.85 / 2.10 m），正对应四个象限。

**为什么是 1/d²（原理，必须能讲出来）**：
- 若树在平面上**随机分布**，则平均每棵树"独占"的面积 ≈ **d²**（d 是平均最近邻距离，可理解为**平均株距**）；
- 面积的倒数就是密度：`D = 1 / (平均每株占地面积) = 1/d²`。
- **自洽性检验**：讲义 Table 1 本身就是按 `密度 = 10,000 / 株距²` 编的（25 m → 16 株/ha；2.5 m → 1600 株/ha；1 m → 10,000 株/ha）。而 worked example 的 d = 1.15 m → 7,561 株/ha，反算 `√(10000/7561) = 1.15 m`。**说明 d 就是"等效平均株距"，你的调查结果可以直接和 Table 1 的"株距"一列对话。**

**【补充】PCQ 的关键假设与失效情形**：
| 假设 | 违反时的后果 |
| --- | --- |
| 树呈**随机 (random / Poisson) 分布** | 若**聚集分布 (clumped)**，点更容易落在空隙里 → d 偏大 → 密度**低估**；若点总落在树丛里则相反 |
| 测站位置**随机或系统布设**，不能"挑好看的地方站" | 主观选点 → 严重系统偏差 |
| 每个象限**必须**取到最近的一棵 | 空象限（无树）无法处理，会破坏估计 |
| 测的是**同一类对象**（如"胸径 ≥ 某阈值的活立木"） | 标准不统一 → 密度不可比 |

### 2.2 均值、标准差与"样本越大越准"

讲义给出的标准差公式（**样本标准差**）：

```
SD = √[ Σ(密度值 − 平均密度值)² / (重复测站数 − 1) ]
```

- 分母是 **n − 1**（贝塞尔校正 Bessel's correction）——因为均值是从同一批数据算出来的，用掉了 1 个自由度；用 n 会**系统性低估**离散度。
- **SD 的意义**：单个测站的密度值围绕均值的**离散程度**，即**这片林子有多不均匀**。

**讲义原话**："If you calculate the standard deviation for those means, you should see that using the combined larger data produces a more accurate estimate of the mean with a lower deviation."（把全班数据合并后，得到的均值更准、离散更低。）

**【补充】这里有一个必须分清的统计学要点（也是最容易被扣分的地方）**：
- **标准差 SD**：衡量**数据本身的离散**。样本量增大时，SD **不会系统性变小**——它收敛到总体真实的离散度。
- **标准误 SE (standard error of the mean)**：`SE = SD / √n`，衡量**均值这个估计量有多可靠**。样本量增大时，**SE 一定变小**。
- 所以"合并数据 → 均值更准确"，严格说是 **SE 变小**；讲义所说的"lower deviation"实际指的是**均值估计的不确定度**下降。答题时可以写："合并后 n 由 (你组的站数) 增至 (全班总站数)，标准误 SE = SD/√n 显著下降，均值估计更可靠；同时更大的样本也更能代表整片林地的空间异质性。"

### 2.3 林分组成 (woodland composition)

- **定义**：各树种在林分中所占的**百分比**，`%物种 A = (物种 A 的株数 / 总株数) × 100%`。
- 本周涉及的树种（讲义点名要求算平均胸径的四种 + 疫病相关的两种）：
  - **oak 栎/橡 (*Quercus*)**
  - **pine 松 (*Pinus*)**
  - **birch 桦 (*Betula*)**
  - **beech 山毛榉 (*Fagus sylvatica*)**
  - **sweet chestnut 欧洲栗 (*Castanea sativa*)**（疫病靶标）
  - **sycamore 悬铃木槭 (*Acer pseudoplatanus*)**（第二份材料的宿主）
- **组成 × 密度 = 每公顷某树种的株数**，这是本周所有"疫病风险"问题的计算骨架。

### 2.4 甜栗疫病 (sweet chestnut blight)

讲义给出的全部信息：
- **病原**：一种**真菌 (fungus)**（讲义链接指向 Forest Research 页面，学名 ***Cryphonectria parasitica***）。
- **致病方式**：**攻击树皮 (attacks bark)**，可**杀死甜栗树**。
- **在重度感染区**：真菌会**扩散到栎树 (oak)**；栎树**不太会死**，但会充当**病原储主 (reservoir)**。

**【补充】机理与判读逻辑**：
- 这是一种**枝干溃疡病 (canker disease)**：菌丝在树皮与形成层中扩展，形成环状溃疡 → **环剥 (girdling)** → 阻断韧皮部运输 → 环剥点以上部分枯死。这解释了为什么它"attacks bark"就能致死。
- **"reservoir（储主/病原库）"这个概念是本周的判读核心**：一个物种**不发病但携带并持续释放孢子**，会让病害在该地区**长期无法根除**。因此风险评估要分**两个层次**：
  1. **直接致死风险** = 只算甜栗；
  2. **总携带/传播风险** = 甜栗 + 栎树。
- 引申的管理含义：若栎树占比很高，即便砍掉全部甜栗也压不住疫情 → 建议中应写明"需同时监测栎树"。

### 2.5 树干直径与"径级离散度 → 年龄结构"

讲义要求："Calculate the average diameter for oak, pine, birch and beech. Also calculate the standard deviation... Is there evidence for any of the species having less variation in trunk size? What might this suggest about the age of those trees?"

**判读逻辑（本周最重要的一条"数据 → 生态学结论"推理）**：

| 观察到的现象 | 直接含义 | 推断的成因 |
| --- | --- | --- |
| 某树种**直径 SD 很小**（径级集中） | 该树种个体大小高度一致 | **同龄林 (even-aged stand)** —— 很可能是**同一次人工栽植 (planted at the same time)** 的一批树 |
| 某树种**直径 SD 很大**（径级分散） | 大小差异悬殊，从小苗到大树都有 | **异龄林 (uneven-aged)** —— **天然更新 (natural regeneration)** 持续发生，或多次补植 |

- **前提假设**：在同一立地、同一物种内，**直径与年龄大致正相关**（直径是年龄的**代用指标 proxy**）。
- **【补充】这个 proxy 的局限**：直径 = 年龄 × 生长速率，而生长速率受**光照、竞争、土壤、被压/优势地位**影响。林下被压木可能很老却很细。所以只能说"**suggest**（提示）"，不能说"证明"。
- **本周的具体预期**：Alderley Edge 是 National Trust 管理的历史林地，含大量 19 世纪人工栽植的针叶与阔叶树；因此**松 (pine) 与山毛榉 (beech) 这类栽植树种更可能出现小 SD**，而**桦 (birch) 作为先锋树种 (pioneer species) 天然更新旺盛，SD 通常最大**。（此为方法学预期，**实际结论必须以你自己的数据为准**。）

### 2.6 生物指示物 (bioindicator) 原理

**定义**：某种生物，其**存在与否、丰度或健康状态**能反映环境条件（尤其是污染水平），因而可以用来"读"环境。

**为什么用生物而不是直接用仪器测 SO₂**：
| 优点 | 说明 |
| --- | --- |
| **时间积分性** | 生物反映的是**长期累积暴露**（讲义明确说估计的是 **annual average** 年均浓度），而仪器抓拍的是瞬时值 |
| **成本极低** | 一片叶子 + 一张方格纸，不需要监测站 |
| **空间覆盖广** | 可以在任意有寄主的地方采样，做**空间制图** |
| **生物学相关性** | 直接反映污染对**活体**的实际影响 |

| 局限 | 说明 |
| --- | --- |
| **半定量** | 只能给出**浓度区间**（见 Table 1），不给精确值 |
| **需要寄主存在** | 没有悬铃木槭的地方就测不了 |
| **混杂因子多** | 见 §六 |
| **校准会过时** | 标定关系来自 **Bevan & Greenhalgh (1976)**，是 1970 年代英国 SO₂ 高值时期建立的 |

**【补充】同类经典案例（便于横向记忆）**：
- **地衣 (lichens)** —— 最著名的 SO₂ 生物指示物，壳状/叶状/枝状地衣对 SO₂ 敏感度递增；
- **水生大型无脊椎动物 (freshwater macroinvertebrates)** —— **Week 6 学过**，用 BMWP/ASPT 等指数指示水质；
- **苔藓与重金属**、**指示植物与土壤 pH** 等。

### 2.7 Rhytisma acerinum（焦油斑真菌）的生物学

讲义给出的全部信息：
- **学名 *Rhytisma acerinum***，俗称 **tar-spot fungus（焦油斑真菌）**。
- **引起的病害**：**tar spot（焦油斑）叶病**。
- **宿主**：**sycamore 悬铃木槭 (*Acer pseudoplatanus*)**。
- **长期已知对大气污染物敏感**（Bevan & Greenhalgh 1976）。
- **敏感机制至今不清楚 (not understood)**；但**普遍认为主要污染物是二氧化硫 (sulphur dioxide, SO₂)**。
- **应用**：通过计算**单位叶面积上的焦油斑数目**，可估算**大气 SO₂ 的年均浓度**。
- **感染程度不同**：Fig. 1 展示了受感染的悬铃木槭叶片，斑点外观与**不同的感染程度 (different degrees of infection)**。

**【补充】背景生物学（原文未写，但理解"为什么它能指示 SO₂"必需）**：
- ***Rhytisma acerinum* 属子囊菌门 (Ascomycota)**。所谓"焦油斑"其实是真菌在叶肉中形成的**黑色子座 (stroma)**——外圈常有淡黄色晕，中心漆黑发亮，形似滴上的柏油。
- **生活史（关键在"落叶越冬"这一环）**：
  1. 夏季在活叶上形成子座 → 斑点逐渐变黑增大；
  2. **随落叶落到地面越冬**，子座在**落叶中成熟**；
  3. **翌年春季**（新叶展开时）从落叶中弹射**子囊孢子 (ascospores)**，随气流侵染新叶。
- **这一生活史正是它对 SO₂ 敏感的可能原因**：真菌**最脆弱的越冬/产孢阶段暴露在近地面空气中**，而近地面**冬春季 SO₂ 浓度最高**（燃煤取暖季）。SO₂ 抑制子囊孢子成熟与萌发 → **污染越重，次年斑点越少**。
- **另一层含义**：市区人行道被清扫落叶，也会打断这一生活史，造成"城市斑点少"的假象（混杂因子，见 §六）。

### 2.8 焦油斑指数 (Tar Spot Index, TSI) 与"反比关系"

**定义（讲义原文）**：
> The number of tar spots per 100 cm² of leaf is the Tar Spot Index (TSI).

**关系性质（讲义原文标题）**：
> **Inverse relationship** between the severity of the disease as measured by TSI and increasing levels of sulphur dioxide.

即：**TSI 越高 → SO₂ 越低；TSI = 0 → SO₂ 最高**。

**为什么是"反比"（判读逻辑，一定要能顺口说出）**：
> SO₂ 杀死或抑制真菌 → 污染重的地方真菌无法完成生活史 → 叶子上几乎没有斑点。
> 所以**"叶子很干净"不代表环境好，恰恰可能代表空气很脏**。这是本周最反直觉、也最容易考的一点。

### 3.1 全部计算公式一览

| 编号 | 名称 | 公式 | 单位 / 说明 |
| --- | --- | --- | --- |
| F1 | 测站平均距离 | `d = (D₁ + D₂ + D₃ + D₄) / 4` | m；4 个象限各一个距离 |
| F2 | 单测站树密度 | `D_station = 1 / d²` | 株 / m² |
| F3 | 单位换算 | `1 hectare = 100 m × 100 m = 10,000 m²`；`株/ha = 株/m² × 10,000` | — |
| F4 | 全场地密度估计 | `D̄ = (Σ D_station) / n` | 株/ha；n = 测站数 |
| F5 | 样本标准差 | `SD = √[ Σ(D_station − D̄)² / (n − 1) ]` | 株/ha |
| F6 | 【补充】标准误 | `SE = SD / √n` | 株/ha；衡量均值的可靠性 |
| F7 | 物种组成 | `%A = (N_A / N_total) × 100%` | % |
| F8 | 某树种每公顷株数 | `D_A = D̄ × %A` | 株/ha |
| F9 | 疫病直接风险株数 | `N_risk = D̄ × %sweet chestnut` | 株/ha |
| F10 | 疫病携带（含储主）株数 | `N_carry = D̄ × (%sweet chestnut + %oak)` | 株/ha |
| F11 | 平均直径 | `x̄ = Σxᵢ / n` | cm；分树种各算一次 |
| F12 | 直径标准差 | `SD = √[ Σ(xᵢ − x̄)² / (n − 1) ]` | cm |
| F13 | 焦油斑指数 | `TSI = (斑点总数 / 叶面积 cm²) × 100` | 斑点 / 100 cm² |
| F14 | 【补充】株距 ↔ 密度互算 | `密度(株/ha) = 10,000 / 株距²`；`株距 = √(10,000 / 密度)` | 用于和 Table 1 对照 |

### 3.2 讲义的密度计算 worked example（Station 1，原文照录 + 逐步复核）

| 步骤 | 内容 | 数值 |
| --- | --- | --- |
| ① 记录 4 个距离 | Distance 1 / 2 / 3 / 4 | 1.20 / 0.45 / 0.85 / 2.10 m |
| ② 求平均距离 d | (1.20 + 0.45 + 0.85 + 2.10) ÷ 4 = 4.60 ÷ 4 | **d = 1.15 m** |
| ③ 求 d² | 1.15² | 1.3225 m² |
| ④ 密度（每 m²） | 1 ÷ 1.3225 | **0.7561 trees / m²** |
| ⑤ 换算到每公顷 | 0.7561 × 10,000 | **7,561 trees / hectare** |
| ⑥ 反算等效株距 | √(10,000 ÷ 7,561) = √1.3225 | 1.15 m（= d，自洽 ✔） |

> **排版陷阱**：原文中写作 "1/1.152"，那是 **1 / 1.15²** 在 docx→md 转换中丢了上标。**不要照抄成 1/1.152。**

> **完整流程**：对**每一个测站**做 ①–⑤，得到一串"株/ha"的值；再用 **F4** 求总体均值作为全场地估计，用 **F5** 求标准差。

### 5.1 【任务 A1】树木密度估计 — 逐步操作

**目的**：给出 Alderley Edge 林地**每公顷树木株数**的估计值及其不确定度，并判断这片林子在育林学上"像什么"。

**野外步骤（PCQ 法，【补充】操作细节）**：
1. **布设测站**：沿一条**样线 (transect)** 每隔固定距离（如 20 m）设一个测站；或用随机坐标定点。**测站数 n 越多越好**（每组通常 5–10 站）。
2. **划象限**：站在测站点上，用指北针把周围分成**四个象限**（如以 N–S 与 E–W 两轴划分）。
3. **量距离**：在**每个象限内**找到**距离测站最近**的一棵符合"计数标准"的树，用卷尺量**测站中心 → 树干中心**的水平距离，记为 D₁–D₄。
4. **同时记录该树的**：树种、周长/直径（供 A3、A6 用）、健康状况（供 A5 用）。
5. **重复**至所有测站完成。

**室内计算步骤**：
1. 对每站：`d = (D₁+D₂+D₃+D₄)/4` → `1/d²`（株/m²）→ `×10,000`（株/ha）。
2. 对全部站：求**均值 D̄**（这就是全场地密度估计）。
3. 求**标准差 SD**（F5），报告成 `D̄ ± SD`（并注明 n）。

**结果判读（讲义问的 "What is your result most similar to?"）**：
- 把 D̄ 放到 **Table 1** 里找最接近的一行，报告成"**本林地密度最接近 XXX 类型（约 YYY 株/ha，等效株距约 Z m）**"。
- **同时用 F14 反算等效株距**，让对比更有说服力："我们的 D̄ = 480 株/ha，等效株距 √(10000/480) ≈ 4.6 m，最接近 Table 1 中 **3–4 m 的 ornamental/urban** 与 **5–10 m 的 orchard** 之间。"（**数值为示例，须以自己的数据为准**。）
- **给客户的话要有育林学含义**，例如：
  - 密度接近 **planted conifer (2,500/ha)** → 这是**未间伐的用材针叶林**；
  - 密度远低于任何栽植标准（几百株/ha）→ 说明这是**已充分间伐的成熟林**，或**已趋于自然林分状态**；
  - 密度接近 **parkland (16/ha)** → 疏林景观。

### 5.3 【任务 A3 + A4】林分组成与疫病风险计算

**A3 组成**：
1. 把所有测到的树（每站 4 棵 × n 站 = 4n 棵）按树种归类计数；
2. `%A = N_A / N_total × 100%`，做成表 C；
3. 检查百分比合计 = 100%。

**A4 疫病风险 — 两问，务必分清**：

> **问 1（原文）**："If this disease reaches Alderley Edge, using the calculated tree density and species composition, **how many trees per hectare are at risk from this disease?**"

- **答**：`N_risk = D̄ × %sweet chestnut`
- **只算甜栗**，因为讲义说这个病 "attacks bark and **can kill sweet chestnut trees**"。

> **问 2（原文）**："In heavily infected areas, the fungus will also spread to oak trees. They are not likely to die, but can act as a reservoir... **what is the total number of trees per hectare could be carrying the disease?**"

- **答**：`N_carry = D̄ × (%sweet chestnut + %oak)`
- **关键词是 "carrying（携带）"而不是 "at risk of dying（有死亡风险）"**。栎树**不会死但会带菌**，所以要**加进来**。

**示范算法（数字为演示，请替换成自己的数据）**：
```
设 D̄ = 500 株/ha，甜栗 = 12%，栎 = 30%
问1  N_risk  = 500 × 0.12 = 60 株/ha  （有死亡风险）
问2  N_carry = 500 × (0.12 + 0.30) = 500 × 0.42 = 210 株/ha （可能带菌）
```

**报告时必须附上的话（专业素养要点）**：
- 明确写出**误差范围**：`N_risk = D̄ × % ± (SD × %)`，或至少说明"该估计基于 n 个测站，均值不确定度为 ± SE"。
- 明确写出**假设**：假设物种组成在整片林地均匀分布。

**【补充】胸径 (DBH) 的标准量法**（讲义未写，但这是野外必须会的规范）：
| 情形 | 标准做法 |
| --- | --- |
| 基本定义 | **DBH = diameter at breast height，胸高直径，量在离地 1.3 m 处** |
| 常用工具 | **围尺 (girth tape)** 量**周长**，再 `DBH = 周长 / π`；或用**直径尺 (diameter tape)** 直接读直径；或用**卡尺 (calipers)** 交叉量两次取平均 |
| 坡地 | 从**坡上方 (uphill side)** 量起 1.3 m |
| 倾斜树 | 沿**树干轴线**量 1.3 m，测量面**垂直于树干**，不是垂直于地面 |
| 1.3 m 以下分叉 | 视为**两株**分别测量 |
| 1.3 m 处有瘤/凸起 | 在其上下各测一次取平均，并在备注中注明 |
| 板根 / 萌生丛 | 在板根以上正常干处测量，注明实际测量高度 |

**【补充】树高的量法**（本周讲义未涉及，但属于同一套调查技能，一并记下）：
- **工具**：**测斜仪 (clinometer)** 或 **激光测高仪 (hypsometer)**。
- **正切法 (tangent method) 三步**：
  1. 退到能同时看到**树基**与**树顶**的位置，用卷尺/测距仪量出**水平距离 L**；
  2. 用测斜仪读**仰视树顶的角度 θ_top** 与**俯视树基的角度 θ_base**；
  3. `树高 H = L × (tan θ_top + tan θ_base)`（观测者与树基不同高时，若树基在视线以上则改为**相减**）。
- **常见误差**：把**倾斜树**当垂直树；把**最靠近你的枝梢**误当树顶（阔叶树尤其容易）；距离 L 未取水平距离（坡地）。

> 原文："Draw around on cm graph paper, the sycamore leaf that you have been given"
- 把叶片**平铺**在 1 cm × 1 cm 方格纸上，铅笔沿**叶缘**描出轮廓。
- **【补充】** 悬铃木槭的叶是**掌状 5 裂 (palmately 5-lobed)**，裂片间的凹缺要如实描出。**叶柄 (petiole) 不算叶面积**，从叶片基部开始描。

**B2 求叶面积（数格子法）**
> 原文："work out the area of the leaf in cm²"
- **【补充】标准数法**：
  1. 数出**完全落在轮廓内**的整格数 = **N_full**；
  2. 对被轮廓切割的边缘格，采用**"过半计入、不过半舍去"**规则计数 = **N_half**（更精确的做法是把所有边缘格数出来记为 N_edge，取 `N_edge / 2`）；
  3. `叶面积 A ≈ N_full + N_half`（或 `N_full + N_edge/2`），单位 **cm²**。
- **【补充】误差控制**：整片叶通常 50–200 cm²，边缘格约占总数 10–20%，因此**边缘格的处理方式是最大误差源**。全班应统一使用同一条规则。

**B3 数斑点**
> 原文："Count the number of tar spots per leaf"
- **【补充】计数规则要统一**：
  - **一个黑色子座 = 一个斑**；若两个斑**边缘相接但中心可分辨**，计为 **2**；若已完全融合成一片，按其大小估计并注明。
  - **叶两面都要看**（斑点通常在**上表面**更明显，但要翻面确认不漏）。
  - 参照 **Fig. 1** 建立"什么算一个斑"的统一标尺。
  - **不要把虫伤、机械损伤、其他叶斑病、坏死斑当作 tar spot**——焦油斑的特征是**漆黑发亮、略隆起、常带黄晕、边界清楚**。

**B4 计算 TSI**
> 原文："The number of tar spots per 100 cm² of leaf is the Tar Spot Index (TSI)"

```
TSI = (斑点总数 S ÷ 叶面积 A cm²) × 100
```

**演算示例（【补充】，用于确认单位不出错）**：
| 例 | 斑点数 S | 面积 A (cm²) | TSI 计算 | TSI | 查表 → SO₂ (µg/m³) |
| --- | --- | --- | --- | --- | --- |
| 甲 | 0 | 120 | 0 ÷ 120 × 100 | **0** | **> 85**（污染最重） |
| 乙 | 1 | 150 | 1 ÷ 150 × 100 | **0.67** | **40 – 55** |
| 丙 | 3 | 100 | 3 ÷ 100 × 100 | **3.0** | **< 25**（最清洁） |
| 丁 | 1 | 200 | 1 ÷ 200 × 100 | **0.50** | **40 – 55** |

**B5 查表判读**
> 原文："use it to estimate the concentration of sulphur dioxide in the air from Table 1"
- 用 §3.4 的表，从 TSI 落入的区间读出 **SO₂ 年均浓度区间 (µg/m³)**。
- **报告写法**：
  > "该叶片面积 A = ___ cm²，焦油斑 ___ 个，TSI = ___。依据 Bevan & Greenhalgh (1976) 的标定关系，采样地点 (Peak District) 的**年均大气 SO₂ 浓度**估计为 **___ – ___ µg/m³**。"
- **【补充】提高可靠性的做法**：单叶结果波动很大，正规做法是**每个地点取 20–30 片叶**（同一高度、同一朝向、避开树冠内部极荫蔽处），用**平均 TSI** 查表；并报告叶片数 n 与 TSI 的离散度。

### 5.7 最终产出：给 National Trust 的 short summary 应包含什么【补充】

讲义要求"write a short summary describing their woodlands"，一份合格的咨询式总结应有：

1. **调查方法与范围**：地点、日期、测站数 n、抽样方法（PCQ）、计数标准。
2. **林分密度**：`D̄ ± SD (n = __)` 株/ha；与 Table 1 的对照结论（"最接近 ___ 类型"）与育林学解读。
3. **物种组成**：表 C + 一句话概括（"以 ___ 为主，占 __%"）。
4. **年龄结构**：四树种的 x̄、SD/CV；指出哪个树种径级最一致，推断为同龄栽植。
5. **病害风险评估**：`N_risk` 与 `N_carry` 两个数字 + "栎树作为储主"的管理含义。
6. **其他病害观察与建议的后续工作**。
7. **不确定性与假设声明**：样本量、空间代表性、直径-年龄代用关系的局限。
8. **（若并入 B 部分）空气质量**：TSI → SO₂ 估计及其局限。

## 六、易错点 / 重点难点

### 密度计算类

1. **`1/1.152` 照抄**——这是 docx→md 丢上标造成的，实际是 **1 / 1.15²= 1/1.3225 = 0.7561**。写成 1/1.152 会得到 0.868，全盘错。
2. **忘记 ×10,000 换单位**——`1 ha = 10,000 m²`。0.7561 株/m² 若直接报成"0.76 株/ha"，误差 4 个数量级。反过来把 `株/ha` 当 `株/m²` 去平方也是常见错。
3. **先算每站密度再平均，还是先平均距离再算密度？**——**必须先对每站算 1/d² 得到各站密度，再对密度求平均**（讲义原文："Once you have a number for the tree density in trees per hectare for each station, estimate the tree density for the whole site by calculating the overall mean"）。因为 `1/d²` 是**非线性变换**，`mean(1/dᵢ²) ≠ 1/mean(dᵢ)²`，顺序颠倒结果不同。
4. **标准差分母用 n 而不是 n−1**——讲义公式明确写 `(number of replicate stations – 1)`。用 n 会系统性低估离散度。
5. **把"SD 变小"和"均值更准"混为一谈**——增大样本量真正下降的是**标准误 SE = SD/√n**，SD 本身反映林地真实的不均匀程度，不会因多测而系统变小。（见 §2.2，这是本周最精细的一个统计学点。）
6. **测站选点带主观偏好**——"往树多的地方站"或"专挑开阔处站"都会造成系统偏差。测站必须**随机或系统布设**，选好点再走过去，不能到了现场再挑。
7. **象限内没找到树 / 一棵树被两个象限重复用**——每个象限只取该象限内最近的一棵，**不得跨象限借用**；出现空象限须记录并说明处理方式。
8. **计数标准不统一**——"多细的算树、幼苗算不算、枯立木算不算"必须**事先定死**（如"DBH ≥ 5 cm 的活立木"），否则各组数据无法合并（而 A2 恰恰要合并）。
9. **量到树冠而不是树干中心**——PCQ 量的是**点到树干（茎轴）的水平距离**。
10. **忽视 PCQ 的随机分布假设**——人工林是**规则栅格分布**、天然林常**聚集分布**，都会使 1/d² 产生偏差。报告中应作为局限性写明。

### 组成与疫病类

11. **两问混答**——"at risk（有死亡风险）"**只算甜栗**；"carrying the disease（携带）"**要加上栎树**。看到 "total number... could be **carrying**" 就必须把储主算进去。
12. **把百分比当成株数直接相加**——必须先 `× D̄` 换成株/ha 再谈"多少株"。
13. **储主 (reservoir) 概念理解反了**——栎树"不太会死"**不等于**"没有风险"。恰恰因为它不死，才会**长期带菌、持续传播**，是防控上更麻烦的角色。
14. **百分比合计不等于 100%**——漏掉"其他树种"一栏，或四舍五入未校正。

### 径级与年龄类

15. **直接用 SD 跨树种比较**——不同树种平均直径差异大，**必须用变异系数 CV = SD/x̄** 才能公平比较相对离散度。
16. **把"直径小 = 年轻"当作铁律**——直径 = 年龄 × 生长速率。**被压木 (suppressed trees)** 可能又老又细。所以只能说 "suggests"。
17. **DBH 量错高度或算错换算**——`DBH = 周长 / π`；若用围尺量得周长却当成直径填表，直径会被高估 π ≈ 3.14 倍。坡地要从**坡上方**起量 1.3 m。

### 生物指示类（本周最反直觉的部分）

18. **★ 把"斑点少 = 环境好"** —— **完全反了**。表标题写的是 **inverse relationship**：**TSI = 0（一个斑都没有）对应 SO₂ > 85 µg/m³，是污染最严重的情形**；**TSI > 2.1（斑点很多）才对应最清洁的空气 (< 25 µg/m³)**。这是本周第一号陷阱。
19. **TSI 忘了 × 100 / 或把"每片叶的斑数"当 TSI**——**TSI 的定义是"每 100 cm² 叶面积上的斑数"**，不是"每片叶的斑数"。必须先除以面积再乘 100。
20. **叶面积把叶柄算进去**——只算**叶片 (lamina)**，叶柄不计。
21. **数格子的边缘格规则不统一**——同一批数据必须统一用"过半计入"或"边缘格数 ÷ 2"，不能一片一个规则。这是叶面积的最大误差源。
22. **把其他叶斑当 tar spot**——焦油斑是**漆黑、发亮、略隆起、常带黄晕**的子座；虫害斑、机械伤、其他真菌斑不能计入。参照 Fig. 1 校准。
23. **只测一片叶就下结论**——单叶 TSI 波动极大（叶大小、树冠位置、受光都影响）。应取多片叶求平均，并说明 n。
24. **忽略混杂因子**：
   - **宿主可得性**：附近悬铃木槭少 → 接种源少 → 斑点少，与 SO₂ 无关；
   - **落叶清扫**：城市清扫落叶会打断真菌越冬产孢环节，人为压低 TSI；
   - **叶龄与采样时间**：斑点从夏到秋逐渐显现增大，**采样季节必须统一**；
   - **树冠位置**：荫蔽、湿度高处感染更重；
   - **其他污染物与气候**：讲义只说 SO₂ 是"generally accepted"的主因，**机制并未被证实 (not understood)**，其他因子（NOx、臭氧、湿度）也可能起作用。
25. **把"标定关系"当作永恒真理**——Table 1 来自 **1976** 年的研究，是英国 SO₂ 高排放年代建立的。**现今英国 SO₂ 已大幅下降**，绝大多数地点都会落入最低污染档，该方法在今天的**分辨力已经很差**。报告中应把这一点作为局限性写出。
26. **混淆两个地点**——**树木调查在 Alderley Edge (Cheshire)**，**叶片来自 Peak District (Derbyshire)**。结论不可张冠李戴。
27. **把结论说成"精确值"**——生物指示给的是**区间**，只能写 "estimated annual average SO₂ in the range __–__ µg/m³"，不能写成单一数字。

### 报告撰写类

28. **只给数字不给解释**——客户（National Trust）要的是**林地描述**，不是一堆算式。每个数字后面都要跟一句"这意味着什么"。
29. **不声明假设与不确定度**——环境咨询报告必须写明样本量、方法假设、误差范围。这是本课"professional skills"部分的核心考点。
