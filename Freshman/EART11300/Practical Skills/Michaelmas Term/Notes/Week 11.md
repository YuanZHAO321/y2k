## 二、核心概念

本次演练覆盖的鉴定要点，按题目涉及范围组织如下。

### 2.1 矿物侧：三项被考到的物理性质

演练只考了 Week 8 四大性质（habit / cleavage / colour / hardness）中的**三项**——**habit、hardness、cleavage**（colour 未出现在本次演练题中）。

**(1) Crystal habit（晶体习性）**
- 定义〔背景补充，Week 8〕：晶面的组合与相对发育程度称为晶体的 habit。它部分取决于晶体结构，部分取决于晶体的生长方式（某些晶面可优先发育）。
- 本题考的是**"看形状→选术语"**，且明确要求**对照 minerals practical handout 第 1 页的图**来配对，即这是一道**术语匹配题**，不是自由发挥题。

**(2) Hardness（硬度）**
- 定义〔背景补充，Week 8〕：hardness 定义为 **resistance to scratching（抗刻划能力）**。它取决于 **bond density（键密度）**，并且**可以随方向变化**，因为矿物不同方向上键的数目与强度不同。Mohs 硬度是**定性**标度：每种矿物能刻划硬度比它低的矿物。
- 本题要求：给出 **Mohs scale 上取整到整数**的数值，**并解释理由**。提供 **copper coin** 与 **glass slide** 两件工具。
- 考点在于**"双向测试"的操作规范**（见第五节 Q2）。

**(3) Cleavage（解理）**
- 定义〔背景补充，Week 8〕：许多矿物倾向于沿特定平面平整地裂开，这源于内部原子结构中**这些面上的键强较弱**。Cleavage planes 永远平行于可能的（或实际的）晶面，与晶体的内部对称性相关。
- 〔背景补充〕Cleavage 比 crystal shape **更可靠**作为鉴定性质，因为它不受决定晶形的外部条件影响（唯一限制是颗粒尺寸）。在偏光显微镜薄片观察中它也极有价值。
- **描述一个 cleavage 必须包含三件事**：
  1. **方向数（number of directions）**：0 / 1 / 2 / 3 / 4 / 6
  2. **角度关系（angular relationship）**：at 90° 还是 not at 90°
  3. **质量（quality）**：perfect / good / moderate / poor
  - 本周反馈明确强调了第 3 项（"remember to indicate how good the cleavage is"）与第 2 项（"at 90°" vs "not at 90°" 的清晰区分）。
- 〔背景补充〕若无 cleavage，破裂表现为 **fracture**，可为 irregular 或 **conchoidal（贝壳状，如碎玻璃）**。

### 2.2 岩石侧：两项被考到的能力

**(1) 三大岩类判别 + 说理（igneous / sedimentary / metamorphic）**
- 判别依据是**手标本可观察属性**：是否由 clasts 组成、是否见 interlocking crystals、晶体是否有自形（own shape）、有无 compositional layering、有无 foliation、有无 fossils/organic matter、是否 glassy、有无 pores/vesicles。
- 本周反馈的核心：**理由必须是"排他性"的**——要让阅卷人**毫无疑问（in no doubt）**它只能是你说的那一类。

**(2) Annotated sketch（带注记素描）**
- 素描的**目的**不是画得像，而是**展示能够判定岩类的 textural features（结构特征）**。
- 必备要素：**scale bar（比例尺）** + **annotations（注记）**（〔背景补充，Week 9〕还应有 **title 标题**）。

## 三、公式与图表

本周材料本身**没有新的表格或图**（它只引用了 minerals practical handout 第 1 页的 habit 图）。以下为**〔背景补充〕**，取自 Week 8 / Week 9 的 answers 文件，是解本周演练题所必需的判读标准，整理于此备查。

### 3.1 〔背景补充〕Habit 术语（Week 8 handout 第 1 页图的文字版）

图的两个轴：**Greater elongation（延长度增加）→** 与 **Decreasing thickness（厚度减小）↓**

| Habit 术语 | 中文 | 形态描述 |
|---|---|---|
| **equant** | 等轴状 | 三个方向尺度大致相等 |
| **prismatic** | 柱状 | 中等程度延长 |
| **acicular** | 针状 | 针一样细长 |
| **fibrous** | 纤维状 | 比针状更细、更长，成束 |
| **tabular** | 板状 | 一个方向变薄，呈板片 |
| **platy** | 片状 | 极薄的片 |
| **massive** | 块状 | 互锁晶体的致密集合体，个别颗粒之间无清晰界线 |

Week 8 给出的对应实例：biotite / muscovite = platy；calcite = tabular 或 prismatic（视样品而定）；feldspar = 常常太不规则而无法定；fluorite / garnet / pyrite (M5) / galena (M8) = equant；quartz = prismatic。

### 3.2 〔背景补充〕Cleavage 方向数与角度对照表（Week 8）

| 方向数 | 名称 | 破裂形态 | 实例 |
|---|---|---|---|
| **0** | No cleavage | 裂成无平面的不规则块体 | quartz, garnet, pyrite |
| **1** | Basal cleavage | 沿平坦薄片剥开 | biotite, muscovite |
| **2 at 90°** | Prismatic cleavage | 长条状，横截面为**矩形** | feldspar（另有一组与之成 90° 的 poor cleavage） |
| **2 not at 90°** | Prismatic cleavage | 长条状，横截面为**平行四边形** | — |
| **3 at 90°** | Cubic cleavage | 裂成立方体 | galena |
| **3 not at 90°** | Rhombohedral cleavage | 裂成菱面体 | calcite |
| **4** | Octahedral cleavage | 裂成八面体 | fluorite |
| **6** | Dodecahedral cleavage | 裂成十二面体 | — |

> 注：上述术语指的是**等效（equivalent）**的解理面组。
> 质量排序（Week 8 给出的 5 矿物）：**biotite、muscovite（最好）> calcite > feldspar**；quartz 无解理。

### 3.3 〔背景补充〕Mohs 硬度标 + 常用工具硬度（Week 8）

| Mohs | 标准矿物 |
|---|---|
| 1 | talc |
| 2 | gypsum |
| 3 | calcite |
| 4 | fluorite |
| 5 | apatite |
| 6 | orthoclase |
| 7 | quartz |
| 8 | topaz |
| 9 | corundum |
| 10 | diamond |

| 工具 | 硬度 |
|---|---|
| fingernail（指甲） | 2 – 2½ |
| **copper coin（铜币）** | **3½ – 4** |
| steel knife | 5+ |
| **window glass（玻璃片）** | **5½** |
| steel scalpel | 6½ |

> **本周演练只提供 copper coin 与 glass slide 两件工具**，因此可分辨的硬度区间实际上是：
> - 被 copper coin 划伤 → H < ~3½
> - 划不动 copper coin、也划不动 glass → H 介于 ~4 与 ~5½ 之间
> - 能划伤 glass slide → H > ~5½
> 加上指甲（自带工具，2–2½）可再细分低端。**答案要取整到整数**，说明只需给出一个合理整数并解释区间来源即可。

### 3.4 〔背景补充〕三大岩类手标本属性对照（Week 9）

| 属性 | Igneous | Sedimentary | Metamorphic |
|---|---|---|---|
| 由 clasts 组成 | 否 | **常见（可磨圆）** | 否 |
| Interlocking crystals | **常见** | 否 | 有（"肥皂泡"式竞争生长） |
| 晶体有自形（own shape） | **部分有**（自由生长于液体中） | 否 | **少数有** |
| Compositional layering | 通常无 | **常见（bedding）** | 可有（"化石层理"，可被褶皱变形） |
| Foliation（面理） | 通常无（有例外：cumulate、流动定向） | 无 | **常见（tectonic fabric）** |
| Fossils / organic matter | **无** | **可有** | 通常不保存 |
| Glassy | **可以** | 否 | 否 |
| Pores / vesicles | 可有 **vesicles**（化石气泡），但不多孔 | **可较多孔** | 无显著孔隙 |
| 矿物种数 | 少（通常 ≤5） | — | 少（通常 ≤6） |

**Week 9 给出的判别流程（B. Steps to follow）**：
1. **(a)** 是否由 clasts（包括化石）组成？**是 → sedimentary。**
2. **(b)** 若否，且能看清晶体：
   - 晶体互锁、且部分有自形 → 很可能 **igneous**（通常看不到层理或定向）。
   - **只有少数**晶体有自形 → 很可能 **metamorphic**（多半能看到层理或定向，但也可能都看不到）。
3. **(c)** 若晶体太小看不清形状：
   - 有 fossils 或 organic matter → **sedimentary**
   - 有 foliation（能劈成层、平行排列的片状矿物使表面发亮）→ **metamorphic**
   - 无面理、无化石、但有少数大的自形晶 → **igneous**
   - 看起来 glassy → **igneous**

**Compositional layering vs Foliation 的区别**〔背景补充，Week 9〕：
- **Compositional layering**：相邻层**成分不同**。
- **Foliation**：片状（flaky）矿物**全部沿同一方向排列**。
- 二者可以共存（如 gneiss R45/A1），也可以互相斜交（discordant）。

### 3.5 〔背景补充〕三大岩类的进一步分类（Week 9，素描/说理时可引用）

- **Igneous —— 按粒度看冷却速度**：中–粗粒 = 冷却慢 = **plutonic**；细粒 = 冷却快 = **volcanic**。若细粒 groundmass 中含大晶体 → **两阶段冷却**（大晶体在岩浆房慢慢长大，基质在喷发时结晶）。
- **Sedimentary —— 按粒度看搬运距离**：粗 = **proximal**（近源）；细 = **distal**（远源）。粒度反映搬运可用能量。含化石的岩石不适用（化石大小由生物种类决定）。
- **Metamorphic —— 按 metamorphic grade**：low grade（变化最小，原岩细粒则仍细粒）→ medium grade（变粗）→ high grade（晶体最大）。成分差异大的岩石之间难以直接比较 grade。

## 四、课堂补充

本课**无 lecture、无 transcript**。以下是本周 feedback 文件中**教师给出的提示与经验之谈**，逐条记录（这是本周材料最有价值的部分）。

1. **关于 habit**——"Match the shapes with the closest ones on page 1 of the minerals practical handout."
   → 教师期待的是**与 handout 图上术语的匹配**，用"最接近的"那一个。不要自创描述性词汇。

2. **关于 hardness 的操作——"两个方向都要测"**
   > "Make sure you test both ways, e.g. if you rub the crystal across the glass slide, it might look like you are scratching it when in fact you are leaving a deposit from the crystal on the slide, so check whether you can get a corner of the slide to scratch the mineral."
   → 用矿物去蹭玻璃，**看起来像划痕的东西可能只是矿物粉末留在玻璃上的沉积（deposit）**。必须**反过来再测一次**：用玻璃片的**角**去划矿物。
   〔背景补充，Week 8 同一提醒的另一种表述〕："if you try to scratch a harder mineral with a softer one, the softer one can leave a powder trail on the harder one which makes it look like it scratched the harder one."（可用手指擦掉粉末验证是否真有刻痕。）

3. **关于施力方式**
   > "You might need to press quite hard, and in a controlled way, i.e. try to dig a little trench rather than aimlessly pushing the material around."
   → 要**用力且受控**，目标是"**挖出一道小沟**"，而不是漫无目的地在表面推来推去。

4. **关于 cleavage 描述的完整性**
   > "Remember to indicate how good the cleavage is. You could compare with your own mineral samples."
   → **必须写质量等级**。判断办法：**拿自己那 5 块矿物做参照**（Week 8 发的、"yours to keep"的样品）——它们的解理质量排序是已知的（biotite/muscovite 最好 > calcite > feldspar），可以作为个人的"标尺"。

5. **关于角度的表述精度**
   > "Also note the clear distinction between 'at 90°' and 'not at 90°' – in the case of the latter, you wouldn't need to specify the actual angle, just that it is not 90°."
   → 只需区分**是不是 90°**。若不是 90°，**不必测出具体角度**，写"not at 90°"即可。（不要因为怕答不全而去硬凑一个角度数值。）

6. **关于岩类说理的标准**
   > "Your reasons should leave me in no doubt that it must be whichever rock type you say it is. For example, some characteristics apply to >1 rock type, so are not enough on their own."
   → 判分标准是**排他性**。某些特征**同时适用于不止一个岩类**，单独列出**不够**（如"含互锁晶体"igneous 与 metamorphic 都可能，需再加"部分晶体有自形 + 无面理无层理"才排他）。

7. **关于"用岩石名当理由"是无效的**
   > "You cannot say 'I know it is sedimentary because it is chalk'. You need to give the properties (Is it made of clasts? Is it porous? etc.) that allowed you to say that it is sedimentary."
   → 认出岩石名字**不能作为**判定岩类的理由。**逻辑方向必须是：属性 → 岩类**，不能是：名字 → 岩类。

8. **关于素描的比例尺画法（教师个人做法）**
   > "I usually wait until I have finished my sketch, and then pick something on the sketch that I can measure, and put a scale bar beside it."
   → **先画完再加比例尺**：画完后挑一个**可以实际量到尺寸**的对象，在旁边配上比例尺。
   > "Some people like to draw a box before they start – it is entirely up to you what you do."
   → 先画外框是**个人偏好，不作要求**。

9. **关于素描的心态与取舍**
   > "Remember, it doesn't need to be perfect (it is not a photo) – it is intended to highlight the important features."
   → 素描**不是照片**，目的是**突出重要特征**，不必完美。
   > "Try to make sure that everything on your sketch is significant, e.g. you don't need to draw the edges of the rock; if there is something weird-looking that you cannot identify, then maybe leave it out."
   → **画上去的每一样东西都应该是有意义的**：不必画岩石的外缘；看不懂的怪东西**可以不画**。
   > "And unless you are a really good artist, then if you do not need to show something in 3-d, just draw a 2-d surface."
   → 除非画功很好，**不需要立体表现就画二维平面**。

### 【Minerals】

#### Q1 — Habit（晶体习性）

**题目原文**
> "Models 3 and 10 are models of two different minerals, showing their ideal shape. What is the most appropriate habit term for each of them?"

**题型解读**
- 考的是**模型（models）**，不是真标本——模型展示的是矿物的 **ideal shape（理想晶形）**，所以不存在"被锤子敲碎、看不到晶面"的困扰，可以直接看整体形态。
- 要求给出 **"the most appropriate habit term"**——单个术语，两个模型各一个。

**教师反馈（答案要求）**
> "Match the shapes with the closest ones on page 1 of the minerals practical handout."

**判断依据（答题方法）**
1. 打开 minerals practical handout 第 1 页的 habit 图。
2. 图的两个维度：**延长度（elongation）** 从左到右增加；**厚度（thickness）** 从上到下减小。
3. 把模型的形状和图上各个形态比对，选**最接近的一个**。
4. 可选术语池〔背景补充〕：**equant / prismatic / acicular / fibrous / tabular / platy**（另有 massive，但那描述的是集合体，不适用于单晶模型）。

**判断链条（可用的自问顺序）**〔背景补充〕
- 三个方向差不多长？→ **equant**
- 明显长一个方向，但还挺"粗"？→ **prismatic**
- 又细又长，像针？→ **acicular**；成束的更细更长的丝？→ **fibrous**
- 一个方向明显变薄，像板？→ **tabular**；薄到像纸片？→ **platy**

**常见错误**
- 自创描述词（如 "long and thin"、"blocky"），而不用 handout 上的标准术语。
- 想给出"精确"答案而纠结于两个相邻术语之间——图本身是**连续过渡**的，选"最接近"即可。

---

#### Q2 — Hardness（硬度，mineral M2）

**题目原文**
> "Determine the hardness of mineral M2. Give your answers as a number on Mohs' hardness scale, to the nearest whole number, and explain your answer. A copper coin and glass slide are available to help you if you need them."

**答案形式要求（三点，缺一不可）**
1. **一个 Mohs 标度上的数字**
2. **取整到最接近的整数**（不要写 "3.5–4" 这种区间作为最终答案）
3. **必须解释理由**（"explain your answer"）——即写出你做了哪些刻划测试、结果如何、由此把硬度框定在哪个区间

**可用工具及其硬度**〔背景补充，Week 8〕：copper coin ≈ **3½–4**；window glass ≈ **5½**；（还可用自己的 fingernail ≈ **2–2½**）

**教师反馈（最核心的一条）**
> "Make sure you test both ways, e.g. if you rub the crystal across the glass slide, it might look like you are scratching it when in fact you are leaving a deposit from the crystal on the slide, so check whether you can get a corner of the slide to scratch the mineral. You might need to press quite hard, and in a controlled way, i.e. try to dig a little trench rather than aimlessly pushing the material around."

**判断依据（正确操作规程）**
1. **双向测试（test both ways）**：A 划 B **和** B 划 A 都要做。
   - 只做一个方向，很可能被**假划痕**骗到。
2. **识别假划痕**：软矿物在硬物表面留下的是**粉末沉积（deposit / powder trail）**，看起来像划痕，但擦一擦就没了；真划痕是**刻进去的沟**。
3. **用玻璃片的角（corner）去划矿物**——角上受力集中，才划得动。
4. **用力要大且受控**，目标是"**挖出一条小沟（dig a little trench）**"，不是在表面来回蹭。

**推理示例（答案怎么写）**〔背景补充式的示范，非原文〕
> "M2 不能被 copper coin (H ≈ 3½–4) 划伤，说明 H > 4；M2 能划伤 glass slide (H ≈ 5½)（且反过来玻璃片的角划不动 M2，排除粉末沉积假象），说明 H > 5½。因此 M2 的硬度约为 6。"
> —— 关键是**每一个数字都对应一次实测**，并且**说明已排除假划痕**。

**常见错误**
- **只测一个方向**，把粉末沉积误判为划痕 → 硬度高估。
- 用力太轻或方向乱动，测不出结果就凭猜。
- 只写数字**不写理由**（题目明确要求 explain）。
- 忘记"取整到整数"。

#### Q3 — Cleavage（解理，mineral M9）

**题目原文**
> "Describe the cleavage of mineral M9:"

**答案形式要求（一个完整的 cleavage 描述必须包含）**
1. **方向数**（0 / 1 / 2 / 3 / 4 / 6）
2. **角度关系**：at 90° 或 not at 90°
3. **质量**：perfect / good / moderate / poor

**教师反馈**
> "Remember to indicate how good the cleavage is. You could compare with your own mineral samples. Also note the clear distinction between 'at 90°' and 'not at 90°' – in the case of the latter, you wouldn't need to specify the actual angle, just that it is not 90°."

**判断依据（怎么数方向、怎么定角度、怎么定质量）**

**(a) 数方向数**〔背景补充，Week 8 calcite 的示例最能说明方法〕
- **平行的两个面算同一个方向**。例如 calcite 的解理碎块有 6 个面，但上下面同向算 1 个、前后面同向算 1 个、左右面同向算 1 个 → 共 **3 个方向**。
- 识别解理面的办法：**平坦、反光好**的表面就是解理面（不规则、不反光的是 fracture 面）。
- 若晶体外表是真正的晶面（看不到解理面），就要**往晶体内部找平面状的裂纹（planar cracks）**。

**(b) 定角度**
- 看**横截面形状**〔背景补充〕：矩形 → 2 at 90°；平行四边形 → 2 not at 90°。
- **只需说"是"或"不是"90°**，不必量具体角度。

**(c) 定质量**
- 教师给的方法：**和自己那 5 块矿物比较**（"You could compare with your own mineral samples"）。
- 参照标尺〔背景补充，Week 8〕：**biotite / muscovite = perfect（一劈就开）** > **calcite = perfect** > **feldspar = good** > ... > **poor（不容易劈开）**；quartz = 无解理。
- 〔背景补充〕Week 8 明确说这些术语**只是定性的**，"don't worry if you are not sure whether to say 'good' or 'perfect'"——perfect 与 good 之间拿不准不必焦虑，但**必须写一个**。

**常见错误**
- **只写方向数和角度，漏掉质量等级**（教师专门用 "Remember to..." 点名的失分点）。
- 把平行的两个面**数成两个方向**（方向数虚高）。
- 明明是 "not at 90°"，却去硬测一个具体角度（多余，且容易测错）。
- 把 fracture 面当成 cleavage 面（不平整、不反光的面不是解理面）。

### 【Rocks】

#### Q4 — 三大岩类判别 + 说明理由（每一块手标本）

**题目原文**
> "For each of the hand specimens provided, indicate what kind of rock it (igneous, sedimentary or metamorphic) and explain your answer."

**答案形式要求**
- 每块标本：**给出岩类** + **给出理由**。
- 理由必须达到"**leave me in no doubt**"（让阅卷人毫无疑问）的强度。

**教师反馈（两条，都是关于理由怎么写）**
> "Your reasons should leave me in no doubt that it must be whichever rock type you say it is. For example, some characteristics apply to >1 rock type, so are not enough on their own."
> "Also, you cannot say 'I know it is sedimentary because it is chalk'. You need to give the properties (Is it made of clasts? Is it porous? etc.) that allowed you to say that it is sedimentary."

**判断依据（答题策略）**

**策略一：使用"排他性"的证据组合。**
关键在于识别哪些特征是**共享的（不足以定案）**、哪些是**排他的（一锤定音）**。

| 特征 | 排他性 | 说明 |
|---|---|---|
| 含 clasts（碎屑/化石碎片） | **强，直接判 sedimentary** | Week 9 流程第一步 |
| 含 fossils / organic matter | **强，判 sedimentary** | igneous 与 metamorphic 均不含 |
| Glassy | **强，判 igneous** | — |
| 有 foliation（面理） | **强，判 metamorphic** | — |
| 有 vesicles（气泡孔） | 强偏 igneous | 但 sedimentary 也可能"porous"，需说清是"化石气泡"而非孔隙 |
| **Interlocking crystals** | **弱（共享）** | igneous 与 metamorphic 都有 |
| **部分晶体有自形** | **弱（共享）** | igneous 多、metamorphic 少 |
| **Compositional layering** | **弱（共享）** | sedimentary 的 bedding 与 metamorphic 的"化石层理"都算 |
| 颜色、光泽、硬度 | **弱** | 单独几乎无判别力 |

→ **写法**：把 1 个强证据写足，或把 2–3 个弱证据组合成排他链。
例：*"互锁晶体（→ igneous 或 metamorphic）+ 多数晶体有自形 + 无面理、无层理、无化石 → igneous。"*

**策略二：绝不用岩石名字当理由。**
- **错误方向**：认出是 chalk → 所以是 sedimentary。（"You cannot say..."）
- **正确方向**：由 clasts 组成 / 多孔 / 含化石 → 所以是 sedimentary。
- 逻辑上，岩石名字本身就是"已经判完了"的结论，用它当理由是**循环论证**，且没有展示任何鉴定技能。
- 〔背景补充，Week 9〕课程明确说岩石名字 "you are not expected to know"——**不考名字，考属性**。

**策略三：按 Week 9 的属性清单逐项过一遍。**〔背景补充〕
教师在题干中给的例子（"Is it made of clasts? Is it porous?"）正是 Week 9 那张属性表的前几列。答题时按 8 列属性自查：clasts / interlocking crystals / own shape / compositional layering / foliation / fossils or organic matter / glassy / pores or vesicles。

**常见错误**
- 理由太弱：只写一条**共享特征**（如"有互锁晶体所以是 igneous"）——不足以排除 metamorphic。
- **用岩石名倒推岩类**（教师点名的错误）。
- 结论对但理由缺失或含糊 → 仍会失分，因为题目考的就是理由。

#### Q5 — Annotated sketch（带注记素描，17 或 18 号标本）

**题目原文**
> "Draw an annotated sketch of 17 or 18. Your sketch should show one or more of the textural features that enable you to determine whether the rock is igneous, sedimentary or metamorphic. Remember a scale on your sketch."

**答案形式要求（三项）**
1. **展示 textural feature(s)**——而且必须是**能用来判定岩类**的那一类特征（一个或多个）。
2. **有 scale（比例尺）**——题干专门提醒 "Remember a scale"。
3. **有 annotations（注记）**——"annotated sketch" 的定义要求。
   〔背景补充，Week 9〕Week 9 的素描题还要求 **title（标题）**：注记 + 比例尺 + 标题三件套。

**教师反馈（四条，全部关于画法）**
> "I usually wait until I have finished my sketch, and then pick something on the sketch that I can measure, and put a scale bar beside it (e.g. see sketch below). Some people like to draw a box before they start – it is entirely up to you what you do."
> "Remember, it doesn't need to be perfect (it is not a photo) – it is intended to highlight the important features."
> "Try to make sure that everything on your sketch is significant, e.g. you don't need to draw the edges of the rock; if there is something weird-looking that you cannot identify, then maybe leave it out."
> "And unless you are a really good artist, then if you do not need to show something in 3-d, just draw a 2-d surface."

**判断依据（素描的四条原则，来自反馈）**

**原则 1 — 比例尺"后加"法。**
画完素描 → 在画面里挑一个**你能实际量出尺寸的对象** → 在它旁边放一根 scale bar。这样比例尺一定是准的。（"先画框"是可选的个人偏好，不作要求。）

**原则 2 — 素描不是照片，目的是"突出重要特征"。**
评分看的是"你有没有把判据画出来"，不是画得像不像。

**原则 3 — 画面上的每样东西都必须"significant"。**
- **不要画岩石的外缘（edges of the rock）**——它不含任何岩类信息。
- **看不懂的东西可以省略**——画上去反而干扰。
- 反过来说：**该画的判据一定要画**（如碎屑岩要画出几个 clasts 与周围 matrix，并尽量正确表现 clasts 的形状范围、大小范围与 clast : matrix 比例〔背景补充，Week 9〕）。

**原则 4 — 能画二维就不画三维。**
除非画功很好，否则**只画一个二维表面**。立体画法容易失控且掩盖特征。

**画什么 textural feature？**〔背景补充，按岩类〕
- **Igneous**：互锁晶体的边界形态、有自形的晶体轮廓、vesicles；若有 phenocryst + groundmass 的两阶段冷却结构，尤其值得画。
- **Sedimentary**：clasts 的形状（圆度）与大小分布、clast 与 matrix 的关系、层理、化石。
- **Metamorphic**：foliation（片状矿物的平行定向）、compositional layering、"肥皂泡"式的晶体边界、以及像 garnet 那样保有自形的变斑晶。

**常见错误**
- **忘记画比例尺**（题干和反馈都专门提醒，说明这是高频失分点）。
- 忘记注记（annotated ≠ 只画图）。
- 花时间去描摹**岩石的外形轮廓**，而没有把判据画清楚。
- 追求逼真、试图画立体效果，结果特征反而看不清。
- 把不认识的、无意义的东西也照抄进去。

## 六、易错点 / 重点难点

以下列点，**★ 标记的是本周 feedback 中教师明确点名的失分点**。

### 矿物部分

1. **★ 硬度测试只做单向 → 被"粉末沉积"骗到。**
   用矿物蹭玻璃留下的痕迹可能只是**矿物粉末的沉积（deposit）**，不是划痕。**必须双向测试**：也要用玻璃片的**角**去划矿物。（Week 8 用另一种说法讲过同一件事：软矿物在硬矿物上留下 powder trail 会造成"软划硬"的假象。）

2. **★ 硬度测试施力方式不对。**
   要"**用力且受控**"，目标是**挖出一道小沟（dig a little trench）**，而不是漫无目的地在表面推来推去。

3. **硬度答案不合规。** 题目要求：Mohs 数值 + **取整到整数** + **解释**。三项缺一即失分。

4. **★ 描述 cleavage 时漏写质量等级。**
   "Remember to indicate how good the cleavage is." —— **perfect / good / moderate / poor 必须写**。判断办法是拿自己那 5 块矿物做参照标尺。

5. **★ 混淆 "at 90°" 与 "not at 90°" 的表述要求。**
   两者**必须清楚区分**；但若是 "not at 90°"，**不必给出具体角度**，写"不是 90°"就够了。（既不要漏，也不要过度。）

6. **数解理方向时把平行面重复计数。** 平行的两个面 = **1 个方向**。calcite 6 个面 → 3 个方向。

7. **把 fracture 当成 cleavage。** 解理面是**平坦且反光好**的；不规则或贝壳状（conchoidal）的破裂面是 fracture，不是解理。

8. **Habit 用自创词而非 handout 术语。** 题目明确要求"match ... the closest ones on page 1 of the handout"。

### 岩石部分

9. **★ 理由使用"共享特征"，不具排他性。**
   "Some characteristics apply to >1 rock type, so are not enough on their own." —— 例如"互锁晶体"（igneous + metamorphic 共享）、"compositional layering"（sedimentary + metamorphic 共享）单列都不够。要用**强证据**或**证据组合**。

10. **★ 用岩石名字当作岩类的理由（循环论证）。**
    "You cannot say 'I know it is sedimentary because it is chalk'." —— 必须给**属性**（Is it made of clasts? Is it porous?），逻辑方向只能是**属性 → 岩类**。

11. **★ 素描忘记比例尺。** 题干"Remember a scale on your sketch"与反馈都提到，说明是高频失分点。**做法**：画完后挑一个可量测的对象，在旁边加 scale bar。

12. **★ 素描画了不重要的东西。**
    "Try to make sure that everything on your sketch is significant" —— **不必画岩石外缘**；**看不懂的东西可以省略**。画面上的每一笔都应服务于"证明这是哪类岩石"。

13. **★ 追求画得逼真 / 硬画立体。**
    "It doesn't need to be perfect (it is not a photo)"；"unless you are a really good artist ... just draw a 2-d surface"。素描是**特征强调工具**，不是写实绘画。

14. **素描没有 annotations。** "annotated sketch" 的核心就是注记——把你识别出的特征**用文字标出来**，让阅卷人看到你的判断。

### 通用（本周反馈的总主题）

15. **结论对但过程没写 = 失分。**
    本周 5 道题里，**4 道明确要求解释或展示依据**（hardness 要 explain、cleavage 要完整描述、岩类要 explain、素描要展示 textural features + 注记）。这门考试考的是**你能不能把观察转化为可辩护的推理**，而不是能不能报出正确名字。

16. **"过度作答"也是一种风险。**
    如 "not at 90°" 不必量角度、看不懂的东西不必画进素描、岩石名字不必背——把精力花在**真正被评分的东西**上。

| **Interlocking crystals** | 互锁晶体 | 晶体彼此镶嵌无孔隙；igneous 与 metamorphic **共享**，单独不足以定案 |
| **Own shape (euhedral)** | 自形 | 晶体被平坦晶面围限，指示在液体中不受阻碍地生长 |
| **Compositional layering** | 成分层理 | 相邻层成分不同；sedimentary 与 metamorphic **共享** |
| **Foliation** | 面理 | 片状矿物平行定向形成的面状构造；判 metamorphic 的强证据 |
| **Tectonic fabric** | 构造组构 | 变形作用产生的晶体优选方位 |
| **Vesicle** | 气孔 | 火成岩中的化石气泡 |
| **Amygdale** | 杏仁体 | 气孔中后期由水溶液沉淀矿物充填形成（Week 9 的 X 号标本） |
| **Groundmass** | 基质（火成岩） | 包围斑晶的细粒基底；斑晶+基质指示两阶段冷却 |
| **Plutonic** | 深成的 | 中–粗粒火成岩 = 冷却慢 |
| **Volcanic** | 火山的 | 细粒火成岩 = 冷却快 |
| **Proximal / Distal** | 近源 / 远源 | 沉积岩粒度分类：粗 = 近源，细 = 远源 |
| **Metamorphic grade** | 变质级 | 变质改造程度（low / medium / high），主要由达到的温度决定 |
| **Annotated sketch** | 带注记素描 | 附有标注文字的科学素描，目的是突出判据而非写实 |
| **Scale bar** | 比例尺 | 素描必备要素；建议画完后挑一个可量测对象在旁边加上 |
| **Textural feature** | 结构特征 | 岩石中能用于判定其成因类型的组构特征，是素描要展示的对象 |
