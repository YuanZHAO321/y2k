**Practical Class Week 1**

# **Aims:**

We will be using a variety of maps in thus unit and this class aims to introduce you to working with maps. We will use map scales and grid references to locate features on a map of the campus.

What are the intended learning outcomes? At the end of this class you should be able to:

1. Estimate the distances between features on a map using the correct map scale

2. Record the grid reference for named features on a map

3. Plot the positions of features on a field map

# **Equipment:**

Mapping board, paper map of Brunswick Park, notebook, pencil, pen, phone or tablet with OS locate app, time chart (if you have an iphone ICS Timechart app)

# **Activities:**

You should have read the information on the BB page about maps and watched the short videos.

We will have a short introduction to the activities before we go outside.

When we go outside you can work in groups of 2-5 people, or you can work on your own.

You do not have to do the activities in order – please start where there is space. There are lots of people here to help you, there are 4 lecturers and 4 Graduate Teaching Assistants, so if you need help or do not understand anything ask us – we are here to help you. We will be wearing high viz jackets so you can find us.
