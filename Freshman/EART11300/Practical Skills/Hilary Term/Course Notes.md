## 一、这门课在讲什么

**EART11300 (Practical and Professional Skills Development)** 是 BSc Earth and Planetary Sciences 大一的三门 40 学分核心课之一。它与另两门核心课的分工非常清楚：EART11100 *Understanding the Earth* 提供地球科学的**知识体系**，EART11200 *Natural Scientist's Toolkit* 提供**数理与化学工具**，而 EART11300 只做一件事——**把手练出来**。

因此本课有三个必须先记住的结构性特征：

**1. 它是技能课，不是知识课。** 全课**没有 lecture、没有课堂录音转写**，所有材料都是 practical sheet / worksheet / answer sheet / 数据集。考核的重心不在"你知道什么"，而在"你能不能按规范做出来、描述出来、算出来、画出来"。这一点在 Week 1 上午场讲义里说得最直白：四条 ILO 中**只有 ILO 1（pH 与 Ka 的数学表达式及摩尔计算）会在 EART11300 内被考核**，其余三条（校准 pH 探头、安全完成滴定、由半中和点求 Ka）的作用是巩固 EART11200 的知识并为二年级课程铺路。**技能的价值在课外兑现**，这是理解整门课定位的钥匙。

**2. 上午 / 下午双轨结构。** 每周分 **Morning** 与 **Afternoon** 两场，**主题完全不同、互不衔接**：上午多为实验室化学 / 生物（滴定、比色、显微制片、形态测量），下午多为地质学（薄片岩相、地质图、沉积构造、化石）。真正的连贯性**不在同一周的上下午之间，而在同一轨的跨周之间**——这正是本总纲按技能类别重组的原因。

结构上的三个例外必须记牢：**Week 6 只有下午场**（水槽实验，全天一场）；**Week 10 只有上午场**（叶绿素，全课收官）；**Week 8 是三段式**——上午火山风险、下午化石保存 + 科学绘图、外加 Museum Quiz。

**3. 它承接秋季学期的同名课程，且是一条明确的升级线。** 秋季练的是"入门级动手"：地图定位与网格参考、流域管理、空气质量测量、Mam Tor 野外指南编写、生物鉴定与河流评估、林地调查、矿物与岩石**手标本**鉴定、湿化学实验、应考演练。春季在每一条线上都往前推了一格：

## 三、技能体系（本节是重点）

### 3.1 实验室定量分析线：W1 → W2 → W3 → W10

这条线的共同内核是一条固定的思维链：**标准/校准 → 显色或滴定 → 终点或读数 → 浓度换算 → 误差控制与结果分级**。四周把这条链的每一环各强化一遍：

- **W1 酸碱滴定测 Ka**：练**校准**（pH 探头两点校准 7.01/4.01）与**曲线读数**。最漂亮的一点是，用半中和点法测 Ka **完全不需要知道酸的准确浓度**——$\text{[HA]}=\text{[A}^-]\Rightarrow K_a=[\mathrm{H}^+]=10^{-\mathrm{pH}}$，即 $\mathrm{p}K_a=\mathrm{pH}_{1/2}$。同时引入**两阶段滴定策略**（粗滴定 2.0 cm³ 定位 → 细滴定 0.20 cm³ 提高突跃段分辨率）与**一致性判据 ±0.10 cm³**。
- **W2 微量重量滴定测水硬度**：练**方法学替代与其代价**。因可持续性而微量化，微量下体积不可读，于是用 $\rho\approx1\ \mathrm{g\,cm^{-3}}$ 把质量当体积；代价是相对误差放大，由此第一次系统训练**非对称不确定度**（−0.01 g / +0.03 g：天平两次读数 ±0.01，加上"最后一滴可能整滴过量"的 +0.02）。还第一次训练**假设的方向性**：只用 $A_r(\mathrm{Ca})$ 而不用 Ca/Mg 加权平均 → 结果**偏大**；Pb²⁺ 污染多耗 EDTA → 结果**偏大**。
- **W3 土壤磷酸盐**：练**提取 (extraction)** 这个新环节，并第一次遇到**操作性定义**——"可给态磷"不是客观形态，而是"用 Olsen 法提出来的那一部分"，所以**报告磷含量必须同时报告提取方法**。仪器端第一次出现**分光光度法**：钼酸铵与磷酸盐生成蓝色配合物，用**互补的红色滤光片 / 650 nm** 检测；Palintest 已把标准曲线固化在 Phot 028 模式里，学生只需处理**稀释因子**（2 ml→10 ml 为 ×5，1 ml→10 ml 为 ×10）。
- **W10 叶绿素**：这条线的**收官与最高点**。仪器不再替你换算——必须自己用 Beer-Lambert $A=\varepsilon c d$（1 cm 比色皿故 $d$ 可略）与 Lichtenthaler & Wellburn 的**联立方程解**：
  $$\mathrm{Chl}\,a = 13.95\,(A_{665}-A_{750}) - 6.88\,(A_{649}-A_{750})\ \ \mathrm{\mu g\,ml^{-1}}$$
  $$\mathrm{Chl}\,b = 24.96\,(A_{649}-A_{750}) - 7.32\,(A_{665}-A_{750})\ \ \mathrm{\mu g\,ml^{-1}}$$
  三个新意识在此一次到位：**基线扣除**（$A_{750}$ 代表散射/浊度而非叶绿素）、**系数与体系绑定**（96% 乙醇 + 1 cm 光程 + 特定波长，换任一项都作废）、**从提取液浓度换算到样品本体**（$C\times V$ 再除以叶面积或叶重）。最后再加统计层：至少收集 4 对同学的数据、画 means ± **standard error**。

> **一句话递进**：W1 学会读曲线 → W2 学会评估自己读得有多准 → W3 学会样品前处理与仪器代劳 → W10 学会自己建立换算并做统计推断。

### 3.2 地质图与构造判读线：W2 → W3 → W7 → W9

这是全课最完整、最有教学设计感的一条递进链，每一周都在方法上前进一格：

- **W2（地质图一）—— 建立"面"的语言。** Strike/dip 的定义与记法（走向 3 位数、倾角 2 位数、必须给倾向；`180/60 E` ↔ `60/270`）；Outcrop 与 Exposure 的区分；**V 字法则**（V 尖端指向倾向，例外为水平层与直立层）；**三点问题**与**地层等高线 (stratum contours)**——平面且均匀倾斜时它们必须**直、平行、等间距**，这既是工具也是自检判据。$\tan(\mathrm{dip})=\Delta h/d$。**输出仍停留在平面图上补线**。
- **W3（地质图二）—— 从平面走向剖面，并处理多产状域。** 三个新东西：①把地层等高线**投影到剖面**上，做真正的**地质剖面**（而非 W2 的纯地形剖面）；②同一张图上做**两条不同方位的剖面**，亲身体会**视倾角随方位而变**；③**真厚度**概念——$t=V\cos\delta$、$t=w\sin\delta$，$t$ 是唯一有地质意义的厚度；④图上出现**角度不整合**分隔的两套产状，必须**分别画两套地层等高线**，且老地层界线在剖面上**终止于不整合面**。
- **W7（褶皱与断层）—— 从"单一产状域"到"被构造改造的岩层"。** 核心分界：**韧性变形 = 褶皱，脆性变形 = 断层**。褶皱要同时给出三组独立描述——几何 (antiform/synform) vs 年龄 (anticline/syncline)、轴面产状 (upright/inclined/overturned/recumbent)、翼间角 (gentle/open/close/tight/isoclinal)，再加是否**倾伏 (plunging)**（判据是**倾角沿轴向是否变化**，以及条带是否闭合成鼻状）。断层用 Anderson 分类（正断层 σ1 垂直、逆断层 σ1 水平、走滑 σ2 垂直）+ BGS 符号（tick 在下降的上盘、齿在上盘）+ 年龄并置关系三重验证，并意识到**同一条断层可以沿走向改变性质**（Causey Pike Fault 西逆冲东走滑）。
- **W9（不整合）—— 从"构造"回到"时间"。** 不整合的本质不是一条线而是一段 **hiatus**；四类（angular / disconformity / paraconformity / nonconformity，后两者中 disconformity + paraconformity 合称 **parallel unconformities**）；并把"识别"拆成三种视图各有标志：柱状图看**波状线**、剖面图看 **cut-off points**、平面图看"**一堆平行的接触线被一条线一刀切断**"。最后升到综合层次：整幅图的**概要素描图 (sketch map)**，并给出好/坏素描图的对照清单。

> **一句话递进**：W2 在平面上补线 → W3 把平面投成剖面并量厚度 → W7 处理被应力改造的几何 → W9 把几何还原成时间序列，并学会把整幅图**综合**成一张图。

### 3.3 显微镜技能线：W1 → W4 → W9

- **W1**：**刻意不给矿物名**，全部用薄片编号（RHB、EG、15216、NH、VT、CFL、E302、R56、R25/SK、PC37）。目的是先把"看什么、怎么看"练出来：PPL 下的**突起、颜色、多色性、解理**；XPL 下的**均质/非均质、消光、干涉色**。最有价值的产出是**"黑色"的四种来源排除法**（真均质矿物 / 充胶孔洞（零突起）/ 非均质矿物垂直光轴切面 / 不透明矿物）与**"最高干涉色才有诊断意义"**这条规则。配套的标准动作：**关小载物台下光阑**增强突起与解理、**旋转载物台**看多色性与消光、**扫全片**取最高干涉色。
- **W4**：把 W1 的性质体系**兑现成鉴定**（olivine、quartz、feldspar、calcite、biotite、garnet），并加上一个更高层的判断——**用结构 (texture) 而非矿物组合定岩石类型**。SB2 与 CG 都以 biotite 为主，一个变质、一个火成，区别只在**晶体是否定向排列**。素描要求也升级：**必须加 scale bar**（换物镜必须重测视场宽度），并注明 PPL 还是 XPL。
- **W9**：显微镜技能第一次**跨到生物学并且要自己制样**——指甲油印迹法自制叶片表皮复型。这里的技能重点从"观察"转向"制片质量控制"（涂薄、涂在叶背、不留指纹、完全干透、慢撕）与"计数规范"（统一物镜倍数、多视野取平均、边界计数规则）。

### 3.4 野外与标本描述线：W5 → W6 → W8

- **W5 上午（火山岩）**：给出一套**七要素描述框架**（Size / Shape / Colour / Mineralogy / Density / Vesicularity → Eruption style），并用"你能描述一块巧克力曲奇吗？"这个梗点破本质：**描述岩石不需要先认识它**。三块标本（pumice / basalt / obsidian）分别演示了三个陷阱：**颜色 ≠ 成分**（黑曜岩深色来自玻璃质，成分是流纹质）、**高黏度 ≠ 必然爆发**（脱气效率与喷出速率是第三个变量）、**玄武质 ≠ 必然在洋中脊/热点**（Stromboli 玄武质但富 H₂O，属火山弧）。
- **W5 下午（沉积物）**：把"描述"推到**标准化指纹**的水平——形状必须拆成**互相独立**的两个分量（**angularity/roundness** 与 **sphericity**），并且要按颗粒类型（矿物 / 贝壳质 / 岩屑）**分行报告**。同时明确各字段的解释边界：**棱角度只对砂级及更粗有效**（细粒被流体缓冲），**球度基本不能用来判搬运环境**（它反映母岩各向异性，是溯源指标）。
- **W6（底形）**：把描述对象换成**正在发生的过程**。核心产出是**底形演替序列**：静止平床 → 波痕 → 沙丘 → 冲刷型沙丘 → 上部平坦床面 → 驻波 → 逆行沙丘，以及每一级对应的**保存构造**（交错纹层 / 交错层理 / 平行纹层 / 上游倾斜纹层）。三个必记的反直觉点：**平行纹层几乎总是高能而非平静**；**波痕→沙丘是"突变"不是渐变**；**逆行沙丘向上游迁移但水和沙粒始终向下游**。
- **W8 下午（化石保存）**：描述对象换成**保存过程**。五大类（未变质软体 / 变质软体 / 未变质硬体 / 变质硬体 / 遗迹化石），变质硬体再分五亚类；最高频的辨析是 **permineralisation（保留微结构）/ recrystallisation（成分保留但微结构全失）/ replacement（成分改变）** 三者，以及 **mould（负形）vs cast（正形）**。同样强调**围岩描述不是可选项**——F27 的黑色粉砂岩直接告诉你那是缺氧、富有机质的低能环境。

### 3.5 数据分析与建模线：W4 → W7 → W8 →（W10 统计）

- **W4 上午**：本课最纯粹的一堂统计课。核心是**三组极易混淆的概念**：①**R² 回答"关系有多紧"，斜率回答"影响有多大"**，且不同变量的斜率**单位不同、不可直接比大小**；②**混杂 (confounding)**——车流量与电力需求本身相关 (r = 0.523)，导致 CO₂-vs-Traffic 的单变量斜率被夸大约 33 倍（124.6 vs 真实的 3.79）；③**离群值必须给机制解释**，且要区分"真实极端事件"与"数据错误"。数据集里最漂亮的一条证据是周六 20:00：车流量极低而 PM2.5 全周最高——证明交通不是主因的 smoking gun。此外野火模块练的是另一种建模：**遥感面积量测 → 生物量与纤维素估算 → 配平燃烧方程 → 摩尔比换算 CO₂**，并要求声明"100% 完全燃烧"等假设使结果成为**上限估计**。
- **W7 上午**：从统计走向**缩放律 (scaling)**。B–L 线性回归比较三组的斜率与截距（斜率大 = 稳健化，小 = 细长化）；关节面积对体重做 **log–log 回归**，斜率就是缩放指数 $b$：$b=2/3$ 为**几何相似 (isometry)**，$b=1$ 为**应力恒定**，$2/3<b<1$ 为**正异速生长**。取对数的四个理由（线性化、斜率有生物学意义、压缩量级避免高杠杆点、稳定方差）是标准答题点。
- **W8 上午**：从数值建模走向**概念框架建模**。**Risk = Hazard × Vulnerability** 不是一个能真算出数字的公式，而是一个用来论证"**hazard 不可消，vulnerability 可降，所以 DRR 有意义**"的框架。配套的是遥感影像判读：PDC（放射状平坦浅色）/ lahar（严格沿谷、可延续多年）/ debris avalanche（丘状 + 马蹄口）/ 熔岩流（指状深色），以及**植被恢复程度作为相对定年工具**。

### 3.6 科学表达线：贯穿全课，W8 集中训练

- **素描 (sketch)** 从 W1 就开始，逐周加码：W1 只要求形态与颜色描述 → W4 **必须加比例尺**并注明偏光条件 → W5 火山岩与沉积物的规范化文字描述 → W6 要求**解释性、标注式图解**（同时表现现象与过程）→ W7 野外照片素描八要素（含比例尺与三个主应力方向）→ W9 整幅地质图的 **sketch map** 好坏清单。

## 四、跨周的核心方法论

1. **描述先于解释，且两者必须分开写。** W5 的"巧克力曲奇"、W1 的"只认性质不认矿物"、W8 的"不要求你鉴定化石"都是同一件事：先用**标准词汇**报告你看到的，再做推断。在 Colour 一栏里写"因为是玄武质所以黑"就是把两步混在了一起。
2. **标准化 = 可比较的前提。** W3 的四个提取影响因素（pH↑、时间↑、振荡↑、温度↑ 都使测得磷↑）说明不固定条件就没有可比性；W6 要求小组自定义"起动临界值"的操作性判据并前后一致；W9 要求不同样品**统一物镜倍数**；W5 用比较卡换取跨人可比。
3. **误差有方向，不确定度可能不对称。** W1：$K_a=10^{-\mathrm{pH}}$ 是减函数，答误差题**必须先把 Ka 的偏向翻译成 pH 的偏向**。W2：−0.01/+0.03 g 的非对称范围，且硬度越低相对误差越大、越可能跨越分类边界。W10：漏减 $A_{750}$ 会让两个浓度**都**系统性偏高。养成"这个错误会让结果偏大还是偏小"的反射。
4. **由观察证据构建论证链——W5 法证练习是全课典范。** 其中四条推理原则可迁移到任何解释题：**"匹配"只是"不能排除同源"，不是"证明同源"**；**缺席证据**在"假设为真则必然留下痕迹"时才有力（Giles 声称待了整天却身上没有 Location 2 的沉积物）；**撒谎 ≠ 有罪**（Rhodri 的 alibi 假但与现场无联系）；**二次转移**意味着物证建立的是"接触过"而非"亲自到过"。
5. **多证据交叉验证。** Brighton 图幅判倾向用了三重证据（dip arrows + 剖面 + 越南越新）；W5 用沉积物 + 植物碎片 + 格网参考 + Digimap 相互印证；W7 判断断层类型用符号 + 年龄并置 + 标志层位移三重；W2/W3 判倾向用"地层等高线由高到低"与"老→新"互校。
6. **将今论古 (the present is the key to the past)。** W6 在水槽里看着沙丘迁移、前积层被保存，就直接读懂了野外的交错层理；W5 由手标本反推一次古喷发；W9 的气孔密度/指数是古大气 CO₂ 的代用指标（而 SI 优于 SD，正因为它对表皮细胞扩张不敏感——这也是"控制干扰变量"思想的体现）。
7. **"缺失"也是信息。** W9 的核心句：*the absence of rocks can be just as informative as the rocks which are present*。同一逻辑在 W5（缺席证据）、W4（Plinian 示意图里没有熔岩流/火山弹，缺项本身是判读依据）、W3（讲义留白处必须自行推理）反复出现。
8. **安全与专业素养是被明确评分的技能。** 每一场化学实验都附完整 Health & Safety 风险表；W6 强调"水和电是致命组合"；实验室之外的对应物是野外的记录规范与团队沟通。
