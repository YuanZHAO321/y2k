## 二、核心概念

### 上午场：土壤磷酸盐的提取与比色测定

#### 1. 为什么测磷酸盐 —— 土壤学与环境意义

- **磷 (P) 是植物生长的必需营养元素 (essential nutrient)**，土壤中以磷酸盐 **PO₄³⁻** 的形式被植物吸收。
- 测得的磷酸盐浓度是土壤中**可给态磷 (available phosphate)** 的指标（**注意：不是全磷**）。它可以与**已施加的肥料量相关联**，用于判断为提高作物产量所施肥料是否合适。
- **过量施用富磷肥料**会导致磷酸盐**淋溶 (leaching)** 进入当地水体，进而在相连河系中造成**富营养化 (eutrophication)** 风险。
- 所以磷测试是**双向**的：既怕不足（作物减产），也怕过量（水体污染）。这正是下面「目标指数 (Target Index)」概念的由来。

📎 **背景补充**：「可给态 (available/plant-available)」是操作性定义 (operationally defined)——它不是土壤中客观存在的某一化学形态，而是「**用某一规定方法提取出来的那一部分**」。换方法（如 Bray-1、Mehlich-3）提取量就不同，指数标准也随之不同。这解释了原文为何强调「Frameworks for the classification of soils according to their phosphorus content are **not universal**」——**报告磷含量时必须同时报告提取方法**，否则数字没有意义。

#### 2. Defra 磷指数分级 (Defra Index Scale)

英格兰、威尔士与北爱尔兰采用 **Defra（环境、食品与农村事务部）指数量表**，规定用 **Olsen's method** 提取磷酸盐并以 **mg/l** 定量。

| Index | Olsen 法磷酸盐浓度 / mg·l⁻¹ |
|---|---|
| 0 | 0–9 |
| 1 | 10–15 |
| 2 | **16–25** |
| 3 | **26–45** |
| 4 | 46–70 |
| 5 | 71–100 |
| 6 | 101–140 |
| 7 | 141–200 |
| 8 | 201–280 |
| 9 | 280（原文如此；📎 应理解为 **>280**） |

**目标指数 (Target Indices)** —— 在保证作物产量的同时把过量风险降到最低：

- **Index 2 (16–25 mg/l)**：**arable（耕地作物）、grassland（草地）、forage crops（饲料作物）** 的最优浓度。
- **Index 3 (26–45 mg/l)**：**vegetable crops（蔬菜作物）** 的理想值。

> 记忆点：**「一般作物 2，蔬菜 3」**。蔬菜需磷更高，所以目标指数上调一档。
> 📎 判读逻辑：测得值落在 Index 0–1 → 缺磷，需补施；落在目标指数 → 维持性施肥即可；高于目标指数（4 及以上）→ 应**减少或停止**施磷，否则淋溶/富营养化风险上升。

#### 3. Olsen's method 的化学原理

- **适用范围**：**mildly acidic to alkaline / calcareous soils**（微酸性至碱性/石灰质土壤）。
- **提取液**：**0.5 M 碳酸氢钠 (NaHCO₃)，pH = 8.5**。
- **作用机理**：加入 pH 8.5 的 0.5 M NaHCO₃ 可**提高土壤中以钙 / 镁 / 铝 / 铁磷酸盐形式存在的磷酸盐的溶解度**。原文给出的示例反应（md 中该行的箭头上下标已在 pdf→md 转换中损坏，条件为 0.5 M NaHCO₃ / pH 8.5）：

```
Ca3PO4(s) + 3NaHCO3(aq)  ──[0.5 M NaHCO3, pH 8.5]──▶
        Na⁺[H2PO4]⁻(aq) + 2Na⁺[HPO4]²⁻(aq) + 3CaCO3(s)
```

- **关键结果**：反应把**碳酸盐与氢氧化物沉淀出来**，而**磷酸盐留在溶液中**（"The reactions precipitate carbonates and hydroxides whilst the phosphates remain in solution."）。
- 溶液中磷的存在形态为 **H₂PO₄⁻** 与 **HPO₄²⁻** 两种（pH 8.5 附近以 HPO₄²⁻ 为主，故方程式中系数为 1 : 2）。

📎 **背景补充（为什么 Olsen 法要选 pH 8.5 的碳酸氢钠）**：碳酸氢钠溶液中的 CO₃²⁻/HCO₃⁻ 会与溶液中的 Ca²⁺ 结合生成难溶 CaCO₃ 而**把 Ca²⁺ 从溶液中"抽走"**；根据溶度积平衡，Ca₃(PO₄)₂ 的解离随之右移，磷酸盐被释放到溶液中。同时较高 pH 抑制 Fe/Al 氧化物表面对磷酸根的吸附（OH⁻ 与 PO₄³⁻ 竞争吸附位点），也有利于释磷。这就是它对**石灰质、中碱性土壤**特别有效的原因；强酸性土壤中磷主要被 Fe/Al 束缚，则更常用 Bray 或 Mehlich 法。

#### 4. 影响提取结果的因素（**考点，且是本次数据分析题的答题依据**）

原文明确：测得值与以下因素**正相关 (correlates positively)**——

| 因素 | 关系 | 📎 机理 |
|---|---|---|
| **pH** | pH ↑ → 提取量 ↑ | 高 pH 促进磷酸盐解吸/溶解 |
| **Extraction time（提取时间）** | 时间 ↑ → 提取量 ↑ | 溶解-解吸尚未达平衡，时间越长释放越多 |
| **Agitation of the extraction vessel（振荡强度/方式）** | 振荡 ↑ → 提取量 ↑ | 改善固液接触、减小扩散边界层 |
| **Temperature（温度）** | 温度 ↑ → 提取量 ↑ | 溶解度与反应速率随温度升高 |

原文特别提示：本次课上给出的方法**「足以理解提取原理并得到一些测量值」，但应当思考改变上述因素会如何导致不同结果**。——这就是为什么**必须严格标准化操作条件**（固定 pH 8.5、固定振荡 1 分钟、同一室温），否则不同人的数据不可比。

#### 5. 分光光度法 (Spectrophotometry / photometry / colorimetry) 原理

- **显色反应**：加入**显色试剂 (colour reagents)** 与样品中目标物种形成**有色配合物**。磷酸盐测试中加入的是**过渡金属化合物——钼酸铵 (ammonium molybdate)**，与磷酸盐形成**蓝色配合物 (blue complex)**。
- **为什么过渡金属配合物有强烈颜色**（原文的电子结构解释）：
  1. 配体 (ligand) 上的电子对与过渡金属离子的 **d 轨道**相互作用；
  2. 导致 **d 轨道能级分裂 (splitting)** 成两组，中间隔着一个**能隙 (energy gap)**；
  3. 该能隙的大小恰好对应**可见光区光子的能量**；
  4. 于是配合物吸收可见光 → 呈现颜色。
- **仪器测量过程**：样品被光源照射 → **能量与配合物能隙相同的光子被吸收**，其余光**透射 (transmitted)** 并被检测器接收 → 由**透射光百分比 (%transmitted light)** 经 **Beer-Lambert Law** 关联到配合物浓度 → 仪器内置的**标准曲线 (calibration curve)** 把透射率换算成目标物种浓度。
- **本次的具体光学条件**：蓝色配合物用**互补的红色滤光片 (complementary red filter)**、检测**波长 λ = 650 nm** 的光。

📎 **背景补充（互补色原则与 Beer-Lambert）**：
- **互补色**：溶液呈蓝色，说明它吸收的是蓝色的互补色——**红/橙色光（约 650 nm）**。所以测「蓝色配合物」要用「红色滤光片 / 650 nm」，测量的是**吸收最强处**，灵敏度最高。这是所有比色法选波长的通则：**测什么颜色，就打它的互补色光**。
- **Beer-Lambert Law**：A = ε·c·l，其中 A = 吸光度 = −log₁₀(I/I₀) = −log₁₀(T)，ε 为摩尔吸光系数，c 为浓度，l 为光程。透射率 T 与浓度呈**对数**关系，而吸光度 A 与浓度呈**线性**关系。这正是「%transmitted light 需要通过标准曲线才能得到浓度」的原因；Palintest 已把标准曲线固化在各测试模式（如 Phot 028）中，所以你直接读到 mg/l。
- 原文写「%transmitted light is related to the concentration ... by the Beer-Lambert Law. **A calibration curve is used to find the concentration**」，其后原本应有一张标准曲线图，md 中缺失。

#### 6. 空白 (blank) 的意义

原文规定：**空白 = 与样品同样稀释的提取滤液，但不加任何显色试剂**（"do not add any further reagents to this cuvette"）。

📎 **背景补充**：空白的作用是**扣除非目标显色造成的信号**——即提取液本身（NaHCO₃ 溶液）、土壤滤液自带的颜色/浊度、比色皿玻璃与光学系统的本底吸收。仪器先测空白并把它定为 100% 透射（零吸光），再测样品，二者之差才归因于磷-钼蓝配合物。**注意这里的空白不是纯水**，而是"除了显色剂之外和样品完全一样"的溶液——这是分析化学中空白设计的核心思想：**空白与样品之间只允许有一个变量**。

### 下午场：地质图判读 2

#### 1. 三条基础概念（Week 2 已建立，本周直接使用）

- **Strike（走向）**：地质面上**水平线**的方位（罗盘方位角，3 位数写法，如 180）。
- **Dip（倾角）**：地质面上**最大坡度角**，永远**垂直于走向**（2 位数写法，如 24），并须给出**倾向 (dip direction)**（如 E）。完整记法：**strike/dip + dip direction**，例如 **180/24E**。
- **Stratum contours（地层等高线，又称 structure contours）**：地质面（层面、断层面、煤层面等）与各**topographic contour（地形等高线）** 的**交点**连成的线；与地形等高线一样按固定高程绘制。
  - 若地质面是**平面 (planar)** → 地层等高线是**直的、平行的、等间距的**；
  - **地层等高线的方向 = 该面的走向**；
  - 地层等高线**弯曲** → 走向沿曲线变化；
  - 地层等高线**间距变化** → 倾角变化（间距密 = 倾角陡）。

#### 2. **本周相对 Week 2 的方法推进（本周特别要求）**

| | **Week 2 · Geological Maps 1** | **Week 3 · Geological Maps 2** |
|---|---|---|
| 核心任务 | 从露头形态**定性推断**倾向（V 字法则）；用 **three-point problem** 构建地层等高线，**在图面上把接触界线补全** | 从露头形态**定量求出** strike/dip/dip direction，并把地层等高线**转换为垂直剖面 (vertical cross-section)** |
| 输出形式 | 平面图（map view）为主；另做过一次纯**地形剖面 (topographic profile)** | **地质剖面**：地形线 + 地质接触面同时绘于剖面上（Ex.1c/d、Ex.2b、Ex.3(5)） |
| 剖面条数 | 单条 | **同一张图上做两条不同方位的剖面**（Ex.1 的 A–B 与 C–D）→ 体会**视倾角随剖面方位而变** |
| 厚度概念 | 未涉及 | **新增**：**true thickness (t) / vertical thickness (V) / outcrop width (w)** 三者的区分与换算 |
| 综合产物 | 无 | **新增**：由剖面构建**stratigraphic column（地层柱状图）**，按正确层序 + 真厚度 |

> **一句话总结推进点**：Week 2 是「**在平面图上把线补全**」；Week 3 是「**把平面图的三维信息投影成剖面，量出真厚度，并处理多个构造域（不整合）**」。

#### 3. Angular unconformity（角度不整合）

原文定义（并回顾 EART11100 *Understanding the Earth* workshop 的内容）：

> 角度不整合是指——**较老的地层先被掀斜 (tilted)，然后被剥蚀 (eroded) 并出露成为一个沉积面 (depositional surface)，之后一套不整合的较年轻地层沉积在其上。**

- **图面判据**：不整合面**截切 (truncate)** 下伏地层的界线；不整合面之上与之下的地层**走向/倾角不同**。
- **作图后果（本周的关键操作要点）**：因为上下两套地层产状不同，**不能用同一套地层等高线**。必须：
  1. 先给**年轻的一套**（本题的 E–F 接触面）画地层等高线并投到剖面上；
  2. 再给**老的一套**（C–D 接触面）**另画一套**地层等高线并投到剖面上；
  3. 老地层的界线在剖面上要**终止于不整合面**（被削截）。

#### 4. True thickness（真厚度）

原文定义：

> **The true thickness of a bed is the distance between the top and bottom, in a direction perpendicular to the stratification.**（真厚度 = 顶底面之间**沿垂直于层理方向**的距离。）
> 在垂直剖面上，倾斜岩层的厚度被**夸大**为某个更大的值 **V（vertical thickness，视厚度/垂直厚度）**。

三个量的区分：

| 符号 | 名称 | 含义 |
|---|---|---|
| **t** | true thickness（真厚度） | 垂直于层面量得的厚度——**唯一有地质意义的厚度** |
| **V** | vertical thickness（垂直厚度） | 在垂直剖面上沿**铅垂方向**量得的厚度，**总是 ≥ t** |
| **w** | outcrop width（露头宽度） | 该层在**水平地面/地图上**出露的宽度 |

原文说明 Figure 1 给出了两条换算式：(a) 已知 V 与 dip → 求 t；(b) 已知 w 与 dip → 求 t。**该 Figure 未包含在 md 文本中**。

📎 **背景补充（补出这两条公式，δ = 倾角）**：
- **由垂直厚度求真厚度**：**t = V · cos δ**
- **由露头宽度求真厚度（水平地面）**：**t = w · sin δ**

  推导：把岩层看作一块倾斜的板。沿铅垂线穿过它的长度 V，与垂直层面的最短距离 t 之间夹角就是倾角 δ，故 t = V cos δ。同理水平方向穿过的长度 w 与 t 之间的夹角为 (90°−δ)，故 t = w sin δ。
- **自检**：δ → 0（水平层）时 cos δ → 1，t → V（水平层的垂直厚度就是真厚度 ✓）；同时 sin δ → 0，t → 0 而 w → ∞（水平层在地表铺开极宽 ✓）。δ → 90°（直立层）时 t → w ✓，而 V → ∞ ✓。
- ⚠️ 上述 t = w·sin δ **只在地面水平**时成立。若地面有坡度，需用更完整的形式（视地面倾向与地层倾向同向/反向而异）。本周练习是在**剖面上**量 V 再换算，属于 (a) 型。

| 露头图案 | 推断 |
|---|---|
| 露头界线**完全平行于**地形等高线 | 地层**水平** (dip = 00°) |

| 地层等高线**弯曲** | 走向变化（褶皱等） |

| 界线被另一套界线**截切**，两侧产状不同 | **角度不整合** |
| 由**地层柱状图**知层序 | 平面倾斜层的**倾向由老指向新** |

**倾角计算（由地层等高线求 dip）**

📎 **背景补充**（Week 2 Ex.3 已引入的方法，本周 Ex.1(b)、Ex.2(a)、Ex.3(6) 反复使用）：

```
tan(dip) = 高差 / 水平距离 = Δh / d
```

其中 Δh 是相邻两条地层等高线的**高程差**（读地形等高线间距，如 10 m），d 是两条地层等高线之间的**垂直（最短）水平距离**——**必须用图上量距 × 比例尺换算成实际水平距离**，且必须沿**垂直于地层等高线**的方向量（即沿倾向量），沿其他方向量得到的是**视倾角 (apparent dip)**，偏小。
- 例：Week 2 中给出比例尺 1:4,000，则图上 1 cm = 40 m。
- **倾向**：从高程**高**的地层等高线指向高程**低**的地层等高线的方向（面向下倾方向）。
- **走向**：即地层等高线本身的方位角。

**剖面绘制的比例尺规则**

- Week 2 明确要求：**剖面的垂直比例尺必须与地图的水平比例尺一致**（no vertical exaggeration）。本周 Ex.2 要求「using the graph paper provided」画剖面 —— 📎 只有在 1:1 无垂向夸大的剖面上，量出的角度才是真倾角、量出的 V 才能用 t = V cos δ 正确换算；一旦垂向夸大，角度与厚度都会失真。

## 五、Practical 要点

### 【上午场】Testing for phosphates: soil extraction and Palintest

#### 目的
测定土壤样品中**可给态磷酸盐**的浓度（mg/l），并对照 **Defra 磷指数**进行分级评价；同时掌握**通用土壤提取流程**与 **Palintest 分光光度仪的独立操作**。目标：**分析两个土壤样品**。

#### 器材清单（据流程反推汇总）
- 顶置天平 (top-pan balance)、提取瓶（带密封盖）、量筒 (measuring cylinder)
- 固体 NaHCO₃、去离子水 (deionised water)
- 巴斯德吸管 (Pasteur pipette)、万能指示纸 (universal indicator paper)
- **2 ml 取样勺 (scoop)**、土壤大样 (bulk samples)
- 重力过滤装置：锥形瓶 (conical flask) + 漏斗 (filter funnel) + **Whatman No.1 滤纸**
- **2 ml 注射器 (syringe)**（干净）、**10 ml 塑料比色皿 (cuvette)** ×2 + 蓝色塑料盖 ×2
- **Palintest P1 与 P2 片剂**、塑料压片棒 (tablet crusher)
- **Palintest 分光光度仪**（带穹顶形样品罩）
- 溢出盘 (spill trays)、tiger bins、蓝色实验纸巾

#### 操作步骤

**Part 1：提取 (Extraction)**

1. 用**顶置天平**在提供的瓶中称取 **2.1 g 固体 NaHCO₃**。
2. 用**量筒**加入 **50 ml 去离子水**至提取瓶，**摇动/搅拌至碳酸氢钠完全溶解**。
3. 用**巴斯德吸管**滴一滴到**万能指示纸**上，**检查提取液 pH ≈ 8.5**。
4. 从大样中选一个土样，用提供的 **2 ml 勺取一"平勺" (level measure)** 转入提取瓶。**注意防止交叉污染 (cross contamination)**。
5. **拧紧瓶盖**，摇动数秒，**检查是否有泡腾 (effervescence)**——酸性土壤会产气。必要时**开盖泄压**。重复摇动，直至**累计摇动时间达 1 分钟**。
6. 搭建**重力过滤装置**（锥形瓶 + 漏斗 + Whatman No.1 滤纸）。滤纸折成**四折 (quartered)** 或**扇形折 (fluted)**——**fluted 效率更高**。
7. 小心把提取混合物倒入滤纸。**最初几滴滤液可能浑浊 (turbid)，若浑浊应弃去**。等待滤液在锥形瓶中积累——**要有耐心，这可能很慢**。

**Part 2a：制备空白 (blank)**

1. 用**干净的 2 ml 注射器**精确抽取 **exactly 2 ml** 提取滤液，加入一个**干净的 10 ml 塑料比色皿**。**不要触摸比色皿侧壁**——留下的痕迹会影响光度计读数。
2. 用**去离子水**稀释至比色皿 **10 ml 刻度**：让**弯月面 (meniscus) 底部**落在比色皿上标示的**白色校准线**上；判读时**眼睛必须与校准线齐平**。
3. 盖上**蓝色塑料盖**。
4. **这就是空白 —— 不要再向此比色皿加入任何试剂。**

**Part 2b：制备待测样 (sample)**

5. 重复上面第 1、2 步，制备**第二个**装有等量稀释滤液的比色皿。
6. 加入 **1 片 Palintest P1**，**直接从包装推入比色皿**（不要先倒在手上）。用**干净的塑料压片棒轻轻**下压加速溶解。⚠️ 可能伴随**剧烈泡腾**，注意溶液可能溢出比色皿——**轻压可减少溢出**。
7. 加入 **1 片 Palintest P2**，按需压碎。⚠️ **此时绝对不要盖盖子**——持续泡腾会在盖下积聚压力，可能把盖子弹飞。
8. **等待 10 分钟**让蓝色显色完成。
9. 盖上蓝色盖子。

**Part 2c：仪器测量**

1. 开机。
2. 用**上/下箭头**选择正确测试模式：**Phot 028 Phosphate/4**，按 **OK**。
3. 显示 **"Insert blank"** 时：取下**穹顶形样品罩**，放入**空白**比色皿，**盖回罩子以隔绝环境光**，按 **OK**，等待显示 **"Insert Sample"**。
4. 显示 **"Insert sample"** 时：取出空白，放入**样品**比色皿，盖回罩子，按 **OK**，等待仪器显示结果。
5. 读数后 **×5**（校正比色皿制备时的稀释），把**未稀释提取滤液**的浓度记入结果表。
6. **若结果饱和**（超出仪器量程，显示 **`>>`**）：需要**进一步稀释后重做**（**空白与显色样都要重新制备**）。改用 **1 ml 提取液定容至比色皿校准线**，此时结果需 **×10**。
   - 野外操作时用仪器随附的 **Palintest dilution tubes + syringe** 配制稀释样。

#### 数据处理

1. 用自己的结果 + 部分同学的结果填完结果表，算出各土样的 **range（极差）** 与 **mean average（算术平均）**。
2. **讨论结果离散的原因**，必须结合 background/theory 中列出的**影响提取过程的因素**（pH、提取时间、振荡、温度）来分析。
3. 用平均值查 **Defra Index** 表，填入 **Classification** 列。

📎 **背景补充（讨论 range 的答题骨架）**：
- **提取端**：各人摇瓶力度/方式不同（agitation）；「1 分钟」计时不严格（extraction time）；配液时称量与量水的误差导致实际浓度偏离 0.5 M、pH 偏离 8.5（pH）；实验台温度差异（temperature）。
- **取样端**：2 ml 勺是**体积取样**而非质量取样，土壤**堆积密度 (bulk density)** 与压实程度不同 → 实际取到的土质量不同；土壤本身**非均质**，即使同一 bulk sample 也有真实的空间变异。
- **测量端**：稀释体积误差（2 ml 注射器、弯月面读数视差 parallax）；显色时间不足 10 min；比色皿有指纹/划痕/残留；空白与样品所用滤液不是同一批。
- **表述要点**：区分 **random error（可用重复测量取均值削减，体现在 range 上）** 与 **systematic error（如温度整体偏高、勺子装填习惯一致偏紧，取均值无法消除，会使全班数据一致偏移）**。

#### 结果判读
- 换算后的浓度 (mg/l) → 查 Defra 表得 Index。
- 与目标指数比较：**arable / grassland / forage → Index 2**；**vegetable → Index 3**。
- 低于目标 → 磷不足，需施肥；高于目标 → 磷过量，有**淋溶 + 富营养化**风险，应减施。

#### 潜在误差来源评价（讲义提出的 4 道思考题，**原文无答案**）

原题：

1. 为什么必须确保显色片剂**直接**转入比色皿？如果不直接转入（例如片剂破碎、或先放在手上）会对结果有什么影响？
2. 为什么不能触摸比色皿侧壁？触摸会对结果有什么影响？
3. 为什么必须弃去提取滤液中特别浑浊 (turbid) 的最初几滴？不弃去会有什么影响？
4. 为什么比色皿、比色皿盖和压片棒在制样前必须完全清洁？

📎 **背景补充（参考答题思路，非原文）**：

1. **片剂直接投入**：片剂含定量的显色试剂，**试剂量决定了显色配合物的生成量**。若片剂破碎有粉末损失、或先接触手（粉末粘在皮肤上、手上的汗/油脂污染片剂），进入比色皿的试剂**少于设计量** → 显色试剂**不足以与全部磷酸盐反应** → 蓝色偏浅 → 透射率偏高 → **读数偏低 (underestimate)**。此外手上的磷（汗液、洗手液、食物残留）也可能**污染样品导致偏高**。安全上也不允许——P1/P2 会造成皮肤灼伤。
2. **不触摸比色皿侧壁**：指纹的油脂会**散射与吸收**通过的光，改变透射率。由于**空白与样品各有一支比色皿**，若只有其中一支被摸脏，就引入了**空白无法扣除的差异**——脏的是样品 → 透射偏低 → 读数**偏高**；脏的是空白 → 读数**偏低**。
3. **弃去最初的浑浊滤液**：浑浊来自穿过滤纸的**悬浮土壤颗粒**。颗粒会**散射光 (turbidity)**，被仪器误判为吸收 → **读数偏高**；同时颗粒表面仍吸附着磷，属于**未被提取液真正溶解的磷**，不应计入"可给态"。弃去头几滴还能让滤纸孔隙被细颗粒初步堵塞（"self-filtering"），后续滤液更清澈。
4. **器皿必须洁净**：比色皿/盖/压片棒上的**前次样品残留（尤其含磷酸盐或钼酸盐显色剂）会交叉污染**当前样品 → 读数偏高；残留的洗涤剂（许多清洁剂**含磷酸盐**！）尤其严重。此外残留的固体颗粒同样造成浊度误差。**这是磷分析的经典陷阱：绝不能用含磷洗涤剂洗涤磷分析器皿。**

#### 常见错误（上午场）

- ❌ 配好提取液**不测 pH** 就直接用 —— pH 是影响提取量的首要因素。
- ❌ 用 **2 ml 勺时堆尖**而非刮平 → 取样量偏大 → 结果偏高。
- ❌ 摇瓶产气后**不开盖泄压**就继续摇 → 瓶盖冲开、样品损失、有安全风险。
- ❌ 累计摇动**不足 1 分钟**或超时 → 提取量系统性偏低/偏高。
- ❌ 弯月面读数时**视线不与校准线齐平** → 视差 (parallax) 误差 → 稀释倍数不准。
- ❌ 加 P2 后**立刻盖盖** → 压力积聚把盖子弹飞（讲义明确警告）。
- ❌ **显色不满 10 分钟**就测 → 蓝色未充分显色 → 读数偏低。
- ❌ **忘记 ×5 稀释因子** → 结果差 5 倍，Defra 分级完全错误。
- ❌ 出现 `>>` 时只重做样品**不重做空白** → 空白与样品稀释倍数不一致，扣除无效。
- ❌ 用力压片 → **压碎比色皿**（安全风险 + 样品损失）。

#### **Exercise 1 — 由露头图案确定面的产状 + 两条剖面**

**图面情境（原文）**：图示一个**山坡 (hillside)**，其上有**泥岩 (mudstones)**，被**砂岩 (sandstone) 单元（阴影区）覆盖 (overlain)**。地形等高线单位为**米**。

**任务**：
- **(a)** 为**泥岩与砂岩之间的接触面 (contact)** 构建**地层等高线 (stratum contours)**，并给每条标注其**海拔高度**。
- **(b)** 确定该接触面的 **strike、dip、dip direction**。
- **(c)** 沿 **A–B** 线绘制**垂直剖面**，显示**地形与接触面**。
- **(d)** 沿 **C–D** 线重复 (c)。

**操作方法（📎 展开的通用作图流程，讲义只给任务不给步骤）**：

1. **找交点**：在图上标出**接触界线**与**每一条地形等高线**的**所有交点**。
2. **连同高程点**：把落在**同一高程**等高线上的交点用直线连起来 → 这就是该高程的**地层等高线**；按等高线高程逐一标注（如 "150 m"、"140 m"…）。
   - **自检**：若接触面是平面，各条地层等高线应当**平行且等间距**。若不平行/不等距，说明找点有误或该面非平面。
3. **strike** = 地层等高线的**方位角**（用量角器相对图上北方向量取，写 3 位数）。
4. **dip 角**：取相邻两条地层等高线，**沿垂直于它们的方向**量图上距离 → 按比例尺换算成实地水平距离 d；高程差 Δh 已知 → **dip = arctan(Δh / d)**（写 2 位数）。
5. **dip direction** = 由**高**地层等高线指向**低**地层等高线的罗盘方向（用 E/W/NE… 表示）。
6. **画剖面 (c)(d)**：
   - 在方格纸上建立与地图**水平比例尺相同**的垂直高程轴；
   - 沿 A–B 线读取它与每条**地形等高线**的交点及其高程 → 点到剖面上 → 平滑连线 = **地形轮廓 (topographic profile)**；
   - 沿 A–B 线读取它与每条**地层等高线**的交点及其高程 → 点到剖面上 → 连成直线 = **接触面在剖面上的迹线**；
   - 接触面之上标砂岩、之下标泥岩，加**花纹 (ornamentation)**。

**为什么要做两条不同方位的剖面 (c) 与 (d)**：
📎 A–B 与 C–D 方位不同，剖面上量到的接触面倾角是**视倾角 (apparent dip)**。只有当剖面**平行于真倾向**时，剖面上的角度才等于**真倾角**；剖面**平行于走向**时，接触面在剖面上表现为**水平线**（视倾角 = 0）。这一对比是本练习的核心教学点。

#### **Exercise 2 — 用地层等高线画剖面 + 真厚度 + 地层柱状图**

**图面情境（原文）**：图示一套**均匀倾斜的沉积序列 (uniformly dipping sequence of sediments)**。

**任务**：
- **(a)** 在**页岩 (shale) 与灰岩 (limestone) 之间的接触面**上绘制地层等高线，并确定该套沉积岩的 **strike、dip、dip direction**。
- **(b)** 用提供的**方格纸**沿 **A–B** 绘制**垂直剖面**。
- **(c)** 用你的剖面构建一张**地层柱状图 (stratigraphic column)**，按**正确层序**列出各沉积单元及其**真厚度 (true thicknesses)**；画在方格纸上**紧邻剖面**处。

**关键点**：
- 因为整套地层**产状一致**，只需为**一个**接触面求出产状，即可**外推到所有接触面**（各接触面的地层等高线互相平行、走向倾角相同，只是位置不同）。
- **(c) 的做法（📎）**：
  1. 在剖面上，对每一个岩层，沿**铅垂方向**量出它的厚度 → 这是 **V（垂直厚度）**；
  2. 用 **t = V · cos δ** 换算为**真厚度 t**（δ 为 (a) 求得的倾角）；
  3. 地层柱状图**竖直画**，**最老的在底、最新的在顶**（Law of Superposition），每层的高度按 t 的比例绘制，并标注岩性名称、花纹与厚度数值。
- ⚠️ 剖面必须**无垂向夸大**，否则量出的 V 不真实。

#### **Exercise 3 — 含角度不整合的地质图剖面**

**方法背景（原文）**：到目前为止（如 Ex.2），我们画地层等高线的地图上，**所有不同时代的地层产状相同**。但现实中不同的地层序列可能有**不同的产状（不同走向与倾角）**——**只要图上存在角度不整合，情况必然如此**。

**图面情境**：图上有**两套地层**：**E 与 F** **不整合覆盖**在 **C 与 D** 之上；**不整合面位于 E 的底部 (at the base of E)**。

**任务（6 小问）**：

1. 在图上**识别并标注不整合面**。
2. 等高线所指示的**主要地形特征**是什么？
3. 从 **E 与 F 接触面的形态**推断出的**倾向 (dip direction)** 是什么？
4. 找到图上 **C 的层理走向/倾角符号 (bedding strike/dip symbol)**，其**走向的大致方位**是什么（用 N–S、NE–SW、E–W 等表示）？**倾向**是哪个方向？
5. 沿 **A–B** 线绘制**垂直剖面**：
   - **a.** 先为 **E–F 接触面**绘制地层等高线（**假定为平面倾斜面 plane-dipping surface**），并把该接触面标到剖面上；
   - **b.** 再为 **C–D 接触面**绘制**另一套**地层等高线，并把它们 **"project"（投影）** 到剖面上——做法是：把地层等高线**延长至 A–B 线**，然后在剖面上**对应的位置与高程**处打点，据此把 **C–D 接触面画成剖面上的一条线**；
   - **c.** 完成剖面：给每一层标注**字母代号**与**花纹 (ornamentation)**。
6. 给出 **E 与 F** 以及 **C 与 D** 的 **strike/dip 与 dip direction**。

**解题要点**：
- **两套地层必须分别处理**——这是本练习相对 Ex.1、Ex.2 的核心跃迁。E–F 一套地层等高线，C–D 另一套；它们的走向、倾角、间距都不同。
- 📎 **不整合面本身在剖面上的画法**：不整合面 = E 的底面。它把 C、D 的层面**截切**掉——剖面上 C–D 接触线应**终止于不整合面**，不得穿过到不整合面之上。E、F 则平行于不整合面之上堆叠。这条"削截关系 (truncation)"是判读角度不整合的最直接图面证据。
- 📎 **第 (2) 问的思路**：看等高线的闭合与 V 形——等高线闭合成同心圈且中心高程最高 → **山丘 (hill)**；等高线呈 V 形且 V 尖指向高程增大方向 → **河谷 (valley)**（Week 2 讲义已指出"topographic contours V upstream"）；等高线密集平行 → **陡坡**；等高线呈舌状向低处凸出 → **山脊 (ridge/spur)**。
- 📎 **第 (3) 问的思路**：用 **V 字法则**——接触界线在穿越河谷时形成 V，**V 的尖端指向倾向**；或先画地层等高线，由高指向低即为倾向。
- 📎 **第 (4) 问的思路**：图上的 strike/dip 符号是"长横线 + 短垂线 + 数字"，**长横线的方位 = 走向**，**短垂线所指一侧 = 倾向**，数字 = 倾角。用图上北方向读出长横线是 N–S / NE–SW / E–W / NW–SE 中的哪一种。

#### 常见错误（下午场）

- ❌ **连错点**：把不在同一高程的交点连成一条地层等高线。务必逐点核对高程标注。
- ❌ **把地形等高线当成地层等高线**（或反之）。建议**两者用不同颜色/线型**，并给每条地层等高线**写上高程数字**。
- ❌ **量倾角时不沿垂直于地层等高线的方向量** → 得到的是视倾角，偏小。
- ❌ **忘记用比例尺把图上距离换算为实地距离**，直接用 cm 代入 tan → 倾角完全错误。
- ❌ **倾向搞反**：倾向永远是**从高地层等高线指向低地层等高线**（即"往下倾的那一侧"）。另一条独立校验：**平面倾斜层的倾向由老地层指向新地层**（用地层柱状图判断新老）。
- ❌ **剖面垂向夸大**：垂直比例尺与水平比例尺不一致 → 剖面上的倾角与厚度全部失真，t = V cos δ 失效。
- ❌ **把 V（垂直厚度）当成真厚度上报** → 系统性高估厚度（倾角越大高估越多）。
- ❌ **Ex.3 中只画一套地层等高线**，把 C–D 也按 E–F 的产状外推 → 完全错误，因为不整合两侧产状不同。
- ❌ **Ex.3 剖面上让 C–D 的界线穿过不整合面** → 违背"老地层被削截"的几何关系。
- ❌ 地层柱状图**层序颠倒**（把新的画在底部）——须遵守 Law of Superposition：**老在下、新在上**。

| # | 难点 | 要害 |
|---|---|---|
| 1 | **稀释因子** | 2 ml→10 ml 是 **×5**；1 ml→10 ml 是 **×10**。忘乘 = 结果差 5–10 倍，Defra 分级直接判错。**这是本次实践唯一的计算，也是最容易丢分的地方。** |

| 10 | **交叉污染** | 取样勺、比色皿、压片棒、洗涤剂（含磷！）都可能污染；磷分析对污染极其敏感。 |

### 下午场

| # | 难点 | 要害 |
|---|---|---|
| 1 | **stratum contour 的定义** | = 地质面与**地形等高线**的**交点**连线，不是地质面本身的形状线。定义不清就无从下手。 |
| 2 | **平面倾斜层的三个判据** | 地层等高线**直、平行、等距**。用它自检作图是否正确。 |
| 3 | **真倾角 vs 视倾角** | 只有沿**垂直于走向（即沿倾向）**测量才得真倾角；任意方位的剖面给出的都是视倾角，且**视倾角 ≤ 真倾角**。 |
| 4 | **t / V / w 三者关系** | **t = V cos δ**（📎），**t = w sin δ**（📎，需地面水平）。**t 是唯一有地质意义的厚度**。 |
| 5 | **角度不整合 = 多产状域** | 不整合两侧**必须各画一套**地层等高线。这是本周相对上周最大的方法跃迁。 |
| 6 | **削截关系** | 剖面上，老地层的界线必须**止于不整合面**。 |
| 7 | **"project onto cross-section" 的具体含义** | 把地层等高线**延长至剖面线 A–B**，读出交点的**位置 + 高程**，再在剖面上按对应位置与高程打点连线。这是把平面信息转成剖面信息的核心机械动作。 |
| 8 | **比例尺与垂向夸大** | 剖面必须 1:1（垂直比例尺 = 地图水平比例尺）。 |
| 9 | **倾向的两种独立判定** | (i) 地层等高线由高→低；(ii) **老 → 新**（配合地层柱状图）。两法互相校验。 |
| 10 | **V 字法则的例外** | **水平层**（露头平行于等高线）与**直立层**（露头笔直穿切等高线）**不适用** V 字法则。 |

| Three-point problem | 三点问题 | 由同一接触面上三个已知点确定其产状并外推界线的方法（Week 2 引入） |
| Cross-section (vertical section) | 剖面（垂直剖面） | 沿指定测线的垂直切面图，同时展示地形与地质界面 |
| Topographic profile | 地形剖面 | 只画地形起伏的剖面（Week 2 已练） |
| Apparent dip | 视倾角 | 沿非倾向方向的剖面上量得的倾角，永远 ≤ 真倾角 |
| True thickness (t) | 真厚度 | 垂直于层理量得的顶底距离，唯一有地质意义的厚度 |
| Vertical thickness (V) | 垂直厚度 | 剖面上沿铅垂方向量得的厚度，总是 ≥ t |
| Outcrop width (w) | 露头宽度 | 地层在地表/地图上出露的宽度 |
| Stratigraphic column | 地层柱状图 | 按正确层序（老在下、新在上）与真厚度绘制的岩层竖直示意图 |
| Unconformity | 不整合 | 地层记录中代表沉积间断/剥蚀的界面 |
| Angular unconformity | 角度不整合 | 老地层先被掀斜、剥蚀成沉积面，其上再沉积产状不同的新地层 |
| Truncation | 削截 | 不整合面把下伏地层界线切断的几何关系 |
| Plane-dipping surface | 平面倾斜面 | 假定为理想平面的倾斜地质面，其地层等高线直、平行、等距 |
| Uniformly dipping sequence | 均匀倾斜序列 | 全套地层产状一致的沉积层组 |
| V-rule ("V's" in valleys) | V 字法则 | 倾斜接触面穿越河谷时形成 V，**V 尖指向倾向**；水平层与直立层例外 |
| Law of Superposition | 地层叠覆律 | 未倒转时，下面的地层老、上面的地层新 |
| Original Horizontality | 原始水平律 | 沉积物最初近似水平沉积，现今倾斜是后期构造作用的结果 |
| Ornamentation | 岩性花纹 | 剖面/柱状图上表示岩性的标准图案 |
| Mudstone / Sandstone / Shale / Limestone | 泥岩 / 砂岩 / 页岩 / 灰岩 | 本周练习涉及的四种沉积岩 |
| BGS / Ordnance Survey | 英国地质调查局 / 英国地形测量局 | 分别发布英国地质图与地形图的机构 |
| Borradaile (2014) | 《Understanding Geology Through Maps》 | 本周及上周多数图件的出处教材 |
