## 二、核心概念

### 上午场：酸、碱、缓冲液与解离常数

#### 1. 酸的定义与 pH

- **酸 (acid)**：溶于水（水溶液）时**给出氢离子 H⁺** 的物质（讲义采用的是 Arrhenius/Brønsted 式的简明定义）。
- 溶液的 pH 与氢离子浓度的关系：

  **pH = −log₁₀[H⁺(aq)]**　　（`[X]` 表示「物质 X 的浓度」）

#### 2. 强酸 vs 弱酸——「解离程度」

- **强酸 (strong acids)**：在溶液中**几乎完全解离**。因此解离方程用**单向反应箭头**（→）表示，代表过程基本进行到底。例：
  - HCl(aq) → H⁺(aq) + Cl⁻(aq)
  - H₂SO₄(aq) → 2H⁺(aq) + SO₄²⁻(aq)
  - （讲义列举的强酸：HCl、H₂SO₄、HNO₃）
- **弱酸 (weak acids)**：在溶液中**只部分解离**，因此用**可逆反应箭头**（⇌）。通式（酸写作 HA）：

  **HA ⇌ H⁺(aq) + A⁻(aq)**

  - 例 1：**乙酸 / 醋酸 (ethanoic / acetic acid)**，约 **0.4%** 的酸分子发生解离
    CH₃COOH(aq) ⇌ H⁺(aq) + CH₃COO⁻(aq)
  - 例 2：**碳酸 (carbonic acid)**，二元酸 (**diprotic acid**)，分两步解离
    H₂CO₃(aq) ⇌ H⁺(aq) + HCO₃⁻(aq)
    HCO₃⁻(aq) ⇌ H⁺(aq) + CO₃²⁻(aq)

- **关键概念辨析（讲义特别加感叹号强调）**：
  > 「Note that pH is affected by both acid **strength** AND **concentration**! A dilute solution of a strong acid can still have a relatively high pH.」
  >
  > **pH 同时受酸的「强度」与「浓度」影响**。强酸的稀溶液 pH 仍然可以相对较高（即不那么酸）。所以**不能用 pH 直接判断酸的强弱**——必须固定浓度比较，或者直接用平衡常数来量化。

- **酸的「强度」用平衡常数量化**：这个常数就是**酸解离常数 (acid dissociation constant) Ka**。

#### 3. Ka 与半中和点——本次实验的理论核心

对通式弱酸 HA ⇌ H⁺ + A⁻，平衡常数为

  **Ka = [H⁺][A⁻] / [HA]**

（原 docx 中此式为图片，转换丢失；此处按标准定义补回。）

**为什么滴定曲线能测 Ka？** 讲义的推理链：

1. 弱酸的 Ka 可以从**滴定曲线 (titration curve)** 求得——曲线是「向酸中逐次加入碱、每次记录 pH」画出来的。
2. Ka 通过定位曲线上的**半当量点 / 半中和点 (half equivalence point of neutralisation)** 来确定。
3. 在半中和点，**恰好一半的酸分子 HA 已经与碱反应生成 A⁻**，因此 **[HA] = [A⁻]**。
4. 把 [HA] = [A⁻] 代回 Ka 表达式，二者约掉：

   **Ka = [H⁺] × ([A⁻]/[HA]) = [H⁺] × 1 = [H⁺]**

5. 又因为 pH = −log₁₀[H⁺]，取反函数得 **[H⁺] = 10^(−pH)**。
6. 代入第 4 步：

   **Ka = 10^(−pH at half neutralisation)**　　也就是 **pKa = pH（半中和点）**

这就是整个上午场实验的逻辑闭环：**只要从曲线上读出半中和点的 pH，直接取 10 的负次方就是 Ka**，完全不需要知道酸的准确浓度。

#### 4. 缓冲液 (buffer) 与缓冲区

- **缓冲液的定义（讲义在校准步骤前的 NOTE 中给出）**：
  > 「A buffer solution maintains an (almost) constant pH when small volumes of acid/alkali are added to it.」
  > **缓冲液在加入少量酸/碱时能维持（近乎）恒定的 pH。**
- **滴定曲线上的缓冲区**：在半中和点附近，pH 在相当大的一段加入体积范围内**几乎保持不变**（只是极轻微上升）。这就是**缓冲区 (buffering zone)**——此处弱酸 HA 与其**共轭碱阴离子 (conjugate base anion) A⁻** 的量几乎相等，体系表现为缓冲液。
- **用 Le Chatelier 原理解释缓冲作用**（讲义要求作答，答案如下）：

  以 CH₃COOH(aq) ⇌ H⁺(aq) + CH₃COO⁻(aq) 为例，此时 HA 与 A⁻ 浓度都相对较高。

  **(a) 加入少量酸 (H⁺) 时**
  - 预期效果：加 H⁺ 应使 pH 下降。
  - 缓冲机制：H⁺ 浓度上升 → **平衡向左移动**，H⁺ 与共轭碱阴离子 CH₃COO⁻ 反应：
    **H⁺(aq) + CH₃COO⁻(aq) → CH₃COOH(aq)**（即解离的逆过程）
  - 结果：该过程**移除了 H⁺**，因此 **pH 的下降被抵抗住**。

  **(b) 加入少量碱 (OH⁻) 时**
  - 预期效果：加 OH⁻ 应使 pH 上升。
  - 缓冲机制：加入的 OH⁻ 与方程右侧的 H⁺ 反应：**OH⁻ + H⁺ → H₂O**。H⁺ 被移除 → **平衡向右移动** → 弱酸分子 CH₃COOH 继续解离、**释放出 H⁺**。
  - 结果：**pH 的上升被抵抗住**。

  记忆要点：**缓冲液靠「储备的一对共轭酸碱」双向吃掉外来的 H⁺ 或 OH⁻**——HA 是对付外来 OH⁻ 的储备，A⁻ 是对付外来 H⁺ 的储备。二者浓度相当时缓冲能力最强，这正好就是半中和点。

### 下午场：偏光显微镜与薄片中矿物的光学性质

#### 0. 总纲

> 「Minerals have a **regular internal atomic arrangement** that affects many of their properties, including their optical properties. Some of these properties **vary with direction** (because the internal crystal structure varies with direction), while other properties are apparently **unaffected by orientation**.」

矿物具有**规则的内部原子排列**，它决定了包括光学性质在内的许多性质。**有些性质随方向变化**（因为内部晶体结构随方向变化），**另一些则似乎不受取向影响**。——这条「哪些性质与取向有关、哪些无关」的区分，是整节课的主线。

| 性质 | 是否随晶体取向变化 | 备注 |
|---|---|---|
| 突起 relief | **基本不变**（可视为该矿物的常数） | 唯一常见例外是**方解石 calcite** |
| 颜色 colour | 若有**多色性**则变 | 无多色性的矿物颜色不随取向变 |
| 解理 cleavage 的**可见性** | **变** | 取决于切面方向；一组解理只在近垂直于解理的切面才可见 |
| 是否均质 isotropic | 由矿物本性决定，但**非均质矿物在光轴方向切面上表现为均质** | 见下 2a |
| 干涉色 interference colour | **强烈依赖取向** | 单个矿物的众多颗粒会呈现一个**色序范围** |

#### 1. 显微镜部件与用途（本次要用到的四件）

| 部件（英文） | 中文 | 用途 |
|---|---|---|
| **The analyser** | 检偏镜 | **拉出 (open/out) = 单偏光 PPL**；**推入 (closed/in) = 正交偏光 XPL** |
| **The focus control** | 调焦旋钮 | 使像清晰 |
| **The rotating stage** | 旋转载物台 | 在不同角度观察样品（观察多色性、消光的关键动作） |
| **The substage iris diaphragm** | 载物台下光阑（虹彩光阑） | **控制透过薄片的光量、改变反差**——把它**关小**可以增强突起、解理与裂纹的可见度 |

> 补充理解：单偏光下只有**起偏镜 (polariser)** 在位；正交偏光下**起偏镜与检偏镜同时在位**（二者振动方向互相垂直）。

#### 2. 单偏光 (PP) 下的性质

**(a) 突起 SURFACE RELIEF**
- **成因**：矿物的**折射率 (refractive index, R.I.)** 与**环氧树脂 (epoxy)** 折射率之差的函数。环氧树脂 **R.I. = 1.54**，它覆盖薄片表面并作为盖玻片的胶。
- **判读**：
  - **低突起 low relief**（R.I. 接近 1.54）：表面**平滑、不显眼**。
  - **高突起 high relief**（R.I. 约 **1.6 – 1.8**）：表面**粗糙、呈磨砂或麻点状**，颗粒有**深色轮廓**。
- **技巧**：细微的突起差异可以通过**关小载物台下光阑**来增强。
- **重要例外**：虽然大多数矿物的 R.I. 严格来说依赖于光线穿过矿物的方向，但这在突起上**几乎观察不到**，因此突起可以视为某一矿物的**常数**——**方解石 (calcite) 是唯一常见的例外**（它的突起随台面旋转明显变化，即闪突起）。

**(b) 颜色 COLOUR 与多色性 PLEOCHROISM**
- 薄片中大多数矿物是**半透明 (translucent)** 的；少数矿物能吸收或反射到达它的全部光线，呈**黑色**，称为**不透明矿物 (opaque)**。
- 半透明矿物中许多是**无色 (colourless)** 的；某些矿物优先吸收特定波长的光，剩余光谱进入眼睛，于是呈现**颜色**。
- **多色性 (pleochroism)**：颜色（强度和/或色调）**随矿物取向而变化**。本质是矿物在不同方向上有**不同的吸收特性**。表现为两种可观察现象：
  1. **同一矿物不同颗粒之间的颜色差异**（因为各颗粒取向不同）；
  2. **旋转载物台时单个颗粒的颜色变化**。
- **诊断价值**：「突起 + 颜色」的组合通常足以**区分岩石薄片中的各种矿物组分**，不过要精确鉴定往往还需进一步测试。

**(c) 解理 CLEAVAGE**
- **成因**：许多矿物倾向沿特定平面平整地破裂；这与**内部原子结构**有关，是这些面**跨面键强较弱**的体现。
- **诊断价值**：解理面与**晶体的内部对称性**相关，且**不受决定晶体外形的外部条件影响**，因此是很好的诊断性质（外形会因生长环境而变，解理不会）。
- **判读**：发育良好的解理方向在薄片中通常表现为**等间距、平行或近平行的裂缝**（细的黑色平行线）。
  - 有**两组或更多解理**的矿物：**大多数颗粒都能看到某组解理的痕迹**，但只有**少数取向有利的颗粒**才能显示完整的解理图案。
  - 只有**一组解理**的矿物：只有在**大致垂直于该解理**切开的切面上才能看到它。
- **与裂纹 (fractures) 的区别**：**较不规则的裂缝或裂纹**可以**完全独立于解理**出现。（判读陷阱，见第六节。）
- **技巧**：解理与裂纹图案同样可以通过**关小载物台下光阑**来突出。

#### 3. 正交偏光 (CP / XP) 下的性质

**(a) 均质性 ISOTROPY 与非均质性 ANISOTROPY**
- **光学均质 (optically isotropic)**：非晶质物质（**玻璃 glass、环氧树脂 epoxy** 等）以及少数矿物。表现为**正交偏光下全黑，且旋转载物台时保持全黑**。
- **两个重要的辨识陷阱（讲义明确点出）**：
  1. 大多数薄片都含有**孔洞 (holes)**——可能是岩石的原生特征，也可能是磨片过程中产生的。它们被**环氧树脂填充**，因此**表现为均质（全黑）**；但可以靠**零突起 (zero relief)** 把它们与真正的矿物区分开。
  2. **不透明矿物本来就是黑的**，因此**无法判断它是均质还是非均质**。
- **大多数矿物是非均质 (anisotropic) 的**，在正交偏光下一般显示**彩色外观**（= 干涉色）。
- **消光 (extinction)**：旋转载物台时，这些颜色会**每隔 90° 被「熄灭」一次**（变黑）。这是**所有非均质晶体的通性**。
- **干涉色的成因——双折射 (double refraction)**：光进入非均质矿物后**分裂成两束光线**，它们在晶体中走**略微不同的路径**而产生**相位差 ('out-of-phase')**，穿过检偏镜后发生**光学干涉**，于是产生干涉色。这种分裂就叫双折射。
- **光轴 (optic axes)**：所有非均质矿物都含有**一个（单轴 uniaxial）或两个（双轴 biaxial）表现为均质行为的方向**，称为光轴。光沿这些方向穿过晶体时**不发生双折射**，因而**不能产生干涉色**。
  - **推论（非常重要）**：**垂直于光轴切开的晶体切面会表现得像均质体一样——正交偏光下全黑且旋转不变**。所以「一直全黑的颗粒」不一定是均质矿物，也可能是非均质矿物的特殊取向切面。

**(b) 干涉色 INTERFERENCE COLOURS**
- 给定矿物的**每个颗粒都有自己特定的干涉色**，取决于**矿物种类 + 晶体切面的取向**（并假定**薄片厚度恒定**）；但把该矿物的所有颗粒**合起来看**，会呈现出**一段颜色范围**。
- 这些颜色构成一个**递升序列**，称为 **Newton 色序 (Newton's Scale)**：从灰、白、浅黄，经过**反复出现的鲜艳色序**，再进入**较为褪淡的颜色**。
- **诊断规则**：对某一矿物而言，**这一序列中的最高色才是诊断性的**——**最高干涉色 (maximum interference colour)**；但该矿物的**大多数颗粒会显示序列中较低的颜色**。
  - 实操含义：判读时要**扫视整张薄片、找该矿物出现的最高色**，而不能拿随便一个颗粒的颜色下结论。
- **三大类干涉色（速查）**：

  | 类别 | 英文 | 具体颜色 |
  |---|---|---|
  | i) 低 | **LOW** | 灰、白、浅黄 (greys, white and pale yellows) |
  | ii) 中 | **INTERMEDIATE** | 鲜艳的红、蓝、绿 (bright reds, blues and greens) |
  | iii) 高 | **HIGH** | 带粉红或绿色调的浅灰与浅褐 (pale greys and browns with pink or green tinges) |

- **两条警告**：
  1. 干涉色**不可与 1b 中的自然颜色（体色）混淆**；
  2. 对于**本身颜色很深的矿物**，其干涉色会**被体色所改变（modified）**。
- **Michel-Levy 干涉色图表 (Michel-Levy colour chart)**：即 Newton 干涉色序的标准图表，用来对照确定某矿物的最高干涉色。

**(c) 其他在实操中出现的现象**
- **双晶 (twinning)**：在 R56 中，一个低干涉色矿物呈**斑马条纹状 (zebra-striped) 外观**，这就叫双晶。
- **环带 (zoning)**：在 VT 中，一个较浅色的高突起矿物有**绿色的边缘 (rims of green)**，成因是**晶体外部与其余部分的成分不同**——这种性质称为环带。（CFL 中那个均质矿物也被描述为「zoned in shades of purple」，即紫色调环带。）

| **% error = ((accepted − measured) / accepted) × 100** | 由答案示例反推 | 见下方注意 |

> **百分误差公式的注意点**：答案文件的示例算式是
> `% error = ((1.8×10⁻⁵ − 5×10⁻⁵) / 1.8×10⁻⁵) × 100 = −178%`
> 即分子写成「**公认值 − 实测值**」。这与常见写法「(实测 − 公认)/公认」**符号相反**。跟本课作答时按讲义这个写法走；但要意识到它导致的符号方向：**实测值偏大 → % error 为负**。

### 3.2 上午场：本实验的化学计量核对（自行推导，用于检验结果合理性）

- 酸：0.050 M 乙酸，取 **2 × 25.0 cm³ = 50.0 cm³** ⟹ n(CH₃COOH) = 0.050 × 0.0500 = **2.50 × 10⁻³ mol**
- 碱：0.100 M NaOH，1:1 反应（CH₃COOH + NaOH → CH₃COONa + H₂O）
- **理论当量点体积** = 2.50 × 10⁻³ / 0.100 = **25.0 cm³**
- **理论半当量点体积 = 12.5 cm³**

> 对照示例粗滴定数据：pH 突跃发生在 26.0 → 28.0 cm³ 之间，当量点约在 **27 cm³**，比理论值 25.0 cm³ 偏大约 2 cm³——这本身就是一条误差线索（见第六节）。

1. 突跃垂直段的中心 ⟹ 当量点体积 ≈ **27 cm³**
2. 半当量点体积 = 27 / 2 = **13.5 cm³**
3. 在曲线上读该体积对应的 pH ⟹ **pH ≈ 4.3**（表中 14.0 cm³ 处正是 4.3）

**理想结果**：
- 半中和点 pH **应约为 4.75**（讲义的 hint）
- **Ka = 10^(−4.75) = 1.8 × 10⁻⁵ mol dm⁻³**
- 这也正是**乙酸 Ka 的公认值 (accepted value) = 1.8 × 10⁻⁵ mol dm⁻³**

### ★ 上午场：P01 — Acids, bases and buffers（测定乙酸的 Ka）

> **「To measure the dissociation constant, Ka, of acetic acid」——测定乙酸的解离常数 Ka。**

#### 5.4 Part 2：绘制滴定曲线（逐步）

1. 小心地把**滴定管架与滴定管移到地面上**，在滴定管顶部放上漏斗。（安全：装填时液面低于眼睛高度）
2. 在滴定管下放一只空烧杯，**打开活塞**，先用**去离子水**、再用 **0.100 M NaOH** 冲洗滴定管。冲洗液倒入水槽弃去。
3. 关闭活塞，小心地把 0.100 M NaOH 加到**超过顶部刻度线**，再放液，**确保活塞内无气泡**。反复补/放液，使**弯月面下缘 (bottom of the meniscus) 恰在 0.00 cm³**。
4. 取下漏斗，小心地把滴定管架**放回实验台**。
5. 用 **25 cm³ 移液管（配移液辅助器！）**转移**两份 25.0 cm³** 的 0.050 M 乙酸到一只洁净的 **250 cm³ 烧杯**中，**共 50.0 cm³**。
6. 把烧杯放到**磁力搅拌器**上、滴定管正下方，放入**磁力搅拌子**。**用最低档启动搅拌**——既保证温和混合，又**尽量降低损坏 pH 探头的风险**。
7. 向烧杯中的乙酸加入 **2–3 滴酚酞**（终点变色：无色 → 粉红，所以初始无色）。
8. 把探头放入乙酸溶液，**确保球泡完全浸没**，并**避开搅拌子**。等读数**稳定后**把 pH 记入结果表。
9. **缓慢打开活塞加入 2.0 cm³ NaOH**，关闭活塞，记录 pH。
10. 继续以 **2.0 cm³ 为一份**加入 NaOH，在**累计体积**旁记录 pH，直到 **NaOH 过量**（表现为**稳定的高 pH，大约 pH = 12**）。**仔细注意哪一次加入对应终点**——pH 急剧变化、且酚酞由无色变为粉红的位置。
11. **重复滴定**，但在**上一次滴定中终点急剧 pH 变化开始之前**（可根据上一次的结果表预判），改为**每次加入 0.20 cm³** NaOH，直到急剧 pH 变化完成，然后再改回 **2.0 cm³** 一份继续加，直到 NaOH 过量（达到稳定高 pH）。
12. **重复第 11 步**，以获得**一致的结果 (concordant results)**——**理想的一致性标准是终点体积相差在 ±0.10 cm³ 以内**。

> **两阶段滴定策略的意义**：第 10 步的「粗滴定 (rough titration)」只是为了**定位终点大致落在哪里**；第 11–12 步的「细滴定」在终点附近把步长从 2.0 cm³ 缩小到 0.20 cm³，从而把突跃段的曲线**分辨率提高 10 倍**，当量点才能读得准。

#### 5.5 数据分析（Data Analysis，逐题）

**① 求每个 NaOH 体积对应的平均 pH**
- 对每一个加入体积，计算**平均 pH**，**剔除任何异常结果 (anomalous results)**。

**② 作滴定曲线**
- **y 轴 = 平均 pH，x 轴 = 加入的 NaOH 体积**，用**平滑曲线**连点（**不是折线，不是直线拟合**）。

**③ 找当量点 (equivalence point)**
- 位置 = **曲线垂直段的中心 (centre of the vertical section of the curve)**。
- 在图上**标出**，并从 x 轴读出**当量点对应的 NaOH 体积**。

**④ 找半当量点 (half-equivalence point)**
- **把当量点的 NaOH 体积除以 2**，得到半当量点体积，在图上定位该体积。

**⑤ 读出半当量点的 pH**
- 讲义提示 (hint)：**应约为 pH 4.75**。

**⑥ 计算乙酸的 Ka**（答案）
- **Ka = 10^(−4.75)**
- **Ka = 1.8 × 10⁻⁵ mol dm⁻³**

**示例（粗数据）对照**：讲义提供了一张仅用步骤 1–10 的「很粗糙」数据集画出的示例图 (exemplar graph)：半中和 pH = **4.3** ⟹ **Ka = 10⁻⁴·³ = 5 × 10⁻⁵ mol dm⁻³**。

**⑦ 与公认值比较，算百分误差**（答案）
- 乙酸 Ka 的**公认值 = 1.8 × 10⁻⁵ mol dm⁻³**。
- 以上面示例的 5 × 10⁻⁵ 为例：
  **% error = ((1.8×10⁻⁵ − 5×10⁻⁵) / 1.8×10⁻⁵) × 100 = −178%(!)**
- 讲义评语：「Hopefully the %error is smaller than this!」

**⑧ 误差来源分析**（答案，**按误差方向组织，务必掌握这个思路**）

先建立**方向判据**：因为 **Ka = 10^(−pH)**，所以 **pH 读得偏低 ⟹ Ka 偏大；pH 读得偏高 ⟹ Ka 偏小**。

| 结果偏向 | 对应的半中和 pH | 讲义给出的可能原因 |
|---|---|---|
| **Ka > 1.8×10⁻⁵**（偏大） | 半中和 pH **< 4.75** | **标准溶液（NaOH）太稀**（滴定管被污染/未用 NaOH 润洗？）／**酸液浓度偏高**／**pH 探头未正确校准** 等 |
| **Ka < 1.8×10⁻⁵**（偏小） | 半中和 pH **> 4.75** | （讲义只给出方向判据，未列具体原因——按对称逻辑即：NaOH 偏浓、酸液偏稀、探头校准偏差方向相反等） |

> **答题模板**：先说「我的 Ka 比公认值大/小」→ 换算成「说明我读到的半中和 pH 比 4.75 低/高」→ 再列出能造成该方向 pH 偏差的具体操作原因。**不要泛泛列一堆误差，要与方向匹配。**

**⑨ 你能做哪些改进？(What modifications could you make to improve the experiment?)**
- **答案文件在此处留空，未给出参考答案。** 结合方法本身，合理的方向包括（以下为基于讲义内容的推演，非原文）：在整个突跃段全程使用 0.20 cm³ 甚至更小的步长；增加重复次数并严格执行 ±0.10 cm³ 一致性判据；用滴定管前充分用待装液润洗；每次实验前重新校准 pH 探头并检查缓冲液未过期/未污染；控制并记录温度（Ka 是温度依赖的平衡常数）；用数据采集器自动记录 pH 以获得连续曲线，或改用一阶导数 dpH/dV 峰值法客观定位当量点，避免目视判读垂直段中心的主观性。

#### 5.6 结论

用滴定曲线的半中和点法可以在**不需要精确知道酸浓度**的前提下测定弱酸的 Ka；乙酸的公认值为 **1.8 × 10⁻⁵ mol dm⁻³**（pKa = 4.75）。同时本实验直观展示了**缓冲现象**：半中和点附近曲线最平坦，正是共轭酸碱对浓度相当、缓冲能力最强之处。

### ★ 下午场：Introduction to the polarising microscope（薄片光学性质入门）

#### 5.7 目的

三条（原文）：
1. 学会**安全使用岩相显微镜**；
2. 认识矿物在 **PPL** 下的光学性质（突起、颜色、多色性、解理）与 **XPL** 下的性质（均质/非均质行为、干涉色）；
3. **练习素描**薄片中的特征。

#### 5.8 器材

偏光显微镜（关键部件：**检偏镜 analyser、调焦 focus control、旋转载物台 rotating stage、载物台下光阑 substage iris diaphragm**）、一套编号薄片（RHB、EG、15216、NH、VT、CFL、E302、R56、R25/SK、PC37）、**Michel-Levy 干涉色图表**、绘图纸与铅笔。

#### 5.9 操作流程与逐片任务

**总体流程**：先做 **PP 部分（第 1–6 题：突起 → 颜色/多色性 → 解理）**，再做 **CP 部分（第 7–10 题：均质性/非均质性 → 干涉色）**，最后做**综合题（第 11–12 题）**。

**详细任务清单见「三、公式与图表」§3.7 的对照表**（内容完整，不在此重复）。这里补充操作要领：

- **观察突起的标准动作**：看不清就**关小载物台下光阑**——高突起矿物立刻从低突起矿物中「跳出来」，轮廓变黑、裂纹凸显。这也是**看解理的标准动作**。
- **观察多色性的标准动作**：选一颗**颜色明显、形状规整（如长方形、长条形）**的晶体，**慢慢旋转载物台 360°**，注意颜色**强度与色调**的变化，记录**最深**与**最浅**两个状态。素描时按讲义要求把**长轴摆成 E–W**，旋转 90° 再画一次，便于对照。
- **描述颜色的规范**：**除色相外必须给明暗程度**——「dark / light / something in between」。例：dark blue-green ↔ pale yellow-green。
- **区分解理与裂纹**：**解理 = 等间距、平行/近平行的规则细线**；**裂纹 = 不规则、无固定间距与方向**。同一颗晶体上两者可以并存（VT 中的淡色矿物即如此）。
- **观察消光的标准动作**：**检偏镜推入**，慢慢旋转载物台，看颗粒是否**每 90° 变黑一次**。若某颗粒**全程不变黑**，先别急着判为均质矿物——先看它在 PPL 下**是否有突起**（排除孔洞）、**是否透明**（排除不透明矿物）、以及**同一矿物的其他颗粒是否有干涉色**（排除垂直光轴切面）。
- **确定最高干涉色的标准动作**：**扫视整张薄片**，找该矿物出现的**最高**干涉色，再与 **Michel-Levy 色表**比对。**单个颗粒的颜色没有诊断意义。**
- **第 9 题的一个细节**：素描 R56 的颗粒时要求把**检偏镜拉出 (analyser out)**——因为要记录的是**突起、解理/裂纹**这些 **PPL 性质**，不是干涉色。

#### 5.10 结果记录方式

本次实践的产出**主要是素描 (sketches) 与文字描述**，不是数值数据。需要交付的素描共 6 处：
1. **RHB**：几颗高突起颗粒 + 其裂纹；
2. **15216**：同一颗褐色多色性晶体的**两幅图**（最深褐 / 最浅褐），第 5 题再**在其上补画解理线**；
3. **NH**：长轴 E–W 的长条绿色晶体一幅 + 旋转 90° 后一幅，各附**颜色描述（色相 + 明暗）**；
4. **VT**：一颗菱形晶体，显示**两组解理面**；
5. **R56**：几颗颗粒（**检偏镜拉出**），注明**突起**与**有解理还是裂纹**；
6. **R25 / SK**：一小块区域，**标注**哪个是高干涉色、哪个是低干涉色。

外加两项文字描述：**EG**（高突起与低突起矿物的全部光学性质）、**PC37**（有几种矿物 + 各自光学性质）。

#### 5.11 结论

本周只建立「**性质的观察与描述体系**」，不做矿物定名。掌握的判读链条是：
**PPL** → 突起（高/低）→ 颜色（不透明/有色/无色）→ 多色性（有/无、色变范围）→ 解理（几组、间距、与裂纹区分）；
**XPL** → 均质还是非均质（含四类「黑」的排除法）→ 干涉色等级（低/中/高，取**最高**）→ 特殊现象（双晶、环带）。
**下周将用这套体系去鉴定常见造岩矿物 (common rock-forming minerals)。**

## 六、易错点 / 重点难点

### 上午场（操作与计算）

| # | 坑 | 说明与对策 |
|---|---|---|
| 1 | **把 pH 当成酸强度的直接度量** | 讲义特意强调：**pH 同时取决于强度和浓度**。强酸的稀溶液 pH 可以不低。判断强弱必须用 **Ka**。 |
| 2 | **强酸/弱酸方程箭头写错** | 强酸用**单向箭头 →**（完全解离），弱酸用**可逆箭头 ⇌**（部分解离）。原 md 因格式转换把 → 显示丢失，别被误导。 |
| 3 | **把当量点当成半当量点直接读 pH** | 必须**先定当量点体积 → 除以 2 → 回到曲线上读那个体积对应的 pH**。当量点的 pH（本体系约 8–9，因生成 CH₃COO⁻ 水解）与 pKa 无关。 |
| 4 | **当量点定位取错位置** | 讲义规定取**垂直段的中心 (centre of the vertical section)**，不是突跃开始处，也不是酚酞刚变色的那一滴。 |
| 5 | **误差方向搞反** | **Ka = 10^(−pH)** 是**减函数**：pH 偏低 → **Ka 偏大**；pH 偏高 → Ka 偏小。答误差题**必须先把 Ka 的偏向翻译成 pH 的偏向**。 |
| 6 | **% error 公式写法** | 讲义用的是 **(公认 − 实测)/公认 × 100**，与常见写法符号相反。跟本课作答就按讲义。 |
| 7 | **滴定管未用 NaOH 润洗** | 只用去离子水冲洗就装 NaOH，会**稀释标准液** → 需要更多体积才到当量点 → 半当量点体积偏大 → 在缓冲区更靠后的位置读 pH。讲义明确把「standard solution too dilute (contamination in burette?)」列为误差来源。**步骤 2 要求先水洗、再用 NaOH 润洗**。 |
| 8 | **滴定管活塞里留气泡 / 起始液面不在 0.00** | 气泡在滴定中排出会造成**体积读数虚高**。步骤 3 要求**先加到超过顶刻度再放液排气泡**，并把**弯月面下缘**调到 0.00 cm³。读数一律看**弯月面下缘**。 |
| 9 | **pH 探头未正确校准或校准中途取出** | 校准必须走完 **"7.01 USE" → "7.01 rEC" → "4.01 USE" → "4.01 rEC" → "Stor"** 全流程，**未显示 "Stor" 前不能把探头拿出 pH 4 缓冲液**。两液之间**必须冲洗+拍干**（否则交叉污染缓冲液）。 |
| 10 | **探头擦拭方式** | 用蓝色实验室纸巾**轻轻拍干 (gently pat dry)**，**不要擦拭/摩擦球泡**——玻璃球泡易损。 |
| 11 | **搅拌速度过快** | 讲义要求**最低档**，一是温和混合，二是**避免搅拌子撞坏 pH 探头**。放探头时要**避开搅拌子**、同时**保证球泡完全浸没**。 |
| 12 | **读 pH 时机** | 每次加碱后**等读数稳定再记**，否则整条曲线系统性偏低（滞后）。 |
| 13 | **全程都用 2.0 cm³ 步长** | 那样突跃段只有 1–2 个点，当量点根本读不准（示例粗数据给出 −178% 的误差就是明证）。**必须执行步骤 11：终点前改用 0.20 cm³**。 |
| 14 | **一致性 (concordance) 判据** | **重复滴定的终点应在 ±0.10 cm³ 以内**，达不到就继续重复。 |
| 15 | **平均值处理** | 先**剔除异常值**再求平均；作图时用**平滑曲线**连点。 |
| 16 | **酚酞初始颜色搞混** | 变色是**无色 → 粉红**，所以**初始必须是无色**（酸性）。若一开始就是粉红，说明烧杯没洗干净或加错试剂。 |
| 17 | **忽略酚酞的毒性** | 它溶于**乙醇（高度易燃）**，且是**疑似致癌/致突变/损害生育力**物质。只用 **2–3 滴**，用封闭滴瓶。 |
| 18 | **滴定管在台面上装填** | 违反安全要求。**必须搬到地面、低于眼睛高度装填**（NaOH 有强腐蚀性，眼损伤风险）。 |

### 下午场（判读陷阱）

| # | 坑 | 说明与对策 |
|---|---|---|
| 1 | **把孔洞当成均质矿物** | 孔洞里是环氧树脂，XPL 下全黑不变——但它**零突起 (zero relief)**。看 PPL 下有没有突起即可区分。 |
| 2 | **把垂直光轴的切面当成均质矿物** | 所有非均质矿物都有 1 个（单轴）或 2 个（双轴）**光轴**；**垂直光轴的切面在 XPL 下全黑且旋转不变**。判据：**同一薄片中该矿物的其他颗粒有干涉色**（E302 第 iii 条即演示此点）。 |
| 3 | **试图判断不透明矿物的均质性** | **不可能判断**——它在 PPL 与 XPL 下都是黑的。讲义明说：「it is impossible to tell whether opaque minerals are isotropic or anisotropic」。 |
| 4 | **把「均质」与「不透明」混为一谈** | CFL 中那个均质矿物**不是不透明的**——它在 PP 光下是**透明的**，只是在 XP 下全黑。 |
| 5 | **把干涉色当成体色（自然颜色）** | 讲义两次警告。判断颜色属性时先确认**检偏镜在不在位**。而且**深色矿物的干涉色会被体色改变 (modified)**。 |
| 6 | **拿单个颗粒的干涉色下结论** | 诊断的是**最高干涉色 (maximum interference colour)**，而**大多数颗粒显示的是序列中较低的颜色**。必须**扫全片取最高**，再对 **Michel-Levy 色表**。 |
| 7 | **忘了干涉色还依赖薄片厚度** | 「assuming a constant thickness」——干涉色只有在**标准厚度（通常 30 μm）**下才可比。磨厚/磨薄会整体抬高/压低干涉色。 |
| 8 | **把裂纹当解理** | 解理 = **等间距、规则、平行**；裂纹 = **不规则、独立于解理**。VT 的淡色矿物两者并存，是专门设的辨析题。 |
| 9 | **看不到解理就断定矿物无解理** | **一组解理只在近垂直于该解理的切面上可见**；有两组以上解理的矿物，也**只有少数取向有利的颗粒**能显示完整解理图案（VT 的菱形切面 vs 其他取向）。看不到 ≠ 没有。 |
| 10 | **看不到低突起矿物的裂纹/解理就以为没有** | RHB 与 EG 都明说：低突起矿物**可能有裂纹和解理，但因低突起而看不见**。 |
| 11 | **不会用载物台下光阑** | 突起、解理、裂纹「看不出来」的标准解法就是**关小光阑提高反差**。讲义在 relief 与 cleavage 两节都提到。 |
| 12 | **忘了突起的例外** | 突起可视为矿物常数，**唯一常见例外是方解石 calcite**（突起随旋转变化）。 |
| 13 | **观察多色性时选错晶体** | 15216 中「偶尔会遇到旋转时颜色不变的晶体——它不太可能是长方形的」：这是在暗示**取向决定能否看到多色性**，应挑**形状规整（长方形/长条形）**的晶体。 |
| 14 | **描述颜色只写色相** | 必须同时给出**深、浅或居中**（dark / light / in between）。 |
| 15 | **把环带 (zoning) 或双晶 (twinning) 误当两种不同矿物** | 环带 = 同一晶体**内外成分不同**（VT 的绿色边缘、CFL 的紫色调环带）；双晶 = **斑马条纹状**外观（R56 中的低干涉色矿物），仍是**同一个晶体**。 |
| 16 | **第 9 题素描时忘了拉出检偏镜** | 要记录的是突起与解理/裂纹这些 **PPL 性质**，必须 **analyser out**。 |
| 17 | **忘了「同一矿物不同颗粒颜色不同」的原因** | E302 (i) 与 R56 都强调：**不是不同矿物，而是同一矿物的晶体结构取向不同**。这是理解「二维切面 vs 三维晶体」的核心。 |

| diprotic acid | 二元酸 | 每个分子可给出两个 H⁺ 的酸 |
| monoprotic acid | 一元酸 | 每个分子只给出一个 H⁺ 的酸 |
| acid dissociation constant, Ka | 酸解离常数 | Ka = [H⁺][A⁻]/[HA]，量化酸的强度（解离程度） |
| conjugate base anion, A⁻ | 共轭碱阴离子 | 酸 HA 失去 H⁺ 后剩下的阴离子（如 CH₃COO⁻） |
| buffer solution | 缓冲液 | 加入少量酸/碱时能维持近乎恒定 pH 的溶液 |
| buffering zone | 缓冲区 | 滴定曲线上 pH 几乎不变的平坦段，此处 [HA] ≈ [A⁻] |
| titration | 滴定 | 逐次加入已知浓度试剂并监测反应进程的定量分析方法 |
| titration curve | 滴定曲线 | pH（y 轴）对加入碱体积（x 轴）作图并用平滑曲线连接 |
| equivalence point | 当量点 / 化学计量点 | 曲线上垂直段的中心，酸恰好被完全中和 |
| half equivalence point / half neutralisation | 半当量点 / 半中和点 | 当量点体积的一半处，此时 [HA] = [A⁻]，故 pH = pKa |
| end point | 终点 | 指示剂发生颜色变化的那一点（酚酞：无色 → 粉红） |
| phenolphthalein | 酚酞 | 酸碱指示剂，溶于乙醇；酸中无色，碱中粉红 |
| pH probe | pH 探头 | 电位法测 pH 的探头，使用前须用标准缓冲液两点校准 |
| calibration | 校准 | 用已知 pH 的标准缓冲液（7.01 与 4.01）设定仪器读数 |
| burette | 滴定管 | 精确放出可变体积液体的刻度玻璃管，读弯月面下缘 |
| meniscus | 弯月面 | 液面弯曲部分；滴定管读数一律读其**下缘** |
| pipette (+ filler) | 移液管（+ 移液辅助器） | 精确转移固定体积液体；严禁口吸，必须用辅助器 |
| magnetic stirring apparatus / stirring bar | 磁力搅拌器 / 搅拌子 | 提供均匀混合；本实验用最低档以保护 pH 探头 |
| deionised water | 去离子水 | 除去离子的纯水，用于冲洗探头与玻璃器皿 |
| concordant results | 一致的结果 | 重复滴定终点相差在 ±0.10 cm³ 以内 |
| anomalous result | 异常值 | 明显偏离的数据点，求平均前应剔除 |
| PPE (personal protective equipment) | 个人防护装备 | 本实验最低要求：护目镜 + 丁腈手套 + 实验服 |
| nitrile gloves | 丁腈手套 | 耐化学品的实验手套 |
| demonstrator | 实验助教 | 处理破损玻璃器皿与溢洒事故的负责人 |

### 下午场（光性矿物学）

| 英文 | 中文 | 一句话解释 |
|---|---|---|
| petrological / polarising microscope | 岩相显微镜 / 偏光显微镜 | 带起偏镜与检偏镜、可旋转载物台的显微镜，用于观察薄片 |
| thin section | 薄片 | 磨到标准厚度（约 30 μm）并盖上盖玻片的岩石透明切片 |
| polariser | 起偏镜 | 位于载物台下方，产生单一振动方向的偏振光 |
| analyser | 检偏镜 | 位于载物台上方；拉出 = PPL，推入 = XPL |
| plane-polarised light (PPL / PP) | 单偏光 | 只有起偏镜在位，用于看突起、颜色、多色性、解理 |
| crossed polars (XPL / CP / XP) | 正交偏光 | 起偏镜与检偏镜同时在位（振动方向垂直），用于看干涉色与消光 |
| rotating stage | 旋转载物台 | 可旋转样品，观察多色性与消光的必备动作 |
| substage iris diaphragm | 载物台下光阑 | 控制光量与反差；关小可增强突起、解理与裂纹 |
| focus control | 调焦旋钮 | 使像清晰 |
| refractive index (R.I.) | 折射率 | 光在介质中减速的量度；环氧树脂 R.I. = 1.54 |
| epoxy | 环氧树脂 | 覆盖薄片表面并粘结盖玻片的胶，R.I. = 1.54，光学均质 |
| surface relief | 突起 | 矿物 R.I. 与环氧树脂 1.54 之差的表现；低突起平滑，高突起（1.6–1.8）粗糙带黑边 |
| opaque | 不透明（矿物） | 吸收/反射全部光，在薄片中呈全黑，无法判断其均质性 |
| translucent | 半透明 | 薄片中大多数矿物的状态，可透光 |
| pleochroism | 多色性 | 颜色（强度和/或色调）随晶体取向变化，旋转载物台可见 |
| cleavage | 解理 | 沿键强较弱的特定晶面平整破裂；表现为等间距平行细黑线 |
| fracture | 裂纹 | 不规则的破裂，与解理无关，间距与方向无规律 |
| isotropic | 光学均质 | XPL 下全黑且旋转不变（玻璃、环氧树脂、少数矿物） |
| anisotropic | 光学非均质 | 大多数矿物；XPL 下呈干涉色，每 90° 消光一次 |
| extinction | 消光 | 非均质矿物旋转载物台时每隔 90° 变黑的现象 |
| double refraction | 双折射 | 光进入非均质矿物后分裂为两束、走不同路径并产生相位差 |
| interference colours | 干涉色 | 双折射的两束光穿过检偏镜后干涉产生的颜色 |
| Newton's Scale | Newton 色序 | 干涉色由低到高的递升序列（灰白浅黄 → 鲜艳色 → 褪淡色） |
| Michel-Levy colour chart | Michel-Levy 干涉色图表 | Newton 色序的标准对照图表，用于判定最高干涉色 |
| maximum interference colour | 最高干涉色 | 某矿物所有颗粒中出现的最高干涉色，才具诊断意义 |
| optic axis (pl. axes) | 光轴 | 非均质矿物中不发生双折射的方向；垂直该轴的切面表现为均质 |
| uniaxial | 单轴（晶体） | 只有一个光轴的非均质矿物 |
| biaxial | 双轴（晶体） | 有两个光轴的非均质矿物 |
| twinning | 双晶 | 同一晶体内取向不同的畴，XPL 下呈斑马条纹状（R56） |
| zoning | 环带 | 晶体外部与内部成分不同造成的同心色差（VT 的绿色边缘） |
| zero relief | 零突起 | 孔洞（充填环氧树脂）的特征，用于与真正的均质矿物区分 |
| common rock-forming minerals | 常见造岩矿物 | 下周将用本周建立的光学性质体系去鉴定的对象 |
