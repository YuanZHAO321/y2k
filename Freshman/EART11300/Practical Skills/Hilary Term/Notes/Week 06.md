## 二、核心概念

### 2.1 什么是底形 (bedform)、什么是沉积构造 (sedimentary structure)

- **底形 (bedform)**：可动沙床在流体作用下自组织形成的**床面起伏形态**，是**活着的、现在正在动的**地貌单元（波痕、沙丘等）。
- **沉积构造 (sedimentary structure)**：底形迁移过程中被埋藏、**保存进岩层内部的层理形态**。底形是「地表形态」，沉积构造是它**死后留下的化石**。
- 两者的对应关系是本周最核心的一条主线：

  | 活着的底形 | 保存下来的构造 |
  | --- | --- |
  | 波痕 (ripple) | 交错纹层 (cross lamination) |
  | 沙丘 (dune) | 交错层理 (cross bedding) |

  讲义原话：*"Ripples can be preserved in the rock record. If only the internal layers are seen these are called cross lamination."*（如果只看得到内部纹层，就叫交错纹层。）

### 2.2 波痕 (Ripples)

**几何形态**

- 波痕是沉积颗粒堆成的**非常小的脊 (very small ridges)**。
- **脊线 (crest) 的延长方向与水流方向垂直 (at right angles to the current flow)**。这一条极其重要：脊线走向可以直接反推古水流的**方位轴**（但还不能定出「往哪一边」）。
- **单向水流形成的波痕在横剖面上是不对称的 (asymmetrical)**：
  - **背流面 / 前坡 (lee slope)**：**短而陡**；
  - **迎流面 (stoss slope)**：**长而缓**。

**古水流方向判读（本周最实用的一条判读法则）**

> **lee slope 永远位于波痕的下游一侧 (down flow part)。**
> 因此：看到不对称波痕 → 陡的那一面指向下游 → 古水流方向确定。

**波浪波痕 vs 水流波痕（必须会区分）**

- **单向水流 (unidirectional current) 波痕**：**不对称**（陡的 lee + 缓的 stoss）。
- **波浪 (wave) 波痕**：由水体**来回往复运动 (back and forth movements)** 形成，横剖面**对称 (symmetrical)**——就是海滩上常见的那种波痕。
- 讲义强调：地质学家可以据此把两者区分开。这直接决定沉积环境解释（河流/浊流 vs 滨浪带）。

**尺度（务必记住数字）**

- **高度 (height)**：从**毫米级**到**小于 5–6 cm**。
- **波长 (wavelength)**：**小于几十厘米 (less than a few tens of cm)**。

### 2.3 沙丘 (Dunes)

**出现方式**

- 讲义原话：随着流速增大，会发生**「突变 (a sudden change)」**，跳到一种更大的底形——沙丘。
- **注意这个「sudden」**：从波痕到沙丘**不是连续渐变**，而是床面构型的**跃迁**，中间不存在稳定的「中等大小波痕」。这是底形相图 (bedform phase diagram) 上存在**明确稳定域边界**的物理体现。

**形态与形成条件**

- 沙丘与波痕**形状相同，只是大得多 (same shape as ripples, but much larger)**。
- **粒度条件**：形成于**中砂到砾 (medium sands to gravels)**。
- **流动强度**：**中到高 (moderate to high flow strengths)**。
- **永远不对称 (always asymmetric)**，且**只由单向流形成 (unidirectional flows only)**——**水流或风都可以**（所以沙漠风成沙丘同理）。

**尺度**

- **高度**：**几十厘米到几十米**。
- **波长**：**大于 1 m**。

**对应的沉积构造：交错层理 (cross bedding)**

- 定义：**层内的倾斜纹层 (inclined layers within the beds)**。
- **倾角有时可达距水平面 35°**（这个数字要背——它接近干砂的**休止角 (angle of repose)**，📎 背景补充：这正是因为交错层理的前积层是由砂粒在 lee slope 上**崩塌 (avalanche)** 堆成的，崩塌面自然停在休止角附近，约 30–35°）。
- **通常保存下来的是较陡的、下游一侧的 lee slope**（*"Commonly it is the steeper lee (down current) slopes of the sand dunes that are preserved."*）。
- **→ 野外应用**：交错层理前积层的**倾向 (dip direction) 就是古水流方向**。

### 2.4 底形相图 (Bedform Phase Diagram)

讲义给出的定义（原文要点）：

> 底形相图展示了**单向流**条件下**水下底形 (subaqueous bedforms)（及其内部沉积构造）的稳定域 (stability fields)**，相对于**特定的流速–粒径条件 (velocity–grain size conditions)**。**该图对应的水深为 0.25–0.5 m。**

**读图时必须注意的三件事：**

1. **两个坐标轴**：纵轴 = **流速 (velocity)**，横轴 = **粒径 (grain size)**。所以**底形不是只由流速决定的，粒径同样是控制变量**。
2. **图上画的是「稳定域」而非一条线**：每种底形占据一块区域，域与域之间是相变边界。
3. **水深是隐含的第三变量**：这张图只在 **0.25–0.5 m 水深**下成立。换水深，边界位置会移动——所以**不能把实验水槽的绝对流速数值直接套用到天然大河上**，只能套用**序列关系**。

📎 **背景补充（相图上粒径方向的关键规律，讲义未展开）**：在**细砂**一侧，随流速增大的序列是 *无运动平坦床面 → ripples → dunes → upper plane bed → antidunes*；但在**粗砂/砾**一侧，**ripples 稳定域消失**，取而代之的是**下部平坦床面 (lower plane bed)**，即序列变成 *无运动平坦床面 → lower plane bed → dunes → upper plane bed → antidunes*。这解释了为什么讲义说沙丘可以形成于「中砂到砾」，而波痕只在细粒沉积物中出现——**粗砂中根本不发育波痕**。本周实验把粒径固定为 255 µm（细–中砂），正是为了走「有 ripples」的那条路径。

### 2.5 水动力条件如何控制底形（本周的因果链）

把讲义各处散落的信息串成一条完整因果链：

```
提高流速 / 增大坡度
      ↓
底部剪切应力 (bed shear stress) 增大
      ↓
超过起动临界值 (threshold of motion) → 开始推移质搬运 (bedload transport)
      ↓
颗粒运动方式依次升级：滚动 (rolling) → 跃移 (saltation) → 悬移 (suspension)
      ↓
输沙率 (sediment transport rate) 增大
      ↓
床面构型依次跃迁：
  无运动平坦床面 → 波痕 → 沙丘 → 冲刷型沙丘 → 有运动平坦床面 → 驻波 → 逆行沙丘
      ↓
不同底形迁移并保存 → 不同内部层理构造进入岩石记录
```

**两个关键的「水面–床面耦合」现象（本周最容易考、最容易记混）：**

- **沙丘阶段**：水面被**沙丘脊 (crest) 上方稍微拉低 (drawn down)**，而在**沙丘之间的槽 (trough) 上方隆起 (humped)**。
  → **水面波与床面波「反相」(out of phase)**。
- **逆行沙丘 (antidune) 阶段**：水面驻波与床面起伏**同相**，且底形**向上游迁移**。

📎 **背景补充**：这两种耦合关系的物理分界是**弗劳德数 (Froude number) Fr = 1**。Fr < 1 为**缓流 (subcritical flow)**，水面扰动可以向上游传播，水面与床面反相（沙丘阶段）；Fr ≥ 1 附近进入**急流 (supercritical flow)**，水面出现驻波 (standing waves)、并与床面同相，底形可以逆流迁移（逆行沙丘阶段）。讲义 Step 7–8 里所说的「移动到 upper regime（上部流态）」，本质就是 Fr 跨过 1。

> **静平 → 波痕 → 沙丘 → 冲垮的沙丘 → 动平 → 驻波 → 逆行沙丘**
> （英文：no-motion plane bed → ripples → dunes → washed-out dunes → upper plane bed → standing waves → antidunes）

### 3.3 实验中要用到的计算式

**(1) 表面流速（绿球法，讲义指定方法）**

在工作段上量出已知距离 $L$，用秒表测中性浮力绿球漂过所用时间 $t$：

$$u_s = \frac{L}{t}$$

📎 背景补充：这测到的是**水面流速**，不是断面平均流速。对明渠紊流，断面平均流速通常约为 $\bar{u} \approx 0.8\,u_s$——报告中讨论误差时应指出这一点。

**(2) 平均水深（讲义规定的取样方法）**

$$\bar{h} = \frac{1}{n}\sum_{i=1}^{n} h_i, \qquad n \ge 10$$

**讲义硬性要求：**
- 至少 **10 个点测量**；
- 测点在工作段（**中央 50 cm**）内**随机**分布；
- **远离进出口效应 (entrance/exit effects)**；
- **水深从自由水面量到沙床顶面，而不是量到坚硬的水槽底板**（⚠️ 极易出错，见第六节）。

**(3) 底形迁移速率（蜡笔法，讲义指定方法）**

在水槽侧壁用蜡笔 (chinagraph pencil) 标出某个沙丘脊的位置，隔时间 $\Delta t$ 再标一次，用直尺量位移 $\Delta x$：

$$c = \frac{\Delta x}{\Delta t}$$

📎 背景补充：迁移速率可以粗略换算为**推移质输沙率 (bedload transport rate)**。对近似三角形的底形：

$$q_b \approx \beta\,(1-\phi)\,c\,H$$

其中 $H$ 为底形高度，$\phi$ 为孔隙度，$\beta$ 为形状因子（三角形取 ≈ 0.5）。这就是「底形迁移得越快 = 输沙率越大」的定量说法。

**(4) 床面坡度**

数字水平仪读出倾角 $\theta$：

$$S = \tan\theta \approx \theta \ (\text{rad, 小角度时})$$

**(5) 📎 背景补充：判断层流/紊流的雷诺数 (Reynolds number)**

讲义 Step 1 提问「flow structure is laminar or turbulent?」，用红色染料 (red dye) 定性判断。其定量判据为：

$$Re = \frac{\rho\,\bar{u}\,h}{\mu} = \frac{\bar{u}\,h}{\nu}$$

明渠中一般 $Re \gtrsim 2000$ 即为**紊流 (turbulent)**。实验水槽中的水流几乎总是紊流——所以染料会**迅速被混合开 (mixed)**，而不是拉出一条细线 (trace out a line)。

**(6) 📎 背景补充：弗劳德数 (Froude number)**

$$Fr = \frac{\bar{u}}{\sqrt{g\,h}}$$

- $Fr < 1$：**缓流 / 下部流态 (subcritical, lower flow regime)** → 波痕、沙丘（水面与床面**反相**）
- $Fr \approx 1$：**临界流** → **驻波 (standing waves)**
- $Fr > 1$：**急流 / 上部流态 (supercritical, upper flow regime)** → **逆行沙丘 (antidunes)**（水面与床面**同相**）

这正是讲义 Step 8 中 "move the flow well into the upper regime" 的物理含义。

📎 **利用它做数据检验**：实验结束后，用每一步记录的 $\bar{u}$ 和 $\bar{h}$ 算出 $Fr$，检查**驻波/逆行沙丘出现的那几步 $Fr$ 是否确实接近或超过 1**。这是把定量数据与定性观察互相验证的最漂亮的一步分析。

## 五、Practical 要点（本节为本周重点）

### 5.1 实验目的与目标（讲义区分了 Aim 与 Objective，注意措辞差别）

- **Aim（目的）**：解释当上覆的**单向水流的能力 (capacity) 增大**时，**沙床会发生什么**。
- **Objective（目标）**：在带**可动沙床的明渠 (open channel with a mobile sand bed)** 中，**演示随输沙强度增大而依次出现的底形序列**。

### 5.2 装置设置 (Equipment Set Up) — 实验的初始条件

三条必须在开始前做到位（否则整个实验的起点就错了）：

1. **铺沙**：将粒径均匀、**0.1–0.3 mm** 的砂铺入水槽，**厚度均匀**；砂面要**夯实 (tamped down)**，做到**均匀密实、轻度压实、尽可能平整 (uniformly packed, lightly compacted and as flat as possible)**。
2. **流量阀完全关闭 (flow valve fully closed)**。
3. **水槽坡度设为零 (flume slope set to zero)**。

### 5.3 通用操作纪律（讲义在流程开头单列，适用于每一步）

> **在实验的每一个阶段都要有耐心，让水流和床面适应新的设定（即达到某种平衡 equilibrium）。最低标准是：新的床面状态必须在水槽中段的工作段 (middle working section) 全段建立起来。**

**这是本实验最容易被赶时间的小组破坏的一条。** 没到平衡就读数 = 数据无意义。

### 5.4 八步实验流程（完整版）

#### **Step 1 — 无运动的平坦床面 (plane bed with no motion)**

**操作**：坡度置零 → **流量控制阀开 2 圈** → 开泵，**泵设在最低档 I** → 放水入槽 → **静置几分钟**让水箱稳定 → 等待全槽**稳定流 (steady flow)** 建立，确认**床面无运动**。

然后：**将坡度增加一点点，但不足以超过床沙起动临界值 (threshold of bed material motion)。**

> **讲义在这里埋了一个方法论问题**：*"To find this point you will need to decide **how many grains need to be moving** for the threshold of motion to be exceeded."*
> —— **「多少颗粒在动才算超过起动临界值？」这个判据必须由你们小组自己定义并写进报告。** 这是本次 practical 中一个真实的**操作性定义 (operational definition)** 训练：科学测量里很多"阈值"并没有客观标准，必须自行明确、前后一致地使用。

**此状态的特征**：起动临界值被超过之前，输沙量**（几乎）为零**，床面不动，**没有任何底形**，床面构型即「无运动的平坦床面」。

**Actions required：**
- 在 **Results Table 1** 中记录：**水槽宽度、泵档设置、阀门开/关状态、平均水深、水槽坡度**。
- 用**秒表 + 绿球**测出并计算**表面流速**。
- **平均水深规则**：至少 **10 个点**，位置在工作段（**中央 50 cm**）内**随机**分布，**远离进出口效应**；**水深从自由水面量到沙床顶面，不是量到坚硬的槽底**。

**Question（须回答）**：**流动结构是层流还是紊流 (laminar or turbulent)？**
- **方法**：用移液管滴入红色染料，观察它**是拉出一条线 (traces out a line)，还是被混合开 (mixed)**。
- 拉出细线 = 层流；迅速扩散混合 = 紊流。

---

#### **Step 2 — 波痕 (ripples) 出现**

**操作**：**逐级增加坡度**，直到出现**小而有限的输沙量 (a small but finite sediment load)**。
> 讲义原话：*"Well done — you have initiated bedload transport!!!!"*（你已经启动了推移质搬运。）

**现象**：几乎立刻出现**小的三角形底形 = 波痕**：
- 高**几毫米**，长**一两厘米**；
- **不对称**：**上游侧缓 (gentle upstream slope)**，**下游面陡 (steep downstream face)**。

**Actions required：**
- 观察构成波痕的**颗粒的运动方式**；
- 观察**水面的几何形态**；
- 在 Results Table 1 中记录：**流速、平均水深、水槽坡度**。

---

#### **Step 3 — 沙丘 (dunes) 成为主导底形**

**操作**：**把泵的排量提高到档 III**。→ 流深与输沙速率会**立即增大**。必要时**继续逐级增加坡度**，直到看见颗粒**周期性地跳跃、弹跳 (hop and bounce)**——但**主要运动方式仍是滚动 (rolling)**。

**Question（须回答）**：**这种跳跃/弹跳的运动叫什么？**
> **答案：跃移 (saltation)。**
> 📎 背景补充：颗粒搬运方式共三类——**推移/滚动–滑动 (traction: rolling & sliding)**、**跃移 (saltation)**、**悬移 (suspension)**。三者随流强递增依次接管，本实验 Step 2→4 正好走完这个序列。

**现象**：出现更大的三角形底形 = **沙丘**。讲义特别提醒：
- **在小水槽里，沙丘的尺寸并不比波痕大多少**（受水槽尺度限制）；
- 但沙丘**更长、顶部更平坦 (longer and flatter topped)**；
- 而且**会扰动水流的自由表面 (disturb the free surface of the flow)** ← **这是在小水槽中区分沙丘与波痕的最可靠判据。**

**水面–床面反相关系**（沙丘床面在工作段全段建立后可见）：
- 水面在**沙丘脊 (crest) 上方被稍微拉低 (drawn down)**；
- 水面在**沙丘之间的槽 (trough) 上方隆起 (humped)**；
- → **水面波与床面波「反相」(out of phase)**。

**Actions required（本步是观察内容最多的一步）：**
- 观察沉积物向下游的搬运过程：颗粒**沿 stoss slope 滚动与跃移上行**；
- 观察颗粒在 **lee slope 上崩塌 (avalanching)**；留意 lee slope 上是否存在**分离泡 (separation bubble)**——它会造成**向上游的回流 (upstream flow)**，把颗粒**扫回坡面 (sweeps grains back up the face)**；
- 观察**水面的几何形态**；
- **画一张仔细的、带标注的素描图 (careful annotated sketch)**，注明**沙丘的高度与几何形态**；**测量特征沙丘高度与波长**；
- 用**蜡笔 + 秒表 + 直尺**记录**沙丘向下游的迁移速率**；
- 在 Results Table 1 中记录**流速、平均水深、水槽坡度**。

---

#### **Step 4 — 最大流量下的沙丘（跃移加强，出现悬移）**

**操作**：**将流量阀完全打开**，产生**最大排量 (maximum discharge)**。

**现象**：
- 流深再次增大，**沉积物运动强度增大**；
- **跃移变得更明显 (saltation more pronounced)**；
- 可能观察到**部分颗粒以悬移质 (suspended load) 运动**——判据非常具体：**颗粒从一个沙丘的脊直接跃到下一个沙丘的迎流面上，中途不在槽 (trough) 中停留**。

**Actions required：**
- 记录**沙丘高度、长度、向下游前进速率**的任何变化（蜡笔 + 秒表 + 直尺）；
- 在 Results Table 1 中记录**流速、平均水深、水槽坡度**。

---

#### **Step 5 — 冲刷型沙丘 (washed-out dunes)**

**操作**：**大幅增加坡度 (a substantial increase in slope)**。

**Actions required：**
- 观察沙丘**变长、振幅降低 (lengthen and reduce in amplitude)**——形成的**又长又低的底形就叫 washed-out dunes（冲刷型沙丘）**；
- 记录它们的**形状**，以及**槽 (troughs) 与冲刷坑 (scour holes) 是否存在**；
- 当冲刷型沙丘**占满整个工作段**后，在 Results Table 1 中记录**流速、平均水深、水槽坡度**。

---

#### ⏱️ **关键时间警告（讲义用 NOTE 单列，必须重视）**

> **实验剩余部分「时间就是一切」**：接下来的底形对应**极高的床沙搬运率**，会**超出水槽再循环沉积物的能力 (overwhelm the capacity of the flume to recirculate sediment)**，导致**迅速冲刷到坚硬的槽底 (rapid scour down to the solid flume bed)**。
> → **每一个底形状态一旦建立，必须尽快完成测量。**

**实践含义**：Step 6–8 之前，团队要**预先分配好谁读什么、按什么顺序读**，不能临场商量；Step 7 和 Step 8 讲义**刻意只要求记录较少的量**（Step 7 只记水深与坡度，Step 8 只记坡度），正是为这个时间约束做的设计。

---

#### **Step 6 — 有运动的平坦床面 (plane bed with motion / upper plane bed)**

**操作**：**再一次大幅增加水槽坡度**。

**Actions required：**
- 观察**冲刷型沙丘消失**，**建立起「有运动的平坦床面」**；
- 注意**水深的变化**与**水面的外观**，以及**是否出现涌沸 (boils) 与水面紊动 (surface turbulence)**；
- 注意**运动中的推移质的外观 (the appearance of the moving bedload)**；
- 在 Results Table 1 中记录**流速、平均水深、水槽坡度**。

> ⚠️ **概念要点**：床面重新变平，**不代表水流变弱了**——恰恰相反，这是**更强**的流动。第 1 步的平床是「静的」，第 6 步的平床是「动的」。它们在岩石记录中留下的东西完全不同（前者无构造，后者是**平行纹层**）。

---

#### **Step 7 — 驻波 (standing waves)**

**操作**：**小幅增加水槽坡度 (increase by a small amount)**。

**Actions required：**
- 观察**平坦、光滑如玻璃 (flat, glassy smooth) 的水面开始变形**，形成**几乎静止不动的起伏 = 驻波 (standing waves)**；
- 观察**槽底床面的外观**，注意**床面特征与水面形态之间的关系**（← 关键：开始出现**同相耦合**）；
- 在 Results Table 1 中记录**平均水深与水槽坡度**（注意：**这一步不要求记流速**）。

---

#### **Step 8 — 逆行沙丘 (antidunes)**

**操作**：**较大幅度增加水槽坡度，使水流充分进入上部流态 (well into the upper regime)**。

**Actions required：**
- 观察**表面波的振幅**及其**下方的底形**，注意底形的**对称性与规则性 (symmetry and regularity)** —— 这些底形称为**逆行沙丘 (antidunes)**；
- 观察颗粒运动：颗粒**从一个逆行沙丘的下游面被侵蚀 (eroded from the downstream face)**，**沉积到下游相邻逆行沙丘的上游面 (deposited on the upstream face of the next antidune downstream)**；
- → **结果：逆行沙丘本身向上游迁移 (moves in the upstream direction)**，与水流和颗粒的运动方向相反；
- **验证方法**：用**蜡笔**在槽壁上**描出一个逆行沙丘的轮廓**，观察它**随时间的移动**；
- 讲义特别强调：**必须认识到，水与颗粒在任何时候都是向下游运动的，尽管底形在向上游移动。**
- 在 Results Table 1 中记录**水槽坡度**（这一步只要求这一项）。

### 5.6 预期结论

1. **随流动强度递增，可动沙床会依次通过一个可重复、可预测的底形序列**：无运动平床 → 波痕 → 沙丘 → 冲刷型沙丘 → 有运动平床 → 驻波 → 逆行沙丘。
2. **底形类型由流动强度与粒径共同决定**（本实验固定粒径，只变流强，走的是相图上的一条垂线）。
3. **颗粒运动方式随流强升级**：滚动 → 跃移 → 悬移；输沙率随之增大。
4. **每一种底形对应一种可保存的内部构造**（交错纹层、交错层理、平行纹层……），因此**在岩石中看到某种构造，就可以反推当时的水动力条件与古水流方向**——这就是本实验的最终价值：**将今论古**。
5. **水面形态是流态的敏感指示器**：沙丘阶段反相、上部平床阶段光滑、驻波/逆行沙丘阶段同相且逆向迁移。

### 5.7 底形判读练习要点（如何在岩石/照片中判读）

**判读顺序（建议按此四步走）：**

1. **先看对称性**：
   - **对称** → **波浪波痕 (wave ripple)**，指示**往复流**（滨浪带）。
   - **不对称** → **单向流**，继续第 2 步。
2. **再看尺度**（决定是波痕还是沙丘）：
   - 高 **< 5–6 cm**、波长 **< 几十 cm** → **波痕** → 内部为**交错纹层 (cross lamination)**。
   - 高 **几十 cm 以上**、波长 **> 1 m** → **沙丘** → 内部为**交错层理 (cross bedding)**。
3. **看内部纹层的倾角与倾向**：
   - 倾角可达 **35°**、成组倾斜 → 前积层 (foreset)，保存的是 **lee slope**；
   - **倾向 = 古水流方向（指向下游）**。
4. **看是否为平行纹层**：
   - 水平平行纹层且无斜层 → **上部平坦床面 (upper plane bed)**，指示**高流强**（不要误判为「静水沉积」！）。

## 六、易错点 / 重点难点

### ⚠️ 概念类

1. **「平坦床面」有两种，含义完全相反。**
   - Step 1 的 **plane bed with no motion**：流强**低于**起动临界值，**无构造**；
   - Step 6 的 **plane bed with motion (upper plane bed)**：流强**很高**，产生**平行纹层**。
   在岩石中看到平行纹层**几乎总是**后者（高能环境），而不是"水很平静"。这是最经典的误判。

2. **底形序列不是连续渐变的。**
   讲义明确说从波痕到沙丘是 **"a sudden change"**——存在稳定域边界，不存在稳定的"中等波痕"。

3. **逆行沙丘 (antidune) 的方向问题。**
   **底形向上游迁移，但水和沙粒始终向下游运动。**讲义专门写了一句 *"It must be recognised that the water and the grains move downstream at all times, even though the bedform moves upstream."* 说明这里历来是学生的混淆点。机制是：**下游面被侵蚀 + 上游面被沉积 = 形态整体后退**。

4. **水面与床面的相位关系不要记反。**
   - **沙丘 = 反相 (out of phase)**：crest 上方水面**下凹**，trough 上方水面**隆起**；
   - **逆行沙丘 = 同相**。

5. **波痕 vs 沙丘不能只看"大小"，尤其在小水槽里。**
   讲义明确说小水槽中沙丘"并不比波痕大多少"。**要用形态（更长、顶部更平）与「是否扰动自由水面」来区分**，而不是单看高度。

6. **粒径同样是控制变量，不只是流速。**
   底形相图有**两个轴**。同样的流速，细砂里出波痕，粗砂里可能是下部平坦床面。本实验固定粒径正是为了排除这一变量——**写报告时必须点明这一实验设计选择**。

7. **相图的适用范围有限。**
   讲义标注水深 **0.25–0.5 m**。不能把水槽的绝对流速数值外推到天然大河，只能外推**序列关系**。

8. **风成沙丘也算 dune。**
   讲义说沙丘由 "unidirectional flows only (water or wind)"，**风也是单向流**。

### ⚠️ 操作类

9. **水深要量到沙床顶面，不是量到坚硬的槽底。**
   讲义专门用斜体强调。量错会让水深系统性偏大，进而算错 $Fr$ 和 $Re$。

10. **平均水深必须 ≥ 10 个随机点，且限定在中央 50 cm 工作段内。**
    进出口附近有**进出口效应 (entrance/exit effects)**，流动未充分发展，测点必须避开。

11. **每一步都必须等到平衡再读数**，且新床面状态要**在整个工作段建立**。抢时间读数会得到过渡态的混合数据。

12. **Steps 6–8 有硬性时间压力**：高输沙率会超出水槽再循环能力，把沙冲光露出硬底。**必须预先分好工、按固定顺序抢读**。

13. **「起动临界值」需要小组自定义判据**（"多少颗粒在动才算动"）。这个操作性定义必须**写进报告并前后一致**。

14. **绿球测的是表面流速，不是断面平均流速**（📎），报告的误差讨论里应提及。

15. **原始材料中有一处数值不一致，注意别记混**：
    - 正文说粒径 **mean = 255 µm；range 300–150 µm**（即 0.15–0.3 mm）；
    - Equipment Set Up 说砂的粒径 **between 0.1 and 0.3 mm**。
    两者范围下限不同。以**正文的 150–300 µm（mean 255 µm）**为准较稳妥；写报告时可注明实际所用批次。

16. **安全**：**水和电是致命组合**——湿手不碰电气部件，只有 Job 1 (J.A.R.V.I.S.) 操作控制器与大红按钮。

### ⚠️ 需要能立刻答出的两个讲义提问

- **Step 1**：*Is the flow structure laminar or turbulent?* → 用红色染料判断；**染料被迅速混合 = 紊流**（水槽中的水流通常是紊流）。
- **Step 3**：*What is this motion by hopping or bouncing called?* → **跃移 (saltation)**。

## 七、本周术语表

| 英文 | 中文 | 一句话解释 |
|---|---|---|
| **Bedform** | 底形 | 可动沙床在流体作用下形成的床面起伏形态，是"活着"的地貌单元 |
| **Sedimentary structure** | 沉积构造 | 底形迁移后被保存进岩层内部的层理形态，是底形的"化石" |
| **Flume** | 实验水槽 | 可控泵档、阀门与坡度的实验用明渠，用来重现底形序列 |
| **Unidirectional flow** | 单向流 | 只朝一个方向流动的水流（或风），形成**不对称**底形 |
| **Ripple** | 波痕 | 高 mm–5/6 cm、波长 < 几十 cm 的小型脊状底形；脊线与流向垂直 |
| **Wave ripple** | 浪成波痕 | 由水体来回往复运动形成，横剖面**对称** |
| **Dune** | 沙丘 | 高几十 cm–几十 m、波长 > 1 m 的大型不对称底形；只由单向流（水或风）形成 |
| **Washed-out dune** | 冲刷型沙丘 | 沙丘被拉长、振幅降低后的过渡底形，介于沙丘与上部平床之间 |
| **Plane bed with no motion** | 无运动的平坦床面 | 未达起动临界值时的平床，无输沙、无底形、无构造 |
| **Plane bed with motion / Upper plane bed** | 有运动的平坦床面 / 上部平坦床面 | 高流强下重新变平的床面，输沙剧烈，形成**平行纹层** |
| **Standing wave** | 驻波 | 水面上几乎静止不动的波状起伏，出现于上部流态边界 |
| **Antidune** | 逆行沙丘 | 上部流态下对称规则的底形，**向上游迁移**（水与砂粒仍向下游） |
| **Crest** | 脊 / 波峰 | 底形的最高线；波痕脊线与水流方向**垂直** |
| **Trough** | 槽 / 波谷 | 相邻底形之间的低洼部分 |
| **Stoss slope** | 迎流面 | 底形上游一侧的坡，**长而缓**；颗粒沿此滚动、跃移上行 |
| **Lee slope** | 背流面 / 前坡 | 底形下游一侧的坡，**短而陡**；颗粒在此崩塌堆积；**永远在下游侧**→ 可判古流向 |
| **Cross lamination** | 交错纹层 | 波痕保存下来的内部倾斜纹层（小尺度） |
| **Cross bedding** | 交错层理 | 沙丘保存下来的内部倾斜层，倾角可达 **35°**，多保存较陡的 lee slope |
| **Threshold of motion** | 起动临界值 | 床沙开始运动所需的最小流动强度；判据需自行操作性定义 |
| **Bedload (transport)** | 推移质（搬运） | 沿床面滚动、滑动、跃移的颗粒搬运方式 |
| **Rolling** | 滚动 | 颗粒贴床面滚动前进，最低流强下的主要方式 |
| **Saltation** | 跃移 | 颗粒跳跃、弹跳式前进（Step 3 问题的答案） |
| **Suspended load** | 悬移质 | 被紊流托举、长时间不落回床面的颗粒；判据为跨越整个槽而不停留 |
| **Avalanching** | 崩塌 | 颗粒在 lee slope 上成批下滑堆积，形成交错层的前积层 |
| **Separation bubble** | 分离泡 | lee slope 背后的流动分离区，内部有**向上游的回流**，会把颗粒扫回坡面 |
| **Flow separation / upstream flow** | 流动分离 / 回流 | 分离泡内与主流方向相反的水流 |
| **Boils** | 涌沸 | 上部平床阶段可能出现的水面上涌紊动结构 |
| **Bedform migration rate** | 底形迁移速率 | 底形脊线单位时间的位移，可换算输沙率；用蜡笔+秒表+尺测量 |
| **Bed slope** | 床面坡度 | 水槽倾角，本实验中提高流强的主要手段之一；用数字水平仪测 |
| **Flow depth** | 流深 | 自由水面到**沙床顶面**的距离（不是到硬槽底） |
| **Working reach / section** | 工作段 | 水槽中央 50 cm，测量必须在此进行以避开进出口效应 |
| **Entrance/exit effects** | 进出口效应 | 槽两端流动未充分发展的干扰区，须避开 |
| **Bedform phase diagram** | 底形相图 | 以流速–粒径为轴、展示各底形稳定域的图；本图对应水深 0.25–0.5 m |
| **Stability field** | 稳定域 | 相图上某种底形能够稳定存在的参数区域 |
| **Laminar flow** | 层流 | 流线平行、不混合；染料呈一条细线 |
| **Turbulent flow** | 紊流 | 流体强烈混合；染料迅速扩散开 |
| **Upper flow regime** | 上部流态 | 高流强流态，对应上部平床、驻波、逆行沙丘（📎 $Fr \gtrsim 1$） |
| **Froude number ($Fr$)** | 弗劳德数 | 📎 $Fr=\bar{u}/\sqrt{gh}$，惯性力与重力之比，划分缓流/急流 |
| **Reynolds number ($Re$)** | 雷诺数 | 📎 $Re=\bar{u}h/\nu$，惯性力与黏滞力之比，划分层流/紊流 |
| **Neutrally buoyant ball** | 中性浮力球 | 随水流漂移的示踪物，配秒表测表面流速 |
| **Vernier depth gage** | 游标深度计 | 精密测量水深的仪器 |
| **Chinagraph pencil** | 蜡笔（可写玻璃/塑料） | 在槽壁标记底形位置，用于追踪迁移 |
| **Digital spirit level** | 数字水平仪 | 测量水槽/床面坡度 |
| **Scour hole** | 冲刷坑 | 底形槽部因涡流侵蚀形成的凹坑；washed-out dune 阶段减少 |
| **Equilibrium (bed state)** | 平衡（床面状态） | 流与床互相适应后的稳定状态，每一步须等其在工作段全段建立后再读数 |
