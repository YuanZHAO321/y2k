## 一、本周主题

### 上午场：火山喷发类型与喷发产物
核心问题：**火山喷发的样式 (eruption style) 由什么控制？我们怎样从一块手标本 (hand specimen) 反推出它是怎么喷出来的？**

本节把五个东西串成一条因果链：

```
构造背景 (tectonic setting)
   ↓ 决定 熔融机制
岩浆成分 (silica content) + 挥发分含量 (volatile content)
   ↓ 决定 物理性质
黏度 (viscosity)
   ↓ 决定 气泡能否逃逸
喷发方式 (effusive 溢流 ↔ explosive 爆发)
   ↓ 决定 产物
火山岩/火山碎屑 (lava / pyroclasts)
```

这条链**双向可用**：正推是"给我构造背景，预测喷发类型"；反推是"给我一块岩石，还原一次古喷发"。反推正是本节实践的技能目标——而这项技能的现实意义在于：**通过重建火山的历史行为来预测其未来行为、评估其对社会的风险**（下周 Week 6 会接着讲火山地貌与火山灾害/风险）。

本节分两部分：
- **Part 1（60 min）**：观察实验室里贴的 6 张喷发照片（编号 B–I），判读喷发类型。
- **Part 2（60 min）**：描述三块火山岩手标本——**浮岩 (pumice)**、**玄武岩 (basalt)**、**黑曜岩 (obsidian)**，每块 20 min。可辅以显微镜观察玄武岩薄片（练习光学显微镜技能）。

### 下午场：沉积物物理特征描述 + 法证地质学情景推理
核心问题：**如何用一套标准化、可复现的观察，把一份沉积物样品"指纹化"，并据此判断两份样品是否来自同一地点？**

技能目标有两层：
1. **描述层**：掌握描述沉积物颗粒的规范语言——形状 (grain shape) = 圆度/棱角度 (angularity/roundness) + 球度 (sphericity)、成分 (composition)、粒度 (grain size)、以及其他表面特征（磨光、霜面、铁氧化物染色）。

## 二、核心概念

### 上午场

#### 1. 构造背景与岩浆生成 (tectonic setting and magma generation)
- 火山活动是**岩浆生成 (magma generation)** 的结果，而岩浆生成 = **固态地幔的部分熔融 (partial melting of the solid mantle)**。
- 不同构造背景用**不同机制**造岩浆，这是本周最重要的一个二分：

| 构造背景 | 熔融机制 | 挥发分 | 典型成分 | 典型产物 |
|---|---|---|---|---|
| 洋中脊 (mid-ocean ridge) / 热点 (hotspot) | **减压熔融 (decompression melting)**——地幔上涌 (mantle upwelling)，压力下降而熔融 | **低**（"干" anhydrous） | 玄武质 (basaltic) | 溢流熔岩、盾状火山、枕状玄武岩 (pillow basalt) |
| 俯冲带火山弧 (volcanic arc at subduction zone) | **流体熔融 / 助熔 (flux melting)**——俯冲板片 (subducting slab) 释放流体（水）进入上覆地幔楔 (mantle wedge)，降低固相线 | **高**（"湿" hydrous） | 安山质–流纹质 (andesitic–rhyolitic)，也可有含水玄武质 | 爆发式喷发、层状火山 (stratocone)、火山灰 |

> ⚠️ 关键补充：弧下的大体积富硅岩浆还来自**地幔熔体与地壳熔体的混合 (mixing mantle and crustal melts)**——普林尼式 (Plinian) 喷发通常发生在火山弧就是这个原因。

#### 2. 岩浆化学与物理 (magma chemistry & physics)
- **分离结晶 (fractional crystallization)** 会改变岩浆的 SiO₂ 含量：早期结晶的矿物贫硅（橄榄石、辉石等），残余熔体因此**逐步富硅**（basalt → andesite → rhyolite）。
- **黏度 (viscosity) 强烈依赖于硅含量**，机制是**聚合作用 (polymerisation)**：SiO₄ 四面体通过共享氧连成网络；硅越多，聚合度越高，网络越发达，熔体越"稠"。
  - 低硅（基性 mafic，如 basalt，富 Fe、Mg）→ 低黏度 → "runny"（稀）
  - 高硅（长英质 felsic，如 rhyolite）→ 高黏度 → "sticky"（黏）

#### 3. 挥发分与喷发方式 (volatiles and eruption style)
这是本节的机制核心，逐步展开：

1. 所有岩浆都含**挥发分 (volatiles)**：H₂O、CO₂、SO₂ 等。其丰度随构造背景与成分而变（见上表）。
2. 在**地壳压力**下，挥发分（部分）**溶解 (dissolved)** 在熔体中。
3. 岩浆上升 → 压力下降 → 挥发分**出溶/脱气 (exsolve / degas)** → 形成**气泡/气孔 (vesicles)** → 岩浆**膨胀 (expand)**。
4. **黏度决定气泡能否逃逸**：
   - **低黏度 → 气泡容易逃逸 → 岩浆以液体形式喷出 → 溢流式 (effusive)**
   - **高黏度 → 气泡逃不掉、生长受阻 → 气泡最终爆裂时把岩浆撕碎（"碎屑化" fragmentation）→ 岩浆以火山碎屑 (pyroclasts) 形式喷出 → 爆发式 (explosive)**

两条独立的"增强爆发性"规则（讲义原文逻辑，务必分清）：
- **黏度越大** → 岩浆越抵抗膨胀 → 越可能碎屑化 → 越可能爆发。
- **挥发分越多** → 岩浆膨胀量越大 → 爆发潜力越大。

> 二者是**乘积效应**而非替代关系。所以会出现"低黏度但富水"的斯特龙博利式 (Strombolian)（弧下含水玄武岩），也会出现"高黏度但不爆"的熔岩穹丘 (lava dome)（高效脱气 + 极慢的喷出速率）。**喷出速率 (eruption rate)** 是第三个隐含变量。

#### 4. 描述一块火山岩的七要素（"巧克力曲奇"法）
讲义的教学梗：**"Can you describe the chocolate chip cookie? If yes, you can describe a volcanic rock!"**
练习册末尾那个"神秘样品"——*淡棕色、略具气孔、盘状、直径约 8 cm、厚约 1 cm、含棕色锥形 5 mm 包裹体约占体积 10%*——就是一块巧克力曲奇。用意：**描述岩石不需要先认识它，只需要系统地、用标准词汇报告你看到的东西**；解释 (interpretation) 是描述之后才做的第二步。

七要素（每块样品 20 min）：

| 要素 | 要回答的问题 | 能推出什么 |
|---|---|---|
| **Size 尺寸** | 大致尺寸（cm，三个轴） | 是否为独立碎屑 (clast) 还是从大岩体上敲下来的 |
| **Shape 形状** | 浑圆 (rounded)、棱角 (angular)、长条 (elongate) 还是块状 (blocky)？**各面结构是否一致？** | 各面结构不同 → 可能同时保存了熔岩流顶部与内部；贝壳状断口 (conchoidal fracture) → 玻璃质 |
| **Colour 颜色** | 浅色还是深色？暗淡 (dull)、有光泽 (shiny) 还是玻璃质 (glassy)？ | 基性 (mafic, 如 basalt) 一般深色，长英质 (felsic, 如 rhyolite) 一般浅色（**但有例外**） |
| **Mineralogy 矿物学** | 有无晶体？多大？什么形状、颜色？ | 斑晶 (phenocryst) 组合可定成分（如橄榄石+斜长石 → 拉斑玄武岩 tholeiitic basalt） |
| **Density 密度** | 掂起来轻还是重？ | 直接反映气孔度 |
| **Vesicularity 气孔度** | 有无气泡？大小、形状、丰度？ | **最关键的爆发性指标**——气孔多 = 挥发分富 = 更可能爆发 |
| **Eruption style 喷发方式（解释）** | 综合以上，推断爆发式还是溢流式 | 本练习的最终产出 |

### 下午场

#### 1. 颗粒形状 (grain shape) 的两个独立分量
讲义开宗明义：描述颗粒形状要**同时记录两件事**，且二者**互不相干**——

**(a) 棱角度 / 圆度 (angularity / roundness)**
- 指颗粒的**棱角是尖锐还是被磨圆**（smooth vs jagged）。
- 讲义特别指出：这个属性"通常、而且是误导性地"被叫作 **roundness**（"圆度"）——因为"圆"容易让人误以为在说整体是不是球形，其实说的只是**角与棱的磨蚀程度**。
- 描述用语：well rounded ↔ poorly rounded（实际操作用 Pettijohn et al. (1987) 的六级视觉对比卡：**very angular / angular / subangular / subrounded / rounded / well rounded**）。

**(b) 球度 (sphericity)**
- 指颗粒整体形状有多"等轴 (equant)"，由**长轴 (long)、中轴 (intermediate)、短轴 (short)** 三轴之比决定。
- 不呈球形时用标准几何术语描述（如 **prolate spheroid** 长椭球）。
- Illenberger (1991) 的四类形状：**球 (spheres)、盘 (discs)、杆 (rods)、片/叶 (blades)**。

> ⚠️ 这两者必须**分开报告**。一个颗粒完全可以是"棱角分明的球"（angular, high sphericity）或"磨得很圆的盘"（well rounded, disc）。本周的样品描述表就是按 "Grain shape"（球度/形状）与 "Angularity"（棱角度）两行分开填的。

#### 2. 实操：用比较卡 (comparators) 目视估计
- 实际野外与实验室中**不测轴长**，而是用**视觉对比卡 (visual comparator chart)** 目估圆度与球度。
- **粒度卡 (grain size card)** 在野外工具包 (field kit) 里，卡上就印着最有用的一张圆度/球度对比图——粒度、圆度、球度一张卡搞定。
- 好处：快、可复现、可跨人比较；代价：半定量，人与人之间有系统偏差（见第六节易错点）。

#### 3. 解释 (interpretation)：形状告诉我们什么
**棱角度 → 搬运历史（有用）**
- 棱角度反映颗粒**被搬运了多远、多剧烈**。
- **一群非常磨圆的颗粒 (very well rounded)** → 要么经历了**多次搬运旋回 (many cycles of transport)**，要么在**高能环境 (high energy environment)** 中被强烈磨蚀（例如**沙漠 (desert)** 或**海滩 (beach)**）。
- **粒径依赖性**：这条规则**主要适用于砂级 (sand-sized) 及更粗的沉积物**。颗粒越细，越会被其搬运流体"缓冲 (cushioned)"而不发生颗粒间撞击——所以**"棱角状的粉砂 (angular silt)" 完全不值得大惊小怪**，它不代表近源。
- 相反，**粗颗粒的棱角掉得很快**：砾石 (gravel) 通常在**几公里到几十公里**的搬运距离内就把角磨掉了。

**球度 → 母岩各向异性（用处较小）**
- 球度主要反映**母岩的各向异性 (anisotropy of the parent material)**：母岩成分本身，或岩石中的**弱面 (planes of weakness)**——层理/纹层 (bedding/lamination)、劈理 (cleavage)、节理 (jointing)。
- 例：**杆状体（如岩脉/矿脉 veins）风化成"橄榄球状"碎屑**；**板岩 (slate) 产出盘状 (disks) 碎屑**。
- 因此球度对**判断搬运环境几乎无用**，但对**溯源母岩类型**有价值——在法证情景中这一点很重要（见下午场推理链）。

#### 4. 沉积物"指纹"还包括什么（本周报告实际用到的字段）
除形状二分量外，四份警方报告统一使用以下字段：

- **Composition 成分**：按**体积百分比**列出各组分，并按相对丰度排序。本周出现的组分类别：
  - **陆源碎屑**：石英 (quartz)、长石 (feldspar)、云母 (mica)、角闪石 (hornblende)、燧石 (chert)、细粒砂岩 (fine grained sandstone)
  - **火成/变质岩屑 (lithic grains)**：基性火成岩 (basic igneous, 含玄武岩 basalt、辉长岩 gabbro)、变质基性侵入岩 (metamorphosed basic intrusive igneous)、花岗岩 (granite)、风化花岗岩 (weathered granite)
  - **碳酸盐/生物碎屑 (bioclasts)**：贝壳碎片 (shell fragments)、双壳类 (bivalves)、腹足类 (gastropods)、有孔虫 (forams)、苔藓虫 (bryozoa)、海胆棘刺 (echinoid spines)、鱼牙 (fish teeth)、**珊瑚藻 (coralline algae / *Corallina*)**、灰岩 (limestone)、方解石 (calcite)
- **Grain size 粒度 / 粒度分布**：本周的关键判据是**双峰粒度分布 (bimodal grain size population)**——出现双峰意味着**两种来源的沉积物混合**，必须拆成 Population 1 / Population 2 分别描述。此外"某组分只出现在粒度分布的细端 (fine end)"本身也是一条可用信息。
- **Other observations 其他观察**：
  - **磨光 (polished) / 高度磨蚀 (high degree of abrasion)**：高能、长期磨蚀
  - **霜面 (frosted grain surface)**：颗粒表面呈毛玻璃状 → **风成 (aeolian)** 磨蚀的标志 → 沙丘 (dune)
  - **铁氧化物染色 (Fe oxide staining)**：陆上氧化环境中滞留、风化
  - **人工集合体 (man-made aggregates of quartz grains)**：人造/破碎骨料 → 停车场、道路铺面等人工场所
  - **化石特征**：如"被钻孔的完整 *Turritella*（塔螺）壳，长 3–9 mm"——单个诊断性化石也能定位

> **判读逻辑速记（表 A 的用法）**：
> 1. 看**气孔度** → 定爆发性（高气孔 = 爆发；无/少气孔 = 溢流 **或** 玻璃质快冷）。
> 2. 看**颜色 + 矿物** → 定成分（深色+橄榄石/斜长石 = 玄武质；浅色 = 流纹质；**玻璃质深色是陷阱**）。
> 3. 看**形状/结构** → 定产状（独立碎屑 = 碎屑化产物；从大岩体敲下 + 多种表面结构 = 熔岩流）。
> 4. 成分 + 气孔度 + 产状 → 反推喷发样式与构造背景。

### 上午场：Volcanism in the Earth system — eruption styles and eruption products

#### Part 1：喷发样式判读（60 min，每张图 5–10 min）
**目的**：把火山喷发的**图像观察**转换为对**岩浆黏度、挥发分含量、喷发样式、构造背景**的推断。

**操作步骤**（实验室墙上贴有 6 张图，编号 B–I；对每张图依次回答 5 个问题）：
1. **这次喷发是溢流式还是爆发式？你能观察到熔岩、火山灰，还是两者都有？**
2. **岩浆黏度是高还是低（是"黏"还是"稀"）？**
3. **喷发前岩浆的挥发分含量可能是高还是低？**
4. **对照 Figure 1 与 Figure 2，这张图最可能代表哪种喷发类型？**（明确允许有多个答案 / 样式可能不清晰）
5. **对照 Figure 3，这个岩浆最可能在什么构造背景下喷发？**

**判读时的观察抓手（如何"看"）**：
- **看喷出物形态**：连续的液态流 → 熔岩流；发光的抛射碎块 → tephra / 火山弹；灰色/棕色柱状云 → 火山灰。
- **看喷发柱高度**：无柱/极低 → Hawaiian；几百 m 的短促脉冲 → Strombolian；几 km → Vulcanian；数十 km + 火山碎屑密度流 → Plinian。
- **看火山形态**：低平宽缓的**盾状火山 (shield)** → 低黏度玄武质，多为热点/洋中脊；陡峭的**层状锥 (stratocone)** → 高黏度、含水，多为弧；**陡壁穹丘 (steep-sided dome)** → 极高黏度流纹质。
- **看气体**：气体量大但没有强柱 → 可能是含水的低黏度岩浆（Strombolian）；**注意区分火山气与地面被加热产生的水蒸气**（图 B 的陷阱）。
- **看熔岩流动性**：流得快、成薄流、有绳状面 → 低黏度玄武质。

**答案汇总见【表 B】**。

#### Part 2：喷发产物描述（60 min，每块样品 20 min）
**目的**：用系统化的手标本描述，**反推**每块岩石形成时的喷发条件。

**原理**：火山岩的**形状与结构保存着它如何形成的信息**。特别地，**密度和孔隙度 (porosity)** 记录了冷却与固结过程中**挥发分出溶的程度**，因此直接反映**喷发的爆发性 (explosivity)**。对火山岩的仔细观察让我们能了解过去的喷发、重建火山的历史——进而**理解并预测活火山未来的行为、评估其对社会构成的风险**。

**操作步骤**：对 **pumice / basalt / obsidian** 三块样品，各花 20 min，依次记录：
Size → Shape → Colour → Mineralogy → Density → Vesicularity → **Eruption style（解释）**
（每一项的具体提问见【二、核心概念 · 上午场 · 4】的七要素表）

**数据如何记录**：逐项分行、写成完整句子的定性描述 + 定量估计（cm 尺寸、mm 级晶体/气孔尺寸、体积百分比）。**必须把"观察"与"解释"分开写**——前六项是观察，第七项才是解释，而且解释要**引用前六项中的具体证据**。

**结果如何判读（三块样品的完整推理链）**：

**浮岩 (Pumice)**
> 观察：高气孔度（可见气孔 0.5 mm–1 cm，约 50% 体积，部分拉长）；淡棕色暗淡；本身是一块独立的浑圆块体。
> 推理：**高气孔度 → 岩浆富挥发分**；**淡色 → 流纹质成分**；**是一个独立碎屑 (discrete clast) → 岩浆被碎屑化过**。
> 结论：**爆发式喷发**。更细的机制：**浮岩碎屑是岩浆碎屑化 (fragmentation) 但碎得还不够彻底（没有碎成更细的火山灰颗粒）时形成的**。可对应图 C（Vulcanian）与图 F（Plinian）那样的喷发。
> 补充：实际浮岩的气孔率是 **90–95%**，3D 模型分辨率下只能看到约 50%——**要意识到观察工具的分辨率极限会系统性低估气孔度**。

**玄武岩 (Basalt)**
> 观察：**两个大面结构截然不同**——一面光滑、褶皱、玻璃质、**无气孔**；另一面粗糙、灰–棕、含 20–40% 的浑圆气孔（3 mm–1 cm）；其余四面在距光滑面几 cm 处可见两者的界面；深色；少量 < 5% 的白色小晶体。
> 推理：**低气孔度 → 贫挥发分岩浆**；**深色 → 玄武质**；**看起来是从更大的岩体上取样下来的 → 属于熔岩流的一部分**。
> **结构的深层解读（本节最漂亮的一步）**：光滑而褶皱的面就是 **pahoehoe（绳状熔岩，夏威夷语意为"光滑的熔岩"）**，它是**熔岩流快速冷却的顶面**；粗糙的面则是**缓慢冷却的熔岩流内部**。二者之间那条距顶面几 cm 的界面就是**冷却壳的厚度**。
> 结论：**溢流式喷发的熔岩流**。可对应图 B、E（也许还有 G）。
> 附加：讲义中的 **MV01（冰岛 Fagradalsfjall）** 示范样品走的是同一条链——蓝色玻璃质表面 + 细粒基质 → **快速冷却**；仅一个 ~6 mm 气孔 → **不是爆发产物 → 溢流（熔岩流）**；绿色斑晶 = **橄榄石 (olivine)**、白色斑晶 = **斜长石 (plagioclase)** → 典型**拉斑玄武岩 (tholeiitic basalt)**；黑/深棕的基性成分（低硅、高 Fe/Mg）→ **低黏度玄武质岩浆**。最终结论：**贫挥发分的玄武质岩浆的溢流喷发，典型于洋中脊/热点火山活动（如冰岛、夏威夷）**。

**黑曜岩 (Obsidian)**
> 观察：玻璃质、暗蓝灰；表面极光滑，被棱角状边分隔，**部分面见贝壳状断口 (conchoidal fracture)**；**无可见气孔**；无可见晶体。
> 推理：**颜色深，但这里的深色反映的是"玻璃质"而非成分**——黑曜岩通常是**流纹质**的（这是本练习最重要的"颜色陷阱"）。**无气孔 → 挥发分在喷出前已经跑掉了**。
> 结论：**溢流式喷发**——挥发分逃逸得足够快，阻止了岩浆碎屑化与爆发。这种情况**通常发生在喷发极其缓慢、出溶的挥发分有充足时间在岩浆上升过程中逃逸**、最终形成熔岩流时。
> **另一条形成途径**：黑曜岩也可以由**浮岩碎屑在高温下被压实、把所有气孔挤出去 (all of their vesicles squeezed out while hot)**，只留下液体岩浆而形成。
> 可对应图 I（Chaitén 的熔岩穹丘）。

> ⚠️ **讲义原文的一处笔误**：Obsidian 的 Eruption style 段写的是 "The **low viscosity** of the obsidian suggests that it formed during an effusive eruption"——按上下文（前一句刚说"Given its relatively low vesicularity, the obsidian is likely to be quite dense"）以及整套逻辑，这里应为 "**low vesicularity（低气孔度）**"。黑曜岩是**高黏度**的，绝不是低黏度。复习时不要被这句带偏。

### 下午场：Forensic geology — 沉积物比对与凶案推理

#### 步骤 0：本节的方法论框架
这场练习的形式是**假设检验**：
- **假设集**：四个 alibi（"我当时在 X 地"）。
- **检验方法**：从每人身上/装备/车辆采集沉积物，与 **(a) 他声称去过的地方**、**(b) 与案件有关的地点（陈尸海滩、营地、以及真正的凶案现场）** 逐一比对。
- **判据**："两份样品的球度、棱角度、成分比例、表面结构、诊断性生物碎屑**全部吻合**" → 判为同源；**任何一项显著不符** → 判为异源。
- **产出**：不是"凶手是谁"这个名字，而是**一条从观察到结论、每一步都可回溯到具体样品字段的证据链**。

```
S1A / S1E           = Snowdonia 山区花岗岩（Digimap 独立证实）
S3B (Rhodri 靴底)   = 93% 燧石砾 → 与 S3A (Location 3 海滩) 完全不符
S2A (Location 2)    = 珊瑚藻+灰岩 → 在 Giles 身上任何样品中都找不到
```

**每一条等式背后的具体判据**（这是"可复现的观察证据"的体现——不是"看起来像"，而是逐字段吻合）：
- **V1 = S1B**：两份描述**逐字相同**——50% 石英、48% 贝壳质（且**丰度排序、物种清单、连"绿色和紫色的海胆棘刺"这样的细节都一致**）、2% 基性火成岩；矿物 spherical–subspherical、贝壳质 rounded–well rounded、石英 subangular–subrounded；且都有"**贝壳碎片磨光、高度磨蚀**"。这份沉积物的**生物碎屑组合极其复杂**（3 种完整腹足、2 种有孔虫、2 种苔藓虫、两色海胆棘刺、鱼牙），这种多组分组合**偶然重合的概率极低**，是本案最强的指纹。
- **V1 = S2C**：S2C（Giles 指甲缝）与 V1 同样逐字吻合，包括"polished shell fragments – high degree of abrasion"。
- **V2 = S1D = S2B = S4A**：都是"40% 贝壳碎片 + ~10% 珊瑚藻 + 40% 石英 + 10–20% 基性火成岩（含辉长岩 gabbro）及变质基性侵入岩"，且棱角度都是 **v. angular–subangular**。**辉长岩 + 变质基性侵入岩这个组合是 Location 4 独有的**（陈尸海滩只有 2% 基性火成岩且含玄武岩，成分比例完全不同）。
- **V3 = S1C = S4B-Pop1**："95% quartz + 5% calcite（只在细端）+ spherical + 90% rounded–well rounded / 10% subangular + **frosted 表面 + Fe oxide staining**"。**霜面**是风成沙丘的判据，**方解石只出现在细端**是一条非常具体、难以偶然重合的特征。
- **S3C = S4C = S4B-Pop2**："100% quartz + very angular + **man-made aggregates of quartz grains** + Fe oxide staining"。"**人造集合体**"这一特征直接排除任何自然海滩来源。

#### 步骤 4：逐个嫌疑人的推理

**Suspect 1 — Dave（`Summary` 原文结论）**
- S1A、S1E **与山区环境一致**，且 **Digimap 证实了对该火成岩的鉴定** → 他**确实去过 Snowdonia**。手帕鼻黏液中的 mica + hornblende + quartz + feldspar 也是花岗质矿物组合，与山区粉尘一致。
- **但是**：**S1B 来自发现 Stan 尸体的那片海滩——车去过那里，因为沙嵌在轮胎花纹里。**
- **S1C 是营地。**
- **S1D 说明车里的某个人去过 Location 4 的海滩。**
- **轮胎花纹的层序推理（本案最巧妙的一步）**：报告明确写明 "Samples occurred in the tyre tread in the following order, **from inside to outside**, S1A, S1B, S1C"。轮胎花纹中的沉积物是**逐次叠加**的——**最里层最早、最外层最晚**（这是**叠覆律 superposition** 在法证语境下的应用）。所以行车顺序是：**山区 (S1A) → 陈尸海滩 (S1B) → 营地 (S1C)**。也就是说，**车是在离开山区之后、回到营地之前去了陈尸海滩的**。
- 结论：**Dave 的 alibi 部分为真（去过山区），但他的车被用于案件相关的移动**。

**Suspect 2 — Giles（`Summary` 原文结论）**
- "**没有任何证据表明他去过 Location 2 的海滩。**" —— S2A（Location 2）那套极具辨识度的成分（**49% *Corallina* + 33% 灰岩 + 被钻孔的 *Turritella***）**在他的裤腿和指甲缝里一点都没有**。这是**"缺席证据 (absence of evidence)" 的正确使用**：如果他真的整天在那片珊瑚藻/灰岩海滩上采集植物，裤腿上不可能一点都不沾。
- "**从他衣物和身上取得的样品表明他去过 Location 4 的海滩、以及发现尸体的那片海滩。**"
  - **裤腿 (S2B) = Location 4 = 颅骨内部的沉积物 (V2)** → 他去过**凶案现场**。
  - **指甲缝 (S2C) = 陈尸海滩 (V1)** → 他**用手在陈尸海滩上做过事**（指甲缝里的沙意味着**用手接触过沙地**——搬运/掩埋尸体的动作）。
- 植物证据 *Spartina anglica* / *Salicornia europaea* 是盐沼植物，与他"采稀有植物"的说法不冲突，但**不能把他放在 Location 2**。
- 结论：**alibi 彻底崩塌**，且他同时与**凶案现场**和**弃尸现场**有物证联系。

**Suspect 3 — Rhodri（`Summary` 原文结论）**
- "**S3C 是酒吧停车场，而 S3B 与 Location 3 的海滩不一致。**"
  - S3A（Location 3 海滩）= **100% 石英、sub-spherical、rounded–subrounded**；
  - S3B（他的靴底）= **93% 燧石 + 5% 细粒砂岩 + 1% 石英 + 1% 贝壳碎片、well rounded、球度高低都有** ——**成分与球度都对不上**，绝无可能来自 S3A。
- 结论：**他关于 Location 3 的说法是假的**；轮拱证明他去过酒吧停车场。**但——他的任何样品都与 V1、V2、V3 不匹配**，所以**沉积物证据不把他与凶案联系起来**。
- **教学点**：**"撒谎" ≠ "有罪"**。发现一个 alibi 是假的，只意味着这个人有别的事想隐瞒；要定罪，还需要物证把他**放到犯罪现场**。

**Suspect 4 — Rob（`Summary` 原文结论）**
- "**S4B 是营地的沙和酒吧周围的沙的组合；植物 *Limonium britannicum* 只见于 Location 4，所以他一定去过那里。**"
- 完整逻辑：
  - **双峰粒度分布 (bimodal grain size population)** 本身就是"**这双鞋踩过两个不同的地方**"的直接证据。拆开后：Pop1 = 营地（霜面、Fe 染色、95% 石英 + 5% 细端方解石），Pop2 = 酒吧停车场（人造石英集合体）。
  - 鞋上**完全没有任何海滩沉积物** → 换鞋 (1115) 之后他**没有再去过任何海滩**。
  - *Limonium britannicum* 证明他**上午确实在 Location 4**（与他自己的说法一致，且他从未否认）。
  - 酒吧老板的证词（1200 到、1745 后离开）**覆盖了手表停止的 1735**。
- 结论：**alibi 成立，排除嫌疑**。他是四人中唯一**沉积物证据、植物证据、人证三线互相印证**的人。

#### 步骤 5：小组要回答的四个问题（`Summary of Findings`，每题都要给证据）

**Q1. 受害者是在哪里被杀的？**
> **答：Location 4 的海滩。**
> **证据链**：**V2 = 破碎颅骨内部 + 结块头发 + 衣袋里的沉积物**，其描述与 **S4A（Location 4 海滩）** 完全一致（40% 贝壳碎片 + 10% 珊瑚藻 + 40% 石英 + 10–20% 含辉长岩的基性火成岩及变质基性侵入岩，v. angular–subangular）。
> **为什么"颅骨内部"是关键**：沉积物**被打进颅骨的伤口内部**（以及嵌进结块的头发里），只可能发生在**致命打击落下的那个地点**——它不可能是后来搬运尸体时才沾上的表面污染。这是本案**把"凶案现场"与"发现尸体的地点"区分开**的唯一直接证据。
> **推论**：陈尸海滩 (V1) 与凶案现场 (V2) 是**两个不同的地方** → **尸体被移动过**。移动尸体需要**车**。

**Q2. 是谁干的？**
> **答：Giles（Suspect 2）。**
> **证据**：他的**裤子在 Location 4**（S2B = V2 = 凶案现场），他的**指甲缝显示他去过发现 Stan 尸体的那片海滩**（S2C = V1）。同时他声称的 Location 2 在他身上找不到任何痕迹。
> **补充结论（`Summary` 原文）**：**他需要一辆车把尸体从 Location 4 运走，所以 Dave 可能也参与其中——他的车肯定参与了。**（S1D = Location 4 沙在车内；S1B = 陈尸海滩沙在轮胎花纹里；轮胎层序显示车在返营前去过陈尸海滩。此外**现场那条手帕上的花岗质矿物鼻涕**也与刚从山区回来的 Dave 相符。）

**Q3. 你对自己的判读/结论有多大把握？**
> **答（`Summary` 原文）**：**沉积物证据当然可以强化警方对 Giles 的指控，但并非 100% 确定。**
> **不确定性的来源（要能自己说出来）**：
> - 沉积物描述是**定性/半定量**的，百分比是目估，圆度是比较卡分级——存在观察者间的系统偏差。
> - **相似的沉积环境可能产出相似的沉积物**——"匹配"是**不能排除同源**，而不是**证明同源**。
> - **二次转移 (secondary transfer)** 无法排除：Giles 裤腿上的 Location 4 沙可能来自坐过 Dave 的车、或与去过 Location 4 的人接触。
> - 沉积物只能建立**空间**联系，**不能给出时间**——它无法证明 Giles 是在 1735 那一刻在 Location 4 的。手表停在 1735 也只是**推定**死亡时间。
> - 样品数量少，每个地点只有一份描述，**没有做重复采样以评估地点内部的变异性**。

**Q4. 你还想收集哪些额外数据来帮助判读？**
> **答（`Summary` 原文）**：**对砂样做统计分析会更精确 —— 见 Week 10。**
> 即：从"两份描述看起来一样"升级为**定量的粒度分布统计**（平均粒径、分选性 sorting、偏度 skewness、峰度 kurtosis 等参数的比较，以及显著性检验），把"匹配"变成一个**可以给出概率的陈述**。
> 可以进一步提出的（延伸思考）：重矿物组合分析、每个地点的多点重复采样以刻画地点内变异、微体化石/孢粉分析、以及对二次转移的对照实验。

#### 步骤 6：这场练习真正要教的东西
1. **先描述、后解释**：所有结论都必须能追溯到某一个具体的描述字段。
2. **建立参照库再匹配**：先把已知地点指纹化，再匹配未知样品，避免确认偏误。
3. **多组分组合比单一特征强得多**：单看"50% 石英"毫无意义，但"50% 石英 + 特定的 8 类生物碎屑按特定丰度排序 + 磨光"几乎是唯一的。
4. **"缺席"也是证据**：Giles 身上**没有** Location 2 的珊瑚藻，与"整天待在那里"直接矛盾。
5. **层序含时间信息**：轮胎花纹由内到外 = 由早到晚。
6. **多峰分布 = 多来源**：遇到 bimodal 必须拆开分别归因。
7. **多条独立证据线交叉验证**：沉积物 + 植物 + 人证 + Digimap 地质图 + 手表时间。
8. **明确报告不确定性**：结论要带置信度和局限性说明，并指出还需要什么数据。

## 六、易错点 / 重点难点

### 上午场
1. **颜色 ≠ 成分（最大的陷阱）**。讲义两次强调：基性岩"一般（但并非总是）"深色。**黑曜岩是深色的，但成分是流纹质（长英质）**——深色来自**玻璃质**，不是来自 Fe/Mg。判成分要综合矿物学、气孔形态、产状，不能只看颜色。
2. **气孔度 (vesicularity) vs 黏度 (viscosity) 别写混**。参考答案里 obsidian 那句 "The low **viscosity** of the obsidian..." 是笔误，应为 "low **vesicularity**"。黑曜岩是**高黏度**的。
3. **高黏度 ≠ 必然爆发**。图 I（Chaitén 熔岩穹丘）：极黏的流纹质岩浆，只要**脱气高效 + 喷出速率极低**，就可以安静地挤出成穹丘。**喷出速率是第三个控制变量。**
4. **玄武质 ≠ 必然在洋中脊/热点**。图 G（Stromboli）是玄武质但**富 H₂O**，判为**火山弧**。判构造背景要**同时看成分和挥发分**。
5. **"白烟"不一定是火山气**。图 B（Holuhraun）：熔岩烤热周围**潮湿地面**产生的大量水蒸气会被误认为喷发柱，从而高估挥发分含量。
6. **区分"减压熔融"与"流体熔融"**。洋中脊/热点 = 地幔上涌 → **decompression melting** → 干；弧 = 俯冲板片脱水 → **flux melting** → 湿。这两个词经常被写反。
7. **观察工具的分辨率会系统性偏差**。3D 模型上浮岩只看得到 ~50% 气孔，实际是 **90–95%**。描述时要注明"在本分辨率下"。
8. **"没有可见晶体"要写成"在本分辨率下不可见"**，不要写成"不含晶体"——很多浮岩和黑曜岩都是含晶体的。
9. **一块样品的不同面可能记录不同过程**。玄武岩的 pahoehoe 光滑面（快冷的流顶）与粗糙面（慢冷的流内部）——**Shape 那一栏专门问"Does it have the same texture all over?"就是为了逼你注意这件事**。
10. **喷发样式是连续谱**。允许并鼓励给出带保留的答案（如"有火喷泉但可能太小，不足以定为 Hawaiian"），这是专业性的体现而非含糊其辞。
11. **描述与解释必须分开**。七要素中前六项是观察，第七项才是推断；不要在"Colour"栏里写"因为是玄武质所以是黑的"。
12. **Plinian 示意图里没有熔岩流/熔岩喷泉/火山弹**——各类型示意图的"缺项"本身是判读依据。

### 下午场
1. **"Roundness（圆度）"这个词有误导性**。讲义原文明确指出这一点：它说的是**棱角磨蚀程度 (angularity)**，**不是**整体形状是否球形。**Roundness 与 Sphericity 是两个完全独立的量**，必须分别报告。
2. **别用细粒沉积物的棱角度做搬运距离推断**。细颗粒被流体"缓冲"，**角状粉砂 (angular silt) 不代表近源**。这条规则**只对砂级及更粗的沉积物有效**。反过来，**砾石的棱角掉得极快**（几 km–几十 km），所以粗砾还很棱角 = 极近源。
3. **别用球度推断搬运环境**。球度主要反映**母岩的各向异性**（成分、层理/纹层、劈理、节理），是**溯源**指标而非**过程**指标。
4. **"匹配"是"不能排除同源"，不是"证明同源"**。这是法证推理的根本局限，第 3 题答案 "not 100% certain" 就是这个意思。
5. **要区分"凶案现场"与"发现尸体的地点"**。判据是沉积物**在体内（颅骨内部、结块的头发中）** 还是**在体表/周围**。**打进伤口里的沙 = 打击发生地**。
6. **"缺席证据"要会用**：Giles 身上找不到 Location 2 那套极有辨识度的珊瑚藻/灰岩沉积，正是推翻他 alibi 的核心。但使用时要谨慎——只有当"如果假设为真则必然留下痕迹"成立时，缺席才有说服力（他声称在那里待了**整天**，所以成立）。
7. **双峰粒度分布必须拆开**。看到 "Bimodal grain size population!!" 却当成一个总体去匹配，就会两边都对不上。
8. **轮胎花纹/鞋底的沉积物是有层序的**。"from inside to outside" 就是"从早到晚"。忽略这句话就丢掉了 Dave 的行程顺序信息。
9. **撒谎 ≠ 有罪**。Rhodri 的 alibi 是假的（他在酒吧不在 Location 3），但没有任何物证把他放到犯罪现场——所以他不是凶手。要把"alibi 不成立"和"与犯罪现场有联系"分成两个独立的判断。
10. **二次转移 (secondary transfer)**：沉积物可以通过共乘一辆车、共用装备等途径转移。物证建立的是"接触过"，不是"亲自到过"。
11. **只看单一成分百分比会误判**。陈尸海滩和 Location 4 海滩**都含石英和贝壳碎片**，区别在于**比例**（50/48/2 vs 40/40/20）、**基性岩屑的类型**（玄武岩 vs 辉长岩+变质基性侵入岩）、**珊瑚藻的有无**、以及**棱角度**（rounded–well rounded vs v. angular–subangular）。**必须逐字段全项比对。**
12. **人工特征要认得出**。"man-made aggregates of quartz grains" 是人造骨料，指向停车场/铺面，绝不是天然海滩。
13. **表面结构 frosted 是风成标志**，polished 是水动力高能磨蚀标志——两者不要混。
14. **沉积物给不出时间**。它只能建立空间联系，死亡时间要靠手表 (1735)、人证（酒吧老板）等其他证据线。
15. **分组作业里每一题都要求 "Be sure to give evidence for your answers"**——答案只写结论不给证据会失分。

| groundmass | 基质 | 岩石中包裹斑晶的细粒或玻璃质部分 |

| olivine | 橄榄石 | 绿色的镁铁质硅酸盐；玄武岩中常见斑晶 |
| plagioclase | 斜长石 | 白色的长石族矿物；玄武岩中常见斑晶 |
| pahoehoe | 绳状熔岩 / 帕霍伊霍伊熔岩 | 夏威夷语"光滑的熔岩"；表面光滑而褶皱，是熔岩流快速冷却的顶面 |
| pillow basalt | 枕状玄武岩 | 玄武质熔岩在水下（洋中脊）喷发形成的枕状构造 |
| lava flow | 熔岩流 | 溢流式喷发形成的流动熔岩体 |
| lava fountain / fire fountain | 熔岩喷泉 / 火喷泉 | 低黏度岩浆被气体驱动喷成的炽热喷泉；高大者是 Hawaiian 式的判据 |
| lava dome | 熔岩穹丘 | 极黏岩浆缓慢挤出堆积成的陡壁穹状体（如 Chaitén） |

| shield volcano | 盾状火山 | 低黏度玄武质熔岩堆积成的宽缓低平火山，多见于热点 |
| stratocone / stratovolcano | 层状火山 / 成层火山 | 熔岩与火山碎屑互层堆积成的陡坡锥形火山，多见于火山弧 |

| fumarole | 喷气孔 | 火山气体逸出的孔洞 |

| pyroclastic density current (PDC) | 火山碎屑密度流 | 沿地面高速运动的炽热灰、气与碎屑混合流；Plinian 喷发最致命的产物 |
| magma conduit | 岩浆通道 | 岩浆从岩浆房上升到地表的管道 |
| magma chamber | 岩浆房 | 地壳中储存岩浆的储集体 |
| dyke | 岩墙 | 切穿围岩层理的板状侵入体 |
| sill | 岩床 | 顺围岩层理侵入的板状侵入体 |
| country rock | 围岩 | 被岩浆侵入/穿切的原有岩石 |
| Hawaiian eruption | 夏威夷式喷发 | 低黏度玄武质，高大火喷泉、熔岩湖、熔岩流，灰柱极小 |
