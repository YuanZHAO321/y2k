## 二、核心概念

### 2.1 什么是稳定同位素研究？

**同位素 (isotope) 的定义回顾**：质子数 $Z$ 相同（因而是同一元素、电子构型相同）、**中子数不同**因而**核质量不同**的原子。上标数字表示**核的质量数 (mass number)**，例如 $^{16}\mathrm{O}$ 与 $^{18}\mathrm{O}$。

**核心事实链**：

1. 在地球化学过程中，同一元素的不同同位素**行为略有不同**；
2. 结果是：一个反应中的**不同相 (phases) 会有不同的同位素比值**；
3. 这种不同同位素的**分离 / 分配**称为 **分馏 (fractionation)**；
4. 分馏的根本原因是**同位素之间的质量差**，质量差进而影响**键强 (bond strength)**、**动能 (kinetic energy)** 等因素。

**旗舰例子——贝壳里的方解石与海水交换氧**：

$$\mathrm{CaC}^{16}\mathrm{O}_3 + \mathrm{H}_2^{18}\mathrm{O} \;\rightleftharpoons\; \mathrm{CaC}^{18}\mathrm{O}_3 + \mathrm{H}_2^{16}\mathrm{O}$$

- 这是**纯粹的同位素交换 (isotopic exchange)**，**不是化学变化**——反应前后化学式完全一样，只是重同位素换了位置。这一点极其重要，后面地温计全靠它。
- 氧在两边处于**不同的成键环境 (bonding environments)**：一边是 CO$_3^{2-}$ 内的 C–O 键，一边是水中的 H–O 键。
- 结果：**方解石偏好 $^{18}\mathrm{O}$**，即 $^{18}\mathrm{O}/^{16}\mathrm{O}$ 在方解石中比在水中高。
- 而且：**方解石中的 $^{18}\mathrm{O}/^{16}\mathrm{O}$ 随温度变化** → 这正是地温计/古温度计的基础。

老师补充：因此我们可以查地质记录中的碳酸钙，看这个比值如何变化。但要注意它是**两个变量的函数**：(a) 温度，(b) 水本身的同位素比值——而后者又受**水文循环 (hydrological cycle)** 控制，取决于**地球上有多少冰**。这既是复杂性，也是机会（可以反过来追踪冰期演化）。

### 2.3 周期表上的颜色编码与"标准原子量"的含义

老师讲了一张"用颜色标注同位素情况"的周期表，逻辑如下：

- **标准原子量 (standard atomic weight) = 该元素所有稳定同位素按其自然丰度做的加权平均 (weighted average)**。
  - 只有一个稳定同位素 → 原子量是一个确定的单值；
  - 有多个稳定同位素 → 按自然丰度加权平均。
  - 老师举例：碳的原子量不是 12，而是 $0.989 \times 12 + 0.011 \times 13 \approx 12.011$。
- **白色格子**：**没有标准原子量**，因为所有同位素都是放射性的、短寿命的（ephemeral），没有稳定的平均原子质量。
- **蓝色 / 黄色**：用于确定标准原子量的同位素数目不同。
- **粉色格子（关键）**：这些元素的**同位素丰度在自然界中以已知的方式发生变化**，所以 IUPAC 不给单一原子量，而是给一个**上下界区间 (bounded by two limits)**。
  - 例：碳的原子量区间约为 $[12.0096,\ 12.0116]$（transcript ASR 报成 12.0196，以区间概念为准）。
  - **正是这些"粉色元素"成为我们研究的稳定同位素体系**——因为丰度会变，才有信息量。

### 2.4 为什么是 H, C, N, O, S？（六条理由，考点）

讲义列出六条，逐条理解：

**1. 同位素之间的相对质量差大 (relative mass difference is large)**
- H：$^2\mathrm{H}$ 与 $^1\mathrm{H}$ 的质量差是**整整 2 倍**（加一个中子直接让核质量翻倍）；
- C：$^{13}\mathrm{C}$ 比 $^{12}\mathrm{C}$ 重 **8%**；
- 这五个都是**轻元素**，所以加一个中子对总质量的**百分比影响很大** → 分馏效应显著。
- 反过来说，重元素（如 Sn）加一个中子只改变约 1% 的质量，质量分馏效应很弱。

**2. 这些元素在自然界丰度高**，是常见地球物质的主要组成部分，且**在常见的固体、液体、气体中都出现**（这一点很关键：分馏发生在相与相之间，元素必须能跨相存在）。

**3. C、N、S 有多种氧化态 (different oxidation states)**（回连 Week 5 的 redox）→ 同一元素能以化学性质迥异的形态存在，同位素在这些形态之间也会分馏。

**4. 五个元素在不同物质中都有可变的成键方式 (variable bonding in different materials)** → 热力学分馏的前提（不同的键 = 不同的振动频率 = 不同的分馏）。

**5. 低丰度同位素的丰度处于"可测量水平" (measurable levels)** → 质谱分析更容易。若稀有同位素只有 $10^{-9}$ 级别就很难精确测。

**6. 五个元素都是生源的 (biogenic)**，是生物材料的重要元素，**生物过程会造成同位素比值的巨大变化**。
> 老师强调：大多数生物过程在把 O 或 C 从环境摄入生物体系（代谢、造骨、造壳）时都是**强分馏 (strongly fractionating)** 的，因此稳定同位素是揭示生物过程的强力工具。

课件用**智利 Chaitén 火山**喷发的照片作配图："这里正在发生的许多过程都能靠稳定同位素来理解。"

### 2.6 两个必须分清的术语：Isotopologues 与 Isotopomers

**Isotopologues（同位素体 / 同位素异构分子）**：**只在同位素组成上不同**的分子。

- 例：CO 有 **6 种** isotopologues：
$$^{12}\mathrm{C}^{16}\mathrm{O},\ ^{13}\mathrm{C}^{16}\mathrm{O},\ ^{12}\mathrm{C}^{17}\mathrm{O},\ ^{13}\mathrm{C}^{17}\mathrm{O},\ ^{12}\mathrm{C}^{18}\mathrm{O},\ ^{13}\mathrm{C}^{18}\mathrm{O}$$
- **数数方法（老师明确讲了）**：C 有 2 种稳定同位素、O 有 3 种 → $2 \times 3 = 6$ 种组合。

**Isotopomers（同位素位置异构体）**：**只在同位素元素所处的位置 / 位点上不同**的分子。

- 例：**乙醛 (acetaldehyde)** 的两个 isotopomers：
$$\mathrm{CH}_3\mathrm{CD}{=}\mathrm{O} \quad \text{vs.} \quad \mathrm{CH}_2\mathrm{D}\,\mathrm{CH}{=}\mathrm{O}$$
两者化学式与同位素组成完全相同（都是 C$_2$H$_3$DO），**只是 D 挂在哪个碳上不同**。

> **记忆法**：isotopo-**logue**（"同族/同类"）= 组成不同；isotopo-**mer**（"异构体"，同 isomer）= 位置不同。

**重水的例子（老师强调）**：$\mathrm{D}_2\mathrm{O}$（重水，deuterated water）与普通 $\mathrm{H}_2^{16}\mathrm{O}$ 相比，**沸点、熔点、黏度 (viscosity)、密度全都不同**——这是"同位素差异会产生真实物性差异"的直观证据。

### 2.7 为什么同位素会表现不同？两种分馏机制

**出发点（也是易错点）**：同一元素的同位素**电子构型完全相同**，所以我们**本应**期待它们化学行为相同。
> 老师的类比：这和上周稀土元素 (REE) 的情形类似——REE 的 4f/5f 电子不参与化学反应，所以整体行为很相似。但这里 $^{12}\mathrm{C}$ (6p+6n) 与 $^{13}\mathrm{C}$ (6p+7n) 之间**确实存在质量差**。

**因此有两类行为造成同位素分馏：**

#### (A) 热力学（平衡）质量分馏 Thermodynamic / equilibrium mass fractionation

**逻辑链（要能完整背下来）**：

1. **回连 Week 6**："内能 $U$ —— 对一个矿物而言，是**储存在键中的势能**加上**原子振动的动能**之和。"
2. 化学键有**伸缩 / 振动频率 (stretching / vibrational frequency)**；键的振动频率取决于成键原子的质量。
3. **振动频率与质量的平方根成反比**：
$$\nu \propto \frac{1}{\sqrt{m}}$$
（更严格地，谐振子 $\nu = \frac{1}{2\pi}\sqrt{k/\mu}$，$k$ 为力常数，$\mu$ 为**折合质量 reduced mass**。）
4. 所以：**键到轻同位素 → 振动频率更高 → 内能更高 → 这些键更容易被打断 (more easily disrupted)**。
   - 老师的直观说法："它们已经处在一个高能级上了，只要输入一点点能量就能打断它。"
5. 反之：**分子若吸纳重同位素 → 内能更低 → 可用于反应的能量 ($\Delta G$) 减少 → 该相更稳定 (more stable)**。
6. **结论：同位素在各相之间的分馏，取决于每个相的成键特征 (bonding characteristics of each phase)。**

> **物理背景（补充理解）**：这本质上是**零点能 (zero-point energy, ZPE)** 效应。$E_0 = \tfrac{1}{2}h\nu$；重同位素 $\nu$ 小 → ZPE 低 → 在势能井中"坐得更深" → 键更难断 → 重同位素倾向于富集在**成键最强/最刚性**的那个相中。这解释了为什么 $^{18}\mathrm{O}$ 优先进入石英（Si–O 键强）而不是磁铁矿。

#### (B) 动力学质量分馏 Kinetic mass fractionation

**逻辑链**：

1. 动能公式：
$$\mathrm{K.E.} = \tfrac{1}{2} m v^2$$
2. **在给定温度下，所有分子的（平均）动能相同**。
3. 因此**质量更大的分子速度更小**。
4. 速度差异导致：
   - **扩散速率 (diffusion rates) 的差异**；
   - **蒸发速率 (evaporation rates) 的差异**——速度快的分子更容易从表面逃逸。
5. **在反应未达到平衡时，反应产物优先偏轻 (preferentially light)，因为到轻原子的键更容易断裂。**

> 老师补充：只要存在**相与相之间的界面**（蒸发、凝结成冰、扩散），只要过程与"速度"有关，就会倾向发生分馏。海水蒸发/冰的凝结是**强分馏**过程，因为重分子更不容易蒸发离开。

### 2.8 分馏系数 $\alpha$ (fractionation factor)

**定义**：描述稳定同位素在两个相之间的分布。对相 A 与相 B：

$$\boxed{\alpha_{A-B} = \frac{R_A}{R_B}}$$

其中 **$R$ 永远是 重同位素 / 轻同位素 的比值**（heavy over light）。

> **概念定位**：这与 Week 3 的**分配系数 (partition coefficient)** 是同一类概念——只不过分配的对象从"元素在两相之间"变成了"同位素在两相之间"。

**例（石英 – 磁铁矿的氧同位素分馏）**：
$$\alpha_{qz\text{-}mt} = \frac{(^{18}\mathrm{O}/^{16}\mathrm{O})_{quartz}}{(^{18}\mathrm{O}/^{16}\mathrm{O})_{magnetite}}$$

**关键理解**：当这两个矿物**处于平衡**时，它们的 $^{18}\mathrm{O}/^{16}\mathrm{O}$ 比值**仍然不同**。原因是两个矿物中 O 的成键环境不同（Si–O vs Fe–O）。**平衡 ≠ 同位素比值相等**，这是最容易搞混的一点。

**$\alpha$ 的数值特征**：由于稀有同位素丰度本来就低、比值本身就接近，$\alpha$ 通常**非常接近 1**，形如 **1.00X**。
- 例：200 °C 时闪锌矿 (sphalerite, ZnS) 与方铅矿 (galena, PbS) 之间的硫同位素 ($^{34}\mathrm{S}/^{32}\mathrm{S}$) 分馏系数 $\alpha = 1.00360$。

### 2.9 为什么用 $10^3 \ln \alpha$ 而不直接用 $\alpha$

**数学恒等（近似）**：
$$10^3 \ln(1.00X) \approx X$$

**验证**：$\alpha = 1.00360 \Rightarrow 10^3\ln\alpha = 1000 \times \ln(1.00360) = 3.594 \approx 3.60$ ✓

**另一种理解方式（讲义原文）**：
$$X = (\alpha - 1) \times 1000$$
即把 1 减掉、再乘 1000，本质是**把小数点后几位"放大"出来看**。

**为什么要这么做（老师给的两条理由）**：
1. **数字更好念、好画图、好交流**：写 3.594（4 个有效数字）比写 1.00360（6 个数字）方便得多。
2. **$10^3\ln\alpha$ 与温度之间存在光滑的关系 (smooth relationship)**，可以直接用于解释地球化学过程——尤其在 $1/T^2$ 坐标下变成**直线**。

> 老师的原话大意："这看起来有点复杂，但我希望你们能看出它只是一个更好用的数字。"

### 2.10 $\delta$ 记号 (delta notation)

**动机**：**绝对**同位素比值很难精确测量，因此测量值都**相对于一个标准 (standard)** 来报告。$\delta$ 就是"把样品的同位素比值与标准的比值做比较"的方式。

**定义（两个等价写法）**：

$$\boxed{\delta = \frac{R_{sample} - R_{standard}}{R_{standard}} \times 1000\ (‰)}$$

$$\delta = \left(\frac{R_{sample}}{R_{standard}} - 1\right) \times 1000\ (‰)$$

**符号含义**：
- $R$：**重同位素 / 轻同位素** 的比值（例如 $^{18}\mathrm{O}/^{16}\mathrm{O}$、$^{13}\mathrm{C}/^{12}\mathrm{C}$、$\mathrm{D}/\mathrm{H}$、$^{34}\mathrm{S}/^{32}\mathrm{S}$）；
- $\times 1000$ → 单位 **‰ (per mil)，千分之一**；
  - 若 $\times 100$ → **% (per cent)，百分之一**。
  - 老师的词源补充：**per cent** 来自拉丁 *per cento*（每一百）；**per mil / ‰** 来自 *per mille*（每一千）。符号从 % 多加一个 0 变成 ‰。
- **若把标准本身当样品测，则 $\delta = 0$**（自洽性检验）。

**为什么用 ‰ 而不是 %**：自然过程造成的同位素比值差异**典型量级就在千分之几**，用 ‰ 数字最顺手。

**$\delta$ 的正负号含义（考点）**：
- $\delta > 0$：样品的 **重/轻同位素比值高于标准** → 样品**同位素偏重 (isotopically heavy)**，重同位素**富集 (enriched)**；
- $\delta < 0$：样品比值**低于标准** → 样品**偏轻 (isotopically light)**，重同位素**亏损 (depleted)**。

**具体元素的写法**：

$$\delta^{18}\mathrm{O} = \frac{(^{18}\mathrm{O}/^{16}\mathrm{O})_{sample} - (^{18}\mathrm{O}/^{16}\mathrm{O})_{SMOW}}{(^{18}\mathrm{O}/^{16}\mathrm{O})_{SMOW}} \times 1000\ ‰$$

$$\delta \mathrm{D} = \frac{(\mathrm{D}/\mathrm{H})_{sample} - (\mathrm{D}/\mathrm{H})_{SMOW}}{(\mathrm{D}/\mathrm{H})_{SMOW}} \times 1000\ ‰$$

$$\delta^{34}\mathrm{S} = \frac{(^{34}\mathrm{S}/^{32}\mathrm{S})_{sample} - (^{34}\mathrm{S}/^{32}\mathrm{S})_{CDT}}{(^{34}\mathrm{S}/^{32}\mathrm{S})_{CDT}} \times 1000\ ‰$$

### 2.11 国际标准 (standards) — 必背

| 元素 | 标准缩写 | 全称 | 说明 |
|---|---|---|---|
| **O、H** | **SMOW** | **Standard Mean Ocean Water**（标准平均大洋水） | 取自现代大洋水的 O、H 平均组成；O 和 H 共用同一标准 |
| **S** | **CDT** | **Canyon Diablo Troilite**（峡谷魔鬼陨石陨硫铁） | 铁陨石中的**陨硫铁 troilite (FeS)**；该陨石就是造出 Arizona 的 **Meteor Crater 陨石坑** 的那颗 |
| **C** | **PDB** | Pee Dee Belemnite（碳酸盐） | transcript 提到：碳同位素的标准来自碳酸盐 PDB，**按定义 $\delta^{13}\mathrm{C} = 0$** |

**老师的关键澄清**：标准**在绝对意义上是什么并不重要**——重要的是"国际社会已经一致同意用它"，从而所有人有了一个**公平的比较基准 (level playing field)**。

> ⚠️ **重要伏笔**：**SMOW 本身会随时间变化**！因为它取决于地球上有多少冰、取决于水文循环。冰期时大量 $^{16}\mathrm{O}$ 被锁在冰盖里，海水变重。这既是古温度重建的**麻烦**，也是重建**冰期历史**的**机会**——Week 9 展开。

### 2.12 把 $\delta$ 和 $\alpha$ 结合起来：$\Delta$ 记号

**核心近似关系（本周最重要的一条公式）**：

$$\boxed{10^3 \ln \alpha_{A-B} \;\approx\; \delta_A - \delta_B \;\equiv\; \Delta_{A-B}}$$

**符号说明**：
- 小写 $\delta$：单个相相对标准的组成；
- **大写 $\Delta$（capital delta）**：**两个相之间的差**，$\Delta_{A-B} = \delta_A - \delta_B$；
- 三者串起来：$10^3\ln\alpha_{A-B} \approx \Delta_{A-B} = \delta_A - \delta_B$。

**推导（讲义没写，但应该会）**：
由 $\delta_A = (R_A/R_{std} - 1)\times 1000 \Rightarrow R_A = R_{std}(1 + \delta_A/1000)$，同理 $R_B$。故

$$\alpha_{A-B} = \frac{R_A}{R_B} = \frac{1 + \delta_A/1000}{1 + \delta_B/1000}$$

$$\ln\alpha_{A-B} = \ln\!\left(1 + \tfrac{\delta_A}{1000}\right) - \ln\!\left(1 + \tfrac{\delta_B}{1000}\right) \approx \frac{\delta_A}{1000} - \frac{\delta_B}{1000}$$

（用 $\ln(1+x) \approx x$，因为 $\delta/1000 \ll 1$）

$$\Rightarrow 1000\ln\alpha_{A-B} \approx \delta_A - \delta_B = \Delta_{A-B} \quad \blacksquare$$

**实用意义**：$\delta$ 是**实测量**，$\alpha$ 是**热力学量**（有实验标定的温度函数）。这条关系式就是连接"实验室测的数"与"温度"的桥梁——**所有地温计题目都走这条路**。

### 2.13 稳定同位素地温计 (geothermometry)

**定义**：**地温计 (geothermometer)** = 确定一个矿物反应发生时的温度。适用于极广的地质应用。

**原始想法：H. Urey（尤里）** —— 要研究气候变化的地质记录，我们想知道**古海洋的温度**。

**方法**：利用方解石与水之间的同位素交换平衡：
$$\mathrm{CaC}^{16}\mathrm{O}_3 + \mathrm{H}_2^{18}\mathrm{O} \;\rightleftharpoons\; \mathrm{CaC}^{18}\mathrm{O}_3 + \mathrm{H}_2^{16}\mathrm{O}$$
- 方解石来源：生物体，例如**底栖有孔虫 (benthic foraminifera)**、贝壳、石灰岩 (limestone)；
- 水：海水（SMOW）。
- 老师补充：方解石以壳体形式在大陆边缘海岸堆积 → 我们对**大陆形成期、碳酸盐台地生长期**都有很好的碳酸钙记录。

**核心问题**："这些岩石形成时海洋有多暖？"

**高温情形的普遍规律**：
$$1000 \ln \alpha_{A-B} \approx \frac{A}{T^2} \quad (T \text{ in Kelvin},\ A \text{ 为常数})$$
即在 $1000\ln\alpha_{A-B}$ vs. $1/T^2$（常画成 $10^6/T^2$）的图上是**一条直线**。

**$\alpha$ 对温度的依赖性正是稳定同位素地温计的基础。**

**两条极其重要的推论**：
1. **高温时 $\alpha \to 1$，即无分馏**（因为 $\ln 1 = 0$）。
2. 因此**该技术在低温平衡下效果最好**，因为那里分馏最大、对温度最敏感。
3. 稳定同位素地温计**主要使用 O 和 S 的同位素**。

> 老师强调：分馏曲线之间的差异在**低温端更大**、对温度**更敏感**，"这正是稳定同位素在行星表面附近如此强大的部分原因"。

| $\delta = \dfrac{R_{sample}-R_{std}}{R_{std}}\times 1000$ ‰ | delta 记号 |

### 3.2 动力学分馏的定量算例（讲义原文，必须会）

**问题**：比较 $^{12}\mathrm{C}^{16}\mathrm{O}$（质量 28）与 $^{12}\mathrm{C}^{18}\mathrm{O}$（质量 30）的平均速度。

**解**：同一温度下两者动能相同：
$$\tfrac{1}{2}(28)\,v_{28}^2 = \tfrac{1}{2}(30)\,v_{30}^2$$

$$\Rightarrow \frac{v_{28}^2}{v_{30}^2} = \frac{30}{28} = 1.0714$$

$$\Rightarrow \frac{v_{28}}{v_{30}} = \sqrt{1.0714} = 1.035$$

$$\Rightarrow v_{28} = 1.035\, v_{30}$$

**结论**：$^{12}\mathrm{C}^{16}\mathrm{O}$ 分子的平均速度比 $^{12}\mathrm{C}^{18}\mathrm{O}$ **快 3.5%**。
**且这个结论在任何温度下都成立** —— 因为温度从等式两边同时消掉了。

> 老师评价：3.5% 不算大变化，但**足够显著**，足以在扩散、蒸发、任何有界面的动态过程中造成平均意义上的分馏。

### 3.3 $\delta$ 计算的"从丰度到 ‰"完整算例（讲义原文）

**背景丰度**：$^{18}\mathrm{O} = 0.1995\%$，$^{16}\mathrm{O} = 99.763\%$。

**情形 1：样品的 $^{18}\mathrm{O}$ 比自然丰度高千分之一（0.1995 → 0.1996）**

$$\frac{(^{18}\mathrm{O}/^{16}\mathrm{O})_{sample}}{(^{18}\mathrm{O}/^{16}\mathrm{O})_{standard}} = \frac{0.1996/99.763}{0.1995/99.763} = \frac{0.002001}{0.002000} = 1.0005$$

减 1：$\;0.0005$

$$\delta^{18}\mathrm{O} = 0.0005 \times 1000 = +0.5\ ‰ \;=\; +0.05\ \%$$

**解读**：样品的 $^{18}\mathrm{O}/^{16}\mathrm{O}$ 比标准**高 0.5 ‰**（= 0.05 %）。

**情形 2：样品的 $^{18}\mathrm{O}$ 比自然丰度低千分之一（0.1995 → 0.1994）**

$$\frac{0.1994/99.763}{0.1995/99.763} = \frac{0.001999}{0.002000} = 0.9995$$

减 1：$\;-0.0005 \Rightarrow \delta^{18}\mathrm{O} = -0.5\ ‰ = -0.05\ \%$

**解读**：样品的 $^{18}\mathrm{O}/^{16}\mathrm{O}$ 比标准**低 0.5 ‰**。

> **这个例子的教学意图**：让你看到"丰度上一个千分之一的微小变化"如何**一路传播 (propagate)** 成一个 ±0.5‰ 的 $\delta$ 值——量级感非常重要。

### 3.4 由 $\delta$ 求 $\alpha$ 的算例 1：液态水 – 水汽（讲义原文）

**已知**（10 °C）：
- 液态水 $\delta^{18}\mathrm{O}_{lw} = -0.80\ ‰$
- 水汽 $\delta^{18}\mathrm{O}_{wv} = -10.79\ ‰$

**步骤**：

$$\Delta_{lw-wv} = \delta_{lw} - \delta_{wv} = -0.80 - (-10.79) = +9.99\ ‰$$

$$1000\ln\alpha = 9.99$$

$$\alpha = \exp\!\left(\frac{9.99}{1000}\right) = e^{0.00999} = 1.01004$$

**物理解读（老师补充）**：水汽比液态水**轻得多**（$\delta$ 更负），因为**重的分子更难蒸发**，所以 $^{18}\mathrm{O}$ 在水汽中亏损、在残余液态水中富集。这是典型的**动力学 + 平衡混合的相变分馏**。

> ⚠️ transcript ASR 把 $-0.80$ 念成了"minus 4.8"，以课件的 **$-0.80$‰** 为准。

### 3.5 由 $\delta$ 求 $\alpha$ 的算例 2：大气 CO$_2$ – 河水中的 HCO$_3^-$（讲义原文）

**已知**：
- 大气 CO$_2$：$\delta^{13}\mathrm{C} = -7\ ‰$
- 河水中碳酸氢根 $[\mathrm{HCO}_3^-]$：$\delta^{13}\mathrm{C} = +1.24\ ‰$

**求** $\alpha_{(\mathrm{HCO}_3^-)-(\mathrm{CO}_2)}$：

$$1000\ln\alpha_{(\mathrm{HCO}_3^-)-(\mathrm{CO}_2)} = \delta_{(\mathrm{HCO}_3^-)} - \delta_{(\mathrm{CO}_2)} = 1.24 - (-7) = 8.24\ ‰$$

$$\alpha = \exp\!\left(\frac{8.24}{1000}\right) = e^{0.00824} = 1.00827$$

**解读**：溶解的碳酸氢根相对大气 CO$_2$ **富集 $^{13}\mathrm{C}$**（$\alpha > 1$）。
> 老师补充：PDB 碳酸盐按定义 $\delta^{13}\mathrm{C}=0$，因此"大气 CO$_2$ 比碳酸盐轻 7 ‰"。

### 3.6 方解石 – 水氧同位素地温计方程（讲义原文）

$$1000\ln\alpha_{(Calcite - \mathrm{H_2O})} = 18.03\,(10^3)\,T^{-1} - 32.42 \qquad (T \text{ in Kelvin})$$

**逐项解释**：
- $18.03 \times 10^3$：实验标定的常数（分子），单位使 $T^{-1}$ 项无量纲化后为 ‰；
- $T^{-1}$：注意这里是 **$1/T$**（不是 $1/T^2$）——**低温体系的标定式常用 $1/T$ 形式**，与高温矿物对的 $1/T^2$ 形式不同，别混；
- $-32.42$：截距。

**讲义给的验算**：

| $T$ | $T$ (K) | 计算 | $1000\ln\alpha$ |
|---|---|---|---|
| 20 °C | 293.15 | $18030/293.15 - 32.42 = 61.50 - 32.42$ | **29.08** ✓ |
| 25 °C | 298.15 | $18030/298.15 - 32.42 = 60.47 - 32.42$ | **28.05** ✓ |

（注意：这里换算用的是 $+273.15$；practical 里多数题目用 $+273$ 也够精度。）

**应用逻辑**：原则上，只要测出石灰岩中的 $\delta^{18}\mathrm{O}$（并知道海水的 $\delta^{18}\mathrm{O}$），就能反算方解石形成时的**海水温度**。

**实践困难（讲义明写）**：**SMOW 的值本身会变**，例如在冰期/间冰期之间变化——所以简单概念在实践中难以直接实现。但它很好地展示了稳定同位素如何用于**古气候 (palaeoclimate) 研究**。（→ Week 9）

### 3.7 图表判读

#### 图 A：$10^3\ln\alpha$ vs. 温度 (°C) —— **曲线** (Sharp)

- 纵轴：$1000\ln\alpha_{mineral-water}$；横轴：$T$ (°C)。
- 每条曲线代表**一个矿物与水**之间的氧同位素分馏。
- **判读要点**：
  1. 曲线是**光滑但非线性**的；
  2. **随温度升高，所有曲线向 0 收敛**（$\alpha \to 1$，无分馏）；
  3. **低温端曲线彼此分得最开、斜率最陡** → **对温度最敏感**；
  4. 石英在最上方（$^{18}\mathrm{O}$ 最富集），磁铁矿在最下方（可为负值）。
- **老师的一句话总结**："各矿物的行为在低温时差异更大，你在低温下得到更强的温度敏感性——这正是稳定同位素在地球表层如此强大的原因之一。"

#### 图 B：$10^3\ln\alpha$ vs. $10^6/T^2$（$T$ in K）—— **直线** (Rollinson)

- 纵轴：$1000\ln\alpha_{mineral-calcite}$（或 $mineral-water$）；横轴：$10^6/T^2$。
- **判读要点**：
  1. 换成 $1/T^2$ 坐标后，曲线**线性化**成直线（对应 $1000\ln\alpha \approx A/T^2$，直线过原点或近原点）；
  2. **横轴的温度刻度变成非线性的**：$10^6/T^2$ 越大 = 温度越低；原点 ($10^6/T^2 = 0$) 对应 $T \to \infty$，此时 $1000\ln\alpha \to 0$；
  3. **直线斜率 = 常数 $A$**；**斜率越陡的矿物对 = 越灵敏的地温计**。

#### 图 C：氧同位素地温计——硅酸盐与氧化物矿物 (Misra Fig. 11.2)

- 图示石英与各种其他矿物之间的氧同位素分馏系数随 $1/T^2$ 变化；
- 例：石英–磁铁矿对，$\Delta_{qz-mt} = 1000\ln\alpha_{qz-mt}$；
- **关键结论**：**平衡时 $^{18}\mathrm{O}$ 相对于所有其他矿物优先分配进石英**，所以图中所有 $1000\ln\alpha_{qz-mineral}$ 值**都是正的**；
- **矿物对的优劣（考点）**：
  - **石英–磁铁矿 (quartz–magnetite)：好用的地温计**——$\alpha$ 值大、斜率陡、对温度敏感；
  - **石英–长石 (quartz–feldspar)：不好用**——$\alpha$ 值小、两者成键环境相似、分馏微弱，测量误差会被放大成巨大的温度误差。
- **判据一般化**：**要选成键环境差异大的两个矿物**（硅酸盐 vs 氧化物），差异越大分馏越大、地温计越灵敏。

#### 图 D：硫同位素地温计——硫化物矿物

- 用 $^{34}\mathrm{S}$ 与 $^{32}\mathrm{S}$；标准 CDT。
$$\Delta^{34}\mathrm{S} = \delta^{34}\mathrm{S}_{min1} - \delta^{34}\mathrm{S}_{min2}$$
- **最常用的 S 同位素地温计：闪锌矿 – 方铅矿 (sphalerite – galena)**，用于确定**成矿温度 (temperature of ore formation)**。
- 课件实物照片：秘鲁 Huaron Mine 的闪锌矿 (ZnS) + 方铅矿 (PbS) + 黄铜矿 (CuFeS$_2$)。
- 另有一张图：**各种硫物种相对于 H$_2$S 的硫同位素分馏**。
  - 老师补充：不同硫物种（SO$_4^{2-}$、SO$_2$、S$^{2-}$、单质 S 等）与 H$_2$S 之间的分馏差异**随氧化还原条件 (redox conditions) 变化**，所以在火山系统中硫同位素可以反演氧逸度/redox 状态。这回连 Week 5。

## 四、课堂补充

以下是 transcript 里有、而 slides 上没有或讲得更透的内容。

### 4.1 为什么稳定同位素"值得学"——工具论

老师开篇的方法论：一个地球化学工具要有用，必须同时满足两条：
1. **动力学系统而可信 (systematic and trustworthy dynamic)**：变化与条件（温度等）之间的关系清楚；
2. **易于测量**。

**质谱 (mass spectrometry) 是稳定同位素的孪生技术**——它的灵敏度与稳健性是稳定同位素之所以强大的关键原因之一。逻辑链：
> 中子数不同 → 行为略有差异 → 质谱揭示这些差异 → 反推出每个环境中"什么在驱动差异" → 得到过程信息。

### 4.2 "isotopically heavy / light" 的口语用法

老师反复用 "isotopically heavier / lighter"，等价说法：
- $\delta$ 越正 = 越重 = 重同位素越**富集 (enriched)**；
- $\delta$ 越负 = 越轻 = 重同位素越**亏损 (depleted)**。
- "$\delta$ 永远是相对于标准的 ±"。

### 4.3 生物过程是强分馏器

老师专门展开：**大多数生物过程在把 O、C 从环境摄取进生物体系（代谢、造骨、造壳）时都是强分馏的**，所以稳定同位素是揭示生物过程的强力工具（食物链层级、光合途径 C3/C4、古饮食重建等，均属此类）。

### 4.4 蒸发/凝结的强分馏与冰期

老师明确点出：
> "在蒸发与冰的凝结这类过程中，分馏会很强，因为较重的分子远不容易离开（蒸发）。"

并且反复预告：**SMOW 会随时间变化，取决于地球上有多少冰和水文循环** → "这既是复杂性，也是这门学问的乐趣：我们可以用它反过来追踪冰期的演化、以及水与同位素在地球上的分布动力学。" → **Week 9 主题**。

### A 部分：稳定同位素术语

#### A1. Isotopologues 列举

**(a) 氧分子 O$_2$ 的所有 isotopologues 及其质量**

由 $^{16}\mathrm{O}, ^{17}\mathrm{O}, ^{18}\mathrm{O}$ 三种同位素两两组合（**无序组合**，$\binom{3}{2}+3 = 6$ 种）：

| Isotopologue | 质量 |
|---|---|
| $^{16}\mathrm{O}^{16}\mathrm{O}$ | 32 |
| $^{16}\mathrm{O}^{17}\mathrm{O}$ | 33 |
| $^{16}\mathrm{O}^{18}\mathrm{O}$ | 34 |
| $^{17}\mathrm{O}^{17}\mathrm{O}$ | 34 |
| $^{17}\mathrm{O}^{18}\mathrm{O}$ | 35 |
| $^{18}\mathrm{O}^{18}\mathrm{O}$ | 36 |

**共 6 种**。
> **注意点**：$^{16}\mathrm{O}^{18}\mathrm{O}$ 与 $^{17}\mathrm{O}^{17}\mathrm{O}$ **质量都是 34**，但它们是**不同的 isotopologues**。这就是"质量数相同 ≠ 同一个分子"的经典陷阱，也是高分辨质谱要解决的问题。

**(b) 水 H$_2$O 的所有 isotopologues 及其质量**（用 H 表示 $^1\mathrm{H}$，D 表示 $^2\mathrm{H}$）

氢位有 3 种组合（HH, HD, DD），氧有 3 种 → $3 \times 3 = 9$ 种：

| Isotopologue | 质量 | | Isotopologue | 质量 | | Isotopologue | 质量 |
|---|---|---|---|---|---|---|---|
| H$_2^{16}$O | 18 | | HD$^{16}$O | 19 | | D$_2^{16}$O | 20 |
| H$_2^{17}$O | 19 | | HD$^{17}$O | 20 | | D$_2^{17}$O | 21 |
| H$_2^{18}$O | 20 | | HD$^{18}$O | 21 | | D$_2^{18}$O | 22 |

**共 9 种**，质量范围 18–22。
> 同样注意：质量 20 有**三种**不同的 isotopologues（H$_2^{18}$O、HD$^{17}$O、D$_2^{16}$O）。

#### A2. 分馏系数 $\alpha$

**(a) 写出闪锌矿 (sph) 与方铅矿 (gal) 之间 $^{32}\mathrm{S}$/$^{34}\mathrm{S}$ 分馏的 $\alpha$ 方程**

$$\alpha_{sph-gal} = \frac{(^{34}\mathrm{S}/^{32}\mathrm{S})_{sphalerite}}{(^{34}\mathrm{S}/^{32}\mathrm{S})_{galena}}$$

> **关键：分子分母内部一定是"重/轻"**，即使题目把 $^{32}$S 写在前面，你写 $R$ 时也必须写成 $^{34}\mathrm{S}/^{32}\mathrm{S}$。

**(b) 验证 $1000\ln\alpha \approx X$（其中 $\alpha = 1.00X$）**

**(i) 硫：闪锌矿–方铅矿，200 °C，$\alpha_{sph-gal} = 1.00360$**
- $X$ 是多少？ **$X = 3.60$**，即 $\alpha$ 的第 3 位及以后的小数位。
  （另一种理解：$X = (\alpha - 1)\times 1000 = 0.00360 \times 1000 = 3.60$）
- $1000\ln\alpha = 1000 \times \ln(1.00360) = \mathbf{3.594}$
- 对比：$3.594$ vs $3.60$ → 近似成立 ✓

**(ii) 氧：石英–方解石，500 °C，$\alpha_{qz-cc} = 1.01017$**
- $X = \mathbf{10.17}$
- $1000\ln\alpha = 1000 \times \ln(1.01017) = \mathbf{10.12}$
- 对比：$10.12$ vs $10.17$ ✓（注意 $\alpha$ 越偏离 1，近似误差越大——这里差 0.05，上一题只差 0.006）

#### A3. Delta 记号的书写

**(a) 硫同位素的 $\delta$ 表达式**（标准：CDT = Canyon Diablo Troilite，即造出 Arizona Meteor Crater 那颗铁陨石中的陨硫铁 FeS）

$$\delta^{34}\mathrm{S} = \frac{(^{34}\mathrm{S}/^{32}\mathrm{S})_{sample} - (^{34}\mathrm{S}/^{32}\mathrm{S})_{CDT}}{(^{34}\mathrm{S}/^{32}\mathrm{S})_{CDT}} \times 1000\ \mathbf{‰}$$

**(b) 氢同位素的 $\delta$ 表达式**（标准：SMOW）

$$\delta \mathrm{D} = \frac{(\mathrm{D}/\mathrm{H})_{sample} - (\mathrm{D}/\mathrm{H})_{SMOW}}{(\mathrm{D}/\mathrm{H})_{SMOW}} \times 1000\ \mathbf{‰}$$

> **Feedback 反复提醒：Remember to include units（记得写 ‰）**。这是最常见的失分点。

#### A4. $\delta$ 与 $\alpha$ 的联用：方解石 – 大气 CO$_2$

**已知**：20 °C，$\delta^{13}\mathrm{C}_{cc} = +3.12\ ‰$，$\delta^{13}\mathrm{C}_{CO_2} = -7.0\ ‰$

**(a) 求 $\Delta_{cc-CO_2}$ 与 $\alpha$**

$$\Delta_{cc-CO_2} = \delta^{13}\mathrm{C}_{cc} - \delta^{13}\mathrm{C}_{CO_2} = 3.12 - (-7.0) = \mathbf{10.12\ ‰}$$

$$1000\ln\alpha = 10.12$$
$$\ln\alpha = \frac{10.12}{1000} = 0.01012$$
$$\alpha = e^{0.01012} = \mathbf{1.01017}$$

（Feedback 提示：**记住 $e^{\ln X} = X$**）

**(b) 燃烧化石燃料使大气 $\delta^{13}\mathrm{C}_{CO_2}$ 降到 $-12\ ‰$，同温度下与之平衡沉淀的方解石 $\delta^{13}\mathrm{C}$ 是多少？**

**关键洞察**：**温度不变 → $\alpha$ 不变 → $\Delta$ 不变 = 10.12 ‰**。

$$\Delta_{cc-CO_2} = \delta_{cc} - \delta_{CO_2}$$
$$10.12 = \delta^{13}\mathrm{C}_{cc} - (-12)$$
$$\delta^{13}\mathrm{C}_{cc} = 10.12 - 12 = \mathbf{-1.88\ ‰}$$

**地球化学意义（本题的真正用意）**：化石燃料来自**有机碳**，$\delta^{13}\mathrm{C}$ 非常负（生物光合作用强烈偏好 $^{12}\mathrm{C}$）。燃烧它们把轻碳注入大气，使大气 CO$_2$ 变轻，而与之平衡的碳酸盐也随之变轻——这就是 **Suess effect（苏斯效应）** 的原理，也是用树轮/珊瑚 $\delta^{13}\mathrm{C}$ 追踪人为碳排放的基础。（回连 Week 4 碳循环）

#### A5. 用 CO$_2$ 平衡法测水的 $\delta^{18}\mathrm{O}$

**背景（方法学，重要）**：实验室里把水与 CO$_2$ 气体在 25 °C 下平衡，然后把 CO$_2$ 抽进质谱仪测它的 $\delta^{18}\mathrm{O}$。
> **为什么这样做**：**测气体的同位素组成比测液体容易**。这是真实实验室的标准操作。

**已知**：$\delta^{18}\mathrm{O}_{CO_2} = +10\ ‰$；$\alpha_{(CO_2)-(H_2O)} = 1.04120$ (25 °C)

**求** $\delta^{18}\mathrm{O}_{H_2O}$

**步骤 1**：
$$1000\ln\alpha_{(CO_2)-(H_2O)} = 1000 \times \ln(1.04120) = \mathbf{40.37}$$

**步骤 2**：套用桥梁公式
$$1000\ln\alpha_{(CO_2)-(H_2O)} = \Delta_{(CO_2)-(H_2O)} = \delta_{(CO_2)} - \delta_{(H_2O)}$$
$$40.37 = 10 - \delta_{(H_2O)}$$
$$\delta^{18}\mathrm{O}_{H_2O} = 10 - 40.37 = \mathbf{-30.37\ ‰}$$

> **注意**：这里 $\alpha = 1.0412$ 已经**明显偏离 1**（4%），所以 $10^3\ln\alpha \approx X$ 的近似误差不小（$X = 41.20$ 而 $10^3\ln\alpha = 40.37$）。**必须老老实实取对数，不能直接用 41.20**。

### B 部分：稳定同位素地温计

**总目标**：用两个相的稳定同位素组成，确定它们**平衡时的温度**。

#### B1. 氧同位素平衡：白云母 – 水（Misra p.278 Q6）

**背景**：一块岩石中的白云母 (muscovite) 与水平衡；已知水的 $\delta^{18}\mathrm{O}$ 与反应温度，求白云母的 $\delta^{18}\mathrm{O}$。

**标定方程**（500–800 °C 适用）：
$$1000\ln\alpha_{musc-H_2O} = \frac{1.90 \times 10^6}{T^2} - 3.10 \qquad (T \text{ in Kelvin})$$

**已知**：$\delta^{18}\mathrm{O}_{H_2O} = -9\ ‰$，$T = 500\ °\mathrm{C}$

**解**：

步骤 1 — **换算成 Kelvin（Feedback 特别提醒：Remember that T must be in Kelvin）**：
$$T = 500 + 273 = 773\ \mathrm{K}$$

步骤 2 — 代入方程：
$$1000\ln\alpha_{musc-H_2O} = \frac{1.90\times10^6}{773^2} - 3.10 = \frac{1.90\times10^6}{597529} - 3.10$$
$$= 3.1798 - 3.10 = \mathbf{0.0798}$$

步骤 3 — 用桥梁公式：
$$1000\ln\alpha_{musc-H_2O} = \Delta_{musc-H_2O} = \delta_{musc} - \delta_{H_2O}$$
$$0.0798 = \delta_{musc} - (-9)$$
$$\delta^{18}\mathrm{O}_{musc} = 0.0798 - 9 = \mathbf{-8.9202\ ‰}$$

**解读（本题的教学点）**：500 °C 下分馏只有 **0.08 ‰**，几乎为零！白云母的 $\delta^{18}\mathrm{O}$ 与水几乎相同。这**正好印证了 lecture 的结论：高温下 $\alpha \to 1$，分馏消失，地温计失效**。要在这样的体系里测温，你的分析精度必须优于 0.08 ‰——不现实。**所以高温体系要选分馏大的矿物对（如 qz–mt），或换用别的温压计。**

#### B2. 硫同位素地温计：Providencia (Mexico) 硫化物矿床（Misra p.279 Q13 / McSween p.284 Q13.4；数据来自 Rye 1974）

**背景**：硫同位素用于确定**硫化物矿床的形成温度**。用**闪锌矿 (ZnS) – 方铅矿 (PbS)** 体系。

**(a) 关系式**
$$\Delta^{34}\mathrm{S}_{sphal-gal} = \delta^{34}\mathrm{S}_{sphalerite} - \delta^{34}\mathrm{S}_{galena}$$

**(b) 温度计算表**

**地温计方程**（PDF 中以图片给出，OCR 丢失了根号——**注意！**）：
$$\boxed{T\,(\mathrm{K}) = \frac{850}{\sqrt{\Delta^{34}\mathrm{S}_{sphal-gal}}}}$$

等价于标定式 $\Delta^{34}\mathrm{S}_{sphal-gal} \approx \dfrac{0.73\times10^6}{T^2}$（Ohmoto & Rye 型标定），因为
$$T^2 = \frac{850^2}{\Delta} = \frac{7.225\times10^5}{\Delta}$$

> ⚠️ **Feedback 的 md 转写把公式写成了 "T = 850 / (Δ³⁴S)"，那是错的**（它自己给的算例 $850/1.98 = 604$ 只有加了根号才对：$850/\sqrt{1.98} = 604$）。**复习时务必按带根号的版本算。**

**完整表格（含验算）**：

| Sample | $\delta^{34}\mathrm{S}_{sph}$ | $\delta^{34}\mathrm{S}_{gal}$ | $\Delta_{sph-gal}$ | $\sqrt{\Delta}$ | $T$ (K) | $T$ (°C) |
|---|---|---|---|---|---|---|
| 1 | 0.95 | −1.15 | $0.95-(-1.15)=2.10$ | 1.4491 | $850/1.4491 = 587$ | 314 |
| 2 | 0.87 | −1.11 | $0.87-(-1.11)=1.98$ | 1.4071 | $850/1.4071 = 604$ | 331 |
| 3 | 1.03 | −1.42 | $1.03-(-1.42)=2.45$ | 1.5652 | $850/1.5652 = 543$ | 270 |
| 4 | 0.01 | −1.71 | $0.01-(-1.71)=1.72$ | 1.3115 | $850/1.3115 = 648$ | 375 |

**Feedback 给的样例（Sample 2）完整步骤**：
$$\Delta^{34}\mathrm{S}_{sphal-gal} = 0.87 - (-1.11) = 1.98$$
$$T = \frac{850}{\sqrt{1.98}} = 604\ \mathrm{K}$$
$$T = (604 - 273)\ °\mathrm{C} = \mathbf{331\ °C}$$

**(c) 讨论题：矿床的形成温度是多少？不同样品给出不同温度该如何解释？**（**这是一道很重要的"科学素养"题，答案值得整段记**）

不同样品记录的温度在 **270 – 375 °C** 之间。差异可能来自：

1. **温度真的在变化**——温度可能随**空间**和/或**时间**变化（矿床不是一瞬间在一个点形成的）。
2. **采样问题 (sampling problem)**——很难挑到**真正代表两矿物平衡**的样品对。
   - 具体证据：所分析的闪锌矿晶体**强烈环带 (strongly zoned)**，因为它们是在**连续几代流体**中生长的。Rye (1974) 原文专门讨论了挑选真正构成平衡对的闪锌矿–方铅矿样品的困难。
3. **分析不确定度**——Rye 论文指出："$\Delta^{34}\mathrm{S}_{sphal-gal}$ 的不确定度 ($\pm 0.1\ ‰$) 导致计算温度在 350 °C 处的不确定度约为 $\pm 15\ °\mathrm{C}$。"
   - **关键论证**：**实测温度范围 (270–375 °C，跨度 105 °C) 远大于这个误差 (±15 °C)** → 所以**温度差异是真实的，不能全归咎于测量误差**。
4. **能不能取平均？** 可以算出平均 = **322 °C，标准差 = 43**。
   - 但 Feedback 明确指出：**分析数量太少 (n=4)，取平均意义不大**。
   - **总体结论：只测一对矿物是不够的 (just measuring one mineral pair is not enough)。**

> **这一题的元教训**：地球化学数据的散布首先要问"是真实的地质变化，还是分析/采样噪声？"——判据是**比较数据散布与分析误差的量级**。这是本课程反复要考的科学思维。

#### B3. 氧同位素地温计：片麻岩 (gneiss) 的石英 – 磁铁矿（White Example 9.2）

**背景**：一块含石英与磁铁矿的**片麻岩（变质岩）**，求其平衡温度。

**(a)** 在"矿物–水氧同位素分馏 vs 温度"图上，标出 $1000\ln\alpha_{qz-H_2O}$ 与 $1000\ln\alpha_{mt-H_2O}$ 两条曲线。
- 石英曲线在**最上方**（正值，$^{18}\mathrm{O}$ 富集）；
- 磁铁矿曲线在**最下方**（负值，$^{18}\mathrm{O}$ 亏损）。

**(b) 用"差值法"从图上读取 $1000\ln\alpha_{qz-mt}$**

**原理（重要技巧）**：
$$1000\ln\alpha_{qz-mt} = 1000\ln\alpha_{qz-H_2O} - 1000\ln\alpha_{mt-H_2O}$$

**推导**：$\alpha_{qz-mt} = \dfrac{R_{qz}}{R_{mt}} = \dfrac{R_{qz}/R_{H_2O}}{R_{mt}/R_{H_2O}} = \dfrac{\alpha_{qz-H_2O}}{\alpha_{mt-H_2O}}$，取对数即得差。
→ **水在这里是"共同参照"，可以约掉**。这个技巧让我们只需要一套"矿物–水"标定，就能得到任意矿物对之间的分馏。

**读图结果**：
- **300 °C**：$1000\ln\alpha_{qz-mt} \approx 9 - (-10) = \mathbf{19}$
- **800 °C**：$1000\ln\alpha_{qz-mt} \approx 0 - (-5) = \mathbf{5}$

（再次验证：**温度越高，分馏越小**。）

**(c) 定量求温度**

**标定方程**（White Table 9.3）：
$$1000\ln\alpha_{qz-mt} = \frac{6.29\times10^6}{T^2} \qquad (T \text{ in Kelvin})$$

**实测**：石英 $\delta^{18}\mathrm{O} = 11.1\ ‰$；磁铁矿 $\delta^{18}\mathrm{O} = 1.9\ ‰$

**解**：

步骤 1 — 先算 $\Delta$（**Feedback 的 Hint 就是这一步**）：
$$\Delta_{qz-mt} = \delta_{qz} - \delta_{mt} = 11.1 - 1.9 = \mathbf{9.2\ ‰}$$

步骤 2 — 用桥梁公式令其等于 $1000\ln\alpha$：
$$\Delta_{qz-mt} = 1000\ln\alpha_{qz-mt} = \frac{6.29\times10^6}{T^2}$$
$$9.2 = \frac{6.29\times10^6}{T^2}$$

步骤 3 — 解 $T$：
$$T^2 = \frac{6.29\times10^6}{9.2} = 683{,}695$$
$$T = \sqrt{683695} = \mathbf{827\ K}$$
$$T = 827 - 273 = \mathbf{554\ °C}$$

**合理性检查**：554 °C 对片麻岩（中–高级变质岩）是**完全合理的变质峰期温度**，落在角闪岩相 (amphibolite facies) 范围内。✓

**参考文献**：Rye, R. O. (1974): *A Comparison of Sphalerite-Galena Sulfur Isotope Temperatures with Filling Temperatures of Fluid Inclusions.* Economic Geology, 69(1), 26–32.

### Practical 解题套路总结（考试必备流程）

**所有本周计算题都是这三条公式的排列组合：**

```
① α_{A-B} = R_A / R_B                     （定义）
② δ = (R_sample/R_std − 1) × 1000 ‰        （定义）
③ 1000 ln α_{A-B} = Δ_{A-B} = δ_A − δ_B    （桥梁）
④ 1000 ln α = f(T)                          （实验标定式）
```

**三类题型的走法：**

| 题型 | 给了什么 | 走法 |
|---|---|---|
| **求 $\alpha$** | 两相的 $\delta$ | $\delta_A-\delta_B = \Delta$ → $\alpha = e^{\Delta/1000}$ |
| **求某相 $\delta$** | 另一相的 $\delta$ + $\alpha$ 或 $T$ | 由 $\alpha$/$T$ 得 $\Delta$ → $\delta_A = \Delta + \delta_B$ |
| **求 $T$（地温计）** | 两相的 $\delta$ + 标定式 | $\Delta = \delta_A-\delta_B$ → 代入 $f(T)$ → 解 $T$（K）→ 减 273 |

**每一步的自检清单：**
1. $R$ 写成**重/轻**了吗？
2. 下标顺序对吗？$\alpha_{A-B}$ 对应 $\delta_A - \delta_B$，**顺序反了符号就反**。
3. $T$ **换成 Kelvin** 了吗？
4. 答案写 **‰** 了吗？
5. 若 $\alpha$ 明显偏离 1（如 1.04），**必须真取 $\ln$**，不能用 $X$ 近似。

## 六、易错点 / 重点难点

1. **"同位素电子构型相同 ⇒ 化学性质相同"是错的（半对半错）**。
   电子构型确实相同，"零阶近似"下化学性质相似；但**核质量差**通过 (a) 键振动频率/零点能、(b) 分子平动速度 两条途径造成真实的、可测的行为差异。**答题时必须把"电子构型相同"作为出发点，再指出质量效应是分馏的唯一根源。**

2. **平衡 ≠ 同位素比值相等**。
   石英与磁铁矿达到平衡时，$^{18}\mathrm{O}/^{16}\mathrm{O}$ 仍然不同，$\alpha \ne 1$。原因是两相中 O 的**成键环境不同**。这是全周最核心也最反直觉的一点。

3. **$\alpha \to 1$ 而不是 $\alpha \to 0$**（高温极限）。
   老师口误说过 "alpha approaches zero"。正确是：**$T \to \infty$ 时 $\alpha \to 1$，$\ln\alpha \to 0$，$1000\ln\alpha \to 0$，无分馏**。
   **直接推论**：稳定同位素地温计**在低温下最好用**（分馏大、对 $T$ 敏感）。B1 白云母题（500 °C，分馏仅 0.08‰）就是反面教材。

4. **$R$ 永远是"重同位素 / 轻同位素"**。
   写 $^{18}\mathrm{O}/^{16}\mathrm{O}$、$\mathrm{D}/\mathrm{H}$、$^{34}\mathrm{S}/^{32}\mathrm{S}$、$^{13}\mathrm{C}/^{12}\mathrm{C}$。**倒过来写会让所有 $\alpha$、$\delta$ 的符号全反。**

5. **下标顺序决定符号**。
   $\alpha_{A-B} = R_A/R_B$，对应 $\Delta_{A-B} = \delta_A - \delta_B$。
   $\alpha_{sph-gal}$ 就必须是 $\delta_{sph} - \delta_{gal}$，写成 $\delta_{gal} - \delta_{sph}$ 会得到负温度或荒谬结果。

6. **温度必须换成 Kelvin**（Feedback 反复提醒）。
   所有 $A/T$、$A/T^2$ 型标定式的 $T$ 都是 K。答案再换回 °C（$-273$ 或 $-273.15$）。

7. **单位 ‰ 一定要写**（Feedback 里 "Remember to include units" 出现了 4 次，说明这是重灾区）。

8. **$10^3\ln\alpha \approx X$ 只是近似，$\alpha$ 越偏离 1 误差越大**。
   - $\alpha = 1.00360$：$X = 3.60$，$10^3\ln\alpha = 3.594$（差 0.006）
   - $\alpha = 1.01017$：$X = 10.17$，$10^3\ln\alpha = 10.12$（差 0.05）
   - $\alpha = 1.04120$：$X = 41.20$，$10^3\ln\alpha = 40.37$（差 0.83！）
   **凡是 $\alpha$ 超过 ~1.01，老老实实取对数。**

9. **Isotopologue vs Isotopomer 别混**。
   前者=**组成**不同（$^{12}$C$^{16}$O vs $^{13}$C$^{16}$O）；后者=**位置**不同（CH$_3$CDO vs CH$_2$DCHO）。
   **数 isotopologue 的方法**：各元素位点的同位素选择数相乘；**同种元素的多个等价位点要用无序组合**（O$_2$ 是 6 种不是 9 种；H$_2$O 的两个 H 位只有 HH/HD/DD 三种）。

10. **注意 O$_2$ 的 $^{16}$O$^{18}$O 与 $^{17}$O$^{17}$O 质量都是 34**；H$_2$O 有三种质量 20 的 isotopologue。质量相同 ≠ 同一分子。

11. **热力学分馏 vs 动力学分馏的判据**：
    - **平衡/热力学**：反应达到平衡、可逆交换、由**键强/振动频率**控制；**重同位素富集在键强的相中**。
    - **动力学**：反应**未达平衡**（单向、快速、不可逆）、由**速度/扩散/蒸发**控制；**产物优先偏轻**。
    考题若说 "reactions do not reach equilibrium"，答案必是动力学分馏。

12. **方解石–水地温计用的是 $1/T$，矿物对地温计用的是 $1/T^2$**。
    $1000\ln\alpha_{cc-H_2O} = 18.03\times10^3\,T^{-1} - 32.42$（**注意是 $T^{-1}$ 且有截距**）
    $1000\ln\alpha_{qz-mt} = 6.29\times10^6/T^2$（**无截距**）
    $1000\ln\alpha_{musc-H_2O} = 1.90\times10^6/T^2 - 3.10$（**$T^{-2}$ 且有截距**）
    **不要套错公式，看清题目给的那一条。**

13. **地温计矿物对的选择原则**：要**分馏大、$1000\ln\alpha$ 对 $T$ 的斜率陡**。
    - ✅ 石英–磁铁矿（硅酸盐 vs 氧化物，成键差异大）
    - ✅ 闪锌矿–方铅矿（硫化物矿床测温标准）
    - ❌ 石英–长石（都是架状硅酸盐，成键相似，$\alpha$ 太小）

14. **古温度重建的根本难点：SMOW 本身随时间变化**。
    冰期时 $^{16}\mathrm{O}$ 被锁进冰盖 → 海水 $\delta^{18}\mathrm{O}$ 升高。所以从石灰岩的 $\delta^{18}\mathrm{O}$ 反算温度，需要**同时知道当时海水的 $\delta^{18}\mathrm{O}$**——这是一个"两个未知数一个方程"的问题。（Week 9 讨论如何解耦）

15. **数据散布的解释思路（B2(c) 型讨论题）**：真实地质变化 / 采样未达平衡（矿物环带！）/ 分析误差三者都要提到，并且要**把数据散布的量级与分析误差的量级作比较**来判断哪个占主导。

16. **$^{14}\mathrm{C}$ 不是稳定同位素**（放射性，Week 10 的内容）；本周的碳只讲 $^{12}\mathrm{C}$ 与 $^{13}\mathrm{C}$。

17. **氧的丰度排序**：$^{16}\mathrm{O} \gg ^{18}\mathrm{O} > ^{17}\mathrm{O}$。$^{18}$O 比 $^{17}$O 丰，别记反。硫：$^{32}\mathrm{S} \gg ^{34}\mathrm{S} > ^{33}\mathrm{S} > ^{36}\mathrm{S}$。

## 七、本周术语表

| 英文 | 中文 | 一句话解释 |
|---|---|---|
| **Isotope** | 同位素 | 质子数相同、中子数不同的核素，电子构型相同但核质量不同 |
| **Stable isotope** | 稳定同位素 | 不发生放射性衰变的同位素（对应核素图上的黑色方格） |
| **Chart of the nuclides** | 核素图 | 以质子数 vs 中子数作图的核素总表；黑色方格为稳定核素，偏离稳定谷越远半衰期越短 |
| **Standard atomic weight** | 标准原子量 | 一元素全部稳定同位素按自然丰度做的加权平均；丰度会变的元素以区间给出 |
| **Fractionation** | 分馏 | 不同同位素在相与相之间的分离/分配，根源是质量差 |
| **Thermodynamic (equilibrium) mass fractionation** | 热力学（平衡）质量分馏 | 由键的振动频率（$\nu \propto 1/\sqrt{m}$）差异造成，重同位素进入键强的相 |
| **Kinetic mass fractionation** | 动力学质量分馏 | 由 $\mathrm{KE}=\tfrac12 mv^2$ 造成的速度差引起（扩散、蒸发）；非平衡产物偏轻 |
| **Vibrational frequency** | 振动频率 | 化学键的伸缩频率，与成键原子质量的平方根成反比 |
| **Internal energy ($U$)** | 内能 | 键中储存的势能 + 原子振动的动能（Week 6 概念） |
| **Isotopologue** | 同位素体 | 只在**同位素组成**上不同的分子，如 $^{12}$C$^{16}$O vs $^{13}$C$^{18}$O |
| **Isotopomer** | 同位素位置异构体 | 只在同位素**位置**上不同的分子，如 CH$_3$CDO vs CH$_2$DCHO |
| **Deuterium (D, $^2$H)** | 氘 | 含 1 质子 + 1 中子的氢同位素，质量是 $^1$H 的两倍，丰度约 0.015% |
| **Protium ($^1$H)** | 氕 | 只有 1 个质子的普通氢，丰度约 99.98% |
| **Heavy water (D$_2$O)** | 重水 | 沸点、熔点、黏度、密度均与普通水不同，是同位素效应的直观例证 |
| **CHONS (H, C, N, O, S)** | 五大稳定同位素元素 | 质量差大、丰度高、多氧化态、成键多样、可测、生源 |
| **Fractionation factor ($\alpha$)** | 分馏系数 | $\alpha_{A-B}=R_A/R_B$；同位素版的分配系数，数值通常为 1.00X |
| **$R$** | 同位素比值 | **永远是重同位素/轻同位素**，如 $^{18}$O/$^{16}$O |
| **$10^3\ln\alpha$ (1000 ln α)** | 千倍对数分馏 | 把 1.00X 换算成更好用的数 X；与 $1/T^2$ 成线性关系 |
| **Delta notation ($\delta$)** | delta 记号 | $\delta=(R_{sample}/R_{std}-1)\times1000$ ‰，样品相对标准的同位素偏离 |
| **Per mil (‰)** | 千分号 | 乘 1000 的单位，来自拉丁 *per mille*；对应 % = *per cento* |
| **Capital delta ($\Delta_{A-B}$)** | 大 delta | $\Delta_{A-B}=\delta_A-\delta_B \approx 10^3\ln\alpha_{A-B}$，两相之间的同位素差 |
| **Isotopically heavy / enriched** | 同位素偏重 / 富集 | $\delta>0$，重同位素比标准多 |
| **Isotopically light / depleted** | 同位素偏轻 / 亏损 | $\delta<0$，重同位素比标准少 |
| **SMOW** | 标准平均大洋水 | Standard Mean Ocean Water，O 与 H 同位素的通用标准；其值随冰量变化 |
| **CDT** | 峡谷魔鬼陨硫铁 | Canyon Diablo Troilite (FeS)，S 同位素标准；来自造成 Arizona Meteor Crater 的铁陨石 |
| **PDB** | PDB 碳酸盐标准 | 碳同位素标准，按定义 $\delta^{13}\mathrm{C}=0$ |
| **Geothermometry** | 地温测量法 | 用矿物反应（此处为同位素交换平衡）确定其形成温度 |
| **Geothermometer** | 地温计 | 具体的测温体系，如石英–磁铁矿、闪锌矿–方铅矿 |
| **Isotopic exchange** | 同位素交换 | 只交换同位素、不发生化学变化的平衡，如 CaC$^{16}$O$_3$+H$_2^{18}$O ⇌ CaC$^{18}$O$_3$+H$_2^{16}$O |
| **Mass spectrometry** | 质谱法 | 精确测量不同质量核素相对丰度的技术，稳定同位素学的支柱工具 |
| **Benthic foraminifera** | 底栖有孔虫 | 分泌方解石壳的单细胞生物，古海洋温度重建的主要载体 |
| **Sphalerite (ZnS)** | 闪锌矿 | 锌的硫化物；与方铅矿构成最常用的 S 同位素地温计 |
| **Galena (PbS)** | 方铅矿 | 铅的硫化物 |
| **Chalcopyrite (CuFeS$_2$)** | 黄铜矿 | 常与闪锌矿、方铅矿共生的铜铁硫化物 |
| **Magnetite (Fe$_3$O$_4$)** | 磁铁矿 | 氧化物；与石英构成灵敏的 O 同位素地温计（$^{18}$O 强烈亏损） |

| **Partition coefficient** | 分配系数 | Week 3 概念；$\alpha$ 是其同位素类比 |
