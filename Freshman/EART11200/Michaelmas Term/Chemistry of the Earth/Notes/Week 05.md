## 二、核心概念

### 2.1 化学式 (chemical formula) 与矿物式的特殊约定

**基本定义**（GCSE 级）：化学式告诉你一个分子中每种元素各有多少个原子。
**矿物学版本**：矿物的化学式给出矿物中**各元素的原子比例 (atomic proportions)**。

三条铁律：
1. **化学式整体电荷必须为零 (zero charge overall)**。
2. **复合离子 (complex ion) 当作一个"单元"来处理**，不要拆开成单原子离子。
3. **复合离子出现多次时用括号**，括号外的下标表示该单元的个数。

| 矿物 Mineral | 离子电荷 Charges on ions | 化学式 Formula |
|---|---|---|
| 水 Water | H$^+$, O$^{2-}$ | H$_2$O |
| 石盐 Halite | Na$^+$, Cl$^-$ | NaCl |
| 金红石 Rutile | Ti$^{4+}$, O$^{2-}$ | TiO$_2$ |
| 刚玉 Corundum | Al$^{3+}$, O$^{2-}$ | Al$_2$O$_3$ |
| 方解石 Calcite | Ca$^{2+}$, (CO$_3$)$^{2-}$ | CaCO$_3$ |
| 镁橄榄石 Forsterite | Mg$^{2+}$, (SiO$_4$)$^{4-}$ | Mg$_2$SiO$_4$ |
| 水镁石 Brucite | Mg$^{2+}$, (OH)$^-$ | Mg(OH)$_2$ |
| 氟磷灰石 Fluorapatite | Ca$^{2+}$, (PO$_4$)$^{3-}$, F$^-$ | Ca$_5$(PO$_4$)$_3$F |

**为什么要把 CO$_3^{2-}$、SiO$_4^{4-}$ 当整体？**（老师在 transcript 里反复强调）
- 方解石：作为矿物学家我们写 Ca$^{2+}$ + CO$_3^{2-}$，**不要**去想成 Ca$^{2+}$ + C$^{4+}$ + 3O$^{2-}$。后一种拆法在数学上电荷也配平（$+2+4-6=0$），但**对矿物学没有用**，因为它掩盖了碳酸根内部的共价键结构。
- 硅酸盐：SiO$_4$ 四面体带 4$-$ 电荷。粗略地可以想成 Si$^{4+}$ + 4O$^{2-}$，但**实际上 Si–O 之间是共价键**，只是整体又挂上了额外的电子，所以形成 (SiO$_4$)$^{4-}$ 这个单元。
- 括号规则示例：水镁石写 Mg(OH)$_2$ 而**不是** MgO$_2$H$_2$；氟磷灰石写 Ca$_5$(PO$_4$)$_3$F 而**不是** Ca$_5$P$_3$O$_{12}$F。因为我们要表达"有 3 个完整的磷酸根单元"。

### 2.2 元素替代 (element substitution) 与固溶体 (solid solution)

矿物式里出现 **(A,B)** 这种带逗号的括号，表示 A 和 B 两种元素可以**互相替代**，比例任意。

**橄榄石 Olivine**：
- 端元 (end member) 1：镁橄榄石 Forsterite，Mg$^{2+}$ + (SiO$_4$)$^{4-}$ → Mg$_2$SiO$_4$
- 端元 2：铁橄榄石 Fayalite，Fe$^{2+}$ + (SiO$_4$)$^{4-}$ → Fe$_2$SiO$_4$
- 固溶体写法：**(Mg,Fe)$_2$SiO$_4$**

含义（transcript 重点澄清）：若某颗橄榄石"含 10% 铁、90% 镁"，**不是说晶体的这一块是镁橄榄石、那一块是铁橄榄石**；而是说在**晶格 (crystal lattice)** 中，90% 的阳离子位 (cation sites) 被 Mg 占据、10% 被 Fe 占据，且是**随机分布**的。公式的意思是：**Mg + Fe 的总数必须 = 2**（对应每一个 SiO$_4$ 单元）。

**碱性长石 Alkali Feldspar**：
- 钠长石 Albite：Na$^+$ + Al$^{3+}$ + (Si$_3$O$_8$)$^{4-}$ → NaAlSi$_3$O$_8$
- 正长石 Orthoclase：K$^+$ + Al$^{3+}$ + (Si$_3$O$_8$)$^{4-}$ → KAlSi$_3$O$_8$
- 固溶体：**(Na,K)AlSi$_3$O$_8$**，即平均每 1 个 Al + 3 个 Si + 8 个 O 对应 **1 个** Na 或 K。

**关键判据（老师明确强调）**：只有当两种元素**电荷相同**时，才会写成这种可互换的替代形式。Mg$^{2+}$↔Fe$^{2+}$ 同为 2+，Na$^+$↔K$^+$ 同为 1+，所以可以直接互换而不破坏电荷平衡。电荷不同的替代需要**耦合替代 (coupled substitution)**，写法不是这样。

### 2.3 化学方程式 (chemical equation)：反应 vs 平衡

$$\ce{A + B -> C + D} \quad \text{(反应 reaction)}$$
$$\ce{A + B = C + D} \quad \text{(平衡 equilibrium)}$$

- **箭头 →**：表示反应正在朝一个方向进行。
- **等号 =**：表示化学**平衡**，左右两侧的物种**同时存在**，体系"对所有物种都满意"（老师原话大意）。

配平的两条要求：
1. 两侧**每种元素的原子数相同**；
2. 两侧**总电荷相同**（在 redox 半反应中尤其关键，容易被忘）。

### 2.4 配平的通用策略（本周最重要的"手艺"）

老师给出的**表格法 (grid method)**：画一张表，行是元素，列是各个反应物/生成物 + 两侧合计。虽然简单反应可以口算，但对复杂矿物反应，写表格能让你**知道自己走到哪一步了**。

**配平顺序的启发式规则（Rules of thumb）**：
1. **先找只在每一侧出现在"一个"化学式里的元素**（例如 Si 只出现在橄榄石和蛇纹石中）——改动它牵连最少。
2. **氧 (O) 留到最后**（general rule: leave O until last）。因为 O 几乎出现在所有矿物里，先动 O 会把一切搞乱。
3. **已经配平的元素不要去碰**——选择系数时，优先选那个"不会破坏已配平元素"的方案。
4. **只能改系数 (coefficients)，绝不能改化学式 (never change a formula)**。
5. 当有多种配平途径时（如 Q4 的滑石/顽火辉石），**扫一眼其它元素**再决定，避免选到会引发连锁失衡的那一条。

### 2.5 摩尔 (mole) 与阿伏伽德罗常数 (Avogadro constant)

**摩尔 MOLE**：SI 单位「物质的量 amount of substance」，符号 **mol**。

> 定义：1 mole 是含有与 **12 g 碳-12 ($^{12}$C)** 中原子数目相同的**实体 (entities)** 的物质的量。实体可以是原子、分子或离子。

12 g $^{12}$C 中有多少原子？→ **$6.022\times10^{23}$**，这就是 **阿伏伽德罗常数 (Avogadro constant)**。

两种等价理解：
1. 阿伏伽德罗常数 = **每摩尔的粒子数**（number of molecules per mole）。
2. 阿伏伽德罗常数被这样定义：使得**一摩尔物质的质量（以克为单位）在数值上等于该物质的原子量或分子量**。

推论：
- 12 g 的 $^{12}$C 含 $6.022\times10^{23}$ 个碳原子
- 1 g 的 $^{1}$H 含 $6.022\times10^{23}$ 个氢原子
- 32 g 的 $^{32}$S 含 $6.022\times10^{23}$ 个硫原子

**分子量 (molecular mass / molecular weight)**：一个分子的质量 = 各组成原子的原子量 × 该元素原子数 之和。

水的例子：
- $M(\ce{H2O}) = 2\times 1 + 16 = 18$
- 1 mole 水 = 18 g
- 18 g 水含 $6.022\times10^{23}$ 个水分子
- （transcript 小趣味）因为 1 cm³ 水 ≈ 1 g，所以量筒量出 18 cm³ 水，里面就正好是 $6.022\times10^{23}$ 个水分子。

**为什么原子量常常不是整数？**（transcript 澄清）
Si 的原子量是 28.086 而不是 28，O 是 15.999 而不是 16——因为自然界的元素是**多种同位素的混合**，原子量是同位素加权平均。前面说"12 g 碳-12"时之所以是整数，是因为特指**只有 $^{12}$C 这一种同位素**的情况。

### 2.6 氧化态 (oxidation state) 与化合价 (valence)

- **化合价 Valence** = 离子上的电荷。例：Fe$^{2+}$ = 二价铁 (divalent iron)，Fe$^{3+}$ = 三价铁 (trivalent iron)。
- 化合价也可以用 **氧化态 (oxidation state)** 来描述。铁的氧化态：Fe$^{2+}$ = **亚铁 ferrous**，Fe$^{3+}$ = **高铁 ferric**，Fe$^0$ = 金属铁。
- 凡是**涉及氧化态改变**的反应，就叫做 **氧化还原反应 (oxidation–reduction reaction / REDOX reaction)**。

**核心定义（用电子来记）**：
- **氧化 Oxidation = 失去电子 (LOSS of electron) = 氧化态升高**：Fe$^{2+}$ → Fe$^{3+}$ + e$^-$
- **还原 Reduction = 得到电子 (GAIN of electron) = 氧化态降低**：Fe$^{3+}$ + e$^-$ → Fe$^{2+}$

**助记 (mnemonic)：OIL RIG** — **O**xidation **I**s **L**oss, **R**eduction **I**s **G**ain。

**极其重要的概念澄清（老师专门强调）**：
> **REDOX 反应不一定需要氧气参与！**（REDOX reactions do not necessarily need to involve oxygen.）
"氧化"这个名字是历史遗留，本质是**电子转移**。

### 2.7 半反应 (half reactions)

把一个 redox 反应拆成"只看某一个元素"的两半，分别写出电子的得失。

**例 1：锌置换铜**
$$\ce{Zn_{(s)} + Cu^{2+}_{(aq)} = Zn^{2+}_{(aq)} + Cu_{(s)}}$$
- Zn 被氧化（失电子）：$\ce{Zn = Zn^{2+} + 2e^-}$
- Cu$^{2+}$ 被还原（得电子）：$\ce{Cu^{2+} + 2e^- = Cu}$
- 注意：**全程没有氧参与**，但这是标准的 redox 反应。

**例 2：氯气与金属铁**
$$\ce{2Fe + 3Cl2 = 2Fe^{3+} + 6Cl^-}$$
- Fe$^0$ 被氧化为 Fe$^{3+}$：$\ce{2Fe = 2Fe^{3+} + 6e^-}$
- Cl$^0$ 被还原为 Cl$^-$：$\ce{3Cl2 + 6e^- = 6Cl^-}$
- **两个半反应产生/消耗的电子数必须相等（6 = 6）**，这样加起来才能抵消。
- **redox 反应中电荷也必须配平，不只是原子数。**

### 2.8 可变氧化态：过渡金属 (transition metals)

**为什么过渡元素有可变氧化态？** 因为它们正在**填充 d 轨道 (filling the d orbitals)**，d 轨道能量相近，电子组态可以变化——电子组态的变化就等价于氧化态的变化。

第一系列（第一周期）过渡金属常见氧化态（地球化学最关心的一组）：

| 元素 | 常见氧化态 | 备注 |
|---|---|---|
| Sc | +3 | |
| Ti | +2, +3, **+4** | 金红石 TiO$_2$ |
| V | +2, +3, +4, +5 | |
| Cr | +2, **+3**, +6 | Cr$^{6+}$ 有毒且可溶 |
| **Mn** | **+2, +3, +4**, +6, +7 | 老师课上点名：Mn 可为 2/3/4/6/7 价 |
| **Fe** | **+2 (ferrous), +3 (ferric)**, 以及 Fe$^0$（金属） | 地球化学最重要 |
| Co | +2, +3 | |
| Ni | +2 | |
| Cu | +1, +2 | |
| Zn | +2 | |

> **注意**：常见的氧化态表里通常**不包含 0 价**，但金属态是真实存在的，写作 Fe$^0$ = 金属铁（地核就是 Fe$^0$）。

**铀 (Uranium, U)** —— 位于周期表最下方的**锕系 (actinide series)**，是另一个氧化态至关重要的元素：
- **U$^{6+}$（较氧化）→ 在水中可溶 (soluble)**
- **U$^{4+}$（较还原）→ 溶解度低得多 (much less soluble)**
- ⇒ **铀矿床形成于"氧化性溶液被还原"之处。**
- 最主要铀矿石矿物：**晶质铀矿 Uraninite (UO$_2$)**，又名沥青铀矿 (pitchblende)。

## 三、公式与图表

### 3.1 基础配平练习（GCSE 级）

**(a) 钠 + 氧**
$$\ce{Na + O2 -> Na2O} \quad(\text{未配平})$$
思路：右边 Na$_2$O 只有 1 个 O，左边 O$_2$ 有 2 个 → O 必须成对出现，所以右边至少要 2 个 Na$_2$O → 于是需要 4 个 Na。
$$\boxed{\ce{4Na + O2 -> 2Na2O}}$$

**(b) 钠 + 水**
$$\ce{Na + H2O -> NaOH + H2}\quad(\text{未配平})$$
思路：Na 和 O 各 1 个看似 OK，但左边 H = 2、右边 H = 3。**左边的 H 只能以 2 的倍数出现**（因为 H$_2$O 里有 2 个 H）→ 取 4 个 H → 左边 2H$_2$O → 右边需要 2NaOH + H$_2$（共 4 H）→ 再回头把 Na 配成 2。
$$\boxed{\ce{2Na + 2H2O -> 2NaOH + H2}}$$

**(c) 钙 + 水 → 氢氧化钙 + 氢气（完整分步示范）**

*Step 1* 写出各物质化学式：
$$\ce{Ca + H2O -> Ca(OH)2 + H2}$$
*Step 2* 逐元素检查：
- Ca：两边各 1 → OK。
- O：左 1、右 2 → 不平。**调整分子数目，但绝不改写化学式**：把水写成 2H$_2$O。
$$\ce{Ca + 2H2O -> Ca(OH)2 + H2}$$
- H：左 4、右 2+2 = 4 → OK。
$$\boxed{\ce{Ca + 2H2O -> Ca(OH)2 + H2}}$$

### 3.2 涉及矿物的重要反应类型

课上列出的地质学中重要的矿物反应类型：
- 变质岩中对**压力/温度变化**的响应 (response to changes in P and T)
- 矿物与**水的反应（水化 hydration）**及与其它流体的反应（如**碳酸化 carbonation**）
- 矿物**失去挥发分**（脱水 dehydration、脱碳酸 decarbonation）
- **风化 (weathering)** 过程中矿物与水的反应
- 从水或其它流体中**沉淀 (precipitation)** 出矿物

一句话总结（transcript）：在我们研究的体系里，**矿物组合 (mineral assemblage) 是在不断变化的**。

**例 1：变质反应（P、T 变化）—— 钠长石 → 硬玉 + 石英**

地质背景：发生在**俯冲带 (subduction zone)**，随压力升高而进行。地表稳定的钠长石被埋深后不再稳定，转变为硬玉 + 石英。

$$\ce{NaAlSi3O8 -> NaAlSi2O6 + SiO2}$$
$$\text{albite (钠长石)} \to \text{jadeite (硬玉)} + \text{quartz (石英)}$$

| 元素 | Albite | Jadeite | Quartz | LHS | RHS |
|---|---|---|---|---|---|
| Na | 1 | 1 | 0 | 1 | 1 |
| Al | 1 | 1 | 0 | 1 | 1 |
| Si | 3 | 2 | 1 | 3 | 3 |
| O | 8 | 6 | 2 | 8 | 8 |

**结论：写出来就已经配平 (balanced as written)。**

---

**例 2：矿物与水反应 —— 蛇纹石化 (serpentinization)**

地质背景：**离散板块边界 (divergent plate boundary)** 的洋底，玄武岩/辉长岩中的橄榄石与海水反应，生成蛇纹石 + 水镁石。实例：大西洋中脊 Lost City 热液喷口区的 Atlantis Massif，回收到的岩石以蛇纹石化橄榄岩 (serpentinized peridotite) 为主。

$$\ce{Mg2SiO4 + H2O -> Mg3Si2O5(OH)4 + Mg(OH)2} \quad(\text{未配平})$$
$$\text{olivine} + \text{water} \to \text{serpentine} + \text{brucite}$$

**Step 0 建表：**

| 元素 | Olivine | Water | LHS 合计 | = | Serpentine | Brucite | RHS 合计 |
|---|---|---|---|---|---|---|---|
| Mg | 2 | 0 | 2 | | 3 | 1 | 4 |
| Si | 1 | 0 | 1 | | 2 | 0 | 2 |
| O | 4 | 1 | 5 | | 9 | 2 | 11 |
| H | 0 | 2 | 2 | | 4 | 2 | 6 |

→ **一个元素都不平！**

**Step 1 从 Si 开始**（Si 在每一侧都只出现在一个矿物里）：左 1、右 2 → **橄榄石 × 2**。

| 元素 | Olivine ×2 | Water | LHS | = | Serp | Bruc | RHS |
|---|---|---|---|---|---|---|---|
| Mg | 2 → **4** | 0 | 2 → **4** | | 3 | 1 | 4 ✔ |
| Si | 1 → **2** | 0 | 1 → **2** | | 2 | 0 | 2 ✔ |
| O | 4 → **8** | 1 | 5 → **9** | | 9 | 2 | 11 ✘ |
| H | 0 | 2 | 2 | | 4 | 2 | 6 ✘ |

Mg、Si 顺带一起平了。

**Step 2 接着配 H**（H 在左侧只出现在水里；O 留到最后）：左 2、右 6 → **水 × 3**。

| 元素 | Olivine ×2 | Water ×3 | LHS | = | Serp | Bruc | RHS |
|---|---|---|---|---|---|---|---|
| Mg | 4 | 0 | 4 | | 3 | 1 | 4 ✔ |
| Si | 2 | 0 | 2 | | 2 | 0 | 2 ✔ |
| O | 8 | 1 → **3** | 9 → **11** | | 9 | 2 | 11 ✔ |
| H | 0 | 2 → **6** | 2 → **6** | | 4 | 2 | 6 ✔ |

$$\boxed{\ce{2Mg2SiO4 + 3H2O -> Mg3Si2O5(OH)4 + Mg(OH)2}}$$

> **注意**（老师提醒）：蛇纹石 Mg$_3$Si$_2$O$_5$(OH)$_4$ 中，有的 O 与 Si 结合、有的 O 在 OH 里，**配平时要把所有 O 一起数**（共 5 + 4 = 9 个）；但化学式仍分开写，是为了表达成键方式。

**例 3：含水矿物分解释放 H$_2$O —— 脱水反应 (dehydration)**

地质背景：许多沉积岩含**含水矿物 (water-bearing minerals)**，在**低级变质 (low-grade metamorphism)** / 俯冲埋深过程中分解释放水。叶蜡石 → 蓝晶石 + 石英 + 水。

$$\ce{Al2Si4O10(OH)2 <=> Al2SiO5 + SiO2 + H2O}\quad(\text{未配平})$$
$$\text{pyrophyllite} \Leftrightarrow \text{kyanite (或红柱石 andalusite)} + \text{quartz} + \text{water}$$

| 元素 | Pyrophyllite | LHS | = | Kyanite | Quartz | Water | RHS |
|---|---|---|---|---|---|---|---|
| Al | 2 | 2 | | 2 | | | 2 ✔ |
| Si | 4 | 4 | | 1 | 1 | | 2 ✘ |
| O | 12 | 12 | | 5 | 2 | 1 | 8 ✘ |
| H | 2 | 2 | | | | 2 | 2 ✔ |

- Al、H 已平 → 不要动它们所在的矿物。
- O 留最后。
- 配 Si：左 4、右 2 → **石英 × 3**（选石英是因为它是"最简单、只含 Si 和 O 的分子"，动它牵连最少）。

| 元素 | Pyrophyllite | LHS | = | Kyanite | Quartz ×3 | Water | RHS |
|---|---|---|---|---|---|---|---|
| Al | 2 | 2 | | 2 | | | 2 ✔ |
| Si | 4 | 4 | | 1 | 1 → **3** | | 2 → **4** ✔ |
| O | 12 | 12 | | 5 | 2 → **6** | 1 | 8 → **12** ✔ |
| H | 2 | 2 | | | | 2 | 2 ✔ |

$$\boxed{\ce{Al2Si4O10(OH)2 <=> Al2SiO5 + 3SiO2 + H2O}}$$

**用摩尔来读这个反应**：「**1 mole 叶蜡石分解生成 1 mole 蓝晶石 + 3 moles 石英 + 1 mole 水**」。
配平系数 = **摩尔比**。这是把配平方程与定量计算联系起来的关键一步：石英的摩尔数是水的 3 倍。

**野外意义**：在变质岩中可以看到残余的叶蜡石碎块，旁边是新生成的蓝晶石和石英——这就是反应进行过的证据。

### 3.3 摩尔相关公式汇总

$$\text{分子量 } M = \sum_i (\text{原子量}_i \times n_i)$$
$$n\ (\text{mol}) = \frac{m\ (\text{g})}{M\ (\text{g·mol}^{-1})}$$
$$N\ (\text{粒子数}) = n \times N_A,\qquad N_A = 6.022\times10^{23}\ \text{mol}^{-1}$$
$$\rho = \frac{m}{V} \;\Longrightarrow\; V = \frac{m}{\rho}$$

**符号说明**：$M$ = 分子量（数值上 = 1 mol 的克数）；$n$ = 物质的量；$m$ = 质量；$N_A$ = 阿伏伽德罗常数；$\rho$ = 密度；$V$ = 体积。

**课堂例题：石英的分子量与原子数**
- 原子量：Si = 28.086，O = 15.999
- $M(\ce{SiO2}) = 28.086 + 2\times15.999 = \mathbf{60.084}$
- 一块重 **120 g** 的石英晶体里有多少 Si 原子？多少 O 原子？
  - $n(\ce{SiO2}) = 120 / 60.084 \approx 2\ \text{mol}$
  - Si 原子：2 mol → $2\times6.022\times10^{23} \approx \mathbf{12\times10^{23}}$ 个
  - O 原子：每个 SiO$_2$ 单元含 2 个 O → 4 mol → $\approx \mathbf{24\times10^{23}}$ 个

### 3.4 氧化还原反应：赤铁矿–磁铁矿

**矿物式的氧化态分解**：
- 赤铁矿 Hematite，Fe$_2$O$_3$ = Fe$^{3+}_2$O$^{2-}_3$（全部三价铁）
- 磁铁矿 Magnetite，Fe$_3$O$_4$ = Fe$^{2+}$Fe$^{3+}_2$O$^{2-}_4$（**混合价态**：1 个二价 + 2 个三价）

**平衡式**：
$$\ce{6Fe2O3 = 4Fe3O4 + O2}$$
$$\text{hematite} \;=\; \text{magnetite} + \text{oxygen}$$
校验：Fe：$6\times2 = 12$ vs $4\times3 = 12$ ✔；O：$6\times3 = 18$ vs $4\times4 + 2 = 18$ ✔。

**电子账**：
- 正向（赤铁矿 → 磁铁矿）：赤铁矿中的 Fe$^{3+}$ **得到一个电子**变成 Fe$^{2+}$，即**被还原 (reduced)**，同时**释放出 O$_2$**。
$$\ce{Fe^{3+} + e^- = Fe^{2+}}\quad(\text{reduction})$$
- 逆向（磁铁矿 + O$_2$ → 赤铁矿）：磁铁矿中的 Fe$^{2+}$ **失去一个电子**变成 Fe$^{3+}$，即**被氧化 (oxidized)**。
$$\ce{Fe^{2+} = Fe^{3+} + e^-}\quad(\text{oxidation})$$
- 半反应两侧电荷校验：左 $(+3) + (-1) = +2$，右 $+2$ ✔。

**地质含义**：这个反应可以被当作一个"**氧缓冲 (oxygen buffer)**"来读——赤铁矿转变为磁铁矿会**产生氧气**；反过来磁铁矿被氧气氧化会形成赤铁矿。

### A. 配平化学反应 (Balancing chemical reactions)

**A1. 脱碳酸反应 (decarbonation)：方解石 + 石英 → 硅灰石 + CO$_2$**

地质背景：海底堆积的贝壳含**方解石 (calcite)**，在**俯冲带**随俯冲板片下沉、升温，与石英反应分解生成**硅灰石 (wollastonite)** 和 CO$_2$。**释放的 CO$_2$ 气体驱动火山喷发。**

$$\ce{CaCO3 + SiO2 = CaSiO3 + CO2}$$

| 元素 | Calcite | Quartz | LHS | = | Wollastonite | CO$_2$ | RHS |
|---|---|---|---|---|---|---|---|
| Ca | 1 | | 1 | | 1 | | 1 ✔ |
| C | 1 | | 1 | | | 1 | 1 ✔ |
| O | 3 | 2 | 5 | | 3 | 2 | 5 ✔ |
| Si | | 1 | 1 | | 1 | | 1 ✔ |

**答案：写出来就已经配平 (balanced as written)。**

**A2. 白云母 + 石英 → 钾长石 + 夕线石 + 水**

> 注意白云母式子里 Al 出现了两次：Al$_2$ 和 Al，**共 3 个 Al**（一部分在八面体位、一部分替代四面体位的 Si）——这是最容易数错的地方。

| 元素 | Muscovite | Quartz | LHS | = | K-feldspar | Sillimanite | Water | RHS |
|---|---|---|---|---|---|---|---|---|

**A3. 斜方辉石 + 斜长石 → 石榴石 + 单斜辉石 + 石英**（提示：先配 Mg）

背景说明：斜方辉石 (orthopyroxene) 的 Ca 含量极低（此处按 0 处理）；单斜辉石 (clinopyroxene) 分子式中 Ca 与 Mg 等量。

$$\ce{MgSiO3 + CaAl2Si2O8 = Mg3Al2Si3O12 + CaMgSi2O6 + SiO2}\quad(\text{未配平})$$

| 元素 | Opx **×4** | Plag | LHS | = | Garnet | Cpx | Quartz | RHS |
|---|---|---|---|---|---|---|---|---|
| Mg | 1 → **4** | | 1 → **4** | | 3 | 1 | | 4 |
| Si | 1 → **4** | 2 | 3 → **6** | | 3 | 2 | 1 | 6 |
| O | 3 → **12** | 8 | 11 → **20** | | 12 | 6 | 2 | 20 |
| Ca | | 1 | 1 | | | 1 | | 1 |
| Al | | 2 | 2 | | 2 | | | 2 |

**解题思路（Feedback 原文逻辑）**：
- 原式**不平**。
- 观察：**Ca 和 Al 已经平了**，所以不必从它们下手（也不要动含它们的矿物）。
- **Mg 是首选**，因为它在左侧只出现在一个矿物（斜方辉石）里。
- 左 Mg = 1，右 Mg = 3 + 1 = 4 → **斜方辉石 × 4**。
- **仅此一步，整个反应就配平了**（Si、O 顺带一起平）。

$$\boxed{\ce{4MgSiO3 + CaAl2Si2O8 = Mg3Al2Si3O12 + CaMgSi2O6 + SiO2}}$$

**A4. 滑石 + 顽火辉石 → 直闪石**（提示：先配 Mg）

$$\ce{Mg3Si4O10(OH)2 + MgSiO3 = Mg7Si8O22(OH)2}\quad(\text{未配平})$$
$$\text{talc} + \text{enstatite} = \text{anthophyllite}$$

| 元素 | Talc | Enstatite **×4** | LHS | = | Anthophyllite | RHS |
|---|---|---|---|---|---|---|
| Mg | 3 | 1 → **4** | 4 → **7** | | 7 | 7 ✔ |
| Si | 4 | 1 → **4** | 5 → **8** | | 8 | 8 ✔ |
| O | 12 | 3 → **12** | 15 → **24** | | 24 | 24 ✔ |
| H | 2 | | 2 | | 2 | 2 ✔ |

**解题思路（这题的"选择判断"是考点）**：
- 从 Mg 开始：左 4、右 7。有**两种**可能的凑法：
  - (2 × Talc) + (1 × Enstatite) → Mg = 6 + 1 = 7 ✔
  - (1 × Talc) + (4 × Enstatite) → Mg = 3 + 4 = 7 ✔
- **怎么选？扫一眼其它元素**：**H 已经配平（两边各 2）**，如果把滑石 ×2，H 就变成 4，**反而破坏 H**。所以选 **(1 × Talc) + (4 × Enstatite)**。

$$\boxed{\ce{Mg3Si4O10(OH)2 + 4MgSiO3 = Mg7Si8O22(OH)2}}$$

> **这题体现的通用原则：不要破坏已经配平的元素。**

**A5. 挑战题：透闪石 + 方解石 + 石英 → 透辉石 + CO$_2$ + 水**

$$\ce{Ca2Mg5Si8O22(OH)2 + CaCO3 + SiO2 = CaMgSi2O6 + CO2 + H2O}\quad(\text{未配平})$$
$$\text{tremolite} + \text{calcite} + \text{quartz} = \text{diopside} + \text{carbon dioxide} + \text{water}$$

**分步策略（Feedback 给出的完整推理链）**：
1. **C 已配平** → 不要从含 C 的矿物（方解石、CO$_2$）开始。
2. **H 已配平** → 不要从透闪石或 H$_2$O 开始。
3. **O 留到最后。**
4. **Mg 在每一侧都只出现在一个矿物里 → 从 Mg 开始。** 左 Mg = 5，右 Mg = 1 → **透辉石 × 5**（红色步骤）。
5. 接着要配 Ca 和 Si。为避免动到已平的 Mg、H、C，**避开透闪石**。先配 **Si**：此时左 Si = 8 + 1 = 9，右 Si = 5×2 = 10 → **石英 × 2**（绿色步骤），左 Si = 8 + 2 = 10 ✔。
6. 再配 **Ca**：左 Ca = 2 + 1 = 3，右 Ca = 5 → **方解石 × 3**（紫色步骤），左 Ca = 2 + 3 = 5 ✔。
7. **此时 C 被破坏了**（左 C = 3，右 C = 1）→ 为同时配平 C 和 O，**CO$_2$ × 3**（橙色步骤）。
8. 最后校验 O：左 = 22 + 2(OH中的O) ... 按分子式计：透闪石 O = 24（22 + OH 中 2 个），方解石 3×3 = 9，石英 2×2 = 4 → **LHS O = 37**；右：透辉石 5×6 = 30，CO$_2$ 3×2 = 6，H$_2$O = 1 → **RHS O = 37** ✔

$$\boxed{\ce{Ca2Mg5Si8O22(OH)2 + 3CaCO3 + 2SiO2 = 5CaMgSi2O6 + 3CO2 + H2O}}$$

**完整校验**：Ca 2+3=5 = 5 ✔｜Mg 5 = 5 ✔｜Si 8+2=10 = 10 ✔｜O 24+9+4=37 = 30+6+1=37 ✔｜H 2 = 2 ✔｜C 3 = 3 ✔

### B. 摩尔与分子量 (Moles and Molecular Mass)

**B1. 黄铁矿 (pyrite, FeS$_2$)**（原子量：Fe = 56，S = 32）

- 分子量：$M(\ce{FeS2}) = 56 + 2\times32 = \mathbf{120}$
- 1 mole 黄铁矿的质量 = **120 g**
- 1 mole 黄铁矿的体积？（黄铁矿密度 = 5 g·cm$^{-3}$）
$$\rho = \frac{m}{V} \Rightarrow 5 = \frac{120}{V} \Rightarrow V = \frac{120}{5} = \mathbf{24\ \text{cm}^3}$$

**B2. 回到 A1 的方解石反应做定量分析**

$$\ce{CaCO3 + SiO2 = CaSiO3 + CO2}$$
原子量：C = 12，O = 16，Si = 28，Ca = 40。

| 物质 | 计算 | 分子量 |
|---|---|---|
| 方解石 CaCO$_3$ | $40 + 12 + 3\times16$ | **100** |
| 石英 SiO$_2$ | $28 + 2\times16$ | **60** |
| 硅灰石 CaSiO$_3$ | $40 + 28 + 3\times16$ | **116** |
| 二氧化碳 CO$_2$ | $12 + 2\times16$ | **44** |

**关键观察：反应两侧的总分子量相等（质量守恒）**
$$\text{LHS} = 100 + 60 = 160 \qquad \text{RHS} = 116 + 44 = 160 \;\checkmark$$

- 1 mole 方解石的质量 = **100 g**
- **若从 1 kg 方解石出发，会产生多少质量的 CO$_2$？**
$$n(\ce{CaCO3}) = \frac{1000\ \text{g}}{100\ \text{g·mol}^{-1}} = 10\ \text{mol}$$
反应式系数为 1:1 → **1 mole 方解石产生 1 mole CO$_2$** → 10 mol 方解石 → 10 mol CO$_2$
$$m(\ce{CO2}) = 10 \times 44 = \mathbf{440\ \text{g}}$$

- **产生的 CO$_2$ 中含多少个碳原子？**
10 mol CO$_2$ 含 10 mol C：
$$N = 10 \times 6.022\times10^{23} = \mathbf{6.022\times10^{24}}\ \text{个碳原子}$$

### C. 氧化还原反应 (Oxidation–Reduction Reactions)

#### C(a) 铀矿物的形成 (Formation of uranium minerals)

（参考 McSween p. 132, Worked Problem 7.5）

**问题背景**：世界上大部分可开采的铀以**晶质铀矿 (uraninite, UO$_2$)** 的形式产在**砂岩型矿床 (sandstone-hosted deposits)** 中。为什么？

**成矿链条**：
1. **来源**：铀的主要来源是**花岗质岩石 (granitic rocks)**，可含高达 **15 ppm** 的铀。
2. **溶解与迁移**：花岗岩被水**风化 (weathered)** 时，铀以 **U$^{6+}$** 形式溶入水中，并以**络合离子 (complex ions)** 的形式被水轻易搬运。
   - **酸性水 (acidic water)** 中，稳定的是**铀酰离子 (uranyl ion)**：
   $$\ce{UO2^{2+}}:\quad 1\times \ce{U^{6+}} + 2\times \ce{O^{2-}} = (+6) + (-4) = \mathbf{+2}\ \checkmark$$
   - **碱性水 (alkaline water)** 中，U$^{6+}$ 以碳酸铀酰络离子迁移：
   $$\ce{UO2(CO3)3^{4-}}:\quad 1\times \ce{U^{6+}} + 2\times \ce{O^{2-}} + 3\times \ce{(CO3)^{2-}} = (+6) + (-4) + (-6) = \mathbf{-4}\ \checkmark$$
3. **沉淀（还原成矿）**：当水开始溶解铁并携带 **Fe$^{2+}$** 时，发生：
$$\ce{UO2(CO3)3^{4-} + 2Fe^{2+} + 3H2O = UO2 + 2Fe(OH)3 + 3CO2}$$

**逐项分析（考点）**：
- **UO$_2$ 中 U 的化合价？** → **U$^{4+}$**。因为 1 个 U$^{4+}$ + 2 个 O$^{2-}$ → 总电荷 $+4-4 = 0$ ✔
- **U$^{6+}$ 在这个反应中是被氧化还是被还原？** → **被还原 (reduced)**，U$^{6+}$ → U$^{4+}$，**得到 2 个电子**。
- **Fe$^{2+}$ 是被氧化还是被还原？** → **被氧化 (oxidized)**，Fe$^{2+}$ → Fe$^{3+}$（在 Fe(OH)$_3$ 中），**失去 1 个电子**；2 个 Fe 共失 2 个电子，正好与 U 得的 2 个电子相抵 ✔
- **成矿结果**：反应发生在**砂岩 (sandstone)** 内部。**UO$_2$（晶质铀矿）和 Fe(OH)$_3$（氢氧化铁 / 三价铁氢氧化物）都不溶于水**，因此两者都在砂岩中**沉淀 (precipitate)**，形成矿床。

**方程式校验**：U 1=1｜C 3=3｜Fe 2=2｜H 6=6｜O: 左 $(2+9)+3 = 14$，右 $2 + 6 + 6 = 14$ ✔｜电荷: 左 $(-4)+(+4) = 0$，右 $0$ ✔

**另一种铀矿石：铀石 (coffinite, USiO$_4$)**
- U 的化合价？→ **U$^{4+}$**，与 [SiO$_4$]$^{4-}$（四面体硅酸根离子）配平。
- 命名由来（Feedback 里的趣味问题）：以美国地质学家 **Reuben Clare Coffin (1886–1972)** 命名（不是 "coffin 棺材"）。

> **总规律（务必记住）**：**U$^{6+}$ 可溶 → 被搬运；U$^{4+}$ 不溶 → 沉淀。所以铀矿床形成在"氧化性溶液遇到还原环境"的地方**（如砂岩中的有机质、含 Fe$^{2+}$ 的水）。

#### C(b) 黄铁矿的氧化 (Oxidation of pyrite) —— 酸性矿山排水的化学

**基本反应（未配平框架）**：
$$\ce{FeS2 + O2 = Fe(OH)3 + SO4^{2-}}$$
当黄铁矿暴露于**大气氧 (atmospheric oxygen)** 时发生，产物是 Fe(OH)$_3$ 沉淀 + 溶液中的 SO$_4^{2-}$ 离子。

**第一步：确定黄铁矿中各元素的氧化态**
- 题目给定：黄铁矿中**铁的氧化态是 +2**。
- 由电荷平衡，2 个 S 合计为 $-2$ → 每个 **S 为 $-1$**（这是**二硫离子 S$_2^{2-}$**，不是普通的 S$^{2-}$，这一点极易搞错）。

**第二步：写铁的半反应**
$$\boxed{\ce{Fe^{2+} = Fe^{3+} + e^-}}$$
- 这是**氧化 (oxidation)**——**失去电子**。

**第三步：写硫的半反应**
S 从 $-1$（黄铁矿中）变到 $+6$（SO$_4^{2-}$ 中：$x + 4\times(-2) = -2 \Rightarrow x = +6$），**氧化态升高 7**：
$$\boxed{\ce{S^- = S^{6+} + 7e^-}}\qquad\text{每 mol FeS2 有 2 个 S：}\ \ce{2S^- = 2S^{6+} + 14e^-}$$
- 这也是**氧化 (oxidation)**——失去电子。

**第四步：每摩尔黄铁矿共产生多少摩尔电子？**
> 每个 Fe 原子产生 **1** 个电子；每个 S 原子产生 **7** 个电子；2 个 S 给出 **14** 个电子。
> **总计 = 15 moles 电子 / mole 黄铁矿。**

**第五步：配平总反应（需要在左边加水、右边加氢离子）**

单位黄铁矿形式：
$$\ce{FeS2 + \tfrac{15}{4}O2 + \tfrac{7}{2}H2O = Fe(OH)3 + 2SO4^{2-} + 4H+}$$
整数形式（乘以 4，更常用）：
$$\boxed{\ce{4FeS2 + 15O2 + 14H2O = 4Fe(OH)3 + 8SO4^{2-} + 16H+}}$$

**双重校验（元素 + 电荷，两者都要查）**：
- Fe：4 = 4 ✔
- S：8 = 8 ✔
- O：左 $15\times2 + 14 = 44$；右 $4\times3 + 8\times4 = 12 + 32 = 44$ ✔
- H：左 $14\times2 = 28$；右 $4\times3 + 16 = 12 + 16 = 28$ ✔
- **电荷**：左 $0$；右 $8\times(-2) + 16\times(+1) = -16 + 16 = 0$ ✔
- **电子账核对**：每个 O$_2$ 得 4 个电子 → 15 O$_2$ 共得 60 个电子；4 mol 黄铁矿放出 $4 \times 15 = 60$ 个电子 ✔ **与第四步完全吻合。**

**第六步：地球化学后果**
- 黄铁矿最终转变为矿物 **褐铁矿 (limonite)**，即含水氧化铁 FeO(OH)·nH$_2$O（野外看到的橙黄色/锈色沉淀）。
- 产物中的 **H$^+$** 使溶液变成**酸性**：$\ce{2H+ + SO4^{2-} = H2SO4}$（**硫酸 sulphuric acid**）。
- **采矿活动使原本深埋的黄铁矿暴露 → 地下水酸化 → 形成酸性矿山水 (acid mine waters)，对当地生态系统有害。** 这就是 **AMD (Acid Mine Drainage)**。典型实例：西班牙 **Rio Tinto**（血红色河流）、密苏里州受露天煤矿排水影响的溪流。

**第七步：细菌加速的无氧路径（important twist）**
黄铁矿的分解会被细菌（如 ***Thiobacillus ferrooxidans***）加速——细菌通过**酶促氧化 (enzymatic oxidation)** 把 Fe$^{2+}$ 氧化成 Fe$^{3+}$，于是黄铁矿的分解可以在**没有氧气的情况下**进行，由 Fe$^{3+}$ 充当氧化剂：

$$\boxed{\ce{FeS2 + 14Fe^{3+} + 8H2O = 15Fe^{2+} + 2SO4^{2-} + 16H+}}$$

**校验**：
- Fe：左 $1 + 14 = 15$；右 15 ✔
- S：2 = 2 ✔
- O：左 8；右 $2\times4 = 8$ ✔
- H：左 16；右 16 ✔
- **电荷**：左 $14\times(+3) = +42$；右 $15\times(+2) + 2\times(-2) + 16\times(+1) = 30 - 4 + 16 = +42$ ✔

> **理解要点（易错）**：在这条路径里，**黄铁矿中的 Fe$^{2+}$ 并没有被氧化**——它以 Fe$^{2+}$ 的形式进入产物（15 个 Fe$^{2+}$ 中包含它）。**只有硫被氧化**（2 个 S × 7 = **14 个电子**），恰好被 **14 个 Fe$^{3+}$ 还原成 Fe$^{2+}$** 所消耗。这与前面有氧路径的 15 个电子不同，是一个很好的电子记账练习。
> 这也构成一个**自催化循环**：Fe$^{3+}$ 溶解黄铁矿 → 产生 Fe$^{2+}$ → 细菌再把 Fe$^{2+}$ 氧化回 Fe$^{3+}$ → 继续溶解黄铁矿。这就是 AMD 一旦启动就极难停止的原因。

#### C(c) 条带状铁建造 (Banded Iron Formations, BIFs)

（参考 McSween p. 164）

**完整故事线（Feedback 中的填空答案已用粗体标出）**：
1. 早期地球的大气中几乎没有**自由氧 (free oxygen)**。
2. **光合作用产生的 O$_2$**，由 **蓝细菌 (cyanobacteria)** 制造，最早出现在**约 27 亿年前 (2.7 Ga)**。
3. 此后的 **4 亿年**里，氧含量上升非常缓慢。
4. **证据之一**：那个时期的**沉积岩中存在晶质铀矿 (uraninite) 和黄铁矿 (pyrite)**。
   - 为什么这是证据？因为**这两种矿物都指示还原条件 (reducing conditions)**——
     - 晶质铀矿含 U$^{4+}$，若有氧就会被氧化成可溶的 U$^{6+}$ 而溶解掉（见 C(a)）；
     - 黄铁矿含 Fe$^{2+}$/S$^-$，若有氧就会被氧化生成 Fe(OH)$_3$ + H$_2$SO$_4$（见 C(b)）。
   - **能在沉积岩中作为碎屑颗粒保存下来，说明当时的地表环境是缺氧的。**
5. 蓝细菌一直在产 O$_2$，但**这些 O$_2$ 被高效地消耗在 BIF 的形成中**。
6. **BIF 的形成机制**：晚前寒武纪，蓝细菌在**表层海水**中释放的氧**氧化了溶解在海水中的 Fe$^{2+}$**，生成 **Fe$^{3+}$ 离子**，后者形成**不溶的氧化物 (Fe$_2$O$_3$)、碳酸盐和硅酸盐**，这些矿物沉降到**海底**形成矿层。
7. **海水中 Fe$^{2+}$ 的来源**：最可能是**海底火山活动 (seafloor volcanism)**。
8. **终结**：随着火山活动速率减慢，海洋中 Fe$^{2+}$ 浓度下降，**大气中的 O$_2$ 水平**开始上升。**BIF 代表了向富氧大气过渡的阶段，这一过渡在约 23 亿年前 (2.3 Ga) 结束。**
9. **此后再未形成过大规模 BIF**（因为海洋中不再有大量溶解的 Fe$^{2+}$——有氧的海洋会立刻把它氧化沉淀掉）。
10. **经济意义**：BIF 是**主要的铁矿资源，占世界商业铁供应量的 90%**。

**画图题的评分要点（sketch）** —— Feedback 要求草图上必须画出：
- 海洋**表层**的**蓝细菌 (cyanobacteria)**
- 陆地上（山脚处）沉积岩中的**晶质铀矿和黄铁矿**
- 蓝细菌产生的**氧气与海水中的 Fe$^{2+}$ 结合形成 Fe$_2$O$_3$**，下沉到海底形成 **BIF 矿层**
- 一座**海底火山 (submarine volcano)**，向海水释放 **Fe$^{2+}$ 离子**
- **氧气从海洋释放进入大气**
- **并在图上标注该图所对应的时间**（约 2.7–2.3 Ga）

**开放性思考题：为什么铁 / 燧石 (chert, 即 SiO$_2$) 的条带是旋回性 (cyclical) 的？**
Feedback 承认这是 **BIF 中尚未被充分理解的一面**，鼓励自己提出假说。合理的假说方向（可作答题素材）：
- **生物旋回**：蓝细菌**季节性/周期性藻华 (blooms)**——藻华期产氧多 → Fe$^{2+}$ 被大量氧化沉淀成铁氧化物条带；藻华衰退期产氧少 → 只有硅质 (chert) 沉积。
- **氧毒性负反馈**：蓝细菌产氧过多 → 局部 O$_2$ 对自身产生毒性或 Fe$^{2+}$（营养元素）被耗尽 → 菌群崩溃 → 停止产氧 → 沉积转为燧石；待 Fe$^{2+}$ 由火山重新补给后，菌群恢复 → 下一层铁条带。
- **供给旋回**：海底火山活动本身是幕式的 (episodic)，Fe$^{2+}$ 的供给周期性变化。
- **海洋上涌 (upwelling) 旋回**：深部富 Fe$^{2+}$ 缺氧水体周期性上涌到有氧的表层。

## 六、易错点 / 重点难点

1. **矿物式中把复合离子拆开数** —— 数 Si、O 时要把 SiO$_4$、CO$_3$、OH 中的原子**全部计入**；但书写时要保持单元完整（Mg(OH)$_2$ 不写 MgO$_2$H$_2$）。
2. **括号外的下标作用于整个括号** —— Ca$_5$(PO$_4$)$_3$F 里 O 共有 $3\times4 = 12$ 个，不是 4 个。
3. **白云母 KAl$_2$Si$_3$AlO$_{10}$(OH)$_2$ 里的 Al 出现两次，共 3 个** —— 数错这个是 A2 题最常见的失分点。
4. **含 (OH) 的矿物：氢和氧都要算进总数** —— 蛇纹石 Mg$_3$Si$_2$O$_5$(OH)$_4$：O = 5 + 4 = **9**，H = **4**。
5. **配平只改系数，绝不改化学式** (never change a formula)。
6. **配平顺序**：先找"每侧只在一个化学式中出现"的元素；**O 永远留到最后**；**不要碰已经配平的元素**。
7. **有多种配平途径时要预判** —— A4 题（滑石/顽火辉石）中，2×Talc 会破坏已平的 H，因此必须选 4×Enstatite。
8. **摩尔的常见误解** —— "1 mole" 不是 "1 个"。**分子量的数值 = 1 mole 的克数**。全班在课上都在这里卡过一次。
9. **原子量不是整数** —— 因为是同位素的加权平均值；"12 g 碳-12"里的整数是因为指定了单一同位素。
10. **配平方程的系数 = 摩尔比** —— 这是从"配平"跨到"定量计算"的桥梁（1 mol 叶蜡石 → 3 mol 石英）。
11. **反应两侧的总分子量应相等**（质量守恒）—— 可以拿来当作检查配平是否正确的独立验算手段（B2 题：160 = 160）。
12. **REDOX 不一定有氧参与** —— Zn + Cu$^{2+}$ 就是反例。**判据是电子转移 / 氧化态变化，不是有没有 O。**
13. **OIL RIG 的方向不要记反** —— Oxidation Is Loss（失电子，氧化态**升高**）；Reduction Is Gain（得电子，氧化态**降低**）。注意"还原 = 数值减小"，与中文直觉一致。
14. **半反应必须同时配平原子数和电荷** —— 两个半反应的电子数必须相等才能相加。
15. **黄铁矿中 S 的氧化态是 $-1$ 不是 $-2$** —— FeS$_2$ 是**二硫化物 (disulphide, S$_2^{2-}$)**。这直接决定了 S 氧化到 SO$_4^{2-}$ 时是失 **7** 个电子而不是 8 个，从而决定了"每摩尔黄铁矿 15 摩尔电子"这个答案。
16. **两条黄铁矿分解路径的电子数不同** —— 有氧路径 15 e$^-$/mol（Fe 和 S 都被氧化）；细菌介导的无氧路径 14 e$^-$/mol（**只有 S 被氧化**，Fe 保持 +2 进入产物）。
17. **铀的溶解度方向不要记反** —— **U$^{6+}$（氧化态高）可溶；U$^{4+}$（还原）不溶**。所以矿床形成于**还原**处。这与很多人"氧化物更难溶"的直觉相反。
18. **BIF 的时间尺度与因果顺序** —— O$_2$ 出现 ~2.7 Ga → BIF 大量沉积（消耗 O$_2$）→ 火山减弱、海洋 Fe$^{2+}$ 耗尽 → 大气 O$_2$ 上升 → BIF 于 ~2.3 Ga 停止。**注意：不是"氧上升导致 BIF"，而是"BIF 消耗氧、直到铁耗尽后氧才上升"。**
19. **沉积岩中的晶质铀矿与黄铁矿是"缺氧大气"的证据** —— 因为二者在有氧条件下都会被氧化破坏。要能解释"为什么"，不只是记住结论。
20. **考试策略** —— 老师明说考的是**理解**不是记忆；practical 的题目是唯一的额外练习来源，务必全部复做一遍。

| garnet / plagioclase | 石榴石 / 斜长石 | Mg$_3$Al$_2$Si$_3$O$_{12}$ / CaAl$_2$Si$_2$O$_8$（钙长石端元） |
| mole (mol) | 摩尔 | SI 物质的量单位，1 mol 含与 12 g $^{12}$C 中原子数相同的实体数 |
| Avogadro constant | 阿伏伽德罗常数 | $6.022\times10^{23}$ mol$^{-1}$，每摩尔的粒子数 |
| molecular mass / molecular weight | 分子量 | 各组成原子的原子量之和；数值上等于 1 mol 物质的克数 |
| atomic mass | 原子量 | 元素各同位素质量的加权平均，因此通常不是整数 |
| valence | 化合价 | 离子所带的电荷，如 Fe$^{2+}$ 为二价 |
| oxidation state | 氧化态 | 描述某元素在化合物中得失电子的状态，等价于化合价的另一种表述 |
| redox reaction | 氧化还原反应 | 涉及元素氧化态改变（即电子转移）的反应，**不一定需要氧参与** |
| oxidation | 氧化 | 失去电子，氧化态升高（OIL: Oxidation Is Loss） |
| reduction | 还原 | 得到电子，氧化态降低（RIG: Reduction Is Gain） |
| OIL RIG | 助记口诀 | Oxidation Is Loss, Reduction Is Gain |
| half reaction | 半反应 | 只写某一元素得失电子的那一半方程，两个半反应的电子数必须相等 |
| ferrous / ferric | 亚铁 / 高铁 | Fe$^{2+}$ / Fe$^{3+}$ |
| hematite / magnetite | 赤铁矿 / 磁铁矿 | Fe$_2$O$_3$（全 Fe$^{3+}$）/ Fe$_3$O$_4$（Fe$^{2+}$Fe$^{3+}_2$，混合价） |
| transition elements | 过渡元素 | 正在填充 d 轨道的元素，电子组态可变因而氧化态可变 |
| d orbital | d 轨道 | 过渡金属外层能量相近的轨道，是可变氧化态的成因 |
| actinide series | 锕系 | 周期表底部一行，含铀 (U) 等氧化态重要的元素 |
| uraninite / pitchblende | 晶质铀矿 / 沥青铀矿 | UO$_2$（含 U$^{4+}$），最主要的铀矿石矿物 |
| uranyl ion | 铀酰离子 | UO$_2^{2+}$，酸性水中稳定的可溶 U$^{6+}$ 形态 |
| coffinite | 铀石 | USiO$_4$（U$^{4+}$ + SiO$_4^{4-}$），另一种铀矿石矿物 |
| pyrite | 黄铁矿 | FeS$_2$，含 Fe$^{2+}$ 和 S$^-$（二硫离子 S$_2^{2-}$） |
| limonite | 褐铁矿 | FeO(OH)·nH$_2$O，黄铁矿氧化的最终产物，橙锈色 |
| acid mine drainage (AMD) | 酸性矿山排水 | 采矿暴露黄铁矿→氧化产 H$_2$SO$_4$ 与 Fe(OH)$_3$，酸化地下水危害生态 |
| *Thiobacillus ferrooxidans* | 氧化亚铁硫杆菌 | 把 Fe$^{2+}$ 酶促氧化为 Fe$^{3+}$，加速黄铁矿在无氧条件下的分解 |
| banded iron formation (BIF) | 条带状铁建造 | 铁氧化物与燧石交替的前寒武纪沉积岩，占世界商业铁供应的 90% |
| cyanobacteria | 蓝细菌 | 光合产氧的原核生物，约 2.7 Ga 开始向海洋释放 O$_2$ |
| chert | 燧石 | SiO$_2$ 质致密沉积岩，BIF 中与铁质条带交替出现 |
| reducing conditions | 还原条件 | 缺乏自由氧的环境；沉积岩中保存的 uraninite 与 pyrite 是其证据 |
| weathering | 风化 | 岩石与水/大气反应而分解，是铀从花岗岩进入水体的第一步 |
| precipitation | 沉淀 | 溶解物质从流体中析出成矿，如 UO$_2$ 与 Fe(OH)$_3$ 在砂岩中沉淀 |
| subduction zone | 俯冲带 | 板块下沉处，高压变质反应与脱碳酸/脱水反应的主要场所 |
| divergent plate boundary | 离散板块边界 | 洋中脊，蛇纹石化发生的构造环境 |
