# Week 10 — 放射性同位素与地质年代学 (Radioactive Isotopes and Geochronology)

## 一、本周主题

本周是 Chemistry of the Earth 11 周主线的**最后一个知识专题**（Week 11 为总复习/答疑工作坊）。主题是：**如何用天然放射性同位素的衰变给岩石"定年"**。

内容分两部分：
- **Part 1 — 放射性衰变 (Radioactive decay)**：什么叫岩石的"年龄"；放射性同位素的五种衰变模式（α、β⁻、β⁺、电子俘获、γ）；从"衰变速率正比于剩余原子数"这一条基本假设出发，**完整推导**出衰变方程 $N/N_0=e^{-\lambda t}$ 和地质年代学基本方程 $D = D_0 + N(e^{\lambda t}-1)$，以及半衰期与衰变常数的关系 $t_{1/2}=\ln 2/\lambda$。
- **Part 2 — 地质年代学 (Geochronology)**：什么样的同位素体系适合做"地质计时器 (geochronometer)"；**等时线 (isochron)** 图的原理、构造与判读；Rb–Sr、Sm–Nd、K–Ar / Ar–Ar、U–Pb / Pb–Pb 四大定年体系各自的适用对象；用 Pb–Pb 法测得的太阳系年龄 4567 Ma。

**在全课中的位置**：本周把前面几周的工具全部串了起来——
- Week 1 的**核合成 (nucleosynthesis)** 与核素图 (chart of the nuclides)：本周直接复用该图，只不过关注的是"哪些格子是彩色的（不稳定）"以及"衰变如何把核素推回稳定谷"。
- 元素周期表与**离子半径/电荷**：Rb 像 K（碱金属，1+）、Sr 像 Ca（碱土金属，2+）——这正是等时线能"张开"的化学前提。
- Week 6/7 的**元素分配 (element partitioning)** 与分配系数 (partition coefficient)：母体与子体必须在不同矿物中被分馏开，等时线才有"斜率"可测。
- Week 8 的**稳定同位素**：那里同位素比值反映的是质量分馏；本周同位素比值反映的是**时间**。两者共用一套质谱测比值的实验逻辑。

## 二、核心概念

### 2.1 "岩石的年龄"到底指什么？

这是本讲第一个、也是最容易被忽略的概念性问题。老师强调："我们不能只说 this is the age of a rock，必须先想清楚这个数字**代表哪一个事件**。"

#### (1) 火成岩 (Igneous rocks) —— 最直接

年龄 = **岩浆从熔融态凝固、矿物结晶的时刻**。

- **喷出岩 (extrusive)**，如玄武岩 (basalt)：夏威夷 2004 年的熔岩流，我们**亲眼看见**了喷发时间。
  - "Rock is 10 years old"（岩石 10 岁）
  - "Age is 10 years"（年龄是 10 年）
  - "Rock formed 10 years ago"（岩石形成于 10 年前）
  - 这三句是**等价陈述**。老师说这看似 trivial，但它是你思考一切年龄问题的"锚 (anchor)"。
- **侵入岩 (intrusive)**，如花岗岩 (granite)（Yosemite 的 El Capitan / Half Dome）：年龄 = 岩体冷却、矿物颗粒生长的时间。

**年代学单位与读法**（考试易错，务必分清）：

| 写法 | 含义 | 读法 |
|---|---|---|
| 100 M.y. / 100 Myr | **一段时长** (duration) | "岩石有 1 亿年那么老" |
| 100 Ma | **一个年龄/时刻** (a point in the past) | "岩石形成于 1 亿年前" |
| 0.1 Ga | 同上，= 100 Ma | "0.1 十亿年前" |

其中 **a = annum（年）**，**M = 10⁶（百万）**，**G = 10⁹（十亿）**。老师原话："this terminology of using the M.y. or Ga, it means that you read it slightly differently."

#### (2) 变质岩 (Metamorphic rocks) —— 必须指明"测的是哪个矿物"

变质岩年龄 = **被测定的那个矿物形成的时间**。

原因：变质岩经历了一条完整的 P–T–流体成分演化路径 (P–T path)。
- 深埋 → 压力温度升高 → 矿物组合 (mineral assemblage) 重结晶（例如石榴石 garnet 在高压下生长）；
- 之后又被抬升回地表 → 热力学重新决定稳定相（可用**相图 phase diagram** 判断哪些矿物在给定 T、P 下最稳定，Week 5 内容）。
- 因此**同一块岩石里不同矿物可能相差数百万年**。必须说"我们测的是这块片岩里 garnet 的年龄"或"biotite 的年龄"。
- 例子：Grand Tetons 的石榴石-云母片岩 (garnet-mica schist)，2,500 Ma = 2.5 Ga。

#### (3) 沉积岩 (Sedimentary rocks) —— "年龄"必须先定义

沉积岩由**来自各种源区、各有各自年龄的碎屑颗粒**组成，再加上后期的**胶结物 (cement) / 基质 (matrix)**（这是最后形成的物质）。

- 测**碎屑颗粒**的年龄 → 得到的是**源区山体（母岩）形成的时间**，不是沉积岩形成的时间。
- 想知道**沉积岩本身何时形成** → 测**胶结/基质**的年龄。

**经典案例：澳大利亚 Jack Hills**
- 组成该沉积岩的碎屑颗粒大多 > 3 Ga（说明 30 亿年前地球上就已在进行沉积作用，这本身极重要）。
- 但其中的单颗**锆石 (zircon)** 晶体测得 **4.4 Ga**——比地球本身只年轻约 1.5 亿年，是**目前找到的地球上最古老的碎片**。
- 锆石颗粒仅约 250 μm（0.25 mm）长。
- 逻辑链：这些锆石大约 44 亿年前在某个火成岩里结晶 → 十亿多年后被风化、搬运、埋进这套沉积岩 → 今天沉积岩出露，我们把锆石挑出来测年。

> **一句话总结**：地质年代学里 **context is everything**。同一块石头可以有很多个"年龄"，关键是问"这个年龄记录的是哪一个事件？"

### 2.2 放射性同位素与核素图 (Chart of the Nuclides)

**放射性同位素 (radioactive isotope / radionuclide)**：会自发衰变的同位素。
**母体 (parent) → 子体 (daughter)**；也说 **radionuclide 衰变为 radiogenic isotope（放射成因同位素）**。

**核素图判读**（注意课上用了**两张坐标轴相反**的图，务必看清轴标！）：
- 第一张：y 轴 = 质子数 Z（原子序数），x 轴 = 中子数 N。向上走 = 沿周期表从 H 走向 U。
- 第二张（Rollinson/教材那张）：**轴翻转了**——y 轴 = N，x 轴 = Z。
- **黑色方块 = 稳定同位素 (stable)**：这个原子永远不变。
- **彩色方块 = 放射性同位素**：会衰变，直到落到黑色的"稳定谷"里。
- 颜色对应衰变模式：蓝 = β⁻，橙 = β⁺，黄 = α。

**与 Week 1 核合成的衔接**：核合成时往原子核上加中子，会沿"增加 N"的方向水平走出稳定谷；走出去的核素不稳定，随后**通过衰变斜着走回稳定谷中心**。

**在核素图上的移动方向**（以 Z 为横轴、N 为纵轴的那张图）：
- α 衰变：**向下 2、向左 2**（N−2, Z−2）
- β⁺ 衰变：**向上 1、向左 1**（N+1, Z−1）
- β⁻ 衰变：**向下 1、向右 1**（N−1, Z+1）

**日常生活里的放射性**：我们脚下的岩石一直在衰变，只是量极小通常无害。老师举例：英国 **Cornwall 的花岗岩**区，铀衰变链会产生 **氡 (radon)** 气体，量虽小但在房屋内会积累——这是完全天然的过程。

### 2.3 五种衰变模式（考点，必须能立即写出 A、Z 的变化）

#### (1) α 衰变 (Alpha decay)

原子核放出一个 **α 粒子**：**2 质子 + 2 中子**，即一个 **⁴He 核**。

$$^{240}_{94}\mathrm{Pu} \;\longrightarrow\; ^{236}_{92}\mathrm{U} \;+\; ^{4}_{2}\alpha$$

- 原子质量数 **A 减少 4**
- 原子序数 **Z 减少 2**

直观理解：原子核"中子超载"不开心，自发地"吐出"一个氦核。

#### (2) β⁻ 衰变 (Beta minus decay)

核内一个**中子**变成**质子**，同时放出一个 β⁻ 粒子（= 电子）和一个反中微子：

$$n \;\longrightarrow\; p^{+} \;+\; \beta^{-} \;+\; \bar{\nu}$$

例：
$$^{14}_{6}\mathrm{C} \;\longrightarrow\; ^{14}_{7}\mathrm{N} \;+\; \beta^{-} \;+\; \bar{\nu}$$

- **A 不变**（核内粒子总数没变，只是一个粒子从中性变成带正电，几乎没有质量损失）
- **Z 增加 1**

（¹⁴C 有 6 质子 + 8 中子；其中一个中子转成质子后变成 7 质子 + 7 中子 = ¹⁴N。）

#### (3) β⁺ 衰变 (Beta plus decay)

核内一个**质子**变成**中子**，放出一个 β⁺ 粒子（**正电子 positron**，像电子但带正电）和一个中微子：

$$p^{+} \;\longrightarrow\; n \;+\; \beta^{+} \;+\; \nu$$

例：
$$^{10}_{6}\mathrm{C} \;\longrightarrow\; ^{10}_{5}\mathrm{B} \;+\; \beta^{+} \;+\; \nu$$

- **A 不变**（核内仍是 10 个核子）
- **Z 减少 1**（6 → 5）

#### (4) 电子俘获 (Electron capture, EC)

原子核**俘获**一个核外电子，核内一个质子 + 该电子 → 中子（电荷中和），并放出中微子和 γ 射线：

$$p^{+} \;+\; e^{-} \;\longrightarrow\; n \;+\; \nu \;+\; \gamma$$

例：
$$^{11}_{6}\mathrm{C} \;+\; e^{-} \;\longrightarrow\; ^{11}_{5}\mathrm{B}$$

- **A 不变**，**Z 减少 1**
- **净效果与 β⁺ 衰变完全相同**（从 6p5n → 5p6n）。这两条路径在同一核素上常常并存（如 ⁴⁰K → ⁴⁰Ar）。

#### (5) γ 衰变 (Gamma decay)

- γ 射线**不是粒子辐射**，而是**极短波长、极高能量的电磁波（光）**。
- γ 衰变只释放能量（核从激发态回到基态），**A 不变、Z 不变、同位素不变**。
  - 老师原话：²⁴⁰Pu 放出一个 γ 射线之后，它**还是** ²⁴⁰Pu。
- **因此 γ 衰变对地质年代学没用**——年代学关心的是"能改变某元素内部同位素比值"的衰变。

**穿透力/屏蔽（好记的口诀，老师用了一个玩笑）**：
- **α 粒子**质量大、穿透力弱 → 一张**纸**就挡住（"有人拿 α 枪打你，举张纸"）
- **β 粒子** → 需要**铝箔 / Al 屏蔽**（"把午餐盒里的锡纸拿出来"）
- **γ 射线** → 需要**厚铅墙**（"躲到铅墙后面去"）

### 2.4 放射性衰变的基本定律

**基本假设（整个年代学的地基）**：
> The rate of decay of a radioactive nuclide **at any instant** is proportional to the number of atoms of that nuclide **remaining at that instant**.
> （任一瞬间的衰变速率，正比于该瞬间剩余的该核素原子数。）

直观理解（老师的比喻）：一大罐铀 → 每秒测到很多次衰变；一小罐铀 → 每秒测到很少次衰变。等这罐铀衰变掉一大半后再来测，每秒的衰变数就变少了。所以是**指数衰减 (exponential decay)**。

$$-\frac{dN}{dt} \;\propto\; N \qquad\Longrightarrow\qquad -\frac{dN}{dt} \;=\; \lambda N$$

符号含义：
- $N$：时刻 $t$ 时**剩余的母体原子数**
- $dN/dt$：**衰变曲线的斜率**（N 对 t 的变化率）
- **负号**：因为 N 随时间**减少**，斜率为负
- $\lambda$：**衰变常数 (decay constant)**，比例常数，单位 yr⁻¹（每年每个原子衰变的概率）

**图形理解**：N–t 曲线是指数下降曲线。起点处斜率很陡（N 大 → 衰变快），后期斜率很平（N 小 → 衰变慢）。斜率始终正比于当时的 N。

### 2.5 好的地质计时器需要什么条件？

#### 条件一：合适的**半衰期 (half-life)**

- **经验法则**：一个 geochronometer 在**约 10 个半衰期**的时间尺度内有效；老师课上的口头版本是"半衰期要和你想测的过程在**一个数量级（factor of ~10）**之内"。
- **半衰期太长** → 在你关心的时间里只衰变了极少一点，要测出 D 的微小变化需要**极高精度**，非常困难。
- **半衰期太短** → 在地质时间尺度上母体**已经衰变殆尽**，什么也测不到。
- 例：测很近的事件（几千到几万年）用 **¹⁴C**；测太阳系起源（~4.57 Ga）必须用 **U–Pb** 这类超长寿命体系。

#### 条件二：**化学性质 (Chemistry)**

- **母体与子体的化学性质必须不同**。
- 因而它们在不同矿物间被**分馏 (fractionated)**——即在不同矿物中有**不同的分配系数 (partition coefficients)**（衔接 Week 6/7）。
  - 这一点是**等时线能形成的根本原因**：如果所有矿物的母/子比值都一样，数据点就挤成一点，画不出直线。
- **子体同位素的天然丰度要低**（即 $D_0$ 要小）：这样放射成因增加的那部分才容易在"本底"之上被测出来。

### 2.6 等时线 (Isochron) 的原理

**定义**：**Isochron = "line of equal time"（等时线）**——等时线图上的一条直线，线上所有点（不同矿物 / 不同岩石样品）**具有相同的年龄**。当一组数据落在一条直线上，我们就得到一条等时线，其斜率给出年龄。

#### 为什么会形成一条直线？（Rb–Sr 体系的完整故事，Rollinson 的经典四步图）

**化学前提**：
- **Rb 是碱金属 (alkali element)，1+ 离子 → 行为像 K**（离子半径也接近）。
- **Sr 是碱土元素 (alkaline earth element)，2+ 离子 → 行为像 Ca**。
- 所以：
  - **富 K 的矿物**（biotite 黑云母 > K-feldspar 钾长石）→ 富 Rb、贫 Sr → **⁸⁷Rb/⁸⁶Sr 高**
  - **富 Ca 的矿物**（plagioclase 斜长石）→ 富 Sr、贫 Rb → **⁸⁷Rb/⁸⁶Sr 低**

**第 1 步（t₀，岩石刚结晶时）**：
- 三种矿物（biotite, K-feldspar, plagioclase）的 ⁸⁷Rb/⁸⁶Sr 分别为 a、b、c（横坐标不同）。
- 但它们**都从同一份岩浆结晶**，而同位素分馏在 Sr 同位素之间可忽略 → **所有矿物的初始 ⁸⁷Sr/⁸⁶Sr 完全相同**。
- 结果：t₀ 时所有点落在一条**水平线**上，纵坐标 = $(^{87}\mathrm{Sr}/^{86}\mathrm{Sr})_0$。

**第 2 步（时间 t₁）**：
- 每衰变掉 1 个 ⁸⁷Rb 原子，就**多出 1 个 ⁸⁷Sr 原子**。由于横纵坐标共用同一个分母 ⁸⁶Sr（且 ⁸⁶Sr 不变），**每个数据点沿一条斜率为 −1 的直线移动**（x 减多少，y 就增多少）。
- 原本 ⁸⁷Rb/⁸⁶Sr 高的矿物（biotite）移动得多；低的（plagioclase）移动得少。
- 点 a、b、c → a′、b′、c′，**仍然共线**，但直线**已经倾斜**了。

**第 3 步（时间 t₂ > t₁）**：
- 继续演化到 a″、b″、c″，**斜率更大**。

**第 4 步（总结）**：
- 直线**绕着 y 轴上的初始比值那一点"转动 (pivot)"**——就像一根绕固定点旋转的杠杆。
- **斜率 = $(e^{\lambda t}-1)$，随时间单调增大**；
- **y 轴截距 = 初始比值 $(^{87}\mathrm{Sr}/^{86}\mathrm{Sr})_0$，永远不变**。

> 老师的原话总结："think of it as the isochron has **pivoted** from where it started, flat here … and over time, the line has **tilted**."

#### 等时线图的通用轴定义（Rb–Sr 与 Sm–Nd 都一样）

- **y 轴 = 放射成因子体同位素 / 同一元素的稳定参考同位素**
- **x 轴 = 母体同位素 / 同一（子体元素的）稳定参考同位素**

| 体系 | y 轴 | x 轴 |
|---|---|---|
| Rb–Sr | ⁸⁷Sr/⁸⁶Sr | ⁸⁷Rb/⁸⁶Sr |
| Sm–Nd | ¹⁴³Nd/¹⁴⁴Nd | ¹⁴⁷Sm/¹⁴⁴Nd |

### 2.7 四大定年体系

#### (1) Rb–Sr 体系

$$^{87}\mathrm{Rb} \;\xrightarrow{\;\beta^{-}\;}\; ^{87}\mathrm{Sr}$$

- $\lambda = 1.42\times10^{-11}\ \mathrm{yr^{-1}}$，$t_{1/2} = 48.8\times10^{9}\ \mathrm{yr} = 4.88\times10^{10}$ yr
- 参考稳定同位素：**⁸⁶Sr**
- **适用对象**：**中性到长英质 (intermediate & felsic) 火成岩**——安山岩 (andesite)、流纹岩 (rhyolite)、花岗岩 (granite)，即**富长石 (feldspar-rich)** 的岩石。
- 原因：这类岩石富 K/Rb 的矿物（钾长石、黑云母）与富 Ca/Sr 的矿物（斜长石）共存，Rb/Sr 分馏大 → 等时线能张得开。
- 例：Oregon 的 South Sister 火山，安山岩。

#### (2) Sm–Nd 体系

$$^{147}\mathrm{Sm} \;\xrightarrow{\;\alpha\;}\; ^{143}\mathrm{Nd}$$

- 参考稳定同位素：**¹⁴⁴Nd**
- **适用对象**：**镁铁质与超镁铁质 (mafic & ultramafic) 火成岩**——玄武岩 (basalt)、辉长岩 (gabbro)，即**富辉石 (pyroxene-rich)** 的岩石。
- Sm 与 Nd 都是**稀土元素 (REE)**（衔接 Week 6），但离子半径略有差异，在辉石/斜长石/石榴石之间分配系数不同，因而仍能被分馏。
- 例：Montana 的 Stillwater 层状侵入体，辉长岩。
- **实用价值**：Rb 和 Sr 都易受流体活动/变质影响而"重置"，而 Sm、Nd 相对不活动 (immobile)，Sm–Nd 常用于测非常古老、经历过变质的镁铁质岩。

#### (3) K–Ar 与 Ar–Ar 体系

**⁴⁰K 有两条衰变分支 (branched decay)**：
$$^{40}\mathrm{K} \;\xrightarrow{\;\beta^{-}\;}\; ^{40}\mathrm{Ca} \qquad\text{和}\qquad ^{40}\mathrm{K} \;\xrightarrow{\;\beta^{+},\ \mathrm{e.c.}\;}\; ^{40}\mathrm{Ar}$$

- 用 **⁴⁰Ar** 分支来定年，而不是 ⁴⁰Ca。原因：**Ar 是惰性气体 (noble gas)**，岩浆结晶时几乎不会进到矿物晶格里去，所以矿物中的 Ar **几乎全部是放射成因的** → $D_0 \approx 0$，这是理想情况（回顾 2.5 的"条件二：D₀ 要小"）。
  - 而 ⁴⁰Ca 分支没用，因为 Ca 在岩石中太丰富，放射成因的那点 ⁴⁰Ca 淹没在本底里。
- **适用对象**：含 K 的矿物，如 **K-feldspar（钾长石）**和 **biotite（黑云母）**。

**Ar–Ar 变体（³⁹Ar–⁴⁰Ar）**：
- 问题：分别测 K（固体，用一种方法）和 Ar（气体，用另一种方法）很麻烦且引入误差。
- 巧妙方案：把样品放进**核反应堆中辐照 (irradiate)**，把 ³⁹K 转变成 ³⁹Ar；然后**同时测 ³⁹Ar 和 ⁴⁰Ar 两个 Ar 同位素**，用 ³⁹Ar 作为 ³⁹K（进而 ⁴⁰K）的**代理 (proxy)**。
- 优点：同一台质谱、同一次分析测两个同位素比值，精度大幅提高。

#### (4) U–Pb 与 Pb–Pb 体系

$$^{235}\mathrm{U} \;\longrightarrow\; ^{207}\mathrm{Pb} \qquad\text{和}\qquad ^{238}\mathrm{U} \;\longrightarrow\; ^{206}\mathrm{Pb}$$

- 这**不是单步衰变**，而是**长长的衰变链 (decay chain)**：²³⁸U → ²⁰⁶Pb 要经过一连串 α 和 β 衰变、途经 Th、Ra、Rn、Po 等中间核素（Cornwall 的氡就来自这条链）。做年代学时只看链首（U）和链尾（Pb），因为中间核素半衰期都极短，链处于**长期平衡 (secular equilibrium)**。
- **两个方法**：
  - **U–Pb**：分别用两条链各自定年。
  - **Pb–Pb**：同时利用两条链，因为它们**衰变速率不同**（²³⁵U 半衰期 ~0.70 Ga，²³⁸U ~4.47 Ga），所以 ²⁰⁷Pb/²⁰⁶Pb 比值本身就是时间的函数——**不需要测 U，只测 Pb 同位素比值就能定年**，实验上非常有力。
- **锆石 (zircon, ZrSiO₄)**：U⁴⁺ 能替代 Zr⁴⁺ 进入晶格，而 Pb²⁺ 因半径/电荷不匹配被强烈排斥 → **锆石结晶时几乎不含初始 Pb（D₀ ≈ 0）**，且锆石极其抗风化和抗变质。这使 U–Pb 锆石定年成为**最强大、最精确**的定年方法。这也是 Jack Hills 4.4 Ga 锆石年龄的来源。

#### 太阳系年龄：Pb–Pb 年代学

- 材料：**碳质球粒陨石 (carbonaceous chondrite)** 中的 **CAI**（Calcium–Aluminium-rich Inclusion，富钙铝包体）——太阳星云中最早凝聚的高温矿物集合体。
- **Connelly et al. (2012), Science, 338, 651–655**：Efremovka 碳质球粒陨石中的 CAI（编号 22E）年龄 = **4567.35 ± 0.28 Myr**。
- 实验流程标注：**W = wash step（淋洗步骤）**，**L = partial dissolution step（部分溶解步骤）**，**R = residue（残余）**——逐步溶解可以剔除受扰动的表层，只保留最"干净"的残余部分。
- 结论：**多个 CAI 给出一致的 ~4567 Ma 年龄，这是人类测定过的最古老物体，我们把它当作太阳系的年龄。**

## 三、公式与图表

### 3.1 衰变方程的完整推导（必须能自己写出全过程）

**第 1 步：从基本定律出发**

$$-\frac{dN}{dt} = \lambda N$$

**第 2 步：分离变量（代数重排）**

$$-\frac{dN}{N} = \lambda\,dt$$

**第 3 步：两边积分**

$$-\int \frac{dN}{N} = \int \lambda\,dt$$
$$\boxed{-\ln N = \lambda t + C} \tag{Equation 1}$$

其中 $C$ 是**积分常数 (constant of integration)**。（老师提醒：这里的 log 一律指**自然对数 ln**。）

**第 4 步：用初始条件定 C**

在 $t = 0$（衰变开始的时刻），$N = N_0$。代入 Equation 1：

$$-\ln N_0 = \lambda \cdot 0 + C \quad\Longrightarrow\quad C = -\ln N_0$$

（幻灯片上写作 $\ln N_0 = C$，符号写法稍有出入，实质是 $C=-\ln N_0$；代回后结果一致。）

**第 5 步：代回并整理**

$$-\ln N = \lambda t - \ln N_0$$
$$\ln N_0 - \ln N = \lambda t$$
$$-\ln\!\left(\frac{N}{N_0}\right) = \lambda t$$

**第 6 步：取指数**

$$\boxed{\dfrac{N}{N_0} = e^{-\lambda t}} \qquad\text{等价地}\qquad N = N_0\,e^{-\lambda t}$$

**符号含义**：
- $N$：时刻 $t$ 剩余的**母体 (parent)** 原子数
- $N_0$：$t=0$ 时的母体原子数
- $\lambda$：衰变常数 (decay constant)，单位 yr⁻¹
- $t$：经过的时间

这条方程把"任意时刻的母体原子数"与"初始原子数"和"衰变常数"联系了起来。

---

### 3.2 子体方程 $D^{*} = N(e^{\lambda t}-1)$ 的推导

用 $D^{*}$ 表示**放射成因子体原子数**（星号 * 专门表示"由放射性衰变产生的"）。

**第 1 步：物质守恒**

每消失一个母体原子，就生成一个子体原子。所以

$$D^{*} = N_0 - N$$

（幻灯片上的小盒子图解：起始 16 个蓝色母体，衰变了 4 个 → 现在 12 蓝 + 4 黄；确实 $4 = 16 - 12$。）

**第 2 步：把 $N_0$ 用 $N$ 表示**

由 $N/N_0 = e^{-\lambda t}$：

$$N_0 = \frac{N}{e^{-\lambda t}} = N\,e^{\lambda t}$$

**第 3 步：代入**

$$D^{*} = N e^{\lambda t} - N$$
$$\boxed{D^{*} = N\left(e^{\lambda t} - 1\right)}$$

**关键点**：这条式子用的是**今天测到的母体数 $N$**（可测），而不是无法直接知道的 $N_0$。

---

### 3.3 地质年代学基本方程

**问题**：岩石形成时可能**本来就含有一些子体同位素**，记作 $D_0$（"initial daughter"）。如果不扣掉这部分，测得的子体太多，算出的年龄就会**偏老**。

幻灯片的盒子例子：起始 $N_0 = 14$ 个母体 + $D_0 = 2$ 个已有的子体（橙色）。经过时间 t，衰变了 4 个 → 现在 $N = 10$，$D^{*} = 4$，测到的总子体 $D = 2 + 4 = 6$。若误以为这 6 个全是放射成因的，年龄就算错了。

**第 1 步：总子体 = 初始子体 + 放射成因子体**

$$D = D_0 + D^{*}$$

**第 2 步：代入 $D^{*}=N(e^{\lambda t}-1)$**

$$\boxed{\,D \;=\; D_0 \;+\; N\left(e^{\lambda t} - 1\right)\,}$$

**符号含义**：
- $D$：时刻 $t$（即"今天"）的**总子体原子数** —— **可测**
- $D_0$：$t=0$ 时已存在的子体原子数 —— **未知，但可通过等时线截距求出**
- $N$：时刻 $t$ 的母体原子数 —— **可测**
- $\lambda$：衰变常数 —— **实验室已标定的常数**
- $t$：岩石年龄 —— **待求**

> **这条方程就是全部地质年代学的基础方程 (the basis for geochronology)。**

---

### 3.4 半衰期与衰变常数的关系（完整推导）

**定义**：**半衰期 $t_{1/2}$** = 一半母体原子衰变掉所需的时间。

直观图解（老师的盒子）：假设 $t_{1/2}$ = 10 亿年，起始 16 个蓝球
- 10 亿年后：8 蓝 + 8 黄
- 20 亿年后：4 蓝 + 12 黄
- 30 亿年后：2 蓝 + 14 黄

注意：每一个半衰期都是把**当时剩下的**母体再减半，而不是每次减掉初始量的一半。

**推导**：

当 $t = t_{1/2}$ 时，$N = N_0/2$。代入 $N/N_0 = e^{-\lambda t}$：

$$\frac{\tfrac{1}{2}N_0}{N_0} = e^{-\lambda t_{1/2}} \quad\Longrightarrow\quad \tfrac{1}{2} = e^{-\lambda t_{1/2}}$$

两边取自然对数：

$$\ln \tfrac{1}{2} = -\lambda t_{1/2}$$
$$-\ln 2 = -\lambda t_{1/2}$$
$$\ln 2 = \lambda t_{1/2}$$

$$\boxed{\,t_{1/2} = \frac{\ln 2}{\lambda} = \frac{0.693}{\lambda}\,} \qquad\text{等价地}\qquad \lambda = \frac{0.693}{t_{1/2}}$$

这是一个**固定关系**：给定 λ 立刻能算出 t½，反之亦然。

---

### 3.5 从基础方程到等时线方程（Rb–Sr 为例）

**第 1 步：把通用方程写成 Rb–Sr 的形式**

$$^{87}\mathrm{Sr} \;=\; ^{87}\mathrm{Sr}_0 \;+\; ^{87}\mathrm{Rb}\left(e^{\lambda t} - 1\right)$$

- $^{87}\mathrm{Sr}$：今天岩石中 ⁸⁷Sr 的总原子数
- $^{87}\mathrm{Sr}_0$：岩石刚形成时就存在的 ⁸⁷Sr 原子数
- $^{87}\mathrm{Rb}$：今天的 ⁸⁷Rb 原子数
- $\lambda$：⁸⁷Rb 的衰变常数 = $1.42\times10^{-11}$ yr⁻¹
- 前提：岩石在这 $t$ 年内是一个**封闭体系 (closed system)**（没有 Rb 或 Sr 的加入/丢失）

**第 2 步：为什么要"除以 ⁸⁶Sr"——这是地质年代学最巧妙的一步**

- 实验困难：用质谱仪**精确测量绝对浓度（原子的绝对数量）非常难**；但测**两个同位素的比值**却相对容易且极精确。
- 解决办法：选一个**不参与该衰变体系的稳定同位素**作为"参比同位素 (ratio-ing isotope)"。Rb–Sr 体系用 **⁸⁶Sr**。
- **为什么 ⁸⁶Sr 合适**：它是稳定的，**且不由任何放射性衰变产生**。所以岩石形成时的 ⁸⁶Sr 数量 = 今天的 ⁸⁶Sr 数量，**它在整个方程里是一个不随时间变化的常数**，可以放心地整体相除。

**第 3 步：整个方程除以 ⁸⁶Sr**

$$\left(\frac{^{87}\mathrm{Sr}}{^{86}\mathrm{Sr}}\right)_{m} \;=\; \left(\frac{^{87}\mathrm{Sr}}{^{86}\mathrm{Sr}}\right)_{0} \;+\; \left(\frac{^{87}\mathrm{Rb}}{^{86}\mathrm{Sr}}\right)_{m}\left(e^{\lambda t} - 1\right)$$

- 下标 **m** = measured，即**可以在质谱仪里测到的量**
- 下标 **0** = initial，即岩石形成时的初始比值

**第 4 步：认出这是直线方程 $y = c + mx$**

$$\underbrace{\left(\frac{^{87}\mathrm{Sr}}{^{86}\mathrm{Sr}}\right)_{m}}_{y\ (\text{测})} \;=\; \underbrace{\left(\frac{^{87}\mathrm{Sr}}{^{86}\mathrm{Sr}}\right)_{0}}_{c\ (\text{y 轴截距})} \;+\; \underbrace{\left(\frac{^{87}\mathrm{Rb}}{^{86}\mathrm{Sr}}\right)_{m}}_{x\ (\text{测})} \cdot \underbrace{\left(e^{\lambda t} - 1\right)}_{m\ (\text{斜率})}$$

| 直线要素 | 对应的物理量 | 怎么得到 |
|---|---|---|
| $y$ | ⁸⁷Sr/⁸⁶Sr（子体/稳定同位素） | 质谱仪**测量** |
| $x$ | ⁸⁷Rb/⁸⁶Sr（母体/稳定同位素） | 质谱仪**测量** |
| $c$（截距） | $(^{87}\mathrm{Sr}/^{86}\mathrm{Sr})_0$ 初始比值 | 从图上**读出 y 轴截距** |
| $m$（斜率） | $e^{\lambda t}-1$ | 从图上**读出斜率** → 解出 $t$ |

> **地质年代学的优雅之处**（老师原话）：两个量我们能测（x, y），另外两个量我们能从图上读出来（截距、斜率）——四个未知量全部解决。

**第 5 步：从斜率解出年龄**

$$m = e^{\lambda t} - 1$$
$$m + 1 = e^{\lambda t}$$
$$\ln(m+1) = \lambda t$$
$$\boxed{\,t = \frac{\ln(m+1)}{\lambda}\,}$$

---

### 3.6 等时线图的判读要点（考试必考）

```
   y = 子体 / 稳定参考同位素            例：87Sr/86Sr
   ↑
   │                                   ● ilmenite
   │                        ●
   │            ●      pyroxene
   │      ● plagioclase
   │  ← 全岩 (whole rock) 也落在这条线上
 c ├────────────────────────────────→  x = 母体 / 稳定参考同位素
   │  ↑                                 例：87Rb/86Sr
   │  截距 c = (87Sr/86Sr)₀ 初始比值
   │  斜率 m = e^{λt} − 1，随 t 增大
```

**判读步骤**：
1. **确认轴**：y 轴一定是"**放射成因子体 / 同元素稳定同位素**"；x 轴一定是"**母体 / 同一个（子体元素的）稳定同位素**"。两轴**分母相同**。
2. **数据是否共线？** 只有落在一条直线上才是有效等时线；若散乱，说明体系不封闭（有开放体系扰动/后期改造）。
3. **读截距** → 初始同位素比值 $(D/D_{\text{stable}})_0$。这本身有地球化学意义（可以指示源区性质）。
4. **读斜率** → 代入 $t = \ln(m+1)/\lambda$ → 年龄。
5. **线越陡 = 年龄越老**。t₀ 时线是水平的（斜率 0，年龄 0）；随时间推移，线绕截距点**逆时针旋转/pivot**，斜率单调增加。
6. **数据点在图上的移动方向**：单个 ⁸⁷Rb 原子衰变成 ⁸⁷Sr，会使该点沿**斜率 = −1** 的路径左上移动（x 减 Δ，y 增 Δ）。这就是"pivot"的微观机制。

7. **等时线形成机制的口头版本**（比幻灯片更清楚）：

   - 结果：**直线绕初始比值这一点 pivot（转动）**；例子中 t₁ ≈ 5 亿年，t₂ 更晚 → 斜率更陡。

8. **辐射防护的记忆点（老师的玩笑）**：α 枪→举纸；β 枪→拿午餐盒里的铝箔；γ 枪→躲到厚铅墙后面。

9. **Cornwall 的氡 (radon)**：花岗岩中铀的天然衰变链产生氡气，在房屋里积累。说明放射性衰变**时刻都在我们周围发生**，只是量很小。

10. **γ 衰变为什么对年代学没用**：因为年代学关心的是"能改变某个元素内部同位素比值"的过程；γ 衰变前后同位素完全不变（²⁴⁰Pu 放 γ 之后还是 ²⁴⁰Pu）。

### 用到的公式

$$^{87}\mathrm{Sr} = {}^{87}\mathrm{Sr}_0 + {}^{87}\mathrm{Rb}\,(e^{\lambda t}-1)$$

⁸⁷Rb 的 $\lambda = 1.42\times10^{-11}$ yr⁻¹，$t_{1/2} = 4.88\times10^{10}$ yr。

### Part A：放射性衰变与半衰期（数值计算 + 作图）

**情境**：一块花岗岩，初始含 ⁸⁷Rb 原子 $N_0 = 1.2\times10^{20}$，初始含 ⁸⁷Sr 原子 $D_0 = 0.3\times10^{20} = 3.0\times10^{19}$。追踪 6 个半衰期。

#### A1. 由半衰期算衰变常数

已知 $t_{1/2} = 48.8\times10^{9}$ yr。

$$\lambda = \frac{0.693}{t_{1/2}} = \frac{0.693}{48.8\times10^{9}\ \mathrm{yr}} = \mathbf{1.4201\times10^{-11}\ yr^{-1}}$$

#### A2. 一个半衰期后剩下多少 ⁸⁷Rb？

用 $N = N_0\,e^{-\lambda t}$，取 $t = 48.8\times10^{9}$ yr：

$$N = (1.2\times10^{20}) \times \exp\!\left[-(1.4201\times10^{-11})\times(48.8\times10^{9})\right]$$

先算指数：$-(1.4201\times10^{-11})(4.88\times10^{10}) = -0.6930$

$$N = 1.2\times10^{20} \times e^{-0.6930} = 1.2\times10^{20}\times 0.5000 = \mathbf{6.00\times10^{19}}$$

**Feedback 的评注**：当然，一个半衰期后 N 就应该是 $N_0/2$。但"看到方程真的给出正确答案，是一件令人满意的事 (it is satisfying to see that the equation works)"。这一步的**教学目的是验证公式的自洽性**。

#### A3. 一个半衰期后有多少 ⁸⁷Sr？

$$D^{*} = N_0 - N = 1.2\times10^{20} - 6.00\times10^{19} = 6.00\times10^{19}$$

（合理：一个半衰期后，一半的母体变成了子体，所以 $D^{*} = N$，两者数值相同。）

$$D = D_0 + D^{*} = (0.3\times10^{20}) + (6.00\times10^{19}) = 3.00\times10^{19} + 6.00\times10^{19} = \mathbf{9.00\times10^{19}}$$

### Part B：从等时线求岩石年龄（核心例题，必考类型）

**数据来源**：McSween worked example 14.3 (p. 293)；原始数据来自 **Nyquist et al. (1979)** 对 **Apollo 12 月球玄武岩样品 12014** 的 Rb–Sr 测定。

**Table 3：Apollo 玄武岩同位素数据**

| 矿物/样品 | Rb (ppm) | Sr (ppm) | ⁸⁷Rb/⁸⁶Sr (x) | ⁸⁷Sr/⁸⁶Sr (y) |
|---|---|---|---|---|
| Whole rock 全岩 | 0.926 | 90.4 | 0.02960 | 0.70096 |
| Plagioclase 斜长石 | 0.599 | 323 | 0.00537 | 0.69989 |
| Pyroxene 辉石 | 0.386 | 22.7 | 0.04920 | 0.70200 |
| Ilmenite 钛铁矿 | 3.76 | 96.5 | 0.11270 | 0.70490 |

**先做一次"化学合理性检查"**（这一步能帮你判断数据是否合理，也是理解等时线的关键）：
- **Plagioclase** 是富 Ca 矿物 → Sr 高达 323 ppm、Rb 只有 0.599 ppm → **Rb/Sr 最低（x 最小 = 0.00537）**，因此也是**最接近初始比值**的点（y 最小 = 0.69989）。✓
- **Ilmenite** Sr 低、Rb 相对高（3.76 ppm）→ **Rb/Sr 最高（x = 0.11270）** → 积累的放射成因 ⁸⁷Sr 最多 → **y 最大 = 0.70490**。✓
- **Whole rock（全岩）**是所有矿物的加权平均，落在中间。✓

#### B1. 画等时线

- **x 轴 = ⁸⁷Rb/⁸⁶Sr**（母体/稳定同位素）
- **y 轴 = ⁸⁷Sr/⁸⁶Sr**（子体/稳定同位素）
- 把 4 个点画上去。注意 **y 轴范围要很窄**（0.6995 – 0.7050），否则看不出斜率。

#### B2. 求截距

用 Excel 做**线性回归 (linear regression)** 拟合最佳直线。

$$\text{intercept} \approx \mathbf{0.6996}$$

**截距代表等时线方程的哪一项？**
> **$(^{87}\mathrm{Sr}/^{86}\mathrm{Sr})_0$，即岩石形成时 ⁸⁷Sr 对 ⁸⁶Sr 的初始比值。**

#### B3. 手工求斜率

选**两个点**算斜率 $m = (y_2-y_1)/(x_2-x_1)$。

**该选哪两个点？为什么？**
> 选 **ilmenite 和 plagioclase**，因为**它们位于直线的两端（x 跨度最大）**。分母 $(x_2-x_1)$ 越大，读数误差被放大的程度越小 → 斜率最稳健。

$$m = \frac{0.70490 - 0.69989}{0.11270 - 0.00537} = \frac{0.00501}{0.10733} = \mathbf{0.04668}$$

（Feedback 注：这与线性回归给出的斜率**接近但不完全相同**。）

#### B4. 由斜率解年龄——完整代数步骤

$$m = e^{\lambda t} - 1$$
$$m + 1 = e^{\lambda t}$$
$$\ln(m+1) = \lambda t$$
$$t = \frac{\ln(m+1)}{\lambda}$$

代入数值：

$$t = \frac{\ln(0.04668 + 1)}{1.4201\times10^{-11}\ \mathrm{yr^{-1}}} = \frac{\ln(1.04668)}{1.4201\times10^{-11}}$$

$$\ln(1.04668) = 0.045619$$

$$t = \frac{0.045619}{1.4201\times10^{-11}} = 3.212\times10^{9}\ \mathrm{yr}$$

$$\boxed{t = 3.21\times10^{9}\ \text{years} = 3.21\ \text{billion years} = 3.21\ \mathrm{Ga}}$$

> **千万不要忘记写单位！**（Feedback 特别提醒 "Don't forget to include units."）

#### B5. 不同点对给出的年龄对比与误差讨论

- 用**线性回归**的斜率算出来的年龄是 **3.23 Ga**。
- 用**手工两点法**（ilmenite + plagioclase）得 **3.21 Ga**。
- Feedback 评论：手工算斜率"bound to be the **least accurate** method"（必然是最不准的方法），**但它离数学上的最优答案并不远**——差 0.02 Ga，约 0.6%。

**（补充练习：换不同点对会得到什么）**

| 所选两点 | 斜率 m | 年龄 t |
|---|---|---|
| Ilmenite + Plagioclase（两端） | 0.04668 | 3.21 Ga |
| Ilmenite + y 轴截距 (0, 0.6996) | 0.04703 | 3.24 Ga |
| Pyroxene + Plagioclase | 0.04814 | 3.31 Ga |
| Whole rock + Plagioclase | 0.04416 | 3.04 Ga |
| **线性回归（全部 4 点）** | ≈ 0.04694 | **3.23 Ga** |

**结论**：**x 跨度越小的点对，误差越大**（Whole rock + Plagioclase 的 Δx 只有 0.024，结果偏离 0.2 Ga）。这就是为什么要选两端的点，以及为什么线性回归（利用全部信息）最可靠。

#### B6. 误差从哪里来？（Feedback 的完整答案，考试简答题模板）

Nyquist et al. 报告的年龄不确定度为 **±0.11 Ga**（基于线性回归拟合）。误差来源包括：

1. **点对直线的偏离 (scatter)**：单个点稍微偏离等时线就会影响拟合。**点越多，拟合的确定性越好** → 所以要尽可能分析多个矿物相。
2. **分析不确定度 (analytical uncertainty)**：想想需要多精确——**⁸⁷Sr/⁸⁶Sr 要看到小数点后第四位（至少）**（0.69989 vs 0.70490，差别只在第 3–5 位）。这需要**非常好的质谱仪**。
3. **样品污染 (contamination)**：
   - 被分析的矿物颗粒**不能被次生矿物污染**（次生矿物年龄更年轻，会把年龄拉小）；
   - **溶样用的酸里哪怕含极微量 Rb 或 Sr**，都会污染分析结果。
4. > **"Radiometric dating requires very precise analytical skill!"**（放射性定年需要极高的分析技巧。）

## 六、易错点 / 重点难点

1. **Ma 与 M.y. 混用**。"Rock is 100 **M.y.** old"（时长）vs "Age is 100 **Ma**"（时刻/年龄）。答题时两种都可以但要用对语境，不要写成 "the rock is 100 Ma old" 与 "the age is 100 M.y." 的错配。a = annum，M = 10⁶，G = 10⁹。

2. **搞不清"哪种岩石的年龄意味着什么"**：
   - 火成岩 = **结晶/凝固**时刻（唯一且明确）
   - 变质岩 = **被测那个矿物形成**的时刻（同一块岩石可有多个年龄）
   - 沉积岩 = 测碎屑颗粒 → 得到**源区年龄**；测胶结物/基质 → 得到**沉积成岩年龄**
   - Jack Hills：岩石 ~3 Ga，其中锆石 4.4 Ga——**这不矛盾**，是两个不同事件。

3. **α 衰变的 A、Z 变化记反**：**A 减 4，Z 减 2**（丢掉 2p + 2n）。老师自己都在课上口误了一次，务必记牢。

4. **β⁻ 与 β⁺ 方向搞反**：
   - **β⁻**：中子→质子，放出电子，**Z +1**（"往前进一格"）
   - **β⁺**：质子→中子，放出正电子，**Z −1**（"往回退一格"）
   - **电子俘获**与 β⁺ **净效果相同**（A 不变、Z −1）。
   - 所有 β 类衰变和电子俘获都**不改变 A**。

5. **以为 γ 衰变能用来定年**：不能。γ 衰变**不改变 A、不改变 Z、不改变同位素**，对同位素比值毫无影响。

6. **半衰期的理解**：不是"每个半衰期减掉初始量的一半"，而是"**每个半衰期把当时剩下的母体再减半**"。5 个半衰期后剩 1/32，不是 0。

7. **忘了 $D_0$，直接用 $D = N(e^{\lambda t}-1)$**：这会让年龄**系统性偏老**。除非能论证 $D_0 \approx 0$（如 K–Ar 中的 Ar、锆石中的 Pb），否则必须用等时线求 $D_0$。

8. **等时线两轴搞反**：**y 轴永远是子体/参考同位素，x 轴永远是母体/参考同位素，两轴分母相同**。画成 x 轴放子体就全错了。

9. **不理解"为什么要除以 ⁸⁶Sr"**：因为(a) 测比值比测绝对量精确得多；(b) ⁸⁶Sr 稳定且不由衰变产生，形成时的量 = 今天的量，作分母是恒定的。

10. **斜率就是年龄？错。** 斜率 $m = e^{\lambda t}-1$，必须做 $t=\ln(m+1)/\lambda$ 才得到年龄。别忘了那个 "+1"。

11. **代入 $t$ 时忘乘半衰期数**（Practical A4 常见错）：算第 n 个半衰期时 $t = n \times t_{1/2}$。

12. **单位遗漏 / 单位不一致**：λ 的单位是 **yr⁻¹**，所以 t 出来就是 **years**。别把 t½ 写成 48.8 却和 λ = 1.42×10⁻¹¹ 混算（要用 48.8×10⁹）。

13. **选点算斜率时选了 x 跨度很小的两点**：误差被极大放大。永远选**直线两端**的点（或用全部点做线性回归）。

14. **Sm–Nd 与 Rb–Sr 的适用对象记反**：
    - **Rb–Sr → 长英质/中性、富长石**（花岗岩、流纹岩、安山岩）
    - **Sm–Nd → 镁铁质/超镁铁质、富辉石**（玄武岩、辉长岩）

15. **K–Ar 定的是 ⁴⁰Ar 分支不是 ⁴⁰Ca 分支**。原因是 Ar 为惰性气体 → 矿物中的 Ar 几乎全为放射成因（D₀ ≈ 0）；而 Ca 太丰富，信噪比差。

16. **Ar–Ar 法中 ³⁹Ar 的角色**：³⁹Ar **本身不是天然衰变产物**，而是**在核反应堆中由 ³⁹K 人工转化**而来，用作 K 含量的**代理 (proxy)**。

17. **U–Pb 是"衰变链"不是单步衰变**：²³⁸U → ²⁰⁶Pb 中间要经过很多步。

18. **"半衰期越长越好"是错的**：好的 chronometer 的半衰期要与所测过程的时间尺度**匹配**（约 10 个半衰期以内有效）。太长 → 变化太小测不准；太短 → 母体早已衰变殆尽。

19. **封闭体系假设 (closed system assumption)**：整个等时线方法建立在"岩石形成后母体和子体元素既没有加入也没有丢失"这一前提上。**数据不共线通常就是体系被扰动的信号**。

20. **教材也会错**：McSween Fig. 14.2 的图注和标签都有错。要**批判性阅读教科书**。

| Isochron | 等时线 | "等时之线"；等时线图上的一条直线，其上所有样品年龄相同。 |
| Isochron diagram | 等时线图 | y = 子体/稳定同位素、x = 母体/稳定同位素的散点图，用于求年龄。 |
| Initial ratio | 初始比值 | 等时线的 y 轴截距，如 $(^{87}\mathrm{Sr}/^{86}\mathrm{Sr})_0$。 |
| Linear regression | 线性回归 | 用全部数据点拟合最佳直线的数学方法，比手工两点法更准确。 |
| Ratio-ing isotope | 参比同位素 | 用作分母的稳定、非放射成因同位素（⁸⁶Sr、¹⁴⁴Nd 等）。 |
| Mass spectrometer | 质谱仪 | 测量同位素比值的仪器；课上提到 TIMS（热电离质谱）与 ICP-MS（电感耦合等离子体质谱）。 |
| TIMS (Thermal ionization MS) | 热电离质谱仪 | 高精度测同位素比值的经典仪器，Rb–Sr、Sm–Nd 定年常用。 |
| ICP-MS | 电感耦合等离子体质谱仪 | 用等离子体电离样品的质谱仪，通量高、可测多元素。 |
| Rb–Sr system | 铷–锶体系 | ⁸⁷Rb →(β⁻) ⁸⁷Sr，λ=1.42×10⁻¹¹ yr⁻¹，t½=48.8 Ga；适合长英质/富长石岩石。 |
| Sm–Nd system | 钐–钕体系 | ¹⁴⁷Sm →(α) ¹⁴³Nd；适合镁铁质/超镁铁质、富辉石岩石。 |
| K–Ar system | 钾–氩体系 | ⁴⁰K 分支衰变为 ⁴⁰Ca(β⁻) 与 ⁴⁰Ar(β⁺/e.c.)；用 Ar 分支，因 Ar 是气体故 D₀≈0。 |
| Ar–Ar (³⁹Ar–⁴⁰Ar) system | 氩–氩体系 | 核反应堆辐照把 ³⁹K 变成 ³⁹Ar，同时测两个 Ar 同位素，精度更高。 |
| U–Pb system | 铀–铅体系 | ²³⁵U→²⁰⁷Pb、²³⁸U→²⁰⁶Pb，均为长衰变链；锆石定年最强大。 |
| Pb–Pb system | 铅–铅体系 | 同时利用两条 U 衰变链（速率不同），只测 Pb 同位素比值即可定年。 |
| Decay chain | 衰变链 | 母体经过一系列中间放射性核素才到达稳定子体（如 ²³⁸U → … → ²⁰⁶Pb）。 |
| Zircon (ZrSiO₄) | 锆石 | 富 U 贫 Pb、极耐风化变质的矿物，U–Pb 定年的首选对象。 |
| Alkali element | 碱金属元素 | 周期表第 1 族，1+ 阳离子；K 与 Rb 同族，故行为相似。 |
| Alkaline earth element | 碱土元素 | 周期表第 2 族，2+ 阳离子；Ca 与 Sr 同族，故行为相似。 |
| Partition coefficient | 分配系数 | 元素在矿物与熔体（或不同矿物）间的分配比；母子体分配系数不同才能形成等时线。 |
| Fractionation | 分馏 | 元素/同位素在不同相之间被分开富集的过程。 |
| CAI (Ca–Al-rich inclusion) | 富钙铝包体 | 碳质球粒陨石中最早凝聚的高温矿物集合体，年龄 4567 Ma，代表太阳系年龄。 |
| Carbonaceous chondrite | 碳质球粒陨石 | 最原始的一类陨石，保存太阳星云最早期物质。 |
| Ma / Ga / M.y. | 百万年前 / 十亿年前 / 百万年（时长） | a = annum；Ma、Ga 表示"多少年前"（时刻），M.y. 表示时长。 |
| Radon (Rn) | 氡 | 铀衰变链中产生的放射性气体；英国 Cornwall 花岗岩区是典型例子。 |
| Mineral assemblage | 矿物组合 | 一块岩石中共存的矿物集合，随 P–T 条件变化而重结晶。 |
| Matrix / cement | 基质 / 胶结物 | 沉积岩中把碎屑颗粒黏结在一起的物质，是**最后**形成的，代表沉积岩本身的年龄。 |
