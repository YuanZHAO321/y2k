# Week 5 — 分类响应对数值预测变量：逻辑回归 (Logistic Regression)

## 一、本周主题

本周学习**逻辑回归 (logistic regression)**：当**预测变量 (predictor) 是数值型**、而**响应变量 (response) 是二分类 (dichotomous categorical)** 时应当使用的方法。它是本课"数据类型组合矩阵"中**最后一个空格**——前四周已经补齐了「分类→数值」(t 检验、ANOVA)、「数值→数值」(线性回归)、「分类→分类」(卡方检验)，本周补上「数值→分类」。

本周同时是**全课概念部分的收官**（Gilman 在讲座开头说"Welcome to the last lecture of Statistics for Natural Scientists"；下周 Week 6 讲非独立数据与混合效应模型 mixed models，属于"数据结构"而非"数据类型"的维度）。因此本周材料里还包含两份**全局性的收尾内容**：

- **Appendix 1「检验选择速查表」**——把六周的所有检验按数据类型组合排成一张表（见第三节）。
- **Appendix 2「R 与 RStudio 的安装与使用」**——工具性回顾（见第五节末）。

本周的三个能力目标（Practical 6 开篇明确列出）：
1. 用**简单与多重逻辑回归 (simple and multiple logistic regression)** 分析"数值预测变量 + 二分类响应"的数据；
2. **清晰简洁地报告 (report)** 逻辑回归的结果；
3. 用逻辑回归模型**预测事件发生的概率 (predict probabilities of events)**。

此外本周还正式引入两个跨方法的重要概念：**ANCOVA（同一模型中混用数值与分类预测变量）**与 **AIC 模型选择**。

## 二、核心概念

### 2.1 为什么线性回归在这里会崩掉（动机）

设想手册开篇的例子：50 只白尾鹿 (white-tailed deer, *Odocoileus virginianus*) 幼崽的**出生体重 (mass at birth, Kg)** 与**是否活到成年 (survived)**。响应变量用**指示变量 (indicator)** 编码：活下来记 1，死了记 0。

> **编码惯例**（讲座口头强调）：人们习惯把**自己关心、想要检出的那个状态**编码为 **1**（"event"，事件），另一个状态编码为 **0**。1 和 0 只是标签，**响应变量本质仍是分类变量**，"yes"和"no"不是真正的数字。

如果硬套线性回归（图 6.1 的红线），会立刻出现三个荒谬之处：

1. **不能解释为对个体的预测**：直线在中段给出 0.5，可是没有哪只幼崽"活了一半"。它要么活，要么死。
2. **也不能解释为概率**：直线是无界的。在鹿的数据里，出生体重 > 4.1 Kg 时直线预测存活率 **> 1**，出生体重 < 1.8 Kg 时预测存活率 **< 0**。概率不可能超出 $[0,1]$。
3. 因此我们需要的不是直线，而是一条**S 形曲线**：概率随预测变量单调变化，但在接近 0 和 1 时**逐渐变平 (taper off)**，永远不越界。

这条曲线就是**逻辑函数 (logistic function)**，用它来拟合数据就叫**逻辑回归 (logistic regression)**。

### 2.2 逻辑函数与它的三条性质

$$ y = \frac{1}{1+e^{-z}} $$

- $y$：**事件发生的概率**（即被编码为 1 的那个响应出现的概率）；
- $z$：**线性预测子 (linear predictor)**，是横轴上的量；
- $e$：自然常数。

三条性质（Gilman 在 slides 15–17 与 transcript 中都逐条推过）：

| 情形 | 推导 | 结果 |
|---|---|---|
| $z = 0$ | $e^{-0}=1$，故 $y = 1/(1+1)$ | $y = 1/2$，事件"发生与不发生一样可能" |
| $z \to -\infty$ | $-z \to +\infty$，$e^{-z}$ 是**极大正数**，$1/(\text{极大})\to 0$ | $y \to 0$ |
| $z \to +\infty$ | $-z \to -\infty$，$e^{-z}\to 0$，分母 $\to 1$ | $y \to 1$ |

所以 $y$ 永远被夹在 $(0,1)$ 之间——**天然满足概率的定义**。

### 2.3 关键的概念难点：为什么还需要"第二个函数"？

Gilman 特别停下来讲了这一点（slide 17 + transcript 中反复解释，并坦承"It took me many, many hearings of this before I understood it"）：

> 逻辑函数 $y = 1/(1+e^{-z})$ 的形状是**固定死的**。给定一个 $z$，$y$ 一定是那个值。我们**不能**把这条红曲线左右平移或改变陡度。当 $z=4$，函数值就必然在那个位置。

但我们真正关心的横轴不是 $z$，而是**真实的预测变量** $x$（出生体重、猴群大小、年龄……）。而且"出生体重为 0 的幼崽有 50% 存活率"显然是胡说。

**解决办法**：再拟合**第二个函数**——假设 $z$ 是真实预测变量的**线性函数**：

$$ z = \beta_0 + \beta_1 x $$

于是完整模型是**两层嵌套**：

$$ y(x) = \frac{1}{1+e^{-(\beta_0+\beta_1 x)}} $$

这里：

- $\beta_0$：**截距 (intercept)**，控制曲线在 $x$ 轴上的左右位置，也就是曲线与 $y$ 轴相交的高度。它是"所有预测变量都等于 0 时"事件的预测（对数几率）。
- $\beta_1$（手册写作 $b_1$，slides 写作 $\beta_x$）：**该预测变量的效应量 (effect size)**，控制曲线的陡度。

**把直线"链接"到曲线的那个函数就叫连接函数 (link function)**。逻辑回归的连接函数就是逻辑函数。任何"带连接函数的回归模型"都属于**广义线性模型 (generalised linear model, GLM)** 这一大类。

### 2.4 曲线形状的两个几何量（手册 Fig. 6.2）

- **最陡处的斜率** $= \dfrac{b_1}{4}$
- **最陡点的横坐标** $= -\dfrac{b_0}{b_1}$

最陡点**永远出现在事件概率恰为 $1/2$ 的位置**（因为此时 $z = 0$）。所以 $-b_0/b_1$ 就是"事件发生与不发生同样可能"的那个预测变量取值。

$b_1$ 为负 → 预测变量增大时事件概率下降（曲线下行）。

**截距的解释要小心**：截距是"预测变量取 0 时"的预测概率。幼鹿不可能出生体重为 0，所以此处截距**没有生物学意义**。这与线性回归中"零不是合理取值时截距须谨慎解释"的告诫完全一致——这也正是**均值中心化 (mean centring)** 的动机。

### 2.5 模型如何拟合：最大似然 (maximum likelihood)

线性回归用**最小二乘**（最小化观测点到拟合线的**平方距离**）。逻辑回归改用**最大似然**。

**单个观测的似然 (likelihood)**：模型预测出生体重 3 Kg 的幼崽存活概率为 0.45。

- 若数据中有一只 3 Kg 且**存活**的幼崽 → 该观测的似然 = **0.45**；
- 若有一只 3 Kg 但**死亡**的幼崽 → 该观测的似然 = **1 − 0.45 = 0.55**。

**整个数据集的似然**是所有单个观测似然的**连乘积**：

$$ L(\mathbf{Y}\mid\theta) = \prod_{i=1}^{n} L(y_i \mid \theta) $$

- $L$：似然；
- $\mathbf{Y}$：观测到的整个响应数据集；
- $\theta$：一组参数取值（即 $b_0, b_1, \dots$）；
- $n$：观测数。

**拟合 = 寻找使这个乘积最大的那组参数**，也就是"在哪组参数下，我们实际观测到的这一套 0/1 结果最有可能出现"。实践中 R 用 Fisher scoring 迭代法自动完成（`summary()` 输出末尾的 `Number of Fisher Scoring iterations: 4` 就是迭代次数）。

### 2.6 优势 (odds)、优势比 (odds ratio) 与对数优势比 (log odds ratio)

这是本周最容易误解的地方，Gilman 在 slides 与 transcript 中都花了大段时间讲。

**优势 (odds)** 的定义：

$$ \text{odds} = \frac{p}{1-p} $$

赌马式的读法："1 to 4"意思是**每出现 1 次正结果，就出现 4 次负结果**。

**逻辑函数的反函数就是 logit（对数优势）**，推导如下：

$$ y=\frac{1}{1+e^{-z}} \;\Longrightarrow\; 1-y=\frac{e^{-z}}{1+e^{-z}} \;\Longrightarrow\; \frac{y}{1-y}=e^{z} \;\Longrightarrow\; \boxed{\ln\!\left(\frac{y}{1-y}\right)=z=\beta_0+\beta_1x} $$

所以：**线性预测子 $z$ 就是事件的对数优势 (log odds)**。这解释了为什么 `summary()` 里的 `Estimate` 是**对数优势比 (log odds ratio, LOR)**：

- $x$ 增加 1 个单位 → $z$ 增加 $\beta_1$ → **优势乘以 $e^{\beta_1}$**。
- 因此 **优势比 (odds ratio, OR) $= e^{\beta_1}$**，即"预测变量每变化一个单位，优势乘以多少倍"。

**符号方向**（永远可以直接读）：

- $\beta > 0$ → 预测变量增大，事件**更可能**发生；
- $\beta < 0$ → 预测变量增大，事件**更不可能**发生。

**举例（手册 Pinochet 数据）**：年龄的 LOR = 0.02168 yr$^{-1}$ → OR = $\exp(0.02168)=1.02192$ yr$^{-1}$。含义：年龄每大一岁，投票支持 Pinochet 的**优势乘以 1.02192**。若某人原本的优势是 4 比 1，那么他年长一岁后优势变成 $4 \times 1.02192 = 4.088$ 比 1。

**为什么非要用这么别扭的量？**（transcript 中的学生疑问 + Gilman 的正面回答）

> 我们真正想知道的是"预测变量每变化一个单位，**概率**变化多少"。但因为拟合的是**曲线**，这个量**在曲线的不同位置是不一样的**：在曲线中段（例如猴群大小约 60 处）每增加一个个体带来的概率变化很大；在曲线两端（群体很大或很小时）概率变化就很小。**所以不存在比 log odds ratio 更简单的、能一个数说清全局的表述。** 正因如此，文献里报告逻辑回归结果时常常就直接报 LOR，尽管读者不易消化。

Gilman 也承认："逻辑回归的效应量在科学文献中经常被错误呈现 (often misrepresented in the scientific literature)"。

### 2.7 由系数换算概率（本周的核心技能之一）

给定某个体的各项预测变量取值，求它发生事件的概率，分**两步**：

**第 1 步：算线性预测子**（把与该个体有关的所有效应加起来）

$$ z = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots $$

**第 2 步：套反连接函数 (inverse link function)**

$$ p = \frac{1}{1+e^{-z}} $$

R 里就是 `1/(1+exp(-z))`。

分类预测变量在这一步用**哑变量 (dummy)** 处理：属于该水平记 1，不属于记 0；**基线水平 (baseline) 的所有哑变量都记 0**。

### 2.8 ANCOVA：同一模型中混用数值与分类预测变量

**定义**：**协方差分析 (Analysis of Covariance, ANCOVA)** = 模型中**同时**包含**数值型**预测变量和**分类型**预测变量。

**在 R 中的实现极其简单**：直接把分类变量加到 `glm()`（或 `lm()`）的公式右边即可，R 会自动处理。**这一招对线性回归同样适用**，不限于逻辑回归。

**R 如何处理分类预测变量**（Practical Q3 与 slide 22 都强调）：

- R 自动挑选**一个水平作为基线 (baseline)**，其余每个水平都**与基线比较**；
- 基线水平**不会出现在输出里**——它"消失"了，因为它的效应被吸收进了截距；
- 因此看到 `educationPS`、`educationS` 而看不到 `educationP`，就说明 **P（小学）是基线**；
- 芬奇例子中 signal 有 6–11 共若干水平，输出里**唯独缺 signal 10**，所以 **signal 10 是基线**；"signal 6 显著为正"意思是**听到 signal 6 时啄键的概率显著高于听到 signal 10 时**。

**自由度/参数计数规则**：一个有 $n$ 个水平的分类预测变量，会给模型**增加 $n-1$ 个待估效应量**。

**重要限制**（slide 22 明确指出）：一个多水平分类变量是**作为一个整体**放进模型的，即使其中某些水平的 p 值不显著，**也不能把这些水平一个一个拿掉**。要么整个变量留下，要么整个拿掉。

### 2.9 样本量的经验法则 (rule of thumb)

做多重逻辑回归时：

> **数据中的 case 数应至少为待估效应量个数的 15 倍。**
> 其中 **case 数 = min(事件数, 非事件数)** ——即响应变量中 1 的个数与 0 的个数**取较小者**。

**Pinochet 例子**：`sum(pino$vote==1)` → 837，`sum(pino$vote==0)` → 867，故 case 数 = **837**。模型 6.5 估计 5 个效应量（age、male、pop、inc、pop×inc），需要 $5\times15=75$ 个 case，实际有 837 个，每个效应量分到 160 多个 case，**数据充裕**。

加入 `education`（3 个水平）后，效应量增加 $3-1=2$ 个，共 **7 个**，仍远小于 $837/15$，依然充裕。

### 2.10 模型选择：向后选择 (backward selection) 与 AIC

**向后选择**：从包含所有预测变量的**全模型 (full model)** 出发，逐步删掉不影响响应变量的预测变量。

**规则 1（交互项优先）**：如果某个预测变量参与了模型中的**交互项 (interaction)**，那么**即使它自己的主效应不显著，也不能删掉它**——必须先删交互项。
> Pinochet 例子：`mc_inc` 主效应 p = 0.36 不显著，但它在 `mc_pop*mc_inc` 交互里，所以不能删；而交互项本身 p = 0.138 也不显著，**先删交互项**。删掉之后重新拟合，`mc_inc` 反而变显著了（p = 0.0249）。

**规则 2（不能只看 p 值）**：回顾 Chapter 3 的**多重检验 (multiple testing)** 问题——比较超过两组时，"至少有一组看起来显著不同"的概率会高于设定的显著性水平。因此**仅凭 p 值判断一个有 3 个及以上水平的预测变量该不该留在模型里，是不可靠的做法**。

**替代方案：AIC (Akaike's Information Criterion)**

- AIC 衡量"给定模型与参数时，响应数据的似然"，并**按模型参数个数加权惩罚**；
- **AIC 越低，模型对观测数据的预测越好**；
- 判断准则：**删掉某预测变量后 AIC 下降 → 该变量不属于最优模型；删掉后 AIC 上升 → 该变量应当留在模型里**。

**Pinochet 例子的 AIC 比较**：

| 模型 | 内容 | AIC |
|---|---|---|
| 6.6 | age + male + pop + inc（无 education） | 2228.6 |
| 6.8 | age + male + pop + inc + **education** | **2194.1** |

删掉 education 后 AIC 从 2194.1 **升到** 2228.6 → education **应该留在模型里** → 6.8 是更好的模型。

**AIC 的争议与局限（务必记住）**：

- 有人认为**不该把 p 值与 AIC 混用**在向后选择中；
- 也有人认为**根本不该用 AIC 做向后选择**；
- **AIC 已知会过拟合 (overfit)**：倾向于把实际上不影响响应变量的预测变量也留进模型。
- Gilman 的处理：在 Pinochet 例子里，最终模型中**所有 p 值都极低（< 0.0001）**，所以可以放心认为这些预测变量确实有预测力。
- 延伸阅读：Burnham & Anderson (2002) *Model Selection and Multimodel Inference: a Practical Information-Theoretic Approach*。

### 2.11 交互项存在时，主效应不能一概而论（承接上周的重要提醒）

Lecture 5.1 开头用**加拿大工资数据**（时薪 ~ 年龄 × 性别）回顾了一个学生提问：

- 红线（女性）与蓝线（男性）斜率**显著不同** → 年龄与性别之间存在**交互作用 (interaction)**；
- 问："这个数据集里性别有显著效应吗？"
- **答案是"看情况 (it depends)"**：60 岁时男性显著高于女性（有显著性别效应）；25 岁时两性收入无差异（无显著性别效应）。

> **核心结论**：**模型中若存在交互项，我们就不能对主效应 (main effects) 的显著性、甚至方向做一般性的结论。** 一个预测变量的效应是大是小、是正是负，都取决于模型中其他预测变量的取值。所以要谈性别的效应，**必须说明是在多大年龄上谈**。

### 2.12 GLM 的大家族与"必须说清是哪一种"

**GLM = 任何带连接函数、把直线转换成某种曲线的回归模型**，是一个**无限大的家族**：

| 模型 | 适用响应数据 | 连接的曲线 |
|---|---|---|
| **linear regression** | 数值 | 直线（不指定 family 时 R 默认） |
| **logistic regression** (`family=binomial`) | 二分类 / binomial | 逻辑（S 形）曲线 |
| **Poisson regression** | 计数 | 指数曲线 |
| **negative binomial regression** | 过离散计数 | — |

> **Gilman 最强烈的一条报告规范**（transcript 里近乎"咆哮"，还开玩笑说要找出教学生只写 "GLM" 的那个人）：
> **绝不能只说"我做了一个 GLM"**。听到 "GLM"，读者只知道你把直线连到了某种曲线上，但不知道是 logistic、Poisson 还是别的。**必须明确写出"logistic regression"**，读者才能复现你的分析。Practical 6 也重复了这一点。

### 2.13 逻辑回归的前提假设与检验

**核心假设**：**逻辑函数是描述"预测变量 → 事件概率"关系的正确函数形式**。也就是我们假定这段关系确实呈 S 形。

**这个假设可能不成立。**

**如何应对（手册给出的层次）**：

1. **转换预测变量 (transforming the predictors)**——有些情况下这样就能解决；
2. 若仍不行，数据可能需要**逻辑函数以外的其他函数**来拟合（即换用其他连接函数 / 其他 GLM）；
3. 手册明确说明**处理该假设违背的方法超出本手册范围**；若将频繁使用逻辑回归，建议深入研读，起点是 **Fox & Weisberg (2011) *An R Companion to Applied Regression***。

**其他隐含要求**（贯穿全课）：

- 观测**相互独立**（若不独立——例如同一只鸟重复测多次、同一猴群多个个体——就需要 Week 6 的**混合效应模型 (mixed models)**。transcript 结尾说"I'll use this figure to motivate some ideas next week"，指的正是这个）；
- 响应变量必须是**二分类**（Appendix 1 明确标注 "Categorical (Dichotomous)"）；
- 样本量满足 2.9 的 15-case 法则。

**假设不成立时的替代方法**：转换预测变量 → 换连接函数 / 其他 GLM → 若预测变量本身也是分类的，退回**卡方检验 / Fisher 精确检验**（Ch.5）→ 若响应是**有序 (ordinal)** 而非二分类，需要有序逻辑回归（手册未讲，建议自行 Google "analysing ordinal data in R"）。

## 三、公式与图表

### 3.1 逻辑函数 / sigmoid

$$ y = \frac{1}{1+e^{-z}}, \qquad y \in (0,1) $$

| 符号 | 含义 |
|---|---|
| $y$ | 事件（被编码为 1 的响应）发生的概率 |
| $z$ | 线性预测子 (linear predictor) |

### 3.2 线性预测子

$$ z = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots + \beta_k x_k $$

| 符号 | 含义 |
|---|---|
| $\beta_0$ | 截距；所有预测变量为 0 时的对数优势 |
| $\beta_i$ | 第 $i$ 个预测变量的效应量，单位是"每单位预测变量的对数优势比" |
| $x_i$ | 第 $i$ 个预测变量的取值（分类变量用哑变量 0/1） |

### 3.3 完整的逻辑回归模型

$$ P(\text{event}\mid x) = \frac{1}{1+e^{-(\beta_0+\beta_1 x)}} $$

### 3.4 logit 连接函数（逻辑函数的反函数）——完整推导

$$
\begin{aligned}
y &= \frac{1}{1+e^{-z}} \\[4pt]
1-y &= 1-\frac{1}{1+e^{-z}} = \frac{(1+e^{-z})-1}{1+e^{-z}} = \frac{e^{-z}}{1+e^{-z}} \\[4pt]
\frac{y}{1-y} &= \frac{1/(1+e^{-z})}{e^{-z}/(1+e^{-z})} = \frac{1}{e^{-z}} = e^{z} \\[4pt]
\therefore\quad \operatorname{logit}(y) &= \ln\!\left(\frac{y}{1-y}\right) = z = \beta_0+\beta_1 x
\end{aligned}
$$

**读法**：逻辑回归其实是"对**对数优势**做普通线性回归"。

### 3.5 优势、优势比、对数优势比

$$ \text{odds} = \frac{p}{1-p}, \qquad \text{OR} = e^{\beta}, \qquad \text{LOR} = \beta = \ln(\text{OR}) $$

$$ \text{新优势} = \text{旧优势} \times e^{\beta \cdot \Delta x} $$

### 3.6 曲线的几何量

$$ \text{最陡处斜率} = \frac{b_1}{4}, \qquad \text{最陡点位置} \; x^{*} = -\frac{b_0}{b_1}, \qquad P(\text{event}\mid x^{*}) = \frac12 $$

### 3.7 似然函数

$$ L(\mathbf{Y}\mid\theta) = \prod_{i=1}^{n} L(y_i\mid\theta) $$

其中单个观测的似然：若 $y_i=1$ 则为 $p_i$；若 $y_i=0$ 则为 $1-p_i$。拟合即求 $\hat\theta = \arg\max_\theta L$。

### 3.8 由系数换算概率——标准三步流程

以 Pinochet 最终模型（原始未中心化预测变量，式 6.12）为例：

$$
\begin{aligned}
z =\; & 0.4946 + 0.01465 \times \text{age} - 0.5968 \times \text{male} \\
& - 4.036\times10^{-6} \times \text{population} + 6.545\times10^{-6}\times\text{income} \\
& - 1.009 \times \text{PS} - 0.5216 \times \text{S}
\end{aligned}
$$

**例 A：20 岁男性，来自 100 万人口的城市，月收入 2500 比索，中学 (secondary) 学历**
（中学 → S = 1, PS = 0）

$$ z = 0.4946 + 0.01465(20) - 0.5968(1) - 4.036\times10^{-6}(10^6) + 6.545\times10^{-6}(2500) - 1.009(0) - 0.5216(1) = -4.35 $$

$$ p = \frac{1}{1+e^{-(-4.35)}} = 0.013 $$

→ 只有略高于 **1%** 的可能性投票支持 Pinochet。

**例 B：60 岁女性，来自 2 万人口的城镇，月收入 75000 比索，中学学历**

$$ z = 0.4946 + 0.01465(60) - 0.5968(0) - 4.036\times10^{-6}(20000) + 6.545\times10^{-6}(75000) - 0 - 0.5216(1) = 1.26 $$

$$ p = \frac{1}{1+e^{-1.26}} = 0.779 $$

→ 约 **78%** 的可能性支持 Pinochet。

> **要点**：做**预测**时不需要解释截距，所以**用原始（未均值中心化）的预测变量拟合模型更方便**。均值中心化只影响截距，**不改变任何其他系数**（对比式 6.8 与 6.10：只有 Intercept 变了）。

### 3.11 R 代码：画出逻辑回归曲线

**情形一：模型中只有一个预测变量**（手册式 6.9，重现 Fig. 6.3）

```r
# 先画散点图：x 轴出生体重，y 轴生死（0/1）
plot(deer$bw, deer$s,
     xlab = "mass at birth (Kg)",   # x 轴标签
     ylab = "survived",             # y 轴标签
     ylim = c(-.25, 1.25))          # y 轴范围留出上下余量，让 0/1 点不贴边

# 拟合逻辑回归：响应 s（生死），预测变量 bw（出生体重）
s.lr = glm(s ~ bw, data = deer, family = binomial)

# 在散点图上叠加拟合曲线
curve(1/(1 + exp(-(s.lr$coefficient[1] + x * s.lr$coefficient[2]))),
      min(deer$bw) - .2,            # 曲线起点：最小出生体重再往左 0.2 Kg
      max(deer$bw) + .2,            # 曲线终点：最大出生体重再往右 0.2 Kg
      col = "red",                  # 曲线颜色
      add = T)                      # add=T 表示叠加到已有图上，而不是新开一张图
```

**逐项说明**：

- `s.lr$coefficient[1]` = 截距 $\beta_0$；`s.lr$coefficient[2]` = 预测变量的效应量 $\beta_1$——**直接从拟合对象里取系数，避免手抄出错**；
- `1/(1+exp(-(b0 + x*b1)))` 就是反连接函数，`x` 是 `curve()` 自动提供的自变量；
- **注意**：逻辑回归**不能用 `abline()`** 画线（transcript 明确指出），因为它不是直线；必须用 `curve()` 把整条逻辑函数写出来。

**情形二：模型中有多个预测变量**

难点在于：事件概率不仅取决于我们关心的那个预测变量，还取决于**模型中所有其他预测变量**。所以画图前必须**为其他预测变量选定基线取值**。

- 若预测变量已均值中心化，最直观的选择是 **0**（代表总体平均水平）；
- 但根据想传达的信息，也可以选别的基线值；
- **不要把均值中心化后的变量放在 x 轴上**——读者看不懂"中心化年龄 = −5"是什么意思。所以要**用原始变量重新拟合一次**再画图。

**手册式 6.11：一张图上画三条曲线（三种教育水平下年龄对投票倾向的影响）**

```r
# 用原始 age 重新拟合（只有截距变了，其他系数与 6.8 完全相同）
pino.lr = glm(vote ~ age + male + mc_pop + mc_inc + education,
              data = pino, family = binomial)

# 第一条（红）：小学学历（基线）女性，收入与城镇规模取平均值
curve(1/(1 + exp(-(0.1276 + x*0.01465))),
      18, 70,                                   # 年龄范围 18–70 岁
      ylim = c(0,1),                            # 概率轴 0–1
      ylab = "probability of supporting pinochet",
      xlab = "voter age",
      col = "red")                              # 第一条 curve 负责建图，因此在这里设轴标签与范围

# 第二条（蓝）：中学学历 —— 在线性预测子里加上 educationS 的效应 -0.5216
curve(1/(1 + exp(-(0.1276 + x*0.01465 - 0.5216))), col = "blue",  add = T)

# 第三条（绿）：大学学历 —— 加上 educationPS 的效应（此处 -1.1118）
curve(1/(1 + exp(-(0.1276 + x*0.01465 - 1.1118))), col = "green", add = T)

# 图例
legend(50, 0.28,                                # 图例左上角的 (x, y) 坐标
       legend = c("primary","secondary","postsecondary"),  # 图例文字
       col = c("red","blue","green"),           # 对应线条颜色
       lty = 1,                                 # 线型，1 = 实线
       cex = 0.9)                               # 文字大小
```

**关键理解**：三条曲线的区别**只在于线性预测子里加了不同的分类效应常数**。加常数 = 曲线沿 x 轴平移（斜率不变），这正是**没有交互项时**分类变量的作用方式。

### 4.3 ★ 完整的现场演示案例：狒狒寄生虫感染 (baboon parasitism)

这是 slides 里**没有**、只在 transcript 里出现的一个完整分析，也是本周最贴近 practical 的示范。

**背景与假设**：狒狒 (baboons) 群居，群体规模从 10–15 到数百不等。研究者想知道**寄生虫感染是否取决于群体大小 (troop size)**。假说：狒狒群像一张"寄生虫的网"——狒狒外出觅食、从土里刨食物，任何个体都可能拾到寄生虫；一旦有一只感染，寄生虫排卵后就容易在群内扩散。**群越大 → 越容易拾到寄生虫 → 拾到后又更容易扩散 → 小群可能更不易被寄生**。

**数据采集方法**（Gilman 花了不少时间讲，因为这决定了数据的结构）：

- 野外观察狒狒群，先数清群体大小；
- 观察动物排便，等几只排完后去采集粪样，显微镜下检查**寄生虫卵**；
- 由于只观察有限时间，**每群只能采到少数个体**，不可能覆盖全群；
- 必须能把粪样**对应到具体个体**，因为还要记录性别（狒狒**两性异形 (sexually dimorphic)**，远距离即可辨别）；
- 共约 **1200 只动物**的记录。

**数据结构**：`sex`（性别）、群体大小 `group size`、troop 编号（任意编号，只用来区分不同群）、三种寄生蠕虫（strongyloides / abbreviata / streptopharagus）的**有无**（有虫卵 = 感染 = 1，无 = 0）——**没有试图估计感染强度**，只记录有无。

**第一步：画图看数据**

```r
baboons = read.csv("...")   # read.csv 是本课最重要的命令之一
```

> Gilman 特别叮嘱：**"这个命令真的很重要。还有几个人在导入数据上有困难，请务必在今天的 practical 上找我或 demonstrator 解决。"** 数据导入过关的同学后面都学得不错。

画 x = 群体大小、y = 感染（0/1）的散点图后，发现问题：**同一群里采了多只狒狒，点全都叠在一起 (stacked on top of each other)**，看不出规律。

**解决办法：加抖动 (dither / jitter)**——给 y 值加一个小的随机数，让点散开。即使放大看，**Gilman 自己也说"肉眼看不出模式"**——正因如此才需要统计检验。

**第二步：拟合模型**

```r

mod = glm(abbreviata ~ group.size, data = baboons, family = binomial)

```

与线性回归相比**只有两处改变**：`lm` → `glm`，以及加上 `family = binomial`。

**输出解读**：

- `group size` 行的 **p 值 < 0.05** → 群体大小有显著效应，感染概率随群体大小变化；
- `Estimate` = **0.005487478** = LOR；
- 换算：$e^{0.005487} \approx 1.0055$ → **群里每多一只狒狒，感染的优势乘以约 1.0055 倍**；
- 截距 = **−0.4459**。

**第三步：画拟合曲线**（`abline()` 用不了，只能手写反连接函数）

Gilman 反问学生："我讲了半天要画曲线，可这条线看着是直的。哪里出问题了？"

**答案**：**它确实是曲线，只是我们只看到了它极小的一段。** 数据全都堆在逻辑曲线中间近乎线性的一小段里。如果把坐标轴大幅延长，就能看到 S 形。但——**延长出去的部分并不相关**：世界上没有大小为 −200 的狒狒群，研究者也没有观察到 400 或 600 只的群，**我们不能在数据范围之外做预测**。

**第五步：预测某群体大小下的感染概率**

```r
z = -0.4459 + 30 * 0.005487478   # 群体大小 = 30 时的线性预测子
1/(1 + exp(-z))                  # 套反连接函数
# → 约 0.43
```

**结论：30 只的小群中，个体感染概率约 43%。**

**第六步：加入第二个预测变量（性别）**

生物学动机（Gilman 给出**两个方向相反的假说**，很好的示范）：

- 狒狒群通常由**一只优势雄性**主导，雌性居于群体中心，**其他雄性被排挤到群体边缘 (periphery)** → 边缘雄性接触寄生虫少 → **雄性感染率可能更低**；
- **或者恰好相反**：很多动物、尤其是灵长类，**雄性免疫系统不如雌性** → 雄性抵抗寄生虫能力差 → **雄性感染率可能更高**。

先按性别给点上色（雌红雄蓝），"看着像右下角雄性多、右上角雌性多，**但肉眼还是判断不了**"。于是正式检验：

```r
mod2 = glm(abbreviata ~ group.size + sex, data = baboons, family = binomial)
```

**输出解读**：

- 出现 `sexM` 行 = **"身为雄性"的效应**（说明 F 是基线）；
- `sexM` 的 Estimate ≈ **−0.35**，强负效应；
- $e^{-0.35} \approx 0.71$ → **在相同群体大小下，雄性感染的优势约为雌性的 71%**；
- **群体大小的效应几乎没变** → 说明两个预测变量之间没有严重混杂。

> ⚠️ **转写中的口误须注意**：Gilman 口头说成 "71% of the probability of females"，**严格说 $e^{\beta}$ 是优势比 (odds ratio)，不是概率之比**。考试与报告中请写"优势 (odds) 约为雌性的 0.71 倍"。

**第七步：检验交互作用**

假说：如果雄性感染率低是因为它们待在群体边缘，那么**群体大小对雄性可能根本没影响，而对雌性有影响** → 这就是交互作用。

```r
mod3 = glm(abbreviata ~ group.size * sex, data = baboons, family = binomial)
```

**结果：交互项不显著**——"有意思的猜想，但没有证据支持"。

**接下来的关键操作**：**回到没有交互项的模型 (mod2) 作为最终模型**。理由（Gilman 明确解释）：交互项进入模型后，**性别与群体大小的主效应估计值都变了**；当交互项不显著时，**我们没法在有交互项的模型里正确解读主效应**（呼应 2.11 节的原则）。

**第八步：把两条曲线加到图上**

新模型的截距 = **−0.282872**。

```r
# 雌性（基线）：截距 + 群体大小效应
curve(1/(1 + exp(-(-0.282872 + b_gs*x))), add = T, col = "red")
# 雄性：截距 + 雄性效应 + 群体大小效应
curve(1/(1 + exp(-(-0.282872 + b_sexM + b_gs*x))), add = T, col = "blue")
```

即"把线性预测子的式子直接塞进连接函数"，与线性回归时的做法完全平行。

### 4.6 ★ Lecture 5.2 的完整案例：Bengalese finch 的择偶偏好学习

这是 slides 里的第二个完整案例，配一段很好的行为生态学故事。

**研究者与背景**：曼彻斯特学生 Giorgia Caspani 在东京大学 Kazuo Okanoya 实验室做 year in research 时收集的数据，已发表于 *Ornithological Science* (Caspani et al. 2020)。

**科学问题**：动物如何习得择偶偏好？**十姊妹 (Bengalese finch, *Lonchura striata var. domestica*)** 的雌鸟部分依据**鸣唱 (song)** 评价配偶，倾向于偏好与**父亲鸣唱相似**的歌。但可能还有别的因素，其中之一叫 **peak shift（峰移）**。

**用草莓解释 peak shift**（Gilman 的类比）：

1. 你去采草莓，尝了左边那颗（偏绿），不好吃；尝了右边那颗（偏红），很好吃。你学到：**红比绿好**。
2. 然后你看到更多草莓，要选一颗。
3. 你学到"这颗（那种红）是好的"。
4. **但大多数人会选颜色更极端的那颗**——比你学过的"好的那颗"还要更红，尽管你对它毫无经验。
5. **这就是 peak shift**：偏好的峰值本应落在"学过是好的"那个刺激上，但实际上**沿着远离'学过是坏的'刺激的方向发生了偏移**。

**实验设计（operant conditioning 操作性条件反射）**：

- 取一段有 **8 音颤音 (8-note trill)** 的雄鸟鸣唱，用音频软件改造成 **6 音**和 **10 音**两个版本；
- 把已适应实验箱的雌鸟放进带扬声器的箱子，播放其中一首歌，然后一个**红色啄键 (peck key)** 亮起；
- 听到**短颤音**后啄键 → **奖励**（几粒小米）；听到**长颤音**后啄键 → **惩罚**（箱内灯熄灭，鸟不喜欢）；
- 多次试验后，鸟学会：**对短颤音歌作出反应、忽略长颤音歌**；
- 短歌称为 **S+**（被训练为偏好的信号），长歌称为 **S−**（被训练为回避的信号）。

**测试阶段**：给每只鸟播放 **120 首歌**，颤音长度 **5–11 音**不等，记录每首歌之后鸟是否啄键 → **二分类（yes/no）响应**。

**第一个研究问题**：**鸟对当前歌的反应概率，是否取决于上一首歌的颤音长度？**（既然鸟学到"短好过长"，那么当前歌比上一首更短时，它是不是更可能反应？）

| current song vs. last song | probability of response |
|---|---|
| shorter | +? |
| equal | ~? |
| longer | −? |

**混杂因素的预先控制（很好的实验设计意识）**：每只鸟连听 120 首，实验开始时**饿**、结束时可能**不饿了**。也许它后期不反应不是因为歌，而是因为**不饿了**。为此，Giorgia 把**每首歌在整个试验中的位置 (position in the trial)** 也放进模型作为预测变量。

**数据结构（`head()` 看前几行）**，每行 = 一只鸟对一首歌的反应：

| 列 | 变量 | 含义 |
|---|---|---|
| 1 | `response` | 1 = 啄键，0 = 忽略 |
| 2 | `position` | 该歌在试验中的位置，**缩放到 0–1**（第一首 0.008，第二首 0.016……）。注意**第一首歌不在数据集里**，因为它没有"上一首"，无法计算 sigdif |
| 3 | `signal` | 听到的是哪首歌；数字表示颤音长度；标注 S+ = 被训练偏好的信号，S− = 被训练回避的信号 |
| 4 | `sigdif` | 当前歌的颤音比上一首**短** = **1**，**长** = **−1**，**相同** = **0** |

> `sigdif` 的例子：第 2 行是 10 音颤音，第 1 行是 6 音颤音，所以第 2 行"更长"，`sigdif = -1`。

**模型一：sigdif + position**

```r
r.lr = glm(response ~ sigdif + position, data = ..., family = binomial)
summary(r.lr)
```

> 命名说明：`r` = response，`lr` = logistic regression。"这只是个名字，我想叫什么都行"——但**取有意义的名字有助于记忆**。

**结果**：`sigdif` 效应很强；`position` **不显著** → 删掉。

**模型二（简化模型）：只留 sigdif**

- **LOR = 1.88**，p 值极低；
- 符号为正 → 预测变量增大时事件更可能。`sigdif` 在"当前歌更短"时为正，事件是"啄键" → **当前歌比上一首短时，鸟更可能啄键**，与预期一致。
- **优势比 OR** $= e^{1.88} = 6.52$ → **当前歌比上一首短时，鸟啄键的优势是"两首等长"时的 6.52 倍**。
- **换算成概率**（截距 = **0.54**）：
  - `sigdif = 1`（当前歌更短）：$p = \dfrac{1}{1+e^{-(0.54 + 1.88 \times 1)}} = \dfrac{1}{1+e^{-2.42}} \approx 0.92$ → **92% 的概率啄键**；
  - `sigdif = 0`（两首等长）：$p = \dfrac{1}{1+e^{-0.54}} \approx 0.63$ → 约 **63%**。
  - 截距 0.54 捕捉的是**基线情形**（预测变量效应尚未加入之前）。

**★ 一个致命的混杂问题（slides 18–19，Gilman 让学生暂停几分钟自己找）**：

> **问题在于：鸟被训练成偏好短颤音的歌。而一首歌之所以"比上一首短"，很大程度上正是因为它本身就是短歌。** 例如那首被训练为偏好的 6 音颤音，比实验中几乎所有其他歌都短。
>
> 所以我们看到的模式**可能根本不是"鸟在相对于上一首歌评价当前歌"，而只是"鸟就是喜欢短歌"**。

**解决办法：把"歌本身"作为预测变量放进模型 → ANCOVA**

**为什么把 signal 当作分类 (categorical) 而不是数值？**（重要的建模判断）

- 我们**可以**把它当数值（6 到 11，对应颤音长度）；
- **但**：鸟被训练成偏好和回避的都是**中间长度**的颤音，所以**偏好未必随颤音长度线性变化**；
- **把歌当作类别 (classes)**，意味着允许鸟对不同长度的歌有**各自独立**的偏好，**不强制这种偏好线性依赖于音符数**。

> **同时包含分类与数值预测变量的模型就叫 ANCOVA**，"实现方式和其他任何线性模型一样"。

**模型三：sigdif + position + signal**

```r
r.lr2 = glm(response ~ sigdif + position + signal, data = ..., family = binomial)
```

**结果**：`position` **仍然不显著** → 删掉 → 得到**最终模型 `response ~ sigdif + signal`**。

**最终模型的解读要点**：

1. **有些 signal 水平不显著，但不能一个一个删掉**——"我们是把它们作为**单一预测变量**放进模型的"。所以这就是最终模型。
2. **基线识别**：输出中**唯独缺少 signal 10** → **R 选了 signal 10 作为基线**，其他所有 signal 都是与它比较。
3. **signal 6 显著为正** → 听到 signal 6 时鸟啄键的可能性**远高于**听到 signal 10 时。**这符合预期**——鸟正是被训练成对 signal 6 作出反应、回避 signal 10。（这实际上是一个**内部一致性检查 (sanity check)**：训练确实生效了。）
4. **signal 11 显著为负** → 听到 signal 11 后啄键的可能性**低于** signal 10。**这提示存在 peak shift**——signal 11 比被训练为"坏"的 signal 10 更极端，鸟对它的回避比对 S− 本身还强。
5. **不做各 signal 之间的两两比较**——Gilman 直说"我并不那么在意"。他的目标**不是**评估各 signal 的效应，**而是在控制住'鸟当前听到的是哪首歌'之后，评估'当前歌与上一首歌之差'的效应**。
6. **控制之后 sigdif 的效应**：**仍然显著，但没那么令人信服，效应量也变小了**。尽管如此，**仍然支持"鸟会相对于之前听过的信号来评价每个信号"**——而 **Giorgia 是第一个证明这一点的人**。

> **方法论启示**：这是本周最重要的科研思维示范——**先怀疑自己的结果可能被混杂因素解释，再通过把混杂变量纳入模型来控制它，然后看关键效应是否依然存在。** 效应变小但仍显著，是诚实且有说服力的结论。

### 5.5 Question 4：多重逻辑回归——为什么值得学一个"新"方法

**Practical 原文的论证**：既然 Q1 用卡方和逻辑回归得到相同答案，Q3 的舱等问题也本可以用卡方做，那为什么还要学逻辑回归？

> **因为卡方检验只能处理"一个分类预测变量 + 一个分类响应变量"。逻辑回归灵活得多——像线性回归一样，它可以同时研究多个预测变量的效应，而且每个预测变量的效应都是在控制住其他预测变量之后的效应。**

```r
# 两个预测变量（练手）
surv.x.sc.lr = glm(survived ~ sex + class, data = td, family = binomial)

# Q4.1：三个预测变量，各自控制其余
surv.x.sca.lr = glm(survived ~ sex + class + age, data = td, family = binomial)
summary(surv.x.sca.lr)
```

**★ Q4.2（Challenge）为什么简单模型里几乎看不出年龄效应，多重模型里却很强？**

对比：

| 模型 | age 的 LOR | p 值 |
|---|---|---|
| Q2：`survived ~ age` | −0.0079 yr$^{-1}$ | 0.0731（勉强显著） |
| Q4：`survived ~ sex + class + age` | **−0.0344 yr$^{-1}$** | **< 0.0001** |

**效应量相差四倍多。**

Practical 明确提示：**答案不能只说"新模型控制了其他变量"——那是废话前提。问题是：为什么控制其他变量反而会揭示出一个原本被掩盖的效应？**

**解题思路**（需要结合对研究系统的实际了解来思考）：

- 年龄与**舱等**是**相关的**：**年纪大的乘客更可能坐头等舱**（有钱需要时间积累），而**头等舱生还率高**；
- 于是"年龄"里混杂了一个**正向**的间接效应（年龄大 → 舱等高 → 更易生还），它**抵消**了"救生艇优先妇孺"带来的**负向**直接效应（年龄大 → 不是儿童 → 不优先上艇）；
- 两股方向相反的力量在简单模型里**部分相消**，使 age 的净效应看起来很小（−0.0079）；
- 一旦把 `class`（和 `sex`）放进模型控制住，那条正向的间接通路被堵死，**年龄的真实（负向）效应就显露出来**（−0.0344）。
- 同理，性别也可能起作用：三等舱里有大量**年轻男性**，他们大量罹难，也会扭曲单纯的年龄—生还关系。

> 这是**混杂 (confounding)** 与**抑制变量 (suppressor)** 的经典教学案例。

**★ Q4.3（Super-challenge）如何用本课学过的方法检验这个假设？**

Q4.2 的答案是一个**假设 (hypothesis)**：*"年长者更可能坐头等舱"*。检验它：

- **预测变量** = `class`（**分类**，3 个水平）；**响应变量** = `age`（**数值**）；
- 查 **Appendix 1 速查表**："Categorical → Numerical，3 组以上" → **ANOVA（Chapter 3）**；
- 若正态性或方差齐性假设不成立 → **Kruskal-Wallis test**；
- 若 ANOVA 显著，再用 **Tukey HSD / Dunn's test**（`dunn.test` 包）做**事后两两比较 (post-hoc)**，确认是"头等舱平均年龄 > 三等舱"这个方向。

```r
age.aov = aov(age ~ class, data = td)
summary(age.aov)
TukeyHSD(age.aov)
# 若假设不成立：
kruskal.test(age ~ class, data = td)
```

> **这道题最大的价值**：示范了 Appendix 1 速查表**在真实研究流程中怎么用**——你的研究问题决定了预测变量与响应变量各是什么类型，类型组合决定了该用哪个检验。

### 5.6 Question 5：加入交互项，并做个体预测

**Q5.1**

```r
surv.full.lr = glm(survived ~ class + sex + age + sex*age,
                   data = td, family = binomial)
summary(surv.full.lr)
```

`sex*age` 交互项检验的是：**年龄对生还的影响是否因性别而异**（例如"妇孺优先"可能意味着年龄对男性的影响与对女性不同）。

**报告时注意**：若交互项显著，则**不能对 age 或 sex 的主效应做一般性结论**（见 2.11 与 4.3 第七步）；必须说明"在某个性别下年龄的效应是……"。

**Q5.2 / Q5.3：电影角色的生还概率**——本周核心技能的综合应用。

| 角色 | 年龄 | 舱等 | 性别 |
|---|---|---|---|
| **Rose DeWitt Bukater** | 17 | first（富家女） | female |
| **Jack Dawson** | 19 | third | male |

**计算步骤**（两人都用同一个模型式子）：

1. 从 `summary(surv.full.lr)` 抄下所有系数；
2. **Rose**：`class = first`（若 first 是基线 → 所有 class 哑变量 = 0）、`sex = female`（若 female 是基线 → `sexmale` = 0，交互项 `sexmale:age` 也 = 0）、`age = 17`
   $$ z_{\text{Rose}} = \beta_0 + \beta_{\text{age}} \times 17 $$
3. **Jack**：`classthird` = 1、`sexmale` = 1、`age = 19`，**交互项一定不能忘**（`sexmale:age` 的哑变量值 = $1 \times 19 = 19$）
   $$ z_{\text{Jack}} = \beta_0 + \beta_{\text{classthird}} + \beta_{\text{sexmale}} + \beta_{\text{age}}\times 19 + \beta_{\text{sexmale:age}}\times 19 $$
4. 两人各自代入 $p = 1/(1+e^{-z})$。

**预期结论**：Rose 的生还概率会很高，Jack 的会很低——**与电影情节一致**（这正是这道题的设计趣味）。

> ⚠️ **最容易丢分的地方**：交互项的取值是**两个预测变量取值的乘积**，不是 1。Jack 的 `sexmale:age` 项要代 $1\times19=19$，而不是 1。

### 5.7 ★ A Closing Thought：哪个才是"正确"的模型？（本周思想性最强的一段）

Practical 结尾专门讨论了这个问题（与手册 2.10 的 AIC 讨论互补）：

同一组预测变量与响应变量，我们建了好几个模型（Q2 只有 age；Q4、Q5 有 age + 其他且互相控制）。**哪个是"对"的？**

> **实际上，所有这些模型都有价值，但它们回答的是不同的问题。**
>
> - **如果我们对某位乘客一无所知、只知道年龄**，那么 **Q2 的模型就是预测他生还与否的最佳模型**。这个模型里年龄的效应被其他因素**混杂 (confounded)** 了——比如某些舱等的人不论年龄都更易生还，而年长者更可能在头等舱，所以我们归给"年龄"的效应有一部分其实来自"舱等"。**但这没关系。** 不同年龄的人确实有不同的生还率，我们**可以**基于年龄预测生还率，**不管背后的机制是什么**。
> - **如果我们的目标是理清各乘客属性与生还之间的机制 (mechanisms)**，那就必须**通过控制其他变量来分离出每个预测变量的效应**。
>
> **所以，不存在为某个数据集挑出"最佳模型"的简单办法。我们只能仔细思考自己想回答的是什么问题。**

**这段话是理解"模型选择"的钥匙**：AIC、p 值、向后选择都是**技术工具**，而"该建哪个模型"归根结底是**科学问题决定的**——是要**预测 (prediction)**，还是要**解释机制 (inference)**？

## 六、易错点 / 重点难点

1. **★ 系数（Estimate）绝不能直接当概率或概率变化量来解释。** 它是**对数优势比 (log odds ratio)**。要得到概率必须走两步：先算线性预测子 $z$，再套 $1/(1+e^{-z})$。同一个 $\beta$ 在曲线不同位置对应的**概率变化量是不同的**（曲线中段变化快、两端变化慢）——这正是无法用"每单位改变多少概率"来简单报告的原因。

2. **★ 优势 (odds) ≠ 概率 (probability)。** $e^{\beta}$ 是**优势比**，说"雄性感染概率是雌性的 71%"是不准确的表述（Gilman 课上口误），正确说法是"**优势**约为雌性的 0.71 倍"。

3. **★ 只写 "GLM" 是严重的报告缺陷。** GLM 是一个无限大的模型家族（logistic、Poisson、negative binomial……）。**必须写明"logistic regression"**，读者才能复现。Gilman 对这一点态度极其强烈。

4. **★ 逻辑回归不能用 `abline()` 画拟合线。** 必须用 `curve()` 把整个反连接函数 `1/(1+exp(-(b0+b1*x)))` 写出来，并加 `add = T`。

5. **★ 参与交互项的主效应不能单独删除。** 必须**先删交互项**，重新拟合后再看主效应。（Pinochet 例：`mc_inc` p = 0.36 看似该删，但删掉交互项后它变成 p = 0.0249 显著。）

6. **★ 交互项存在时，不能对主效应做一般性结论。** 效应的大小甚至方向都取决于其他预测变量的取值（工资数据：25 岁无性别差异，60 岁有）。要谈主效应必须**指定其他预测变量的取值**。

7. **★ 交互项不显著时，应回到无交互项的模型解读主效应。** 因为交互项在模型里会改变主效应的估计值。

8. **★ 多水平分类预测变量必须整体进出。** 即使其中某些水平的 p 值不显著，**也不能一个一个删**。

9. **★ 不能只用 p 值做模型选择。** 多重检验问题使得"3 个及以上水平的预测变量"仅凭 p 值判断不可靠 → 用 **AIC**（越低越好；删掉后 AIC **上升**说明该变量应留下）。**但 AIC 会过拟合**，且"p 值与 AIC 混用"本身有争议。

10. **★ 基线水平不出现在输出里。** 看到 `educationPS`、`educationS` 而没有 `educationP`，就知道 P 是基线；输出里"少了谁，谁就是基线"。所有系数都是**相对基线**的比较。

11. **★ 分类变量参数计数**：$n$ 个水平 → **增加 $n-1$ 个待估效应量**（不是 $n$ 个）。

12. **★ 效应量必须带单位**：`yr⁻¹`、`person⁻¹`、`peso⁻¹` ——因为它是"预测变量每变化 1 个单位"的 LOR。忘记单位是 practical 明确点名的失分点。

13. **★ 预测时不要忘记交互项的取值**：交互项哑变量的值是**两个变量取值的乘积**（Jack 的 `sexmale:age` = $1\times19=19$，不是 1）。

14. **截距的解释要小心。** 截距是"所有预测变量为 0 时"的对数优势。若 0 不是合理取值（出生体重 0 的幼鹿、年龄 0 的选民），截距**没有实际意义**。→ 用**均值中心化**解决。但**均值中心化只改变截距，不改变其他任何系数**，且**做预测时用原始变量更方便**、**画图时必须用原始变量**（读者看不懂中心化后的横轴）。

15. **"曲线看起来是直的"不是错误。** 数据往往只落在逻辑曲线中间近似线性的一小段上。**但不要外推到数据范围之外**（不存在 −200 只的狒狒群）。在某些数据集里曲率则很关键。

16. **样本量法则**：**每个待估效应量至少 15 个 case**，且 **case 数 = min(事件数, 非事件数)**——不是总样本量！

17. **卡方检验与逻辑回归在最简单情形下给出相同答案**（Titanic Q1 已验证），但**卡方只能处理"一个分类预测 + 一个分类响应"**；**逻辑回归能同时处理多个预测变量并互相控制**，这才是学它的理由。

18. **★ 混杂效应可以"掩盖"真实效应（Titanic Q4.2）。** 控制其他变量后效应变强并不矛盾——原因是存在**方向相反的间接通路**（年龄↑ → 舱等↑ → 生还↑，抵消了 年龄↑ → 非儿童 → 生还↓）。

19. **★ 不存在唯一"正确"的模型。** 目标是**预测**时，简单模型（哪怕效应被混杂）就够用且更实用；目标是**解释机制**时，才需要控制其他变量。**是科学问题决定模型，不是统计量决定模型。**

20. **数据结构的独立性**：同一群/同一个体的重复观测**并不独立**（狒狒同群多个个体、同一只鸟听 120 首歌）。本周的模型假设观测独立 → **Week 6 的混合效应模型**正是为此而设。

21. **逻辑回归的核心假设是"逻辑函数是正确的函数形式"**，它可能不成立。应对顺序：**转换预测变量 → 换其他连接函数/其他 GLM**；深入处理超出本课范围（参考 Fox & Weisberg 2011）。

22. **有序 (ordinal) 响应变量不是数值变量**（如 Likert 量表），应当用 **Wilcoxon 或 Kruskal-Wallis**，而不是当数值处理。

23. **建模判断**：把 signal 这类变量**当分类还是当数值**，取决于**你是否愿意假设效应随该变量线性变化**。芬奇例子中因为训练的是中间长度的颤音，偏好未必线性 → **当分类处理更安全**。

| logistic regression | 逻辑回归 | 数值预测变量 + 二分类响应变量时使用的回归方法，拟合 S 形逻辑曲线 |
| logistic function | 逻辑函数 | $y=1/(1+e^{-z})$，取值恒在 (0,1) 之间的 S 形曲线 |
| sigmoid | S 形曲线 | 逻辑函数图形的俗称 |
| generalised linear model (GLM) | 广义线性模型 | 任何带连接函数、把直线映射成某种曲线的回归模型的统称；**报告时必须说明具体是哪一种** |
| link function | 连接函数 | 把线性预测子与响应变量的期望连接起来的函数；逻辑回归的连接函数是 logit |
| inverse link function | 反连接函数 | 由线性预测子换算回概率的函数，即 $1/(1+e^{-z})$ |
| linear predictor | 线性预测子 | $z=\beta_0+\beta_1x_1+\cdots$，即事件的对数优势 |
| logit | 对数优势变换 | $\ln\!\left(\frac{p}{1-p}\right)$，逻辑函数的反函数 |
| odds | 优势 / 赔率 | $p/(1-p)$；"1 比 4"意为正结果每出现 1 次、负结果出现 4 次 |
| odds ratio (OR) | 优势比 | $e^{\beta}$；预测变量每增加 1 个单位，优势乘以的倍数 |
| log odds ratio (LOR) | 对数优势比 | 逻辑回归 `summary()` 中 `Estimate` 一栏报告的效应量，即 $\beta$ 本身 |
| event | 事件 | 被编码为 1 的那个响应类别（通常是研究者关心、想检出的那个状态） |
| indicator variable | 指示变量 | 把二分类变量编码为 0/1 的数值变量，可当数值预测变量使用 |
| dichotomous | 二分的 | 只有两个类别的分类变量 |
| likelihood | 似然 | 给定模型与参数时，观测到某个数据的概率 |
| maximum likelihood | 最大似然 | 逻辑回归的拟合原则：选使观测数据出现概率最大的参数值 |
| Fisher scoring iterations | Fisher 评分迭代次数 | R 求最大似然解所用的迭代次数，出现在 `summary()` 末尾 |
| Wald test | Wald 检验 | `glm()` 计算 p 值所用的检验；问"若真无关系，观测到这么大效应量的概率是多少" |
| likelihood ratio test | 似然比检验 | 另一种求 p 值的方法：比较有/无该预测变量时响应数据的似然。结论通常与 Wald 检验一致，但**精确 p 值不同** |
| z value | z 值 | `Estimate / Std. Error`，Wald 检验的检验统计量 |
| AIC (Akaike's Information Criterion) | 赤池信息量准则 | 按参数个数加权的模型似然度量；**越低越好**；已知有过拟合倾向 |
| backward selection | 向后选择 | 从全模型出发逐步剔除无用预测变量的模型选择策略 |
| overfit | 过拟合 | 模型纳入了实际上不影响响应变量的预测变量 |
| ANCOVA (Analysis of Covariance) | 协方差分析 | 同一模型中同时包含数值型与分类型预测变量 |
| baseline (level) | 基线水平 | R 为分类预测变量自动选定的参照类别，其效应被吸收进截距，不出现在输出里 |
| mean centring | 均值中心化 | 把预测变量减去其均值，使 0 代表总体平均，从而让截距可解释；**只改变截距** |
| interaction | 交互作用 | 一个预测变量的效应依赖于另一个预测变量取值的现象 |
| main effect | 主效应 | 单个预测变量自身的效应；模型中有交互项时不能一概而论 |
| effect size | 效应量 | 预测变量对响应变量影响的大小；逻辑回归中即 LOR，**必须带单位** |
| confounding | 混杂 | 一个预测变量的效应中混入了其他相关变量的影响 |
| case | 案例数 | 计算样本量是否充足时用的单位 = min(事件数, 非事件数) |
| dither / jitter | 抖动 | 给绘图点加小随机数，避免大量点重叠在一起 |
| binomial (family) | 二项（分布族） | `glm()` 中指定逻辑回归的参数；之所以叫 binomial 是因为**误差服从二项分布** |
| Poisson regression | 泊松回归 | 另一种 GLM，用于计数型响应变量，连接的是指数曲线 |
| peak shift | 峰移 | 行为学现象：偏好峰值沿远离"学过是坏的"刺激的方向偏移，超出实际学过的"好"刺激 |
| operant conditioning | 操作性条件反射 | 通过奖励与惩罚训练动物形成特定反应的实验方法 |
| ordinal | 有序（变量） | 有次序但非真正数值的分类变量（如 Likert 量表），应用 Wilcoxon / Kruskal-Wallis 分析 |
| working directory | 工作目录 | R 默认读写文件的文件夹 |
| vector | 向量 | 每个元素由单个索引描述的一维数据对象 |
| array | 数组 | 具有多于一维的数据对象，如 `[1,2]` 表示第 1 行第 2 列 |
| package | R 包 | 他人写好并发布的 R 代码集合，用 `install.packages()` 安装、`library()` 加载 |
| annotate | 注解 | 用 `#` 在代码中写说明，R 不执行 `#` 之后的内容 |

## 附：本周完整 R 命令速查

```r
# ---------- 数据导入与检视 ----------
td = read.csv("titanic.csv")     # 导入 csv（本课最重要的命令）
head(td)                          # 看前几行
sum(td$survived == 1)             # 数事件数
sum(td$survived == 0)             # 数非事件数

# ---------- 造指示变量 ----------
male = ifelse(td$sex == "male", 1, 0)

# ---------- 均值中心化 ----------
mc_age = td$age - mean(td$age)

# ---------- 拟合逻辑回归 ----------
m1 = glm(survived ~ age, data = td, family = binomial)          # 简单
m2 = glm(survived ~ sex + class + age, data = td, family = binomial)  # 多重（含 ANCOVA）
m3 = glm(survived ~ class + sex*age, data = td, family = binomial)    # 含交互项
summary(m1)                       # 看结果

# ---------- 由系数算概率 ----------
z = coef(m1)[1] + 20*coef(m1)[2]  # 线性预测子（20 岁）
1/(1 + exp(-z))                   # 反连接函数 → 概率

# ---------- 优势比 ----------
exp(coef(m1))                     # 把所有 LOR 一次性转成 OR

# ---------- 画图 ----------
plot(td$age, td$survived, xlab = "age", ylab = "survived", ylim = c(-.25, 1.25))
curve(1/(1 + exp(-(m1$coefficient[1] + x*m1$coefficient[2]))),
      min(td$age)-.2, max(td$age)+.2, col = "red", add = T)
legend(50, 0.28, legend = c("primary","secondary","postsecondary"),
       col = c("red","blue","green"), lty = 1, cex = 0.9)

# ---------- 上周方法（对照用） ----------
tab = table(td$sex, td$survived)
prop.table(tab, 1)
chisq.test(tab)

# ---------- Q4.3 检验"年长者更可能在头等舱" ----------
summary(aov(age ~ class, data = td))
TukeyHSD(aov(age ~ class, data = td))
kruskal.test(age ~ class, data = td)   # 假设不成立时的非参数替代

# ---------- 工具 ----------
?glm                              # 查帮助
install.packages("dunn.test"); library(dunn.test)
```
