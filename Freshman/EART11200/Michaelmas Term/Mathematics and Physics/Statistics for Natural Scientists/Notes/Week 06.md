## 一、本周主题

本周学习**混合效应模型 (mixed effects model)**，用来处理**观测值彼此不独立 (non-independent observations)** 的数据。

**在全课 6 周中的位置**：

| 周 | 预测变量 | 响应变量 | 方法 |
|---|---|---|---|
| 1–2 | 分类（2 组） | 数值 | t 检验 / Monte Carlo / 置换检验 |
| 3 | 分类（≥3 组） | 数值 | ANOVA |
| 4 | 数值（可含分类） | 数值 | 线性回归 / 多元回归 / ANCOVA |
| 5 | 分类 | 分类 | 卡方检验 |
| 5–6(上周) | 数值 + 分类 | 二分类 | 逻辑回归 (logistic regression, `glm(family=binomial)`) |
| **6（本周）** | 任意 | 任意 | **混合效应模型：拆掉"观测独立"这一共同假设** |

**核心转折**：前五周所有方法——t 检验、ANOVA、回归、卡方、逻辑回归——都建立在同一个共同假设上：**每个观测都是一条全新的、独立的信息**。本周正是要拆掉这个假设。

> 手册开篇原话（转述）：*"到目前为止本手册考虑的所有分析都共享一个共同假设：它们都假设我们研究的观测是独立的。"*

**独立 (independence) 的定义**：知道任何一个观测的值，不会告诉你关于其他观测值的任何信息。

**为什么重要**：如果观测独立，每个观测都是**完全新的一份信息**。如果不独立，一个新观测可能只是在重复其他观测已经告诉你的东西——**信息是冗余的 (redundant)**。这时你实际掌握的信息量比"数据点个数"所暗示的**要少**，检测模式的统计效力 (power) 也比你以为的要低。

**现实性**：除了控制极好的实验室实验，观测完全独立**几乎从不成立**。老师在课堂上特别强调：地球与环境科学的野外数据**几乎总是**非独立的。

## 二、核心概念

### 2.1 非独立数据从哪里来？（识别清单）

数据非独立，本质上是因为观测被**分组 (grouping)**，而组与组之间存在我们无法（或没有）测量的差异。常见来源：

1. **空间分组**：同一样方 (plot)、同一公园、同一滑雪道 (ski slope)、同一林间空地 (forest clearing) 的样本。
2. **社会/生物学分组**：同一狒狒群 (troop)、同一蜂群 (colony)、同一窝、同一家庭。
3. **时间分组**：同一天采样（昆虫数量逐日波动）、同一季节。
4. **个体重复测量**：对同一个体测多次（同一个人多次血压、同一棵树多年生长）。
5. **遗传分组**：同一基因型 (genotype)、同一品系。
6. **仪器/操作者分组**：同一台机器、同一个实验员、同一批试剂。

**统一特征**：组内观测彼此相似的程度 > 组间观测相似的程度。

老师给的直觉例子：
- 同一狒狒群的个体"在彼此的粪便里走来走去"，一只感染了很容易传给全群；不同群可能生活在湿度不同的地方（土里的虫卵存活时间不同），或食性不同（吃水果 vs 吃土里的昆虫）。
- 不同滑雪道可能在**朝向 (aspect)、纬度、年降水量**上不同；也可能在**历史农药使用**这类我们**无法测量**、甚至**想不到要测量**的方面不同。

> **关键**：正是"我们测不到 / 想不到"的那部分组间差异，制造了非独立性。

### 2.2 伪重复 (pseudoreplication)：不处理会怎样？

**定义**：把非独立的观测当作独立观测来计数与分析，从而**高估样本量**、**高估信息量**、**低估 p 值**、**高估置信度**，最终产生**假阳性 (false positive)**。

Practical 7 用一个极端思想实验讲透了：

> 研究一种新青蛙，问雌性是否比雄性大。
> - 测 1 只雌（56 g）+ 1 只雄（48 g）→ 不敢下结论，可能是偶然。
> - 测 100 只雌（全 56 g）+ 100 只雄（全 48 g）→ 非常确信雌性更大。
>
> **效应量相同，但样本量更大 → 结论更强。**
>
> 但反过来：如果我们只是把一个数据集**复制粘贴 (duplicate)** 若干次再分析，一定会得到假阳性。**要增大数据集，必须收集新的、独立的样本。**

**回到蜜蜂**：假设极端情形——蜂群之间微生物组不同，但**同一蜂群内每只蜂的微生物组完全相同**。那么每群采 5 只蜂 = 把"每群采 1 只"的数据复制 5 遍，**没有增加任何新信息**，却让分析以为样本量是 5 倍。真实的 Bridson 数据没这么极端，但只要"同群蜂比异群蜂更相似"，就会**部分**遭受这个问题。

### 2.3 动机实例一：滑雪道种荚（伪重复导致 p 值从 0.33 变成 <0.0001）

**背景**：研究一种草地植物的种荚总质量 (seed pod mass, g) 是否随生长海拔 (altitude, m) 变化。种荚质量可作为植物**繁殖投入能量**的替代指标。数据在三条滑雪道 (slope A / B / C) 上采集，文件 `seed_pods_from_slopes.csv`，列：`alt`（海拔 m）、`slope`（A/B/C）、`seed.mass`（g）。

**朴素线性回归**（代码 7.1–7.2）：

```r
spm.s = read.csv("seed_pods_from_slopes.csv")   # 读入数据，命名 spm.s = seed pod mass from slopes
plot(spm.s$alt, spm.s$seed.mass,                # 散点图：x 为海拔，y 为种荚质量
     xlab = "altitude (m)",                      # x 轴标签
     ylab = "seed pod mass (g)",                 # y 轴标签
     ylim = c(9, 18.5))                          # 固定 y 轴范围，便于与后续图对比

spm.lm = lm(seed.mass ~ alt, data = spm.s)       # 简单线性回归：种荚质量 ~ 海拔
summary(spm.lm)                                  # 查看拟合结果
```

输出（节选）：

```
Coefficients:
              Estimate Std. Error t value Pr(>|t|)
(Intercept) 16.3054075  0.7100756  22.963  < 2e-16 ***
alt         -0.0023405  0.0005377  -4.352 5.54e-05 ***

Residual standard error: 1.58 on 58 degrees of freedom
Multiple R-squared:  0.2462,	Adjusted R-squared:  0.2332
F-statistic: 18.94 on 1 and 58 DF,  p-value: 5.537e-05
```

**读法**：海拔每升高 1 m，种荚总质量下降 0.0023 g；p < 0.0001，看起来"证据非常强"。

**按滑雪道上色**（代码 7.3）：

```r
plot(spm.s$alt, spm.s$seed.mass,
     xlab = "altitude (m)", ylab = "seed pod mass (g)", ylim = c(9, 18.5),
     col = as.factor(spm.s$slope))       # col 接受因子 → R 为每条滑雪道分配一种颜色
legend(1580, 18.65,                      # 前两个参数 = 图例框左上角的坐标 (x, y)
       legend = c("slope A","slope B","slope C"),  # 图例文字
       pch = c(1,1,1),                   # 图例中使用的点型（1 = 空心圆）
       col = c(1,2,3),                   # 图例中使用的颜色（对应 R 默认 1=黑 2=红 3=绿）
       y.intersp = 1)                    # 图例各行的垂直间距
```

**图 7.2 揭示的真相**：三条滑雪道覆盖**不同的海拔区间**，各自的种荚质量也不同；但**在任何一条滑雪道内部，海拔与种荚质量没有明显关系**。整体那条负斜率的线，完全是"低海拔的 A 道种荚重、高海拔的 C 道种荚轻"这个**组间差异**造成的。

#### 用置换检验算出"正确的 p 值"（本章最精彩的推导）

思想实验：假设零假设为真（海拔与种荚质量无关），但三条滑雪道由于**我们无法解释的原因**平均种荚质量不同。那么，仅凭偶然看到至少像观测数据这么强的关系的概率是多少？

推理链：
1. 若组内没有海拔–质量关系，那么**在组内取平均不损失任何信息**。
2. 于是数据实际只有 **3 个数据点**（每条滑雪道一个：平均海拔 + 平均种荚质量）。
3. 观测数据中：最低海拔（A 道）→ 最大种荚质量；最高海拔（C 道）→ 最小种荚质量。
4. 若零假设为真，三条道按平均种荚质量从低到高排序，**6 种排列等可能**：ABC, ACB, BAC, BCA, CAB, CBA。
5. B 道海拔居中。**只要 B 排在中间，关系强度就与观测一样强**：`ABC`（与观测同向）与 `CBA`（反向但强度相同）。
6. 所以 6 种排列中有 **2 种**关系至少一样强 → **正确的 p 值 = 2/6 ≈ 0.33**。

$$p = \frac{2}{6} \approx 0.33$$

**结论对比**：

| 分析方式 | p 值 | 结论 |
|---|---|---|
| 朴素线性回归（把 60 株植物当独立） | < 0.0001 | 强证据 |
| 正确的置换检验（承认只有 3 个独立单元） | 0.33 | **完全没有证据** |

> 这就是伪重复的破坏力：**从"强证据"直接变成"毫无证据"。**

#### 尝试一：ANCOVA（把 slope 作为固定的分类预测变量）

第 6 章学过的 ANCOVA = 含分类预测变量的线性回归。它问的是：**在控制滑雪道效应之后**，种荚质量与海拔是否有关系？

```r
spm.lm.2 = lm(seed.mass ~ alt + slope, data = spm.s)  # 同时放入数值预测变量 alt 与分类预测变量 slope
summary(spm.lm.2)
```

```
Coefficients:
              Estimate Std. Error t value Pr(>|t|)
(Intercept) 14.8904916  0.4494392  33.131  < 2e-16 ***
alt          0.0004512  0.0004075   1.107    0.273
slopeB      -2.2927437  0.3053828  -7.508 5.01e-10 ***

```

**读法（重要）**：
- **slope A 是基线 (baseline)**——它不出现在输出里，其他各道都与它比较。
- `(Intercept)` = 14.89 g：A 道植物的期望种荚质量。
- `slopeB` = −2.29：B 道比 A 道少 2.29 g（即 12.60 g）。
- `slopeC` = −4.06：C 道比 A 道少 4.06 g（即 10.83 g）。

**ANCOVA 在这个例子里给出了正确答案。** 但它并不总是对的 ↓

### 2.4 动机实例二：林间空地（ANCOVA 会"瞎掉"）

**换一个场景**：不研究滑雪道，改研究**林间空地 (forest clearings)**。特点：
- 每块空地**海拔跨度很小**；
- 每块空地**很小**，只含少数几株目标植物；
- 共 15 块空地，60 株植物（文件 `seed_pods_from_clearings.csv`，多一列 `clearing`、一列 `genotype`）。

图 7.3 显示：**跨空地看有明显趋势**（高海拔空地种荚质量低），**空地内部趋势不清楚**（因为空地内海拔差异太小）。

```r
spm.c = read.csv("seed_pods_from_clearings.csv")
spm.lm.3 = lm(seed.mass ~ alt + clearing, data = spm.c)   # ANCOVA：把 clearing 作为固定分类预测变量
summary(spm.lm.3)
```

```
Coefficients:
              Estimate Std. Error t value Pr(>|t|)
(Intercept)  8.2898321  3.6430391   2.276 0.027798 *
alt         -0.0004472  0.0018076  -0.247 0.805738
clearingB    5.6132111  0.2583584  21.726  < 2e-16 ***
clearingC    7.9561769  2.2516398   3.534 0.000978 ***
clearingD    3.6482711  0.2749602  13.268  < 2e-16 ***
clearingE    3.6556416  0.3078719  11.874 2.59e-15 ***
clearingF    5.2155200  0.3029063  17.218  < 2e-16 ***
clearingG    3.9503980  0.5654596   6.986 1.20e-08 ***
...
```

**问题**：空地之间差异极显著，但 `alt` p = 0.806——**看不到明显存在的海拔趋势**！

**原因**：当我们把 `clearing` 作为**固定效应**"控制掉"以后，**空地之间的差异全部被吸收进 clearing 的各个系数里**，只剩下**空地内部**那点微不足道的海拔变异供 `alt` 使用。而空地内海拔跨度很小，检测不到任何东西。

> **一句话**：**ANCOVA 对"组间趋势"是瞎的 (blind to the trend among clearings)。**

#### 尝试二：组内取平均，把每块空地当一个数据点？

也不行，两个问题：
1. **丢信息**：如果组内确实存在趋势，那些趋势含有信息，取平均就丢掉了。
2. **丢权重**：每块空地的植株数不同。平均值只是真值的**估计**，基于更多数据点的估计更准确，**理应在回归中占更大权重**。只用平均值，这个权重信息就没了。

> **结论**：**前面学过的所有方法都不适合这类数据。**

### 2.5 固定效应 vs 随机效应（本章第一大核心难点）

#### 定义与判据

| | **固定效应 (fixed effect)** | **随机效应 (random effect)** |
|---|---|---|
| 我们做什么 | **估计一个具体的数值** $\beta$ | **不估计具体数值**，只假设它们来自某个分布，估计该分布的**方差** $\sigma^2$ |
| 输出在哪 | Fixed effects 表（Estimate / Std. Error / t / p） | Random effects 表（Variance / Std.Dev.） |
| 我们关心什么 | 这个预测变量**对总体的效应**是什么 | 组间**有多少变异**，而非**哪个组是什么样** |
| 组的地位 | 这些组本身就是研究对象、可穷举 | 这些组只是**从大量可能的组中随机抽到的一小撮** |
| 参数个数 | $k$ 个组要花 $k-1$ 个参数 | **无论多少组，只花 1 个参数**（该方差） |
| 例子 | 海拔、性别、群体大小、处理组 | 滑雪道、林间空地、蜂群 ID、狒狒群、基因型、采样日 |

#### 判断口诀

**问自己**：*"我在意某个具体的组本身吗？如果读者不知道 clearing G 比 clearing A 高 3.95 g，他们损失了什么吗？"*

- 若**在意**（如：处理组 vs 对照组、男 vs 女、一等舱 vs 三等舱）→ **固定效应**。
- 若**不在意**（这些组只是"从成千上万个中随机抽到的 15 个/37 个/62 个"，其身份本身对读者毫无用处）→ **随机效应**。

老师的原话（转写）：

> *"这只是全世界成千上万、也许几万个狒狒群里的 37 个。知道第 4 群的感染概率比第 1 群略高一点，这告诉了我们关于世界的什么新东西？除非我们出于某种原因就是对这几个特定的群感兴趣，否则这个信息对我们几乎毫无用处。"*

#### 随机效应"省参数"的巨大好处

老师在课堂上先演示了把 `troop` 当固定效应会有多糟：

```r
baboons$troop = as.factor(baboons$troop)   # 把 troop 从数字转成因子，否则 R 会当作数值预测变量
mod.ancova = glm(abbreviata ~ group.size + sex + troop,
                 family = binomial, data = baboons)
summary(mod.ancova)
```

结果：**输出表巨长**，37 个群 → 36 个 `troopX` 系数。老师的批评：

1. R 必须**任选一个群做基线**（这里是 troop 1），但**我们凭什么关心 troop 1**？
2. **消耗了大量信息去估计 36 个我们根本不关心的效应量** → **降低统计效力 (power)**。
3. 输出**极难解读**。

> *"要是有这么一种模型，能用**一个参数**就把所有这些变异都解释掉，而不用给每个群单独估一个效应量，那该多好啊。"* → **这就是随机效应模型。**

#### 随机效应的代价与回报

**代价**：模型**不会告诉你每个组各自的效应**。
**回报（关键，务必理解）**：正因为我们**没有**把变异**指派给**各个组，模型**没有假定**"这些变异一定是组造成的、而不是海拔造成的"。所以——

> **如果"一个大的海拔固定效应"比"一个大的组随机效应"更能解释观测数据，模型就会找出海拔效应。**

这正是 ANCOVA 做不到的：ANCOVA 强行把组间差异**全部**归给组，海拔什么也分不到。混合模型让数据自己决定这笔变异该怎么分。

### 2.6 随机截距 vs 随机斜率（本章第二大核心难点）

#### 随机截距 (random intercept) — `(1|group)`

**含义**：**每个组有自己的基线水平**（截距），但**所有组共享同一条斜率**。

- 几何图像：一族**互相平行**的直线，只是上下平移。
- 种荚例子：*"每块空地的植物有不同的期望种荚质量，与其海拔无关。"*
- 狒狒例子：*"每个狒狒群有自己的基线感染概率。"*

#### 随机斜率 (random slope) — `(1 + x|group)`

**含义**：**每个组不但有自己的截距，连某个固定预测变量的效应（斜率）也各不相同**。

- 几何图像：一族**既不平行、也不同高**的直线。
- 种荚例子：*"也许海拔对每个基因型的影响不同。某些基因型适应高海拔，它们的种荚质量–海拔斜率没那么负；如果适应足够强，斜率甚至可能为正。"*
- 狒狒例子（老师课堂扩展）：*"狒狒是有**文化**的。也许在某些群里雄性住在群中央，性别几乎没影响；而在另一些群里雄性被排斥到群外围，性别的影响就大。所以我们能不能让**性别的效应**在不同群之间不同？"*

#### 与"固定效应交互作用"的对照（老师强调的关键区分）

> 如果我们**直接关心各个基因型/各个群的特性**，就应该把 `altitude × genotype` 作为**固定效应的交互作用 (interaction)** 放进模型；
> 如果我们**不关心个别基因型/群**，只想**控制掉**这种斜率差异，就用**随机斜率**。

**同一个科学现象，两种建模选择，取决于你想不想报告具体是哪个组不一样。**

#### 随机效应的交互作用 — `(1|A:B)`

`(1|clearing:genotype)` 表示"**空地 × 基因型这个组合**"的随机截距：即"某些基因型在某些空地长得好，另一些基因型在另一些空地长得好"。冒号 `:` 表示交互作用。

---

### 2.7 方差成分 (variance components) 与组内相关

混合模型把**未被固定效应解释的变异**拆成两块：

$$\text{总未解释变异} = \sigma^2_{\text{group}} + \sigma^2_{\text{residual}}$$

- $\sigma^2_{\text{group}}$：**组间**变异（Random effects 表中该分组因子那一行的 `Variance`）
- $\sigma^2_{\text{residual}}$：**组内个体间**变异（`Residual` 那一行的 `Variance`）

**组解释的变异比例**（即**组内相关系数 ICC**，本课不用这个名字但就是它）：

$$\text{proportion explained by groups} = \frac{\sigma^2_{\text{group}}}{\sigma^2_{\text{group}} + \sigma^2_{\text{residual}}}$$

**单位说明**：若响应变量以 g 为单位，则方差单位为 **g²**（因为变异是通过对偏差平方计算的）。

**极端行为（Practical 7 讲得最清楚）**：
- 若**组间变异大、组内变异小**（如假想中同群蜂全一样）→ 模型**几乎把每个组当成一个数据点**。
- 若**组间变异小、组内变异大**（即组几乎没影响）→ 模型**几乎把每个个体当成独立数据点**。

**混合模型是这两个极端之间的连续插值**——这正是它比"全当独立"和"组内取平均"都好的原因。

## 三、公式与图表

### 3.1 从简单线性回归到混合模型的数学演进

记号约定（沿用手册）：
- $s_i$：第 $i$ 个观测的种荚质量（响应变量，seed pod mass）
- $a_i$：第 $i$ 个观测的海拔（预测变量，altitude）
- $\beta_0$：截距 (intercept)
- $\beta_a$：海拔的效应（回归线的斜率）
- $\varepsilon_i$：第 $i$ 个观测的未解释误差 (residual error)
- $\sigma$：$\varepsilon$ 的标准差

#### (A) 简单线性回归

$$s_i = \beta_0 + \beta_a a_i + \varepsilon_i$$

逐项解释：第 $i$ 个观测的种荚质量 = 某个截距 + 海拔效应 × 该观测的海拔 + 一个每个观测各不相同的未解释误差。

**拟合方式一（最小二乘 least squares）**：求使 $\sum_i \varepsilon_i^2$ 最小的 $\beta_0, \beta_a$ ——这就是第 4 章的"最佳拟合线"。

**拟合方式二（最大似然 maximum likelihood, ML）**：
假设 $\varepsilon_i \sim N(0, \sigma^2)$（线性回归的标准假设：未解释变异服从正态分布）。

手册给的正态密度直觉（重要，用于理解 ML）：
- 抽到 $\sigma$ 的可能性约为抽到 0 的 **60%**；
- 抽到 $2\sigma$ 约为 **13.5%**；
- 抽到 $3\sigma$ 约为 **1%**。

一旦选定 $\beta_0$ 与 $\beta_a$，就确定了一条直线；确定了直线，也就确定了所有 $\varepsilon_i$（它们就是各数据点到直线的距离）。于是可以计算"在这组参数下，恰好观测到我们这份数据"的**似然 (likelihood)**。寻找使似然最大的 $(\beta_0, \beta_a, \sigma)$，即为最大似然拟合。

> **重要事实**：对线性回归，**最大似然拟合与最小二乘给出完全相同的参数值**。

#### (B) ANCOVA（把组作为固定效应）

$$s_i = \beta_0 + \beta_a a_i + \beta_B B_i + \beta_C C_i + \cdots + \beta_N N_i + \beta_O O_i + \varepsilon_i$$

- $B_i$：**指示变量 (indicator)**，当观测 $i$ 来自空地 B 时为 1，否则为 0；$C_i, \dots, O_i$ 同理。
- $\beta_B$：空地 B 相对于**基线空地 A** 的效应；$\beta_C, \dots$ 同理。
- 下标到 **O** 是因为共 15 块空地，O 是字母表第 15 个字母。
- 省略号 `…` 表示被省略的项，它们与前后各项形式相同。

**参数个数**：$\beta_0, \beta_a, \beta_B, \dots, \beta_O$ 共 **16 个**（+ $\sigma$）。可用最小二乘或 ML 拟合，两者结果相同。

#### (C) 混合效应模型（把组作为随机效应）

$$s_i = \beta_0 + \beta_a a_i + \gamma_{c(i)} + \varepsilon_i, \qquad \gamma_A, \gamma_B, \dots, \gamma_O \sim N(0,\ \sigma^2_{\text{clearing}})$$

- $\gamma_{c(i)}$：观测 $i$ 所属空地的随机截距——即**该空地偏离"仅由其海拔所作预测（$\beta_0 + \beta_a a_i$）"的量**。
- **关键**：我们**不去求** $\gamma_A, \gamma_B, \dots$ 的具体值；我们只求使观测数据似然最大的 $(\beta_0,\ \beta_a,\ \sigma,\ \sigma_{\text{clearing}})$ ——**只有 4 个参数**（对比 ANCOVA 的 17 个）。
- $\beta_0, \beta_a$ 称为**固定效应**（要估出确定的数值）；$\gamma_A, \gamma_B, \dots$ 称为**随机效应**（不估值，只假设它们从分布中随机抽取）。
- **固定效应与随机效应同处一个模型 → 故名"混合 (mixed)"效应模型。**
- 实际拟合时需要**对 $\gamma$ 可能取的所有值做积分**，数学"有点丑陋"，但"我们有电脑替我们算"。

#### (D) 多个随机效应

$$s_i = \beta_0 + \beta_a a_i + \gamma_{c(i)} + \eta_{g(i)} + \varepsilon_i$$

其中 $\gamma \sim N(0, \sigma^2_{\text{clearing}})$，$\eta \sim N(0, \sigma^2_{\text{genotype}})$。

#### (E) 随机斜率

$$s_i = \beta_0 + \gamma_{c(i)} + \left(\beta_a + \delta_{g(i)}\right) a_i + \varepsilon_i$$

即：**海拔对每个基因型的效应，从一个均值为 $\beta_a$、标准差为 $\sigma_a$ 的正态分布中抽取**。

- $\beta_a$：**任一未指定基因型**的期望海拔效应（总体平均斜率）。
- $\sigma_a$：**海拔效应在各基因型之间的变异程度**。

手册原话（转述）：*"我们假设每个基因型的海拔效应是从均值为 $\beta_a$、标准差为 $\sigma_a$ 的正态分布中抽取的。"*

### 3.2 R 混合模型公式语法对照表（**必背**）

| R 语法 | 数学含义 | 中文说明 |
|---|---|---|
| `y ~ x` | $y_i = \beta_0 + \beta_x x_i + \varepsilon_i$ | 普通线性回归，仅固定效应 |
| `y ~ x + g` | $+\ \beta_{g}$（每组一个系数） | ANCOVA：组作为**固定**分类预测变量 |
| `y ~ x + (1\|g)` | $+\ \gamma_{g(i)},\ \gamma\sim N(0,\sigma_g^2)$ | **随机截距**：每组有自己的基线水平，斜率共享 |
| `y ~ x + (1\|g1) + (1\|g2)` | $+\ \gamma_{g_1(i)} + \eta_{g_2(i)}$ | **两个交叉的随机截距** |
| `y ~ x + (1\|g1:g2)` | $+\ \zeta_{(g_1,g_2)(i)}$ | 两个分组因子**交互组合**的随机截距（`:` = 交互） |
| `y ~ x + (1 + x\|g)` | $+\ \gamma_{g(i)} + \delta_{g(i)} x_i$ | **随机截距 + 随机斜率**：截距和 $x$ 的效应都随组变化 |
| `y ~ x1 + x2 + x1*x2 + (1\|g)` | 固定效应含交互 | 固定效应交互 + 随机截距 |

**记忆要点**：
- **竖线 `|` 左边**：这个随机效应作用于**什么**（`1` = 截距；`1 + x` = 截距和 x 的斜率）。
- **竖线 `|` 右边**：**按哪个分组因子**随机变化。
- **`(1|g)` 读作**："allow the intercept to vary randomly by g"。
- **`(1 + x|g)` 读作**："allow both the intercept and the slope of x to vary randomly by g"。

**逐栏解读**：

| 区块 / 栏 | 含义 |
|---|---|
| `fit by REML` | 用**受限最大似然 (Restricted Maximum Likelihood)** 拟合。REML 对方差成分的估计比普通 ML 更无偏 |
| `t-tests use Satterthwaite's method` | 混合模型的自由度不是整数，用 Satterthwaite 近似算 df（由 `lmerTest` 提供） |
| `Formula:` | 复述模型公式，**务必核对是不是你想要的** |
| `REML criterion at convergence` | 拟合收敛时的 REML 判据值（类似 −2×log 似然），本身没有绝对意义，**用于模型间比较** |
| `Scaled residuals` | 标准化残差的五数概括，用于粗查异常值（极端值远超 ±3 需警惕） |
| **`Random effects` 表** | |
| — `Groups` | 分组因子名（`clearing`），最后一行固定是 `Residual` |
| — `Name` | 该随机效应作用于什么（`(Intercept)` = 随机截距；若是随机斜率，会出现预测变量名那一行） |
| — `Variance` | **方差成分** $\sigma^2$，单位是响应变量单位的平方（此处 g²） |
| — `Std.Dev.` | 上一栏开平方，单位与响应变量相同（此处 g）。**不是标准误！** |
| — `Corr` | （出现随机斜率时）随机截距与随机斜率之间的相关系数 |
| `Number of obs / groups` | 观测总数 60，分组数 15。**核对样本量与分组数的关键行** |
| **`Fixed effects` 表** | 读法与 `lm()` 完全相同 |
| — `Estimate` | 效应量（斜率），带单位。此处 −0.0027887 g/m |
| — `Std. Error` | 该估计的标准误 |
| — `df` | Satterthwaite 近似自由度（**不是整数**，正常现象） |
| — `t value` | Estimate / Std. Error |
| — `Pr(>\|t\|)` | p 值 |
| `Correlation of Fixed Effects` | 各固定效应估计之间的相关（此处 −0.913，因为截距与斜率在共线时高度相关；通常不必解读） |

**本例的实质结论**：
- `alt` 的 Estimate = −0.0027887 → **海拔每升高 1 m，每株植物的种荚总质量期望下降 0.0028 g**（数据中质量以 g、海拔以 m 计）。
- p = 0.00662 → 有强证据表明这个关系是**总体的属性**，而非随机抽样的偶然模式。
- **ANCOVA 看不到的趋势，混合模型看到了！**（对比 `spm.lm.3` 中 `alt` 的 p = 0.806）

**关于截距的重要警告（外推陷阱）**：
截距 16.82 g 是"所有预测变量为 0 时的期望响应"，即**海平面处的期望种荚质量**。但

```r
min(spm.c$alt)     # 求数据中海拔的最小值。（手册代码 7.9 误写为 min(seed.mass$alt)，是笔误）
# [1] 513
```

数据中最低海拔是 **513 m**，**0 在观测范围之外**。**不能确信在观测范围之外模式仍成立，因此不应据此预测海平面植物的种荚质量。**

**方差成分计算**（本例）：

$$\frac{\sigma^2_{\text{clearing}}}{\sigma^2_{\text{clearing}} + \sigma^2_{\text{residual}}} = \frac{5.7021}{5.7021 + 0.0454} = \frac{5.7021}{5.7475} \approx 0.992 = \mathbf{99.2\%}$$

**解读**：未被固定效应解释的变异中，**99.2% 来自空地之间的差异**，只有 0.8% 来自空地内部。空地间差异远大于空地内差异——与图 7.3 的直觉完全一致。

### 4.1 上周（逻辑回归）复习 —— 狒狒寄生虫数据

**数据集**：研究者观察野外狒狒群，收集粪便 (scat)，检查三种**蠕虫寄生虫 (helminth parasites)**：`strungulace`（圆线虫类）、`abbreviata`（转写写作 "riviata"）、`streptophagus`。

| 列 | 含义 |
|---|---|
| `sex` | 狒狒性别（**性二态明显**，野外可直接辨认） |
| `group.size` | 该个体所在群的规模（20–120） |
| `troop` | 群编号（按研究者遇见的顺序**随意编号**） |
| 三列寄生虫 | 0/1 是否感染 |

**关键数据结构**：**近 1,200 只狒狒，但只分布在 37 个群里**；且**每群都不是全采样**，只是子集（例：第 1 群有 21 只，只采到 3 只的粪便）。← **这正是非独立的根源**。

**科学假设**：
- **性别**：两性行为不同、吃的东西不同、活动地点不同；免疫系统也不同（*"许多灵长类中雌性免疫系统相当好，雄性往往不太行"*）。
- **群体大小**：*"这些动物一旦成群，基本上就是在彼此的粪便里走来走去。"* 一只感染就容易在群内扩散；大群更容易有人先感染，然后传开。

#### 交互作用的教学（老师花了很大篇幅，是本课的重要复习）

```r
mod1 = glm(abbreviata ~ group.size + sex + group.size * sex,
           family = binomial, data = baboons)
# 响应变量 abbreviata：0/1 是否感染
# group.size * sex：交互项，问"性别的效应在不同群体大小下是否不同？"
#                    等价地问"群体大小的效应是否取决于性别？"
# family = binomial：把 glm 设定为逻辑回归
summary(mod1)
```

**结果**：交互项 `group.size:sex` 的 **p = 0.436**，远大于 0.05 → **没有任何证据表明两性对群体大小的响应不同**。

**老师的生物学预期**：*"雌性倾向于待在群的中心，雄性常在外围，所以也许群体大小对雄性不重要。"* —— 但数据不支持。

**尽管交互不显著，老师仍然把它画出来**，因为这是个有用的示范：

```r
# 逻辑回归的画线方法：把"线性预测子"塞回"链接函数"
# 链接函数（logistic / inverse logit）：p = 1 / (1 + exp(-LP))
curve(1/(1+exp(-(-0.397094 - 0.101455 + 0.007296*x - 0.04029*x))), add=TRUE)  # 雄性
curve(1/(1+exp(-(-0.397094 + 0.007296*x))), add=TRUE)                          # 雌性
```

- **线性预测子 (linear predictor, LP)** = 括号里那一堆；
- **链接函数** = $\dfrac{1}{1+e^{-LP}}$；
- 雄性：截距 −0.397094 + 雄性效应 −0.101455 + 群体大小效应 0.007296×gs + 交互 −0.04029×gs；
- 雌性：只有截距 + 群体大小效应（**雌性是基线**，没有"雄性效应"，也没有交互项）。
- 老师安慰大家：*"如果你没背下这个公式别担心，可以查。我查了好多年，直到它刻进我脑子里。"*

**画出来的两条线不平行** —— 因为模型里有交互项。

> **老师强调的核心教训（易错点）**：
> **模型里有交互项时，主效应 (main effects) 极难解读，因为其他预测变量的效应是"在截距处"测量的。**
> - 性别的效应是在 **group.size = 0** 处测的；
> - 群体大小的效应是在**基线性别（雌性）**处测的。
>
> *"如果我们想笼统地问'有没有群体大小的效应'？在这个模型里，雌雄的答案不同，因为我们强行塞了个交互项进去。如果想笼统地问'有没有性别效应'？在大群里看起来有，但到很小的群时几乎没差别。"*

**去掉交互项后重跑**：

```r
mod2 = glm(abbreviata ~ group.size + sex, family = binomial, data = baboons)
summary(mod2)
```

- 群体大小效应仍显著；
- **性别效应现在清晰显现了**——有交互项时看不到！
- 重画图：两条线**平行**，无论看哪里，**雌性感染率都高于雄性**；两性感染率都随群体大小上升。

> **老师的结论**：*"如果模型里有交互项，而我们没有理由相信这个交互是真实的（如本例），最简单的做法就是**把它拿掉**。"*

#### 如何用模型做预测（老师说"上周有人觉得这里难"）

流程：**先算线性预测子 LP，再塞进链接函数**。

```r
# 定义线性预测子：LP = 截距 + 群体大小效应*gs + 雄性效应*male
LP = function(gs, male) { -0.397094 + 0.00549*gs + (-0.347)*male }

gs   = 20      # 想预测的群体大小
male = 1       # 1 = 雄性；0 = 雌性
1/(1+exp(-LP(gs, male)))    # 塞进链接函数得到感染概率
# 约 0.37 → 群体大小 20 的雄性，感染概率约 37%
```

**老师的自我打脸小插曲（很有教学价值）**：他先目测图上"群体大小 60 的雌性感染率大概 57%"，实际算出来**接近 50%**。*"哦，我差了一点。"* → **说明肉眼读图不可靠，一定要算。**

### 4.2 "样本量到底是多少？"—— 课堂投票与陷阱题

老师展示两张图：上图是 1,200 只狒狒的原始 0/1 散点（加了 **dither / 抖动**，把点错开以免重叠）；下图是**按群×性别取平均的气泡图**（圆圈大小 ∝ 采样个体数）。

然后提问：**这份数据的样本量 (sample size) 是"个体数"还是"群数"？**

- 一位学生答"**群数**"，理由：*"因为圆圈大小不一样，代表你采了多少样本，所以就不能真的是个体数。"*
- 举手投票：两边都有人，多数人没投票。老师又问："没投票的人里，多少是完全不知道？多少是**觉得这是个陷阱题**？"

**老师的答案**：**这确实是个陷阱题——我们其实不知道有多少个数据点。**

推理：
- 如果群间变异**非常大**（例：某些群住得更潮湿，土里虫卵存活更久；或某群主要吃水果，另一群主要吃土里的昆虫），那么**几乎所有关于任一点的信息其实都是关于"群"的** → **有效样本量 ≈ 群数（37）**。
- 如果群**完全没影响**（所有动物都一样，感染概率只取决于群体大小），→ **有效样本量 = 个体数（约 1,200）**。
- **我们不知道是哪一种，至少从图上看不出来。** → **所以我们需要一种能"在控制群的前提下"估计群体大小效应的分析方法。** ← **这就是引出混合模型的动机。**

> **考点提炼**：非独立数据的**有效样本量 (effective sample size)** 介于"组数"和"个体数"之间，具体位置由**方差成分的比例**决定；**混合模型正是在自动确定这个位置。**

### 4.3 `glmer()`：广义线性混合模型（转写独有，手册未涵盖）

**命名解释（老师原话）**：
- `glm` = **g**eneralized **l**inear **m**odel（广义线性模型）
- 后缀 `er` = 因为它有 **r**andom **e**ffect（随机效应）
- 同理 `lmer` = **l**inear **m**ixed-**e**ffects **r**egression

```r
mod.glmer = glmer(abbreviata ~ group.size + sex + (1|troop),
                  family = binomial, data = baboons)
# 与 glm 唯一的区别就是多了 (1|troop)：
# 允许每个 troop 有自己的基线感染概率，且这些基线来自一个正态分布
```

**遇到问题：拟合算法挣扎**。老师解释：

> *"混合效应模型是由算法拟合的，算法必须**搜索参数空间**去找参数值，不能直接算出来。有时候这很难。让它变难的一个因素是**你的预测变量尺度差异很大**——有的从 0 到 100，有的从 0 到 1，算法就会挣扎。"*

本例中：`sex` 只有 0/1，而 `group.size` 从 20 到 120 → **尺度差 100 倍**。

**解决：重新标度 (rescaling) 预测变量**

```r
baboons$gs100 = baboons$group.size / 100
# 创建新预测变量 gs100："一个单位 = 100 只个体"
# 命名带 100 是为了提醒自己这是重新标度过的

mod.glmer2 = glmer(abbreviata ~ gs100 + sex + (1|troop),
                   family = binomial, data = baboons)
summary(mod.glmer2)     # 这次没有警告信息 → 拟合成功
```

**结果对比（老师逐项比较，非常重要）**：

| 参数 | 普通 `glm`（无随机效应） | `glmer`（有 `(1\|troop)`） |
|---|---|---|
| 性别效应 | −0.347 | −0.346（几乎不变） |
| 群体大小效应 | 0.00549（每只） | 0.572（每 100 只）≈ 100 倍，**一致** |
| 群体大小 p 值 | **0.0326** | **0.0446**（**变大，更不确定**） |

> **老师的核心解读**：
> *"我们的预测几乎没变，模型参数也差不多。但 **p 值变了一点**。在新模型里，我们不像以前那么确信了……当我们考虑了群间可能的变异后，我们对群体大小效应的真实性**信心下降了**。它仍然小于 0.05，所以故事没变——如果我们要报告生物学效应，现在跟以前想的没有不同。**但我们的 p 值更准确了。这是对系统真实情况的更好表征。**"*

**老师的坦诚**：*"当你在课上做的时候会更直观一些。而且它可能要等到你做了 20 年才会完全直观。我觉得我花了 20 年。有些人快一些。"*

### 4.4 随机斜率 `(1 + sex|troop)`（转写独有）

**动机（老师的生物学故事）**：
> *"狒狒是有**文化**的。也许在某些群里，雄性住在群的中央，性别几乎没有影响；而在另一些群里，雄性被排斥到群的外围，性别的影响就更大。所以我们能不能允许**性别的效应**在不同群之间不同？"*

```r
mod.glmer3 = glmer(abbreviata ~ gs100 + sex + (1 + sex|troop),
                   family = binomial, data = baboons)
# (1 + sex|troop)：允许 ①基线感染概率 ②性别的效应
#                   两者都在不同 troop 之间变化
summary(mod.glmer3)
```

**结果（差异这次更明显）**：

| 效应 | 加随机斜率前 | 加随机斜率后 |
|---|---|---|
| 群体大小 | p ≈ 0.0446 | p ≈ 0.035（数值上变化不大，"是证据但不是特别强的证据"） |
| **性别** | **p = 0.003**（"很确信"） | **p 接近 0.05 显著性阈值**（"证据弱多了"） |

> **老师的解读（本课最重要的段落之一）**：
> *"之前 p = 0.003，我们可以拿去存银行。现在这个就得多想想了，它是不是真的。这是一个更弱的结果。"*
>
> *"结果变弱的原因是：**我们掌握的信息比把所有观测都当作独立数据点时要少**。因为现在模型把很多变异分配给了群。**实际上，这些群才有点像是数据点。个体上的权重变小了，群上的权重变大了，我们的统计效力就变低了。所以这给了我们一个关于数据中证据强度的、更真实的故事。**"*
>
> 可能的替代解释：*"也许我们只是碰巧选到了一堆雌性感染率高的群，也许这只是偶然。"*

**画图对比**：
- **实线** = 混合效应模型的预测；
- **虚线** = 无随机效应的固定效应模型预测；
- **两者几乎没有差别** → **生物学故事非常相似**；
- **但 p 值有实质性变化**。

> **老师的警告**：
> *"有时候，像这个例子，p 值仍然落在显著性阈值的同一侧；**但有时候它们会完全翻转。你以为显著的会变得不显著；偶尔，你以为不显著的会变得显著。所以考虑这种变异性很重要。如果不做，我们会得出错误的推论——我们会对结果过度自信，得出错误的结论。**"*

### 4.5 用似然比检验判断随机效应是否显著（转写 + Practical 均有）

**问题**：*"我们有多确信这个群解释了数据中的某些东西——即有些变异是附着在群上而不是仅仅附着在个体上？"*

**方法**：拟合两个模型（一个含目标随机效应，一个不含），用 `anova()` 比较。

```r
# 完整模型：含随机截距 + 随机斜率
mod.full   = glmer(abbreviata ~ gs100 + sex + (1 + sex|troop), family = binomial, data = baboons)
# 简化模型：只含随机截距，没有 sex 的随机斜率
mod.reduce = glmer(abbreviata ~ gs100 + sex + (1|troop),        family = binomial, data = baboons)

anova(mod.full, mod.reduce)
# 命令名叫 anova，但实际执行的是"似然比检验 (likelihood ratio test)"
```

**结果**：p = **0.1054** → *"我们并不真的确信性别效应在不同群之间的差异是真实的。"*

> **但老师立刻补上最关键的一句**：
> *"**但我们真的必须考虑它们。而当我们考虑了它们之后，我们的 p 值就变了。所以我们应该报告的正确 p 值，是那个考虑了群间变异后的、更高的 p 值。**"*

> **这一点极其重要，也是本周最容易被误解的地方**：随机效应的 LRT 不显著，**不代表**你可以把随机效应删掉。随机效应的作用是**正确核算不确定性**，不是"筛选变量"。

### 5.1 数据背景：蜜蜂肠道微生物组

**微生物组 (microbiome)**：栖息于某一特定环境的**全部微生物群落**（细菌、真菌、病毒等）。土壤、水中都有；动植物**体表体内**也有。越来越多证据表明**宿主相关微生物组**（皮肤、肠道、肺）对宿主健康至关重要，且**多样性高的微生物组通常对宿主更健康**。

**研究**：Bridson 等 (2022)，英格兰东北部蜜蜂肠道微生物组。目标：理解**控制肠道微生物多样性的因素**——这很重要，因为丰富的肠道菌群可能有助于**维持蜂群健康**。

**数据结构（关键）**：**从 62 个蜂群 (colonies) 中各采 3–5 只蜜蜂，共 286 只**。对每只蜂测序肠道微生物组，重建组成，计算 **Shannon 多样性 (Shannon index)**——一个同时刻画**丰富度 (richness)** 与**均匀度 (evenness)** 的常用群落多样性指标。

**变量表**（文件 `data_from_Bridson_et_al_2022.csv`）：

| 列名 | 层级 | 含义 |
|---|---|---|
| `Shannon.index` | 个体 | **响应变量**：该只蜂肠道微生物组的 Shannon 多样性 |
| `het.ind` | **个体** | 个体杂合度 (individual heterozygosity)——个体**遗传多样性**度量。许多物种中杂合度高的个体适合度更高 |
| `het` | **蜂群** | 蜂群平均杂合度 = 该群所采个体杂合度的均值 → 度量**个体内部**的遗传多样性；越高表示个体拥有越多不同等位基因 |
| `sa` | **蜂群** | 共享等位基因比例 (proportion of shared alleles) → 度量**个体之间**的遗传多样性；**越高表示蜂之间遗传上越相似，即蜂群多样性越低** |
| `l.div.5` | **蜂群** | 蜂群周围 5 km 内的**土地覆盖多样性 (landcover diversity)**：有多少种不同的植被或土地利用类型 |
| `urb` | **蜂群** | 蜂群周围 5 km 内**城市土地覆盖比例**：多少面积已被建筑、道路、铺装转化 |
| `ID` | **蜂群** | **蜂群唯一标识符** ← **这就是随机效应的分组因子** |

> 这些度量都是比例或比例的对数，**无量纲 (unitless)**。

> **注意变量的层级结构**：`het.ind` 是**个体层面**的预测变量（组内变化），而 `het`、`sa`、`l.div.5`、`urb` 都是**蜂群层面**的预测变量（组内恒定，只在组间变化）。这一点决定了它们在混合模型中的行为差异。

### 5.3 Question 2：混合效应模型

#### 为什么 Q1 是"朴素 (naïve)"的

> *"研究者采样了 286 只蜜蜂，但这些蜂只来自 62 个蜂群。蜜蜂在群内紧密共同生活、共享富含微生物的食物来源，所以同群的蜜蜂可能有相似的肠道微生物组。这意味着来自同一蜂群的蜜蜂观测（即研究中的个体数据点）**可能不独立**。"*

**若把蜜蜂当作独立**：**高估信息量 → 低估 p 值 → 高估我们对所研究模式的信心**。

#### 混合模型的直觉表述（Practical 的绝妙定义，值得背）

> **普通线性回归**假设：每个样本有一个期望值，观测值因**只描述该样本的**某种未解释变异而偏离期望。
>
> **混合效应模型**：把响应变量中的未解释变异**在个体与组之间进行划分**。模型假设：每个样本有一个期望值；**每个组的成员因某种"描述该组"的未解释变异而偏离其期望**；然后**每个个体样本再因某种"只属于该样本"的未解释变异而偏离其组的预测**。
>
> - 若**组间变异大、组内个体间变异小**（如假想中同群蜂全一样）→ 模型**几乎把每个组当成一个数据点**。
> - 若**组间变异小、组内个体间变异大**（即几乎没有组效应）→ 模型**几乎把每个个体当成独立的**。

#### Q2.1 拟合第一个混合模型

```r
install.packages("lme4")      # 一次性安装
install.packages("lmerTest")
library(lme4)                 # 每次开 R 都要重新加载
library(lmerTest)

shan.div.lme = lmer(Shannon.index ~ het.ind + (1|ID), data = bees)
# lmer()  : 拟合线性混合效应模型
# 波浪号左边 Shannon.index : 响应变量
# het.ind                  : 固定效应预测变量
# (1|ID)                   : 给每个蜂群一个随机效应（随机截距）；ID 是蜂群唯一标识
#                            模型不去估计每个群的效应，而是假设各群效应从
#                            均值 0、某方差的正态分布中抽取，并估计那个方差
# data = bees              : 到 bees 数据框里找这些变量名
summary(shan.div.lme)
```

**问题**：蜜蜂肠道微生物组的 Shannon 多样性是否随**个体**杂合度变化？
**答案：否 (No)。** `het.ind` 的 **p = 0.371**，没有证据。

#### 读随机效应表 + 计算组解释的变异比例

```
Random effects:
 Groups   Name        Variance Std.Dev.
 ID       (Intercept) 0.05272  0.2296
 Residual             0.13807  0.3716
Number of obs: 286, groups:  ID, 62
```

- `ID` 行的 `Variance` = **分配给组（蜂群）的变异** = 0.05272
- `Residual` 行的 `Variance` = **分配给组内个体的变异** = 0.13807
- `Number of obs: 286, groups: ID, 62` → **286 只蜂、62 个蜂群**，与设计相符

$$\frac{0.05272}{0.05272 + 0.13807} = \frac{0.05272}{0.19079} \approx 0.28$$

→ **蜂群间差异解释了约 28% 的变异。**

#### 检验"组间差异是否显著"：似然比检验

```r
shan.div.lm  = lm(Shannon.index ~ het.ind, data = bees)         # 不含随机效应的模型
anova(shan.div.lme, shan.div.lm)                                 # 似然比检验
# 注意：命令名是 anova()，但做的是 likelihood ratio test（似然比检验）
# 【极重要】必须把【混合模型放在前面】，颠倒顺序会报错！
#   (Practical 原文：'If you switch the order, you will get an error,
#    and you will be very frustrated. (I was!)')
```

输出：

```

Models:
shan.div.lm: Shannon.index ~ het.ind
shan.div.lme: Shannon.index ~ het.ind + (1 | ID)
             npar    AIC    BIC  logLik deviance  Chisq Df Pr(>Chisq)
shan.div.lm     3 339.79 350.75 -166.89   333.79
shan.div.lme    4 314.06 328.69 -153.03   306.06 27.722  1  1.401e-07 ***
```

**逐栏读法**：

| 栏 | 含义 |
|---|---|
| `refitting model(s) with ML (instead of REML)` | **自动提示**：做模型比较时 REML 不适用，R 自动改用 ML 重拟合。**这是正常信息，不是错误** |
| `npar` | 模型参数个数（3 → 4，多的那 1 个就是 $\sigma^2_{ID}$） |
| `AIC` / `BIC` | 信息准则，**越小越好**（339.79 → 314.06，混合模型大幅更优） |
| `logLik` | 对数似然，**越大越好**（−166.89 → −153.03） |
| `deviance` | −2×logLik |
| `Chisq` | 似然比检验统计量 = 27.722 |
| `Df` | 自由度差 = 1（多估了 1 个参数） |
| `Pr(>Chisq)` | **p 值 = 1.401×10⁻⁷** ← **最重要的一栏** |

**解读**：p 极小 → **蜂群之间不太可能仅凭偶然产生这么大的差异** → **有显著证据表明蜂群之间确实存在真实差异**。

#### **规范报告范式（本课重点技能，必背）**

> *"Differences among colonies explained 28% of the variability in Shannon diversity in bee gut microbiomes in our data (p < 0.0001). We found no evidence for an effect of individual heterozygosity on Shannon diversity (p = 0.371)."*

中译：*在我们的数据中，蜂群间差异解释了蜜蜂肠道微生物组 Shannon 多样性 28% 的变异（p < 0.0001）。我们没有发现个体杂合度对 Shannon 多样性有影响的证据（p = 0.371）。*

> **报告模板拆解**：
> 1. **随机效应部分**：`Differences among [组] explained [X]% of the variability in [响应变量] (p = [LRT 的 p 值])`
> 2. **固定效应部分**：`We found [no evidence for / evidence for] an effect of [预测变量] on [响应变量] (β = [效应量], p = [p 值])`
> 3. **p 值写法**：极小时写 `p < 0.0001`，不要写一长串科学计数法。
> 4. **显著时必须给效应量 β**；不显著时可只给 p 值。

#### Q2.2 对其余四个预测变量分别拟合混合模型

```r
lmer(Shannon.index ~ het     + (1|ID), data = bees)
lmer(Shannon.index ~ sa      + (1|ID), data = bees)
lmer(Shannon.index ~ urb     + (1|ID), data = bees)
```

**标准答案**：

> *"The Shannon diversity of bee gut microbiomes decreased as the proportion of shared alleles in the colony increased (β = −0.81, p = 0.0449). **Q1 vs Q2 的对比（本 practical 的核心教学点）**：

| 预测变量 | 朴素 `lm` 的 p | 混合模型 `lmer` 的 p | 变化 |
|---|---|---|---|
| `sa`（共享等位基因） | **0.0056**（β = −0.78） | **0.0449**（β = −0.81） | p **变大约 8 倍**，仍显著 |
| `het.ind` | 0.299 | 0.371 | 变大 |
| `het` | 0.268 | 0.367 | 变大 |
| `urb` | 0.169 | 0.422 | 变大 |
| `l.div.5` | 0.793 | 0.999 | 变大 |
| `sa + urb` 中的 `urb` | 0.0775（边缘显著） | **0.2671**（完全不显著） | **结论质变！** |
| `sa × urb` 交互 | — | 0.929 | 无 |

> **结论**：**几乎所有 p 值都变大了**，因为混合模型不再高估信息量。特别是 `urb`：朴素分析给出"边缘显著的负关系"，混合模型直接把它抹平了——**这就是伪重复制造假阳性的活生生例子**。
> 注意**效应量 β 几乎不变**（−0.78 → −0.81），**变的是 p 值/置信度**——这与老师在课堂上说的完全一致。

#### Q2.3（Challenge）5 个模型的方差比例不同，报告哪一个？

**标准答案思路**：

> *"我们的结果表明蜂群内共享等位基因比例解释了肠道微生物组多样性的部分变异，但我们没有发现其他任何预测变量有效应的证据。因此，我**报告"以共享等位基因比例为预测变量"的那个模型中蜂群所解释的变异**。"*
>
> *"Differences among the colonies explained **26.3%** of the variability in bee gut microbiome diversity (p < 0.0001)."*

计算：

$$\frac{0.04924}{0.04924 + 0.13767} = \frac{0.04924}{0.18691} \approx 0.2634 = 26.3\%$$

> **原则**：**从你最终要报告给读者的那个模型中提取方差成分。** 因为方差比例是"未被**该模型的固定效应**解释的变异"的划分，随固定效应结构变化而变化。

**LRT 判断组间差异是否显著**：

```r
shan.div.lme = lmer(Shannon.index ~ het.ind + (1|ID), data = bees)
shan.div.lm  = lm(  Shannon.index ~ het.ind,          data = bees)
anova(shan.div.lme, shan.div.lm)     # 混合模型在前！
```

> p < 0.05 表示**含随机效应的模型显著更优**，即数据中由蜂群解释的 Shannon 多样性变异**超过了仅凭偶然所能期望的量**。

> **小注**：答案键此处代码用的是 `het.ind` 模型，而报告的 26.3%（0.04924 / 0.13767）对应的是 `sa` 模型。**以文字结论为准**：应报告 `sa` 模型的方差比例。（转写末尾学生也指出答案键有笔误，此处保持警惕。）

## 六、易错点 / 重点难点

### 6.1 何时该用随机效应而不是固定效应

| 情形 | 用固定效应 | 用随机效应 |
|---|---|---|
| 我在意具体哪个组是什么样 | ✅ | ❌ |
| 这些组是从大量可能的组中随机抽的一小撮 | ❌ | ✅ |
| 组数很少（如 2–4 个），且它们本身就是研究对象（处理组/对照组） | ✅ | ❌（组太少估不准方差） |
| 组数很多（如 15、37、62），且只是"抽样单元" | ❌（浪费大量自由度） | ✅ |
| 数据是分层/嵌套/重复测量结构 | ❌ | ✅ |

**核心判据**："**这些组的身份本身，对读者有信息价值吗？**"

### 6.2 ANCOVA 的两个陷阱（务必区分）

1. **ANCOVA 对"组间趋势"是瞎的**：当预测变量的变异主要发生在**组之间**而非组内（如林间空地例、蜜蜂的蜂群层面变量 `sa`/`urb`/`het`/`l.div.5`），把组作为固定效应会**吸干**该预测变量的所有信号。
2. **ANCOVA 浪费大量自由度**：37 个群 → 36 个系数，输出表极长，且**降低统计效力**；R 还必须任选一个组作基线，而这个基线通常毫无意义。

> **但请注意**：在滑雪道例中 ANCOVA 给出了**正确**答案。所以 ANCOVA 并非"总是错"，而是"**在某些数据结构下会瞎掉**"。混合模型是更稳健、更通用的选择。

### 6.3 组内取平均法的两个陷阱

1. **丢失组内趋势的信息**；
2. **丢失各组样本量差异带来的权重信息**（基于更多观测的均值应有更大影响力）。

### 6.4 随机效应的 LRT 不显著 ≠ 可以删掉随机效应

**老师在转写中反复强调**：狒狒例中 `(1+sex|troop)` 的 LRT p = 0.1054，"我们不太确信这些差异是真的"，**但**："**我们真的必须考虑它们。应该报告的正确 p 值，就是那个考虑了这些变异之后的、更高的 p 值。**"

Chapter 7 的"选择随机效应结构"一节给出同一原则：

> - **如果加了不该加的随机效应**：模型会给它一个很小的值，**对固定效应估计几乎没影响，结果依然可靠**。
> - **如果该加而没加**：模型**没有正确处理观测的非独立性，推论可能大错特错**。
>
> → **不确定时，就加上。（宁可多加，不可漏加。）**

> **唯一的重要限制**：**必须能把模型拟合出来才能解读它。** 随机效应太多时 R 可能拟合不出来。这时只能退而求其次用更简单的模型——**或者，更好的做法是去收集更多数据！**

### 6.5 两类常见警告信息（Chapter 7 专节）

**背景**：混合模型用最大似然拟合，参数值**无法精确计算**，只能由算法在参数空间中**搜索**。第 4 章的线性回归零点几秒就能拟合，**复杂的混合模型可能要几分钟**，有时干脆失败。

#### 警告一：奇异拟合 (singular fit)

```
boundary (singular) fit: see ?isSingular
```

**含义**：**数据不足以估计随机效应表中的某些方差**。最常见于**某个方差非常接近 0** 时。

**为什么严重**：**如果随机效应估计错了，固定效应也可能估计错。**

**手册给出的血淋淋证据**（代码 7.12 vs 7.14，同一份数据同一个模型）：

| | 奇异拟合（`alt` 以米计） | 重标度后（`alt.in.km` 以公里计） |
|---|---|---|
| 海拔效应 | **−0.00352 g/m** | **−0.00283 g/m** |
| p 值 | **< 10⁻⁷** | **0.00564** |

> *"如果我们解读了那个奇异拟合的模型，我们会推断出 −0.00352 g/m 的海拔效应和小于 10⁻⁷ 的 p 值。**那将是对数据中真实模式的一个糟糕估计！**"*

**解决方案（按顺序尝试）**：
1. **重新标度预测变量 (rescale)** —— 算法在预测变量的量级"既不太大也不太小"时工作最好。
2. 若重标度无效 → **简化模型**，逐个移除随机效应，直到能准确拟合。

**重标度示例（手册）**：

```r
alt.in.km = spm.c$alt / 1000       # 把海拔从米换成公里
                                    # 原范围 513–2100 → 新范围 0.513–2.1

sm.lmer.5 = lmer(seed.mass ~ alt.in.km + (1|clearing) + (1 + alt.in.km|genotype),
                 data = spm.c)
summary(sm.lmer.5)                 # 这次没有奇异警告，可以放心解读
```

结果：**海拔每升高 1 km，每株期望种荚质量下降 2.83 g**（p = 0.00564）。**要换算回 g/m 给读者，除以 1000 即可**（= −0.00283 g/m）。

> **单位换算是允许且常用的技巧**：*"我们完全可以用公里来测量海拔——这也许是个不太常见的思考海拔的方式，但这样做并没有任何问题。"*

**重标度示例（课堂）**：`baboons$gs100 = baboons$group.size / 100`，把"1 个单位 = 1 只个体"改成"1 个单位 = 100 只个体"，让 `gs100`（0.2–1.2）与 `sex`（0/1）尺度相当。

#### 警告二：不收敛 (failure to converge)

```
Model failed to converge...
```

**含义**：**R 不确信自己找到了使观测数据似然最大的那组参数**，**该拟合不可信**。

**解决方案（按顺序）**：
1. **重新标度预测变量**；
2. **换一个拟合算法**；
3. **让算法跑更长时间**；
4. 查 `?lmerControl` 的文档（调参超出本手册范围）；
5. 仍不行 → **只能退而求其次，拟合更简单的模型**。

```
 Residual             1.602e-01 4.003e-01
```

> **识别技巧**：随机效应表中出现 **`Corr` 为 ±1.00** 或 **方差为 0 / 极小的科学计数法（如 3.372e-11）**，就是奇异拟合的标志。

### 6.6 R 语法与操作陷阱清单

| 陷阱 | 说明 |
|---|---|
| 忘记 `library(lmerTest)` | `lmer()` 输出里**没有 p 值列** |
| `install.packages` vs `library` | `install.packages` **一次性**（装完永久在电脑上）；`library()` **每次重开 R 都要跑** |
| `anova()` 参数顺序 | **混合模型必须放第一个**！`anova(lme, lm)` 正确，`anova(lm, lme)` **报错**（Practical 原文：*"you will be very frustrated. (I was!)"*） |
| `anova()` 名不副实 | 它做的是**似然比检验**，不是 ANOVA |
| `abline()` 不吃混合模型 | `abline(lm.obj)` 可以；混合模型必须手动 `abline(intercept, slope)` |
| 分类变量未转因子 | 若组编号是数字（如 `troop` = 1..37），做固定效应 ANCOVA 前必须 `as.factor()`，否则 R 当数值处理。（作为随机效应 `(1\|troop)` 时 `lmer` 通常能正确处理，但显式转因子更安全） |
| `Std.Dev.` ≠ 标准误 | 随机效应表的 `Std.Dev.` 是方差成分的**标准差**，与固定效应表的 `Std. Error` 完全不同 |
| 截距外推 | 截距是"所有预测变量 = 0"时的期望值。若 0 在数据范围外（如海拔最小值 513 m），**不要解读/预测** |
| `df` 不是整数 | Satterthwaite 近似的正常结果，不是 bug |
| `refitting model(s) with ML` | `anova()` 的正常提示，不是错误 |

### 6.7 有交互项时主效应难解读（上周内容，本周老师重点复习）

- **有交互项时**：其他预测变量的效应是**在截距处**测量的（即另一个变量 = 0 / 基线水平时）。
- 狒狒例：有交互项时 `sex` 的效应是"group.size = 0 时的性别效应"——**而群体大小为 0 的群根本不存在**，所以这个数字没有实际意义，也检测不到显著性。
- **去掉不必要的交互项后**，性别效应立刻变得清晰显著。
- **原则**：**若模型中有交互项，而你没有理由相信这个交互是真实的，最简单的做法就是把它拿掉。**

### 6.8 概念性易混淆点汇总

| 混淆 | 澄清 |
|---|---|
| 随机效应 vs 固定效应交互 | 想报告"具体哪个组不一样" → 固定效应交互；只想控制掉 → 随机斜率 |
| `(1\|g)` vs `(1+x\|g)` | 前者只让**截距**随组变；后者让**截距和 x 的斜率**都随组变 |
| `(1\|A) + (1\|B)` vs `(1\|A:B)` | 前者是**两个独立的**分组因子；后者是它们的**组合**作为一个新的分组因子 |
| "混合模型让 p 值变大" | 不是绝对的。老师明确说过：*"有时候它们会完全翻转——你以为显著的变得不显著；**偶尔，你以为不显著的会变得显著**。"* |
| 混合模型改变了效应量吗 | **一般不会改变多少**（bee 例 −0.78→−0.81；狒狒例 −0.347→−0.346）。**改变的是置信度/ p 值。** |
| REML vs ML | `lmer()` 默认用 **REML** 拟合（对方差成分更无偏）；但**模型比较（LRT）时必须用 ML**，`anova()` 会自动重拟合并提示 |
| 方差比例算的是什么 | **未被固定效应解释的那部分变异**中，组间占多少。不是"总变异"的比例 |

## 七、本周术语表

| 英文 | 中文 | 一句话解释 |
|---|---|---|
| independence | 独立性 | 知道任一观测的值不会告诉你关于其他观测值的任何信息 |
| non-independent data | 非独立数据 | 同组观测彼此相似，信息存在冗余，实际信息量少于数据点个数 |
| pseudoreplication | 伪重复 | 把非独立观测当独立处理，从而高估样本量、低估 p 值、制造假阳性 |
| redundant information | 冗余信息 | 新观测只是重复了其他观测已提供的内容，未增加真实信息 |
| effective sample size | 有效样本量 | 数据实际提供的独立信息量，介于"组数"与"个体数"之间 |
| mixed effects model | 混合效应模型 | 同时含固定效应与随机效应的模型，用于处理非独立数据 |
| fixed effect | 固定效应 | 我们要估计出确定数值的效应（如海拔、性别、群体大小） |
| random effect | 随机效应 | 不估具体值、只假设来自某分布并估其方差的效应（如蜂群、狒狒群、空地） |
| random intercept | 随机截距 | `(1\|g)`：每组有自己的基线水平，但共享同一条斜率 |
| random slope | 随机斜率 | `(1+x\|g)`：某固定预测变量的效应也在组间变化 |
| random effects structure | 随机效应结构 | 模型中包含哪些随机截距/随机斜率的整体设定 |
| variance component | 方差成分 | 随机效应表中的 `Variance`，衡量该层级贡献的变异大小 |
| residual variance | 残差方差 | 组内个体之间未被解释的变异 |
| proportion of variability explained by groups | 组解释的变异比例 | $\sigma^2_{group}/(\sigma^2_{group}+\sigma^2_{residual})$，即组内相关系数 ICC |
| maximum likelihood (ML) | 最大似然 | 寻找使"观测到这份数据"的概率最大的参数值 |
| REML (restricted maximum likelihood) | 受限最大似然 | `lmer()` 的默认拟合法，对方差成分的估计更无偏 |
| likelihood | 似然 | 在给定参数下观测到这份数据的概率 |
| likelihood ratio test (LRT) | 似然比检验 | 比较嵌套模型的检验；R 中用 `anova()` 执行 |
| least squares | 最小二乘 | 通过最小化残差平方和拟合模型；对线性回归与 ML 结果相同 |
| Satterthwaite's method | Satterthwaite 方法 | 混合模型中近似计算自由度的方法，由 `lmerTest` 提供 |
| singular fit | 奇异拟合 | 数据不足以估计某些随机效应方差，方差被压到 0，固定效应也可能出错 |
| convergence failure | 不收敛 | 算法未能确信找到似然最大点，拟合结果不可信 |
| rescaling predictors | 重新标度预测变量 | 通过除以常数把预测变量的量级调整到相近，帮助算法收敛（如 m→km、个体→百个体） |
| ANCOVA | 协方差分析 | 含分类预测变量的线性回归；把组作为**固定**效应，对组间趋势"瞎掉" |
| baseline (reference level) | 基线（参照水平） | 分类预测变量中不出现在输出里、其他各水平与之比较的那个水平 |
| indicator variable | 指示变量 | 取 0/1 表示观测是否属于某个类别的虚拟变量 |
| main effect | 主效应 | 单个预测变量的效应；模型含交互项时它在"截距处"测量，难以解读 |
| interaction | 交互作用 | 一个预测变量的效应取决于另一个预测变量的取值；R 中用 `*` 或 `:` |

| `lmer()` | — | `lme4` 包中拟合**线性**混合效应模型的函数 |

## 附：全课收官一句话

> 前五周教会我们**在观测独立的前提下**如何从数据中提取模式；本周教会我们**当这个前提不成立时**（也就是野外数据的绝大多数情形）该怎么办。混合效应模型改变的往往不是**我们看到了什么**，而是**我们该有多相信自己看到的东西**——而后者，恰恰是统计学存在的理由。
