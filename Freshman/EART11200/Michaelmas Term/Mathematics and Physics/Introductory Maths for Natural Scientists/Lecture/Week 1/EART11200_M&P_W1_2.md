# EART11200: Natural Scientist’s Toolkit

Some basic tools to get you started

# Scientific Notation

A simple way to write very large or very small numbers:

10,000,000,000,000 = 10<sup>13</sup> = 1E13

- 0.000000000001 = 10<sup>-12</sup> = 1E-12

If you are multiplying 2 powers of 10, add the powers (superscript numbers, # after E)

(3 x 10<sup>13</sup> ) x (2 x10<sup>-12</sup> ) = 6 x10<sup>1</sup> = 60

If dividing, subtract the powers: 1E13/1E-12 = 1E25       [13-(-12) = 25]

NB 10<sup>0</sup> = 1

# Law of indices

You have just seen an example of the law of indices (index or power: b<sup>3</sup> )

Indices can be added or subtracted (when numbers are multiplied or divided), so long as the base number (b above) is the same – for scientific notation/prefixes, b is 10.

Indices cannot be combined in this way if the base number changes:

a<sup>2</sup> b<sup>4</sup> cannot be simplified, but

a<sup>2</sup> b<sup>4</sup> x a<sup>5</sup> b<sup>6</sup> c = a<sup>7</sup> b<sup>10</sup> c

## Squares, cubes, roots and indices

Provided the base number is the same there are some further tricks with indices.

(a<sup>3</sup> )<sup>3</sup> = a<sup>3</sup> x a<sup>3</sup> x a<sup>3</sup> = a<sup>9</sup> (multiply)

The square root of a number can be written a<sup>1/2</sup> while a<sup>1/3</sup> is a cube root. These fractional indices are used in just the same way as whole numbers.

Read supporting material (all_maths) if you are unfamiliar with indices, or ask in the practical class.
