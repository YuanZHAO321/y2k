## 一、本周主题

本周是一节 **"科学机制 + 资源管理"双主题**课，外加一个 **Paper of the Week 研讨环节**和一个 **Kahoot 综合测验**。可拆成四块：

### A. 生物多样性与生态系统功能的关系（BEF, Biodiversity–Ecosystem Functioning）
核心问题：**"生物多样性本身是否影响生态系统的运作方式？"**（Does biodiversity itself affect the way ecosystems function?）

讲师的推进逻辑：
1. **为什么要关心生物多样性**——三条理由：
   - (i) 社会不愿看到物种灭绝，物种有**内在价值 (inherent value)**（有些物种的"价值"被赋予得更高——所谓 **enigmatic megafauna**，如狮子、熊猫，吸引旅游与关注）；
   - (ii) 存在**强物种间相互作用 (strong species interactions)** 时，一个物种消失会拖累另一个（兰花–天蛾例子）；
   - (iii) 但真正的科学问题是第三条：多样性本身是否驱动**功能**。
2. **"地上"与"地中"**：我们看到的是 megafauna 和花草树木（life **on** Earth），但支撑一切的是**土壤 (life *in* Earth)**——"没有土壤就没有地球上的生命"。
3. 先定义 **biodiversity**，再定义 **ecosystem functioning**，然后讨论二者的**机制性联系**（生态位分化、拮抗、促进）。
4. 用**实验证据**检验：大尺度（BEF-China、Jena）、小尺度（微宇宙 microcosm）、地上（植物生产力）与地下（菌根真菌）。
5. 强调**关系不总是正向线性的**，且**发表 ≠ 无问题**。

### B. 磷：土壤、食物与水（Phosphorus in soil, food and water）
本节目标（幻灯片 36）：

- 聚焦**农业中的磷**
- 磷在**陆地和水中如何循环**
- **共限制 (co-limitation)** 的概念

讲师给出的对比框架非常重要：
> **氮**是大气中最丰富的气体，我们**不缺氮**，问题是**形态 (form)**——能否被生物利用（因此需要固氮者 nitrogen fixers）。

## 二、核心概念

### 2.1 生物多样性 (Biodiversity)

**定义**：**生命变异的程度 (the degree of variation in life)**。

**关键点：依赖于尺度 (scale-dependent)**。讲师强调是**时间尺度 + 空间尺度**两者。空间尺度上产生三个层级：

| 指标 | 英文 | 定义 | 讲师给的例子 |
|---|---|---|---|
| α 多样性 | alpha diversity | **单个**生境／生态系统**内部**的多样性 | 去附近**一片森林**，测这一片森林里的多样性 |
| β 多样性 | beta diversity | **生态系统之间**的比较——独有物种的数量 | 把 10 英里外**另一片森林**的 α 多样性拿来对比 |
| γ 多样性 | gamma diversity | **一个区域内**（含多个生态系统）的多样性 | 把**英格兰北部**的森林群与**英格兰南部**的森林群比较 |

> 讲师原话："这些很重要，因为它们指明了多样性是在**什么尺度**上被刻画的。" 读论文时会不断遇到这三个词。

**生物多样性的两个成分**（幻灯片 13）：
1. **物种丰富度 (species richness)** = 物种的**数量**（有多少种）
2. **均匀度 (evenness)** = 物种的**相对多度 (relative abundance)**（各种之间是否均衡）

**diversity *sensu stricto*（严格意义上的"多样性"）= 同时包含 richness 和 evenness 的指数**，例如 **Shannon 指数**。

> 讲师的直观解释：如果一个群落里有**一个极端优势种 + 一堆低多度种**，它的多样性指数会**远低于**一个各物种多度都差不多的群落，即使两者物种数一样。微生物学里也大量使用 Shannon 指数，正因为它同时编码了"有多少种"和"各占多少"。
>
> ⚠️ 这是 Kahoot 第 10 题的考点：**"strict sense 的 diversity 定义是 richness 和 relative abundance，而不是物种总数。"**

### 2.2 生物多样性的其他度量维度

**功能类型 (functional type)**：按**相似性状 (traits)** 把生物归类，而不是按分类学。
- 依据可以是：**形态特征 (morphological)**、**化学组成 (chemical composition)**、**与共生体的关联 (association with symbionts)**。
- 粒度从很具体到很宽泛，**由使用者自行定义 (user defined)**。
- 植物例子：**grasses（禾草）、forbs（非禾本草本／杂类草）、sedges（莎草）、heathers（欧石南）**。
- 微生物例子（讲师补充）：**nitrogen fixer（固氮者）** 就是一个基于功能的描述符——它按**对整个群落的功能贡献**来定义，而不是按属名。

**广义生物多样性所涵盖的层级**（总结幻灯片 54）：
> **基因 (genes) → 基因型 (genotypes) → 物种 (species) → 属 (genera) → 功能类型 (functional types)**

### 2.3 性状 (Traits) —— 分类学的功能性替代／补充

**定义**（幻灯片 31）：生物体的**形态学 (morphological)、解剖学 (anatomical)、生理学 (physiological)、生物化学 (biochemical) 与物候学 (phenological)** 特征。

**为什么重要**（讲师原话，非常适合作为答题句）：
> **"Taxonomy is just what something is called; function is what it does. 名字并不告诉你它在生态系统里能干什么，性状才告诉你。"**

- 固氮就是最好例子：负责固氮的生物**分类学上极其分散**，与其纠结它是不是 *Pseudomonas*，不如把它当作群落中的一个**功能性状**。
- 性状方法在**植物**上最成熟，但正越来越多地用于**动物和微生物**。
- 性状常由多项研究测定并汇编成**全球数据库**，代表是 **TRY 植物性状数据库**（幻灯片 32；转写作 "tri plant database"）。

**TRY 数据库示例（一篇 2019 年论文的图）中出现的性状分层**：
- **叶片性状 (leaf traits)**：养分含量（N、P）→ 反映资源策略是 **acquisitive（获取型）还是 conservative（保守型）**；**木质素 (lignin) 含量**（lignin 是让植物"木质化"的物质）。
- **叶片相关的生态过程 (ecological processes)**：**叶凋落物分解速率 (decomposition rate)**。
- **根系性状 (root traits)**：根中元素／组分含量、木质化程度。
- **根系相关生态过程**：**根系分解速率**——讲师强调**根的分解速率可以和叶的完全不同**。
- 意义：这类框架让"给生物赋予功能"这件事**标准化**。

**性状表达 (trait expression)**：讲师特别区分——
> "expression 意味着**真的把这个性状用起来**了；生物**有能力**做某事（有该性状），和它**正在做**（表达该性状）是两回事。"

### 2.4 生态系统功能 (Ecosystem functioning)

**定义**：**对生态系统"表现"的任何度量 (any measure of the performance of an ecosystem)**。

三个关键性质：
1. **取决于个人／立场 (depends on individual perspective)**——你关心什么，什么就是"功能"。
2. 因此**不同生态系统功能之间可能彼此对立 (may oppose each other)**。
3. 例子（幻灯片 16）：**productivity（生产力）、reproduction（繁殖）、leaching of nutrients（养分淋失）、decomposition（分解）、carbon storage（碳储存）**。
   - 讲师点评：**leaching of nutrients 是"负面"功能**的好例子；而 **productivity 与 carbon storage 本质上很相似**（都在问"积累了多少质量／多有生产力"）。

### 2.5 为什么 BEF 之间"应该"存在关系？——三大机制

这是本周**最核心的机制清单**（幻灯片 18），也是 **Kahoot 最后一题**的答案来源。

| 机制 | 英文 | 含义 | 对功能的效应 | 讲师例子 |
|---|---|---|---|---|
| 生态位分化 | **Niche differentiation** | 不同生物有不同**专门化**，共存时整体系统更**高效** | **正向** | 森林中一棵树**浅根**、另一棵**深根**，彼此不竞争，还可能互助 |
| 拮抗 | **Antagonism** | 一方以**牺牲另一方**为代价获益 | **负向** | 竞争、捕食、病原 |
| 促进 | **Facilitation** | 一方**改善**另一方的生存条件 | **正向** | **菌根真菌 (mycorrhizae)** 促进树木和其他植物生长 |

> ⚠️ **Kahoot 第 12 题**：What mechanism best explains biodiversity–ecosystem function relationships? → **niche partitioning of resources（资源的生态位分割）**。

**局部尺度上的重要生态位维度**（幻灯片 19，植物 vs 菌根真菌）：

| 植物 (Plants) 的生态位轴 | 菌根真菌 (Mycorrhizal fungi) 的生态位轴 |
|---|---|
| **光 (light)**——讲师喜欢称植物为 **"light eaters"** | **是否有菌根 / 菌根类型**（并非所有植物都有菌根！） |
| **根深 (rooting depth)** | **宿主植物物种 (host plant species)**——菌根真菌对宿主有特异性 |
| **土壤性质 (pH、养分、水分等)** | **土壤性质 (pH、养分、水分等)** |
| **放牧压力 (grazing pressure)**——取决于是草地还是森林 | **干扰 (disturbance)** |

**耦合逻辑**（讲师展开）：
- 顺境：光不限制 → 根系够深拿到养分 → 菌根再额外供给养分 → 植物受益 → 反过来也**回报菌根真菌**（碳）。
- 逆境 A：菌根受**干扰** → 植物获取养分的能力被削弱。
- 逆境 B：**光竞争过强** → 植物受困 → **直接损害菌根真菌的增殖能力**（因为菌根靠植物的碳）。

### 2.6 地上–地下耦合 (Above-ground / Below-ground linkages)

- **垂直多样性 (vertical diversity)**：地上层与地下层之间的关系（如植物–菌根）。
- **水平多样性 (horizontal diversity)**：**同一层内部**的多样性（地上层内部，或地下层内部）。
- **直接生态联系 (direct linkages)**：菌根真菌给植物输送养分；病原体直接侵袭根系／菌根网络。
- **间接途径 (indirect pathways)**：**枯落物 (detritus) 分解** → 释放养分供植物吸收；**土壤动物 (insects and other creatures)** 移动 → 改变**通气 (aeration)**。
- 地下：**根系与真菌的取食者 (root and fungal grazers)**、**病原体 (pathogens)**。
- 地上：**食草动物 (herbivores)** 取食嫩梢、**叶部真菌病原**。
- 讲师的总结句：**"所有东西都是连通的，即使你看不见它们；想要地上健康，就必须照顾好土壤。"**
- **"Everything on Earth will have some kind of pathogen — except perhaps viruses."**（一句有意思的顺口话，可当作"病原普遍性"的记忆点）

### 2.7 生物多样性的两个经典相互作用案例

**案例 1：兰花–天蛾协同进化 (coevolution)**（幻灯片 6–7）
- 兰花：***Angraecum sesquipedale***（马达加斯加的"大彗星兰"），有极长的**花距 (nectary)**。
- 达尔文原文（幻灯片引）："A whip-like green nectary of astonishing length hangs down beneath the labellum... I found the nectaries **eleven and a half inches long**, with only the lower **inch and a half** filled with very sweet nectar. What can be the use... of a nectary of such disproportional length? **We shall, I think, see that in Madagascar there must be moths with probosces capable of extension to a length of between ten and eleven inches!**"
- **40 年后**（幻灯片 7）：预言的传粉者被发现——***Xanthopan morgani praedicta***（种加词 *praedicta* 即"被预言的"），一种长喙天蛾。
- 讲师的要点：
  - 这是**协同进化 (coevolution)** 的经典案例——生命之树上看似极其疏远的两支，可以**相互塑造彼此的演化**（"我们不知道是谁先谁后"）。
  - **强相互作用下的连锁风险**：如果天蛾濒危 → 能取到花蜜、携带花粉的个体变少 → **兰花随之受威胁**。这正是"物种丧失会拖累其他物种"的具体化。

**案例 2：切叶／培菌蚁与其表皮共生细菌**（幻灯片 8）
- 出处：***Science*, 6 January 2006, Vol. 311, no. 5757, pp. 81–83, DOI: 10.1126/science.1119744**
- 内容：*Cyphomyrmex costatus*、*C. muelleri*、*C. longiscapus* 三种蚂蚁的**前侧板 (propleural plates)** 上覆盖着细菌；SEM/TEM 显示表皮上有大量**凹窝 (foveae / crypts)**，每个凹窝内有**腺细胞 (gland cells) 与导管细胞 (duct cells)** 供养其中的**互利共生细菌 (mutualistic bacteria, Fb)**；*C. longiscapus* 的凹窝几乎布满全身。
- 比例尺：50 μm (A–C)、5 μm (E, G)、0.5 mm (F)。
- ⚠️ **重要更正**：讲师在课堂上说 "这些细菌住在蚂蚁身上……看起来像某种**感染 (infection)**"——**这是口误／简化**。幻灯片图注写明是 **mutualistic bacteria**（蚂蚁演化出**专门的腺体和隐窝来"豢养"**这些细菌，属于典型的**互利共生**，而非感染）。这也正是幻灯片放在 "INTERACTIONS are important" 主题下的原因。

### 2.8 土壤为什么重要（政治与社会维度）

- 引言（幻灯片 3）：**Charles E. Kellogg, USDA Yearbook of Agriculture, 1938**
  > *"Essentially, all life depends on the soil ... There can be no life without soil and no soil without life; they have evolved together."*
- 幻灯片 4：**近十年来对土壤的政治与社会关注显著上升**。引用 **The Rt Hon Michael Gove MP**（时任 Secretary of State for Environment, Food and Rural Affairs, DEFRA）：
  > *"We need to replenish depleted soil, plant trees, support wetlands and peatlands, rid seas and rivers of rubbish, reduce greenhouse gas emissions, cleanse the air of pollutants, develop cleaner, sustainable energy and protect threatened species and habitats."*
- 讲师解读：这段话里**每一项都是一个巨大的问题**，我们正试图用 **SDGs** 集体应对；而这段话的**第一件事就是土壤耗竭 (depleted soils)**，第二件（plant trees）指向**生物多样性不足**。
- 土壤的两条主线：
  1. 直接关系 **Zero Hunger**（消除饥饿）；
  2. 是**巨大的碳源与碳汇 (a massive source, a massive sink of carbon)**——保护土壤碳是**气候减缓 (mitigation)** 的途径之一。
- 讲师补充：地球生命其实一直延伸到**很深的地下 (deep subsurface)**，只是我们与之脱节；本课聚焦"其他一切都依赖的那层土壤"。

### 2.9 Anthropocene 与 Defaunation

- **Anthropocene（人类世）**：人类主导地球的时期，标志包括：
  - **塑料**沉积到从未出现过的地方；
  - 大气 **CO₂** 极快速的大幅上升，与工业过程直接相关。
- 幻灯片 10 的论文（转写为 "the D4 nation in the Anthropocene"）：**"Defaunation in the Anthropocene"**（人类世的动物区系消减），讲师说"大约十年前"的一篇很好的论文（即 Dirzo et al., 2014, *Science*）。
- 图的信息：**操纵实验展示"差异化的动物消减"如何级联**——**移走一个类群，就会对另一个产生负面影响**。

### 2.10 磷 (Phosphorus) —— 核心概念

#### (1) 磷循环 (The phosphorus cycle)（幻灯片 37）
讲师按**颜色**读图，这是判读该类循环图的通用方法：

| 颜色 | 含义 | 具体项 |
|---|---|---|
| **绿色 (green)** | **库／组分 (pools)** | 微生物 (microbial)、植物残体 (plant residue)、腐殖质 (humus) |
| **蓝色 (blue)** | **输入 (inputs)** | 矿质肥料 (mineral fertilizers)、大气沉降 (atmospheric deposition)、植物残体 (plant residues)、动物粪肥与生物固体 (animal manures & biosolids) |
| **红色 (red)** | **损失 (losses)** | **径流与侵蚀 (runoff and erosion)**——化肥的**很大一部分**由此流失；**淋溶 (leaching) 进入地下水**——通常**较次要**；**收获作物 (harvesting)** 直接把磷移出系统 |

> 讲师补充：粪肥之所以是好的天然肥料，正因为它含有**全套构建元素**，包括磷。

#### (2) 磷在土壤中的分布高度**异质 (heterogeneous)**（幻灯片 38）
- **跨大尺度**（不同大洲之间）**和小尺度**（同一国家内部）都不均匀。
- 讲师的政策含义："我们在世界各地**并不是从同一起点出发的**。"
- 出处：**Plaza, Zaccone, Sawicka, Méndez, Tarquis, Gascó, Heuvelink, Schuur & Maestre (2018), "Soil resources and element stocks in drylands to face global issues", *Scientific Reports* 8: 13788.**

#### (3) 有机磷 → 无机磷：磷酸酶 (Phosphatases)（幻灯片 39）
- **磷酸酶 = 一"家族"不同的酶**，催化**不同形态有机磷的矿化 (mineralisation)**。
- 子类按被作用基团的**化学结构**命名：**phosphomonoesterases（磷酸单酯酶）**、**phosphodiesterases（磷酸二酯酶）**。
- **由植物、微生物、动物共同产生**——是"相当普适的有机磷系统"。
- 讲师的命名规律提示（呼应前几周的 nitrogenase）：**"-ase" 后缀通常表示酶，而且名字本身通常提示它干什么。**
- 课上给的具体反应（转写口语）：**hexaphosphate**（六个磷酸基团挂在一个六碳环上——即**肌醇六磷酸 inositol hexakisphosphate / 植酸 phytic acid, IP6**）→ 被磷酸酶催化、**脱去一个磷酸基团** → 得到 **pentaphosphate（肌醇五磷酸 IP5）**。两者都是有机磷，但**作为养分的亲和性／可利用性不同**。

#### (4) 磷酸酶活性与氮浓度相关（幻灯片 40）—— 本周关键"跨元素"证据
- 幻灯片标题即结论：**"The activity of the suite of enzymes called 'phosphatases' are related to nitrogen concentrations."**
- 图轴（转写）：x 轴是**氮浓度由低到高**（可提取的**硝酸盐 nitrate** 与**铵 ammonium** 量），y 轴是**磷酸酶活性**——用 **nitrophenol（对硝基苯酚 p-nitrophenol, pNP）** 的生成量来指示（这是磷酸酶活性测定的标准显色底物产物）。
- 意义：**磷酸酶并不独立于其他元素**；系统中的氮浓度会影响磷酸酶活性，进而影响有机磷矿化。

#### (5) 调控植物吸磷的诸多因子（幻灯片 41，DOI: 10.1104/pp.111.175232）
讲师逐层拆解这张综述图（**这张图的分层方式本身就是考点式的框架**）：

| 层次 | 内容 |
|---|---|
| **管理／输入端** | **废物再利用 (waste reuse)**（循环路径） vs **化肥输入 (fertilizer P input)** |
| **植物过程 (plant processes)** | 地上部分的一切 |
| **根际过程 (rhizosphere processes)** | 与同一植物根系相关的一切 |
| **土壤性质 (soil properties)** | 看似独立于植物，实则与之耦合 |

- **有机磷动态 (organic P dynamics)**：通过多种途径添加，并经**扩散 (diffusion)、转化 (transformation)、活化 (mobilisation)、吸收 (absorption)、微生物活动 (microbial activities)** 被差异化获取。与氮循环一样，**存在关键的微生物组分**。
  - 影响因子：**空间可及性 (spatial availability)**——磷浓度在土壤空间中的差异；**生物有效性 (bioavailability)**——受**酸化／土壤 pH** 强烈影响。
- **无机磷动态 (inorganic P dynamics)**：对**黏土 (clays) 和铁矿物 (iron minerals)** 有**高亲和力** → **吸附／解吸 (sorption / desorption)** 决定它"在场"还是"出局"；可形成**次生矿物 (secondary minerals)** 把磷直接锁进矿物结构，或来自**原生矿物 (primary minerals)**。
  - ⚠️ 讲师在课上向 Vicky 求证的要点：**无机磷几乎唯一的原生矿物来源是磷灰石 (apatite)**——**没有多少其他原生矿物含磷**，这正是磷"难搞"的根本原因之一。
- **调控过程 (regulation)**：磷的**螯合／固存 (sequestration)** 能力、**一氧化氮／信号分子的信号传导 (signalling)**、植物之间的 **cross-talk**、以及**地上–地下（shoot–root）调控**。

#### (6) "磷是黏的" (Phosphorus is 'sticky')（幻灯片 42）—— 本节最重要的一页
- 通过**离子力**强烈**吸附到颗粒表面**；
- 形成**复杂分子**，其中一些**极难溶或化学上很复杂**；
- 因此**比硝酸盐 (nitrate) 更难被植物吸收**；
- 结果：向土壤施磷会**累积 (build-up)**，一旦停止施用会产生**遗留效应 (legacy effect)**。
- 讲师的实验室轶事（很好的记忆锚点）：黏土含量高的样品里**提取 DNA 很困难，因为 DNA 也会黏在黏土上**；实验室反而**利用磷"更黏"这一点去占据黏土位点**，从而把 DNA 释放出来回收。→ 说明"黏性"有深远的跨领域影响，但对本课的关键是：**植物取用磷相对困难**。

#### (7) 磷供给危机与"没有银弹" (No single 'silver bullet')（幻灯片 43，Cordell et al. 2009）
- 图的读法：横轴时间**从现今到 2100 年（预测）**；堆叠面积表示**磷的来源**：
  - **黑色 = 磷矿石 (phosphate rock，即磷灰石)**
  - **human excreta（人类排泄物）**
  - **manure（动物粪便）**
  - **food waste（食物浪费）**
  - **crop residues（作物残体）**
  - **other**
- 叠加线为**需求 (demand)**，单位 **megatons per year (Mt P/yr)**；**business as usual** 情景给出未来所需量。
- **可降低需求的杠杆（讲师列举）**：
  1. **提高效率 (increased efficiency)**——最有效的单项；
  2. **改变饮食 (changing diets)**；
  3. **农业效率 (agricultural efficiency)**；
  4. **改变施肥方式或肥料类型**。
- **结论句（可直接用于论述题）**：**"就像气候变化一样，通常没有单一出路；很多措施必须协同运作 (operate in concert)。"**

#### (8) 植物到底有多依赖**无机**形态的磷？（幻灯片 44）
- 前提：**土壤含有极其多样的磷形态 (a VAST diversity of different forms of phosphorus)**，且**通常是有机的**。
- 磷在生物学中无处不在：**DNA 骨架的关键组分**，也进入某些**氨基酸／生物分子**。
- **可利用性（labile ↔ recalcitrant）谱系**（由易到难）：

  | 磷形态 | 英文 | 可利用性 |
  |---|---|---|
  | 溶解态（无机）磷酸盐 | dissolved phosphate | **最易利用 (most labile)** |
  | 磷酸单酯 | phosphate **monoesters** | 中等 |
  | 磷酸二酯 | **diesters** | 较难 |
  | 肌醇磷酸类 | **inositol phosphates** | **顽固性有机磷 (refractory / recalcitrant organic P)**，最难利用 |

  > 讲师定义："**refractory 意思就是难以获取**"；"**在几乎所有情况下，溶解态形式都比更复杂／更顽固的形式更 labile（生物可利用）**"。
  > ⚠️ ASR 把 **labile** 反复识别成 "label"，见勘误表。

#### (9) 案例：东南亚超多样热带雨林中的磷生态位分割（幻灯片 45–50）
- 合作者名单（幻灯片 45）：**Xubing Liu、Joe Taylor、David Burslem、Andy Taylor、Thorunn Helgason**。
- 系统特征（幻灯片 46）：**Hyper-diverse: ~150 tree species per hectare**（超高物种丰富度）；**遭受采伐 (logging)：对龙脑香科 dipterocarps 的选择性移除 → 整个生态系统的彻底毁坏 (total destruction)**。
- **核心假说**：不同树种／不同**菌根类型**对**不同形态的磷**有偏好 → **niche partitioning for phosphorus between mycorrhizal type**（"host fungal specificity"：不同的树有不同的菌根真菌，而不同菌根真菌对不同磷形态有不同亲和力）→ **preferential / discriminatory use of soil P forms**。
- **实验设计**（幻灯片 47）：给植物提供**特定磷底物**，比较生长：

  | 处理 | 全称 | 性质 |
  |---|---|---|
  | 无添加磷对照 | No added P（低磷**沙／泥炭混合基质** sand/peat mix） | 本底极低磷 |
  | **SP** | **Sodium orthophosphate（正磷酸钠）** | 简单**无机**磷 |
  | **D6GP** | **D-glucose-6-phosphate（D-葡萄糖-6-磷酸）** | 简单**有机**磷（单酯） |
  | **PASS** | **Phytic acid, sodium salt（植酸钠）** | **顽固性**有机磷 |
  | Mix | SP + D6GP + PASS 混合 | **复杂度与多样性最高** |

  → 设计梯度沿 **"increasing complexity and diversity"** 展开。
- **结果**（幻灯片 48–49）：
  - **植物生物量随"磷形态"与"菌根类型"显著变化**（两个清晰的关联：**磷的形态** × **定殖该植物的菌根真菌类型**）。
  - 幻灯片 49 的**桑基／弦图判读法**：**磷源方块的大小 = ECM 或 AM 植物对该磷源的总利用量**；**楔形／条带的粗细 = 每个物种对该磷源的利用量**。
  - **关键对比**：
    - **ECM（外生菌根）树种 = 冠层优势种 (canopy dominants，如龙脑香科)** → **对顽固性 (recalcitrant) 磷的偏好随之增加**；
    - **AM（丛枝菌根）植物 = 物种丰富的林下层 (species-rich understorey)** → **偏好方向恰好相反**（偏易利用形态）。
  - 讲师的强调句：**"即便在森林的一小片区域里，你在垂直方向上就有多样性——上层植物和它们脚下的植物在磷偏好上完全相反。"** 但趋势本身是**一致 (consistent)** 的。
- **管理含义**：**选择性采伐会移除那些可能对"别的树取不到的那部分磷"的循环至关重要的物种**，从而**对系统内所有树种产生负面影响**——这是"多样性丧失有连锁后果"的具体机制。

#### (10) "通向冠层优势的共生途径" (A symbiotic pathway to canopy dominance)（幻灯片 50）
出处：**D Johnson et al. 2023, *Trends in Plant Science***。这是一个**正反馈环**，建议按环记忆：

```
向共生体大量投入碳 (large investment of carbon to mutualists)
        ↓
广布菌丝 (extensive hyphae) + 有效的共同菌根网络 (effective CMN)
        ↓
获取磷 (access to P) + 病原保护 (pathogen protection)
        ↓
幼苗存活 (seedling survival) + 幼苗生长 (seedling growth)
        ↓
成为冠层优势种 → 有更多碳可投入 ↺（回到起点）
```
- **CMN = common mycorrhizal network（共同菌根网络）**，即所谓 **"wood wide web"**——**菌丝 (hyphae)** 的网络把不同根系连接起来。讲师说这是**相对晚近的知识**，也是当下"蘑菇很流行"的科学背景。
- 讲师的解读：这实际上是**在选择性地偏袒那些对整个生态系统所有成员都有好处的成员**。

#### (11) 共限制 (Co-limitation)（幻灯片 52）—— 必背结论
- 呼应幻灯片 40 的"氮–磷酸酶"联系：
- **"元素循环（C、N、P 等）不是各自孤立运行的 (do not operate independently / none of these things occur in silos)。"**
- **磷的需求 (P demand) 与氮的供给 (N supply) 相关**；
- 植物生长可以**被 N 和 P 共同限制 (co-limited)**，也可以**被其中任一元素单独限制**；
- **推论**：**向系统中添加氮（有意或无意）会改变磷的循环方式**。
- 讲师的应试提示：**"在你能处理任一元素的限制之前，你必须对两者都有详细了解。"**

#### (12) 磷部分的小结（幻灯片 53）
1. 磷只是地球众多元素之一，**但极其重要**（常常是最限制性的那个）；
2. **我们管理磷的方式，是管理其他资源的范例 (exemplar)**；
3. **更高效地使用磷需要"多系统"路径**，需要整合：**土壤科学（初级磷源）、植物科学（不同物种吸磷能力差异）、地球科学（相互作用）、水文学（磷的迁移）、食物链（磷经不同营养级 trophic levels 的循环）、营养师 (dieticians)、技术**……
4. 这些问题**复杂、无明显单一解，但彼此互联**。

### 2.11 全课总结（幻灯片 54）—— 六条，逐条背

1. **广义生物多样性涵盖生命变异的多个方面**：genes, genotypes, species, genera, functional types（**层级是使用者定义的**）。
2. **其中一部分变异可以由"性状 (traits)"有效刻画**（记住：traits = 生物**做什么**，不是它**叫什么**）。
3. **植物功能类型 (plant functional type) 在决定草地中自由生活与共生微生物的功能与多样性上起关键作用。**
4. **这些关系背后的机制仍然理解得很差 (poorly understood)**——复杂系统天然难懂。
5. **多样性与功能之间的关系并不总是正向且线性的 (not always positive and linear)**——**取决于你看的是哪个系统**。地上部分有时看起来很一致，但**从来没有那么简单**。
6. **生物多样性正日益被社会、政治家、甚至经济学家所重视**——呼应第一讲的 **triple planetary crisis**（气候变化 / 污染 / 生物多样性丧失），三者互联，生物多样性丧失理应与其他全球问题获得同等程度的关注。

## 三、公式与图表

### 3.1 Shannon 多样性指数 (Shannon index / Shannon–Wiener index)

幻灯片 13 给出符号定义：**H' = diversity; pᵢ = evenness of species i; s = richness**。标准形式为：

$$H' = -\sum_{i=1}^{s} p_i \ln p_i$$

其中：
- $s$ = **物种丰富度 (species richness)**，群落中的物种数；
- $p_i = \dfrac{n_i}{N}$ = 第 $i$ 个物种的**相对多度 (relative abundance / proportional abundance)**，$n_i$ 为该物种个体数（或读数、序列数），$N=\sum n_i$；
- 对数底数可取 $\ln$（自然对数，单位 nats）、$\log_2$（bits）或 $\log_{10}$——**同一研究内必须统一，跨研究比较时要核对底数**；
- 负号使 $H' \ge 0$（因为 $0<p_i\le 1$ 时 $\ln p_i \le 0$）。

**判读要点（讲师反复强调的直觉）**：
- $H'$ **同时**编码 richness 与 evenness。
- **极端 1**：只有一个物种（$p_1=1$）→ $H'=-1\times\ln 1 = 0$，多样性最低。
- **极端 2**：$s$ 个物种**完全均匀**（每个 $p_i=1/s$）→ $H' = -s\cdot\frac{1}{s}\ln\frac{1}{s} = \ln s$，达到给定 $s$ 下的**最大值**。
- **对比情景（讲师原话的数学化）**：群落 A 有 1 个极端优势种 + 许多稀有种；群落 B 有同样多的物种但多度均衡 → **两者 richness 相同，但 $H'_B \gg H'_A$**。这就是"为什么只报 richness 不够"。

**（补充，非本周幻灯片内容，但同类考点常配套出现）**

- **Pielou 均匀度指数 (evenness)**：把 $H'$ 标准化到 $[0,1]$

$$J' = \frac{H'}{H'_{\max}} = \frac{H'}{\ln s}$$

- **Simpson 指数**：$D = \sum_{i=1}^{s} p_i^2$ 为"随机抽两个个体同种"的概率；常用其变形 **Gini–Simpson 指数** $1-D$ 或**倒数形式** $1/D$（后者是"有效物种数"）：

$$1 - D = 1-\sum_{i=1}^{s}p_i^2 \qquad\text{或}\qquad \frac{1}{D}=\frac{1}{\sum p_i^2}$$

  Simpson 相对**更偏重优势种**，Shannon **相对更敏感于稀有种**。

- **Whittaker β 多样性**（连接课上的 α/β/γ）：

$$\beta = \frac{\gamma}{\bar{\alpha}}$$

  即区域总多样性除以各样点的平均 α 多样性；$\beta=1$ 表示各样点物种组成完全相同，$\beta$ 越大表示**样点间物种更替 (turnover) 越强**。

- **种–面积曲线 (species–area relationship, SAR)**（本周未讲，作为背景补充）：

$$S = cA^{z} \qquad \Longleftrightarrow \qquad \log S = \log c + z\log A$$

  $S$ 为物种数、$A$ 为面积、$z$ 通常在 0.15–0.35 之间。**双对数坐标下为直线，斜率 $z$**。它解释了为什么"栖息地面积减少 → 物种数下降"，也是本周多篇论文把 richness 画在**对数坐标**上的传统由来。

### 3.2 生物多样性效应的加性分解 (Additive partitioning)（Paper of the Week 用到）

讲师在讲 BEF-China 论文时说："他们不只看生物量增加，还试图分解不同的效应：**biodiversity effect（他们记作 NE，是一个加性组分）**、**complementarity effect（互补效应）**、**selection effect（选择效应）**。"这是 **Loreau & Hector (2001)** 的标准分解：

$$\Delta Y \;=\; \underbrace{N \,\overline{\Delta RY}\;\overline{M}}_{\text{Complementarity Effect, CE}} \;+\; \underbrace{N\,\mathrm{cov}\!\left(\Delta RY,\,M\right)}_{\text{Selection Effect, SE}}$$

$$\text{NE (Net Biodiversity Effect)} = \Delta Y = CE + SE$$

其中：
- $\Delta Y = Y_O - Y_E$ = **混种实际产量 − 由单种产量按播种比例加权得到的期望产量**（即"混种比单种多出／少出多少"）；
- $N$ = 混种中的物种数；
- $\Delta RY_i = RY_{O,i} - RY_{E,i}$ = 物种 $i$ 的**相对产量偏差 (deviation from expected relative yield)**；
- $M_i$ = 物种 $i$ 的**单种 (monoculture) 产量**；
- $\overline{\;\cdot\;}$ 表示对物种取平均。

**判读方法**：
- **NE > 0** → 混种整体优于单种平均（生物多样性有正效应）；
- **CE > 0** → **互补／促进**占主导：所有物种在混种中普遍表现好于预期（生态位分化、资源分割、促进作用）；
- **SE > 0** → **选择效应**：**恰好高产的物种在混种中占了优势**（$\Delta RY$ 与 $M$ 正协方差）；**SE < 0** 则表示占优的是低产种；
- ⚠️ 讲师明确指出：图中**有些点落在零线以下**，说明**某些效应是负的**——"**不是一条简单的上升直线，有很多不同的贡献因子，各自的影响方式略有不同**"。

- 图轴：**y = maximum potential species density（最大潜在物种密度）**，**x = maximum standing crop plus litter（最大现存生物量 + 凋落物）**——即"生产力／生物量"轴。
- 形状：**单峰 (hump-shaped)**——中等生产力处物种密度最高，两端（强胁迫 stress 端与强干扰／高生产力端）都低；概念上叠加了 **stress、disturbance、niche differentiation、colonisation by suitable species** 这几个过程。
- ⚠️ 讲师的批判：**"这看上去太整齐了 (overly neat)。"** 回到**实际数据**远没有这么漂亮，**而且形状常常是实验设计方式的产物**；如果你换成看**地下组分**，图可能完全不同。
- **元教训（很可能是简答题）**：**"Just because a piece of work is published, does not mean it has no 'issues'."**（幻灯片 25 标题原句）

**(d) Tilman et al.（幻灯片 26）—— 物种丰富度与生物燃料生产**
- 多联图；除其中一幅外，**x 轴均为植物物种数**，取值 **0, 1, 2, 4, 8, 16**（讲师说这是"很常见"的梯度设置）。
- y 轴是不同指标：**生物量 (biomass)、能量产出 (energy)、土壤 CO₂ 固存 (CO₂ soil sequestration)**——讲师点破：**"它们是不同的度量，但都在指向同一件事：这个生态系统运转得多好。"**
- 分层：**地上 (above-ground)、根系 (root)、土壤 (soil)** 三个部位分别有图。
- 判读结论：**所有情形下都呈现随物种数增加的普遍上升**；重点看 **16 种 vs 1 种**的**倍数差**有多大。
- ⚠️ 幻灯片写 "David Tilman et al **Nature**"；该实验（Cedar Creek 低投入高多样性 LIHD 草地生物能源研究）通常引作 **Tilman, Hill & Lehman, 2006, *Science***。**期刊名以幻灯片为准记忆有风险，考试若涉及请以老师课件为准，但心里知道存在出入。**

**(e) 其他"功能"维度（幻灯片 27）**
- **氮淋失 (nitrogen leaching)**：氮是三大必需养分之一（**N、P、K**）；**淋失越多，生态系统功能越受损**。
- **土壤呼吸 (soil respiration)**：讲师给出的关键结论是——**"是植物群落的组成 (composition)，而不是多样性 (diversity)，在调控草地的土壤呼吸。"** 即**"有哪些种、它们在获取多少养分"可能比"有多少种"更重要**。这是本周对"多样性万能论"的一个重要反例。

**(f) 菌根真菌微宇宙实验（幻灯片 28–29；Wilkinson et al. 2010, *PLoS ONE* 5: e12604）**
- **装置**：**Kilner jar（密封玻璃罐）微宇宙**，罐内置 **NaOH 阱 (sodium hydroxide trap)** 捕集 CO₂ → 测 **CO₂ 外排 (efflux)**；同时测**生物量 (biomass)**。
- **规模**：每个实验 **270 个微宇宙 (microcosms)**，接种 **1、2、4 或 8 个 ECM 物种**以构建**丰富度梯度**。
- **第二个实验（幻灯片 29 备注，是本周最详细的一段方法学描述）**：
  - 沿用同样设计，但检验的是**基因型丰富度 (genotypic richness)** 对**群落呼吸与生产力**的影响；
  - 梯度：**1 至 8 个基因型**，物种为 ***Paxillus obscurosporus***（转写作 "Paxillus obscurus sporus"）；
  - 同时设置**3 种 C:N 比**处理；
  - **结果 1**：基因型丰富度对**生物量生产有显著正效应**——**8 基因型混合体的生物量比单基因型（monoculture）高 50%**；
  - **结果 2**：**基因型丰富度的效应比 4 倍幅度的 C:N 比操纵还要显著**；
  - **警示**：*Paxillus* spp. 已知在**氮充足**时长得好，**其他物种的响应可能不同**（外推需谨慎）；
  - **结果 3**：种内丰富度的效应**由强烈的"个体（基因型身份）效应"支撑，并与 C:N 比存在交互作用 (interaction)**。
- **图的判读（讲师逐一指认）**：x 轴 = **基因型丰富度 (genotypic richness)**（= 遗传变异程度）；左侧 y 轴 = **生物量（实心圆 closed circles）**；右侧 y 轴 = **CO₂ 外排（三角形 triangles）**；均为**纯培养 (pure culture)**。
- **统计**：**richness 的效应显著，p = 0.001**。⚠️ 讲师对 p 值的口头解释是 **"0.1% 的结果可能来自偶然"**——见"易错点"一节的**统计学更正**。
- **结论**：**种内（基因型）多样性本身就能调控真菌的生产力与呼吸**——即 **BEF 关系不止发生在物种层面，也发生在基因型层面**；而且**可以直接在菌根真菌身上测功能，而不必只测它们对植物的影响**。
- **双重意义**：既关乎"怎样让植物长好"，也关乎 **CO₂ 的吸收（碳循环的连带后果）**。

**(g) 菌根系统中的尺度问题（幻灯片 30；Hazard & Johnson 2018, *New Phytologist*）**
- 结论：**菌根系统中的 BEF 关系仍研究不足 (poorly studied)**；**空间尺度是关键因子**。
- 复杂度递增序列（讲师给的层级）：**单条根 (single root) → 单株树系统 (tree system) → 树与树之间的相互作用 (interaction between trees)**；**各层级必须彼此关联地研究**。

**(h) 采伐如何影响热带森林的植物性状（幻灯片 33–34）—— 方差分解条形图**
- 研究问题：**采伐 (logging) 如何影响土壤养分，从而解释热带森林中的性状表达 (trait expression)**。
- 图中的性状分三组：
  1. **养分 (nutrients)**：**Mg, Ca, K, N, P, C**；
  2. **光合 (photosynthesis)**：**叶片同位素示踪 (isotopic tracer) 的摄取程度**、**类胡萝卜素 (carotenoids)**（光合色素）、**比叶面积 (specific leaf area, SLA)**；
  3. **结构 (structure)**：**叶面积 (leaf area)**、**叶干质量 (dry leaf mass)**、**叶干物质含量 (leaf dry matter content, LDMC)**、**分枝多样性 (branch diversity)**、**木质素 (lignin)**、**纤维素 (cellulose) 与半纤维素 (hemicellulose)**。
- **配色即图例（幻灯片 34 标题）**：
  - **棕色 (Brown) = 由各类土壤性质解释的性状变异**；
  - **绿色 (Green) = 由森林类型（即 logged 还是 unlogged）解释的性状变异**；
  - 其余（未着色部分）= **未被解释的变异**。
- **判读示范（讲师逐条读）**：
  - **Ca、C、P** 的变异**主要由 soil PC1（土壤主成分 1，即最大的土壤控制因子）解释**——也就是说这些养分能被植物获取多少，**首要由土壤本身决定**；
  - 而在**第 2、3 幅图中的许多性状**，**绿色（森林类型 logged/unlogged）占比更大**——即**人为干扰**主导。
  - **未解释的部分很大** → 讲师："**这在概念上不那么漂亮，但在这类研究中相当典型——你没法解释一切。**"
- **概念收获**：可以据此区分**"由土壤天生／先定的部分" vs "由更大尺度的系统功能状态（是否被采伐）决定的部分"**。
- **比叶面积的记忆法（讲师原话）**：**"把叶子想成植物上的太阳能板——叶面积越大，能接收的光越多。"**
- **术语**：**lignin（木质素）是让植物木质化的物质，非常难分解**。

**(i) 小尺度 BEF：Thomas Bell 的工作（幻灯片 23）**
- 图示：一棵树（讲师认为像橡树），研究**与该树相关的细菌群落有多么多样**，以及**不同微生物物种如何从这棵树上"分离出来"**。
- 意义：给出**逐树 (tree-by-tree)、个体水平**的信息，与大尺度实验互补。

**(j) 大尺度 BEF 实验平台（幻灯片 22）**
| 平台 | 位置 | 生态系统类型 | 备注 |
|---|---|---|---|
| **BEF-China** | 中国（亚热带） | **林地 / 森林 (woodland)** | 本周 Paper of the Week 的来源；https://bef-china.com |
| **Jena Biodiversity Experiment** | **德国耶拿 (Jena, Thuringia, Germany)** | **草地 (grassland)** | ⚠️ 讲师课上说 "somewhere in Europe, I want to say Austria" —— **是德国，不是奥地利**，见勘误表 |

## 五、Practical 要点

本周**没有独立的实验课 (practical)**，但课堂内有**三个结构化活动**，且**很可能对应课程评估与复习**：

### 5.1 Paper of the Week（本周主活动）

**论文**：BEF-China 大尺度亚热带森林实验，**DOI: 10.1126/science.aat6405**（*Science*）；网站 **https://bef-china.com**。
- 讲师说"大约四五年前发表"；实际为 **2018 年**（Huang et al., *Science* 362: 80–83, *Impacts of species richness on productivity in a large-scale subtropical forest experiment*）。
- 获取途径：Blackboard 讲义下方的 PDF；或 Google Scholar 搜索标题经学校账号访问。

**实验设计（讲师现场讲解的要点）**：

| 项目 | 内容 |
|---|---|
| 类型 | **大尺度、长期野外实验 (large-scale long-term field experiment)**——"巨大的工程，不容易实现，但是理解 BEF 关系在真实尺度上的宝贵机会" |
| 地点 | 中国，位于几个省交界处；地图上比例尺**整条为 2 km**，**两个站点彼此隔离** |
| 站点 | 论文中通篇称为 **Site A** 与 **Site B** |
| 处理 | 种植不同水平的**树种丰富度**：**未种植（对照） / 单种 (monoculture, 1) / 2 / 4 / 8 / 16 / 24 种** |
| 额外处理 | **绿色样点 = 自由演替 (free / natural succession)**——不人为设定物种数 |
| 时间 | 约 **2008–2010 年**开始种植，**监测约 10 年**；论文分析的是 **8 年**期 |
| 响应变量 | **地上碳储量 (above-ground carbon)**；图中以 **stand volume（林分蓄积量）** 作为**碳量的代理指标 (proxy)** |
| 站点差异 | **Site A 的增幅明显大于 Site B**——同样的处理在不同站点响应不同 |

**核心结果（务必记牢）**：
1. **8 年后，16 种混交林积累的碳超过平均单种林 (average monoculture) 的两倍以上 (over twice the amount)**；
2. 且**与两个商业单种林 (commercial monocultures) 的碳量相当**——"commercial 意味着已被优化到高效率"，这条对比使结果具有**实际管理意义**；
3. **物种丰富度**与**功能多样性 (functional diversity)、系统发育多样性 (phylogenetic diversity)** 之间有**很清晰的相关**；
4. **收益递减 (diminishing returns)**：**8 种与 16 种之间差别极小**，但两者**显著高于 2 种和 4 种**——**"在这个系统里，从 4 种跳到 8 种才是变化真正开始的地方"**（这是回答"多少物种才够"的关键判断）；
5. **效应分解**（见 3.2）：**NE（net biodiversity effect，加性组分）= CE（complementarity effect）+ SE（selection effect）**；**有些点落在零线以下（负效应）**，说明**不是一条简单上升的直线**。
6. **照片对比判读**：左图（低多样性）**露出较多背景／地表**；右图（高多样性）**明显更绿、更繁茂**。

## 六、易错点 / 重点难点

### 6.1 概念性易错点

1. **richness ≠ diversity**。**Diversity *sensu stricto* = richness + evenness**（Kahoot 第 10 题就在考这个）。答"多样性就是物种数"会直接失分。
2. **α / β / γ 的区分要用"尺度"而非"数量"来记**：α = 一个生境**内**；β = 生境**之间**的比较／独有物种数；γ = **一个区域**（含多个生态系统）。**同一片森林里数树 = α；两片森林比 = β；南北英格兰比 = γ。**
3. **ecosystem functioning 没有唯一定义**——它是"任何对生态系统表现的度量"，**依赖立场**，且**不同功能可能彼此对立**（如生产力 vs 养分淋失）。考题问"什么是生态系统功能"时，**必须写"depends on perspective"这一层**。
4. **BEF 关系并非总是正向且线性的**。这是本周被反复强调的"反直觉"结论：
   - 幻灯片 27 的反例：**是植物群落的组成 (composition)，而不是多样性 (diversity)，在调控草地土壤呼吸**；
   - BEF-China 出现**收益递减**（8 种与 16 种几乎无差）；
   - 效应分解中**部分点为负**。
5. **taxonomy vs traits**：分类学告诉你"叫什么"，性状告诉你"做什么"。固氮者分类学上极度分散，用"功能性状"描述才有生态意义。
6. **trait ≠ trait expression**：**拥有某性状的能力**与**实际把它表达出来**是两回事（采伐会改变性状表达）。
7. **蚂蚁–细菌是互利共生 (mutualism)，不是感染 (infection)**。讲师课堂口误，幻灯片图注明确写 "mutualistic bacteria"，且蚂蚁演化出**专门的腺体和隐窝**来供养它们。**答题以幻灯片为准。**
8. **Jena 实验在德国，不是奥地利**（讲师口误）；**Jena = 草地实验，BEF-China = 森林实验**——两者常被一起引用但类型不同。
9. **磷没有显著的气态库**；氮的问题是**形态可用性**，磷的问题是**来源稀缺 + 强烈吸附**。**不要把 N 和 P 的限制机制混为一谈。**
10. **"legacy effect"是双向的**：长期施磷会在土壤中累积；**停止施用后仍有残留供给**——这既是"污染遗产"也是"缓冲库"。
11. **ECM 与 AM 的偏好方向相反**（本周最容易记反的一条）：
    - **ECM = 冠层优势树（如龙脑香）→ 对 recalcitrant（顽固性）磷的偏好更高**；
    - **AM = 物种丰富的林下层 → 偏好相反（更依赖易利用形态）**。
12. **元素循环不在"筒仓"里 (not in silos)**：加氮会改变磷的循环（通过磷酸酶活性）。**共限制 (co-limitation)** 是本周必须能解释的术语。
13. **"发表 ≠ 无问题"**，而且**图形的"漂亮"往往是实验设计的产物**（1979 驼峰模型 vs 真实数据）。这是本课程反复出现的**证据强度／科学素养**考点。

### 6.2 统计学更正（重要）

⚠️ 讲师对 p 值的口头解释是：**"p = 0.001 意味着 0.1% 的结果可能来自偶然。"** 这是常见的**通俗化误述**。严格表述应为：

> **p 值 = 在原假设 (null hypothesis) 为真的前提下，观察到当前或更极端结果的概率。**
> p = 0.001 表示：**如果丰富度实际上没有效应，那么只有 0.1% 的概率会观察到这么强（或更强）的结果**——因此我们拒绝原假设。
> 它**不是**"结果有 0.1% 的可能是偶然造成的"，也**不是**"假设为真的概率"。

考试中若要求评价证据强度，用严格表述更安全。

### 6.3 方法论／论述型难点

- **为什么必须跨多个分类群检验 BEF？**（幻灯片 21）
  因为**关系可能不成立于所有类群**：**微生物与植物在形态、多度、生理和繁殖方式上差别巨大**；而且**微生物多样性本来就更难测量（"按定义就看不见"）**。→ 结论：**你研究什么，决定了你怎么研究它**。
- **为什么需要大尺度实验？** 局部结果无法外推，除非在大尺度上检验并验证。
- **空间尺度递进**（菌根系统）：**单根 → 单株 → 树间相互作用**，复杂度递增，且**各层必须彼此关联**。
- **未解释方差很大是正常的**（幻灯片 34）——不要因为"解释不完"就否定研究。
- **"没有银弹" (no silver bullet)** 是本模块贯穿的论述模板：磷危机如此，气候变化亦如此——**需要多种措施协同 (operate in concert)，并跨学科整合**。

## 七、本周术语表

| 英文 | 中文 | 一句话解释 |
|---|---|---|
| Biodiversity | 生物多样性 | 生命变异的程度；**依赖于时间与空间尺度** |
| Alpha (α) diversity | α 多样性 | **单个**生境／生态系统**内部**的多样性 |
| Beta (β) diversity | β 多样性 | **生态系统之间**的多样性比较（独有物种数／物种更替） |
| Gamma (γ) diversity | γ 多样性 | **一个区域内**（含多个生态系统）的总多样性 |
| Species richness | 物种丰富度 | 群落中**物种的数量** |
| Evenness | 均匀度 | 各物种**相对多度**的均衡程度 |
| Relative abundance | 相对多度 | 某物种个体数占总数的比例 $p_i$ |
| Diversity *sensu stricto* | 严格意义的多样性 | **同时**包含 richness 与 evenness 的指数（如 Shannon） |
| Shannon index (H′) | 香农指数 | $H'=-\sum p_i\ln p_i$；单一物种时为 0，均匀分布时达 $\ln s$ |
| Simpson index | 辛普森指数 | $D=\sum p_i^2$，随机抽两个个体同种的概率；更偏重优势种（**补充**） |
| Pielou evenness (J′) | Pielou 均匀度 | $J'=H'/\ln s$，把 $H'$ 标准化到 0–1（**补充**） |
| Species–area relationship | 种–面积关系 | $S=cA^z$，双对数下为直线（**补充**） |
| Functional type | 功能类型 | 按**相似性状**（而非分类学）归类的生物群，如 grasses/forbs/sedges/heathers、nitrogen fixers |
| Traits | 性状 | 生物的形态、解剖、生理、生化与物候特征；**"function is what it does"** |
| Trait expression | 性状表达 | 生物**实际把该性状用起来**（有能力 ≠ 正在做） |
| TRY database | TRY 植物性状数据库 | 汇编全球植物性状测量的公共数据库 |
| Specific leaf area (SLA) | 比叶面积 | 单位干质量的叶面积；讲师类比"太阳能板面积" |
| Leaf dry matter content (LDMC) | 叶干物质含量 | 叶干质量／鲜质量，反映叶的坚韧与资源保守程度 |
| Lignin | 木质素 | 使植物木质化的聚合物，**极难分解** |
| Acquisitive vs conservative | 获取型 vs 保守型 | 植物的两种资源策略（快速获取 vs 节约保存） |
| Ecosystem functioning | 生态系统功能 | 对生态系统**表现**的任何度量；**依赖立场**，不同功能可能对立 |
| Ecosystem services | 生态系统服务 | 人类从生态系统获得的收益（本周仅口头提及，未展开分类） |
| BEF | 生物多样性–生态系统功能（关系） | Biodiversity–Ecosystem Functioning，本周主线 |
| Niche differentiation / partitioning | 生态位分化／分割 | 不同物种专门化于不同资源，使整体更高效——**BEF 的首要机制** |
| Antagonism | 拮抗 | 一方以牺牲另一方为代价获益（竞争、捕食、病原） |
| Facilitation | 促进 | 一方改善另一方的生存条件（如菌根促进植物生长） |
| Complementarity effect (CE) | 互补效应 | 混种中所有物种普遍表现优于预期（由生态位互补／促进驱动） |
| Selection effect (SE) | 选择效应 | 混种优势来自"恰好高产的物种占了上风" |
| Net biodiversity effect (NE) | 净生物多样性效应 | $NE = CE + SE$，混种相对期望值的总增益 |
| Coevolution | 协同进化 | 两个物种相互施加选择压力、共同演化（兰花–天蛾） |
| Mutualism | 互利共生 | 双方均获益的共生关系（蚂蚁–细菌、菌根） |
| Enigmatic megafauna | 有魅力的大型动物 | 熊猫、狮子这类高关注度物种；生态复杂性远不止于此 |
| Defaunation | 动物区系消减 | 人类世中动物（尤其大型动物）的大规模丧失 |
| Anthropocene | 人类世 | 人类主导地球的时期，以塑料沉积与快速 CO₂ 上升为标志 |
| Above-/below-ground linkages | 地上–地下耦合 | 地上与地下组分之间的直接与间接生态联系 |
| Vertical / horizontal diversity | 垂直／水平多样性 | 层与层之间 / 同一层内部的多样性 |
| Detritus | 枯落物／碎屑 | 死亡有机物，分解后释放养分供植物吸收 |
| Mycorrhiza(e) | 菌根 | 根–真菌共生，约 4.5 亿年前演化，自然界普遍存在 |
| ECM (ectomycorrhiza) | 外生菌根 | 菌丝包裹根外并进入细胞间隙；本周案例中为**冠层优势树**，偏好**顽固性磷** |
| AM (arbuscular mycorrhiza) | 丛枝菌根 | 菌丝进入根细胞形成丛枝；本周案例中为**物种丰富的林下层**，偏好相反 |
| Hyphae | 菌丝 | 真菌的丝状结构，可延伸并连接不同根系 |
| CMN (common mycorrhizal network) | 共同菌根网络 | 连接多株植物的菌根菌丝网络，俗称 **"wood wide web"** |
| Dipterocarps | 龙脑香科（树） | 东南亚热带雨林的冠层优势树，**选择性采伐的首要对象** |
| Hyper-diverse | 超多样 | 物种丰富度极高（如 ~150 tree species/ha） |
| Microcosm | 微宇宙 | 受控的小型实验生态系统（本周为 Kilner jar + NaOH 阱） |
| Genotypic richness | 基因型丰富度 | **种内**遗传变异的多样性水平 |
| Intraspecific / interspecific diversity | 种内／种间多样性 | 同一物种内部 / 不同物种之间的多样性 |
| CO₂ efflux | CO₂ 外排 | 呼吸释放的 CO₂ 通量，本周用 NaOH 阱测定 |
| Soil respiration | 土壤呼吸 | 土壤释放 CO₂ 的总过程；本周结论是受**群落组成**而非多样性调控 |
| Nitrogen leaching | 氮淋失 | 氮随水流出系统，损害生态系统功能 |
| Phosphorus (P) | 磷 | 生命必需元素（DNA 骨架等）；常为**限制性养分**；无气态库 |
| Apatite | 磷灰石 | **几乎唯一的主要含磷原生矿物**，磷矿石的来源 |
| Phosphatase | 磷酸酶 | 催化有机磷矿化的一"家族"酶；由植物、微生物、动物产生 |
| Phosphomonoesterase / phosphodiesterase | 磷酸单酯酶／二酯酶 | 按所作用基团结构划分的磷酸酶亚类 |
| p-Nitrophenol (pNP) | 对硝基苯酚 | 磷酸酶活性测定中的显色产物指标 |
| Inositol hexakisphosphate (IP6) / phytic acid | 肌醇六磷酸／植酸 | 六碳环上带六个磷酸基的**顽固性有机磷** |
| Phosphate monoesters / diesters | 磷酸单酯／二酯 | 有机磷的两大结构类别，可利用性介于中间 |
| Labile | 易利用的 | 容易被生物获取的形态（溶解态磷酸盐最 labile） |
| Recalcitrant / refractory | 顽固性的／难获取的 | 难以被生物获取的形态（肌醇磷酸类） |
| Mineralisation | 矿化 | 有机形态转化为无机（可被吸收）形态 |
| Sorption / desorption | 吸附／解吸 | 磷在黏土与铁矿物表面的吸附与释放，决定其"在场"与否 |
| Secondary minerals | 次生矿物 | 风化／沉淀形成的矿物，可把磷锁进结构中 |
| Legacy effect | 遗留效应 | 长期施磷造成土壤累积，停止施用后仍持续影响 |
| Rhizosphere | 根际 | 受根系直接影响的土壤区域 |
| Bioavailability | 生物有效性 | 养分能被生物实际吸收利用的程度（受 pH 等控制） |
| Co-limitation | 共限制 | 生长同时受两种（或以上）元素限制，如 N 与 P |
| Silver bullet | 银弹／万灵药 | 单一彻底的解决方案；本周结论是**磷危机没有银弹** |
| Peak phosphorus / P supply crisis | 磷峰值／磷供给危机 | 磷矿石供给达峰与需求上升的矛盾（Cordell et al. 2009） |
| Biosolids | 生物固体 | 污水处理产生的可农用固体，磷的输入之一 |
| Trophic level | 营养级 | 食物链中的层级；磷经各营养级循环 |
| Stand volume | 林分蓄积量 | 林分木材体积，本周用作**地上碳量的代理指标** |
| Monoculture | 单种栽培／纯林 | 只种一个物种的样地；BEF 实验的比较基准 |
| Commercial monoculture | 商业纯林 | 为效率优化的商业单种林；BEF-China 的对照参照 |
| Natural / free succession | 自然演替 | 不人为设定物种数、任其自然发展的对照处理 |
| Diminishing returns | 收益递减 | 多样性继续增加时功能增益变小（8 种 vs 16 种几乎无差） |
| Functional / phylogenetic diversity | 功能／系统发育多样性 | 基于性状差异 / 亲缘距离度量的多样性 |
| Perturbation | 扰动 | 对系统的冲击；**resilience** 即从扰动中恢复的能力 |
| Resilience | 韧性／恢复力 | 系统**从扰动中恢复**的能力（Kahoot 第 2 题） |
| Triple planetary crisis | 三重行星危机 | 气候变化 + 污染 + **生物多样性丧失** |
| SDGs | 可持续发展目标 | 由**联合国**设立并指导实施（Kahoot 第 1 题） |
