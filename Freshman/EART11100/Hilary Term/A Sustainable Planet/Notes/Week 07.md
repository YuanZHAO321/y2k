## 二、核心概念

### 2.1 气候危机背景（为什么需要 CCUS）

#### 2.1.1 排放—升温的因果链

- **大气 CO₂ 浓度**：自 **1900 年代中期**（工业革命扩散期）起急剧上升；随着各国相继工业化，集体排放量持续攀升。幻灯片曲线覆盖到约 2015 年。
- **国别排放占比**（2021 年数据）：⚠️ 讲者特别提醒——**这是绝对排放量，不是 per capita（人均）**，没有按人口规模归一化；未来 10 年格局仍会变动。
  - 这是本课反复出现的**数据解读陷阱**：绝对排放 vs 人均排放会给出完全不同的责任叙事。
- **升温证据**：全球温升的幅度与频率都在增加。讲者用 **Visual Capitalist** 的「warming stripes 式」图（按月份切分年份、颜色深浅代表温升幅度）说明——**最深的颜色都集中在最近几年**。
- **2024 = warmest year on record（有记录以来最暖年）**，且全球已经**越过 Paris Agreement 试图守住的 1.5 °C** 阈值。

#### 2.1.2 气候变化的影响（不止是温度）

- 森林野火（**Los Angeles fires** 为近例）、热浪、极端降雨、干旱等**极端天气/气候事件**增加。
- ⚠️ **归因难题（重要科学方法论点）**：单一极端事件**很难直接归因于气候变化**，因为「气候」按定义需要**至少 30 年的天气数据**才能谈趋势。但这些事件类型的**风险上升**本来就是气候变化模型的既有预测。
- **地理不均**：英国相对「well buffered（缓冲较好）」，但世界许多地区不是。

#### 2.1.3 The race to Net Zero — 各国承诺时间表

| 目标年 | 国家 |
|---|---|
| **2045** | Germany, Sweden, Denmark |
| **2050** | Australia, Canada, France, Netherlands, New Zealand, Norway, UK, **USA ???????** |
| **2060** | China, Russia |
| **2070** | India |

- 幻灯片上 **USA 后面标了一串问号**——对应讲者说明：Trump 上任后**已退出 Paris Agreement**，而 Paris Agreement 的核心目标之一正是净零与控温，因此美国承诺被打上巨大问号。
- 讲者的批判性评论：有些国家**把净零写入法律 (enshrined in law)**，听起来很严肃，但 **"I would argue they're just words"**（我认为那不过是文字）。不过**方向 (direction of travel)** 是明确的。
- 数据时效性：该图整理于 2024 年底（为一次会议准备），**已因近期政治剧变而过时**。

#### 2.1.4 António Guterres 的核心引言（必记）

> *"Our world needs climate action on all fronts: **everything, everywhere, all at once**."*
> — **António Guterres, UN Secretary-General（联合国秘书长）**

**讲者的解读（这是全讲的价值判断主轴）**：
> "nothing is off the table" — 没有任何方案可以被排除在桌面之外；我们需要各式各样的路径；没有一条是简单的，而且许多路径彼此交互。

这句引言在后文被再次调用，用来为 **Direct Air Capture (DAC)** 这类「单看数字似乎微不足道」的技术辩护：**我们没有资格挑三拣四 (can't be picky and choosy)**。

#### 2.1.5 关键环境科学挑战（幻灯片列点）

- **摆脱温室气体排放过程，尤其是能源**（fossil fuels → renewables 的转型「不是一个容易达成的平衡，且具争议性」）
- **Remember the soil!（别忘了土壤）** — 土壤在碳储存中扮演主要角色
- **New technologies（新技术）** — 例如电池效率的微小改善即可带来巨大差异；讲者本人更关注 **new biotechnologies（新生物技术）**
- **Multifactorial impacts still need to be quantified（多因素影响仍待量化）** — 尤其是 CO₂ 地质封存
- **Nature-based solutions（自然基础解决方案）**

### 2.2 CCUS 的定义与整体架构

#### 2.2.1 定义

**CCUS = Carbon Capture, Utilisation and Storage（碳捕集、利用与封存）**
- 常见的窄义变体：**CCS = Carbon Capture and Storage / Carbon Capture and Sequestration**（不含 Utilisation）。
- 定义（幻灯片总结）："a suite of tools aimed at the **capture, utilisation and permanent storage (disposal!)** of CO₂"。

#### 2.2.2 CCUS 在减排链条中的位置（简化流程）

```
重工业排放源 → [捕集] → (压缩/短期储存/运输 — 本课不涉及) → ┬→ [利用] → 循环经济 (circular economy)
                                                            └→ [封存] → 永久移除出大气
```

**排放源**：不只是能源，还包括 **foundation industries（基础工业）**——**cement（水泥）、steel（钢铁）、ceramics（陶瓷）、glass（玻璃）、chemicals（化工）**。
- 讲者：**cement production 目前是最大贡献者**（"cement production I believe is at the moment the biggest contributor"）。

**Utilisation 与 Storage 的本质区别（考点）**：
- **Utilisation（利用）** = 把捕集的 CO₂ 拿去做产品，减少对化石来源碳前驱物的需求 → 服务于**循环经济**，目标是**net zero（净零）而非 net negative（净负）**。
- **Storage（封存）** = 把 CO₂ **永久移出大气**，是真正的**移除 (removal)**，不是**再利用 (re-using)**。

#### 2.2.3 「相互连结的工具箱」与 Venn 图（ILO 2 的核心图）

讲者是在讲稿完成之后才**回头把各项技术映射到一张三圆 Venn 图**上的，因为她发现「这根本不是三个可以简单归类的盒子」。

```
        ┌─────────── CAPTURE (捕集) ───────────┐
        │  direct air capture (DAC)             │
        │  biocatalytic conversion              │
        │  disruptive technologies              │
        │        ┌──── 重叠区 A ────┐            │
        │        │ afforestation     │           │
        │        │ habitat restoration│          │
        │        │ biochar            │          │
        │        │ enhanced rock      │          │
        │        │   weathering       │          │
        └────────┤ (捕集 + 封存)      ├──────────┘
                 │                    │
   ┌─────────────┤   geological       ├──────────────┐
   │ UTILISATION │     storage        │   STORAGE    │
   │  chemical   │  ┌──────────────┐  │  (地质封存)   │
   │  conversion │  │ EOR (三圆交集)│  │              │
   │  use in food│  │ carbon-negative│ │              │
   │    growth   │  │   concrete     │ │              │
   │  use in     │  └──────────────┘  │              │
   │ fizzy drinks│                    │              │
   └─────────────┴────────────────────┴──────────────┘
```

**要点**：
- **没有清晰边界**：多数情况下一项技术同时落在两到三个圆里。
- 例：**nature-based / landscape-based solutions 既捕集又封存**；**biocatalytic conversion / biological fixation 之所以捕集，正是为了利用**；**EOR 同时是利用和封存**。
- 因此本课**整体地 (holistically)** 讲 CCUS，而不是分成三堂独立的课。

### 2.3 Nature-Based Solutions（自然基础解决方案）— ILO 3

**定义（讲者的传统定义）**：走进自然，在**景观 (landscape) 或生态系统 (ecosystem) 尺度**上，最大化自然系统本身已经在做的事（此处即 CO₂ 的捕集与封存）的潜力。

**讲者的关键论点（这是她本人的研究立场）**：
> **Emerging disruptive biotechnologies——特别是微生物与微生物组 (microbiome) 的 CO₂ 固定与利用——正在重新定义并演化「nature-based solutions」这个概念。**
> 也就是说：nature-based 不必只在生态系统尺度，也可以是**单个微生物或一个微生物群落被封装在生物反应器 (bioreactor) 里**——它们同样在借力自然过程。

**已确立的 nature-based solutions（幻灯片总结列表，考点）**：
1. soil carbon sequestration（土壤碳固存）
2. afforestation / reforestation（造林/再造林）
3. biochar（生物炭）
4. enhanced weathering（强化风化）
5. habitat restoration（栖地复育）

### 2.4 CO₂ Capture（捕集）逐项

#### 2.4.1 Soil carbon sequestration（土壤碳固存）
*参考文献：Ontl & Schulte (2012) Soil Carbon Storage. **Nature Education Knowledge** 3(10):35*

**机制**：
- 大气 CO₂ 经 **photosynthesis（光合作用）** 被吸收，经 **respiration（呼吸作用）** 释放——两者互为逆过程；但因为存在其他一系列过程，系统整体呈**净吸收 (net drawdown)**。
- 路径：CO₂ → 植物地上部 (shoots) 与根 (roots) → 凋落物分解 (decomposition) → 供养**土壤动物 (soil fauna) 与微生物**，包括 **mycorrhizae（菌根真菌）与 rhizobia（固氮根瘤菌）** → **短期以 humus（腐殖质）形式存在** → **长期经成岩作用 (diagenesis) 在地质时间尺度上被封存**。
- 土壤既**直接**储碳（土壤有机质），也**间接**储碳（支撑其上的作物、植物与动植物群落）。

**可提升固碳的农业管理措施（考点，与 SDG 2 Zero Hunger 那一讲呼应）**：

| 措施 | 英文 | 作用机理 |
|---|---|---|
| 减耕/免耕 | reduced tillage / no-till | 减少土壤 CO₂ 逸失 |
| 侵蚀控制 | controlling erosion | 减少碳流失 |
| 添加有机改良剂 | addition of organic amendments | 增加系统碳输入 |
| 覆盖作物 | cover crops | 既减少流失又增加输入 |

#### 2.4.2 Habitat restoration（栖地复育）

**核心图的读法**：不同栖地的碳储量对比，分为**地上 (above-ground，植被与动植物) 与地下 (below-ground，土壤) 两部分**。
- **土壤储碳量不成比例地远大于大气、植物与动物生命的储量。**
- **Wetlands（湿地）是陆域中最大的碳储存栖地**（讲者强调「definitely the largest」）。
- **Boreal forests（北方针叶林）** 次之，且覆盖面积巨大。

**Blue carbon restoration（蓝碳复育）**：滨海环境，因邻近海洋而得名，构成一个**栖地连续体 (continuum)**：
- **mangrove forests（红树林）、salt marshes（盐沼）、kelp（海带/巨藻）**
- 甚至 **whales（鲸）等大型海洋哺乳动物/生物**——集体储存大量碳。

**逻辑关键**：这些栖地**只有在健康状态下才能最大化储碳**——这正是「复育 (restoration)」的核心论证。

**本地案例（Manchester 周边）**：
- **Mellor Moor**（转写作 "mellimore"，位于 **Peak District** 边缘，可望见 **Kinder Scout**）——**moorland（高沼地）是一种湿地**；生长其上的 **sphagnum moss（泥炭藓）** 等苔藓保有巨量碳。
- **University of Manchester 有跨校项目**，致力于让泥炭藓等尽可能「开心」，以保留最多 CO₂。
- 讲者家附近亦有 **afforestation projects（造林项目）**。

#### 2.4.3 Reforestation / Afforestation（再造林 / 造林）
*数据来源：8billiontrees.com*

- **reforestation（再造林）** = 补种最近被移除的树；**afforestation（造林）** = 在原本无林地增加林木覆盖。
- **不同树种储碳量差异巨大**：幻灯片对比了 4 个树种，**Oak（橡树）——英国常见——储存的 CO₂ 远多于其他树种**（Live Oak 图示）。
- **碳预算的教学法（讲者的巧思）**：把国际旅行的碳成本换算成「需要多少棵树」。
  > "sometimes as a student you might think of expenditure in terms of how many pints... if we start thinking in **carbon budgets** then we can start putting **numbers of trees per person** to cover that kind of trip."
  - ⚠️ 讲者立场澄清：**这不是说国际旅行是坏事**（"we all do it"），而是**把成本情境化 (contextualise)**，用「树」作为单位。
- **House plants（室内植物）也有贡献**：幻灯片附有各室内植物的 CO₂ 吸收排名表；**calatheas（竹芋 / prayer plants，祈祷植物）吸收量最高**。
  - 讲者的自嘲式教学点：她家有很多 calathea，但地板是 **oak floor（橡木地板）**——"swings and roundabouts"（有得有失）。核心讯息：**即使是自己非常在地的环境，也可以为 CO₂ 捕集做优化**。

#### 2.4.4 Biochar（生物炭）
*参考文献：Al Masud et al. (2023) **Science of The Total Environment** 904:166813*

**机制（重要，考点）**：
- 取**有机生物质废弃物 (organic biomass waste)**——纸浆 (paper pulp)、厨余 (food waste) 等 → **干燥 (drying)** → **pyrolysis（热解）** → 得到类似木炭 (charcoal) 的物质。
- **本质是「作弊」地加速自然过程**：自然界经由压力与温度、通过成岩作用 (diagenetic processing) 在极长时间尺度上做同样的事，人工热解把它压缩到极短时间。

**产物（circular economy 的关键——讲者在 Q&A 中特别强调）**：
- **biochar（主产物）** + **biogas（生物气）** + **bio-oil（生物油）** + **heat and electricity（热与电）**

**为什么 biochar 能锁碳**：
- **几乎全是碳 (almost entirely carbon)**，且是**非常稳定的碳形式**。
- 目标是让碳**不再具生物可利用性 (no longer widely bio-available)**——对比：进入 **landfill（垃圾掩埋场）** 的废弃物会降解成 **methane（甲烷）而非 CO₂**（甲烷的暖化潜势远高于 CO₂，这是关键的隐含论点）。

**Biochar 的土壤改良附加效益（这是它同时算 nature-based solution 的原因）**：
- 提高**病虫害抗性 (pest and disease resistance)**
- 改善 **tilth**（⚠️ 讲者当场说「I don't know what tilth is but I think it's basically a soil conditioner」——**tilth 的正确定义**：土壤经耕作后的**物理状态/团粒结构与可耕性**，即土壤的「手感/结构好坏」）
- 提高**微生物活性**——因为 biochar 是极佳的微生物**定殖表面 (surface for microbes to colonise)**
- 提高**养分保持 (nutrient retention)** 与**水分保持 (moisture retention)**
- 最终使系统**更耐旱 (more tolerant to drought)**

> **一举两得**：既把 CO₂ 锁在极稳固、不可利用的形式里，又改善了土壤健康。

**课堂 Q&A（Mentimeter 提问）：能否直接从 CO₂ 生产 biochar？**
> **答：大概不行。** 理由链：
> - CO₂ 可以变成**钻石**，因为钻石是**纯碳**且有**可预测的重要结构（tetrahedral 四面体结构）**。
> - 但 **biochar 既不是纯碳，结构也完全不同**——它来自**混杂有机材料的「自下而上 (bottom-up)」精炼**。
> - **天然木炭并非纯碳**，其中含有大量**碳氢化合物 (hydrocarbons)**，而**氢来自那些有机原料**。
> - **CO₂ 分子里没有氢**。因此，要从 CO₂ 做出任何**有机物**，你**必须另外找到加入氢的途径**（这与讲者自己的研究一致——她们给微生物喂 CO₂ 时要**补氢气 H₂**）。
> - 附带结论：这也正是为什么 biochar 生产会顺带产出气体、油等副产物，可纳入**循环经济**。

#### 2.4.5 Enhanced rock weathering（强化岩石风化）
*参考文献：Bach et al. (2019) **Frontiers in Climate** 1: DOI=10.3389/fclim.2019.00007*

**机制**：
- ⚠️ **这一项明确不是生物过程 (definitely not biological)**——是纯化学。
- 利用**天然存在的岩石风化反应**：**硅酸盐风化会消耗 CO₂ 并产生矿物**。
- 人为强化方式：向环境（**陆域或海域皆可**）**播撒硅酸盐矿物岩石 (seeding with silicate mineral rocks)**，尤其是**高比表面积 (high surface area)** 的细粉 → 反应速率大增 → 消耗更多 CO₂。

**双重效益（"killing two birds with one stone"）**：
1. 从大气中**拉下 CO₂**；
2. 产物随径流冲入海洋，引入 **bicarbonate（碳酸氢根 HCO₃⁻）**，**缓冲海洋酸化 (buffer against ocean acidification)**。

**代表性反应式（硅酸盐风化，以硅灰石为例）**：
$$\mathrm{CaSiO_3 + 2CO_2 + H_2O \longrightarrow Ca^{2+} + 2HCO_3^- + SiO_2}$$
后续在海洋中可进一步沉淀为碳酸盐：
$$\mathrm{Ca^{2+} + 2HCO_3^- \longrightarrow CaCO_3\downarrow + CO_2 + H_2O}$$
（⚠️ 注意第二步会释回一半 CO₂，所以**净封存效率取决于最终碳的去向**——这是强化风化核算上的经典争点。）

#### 2.4.6 Direct Air Capture (DAC，直接空气捕集)

⚠️ 讲者定位：**这是本节唯一被她归为「disruptive technology（颠覆性技术）」而非 nature-based 的方案。**

**机制（以 Climeworks 为例）**：
1. **抽入环境空气 (ambient air)**；
2. CO₂ 被**吸附到滤材 (filter) 上**；
3. 滤材**饱和 (saturated)** 后，把 CO₂ 脱附下来；
4. 得到**浓缩 CO₂ (concentrated CO₂)**。

**Climeworks 的两条 CO₂ 去向（重要案例）**：
- **主流：交给隔壁邻居 Carbfix** 注入地下永久处置。⚠️ **Climeworks 是刻意「strategically situated」把厂址选在 Carbfix 旁边的**——这是一个极佳的「捕集与封存必须耦合」的案例。
- **支流：送去温室 (greenhouse)** 做**果蔬的浓缩 CO₂ 施肥栽培**。冰岛遍地都是这种温室，因为有便宜的 **geothermal（地热）** 供暖，浓缩 CO₂ 是额外加成。

**站点**：Climeworks 的 **"Mammoth"** 厂，位于**冰岛**，紧邻一座**地热电厂**，有展览可参观，交通便利。

**批判性评估（考点）**：
- **PR 光鲜**，成功吸引 **Bill Gates** 经由其 **Breakthrough Energy** 基金投资。
- **但从大局看，捕集量在数字上并不算显著 (the numbers don't make it look like a particularly meaningful amount of CO₂)。**
- **讲者的辩护**：回到 Guterres 的 "everything, everywhere, all at once"——**"we can't be picky and choosy about what methods we use"**；只要**可规模化 (scalable)** 且真的能运作，它就是有帮助的。

### 2.5 CO₂ Utilisation（利用）

#### 2.5.1 最重要的一句警告（幻灯片直接引用，务必背）

> *"**CO₂ utilization does not necessarily reduce emissions and does not necessarily deliver a net climate benefit, once indirect and other effects have been accounted for.**"*
> （一旦把间接效应与其他效应计入，CO₂ 利用**未必**减少排放，也**未必**带来净气候效益。）

**讲者的解读**：
- 利用**不像封存那样简单**（"take it from the atmosphere and lock it away"），而是**更细致 (more nuanced)**。
- 真正的价值在于：你用了大气来的 CO₂，就**免去了从油气开采前驱化学品 (precursor chemicals) 的需求**——即**用已经产生的碳，而不是再多产生新的碳**。
- 所以 **utilisation 的目标是 net zero，不是 net negative**。

| 路径 | 说明 | 讲者备注 |
|---|---|---|

| **Fuels（燃料）** | 生物燃料，最典型是 **biodiesel（生物柴油）** | 本讲重点之一 |

#### 2.5.3 Disruptive biotechnologies（颠覆性生物技术）— 讲者的主场

**核心主张**：这些技术**正在重新定义 nature-based solutions**——从生态系统尺度下沉到**微生物 / 微生物组尺度**。

**产业景观**：多家公司，**大多在美国，也有英国本土与欧洲的**，共同目标是**利用微生物代谢把 CO₂ 转化为各种有用产品**。

##### (a) Algae-based（藻类路线）— 最成熟但有硬伤

- 机制：藻类经 **photosynthesis（光合作用）** 捕集 CO₂（原理与树、草一样），大规模培养。
- 形式：**绿色管道式光生物反应器**；也有部署在**海面浮体 (floats on the ocean surface)** 上的版本——好处是**省去大量基础设施**。
- ⚠️ **致命限制**：**by definition 需要极大量的光 (require so much light)**，光照必须最大化。
- 讲者评价：**"this does not look like particularly low-hanging fruit"**（这看起来不像是好摘的果子），但**技术路线成熟 (well-trodden)**。
- 分类学上的一个细致点：讲者说藻类固碳「与其说是 light-dependent utilisation，我更倾向说它是一个 **storage** 过程」，但可以进一步用它们的代谢产出有用化学品——**又一次说明边界模糊**。

##### (b) LanzaTech + *Clostridium*（最知名的 CO₂ 直接捕集与利用生物技术）

- **公司**：LanzaTech（讲者说「我想总部在 **Chicago**」），**产出极为丰富 (prolific)**，是**最知名的直接捕集并利用 CO₂ 的生物技术公司**。
- **生物**：**_Clostridium_（梭菌属）** 的一类细菌，属于 **acetogens（产乙酸菌）**——**能制造 acetate（乙酸盐）**。
- **代谢途径**：**Wood–Ljungdahl pathway（伍德–扬达尔途径，又称还原性乙酰辅酶 A 途径）**
  - ⚠️ 这是一条**极其古老 (very ancient) 的途径**，因此在微生物世界中**极为广布 (very widespread)**。
  - 功能：不只捕集 CO₂，还把它**转化为能量 (energy)** 以及其他产物。
  - *参考文献：Elisiário et al. 2021*
- **关键商业模式（幻灯片的「齿轮 cog」图示）**：这些公司**并不只是用野生菌**——它们**「劫持 (hijack)」细胞的机械运作或基因组信息**，逼它更高效地工作，或**扩大产品谱系 (wider repertoire of products)**。
  - ⚠️ **这些改造属于专利或商业机密 (patented / secret sauce IP)**——**外界永远不会真正知道他们是怎么做的**。这是本讲一个重要的**科学透明度/可验证性**议题。

##### (c) C3 Biotechnologies + *Halomonas*（Manchester 本地案例）

- **人物**：**Nigel Scrutton** 教授（讲者在 **MIB** 的同事，现为 **Fellow of the Royal Society**）。
- **公司**：**C3 Biotechnologies**（他名下数家公司之一）。
- **产品**：**advanced synthetic fuels（先进合成燃料）**，如 **kerosene（煤油/航空燃料）**；讲者称他们与**美国 Department of Defense** 有重大合约。
- **生物**：**不用 _Clostridium_，改用 _Halomonas_**——一种**耐盐/嗜盐细菌 (salt-tolerating / salt-loving)**。
- **⚠️ 为什么用嗜盐菌？这是本讲最漂亮的工程巧思，必考点级别**：
  - 你可以对其基因组做工程改造，高效产出目标物；
  - **但关键在于：因为它们只在有盐存在时才生长，所以整个发酵过程不需要在无菌条件 (sterile conditions) 下进行。**
  - **高盐环境本身就是天然的选择压力，杂菌长不起来。**
  - **省下的是灭菌操作的巨额成本与能耗 (costs and energy requirements of sterilizing your operation)**——讲者原话 **"that's a big deal"**。
- **产品谱系**：hydrocarbons（碳氢化合物）、bioplastics（生物塑料）、osmolytes（渗透调节物质）等可用于工业场景的物质。

##### (d) Nixon 课题组：Microbiome（微生物组）路线 — 冰岛

⚠️ **讲者明确说明：这一节的数据细节「far beyond the scope of your exam / this course」，纯粹是 illustrative。但概念框架仍值得理解。**

- **思路差异**：不用**单一菌株 (individual organisms)**，而是用**群落 / 微生物组 (communities / microbiomes)**，让它们做**在自然界中本来就做得很好的事**——把 CO₂ 转成它们所需的东西。
- **取样地点**：**冰岛的 geothermal springs / hot springs（地热泉/温泉）**
  - 这些环境的**有机碳极低 (very low in organic carbon)**，因此微生物**必须自己造有机碳**（自养）。
  - 它们代表**极古老的生命形式**，常被当作**早期地球 (early Earth) 或其他行星 (other planets) 的类比 (analogue)** 来研究——这是**天体生物学 (astrobiology)** 的连结。
  - **冰岛既是火山活跃 (volcanically active) 也是构造活跃 (tectonically active)** 的，从基岩渗上来的**主导气体就是 CO₂**（还有其他杂气）。
- **实验方法**：给这些群落**喂 CO₂ + 少量 H₂（提供还原力/氢源）+ 一些营养盐**，看它们能造出什么。
- **关键假设**：野外看到的**厚厚的微生物质 (biomass)**（视频中讲者亲手采集的「gunge」，厚到不知长了多少年）**就是从基岩渗上的 CO₂ 造出来的**。
- **工业相关性**：她们还测试**工业废气流中的其他杂质气体（如硫 sulfur）**，目标是**微调 (tweak) 而非彻底重写 (completely rewire)** 群落的代谢，让它们产出人类想要的东西。

### 2.6 CO₂ Storage（封存）— 本讲的重点难点

#### 2.6.1 术语之争：Storage vs Disposal（讲者的「bold statement」）

> **幻灯片标题就把 "Storage" 打了删除线**：**CO₂ ~~Storage~~ (CCU**S**)**
> ***"'storage' is a misnomer — think of it as 'disposal'!"***

**论证链（考点，也是一个绝佳的「科学传播/框架效应」案例）**：
1. CCS 文献常说封存要维持 **tens of thousands of years（数万年）**，理想上是**永久 (permanent)**。
2. **「永久储存」如果不是「处置」，那是什么？**
3. **风险**：叫它 "storage" 会让人**不够严肃看待**，而这个方法的不确定性其实相当令人担忧、需要关注。
4. **类比论证**：**nuclear waste（核废料）** —— "the **disposal** of nuclear waste：没人愿意草率行事；但 the **storage** of nuclear waste 听起来就没那么严重。"
5. **"the words matter and I don't think they're helpful."**
   ⚠️ 讲者自陈这是 **"my personal view"（我的个人观点）**——考试作答时应标注为一种立场/论证，而非公认定义。

#### 2.6.2 Key attributes for secure geological storage（安全地质封存的关键属性）— 必考清单
*出处：Nixon, Walker and Tyne, **in prep**（讲者本人正在撰写的论文）*

| 属性 | 英文 | 具体要求与为什么 |
|---|---|---|
| **储层地质** | **Reservoir geology** | **porosity（孔隙度）** — 要能容纳大量 CO₂；**permeability（渗透率）** — 要让 CO₂ 能自行在地层中扩散分布 |
| **全球封存潜力** | **Global storage potential** | 储层要**足够大 (big enough) 才值得做** |
| **深度 > 800 m** | **Depth > 800 m** | 这是**硬门槛**：足够的压力/温度使 CO₂ 保持**高密度（超临界）相态**，从而安全地被约束在有限体积内（见 §2.6.3） |
| **封闭性** | **Containment** | **caprock integrity & composition（盖层完整性与组成）** — 需要**不透水的密封层**；**trapping mechanisms（圈闭机制）** — 六种，见对照表 |
| **可及性 / 基础设施** | **Accessibility / infrastructure** | 必须能到达该场址、有管线与注入设施 |

**类比要点**：这**与油气开采的地质环境高度平行**——porous & permeable 的储层 + 其上的 **impermeable seal（不透水盖层）**。**这正是为什么枯竭油气藏是首选目标之一，也是为什么油气行业的技术可以直接迁移过来。**

#### 2.6.3 为什么是 800 m？（讲者口述被 ASR 弄糊了，此处补全正确物理）

⚠️ 转写作 "it keeps the co2 high"，几乎肯定是 **"it keeps the CO₂ [in a] dense / supercritical [phase]"** 的识别错误。正确物理如下：

- **CO₂ 的临界点**：$T_c \approx 31.1\ ^\circ\mathrm{C}$，$P_c \approx 7.38\ \mathrm{MPa}$（≈ 73.8 bar）。
- 在正常地温梯度与静水压力梯度下，**约 800 m 深度**即同时越过这两个临界值 → CO₂ 进入 **supercritical（超临界）** 状态。
- **超临界 CO₂ 的意义**：密度接近液体（约 600–800 kg/m³），黏度接近气体 → **单位体积储存的质量大幅提高**（同样质量的 CO₂ 占据的孔隙体积小得多），同时仍能在孔隙中流动分布。
- 若深度不足 800 m，CO₂ 呈气相，密度低、体积巨大、浮力驱动的上升趋势更强 → **既不经济也不安全**。

#### 2.6.4 三大目标地层（Key attributes of the main target formations）
*出处同样为 Nixon, Walker and Tyne, in prep*

> **幻灯片给出的全球容量排序（必背）**：
> $$\textbf{saline aquifer} > \textbf{depleted O\&G} > \textbf{basalt}$$
> （盐水层 > 枯竭油气藏 > 玄武岩）

**三者的权衡（讲者口述的核心论证）**：
- **Saline aquifers（盐水层）**：**容量遥遥领先 (by far the largest)**。但它们**从未被开发利用过**，因为「坦白说除了封存 CO₂ 之外它们没什么用」——**这既是优点（无竞争用途）也是缺点（几乎没有既有的地质完整性研究基础）**。
- **Depleted oil & gas reservoirs（枯竭油气藏）**：**已有基础设施 (infrastructure)**；而且**按定义已经自我证明**能在**数百万年**尺度上封闭气体或油——**这是最强的天然论证**。可以由 EOR 过渡为封存，也可直接封存。
- **Basalt formations（玄武岩层）**：**「奇怪的一个」**——**玄武岩可以是完全不透水的 (completely impermeable)**，正常来说这是致命缺陷。但 **Carbfix 有一套非常独特的玄武岩封存方式**（见 §2.6.6）。目前有几个进行中的项目，但**在总量中占比很小**。

**其他两类（在地图上出现但非主流）**：
- **Coal seams（煤层）**：绿色标示。**贡献量小，且没有大规模计划。**
- **Salt caverns（盐穴）**：紫色标示。**主要用于/被提议用于氢气、甲烷等气体的短暂性 (transient) 储存**；**容量不足以处置 CO₂**。已被证明可行，但**规模上不在同一量级**。

2. **但如果我们要在地下任何地方封存 CO₂，唯一拥有这套知识与专业能力的部门就是油气部门**——讲者本人**偏好称之为 "energy sector（能源部门）"** 而非 oil & gas。

> - **质疑方**：利益冲突、**moral hazard（道德风险）**——CCS 可能被用作延长化石燃料寿命的许可证（尤其是 EOR，见下）；研究资助的独立性问题。

#### 2.6.8 CO₂-EOR（Enhanced Oil Recovery）与它的道德悖论

**技术定义**（幻灯片术语表）：**CO₂-EOR** = 在一次采油 (primary) 与二次采油 (secondary) 手段失效后，**注入 CO₂ 以从油藏中额外采出石油**的技术。

**机制**：常规回收方式已无法采出经济可行量的烃类时，**注入 CO₂ 迫使残余油气（尤其是石油）被驱出**。这项技术**由来已久**。

**「顺带封存」**：**注入的 CO₂ 有相当比例（往往达到约三分之一 up to about a third）最终留在地层里**。因此石油公司发现「**我们看起来很棒，因为我们一直在封存 CO₂**」。

**⚠️ 讲者抛出的批判性问题（课堂原声，极可能成为考题）**：
> "如果 EOR 的目的是采出更多石油，而那些石油又进入整条工业管线、生产更多东西、不可避免地产生更多 CO₂——**那么它到底该不该被列在这张 CCS 地图上？**"

**讲者的判断**：**"although it does store CO₂ it's almost indirect — that's not really the purpose of doing it."**（它确实封存了 CO₂，但那几乎是附带的；那并不是做这件事的真正目的。）

#### 2.6.9 六种圈闭机制（Trapping mechanisms）— 本讲最核心的机制清单
*全部出自：**Tyne et al. 2023, Environ. Sci. Technol. 57:9459**（一篇综述）；由 **Rebecca Tyne** 撰写，她现已是本系的学者*

⚠️ **讲者的关键提醒**：**"often people say there are five but there are actually six, because there's a microbial component in this system as well."**（一般人说有五种，但其实有六种——因为系统里还有微生物这一环。）**第 4 项 microbial carbon cycling 是讲者本人的研究方向，也是文献长期忽略的一环。**

**六种机制的完整定义（幻灯片原句 + 讲解）**：

1. **Residual trapping（残余圈闭）**
   > "CO₂ is immobilised in pore spaces as disconnected droplets or bubbles, trapped by **capillary forces** during the movement of formation fluids."
   - CO₂ 在**孔隙空间**中被固定成**互不连通的液滴或气泡**，在**地层流体运移**过程中被**毛细力**捕获。
   - **发生极快**：一旦注入、CO₂ 开始扩散，就会很快出现残余圈闭。

2. **Structural trapping（构造圈闭）** — 最容易理解的一种
   > "CO₂ is **physically contained beneath impermeable rock layers (caprocks)** in geological structures such as **anticlines（背斜）or fault traps（断层圈闭）**."
   - **这是成功封存环境的先决条件 (prerequisite)**——因为需要被约束住的 CO₂ 比例非常大，所以盖层**必须不透水**。

3. **Solubility trapping（溶解圈闭）**
   > "CO₂ **dissolves into formation water**, becoming part of the fluid phase and **reducing its potential to migrate**."
   - 类比：**像做碳酸水 (carbonated water)**。
   - **自发反应 (spontaneous)**——因为**地下从来不是干的**，所以**无论哪种地层类型都会发生某种程度的溶解圈闭**；程度取决于化学条件（pH、盐度、温度、压力）。
   - **"a very important way to take that CO₂ out of play"**（是让 CO₂ 退出流动博弈的极重要途径）。
   - 化学：$\mathrm{CO_2(aq) + H_2O \rightleftharpoons H_2CO_3 \rightleftharpoons H^+ + HCO_3^- \rightleftharpoons 2H^+ + CO_3^{2-}}$

4. **Microbial carbon cycling（微生物碳循环）** ← **第六种，被忽略的一种**
   > "CO₂ **is converted into biomass or other forms through microbial metabolic processes**."
   - CO₂ 经微生物代谢转化为**生物质或其他形态的碳**。
   - **可以是圈闭（固定为生物质），也可以是泄漏路径（转化为 CH₄ 甲烷）**——**这是双刃剑**，正是 Paper of the Week 的核心。

5. **Mineral trapping / Precipitation（矿化圈闭 / 沉淀）**
   > "CO₂ reacts with minerals in the host rock to **form stable carbonate minerals**, locking carbon away in **solid form**."
   - **这是 CO₂ 地下封存的终极目标 (ultimately the goal)**——把 CO₂ 变成**在长时间尺度上稳定的碳酸盐矿物**，且时间尺度正好是我们需要的量级。
   - 化学（以钙为例）：$\mathrm{Ca^{2+} + CO_3^{2-} \longrightarrow CaCO_3\downarrow}$；玄武岩中富含 Ca、Mg、Fe，因此矿化速率远高于砂岩 → **Carbfix 的原理基础**。

6. **Adsorption trapping / Sorption（吸附圈闭）** — **仅适用于煤层**
   > "CO₂ is **adsorbed onto the surface of coal seams**, **replacing methane** and becoming physically retained in the **coal matrix**."
   - CO₂ 吸附到煤的表面，**置换出原有的甲烷**（这也是 **ECBM, Enhanced Coal Bed Methane 强化煤层气开采**的原理），被物理保持在煤基质中。
   - ⚠️ **讲者定位**：机制上有趣（化学上值得思考），但**在总量占比上不显著**，且**没有大规模煤层封存的计划**。

#### 2.6.10 「不是所有圈闭机制都同等安全」— 时间演化图（关键图，必考）
*出处：Bashir et al. 2024*

**图的设定**：
- 上覆 **low permeability shale（低渗透页岩）** 作为**最常见的盖层 (caprock)**；
- 储层为 **high permeability sandstone（高渗透砂岩）** — **砂岩既是常规采油的主要储层，也正是我们在盐水层中所寻找的地质类型**。
- **横轴** = **注入停止后经过的时间 (time since injection stops)**；**纵轴** = 各机制对总圈闭量的**贡献比例**。

#### 2.6.11 Containment risks（封闭失效风险）— 五种泄漏情景
*出处：**Anderson 2017, Natural Resources Research, 26:89**（讲者推荐精读的综述）*

⚠️ **讲者的元判断（ILO 5 的核心句）**：
> **"we still do not understand all the factors that encourage containment compromise"**（我们仍未理解所有促成封闭失效的因素）——**尤其是盐水层，因为我们不拿它做别的用途，所以研究基础薄弱**。
> 对比：**油藏的完整性 (integrity) 研究得很透彻**，因为**封井与弃置 (seal and abandon) 时必须确保安全**——**这套技术与 CO₂ 封存高度重叠**。**但换成另一种地层、另一套技术，就仍是知识空白 (knowledge gap)。**

**五种情景（幻灯片 A–E，逐条掌握）**：

| 标号 | 情景 | 机制 | 严重程度 |
|---|---|---|---|
| **A** | 注入的 CO₂、被驱替的流体、以及任何被活化的元素**接触到较小的断层或裂隙 (smaller faults or fractures)** | 造成**局部的轻微压力累积 (minor pressure buildup)** | 讲者评：**"feels quite localized"**，影响可能不大，但**取决于这一过程有多广泛** |
| **B** | 注入的 CO₂、被驱替的流体与活化元素**接触到断层、通往地表的通道，或废弃老井 (old abandoned wells)** | **结构性的直通地表路径** | **严重得多的结构性路线 (much more significant structural routes)**。废弃井是经典的「人造烟囱」风险 |
| **C** | CO₂ 注入到**微小的浮力圈闭 (minor buoyant traps)** 中，**找到或制造出泄漏路径 (finds or creates leakage pathways)**；压力升高；把原位流体推过**溢出点 (spill points)** | CO₂ 可以**利用既有裂隙，也可以自己创造新的裂隙** | 中–高 |
| **D** | 注入 CO₂ 造成**压力的临界性累积 (critical buildup of pressure)**、应力状态改变，以及多因素叠加 | **诱发地震 (induce seismicity)** | 一旦沿断层诱发地震，**整个系统的完整性都受威胁** |
| **E** | 注入的 CO₂ **沿地层倾向上倾运移 (migrates up dip)**，而储层地层一路延伸到地表 | 抵达**地表淡水体 (surface bodies of freshwater)、海洋 (oceans) 或大气 (atmosphere)** | **最坏情况**：污染**饮用水源 (water table / drinking water)**，或**影响元素的迁移性 (mobility)** 导致取用清洁水困难；**最糟的是 CO₂ 回到大气——那样整件事就白做了** |

**图上的一个细节**：剖面图显示了 **water table（地下水位面）** 这一层——即取用饮用水的层位；图上是**截断的深度剖面 (truncated depth profile)**（真实尺度上储层比图示深得多）。

### 2.7 深部生物圈（Deep Biosphere）与 CO₂ 封存的微生物学 — 讲者的「敲鼓」环节

#### 2.7.1 一个必须先破除的误解

⚠️ 讲者在面向产业的会议上常被问：
> *"why are you interested in microbiology — there's no water in the subsurface"* / *"the subsurface is sterile"*

**她的回应（必记）**：
> **"the subsurface is definitely NOT sterile — it harbors the unseen majority of microbial life on Earth."**
> （地下绝对不是无菌的——它容纳了地球上**看不见的大多数**微生物生命。）
> **地球上大多数的 bacteria 与 archaea 都来自 deep subsurface。**
> **"we don't really understand what they're doing in most of the scenarios there"** — 这就是所谓的 **deep biosphere（深部生物圈）**。

#### 2.7.2 微生物学认识论的三次革命（讲者的历史框架）

| 阶段 | 时间 | 技术 | 认识跃迁 |
|---|---|---|---|
| 1 | ~19 世纪 | **Darwin's notebook**（观察鸟类） | 理解演化如何发生 |
| 2 | ~1970s–1990s | **16S rRNA fingerprinting（16S 核糖体 RNA 指纹技术）** | ⚠️ **Genetic Revolution（遗传学革命）**：发现**原核生物有两个域 (domains)：Bacteria 与 Archaea**，而非只有细菌。*(Woese et al. 1990)* |
| 3 | 现在 | **Genomic era（基因组时代）/ Metagenomics（宏基因组学）** | 揭示地下**极度多样的生命之树 (insanely diverse tree of life)**；**这棵树上的大量枝叶来自地表以下 20 米以内**，且**由单一个研究组**用基因组学方法从**无法培养 (unculturable)** 的生物中恢复出基因组。*(Castelle and Banfield 2018, **Cell**)* |

⚠️ 讲者措辞小瑕：她说 "two **kingdoms** of prokaryotes"，Woese 体系的正确术语是 **domains（域）**。

#### 2.7.3 Metagenomics（宏基因组学）能给出什么（幻灯片列点）

在**群落内部 (within communities)** 可以获得：
- **Strain-level phylogeny（菌株级系统发育）**
- **Draft quality 'genomes'（草图质量的「基因组」）**
- **New lineages（新的演化谱系）**
- **Dark Matter（微生物暗物质）** — 完全未知的分支
- **Metabolic potential（代谢潜力）**
- **Viral predation history（病毒捕食史）**

#### 2.7.4 「工程化的地下环境」特别宜居
*Hubbard et al. 2014; Amundsen et al. 2024, **Nature Reviews Microbiology**; Nixon, Walker and Tyne, in prep*

- 微生物在 **aquifers（含水层）、igneous rocks（火成岩）** 等多种地下环境中都存在，**每一种环境都不一样**。
- ⚠️ **关键洞见**：**一旦人为「工程化」地介入地下（钻井、注入），这些环境会变得非常宜居 (they become very habitable)**——因为你输入了能量与物质。

#### 2.7.5 经典警示案例：油田的 souring（酸化）问题

**这是深部生物圈研究之所以起步的原因**（"this is really what kicked off research about life in the deep subsurface"）。

**机制链**：
1. 常规采油：从 **injector well（注入井）** 注入 **seawater（海水）**，从 **producer well（生产井）** 采油。
2. **海水中含有 sulfate（硫酸盐 SO₄²⁻）**。
3. 储层与海水中都存在能**把 sulfate 还原为 sulfide（硫化物 H₂S/S²⁻）**的细菌（**sulfate-reducing bacteria, SRB / sulfidogens**），它们借此获得能量。
   $$\mathrm{SO_4^{2-} + \text{有机物 / } H_2 \longrightarrow H_2S + \dots}$$
   ⚠️ 讲者：**"you don't need to know the mechanism"**——**只需知道这是一个极普遍且极昂贵的问题**。
4. **为什么糟糕（三条，必记）**：
   - **成本极高**，有时高到**这个资源就变成了不可采资源 (unrecoverable)**；
   - **极强腐蚀性 (very corrosive)**——**钢材极易被硫化物腐蚀**，可能导致**基础设施的灾难性失效 (catastrophic failure)**；
   - **对人与所有其他生命剧毒 (very toxic)**（H₂S）。
5. ⚠️ **重要限定**：**这是油藏特有的**；即使是 **shale gas reservoirs（页岩气藏）** 的问题成因**看起来也完全不同**。**"we still don't know what we don't know."**

**推论到 CO₂ 封存**：
> **既然如此，为什么在地下封存 CO₂ 就不会引发某种微生物响应？**
> 尤其考虑到：**CO₂ 存在的历史，远比地球上大量有机碳的历史更悠久**——**数十亿年前的生命就一直很愉快地以 CO₂ 作为代谢基础**（光合作用正是由此而来）。

#### 2.7.6 CO₂ 生物地球化学的概念图（Nixon 课题组的框架，考点级概念）

**碳的可能命运网络**：

```
                    ┌── acetogens (产乙酸菌, Wood–Ljungdahl) ──▶ 固定为可被其他生物利用的有机碳
   注入的 CO₂ ──────┤                                                    │
                    └── (与 H₂ 结合) ──▶ methanogens ────────▶ CH₄（甲烷）◀┘
                                                                  ▲
   残余油 / kerogen (干酪根) ──[降解 degradation]──▶
   ──[发酵 fermentation]──▶ 易利用的碳源 ──────────────────────────┘
                                    │
                                    ├──▶ 产生 sulfide（硫化物）→ 腐蚀、毒性
                                    ├──▶ 介导 iron（铁）反应
                                    └──▶ ⭐ 机会：加速 CO₂ → 碳酸盐矿物的转化？
```

**讲者的关键类比（极佳的记忆钩子）**：
> **"that kerogen is basically natural biochar"** —— **干酪根本质上就是天然的生物炭**：都是难以被生物利用的稳定有机碳。**但微生物的降解与发酵可以把它变成极易利用的碳源**，从而**点燃 (fuel) 整串下游代谢过程**。

**site-specific attributes（决定上述过程是否相关的场址特异属性，幻灯片列表，必记）**：
- **pH**
- **redox（氧化还原电位）**
- **temperature（温度）**
- **pressure（压力）**
- **salinity（盐度）**
- **geochemistry (aq)（水相地球化学）**
- **organic C content（有机碳含量）**
- **microbiota（微生物区系）**

**按地层类型的差异化预测（重要的应用推理，考点）**：

| 地层类型 | 微生物活动预期 | 理由 |
|---|---|---|
| **枯竭油气藏 (depleted O&G)** | **高** | 有**残余的复杂有机碳 (complex organic carbon)**，甚至其降解产物 → 微生物有食物 |
| **盐水层 (saline aquifer)** | **较低但非零** | **高盐度是对生命非常有压力的环境 (very stressful)**——**不是不可能，但你会找到不同类型的生命**（嗜盐菌） |
| **极深/极热地层** | **可以完全排除** | ⚠️ **生命的已知温度上限是 122 °C**（且在那个温度也「不是快乐的存在」）。**如果储层是 200 °C，那么以上所有微生物过程都可以不予考虑。** |

**另加**：**aqueous geochemistry（水相地球化学）** —— 有多少营养盐？有机的还是无机的？——都会影响这一切的相关性，**必须逐场址 (site by site basis) 判断**。

#### 2.7.7 Biogeochemical baselines are essential (and lacking)（生物地球化学基线：不可或缺却付之阙如）

⚠️ **这是 ILO 5「不确定性」下最具体的一条政策/方法论建议，务必掌握。**

**要在注入 CO₂ 之前建立的基线，必须回答四个问题（幻灯片的四栏框架）**：

| 问题 | 具体要问什么 | 方法 |
|---|---|---|
| **Who?（谁在那里）** | community membership? biodiversity?（群落组成？生物多样性？） | 16S rRNA、宏基因组 |
| **What?（它们能做什么）** | metabolic potential?（代谢潜力？） | 宏基因组（基因组编码的能力） |
| **Viable? Active?（是否存活/活跃）** | metabolic lifestyles? growth rates?（代谢生活方式？生长速率？） | 转录组/蛋白组/活性测定 |
| **_in situ_ conditions?（原位条件是什么）** | pH、temp、salinity、TDS（总溶解固体）、pressure、organic C、metals、**e⁻ donors（电子供体）**、**e⁻ acceptors（电子受体）** | 地球化学分析 |

⭐ **Manchester 研究方法论的核心主张（讲者反复强调，可作为论述题的方法论段落）**：

### 2.9 Paper of the Week — Tyne et al. 2021, *Nature*

#### 2.9.1 论文与作者背景

- **第一作者 Rebecca Tyne**，**现为本系学者 (an academic in our department)**。讲者盛赞：**"a fantastic young researcher"**，未来学生**有很多机会与她合作做 project**；**在职业生涯早期就做出这样的工作、发在 Nature 上是了不起的成就**。
- **为什么选这篇**：它**整合了本系所使用的一整套技术**（贵重气体地球化学、团簇同位素、稳定同位素、微生物学），是本地相关研究的绝佳示范；且 **Nature 论文篇幅精炼、易读（只有三张图）**。
- ⚠️ 讲者致歉：她上周生病，这篇论文**前一晚才上传到 Blackboard**。论文也**很容易凭标题搜到**。

#### 2.9.2 核心发现（punchline）

> **在一个 CO₂-EOR 场址中，注入的 CO₂ 有高达 19% 在仅仅 30 年内就被微生物转化成了甲烷 (CH₄)。**

**为什么这震撼**：
- CO₂ 封存/处置**理应在数万年尺度上安全**；
- **但在三十年内，将近五分之一已经变成了别的东西**。
- 这种可能性**先前已被假说化 (hypothesised) 一段时间，但这是第一次真正的实证 (first demonstration)**。

#### 2.9.3 研究场址与设计（准自然实验设计，值得学习的方法论范例）

| 项目 | **Olla Oil Field（实验组）** | **Nebo-Hemphill Oil Field（对照组）** |
|---|---|---|
| 位置 | **Louisiana（路易斯安那），northern Gulf of Mexico（墨西哥湾北部）** | **Olla 东南 20 km**，**同一地层 (same formation)** |
| 处理 | **1983–1986 年注入 CO₂ 做 CO₂-EOR**；**1984 年 water flooding（注水驱替）** | **从未注入过 CO₂**（天然对照 control site） |
| 注入总量 | **2.2 × 10⁸ m³ CO₂** | — |
| EOR 结束后残留 | **~9 × 10⁷ m³**（约占注入量的 41%；讲者口述"about a third"） | — |
| **CO₂ 浓度** | **18 ± 12 mol%** | **1.02 ± 0.69 mol%** |
| **CH₄ 浓度** | **77 ± 13 mol% (STP)** | **92.6 ± 8.2 mol% (STP)** |

⭐ **设计的力量**：**同一地层、相距仅 20 km、一个注了 CO₂ 一个没注**——这构成了一个近乎完美的**对照实验 (natural control)**，使「差异归因于 CO₂ 注入」的推论极为稳固。**这是本课「证据强度」评估的教科书案例。**

#### 2.9.4 方法：为什么用 noble gases（贵重气体）+ clumped isotopes（团簇同位素）

**核心方法论论证（必记）**：
> **"Stable isotopes of carbon are frequently modified by chemical or biological processes; the inert nature of noble gases means that they are ideal tracers for injected CO₂."**
> **碳的稳定同位素经常被化学或生物过程改造；而贵重气体的惰性使它们成为注入 CO₂ 的理想示踪剂。**

- **³He（氦-3）** 作为惰性的 **proxy tracer（代理示踪剂）**——追踪深部地下流体与气体的运移。
- **同位素分馏 (isotopic fractionation) 像指纹一样**，指示是**什么过程**制造了这个产物 → 由此**拆解 (tease apart) 出哪部分是非生物 (abiotic)、哪部分是生物 (biotic) 的，以及生物过程是怎么发生的**。

#### 2.9.5 图 a：δ¹³C of CO₂ vs CO₂/³He 比值

**读图逻辑**：
- 虚线给出两条**端元 (endmember)** 分馏轨迹：**methanogenesis（产甲烷作用）** 与 **dissolution（溶解，pH 7）**。
- **阴影区** = **两者共同作用（微生物产甲烷 + 溶解）** 的组合区域。
- 标记为 **'consumption'** 的线 = **原始注入 CO₂ 中已被净微生物产甲烷作用移除的比例**。
- **injected gas（注入气）** 的位置作为起点参照。

⭐ **关键定量结论（必背）**：
$$\mathbf{M{:}D = 0.26}$$
> **Dissolution（溶解）造成的 CO₂ 移除量，约为 microbial methanogenesis（微生物产甲烷）的三倍。**
（M:D = methanogenesis : dissolution 之比 = 0.26，即 1/0.26 ≈ 3.8 倍；幻灯片表述为「approximately three times more」。）

⚠️ **注意这句话的双重含义**：
- 一方面，**溶解仍是主导的移除机制**（好消息，因为溶解圈闭是相对安全的）；
- 另一方面，**微生物产甲烷仍占到 CO₂ 移除的相当一部分（那 19%）**，而**这一路径把 CO₂ 变成了一种更强的温室气体、且更容易迁移**（坏消息）。

#### 2.9.6 图 b：δ¹³C of CO₂ vs δ¹³C of CH₄

- **阴影区** = 从 **Black Lake Oil Field** 注入 Olla 系统的**注入气 (injectate) 的 CO₂ 同位素组成**。
- Olla 的数据**同时与两者一致**：与**储层温度下的热再平衡 (thermal re-equilibration，实线)** 一致，也与**微生物产甲烷 (虚线)** 一致。
- **1σ 不确定度小于符号大小**（即误差极小）。
- **在图上，注入井场址与对照场址明显分离，且都远离注入气本身的组成**。

**分馏的基本原理（务必掌握，考试常考的机理句）**：
> **生物过程总是偏好较轻的同位素 (biology will always favor a lighter isotope)。**
> **Methanogens 在产甲烷时优先使用较轻的 CO₂ 同位素 (¹²C) 而非较重的 (¹³C)** → 结果是：**生物成因甲烷相对贫化 ¹³C（δ¹³C 更负）**，而**残余 CO₂ 池相对富集 ¹³C（δ¹³C 更正）**。
> 这种**相对富集/贫化的分离 (fractionation/separation)**，是判定某物是否由生物产生的**稳健方法**。
> ⚠️ 讲者自陈：**"isotopes can be a really tricky one to get around — I always have to go back and refresh my memory about which way it works."**（同位素方向性很容易搞混，连她都要反复查。）**这句话就是给学生的暗示：这是个易错点。**

#### 2.9.7 图 c：Clumped isotopes（团簇同位素）— 独立证据

**Clumped isotope（团簇同位素）定义**（幻灯片术语表）：**与其他重同位素成键的重同位素**。**甲烷的团簇同位素可以记录其形成温度 (formation temperature)，因此可用来鉴别甲烷的来源。**
（具体测的是甲烷分子中**同时含有重碳 ¹³C 和重氢 D 的同位素体 (isotopologue)**，可同步分析。）

**判别原理**：
- **Thermogenic CH₄（热成因甲烷）** 主要在**内部同位素平衡 (internal isotopic equilibrium)** 条件下形成 → 落在**平衡线（黑线）**上，且对应一个可预测的形成温度。
- **Microbial CH₄（微生物成因甲烷）** 的团簇同位素组成**高度可变 (highly variable)**，同时出现**非平衡与表观平衡**两种信号。

**图上的元素**：
- **黑线** = 内部热力学平衡线
- **阴影十字** = 各同位素体在当前储层温度下热平衡的位置
- **深灰箭头** = **methanogenesis（产甲烷）** 的理论趋势
- **浅灰箭头** = **AOM（Anaerobic Oxidation of Methane，甲烷厌氧氧化）** 的理论趋势

⭐ **结论**：
> **Clumped isotopologues provide clear evidence that the Olla CH₄ is microbial in origin.**
> （团簇同位素体提供了明确证据：Olla 的甲烷是微生物成因的。）
> ⚠️ 而**对照场址的数据落点是模糊的 (ambiguous)**——无法确定成因，这恰好反衬出 Olla 信号之强。

#### 2.9.8 作者的最终解释（Extended Data 中的图解总结）

**三阶段叙事**：

| 阶段 | 发生了什么 | 同位素分馏特征 |
|---|---|---|
| **1. CO₂ injection（注入期）** | CO₂ 注入并在整个系统中迁移扩散 | **基本没有微生物活动**，分馏落在注入气组成附近 |
| **2. Post-injection（注入后）** | ① **microbial methanogenesis（微生物产甲烷）** ② **CO₂ dissolution（CO₂ 溶解）** 同时发生 | 两条独立的分馏轨迹 |
| **3. Today（今天检测到的）** | 两者之和 | 今日观测到的分馏模式 = **两条路径的组合** |

⭐ **关键点（讲者原话）**：**"crucially that combination of methane production includes a microbial component which was unexpected."**（关键在于：这个甲烷生成的组合中包含了一个**出人意料的**微生物组分。）

#### 2.9.9 Paper of the Week 术语表（幻灯片 Glossary of terms，逐条掌握）

| 术语 | 定义 |
|---|---|
| **isotope（同位素）** | 同一元素的两种或多种形式，**质子数相同、中子数不同**，因此**相对原子质量不同但化学性质相同**；特指某元素的放射性形式 |
| **isotopic fractionation（同位素分馏）** | 在自然过程中，一种同位素相对另一种的**分离或富集**。**Methanogens 在产甲烷时优先使用较轻的 CO₂ 同位素 (¹²C) 而非较重的 (¹³C)**，导致**生物成因甲烷中 ¹³C 相对贫化**，而**残余 CO₂ 池中 ¹³C 相对富集** |
| **clumped isotope（团簇同位素）** | **与其他重同位素成键的重同位素**。甲烷的团簇同位素可**记录其形成温度**，因此可用于**鉴别甲烷的成因** |
| **noble gases / isotopes（贵重气体/惰性气体）** | 元素周期表**第 18 族**成员：**He, Ne, Ar, Kr, Xe, Rn**，某些情形下还包括 **Og**。其**相对同位素丰度是地球科学中重要的地球化学示踪工具** |
| **methanogenesis（产甲烷作用）** | 由被称为 **methanogens（产甲烷菌）** 的 **Archaea（古菌）** 进行的、**与能量保存耦合的甲烷生成过程** |
| **hydrogenotrophic methanogenesis（氢营养型产甲烷作用）** | 微生物介导的 **CO₂ 与 H₂ 转化为甲烷**：$$\mathrm{CO_2 + 4H_2 \longrightarrow CH_4 + 2H_2O}$$ |
| **AOM (Anaerobic Oxidation of Methane，甲烷厌氧氧化)** | **在无氧条件下的微生物甲烷消耗**；是该研究场址更广义的、涉及甲烷的碳循环的一部分 |
| **CO₂-EOR (Enhanced Oil Recovery，CO₂ 强化石油开采)** | 在一次与二次采收手段失效后，**通过注入 CO₂ 从油藏中额外采出石油**的技术 |

| **Enhanced rock weathering（强化岩石风化）** | Nature-based（**非生物、纯化学**） | 播撒**高比表面积硅酸盐岩粉** → 加速天然风化反应 → 消耗 CO₂ 生成碳酸氢根与矿物 | 陆域农田撒粉；海域投放 | **中–高**：**采矿、粉碎（高比表面积）、运输、撒布的能耗都不低**（推断） | **中（较新，多为试验规模）** | **岩粉粉碎能耗可能抵消部分收益**；**净封存量核算复杂**（碳酸氢根入海后可能释回一半 CO₂）；**重金属释放风险**（推断）；**验证与核查 (MRV) 困难** |
| **Direct Air Capture (DAC，直接空气捕集)** | **Disruptive technology**（讲座中唯一如此归类） | 抽入环境空气 → CO₂ 吸附于滤材 → 滤材饱和后脱附 → 得浓缩 CO₂ | 任何地点（不受排放源位置限制）；**必须与封存或利用耦合**（Climeworks ↔ Carbfix） | **成本与能耗最高**：大气 CO₂ 仅约 420 ppm，**极度稀释使分离功耗极大**（推断）；Climeworks 依赖冰岛廉价地热能 | **低–中（早期商业化）** | **⚠️ 体量微不足道**（讲者：the numbers don't look meaningful）；**依赖廉价低碳能源**，否则得不偿失；**可规模化性未证**；PR 声量远大于实际减排量 |
| **Algae photobioreactors（藻类光生物反应器）** | Disruptive biotech / Nature-based | 微藻经光合作用固定 CO₂，生物量可再转化为产品 | 工业烟气旁；海面浮体（省基建） | **高**：**必须最大化光照**，基础设施密集 | **中（well-trodden 但未突破）** | **⚠️ 光照需求是硬约束 (by definition)**；讲者判断 **"not particularly low-hanging fruit"**；水与养分需求大 |
| ***Clostridium* 气体发酵（LanzaTech）** | Disruptive biotech | **acetogens（产乙酸菌）** 经 **Wood–Ljungdahl pathway**（极古老、极广布）把 CO₂ + H₂/CO 转成 acetate 及下游产品；公司**基因改造以提效与扩产品谱** | 工业废气流（钢厂等）；产燃料、化学品、服装原料 | **中**：需 H₂ 来源与发酵基建；**需无菌条件（成本项）** | **中–高（LanzaTech 已商业化，最知名）** | **需外源 H₂**（其碳足迹决定成败）；**改造细节为专利/商业机密，外部无法验证**；**利用 ≠ 移除**（净气候效益存疑） |
| ***Halomonas* 平台（C3 Biotechnologies, Manchester）** | Disruptive biotech | **嗜盐菌**基因工程生产 hydrocarbons、bioplastics、osmolytes、合成航空煤油 | 先进合成燃料（有美国 DoD 合约）；工业化学品 | **中，但显著低于常规发酵**：⭐ **因只在高盐下生长，无需灭菌 → 省下灭菌的成本与能耗（"that's a big deal"）** | **中（已成立公司、有重大合约）** | 高盐工艺对**设备腐蚀**（推断）；同样需要碳与能量输入；利用 ≠ 移除 |
| **Microbiome（微生物组）路线（Nixon lab, Iceland）** | Disruptive biotech / **重新定义的 nature-based** | 用**整个群落**而非单一菌株，利用其在低有机碳地热泉中**已演化出的 CO₂ 利用能力**；喂 CO₂ + H₂ + 营养盐 | 研究阶段；目标是**耐受工业废气杂质（如硫）** | 研究阶段，未定 | **低（proof of concept 阶段）** | **群落行为难控与难预测**；**产物谱系需要 tweak 而非 rewire**；⚠️ **讲者明示此节数据不在考试范围** |

### 3.2 ⭐ 封存圈闭机制对照表（六种）
*机制定义全部出自 Tyne et al. 2023, Environ. Sci. Technol. 57:9459；时间演化出自 Bashir et al. 2024*

| # | 机制 | 英文 | 原理（幻灯片原句要旨） | 起效时间 | 安全性（越右越安全） | 适用地层 | 关键控制因素 / 风险 |
|---|---|---|---|---|---|---|---|
| 1 | **构造圈闭** | **Structural (& stratigraphic) trapping** | CO₂ 被**物理性地封闭在不透水盖层 (caprock) 之下**的地质构造中（**anticlines 背斜、fault traps 断层圈闭**） | **立即**（注入即生效） | **最低**（第一位，最不安全） | **所有**有盖层的储层；**是成功封存的先决条件 (prerequisite)** | **完全依赖 caprock 完整性**；断层活化、废弃井、超过溢出点即失效 |
| 2 | **残余圈闭** | **Residual trapping** | CO₂ 在**孔隙空间**中被固定为**互不连通的液滴或气泡**，在地层流体运移时被**毛细力 (capillary forces)** 捕获 | **很快**（注入后 CO₂ 一扩散就发生） | **较低—中**（**全程持续重要**） | 高孔隙度、高渗透率储层（尤其砂岩） | 取决于**孔隙结构与润湿性**；不能单独承担全部封存量 |
| 3 | **溶解圈闭** | **Solubility trapping** | CO₂ **溶入地层水**成为流体相的一部分，**降低其迁移潜势**；类比碳酸水；**自发反应** | **随时间递增** | **中—高** | **所有地层**（因为**地下从来不是干的**） | 受 **pH、盐度、温度、压力、水化学**控制；溶解后的水**密度略增会下沉**（有利）；但可**酸化并侵蚀盖层矿物**（推断风险） |
| 4 | **微生物碳循环** | **Microbial carbon cycling** | CO₂ **经微生物代谢被转化为生物质或其他形式的碳** | **贯穿全程**（一旦条件适宜） | **⚠️ 双刃剑，未纳入标准图** | 有液态水、T < 122 °C、有电子供体的地层；**枯竭油气藏最活跃**（有残余有机碳），**盐水层受高盐抑制**，**超深高温地层可排除** | **风险**：产甲烷（CO₂→CH₄，更强温室气体且更易迁移）、**sulfidogenesis（产硫化物 → 腐蚀 + 剧毒）**、**bioclogging（生物堵塞，阻塞注入性）**<br>**机会**：**微生物介导的矿化加速** |
| 5 | **矿化圈闭 / 沉淀** | **Mineral trapping / Precipitation** | CO₂ **与围岩矿物反应生成稳定的碳酸盐矿物**，把碳以**固相**锁住 | **最晚出现 (comes much later)** | **⭐ 最高（最终目标 ultimately the goal）** | 富含 Ca/Mg/Fe 的岩石——**玄武岩最佳（Carbfix 原理）**；砂岩慢得多 | 反应速率是主要瓶颈；**Carbfix 通过先把 CO₂ 溶于水再注入以大幅提速**；可能**堵塞孔隙、降低注入性**（推断） |
| 6 | **吸附圈闭** | **Adsorption / Sorption trapping** | CO₂ **吸附到煤层表面，置换出甲烷**，被物理保持在**煤基质 (coal matrix)** 中 | 注入即发生 | 中（机制上有趣） | **仅限 coal seams（煤层）** | ⚠️ **体量占比极小，无大规模计划**；煤层膨胀会降低渗透率（推断）；与 ECBM 的道德悖论类似 EOR |

**必背的时间—安全性序列**：
$$\text{Structural} \;\longrightarrow\; \text{Residual} \;\longrightarrow\; \text{Solubility} \;\longrightarrow\; \text{Mineral}$$
$$\text{（早、最不安全）} \qquad\qquad\qquad\qquad \text{（晚、最安全）}$$

|---|---|---|---|---|---|---|

### 3.4 关键化学方程式

**(1) 氢营养型产甲烷作用（Paper of the Week 的核心反应，必背）**
$$\mathrm{CO_2 + 4H_2 \longrightarrow CH_4 + 2H_2O}$$
- 由 **Archaea（古菌）中的 methanogens** 催化，**与能量保存耦合**。
- ⚠️ 在 CO₂ 封存语境中，这是**把安全的 CO₂ 变成了更强的温室气体 CH₄**——**风险**。

**(2) 产乙酸作用（Wood–Ljungdahl pathway，LanzaTech 的基础）**
$$\mathrm{2CO_2 + 4H_2 \longrightarrow CH_3COOH + 2H_2O}$$
- 由 ***Clostridium* 属的 acetogens** 催化；**这是一条极古老、极广布的途径**。

**(3) 溶解圈闭的碳酸平衡**
$$\mathrm{CO_2(g) \rightleftharpoons CO_2(aq)};\quad \mathrm{CO_2(aq) + H_2O \rightleftharpoons H_2CO_3 \rightleftharpoons H^+ + HCO_3^- \rightleftharpoons 2H^+ + CO_3^{2-}}$$

**(4) 矿化圈闭（以钙为例）**
$$\mathrm{Ca^{2+} + CO_3^{2-} \longrightarrow CaCO_3\downarrow \quad (calcite)}$$
$$\mathrm{Mg^{2+} + CO_3^{2-} \longrightarrow MgCO_3\downarrow \quad (magnesite)}$$

**(5) 强化岩石风化（硅酸盐风化，以硅灰石为例）**
$$\mathrm{CaSiO_3 + 2CO_2 + H_2O \longrightarrow Ca^{2+} + 2HCO_3^- + SiO_2}$$

**(6) 硫酸盐还原 / 油藏 souring（有害微生物活动的典型）**
$$\mathrm{SO_4^{2-} + 4H_2 \longrightarrow H_2S + 2H_2O + 2OH^-}$$
后果：**腐蚀钢材、剧毒、使资源变为不可采**。

### 3.5 容量估算公式

⚠️ **本周材料中并未出现任何容量估算公式**——讲座只给出**定性的容量排序**（saline aquifer > depleted O&G > basalt）与**逐年注入量的气泡图**。

以下为**该领域标准的储层封存容量公式（考纲外补充，用于理解讲座中「global storage potential」这一属性）**：

$$M_{\mathrm{CO_2}} = A \cdot h \cdot \phi \cdot \rho_{\mathrm{CO_2}} \cdot E$$

| 符号 | 含义 | 单位 | 说明 |
|---|---|---|---|
| $M_{\mathrm{CO_2}}$ | 封存容量（质量） | kg 或 Mt | 目标量 |
| $A$ | 储层面积 | m² | 由地震勘探与测井圈定 |
| $h$ | 储层有效厚度（net thickness） | m | 只算真正可容纳 CO₂ 的净厚度 |
| $\phi$ | **孔隙度 (porosity)** | 无量纲（0–1） | ⭐ 对应讲座 "Reservoir geology: porosity" |
| $\rho_{\mathrm{CO_2}}$ | 原位（储层温压下）CO₂ 密度 | kg/m³ | ⭐ **这里就是 800 m 深度门槛的意义所在**：超临界态密度约 600–800 kg/m³，远大于气态 |
| $E$ | **储存效率因子 (storage efficiency factor)** | 无量纲（典型 0.01–0.04，即 1–4%） | ⭐ 关键且高度不确定的一项：真实注入的 CO₂ 只能占据孔隙体积的极小比例（受**渗透率 permeability**、浮力上浮、粘性指进 viscous fingering、构造闭合面积等限制）——**讲座中「permeability 使 CO₂ 能自行扩散分布」这条属性，物理上就是在拉高 $E$** |

**记忆要点**：$A\cdot h\cdot\phi$ = **孔隙体积**；乘 $\rho$ 换成质量；乘 $E$ 打上现实折扣。**盐水层容量之所以最大，主要来自巨大的 $A \cdot h$。**

### 3.6 【考纲外补充】工业捕集技术三条路线

> ⚠️ **本讲完全未涉及**（讲者明确将其划归 chemical engineering 并排除）。此处仅为补足主控预设的知识框架，**考试不作要求**，且**若与讲座冲突一律以讲座为准**。

| 路线 | 英文 | 原理 | 适用场景 | 能耗 | 成熟度 | 主要问题 |
|---|---|---|---|---|---|---|
| **燃烧后捕集** | **Post-combustion** | 从烟气 (flue gas) 中用胺类溶剂等吸收 CO₂（烟气 CO₂ 浓度低，~4–15%） | **可改造 (retrofit) 现有电厂与水泥厂** | 高（溶剂再生耗热） | **最成熟** | 稀释度高 → 能耗大；溶剂降解与胺排放 |
| **燃烧前捕集** | **Pre-combustion** | 燃料先气化/重整成 syngas (CO + H₂)，经水气变换转成 CO₂ + H₂，在**高浓高压**下分离 CO₂，燃烧 H₂ | **IGCC 电厂、制氢（蓝氢）** | 中（分离效率高但前端改造大） | 中 | 只能新建，无法改造；系统复杂 |
| **富氧燃烧** | **Oxy-fuel combustion** | 用**纯氧**代替空气燃烧 → 烟气几乎只有 CO₂ + H₂O，冷凝水后即得高纯 CO₂ | 新建电厂、水泥（含固有工艺排放） | **空气分离制氧 (ASU) 能耗极大** | 中—低 | 制氧能耗是主要成本项；材料耐高温要求 |

**与本讲的连结**：无论用哪条路线捕集，**下游的压缩、运输与封存问题完全相同**——而本讲讲的正是**下游（封存）与替代性的上游（自然基础捕集）**。

**本周无独立 practical**，但**课堂内有一段 15–20 分钟的结构化小组讨论（Paper of the Week discussion）**，且**明确要求「如果你一个人坐一桌，请去和别人拼桌」**，讲师会巡场引导，部分问题会放到 **Mentimeter** 上。以下为三道讨论题与建议的作答框架。

### 讨论题 1
> **Is the microbial conversion of methane in a geological CO₂ storage reservoir a risk or an opportunity? Why?**
> （地质 CO₂ 封存储层中的微生物甲烷转化，是风险还是机会？为什么？）

⚠️ 注意题干措辞：幻灯片写的是 "microbial conversion **of** methane"，但**论文讲的是 CO₂ **到** 甲烷的转化**（转写中讲者的口述也是 "microbial conversion of methane"）。**答题时按「CO₂ → CH₄ 的微生物转化」理解。**

**论「风险」的一侧**：
- **CH₄ 的全球暖化潜势远高于 CO₂**（百年尺度 GWP 约为 CO₂ 的 28–30 倍，20 年尺度约 80 倍）——**同样的碳，泄漏出去后的气候伤害更大**。
- **CH₄ 的分子更小、黏度更低、在水中溶解度远低于 CO₂** → **更容易穿过盖层微裂隙迁移，也更难被 solubility trapping 拿下**（推断，但物理上稳固）。
- **它把碳从「正在走向矿化」的轨道上拉走了**：CO₂ 才能矿化成碳酸盐（最安全的圈闭），CH₄ 不能。**19% 在 30 年内被转走，意味着最安全的那条路径被削弱了。**
- **产气会增加储层压力**，可能推高 §2.6.11 中 D（诱发地震）与 C（超过溢出点）的风险。
- **同一批微生物群落还可能做 sulfidogenesis（腐蚀 + 剧毒）与 bioclogging（堵塞注入井）**——ILO 5 幻灯片明列的三大有害活动。
- **核算问题**：如果封存量的核证 (MRV) 只测 CO₂，那么被转成 CH₄ 的部分会被**错误地记为「仍然封存着」**——这是**碳信用市场的诚信问题**。

**论「机会」的一侧**：
- **CH₄ 是有价值的能源产品**——理论上可以把枯竭油气藏当成一个「**生物甲烷反应器**」，注 CO₂、采 CH₄（这本质上是 microbial EOR / bio-methanation 的思路）。
- **讲者自己指出的机会**：**微生物或许可以加速 CO₂ → 碳酸盐的矿化转化 (expedite the conversion of CO₂ into carbonate minerals)**——如果能引导群落走这条路而非产甲烷，就是净收益。
- **acetogens 把 CO₂ 固定为生物质**也是一种圈闭（第 4 种机制的正面版本）。
- **AOM（甲烷厌氧氧化）** 的存在意味着系统里可能有**自我修复的负反馈**——产出的甲烷可能被再消耗（论文图 c 中列出了 AOM 的理论趋势箭头）。

**建议的结论姿态**：**取决于场址 (site-specific)**。关键变量正是幻灯片列出的 8 项 site-specific attributes（pH、redox、温度、压力、盐度、水化学、有机碳、微生物区系）——**这正是为什么 biogeochemical baselines 不可或缺**。「风险 vs 机会」的答案不是二选一，而是**「能不能被预测与管理」**。

### 讨论题 2
> **Is residual oil important in this scenario? How might this finding relate to CO₂ stored in saline aquifers?**
> （残余油在这个情景中重要吗？这个发现与盐水层中的 CO₂ 封存有何关联？）

**残余油为什么重要（几乎肯定重要）**：
- 产甲烷需要**电子供体（还原力）**。**氢营养型产甲烷需要 H₂**：$\mathrm{CO_2 + 4H_2 \to CH_4 + 2H_2O}$。
- 在 Olla 这样的 EOR 场址，**残余油与 kerogen 提供了有机碳**，经**降解 (degradation) 与发酵 (fermentation)** 产生 **H₂、乙酸等中间产物**，**为产甲烷菌供料**（正是 §2.7.6 概念图的左半边）。
- 讲者的类比：**kerogen 本质是天然 biochar**——本来难以利用，但微生物可以把它变成「非常容易取用的碳源，进而点燃一整串下游过程」。
- 此外 **1984 年的 water flooding（注水）** 也很关键：**注入的水既带来了水分（微生物必需），也可能带来硫酸盐与外来菌群**。

**外推到盐水层**：
- **盐水层缺乏残余有机碳** → **电子供体稀缺** → **产甲烷的燃料供应受限**。
- **高盐度对生命是很强的胁迫 (very stressful)**——讲者原话：**"not impossible, but you'd find a different type of life there"**（会是嗜盐/耐盐的类群，通常代谢速率更低、生物量更小）。
- ⭐ **因此合理预期：盐水层中的微生物产甲烷风险显著低于枯竭油气藏。**
- ⚠️ **但不能因此掉以轻心的三个理由**：
  1. **深部生物圈无处不在**——「地下绝对不是无菌的」；
  2. **工程化的介入本身会使环境变得宜居**（注入井带来水、压力扰动与可能的营养输入）；
  3. **盐水层恰恰是研究最薄弱的地层类型**（"we don't use them for anything else"）——**知识空白最大的地方，不确定性也最大**。
- **温度是另一个主控变量**：若盐水层足够深、温度超过 **122 °C 的生命上限**，则可完全排除微生物过程。

### 讨论题 3
> **What could be done in future CO₂ injection campaigns to anticipate this scenario?**
> （未来的 CO₂ 注入项目可以做什么来预先应对这种情景？How will we incorporate the learning from this study to monitor for this?）

**建议的答题结构（对应幻灯片 "Biogeochemical baselines are essential (and lacking)" 那一页）**：

1. **注入前建立生物地球化学基线 (pre-injection baseline)** — **这是讲者最强调的一条**：
   - **Who?** — 用 **16S rRNA 测序 + 宏基因组学** 确定群落组成与多样性；
   - **What?** — 用**宏基因组**确定**代谢潜力**（是否携带产甲烷、硫酸盐还原、产乙酸的基因）；
   - **Viable? Active?** — 用**转录组/蛋白组/活性测定**确认它们是否真的活跃，以及**生长速率**；
   - **in situ conditions?** — 完整的地球化学表征：pH、温度、盐度、TDS、压力、有机碳、金属、**电子供体与电子受体**。

2. **纳入示踪剂与同位素监测体系（本论文的直接方法学遗产）**：
   - **在注入气中加入或表征 noble gas 指纹（如 ³He、Ar）**——**因为惰性，不被化学/生物过程改造，是理想的守恒示踪剂**；
   - **常规监测产出流体的 δ¹³C(CO₂) 与 δ¹³C(CH₄)**，用**分馏方向**判断是否有微生物活动；
   - **必要时做 clumped isotope 分析**，独立判定甲烷是热成因还是微生物成因；
   - ⭐ **核心方法论**：**碳同位素会被过程改造，所以要配一个不会被改造的贵重气体做参照系**，两者结合才能定量拆分。

3. **设立对照场址 (control site)**：本研究之所以有力，正因为有 **Nebo-Hemphill 这个同地层、20 km 外、未注入的天然对照**。**未来项目应在设计阶段就规划对照井或注入前的本底井。**

4. **按地层类型分级管理风险**：枯竭油气藏（有残余有机碳）需要比盐水层更密集的微生物监测；超过 122 °C 的储层可豁免。

5. **考虑主动管理 (active management)**：
   - 抑制不利过程（如控制注入水的硫酸盐含量，避免 souring —— 这是油气行业已有的成熟做法）；
   - **引导有利过程**——探索**微生物介导矿化**的可能性（ILO 5 幻灯片明列的 "Opportunities"）。

6. **更新长期安全评估模型**：现有的圈闭时间演化模型（Bashir 2024）**根本没有把微生物碳循环画进去**。**19% / 30 年**这个数字说明——**在构造圈闭主导、矿化尚未接手的脆弱窗口期内，微生物过程可能是被低估的主要碳去向。**

7. **修订 MRV（监测、报告与核证）规则**：碳信用的核证必须**同时计量 CH₄**，否则会系统性高估封存量。

## 六、易错点 / 重点难点

### 6.1 概念辨析类

| # | 易错点 | 正确理解 |
|---|---|---|
| 1 | **CCUS vs CCS** | **CCUS** 含 **Utilisation**；**CCS** 只有 Capture + Storage（S 也可指 Sequestration）。讲座两个词都用，注意语境 |
| 2 | **Utilisation ≠ Removal（利用 ≠ 移除）** | ⭐ **最关键的辨析**。**只有 Storage 才是把 CO₂ 从大气中永久移除**；Utilisation 是**再利用**，目标是**避免产生新的 CO₂（趋向 net zero）**，**不是 net negative**。牢记那句引文：**"does not necessarily reduce emissions and does not necessarily deliver a net climate benefit"** |
| 3 | **圈闭机制有几种？** | ⭐ **六种，不是五种**。多数文献只列五种（structural, residual, solubility, mineral, adsorption），**漏掉了 microbial carbon cycling**。讲者特意点出这一点 |
| 4 | **最先生效 ≠ 最安全** | ⭐ **恰恰相反**：**structural trapping 立即生效但最不安全**（依赖盖层）；**mineral trapping 最晚出现但最安全**。这是 Bashir 2024 图的全部要点 |
| 5 | **同位素分馏的方向** | ⭐ 讲者自承易错。**生物偏好轻同位素 (¹²C)** → **产物 (CH₄) 相对贫化 ¹³C（δ¹³C 更负）**，**残余底物池 (CO₂) 相对富集 ¹³C（δ¹³C 更正）**。记忆口诀：**「生物挑轻的吃，产物变轻，剩下的变重」** |
| 6 | **为什么用 noble gases 而不只用碳同位素** | **碳同位素会被化学与生物过程改造**（这正是我们想研究的信号，但也让它不适合当守恒示踪剂）；**noble gases 惰性，不参与反应** → **理想的注入 CO₂ 示踪剂**。两者结合才能定量拆分 |
| 7 | **Enhanced rock weathering 是生物过程吗？** | ⭐ **不是**。讲者特别强调 **"this one is definitely not biological"**——它是**纯化学**的硅酸盐风化。它之所以算 nature-based，是因为**利用的是天然存在的反应** |
| 8 | **DAC 是 nature-based 吗？** | ⭐ **不是**。讲座中 **DAC 是唯一被明确归为 disruptive technology** 的捕集方案 |
| 9 | **绝对排放 vs 人均排放** | ⚠️ 幻灯片的国别排放图**是绝对值，未按人口归一化**。若考题给出这类图并问「谁责任最大」，**必须点出这个 caveat** |
| 10 | **归因单一极端事件** | ⚠️ **不能把单一野火/热浪直接归因于气候变化**——「气候」按定义需要 **30 年的数据**。正确表述是：**这类事件的风险上升是气候变化的既有预测** |
| 11 | **CO₂ 与 CH₄ 的储层含量方向** | ⚠️ 见 §4.2：讲者口误说 Olla 甲烷浓度更高。**实际是 CO₂ 更高（18 vs 1.02 mol%），CH₄ 更低（77 vs 92.6 mol%）**。论文的力量来自**同位素指纹**，不是浓度大小 |
| 12 | **M:D = 0.26 的读法** | ⭐ **M:D 是「产甲烷 : 溶解」之比**。0.26 意味着**溶解移除的 CO₂ 约为产甲烷的 3–4 倍**。别把比值方向读反 |
| 13 | **19% 是什么的 19%** | ⭐ **是「注入的 CO₂ 中被微生物转化成甲烷的比例」**，且**只用了 30 年**（论文说 "as much as 19%... only 30 years prior"）。对比目标：**数万年的安全期** |
| 14 | **domains vs kingdoms** | Woese 体系：**Bacteria、Archaea、Eukarya 是三个 domains（域）**。讲者口述的 "kingdoms" 不准确 |
| 15 | **深部地下是无菌的吗** | ⭐ **绝对不是**。**地球上大多数的细菌与古菌都在深部地下**（"the unseen majority"）。这是全讲最需要破除的误解 |

### 6.3 议题分析型题目的答题框架（本课的考试特点）

本课是**议题导向 (issue-led)** 的，论述题通常要求你同时处理**科学机制 + 数据证据 + 政策与社会维度**。建议的四段式：

1. **问题是什么**：明确界定（例：「地质 CO₂ 封存能否在数万年尺度上保持安全？」）
2. **成因机制**：给出物理/化学/生物机制（六种圈闭机制、五种泄漏情景、微生物碳循环）
3. **有哪些方案及其权衡**：用对照表的维度作答——**成本、能耗、成熟度、容量、风险、可逆性**
4. **证据强度与争议在哪**：
   - **强证据**：Sleipner 30 年运行史（技术可行性）；Tyne 2021 的对照场址设计 + 双重独立同位素证据（微生物产甲烷确实发生）
   - **弱证据/空白**：盐水层完整性的研究基础薄弱；「we still do not understand all the factors that encourage containment compromise」；**生物地球化学基线普遍缺失**；微生物碳循环未被纳入标准圈闭模型
   - **争议**：**EOR 是否应算作 CCS**；**油气行业主导 CCS 的道德风险与技术必要性**；**"storage" 这个词是否弱化了严肃性**；**CO₂ utilisation 的净气候效益存疑**

### 6.4 最容易被忽略但极可能考的三个「讲者立场」

1. **"Storage is a misnomer — think of it as disposal."**（含核废料类比）— **注意标注为讲者的 personal view**。
2. **"Everything, everywhere, all at once" → "we can't be picky and choosy."** — 用来为 DAC 这类低效方案辩护的价值论证。
3. **"It's not as black and white as saying they produce oil and gas therefore it's dirty."** — 关于油气行业角色的 nuance 论证，配合「hold them to account」与「policy needs to be involved」。

### 7.5 圈闭机制 (Trapping mechanisms)

| 英文 | 中文 | 一句话解释 |
|---|---|---|
| **Structural (& stratigraphic) trapping** | 构造（与地层）圈闭 | CO₂ 被物理性封闭在不透水盖层之下的构造中；**立即生效但最不安全** |
| **Residual trapping** | 残余圈闭 | CO₂ 在孔隙中被毛细力捕获成互不连通的液滴或气泡；**快速生效、全程重要** |
| **Capillary forces** | 毛细力 | 造成残余圈闭的力 |
| **Solubility trapping** | 溶解圈闭 | CO₂ 溶入地层水成为流体相的一部分，降低迁移潜势；**自发、随时间递增** |
| **Microbial carbon cycling** | 微生物碳循环 | CO₂ 经微生物代谢转成生物质或其他碳形态；**第六种机制，常被遗漏，双刃剑** |
| **Mineral trapping / Precipitation** | 矿化圈闭 / 沉淀 | CO₂ 与围岩反应生成稳定碳酸盐矿物；**最晚出现但最安全，是终极目标** |
| **Adsorption / Sorption trapping** | 吸附圈闭 | CO₂ 吸附到煤层表面并置换甲烷；仅限煤层 |

| **Metagenomics** | 宏基因组学 | 直接从环境样本测序全部 DNA；可得菌株级系统发育、草图基因组、新谱系、代谢潜力、病毒捕食史 |
| **Microbial dark matter** | 微生物暗物质 | 只在基因组数据中出现、从未被培养或表征的微生物类群 |
| **Methanogenesis** | 产甲烷作用 | 由产甲烷古菌进行的、与能量保存耦合的甲烷生成 |
| **Hydrogenotrophic methanogenesis** | 氢营养型产甲烷作用 | CO₂ + 4H₂ → CH₄ + 2H₂O |
| **Methanogen** | 产甲烷菌（古菌） | 执行产甲烷作用的古菌 |
| **AOM (Anaerobic Oxidation of Methane)** | 甲烷厌氧氧化 | 无氧条件下的微生物甲烷消耗 |
| **Sulfate-reducing bacteria (SRB) / sulfidogenesis** | 硫酸盐还原菌 / 产硫化物作用 | 把 SO₄²⁻ 还原为 H₂S 获取能量；造成油藏 souring |
| **Souring** | （油藏）酸化 | 注海水带入硫酸盐 → SRB 产 H₂S；**昂贵、极腐蚀、剧毒** |
| **Bioclogging** | 生物堵塞 | 微生物生长或其产物堵塞孔隙、降低注入性 |
| **Kerogen** | 干酪根 | 沉积岩中难溶的固体有机质；⭐ **讲者称其「本质上是天然的 biochar」** |
| **Biological fixation** | 生物固定（作用） | 微生物把无机碳转成有机碳的过程 |
| **122 °C** | 生命温度上限 | 已知任何生命形式所能耐受的最高温度 |

### 7.7 同位素地球化学（Paper of the Week）

| 英文 | 中文 | 一句话解释 |
|---|---|---|
| **Isotope** | 同位素 | 同元素、质子数相同而中子数不同的形式；质量不同但化学性质相同 |
| **Isotopic fractionation** | 同位素分馏 | 自然过程中某一同位素相对另一者的分离或富集；**生物总是偏好轻同位素** |
| **δ¹³C** | 碳-13 同位素比值（相对标准的千分偏差） | 用来判断碳的来源与经历过的过程 |
| **Clumped isotope / isotopologue** | 团簇同位素 / 同位素体 | 重同位素彼此成键的分子；**甲烷的团簇同位素可记录形成温度，从而鉴别成因** |
| **Internal isotopic equilibrium** | 内部同位素平衡 | 分子内同位素分布达到热力学平衡；**热成因甲烷的特征** |
| **Thermogenic methane** | 热成因甲烷 | 由高温热裂解有机质产生的甲烷；处于内部同位素平衡 |
| **Microbial methane** | 微生物成因甲烷 | 由产甲烷菌产生；**团簇同位素组成高度可变** |
| **Noble gases** | 惰性气体 / 贵重气体 | 周期表第 18 族（He, Ne, Ar, Kr, Xe, Rn）；⭐ **因惰性而成为理想的守恒示踪剂** |
| **³He** | 氦-3 | 深部流体运移的常用示踪剂 |
| **Endmember** | 端元 | 混合体系中的纯粹极端组分；图 a 中的两条端元轨迹为产甲烷与溶解 |
| **M:D ratio** | 产甲烷:溶解 之比 | Olla 场址为 **0.26**，即溶解移除的 CO₂ 约为产甲烷的三倍 |
| **Olla Oil Field** | 奥拉油田 | 路易斯安那州，1983–86 年做 CO₂-EOR 的实验场址 |
| **Nebo-Hemphill Oil Field** | 尼波–亨普希尔油田 | Olla 东南 20 km、同地层、未注入 CO₂ 的**对照场址** |
| **Black Lake Oil Field** | 黑湖油田 | 注入 Olla 的 CO₂ 的来源地 |
| **Water flooding** | 注水驱替 | 注入水以维持压力并驱油；Olla 于 1984 年进行 |
| **Control site** | 对照场址 | 未受处理的比较基准；本研究方法学力量的来源 |

## 附：一页速记（考前 10 分钟）

- **CCUS = 相互连结的工具箱**，三圆 Venn，**边界模糊**；**Utilisation ≠ Removal**。
- **捕集**：nature-based（土壤、栖地、造林、biochar、强化风化）+ disruptive（**DAC**、藻类、*Clostridium*/Wood–Ljungdahl、*Halomonas* 免灭菌、microbiome）。
- **封存三大地层**：**saline aquifer > depleted O&G > basalt**；**深度 > 800 m（超临界）**；三旗舰：**Sleipner 1996 / Carbfix 2012 / Gorgon 2019**。
- **六种圈闭**：structural（快、最不安全）→ residual（全程）→ solubility（渐增）→ **microbial（第六种、双刃剑）** → **mineral（最晚、最安全）**；+ adsorption（仅煤层）。
- **五种泄漏风险 A–E**：小断层微压 / **废弃井与断层通地表** / 溢出点与新裂隙 / **诱发地震** / **上倾运移污染地下水与大气**。
- **深部地下不是无菌的**；**122 °C 是生命上限**；油藏 **souring** 是警示案例（贵、腐蚀、剧毒）。
- **Tyne et al. 2021 Nature**：Olla（EOR）vs Nebo-Hemphill（对照，20 km）；**19% 的注入 CO₂ 在 30 年内被微生物转成 CH₄**；**M:D = 0.26（溶解移除约为产甲烷的 3 倍）**；**noble gas 惰性做示踪 + clumped isotope 定成因**。
- **三句必引**：Guterres **"everything, everywhere, all at once"**；**"storage is a misnomer — think of it as disposal"**；**"CO₂ utilisation does not necessarily deliver a net climate benefit"**。
- **政策/伦理**：**EOR 该不该算 CCS**；**油气行业既是唯一有能力者也是利益相关方**；**biogeochemical baselines 不可或缺却普遍缺失**。
