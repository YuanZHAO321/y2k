## 一、这门课在讲什么

### 1.1 真实定位：不是"固体地球过程课"，而是"地球系统各圈层动力过程课"

课程名字（A Dynamic Planet）和 Rhodri 在 Week 1 的自我介绍容易让人以为这是一门"火成—侵蚀—沉积—变质"的岩石循环课。**实际内容跨度远比这宽**：11 周里有 **5 周完全是大气、水圈、冰冻圈与气候**（W2、W4、W6、W8、W11），只有 6 周属于固体地球（W3、W5、W7、W9、W10，加 W1 导论）。因此本课的准确定位是：

> **以"驱动力—过程—记录"为统一框架，分别检视大气圈、水圈、冰冻圈、岩石圈内部正在运行的动力过程，最后用气候反馈把各圈层耦合成一个系统。**

Week 1 给出的总纲图已经写明了这一点：全课挂在**两条主线**上——
- **岩石循环 (Rock Cycle)**，由**地球内热**驱动（Rhodri 负责）；
- **水文循环 (Hydrological Cycle)**，由**太阳能**驱动（David 负责）。

老师反复强调这两条线**不是两个封闭的圆圈，而是重叠、互相反馈的**（火山排气改变大气成分；降雨中的弱酸风化岩石）。Week 11 的全部工作就是把这个"重叠区"展开讲透。

## 三、知识体系（按圈层与过程重组）——本节是重点

### 3.1 大气圈：辐射 → 环流 → 天气 → 化学（W2 / W4 / W6）

这是一条**从能量到运动、再到可预报性、最后到成分**的严格递进链。

**（1）能量层：三个调节旋钮（W2）**
地球表面温度由 **solar constant、albedo、greenhouse gas concentration** 三者共同决定。无大气 = −18 °C，现今 = +15 °C，**温室效应净贡献 33 °C**。关键是把机制说对：温室气体**不阻止能量外逃的总量**（顶层收支永远平衡），而是**提高了红外逃逸的难度**，迫使系统在更高温度下辐射出等量能量。反照率的作用**在能量收支上等价于"把太阳调暗"**——这条等价性直接支撑了 W8 的雪球地球与 W11 的冰-反照率反馈。

**（2）运动层：三圈环流与急流（W2）**
差异加热驱动环流，**自转把单圈打碎成三圈**；环流圈数 = f(自转速率, 行星大小)——木星土星有很多支急流，条带花纹即由此而来。必须记住的判读原则：**上升 = 云雨（ITCZ、极锋），下沉 = 干燥（副热带高压 → 全球主要沙漠）**。急流的三条性质（W2 幻灯片 40）贯穿后面所有周：
- 急流分隔极地气团与热带气团（→ W8 判图、W11 天气回顾）；
- **冬半球急流更强**（因为温度梯度最大）；
- 急流在宽阔山脉上空成脊、下游成槽（stationary Rossby waves）。

**（3）可预报性层：天气与预报（W4）**
Bjerknes 的两要素配方（**准确的初始状态 + 准确的演化定律**）是全课最重要的方法论框架之一——W8 直接把它推广到整个地球系统。三大失败原因正好对应两要素各自被打破的方式：**初值不完美 / 模式不完美（→ 参数化）/ 混沌（两周上限）**。温带气旋的挪威模式四阶段演化（初始波 → 开放波 → 锢囚 → 成熟）是"给天气图预测后续"的标准工具。

**（4）成分层：大气化学（W6）**
- **平流层**：Chapman 循环（两个互锁的齿轮，慢循环控制 odd oxygen 总量、快循环控制 O₃ 形态）；**催化循环**中 X（OH、NO、Cl、Br）**不被消耗**，一个 X 可摧毁上万个臭氧。**臭氧洞是与全球缓慢衰减完全不同的第二类机制**：极涡隔离 → 下沉 → 极冷 → PSCs → 非均相反应把惰性储库氯活化 → 冬季黑暗中累积 → 春季日出光解 → 灾难性损耗，并有"无臭氧 → 无 UV 吸收 → 无增温 → 极涡更稳定"的正反馈。
- **对流层**：一次 vs 二次污染物；**OH 是大气的"清洁剂"**（寿命 ~1 s 但浓度近恒定）；**平流层臭氧好、对流层臭氧坏**（老师说这是年年有人答错的点）；1952 伦敦大烟雾 = **高排放 + 高压 → 静风 + 逆温 → 污染锁在近地层**。

### 3.2 水圈与冰冻圈：密度分层、输运与反馈（W6 / W8）

**水圈（W6 后半）**的核心是**"海洋从上面加热" → 稳定层结 → 温跃层 → 抑制垂直混合**。这一条同时解释了三件事：为什么深海又冷又均匀、为什么营养盐上不来（→ 上升流的重要性）、为什么有机质能在底水缺氧中保存（→ W9 黑色页岩）。
其余骨架：环流圈（NH 顺时针、SH 逆时针）与西边界流（Gulf Stream、Kuroshio）；**盐度由 E − P 控制**（副热带最咸、ITCZ 与中纬最淡）——这是海洋盐度格局作为"大气环流在海洋里盖的印"的最佳例证；**Ekman 45° vs 90°** 的区分；沿岸风 → 离岸 Ekman 输运 → 上升流 → 高初级生产力。
方法论亮点：**"湾流让欧洲温暖"是神话**——真正原因是欧洲位于**不结冰海洋的下风向**。老师用它讲"科学不是固定的"。

**冰冻圈（W8）**的骨架是**组成 → 不对称 → 放大 → 深时**：
- 组成：海冰、冰盖、冰架、山岳冰川、**permafrost**、积雪、湖河冰（**云中冰晶不算**，属大气圈）。
- 南北不对称完全由海陆分布决定：南极是"被海洋环绕的大陆"，北极是"被陆地环绕的海洋"。
- **Arctic amplification（2–4 倍）**：冰-反照率反馈为主，叠加递减率反馈、Planck 反馈的纬度差异、经向热输送、薄冰效应、水汽与云、永冻土碳。
- 深时冰期序列：Huronian（GOE 氧化甲烷）→ Cryogenian 雪球（Rodinia 解体 → 风化）→ Hirnantian（陆生植物登陆）→ Late Palaeozoic（成煤埋碳）→ Late Cenozoic（构造抬升 + Milankovitch **加内部反馈**）。

**气候模拟（W8 后半）**是全课唯一的"方法论周"，必须掌握的分界：
> **输入 = 初始条件 + 边界条件（海陆/地形/植被）+ 外强迫（太阳常数、轨道参数）+ 不预报的设置（GHG 浓度）；输出 = 风、洋流、温压湿、降水、积雪、盐度、位势高度、云量、海冰。**
> **GHG 是输入（FOAM 没有化学模块），海冰是输出**——这两条是最高频的考点。
> 气候是**边值问题**，天气是**初值问题**："That's the lesson from chaos."

### 3.3 岩石圈—内动力：熔融、构造、变质（W3 / W5 / W10）

三周共用**同一张 P–T 思维图**，只是走的路径不同：

**W3（熔融）**：地球内部基本是固态，熔融必须**高度局部化 + 特殊条件**。三种越过固相线的方式，各自"动的东西"不同——
| 机制 | 动什么 | 深度 | 构造背景 | 熔体 |
|---|---|---|---|---|
| 加热（地幔柱/热点） | **右移 geotherm** | ~80–100 km | 板内 | basic |
| 减压（岩石圈减薄） | **移除"盖子"，浅部梯度变陡**（**不加热**） | ≲10 km | 洋中脊、大陆裂谷 | basic |
| 加水（俯冲） | **左移 solidus** | >80 km | 汇聚边界 | 变化大 |
| （造山增厚） | 右移 geotherm（保温） | 下地壳 | 陆陆碰撞 | felsic，**不产生火山** |

之后是**部分熔融 → 熔体总比母岩更长英质 → 只有 basic 与 felsic 两大类岩浆 → SiO₂ 控制黏度 → 黏度 + 挥发分 + 喷发速率控制爆发性 → 喷发方式 + 就位环境控制产物 → 产物比例控制火山形态**。这条链条是本课最长、最完整的一条因果链，也是最标准的论述题骨架。

**W5（构造与垂直运动）**：主线是"记住数字 3"——三种主应力配置 → 三种端元断层；三种垂直运动机制（**isostasy / flexural loading / dynamic effects**）；三种边界体制。核心概念是 **100 km 波长判据**：小于它可用局部（Airy）均衡，大于它必须用弹性挠曲。由此得到两个反直觉结论：**挤压背景（俯冲）里同时有抬升（岛弧）与沉降（弧后盆地，因 slab rollback）**；**陆陆碰撞同时有抬升（造山带）与沉降（前陆盆地，因挠曲负荷）**。全课最重要的一句大写强调也在这周：**ALL SEDIMENTARY ROCKS WERE DEPOSITED IN A SEDIMENTARY BASIN**。

**W10（变质）**：把 W5 的"压力"与 W3 的"温度"重新组织成一句关键简化：
> **构造背景强烈控制温度（地温梯度 3–5 至 >100 °C/km），但基本不控制压力（P ≈ ρgh，ρ 与 g 到处差不多）⟹ 实际上只剩一个自由变量 T ⟹ 变质矿物组合是构造背景的指纹。**

由此得到最经典的算例：**同样埋到 10 km，俯冲带只有 ~50 °C（高 P 低 T → 蓝片岩），洋中脊有 ~500 °C（低 P 高 T → 角岩/麻粒岩路径）**。另外两条不可省的结论：**偏应力不引起变质（在热的深部被塑性流动瞬时化解，"游泳池里出拳"），只控制组构**；**矿物组合记录的是峰期温度而不是峰期压力**（岩石导热差 → 热弛豫 → 弧形 P–T–t 路径）。而**不退变质**（缺活化能 + 挥发分已逃逸）正是变质岩能充当"深部记录仪"的根本原因。

### 3.4 岩石圈—外动力：侵蚀、沉积、成岩（W7 / W9 / W10 前半）

这三周是一条严格的**源—汇（source-to-sink）链**：

```
隆升（W5）→ 风化（原地削弱，不搬运）→ 侵蚀（搬走 regolith）
   ├ 重力：块体运动谱系（fall → slide → slump/creep → debris flow）
   │        强度递减 且 所需坡度递减（碎屑流可低至 <1°）
   ├ 流水：V 形谷（软岩高风化）vs 峡谷（硬岩低风化）；young → mature → old（peneplain）
   └ 冰川：继承并重新开挖先存河谷 → U 形谷、悬谷、冰斗、刃脊、角峰
                    ↓
沉积（W9）：搬运能力下降即沉积；但**长期保存必须在正在沉降的盆地里**
   ├ 河流：河道/天然堤/泛滥平原/决口扇；曲流的侧积面
   ├ 浅海：三种能量 → 三种海岸线（河流 = 凸出叶状；波浪 = 平直+沙嘴+潟湖；潮汐 = 喇叭形内凹）
   ├ 深水：重力流（周围水完全静止！）→ 海底扇 = 地球上最大的沉积体
   └ 非碎屑：有机泥/黑色页岩（高生产 + 缺氧保存 + 无稀释）、碳酸盐、蒸发岩
                    ↓
成岩（W10 前半）：压实（重组 → 破裂 → 压溶）→ 溶解 → 胶结 → 重结晶 → 矿物置换
                    ↓ 继续埋藏
变质（W10 后半）
```

**W7 与 W9 共享同一条力学原理**："**去限制 (de-confinement) → 摩擦面积增大或能量扩散 → 流速骤降 → 卸载**"。这条原理同时解释了**天然堤、三角洲、海底扇朵叶体**三种完全不同尺度的沉积体。这是全课"同一机制反复出现"的最好例子。

**W9 的动态平衡判据**（accommodation vs sediment supply）与 **W5 的隆升/沉降**、**W7 的侵蚀速率**构成一个完整的收支表：**空间 ≥ 沉积物 → 就地沉积；空间 < 沉积物 → 继续向下游搬运**。海岸线的最终位置就是这个平衡的解。

### 3.5 圈层耦合：气候反馈（W11）

W11 不新增过程，而是**把前面所有过程接成闭合回路**。五个实例的耦合结构：

| 反馈 | 正/负 | 它把哪两周焊在一起 |
|---|---|---|
| **硅酸盐风化反馈** | 负（地球的长期恒温器） | W7 的风化 × 大气 CO₂ |
| **冰-反照率反馈** | 正（可致状态突变） | W2 的反照率 × W8 的冰冻圈 |
| **冰川电锯 (glacial buzzsaw)** | 负（限制山高） | W7 的冰蚀 × W5 的造山 |
| **Rodinia 解体 → Sturtian 雪球** | **负后接正（接力）** | W5 的构造 × W3 的溢流玄武岩 × W7 的风化 × 反照率 |
| **温度梯度 → 环流 → 缺氧 → 黑色页岩** | 响应链，尾端为负反馈 | W2 的环流 × W6 的海洋 × W9 的沉积 |

**最重要的结构性洞见（Example 4）**：**同一事件中负反馈与正反馈可以先后接力**——硅酸盐风化（负）把系统缓慢推到临界点，冰-反照率（正）完成状态跃迁。这就是 tipping point 的一般结构，与 W8 雪球模拟中"缓慢降温 400 年、然后 10–20 年内崩溃"的图完全对应。

W11 的另一半是**人为强迫下五大圈层的响应**（大气、水圈、冰冻圈、岩石圈、生物圈各有独立证据），以及用 **Lear et al. (2020)** 的深时点检验 IPCC 的 **ECS 1.5–4.5 °C/倍增**——注意必须**校正慢反馈**才能比较。

## 四、跨周的核心思想与方法论

以下六条是**跨越两位老师、贯穿全部 11 周**的思想，也是把这门课从"知识堆"变成"体系"的关键。

**① 能量/物质的收支平衡视角。**
从 W1 的"能量分布不均 → T/P 梯度 → 质量与能量沿梯度运动 → 新位置不稳定 → 相变 → 密度改变 → 重力介入"这条链开始，全课几乎每一处都是收支：辐射收支（W2、W8、W11）、水汽收支 E−P（W6）、沉积物收支 accommodation vs supply（W9）、抬升 vs 侵蚀（W5、W7）、氧气供需（W9 缺氧）、CO₂ 源汇（W11）。
**答题信号**：只要题目问"为什么这里高/低/多/少"，先写收支的两端。

**② 驱动力—响应—记录 的三段式。**
Rhodri 的岩石都是"记录"，David 的天气都是"响应"。三段式在各周的实例：偏应力 → 变形 → 断层/褶皱（W5）；温度梯度 → 急流 → 天气图（W2/W4）；抬升 → 侵蚀 → 地貌（W7）；水动力 → 搬运 → 沉积构造（W9）；P/T → 反应 → 矿物组合（W10）；强迫 → 响应 → 代用指标（W11）。
**核心技能是反向使用**：从记录反推驱动力。这正是考试唯一真正考的东西。

**③ 尺度谱：时间与空间。**
本课的过程横跨 **秒（OH 自由基寿命）到 10⁹ 年（深时气候）**，**微米（云滴过饱和、PM2.5）到 10⁴ km（行星环流）**。几条必须内化的尺度对照：
- 可预报性：天气 **2 周**（大尺度）；气候统计特征则由边界条件决定（边值问题）。
- 响应时间：海冰**数月—数年** ≪ 山岳冰川**年—十年** ≪ 冰盖 **10³–10⁵ yr**。
- 反馈时间：冰-反照率**年—千年** ≪ 硅酸盐风化 **10⁵–10⁶ yr** ≪ 冰川电锯 **10⁵–10⁷ yr**。
- 变质/构造：造山 **10⁶–10⁸ yr**；最老洋岩石圈只有 **~200 Ma**（不断被俯冲消耗）。
**尺度还是判据**：软流圈的"塑性"只在地质时间尺度成立；冰的韧性/脆性取决于变形速率（"修眼镜架：慢慢弯会弯，猛拽会断"）。

**④ 将今论古（uniformitarianism）与它的限度。**
W1 的"空间读法"（今天不同的地方处在 Wilson 旋回的不同阶段）是这条思想的第一次亮相。W8 把它推到极致：**行星尺度环流（Hadley 环流、ITCZ 湿带、副热带干带、极锋急流）在整个地质历史中是稳定特征**，因此**只要知道古纬度就能推断古气候，进而推断沉积环境**。
**但 W11 立刻给出限度**：野外单点剖面上"辫状河 → 风成砂岩"的相变，**既可能是气候变了，也可能是板块把这块陆地漂进了另一个气候带**。区分二者需要**独立的古纬度约束（古地磁）+ 多点区域对比**。这是本课最好的一道方法论简答题。

**⑤ 正/负反馈与系统稳定性。**
负反馈 = 稳定、有自我调节（硅酸盐风化、冰川电锯）；正反馈 = 不稳定、可致状态突变（冰-反照率、极涡臭氧、永冻土甲烷）。三条必须掌握的推论：
- **判别方法是走完整圈回到起点变量比符号**，不能只写到中间。
- **"正/负"不含价值判断**。
- **多稳态与滞后（hysteresis）**：因为 α 本身是 T 的函数，能量平衡方程可有多个解 → 雪球模拟只出现两种终态；进出路径不重合 → 退出雪球需要 CO₂ 累积到极高。

**⑥ 模型是简化，简化处就是不确定性所在。**
这是 David 反复讲的态度，Rhodri 也有对应版本。
- 平衡态是**假设**：现实可能处于能量失衡（W2）。
- 参数化**必要但确实是简化**（W4）；分辨率决定哪些过程被显式解析（W8）。
- 地幔**并不是牛顿流体**，Airy 模型只是便于计算的假设（W5）。
- 岩石循环**不是简单的圆圈**，存在大量捷径与回路（W1，老师强调两次）。
- 变质作用的"封闭系统"其实不严格（挥发分会跑掉），而**这个"不严格"恰恰是不退变质的原因**（W10）——这是全课最漂亮的一次"例外反过来支撑结论"。
- **科学不是固定的**：湾流神话的推翻（W6）、"山脉阻挡冷空气"假说被压平地形对照实验证伪（W8）。

## 五、核心结论速查

**能量与辐射**
- 无大气 −18 °C，现今 +15 °C，**温室效应 = 33 °C**；责任气体 H₂O、CO₂、CH₄。（W2）
- 气候三旋钮：**solar constant / albedo / GHG concentration**。反照率的效果≈把太阳调暗。（W2）
- **暗弱年轻太阳悖论**：早期太阳暗（2.4 Ga 时 1100 W m⁻²，低 19%），靠高浓度温室气体维持液态水。（W2/W8）

**环流与天气**
- 环流圈数 = f(自转速率, 行星大小)；不自转 = 1 圈。（W2）
- **上升 = 云雨（ITCZ、极锋）；下沉 = 干燥（副热带高压 → 沙漠）**。（W2）
- 急流三定律：分隔冷暖气团 / 冬半球更强 / 在宽阔山脉成脊、下游成槽。（W2）
- **DALR = g/c_p ≈ 10 °C/km（恒定，升降对称）；MALR 5–8 °C/km（本课取 5）**；下山全程用 DALR 且 **Td 冻结不变** → rain shadow。（W2）
- **可预报性上限 = 两周**（大尺度）；温带气旋由**温度梯度/急流**驱动，热带气旋由**潜热释放**驱动。（W4）
- 观测 ≠ 预报（老师点名的考试易错点）。（W4）

**大气化学与海洋**
- Chapman 循环 R1–R5；**催化循环中 X 不被消耗**；X = OH、NO、Cl、Br。（W6）
- **平流层臭氧好，对流层臭氧坏**；臭氧洞 ≠ 全球衰减（需极涡 + 下沉 + 极冷 + PSCs + 黑暗积累 + 春季日出）。（W6）
- 高压 = 好天气 ≠ 好空气：**静风 + 逆温 = 最糟的空气质量**（1952 伦敦大烟雾）。（W6）
- **盐度：副热带最高（E>P），ITCZ 与中纬最低（P>E）**。（W6）
- **Ekman：表层流偏风向 45°，整层净输运偏 90°**（NH 右、SH 左）→ 上升流。（W6）
- 浅化时 **wave height 增大**；离岸流要**平行海岸游**；海啸在船上要**驶向深水**。（W6）

**冰冻圈与气候模式**
- **海冰融化不抬升海平面**；抬升海平面的是陆基冰与热膨胀。（W6/W8）
- 北极最小值在 **9 月**（纪录 2012），南极最小值在 **2 月末**（纪录 2023）。（W8）
- **Pleistocene 冰期 = Milankovitch + 内部反馈**（轨道只是起点）。（W8）
- 雪球进入的临界：**冰缘推进到距赤道 20–25° 以内** → 数十年内崩溃；退出靠**火山排 CO₂ 而风化汇与海洋汇同时被冰关闭**。（W8/W11）
- 模式：**GHG 是输入，海冰是输出**；气候 = 边值问题，天气 = 初值问题。（W8）

**火成作用**
- 三种熔融机制及其"动的东西"：**热点动 geotherm，俯冲动 solidus，减压动的是盖子（不加热）**。（W3）
- **熔体总比母岩更长英质**；只有两大类岩浆：basic 与 felsic。（W3）
- 黏度三控制：**T↑黏度↓；SiO₂↑黏度↑；溶解 H₂O↑黏度↓**。上升过程中三者同向使黏度升高。（W3）
- **爆发三条件：SiO₂ 富、H₂O 富、喷发速率高**；碎裂判据 = 气体体积 > 液+固体积。（W3）
- **造山带熔融几乎不产生火山**（只有 pluton）；**冰岛是"洋中脊不产生陆上火山"的唯一大例外**（热点重合）。（W3）
- 洋中脊 **18 km³/yr** vs 大洋岛屿 **4 km³/yr**；洋中脊总长 65,000 km；最老洋岩石圈 ~200 Ma。（W3）
- 粒径界限：**ash < 2 mm < lapilli < 64 mm < bombs/blocks**。（W3）

**构造与垂直运动**
- Anderson 三种断层：**σ1 垂直 = 正断层（~60°，地壳变薄）；σ3 垂直 = 逆冲（~30°，变厚）；σ2 垂直 = 走滑（厚度不变）**。判正/逆只看**上盘升降**。（W5）
- **褶皱的应变量看紧闭度（翼间角），不看尺度**。（W5）
- **Airy = 厚度变化；Pratt = 密度变化**；山根 b ≈ 4.5 h。（W5）
- **100 km 波长判据**：< 100 km 用局部均衡；> 100 km 由弹性挠曲完全补偿（苏格兰上升 / 南英格兰下沉）。（W5）
- **Passive rifting：先拉张后上涌（Basin and Range）；Active rifting：先上涌后崩塌拉张（East African Rift）**——顺序不能反。（W5）

**外动力与沉积**
- **厚土 = 风化慢**（自限效应）；风化速率高需要 **降雨多 + 温度高 + 坡陡（relief，不是海拔）**。（W7）
- 块体运动谱系：**强度递减 且 所需坡度递减**；碎屑流可低至 <1°。（W7）
- **V 形谷 = 软岩高风化（谷壁破坏）；峡谷 = 硬岩低风化（谷壁不坏）**；U 形谷与峡谷都有陡壁，**必须交叉验证**（悬谷、冰斗、刃脊、角峰、misfit river、无分选冰碛）。（W7）
- 冰川**继承并重新开挖先存河谷**；冰碛的标志是**完全无分选**。（W7）
- **长期保存必须在正在沉降的沉积盆地里**（老师说"只记一件事就记这个"）。（W9）
- 三种海岸线：**河流 = 凸出叶状（三角洲）；波浪 = 平直（沙嘴、障壁、潟湖）；潮汐 = 喇叭形内凹（河口湾，分形嵌套）**。（W9）
- **深水重力流不是水下的河流**——周围水完全静止，驱动力是超额密度；海底扇是**地球上最大的沉积体**。（W9）
- 有机质富集 = **高生产 + 缺氧保存 + 无稀释**；缺氧有两条独立路径（高生产力耗氧 / 受限盆地混合差，如黑海）。（W9）
- 碳酸盐：**需要光与营养盐，促进条件是温暖，抑制条件是异常 pH 与异常盐度**；三类台地 = 镶边陆架 / 孤立台地（环礁）/ 缓坡。（W9）
- **蒸发岩 = 极好的古气候（干旱）与古地理（封闭/受限）指标**；露头系统性偏向石膏（石盐极易溶）。（W9）

**成岩与变质**
- 成岩 vs 变质四判据：驱动因素 / 开闭系统 / 沉积结构是否可辨 / 产物；两者**渐变过渡**。（W10）
- **白云石化使矿物体积 −11%、孔隙度相应增加**（少数利好储层的成岩过程）。（W10）
- 地温梯度：俯冲带 **3–5**，平均 **25–30**，盆地 ~**35**，洋中脊 ~**50**，火山区 **>100** °C/km。（W10）
- **构造背景控制温度，基本不控制压力**（P ≈ ρgh）→ 只剩一个自由变量 T。（W10）
- **偏应力不引起变质，只控制组构**；**矿物组合记录峰期温度而非峰期压力**。（W10）
- **蓝片岩 = 俯冲带的唯一指纹**（只有那里能同时给出高 P + 低 T）。（W10）
- **不退变质的两个原因**：冷却时失去活化能；脱挥发分反应把 H₂O/CO₂ 排走。→ 变质岩因此成为深部过程的记录仪。（W10）
- 变质级升高 = 粒度增大，**唯一例外是断层带（动力变质，粒度减小）**。（W10）
- 变斑晶 (porphyro**blast**, 新生长) vs 残斑 (porphyro**clast**, 残余)。（W10）

**反馈与人为变化**
- 五个反馈实例及其正负（见 §3.5 表）。（W11）
- **Rodinia 解体本身不够，必须有热带溢流玄武岩**：pCO₂ 1830 → 510 ppm（降温 8 °C，未进雪球）→ 加热带玄武岩后 **< 250 ppm** → 雪球。（W11）
- **冰川电锯在高纬失效**：冻结于基岩的冷底冰川**保护**山体（Patagonia、Antarctica、Alaska）。（W11）
- 温室气候链条不能跳步：**弱温度梯度 → 环流减弱 → 深水通风差 → 缺氧 → 有机质不分解 → 黑色页岩**。（W11）
- 深时敏感度必须**校正慢反馈**才能与 IPCC 的 ECS（**1.5–4.5 °C/倍增**）比较。（W11）
- 人为变化影响**全部五个圈层**，各有独立证据（盐度扩张 0.184 g/kg、海洋酸化、北极海冰、616 个钻孔的地表温度史、永冻土爆发坑、京都樱花物候自 812 年）。（W11）

### 6.2 全课最容易失分的十个点

1. **岩石循环 ≠ 简单圆圈**；两条主线**不封闭、互相反馈**（W1）。
2. **绝热计算中 Td 的行为**：未饱和上升不变、饱和后与 T 同降、下山冻结（W2）。
3. **观测 vs 预报的术语纪律**（W4）；**参数化不负责观测质量控制**（W4）。
4. **减压熔融不加入任何热量**（W3）。
5. **判正/逆断层只看上盘升降，不看倾向**（W5）；**褶皱应变看紧闭度不看尺度**（W5）。
6. **高盐度在副热带不在赤道**（W6）；**平流层臭氧好、对流层臭氧坏**（W6）。
7. **海冰是模式输出不是输入**（W8）；**Milankovitch 必须加内部反馈**（W8）。
8. **厚土 = 风化慢**（W7）；**只凭陡壁不能判定冰川成因**（W7）。
9. **深水重力流不是水下的河流**（W9）；**沉积 ≠ 长期保存**（W9）。
10. **偏应力不引起变质**（W10）；**冰川电锯在高纬失效**（W11）。

### 8.4 与 Chemistry of the Earth 及其他

- **W6 的大气化学**（Chapman 循环、催化循环、OH 自由基、光解、非均相反应）是本课与地球化学课程最直接的接口：反应式、活化能、催化剂定义、自由基概念都可直接迁移。
- **W9 的蒸发岩矿物学**（方解石/白云石、石盐/钾盐、石膏/硬石膏）与**离子来源**（陆地风化 + 洋中脊热液）是水化学与低温地球化学的内容。
- **W10 的同质多象、脱挥发分反应、活化能**是相平衡与矿物化学的直接应用；calcite + quartz → wollastonite + CO₂ 是经典的变质反应例。
- **W11 的碳循环**（硅酸盐风化是净汇、碳酸盐风化净零；δ¹³C 与 δ¹⁸O 代用指标）是同位素地球化学的接口。
