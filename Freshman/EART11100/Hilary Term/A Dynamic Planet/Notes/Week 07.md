### 1.3 全周逻辑主线（因果链条总纲）

```
抬升（均衡/挠曲/动力地形/火山）
   ↓ 新鲜基岩暴露于地表
风化 weathering（原地物理+化学破坏，不搬运）
   ↓ 生成风化壳 regolith / 土壤
侵蚀 erosion（搬走 regolith）
   ├─ 机制 1：重力 gravity —— 坡地过程 / 块体运动 mass wasting
   │        （落石 → 滑动 → 滑塌/蠕变 → 碎屑流；所需坡度递减）

            ├─ 水流 fluvial（重力驱动）
            ├─ 冰流 glacial（重力驱动）
            └─ 气流 aeolian（气压梯度驱动）
   ↓
地貌 geomorphology（V 形谷 / 峡谷 / U 形谷 / 冰斗 / 刃脊 / 角峰 / 准平原……）
   ↓ 若 侵蚀 > 抬升，持续 denudation（剥蚀）
地貌演化序列：young → mature → old（peneplain 准平原）
```

## 二、核心概念

### 2.1 两类地貌：侵蚀 vs 沉积 (Slides 4–6)

老师说：世界上你看到的地景，基本上**只分两类**。

| 对比项 | **侵蚀地貌 Erosional Landscape** | **沉积地貌 Depositional Landscape** |
|---|---|---|
| 主导构造过程 | **抬升 uplift** | **沉降 subsidence** |
| 主导地表过程 | **风化 + 侵蚀** | **沉积物堆积 deposition** |
| 地形起伏 relief | **高起伏 (high relief)** | **低起伏**：若已被沉积物填满则非常平坦；若未填满则被湖或海淹没 |
| 地表物质 | 裸露正在被侵蚀的**基岩 (bare eroding bedrock)**，或覆盖**风化产物 (regolith)** 的表面 | 基岩被**埋在数十至数百米（甚至更厚）沉积物之下** |
| 本周是否讲 | ✅ 本周唯一焦点 | ❌ 两周后再讲 |

> **识别口诀（老师原话意译）**：看到明显的地形起伏 + 裸露基岩 / 薄层风化壳 → 多半是侵蚀地貌；看到极平坦、基岩被厚沉积物埋藏 → 多半是沉积地貌。

**关键案例：Death Valley, California（死谷，美国加州）(Slide 6)**
- 这是老师特意选的"一张图看尽两类地貌"的地点：**在几公里范围内同时看到侵蚀地貌与沉积地貌**。
- 图上一条红色的**大型（正）断层 (normal fault)** 把画面切成两半：
  - 右上盘块体 = **抬升 (uplift)** → 高起伏、裸露基岩、局部覆盖薄层 regolith；
  - 左下盘块体 = **下掉 (downthrown) / 沉降** → 河流把上盘侵蚀下来的沉积物搬下来堆积，形成**光滑平坦的表面**，基岩被埋在厚沉积楔之下。
- 老师提醒：**现实中这两类地貌很少像死谷这样并置得如此清楚**，多数时候你一次只看到其中一类。

### 2.2 风化 (Weathering) —— 定义与类型 (Slides 9–10)

**定义（务必与侵蚀区分）**：
> **风化 = 岩石在原地 (in place / in situ) 发生的物理与化学破坏，是"削弱"岩石的过程，不涉及搬运。**
> **侵蚀 = 把已经生成的 regolith 搬走并运到别处。**

老师用照片解释：有人挖了一条探槽，底部是坚硬基岩，向上逐渐变成碎块状、松散状，最上面长草 —— 这个自下而上"逐渐被削弱"的剖面就是 regolith / 土壤剖面的形成过程。

**风化发生的前提**：抬升（均衡、挠曲、动力效应，Week 5）或**火山作用**（Week 3）把新的岩石送到地表，使其**第一次可以被风化**。

#### 物理（机械）风化 physical / mechanical weathering
| 过程 | 机制 | 发生条件 |
|---|---|---|
| **冻融楔裂 frost wedging (freeze–thaw)** | 水进入裂隙；水是"怪异物质"——**固相体积大于液相**，结冰膨胀把裂隙撑开 | 温度需要（至少一年/一天中的一部分时间）降到冰点以下 |
| **剥离作用 exfoliation (heat–cool, peeling)** | 昼夜温差导致岩石体积反复胀缩，逐渐削弱岩体并产生新裂隙，呈层状剥落 | 昼夜温差大的地区（如沙漠）最显著 |
| **植物作用 action of plants** | 根系长入裂隙，生长时把岩石撑开 | 老师注：**自志留纪 (Silurian) 陆生植物出现以来**才有此过程（转写里说的"43 years ago"显然是"约 430 Ma"的转写错误） |

#### 化学风化 chemical weathering（**永远以水为媒介**）
清单（Slide 10）：**水解 hydrolysis、水合 hydration、碳酸化 carbonation、氧化 oxidation、离子交换 ion exchange、螯合 chelation**。

- 老师补充的机理要点：**雨水本身呈弱酸性（弱碳酸 carbonic acid）**，能驱动这些反应。
- 两条统一的结果（这是考点式的归纳）：
  1. **生成体积不同的新矿物** → 体积变化在岩石内部产生应力 → **从根本上削弱岩石**；
  2. **矿物溶解 (dissolution)** → 物质以溶解质 (solute) 形式带走。
- 老师提到这部分与 A Sustainable Planet 里 Vicky Coker 讲的**土壤形成过程**重合，可互相参照。

### 2.3 风化速率的控制因素 I：气候 (Slides 11–13)

**核心结论**：**风化速率受气候控制。**

- **降雨多** → 提供化学风化必需的水 → 化学风化快。
- **太冷** → 水以**固相（冰）**存在，无法充当化学反应的媒介 → 化学风化受抑（转而以物理风化如冻融为主）。
- **温度高** → **纯热力学效应**：反应速率随温度升高而加快。

**Slide 12 图（气候–风化壳厚度图）的判读**：
- 老师亲口吐槽：**这张图的坐标轴被作者"反过来"画了** —— 降雨量向**左**增大、温度向**上**减小，很反直觉。他说"**如果你不喜欢这个画法，在自己笔记里把它翻过来画**"。
- 图的实质结论：**高降雨 + 高年均气温 → 风化（尤其化学风化）速率最高、风化剖面最厚**；降雨减少 → 化学风化减弱；温度降低 → 逐渐转向以冻融为代表的物理风化为主。

**纬向剖面：regolith 深度随纬度的双峰式分布（老师详细讲了这张示意剖面）**
从赤道到极地：

| 纬度带 | 温度 | 降水 | Regolith / 土壤剖面深度 | 原因 |
|---|---|---|---|---|
| **赤道 / 热带 (low latitude)** | 高 | 很高 | **最深** | 又暖又湿，化学反应最快 |
| **副热带 / 沙漠带 (subtropics, extratropics)** | 仍很高 | **极少** | **很浅、发育极差** | 缺水，化学反应无法进行 |
| **温带 (temperate，英国所在)** | 较凉 | 相当湿润 | **中等厚度** | 有水可驱动化学反应，但温度限制速率 |
| **极地 (high latitude)** | 低 | 干（且大量被冰覆盖） | **很薄** | 又冷又干；且地表被冰覆盖，谈不上土壤发育 |

→ **形成"双峰 (bimodal)"式的 regolith 厚度纬向分布**（热带一个峰、温带一个次峰，中间被沙漠带的低谷分开）。老师说这与 Dave Schultz 讲的大气环流内容高度呼应（哈德利环流控制降水带）。

**两个对照实例 (Slide 13)**：
- **Snowdonia, UK（威尔士斯诺登尼亚）**：中–高纬度、中等海拔（~1000 m）→ **块原 (blockfield) + 极薄的 regolith**；破碎方式以**机械破碎**为主。
- **Kerala, India（印度喀拉拉邦）**：低纬度、低海拔 → **极厚的红土型风化壳 (laterite regolith)**；又湿又热，化学风化把剖面做得非常深。

### 2.4 风化速率的控制因素 II：坡度 (Slides 14–17)

这是老师认为**"稍微复杂但非常基础、非常重要"**的概念，也是他自评"处于大一学生理解上限"的概念（所以**极可能是考点**）。

#### (a) Regolith 生长是**自限的 (self-limiting)**
因果链：
1. 风化向下推进 → regolith 变厚 → **地表到新鲜基岩的距离 X 增大**；
2. 同时，**粒径变小 + 生成黏土 (clay)** → **渗透率 (permeability) 降低** → 水更难到达深处；
3. 于是**水（以及冻融等地表过程）无法抵达反应锋面 (reaction front)**；
4. → **风化速率沿 regolith 剖面向下递减**，最终在**完全平坦**的地方达到一个"**极限深度**"，风化基本停止。

> 老师的形象说法：**厚土层反而"保护"了下面的基岩不再被风化。**

#### (b) 打破自限的办法：**把 regolith 搬走**
- 若 regolith **被迅速（或持续）移走**，水就能重新接触反应锋面 → **风化速率提高**。
- **而移走 regolith 的速率取决于坡度梯度 (slope gradient)**（重力）。

#### (c) 坡度 → 风化速率的三档对照 (Slide 15，配 **Mont Aiguille, French Alps**照片)
| 坡度 | Regolith 移除 | 风化速率 |
|---|---|---|
| **陡坡（近垂直崖壁，如 Mont Aiguille 顶部）** | **瞬时移除 (instantaneous removal)** —— 岩石一被削弱立刻靠重力滑落 | **高** |
| **中等坡度** | 中等移除 | 中等 |
| **低坡度 / 平地（照片下部）** | 移除很慢，土层留在原地 | **低** |

> **反直觉之处（老师特别点出）**：照片下部那层**又厚又漂亮的土壤**，恰恰是**风化速率最低**的地方；上面**几乎没有土**的陡崖，才是**风化最快**的地方。**厚土 ≠ 风化快。**

#### (d) 风化限制型 vs 搬运限制型坡地 (Slides 16–17) —— 高阶概念
| 类型 | 定义 | 表观特征 | 速率关系 |
|---|---|---|---|
| **风化限制型坡 weathering-limited slope** | **搬运过程效率极高**，碎屑被移走的速度**快于**风化产生它的速度 | 地表几乎总是**裸露基岩、regolith 极薄** | 整体剥蚀速率被**风化**这一步"卡住"（限制） |
| **搬运限制型坡 transport-limited slope** | **风化产生碎屑效率高**，但**搬运过程效率低**，无法及时把碎屑移走 | **厚 regolith** 堆积在坡上 | 整体剥蚀速率被**搬运**这一步"卡住" |

> 注意老师的补充口径：他说 transport-limited 的地方"**weathering rates are fundamentally actually highest**"（这里指风化**产生碎屑**的能力最强）。**理解要点**：两个术语描述的是"**哪一步是瓶颈**"，不是"哪一步慢"。

### 2.5 风化小结 + 全球风化速率图 (Slide 18)

**风化速率（= 沉积物生成速率）在以下条件下高：**
1. **降雨丰沛 + 温度高**的地区；
2. **坡度陡（因而地形起伏大）**的地区。
3. ⚠️ **注意正反馈 (positive feedback)**：高地形 → **地形雨 (orographic rainfall)**（Dave 的课） → 降水更多 → 风化更快 → ……

**全球风化速率图判读（老师逐块讲解）**：
- **热带辐合带 (ITCZ) 所在的热带**：风化速率**很高**；
- **副热带干旱带**：风化速率**很低**；
- **温带**：回到中等–较高；
- **叠加在气候带之上的"细长高值条带"= 主要造山带 (major mountain belts)** —— 因为坡度陡。
- 老师特别纠正一个易错说法：**不能只说"高的地方"风化快，必须是"有起伏 (relief) 的地方"** —— 需要有相对于基准面的**坡**，物质才能被搬走。

### 2.6 侵蚀的两大机制 (Slides 22 / 34 / 51 —— 三次重复出现，说明是骨架)

> **侵蚀 (erosion) = 移走风化生成的 regolith 并把它搬到新地点。**

1. **重力 gravity**：在陡坡区，物质靠自身**重力势能 (gravitational potential)** 从抬升区（山脉、腹地）运到低地（沉积盆地）。→ 坡地过程 / 块体运动。
2. **流体流动 fluid flow**：流体施加**剪应力 (shear stress)** 把物质从一处推到另一处：
   - **水流（河流/溪流）—— 流水过程 fluvial**（水的流动本身由重力驱动，沉积物则靠水的挟带）；
   - **冰流 —— 冰川过程 glacial**（重力驱动）；
   - **气流（风）—— 风成过程 aeolian**（由**高气压区流向低气压区**驱动 —— 注意这是本课唯一由**非重力**梯度驱动的营力）。

> ⚠️ 老师在冰川段开头亲口说：「**我这堂课有一个大洞 (a gaping hole)：你需要知道风也能干同样的活，但我不打算讲它。**」→ **风成过程本周未展开**，见第三节表格中的"补充"标注。

### 2.7 坡地过程 / 块体运动 (Hillslope processes / Mass wasting) (Slides 22–30)

**术语统一（老师专门道歉澄清）**：**hillslope processes = gravity movement = mass wasting**，幻灯片上用了不同的词，**意思完全一样**。

**发生条件与意义**：
- 由**陡峻地形**触发（该地形**常常本身就是流水或冰川侵蚀加陡**的结果 → 又一次体现"多过程叠加"）；
- 是**最壮观**的侵蚀–搬运过程之一；
- 是**对生命与基础设施的重大灾害 (hazard)**；
- **也能发生在海底 (submarine settings)** —— 只要坡度允许。

#### 块体运动谱系（Slide 23 / 29 的核心图，务必背下这个顺序）

按**运动物质的强度 (strength) 递减**排列，同时**启动所需坡度 (gradient) 也递减**：

| 顺序 | 类型 | 力学行为 | 强度 | 所需坡度 |
|---|---|---|---|---|
| 1 | **落石 Rock fall** | **脆性 Brittle** | 最高 | **最陡** |
| 2 | **滑动 Slide** | 脆性 | ↓ | ↓ |
| 3 | **滑塌 Slump（快）/ 蠕变 Creep（慢）** | **韧性 Ductile** | ↓ | ↓ |
| 4 | **碎屑流 Debris flow** | **流体 Fluid** | 低 | **可低至 <1°**（老师原话） |
| 5 | **浊流 Turbidity current & 火山碎屑流 Pyroclastic flow** | 流体（特例） | — | — |

> **两条平行的趋势要一起记：物质越弱 → 越像流体 → 启动所需坡度越小。**
> 第 5 类是**特例**：与**火山**和**水下 (subaqueous)** 条件相关，**本周不讲，留到两周后的沉积讲座**。

#### 各类型详解

**① 落石 Fall (Slide 24)**
- **机制**：脱离 (detachment) 时**几乎没有剪切 (little or no shear)**，就是"掉下来"；随后通过**自由落体、弹跳 (bouncing)、滚动 (rolling)** 运动。
- **发生地**：**冰川谷、峡谷 (canyon)、海崖 (sea-cliff)** 等**谷壁陡峭**的地貌区；需要**很硬的基岩 + 很陡的坡**。
- **识别标志**：崖底堆积的碎块及碎块堆 → **岩屑堆 / 倒石堆 (talus)**。**talus 是"落"这一过程的良好指示物**。

**② 滑动 Slide (Slide 25)**
- **机制**：沿**一个或数个剪切面 (surfaces of shear)** 脱离并运动，剪切面表现为**滑脱疤 (scar) 和断层**；**块体内部只有有限的脆性变形**（破裂、断层）。
- **关键判据**：**运动块体基本保持原形状**，整体沿面下滑。

**③ 滑塌 Slump (Slides 26–27)**
- **机制**：同样沿剪切面运动，但块体内部同时发生**脆性 + 韧性变形（断层 + 褶皱）**。
- **关键判据**：**块体在运动过程中彻底变形**，"出发时的形状已经不复存在"，被褶皱和撕裂。
- **对物质的要求**：比落石、滑动**更软** —— 通常是**未固结 (unconsolidated) 的沉积物 / regolith / 土壤**。
- **速度**：可以**灾变式 (catastrophic)** 整体崩落，也可以**蠕变 (creep)** —— 慢到肉眼察觉不到。

> **重点案例：Mam Tor Slump（英国峰区，同学们已在野外实习去过）**
> - 老师提问式强调：「你们在 Mam Tor 看到的那个东西，可能被叫作 landslide，但**它其实是一个 slump，不是 slide**」——**理由：运动块体不完整 (not intact)，在运动中发生了变形，物质本身软。**
> - **1970 年代切断了曼彻斯特–谢菲尔德之间的主干公路**。
> - **已经蠕变了数千年**；你站在那里时看不到它在动，**但它确实在动**。
> - 形态要素（Slide 27）：后方**弧形 (arcuate) 滑塌疤 (slump scar)** = 侵蚀区、物质原先占据的空间，呈"**圆形剧场 (amphitheatre) / 类冰斗**"状；前方**滑塌体 (slump mass)** = 舌状/杂乱的堆积体。

**④ 碎屑流 Debris flow (Slide 28)**
- **形成条件**：**水饱和 (water-saturated)** 的土壤/沉积物/regolith 发生破坏，**通常是灾变式滑塌而非蠕变**。
- **力学机理（老师讲得很细，是理解重点）**：
  1. 大量降雨渗入 regolith → 水**润滑 (lubricate)** 颗粒之间的接触 → **颗粒间内摩擦力大幅降低**；
  2. 块体运动赋予的**动能**使**颗粒相互碰撞并弹开 (collide and bounce apart)** → 颗粒之间出现可自由流动的空间；
  3. 结果：即使物质**含 >50% 的颗粒**，整体**表现得像流体 (behaves as a fluid)**。
- **搬运能力**：视频里可见**能搬运巨大的块体**。
- **危害**：对社会与基础设施构成重大威胁。
- **案例**：**2019 年环法自行车赛 (Tour de France) 被碎屑流打断**（老师放了 YouTube 视频）。
- ⚠️ **易错点（老师反复强调）**：新闻里常把碎屑流叫作 "landslide"，**但从科学角度这是完全不同的过程** —— **碎屑流是整体作为流体运动，而且它也不是河流 (manifestly not a river)**。

**⑤ 坡地过程的终点 (Slide 29)**
- 随着坡地过程**降低坡度**，行为从 fall/slide/slump **过渡到** debris flow（需要更低坡度）；
- **最终坡度低到重力势能不足以单独搬运物质** → **流水过程 (fluvial) 接管**搬运工作。

**⑥ 坡地地貌的野外识别 (Slide 30 "What to look for")**
- **陡崖 + 崖底一堆块体 (talus)** → 落石主导。（老师玩笑：合格的工程师会告诉别人**别在这里盖房子**。）
- **弧形 / 圆形剧场式的开挖疤 (arcuate, amphitheatre-like excavation) + 下方一坨杂乱沉积体** → 滑动、滑塌、碎屑流主导。
- 老师补充：很多时候你**看不到搬运下来的物质**，因为**河流过程已经接手**把它带走了。

### 2.8 流水侵蚀与地貌 (Fluvial erosion and geomorphology) (Slides 33–47)

#### (a) 水为什么能侵蚀 (Slide 35)
- **与风化一样，水是最重要的侵蚀营力。**
- 降雨落到土壤上 → **顺坡流动**；
- **因为水有黏度 (viscosity)，它能对颗粒施加剪应力 (shear stress)**，于是能：
  - **推移质 (bed load)**：大颗粒，在河床上**滚动 (roll) 与跳跃 (bounce)**；
  - **悬移质 (suspended load)**：小颗粒，悬浮在水体中被带走；
  - **溶解质 (dissolved load / solute)**：作为"万能溶剂"，把化学风化产生的**离子/溶质**溶解并搬运。
- **老师的现实延伸**：这套过程也正是**颗粒态污染物**的自然搬运机制 —— **微塑料 (microplastics)**、**永久性化学物质 (forever chemicals，如不粘锅上的 Teflon/PFAS)**。（他顺带说"那种锅别买"。）

#### (b) 河系的平面形态 (plan view) (Slide 36)
水往下流 → 细流汇成溪 → 溪汇成河 → 可达大陆尺度（Mississippi、Nile）。

| 分带 | 平面形态 | 主导过程 |
|---|---|---|
| **支流带 Tributive zone** | **树枝状汇聚**（小溪并入大河） | **侵蚀 erosion** ← **本周只关心这一段** |
| **中间带 Intermediate** | 过渡 | 过渡 |
| **分流带 Distributive zone** | **分叉发散** | **沉积 deposition**（两周后讲） |

> **考试用识别点**：**在地图/平面图上看到"汇聚型的树枝状 (tributive) 水系"= 正在侵蚀的河流系统**；这与下游沉积段的分流形态形成鲜明对比。

#### (c) 河谷横剖面：V 形谷 vs 峡谷（这是本节最重要的因果对照）

**共同起点**：河流**下切 (downcutting)** → **谷壁坡度不断变陡** → 谷壁开始受坡地过程支配。**接下来分两条路：**

| | **V 形谷 (V-shaped valley)** | **峡谷 / 嶂谷 (canyon / gorge)** |
|---|---|---|
| **岩性** | 岩石**软 (soft)** | 岩石**硬 (hard)** |
| **风化速率** | **高**（regolith 发育快） | **低**（regolith 发育慢） |
| **谷壁行为** | 变陡的谷壁**发生破坏 (fail)**，退到**平衡坡度 (at-equilibrium slope)** | 谷壁**不破坏**，保持陡立，河流继续深切 |
| **伴随的坡地过程** | **滑塌 slump + 碎屑流 debris flow**（老师补充：**滑动/滑塌是主角**） | **落石 falls** |
| **结果剖面** | 典型 **V 字形**，谷壁为渐变的缓坡 | **近垂直的陡峭谷壁**，**不是 V 形** |
| **物质如何进河** | 谷壁物质滑下来 → 降低谷壁坡度 → 同时**给河流供沙**，河流以推移质/悬移质带走 | 谷壁物质靠"落"进入河道 |

**案例**：
- **Madagascar（马达加斯加）(Slide 37)**：**温暖湿润**的气候促进风化 → 谷壁破坏 → 典型 V 形。
- **Tabernas, Spain（西班牙塔韦纳斯）(Slide 38)**：**风化速率低**（气候干燥），**但岩石极软**，且**植被稀疏**（根系无法把 regolith 绑住）→ 谷壁照样破坏 → 形成 **恶地地貌 (badland geomorphology)**；图上可标出 **tributary（支流）** 与 **at equilibrium slope（平衡坡度）**。老师补充趣闻：这里是 1960–70 年代拍**意大利式西部片 (spaghetti westerns)** 的地方。
  - > **这个案例的教学价值**：说明 V 形/恶地不一定要"高风化"，"**软岩 + 缺植被**"也能达到同样效果 —— 再次呼应"极少有单一控制因素"。
- **Lake District, UK（英国湖区，转写独有）(Slide 39 配图)**：河流切入**石灰岩 (limestone)**。
  - **关键机理**：石灰岩由**碳酸钙**组成，**相对容易被溶解** → **河流主要靠"溶解"向下切，而不是物理侵蚀**；
  - 但**石灰岩本身非常硬** → 谷壁不破坏 → 形成**陡壁**的峡谷型剖面。
  - > 这是"**化学侵蚀 + 力学强度**解耦"的绝佳例子。

#### (d) 河流地貌演化序列：young → mature → old (Slides 40–47)

**前提**：河系建立之后，**只要 侵蚀速率 > 抬升速率**，河流就会持续 **剥蚀 (denude)** 地貌 → 引发**地貌演化 (landscape evolution)**。
老师的拟人化说法：「**河流想做的事，就是把所有被抬升的岩石统统搬走**（当然河流没有意志）」。

**阶段 1：幼年期 "Young"（刚抬升不久）**
- **坡降陡 (steep gradients)**、高海拔；
- 侵蚀方式：**下切 (downcutting) + 溯源侵蚀 (headward erosion)**，标志是**裂点 (knickpoint)**，野外表现为**瀑布**；河流沿着一连串瀑布**向上游/向内陆切回去**；
- **河间地 (divides / interfluves) 宽阔且未被切割 (broad and undissected)** —— 因为**支流还没有时间发育**；
- **案例：Yellowstone River（美国落基山，黄石河上游）(Slide 41)** —— 该区**非常晚近才抬升**，河流刚开始改造地貌。图上可标出：**broad undissected interfluve（宽阔未切割的河间地）、headward erosion（溯源侵蚀）、downcutting（下切）、knickpoint/waterfall（裂点/瀑布）**；老师还在图上指出了**陡坡下的 talus 堆积**（落石）与**漂亮的 V 形剖面** → 又一次"多过程共存"。

**阶段 2：中期 "Intermediate / Mature"**
- 支流网**已经完全切割 (fully dissected) 原先的高地**；
- **整片区域被广泛的水系网 (extensive drainage network) 覆盖**；
- 侵蚀方式**改变**：从"下切+溯源"转为**横向侧蚀 (horizontal sweeping)** —— 河谷开始**横向拓宽**而非纵向深切；
- 发育**泛滥平原 (flood plain)** 与 **曲流 (meanders)**；
- **坡地后退 (slopes retreat)**，**河间地变窄**；
- 地貌整体表现为主要支流之间的**波状起伏丘陵 (rolling hills)**、**圆润的山丘 (rounded hills)**。
- **案例：River Severn 上游支流区（英国塞文河）(Slide 43)** —— 可见河谷已经比河道本身宽出一截，河流可在略微加宽的谷底**蜿蜒曲流**；支流之间是**圆润的丘陵**。

**阶段 3：老年期 "Old" / 成熟末期**
- 泛滥平原**继续加宽**，河流几乎只做侧向工作；
- **坡地后退直到彼此相遇** → 相邻河流之间**再无高地残留**；
- 形成**极其平坦、无特征的地面** → **准平原 (peneplain)**。
- **案例：Lower Mississippi Valley（密西西比河下游谷地）(Slide 45)** —— **该河已经占据此地约 40 Ma（4000 万年）**，**没有任何残余高地**，河流"已经完成了它的工作"。

**⚠️ 重要普适性说明（转写独有）**：这一套 young→mature→old 的演化序列，**在湿润软岩的 V 形谷体系和干旱硬岩的峡谷体系中同样适用** —— 幻灯片 47 的总结图就是把两行（"高风化+弱岩"的 V 形谷行 / "低风化+强岩"的峡谷行）× 三列（Young / Mature / Old）排成矩阵。**判读方法**：
- **先看谷壁形态定"岩性 + 风化"这一维**（V 形渐变坡 vs 陡立崖壁）；
- **再看河间地是否被切割、有无泛滥平原定"演化阶段"这一维**（宽阔平坦未切割 = Young；被水系完全切割 + 有泛滥平原和曲流 = Mature；完全平坦无高地 = Old/peneplain）。

### 2.9 冰川侵蚀与地貌 (Glacial erosion and geomorphology) (Slides 48–66)

#### (a) 冰川的形成与流动 (Slide 52)
- **成因**：**降雪量超过消融量 (excess of snow relative to melting)**；
- **雪 → 冰**：积雪被**压实 (compaction)** 形成冰；
- **流变**：冰**兼具韧性 (ductile) 与脆性 (brittle) 行为**，能**顺坡下流**，时间尺度为**年 → 数百年**（老师口述扩展为"**月 → 世纪 → 数千年**"）。
- **老师的类比（很好用）**：你从冰箱拿冰、砸冰时觉得它是脆性材料；**但和大多数材料一样，只要变形足够慢，它就表现为塑性/韧性**。就像修眼镜架：**慢慢弯它会弯，猛地一拽就断**。
- 交叉引用：冰冻圈 (cryosphere) 细节由 **Dave Schultz** 另行讲授（课上问过同学"你们学过 cryosphere 了吗"，答案是还没有）。

#### (b) 冰为什么侵蚀能力惊人 (Slide 53)
- **冰的密度比水小，但黏度 (viscosity) 高得多** → **侵蚀与搬运能力极其巨大**；
- 老师的极端例子：**房子甚至摩天楼大小的岩块**从谷壁掉到冰川上，**冰川运走它毫无压力** —— 冰川搬运**极高粒级 (calibre) 沉积物**的能力是巨大的。

#### (c) 冰川的空间组织（继承河谷！）(Slides 53–55)
- **谷冰川 (valley glacier) 通常形成于、并重新开挖 (re-excavate) 原有的主干河谷 (major fluvial trunk river valleys)**。
  - > **因果链关键**：**冰川不是随机分布的；它占据的是前一个（流水）阶段留下的河谷，然后从根本上改造其形态。** 这是"多过程叠加"的最强例证。
- 谷冰川由**冰帽 (ice caps)**、或由发育在**原先的河流支流谷**中的**较小的悬冰川 (hanging glacier) / 冰斗冰川 (cirque glacier)** 供给。
  - **悬冰川特征**：更**陡**，从高处把冰陡直地送下来喂养主谷冰川。
- **案例**：
  - **Aletsch Glacier, Switzerland（阿莱奇冰川，瑞士）** —— **阿尔卑斯最长的冰川**（幻灯片标注了下坡方向）；
  - **Bucher Valley Glacier, Alaska（阿拉斯加）** —— 展示**悬冰川**由后方**冰原 (ice field)** 供给；
  - **Baffin Island, Arctic Canada（加拿大北极巴芬岛）** —— 卫星影像上可见后方冰原与多条悬冰川分别喂养数条谷冰川。

#### (d) 冰川的四种侵蚀/搬运机制 (Slide 56) —— **必背**
| 机制 | 说明 |
|---|---|
| **① 上覆坠落 (supraglacial input)** | 物质通过**重力过程（落石等）掉到冰川表面**，被驮着走 |
| **② 拔蚀 / 掘蚀 (plucking)** | 冰川底部与基岩界面处，**暖季略微融化渗入、冷季在岩块周围再冻结 (melting then freezing around)**，把岩块**冻牢后拔起 (pluck)** 带入冰体 |
| **③ 磨蚀 / 粉碎 (pulverising / abrasion)** | 冰的力量在**底部与两侧**把岩石**碾碎**，碎屑被并入冰中 |
| **④ 推挤 (bulldozing / pushing)** | 冰川**前进（生长）阶段**，从**前端把沉积物往前推** |

#### (e) 沉积面：冰碛 (moraine) (Slide 57)
- 在**冰川前端 (front)**，被搬运的物质**原地融出 (melted out in situ)**；
- **所有粒级的沉积物被"一股脑倾倒"，完全没有分选 (unsorted)** → 堆成**冰碛 (moraines)**。
- > **识别要点**：**"无分选 (unsorted)"是冰川成因沉积物的关键标志**（与水流分选良好的沉积物形成对比）。

#### (f) 冰川如何改造谷形 → U 形谷 (Slides 57–59)
因果链：
1. 冰川**加深并拓宽 (deepen and widen)** 原有河谷；
2. **冰川底部相对平坦、两侧相对陡直**；
3. **由于巨大的荷载、高黏度与高力学强度**，冰川**推平/铲除 (bulldoze) 河谷中原有的弯曲与山嘴 (spurs)**，**把河谷拉直** —— 老师原话："冰川不喜欢拐弯，**它宁可直着往下走**"；
4. **结果**：**平直、深、谷底很宽的 U 形谷 (U-shaped valley)**。
5. **冰退之后**才看得到：**冰川还在的时候，你其实看不到它造出来的地貌**；只有**冰融化后**才把它改造出的地貌"揭示 (reveal)"出来。
6. **常伴生"不匹配河 (misfit river / misfit stream)"** —— 现在占据谷底的河流**看起来太小，不足以造出这么大的谷**。

**时间尺度（很重要）**：英国部分地区**直到约 10,000 年前（末次冰盛期 Last Glacial Maximum 以来）仍被冰覆盖**，冰川消退的时间很近，所以**英国地表保留了大量新鲜的冰川地貌** —— 老师调侃：这就是为什么"U 形谷"是英国физical geography 学生的执念，而世界上其他地方的人根本不在乎。
**案例**：**Greenland（格陵兰）新近脱冰的谷地 (Slide 59)** —— 陡壁、平底、平直。

#### (g) 悬谷 (Hanging valley) (Slides 60–61)
**机理（老师承认自己讲得有点绕，这里整理清楚）**：
- **河流**：支流是通过**溯源侵蚀**形成的，因此**支流与主河之间通常保持平滑连续的坡降 (smooth gradient)** —— 支流会一直下切到主河河床高度。
- **冰川**：支冰川**只需把冰送到主冰川的"冰面顶部"** —— 因为主谷里**填满了很厚的冰**，支谷的冰**根本没有必要下切到主谷谷底**。
- **结果**：冰退后，支谷的谷口**"悬挂"在主谷谷壁的高处** → **悬谷 (hanging valley)**，支流以**陡坡或瀑布**注入主谷。
- 幻灯片表述：**支冰川只侵蚀到主谷冰川顶面的高度**。
- **案例：Yosemite National Park, California（美国优胜美地）(Slide 61)** —— 主冰川谷（陡壁 + 平底）+ 侧向支谷 + 交汇处的**瀑布**。

#### (h) 冰斗与冰斗湖 (Cirques and tarns) (Slides 62–63)
- **成因**：位于谷冰川**源头 (headwall)** 的**冰原/粒雪盆**在冰退过程中**向后退缩并加深谷地后壁**；
- **形态**：**圆形剧场式 (amphitheatre-like) 的洼地**，后壁极陡；
- **术语来源**：法语 **cirque = 马戏团/圆形剧场**；
- **常见伴生**：内部常积水成**近圆形小湖 → 冰斗湖 (tarn)**。
- **案例：Cirque de Gavarnie, Pyrenees（法国比利牛斯山加瓦尔尼冰斗）**。

#### (i) 刃脊与角峰 (Arêtes and Horns) (Slides 64–65)
- **成因（因果链）**：
  1. 冰川在谷中时，**冰体本身支撑着谷壁**，允许谷壁保持陡立；
  2. **相邻的两条冰川各自拓宽自己的谷** → 两谷不断靠拢；
  3. **两侧谷壁退到几乎相接** → 中间只剩下**极窄、极陡的山脊 → 刃脊 (arête)**；
  4. 若是**三条（或更多）谷从不同方向同时向中心退缩** → 中间残留一个**金字塔形的尖峰 → 角峰 (horn / pyramidal peak)**。
- **案例**：
  - **Crib Goch, Snowdonia, Wales（威尔士斯诺登尼亚，克里布戈赫）= 经典刃脊 (arête)**；
  - **The Matterhorn（马特洪峰）= 名副其实的、"horn"一词的词源性角峰**，老师称之为"可能是世界上最著名的山"。

#### (j) 冰川地貌野外识别清单 (Slide 66 "What to look for")
1. **U 形谷** —— 陡壁 + 宽平谷底 + 平直，谷底常有**misfit river**；
2. **悬谷 (hanging valleys)** + 交汇处瀑布；
3. **刃脊 (arêtes) 与角峰 (horns)**；
4. **冰斗 (cirques)**（常含 tarn）—— 标志着冰川的**源区**；
5. **（补充）无分选的冰碛 (moraine)**。

> ⚠️ **老师专门设置的课堂陷阱（详见第六节）**：**U 形谷与峡谷 (canyon) 在外观上可能非常相似** —— 光看"陡峭谷壁"不足以判定冰川成因，**必须同时寻找悬谷、冰斗、刃脊、角峰等其他冰川地貌来交叉验证**。

### 3.2 【图表判读】块体运动谱系图 (Slide 23 / 29)

这是一张**双轴递减图**，纵向从上到下依次为：
```
Rock fall (脆性 Brittle)
   │
Slide
   │            ↓ 沉积物/regolith 强度递减 (Decreasing strength)
Slump (快) / Creep (慢)  (韧性 Ductile)
   │            ↓ 启动所需坡度递减 (Decreasing gradient required)
Debris flow (流体 Fluid)
   │
Turbidity current & Pyroclastic flow (特例：水下 / 火山)
```
**判读方法**：给你一个块体运动的照片或描述，先判断"**运动物质有多硬**"和"**坡有多陡**"，两者应当同向对应；若不一致（如缓坡上出现大规模快速运动），八成是**碎屑流**（水饱和降低了内摩擦）。

### 3.3 【图表判读】气候–风化速率图 (Slide 12)

- **坐标轴被反画**：**降雨量向左增大**、**平均年气温向上减小**。老师建议**自己重画成正常方向**。
- **读法**：找到"高降雨 + 高温"那个角 → **化学风化最强、风化剖面最厚**；沿降雨减少方向 → 化学风化减弱；沿温度降低方向 → 过渡到**以物理风化（冻融）为主**的区域。

### 3.4 【图表判读】Regolith 厚度的纬向剖面图

横轴：**赤道（低纬）→ 极地（高纬）**；纵轴：**风化剖面/土壤深度**；另叠加一条**黄色的温度曲线**。
判读顺序：
1. **赤道带**：深度**峰值**（暖 + 湿）；
2. **副热带沙漠带**：深度**骤降**（温度仍高，但**无水**）；
3. **温带**：深度回升到**中等**（凉但湿）；
4. **极地**：深度**很低**（冷 + 干 + 冰覆盖）。
→ **整体呈"双峰 (bimodal)"分布。**

### 3.5 【图表判读】坡度–风化速率图 (Slide 15，Mont Aiguille)

自上而下三档：**陡坡 → 瞬时移除 regolith → 高风化速率**；**中坡 → 中等移除 → 中等速率**；**缓坡/平地 → 移除很慢 → 低风化速率**。
**判读陷阱**：**土层最厚的地方风化最慢**（厚土保护基岩），**土层最薄的陡崖风化最快**。

### 3.6 【图表判读】全球风化速率图 (Slide 18 相关)

叠加**两套控制**：
- **纬向气候带**：热带高（绿/橙/蓝色系）→ 副热带干旱带低（红色）→ 温带回升；
- **叠加的细长高值条带 = 主要造山带**（坡度控制）。
→ **结论：全球风化格局 = 气候带 × 地形起伏。**

### 3.7 【图表判读】河流演化总结矩阵 (Slide 47)

**二维矩阵**：
- **行（纵向 = 岩性/风化控制）**：上排"**低风化 + 强岩**" → **峡谷型**；下排"**高风化 + 弱岩**" → **V 形谷型**；
- **列（横向 = 时间演化）**：**Young（陡、下切+溯源、宽阔未切割河间地）→ Mature（水系完全切割、侧向拓宽、泛滥平原+曲流、圆润丘陵）→ Old（准平原 peneplain）**。
- **关键**：**两种岩性风格都遵循同一套时间演化序列**（老师明确说明，包括干旱区/硬岩区）。

### 3.8 公式说明

**本周幻灯片与讲课中没有出现任何定量公式** —— 全部为过程–机制的定性因果推理。以下为帮助理解而补充的定性关系（**补充，非考纲**）：

- **风化–搬运的瓶颈判据（概念式）**：
  - 若 `搬运速率 > 风化产碎屑速率` → **weathering-limited slope**（薄 regolith / 裸基岩）
  - 若 `风化产碎屑速率 > 搬运速率` → **transport-limited slope**（厚 regolith）
- **流体底部剪应力（解释"为什么流体能搬运颗粒"）**：`τ ≈ ρ g h sinθ`（ρ 流体密度、h 流深、θ 坡角）。
  - 用它可以定性理解本周两个结论：**坡度 ↑ → 剪应力 ↑ → 搬运能力 ↑**；**冰虽然 ρ 略小于水，但其极高的黏度与巨大的厚度 h 使其侵蚀/搬运能力远超河流**。
- **剥蚀与地形演化**：`地形变化速率 ≈ 抬升速率 − 侵蚀速率`。
  - 本周反复出现的前提"**若 侵蚀 > 抬升，则景观被 denude**"就是这个关系的定性版本。

### 4.3 具体案例与补充细节
9. **Death Valley**："在几公里范围内同时看到侵蚀与沉积地貌"的罕见地点；他还提到画面里能看到河流把物质带入沉积区。

12. **媒体用词批判**：新闻把碎屑流叫 landslide 是**科学上错误的**。
13. **微塑料与 PFAS**：河流的悬移/推移/溶解搬运机制**同样搬运颗粒态污染物**（微塑料、不粘锅上的 Teflon 类"永久性化学物质"）——"那种锅别买"。

1. **先定大类**：有起伏 + 裸岩/薄 regolith → 侵蚀地貌；极平坦 + 厚沉积 → 沉积地貌。
2. **再定营力**：
   - 崖 + talus / 弧形疤 + 舌状堆积 → **坡地过程主导**；
   - 汇聚树枝状水系 + V 形或陡壁河谷 + 裂点瀑布 → **流水主导**；
   - U 形 + misfit river + 悬谷 + 冰斗 + 刃脊/角峰 → **冰川主导**（**必须多项交叉验证**）。
3. **再定子类型**：软岩高风化 → V 形谷/恶地；硬岩低风化 → 峡谷。
4. **最后定演化阶段**：河间地宽阔未切割 = Young；水系完全切割 + 泛滥平原/曲流 = Mature；完全平坦无高地 = Old / peneplain。
5. **永远追问**："**这里还有没有第二种过程在起作用？**"（老师的核心态度）

## 六、易错点 / 重点难点

### ⚠️ 老师亲自设置的课堂陷阱
> **"陡峭的谷壁是不是只能由冰川造成？举手表示 yes / 举手表示 no。"**
> **答案：NO。**
> 老师随即说"**很好，注意听**"，并在冰川小结里展开：**U 形谷与峡谷 (canyon) 在某些方面表面上很相似 (superficially similar)**。
> **正确做法**：如果你看到一个陡壁谷地，**不能只凭陡壁判定冰川成因**，**必须去找其他冰川地貌来佐证** —— **悬谷、冰斗、刃脊、角峰、misfit river、无分选冰碛**。
> （同理，硬岩 + 低风化的河流峡谷同样有陡壁，其成因链条完全不同。）

### 易混淆概念对
| 易混对 | 关键区别 |
|---|---|
| **Weathering vs Erosion** | 风化 = **原地**削弱，**不搬运**；侵蚀 = **搬走** regolith。两者速率互相耦合（搬走越快 → 风化越快）。 |
| **Slide vs Slump** | 都沿剪切面运动。**Slide：块体保持形状**（内部只有有限脆性变形）；**Slump：块体在运动中彻底变形**（脆性 + 韧性，断层 + 褶皱），物质更软、通常未固结。**Mam Tor 是 slump。** |
| **Slump vs Debris flow** | Slump 仍是**块体**运动（有剪切面）；Debris flow 是**水饱和后整体像流体**流动，且**所需坡度可 <1°**。 |
| **Debris flow vs 河流 / "landslide"** | 碎屑流**不是河流**（不是水挟带颗粒，而是颗粒–水混合体整体作为流体）；媒体常误称为 landslide。 |
| **Weathering-limited vs Transport-limited slope** | 描述的是"**哪一步是瓶颈**"。Weathering-limited：搬运太高效 → **薄 regolith / 裸岩**；Transport-limited：搬运太低效 → **厚 regolith**。 |
| **V 形谷 vs 峡谷 canyon** | V 形 = **软岩 + 高风化 + 谷壁破坏（slump/debris flow）→ 达到平衡坡度**；峡谷 = **硬岩 + 低风化 + 谷壁不破坏（只有 fall）→ 保持陡立**。 |
| **U 形谷 vs 峡谷 canyon** | 两者都有陡壁！区别在于 **U 形谷有宽平谷底 + 平直 + misfit river + 配套的悬谷/冰斗/刃脊/角峰**。**必须交叉验证。** |
| **悬谷 (glacial) vs 河流支流** | 河流支流**坡降平滑**（溯源侵蚀会下切到主河床）；冰川支谷**悬在高处**（只需喂到主冰川冰面顶部）→ 冰退后出现瀑布。 |
| **Cirque（冰斗）vs Slump scar（滑塌疤）** | 二者都呈"**圆形剧场 (amphitheatre)**"形态 —— 老师描述 Mam Tor 滑塌疤时甚至用了 "cirque-like"。**区分靠环境背景**：冰斗位于**谷源头/高处**、常含 tarn、伴随刃脊角峰；滑塌疤位于**坡面上**、下方有滑塌体。 |
| **Peneplain（准平原）vs 沉积地貌的平坦面** | 准平原是**侵蚀**造成的平坦（剥蚀到极限，基岩接近地表）；沉积平原是**沉积物填满**造成的平坦（基岩被深埋）。 |
| **Tributive vs Distributive** | 汇聚 = 侵蚀段；发散分流 = 沉积段。 |

### 高频失分点提醒
1. **别把"厚土壤"等同于"风化强"** —— 恰恰相反（自限效应）。
2. **别只说"高海拔风化快"** —— 必须强调 **relief / 坡度**。
3. **化学风化"永远由水介导"** —— 太冷（水成冰）或太干（无水）都会抑制它，即使温度高（沙漠带）。
4. **块体运动谱系的两条趋势要一起答**：强度递减 **且** 所需坡度递减。
5. **回答"为什么冰川谷在这里"时要提**：冰川**继承并重新开挖了先存的主干河谷**（多过程叠加）。
6. **回答任何地貌题时都应检查是否有多过程叠加** —— 这是本讲第二条 ILO，很可能是论述题的加分点。
7. **注意时间尺度**：冰流 = 月–千年；英国冰退 ≈ 10 ka；密西西比占据其谷地 ≈ 40 Ma；Mam Tor 蠕变 ≈ 数千年；植物参与风化 ≈ 自志留纪 430 Ma 起。
8. **风成过程本周未讲**，但老师说"你需要知道风也能做这件事" —— 若考题涉及，答出"**气流施加剪应力挟带颗粒；由气压梯度驱动**"这一机制层面即可。

### 关键时间/空间尺度速查
| 对象 | 尺度 |
|---|---|
| 冰的塑性流动 | **月 → 世纪 → 数千年**（幻灯片写"年 → 数百年"） |
| 英国最后一次被冰覆盖 | **约 10,000 年前**（LGM 以来消退） |
| Mam Tor 滑塌蠕变 | **数千年**（1970s 切断公路） |
| 密西西比河下游占据其谷地 | **约 40 Ma** → 已成 peneplain |
| 陆生植物参与物理风化 | **自志留纪 ≈ 430 Ma 起** |
| Yellowstone 河所在区抬升 | **非常晚近**（故为 young river） |
| 沉积地貌中基岩埋深 | **10 → 数百 m 以上沉积物** |
| 碎屑流启动所需坡度 | **可低至 <1°** |

### 附：本周一句话总纲

> **抬升把新鲜岩石送到地表 → 气候（水 + 温度）与坡度共同决定它被风化削弱得多快 → 重力（坡地过程）先把 regolith 挪下坡，坡度不够时流水接手，气候够冷时冰川接手 → 每种营力按各自的机制留下一套可识别的地貌指纹 → 只要侵蚀持续超过抬升，地景就沿 young → mature → old 演化直至准平原。而现实中的任何一片地景，几乎总是多种过程共同作用的结果。**
