### 2. 景观的二分法（本周的总纲）

地球表面的景观可以分成两大类，本周**只讲第二类**：

- **剥蚀景观 (Erosional Landscapes)**：由**隆升 + 风化 + 剥蚀**产生。
- **沉积景观 (Depositional Landscapes)**：由**沉降 + 沉积**产生。这也就是所谓的**"沉积环境" (sedimentary environments)**。

> 关键理解：本课程把"沉积环境"和"沉积景观"当成同义词看待——**一个沉积环境本质上就是一片正在被沉积物塑造的地表/海底地貌**。因此本周的讲法是"地貌学式"的：先看地表形态 (geomorphic elements)，再反推塑造它的水动力过程。

## 二、核心概念

### PART 1 — 碎屑沉积环境

#### 2.1 剥蚀景观 vs 沉积景观：如何一眼分辨

因为主导过程不同，两类景观有完全不同的"外貌特征"，这是野外与遥感判读的第一步：

| 特征 | 剥蚀景观 (Erosional) | 沉积景观 (Depositional) |
|---|---|---|
| 主导过程 | **隆升 (uplift)** + 风化 + 剥蚀 | **沉降 (subsidence)** + 沉积 |
| 地形起伏 (relief) | **高起伏 (high relief)**，有地形高差 | **低起伏 (low relief)**，非常平坦 |
| 地表物质 | 覆盖**风化产物（表岩屑 regolith）**，或**裸露的基岩 (bare eroding bedrock)** | 基岩被**10 m 到数百 m 厚的沉积物**掩埋 |
| 水体 | 一般不积水 | 若尚未被填满 → 被**湖泊或海水淹没**；若已填满 → 极平坦的陆地 |
| 幻灯片实例 | — | **Death Valley, California**（由**正断层 (normal fault)** 控制的"释放型双层床"式构造，一侧隆升一侧沉降，两类景观并列） |

> 讲师强调的判读逻辑：看到"高起伏 + 基岩出露"→ 剥蚀区；看到"极平坦 + 厚沉积盖层"→ 沉积区。Death Valley 是把两者放在同一张照片里的经典教学例子：断层的上升盘是剥蚀景观，下降盘是沉积景观。

#### 2.2 沉积为什么会发生？——搬运介质的"能力"下降

**基本机制**：沉积物被搬运时，一旦**搬运介质 (transporting medium) 的搬运能力 (capacity) 下降**，它就"背不动了"，沉积物就地卸下。

- 搬运介质主要是**水**，也可以是**冰**和**空气（风）**。
- 能力下降的直接原因通常是**动量 (momentum) 或流速 (velocity) 的损失**。
- 这种"局部、短期"的沉积**可以发生在世界上任何地方**。

**讲师的河床例子（非常好的直觉锚点）**：山区河床里散布着**巨砾 (boulders) 与卵石 (cobbles)**——它们是被河流搬来的，河流在某一刻"决定"背不动了就把它们丢在原地。但这**不是永久沉积**：下一次**春汛或强降雨事件**时，水量与流速增大，河流会**重新搬起**这些块体（以及更细的粒级），继续往下游运，直到流量再次衰减 (wane) 才重新卸载。

> 因果链：**流速↓ → 搬运能力↓ → 沉积**；反之 **流量/流速↑ → 重新侵蚀与搬运**。这条链条在本周会被反复使用（河漫滩、三角洲、浊流朵叶体都是同一个原理）。

#### 2.3 长期保存的条件：可容纳空间 (accommodation) 与沉积盆地

这是讲师说的**"如果这节课你只记住一件事"**的那一条：

> **沉积物的长期保存 (long-term storage/preservation) 必须发生在正在沉降的沉积盆地里。**

因果链：
1. 要长期保存沉积物，就必须**有空间可以装它**——这个空间叫 **accommodation（可容纳空间）**。
2. Accommodation 从根本上由**地壳的沉降 (subsidence)** 制造（W5 讲过的机制）。
3. 长期沉降的区域 = **沉积盆地 (sedimentary basin)**。
4. 盆地持续沉降 → 先沉积的沉积物被后来的沉积物**埋藏 (burial)**，从而受到保护。
5. 埋藏把沉积物带到**更高的温度与压力**条件下 → 沉积物**成岩转化为沉积岩 (sedimentary rock)**。

> 讲师的手势演示：把手掌想象成一个正在下沉的面，下沉扫出的那块体积就是 accommodation。
> 反面强调：像山区河床那种地方，沉积物只能被"暂存"，最终一定会被搬到沉降的盆地里去。

#### 2.4 现今全球沉积盆地的分布

幻灯片上的全球图（讲师说"不用背这张图"，但要理解其含义）：

- **绿色 = 正在沉降的区域 = 沉积盆地**，具有长期堆积沉积物的潜力。
- **黄色/红色 = 正在隆升或仍处于"高位"的区域** → 这些是**碎屑沉积物的物源区**。
- **非绿色区域基本都在产生沉积物，并把它输送到绿色区域（以及蓝色的海域）。**
- 盆地既包括**陆上**的，也包括**靠近大陆的海域**。
- **深海（洋壳之上）不算作沉积盆地**，理由有二：
  1. **很少有机制能把大量沉积物运到那么远的地方**；
  2. 洋壳上就算有沉积物，**最终也会随俯冲 (subduction) 进入地幔**被消耗掉。

#### 2.5 动态平衡 (dynamic equilibrium)：沉积物供给 vs 可容纳空间

与整个地球系统一样，沉积过程由一个**动态平衡**支配：

> **平衡的两端 = 输入的沉积物体积 vs 沉降制造出的空间体积。**

判据（务必记牢，考试常考）：

- 若 **空间体积 ≥ 沉积物体积** → **所有沉积物都在此处沉积下来**（盆地"吃得下"）。
- 若 **空间体积 < 沉积物体积** → **多余的沉积物继续沿系统向下游搬运 (down system)**，直到遇到有足够空间的地方才沉积。

**讲师的黑板演示（重要，解释了海岸线位置的由来）**：
想象一个铰接点 (hinge point)，一侧隆升、一侧沉降，形成一个"平衡面"。沉积物不断被搬到沉降侧，**把空间一点点填满（filled to the brim）**；填满后沉积物就必须被搬得更远、更远。最终会到达一个位置：物源区的剥蚀量已不足以再填满更远的空间——**这个位置就是海岸线 (shoreline) 的最终平衡位置**，除非有新的隆升或沉降事件重新打破平衡。

**沉积物的"逐级下传"路线（本周结构的骨架）**：

```
高地（隆升 + 风化剥蚀，W7）
   │  河流搬运
   ▼
① 河流环境 fluvial  ──空间不足→
   ▼
② 浅海环境 shallow marine ──空间不足→
   ▼
③ 深水环境 deep water（重力流）——所有颗粒的最终归宿
```

> 为什么要把"浅水"和"深水"分开？讲师给的理由：全球大陆周围普遍存在一圈**陆架 (shelf)**，陆架外缘有一个明显的**坡折 (shelf break)**，之后水深急剧增大。**深水中搬运沉积物的过程与浅水中完全不同**（浅水靠河流/波浪/潮汐，深水靠重力）。

#### 2.6 河流环境 (Fluvial systems)

注意：本周讲的河流是**处于沉积状态 (depositional phase)** 的河流，不是 W7 里那种正在下切侵蚀的河流。它们有一副非常有辨识度的面孔：**极其平坦的泛滥平原 + 略微抬高的河道边缘**。

##### 四个地貌单元 (geomorphic elements)

1. **河道 (channel)**——流量被**限制 (confined)** 在河道内，是**高能量、能量集中**的区域。
2. **天然堤 (levee)**——河道两侧略微抬高的脊状体。
3. **泛滥平原 / 河漫滩 (flood plain)**——天然堤之外极平坦的宽阔区域。
4. **决口扇 (crevasse splay)**——天然堤溃决处向泛滥平原展开的舌状/朵状沉积体。

##### 天然堤 (levee) 的成因机制（重点因果链）

1. 平时河水**限制在河道内**，流动集中、能量高。
2. **降雨过量** → 水位超过河道深度 → 水**漫出河道 (overbanking)**。
3. 一旦离开河道，水流变得**极浅**并且**去限制化 (de-confined)**——它可以铺展到比河道宽得多的面积上。
4. 结果：**流体与底床的摩擦接触面积大幅增加** → 水流**极快地减速**，几乎瞬间损失全部流速。
5. 流速损失 = 搬运能力损失 → **沉积**。
6. **减速最快的位置正好紧邻河道** → 因此在河道两侧就地堆出一个**楔形沉积体 (wedge of sediment)**。
7. 每一次洪水都再叠加一层楔形体 → 河道两侧逐渐**加高**，形成 **levee**（词源为法语 *lever*，"抬升"）。

**自我强化的平衡（讲师特别指出）**：天然堤越高，河流就**越难再进入自己的泛滥平原**——河流实际上是在**给自己筑起屏障**。因此系统达到一种新的平衡态。

##### 沉积物如何进入泛滥平原：两条路径

| 路径 | 触发条件 | 出水方式（平面几何） | 沉积产物 |
|---|---|---|---|
| **漫岸 (overbanking)** | 河流**处于洪水期**，水位漫过天然堤顶 | 沿河道**线状 (linear)** 整体出水 | 大量**极细粒沉积物（黏土 clays）**铺展到泛滥平原上；黏土是**很肥沃的矿物**，因此漫岸事件是**泛滥平原肥力的来源** |
| **决口 (crevassing / crevasse splay)** | 河流**不一定在洪水期**；因为有天然堤，河道水面本身常常**高于泛滥平原**；当天然堤**变弱或被扰动**时会**溃决 (fail)**，堤体坍入河中 | 水从**单一点 (single point)** 离开河道 | 向泛滥平原展开一个**朵状沉积体 (lobe)** = **决口扇 (crevasse splay)** |

> 判读要点：**线状出水 = 漫岸；点状出水 + 朵状体 = 决口扇。** 这在 Kahoot 第 1 题被直接考到。

##### 河流的侧向迁移：曲流 (meandering) 与其岩石记录

沉积型河流通常**不是直的**，而是**曲流**。它们通过在泛滥平原上**四处迁移**来"占据"整个泛滥平原，方式有两种：**跳槽/改道 (avulsion，转写作 "bolstering"，即从一个位置突然跳到另一个位置)**，或**曲流侧向迁移 (meandering)**。

**曲流的动力学（讲师的板书推导）**：
1. 在弯道处，**外侧的流线路径更长 → 流速更快；内侧路径短 → 流速更慢。**
2. **快流 = 能重新捡起沉积物（侵蚀）；慢流 = 失去搬运能力（沉积）。**
3. 因此：**外岸 (outer bank) 侵蚀，内岸 (inner bank) 沉积**。
4. 每一次增量的"外侧侵蚀 + 内侧沉积"都把河道整体**向外侧平移一点**。
5. 反复进行 → 河道**横扫整个泛滥平原**。

**横剖面几何（考试易考）**：
- 平面上：外岸凹、内岸凸。
- 横剖面上：**内岸较浅（沉积侧，即点砂坝 point bar）**，**外岸较深（侵蚀侧）**。
- 累积结果：形成一个**砂体 (sand body)**，其内部由一系列**从高处起、向下倾斜的界面**组成——这些界面就是**侧积面 (lateral accretion surfaces)**，每一个都记录了河道迁移的一个增量。

**幻灯片实例判读（印尼，约 10 Ma 的古河道沉积）**：
- 照片中可见一个明显的**砂体"大团块"**；
- 砂体内部一组界面"从上方开始、向下延伸"，一条接一条**朝同一个方向叠瓦式排列** → **指示河道迁移的方向**（照片中向左迁移，示意图中向右，讲师提醒这一点"有点讨人厌"，注意别看反）；
- 砂体周围的**深色岩石**代表**河道所迁移穿过的泛滥平原（细粒、富有机质）**。

> **判读方法总结**：在露头/岩心里看到"砂体 + 内部一组同向倾斜的侧积面 + 上下被深色细粒泛滥平原泥包围"→ 判定为**曲流河道充填 (meandering channel fill)**，且侧积面倾向指示迁移方向。

#### 2.7 浅海环境 (Shallow marine systems)：三种能量、三种海岸线

在**陆-海交界处**，有**三种主导过程**控制沉积物的搬运与沉积。**每一种都塑造出一种独特的海岸线平面形态**——这是本周最实用的判读技巧：

| 主导过程 | 海岸线形态 | 地貌单元 |
|---|---|---|
| **河流 (rivers)** | **叶状/凸出海岸线 (lobate coastlines)** | **三角洲 (deltas)** |
| **波浪 (waves)** | **线性海岸线 (linear coastlines)** | **滨岸平原 (strandplains)、沙嘴 (spits)、海滩 (beaches)、潟湖 (lagoons)** |
| **潮汐 (tides)** | **港湾状/内凹海岸线 (embayed coastlines)** | **河口湾 (estuaries)、潮坪 (tidal flats)** |

##### (a) 河流主导：三角洲 (deltas)

**机制（讲师用汽车排气管作类比）**：
1. 海是一个**静止水体 (standing body of water)**；河流进入海时带有**残余动量/残余能量 (residual momentum/energy)**。
2. 这股残余能量在海水中**扩散**（湍流扩散 turbulent diffusion）——就像**汽车排气管**：手贴近排气口感觉很强劲，稍微拿远一点，那股"高能区"变宽了，但流速明显变弱，因为能量已经扩散到周围的空气里。
3. 河流入海同理：**能量迅速扩散 → 搬运能力迅速下降 → 沉积物在河口处就迅速卸载**。

**分叉的自组织过程（三角洲外形的由来）**：
4. 在河口正前方堆出一个沉积"团块" → 这个团块**成为河流自身的障碍物 (obstacle)**。
5. 河流被迫**在障碍物两侧分叉 (bifurcate)**。
6. 新的分叉各自又在自己的口门前堆积 → **再次分叉**。
7. 如此反复：**主河道向下游不断分裂成越来越小的分流 (distributaries)**，整体堆出一个凸向海的沉积体 = **三角洲 (delta)**。
8. 每个分流口门前堆积的砂体叫做 **河口坝 (mouth bar)**。

**识别标志**：地图上看到**海岸线有一块凸出物 (protuberance / lobe) 伸入海中，且有河流在该处入海** → 这里搬运沉积物的主要能量来源就是**河流的残余能量**。
**典型实例**：**Mississippi Delta（密西西比三角洲，美国）**——首页图即为它，沉积物来自落基山 (Rocky Mountains) 的剥蚀。

##### (b) 波浪主导：线性滨面 (linear "shorefaces")

**核心机制：沿岸漂移 (longshore drift)**
1. 海岸线**极少与波浪传播方向（波峰走向）正交**——海岸本来就不规则，正交是很罕见的巧合。
2. 波浪**斜向 (obliquely) 拍岸** → 冲上滩面时，沉积物被沿着一个**带有沿岸分量**的方向搬运。
3. 但**回流 (backwash) 永远在重力作用下沿滩面垂直下滑**。
4. 因此每一个波周期：**上冲时斜向前挪一点，回流时垂直下退** → 净效果是沉积物**沿岸持续单向搬运**。
5. 长期结果：**把海岸线上的所有不规则性都"抹平" (smoothing out irregularities)** → 形成**极其平直、狭长的海岸线**。

**由此产生的地貌序列（一条演化链）**：
- **海滩 (beach)** → 沉积物沿岸搬运，在海湾口开始延伸出一条**沙嘴 (spit)**；
- **沙嘴 (spit)** 继续增长，试图把海湾封闭；
- 一旦**完全封闭海湾** → 被隔出的水体成为**潟湖 (lagoon)**，而隔开海与潟湖的那条砂坝就叫 **海滩障壁 / 障壁坝 (beach barrier)**。
- 另有 **滨岸平原 (strandplain)**：一系列平行的海滩脊向海方向进积形成的平坦滨岸带。

> 讲师明确的口诀式结论：**看到又直又长、几乎没有凸出物的海岸线（尤其带潟湖）→ 波浪主导。**

##### (c) 潮汐主导：河口湾 (estuaries)

**机制**：潮汐**一进一出**的往复流动，尤其是灌入河道时，会**把河道"挖"开并向海方向加宽**（在潮汐能量最强处最明显）。

**结果形态**：与三角洲**恰好相反**——三角洲是"凸出去"，潮汐海岸是**"凹进来"**：海水形成**巨大的内凹湾 (embayments / indentations)** 深入陆地。

**特征几何**：**喇叭形/漏斗形 (trumpet-shaped / funnel-shaped)，向海方向迅速加宽**。
**分形特征（讲师特别指出）**：河口湾呈**分形网络 (fractal network)**——一个大型 estuary 里嵌套着较小的 estuary，里面还有更小的，**每一级都保持同样的喇叭形态**。
**典型实例**：**Guinea-Bissau（几内亚比绍）**的海岸；Kahoot 中还出现了**法国波尔多的 Gironde 河口湾 (Gironde estuary, Bordeaux)**（转写误作 "gyrant esterina bordeaux"）。

##### (d) 综合判读：三种过程往往同时作用

**讲师强调：现实中很少只有单一过程在起作用，三者常常同时操作。**

**Zambezi Delta, Mozambique（赞比西三角洲，莫桑比克）——三重证据的教科书案例**：
- 整体呈**凸出的叶状体**，河流在此入海 → **河流主导（三角洲）**；
- 但主河道本身呈**喇叭形、向海迅速加宽** → **潮汐作用正在挖掘和加宽这些河道**；
- 而海岸线的某些段落**极其平直**，并有**沙嘴 (spits)** 开始发育 → **沿岸漂移 / 波浪作用**，并可判断波浪来袭方向。

> **这是本周最重要的技能**：给一张卫星/航拍图，逐项寻找"凸出物 / 平直段+沙嘴+潟湖 / 喇叭形内凹"这三类特征，**重建出该地的主导沉积物搬运机制**。

#### 2.8 陆架、陆坡与深水环境 (Deep water)

##### 海底地形的三级台阶

**bathymetry（水深测量/海底地形）= 海洋版的 topography。** 全球海底地形图上最醒目的规律：**所有大陆周围都环绕着一圈相对浅水的陆架。**

| 单元 | 坡度 (gradient) | 地质本质 | 水深 |
|---|---|---|---|
| **大陆架 (continental shelf)** | **~0.05°** | **仍然是大陆地壳**，只是**目前恰好被海水淹没**了；密度约 **2.7 g/cm³**、厚 | 通常 **< 100 m** |
| **大陆坡 (continental slope)** | **0.1 – 2°**（三者中最陡） | 大陆地壳向洋壳**变薄的过渡带**，水深快速增加 | 数百 m → 数 km |
| **洋底 (ocean floor)** | **< 0.1°** | **洋壳**：密度约 **3.0 g/cm³**、薄、致密 | 可达数 km |

> 概念要点：**陆架从地质上说"仍然是陆地"**——因为大陆地壳**浮力大 (buoyant)、厚**，所以即使被淹没也保持高位；洋壳**致密而薄**，因此低伏。

##### 陆架宽度的变化及其意义（Gulf of Mexico 实例）

同一张北墨西哥湾水深图上：
- **德州 (Texan) 海岸一侧：陆架宽约 220 km** ——水深在 220 km 的距离内"极其缓慢"地增加，几乎不变陡。
- **密西西比三角洲处：几乎没有陆架 (nearly no shelf)** ——陆地极其靠近坡折，只剩几公里的陆架，之后水深骤增。
- 同一张图上还能顺带判读海岸线：三角洲处是**河流能量驱动海岸线向海建造 (build out)**；另一侧海岸线**平直但带内凹** → **有潮汐作用**。

##### 为什么"过陆架"这件事这么关键？

- **把沉积物运过陆架是非常困难的**——因为**要在一个极其平坦的表面上搬运很长的距离**（能量早就耗尽了）。
- **最简单的办法就是把海岸线本身向海推出去 (build the coastline outwards)**，就像密西西比三角洲所做的那样。
- **一旦沉积物到达陆架边缘 (shelf edge)，一整套完全不同的过程就接管了**——即**块体搬运/重力过程 (mass wasting and gravity processes，W7 讲过)**。

##### 海底峡谷 (submarine canyons)

- 峡谷常常**从洋底向后（向陆）下切 (cut back)**，切穿陆架，从而能**直接"截取" (tap) 三角洲或滨面输送来的沉积物**。
- **触发机制**：**地震 (earthquakes)**，或沉积物堆积造成的**过陡化 (oversteepening)** → **滑坡 (landslides)**。
- **实例**：**Southern California 的水深图**上可清晰看到峡谷从深海盆地切回、几乎抵达海岸线；峡谷在洋底**去限制 (de-confine)** 之处，还能看到一些"看起来像河流"的水道形态——**但它们完全不是河流，而是重力过程的产物**。
- **实例**：**Monterey Canyon, California（蒙特雷峡谷）**。

##### 重力流：碎屑流与浊流 (debris flows and turbidity currents)

**驱动机制（本周最重要的机制之一）**：
1. **沉积物 + 水的混合物本身就是一种流体 (a fluid in its own right)**；
2. 但它**比周围介质（海水）密度更大**；
3. 因此它**依靠自身的重力势能 (gravitational potential) 流动**。

**与河流的根本区别（讲师反复强调，是最大的易错点）**：
> **这完全不像河流。深水中的水是"绝对静止的" (perfectly still / totally still)。**驱动流动的**不是**水的整体流动，而是**高密度混合体在静止水体中因自身重力势而下滑**。

**实验室演示（讲师说明年 Sedimentary Rocks and Fossils 课上会亲手做）**：一个装满**完全静止的水**的水槽，把配好的**沉积物-水混合物**在闸门后混匀，然后**开闸释放** → 混合物因超额密度沿槽底奔流。

**发生条件**：**坡度足够大 + 流体浓度足够高**——**陆上与水下都能发生**。
**陆上的浊流对应物 = 火山成因的火山碎屑流 (pyroclastic flows)**（W3 讲过）。

**流速与破坏力**：
- **像火山碎屑流一样，可以达到 100+ km/h**。
- **全球 95% 以上的互联网数据仍通过海底电缆传输**，而这些流**能量大到会经常性地扯断这些电缆** → 对**海底基础设施构成重大风险**。

**科学认知史（讲师讲的很好的"科学如何进步"的故事）**：
- 这些深海景观**直到约 50 年前人类才知道它们存在**；
- **人类在自然界深水中直接观测到一次浊流，只是大约 15 年前的事**；
- 在此之前，**人们只是"推测"它们必然在发生，但从没有人亲眼见过**；
- 而第一次真正观测到的时候，**只拍到几秒钟画面，设备就被完全摧毁了**。

##### 海底扇 / 深水扇 (submarine fans / deep-water fans)

- **成因**：重力流沿峡谷奔流，在峡谷口**去限制 (de-confine)** 到开阔平坦的洋底上——**和河流出山口一模一样的道理**：失去侧向限制 → 能量迅速损失 → **卸载所携带的沉积物**，形成**朵叶体 (lobes)**。
- **地位**：**海底扇是地球上最大的沉积体 (the largest sedimentary deposits on Earth)**。
- **它们是任何一颗曾被从高地剥蚀下来的颗粒的最终归宿 (the final resting place)。**
- **规模实例（Bengal Fan，孟加拉扇）**：在**恒河-布拉马普特拉河 (Brahmaputra–Ganges) 河口**，重力流频繁发生，**有些流体可以奔流达 3500 km 进入深海**；峡谷口堆积的这个朵叶体**比整个印度次大陆还要大**。
- **气候意义（讲师特别强调的现代研究价值）**：这些系统**搬运的有机碳数量极其巨大**，是**重要的碳汇/碳信号**。理解这些系统的运作方式对**气候研究、认识碳最终被埋藏到哪里**非常重要。此外，**来自陆地的大量废弃物和有机质最终也堆积到这里**。
- **应用意义**：它们**对海底基础设施构成重大风险**（见上）。

### PART 2 — 生物成因与化学沉积

PART 2 处理"不是由已有岩石剥蚀而来"的那些沉积物：

| 类型 | 定义 | 讲师的一句话 |
|---|---|---|
| **碎屑沉积 (clastic)** | 由**先存岩石的剥蚀**而来 | PART 1 的全部内容 |
| **生物成因沉积 (biogenic)** | 由生物的**软体部分（"有机质" organic）**和**硬体部分（"骨骼" skeletal）**而来 | **"这些沉积物是'生'出来的，不是'造'出来的" (born, not made)** |

> 关于生物硬体部分的一个补充点：骨骼可以是**外骨骼或内骨骼**，而**化石记录中外骨骼要常见得多**。

#### 2.9 有机泥 (organic muds) 与黑色页岩 (black shales)

**术语关系**：**有机泥 = 沉积物的名字；黑色页岩 = 由它成岩后形成的岩石的名字。**

##### 有机质的来源与成分

- 海洋有机质主要是生活在湖泊与海洋**水柱 (water column)** 中的**浮游动植物 (planktonic fauna and flora)** 的生物量。
- **重要概念澄清（讲师特别强调）**：**"浮游生物 (plankton)" 不是一个生物分类学类群，而是一种"生活方式" (mode of life)**——指**没有自主运动能力、随水漂流、无法选择去哪里的生物**。许多浮游生物是**植物 (flora)**，也有许多（如许多**有孔虫 foraminifera**）是**动物 (fauna)**。
- 因为来自**复杂生物**，其**化学组成极其多样，没有单一的化学式**（讲师类比：你的心脏、肌肉、血液成分各不相同）：

| 有机化合物 | 来源 |
|---|---|
| **蛋白质 (Proteins)** | 动物组织与酶 |
| **碳水化合物 (Carbohydrates)** | 动物组织 |
| **脂类 (Lipids)** | 藻类 (algae)、花粉 (pollen)、孢子 (spores) |
| **木质素 (Lignin)** | 植物组织（陆地植物物质可被冲刷进湖泊与海洋） |

- **它们在大多数岩石中都非常稀（dilute）**（幻灯片给出的平均含量）：

| 岩石类型 | 有机碳含量 (wt%) |
|---|---|
| **泥岩 (Mudstones)** | **0.99 wt%** |
| **碳酸盐岩 (Carbonates)** | **0.33 wt%** |
| **砂岩 (Sandstones)** | **0.28 wt%** |

> 尽管含量都不到 1%，它们在历史上被视为极其重要，因为**它们是石油与天然气的基础**。讲师的评论：即便我们减少对油气作为**能源**的依赖，只要还需要**塑料**，石油大概还会存在很久；把这些稀薄的有机质从岩石里取出来，几十年来驱动了整个经济模式，因此地质学家、工程师和化学家在这上面投入巨大。

##### 两个根本控制因素（本节的核心因果框架）

一切都围绕这个（讲师说是"极度简化的"）平衡反应：

```
6CO₂  +  6H₂O   ⇌   C₆H₁₂O₆  +  6O₂
二氧化碳   水          碳水化合物    氧气

 →（正向 prograde）= 光合作用 (Photosynthesis)
 ←（逆向 retrograde）= 呼吸作用 / 燃烧 (Respiration / Combustion)
```

**因素 (a)：最初的有机生产率 (rate of organic productivity)**
- **根本上依赖光合速率 (photosynthetic rate)**。
- **没有光合作用，就永远不会有有机质。**
- 即使某种生物本身不进行光合作用（像我们一样靠吃别的生物生存），它**最终仍然依赖光合途径来制造最初的生物量**。
- 因此**光是驱动这一切的催化剂**。

**因素 (b)：死亡后有机质的降解速率 (rate of decay after death)**
- **若降解速率 > 生产速率，则永远无法保存有机质。**
- 逻辑：你可以随便生产多少有机质，但如果全部又被分解回去，就没有任何东西留在沉积物里供后人发现。

> **口诀：有机质富集 = 高生产 (production) + 高保存 (preservation)。两个条件缺一不可。**

##### 条件 (a)：哪里生产率高？

- **高初级生产力主要发生在陆地上**，以及**海洋/湖泊上部 200 m 的"透光带" (photic zone)**。
  - 转写中讲师给的更精确的说法：**光合作用绝大多数发生在最上面约 20 m 内，而在 200 m 以下则绝对不发生。**
  - 原因：**水吸收光的效率比你想象的高得多**，尤其是**浑浊（含泥）的水**——很快就没有足够的光来驱动光合作用。
- **但仅有光还不够，许多生物还需要营养盐 (nutrients)。**
- **上升流 (upwelling) 机制（重点因果链）**：
  1. **温水浮在上层，冷水沉在下层**（温水浮力大）；
  2. **冷的底层水能容纳大量营养盐**；
  3. 洋流把这些**冷的、富营养的水**驱赶到**大陆边缘 (continental margins)** 时，水会**沿着陆坡上涌到表层**；
  4. 富营养水**与透光带相遇** → **极高的初级生产力**；
  5. 食物链：**浮游植物 (phytoplankton) → 浮游动物 (zooplankton)**。
- **全球分布**：现今主要**集中在大陆的西岸 (west coasts of continents)**。
  - 幻灯片/讲解实例：**西南非洲 (southwest Africa)** 外海——典型的冷水上升流区，"这些地方本质上生物极多"。
- **另一种施肥机制（讲师补充，幻灯片上没有）**：**西北非洲外海**的高初级生产力**不是上升流造成的**，而是因为**撒哈拉的盛行风把沙尘吹到海上**；**撒哈拉沙尘中含有大量黏土 (clays)，黏土本身富含营养、是相当复杂的矿物** → **沙尘给海洋"施肥"，驱动初级生产力**。
  - > 讲师提示：像前面看全球风化速率图一样，**看全球初级生产力图时也要主动去推理"是什么在驱动这里的高产"**。

##### 条件 (b)：哪里能被保存？——缺氧 (anoxia) 的两种成因

**机制一：高生产力驱动的缺氧（"氧气需求 > 氧气供给"）**
1. **波浪对表层水的混合能力非常有限**——顶多影响**最上面几十米**的水柱（"absolutely maximum"）。
2. 因此**整体上海洋是相对不混合的**——讲师的比喻："**大部分时候就像一潭死水 (a stagnant pond)**"。
3. 有机质在**表层透光带**生产，死后**下沉进入下部完全静止的深水**。
4. 在生产率极高的地区，大量死亡生物"雨"落海底，分解时**消耗氧气**（即逆向反应：有机质 + O₂ → 分解）。
5. **氧气需求 > 氧气供给** → **可用氧气被极快耗尽**。
6. 氧气耗尽后 → **下部海洋形成缺氧层 (anaerobic layer)** → **有机质的保存成为可能**（只能进行厌氧分解，且分解不完全，生成不同的有机化合物）。
7. **海洋分层 (stratification) 与有机质保存由高生产率所促进** → 正反馈。
8. **图上表现**：初级生产力高的区域，**海底氧含量极低（图上蓝色越深、氧越低）**；海底开始堆积**未被分解的有机软泥 (ooze) 与泥**。

**机制二：受限盆地驱动的缺氧（"混合太差"）**
1. **在受限、连通性差的海道 (restricted, poorly connected seaways) 和湖泊中也易于发育缺氧底水**。
2. 原因：**小型海域和湖泊里很难建立起洋流环流**。大洋里有各种环流圈（如墨西哥湾流等）把水搅动起来；**小水体则很难建立这种环流**（讲师类比：你家后院的池塘）。
3. 死亡生物沉到海/湖底，**分解时消耗氧气**；
4. **缺乏主要洋流 → 抑制氧气向下的混合 → 快速建立起氧浓度梯度**；
5. **分层与有机质保存由"混合不良"所促进**。
6. **现代实例**：**黑海 (Black Sea)** 与**波罗的海 (Baltic Sea)**——讲师说黑海**初级生产率其实并不高**，但因为**极其停滞 (stagnant)**，**自由氧被极快耗尽**，海底同样覆盖着未完全分解的有机质。

##### 条件 (c)：避免稀释 → 生成"烃源岩"

- **要形成真正富有机质的岩石，最好还要缺乏碎屑或碳酸盐沉积作用**，因为这些会**"稀释" (dilute) 有机质**。
- 这类岩石被称为 **烃源岩 (source rocks)**：其中的有机质降解形成 **干酪根 (kerogens)**，**干酪根是油气的来源**（这与 Vicky 的油气系统讲座相衔接，讲师当堂确认过学生已学过 source rocks）。
- **经典实例：Kimmeridge Clay（基末利黏土）**
  - **年代**：幻灯片写 **Middle Jurassic, c. 155 Ma**（**注意：155 Ma 严格来说属于晚侏罗世 Late Jurassic / Kimmeridgian 阶；幻灯片的 "Middle Jurassic" 用词与年龄不一致，考试写 "Late Jurassic, ~155 Ma" 更安全，但要知道课件是这么写的**）。
  - **露头**：英格兰西南 / 南岸 **Kimmeridge 海岸**。
  - **岩性外观**：下方是石灰岩，其上是一段**很厚的黑色岩层**；含黏土但**有机质含量极高**。
  - **成因解释**：**155 Ma 前该处经历了极长时间的极度停滞水体**，有机质在海底堆积时未能分解。
  - **富有机质沉积的经典外观：非常黑 (looks really black)**——那是**成熟化的有机质**。
  - **经济意义**：这是**北海油气田的主要烃源岩**；在北海它进入地下（sub-surface），成为油气的主要来源。
  - **趣味事实（讲师讲的）**：在 Kimmeridge 附近某处，**用打火机点 Kimmeridge Clay，它能燃烧几分钟**（会自行熄灭，不会造成大火）。

#### 2.10 碳酸盐岩 (Carbonates)

> **课堂状态提示**：讲师**没有在课堂上详细讲这一节**，而是**布置了一段线上视频**，并**两次强调"一定会考"**。因此以下内容按幻灯片系统整理，这部分务必自学补齐。

##### 基本性质

- **碳酸盐岩是海洋（以及湖泊）环境中形成的主要生物成因沉积物与沉积岩类型。**
- 主要为**石灰岩 (limestone, CaCO₃)** 与**白云岩 (dolomite, CaMg(CO₃)₂)**（还有其他种类）。
- **沉淀过程主要由生物介导 (biologically mediated)**：生物从水中**提取溶解的 Ca、Mg、C、O**。
- **少数生物用硅质 (SiO₂) 造壳**，例如**放射虫 (radiolaria)**。
- **骨骼的功能**：为生物提供**刚性结构**，或**保护它（一个"家"）**。
- 讲师的对比：**石灰岩恰好是有机岩的反面——只有硬体部分被保留下来，有机部分则消失。**

##### 碳酸盐生产的控制因素（考点：什么促进、什么抑制）

因为生产主要由生物介导，**生产需要**：
- **光 (Light)** → 必须在**透光带 (photic zone)**，且**不能有悬浮泥质 (absence of suspended mud)**；
- **营养盐 (Nutrients)** → 通常来自陆地。

此外，**生物生长被以下条件促进**：
- **温暖的水 (warm water)**；

**被以下条件抑制**：
- **异常（偏低）的 pH**；
- **异常的盐度 (unusual salinities)**（过淡的**微咸水 brackish** 或过咸的**超盐 hypersaline** 都不行）。

> **结论：碳酸盐主要产生于浅海环境 (shallow marine environments)**——**温暖、清澈、正常海水盐度、远离碎屑输入**的浅水陆架。
> 因此**碳酸盐台地 (platforms) 与缓坡 (ramps) 形成于浅水陆架上**。
> **全球分布图**：红色的"暖水碳酸盐 (warm-water carbonates)"区是碳酸盐生产速率最高的地方。

##### 碳酸盐物质的三种来源方式

**(I) 原地生长 (IN SITU GROWTH)**
- 指由**固着在沉积物基底上的生物**沉淀出的碳酸盐。
- 在**浅水透光带**，这些生物构成 **礁 (reef)**；**生物死亡后，其骨骼可能不会离开生长地点太远**。
- **实例：Bahamas Bank（巴哈马滩）**。
- **常见的原地造礁生物（地质历史上有很大变化 — varied through geological time）**：
  - **珊瑚 (Corals)**
  - **藻席/藻叠层 (Algal Mats)**
  - **层孔虫 (Stromatoporoids)**
  - **海绵 (Sponges)**
  - **苔藓虫 (Bryozoa)**
  - **海百合 (Crinoids)**
- 讲师补充：**现代造礁环境以珊瑚为主**，但从蛤类到有孔虫的**广泛生物**都贡献壳体。

**(II) 浮游、游泳与底栖 (PLANKTON, NEKTON AND BENTHOS)**
指**能自由移动的生物**，它们的骨骼物质也可能贡献给沉积物：

| 生活方式 | 定义 | 典型代表 |
|---|---|---|
| **浮游 (Plankton)** | **漂浮**（无自主移动能力）；以微体生物为主 | **藻类 (Algae)**、部分**有孔虫 (foraminifera)**，如 **Globigerinids（抱球虫类）** |
| **游泳 (Nekton)** | **游动**；以大型生物为主 | 现代如**乌贼 (Cuttlefish)** |
| **底栖 (Benthos)** | **生活在沉积物之上或之中** | 微体：部分**有孔虫**（如 *Amphistegina* 底栖有孔虫，长轴约 3 mm）；大型：**腹足类 (Gastropods)**、**双壳类 (Bivalves)** |

**(III) 无机沉淀（次要）**
- **水柱中的无机碳酸盐沉淀**偶尔会发生，称为 **"白化水" / "泛白" (whitings)**。
  - **总体上不是碳酸盐物质的主要贡献者。**
  - 实例：**伯利兹北部陆架潟湖 (northern Belize shelf lagoon)** 中呈大致东西向拉长的 whitings，**最上方那条长度量级约 300 m**。
- **碳酸盐有时可直接沉淀在已有颗粒表面** → 形成 **包覆颗粒 (coated grains)**：
  - **鲕粒 (Ooid) / 豆粒 (pisoid)**
  - **核形石 (Oncoid)**

##### 碳酸盐台地的三种类型（Bosence, 2005）

这是本节的**核心分类考点**：

| 类型 | 碳酸盐生产力 | 水体条件 | 形态特征 | 实例 |
|---|---|---|---|---|
| **镶边陆架 (Rimmed shelves)** | **高 (HIGH)** | **温暖、清澈、正常海水盐度** | **与陆地相连**；**平坦的台顶**；有**明显的堡礁 (barrier reef)**；礁后有**受礁保护、免受波浪影响的潟湖 (lagoon)**；礁前是**通往真正深水的陡坡** | **Great Barrier Reef, Australia（大堡礁）** |
| **孤立台地 / 环礁 (Isolated / unattached platforms, "atolls")** | **高 (HIGH)** | **温暖、清澈、正常海水盐度**（与镶边陆架相同） | **不与陆地相连（本身就是一座岛）**；其余与镶边陆架相同：**平顶 + 堡礁 + 潟湖 + 礁前陡坡** | **Bora Bora, French Polynesia（波拉波拉岛）** |
| **碳酸盐缓坡 (Carbonate ramps)** | **较低 (LOWER)** | **水更凉**，或**被碎屑污染**，或**微咸 (brackish) / 超盐 (hypersaline)**——"台地过得不太舒服" | **一个均匀向深水倾斜的缓坡**；**没有堡礁**，只有**局部的斑礁 (patches of reef)** | **Trucial coast, southern Arabian Gulf（阿拉伯湾南岸特鲁西尔海岸）** |

**镶边陆架的内部相带（大堡礁标注）**：
`开阔海条件 (open marine conditions) → 堡礁 (barrier reef) → 潮汐通道 (tidal channels) + 潮汐颗粒灰岩浅滩 (tidal grainstone shoals) → 斑礁 (patch reef) → 潟湖泥灰岩 (lagoonal mudstone)`

**环礁的两条重要因果链**：
- **成因位置**：常形成于**海洋火山岛周围的浅水中**；因为**陆地面积太小、产不出多少碎屑沉积物**，所以是**碳酸盐生产的绝佳场所**。
- **"追赶"能力**：**高碳酸盐生产力意味着礁体可以跟上海平面**——即使**火山在沉降**或**海平面在上升**，礁体也能向上生长保持在透光带内。**潟湖之所以能维持，是因为礁体抑制了海水的混合。**

**碳酸盐缓坡的因果链（以阿拉伯湾为例）**：
1. **循环差 (poor circulation) + 高温** → **水体超盐 (hypersalinity)**；
2. 超盐 → **碳酸盐生产受限**，只剩**少数礁体**，以及**潮间带 (intertidal) 的细菌席与藻席**；
3. **缺乏良好的堡礁屏障** → **波浪与潮汐过程把物质打碎并搬到更深水去**；
4. → 低生产力条件下**沉积物更容易被改造 (reworked) 并被搬离浅水**，因而形成均匀倾斜的缓坡而非有陡崖的台地。
5. 相关的相带标注：**萨布哈 (sabkha，海岸盐坪)**、**风成 (aeolian)** 沉积。

#### 2.11 蒸发岩 (Evaporites)

##### 定义与核心问题

- **化学沉积物直接从海水与湖水中沉淀出来**，**不经生物活动介导**，**完全是无机的**。
- 直接沉淀发生是因为**水体对该矿物达到了过饱和 (supersaturated)**。
- **核心问题：过饱和是怎么发生的？**

##### 机制：蒸发 > 淡水输入

- 在**蒸发量超过河流带来的淡水（雨水）输入**的地区，**溶解的矿物被超浓缩 (hyperconcentrated)**。
- **根本上是气候控制的 (due to climate)**。

**离子从哪里来（讲师补充的重要背景）**：
1. **陆地风化反应**（如**水解 hydrolysis**、**螯合 chelation** 等，Vicky 的课讲过）**产生离子** → **河流把这些离子输送到湖泊和海洋**；
2. **洋中脊 (mid-ocean ridges)** ——洋壳在此因拉张而生成，**海水与海底火山流体的相互作用引入大量离子**。
3. 这些离子主要是**常见的地表金属/元素**：**钙 (Ca)、镁 (Mg)、氯 (Cl)、钾 (K)、硫 (S)**（加上碳与氧）——把它们重新组合，就能得到下面所有蒸发岩矿物。

##### 主要蒸发岩矿物（幻灯片清单）

| 矿物族 | 具体矿物与化学式 |
|---|---|
| **碳酸盐类** | **方解石及其同质多象 (Calcite and polymorphs, CaCO₃)**、**白云石 (dolomite, CaMg(CO₃)₂)** |
| **盐类（卤化物 Halogens）** | **石盐 (halite, NaCl)**、**钾盐 (sylvite, KCl)**、**MgCl** 等 |
| **硫酸盐类** | **石膏 (Gypsum, CaSO₄·2H₂O)**、**硬石膏 (anhydrite, CaSO₄)** |

> **石膏 = 巴黎石膏 (plaster of Paris)**，在医学和造型制作上都有用途，因此有一定的经济价值。

**盐度数据（幻灯片原文，含单位问题见"易错点"）**：**死海 (Dead Sea) 的石盐（食盐）超浓缩到 40 ppm，比正常海洋高 5 ppm，这已足以促使盐类无机沉淀。**

##### 为什么会出现"局部"的超盐？——海洋并非充分混合

- **如果海洋是完美混合的，这些超浓缩水团会被搅匀掉。**
- 但**超盐很容易在以下条件下发育**：
  1. **与开阔大洋连通差/不连通的海道 (seaways) 和（尤其是）湖泊**；
  2. **蒸发量超过淡水输入。**

**全球海洋盐度图的判读（讲师当堂提问的三个点，极好的复习题）**：

| 图上现象 | 解释 |
|---|---|
| **大西洋有两条盐度偏高的带** | 这是**副热带 (extra-tropics / subtropical belts)**：**降水少 + 温度高**（热带是"暖但湿"，副热带是"热但干"）。这两条带的存在**说明大西洋并非充分混合**——否则盐度应该处处均匀。（讲师的比喻：如果你游泳横渡大西洋，你会注意到盐度在变。） |
| **一处盐度显著偏低的区域** | **亚马逊河 (Amazon) 河口**——巨量淡水输入。 |
| **孟加拉湾 (Bay of Bengal) 非常淡** | **恒河 (Ganges) 与布拉马普特拉河 (Brahmaputra) 的巨大淡水排放量。** |
| **地中海 (Mediterranean) 盐度特别高** | **双重原因**：(1) **蒸发量 > 降水量**，因为它位于**又热又干的副热带气候带**；(2) **与大西洋连通极差**——仅通过**直布罗陀海峡 (Straits of Gibraltar)** 相连，而且小型海道**很难建立环流**。水从直布罗陀流入，然后地中海就"一直在蒸发"；虽然有尼罗河等大河汇入，**但不足以抵消蒸发** → 盐度持续升高。 |

**现代蒸发岩沉积实例**：
- **死海 (Dead Sea)**：位于极热的地方、封闭，蒸发极快，**盐类直接沉淀到湖底**。
- **大盐湖 (Great Salt Lake, Utah)**：**当前正在沉淀盐类**——犹他州非常干旱，湖体**小、不连通、蒸发迅速**。

##### 蒸发岩作为古气候与古地理指标（本节的核心考点）

> **蒸发岩是极好的古气候 (palaeoclimate) 与古地理 (palaeogeographic) 指标。**
> 如果它们保存在沉积记录中，就告诉你：
> 1. **当时气候是干旱的 (arid) —— 又热又干**；
> 2. **该水体是封闭的，或与开阔大洋的连通严重受限。**
>
> 因此可以用这类证据**重建古气候与古地理的故事**。

**保存偏差（重要且易被忽视）**：
- **实例：Death Valley 的蒸发岩沉积**——主要是**石膏 (Gypsum)**，与同样进入湖/海的**碎屑黏土 (clastic clay) 互层 (interstratified)**。
- **石盐 (halite) 与硬石膏 (anhydrite) 极少能在露头见到，因为它们太容易被雨水溶解。**
  - > 推论：野外看到的蒸发岩剖面**系统性地偏向石膏**，不能据此认为原始沉积中没有石盐。地下/钻井剖面才能见到完整的盐岩层。

## 三、公式与图表

### 3.0 本周唯一的"公式"

```
6CO₂  +  6H₂O   ⇌   C₆H₁₂O₆  +  6O₂
```
- **正向 (prograde) = 光合作用 (Photosynthesis)** → **生产**有机质，需要**光**。
- **逆向 (retrograde) = 呼吸作用 / 燃烧 (Respiration / Combustion)** → **分解**有机质，需要**O₂**。
- **有机质在沉积物中富集 ⟺ 正向速率 > 逆向速率**，即**高生产力 + 缺氧保存**。
- **同一个方程解释了"为什么有机质产在表层" 和 "为什么它保存在缺氧底水中"** ——这是本周最经济的记忆装置。

### 3.1 沉积物预算判据（accommodation vs supply）

| 条件 | 结果 |
|---|---|
| **空间体积 ≥ 沉积物体积** | 沉积物**全部在此沉积**；海岸线**后退/维持** |
| **空间体积 < 沉积物体积** | **多余沉积物向下游/向盆地方向搬运**；海岸线**向海推进 (progradation)**，直至物源不足以继续填充 |

|---|---|---|---|---|---|---|
| **三角洲 (delta)** — 河流主导 | **河流残余动量/能量在静止海水中湍流扩散**（"排气管"效应）→ 能量迅速下降 | 河口坝为**砂**；前三角洲为**泥**；整体**向上变粗 (coarsening-up)** | 前积层 (foreset/clinoform)、交错层理、滑塌变形构造 | 河流带来的陆源植物碎屑 + 海相化石**混合**；盐度多变、生物多样性偏低 | **凸出的叶状海岸线 (lobate coastline)**；**主河道向下游反复分叉 (bifurcation)** 成越来越小的分流；分流口门前的**河口坝 (mouth bars)** | **Mississippi Delta, USA**（沉积物源自 Rocky Mountains）；**Zambezi Delta, Mozambique** |
| **滨面/海滩/滨岸平原 (shoreface / beach / strandplain)** — 波浪主导 | **波浪斜向拍岸 + 回流垂直退回 → 沿岸漂移 (longshore drift)**，净沿岸单向搬运 | **分选极好的砂**（有时砾）；成熟度高 | 低角度海滩交错层理、**丘状交错层理 (hummocky cross-stratification)**、浪成波痕、平行纹层 | 正常盐度海相化石；生物扰动强；壳体常磨蚀破碎 | **极其平直、狭长、几乎无凸出物的海岸线**——沿岸漂移**抹平了所有不规则性** | 课件航拍：strandplain、beach |
| **沙嘴 (spit)** — 波浪主导 | 沿岸漂移在海湾口继续延伸 | 砂 | 同海滩 | 同海滩 | **从海岬向海湾内延伸的狭长砂体**，试图封闭海湾 | 课件航拍 |
| **障壁坝 + 潟湖 (beach barrier + lagoon)** — 波浪主导 | 沙嘴**完全封闭海湾** → 潟湖与外海隔绝，内部**低能、水体受限** | 障壁：**分选好的砂**；潟湖：**泥、有机质，可含蒸发岩** | 障壁：海滩层理；潟湖：**水平纹层、生物扰动**；可含**缺氧纹层** | 潟湖：**低分异度、耐盐度变化的类群**（可为半咸水或超盐组合） | **一条砂坝把水体与外海隔开**；**Kahoot 第 2 题**：B = beach barrier，其后水体 = lagoon | 课件航拍 |
| **河口湾 (estuary)** — 潮汐主导 | **潮汐往复流灌入并"挖掘"、加宽河道**，在潮能最强处最显著 | 砂-泥**互层**（潮汐韵律）；向海方向常变粗 | **潮汐束状体 (tidal bundles)**、**双黏土层 (double mud drapes)**、**人字形交错层理 (herringbone cross-stratification)**、潮汐韵律层 | 半咸水 (brackish) 组合：**分异度低但个体丰度高**；生物扰动强 | **喇叭形/漏斗形、向海迅速加宽的深大内凹 (embayment)**；**分形网络**——大 estuary 内嵌套小 estuary，每级都是喇叭形 | **Guinea-Bissau**；**Gironde estuary, Bordeaux（Kahoot 题）** |
| **潮坪 (tidal flat)** — 潮汐主导 | 潮汐涨落，能量向陆方向递减 | 向陆变细：**砂坪 → 混合坪 → 泥坪** | **透镜状/波状/脉状层理 (lenticular / wavy / flaser bedding)**、干裂、潮沟 | 半咸水底栖类群、强烈生物扰动 | 与 estuary 伴生的极平坦潮间带；层理呈**砂泥交替的潮汐韵律** | 课件列于 "embayed coastlines" 类 |

#### C. 深水（碎屑）

| 环境类型 | 水动力条件 | 典型沉积物与粒度 | 特征沉积构造 | 化石组合 | 识别标志（本周核心） | 典型实例 |
|---|---|---|---|---|---|---|
| **大陆架 (continental shelf)** | 浪基面以下为主的低能环境；被淹没的**大陆地壳** | 泥为主，砂质经风暴带入 | 生物扰动强、风暴层 (tempestites) | 正常盐度、高分异度海相化石 | **坡度 ~0.05°**，水深**通常 < 100 m**；宽度变化极大（**Texas 一侧 220 km；Mississippi 三角洲处几乎为零**） | **北墨西哥湾 (N Gulf of Mexico)** |
| **大陆坡 (continental slope) + 海底峡谷 (submarine canyon)** | **坡度陡 (0.1–2°)**；**地震或过陡化触发滑坡**；**限制性重力流下切** | 混杂：滑塌体、碎屑流沉积、粗粒峡谷充填 | **滑塌褶皱 (slumps)、块体搬运沉积 (MTDs)**、侵蚀性峡谷底面 | 再沉积的浅水化石与原地深水化石混合 | **从洋底向陆"切回"、切穿陆架的峡谷**，可**直接截取三角洲/滨面的沉积物** | **Monterey Canyon, California**；**Southern California 水深图** |
| **海底扇 / 深水扇 (submarine fan)** — 重力流主导 | **周围海水完全静止**；**沉积物-水混合体因密度大于海水而靠自身重力势流动**；**流速可达 100+ km/h**；峡谷口**去限制 → 快速失能 → 卸载** | 从峡谷口的**砾/粗砂**到扇缘的**泥**；单层内**递变层理** | **鲍马序列 (Bouma sequence)**、**递变层理 (graded bedding)**、**底面痕迹 (sole marks: flute/groove casts)**、砂泥互层的浊积岩 (turbidites) | **深水原地化石 + 从浅水被再搬运来的浅水化石混杂**（异地组合，重要判据） | **地球上最大的沉积体**；扇形/朵叶状 (lobes)；洋底上"看起来像河流"但**完全不是河流**的水道 | **Bengal Fan**：流体可行进 **3500 km**，朵叶体**比印度次大陆还大**（源自 **Brahmaputra–Ganges** 河口） |

#### D. 生物成因与化学沉积

|---|---|---|---|---|---|---|
| **有机泥 / 黑色页岩 (organic mud / black shale)** | **静水、分层、缺氧底水**；成因二选一或叠加：(1) **高生产力（上升流）耗尽氧气**；(2) **受限、连通差的海道或湖泊，混合不良** | **极细粒泥**，富有机质；**需缺乏碎屑与碳酸盐稀释** | **保存完好的水平纹层 (laminations)**——**因缺氧无底栖生物扰动**；黄铁矿结核 | **无底栖生物、无生物扰动**；仅有**浮游化石（如有孔虫、藻类）**、偶见游泳生物 | **岩石极黑**；纹层未被扰动；成为**烃源岩 (source rock)**，有机质降解成**干酪根 (kerogen)** | **Kimmeridge Clay（~155 Ma，英国南岸）**——北海油气主力烃源岩，可点燃；现代类比：**黑海 (Black Sea)、波罗的海 (Baltic Sea)**；上升流区：**西南非洲外海** |

### 3.3 全球图件的判读方法（本周考"读图"的三张图）

**(1) 全球沉降/隆升图（沉积盆地分布）**
- **绿色 = 沉降 = 沉积盆地 = 沉积物的"汇 (sink)"**；
- **黄/红 = 隆升或高地 = 沉积物的"源 (source)"**；
- **蓝色海域**也是汇；
- **判读口诀**：**凡是不绿的地方都在制造沉积物，并把它送往绿色的地方。**
- **深海不算盆地**（运不到 + 会随俯冲消失）。

**(2) 全球初级生产力图（有机质）**
- 找**大陆西岸的高值带** → **冷的富营养水上升流 (upwelling)**（如**西南非洲**）；
- 但要留一手：**西北非洲**的高值是**撒哈拉沙尘施肥**，不是上升流；
- **再叠加海底溶解氧图**：**高生产力区正对应深蓝色（低氧）海底** → 这就是有机质得以保存的地方。

**(3) 全球海表盐度图（蒸发岩）**
- **两条副热带高盐带**（大西洋南北各一）→ **热而干、降水少**；它们的存在**证明大洋没有被完全混合**；
- **低盐斑块** → 找**大河河口**（**亚马逊**、**恒河-布拉马普特拉/孟加拉湾**）；
- **地中海高盐** → **副热带气候 + 仅经直布罗陀海峡与大西洋相连的受限海道**；
- **判读逻辑**：**高盐 = 蒸发主导 + 连通受限 → 有蒸发岩潜力。**

### 3.4 航拍/卫星图判读流程（本周最实用的技能）

按顺序问自己三个问题：

1. **海岸线是"凸出去"的吗？** → 有 lobe/protuberance 且有河流入海 → **河流主导 → 三角洲**（找**分叉的分流** + **河口坝**）。
2. **海岸线是"又直又长"的吗？** → **波浪主导**（找**沙嘴 spit**、**障壁坝 beach barrier**、**潟湖 lagoon**；机制是**沿岸漂移**）。
3. **海岸线是"凹进去"的、河道呈喇叭形向海加宽吗？** → **潮汐主导 → 河口湾 estuary**（找**分形嵌套**）。
4. **三者常同时存在** → 逐段判读，像 **Zambezi Delta** 那样给出"整体河流主导 + 河道受潮汐改造 + 局部波浪整平"的综合结论。
5. **有没有树？** → **有树 = 陆上**（排除海底扇等深水解释）——这是 Kahoot 第 1 题的关键线索。

### 4.2 幻灯片上没有的机制细节与类比

| 主题 | 讲师的口头补充 |
|---|---|
| **沉积的可逆性** | 河床中的巨砾**不是永久沉积**——下一次**春汛或强降雨**会把它们重新捡起继续往下游搬 |
| **Accommodation 的手势演示** | 把手掌当作一个正在下沉的面，扫出的体积就是可容纳空间 |
| **海岸线的最终位置** | 沉积物把盆地"填到满溢 (filled to the brim)"后必须向更远处搬运，**直到剥蚀量不足以再填满更远的空间**——**这个位置就是海岸线的平衡位置**，除非新的隆升/沉降打破它 |
| **天然堤成因的关键** | 减速最剧烈的位置**正好紧邻河道**，所以楔形体堆在河道边上；而且**河流因此给自己筑起了屏障，越来越难进入自己的泛滥平原** |
| **三角洲 = 汽车排气管** | 手贴近排气口感觉强劲，稍远则"高能区变宽但流速变弱"——**能量扩散到周围介质中**；河流入海完全同理 |
| **三角洲形态的自组织** | 河口沉积体**成为河流自身的障碍物**，逼迫它**反复分叉**——三角洲的分流网络是**自己造出来的** |
| **沿岸漂移的净效应** | **上冲斜向、回流垂直** → 净沿岸搬运 → **抹平海岸线的所有不规则性** |
| **河口湾的分形性** | 一个大 estuary 里嵌套小 estuary，小的里面还有更小的，**每一级都保持喇叭形** |
| **深水水体是静止的** | **"The water is absolutely still."** 驱动流动的是**混合体自身的重力势**，不是水的整体流动——**这是与河流的根本区别** |
| **过陆架的困难** | 在**极平坦的表面上搬运极长距离**非常困难；**最简单的办法是把海岸线本身建出去** |
| **海底电缆** | **全球 95% 以上的互联网数据仍通过海底电缆传输**，重力流**经常性地扯断这些电缆** |
| **科学史** | 深水景观**约 50 年前才为人所知**；**约 15 年前才第一次在自然界直接观测到浊流**；观测到的那一次**只拍到几秒钟，设备就被彻底摧毁** |
| **Bengal Fan 的碳意义** | 搬运的**有机碳量极其巨大** → 是**重要的碳信号**；理解这些系统对**气候研究和"碳最终埋在哪里"**很重要；**陆地废弃物也最终堆积到这里** |
| **Plankton 的定义澄清** | **Plankton 不是分类学类群，而是"生活方式"**——随流漂浮、无自主选择权；**既有植物也有动物（如许多有孔虫）** |
| **有机质成分无统一化学式** | 类比：你的心脏、肌肉、血液成分各不相同；根本上都是碳水化合物但各不相同 |
| **光合作用的深度限制（更精确的数字）** | **绝大多数发生在最上面约 20 m**；**200 m 以下绝对不发生**；**水吸光效率比想象中高得多，浑水尤其如此** |
| **撒哈拉沙尘施肥** | **西北非洲**外海的高生产力**不是上升流**，而是**撒哈拉盛行风带来的富营养黏土给海洋"施肥"** |
| **波浪混合的深度限制** | 波浪对表层水的混合**顶多影响最上面几十米**；**整体上海洋"就像一潭死水"** |
| **黑海的特殊性** | 黑海的**初级生产率其实不高**，但**极度停滞**，因此自由氧被极快耗尽 —— **说明"停滞"这一条件本身就足以造成缺氧** |
| **Kimmeridge Clay 可以点燃** | 在 Kimmeridge 附近某处，**用打火机点它可以燃烧几分钟**（会自行熄灭） |
| **石灰岩 vs 有机岩** | **石灰岩是有机岩的反面**：只留下**硬体部分**，有机部分消失 |
| **蒸发岩离子的两个来源** | (1) 陆地**风化反应（水解、螯合等）产生离子 → 河流输入**；(2) **洋中脊海底火山与海水的相互作用引入大量离子** |
| **石膏的用途** | **石膏 = plaster of Paris**，在**医学与造型制作**中都有用途 → 有经济价值 |
| **副热带 vs 热带** | **热带 = 暖但湿；副热带 (extra-tropics) = 热但干** —— 这就是两条高盐带的位置由来 |

## 六、易错点 / 重点难点

### 6.1 概念性易错点

1. **"沉积" ≠ "长期保存"。**
   局部、短期的沉积**到处都能发生**（山区河床里的巨砾）；但**长期保存必须有 accommodation，必须在沉降的沉积盆地里**。这是讲师唯一说"如果只记一件事就记这个"的点。

2. **深海不是沉积盆地。**
   两条理由都要说得出来：(1) **很少有机制能把沉积物运那么远**；(2) **洋壳上的沉积物最终会随俯冲被消耗**。注意区分"深海洋底"与"海底扇"——**海底扇位于陆坡脚下/盆地底部，是有沉积物到达的地方**。

3. **深水重力流绝不是"水下的河流"。**
   最大的易错点。**周围的水完全静止**；驱动力是**沉积物-水混合体自身的超额密度带来的重力势**。洋底上那些"看起来像河流"的水道**完全由重力过程造成**。

4. **三角洲与河口湾是"镜像关系"。**
   **河流主导 → 凸出去 (lobate)；潮汐主导 → 凹进来 (embayed, 喇叭形)。** 两者都与河流有关，靠**形态**区分，不要混。

5. **decelerating 的原因要说清。**
   泛滥平原 / 三角洲 / 海底扇朵叶体三者用的是**同一个机制**：**去限制 (de-confinement) → 摩擦面积增大或能量扩散 → 流速骤降 → 卸载沉积物**。答题时要写出这条链，而不只是说"能量降低了"。

6. **有机质富集需要"两个条件同时满足"。**
   只讲高生产力（上升流）**不够**——还必须**缺氧保存**；只讲缺氧**也不够**——必须先有生产。另外还有第三个（常被忘）条件：**缺乏碎屑与碳酸盐的稀释**。

7. **缺氧有两条独立路径，不要只记一条。**
   (a) **高生产力耗尽氧气**（如上升流区）；(b) **受限盆地混合不良**（如黑海——**它的生产力其实不高**）。Kahoot 第 6 题就在考这个：**"充分混合的湖泊"不行**，但**普通（混合差的）湖泊反而是有机质的好去处**。

8. **上升流不能"同时上升又下沉"。**
   Kahoot 第 6 题的干扰项设置："大陆边缘暖水下沉处"是错的——**上升与下沉不可能发生在同一处，那是一个环流圈**。

9. **不是所有的高生产力区都是上升流造成的。**
   **西北非洲外海是撒哈拉沙尘施肥**，不是上升流。看图时不要一律套用上升流解释。

10. **碳酸盐"喜欢什么"要成套记牢。**
    **需要：光（透光带、无悬浮泥）+ 营养盐。促进：温暖。抑制：异常 pH（偏低）、异常盐度（过淡或过咸）。** Kahoot 第 10 题的三个错项各打一个死穴：**A 太浑（密西西比河口的泥）、B 太深、D 太冷**。

11. **镶边陆架 vs 环礁：唯一的区别是"是否与陆地相连"。**
    两者的**生产力条件与形态要素完全相同**（平顶 + 堡礁 + 潟湖 + 礁前陡坡）；**环礁是岛，不与陆相连**。

12. **碳酸盐缓坡是"低生产力"的产物。**
    因果链要连起来：**生产力低 → 造不出堡礁 → 没有屏障 → 波浪与潮汐把物质打碎并搬向深水 → 形成均匀倾斜的缓坡而不是有陡崖的台地。**

13. **蒸发岩题目常用"双重否定"的问法。**
    Kahoot 第 8 题：问的是"哪一项**抑制**蒸发岩沉积" → **充分混合的大洋**。而"**无河流输入**"其实是**促进**因素（河水是淡水，会稀释）。看清题干问的是"促进"还是"抑制"。

14. **露头里看不到石盐 ≠ 当时没有沉淀石盐。**
    **石盐与硬石膏极易被雨水溶解，几乎从不出露**；野外见到的蒸发岩剖面被系统性地偏向了**石膏**。

15. **陆架"在地质上仍然是陆地"。**
    它是**被海水恰好淹没的大陆地壳**（2.7 g/cm³、厚、有浮力），不是洋壳（3.0 g/cm³、薄、致密）。所以"浅海沉积"其实沉积在大陆之上。

### 6.3 材料内部的数据不一致（写答案时注意）

1. **Kimmeridge Clay 的年代**：幻灯片写 "**Middle Jurassic, c. 155 Ma**"，但 **155 Ma 属于晚侏罗世 (Late Jurassic, Kimmeridgian)**。**建议记 "~155 Ma，晚侏罗世"**，同时知道课件的写法。
2. **死海盐度的单位**：幻灯片写 "**40 ppm，比正常海洋高 5 ppm**"。**这个单位显然有误**（海水盐度约 35 **g/kg = 3.5 wt% ≈ 35 ppt/‰**，死海约 340 g/L）。讲师在课上也自我更正过一次单位（"抱歉，这里是 parts per billion，那边的数字是 parts per trillion"）。**记住相对关系（死海比正常海水高得多、足以直接沉淀盐类）即可，不要背这个数字。**
3. **透光带深度**：幻灯片写"**上部 200 m**"；讲师口头说"**绝大多数在上部约 20 m，200 m 以下绝对没有**"。**两者不矛盾——200 m 是透光带的下限，20 m 是生产力的实际主体所在。**

| Kerogen | 干酪根 | 有机质降解形成的固态有机物，油气的直接来源 |
| Photic zone | 透光带 | 海洋/湖泊上部有足够光进行光合作用的水层（约上部 200 m，主体在 20 m 内） |
| Primary productivity | 初级生产力 | 单位时间内光合作用制造有机物的速率 |
| Upwelling | 上升流 | 冷的富营养深层水沿大陆边缘上涌至透光带，驱动高生产力 |
| Phytoplankton / Zooplankton | 浮游植物 / 浮游动物 | 浮游生物中的自养者与异养者 |
| Plankton | 浮游生物 | **一种生活方式**：随流漂浮、无自主移动能力（既有动物也有植物） |
| Nekton | 游泳生物 | 能主动游动的生物（如现代乌贼） |
| Benthos | 底栖生物 | 生活在沉积物表面或内部的生物（腹足类、双壳类、底栖有孔虫等） |
| Anoxic / anaerobic | 缺氧的 / 厌氧的 | 溶解氧耗尽的水体条件，是有机质保存的前提 |
| Stratification | 水体分层 | 水体上下不混合，使底水缺氧 |
| Restricted seaway | 受限海道 | 与开阔大洋连通差的海域，易发育缺氧或超盐 |
| Carbonate | 碳酸盐岩 | 以石灰岩 (CaCO₃) 和白云岩 (CaMg(CO₃)₂) 为主的沉积岩类 |
| Foraminifera | 有孔虫 | 具钙质壳的单细胞原生生物，浮游型与底栖型均有 |
| Radiolaria | 放射虫 | 用硅质 (SiO₂) 造壳的浮游微体生物 |
| Reef | 礁 | 由固着生物原地生长构筑的碳酸盐格架 |
| Stromatoporoid | 层孔虫 | 已灭绝的重要造礁生物 |
| Bryozoa | 苔藓虫 | 群体固着的造礁贡献者 |
| Crinoid | 海百合 | 具柄棘皮动物，重要的碳酸盐碎屑贡献者 |
| Algal mat | 藻席 | 由藻类形成的席状生长体，可形成叠层构造 |
| Whitings | 白化水 / 泛白 | 水柱中无机碳酸盐沉淀事件，总体贡献不大 |
| Coated grain | 包覆颗粒 | 碳酸盐直接沉淀在已有颗粒表面形成的颗粒 |
| Ooid / pisoid | 鲕粒 / 豆粒 | 具同心包壳的球状碳酸盐颗粒（豆粒粒径更大） |
| Oncoid | 核形石 | 由微生物（藻类）包覆形成的不规则同心状颗粒 |
| Carbonate platform | 碳酸盐台地 | 碳酸盐生产与沉积的整体环境 |
| Rimmed shelf | 镶边陆架 | 与陆相连、有堡礁与礁后潟湖的高生产力碳酸盐台地 |
| Barrier reef | 堡礁 | 台地边缘阻挡波浪的礁体 |
| Patch reef | 斑礁 | 潟湖或缓坡上的孤立小礁体 |
| Isolated platform / atoll | 孤立台地 / 环礁 | 不与陆地相连的碳酸盐岛台，常围绕海洋火山岛发育 |
| Carbonate ramp | 碳酸盐缓坡 | 低生产力条件下形成、无堡礁、均匀向深水倾斜的碳酸盐环境 |
| Grainstone | 颗粒灰岩 | 颗粒支撑、无泥基质的石灰岩，见于潮汐浅滩 |
| Sabkha | 萨布哈 | 干旱海岸的盐坪，蒸发矿物在其中沉淀 |
