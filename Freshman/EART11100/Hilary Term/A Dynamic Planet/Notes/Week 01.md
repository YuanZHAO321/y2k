## 二、核心概念

### 1. 地球系统科学 (Earth System Science) 与"分异行星"

**定义**：把地球当作**一个整体 (the planet as a whole)** 来研究的学科；具体做法是研究发生在**各个圈层内部**以及**圈层之间**的过程。Rhodri 在课上特意强调"whole"这个词要小心理解——不是把地球当成一个均一的球，恰恰相反：

> **地球是一颗分异行星 (differentiated planet)**：它在形成时经历了**部分熔融 (partial melting)**，密度大的物质在重力作用下沉到中心，密度小的留在外部。**正因为分异了，才有了不同的"圈层"**，也才有了圈层之间的梯度和物质交换。

这是一条重要的因果链：**部分熔融 → 密度分异 → 分层结构 → 层间存在化学/物理性质差异与梯度 → 物质与能量必须在层间流动 → 地球化学循环。**

### 2. 五大圈层 (The five spheres / reservoirs)

课上是以开放提问形式引出的（学生答出 lithosphere/geosphere、atmosphere、cryosphere）。老师说"五个，取决于定义也可以说四个"（把 cryosphere 和 hydrosphere 合并算作水圈就是四个）。

| # | 圈层 | 内容 |
|---|------|------|
| 1 | **Atmosphere 大气圈** | 气体 |
| 2 | **Cryosphere 冰冻圈** | 固态水（水冰） |
| 3 | **Hydrosphere 水圈** | 液态水 |
| 4 | **Biosphere 生物圈** | 所有生命的总和 |
| 5 | **Geosphere 地圈（固体地球）** | 再细分为：**Lithosphere 岩石圈** → **Asthenosphere 软流圈** → **Remaining mantle 其余地幔** → **Outer core 外核** → **Inner core 内核** |

关键补充：这些圈层**不是孤立的、也不是各自封闭的系统 (not individually closed systems)**。整个单元研究的正是它们**之间**的交换。

### 3. 两大互相作用的循环：岩石循环 vs 水文循环

Slide 12 是全课的"总纲图"。人类基本生活在地球表面，我们在地表看到的绝大部分现象，都是**两个大循环叠加**的产物：

| 循环 | 驱动能源（"电池"） | 主讲人 | 主要涉及圈层 |
|------|------------------|--------|------------|
| **Rock Cycle 岩石循环** | 地球**内部热量** (Earth's internal heat) | Rhodri | Geosphere |
| **Hydrological Cycle 水文循环** | **太阳能** (the Sun's energy) | David | Atmosphere / Hydrosphere / Cryosphere |

Rhodri 的原话：这是驱动地球行为的**两块"电池"**——地球内热和太阳能。

**关键点（Slide 15，老师反复强调）**：这两个循环**不是分开的、封闭的循环**，它们**重叠、互相作用、存在内部反馈 (internal feedbacks)**。老师在图上"故意画了两个方框重叠的区域"。

**重叠的具体例子（口头补充）**：
- 火山作用属于岩石循环——熔融物质被带到地表喷出；但**同时排放气体**，这些气体改变**大气成分**，进而影响**气候系统**。（岩石循环 → 大气圈 → 气候）
- 反向：**流水的物理作用 + 雨水中的弱酸 (weak acids in rain)** 把火成岩物理破碎并化学溶解，变成颗粒状的**沉积物 (sediment)**；风和水（属于水文循环）再把沉积物搬运走。（水文循环 → 岩石循环）

单元后半段会**加重强调这两个循环的重叠区**（第 11 周气候反馈是集大成）。

### 4. 地球化学循环 (Geochemical cycles)：是什么，为什么发生

**定义**：地球化学循环是**质量（元素）在不同地球圈层/储库之间的循环**——即**物质的实际移动**。加上生物参与就是 **(bio)geochemical cycles 生物地球化学循环**。

**根本原因：热（能量）在地球上分布不均 (heat / energy is unevenly distributed)。** 这是本周最重要的因果起点。

#### 4.1 为什么能量分布不均？（Slide 17，老师逐条讲解）

**外部（大气/地表）**：
- **地球自转 (Earth spins)** → 昼夜 → **时间上的不均一 (temporal heterogeneity)**，白天通常比夜晚暖。
- **地球绕太阳在一个平面上公转** → **气候带 (climate belts)**。赤道区接收阳光更**垂直**，升温多；两极接收的是**切向 (tangential)** 入射的光线，单位面积能量少。
- **地球有倾角 (tilted)** → **季节 (seasons)**。
- 老师补充：这是**三维问题**——不只随**纬度**变化，也随**高度 (altitude)** 变化（David 后面会详讲）。

**内部（固体地球）**：
- **地球不是完美球体，物质也不均一 (not spherical and not materially heterogeneous)** → 有些部分升温比别处快。
- **具体案例（口头 + 图）**：北美之下的**地震层析成像 (seismic tomography) 热图**。在太平洋—北美之下，一直到大约 **3000 km 深**处，有一片**异常低温的岩石**。原因是一个**俯冲 (subducting) 的构造板块**：板块本身是冷的，它的俯冲把大片**冷物质**带入了岩石圈、软流圈乃至更深的地幔。→ 板块构造本身就在制造地球内部的温度不均一。

老师明确说"这些只是**部分**原因 (SOME reasons)"。

#### 4.2 从不均一到物质运动的机制链（Slide 18，核心因果链）

```
能量分布不均
  → 在地球系统各组分中产生 温度梯度 (T gradient) 与 压力梯度 (P gradient)
  → 质量和能量沿梯度运动 (mass and energy move through gradients)
  → 物质被搬到新位置，新位置的 T/P 条件使其变得 不稳定 (unstable)
  → 发生 相变 (phase change) 或 化学反应 (chemical reaction)
  → 生成物理性质（尤其是密度）不同的新物质
  → 重力 (gravity) 介入，驱动进一步的运动
```

**例 1（水文循环，跨圈层 + 相变）**：海洋蒸发中 **80% 发生在赤道地区**。水汽被输送到**高纬度**，在那里以**雪**的形式沉降。→ 因为温度变化发生了**相变**，同时物质从 **hydrosphere（水圈）移动进了 cryosphere（冰冻圈）**。这是"跨储库质量迁移 + 相变"的教科书例子。

**例 2（岩石循环，减压熔融）**：岩石**向上运动 → 进入低压区 → 减压 (decompression) → 熔融 (melting)**。同样是"位置改变 → 新 P 条件 → 相变"。（第 3 周会详讲 decompression melting。）

**例 3（David 补充的完整水循环路径）**：海洋蒸发 → 大气输送 → 全球降水 → 之后水的去向分三条：(a) 汇成**地表径流 (runoff)** 回到河流、回到海洋；(b) 落到陆地被**生物圈吸收**；(c) 下渗成为**地下水 (groundwater)**，之后以**泉 (springs)** 出露或在下游补给河流。

### 5. 岩石循环 (The Rock Cycle)

**定义（Slide 20 原文）**：岩石循环是这样一个概念——**当岩石被迫脱离其平衡条件 (forced out of their equilibrium conditions) 时，它们会改变自己的物理与化学性质。**

**驱动**：
- **主要**：T 和 P 的变化，主要由**构造作用 (tectonics)** 驱动。构造作用 = 刚性板块上的物质在地表的移动；这种移动改变了岩石所处的 T/P 条件，从而在物理与化学上把岩石变成另一种**岩石类型 (rock type)**。
- **辅助**：**水文循环**（流水、雨中弱酸的风化与搬运）、**重力 (gravity)**、以及**有时是生命 (sometimes life!)**。

**一条完整的示例路径（老师口述）**：
```
熔融岩浆 → 喷出地表 → 冷却 → 结晶质火成岩 (crystalline igneous rock)
  → 流水物理作用 + 雨中弱酸化学溶解 → 物理破碎 + 化学分解
  → 颗粒状沉积物 (sediment)
  → 被风和水搬运 (transport)
  → 再沉积 (redeposited) → 埋藏 (buried)
  → 埋得够深 → 重结晶 = 变质作用 (metamorphism)
  → 埋得更深、温度够高 → 再次熔融 (melting) → 回到岩浆
```

**重要限定（老师两次强调）**：和所有（生物）地球化学循环一样，岩石循环**不是一个简单的"圆圈"式循环**。老师说"它比我画成一个圆圈复杂得多"——实际路径可以在任何环节短路、跳步或反复。这是易错点。

### 6. 复习：固体地球的结构——两种模型

| | **化学模型 ("Popular" / chemical model)** | **力学模型 (Mechanical model)** |
|---|---|---|
| 依据 | **成分 (composition)** 的重大变化 | **流变学 (rheological) 行为**的变化，即"流动方式"（老师通俗解释：**多软还是多硬 / squishy or hard**） |
| 分层 | Crust 地壳 / Mantle 地幔 / Outer core 外核 / Inner core 内核 | **Lithosphere 岩石圈 / Asthenosphere 软流圈 / Outer core / Inner core** |
| 评价 | 科普节目常用；对理解地球内部复杂过程**不太有用** | **对理解构造作用与岩石循环更有用**（本单元采用） |

*（Rheology 流变学 = 研究流动的学科，"m. study of flow"）*

#### 6.1 岩石圈 vs 软流圈的力学对比（Slide 22 + 口述数据）

- **Asthenosphere 软流圈**：**弱 (weak)**，因**热梯度（对流 convection）**发生**低速率的韧性变形 (ductile deformation)**——它是**塑性的 (plastic)**（注意：是在**地质时间尺度**上塑性）。
- **Lithosphere 岩石圈**：足够**刚性 (rigid)**，因而可以被分成若干**相对完整的板块 (relatively coherent plates)**；这些板块因为下伏软流圈的变形而**相对彼此运动**——它是**脆性的 (brittle)**。
- **口述数据**：岩石圈厚约 **30–70 km**，平均密度约 **2.8–3.0 g/cm³**。
  - ⚠️ 转写中老师随后说下伏地幔"密度约 2.2 g/cm³"——这与他自己前一句"更致密 (denser)"自相矛盾，应为口误或转写错误。**正确理解：软流圈/地幔比岩石圈的地壳部分更致密（地幔约 3.3 g/cm³）。**记忆时抓住定性结论：**刚性的岩石圈"漂"在更韧性、更致密的软流圈之上**。
- **口述补充**：**洋壳 (oceanic crust) 密度约 3.0 g/cm³** → 密度大 → **位置低 (sits low)** → 海水得以灌入。这是"新生洋壳出现时海洋开始淹没裂谷"的物理原因。

#### 6.2 三类板块边界与岩石圈厚度的响应

| 边界类型 | 运动 | 对岩石圈厚度的影响 | 类比/实例 |
|---|---|---|---|
| **Divergent 离散型** | 板块彼此拉开 | **变薄 (thinning)** | 老师类比：**像把口香糖拉长** |
| **Convergent 汇聚型** | 板块彼此靠近 | **变厚 (thickening)** | — |
| **Conservative 守恒型（转换型）** | 彼此**滑过 (slide against one another)** | 厚度**几乎不变** | **美国与加拿大西海岸** |

**下游后果（本周点到、后面详讲）**：**离散 → 岩石圈变薄 → 减压熔融发生在很浅的位置 → 生成火山**。这正是东非裂谷带边缘火山成群的原因。

### 7. 复习：Wilson 旋回 (Wilson Cycle) 的"空间读法"

老师提出了一个**视角转换**，这是本周方法论上最有价值的一点：

> 上学期学 Wilson Cycle 时，重点是**时间**——某一块地区随时间如何演化。本周要换成**空间**读法：**今天地球上不同的地方，正处在 Wilson 旋回的不同阶段**。因此可以"看着一张今天的世界地图，读出每个地方处在旋回的哪一步"。

**七个阶段 ↔ 现代实例（Slide 23/25/26 + Kahoot 答案）**：

| 阶段 | 名称 | 图上代号 | 现代实例 |
|---|---|---|---|
| 1 | Mature (eroded) continental crust 成熟（被剥蚀的）大陆地壳 | D | **Siberian Craton 西伯利亚克拉通** |
| 2 | Continental rifting 大陆裂谷作用 | G | **East Africa 东非** |
| 3 | Formation of first oceanic crust 首次形成洋壳 | F | **Red Sea 红海** |
| 4 | Mature ocean formed 成熟大洋（仍在张开） | B | **South Atlantic 南大西洋** |
| 5 | Incipience of ocean–continent subduction 洋—陆俯冲开始 | A | **South Pacific 南太平洋** |
| 6 | Closing ocean (subduction of spreading centre) 大洋闭合（扩张中心被俯冲） | C | **Mediterranean 地中海** |
| 7 | Docking of continents, orogenesis 大陆拼合、造山 | E | **Himalaya 喜马拉雅** |

**幻灯片给出的答案序列（Slide 26）**：`D, G, F, B, A, C, E`（对应阶段 1→7）。

**闭环**：阶段 7 造山结束后，山带被**剥蚀夷平**，最终回到阶段 1 那种**稳定、平坦的大陆地壳**（如西伯利亚克拉通）——旋回闭合。

### 图 2：两大循环重叠图（Slide 12–15）
- 一个方框代表 **Rock Cycle**（标注"driven by the Earth's internal heat"），另一个方框代表 **Hydrological Cycle**（标注"driven by the sun's energy"）。

### 图 3：水文循环流程图（Slide 19，USGS 图）
- 判读路径：**海洋蒸发（80% 集中在赤道）→ 大气输送 → 降水 →** 分三支：**地表径流 → 河流 → 海洋** / **被生物圈吸收** / **下渗为地下水 → 泉或补给河流**。
- 判读要点：每一个箭头都是一次**通量 (flux)**；每个方框是一个**储库 (reservoir)**。这就是"通量框图"的标准读法——**储库=方框，通量=箭头**。

### 图 4：岩石循环环形图（Slide 20）
- 判读要点：图上画成圆环（岩浆→火成岩→风化剥蚀→沉积物→沉积岩→变质岩→熔融），但老师明确警告**真实过程不是简单圆环**，存在大量捷径与回路（例如火成岩可直接被变质，沉积岩可直接被剥蚀回沉积物）。
- 每一段箭头都要能说出**驱动力**：抬升/剥蚀由构造+重力+水驱动；埋藏成岩与变质由 T/P 增加驱动；熔融由温度升高**或**减压驱动。

### 图 5：地震层析成像热图（Slide 17 配图，北美之下）
- 横轴为地理位置（太平洋 → 北美），纵轴为**深度，一直到约 3000 km**。
- 颜色代表**温度/地温梯度**。
- **判读要点**：图中那片异常的**低温（冷）岩石**条带 = **正在俯冲的板块残余 (remnant of the subducting slab)**。这张图证明：**板块构造把冷物质注入了地球内部，主动制造了内部的温度不均一**——不是只有"内热向外"，还有"冷物质向内"。

### 图 6：Wilson 旋回七阶段图 + 世界地图配对（Slide 23/25/26）
- 上半：七个构造演化阶段的**剖面示意**（从稳定克拉通 → 裂谷 → 新生洋壳 → 成熟洋 → 俯冲起始 → 洋盆闭合 → 陆陆碰撞造山）。
- 下半：世界地图，标出 A–G 七个地点与 1–7 七个阶段。
- **判读方法（老师希望养成的技能）**：给任意剖面图，能读出①岩石圈是在**变薄**还是**变厚**；②是否有**洋壳**存在、有多宽；③是否存在**俯冲带**；④有无**陆陆碰撞/山根**。由这四条即可定位到旋回的哪一步，再反推现代实例。

## 六、易错点 / 重点难点

1. **岩石循环 ≠ 简单的圆圈。** 老师两次强调"it is not a simple circular cycle"。真实路径存在大量捷径与回路（火成岩可直接变质、沉积岩可直接被剥蚀回沉积物、变质岩可再熔融也可被抬升剥蚀）。考试中若把它描述成单向环路会失分。
2. **两个循环不是封闭的。** Rock cycle 与 hydrological cycle **重叠且互相反馈**。必须能举出**双向**例子：火山排气 → 大气/气候（岩→水气）；降雨弱酸风化 → 沉积物（水气→岩）。
3. **两块"电池"别搞混**：Rock cycle 由**地球内热**驱动；Hydrological cycle 由**太阳能**驱动。
4. **化学模型 vs 力学模型**。Crust/Mantle/Core 是**成分**分层；Lithosphere/Asthenosphere 是**流变学**分层。**两者不对应**——岩石圈 = 地壳 + 最上部地幔。本单元用**力学模型**，因为它才解释得了构造与岩石循环。
5. **软流圈的"塑性"是地质时间尺度上的。** 它不是液体，而是在长时间尺度上发生**低速率韧性变形**。岩石圈是**脆性**的、可分成刚性板块。
6. **转写中的密度数字有误。** 口述"地幔约 2.2 g/cm³"与同句的"更致密"自相矛盾（正确约 3.3 g/cm³）。记忆时抓**定性关系**：岩石圈（含地壳 2.8–3.0）**较轻较刚**，浮于**更致密更韧**的软流圈之上；**洋壳约 3.0 → 位置低 → 海水灌入**。
7. **Wilson 旋回题的"关键词陷阱"**（老师亲自点破，全班在这里失分最多）：
   - "**beginning** to form oceanic crust" → **红海**，不是南大西洋（后者早已是成熟大洋）。
   - "mature ocean **still opening**" → **南大西洋**。
   - "mature ocean **beginning to close**" → **南太平洋**。
   - **地中海与红海都又小又窄，但一个在"生"、一个在"死"**——这是最容易搞反的一对。
8. **裂谷 → 火山的因果链要说全**：岩石圈**拉张变薄** → 软流圈**上涌、减压** → **减压熔融**发生在**很浅**的位置 → 岩浆上升 → **裂谷边缘火山成群**（东非、乞力马扎罗）。只说"裂谷有火山"不给分，要说出**变薄 → 减压熔融**这一步。
9. **"能量不均 → 梯度 → 物质运动 → 相变"这条链是全周的骨架**，任何一个具体例子（赤道 80% 蒸发 → 高纬降雪；岩石上升 → 减压熔融）都要能反过来套回这条链。
10. **地球内部的温度不均一是双向造成的**：不只是"内热向外传"，**俯冲板块还把冷物质带进去**（北美之下 3000 km 深的低温异常）。
11. **副热带 ≠ 热带**：最热最干的是**副热带**（下沉气流），**热带很湿**。
12. **臭氧层耗损 (ozone layer depletion) ≠ 臭氧洞 (ozone hole)**：化学物质有重叠，但**动力学情形完全不同**，臭氧洞需要**极冷的极地平流层云**加速反应（Week 6 详讲）。
13. **评估方式**：整门课 **100%** 靠**考试周的一次两小时考试**（选择题 + 简答），没有平时作业分——复习必须覆盖全部 11 周。
14. **务必用课后版幻灯片复习**：课前上传版可能**缺少 Kahoot 答案与补充信息**。

## 七、本周术语表

| 英文 | 中文 | 一句话解释 |
|---|---|---|
| Earth System Science | 地球系统科学 | 把地球当作一个整体来研究，重点是各圈层**内部**及**之间**发生的过程 |
| Differentiated planet | 分异行星 | 形成时经历部分熔融，致密物质下沉、轻物质上浮，因而形成分层结构 |
| Partial melting | 部分熔融 | 岩石中只有一部分组分熔化，是造成地球化学分异的关键机制 |
| Sphere / Reservoir | 圈层 / 储库 | 地球系统中一个可存储物质与能量的组分（如大气圈、水圈） |
| Atmosphere | 大气圈 | 地球外部的气体包层 |
| Cryosphere | 冰冻圈 | 地球上所有固态水（冰）的总和 |
| Hydrosphere | 水圈 | 地球上所有液态水，绝大部分为海洋 |
| Biosphere | 生物圈 | 所有生命的总和 |
| Geosphere | 地圈 | 固体地球部分，含岩石圈、软流圈、其余地幔、外核与内核 |
| Lithosphere | 岩石圈 | 刚性、脆性的外壳，厚约 30–70 km，密度约 2.8–3.0 g/cm³，被分为若干板块 |
| Asthenosphere | 软流圈 | 岩石圈之下较弱、在地质时间尺度上呈韧性/塑性变形的地幔层，因热梯度而对流 |
| Rheology | 流变学 | 研究物质流动与变形方式的学科；力学模型正是按流变行为分层的 |
| Ductile deformation | 韧性变形 | 不破裂而持续流动的变形方式（软流圈） |
| Brittle | 脆性 | 受力后破裂而非流动（岩石圈） |
| Convection | 对流 | 因热梯度造成物质携热循环运动，驱动软流圈流动与板块运动 |
| Rock Cycle | 岩石循环 | 岩石被迫脱离平衡条件时改变其物理化学性质的整套过程，由地球内热/构造驱动 |
| Hydrological Cycle | 水文循环 | 水在地球系统中的流转，由太阳能驱动 |
| (Bio)geochemical cycle | （生物）地球化学循环 | 质量（元素）在不同地球储库之间的循环，可有生物参与 |
| Equilibrium conditions | 平衡条件 | 岩石（或任何物质）在其中保持稳定的 T/P 与化学条件 |
| Temperature/Pressure gradient | 温度/压力梯度 | 空间上的 T 或 P 差异，是驱动质量与能量流动的直接原因 |
| Phase change | 相变 | 物质在新 T/P 条件下改变物态（如水汽→雪、固体岩→熔体） |
| Decompression melting | 减压熔融 | 岩石上升进入低压区，即使温度不变也发生熔融 |
| Weathering | 风化 | 岩石在地表被物理破碎与化学分解（雨中弱酸是重要因素） |
| Erosion | 侵蚀 | 风化产物被搬离原地的过程 |
| Sediment | 沉积物 | 风化剥蚀（或生物、化学作用）产生的颗粒物质 |
| Deposition | 沉积作用 | 被搬运的沉积物在某处停积下来 |
| Burial | 埋藏 | 沉积物被后续沉积覆盖，进入更高 T/P 环境 |
| Diagenesis | 成岩作用 | 沉积物在浅埋藏条件下固结成岩的过程 |
| Metamorphism | 变质作用 | 埋藏加深、T/P 升高造成岩石重结晶而不熔融 |
| Igneous rock | 火成岩 | 岩浆/熔岩冷却结晶形成的岩石 |
| Plate tectonics | 板块构造 | 刚性岩石圈板块的相对运动，是岩石循环的主要驱动 |
| Divergent boundary | 离散型边界 | 板块拉开，导致岩石圈**变薄** |
| Convergent boundary | 汇聚型边界 | 板块靠近，导致岩石圈**变厚** |
| Conservative boundary | 守恒型（转换型）边界 | 板块相互滑过，岩石圈厚度基本不变（如北美西海岸） |
| Subduction | 俯冲 | 致密板块下插入另一板块之下，同时把**冷物质**带入地球内部 |
| Wilson Cycle | Wilson 旋回 | 大洋从张开到闭合、再到造山与夷平的完整构造演化旋回 |
| Craton | 克拉通 | 长期稳定、已被剥蚀夷平的大陆核心（如西伯利亚克拉通） |
| Continental rifting | 大陆裂谷作用 | 稳定大陆地壳开始被拉张撕开（如东非） |
| Orogenesis / Orogenic belt | 造山作用 / 造山带 | 两个具浮力的大陆岩石圈碰撞形成山系（如喜马拉雅） |
