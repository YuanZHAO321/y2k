## 二、核心概念

### A. 平流层化学

#### A1. Chapman Cycle（查普曼循环）——臭氧层的自然维持机制

五个反应（幻灯片原文，`hν` 表示光子，`M` 表示第三体碰撞分子）：

| 编号 | 反应式 | 条件 | 角色 |
|---|---|---|---|
| **R1** | O₂ + hν → 2 O | λ < 242 nm | **initiation**（引发）：短波 UV 打断 O₂ |
| **R2** | O + O₂ + M → O₃ + M | 放热（energy release） | **大气中唯一生成 O₃ 的途径** |
| **R3** | O₃ + hν → O₂ + O | λ < 310 nm | 快速反应：UV 打断 O₃ |
| **R4** | O + O₃ → 2 O₂ | — | **termination**（终止） |
| **R5** | O + O + M → O₂ + M | — | **极慢，可忽略（neglect）** |

**关键结构——两个互锁的循环（two interlocking cycles）**：

- **慢循环（幻灯片用黑色标注：R1 + R4）**：控制 **odd oxygen（奇数氧）** 的产生与消灭，即把 O₂ 拆成 O、再把 O 变回 O₂。这是整个体系的"总量控制阀"。
- **快循环（幻灯片用蓝色标注：R2 + R3）**：控制 **臭氧 O₃** 本身的产生与消灭，即 O 与 O₂ 之间来回交换。这个循环转得非常快。
- 两个循环通过**共同的 O 原子（原子氧）**连接在一起。

**为什么 R5 可以忽略**：原子氧 O 是自由基（radical，带未配对电子），极不稳定、极易与别的分子结合，因此在大气中丰度极低。两个 O 恰好相遇的概率非常小，所以 R5 的速率可忽略。
> ⚠️ 转写文字这里有明显口误/转写错误："molecular oxygen tends to be rather rare because it's an ion"——按上下文，讲师说的是**原子氧（atomic oxygen, O）非常稀少**，而分子氧 O₂ 占大气约 21%，非常丰富。复习时不要被转写误导。

**M 是什么**：第三体（third body），通常是 N₂ 或 O₂ 分子。它不参与化学变化，但在 R2/R5 中吸收多余的能量与动量，让新生成的分子稳定下来而不立即再解离。

**为什么平流层温度随高度上升（temperature inversion in the stratosphere）**：R1 和 R3 中 O₂、O₃ 吸收 UV 发生**光解（photolysis）**，R2 复合时**放热**。这些过程把 UV 能量转化为热能，所以平流层是被"从内部加热"的——这是平流层稳定层结（极强稳定度、抑制垂直混合）的根源。

#### A2. 催化循环（Catalytic Cycle）——臭氧的化学损耗

引入一个通用的干扰物种 **X**（原子或分子），Chapman cycle 被破坏：

```
X  + O₃  →  XO + O₂
XO + O   →  X  + O₂
─────────────────────
净：O₃ + O → 2 O₂        （X 不被消耗）
```

**机制拆解（讲师强调的因果链）**：

1. O₃ 不如 O₂ 稳定；同时游离的原子氧 O 极其活泼。
2. X 先从 O₃ 手里"偷"走一个 O（生成 XO），再把这个 O 交给另一个原子氧 O，生成 O₂。
3. **净效果 = 消耗掉"两份臭氧当量"**（幻灯片原话：*X steals O, destroying two ozones*）——因为那个被消耗掉的原子氧 O 本来会通过 R2 生成一个新的 O₃。
4. **X 在反应中完全不被消耗**（*X is not consumed in reaction*）——这是催化的本质。所以**一个 X 可以反复循环，摧毁成千上万个臭氧分子**。
5. 由于大气中 O₂ 极其丰富，损耗掉的臭氧转化成的那点 O₂ 对 O₂ 总量毫无影响，因此 **Chapman cycle 无法通过"O₂ 变多"来自我补偿**——损失是**永久性的、不可逆的（no way back out of this cycle）**。

**词源**：**cata-**（"complete"，完全）＋ **lysis**（"loosening"，松解）→ catalysis = 完全的松解/破坏。（讲师课上专门查笔记讲了这个词源。）

**X 的四大来源（幻灯片备注原文，务必记住每一个的上游）**：

| X | 直接来源 | 更上游的来源 |
|---|---|---|
| **OH** | 水汽 | 平流层中**甲烷 CH₄ 被氧化/破坏**产生的水汽 |
| **NO** | N₂O（一氧化二氮） | **氮循环**（自然 + 农业） |
| **Cl** | 有机卤化物 | 部分天然存在；但**长寿命 CFCs 使其大幅增加** |
| **Br** | 有机卤化物 | 同上（溴的单原子破坏效率比氯更高） |

**自然扰动 vs 人为扰动**：

- **自然**：火山喷发释放氯。讲师补充了完整的地球系统因果链——**海水中的氯 → 随俯冲板块进入地球内部 → 被内部过程改造 → 通过火山喷发重新释放**。若喷发足够剧烈、把足够多的氯送进平流层，就能自然地破坏臭氧。地质历史上的大气化学记录中，**火山喷发对应的臭氧扰动信号非常清晰**。
- **人为**：CFCs 的光解。

#### A3. CFCs 与蒙特利尔议定书

- **CFC = chlorofluorocarbon（氯氟烃）**。幻灯片例子：**CFC-12 = 二氯二氟甲烷 dichlorodifluoromethane（CCl₂F₂）**——中心一个 C，四面体（"little pyramids"）四个顶点上接 2 个 Cl、2 个 F。
- **用途与时间线**：直到 **1980 年代初**都被广泛用作**制冷剂（refrigerant）**和**发胶/喷雾剂（hairsprays）的推进剂**。
- **为什么危险——关键在"稳定性"这一悖论**：CFCs 在**对流层中极其稳定**（不与 OH 反应、不溶于水、不被雨冲刷），正因如此它们**活得足够久**，能被环流慢慢带到**平流层**；在那里遇到强 UV 而被光解，释放出**自由氯 Cl**，进入上述催化循环。
- **后果**：平流层臭氧减少 → 到达地表的有害 UV 增加 → **皮肤癌**增加；对**皮肤敏感的两栖动物（amphibians）**等生物危害尤其大。
- **对策**：**Montreal Protocol（蒙特利尔议定书），1987 年**，国际协议，逐步淘汰（suspend over time）CFCs 生产。讲师评价：**"largely successful"**——很大程度上阻止了平流层臭氧的持续下降。

#### A4. 臭氧洞（Ozone Hole）与极地涡旋（Polar Vortex）

**这是与 A2 完全不同的第二类损耗机制**：不是全球缓慢下降，而是**空间与时间上高度聚焦（focused in space and time）的巨量损失**。

**极地涡旋是什么**：把它想成**急流（jet stream）向上、向平流层的延伸**（幻灯片原话：*Think of the polar vortex as an extension of the jet stream in the stratosphere*）。极地对流层顶大约在 **9 km**；再往上，平流层里也有一圈环绕极区的强西风。这圈强风把**极地空气与低纬（热带）空气隔离开**，形成一个**封闭的"小浴缸"式反应舱（a little bathtub / reaction chamber）**。

**完整时间线（幻灯片 16 备注 + 课堂讲解）：**

**冬季阶段（黑暗中的"充电"）**

1. 平流层中的氯化合物与氮化合物反应，生成**稳定的储库分子（reservoir species）：HCl 和 ClONO₂**（硝酸氯）。这些分子本身**不破坏臭氧**。
2. 这些储库分子被环流**输送向极地**。
3. 寒冷的极夜里，涡旋内部发生**强烈的下沉（strong descent / subsidence）**，涡旋核心与赤道一侧的空气**彻底隔离**。
4. 涡旋核心变得**极冷**，冷到足以形成 **PSCs（Polar Stratospheric Clouds，极地平流层云）**——成分是**硝酸（HNO₃）固体晶体 + 水冰**。
   > ⚠️ 讲师特别点出这里的"反直觉点"：下沉运动本来是**不利于成云**的，但极夜平流层实在太冷，加上有足够水汽，冰晶依然能形成。
5. **PSCs 的冰晶表面提供了非均相反应（heterogeneous reaction）的场所**，把惰性的储库氯**活化**成 **Cl₂ 和 HOCl**——这两者在气态下稳定、且**在黑暗中不反应**，于是整个冬天**不断累积**。
6. 同时，因为 HNO₃ 和水被锁进云晶体并沉降，平流层发生 **denitrification（脱氮）和 dehydration（脱水）**。（脱氮很关键：没有 NO₂ 就无法把活性氯重新捕获回 ClONO₂ 储库。）

**春季阶段（日出后的"放电"）**

7. 太阳升起、阳光进入涡旋 → Cl₂ 与 HOCl 被**光解**，释放出高活性的 **Cl 与 ClO**。
8. 这些氯物种充当 A2 中的 **X**，**催化性地**摧毁 O₃。
9. 因为氯被不断再生（regenerated），损耗是**灾难性的（catastrophic）**——整段臭氧柱在很短时间内被"挖空"。讲师原话：*a big chunk of the ozone layer being taken out very quickly*。视频里对比过春季前后的臭氧廓线（ozone profile），可以直接看到某一高度层的臭氧被整体削掉。

**正反馈（务必记住）**

10. 涡旋内没有臭氧 → **没有东西吸收 UV** → 平流层**无法被加热** → 保持低温 → **涡旋得以维持**、低纬富臭氧空气无法混入核心 → **涡旋寿命延长、低臭氧期延长**。这是一个自我强化的正反馈回路。

**南北半球差异（重要考点）**：

| | 南半球（Antarctic） | 北半球（Arctic） |
|---|---|---|
| 首次观测到臭氧洞 | 是 | 否（只是"时而出现类似过程"） |
| 涡旋稳定性 | 稳定、持久 | **波动大、更频繁地崩溃（breaks down）** |
| 原因 | 南极四周海洋、地形平坦、纬向对称好 | **北半球山脉多**，地形强迫产生更多**行星波（waves）**，同时扰动对流层急流和平流层极涡 |
| 结果 | 每年可靠地出现大臭氧洞 | 只在偶尔某些年份出现明显臭氧减少 |

**恢复情况**：因为削减 CFC 排放，南半球臭氧洞**总体在改善**，但**不是均匀改善**——**逐年好坏取决于当年的天气型和极涡的稳定程度**。某些年份极涡异常稳定、整个冬天不崩溃，那一年的臭氧损耗就会**严重得多**。而且平流层里已有的氯需要时间才能被自然过程清除，**不会瞬间恢复**。

### B. 对流层化学

#### B1. 一次污染物 vs 二次污染物

**对流层 = 我们生活的那层空气 = "巨大的搅拌碗"（giant mixing bowl）**，所有天气活动都在这里，所有排放最终都进入这里。

**一次污染物（Primary pollutants）= 直接从源头排放出来的**

| 污染物 | 来源 | 生成机制 |
|---|---|---|
| **SO₂**（二氧化硫） | 燃煤 | 燃烧**富硫煤（sulfur-rich coal）** |
| **VOCs**（挥发性有机化合物） | 车辆尾气、室内涂料/清洁剂 | **不完全燃烧（incomplete combustion）**的碳氢化合物 |
| **Particulates / soot**（颗粒物、烟炱） | 燃烧 | 不完全燃烧、扬尘 |
| **NOx = NO + NO₂** | 内燃机 | **高温燃烧**使空气中的 **N₂ 与 O₂ 直接反应** |
| **NH₃**（氨） | 农业 | 化肥使用释放 |

其他源：工厂、车辆、**野火（wildfires）、火山、农业**。

**二次污染物（Secondary pollutants）= 排放后在大气中经化学反应或相变生成的**

| 二次污染物 | 前体物 | 机制 |
|---|---|---|
| **O₃（对流层臭氧）** | **VOCs + NOx + 阳光** | 白天的**光化学反应（photochemical reactions）**，城市环境中不断生成和破坏臭氧 |
| **硫酸气溶胶 H₂SO₄** | SO₂ | **OH 氧化 SO₂**；气态 → 固态/液态颗粒 |
| **硝酸气溶胶 HNO₃** | NO₂ | **OH 氧化 NO₂** |

**清除机制（removal）**：

- **Dry deposition（干沉降）**：颗粒直接靠重力沉降到地面。
- **Wet deposition（湿沉降）**：被雨滴捕获，或**作为凝结核（nucleus）**让液滴/冰晶在其上凝结，随降水落下。
- 讲师提醒：湿沉降"把污染物移出大气"，但结果是**酸雨（acid rain）**——*"not an ideal solution anyway, but at least it's out of the atmosphere"*。

#### B2. 臭氧：平流层好、对流层坏（讲师明确说这是"每年都有很多同学答错"的点）

> **Ozone in the stratosphere: GOOD.  Ozone in the troposphere: BAD.**

- **平流层臭氧 = 好**：吸收高强度、短波 UV，保护地表生命。我们希望它越多越好。
- **对流层臭氧 = 坏**：那个"额外的氧"具有强氧化性 → 呼吸道刺激物（irritant）、损害健康；还会**加速塑料等材料的老化降解**。

#### B3. 羟基自由基 OH——大气的"清洁剂"（detergent of the atmosphere）

幻灯片要点：

- **OH 是大气中重要的氧化剂（oxidant）**。
- **寿命极短（~1 秒）**，但**浓度近乎恒定**——因为它**被消耗得多快，就被重新生成得多快**（reformed as quickly as it is destroyed），可以视为处于**化学平衡（equilibrium）**状态。
- **丰度很低，但对维持大气化学平衡至关重要**。
- 作用：把 **NO₂（一次污染物）转化为 HNO₃（二次污染物）**，从而**把它移出气相**；同样地也与**甲烷、一氧化碳、VOCs**反应，**"清洗"大气**。
- 因为 OH 的存在，**NO₂ 浓度会下降**。

**OH 的两条生成途径（幻灯片备注引 Wikipedia）**：

1. **白天**：不同波长的光与空气中的**水**及**植物释放的萜烯（terpenes）**发生光化学反应，产生**活性氧物种（ROS, Reactive Oxygen Species）**，其中主要一类就是羟基自由基。
2. **全天 24 小时**：**萜烯与臭氧反应**生成 OH。

课堂上讲师给的简化说法：OH 来自 **H₂O 的破坏**——H₂O 断掉一个 H，剩下 OH。

**为什么重要**：一旦污染物被 OH 转成固相/液相，就更容易被**干沉降**或**被雨捕获/充当凝结核**而清除出大气。

#### B4. 颗粒物（Particulate Matter, PM）与健康

| 名称 | 定义 | 典型成分 |
|---|---|---|
| **PM10** | 直径 **≤ 10 微米（μm）** 的所有颗粒 | 粉尘、**花粉、细菌**、燃烧产物、**烟炱（soot）、轮胎碎屑（tire fragments）** |
| **PM2.5** | 直径 **≤ 2.5 微米** 的所有颗粒 | 燃烧产生的气体经**化学反应生成的固体气溶胶颗粒** |

**逻辑关系**：PM10 是包含关系，**PM10 的浓度必然大于 PM2.5 的浓度**（PM2.5 是 PM10 的子集）。

**健康机制（因果链）**：

- 与**人类头发直径**对比（幻灯片用头发做尺度参照）：PM10 相对头发直径已经是很大的"靶心"。
- **PM10**：一般被**鼻毛和黏液（hair and mucus）**拦截在鼻腔或咽喉。
- **PM2.5 及更小**：**突破呼吸系统的天然防线，直达肺部**。
- **短时间暴露影响有限**；但**长期累积**后，颗粒**沉积在肺泡（alveoli）上**，损害肺功能与**氧气交换效率**。

**讲师补充的现实提醒**：污染不只是室外问题。**室内**的清洁剂、油漆等会释放 VOCs；**有研究表明室内 VOC 浓度甚至高于污染的城市户外环境**。

#### B5. 案例研究：1952 年伦敦大烟雾（Great Smog of London, 5–9 December 1952）

**核心公式化因果条件（幻灯片原文）**：

> **高排放 + 高压系统（晴朗、弱风、低层对流层稳定 → 逆温 → 垂直混合极差）= 严重污染事件**

**气象背景（1952 年 12 月 7 日地面天气图，课堂展示）**：

- **高压中心正好位于英格兰南部**；
- 站点数据：**T = −8 °C，Td = −9 °C，p = 1035.5 hPa**；地面气温 **−5 °C 到 0 °C**；
- **等压线（isobars）非常稀疏 → 风极弱**；伦敦及其西侧站点的**站点模式（station models）显示静风（calm）**；
- **地面以上约 1.5 km 处温度为 +2 °C**，而地面只有 −5 ~ 0 °C。

**逆温（Inversion）**：

> 当**温度随高度上升**时称为**逆温**。逆温**抑制垂直混合**，把污染物**捕获（trap）在近地面**，导致空气质量极差。

讲师比喻：逆温层像一个**"盖子（lid）"**，污染物无法向上输送到整个对流层深度，只能在浅薄的近地层里不断浓缩。（他说二年级的 atmospheric science 课会讲为什么这是"稳定"的。）

**排放侧**：气温在冰点以下 → 大家**疯狂烧煤取暖**；当时**英国的煤含硫极高** → 大量**颗粒物 + SO₂**；SO₂ 在**低云和雾中被氧化成硫酸**。

**观测数据（Beaver, Hugh, Dec 1953, "Great Britain Committee on Air Pollution: Interim Report", HMSO, pp. 17–18）**——图上四条曲线的单位要记住：

| 量 | 单位 |
|---|---|
| **Sulphur Dioxide** | 空气中的百万分之一体积比 **ppm**（**10 个站点的平均**） |
| **Smoke** | **mg m⁻³**（**12 个站点的平均**） |
| **Temperature** | **华氏度**（Air Ministry 屋顶的**正午读数**） |
| **Deaths** | 每天的**总死亡人数** |

图上可见：随高压系统建立，**烟（实线）与 SO₂（虚线）浓度同步上升**，**每日死亡数随之飙升**。

**Excess Deaths（超额死亡）——流行病学核心概念**

- 定义：把某一事件期间的死亡数，与**"正常情况下平均每天会死多少人"**（取自过去若干年同期的长时间序列）相比，**取两者之差**。
- 图上：**虚线 = 往年同期每日死亡数；实线 = 1952–53 年冬季实际死亡数**；两者之差的尖峰即为超额死亡。
- **关键的历史教训**：**在事件发生的当时，没有人把超额死亡和空气污染联系起来！**医院只是"比平时忙"，急救人员并未意识到这是一次污染事件。**是事后统计分析才揭示出来的**。
- **同一方法在 COVID 期间被大量使用**——因为每天本来就有人死，重要的是**超出常规日死亡数的那部分**，据此在统计意义上估算 COVID 致死人数。

**后续治理（讲师口述）**：立法限制燃煤炉排放、**淘汰富硫煤**、转向**电气化供暖与天然气** → 空气质量显著改善。

### C. 水圈（Hydrosphere）

#### C1. 地球水的分布与"水圈"的定义边界

- 地球上的水**绝大部分在海洋里**。
- 少量淡水储存于：**冰盖与冰川（ice caps, glaciers）、地下水（groundwater）**，以及更少量的**湖泊、土壤水、河流**。
- **定义边界（易考）**：**大气中的水一般不算作水圈**（*Atmospheric water is generally not considered part of the hydrosphere*）；**生物体内的水**通常也不算。
- 因此本讲余下部分**专注于海洋**。

#### C2. 温跃层（Thermocline）与海洋层结（Stratification）

**定义**：**thermocline = 近表层 dT/dz 很大的那一层**（*the region of large dT/dz close to the surface*）。

**驱动机制（因果链，讲师反复强调）**：

1. **太阳辐射的吸收和海气热量交换只发生在海洋极薄的表层**（*Only a tiny fraction of the ocean interacts with the atmosphere directly*）。
2. 因此**海洋是"从上面加热"的（heated from above）**。
3. 暖水密度小、浮在上面 → 海洋变成**稳定层结（stably stratified）**。
4. 稳定层结**抑制向下的热量传递（inhibiting heat transfer to lower levels）**，也**抑制混合**。
5. 结果：暖水被锁在浅层，深海保持又冷又均匀。

**特征与尺度**：

- **今天的海洋是深度层化的（deeply stratified）——但历史上并非一直如此**（此处呼应 hothouse/icehouse 概念，见 F 节）。
- **温跃层夏季最强**（strongest in summer）。
- 尺度：从**几十米到几百米**都有；**热带最强**（加热最强）。
- **日常尺度的微缩版**：讲师举例——夏天在地中海或海里站着，**从腰部到脚只有一米左右，就已经能明显感到温度骤降**，这就是温跃层的"微缩版本"。

**大西洋位温经向剖面图（Vertical meridional section of potential temperature）的判读**：
从**南极到北极**穿过大西洋的纵剖面上——热带表层是**又暖又浅的一层**，向中纬度延伸；而**海洋深处几乎没有温度梯度**（温度低而均匀）。结论：**从温度看，"动作"几乎全发生在近表层**。

（实时观测参考：热带北太平洋的 **TAO（Tropical Atmosphere Ocean）观测阵列**浮标温度-深度廓线，https://tao.ndbc.noaa.gov/ ；全球浮标 https://www.ndbc.noaa.gov/ ）

#### C3. 表层洋流与环流圈（Surface Currents & Gyres）

**基本格局**：

- 每个大洋盆地中，**北半球是顺时针（clockwise）环流圈**，**南半球是逆时针（counterclockwise）环流圈**。
- **洋流把暖水输送向极、把冷水输送向赤道**（*transport warm water poleward and cold water equatorward*）。
- **暖流 vs 冷流的判定法则（北半球）**：水从**南边（低纬）流上来** = **暖流**；水从**北边（高纬）流向赤道** = **冷流**。

**西边界流（Western Boundary Currents）——每个海盆都有的强暖流**

- **Gulf Stream（湾流）**——北大西洋；
- **Kuroshio Current（黑潮，kùróshíó）**——北太平洋。
- 特点：**又强又窄**，把热带暖水一路带到高纬度；在 SST 图上表现为沿大陆**东岸**向北突出的**温度"隆起（bulge）"**。

**东边界（大陆西岸）——冷流 + 上升流**

- 南美洲西岸有很强的冷流（配合安第斯沿岸上升流）。
- **讲师的亲身对比案例**：他在**宾夕法尼亚**长大，暑假去**美国东海岸**海滩——即使纬度相当高，海水依然相当宜人（湾流之功）；而**加利福尼亚**的太平洋沿岸，即使 9 月末也**冷得难受**，要一直南下到**圣迭戈（San Diego）靠近墨西哥边境**才觉得舒服。这就是**西边界暖流 vs 东边界冷流＋上升流**的直观体现。

**赤道流（Equatorial currents）**：受大陆阻隔而被切断；**在"水球（aquaplanet）"模式实验中，因为没有大陆阻挡，赤道流会非常强而连续**。（可在 Build Your Own Earth 里选 Aquaplanet 验证。）

#### C4. 盐度（Salinity）与 E − P

**控制机制**：

> **E > P（蒸发 > 降水）→ 盐被浓缩 → 高盐度**
> **P > E（降水 > 蒸发）→ 被稀释 → 低盐度**
> （P 也包含**径流 runoff**）

**全球格局（幻灯片 44/45 的纬向分布，从赤道向两极）**：

| 纬度带 | E vs P | 盐度 | 大气环流原因 |
|---|---|---|---|
| 赤道 / **ITCZ（热带辐合带）** | **P > E** | **低（蓝）** | 上升运动、强降水 |
| **副热带（Subtropics）** | **E > P** | **最高（橙红）** | **副热带反气旋（subtropical anticyclones）**：下沉、少云、日照强、蒸发旺盛 |
| **中纬度（极地急流 Polar Jet Stream 所在）** | **P > E** | **低** | 风暴路径、锋面降水多 |
| 高纬/极地 | **P > E** | 低 | 蒸发弱 |

**实例（讲师亲身体验）**：**地中海盐度很高**；**红海（Red Sea）盐度更高**——在红海里游泳时**浮力明显更大**，与淡水泳池或普通海水对比强烈。

**为什么盐度重要**：**海水密度 = 温度 + 盐度共同决定**，而**正是这种密度差驱动了全球海水环流**（→ thermohaline circulation / 海洋输送带，本周点到为止，后续详述）。

**海气耦合的对称性（讲师强调的"大图景"）**：海洋盐度的格局，就是大气环流格局（副热带反气旋、ITCZ、中纬急流）在海洋里"盖的一个印"——**这是把 hydrosphere 和 atmosphere 联系起来看的最好例子之一**。

> 📌 **讲师明说这可能会考**：给你一个假想地球的分布图，让你指出**哪里盐度最高、哪里最低**。方法就是先判断该纬度带是 E>P 还是 P>E。

#### C5. Ekman 螺旋与 Ekman 输运（动量的海气交换）

**问题**：风吹在海面上，海流会沿风向流动吗？——**不会。**

**机制（力平衡）**：

1. 风通过**摩擦（friction）**把动量传给海表水。**海水中的摩擦比大气中大得多**。
2. 做**力平衡**（摩擦力 + **科氏力 Coriolis force**）→ 得到理论结果：**表层流方向与风向成 45°夹角**（北半球偏**右**）。
3. 越往深处，**驱动力越弱**（因为强迫来自表面）→ **流速逐渐减小**；同时**方向继续偏转**。
4. 每一层靠摩擦被上一层拖动、比上一层慢、并被科氏力继续偏转 → **形成螺旋**，到约 **100 m（330 ft）深度运动基本消失**。
5. 由于深层流得比浅层慢，它们最终**"扭转过来"、与表层流方向相反**。

> **Ekman spiral（艾克曼螺旋）**：流速与流向随深度的这种螺旋式变化。以瑞典科学家 **Vagn Walfrid Ekman（1874–1954）**命名，他在 **1902 年**首次从理论上推出。

6. 把**整层（约 0–100 m）积分**，得到**净输运**——**Ekman transport（艾克曼输运）**：

> **Ekman 输运方向 = 与风向成 90°**
> **北半球（NH）：风向的右侧 90°**
> **南半球（SH）：风向的左侧 90°**（因为科氏力方向相反）

**要点区分（极易混淆）**：
**45° = 表层流与风的夹角；90° = 整层净输运与风的夹角。**

#### C6. 上升流（Upwelling）与初级生产力

**因果链（讲师完整讲了一遍）**：

1. 风**沿海岸吹**（北半球，使**海岸位于风的左侧**）。
2. **Ekman 输运把表层水搬到风的右侧 = 离岸方向（offshore）**。
3. 表层水被搬走了，**必须有水来补充** → 只能**从下面上来**。
4. 由于**温跃层**的存在，下面的水**明显更冷**，而且**营养盐更丰富（nutrient-rich）**。
5. **冷 + 富营养的水涌升到真光层** → **初级生产力（primary productivity）暴增**。

**这一机制解释的可观测格局**：

- **SST 场**：北美西海岸（加利福尼亚）、南美安第斯沿岸出现**异常冷的海水**（北风沿岸吹 → 上升流）。
- **NPP（Annual Net Primary Production，年净初级生产力）图**——单位：**植物产生净有用化学能的速率，g of C m⁻²**：
  - **红/橙色 = 高生产力**；
  - **大陆西岸的上升流带**是高值区；
  - **风暴路径（storm track）区**（如北大西洋）也是高值区——但那里的机制**不是 Ekman 上升流，而是风暴造成的强烈混合（mixing due to the storms）**把深层营养盐搅上来。
  - > ⚠️ 注意区分这两种"把营养盐送上来"的机制：**沿岸风驱动的 Ekman upwelling** vs **风暴引起的垂直混合**。

**微观案例：墨西哥/中美洲太平洋沿岸的两个"生产力热点"（讲师的自己的研究）**

来源：**Schultz, D. M., W. E. Bracken, L. F. Bosart, G. J. Hakim, M. A. Bedrick, M. J. Dickinson, and K. R. Tyle, 1997: "The 1993 Superstorm cold surge: Frontal structure, gap flow, and tropical impact." *Mon. Wea. Rev.*, 125, 5–39; Corrigendum, 125, 662.**

- **现象**：NPP 图上，墨西哥/中美洲太平洋一侧的**两个海湾**（Gulf of Tehuantepec 和 Papagayo/尼加拉瓜外海）出现**异常的生产力极大值**，尺度远小于周围的大格局。
- **机制（geosphere–atmosphere–ocean 三圈耦合）**：
  1. 冬季，**大型温带气旋（extratropical cyclone）**穿过北美、在美国东岸外发展。
  2. 气旋后面**跟着一个高压系统**，驱动强劲的**北风**沿落基山/Sierra Madre 山脉东侧**南下**。
  3. 山脉中有**缺口（gaps）**——一个在特万特佩克地峡、另一个在**尼加拉瓜**。气流**从缺口"突破"到太平洋一侧** = **gap flow（缺口风）**。
  4. 这股突破气流的**前缘形成弧状云（arc-shaped cloud）**，卫星可见光图上清晰可辨。
  5. 强风**把浅层暖水吹走并强烈混合** → **SST 骤降**。
  6. **红外卫星实测数据**：事件**前** SST 约 **23–24 °C**（另一湾可达 **25 °C**）；事件**后**中心最低降到 **16 °C**，另一处约 **18 °C** → **降温 4–7 °C**。
  7. 这种事件**每个冬天可发生数次**，累积效应造成常年的生产力高值区。
- **名称**：这些强风在墨西哥/西班牙语中叫 **Nortes**。
- **生态与经济后果**：冷却/上升流发生后**数周到数月**，浮游生物**暴发（bloom）** → 食物链上行 → 最终**金枪鱼（tuna）等大鱼聚集**。因此 **1960 年代有大量关于 Nortes 及其海洋效应的研究——金枪鱼渔业想知道什么时候去哪里捕更多的鱼**。

**判读练习（课堂互动）**：讲师展示了 1993 Superstorm 的**可见光卫星云图**，问：
- **这是热带气旋还是温带气旋？** → **温带气旋（extratropical cyclone）**。
- **低压中心在哪？** → **在"逗号头（comma head）"与"逗号尾（comma tail）"之间的钩状（hook）处**。
- 那条一直延伸到墨西哥的**逗号尾**是被**山脉（落基山向墨西哥、中美洲的延伸脊）挡住堆积**的高反照率云。

#### C7. 海平面上升

- **机制**：大气变暖 → **海洋温度上升** → **水受热膨胀（thermal expansion）** → **占据更大体积** → **平均海平面上升**。
  （幻灯片标题：*Mean sea level is rising as the oceans warm (expand and occupy more volume)*）
- **量级**：过去 **30 年**，多颗卫星（altimetry）合成的时间序列显示**厘米量级（on the order of centimetres）**的上升。
- **空间分布**（trend map）：有局地极大和极小（与气候型有关），但**除极少数异常位置外，全球海洋几乎处处在上升**。
- 数据来源：**https://sealevel.colorado.edu/** 与 `.../trend-map`。
- ⚠️ 注意：本周只讲了**热膨胀**这一项贡献；冰川/冰盖融化是 Week 8 冰冻圈的内容。

#### C8. 波浪（Waves）

**（1）按周期分类的波谱（幻灯片 59：wave period vs log(wave height)，Pinet 2016）**

从**短周期→长周期**：

| 类型 | 周期尺度 | 成因 |
|---|---|---|
| **Capillary waves（毛细波）** | 最短（<~0.1 s） | **表面张力（surface tension）** |
| **Chop（碎浪/风浪）** | 秒级 | 局地风直接作用 |
| **Swell（涌浪）** | 更长周期 | 远处风区生成、经频散整理后传来 |
| **Seiches（假潮/湖震）** | **1–5 分钟** | **海湾/封闭水体内的驻波振荡** |
| **Tsunamis（海啸）** | **数十分钟到数小时** | 海底地震、滑坡、崩塌 |
| **Tides（潮汐）** | **12 h / 24 h** | 月球与太阳的引潮力 |

> 讲师特别提到：**毛细波很重要**——因为**卫星可以通过观测海面毛细波来反演海面风场**（散射计原理）。

**（2）基本定义**

- **Wave height（波高）**：**波谷（trough）到波峰（crest）**的高度差。
- **Wavelength（波长）**：**相邻两个波谷之间（或相邻两个波峰之间）的距离**。
- **Wave period（周期）**：相邻两个波峰经过同一点的时间间隔。
- **Wave base（波基面）**：水质点轨道运动衰减到可忽略的深度，约等于**½ 波长**。**深水波（deep-water waves）= 水深 > 波基面，波"感觉不到"海底**。

**（3）波浪不搬运水，只搬运能量**

> **Surface waves mostly do NOT transport water molecules forward.**
> *（\*except for Stokes drift）*

- 水质点做**轨道运动（orbital motion）**，原地转圈，**能量向前传播而水本身不前进**。
- **例外：Stokes drift（斯托克斯漂流）**——**波峰处的轨道运动比波谷处更强**，导致每转一圈都有一点点净前进，因此存在**微小的净输运**。

**（4）从风区到涌浪：频散（dispersion）与整理**

- 在**风区（fetch）内**：由于各种波的**相长干涉与相消干涉（constructive and destructive interference）**，海面波形**混乱不规则（chaotic, less organized）**。
- **离开风区后**：波按速度**自我分选（sort themselves by dispersion）**——
  > **短周期波传播慢，长周期波传播快。**
- 结果：长周期波跑在前面，形成规则的 **ocean swell（涌浪）**。**我们在海滩上看到规则破碎的浪，就是这种整理过的涌浪。**

**（5）浅化（shoaling）、破碎与折射（refraction）**

- 深水波进入浅水：**波速减小、波长减小、波高增大（increases）** → 最终**破碎（breaking）**。
  > ⚠️ **幻灯片 63 的原图有错**：原书图上写 "wave height **decreases**"，**应为 "wave height increases"**，讲师已在幻灯片上更正。**这是一个明确的勘误点。**
- **破碎的意义**：能量在破碎时释放到岸边 → **驱动沙、砾等沉积物的搬运（transport of sediments）**。这是把 hydrosphere 与地貌/沉积过程联系起来的关键接口。
- **折射（Refraction）**：
  > **波进入浅水会折射，使波峰线尽可能地变得与海岸平行。**
  - 判读方法：远海处波峰线可能与海岸**近乎垂直/斜交**；越靠近海岸，波峰线**逐渐弯曲**，破碎时**基本平行于海岸**。
  - 原因：波峰线上先进入浅水的那一段先减速，于是整条波峰线被"扳"向岸线。

**（6）离岸流（Rip current）——讲师说"这条可能救你的命"**

- **成因**：波浪破碎把水推上岸，这些水必须回流；受**海底地形（bottom topography）**影响，回流可能在某处**局地增强**，形成**很强的、垂直于海岸向外的窄流**。
- **错误做法**：**逆着离岸流往岸边硬游**——游不动，会耗尽体力。
- **正确做法**：
  > **平行于海岸游 / 垂直于离岸流方向游。**
  - 理由：**离岸流通常很窄**，横向游一小段就能脱离它的控制，然后再回岸。

**（7）海啸（Tsunami）——圈层相互作用的例子**

- **成因**：**地震、水下滑坡或崩塌（slump）**造成**深水层水体的大规模位移**——这是 **geosphere/lithosphere 与 hydrosphere 的直接耦合**。
- **深海中的表现**：波高只有**几十厘米到 1 米**，与普通波浪无异，船上几乎察觉不到；**但整个水柱深处都在运动，蕴含巨大能量**。
- **近岸放大**：随着水深变浅，能量被压缩到浅水柱中 → **波高剧增**，可造成毁灭性内陆洪水。
- **自救原则**：
  - 在岸上：**留意海啸警报/警报器**；若震源不在极近处会有一些时间；**尽快向高处、尽量向内陆撤离**。
  - **在船上：不要靠岸上岸！应该驶向更深的水域**——那里波高小，海啸波只是从船底滑过。
- 参考：https://www.ready.gov/tsunamis ；https://community.fema.gov/ProtectiveActions/s/article/Tsunami

#### C9. 潮汐（Tides）

**（1）两个潮汐隆起（two bulges）**

- 潮汐由**月球和太阳**共同造成，**月球的影响最大**（虽然太阳质量大得多，但潮汐力与距离的**三次方**成反比）。
- **朝向月球的一侧**：水被月球引力**吸引**而隆起。
- **背向月球的一侧**：由于地-月系统绕共同质心旋转所产生的**离心效应（centrifugal force）**，也形成一个隆起。
- 因此地球自转一周会依次经过**两个隆起** → **地球上很多地方一天有两次高潮和两次低潮（半日潮）**。

**（2）为什么真实潮汐比理想模型复杂**

- **摩擦（friction）与不对称性（asymmetry）**：水在"巨大浴缸（giant bathtub）"般的海盆里**晃动（sloshing）**，因此**月球位置与潮汐最大值出现的位置之间存在延迟（lag）**。
- **月球轨道不在黄道面（ecliptic plane）内**，所以潮汐随所在位置和时间变化。
- **海盆形状/地形**决定各地实际潮差。

**（3）潮型的纬度分布（重要规律）**

| 纬度 | 潮型 |
|---|---|
| **低纬度** | **半日潮（semidiurnal）——一天两次** |
| **中间纬度** | **混合潮（mixed tides）**——半日与全日分量叠加 |
| **高纬度（两半球）** | **全日潮（diurnal）——一天一次** |

**（4）主要分潮的周期（幻灯片 73，Pond and Pickard 1983, *Introductory Dynamical Oceanography*）**

| 周期 | 类型 |
|---|---|
| **½ 天（~12 h）** | 半日分潮（semidiurnal，如 M₂、S₂） |
| **1 天（~24 h）** | 全日分潮（diurnal，如 K₁、O₁） |
| **13.6 天** | 双周分潮（fortnightly，Mf） |
| **27.4 天** | 月分潮（monthly，Mm） |
| **182.6 天** | 半年分潮（semi-annual，Ssa） |

  > 讲师提醒：**去海岸看岩层露头（rock formations）之前，必须查好高潮低潮时间。**
- **NASA 潮汐动画**：https://moon.nasa.gov/moon-in-motion/tides/

**（6）大气也有潮汐（Atmospheric Tides）**

> **The atmosphere has tides, too — although relatively small and generated by HEATING rather than gravitational tidal forces.**

- **驱动机制的根本差异**：海洋潮汐由**引潮力**驱动；**大气潮汐由（高层大气的）太阳加热循环**驱动 → 加热周期造成**气压场的周期性变化**，因此**大气潮跟随太阳**。
- **主要分量**：**S₂（principal solar semidiurnal，太阳半日分潮）**。
- **振幅**：幻灯片图上 **1000 = 1 mbar** 的刻度——**振幅约 1 hPa 量级，很小**。
- **传播方向**：**向西传播（propagation is to the west）**，跟随太阳。
- **实例**：**Ascension Island（大西洋 8°S）**的地面气压时间序列（横轴 0 → 3 天，每 0.5 天一格）——可以清楚看到**每天两个峰**的半日振荡。
- **全球变化**：大气潮的振幅与相位随地点变化（幻灯片 79，*Mass, Steenburgh, and Schultz 1991, Monthly Weather Review*——讲师说这是他**最早期的论文之一**，研究美国各地大气潮的形态与含义）。

## 三、公式与图表

### 1. Chapman Cycle 反应组（必须默写）

```
[R1]  O₂ + hν  →  2 O            λ < 242 nm     （initiation，慢）
[R2]  O + O₂ + M  →  O₃ + M      放热           （唯一的 O₃ 生成途径，快）
[R3]  O₃ + hν  →  O₂ + O         λ < 310 nm     （快）
[R4]  O + O₃  →  2 O₂                           （termination，慢）
[R5]  O + O + M  →  O₂ + M                      （极慢，忽略）
```

**符号说明**：
- `hν` = 光子能量（h = 普朗克常数，ν = 频率）；波长越短、能量越高。
- `M` = 第三体（third body），通常为 N₂ 或 O₂，吸收多余能量/动量使产物稳定，本身不发生化学变化。
- `O` = **原子氧自由基（radical）**——带有**未配对电子（unpaired electron）**的化学物种，极活泼。

**两个波长阈值的物理含义**：
- **242 nm** 是打断 O=O 双键所需的最短波长门槛（键能更强 → 需要更高能量 → 更短波长）；
- **310 nm** 是打断 O₃ 所需——**O₃ 的键更弱，所以较长波长的 UV 就足以打断它**。
- **推论**：O₃ 能吸收 242–310 nm 这一段 O₂ 吸收不了的 UV-B，**这正是臭氧层保护地表的关键**。

**互锁循环示意图的判读方法**：
图中两个"齿轮"式循环——
- **左侧（黑，慢）齿轮**：`O₂ ⇄ 2O`，标注 *creates/destroys **odd oxygen***，由 [R1] 和 [R4] 驱动。
- **右侧（蓝，快）齿轮**：`O + O₂ ⇄ O₃`，标注 *creates/destroys **ozone***，由 [R2] 和 [R3] 驱动。
- **两个齿轮的啮合点 = 原子氧 O**。
- **判读逻辑**：只要 [R1]–[R4] 保持**平衡（in balance / equilibrium）**，臭氧层就被稳定维持；**任何外来物种打乱这个平衡都会造成净臭氧损失**。

### 2. 催化循环（Catalytic Cycle）

```
X  + O₃  →  XO + O₂       （X 从臭氧偷走一个 O）
XO + O   →  X  + O₂       （X 被再生，同时消灭一个原子氧）
──────────────────────────
净反应：O₃ + O → 2 O₂
```

**图表判读要点（幻灯片 8–13 的动画分解）**：
1. 第一步：X 攻击 O₃；
2. 第二步：XO 与 O 反应；
3. 关键标注一：***X steals O, destroying two ozones***——净效果相当于消灭两个臭氧当量（一个直接消灭的 O₃，加上一个本可以由那个 O 生成的 O₃）；
4. 关键标注二：***X is not consumed in reaction***——所以可无限循环；
5. 结论标注：**catalytic cycle / catalysis**。

**X = OH, NO, Cl, Br**。

### 3. 臭氧洞时间线示意图（幻灯片 16，编号 1–4 对应图中标号）

判读顺序（务必按这个顺序背）：

```
冬季（黑暗）
  ① 强下沉 + 极冷 → 形成 PSCs（HNO₃ 晶体 + 水冰）

```

### 4. 平流层温度廓线 vs 臭氧廓线（Kahoot 第 3 题的图）

**现象**：**平流层最暖处在约 50 km（平流层顶 stratopause）；但臭氧浓度最大值在约 25 km。**

**为什么两者不重合——两个相反梯度的"竞争/平衡"**：

| 因素 | 随高度 |
|---|---|
| **可用的 UV 辐射通量** | **随高度增加而增强**（往下走，UV 被逐层吸收滤掉，越深越少） |
| **氧分子的数密度（number density）** | **随高度增加而减小**（大气密度随高度指数下降） |

- **臭氧浓度极大值（~25 km）**：出现在这两者**乘积最优**的高度——再往上，虽然 UV 足，但**"分子太少，没有足够的地方让臭氧生成/吸收"**；再往下，虽然分子多，但 UV 已被上层滤掉。
- **温度极大值（~50 km）**：出现在**UV 吸收（单位质量加热率）最强的高度**——那里空气密度极低，**同样多的吸收能量加热的空气质量很少，所以温度升得很高**。

> 讲师原话概括："**平衡在于——上面是紫外辐射吸收最多（导致加热）的地方，下面是分子密度更大、能吸收 UV 的地方。**"


  1. **大陆西岸沿岸带**（加州、秘鲁-智利）→ **Ekman 上升流**；
  2. **中纬风暴路径（北大西洋等）**→ **风暴引起的垂直混合**；
  3. **Tehuantepec / Papagayo 两个小热点**→ **Nortes 缺口风引起的混合与上升流**。
- **低值区**：**副热带大洋环流圈中心**——下沉、层结强、温跃层深、营养盐上不来（"海洋沙漠"）。
- 讲师坦言图上**还有一些他也没研究过的局地极大值**——"maybe something to explore for people in the future"。

### 9. 波浪周期谱图（幻灯片 59：wave period 横轴 vs log(wave height) 纵轴）

判读方法：从左（短周期）到右（长周期）依次为 **capillary → chop → swell → seiche → tsunami → tide**；纵轴用对数是因为波高跨越好几个数量级。记住每一类的**成因**（表面张力 / 风 / 远处风区+频散 / 海湾共振 / 地质位移 / 天体引力）。

### 10. 有用的定量关系（课程给出的定性关系 + 标准补充公式）

**课程明确给出的定性关系**（考试重点在这些）：

| 关系 | 内容 |
|---|---|
| 表层流 vs 风 | **45°**（NH 向右） |
| Ekman 输运 vs 风 | **90°**（NH 向右，SH 向左） |
| Ekman 层厚度 | **≈ 100 m** |
| 波的频散 | **周期越长 → 传播越快** |
| 浅化 | 水深减小 → **波速↓、波长↓、波高↑** → 破碎 |
| PM 关系 | **[PM10] > [PM2.5]**（后者是前者的子集） |

**标准补充公式**（幻灯片未直接列出，但理解上述图表有帮助，作为背景知识）：

- **波基面**：`wave base ≈ λ / 2`（λ = 波长）——水深大于此值即为深水波。
- **深水波速**：`c = gT / (2π)` ≈ `√(gλ / 2π)`——**c 与周期 T 成正比，这就是"长周期波跑得快"（频散）的数学根据**。
  - 符号：c = 相速度（m s⁻¹），g = 9.81 m s⁻², T = 周期（s），λ = 波长（m）。
- **浅水波速**：`c = √(g d)`——**只依赖水深 d**。这解释了为什么海啸（波长极长，处处是"浅水波"）在深海中传播极快、进入浅水后急剧减速并使波高暴涨。

### 1. 开场天气实况更新（500 hPa 图判读实战）

讲师用**前一天（周日）午夜的 500 hPa 图**做实时教学：

- **等值线 = 500 hPa 等压面的位势高度**；
- **风羽（wind barbs）**：**羽/旗（pennants）越多，风越强**；
- **等值线越密集 = 风越强**（可与风羽互相验证）；
- **实况**：急流在**北美东部下凹（dip）**（那里连日偏冷），随后向**东北**延伸；**周日及上周后半段，急流位于英国以北**。
- **法则复习**：**急流以南是暖侧（warm side）** → 英国处于暖侧 → 天气温和。
- **深云与降水倾向于跟随急流** → 急流在北方 → **英国相对干燥**。
- **昼夜温差的机制**：天空**少云或无云** → **夜间强辐射冷却** → 清晨只有 5–6 °C；白天有太阳加热 → 下午 10–15 °C。讲师调侃这让穿衣很难，"只需要一件薄外套"。

### 2. 关于"墨西哥湾流让欧洲温暖吗？"的科学观念课（课前视频的答疑）

这是本周**最重要的科学方法论内容**，讲师花了很长时间讲：

- **传统断言**："Gulf Stream makes Europe temperate"——长期被当作常识，媒体和大众讨论中反复出现。
- **科学实验**：有研究者在模式中**"关掉"墨西哥湾流**、同时**保持海温固定**，结果**欧洲气候几乎没有变化**。
- **真正的机制**：欧洲之所以温和，是因为**处在一大片不结冰的水体的下风向（downwind of a large body of water that doesn't freeze）**：
  - 这个纬度上，即使**隆冬**，海水温度仍有约 **8–10 °C**；
  - **越靠近英国，冬季海温更是 11–12–15 °C**。
  - **是这片温暖的海水在调节我们的气温，而不是湾流本身。**
- 湾流确实把暖水**比原本更往北推了一点**，但**它并不是欧洲温和气候的原因（not the Gulf Stream per se）**。
- **方法论要点（讲师的重点）**：
  > "科学不是固定的（science isn't fixed）……即使是某篇科学论文里陈述过的观点，也随时可能被**新结果、新证据或新的思考方式**推翻。做科学家最有趣的事情之一，就是**拿一个众所周知的东西，换一个角度重新审视，看它是否还站得住脚**。"
  > 他还说：也许在座各位中的某个人，未来会推翻他今天讲的某些内容。

### 常见混淆点逐条辨析

**① 45° vs 90°（Ekman）**
- **45°** = **表层流**与风的夹角；
- **90°** = **整层积分的 Ekman 净输运**与风的夹角。
- 半球：**NH 向右，SH 向左**。

**② 臭氧的两种损耗机制不要混为一谈**

| | 全球性衰减 | 臭氧洞 |
|---|---|---|
| 空间 | 全球 | **极涡内部，高度局限** |
| 时间 | 数十年缓慢 | **春季日出后数周内急剧发生** |
| 机制 | 气相催化循环 | **PSCs 表面的非均相反应 → 冬季活性氯累积 → 春季光解爆发** |
| 必要条件 | 只需要 X 存在 | **极涡 + 下沉 + 极冷 + PSCs + 黑暗积累 + 春季日出** |

**③ 平流层臭氧好 vs 对流层臭氧坏**——讲师年年强调的错题。

**④ 一次 vs 二次污染物**
- **一次 = 直接排放**：SO₂、NO、NO₂、VOCs、颗粒物、NH₃。
- **二次 = 大气中生成**：**O₃、H₂SO₄、HNO₃**。
- 陷阱：**NO₂ 是一次污染物**（燃烧直接排放），但它也是生成 O₃ 和 HNO₃ 的前体物。

**⑤ PM10 与 PM2.5 是包含关系，不是并列关系**
PM10 = 直径 ≤10 μm 的**全部**颗粒，**包含** PM2.5。因此 **[PM10] 一定 ≥ [PM2.5]**。

**⑥ 高盐度不在赤道，在副热带**——因为 ITCZ 降水极多。

**⑦ 高气压 = 好天气 ≠ 好空气**
**高压系统 = 晴朗、弱风、下沉、逆温 = 最糟糕的空气质量条件。** 这是伦敦烟雾和 Kahoot 第 7 题的共同答案。

**⑧ 海洋 PM10 高值是海盐，不是污染**（ManUniCast 读图陷阱）。

**⑨ 波不搬运水**——只有 Stokes drift 有微小净输运。破碎带才有真正的水与沉积物输运。

**⑩ 幻灯片 63 的印刷错误**：浅化时 **wave height INCREASES**（原书图印成 decreases，讲师已更正）。

**⑪ 大气潮汐是加热驱动的，不是引力驱动的**；主分量 **S₂**，振幅约 1 hPa，**向西传播**。

**⑫ 极涡的正反馈**：**没有臭氧 → 不能吸收 UV → 不能增温 → 极涡更稳定 → 更难混入富臭氧空气 → 低臭氧期更长**。要能把这个闭环讲出来。

**⑬ CFCs 的"稳定性悖论"**：正因为它们在对流层**极其稳定**（不被清除），才能活到进入平流层并在那里被 UV 打碎——**稳定性是它们危险的原因，不是安全的保证**。

**⑭ 湾流神话**：欧洲温和**不是**因为湾流，而是因为**位于不结冰海洋的下风向**。

**⑮ 上升流 vs 风暴混合**——两种把营养盐带到表层的不同机制，NPP 图上的高值区要能分别归因。

| **VOC** | 挥发性有机化合物 | 不完全燃烧、油漆、清洁剂释放；与 NOx 在阳光下生成臭氧 |
| **Hydroxyl radical (OH)** | 羟基自由基 | 对流层关键氧化剂；寿命约 1 s、浓度近恒定，把污染物氧化后移出气相 |
| **Oxidant** | 氧化剂 | 使其他物质失去电子的物种；大气中最重要的是 OH |
| **Dry deposition** | 干沉降 | 颗粒直接沉降到地面 |
| **Wet deposition** | 湿沉降 | 被雨滴捕获或充当凝结核随降水落下；后果之一是酸雨 |
| **PM2.5 / PM10** | 细颗粒物 / 可吸入颗粒物 | 直径 ≤2.5 μm / ≤10 μm 的颗粒；PM2.5 可绕过呼吸道防线直达肺泡 |
| **Alveoli** | 肺泡 | 肺内进行氧气交换的结构；PM2.5 长期累积在此损害肺功能 |
| **Inversion** | 逆温 | 温度随高度升高；极稳定、像"盖子"一样抑制垂直混合并锁住污染物 |
| **Great Smog of London** | 伦敦大烟雾 | 1952 年 12 月 5–9 日，高压 + 逆温 + 富硫煤燃烧导致的重大污染致死事件 |
| **Excess deaths** | 超额死亡 | 实测死亡数减去历史基线；流行病学与公共卫生的核心统计方法 |
| **ManUniCast** | 曼大预报系统 | 曼彻斯特大学的天气与空气质量数值预报网站，本课的实操工具 |
| **Hydrosphere** | 水圈 | 地球上的液态与固态水；主体是海洋，一般不含大气水和生物体水 |
| **Thermocline** | 温跃层 | 近表层 dT/dz 很大的层；夏季最强、热带最强，强烈抑制垂直混合 |
| **Stratification** | 层结 | 海洋"从上加热"导致的稳定分层，阻碍热量与营养盐的垂直交换 |
| **Potential temperature** | 位温 | 扣除压缩加热效应后的温度，用于比较不同深度/高度的热力状态 |
| **Gyre** | 环流圈 | 各大洋盆地的大尺度环流；NH 顺时针、SH 逆时针 |
| **Western boundary current** | 西边界流 | 每个海盆西侧的强窄暖流，如 Gulf Stream、Kuroshio |
| **Gulf Stream** | 墨西哥湾流 | 北大西洋西边界流；讲师强调它**并非**欧洲温和气候的真正原因 |
| **Kuroshio Current** | 黑潮 | 北太平洋西边界流 |
| **Equatorial current** | 赤道流 | 被大陆切断；在 aquaplanet 模拟中会非常强而连续 |
| **Salinity** | 盐度 | 海水含盐量；由 E − P 控制，与温度共同决定海水密度 |
| **E > P / P > E** | 蒸发大于降水 / 降水大于蒸发 | 前者造成高盐（副热带），后者造成低盐（ITCZ、中纬） |
| **ITCZ (Intertropical Convergence Zone)** | 热带辐合带 | 赤道附近的强降水带，对应盐度极小值 |
| **Subtropical anticyclone** | 副热带反气旋 | 下沉、少云、蒸发强，对应盐度极大值 |
| **Ekman spiral** | 艾克曼螺旋 | 风驱动的流速随深度减小、流向持续偏转的螺旋结构，约 100 m 处消失 |
| **Ekman transport** | 艾克曼输运 | 整层净输运，垂直于风向：NH 向右 90°、SH 向左 90° |
| **Coriolis force** | 科氏力 | 地球自转产生的偏向力；NH 向右偏、SH 向左偏 |
| **Upwelling** | 上升流 | 离岸 Ekman 输运把表层水搬走，冷而富营养的深层水补充上来 |
| **Net Primary Production (NPP)** | 净初级生产力 | 植物净合成有用化学能的速率，单位 g C m⁻² |
| **Gap flow / Nortes** | 缺口风 / 北风事件 | 冷高压驱动的气流穿过山脉缺口冲入太平洋，造成 4–7 °C 的 SST 骤降与生产力暴发 |
| **Extratropical cyclone** | 温带气旋 | 中纬度锋面气旋；卫星图上呈逗号状，低压中心在逗号头与尾之间的钩状处 |
| **Thermal expansion** | 热膨胀 | 海水受热体积增大，是近 30 年海平面上升的重要贡献之一 |
| **Wave height / Wavelength / Period** | 波高 / 波长 / 周期 | 谷到峰的高差 / 相邻两谷（峰）间距 / 相邻波峰经过同一点的时间 |
| **Wave base** | 波基面 | 约 ½ 波长的深度；水深大于它即为深水波，"感觉不到"海底 |
| **Stokes drift** | 斯托克斯漂流 | 波峰处轨道运动强于波谷，造成微小的净向前输运（波浪唯一的水体输运） |
| **Fetch** | 风区 | 风持续吹拂海面的区域；区内波形混乱，区外经频散整理为涌浪 |
| **Dispersion** | 频散 | 长周期波比短周期波传播快，使波列自我分选 |
| **Swell** | 涌浪 | 离开风区后整理成规则长周期波列，是海滩上常见的破碎浪 |
| **Chop** | 风浪/碎浪 | 局地风直接产生的短周期不规则浪 |
| **Capillary waves** | 毛细波 | 由表面张力控制的极短波；卫星据此反演海面风 |
| **Seiche** | 假潮 / 湖震 | 海湾或封闭水体中的驻波振荡，周期 1–5 分钟 |
| **Shoaling** | 浅化 | 波进入浅水，速度与波长减小、**波高增大**，最终破碎 |
| **Refraction** | 折射 | 波峰线在浅水中弯曲，使波尽可能平行于海岸破碎 |
| **Rip current** | 离岸流 | 破碎后的回流受地形集中形成的强离岸窄流；逃生方法是平行海岸游 |
| **Tsunami** | 海啸 | 地震/滑坡造成的水体大位移波；深海仅几十厘米，近岸急剧增高 |
| **Tide** | 潮汐 | 月球（主）与太阳引潮力造成的两个隆起，随地球自转产生高低潮 |
| **Semidiurnal / Diurnal / Mixed tide** | 半日潮 / 全日潮 / 混合潮 | 低纬度多半日潮，高纬度多全日潮，中间纬度为两者叠加 |
| **Tidal constituents** | 分潮 | 周期分别为 ½ 天、1 天、13.6 天、27.4 天、182.6 天等的潮汐分量 |
| **Atmospheric tide (S2)** | 大气潮汐 | 由太阳加热（非引力）驱动的气压振荡，振幅约 1 hPa，向西传播 |
| **Marine snow** | 海洋雪 | 从真光层向深海持续下沉的有机碎屑颗粒（来自课前视频） |
| **Hothouse / Icehouse climate** | 温室气候 / 冰室气候 | 前者无大陆冰盖、极赤温差小、**海洋输送带减弱**；后者相反 |
| **BYOE (Build Your Own Earth)** | 自建地球 | 曼大的气候模式交互工具，从 Week 8 起使用 |
