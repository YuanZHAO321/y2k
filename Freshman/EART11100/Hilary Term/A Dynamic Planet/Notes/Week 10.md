### 1. 成岩作用 (Diagenesis) —— W10 PT1

#### 1.1 定义与和变质作用的界线

- **成岩作用 (diagenesis)**：使**松散沉积物 (loose sediment) 岩化 (lithification) 成岩石**的**一系列过程**（lithos = 希腊语「岩石」）。
- **变质作用 (metamorphism)**：在**施加热能与机械能**之后，**固态**下（严格无熔融）发生的**矿物学与结构的改变**。

两者都涉及**加热 + 加压**，且**成岩作用是渐变过渡到变质作用的 (gradational)**——没有一条尖锐的界线。但可以用**四条判据**区分：

| 判据 | 成岩作用 Diagenesis | 变质作用 Metamorphism |
|---|---|---|
| **驱动因素** | 仅仅是**沉积盆地内上覆负载 (overburden) 的简单埋藏** | **额外的热或机械能**——不可能仅靠盆地内简单埋藏达到 |
| **体系开闭** | **开放系统**：可加入新物质（尤其是**胶结物 cements**），**全岩化学成分可显著改变** | **基本封闭系统**：全岩成分基本不变（详见下） |
| **沉积结构** | 沉积结构 (sedimentary textures) 在成岩过程中**仍可辨认** | 变质之后沉积结构**不再可辨** |
| **产物** | 沉积岩 | 变质岩 |

> 记忆钩子：**「盆地里躺着 = 成岩；被构造/岩浆折腾 = 变质」**；**「还看得出原来的颗粒和层理 = 成岩；看不出来了 = 变质」**。

#### 1.2 成岩作用的子过程（幻灯片用「累加式清单」逐张展开）

完整清单：**压实 (Compaction) → 颗粒重组/旋转 → 颗粒破裂 → 压溶 → 溶解 → 胶结 → 重结晶 → 矿物置换**。

**(a) 压实 (Compaction) 之一：颗粒重组/旋转 (grain reorganisation / rotation)**
- 上覆负载施加机械压实，颗粒**重新排列、旋转**以减小体积。
- 关键细节：**岩石体积没有减小，减小的是孔隙空间 (pore space)**；颗粒被「堆得更紧 (better packed)」。
- 导致**脱水 (dewatering)**——占据孔隙的水被排出。
- **颗粒的长轴倾向于旋转到与压缩/缩短方向垂直**（这与后面变质作用中片理的成因是同一个力学道理！）。
- **野外证据：砂岩岩脉 (sandstone dykes)**——压实脱水时，砂粒被水带上来、注入上覆沉积物中形成脉状体，是脱水的直接证据。

**(b) 压实之二：颗粒破裂 (grain fracturing)**
- 当颗粒已经堆到不能再堆，进一步的压实只能靠**颗粒的机械破裂**来吸收。
- 观察标志：正交偏光 (XPL) 薄片中砂岩里大量**破裂的颗粒**。

**(c) 压实之三：压溶 (pressure solution)**
- 机制：**与压缩方向垂直的颗粒接触面上的物质溶解**，溶质**再沉淀为胶结物，沉淀在与压缩方向平行的颗粒接触面上**。
- 净效应：同样是**孔隙度损失**（岩石厚度减小）。
- 岩性依赖：**碳酸盐中极常见**（这些矿物极易进入溶液）；**碎屑岩需要更大的埋深**才能发生。
- 薄片识别：垂直于压缩方向的颗粒接触面变得**平直或内凹 (concave/indented)**；平行于压缩方向的面保持**自然的外凸 (convex)** 并带胶结物。

**(d) 溶解 (dissolution)**
- 由 T、P 或**孔隙水成分**的变化引起，使矿物**在溶液中比在固相中更稳定**。
- 例：向碳酸盐中泵入**淡水（大气水 meteoric water）**会溶解方解石与文石——**可以在近地表就发生**。
- 石英进入溶液要困难得多，**需要更大的埋深**。
- **只溶解不再沉淀**的情形，出现在**长期被外来孔隙水持续冲刷、供应源源不断**的系统中——孔隙水始终不饱和，抑制了再沉淀。
- 常见于碳酸盐，碎屑岩中较少。

**(e) 胶结 (cementation)**
- 定义：**化学沉淀物（新晶体）在沉积物/岩石的孔隙中形成，把颗粒黏结在一起**。
- 常见胶结物：**石英、各种碳酸盐（方解石、文石、白云石）、黏土**。
- 效应：**填充粒间孔隙，降低原生孔隙度 (primary porosity)**。

**(f) 重结晶 (recrystallisation)**
- 定义：**同一矿物相**的晶格**重新取向**；通过**已存在的同一矿物相的溶解—再沉淀**实现。
- **通常不引起孔隙空间的净变化**。
- 注意与变质作用里的 recrystallisation 是同一个词、同一个机制概念，只是强度不同。

**(g) 矿物置换 (mineral replacement)**
- 定义：新形成的矿物**原地 (in situ) 取代**先存矿物。
- 两种情形：
  1. **成分相同、但为其同质多象 (polymorph)**：例如生物成因**文石 (aragonite) → 方解石 (calcite)**。
  2. **一个矿物相被另一个完全置换**：例如**方解石 → 白云石 (dolomite)**。
- **体积效应**：多象转变或离子交换会导致体积变化，从而**破坏或增加孔隙度**。
  - 关键例子：**方解石 → 白云石导致矿物体积减少 11%，孔隙空间等量增加**。
- **白云石化 (dolomitisation)** 的反应式（幻灯片注明「No need to learn」）：

  $$2\,\mathrm{CaCO_3\,(calcite)} + \mathrm{Mg^{2+}} \leftrightarrow \mathrm{CaMg(CO_3)_2\,(dolomite)} + \mathrm{Ca^{2+}}$$

  - 为什么受重视：这是**少数能增加孔隙度的成岩过程**，对**油气或地下水储集**有利。

#### 1.3 成岩作用的效应：烃源岩成熟与油气窗

- 幻灯片给的情景：**地温梯度约 35 °C/km 的盆地中的成熟 (maturation)**。
- **成熟的烃源岩 (mature source rocks) 才能生成石油**。
- **油窗 / 气窗 (oil / gas windows)**：生油/生气的**温度区间**。
  - **油峰 (oil peak)**：生油量最大的温度。
  - **气峰 (gas peak)**：生气量最大的温度。
- **过成熟 (overmature) 的烃源岩不再生成油或气**。
- （参考值，幻灯片未给数字，供理解用：油窗约 60–120 °C，湿气/凝析气约 120–150 °C，干气约 150–200 °C；在 35 °C/km 下大致对应 2–6 km 埋深。）

> **因果链**：埋藏 → 温度升高 → 干酪根 (kerogen) 热裂解 → 先出油、再出气 → 温度过高则只剩残余碳（过成熟）。这条链条把 diagenesis 与经济地质直接连起来。

### 2. 什么是变质作用 (Metamorphism)

#### 2.1 定义

- 词源：**meta（改变）+ morph（形态）**＝「形态改变」。
- **定义**：**在固态下（严格无熔融）发生的矿物学 (mineralogy) 与结构 (texture，即矿物的形状与大小) 的改变。**
  - 课堂强调：**一旦发生熔融，我们立刻回到火成作用的那一套过程**，就不再是变质作用了。
- **本质**：对**热能 (thermal energy) 与机械能 (mechanical energy，即压力/做功) 输入的响应**——岩石**向新的平衡态 (equilibrium state) 调整**。
- **不改变岩石的全岩化学成分 (bulk chemical composition)** ⟹ 是一个**封闭系统 (closed system) 过程**：**只有能量的传递，没有物质的传递**。

#### 2.2 「封闭系统」的两个例外

幻灯片和课堂都点明：一年级层面把变质作用当作严格封闭系统处理，但严格说有两类例外：

1. **挥发分 (volatiles) 的丢失**：**H₂O 与 CO₂**会被排出（H₂O 大量赋存于黏土矿物的晶体结构中；CO₂ 来自碳酸盐）。**它们有时也可以被加入**。
2. **交代作用 (metasomatism)**：由**热的、饱和的孔隙水的泵送 (pumping)** 带来的**元素的加入或带出**所引起的变质作用——这是真正的开放系统。

> 讲者在课堂末尾特意回头承认：「我一开始说是封闭系统，你可以先忽略这句——事实上多数时候不是完全封闭的，变质过程中会把水从矿物里挤出来。」这个「例外」恰恰是**不发生退变质**的关键机制之一（见 §2.9）。

#### 2.3 变质作用中发生的两件事

##### (1) 重结晶 (Recrystallisation)

- 定义：**已存在的矿物采取新的结构（形状与大小）**；某些矿物还会采取**优选方位 (preferred orientation)**。
- **不产生新矿物**——矿物种类不变，只是「换个形状住得更舒服」。
- **教科书例子：砂岩 (sandstone) → 石英岩 (quartzite)**
  - **原岩薄片**：石英颗粒**边缘浑圆 (rounded, abraded)**——因为它们作为沉积物被搬运时棱角被磨掉；颗粒之间有**孔隙**，孔隙里长着**胶结物晶体**。
  - **变质后薄片**：**浑圆边缘消失、孔隙与胶结物消失**，代之以**紧密咬合的「粒状变晶结构」(interlocking granoblastic texture)**。
  - **矿物完全相同（都是石英），只是重结晶到一个在该压力条件下"更快乐、能量更低"的状态**。
  - 课堂提示：两张薄片颜色不同只是因为**薄片磨的厚度略有差别**，与矿物无关（薄片判读易错点）。

##### (2) 新矿物化 (Neomineralisation)

- 定义：**以牺牲已有矿物为代价形成新矿物**（新的化学式，或新的同质多象）。
- 机制：**矿物之间（± 流体）发生化学反应**——本质上是**元素在不同矿物之间「互换」并重新组合**，且**全程在固态下进行**，**没有任何新物质从体系外进来**。
  - 课堂的简化模型：矿物 A 由元素 x+y 组成，矿物 B 由元素 z+w 组成，两者各交换一个元素，就得到全新的两个矿物 —— 总成分没变。
- **教科书例子：页岩 (shale) → 片岩 (schist)**
  - 页岩是**由黏土矿物 (clay minerals) 组成的沉积岩**；黏土矿物**结构复杂、含大量不同金属元素 + 硅**。
  - 变质后，这些元素**重新分配、重排晶体结构**，形成三类全新矿物：
    - **云母 (micas)** —— 薄片中呈鲜艳的蓝、黄、橙干涉色；
    - **石榴子石 (garnet)** —— 大的黑色团块（幻灯片描述为 "black blobs"）；
    - **十字石 (staurolite)** —— 白色至灰色。
  - **同时颗粒尺寸明显增大**。
- **同质多象 (polymorph) 的形成**也算新矿物化：
  - **定义（课堂给的）**：**化学成分完全相同、但分子/晶体结构不同的矿物**。
  - 例：**方解石 (calcite) 与文石 (aragonite)**，同为 CaCO₃，晶体结构不同。
  - 例：**石英 (quartz) → 柯石英 (coesite)**（见 §2.8 冲击变质）。

> **两件事对比**：重结晶＝**只换形状**；新矿物化＝**换矿物**。绝大多数真实变质岩两者同时发生。

#### 2.4 为什么变质岩重要？

1. **体积上最丰富**：变质岩在**地壳（及上地幔）中的体积超过火成岩与沉积岩之和**——尽管在地表不常见到。
2. **经济价值**：**寄主重要的经济矿产 (economically important mineral deposits)**。
3. **不退变质 (they tend not to undergo retrograde metamorphism)**：岩石被带到深处发生一系列矿物与结构变化，**抬升冷却回到地表时这些反应往往不逆转**——因此**变质岩保留了深部条件的记录**，可以用来**重建地球内部深处正在发生的过程**。这是本周最重要的一条「方法论」结论。

#### 2.5 原岩控制 (Protolith control)

- **所有类型的火成岩和沉积岩都可以（潜在地）被变质**。
- 变质岩可以由**任何先存岩石（原岩 protolith）**衍生而来，因此**变质岩整体上展现出极大的全岩成分范围**。
- 因果推论：**起始成分种类多 × 变质条件（P、T、应力）组合多 ⟹ 可能的变质岩类型数目非常庞大**。
- **经验法则 (rule of thumb)**：**变质级 (metamorphic grade) 升高 = 晶体尺寸增大**（但显然也取决于原岩的粒度）。
  - 课堂应用：「野外看到变质岩越来越粗，通常意味着它埋得越深。」
  - **唯一例外**：**断层带的动力变质（粒度反而减小）** —— 见 §2.8。

##### 为什么用泥岩 (mudstone) 和玄武岩 (basalt) 作为原岩案例？

这是本周一个非常重要的**概念性论证**（幻灯片 Slide 31 + 课堂详述）：

- 思想实验：可能被变质的主要岩石类型有哪些？
- **砂岩 (sandstone) 没用**：它压倒性地由**石英**组成（有时含一点长石），而**石英在所有变质级下都稳定**——它不会分解、不会形成新矿物，因此**不能告诉你任何关于变质条件的信息**。石英岩只是「更大的石英」。
- **碳酸盐岩类似**：大理岩 (marble) 主要是方解石重结晶，也是以**结构变化为主**。
- **泥岩 (mudstone) 与玄武岩 (basalt) 才是好的记录器**：
  - **泥岩**富含**成分极其复杂的黏土矿物群**，含大量不同元素，**极易随温压条件重新组合**成一系列新矿物。
  - **玄武岩**（或其他基性火成岩，如**辉绿岩 dolerite、辉长岩 gabbro**）同样具有**复杂的矿物结构**。
- 结论：**其他岩类的变质以结构变化为主 (dominated by textural change)**；**泥质与基性岩才提供「矿物学温度计/压力计」**。

#### 2.6 变质作用的成因：两大营力

**营力一：温度 (Temperature)**
- (a) **「原生热」(Original heat)** —— **地温梯度 (geothermal gradient)**
- (b) **「局部热」(Local heat)** —— **火成侵入体 (igneous intrusions)**

**营力二：应力 (Stress)**
- (a) **负载压力 (Load pressure)** —— 即静岩压力
- (b) **偏应力 (Deviatoric stress)**

##### (1a) 原生热：地温梯度

- **热源**：**放射性衰变**，以及**残余的吸积与分异动能 (accretionary and differentiation kinetic energy)**——即行星形成期转化并储存下来的热。
- **平均地温梯度：25–30 °C/km**。
- **但它随构造背景强烈变化**——这是本周的核心变量！

| 构造背景 | 地温梯度 | 出处 |
|---|---|---|
| **俯冲带 (subduction zone)** | **约 3–5 °C/km**（冷的地壳被快速带入深处，把地温「压低」） | 幻灯片 + 课堂 |
| **平均/稳定大陆** | **25–30 °C/km** | 幻灯片 |
| **沉积盆地（成岩例）** | **约 35 °C/km** | W10 PT1 |
| **洋中脊 (mid-ocean ridge) / 离散边界** | **约 50 °C/km**（约为正常值的两倍；课堂口误说成 60） | 幻灯片 + 课堂 |
| **活动火山区（岩浆侵入围岩处）** | **可 > 100 °C/km** | 课堂 |

##### 关键定量推理（课堂反复强调，务必掌握）

> 把一块岩石**埋到 10 km**：
> - 在**俯冲带**（5 °C/km）：承受 10 km 的上覆负载，但温度只有 **约 50 °C** ⟹ **高压 / 低温**。
> - 在**离散边界**（约 50–60 °C/km）：同样只有 10 km 的上覆负载，温度却达 **约 500–600 °C** ⟹ **（相对）低压 / 高温**。
>
> **同样的压力，截然不同的温度 ⟹ 形成完全不同的变质矿物 ⟹ 变质矿物组合是构造背景的指纹。**

##### (1b) 局部热：火成侵入体

- 出现在 **Week 3 讨论过的那些构造背景**中。
- 特点：**强烈的局部热源**，**扰乱「正常」的地温梯度**，产生**强烈但局限 (strong but localised)** 的变质效应。
- 幻灯片图示：人站在一条侵入到围岩 (country rock) 中的**玄武质岩墙 (dyke)** 上；紧邻侵入体的区域被强烈「烘烤 (baked)」。
- **课堂给的定量约束（很重要的易错点）**：
  - 用岩浆冷却图（Week 3 学过）：对一个厚度为 250 m 的岩体，在距接触面 250 m 处，温度相对于初始岩浆温度的比值 **< 0.2**。
  - 即：若岩浆为 1000 °C，1000 年后在 250 m 外温度约 **200 °C** ——**通常不足以引起变质**。
  - **结论：受影响的范围（变质晕）大致不会显著超过岩体自身的厚度**（向两侧各约一个厚度）。一条 3 m 厚的岩墙只能烤几米。

##### (2a) 负载压力 / 静岩压力 (Load pressure = lithostatic / confining stress)

- **先定义应力**：**应力 (S) = 力 (F) / 面积 (A)**；正式定义是「物体中某质点通过一个假想分界面施加于相邻质点的单位面积平均力」。
  - **为什么用应力而不用力**：一个边长 25 cm 的砂岩立方体受 10 吨压力可能几乎不变形；同样的力施加在边长 1 cm 的立方体上则会被**粉碎**。所以材料行为要以**应力单位（帕斯卡 Pa = N/m²）**来衡量，而不是力。
  - **课堂类比：钉床 (bed of nails)**——钉子越多，力被分摊到越大的总面积上，应力越小，所以人能躺上去。
- **负载压力**：由**上覆岩石的重量**产生；**在各个方向上均匀作用**（类比：水下的静水压力——游泳时下潜到池底感受到的四面八方的压力）。
- **公式**：

  $$P = \rho\,g\,h$$

  （ρ = 上覆岩石/水的密度，g = 重力加速度，h = 深度）

- **关键推论（本周最重要的洞见之一）**：
  - **大陆地壳密度 ≈ 2.8 g/cm³**；**地幔橄榄岩 (peridotite) 密度 ≈ 3.1 g/cm³** —— **两者差别不大**（处在密度谱的两端也才差约 10%）。
  - **g 全球基本相同**。
  - ⟹ **负载压力的主控变量是深度 h**，而不是密度或构造背景。
  - ⟹ **「不管你在俯冲带、在拉张边界、还是在造山带内部，你身上的上覆负载压力基本只是你埋深的函数。」**
  - 幻灯片的表述：**负载压力随构造背景确实有变化，但相对于温度的变化可以忽略不计**。

> ⚠️ **数值校核（幻灯片存疑处）**：Slide 14 写「By approx. 3.5×10⁸ Pa (3.5 Kbar)/km」，Slide 38 写「Normal load pressure gradient is 3.5 GPa/Km」。二者互相矛盾，且都与实际不符。**正确计算**：P = ρgh = 2800 kg/m³ × 9.8 m/s² × 1000 m ≈ **2.7×10⁷ Pa ≈ 27 MPa ≈ 0.27 kbar 每公里**（即约 **1 kbar ≈ 3.7 km**，或 **1 GPa ≈ 35 km**）。考试若需估算深度，请用 **≈ 27–30 MPa/km** 或记住 **1 GPa ≈ 35 km**；幻灯片上的 3.5 kbar/km 与 3.5 GPa/km 应视为笔误（3.5×10⁸ Pa 大约对应 **10 km** 的负载，而非 1 km）。

##### (2b) 偏应力 (Deviatoric / differential / triaxial stress)

- 定义：**在某些环境中，应力不是各向均匀地作用于岩石**（不是简单的静岩应力）。
- **成因**：板块不仅垂向埋藏，还**水平运动**：
  - **汇聚板块边缘的挤压力 → 偏应力**
  - **离散板块边缘的拉张力 → 偏应力**
- **岩石对偏应力的响应随深度/温度改变**：
  - **冷而脆的上地壳**：**破裂 (fracturing) = 断层作用 (faulting)**。
  - **温而韧的中—下地壳**：**塑性变形 (plastic deformation) = 褶皱作用 (folding)**。**热降低了岩石强度**。
- **核心结论（考点）**：
  > **热的岩石是软弱的，因此它们通过塑性变形来「化解并耗散」偏应力 ⟹ 偏应力对矿物稳定性的影响极小 ⟹ 偏应力本身不引起变质作用。**
  - **课堂类比（极好用）：游泳池里挥拳**。深部能流动的岩石就像水；你在泳池一端出拳施加偏应力，**池子另一端的人感觉不到**——因为**水绕着你的拳头流走了，偏应力立刻被化解**。同理，**你无法靠偏应力把岩石「压」到高压状态**。
  - ⟹ **变质作用完全由上覆负载压力（+ 温度）引起，而不是由褶皱与断裂引起。**
- **但偏应力对结构 (texture) 有决定性影响**：
  - 已有矿物可被**压扁、拉长或旋转**；
  - **新矿物的形状与方位也被偏应力引导**。

#### 2.7 偏应力 → 变质结构（组构 fabric）

##### (i) 面状组构：劈理与片理 (Cleavage / Schistosity)

- 机制：**片状 (flaky/platy) 矿物**（黏土、云母）**旋转并再生长到彼此平行**，形成**垂直于 σ₁（最大主应力）方向的面理**。
  - 直观理解：与压实时颗粒长轴转向垂直于缩短方向是同一个道理，只是叠加了新矿物的定向生长。
- **命名随粒度/变质级而变**：
  - **细粒、低级变质岩**：称为**劈理 (cleavage)**。
  - **中—粗粒、中高级变质岩**：称为**片理 (schistosity)**。
- **野外证据 1（板岩）**：**被褶皱的变质泥岩（板岩 slate），带有轴面劈理 (axial-planar cleavage)**。
  - 判读方法（课堂逐步讲解）：先认出**层理面 (bedding planes)**——原本水平沉积；层被**挤压屈曲成褶皱**；然后认出另一组**近垂直的面理**穿过褶皱——那就是**劈理**，它由被重定向的矿物构成，且**与褶皱轴面平行、与缩短方向垂直**。
- **野外证据 2（片岩）**：**变质泥岩（石榴石云母片岩 garnet mica schist），带有被褶皱的层理与轴面片理**。
  - 判读：暗色矿物具有**明显的优选方位**，长轴**平行于褶皱轴面、垂直于挤压方向**。
- **重要观察提示**：**面理在粗粒岩石中难以看出，在富含黏土的细粒低级变质岩中最容易看出**。

##### (ii) 线状组构：线理 (Lineation)

- 定义：**变质成因的线状组构 (linear fabric)**。
- **线理常记录拉伸应变 (stretching strains)**，对应应力状态 **σ₁ ≈ σ₂ >> σ₃**。
- **课堂类比：口香糖**——拉伸时形成很长的、几何上近似**圆柱状 (cylindrical)** 的形态。
- 前提：岩石需**足够韧性 (ductile)** 才能被拉伸而不断裂。
- **同样地：拉伸本身不引起变质，但当拉伸与变质同时发生时，就形成这些独特的组构。**

##### 组构的用途

> **通过拉长颗粒的方位，我们可以在应力早已消失很久之后，反推当时施加于岩石的应力方向。** 面理⊥σ₁；线理∥拉伸方向；糜棱岩中的不对称构造给出剪切指向（见 §2.8）。

#### 2.8 三大类变质作用

由 §2.6 得到的**关键简化**（幻灯片 Slide 22 的逻辑总结）：

> 变质作用由 **T 增加 + P 增加** 引起，结果是 **① 形成新矿物 ② 晶体增大 ③ 若有显著偏应力则晶体重定向与分异**。
> 又因为 **T 随深度的增加在不同地方差别很大**，而 **P 随深度基本线性增加（到处一样）**，
> ⟹ **实际上只剩一个自由变量：T。**
> ⟹ **因此我们可以根据一块变质岩的成分与结构，反推它形成于何处（多深、什么构造背景）。**

**变质相 (metamorphic facies) 的定义**：**在特定的压力—温度域内形成的一组矿物组合 (sets of mineral assemblages)**。
- 课堂强调：**「相」不是一种矿物，而是"一桶"共生在一起的矿物 (a bucket of minerals that occur together)**。识别变质相要看**矿物的组合**，看单个矿物通常不够。
- 「facies」这个词讲者解释为「就是指某一类岩石」。

按 T、P 的变化方式分为三类：

| 类型 | T | P | 是否有偏应力 | 是否画在 P-T（深度-温度）图上 |
|---|---|---|---|---|
| **区域变质 (Regional)** | ↑ | ↑ | **几乎总是有**（挤压） | 是 |
| **接触变质 (Contact)** | ↑ | **不变** | **无** | 是（沿低压水平方向） |
| **动力变质 (Dynamic)** | **不变** | ↑（应力） | 有（偏应力为主） | **否**（因为不涉及埋藏） |

---

##### 【A】区域变质作用 (Regional metamorphism)

- **最重要、最常见**的一类。也叫**埋藏变质 (burial metamorphism)**。
- **成因链**：**使地壳增厚 ⟹ 岩石被深埋 ⟹ P 上升，同时 T 沿该地地温梯度上升**。
- **构造背景**：通常通过**一个地壳板片俯冲到另一个之下**实现——**洋—陆碰撞**或**陆—陆碰撞**。
- **产物特征**：
  1. **随 T、P 增加出现一系列不同的矿物组合**（＝穿过不同的变质相）。
  2. **粒度随 T、P 增加而增大**。
  3. **几乎总是与收缩（偏应力）相伴**（因为要增厚地壳，必须有两个板块相向运动）⟹ **随 T、P 增加，发育从劈理到片理的面理**。
- **泥岩系列（幻灯片 Slide 26 的经典序列）**：

  **泥岩 (mudstone，原岩) → 板岩 (slate) → （绿）片岩 ((green)schist) → 片麻岩 (gneiss)**

  课堂逐级描述：
  - **板岩 / 千枚岩 (slate / phyllite)**：仍能看到**在海底沉积时形成的清晰层理**，但**已发育劈理**（片状矿物垂直于偏应力方向重排）；**粒度仍然很细**。
  - **片岩 (schist)**：继续变质，**生成一整套全新的矿物**；粒度变粗；**片理发育**。
  - **片麻岩 (gneiss)**：压力/温度进一步升高，**又一套新矿物**，**晶体更粗**，出现**长英质与暗色矿物的条带状分异 (segregation)**。
- **再往上**：若岩石**含水**，温度继续升高会到达**（湿）固相线**，**开始熔融——那就不再是变质作用**（进入混合岩 migmatite / 花岗岩浆的领域）。若**岩石无水**，则可以在图上继续往右、往更高温走而不熔融。

##### 【B】接触变质作用 (Contact metamorphism)

- **成因**：**与侵入体接触的岩石遭遇高 T，但没有高 P**。
- **构造背景**：**与火成岩产生的地方相同**（Week 3）——**大陆与洋壳的拉张环境、地幔热点之上、含水俯冲板片之上**。
- **特征**：
  1. **随 T 增加出现一系列不同矿物组合**（但**与 P 无关**——课堂原话：「这纯粹是一个烹饪实验 (a purely cooking experiment)」）。
  2. **粒度随 T 增加而增大**。
  3. **不伴随增加的应力 ⟹ 不发育面理 (no foliation)**。
     - 讲者顺带解释词源：**foliation** 源自拉丁语 **folio**，意思像「书页」。
- **产物：角岩 (Hornfels)**
  - **无面理的 (non-foliated)、「粒状变晶的」(granoblastic) 岩石**，**晶体尺寸显著增大**。
  - 常出现**重结晶集合体形成的「斑点」**——即**变斑晶 (porphyroblasts)**：细粒基质中的个别大晶体。幻灯片称之为「spotted rock（斑点岩）」。
  - **变质晕 (aureole / contact aureole / metamorphic aureole)**：侵入体周围发生变质的区域。
  - **野外判别线索**：**附近应该有侵入的火成岩** ;-) —— 讲者半开玩笑但很实用：如果分不清是接触变质还是区域变质，去找旁边有没有火成岩体。

##### 【C】动力变质作用 (Dynamic metamorphism)

- **成因**：**施加了（应力）压力，但几乎没有温度增加**。
- 这个应力**通常是偏应力，且不涉及埋藏**——**所以不画在温度/深度剖面图上**。
- **发生场所**：**沿断层，在应力集中的那个紧邻带内**。
- **产物特征：粒度减小（reduction）** —— **这是「变质使粒度增大」这一法则的唯一例外**（课堂明确点出）。
  - **脆性粒度减小 (brittle grain size reduction)**：**破裂，无重结晶** ⟹ **碎裂岩类 (cataclastic rocks)**，如**断层角砾岩 (fault breccia)**。
    - 讲者强调：**严格说这不算真正的变质岩**（只是被机械粉碎）。
  - **韧性粒度减小 (ductile grain size reduction)**：**动态重结晶 (dynamic recrystallisation)** ⟹ **糜棱岩 (mylonites)**。
- **糜棱岩的识别**：
  - 发育**明显的面理**，**平行于剪切方位**。
  - 含**未被完全破碎的超大晶体团块——残斑 (porphyroclasts)**（注意与接触变质的**变斑晶 porphyroblasts** 区分：**blast = 新生长的；clast = 残余的碎块**）。
  - 残斑常呈**透镜状/菱形（"fish"，如云母鱼 mica fish）**，其**「尾翼」的不对称几何给出剪切指向 (sense of shear)**。
  - **判读方法**：看残斑拉长的方向与两侧尾翼的偏转方向——尾翼从底部伸出并向顶部偏转的方向，指示上盘的运动方向。幻灯片专门设问：「这张照片里的剪切指向是顶部向左还是顶部向右？」课堂上是**顶部向左 (top to the left)**（讲者最后确认举手选「top to the left」的同学是对的）。
  - **野外线索**：**这块岩石通常明显处在断层或断层带里** ;-)
- **冲击变质 (Shock metamorphism)——陨石撞击**
  - 「有趣但罕见」。**极高压力（数十 GPa！）但温度增加相对温和**，生成**自然界通常不会出现的矿物**。
  - **K-T（白垩系—第三系）界线撞击事件（约 65 Ma；现代精确值为 66 Ma）的关键证据**：
    1. **撞击点附近广泛形成柯石英 (coesite)**。
       - ⚠️ **幻灯片与课堂都称柯石英为「石英的高温 (high-T) 同质多象」——这是错误的**。柯石英实际上是**石英的高压 (high-pressure) 同质多象**（约 > 2–3 GPa 才稳定），正因为它需要极高压力而非高温，才成为撞击（或超高压俯冲）的诊断性证据。复习时请按**高压多象**理解，这与「撞击＝极高 P、温和 T」的整体逻辑也自洽。
    2. **距撞击点数千公里外广泛分布的击变石英 (shocked quartz)**——**正常晶格被扰乱**（发育面状变形页理）。
  - **铱异常 (iridium anomaly) 的完整因果链（课堂详述，是很好的跨学期串联）**：
    - 1980 年代中期以前，恐龙大灭绝的原因不明。地球化学家在美国西部的 K-T 界线发现一层**富铱 (Ir) 的黏土层**。
    - **为什么反常**：**铱是亲铁元素 (siderophile element)**——回想上学期（How to Build a Planet）的行星分异：铱在分异过程中**进入了地核**，因此**地球表面极度亏损铱**。
    - **为什么界线上富铱**：**小行星是未分异的天体 (not differentiated bodies)**，因此**相对富铱**。撞击把富铱的尘埃抛入大气，随后沉降形成这一薄层。
    - 讲者展示了手持标本：下部沉积物（**白垩纪**，恐龙存在到此为止）—**粉红色富铱层**—上部沉积物（**古近纪/第三纪**）。
    - **随后不久又发现同一层富含柯石英**，把「化学异常」升级为「撞击的物理证据」。

#### 2.9 为什么矿物不退变质 (retrograde)？——本周的方法论支柱

**退变质反应通常不发生，有两个原因：**

1. **能量原因（活化能）**：
   - 进变质 (prograde) 时，你在**给岩石加能量**，其中一部分是**活化能 (activation energy)**，用来启动化学反应。
   - 退变质路径上，你在**冷却岩石 = 岩石在损失能量**，**因此不再提供反应所需的活化能**，反应无法逆向进行。
2. **物质原因（挥发分逃逸）**：
   - **许多进变质反应是脱挥发分反应 (devolatilisation reactions)**：
     - **脱水反应 (dehydration reactions)**：释放 **H₂O**；
     - **脱碳酸反应 (decarbonation reactions)**：释放 **CO₂**。
   - **教科书反应式**：

     $$\mathrm{calcite} + \mathrm{quartz} \;\rightarrow\; \mathrm{wollastonite} + \mathrm{CO_2}$$
     $$(\mathrm{CaCO_3} + \mathrm{SiO_2} \rightarrow \mathrm{CaSiO_3} + \mathrm{CO_2})$$

   - 一旦挥发分**离开岩石**（沿裂隙上升到地表），**它们就不再可用于逆反应**：

     $$\mathrm{wollastonite} + \mathrm{CO_2} \;\rightarrow\; \mathrm{calcite} + \mathrm{quartz} \quad(\text{无法发生，因为 CO}_2\text{ 已经跑了})$$

**结论（考试高频）**：**正因为不退变质，我们才能拿地表的变质岩去重建地壳深处发生的过程。** 这句话在幻灯片和课堂上各出现了三次以上。

### 3.5 【核心图 1】P-T 图（温度—深度/压力图）的判读方法

这是本周最需要「用文字讲清」的图（课堂称之为「a busy diagram」，讲者花了很长时间口头拆解）。

**第一步：认清坐标轴**
- **纵轴 = 深度 (depth)，向下为深**（等价于**压力 P**，因为 P ≈ ρgh 基本线性于深度；因此有些版本的图纵轴直接标 P，两者可以互换阅读，右侧常标 kbar/GPa，左侧标 km）。
- **横轴 = 温度 (temperature)，向右为热**。
- **⚠️ 注意纵轴方向**：地质学惯例是**深度向下增大**，所以图的**左上角 = 浅而冷（近地表）**，**右下角 = 深而热**。

**第二步：认清图上的「彩色块」= 变质相场**
- 图上一块块不同颜色的区域，是**在特定 P-T 域中形成的矿物组合（＝变质相）**。
- 左上（低 P 低 T）：沸石相；
- 中部沿正常梯度：**绿片岩相 → 角闪岩相 → 麻粒岩相**；
- **左下方（高 P 低 T，即"图的左下角"）：蓝片岩相 → 榴辉岩相**；
- **上部靠右（高 T 低 P）：角岩相**（接触变质区域）。
- 图右侧还有一条重要曲线：**（含水）固相线 / 熔融曲线**——**越过它就开始熔融，不再属于变质作用**。

**第三步：认清「地温梯度线」= 从原点出发的射线**
- 每一种构造背景对应一条**从原点（地表、常温）出发的直线（近似）**，斜率 = 该地的地温梯度。
- **课堂讲到的三条线**：
  1. **绿色线（正常地温梯度，25–30 °C/km）**：随深度增加，依次穿过 **黏土 → 绿片岩相 → 角闪岩相**；若岩石含水，最终**到达熔融线开始熔融**；若岩石无水，则可以「跑出图的右边缘」继续升温而不熔。
  2. **火山地体（陡梯度）**：**埋得更浅，温度上升更快**——路径更"平躺"，掠过相似的相域但**典型地进入麻粒岩相**。
  3. **俯冲带（缓梯度，3–5 °C/km）**：**必须埋得非常深，温度才升一点点**——路径更"竖直"，进入**蓝片岩相 → 榴辉岩相**这一套**完全不同的矿物组合**。
- **一句话记法**：**梯度线越"陡立"（向下），越走向高 P 低 T（蓝片岩/榴辉岩）；梯度线越"平躺"（向右），越走向高 T 低 P（角岩/麻粒岩）。**

**第四步：把三类变质作用摆到图上**
- **区域变质**：沿一条地温梯度线**向右下方**移动（T↑ 且 P↑）。
- **接触变质**：在图的**上部近似水平地向右**移动（T↑ 而 P 不变，因为在浅处）。
- **动力变质**：**不画在这张图上**——因为它不涉及埋藏（不是负载压力，而是偏应力），课堂两次强调这一点。

**第五步：反向使用（考试真正要你做的事）**
> 给你一个矿物组合 → 找到它对应的相场 → 相场的位置给出 **P（⟹ 深度）与 T** → 再看这个 P-T 组合落在哪条地温梯度线上 → **反推构造背景**。
>
> 例：蓝闪石组合 ⟹ 蓝片岩相 ⟹ 高 P 低 T ⟹ 只有 3–5 °C/km 的梯度能到那儿 ⟹ **俯冲带**。
> 例：角闪石+斜长石 ⟹ 角闪岩相 ⟹ T ≈ 600 °C，中等 P ⟹ 正常或偏火山地温梯度 ⟹ **碰撞造山带中—高级部位**。

### 3.6 【核心图 2】P-T-t 路径（压力—温度—时间路径）的判读方法

这是本周概念上最精妙的一段（幻灯片 Slide 28–30，课堂用「被子/毯子」的类比讲解）。

**前提：岩石是极差的热导体 (rocks are really poor conductors of heat)**
- **课堂类比**：**岩石像被子和毯子**——「你起床两小时后回到床上，被窝还是热的（保温好）；但冬天刚钻进被窝时又是冰的（升温慢）」。
- ⟹ **岩石储热好、升温慢**。

**推论 1：埋藏时 P 比 T 上升得快**
- 岩石被埋下去时，**压力是"瞬时"响应的**（上覆负载一加上去，P 立刻到位）；
- 但**温度跟不上**——热传导需要时间，岩石**来不及与所处深度的环境温度达到平衡**。
- ⟹ **实际路径落在"理想地温梯度线"（图上的红线）的左侧（偏冷一侧）**：岩石「记录了压力的增加，但没有足够快地变热」。

**推论 2：埋藏停止后，岩石继续升温**
- 当**埋藏停止（达到峰期埋深）**时，这块相对偏冷的岩石**仍在被周围的热岩石加热**，**继续升温**——这一过程叫**热弛豫 (thermal relaxation)**。
- 在 P-T 图上，路径此时**近似水平向右移动**（P 不变或略降，T 继续升）。
- 然后随着**抬升剥露 (exhumation)**，路径**向左上方回落**（P 降、T 降）。
- **结果是一条"弧形"的 P-T 曲线 (an arcing P-T profile)**——即经典的**顺时针 P-T-t 路径 (clockwise path)**（在 P 向上、T 向右的常规画法下）。

**推论 3（本节最重要的结论，考点）**
> **矿物组合反映的是所达到的最高温度 (peak T)，而不是最高压力 (peak P)。**
>
> **峰期变质级 = 峰期温度**，而**峰期温度往往在埋藏结束之后一段时间才出现**。
>
> 课堂原话：「基本上，岩石记录的是埋藏过程中的最高温度，不是最大埋深……如果你看不懂那张图，就忘掉图，记住这句话。」

**如何判读一条 P-T-t 路径**
1. **确认坐标与方向**：P（或深度）纵轴、T 横轴；注意深度是否向下增大（会影响"顺时针/逆时针"的视觉方向，判断时以**物理过程**为准，不要死记方向词）。
2. **找起点**：通常在原点附近（地表、常温）。
3. **看上升段（进变质）**：路径**陡于**该地的地温梯度线 ⟹ 说明 P 增加快于 T ⟹ **快速埋藏**（俯冲、逆冲叠置）。
4. **找拐点**：路径最深处 = **峰期压力 P_max**（最大埋深）。
5. **看拐点之后**：若路径继续向右（T 仍在升）⟹ **热弛豫**；这一段的最右端 = **峰期温度 T_max = 岩石实际记录下来的变质级**。
6. **看下降段（退变质/剥露）**：向左上回落。**因为不发生退变质（§2.9），这一段通常不被矿物组合记录**——所以我们看到的是 T_max 的"化石"。
7. **形态与构造背景的对应**：
   - **顺时针路径（先增压、后升温、再降压降温）** ⟹ **碰撞造山 / 地壳增厚 / 区域变质**（本周的主线情景）。
   - **逆时针路径（先升温、后增压）** ⟹ **岩浆加热主导**的背景（接触变质、岩浆弧、地幔柱下的地壳）。
   - **"发夹式"极陡路径** ⟹ **俯冲带**（快速下插、快速折返，全程低温）。

### 3.7 【小图】接触变质晕的温度衰减图（Week 3 复用）

- 横轴：距接触面的距离（常以岩体厚度归一化）；纵轴：温度相对于初始岩浆温度的比值；不同曲线代表不同的冷却时间。
- **读法**：对一个厚 250 m 的岩体，在 250 m 外、1000 年后，**T/T_magma < 0.2** ⟹ 若岩浆为 1000 °C，则该处最高只到约 200 °C ⟹ **通常不足以引起变质**。
- **实用结论**：**变质晕的宽度大致不超过侵入体自身的厚度**（每侧约一个厚度）。看到一条 3 m 厚的岩墙，别指望它烤出几十米宽的角岩带。

### 4.2 课堂强调但幻灯片文本上不显眼的要点

1. **「熔融就不是变质了」**：讲者反复划这条线——一旦熔融，立刻回到火成作用的框架。
2. **薄片颜色不同 ≠ 矿物不同**：砂岩/石英岩对比薄片颜色差异**只是磨片厚度不同**造成的干涉色差异，别误判为不同矿物。这是薄片实践的典型陷阱。
3. **「变质相不是一种矿物，是一桶矿物」**：讲者纠正学生可能的误解——「amphibolite 不是一种矿物，是共生在一起的一组矿物的名字」。识别时**必须找组合**。
4. **砂岩是"无用的原岩"**：因为几乎全是石英，而石英在所有变质级都稳定。**泥岩和玄武岩（及辉绿岩、辉长岩等基性岩）才是好的记录器**，因为它们矿物成分复杂、元素种类多，能随条件不断重组。
5. **「变质使粒度增大」的唯一例外是断层带**：讲者在讲动力变质时特意回头点名这一点。
6. **碎裂岩「严格说不算变质岩」**：因为它只是机械粉碎，**没有重结晶**。糜棱岩才算（韧性的动态重结晶）。
7. **两个判别小窍门（讲者半开玩笑但很实用）**：
   - 分不清接触变质还是区域变质？**看看旁边有没有火成岩体。**
   - 分不清是不是糜棱岩？**看看你是不是站在一条断层上。**
8. **「封闭系统」的自我修正**：讲者一开始要求把变质当作严格封闭系统，最后又主动回来说明「其实多数时候不完全封闭——水会被挤出去」，并把这一点**用作解释不退变质的第二个原因**。这个前后呼应是本周论证的关键闭环。
9. **区域变质几乎必伴偏应力**：因为要增厚地壳就必须有两个板块相向运动 ⟹ **区域变质岩几乎总带劈理或片理**；反之，**接触变质岩几乎总不带面理**。这是野外/手标本上最快的二分判据。
10. **糜棱岩剪切指向的课堂互动**：讲者展示照片让全班举手，答案是 **top to the left（顶部向左）**——判断依据是残斑（"fish"）的**尾翼几何**：尾翼从底部伸出、向顶部一侧偏转，指示上盘的运动方向。

### 4.3 转写中的口误与不准确之处（复习时请以正确说法为准）

## 五、Practical 要点

**（本周无独立 practical。）**

材料中没有 practical 手册或题目。但以下与实践直接相关，值得在标本/薄片练习中留意：

1. **薄片对比训练（幻灯片给了成对图像）**：
   - **砂岩 vs 石英岩**：找**浑圆颗粒 + 孔隙 + 胶结物**（沉积）对**咬合的粒状变晶结构、无孔隙**（变质）。
   - **页岩 vs 片岩**：找**新生矿物（鲜艳干涉色的云母、黑色石榴石、灰白十字石）+ 粒度增大 + 定向性**。
   - **W10 PT1 的 XPL 薄片**：**破裂颗粒**（压实）与**压溶面**（垂直压缩方向的接触面平直/内凹，平行方向外凸并带胶结物）。
2. **手标本判别流程（本周可直接总结出的实用流程）**：
   - Step 1：**有没有面理？** 有 ⟹ 区域变质（或糜棱岩）；无 ⟹ 接触变质（角岩、石英岩、大理岩）或块状高级岩。
   - Step 2：**粒度多大？** 细（板岩/千枚岩）→ 中粗（片岩）→ 粗且分带（片麻岩）。
   - Step 3：**有什么指示矿物？** 绿泥石（低）/ 石榴石、十字石（中）/ 夕线石、辉石（高）/ 蓝闪石（高 P 低 T）。
   - Step 4：**颜色线索**：绿（绿片岩）/ 黑白相间（角闪岩）/ 蓝（蓝片岩）/ 红绿（榴辉岩）。
   - Step 5：**周边地质关系**：旁边有侵入体？在断层带里？
3. **剪切指向判读**：糜棱岩中残斑（云母鱼）的**不对称尾翼**——练习用照片判断 top-to-the-left / top-to-the-right。
4. **提醒**：**薄片的颜色差异可能只是磨片厚度不同**，判读时先看**形态与关系**，再看颜色。

## 六、易错点 / 重点难点

1. **⭐ 偏应力不引起变质作用，只影响结构。** 这是本周最容易答反的概念。
   - **变质由「负载压力 + 温度」引起**；偏应力在热的深部**被塑性流动瞬时化解**（游泳池出拳类比），因此**对矿物稳定性影响极小**。
   - 但偏应力**决定了组构**：劈理、片理、线理、糜棱面理。
2. **⭐ 矿物组合记录的是峰期温度 (T_max)，不是峰期压力 (P_max)。** 因为岩石导热差，**峰期温度往往滞后于峰期埋深出现**。
3. **⭐ 构造背景控制温度，但基本不控制压力。** 压力 ≈ ρgh，而 ρ、g 到处差不多 ⟹ **P 只是深度的函数**；而地温梯度在 3–5 至 >100 °C/km 之间变化上百倍。这正是「只剩一个自由变量 T」这一简化的来源。
4. **变质 ≠ 熔融。** 严格固态。越过（含水）固相线就进入火成领域（混合岩）。
5. **变质 vs 成岩的四条判据**（驱动因素 / 开闭系统 / 沉积结构是否可辨 / 是否只靠埋藏）。注意**两者是渐变过渡的，没有尖锐界线**。
6. **粒度增大是通例，断层带（动力变质）是唯一例外**（粒度减小）。
7. **碎裂岩 vs 糜棱岩**：脆性、无重结晶、"严格说不算变质岩" vs 韧性、动态重结晶、真正的变质岩。
8. **变斑晶 (porphyroblast) vs 残斑 (porphyroclast)**："blast"＝新生长（角岩、片岩中的石榴石），"clast"＝残余碎块（糜棱岩中）。
9. **不是所有矿物都能指示变质级**：石英、长石、白云母**在所有级别都稳定 ⟹ 无用**。要用**绿泥石、黑云母、十字石、石榴石、夕线石**等**指示矿物的组合**。
10. **原岩选择很重要**：**泥岩与玄武岩是好记录器**，**砂岩与碳酸盐岩是差记录器**（只发生结构变化）。这条常被作为"为什么课程只讲这两种原岩"的问答题。
11. **接触变质晕的尺度**：**大致不超过侵入体的厚度**。别以为一条小岩墙能烤出大范围变质带。
12. **不退变质的两个原因要都答出来**：① **冷却 ⟹ 失去活化能**；② **脱挥发分反应把 H₂O/CO₂ 排走 ⟹ 逆反应缺原料**。并要接上结论：**因此变质岩才能记录深部过程**。
13. **柯石英是高压多象，不是高温多象**（课件与课堂的口误，见 §4.3）。
14. **蓝片岩 = 俯冲带的唯一指纹**：因为只有俯冲带能同时提供高 P 与低 T。
15. **P-T 图的纵轴方向**：深度向下增大 vs 压力向上增大，两种画法都存在——**判断路径时以物理过程（先埋后热、还是先热后埋）为准，不要死记"顺时针"三个字**。
16. **区域变质 ≈ 有面理；接触变质 ≈ 无面理。** 因为前者必然伴随板块相向运动（偏应力），后者不必。
17. **成岩子过程中"压实"包含三个层次**（颗粒重组/旋转 → 颗粒破裂 → 压溶），别把压溶漏在压实之外。
18. **压实减小的是孔隙度，不是岩石体积**（这句幻灯片原文很容易记反：原文是 "rock volume is not reduced, but pore-space is reduced"，意即通过挤走孔隙水实现体积缩减，颗粒骨架本身未被压缩）。
19. **白云石化增加孔隙度（−11% 矿物体积）**——是少数"利好储层"的成岩过程，常作为应用题的落点。

| Granoblastic texture | 粒状变晶结构 | 等粒、紧密咬合、无定向的变晶结构（石英岩、角岩）。 |
| Geothermal gradient | 地温梯度 | 温度随深度增加的速率；平均 25–30 °C/km，随构造背景剧烈变化。 |
| Stress | 应力 | 单位面积上的平均力，S = F/A，单位 Pa。 |
| Load pressure / Lithostatic / Confining stress | 负载压力 / 静岩应力 / 围压 | 上覆岩石重量造成、各向均匀作用的压力，P = ρgh。 |
| Deviatoric (differential/triaxial) stress | 偏应力（差应力/三轴应力） | 各向不均匀的应力；不引起变质，但控制变质结构。 |
| σ₁ | 最大主应力 | 最大压缩方向；劈理/片理垂直于 σ₁ 发育。 |
| Ductile deformation | 韧性变形 | 热而软弱的岩石以塑性流动（褶皱）方式变形。 |
| Brittle deformation | 脆性变形 | 冷而硬的浅部岩石以破裂（断层）方式变形。 |
| Foliation | 面理 | 变质岩中的面状组构总称（源自拉丁语 folio，"书页"）。 |
| Cleavage | 劈理 | 细粒、低级变质岩中的面理。 |
| Schistosity | 片理 | 中—粗粒、中高级变质岩中的面理。 |
| Axial-planar cleavage | 轴面劈理 | 与褶皱轴面平行、与缩短方向垂直的劈理。 |
| Lineation | 线理 | 变质成因的线状组构，常记录拉伸应变（σ₁≈σ₂>>σ₃）。 |
| Metamorphic grade | 变质级 | 变质作用的强度（主要由峰期温度决定）；级别升高通常粒度增大。 |
| Metamorphic facies | 变质相 | 在特定 P-T 域内形成的一组共生矿物组合；"一桶矿物"而非单一矿物。 |
| Index mineral | 指示矿物 | 稳定范围窄、能指示变质级的矿物（绿泥石、十字石、夕线石等）。 |
| Mineral assemblage | 矿物组合 | 共生在一起的一组矿物，是判定变质相的依据。 |
| Regional metamorphism | 区域变质作用 | T 与 P 同时升高的变质，由地壳增厚/深埋引起，几乎必伴偏应力。 |
| Burial metamorphism | 埋藏变质作用 | 区域变质的别称，强调埋藏是压力来源。 |
| Contact metamorphism | 接触变质作用 | T 升高而 P 不变，由火成侵入体的局部热引起，不发育面理。 |
| Dynamic metamorphism | 动力变质作用 | 应力（多为偏应力）作用而温度基本不变，见于断层带；粒度减小。 |
| Shock metamorphism | 冲击变质作用 | 陨石撞击造成的极高压（数十 GPa）、温和温度的变质。 |
| Aureole / Contact aureole | 变质晕 / 接触晕 | 侵入体周围发生接触变质的区域；宽度大致不超过岩体厚度。 |
| Porphyroblast | 变斑晶 | 变质中新生长于细粒基质中的大晶体（角岩的"斑点"、片岩中的石榴石）。 |
| Porphyroclast | 残斑 | 糜棱岩中未被破碎而残留的大晶体，其不对称尾翼指示剪切指向。 |
| Cataclasis / Cataclastic rock | 碎裂作用 / 碎裂岩 | 脆性粒度减小、无重结晶；产物如断层角砾岩，严格说不算变质岩。 |
| Fault breccia | 断层角砾岩 | 断层带内被机械粉碎的棱角状碎块集合体。 |
| Mylonite | 糜棱岩 | 韧性剪切带中经动态重结晶形成的细粒强面理岩石，含残斑。 |
| Dynamic recrystallisation | 动态重结晶 | 变形同时进行的重结晶，造成韧性粒度减小。 |
| Sense of shear | 剪切指向 | 剪切带两侧的相对运动方向，由残斑尾翼等不对称构造判定。 |
| Slate | 板岩 | 低级变质泥岩，极细粒，发育板劈理，仍可见层理。 |
| Phyllite | 千枚岩 | 略高于板岩，面上具丝绢光泽。 |
| Schist | 片岩 | 中级变质岩，肉眼可见定向云母，常含石榴石、十字石变斑晶。 |
| Greenschist | 绿片岩 | 由玄武岩变质而来的绿色片状岩石（绿泥石+绿帘石+阳起石）。 |
| Amphibolite | 角闪岩 | 角闪石+斜长石为主的中高级变质基性岩；峰温约 600 °C。 |
| Blueschist | 蓝片岩 | 含蓝闪石的高 P 低 T 变质岩；俯冲带的诊断性标志。 |
| Eclogite | 榴辉岩 | 绿辉石+石榴石、无斜长石的极高压变质基性岩。 |
| Granulite | 麻粒岩 | 极高温、基本无水矿物的变质岩，代表深部地壳。 |
| Gneiss | 片麻岩 | 高级变质岩，粗粒，具浅色/深色矿物分异的条带状构造。 |
| Migmatite | 混合岩 | 已开始部分熔融的高级变质岩，标志变质作用的上限。 |
| Hornfels | 角岩 | 接触变质产物，无面理、粒状变晶、常含变斑晶（"斑点岩"）。 |
| Quartzite | 石英岩 | 砂岩变质而成，紧密咬合的石英集合体；不是好的变质级指示物。 |
| Marble | 大理岩 | 灰岩/白云岩变质而成，方解石重结晶，以结构变化为主。 |
| Chlorite | 绿泥石 | 低级变质的指示矿物，高温下分解生成角闪石与十字石。 |
| Biotite | 黑云母 | 从低级到高级都稳定，需与其他矿物组合才能定级。 |
| Muscovite | 白云母 | 多数变质级下稳定，除极高压外不是好的指示矿物。 |
| Staurolite | 十字石 | 中级变质指示矿物（片岩中的白灰色晶体）。 |
| Garnet | 石榴子石 | 常见变斑晶，中级及以上；片岩中的黑/红色团块。 |
| Sillimanite | 夕线石 | 高级变质指示矿物（与黑云母共生指示高级）。 |
| Glaucophane | 蓝闪石 | 蓝色角闪石，蓝片岩相的特征矿物。 |
| Coesite | 柯石英 | 石英的**高压**同质多象；撞击与超高压变质的诊断矿物。 |
| Shocked quartz | 击变石英 | 晶格被冲击波扰乱的石英，可分布在距撞击点数千公里处。 |
| Iridium anomaly | 铱异常 | K-T 界线富铱层；铱是亲铁元素，地表亏损，小行星未分异故富铱。 |
| Siderophile element | 亲铁元素 | 分异时进入地核的元素（如铱）。 |
| Retrograde metamorphism | 退变质作用 | 抬升冷却时的逆向变质；通常不发生（缺活化能 + 缺挥发分）。 |
| Prograde reaction | 进变质反应 | 升温升压方向的变质反应，多为脱挥发分反应。 |
| Devolatilisation reaction | 脱挥发分反应 | 释放挥发分的反应，含脱水与脱碳酸两类。 |
| Dehydration reaction | 脱水反应 | 释放 H₂O 的进变质反应。 |
| Decarbonation reaction | 脱碳酸反应 | 释放 CO₂ 的进变质反应，如 calcite + quartz → wollastonite + CO₂。 |
| Wollastonite | 硅灰石 | 方解石+石英脱碳酸反应的产物，是经典的变质反应例。 |
| Activation energy | 活化能 | 启动化学反应所需的能量；冷却时不再供给，故不退变质。 |
| P-T path / P-T-t path | P-T 路径 / P-T-t 路径 | 岩石在压力—温度（—时间）空间中走过的轨迹，呈弧形。 |
| Thermal relaxation | 热弛豫 | 埋藏停止后岩石继续升温，使峰温滞后于峰压出现。 |
| Peak metamorphic grade | 峰期变质级 | 矿物组合所记录的最高变质强度，对应峰期**温度**。 |
| Compaction | 压实作用 | 上覆负载导致颗粒重组、破裂与压溶，减小孔隙度并排水。 |
| Dewatering | 脱水（排水） | 压实中孔隙水被排出；砂岩岩脉是其证据。 |
| Sandstone dyke | 砂岩岩脉 | 脱水时砂粒随水注入上覆沉积物形成的脉状体。 |
| Pressure solution | 压溶作用 | 垂直压缩方向的接触面溶解、平行方向再沉淀为胶结物。 |
| Dissolution | 溶解作用 | T、P 或孔隙水成分变化使矿物更稳定于溶液中而被溶掉。 |
| Meteoric water | 大气水（淡水） | 来自降水的地下水；泵入碳酸盐可溶解方解石与文石。 |
| Cementation | 胶结作用 | 化学沉淀的新晶体填充孔隙、黏结颗粒，降低原生孔隙度。 |
| Primary porosity | 原生孔隙度 | 沉积时即存在的孔隙度，被胶结作用降低。 |
| Mineral replacement | 矿物置换 | 新矿物原地取代先存矿物（文石→方解石；方解石→白云石）。 |
| Dolomitisation | 白云石化 | 方解石转变为白云石，矿物体积减少 11%，孔隙度相应增加。 |
| Source rock maturation | 烃源岩成熟 | 埋藏升温使有机质生成油气的过程。 |
| Oil window / Gas window | 油窗 / 气窗 | 生成石油/天然气的温度区间。 |
| Oil peak / Gas peak | 油峰 / 气峰 | 生油量/生气量最大时对应的温度。 |
| Overmature | 过成熟 | 温度过高、烃源岩不再生成油气的状态。 |
