## 一、本周主题

本周讲**地球生命史上最具行星尺度影响的一次生物创新——产氧光合作用 (oxygenic photosynthesis) 的起源，及其引发的连锁后果**：大氧化事件 (Great Oxidation Event)、条带状铁建造 (banded iron formations)、休伦冰期 (Huronian Ice Age)、地球第一次大灭绝、臭氧层的形成，以及有氧呼吸带来的能量革命。下半场紧接着讲**真核细胞 (eukaryote) 的起源**：吞噬作用 (phagocytosis)、内共生学说 (endosymbiosis)、细胞器的细菌出身、LECA 的分化，以及有丝分裂 (mitosis) 与减数分裂 (meiosis) / 有性生殖的出现。

**在 11 周中的位置**：Week 1 讲生命起源与能量（LUCA、化学合成、光合作用的初现），本周（Week 4）接着讲"光合作用如何升级为产氧型、并把整个行星改造了一遍"，以及"复杂细胞怎么来的"。这一讲是**从『分子层面的生命』过渡到『可见的、复杂的、多细胞的生命』的枢纽**——没有氧气就没有大细胞，没有内共生就没有真核细胞，没有真核细胞就没有后面 7 周要讲的植物、森林、恐龙和人类。下一讲（Rob Sansom）主题是"生命变大变复杂"/生命从海洋登上陆地。

**一句话因果主线**：
> 蓝细菌把两个反应中心串联 → 有足够能量氧化水 → 释放 O₂ → 先氧化海水中的还原态金属（BIF）→ 金属耗尽后 O₂ 进入大气 → 氧化甲烷（强温室气体）→ 全球降温 → 休伦冰期 → 冰期 + 氧毒性 = 第一次大灭绝 → 幸存者演化出抗氧化能力 → 有氧呼吸（能量效率 18 倍）→ 细胞变大 → 大细胞能吞小细胞 → 吞而不消化 → 内共生 → 真核细胞。

## 二、核心概念

### （一）回顾：能量从哪来（Week 1 的接续）

- 地球刚形成时是"一团沸腾的能量"，处于强烈的**化学不平衡 (chemical disequilibrium)** 状态——大量物质"想要"互相反应。最早的生命本质上就是化学：直接攫取环境中现成的化学能。
- 随着地球冷却、系统趋于平衡，可用的化学能越来越少，只在局部残留（火山温泉、热泉、深海热液喷口 deep-sea vents）。生命要**走出这些小生境 (niches)**，就必须演化出别的取能方式。
- 结果就是**光合作用 (photosynthesis)**——今天地球上绝大部分生命的能量来源。
- **两大原核超界 (super kingdoms)**：**古菌 (Archaea)** 与 **细菌 (Bacteria)**，都由 **LUCA (Last Universal Common Ancestor)** 分化而来。
  - **Archaea 的取光方式**：用**细菌视紫红质 (bacteriorhodopsin)**——一种膜结合蛋白 + 色素。它与我们眼睛里的**视紫红质 (rhodopsin)** 在**化学上相关（同为视黄醛 retinal 类色素）但在演化上不同源**。⚠️ 老师特别提醒这个"命名陷阱"：名字虽然叫 "bacterio-"，它却是古菌的系统；因为发现顺序造成的历史命名。
  - **Bacteria 的取光方式**：**叶绿素 (chlorophyll)**。叶绿素吸光后可以把一个电子交给另一个分子，**产生电流**，电流做功、最终生成 **ATP**。

### （二）光合反应中心 (Reaction Centre)

**结构**（老师的卡通图）：
- 核心是**两条相互缠绕的蛋白**（老师戏称为 "copulating caterpillar model"，交尾毛虫模型），呈**二聚体核心 (dimeric core)**。
- 缠绕的中央夹着**一对特殊的叶绿素 ("special pair" of chlorophylls)**。细菌里叫细菌叶绿素 (bacteriochlorophyll)，与植物叶绿素在化学结构上只有微小差异。
- **工作原理**：special pair 吸光 → 把电子交给膜另一侧的电子受体 → 形成**电荷分离 (charge separation)** → 膜两侧一正一负 → **相当于一块电池** → 驱动**电子传递链 (electron transport chain)**。
- **关键限制**：special pair 丢掉电子后必须被"补充"（*Electrons need "replacing"*）——电子从哪来，决定了这种光合作用的类型和能力上限。

**Type I vs Type II——两类反应中心**：

| | Type I | Type II |
|---|---|---|
| 突出结构位置 | 电子受体挂在膜的**内侧**（细胞质一侧） | 有结构突出在膜的**外侧** |
| 电子流向（老师的说法） | **把电子送进细胞内**（还原胞内载体） | **从外部取电子**（如 H₂S） |
| 典型辅因子 | **铁硫蛋白 (Fe-S iron-sulphur proteins)** | **细胞色素 (cytochromes, 含 Fe)** |
| 代表类群 | 绿硫细菌 (green sulphur bacteria)、太阳杆菌 (heliobacteria) | 紫硫细菌 (purple sulphur bacteria)、绿非硫细菌 (green non-sulphur bacteria) |

- ⚠️ **"Type I / Type II" 的编号毫无生物学含义**，纯粹是**发现/描述的先后顺序**造成的（课后 Q&A 老师明确澄清）。两者其实**既是受体也是供体**，只是拓扑与电子流向不同。
- 老师说：**不要求掌握这些反应中心的详细化学**，只要抓住"两类结构不同、电子进出方向不同、分属两个独立谱系"这一点。整门课**只要求会一个反应式**（即下文的水裂解式）。

**演化逻辑（重点）**：
1. 最早的光合细菌只有**一种原始反应中心**，核心的两条蛋白**完全相同（同源二聚体 homodimer）**。
2. 后来发生**基因复制 + 分化**，两条蛋白变得不同（异源二聚体 heterodimer）。
3. 关键证据：**Type I 内部的两条蛋白彼此更像，Type II 内部的两条蛋白彼此更像，而跨类型之间不像**——说明"同源二聚体 → 异源二聚体"的分化**独立发生了两次**，分别发生在两个不同的细菌谱系里。
4. 因此约 **3.5 Ga（35 亿年前）**，海洋里已有两群互不相干的光合细菌，各自用不同的电子供体、在不同环境里做**不产氧光合作用 (anoxygenic photosynthesis)**。它们的后代**今天仍然活着**（老师说光合作用方式的多样性"足够单开一门课"）。

### （三）蓝细菌 (Cyanobacteria) 与横向基因转移

- **蓝细菌 (cyanobacteria)**，俗称"蓝绿藻 (blue-green algae)"——名字是历史误称，它们是细菌不是藻类。
- **异常之处：它们同时拥有 Type I 和 Type II 两种反应中心。** 但这两类反应中心是在**两个不同谱系**里各自演化的，怎么会跑到同一个细胞里？
- **答案：横向基因转移 (lateral gene transfer, LGT / horizontal gene transfer)。**

**LGT 的机制与"为什么可能"**：
- 细菌"对 DNA 完全不挑"，到处乱扔 DNA（"they chuck DNA around like there's no tomorrow"）：
  - 细胞破裂 → DNA 释放到环境 → 被别的细胞吞入（**转化 transformation**）；
  - **噬菌体 (bacteriophage)** 像"小飞船"降落在细菌表面，把 DNA/RNA 注射进去（**转导 transduction**）；
  - 主动的转移机制（**接合 conjugation**）。
- **关键便利条件**：细菌基因**成串排列（操纵子 operon / 基因簇）**，一个反应中心的 6–12 个基因**挤在基因组的同一个位置**。因此不需要"多次巧合地搬运零散片段"，**一整块 DNA 一次搬走即可**。
- 这是**极低概率事件，但只需要发生一次**。
- **现代类比（老师强调）**：**抗生素抗性 (antibiotic resistance)**。抗性只在少数细菌里演化出来，但负责该性状的基因已被证明能在细菌间转移——所以抗性会在完全不同的菌种间扩散。"现在你的胃里就在发生这种事。"

### （四）两个光系统串联 → 氧释放复合体 (Oxygen Evolving Complex)

**"两节电池串联"类比（本讲最重要的直觉模型）**：
- 一个反应中心 = 一节电池，产生一个跨膜电位差。
- **Type II 反应中心**（细菌型）产生约 **1 V**；**Type I 反应中心**产生约 **0.7–0.8 V**。
- 单独一节电池带不动需要 3 V 的设备；把两节 1.5 V 电池**串联 (in series)** 就能带动。
- 同理：Type I + Type II 串联 → 约 **1.8 V** → 能量大幅提升 → **可以做以前做不到的化学**。

**但这不是一夜之间**：
- LGT 把两套反应中心送进同一个细胞后，起初它们只是**各干各的、并不协作**。
- 之后要**逐步演化出中间的电子载体 (electron carriers)** 把两者串起来，形成一条完整的、跨越更大电位差的传递链。
- 老师估计这个过程花了**几亿年 (a few hundred million years)**。

**最终成果：氧释放复合体 (Oxygen Evolving Complex, OEC)，能氧化水。**
- 之前的光合作用依赖**容易氧化**的电子供体：金属离子、H₂S 等。
- **H₂S 与 H₂O 化学上很像**（硫与氧同族），但 **H₂S 极易氧化，H₂O 极难氧化**——水是非常稳定的分子，"它不想被氧化"，需要大量能量。单个反应中心的电位不够。
- 有了两个光系统串联，才**够劲把水拆开**。
- **氧化 (oxidation) = 失去电子**（老师现场提问确认；也可理解为"加氧"，但本质是失电子）。水失去电子的同时也失去 H⁺，剩下原子氧；原子氧不稳定，两两结合成 O₂。

**这是生命做过的最改变行星的一件事**——把地球从**还原态行星 (reduced planet)** 变成**氧化态行星 (oxidized planet)**，彻底改写了大气的化学性质。

### （五）化石与地质证据

**1. 叠层石 (Stromatolites)**
- 由**微生物席 (microbial mats)**——主要是蓝细菌——层层生长、捕获并沉淀矿物、逐层堆叠固结而成的层状岩石构造。
- 是**地球上最早的生命化石证据之一**，也是**蓝细菌出现的最早化石证据**。
- 由此推断：约 **3 Ga（30 亿年前）** 蓝细菌已经出现，氧气开始进入大气。
- 老师坦承"叠层石具体怎么形成要问你们的地质学老师"（他是植物生理学家不是地质学家）。

**2. 条带状铁建造 (Banded Iron Formations, BIF)** — 铁氧化物条带
- 当时海洋中溶有**大量还原态金属**，尤其是**铁 (Fe)** 和**锰 (Mn)**，以 **Fe²⁺（亚铁 ferrous）** 和 **Mn²⁺** 形式存在。
- **关键溶解度差异（老师强调"课程后面还会回来"）**：
  - **Fe²⁺ 高度可溶于水**（Mn²⁺ 同理）→ 所以早期海洋里"漂着"大量溶解铁；
  - **Fe³⁺（高铁 ferric）基本不溶**。
- O₂ 一被释放，立刻和 Fe²⁺ 反应：Fe²⁺ 失电子变 Fe³⁺ → 生成**氧化铁（铁锈）**→ **不溶 → 沉降到海底 → 形成红色/橙色的沉积层**。
- 因此我们今天在沉积岩中看到**明显的红色条带互层**——这就是"氧气曾经被生产出来"的直接地质记录。
- **产地案例**：南非 **Sishen 铁矿**（转写作 "Cishan"）。课堂播放了 BBC《How to Grow a Planet》纪录片片段（Iain Stewart 主持）：一次爆破炸开 20 万吨铁矿石，露出一段"时间的横截面"；主持人把铁氧化物磨成粉、配成溶液、通电电解，让**被封存了 25 亿年的氧气**重新变成气泡冒出来，并把它吸进肺里。老师评价：*"partly silly, but…"*——重点是这些氧确实来自 25 亿年前生命的第一次呼吸。
- **实物提示**：Williamson Building 一楼的岩石标本室（找 Mandy Edwards）可以看到这类带条带的岩石标本。

### （六）大氧化事件 / 氧危机 (The Great Oxidation Event / Oxygen Crisis)

- 时间：约 **2.5 Ga（25 亿年前，即 2500 Ma）**。
- **不是瞬时事件**：从零氧到达到新的稳定水平，历时约 **500 Myr（5 亿年）**。之所以慢，是因为**所有的氧最初都被"化学吸收"了**（先氧化溶解的金属）。
- 最终大气 O₂ 达到约 **0.05 atm 分压**（远低于今天的 0.21 atm）。
- 老师强调："在地质与演化尺度上，这仍然是一次**相当突兀的剧变**"——他说"几乎是一夜之间，而我说的一夜是三四亿年"。
- 两条独立的重建曲线（两种不同方法）给出的历史氧含量演化基本一致。
- 地球历史后期还会有**其他的增氧事件**（课程后面会讲）。
- 🌟 **老师的核心观点**：**这是地球史上第一次污染事件 (the first ever major pollution disaster)。** 蓝细菌制造了一种**有毒分子**并把它排放到环境里，毒害了当时的一切——**和今天人类合成新分子、排放、毒害环境是完全一样的事。**

### （七）休伦冰期 (Huronian Ice Age) — 生物驱动的第一次雪球地球

- 世界上**第一次冰期**，也是第一次 **"雪球地球" (Snowball Earth) 事件**——整个行星几乎同时进入冰期。
- **成因链条**：
  1. O₂ 先被海水中的还原态 Fe、Mn 吃掉（不进大气）；
  2. 一旦**易反应的金属被消耗殆尽**，O₂ 开始逸入大气；
  3. 当时大气**由甲烷 (CH₄) 主导**——甲烷是**还原态碳**；
  4. **CH₄ + 2O₂ → CO₂ + 2H₂O**；
  5. **甲烷是比 CO₂ 强得多的温室气体**，把强温室气体换成弱温室气体 → **全球降温**；
  6. 叠加**当时太阳比今天弱**（faint young Sun）+ 大陆位置阻碍了大气和洋流的自由环流 → 触发全球性冰期。
- ⚠️ 老师明确标注："**OK, continents may also have played a role**"——大陆漂移、大陆位置、洋流格局也重要，但**主驱动是蓝细菌造成的大气变化**。
- **甲烷在大气中的寿命**：不算太长（年—世纪—千年量级），所以一旦氧化源源不断，甲烷库很快被消耗。
- 老师的现代类比（课后 Q&A）：现在南北半球的极地环流格局不同——北极被陆地环绕、水体环流差；南极被环南极洋流包围。**雪球地球通常需要大陆聚集在赤道附近成环**，阻断洋流的经向输热。（他自承这不是他的专业领域。）
- **厨房小故事（记忆锚点）**：老师讲他侄女上大学前去 IKEA 买了一套锅，到了宿舍发现是电磁炉不能用；而他当年用的是燃气灶——**燃气灶烧的就是甲烷**。用来引入"甲烷 + 氧气 → 火焰"这个反应，只是在大气中它是缓慢进行的。

### （八）氧气的坏处：自由基与芬顿反应 (Fenton Reaction)

**"氧气是有毒的"**——这是本讲反复强调的反直觉要点。

**三步反应链（幻灯片上给出，需要理解，不要求死背细节）**：

1. **O₂ + Fe²⁺ → O₂•⁻ + Fe³⁺**
   生成**超氧阴离子 (superoxide)**——一种**自由基 (free radical)**。
   > **自由基定义**：带有**未配对电子 (unpaired electron)** 的分子物种。稳定分子里电子成对存在，一对电子自旋相反、共享同一个原子轨道。O₂ 本身稳定，但获得一个电子变成 O₂•⁻ 后就多出一个未配对电子。老师说这是"氧气特有的怪化学，大多数分子不这样"。

2. **2 O₂•⁻ + 2H⁺ → H₂O₂ + O₂**
   生成**过氧化氢 (hydrogen peroxide)**——**就是漂白剂**。（老师补充：双氧水做头发漂白剂的原理，就是化学性地与头发里的**黑色素 (melanin)** 反应，改变其化学性质从而改变颜色。）

3. **H₂O₂ + Fe²⁺ → OH• + OH⁻ + Fe³⁺**
   生成**羟基自由基 (hydroxyl radical)**——**已知反应性最强的物种 (the most reactive species known)**。

以上整套反应统称 **芬顿反应 (Fenton reaction)**：**氧气 + 还原态铁 → 自由基**。

**危害**：羟基自由基会攻击
- **蛋白质 (proteins)**
- **膜脂 (membrane lipids)**
- **DNA 和 RNA** → 改变碱基序列 → **突变 (mutations)**

**与衰老的关系**：人老了皮肤起皱、器官出问题，很大一部分（不是全部）就是这套化学造成的累积损伤。这也是"**抗氧化剂 (antioxidants) 对身体好**"这一说法的化学基础。

**为什么这在 GOE 时是致命的**：
- 氧气刚出现时，**地球上没有任何生物接触过有意义浓度的分子氧**——这是一种全新的、未知的分子，**没有任何生物有任何防御机制**。
- 更糟的是：**生命本身一直在制造还原态铁**（电子传递链里不断氧化还原 Fe 和 Mn）。芬顿反应的两个原料，生命自己就在源源不断地提供。
- **今天你们体内每一秒都在发生这套反应。**

**抗氧化剂 (antioxidants)**——本质上就是"能与高反应性分子反应、把损伤截停"的物质：
- **维生素 C (vitamin C / 抗坏血酸 ascorbic acid)**——**水溶性**，在细胞质等水相中起作用。
- **维生素 E (vitamin E)**——**脂溶性 (fatty molecule)**，存在于**膜**中保护膜脂。
- **花青素 (anthocyanins)**——红色、紫色、蓝色果实中的丰富来源。
- ⚠️ **老师的"打脸"知识点**：我们总说吃橙子柠檬补维生素 C，但**维生素 C 最好的来源其实是绿色蔬菜**。原因很有逻辑：**凡是绿色的东西 = 有叶绿体 = 在做光合作用 = 在制造氧气 + 制造还原态铁 → 它们是最容易遭受氧化胁迫 (oxidative stress) 的生物，比我们脆弱得多，所以必须自备大量抗氧化剂。**
- 人类**基本不自己合成**这些抗氧化剂，主要**从饮食中摄取**；多种维生素本身就是抗氧化剂。我们的**线粒体**也在不停制造活性氧 (reactive oxygen)。

### （九）第一次大灭绝 (The First Mass Extinction)

- **两重打击叠加**：
  1. **雪球地球** → 全球冰封，只有火山等局部区域保留温暖的液态水"避难所 (pockets of warmth)" → **生命可栖息的物理空间急剧缩小**；
  2. **氧毒性** → 幸存在这些空间里的生物又被这种全新的毒物摧残。
- 冰期本身是氧气造成的，所以两者本质是同一个原因的两条路径。
- 结果：**化石记录中当时的绝大多数生物消失** —— 这是**地球历史上第一次大灭绝事件**。
- 老师的哲学感慨："**这本可能就是故事的结局——生命把自己杀死了。**"
- **但有东西活下来了**。幸存条件：
  1. **地理运气**：待在仍然温暖、有液态水的地方；
  2. **生化创新**：碰巧已经在制造某些能保护自己免受活性氧伤害的分子，或者后来演化出**制造抗氧化剂的能力**；
  3. **时间缓冲**：氧浓度爬升花了 5 亿年，不是一夜之间，给了演化以反应时间。

### （十）氧气的好处（一）：臭氧层 (Ozone Layer)

**反应式**：
- **O₂ + UV → 2 O•**（紫外线打断氧分子，生成原子氧自由基，不稳定）
- **O₂ + O• → O₃**（原子氧与氧分子结合成**臭氧 ozone**）

**为什么形成在高层**：臭氧倾向于在**大气外层（平流层 stratosphere）**形成，因为**那里紫外线最强**。于是行星外围形成一层臭氧壳。

**意义**：
- 臭氧层**阻挡 UV 进一步进入地表**。
- **UV 是极具破坏性的高能光**，能**打断生命分子中的化学键**；晒伤 (sunburn) 就是最直观的例子。
- **没有臭氧层，生命不可能存在于陆地上**——水体能吸收 UV，所以早期生命只能躲在水下。
- 因此：**臭氧层的出现 = 生命第一次有可能离开水体。** 这正是下周（生命登陆）的前提条件。
- 纪录片旁白的说法：三十亿年前加拿大南部的荒芜盐滩最接近那个古老世界；当时原始大气挡不住紫外线，UV 强度是今天的数百倍，**陆地上什么都活不了**。发生在 30–25 亿年前的这次事件是"生命史上最大的单一转折点"，而它**全部由植物最早的祖先造成**。

### （十一）氧气的好处（二）：有氧呼吸与"细胞变大"

| | 反应式 | ATP 产量 |
|---|---|---|
| **无氧呼吸 (anaerobic respiration) / 发酵 (fermentation)** | C₆H₁₂O₆ → 2 C₂H₅OH + 2 CO₂ | **2 ATP** |
| **有氧呼吸 (aerobic respiration)** | C₆H₁₂O₆ + O₂ → CO₂ + H₂O | **36 ATP** |

- 无氧那条就是**发酵**：酵母 (yeast) 在低氧环境下分解葡萄糖生成**乙醇 (C₂H₅OH)** + CO₂——葡萄酿酒、大麦酿啤酒就是这个。
- **效率相差 18 倍**。有氧条件下可以把糖**完全氧化**到 CO₂，把碳的还原势彻底榨干。
- **演化后果（本讲的第二个关键因果链）**：
  - 生命早期细胞**被迫很小**，因为能从环境中提取的能量太少，养不起大体积（体积↑ → 需求↑，而表面积/体积比↓）。
  - 氧气出现后，**能耐受氧的幸存者**可以做高效呼吸 → **细胞体积可以爆炸式增长**。
- **为什么"变大"重要？** 因为它**让生命能做的事变多了**：
  - 早期生态系统只有三种营养方式：**化能自养 (chemoautotrophs)**（从环境化学中取能）、**光合自养 (photoautotrophs)**、**异养 (heterotrophs)**——但当时的异养只是被动**吸收周围漂浮的有机/无机分子**。
  - 有了大细胞和小细胞的**体型差**，就出现了一种全新的营养方式：**吃 (eating)** —— 大细胞吞小细胞。
  - 这直接开启了下半场的故事。

### （十二）下半场：Come Together — 真核细胞的起源

#### 时间坐标（约 2 Ga）
- 生命已诞生；光合作用已演化；蓝细菌已产氧；**休伦冰期结束**（结束的驱动可能是大陆漂移 + 太阳活动变化的组合）。
- 世界重新变暖，冰盖退缩，液态水与可居住空间增加。
- 然后，在演化尺度上又一次**突兀的变化**：复杂细胞出现。

#### 最早的真核化石
- ***Grypania spiralis*** — **可能是已知最古老的真核生物**，约 **1.9 Ga（19 亿年前）**。螺旋状的宏观化石。

#### 术语澄清（老师专门讲的词源）
- **-karyote** 源自"核/细胞"。
- **Eukaryote（真核生物）= "true cell / true nucleus"**——有**细胞核 (nucleus)**。
- **Prokaryote（原核生物）= "pre-cell / before nucleus"**。
- ⚠️ **现代分类学已经不再把 "prokaryote" 当作一个正式类群**，因为它把**细菌 (Bacteria)** 和**古菌 (Archaea)** 两个在分子层面根本不同的类群硬拼在一起（DNA 使用方式、多种结构都不同）。三域：Bacteria / Archaea / Eukaryota。

#### 吞噬作用 (Phagocytosis) — 第一批"真正的"异养者
- 词源：**phago-（吃）+ cytosis（细胞）= 细胞吃细胞**。
- **前提**：有氧呼吸 → 更高能量效率 → 更大的细胞 → 大细胞能吞小细胞（**或者反过来，小细胞入侵大细胞**——两种方向都有证据）。
- **演化"吃"并不简单**，需要两套装置：
  1. **吞进去的装置**：**肌动蛋白细胞骨架 (actin cytoskeleton)**，能变形、包裹住另一个细胞。典型例子是**变形虫 (amoeba)**——用**伪足 (pseudopodia，字面意思"假腿")** 把细菌细胞包起来吞入。
  2. **消化的装置**：把消化酶注入包裹形成的膜泡中，分解并吸收猎物。
- 老师的说法：**这实际上是最原始的一套"肠道" (the very first primitive gut)** —— 一个被膜包起来、往里注入酶、在里面消化的腔室。
- 🌟 **决定性的一问**：**如果消化这一步出了错呢？** —— 这就是内共生的起点。

#### 共生 (Symbiosis) 与内共生 (Endosymbiosis)
**Symbiosis 定义**：不同生物**持续地生活在一起 (persistent living together)**。三种类型：

| 类型 | 定义 | 例子 |
|---|---|---|
| **寄生 (Parasitic)** | 一方获益，另一方**受害** | 肠道寄生虫；疟原虫 (malaria) |
| **共栖 (Commensal)** | 一方获益，另一方**不受影响** | 依附但不索取也不回报 |
| **互利共生 (Mutualistic)** | **双方都获益** | **地衣 (lichen)** |

- **地衣 (lichen)** 案例（老师现场提问的答案）：**真菌 (fungus) + 藻类 (alga) 或蓝细菌 (cyanobacterium)** 的互利共生体。
  - **真菌得到**：食物来源（藻类光合产物），从而能生活在自己单独活不了的地方（裸岩、极地）。
  - **藻类得到**："一栋房子"——受保护的环境，能在原本长不了的地方存活。
  - ⚠️ 易错点：地衣**不是一种真菌**，虽然分类上常按真菌方命名。

- **内共生 (Endosymbiosis)**：**一种生物生活在另一种生物的（细胞）内部**——共生关系中最极端、最有趣的一种。

**现代内共生的例子（老师课堂上带学生举的）**：
- **珊瑚 (coral)**：光合生物（虫黄藻）**living inside the cells of** 非光合生物（珊瑚虫）——大堡礁 (Great Barrier Reef)。
- **绿色海蛞蝓 (green sea slugs)**：吞下藻类，藻类在蛞蝓体内继续生活。
- **草履虫 (Paramecium)**：单细胞生物，外周布满鞭毛/纤毛；有些草履虫种类**体内住着藻类 (Chlorella)**。⭐ **这正是 Duncan Cameron 的研究对象**——他若身体允许本会亲自讲这部分。
- ⚠️ 学生答"我们体内的细菌"被老师纠正：**肠道菌群住在我们的身体里，但不住在我们的细胞里**——那不是 endosymbiosis。

#### Lynn Margulis 与内共生学说
- **Lynn Margulis** 是老师的"科学英雄"之一。
- 她提出**内共生学说 (endosymbiotic hypothesis / symbiogenesis)**：细胞器由被吞入而未被消化的细菌演化而来。
- **科学社会学的一课（老师特意讲的故事）**：他的科学英雄们的共同点是——提出想法时**所有人都说"你在胡说八道"**。Margulis 还多了一重障碍：她在 1960–70 年代的科学界"犯了一个致命错误——身为女性"。所幸不是所有人都那么偏见，她的观点最终获胜。
- 今天，内共生被视为**生命演化的关键踏脚石之一 (key stepping stones)**。

#### 真核细胞的结构：细胞器 (Organelles)
- **细胞核 (nucleus)**：与细菌的核心差异。细菌的 DNA 虽也结合蛋白、有一定结构，但**基本就散在细胞里**；真核的 DNA **被膜包裹**。
- **内质网 (endoplasmic reticulum, ER)**：复杂的折叠膜系统。**粗面内质网 (rough ER)** 上结合**核糖体 (ribosomes)**，负责合成蛋白质。
- **高尔基体 (Golgi body)**。
- **线粒体 (mitochondrion)**。
- **质体 (plastid)**：
  - ⚠️ 幻灯片用 **"plastid"** 而不是 "chloroplast"，因为**叶绿体只是质体的一种**。有些植物细胞里的质体**不做光合作用**，另有分工。
  - **例子**：植物**根**里有一种被改造的质体（淀粉体/平衡石 statolith）能**感知重力**，这是植物"知道哪边是下"的机制之一，也是**根向下生长**的原因。
- ⚠️ **重要的反例提醒**：**细菌也有内膜！** 幻灯片展示了一种丝状蓝细菌，内部有清晰的膜层（类囊体膜）。所以"有内膜"本身并不能证明真核细胞特殊——**关键在于细胞器的其他特征**。

#### 线粒体与叶绿体是细菌出身的证据（考点）
幻灯片列出四条，都是 Margulis 论证的核心：

1. **双层膜 (double membrane)**——外层来自宿主的吞噬膜，内层来自内共生体自己的膜。**两层膜在化学上可区分**（脂质组成不同）。内膜控制物质进出。
   - 🔑 **形成逻辑**：小细胞本来有一层自己的膜；大细胞吞它时用自己的膜把它包了一层 → 变成两层膜。
2. **含有 DNA**——**自己的基因组**，通常是**环状 (circular)** 的（像细菌），但是**简化的、缺失了必需基因**。
3. **能自己合成蛋白质**——有自己的核糖体。
4. **具备细菌的特征**——例如 **70S 核糖体**（细菌型，真核细胞质是 80S）、**密码子使用偏好 (codon usage)** 与细菌一致。

#### 真核生物的"嵌合"起源（本讲最精妙的推理）
- **生命之树 (tree of life)** 上的读法：LUCA 分出 **Archaea** 与 **Bacteria** 两支（细菌内部还分革兰氏阳性/阴性，本课不要求）。真核生物（动物 animals、真菌 fungi、植物 plants）的分支点**从古菌一侧分出**。
- → **结论 A：真核生物的"外壳"（宿主细胞）来自古菌 (Archaea)。**
- **但没这么简单**：
  - 光合作用是在**细菌**里演化的；**叶绿体做产氧光合作用、有两个光系统、放氧** → **叶绿体来自蓝细菌 (cyanobacteria)**。
  - 同理，比较**线粒体的性状与基因**，可以判定**线粒体来自细菌**。
- → **结论 B：真核生物的"内部"（细胞器）来自细菌 (Bacteria)。**
- 🌟 **所以"真核生物到底来自古菌还是细菌"是个假问题——答案是两者都是。真核细胞是一个嵌合体 (chimera)**：一个古菌样的宿主细胞吞噬细菌，并与之建立了稳定关系。

#### Lokiarchaeota — 我们最近的古菌亲戚？
- **问题所在**：**现代古菌都不会吞噬作用**——没有任何已知的现代古菌具备 phagocytosis 的机制，所以"古菌宿主吞了细菌"这个故事缺一个活体证据。
- **突破**：**Loki's Castle**（洛基城堡）——**挪威沿岸/北大西洋（北冰洋中脊）深海热液喷口区**，**2008 年发现**。
  - ⚠️ 名字来自**北欧神话中的洛基 (Loki)**。老师课上误说是"某个日本卡通"，这是转写/口误，别记错。
- 在此发现了 **Lokiarchaeota（洛基古菌门）**，它**具有多项真核生物的性状，包括与吞噬作用相关的机制**。
- **研究方法的重要限制（老师强调）**：这是**通过投放探针采样、直接测 DNA 序列（宏基因组学 metagenomics）** 得到的——**还没有人把它培养出来**，也没有真正把这个生物本体分离出来。**"不清楚它是否真的能做吞噬作用"**。
- 结论只能说：**真核生物的祖先可能是某种类似 Lokiarchaeota 的东西。**
- 参考：Nature 2015, vol 521 no 7551 (nature14447)。

#### "一桩幸福的婚姻"？—— 内共生关系的成熟
- **基因转移**：随时间推移，内共生体（细菌）**逐渐丢失基因**，其中一部分**转移到宿主细胞核**里。
- **表面上：细胞器"失去了控制权"**。
- **实际上：形成了双向依赖**：
  - **逆向信号 (retrograde signalling)**：细胞器 → 细胞核（告诉细胞核它需要什么蛋白质）；
  - **正向信号 (anterograde signalling)**：细胞核 → 细胞器。
  - **细胞器"喂养"宿主**（线粒体制造 ATP）；
  - **宿主也"喂养"细胞器**（提供矿物质、构建原料）。
- **不可逆性对比（重要）**：
  - **草履虫 + 藻类**：可以分开、也可以重新结合——**可逆的关系**。
  - **线粒体 / 叶绿体**：**完全不可逆**。你无法把线粒体取出来单独培养——它已经彻底依赖宿主。这正是"细胞器"与"内共生体"的界线。

#### 单次起源 (Single Endosymbiotic Event)
- **方法**：取今天所有生物的**线粒体序列**，建**系统发育树 (phylogenetic tree)**，看它们彼此的亲缘关系。
- **结论**：所有线粒体都**汇聚到一次单一事件**。叶绿体同理。
- **推断的先后顺序（用简约性原则）**：
  1. 一个古菌（样的）宿主吞入一个细菌 → **第一个线粒体** → 这条谱系辐射分化出大量真核生物；
  2. 其中**一条谱系**又吞入一个**蓝细菌** → 得到既有线粒体又有叶绿体的细胞 → **第一个藻类 (the first alga)**。
- **为什么是这个顺序？** **奥卡姆剃刀 / 简约法 (Occam's razor / parsimony)**：反过来（先叶绿体后线粒体）不是不可能，但那样就需要**大量谱系各自独立丢失叶绿体**，假设太多。**我们采纳最简单的解释。**

#### LECA 与真核生物的两大分支
**LECA = Last Eukaryote Common Ancestor（最后的真核生物共同祖先）**

| 分支 | 含义 | 演化去向 | 分子标志（共有衍征） |
|---|---|---|---|
| **单鞭毛类 Unikonts（= Amorphea）** | "One flagellum"，一根鞭毛 | **动物 (animals) + 真菌 (fungi)** | **三基因融合 (3-gene fusion)**：carbamoyl phosphate synthase + dihydroorotase + aspartate carbamoyltransferase（即 CAD） |
| **双鞭毛类 Bikonts** | "Two flagella"，两根鞭毛 | **植物 (plants)** | **二基因融合 (2-gene fusion)**：thymidylate synthase + dihydrofolate reductase |

- **鞭毛 (flagella)** 就是细胞用来游泳的"尾巴"。老师说鞭毛数本身不必深究，**重点是这两支的去向**。
- 🌟 **核心结论：动物和真菌彼此的亲缘关系，比它们各自与植物的关系更近。**
- **科学史反转（老师爱讲的点）**：150 年前植物学刚成为学科时，人们（包括 **Linnaeus 林奈**）把**真菌归类为更接近植物**。**这是完全错的**——真菌离动物近得多，植物是相当独立的一支。
- **为什么基因融合是好证据？** 因为**两个/三个独立的基因融合成一个基因是极不可能发生的事件**，几乎不会独立发生两次。观察到：
  - 三基因融合**在动物和真菌中都有，在植物中没有**；
  - 二基因融合**在植物中有，在动物和真菌中没有**。
  - → 这种**罕见事件的共享**是判定分支关系的强证据（系统发育学中的**共有衍征 synapomorphy**）。

#### 分而治之：有丝分裂 (Mitosis)
- **问题的来源**：
  - **细菌/古菌**：**一个单一的环状 DNA**，靠**出芽/二分裂 (budding / binary fission)** 分裂——复制基因组、分到两边、细胞一分为二。最坏的情况是两份 DNA 都留在同一边，那就一个子细胞存活。机制简单。
  - **真核生物**：**多条线性染色体 (multiple linear chromosomes)**（人类 **46 条 = 23 对**）。
- **由此产生的挑战**：必须保证**每条染色体的一份都准确分配到每个子细胞**，让两个子细胞的 DNA 组成与母细胞完全相同。这需要演化出一整套复杂机械。
- **有丝分裂的关键步骤**（老师说他当年必须背 **prophase 前期 / metaphase 中期 / anaphase 后期 / telophase 末期**，但**本课不要求背步骤**）：
  1. **核膜解体**，细胞核瓦解；
  2. **染色体凝缩 (condensation)**——从杂乱的染色质变成显微镜下可见的独立结构；
  3. 染色体排列到**纺锤体 (spindle)** 上——一个在细胞内形成的**蛋白质支架**；
  4. 被拉开、分离到两极。
- **老师要求掌握的只有一句话**：**有丝分裂是让细胞均匀分配 DNA 的机制，保证每个子细胞得到每条染色体的一份。**

#### 谈谈性：减数分裂 (Meiosis) 与有性生殖
- **细菌的"性"**：**细菌接合 (bacterial conjugation)** —— 幻灯片的说法是 *"sex but not as we know it?"*（是性，但不是我们所知的性）。细菌交换 DNA 的方式包括环境摄取、噬菌体转移、原始的细胞间转移，但**相比真核生物的机制粗糙得多**。
- **减数分裂 (Meiosis)**（幻灯片原话）：**"Genomes fuse, shuffle and divide. End with the same genes… but a different set of alleles."**
  - 基因组**融合 → 洗牌 → 分裂**；
  - 结果：**基因 (genes) 还是那些基因，但等位基因 (alleles) 的组合不同了**。
  - ⚠️ **这个 gene / allele 的区分是关键考点。**
- **机制要点（不要求细节）**：DNA 的一半分向一边、另一半分向另一边，产生的配子细胞再与另一个体的细胞结合，产生**混合了两个亲本 DNA 的细胞**。
- **为什么有性生殖如此重要（老师现场提问的答案）**：**它产生遗传变异 (genetic variation)**。
  - 个体 A 有一种基因序列，个体 B 有另一种；有性生殖让两者**汇聚、交换、以不同组合重排**；
  - 于是演化能**在更大的组合空间里搜索**，为新的演化难题找到新解；
  - **相比只靠突变的无性繁殖，这是加速演化的巨大一步。**
- **演化的层层递进（老师的总结逻辑）**：
  > 氧气 → 更大更复杂的细胞 → 需要更复杂的分裂机制 → **有丝分裂**（把大套 DNA 均分）→ 有丝分裂演化出的结构（纺锤体、染色体凝缩等）成为**更复杂的减数分裂**的基础 → **有性生殖** → 演化加速。

## 三、公式与图表

### （一）必须掌握的反应式

**1. 水的光解 / 氧释放复合体（⭐ 老师明说"整门课只有一个反应式真的需要你们知道"）**
```
2 H₂O + Light → 4 e⁻ + 4 H⁺ + O₂
```
- 符号：H₂O = 水（电子供体）；Light = 光能（由两个串联光系统提供的电位差）；e⁻ = 送入电子传递链的电子；H⁺ = 质子（贡献跨膜质子梯度）；O₂ = 副产物分子氧。
- 记忆：**2 个水 → 丢 4 个电子 → 同时丢 4 个质子 → 剩下 2 个原子氧 → 结合成 1 个 O₂**。

**2. 甲烷氧化（休伦冰期的化学基础）**
```
CH₄ + 2 O₂ → CO₂ + 2 H₂O
```
- 意义：把**强温室气体 CH₄** 换成**弱温室气体 CO₂** → 温室效应减弱 → **全球降温**。

**3. 芬顿反应 (Fenton Reaction) 三步链**
```
O₂  + Fe²⁺  →  O₂•⁻ + Fe³⁺              超氧 superoxide（自由基）
2 O₂•⁻ + 2 H⁺ →  H₂O₂ + O₂              过氧化氢 hydrogen peroxide（漂白剂）
H₂O₂ + Fe²⁺ →  OH• + OH⁻ + Fe³⁺        羟基自由基 hydroxyl radical（最强反应性物种）
```
- 符号：**•** 表示未配对电子（自由基标记）；Fe²⁺/Fe³⁺ 在链条中**循环催化**，所以少量铁就能持续制造自由基。

**4. 臭氧的生成**
```
O₂ + UV → 2 O•
O₂ + O• → O₃
```

**5. 呼吸的两条路线（对比记忆）**
```
无氧（发酵）：C₆H₁₂O₆ → 2 C₂H₅OH + 2 CO₂        产 2 ATP
有氧：      C₆H₁₂O₆ + O₂ → CO₂ + H₂O           产 36 ATP
```
- 比值 **36 : 2 = 18 倍**，这就是"细胞可以变大"的能量学根据。

### （二）图表判读要点

**图 1：反应中心卡通图（"copulating caterpillar"）**
- 判读：横向一条膜；膜中央嵌着两条相互缠绕的蛋白（二聚体核心）；核心中间是 special pair 叶绿素。
- 箭头从叶绿素指向膜的**另一侧**——表示**吸光后的跨膜电子转移 = 电荷分离**。
- 边上标注 *"Electrons need replacing"*——提醒电子供体是这套系统的瓶颈。

**图 2：Type I vs Type II 对比图**
- 判读关键：看**突出物在膜的哪一侧**。Type I 的电子受体挂在**内侧（细胞内）**；Type II 的附属结构突出在**外侧**，并标有 **H₂S** 作为外源电子供体。
- 图上还标了辅因子类型：**Fe（cytochromes）** 与 **Fe-S（iron-sulphur proteins）**。

**图 3：反应中心的演化谱系图 (Evolution of reaction centres)**
- 判读：底部是 **Ancestor Bacteria（祖先细菌）**，向上分成两支，一支标 **Type I**，一支标 **Type II**。
- 图注：***"Type I and Type II centres evolved in different lineages"***——这是本图唯一要记住的结论。
- **配套要记**：Type I → 绿硫细菌、太阳杆菌；Type II → 紫硫细菌、绿非硫细菌。
- **接下来一张的转折**："**Except…**" → **蓝细菌两者都有** → 由 **lateral gene transfer** 解释。

**图 4：大气氧含量随地球历史的演化曲线**
- 横轴：地质时间（Ga，距今十亿年）；纵轴：大气 O₂ **分压 (partial pressure, atm)**。
- 图上有**两条曲线**——代表**两种不同的重建方法给出的两组独立估计**；两条曲线细节不同但**故事一致**，这本身就是证据可靠性的论证方式（⭐ 这是一个方法论考点）。
- 判读要点：
  1. 早期地球 **≈ 0 氧**；
  2. 蓝细菌出现（约 2.5 Ga）后**缓慢上升**——缓慢是因为氧先被海水中还原态金属消耗；
  3. 经过约 **500 Myr** 达到新的稳定水平 **≈ 0.05 atm**；
  4. 曲线上标注 **"Cyanobacteria appear"** 与 **"Huronian Ice Age"** 两个事件；
  5. 后期地球史上还有**其他增氧事件**（本课后面会讲），所以曲线不是一次性到顶。
- 图源署名：Heinrich D. Holland（CC BY-SA 3.0）。

**图 5：条带状铁建造 (BIF) 照片**
- 判读：致密的深色（铁质）层与红/橙色层**交替互层**。
- 红色 = **氧化铁（铁锈）**，即 Fe³⁺ 相；这是**海水中溶解 Fe²⁺ 被生物氧遇氧沉淀**的产物。
- 一句话结论（幻灯片标题）：***"Bands of iron oxides show evidence of oxygen production."***
- 署名 André Karwath, CC BY-SA 2.5。

**图 6：叠层石 (Stromatolites)**
- 判读：**层状、穹状/柱状**的堆叠结构，剖面有明显的同心纹层。
- 成因：微生物席逐层生长 + 捕获/沉淀矿物 → 逐层加积。
- 意义：**最早的生命化石证据之一 + 蓝细菌出现的化石标志**。

**图 7：真核细胞结构图 (The Eukaryotic Cell)**
- 需要能指认：**细胞核 (nucleus，图中蓝色)**、**内质网 (ER，复杂折叠膜)**、**高尔基体 (Golgi body)**、**线粒体 (mitochondrion)**、**质体/叶绿体 (plastid / chloroplast，图中绿色)**。
- 对比图：一张**丝状蓝细菌**的电镜照片，里面能看到清晰的**内膜层**——⚠️ 用来说明"**细菌也有内膜**，内膜本身不是真核的专利"。
- 线粒体/叶绿体的电镜图上要能看出**双层膜**与**内部膜层（嵴 / 类囊体）**。

**图 8：生命之树 (Tree of Life)**
- 判读方法（⭐ 系统发育树的通用读法）：
  1. 找到**根 (root)** = **LUCA**；
  2. LUCA 分出两大支：**Bacteria** 与 **Archaea**（图中细菌还细分革兰氏阳性/阴性，不要求）；
  3. 找到 **Eukaryotes** 的分支点——**它嵌套在古菌一侧**；
  4. 在真核内部找到 **animals / fungi / plants** 的位置，注意 **animals 和 fungi 相邻**，**plants 单独一支**；
  5. **分支长度/顺序 ≠ "高级程度"**；只表示共同祖先的相对新旧。
- 图上标注：***"Eukaryotes are more similar to Archaea than to Bacteria; Eukaryotes probably evolved from Archaea."***
- ⚠️ **但这句话只讲了宿主的故事**——细胞器来自细菌。判读这张图时必须叠加"嵌合起源"的理解。

**图 9：LECA 分化图**
- 从 **LECA** 出发分两支：
  - **Unikonts (Amorphea)**，"One flagellum" → **"Animals" + "Fungi"**，标志 **3-gene fusion**（carbamoyl phosphate synthase, dihydroorotase, aspartate carbamoyltransferase）；
  - **Bikonts**，"Two flagella" → **"Plants"**，标志 **2-gene fusion**（thymidylate synthase, dihydrofolate reductase）。
- 判读要点：**看分支上标的"罕见分子事件"来判断谁和谁是一家**。

**图 10：有丝分裂示意图 (Mitosis)**
- 判读：按顺序看 **核膜解体 → 染色体凝缩成可见的 X 形 → 排列在赤道板上、连到纺锤体 → 姐妹染色单体被拉向两极 → 核膜重建、细胞质分裂**。
- 本课**只需理解功能**：确保每个子细胞获得与母细胞相同的完整染色体组。
- 图源：Ali Zifan, CC BY-SA 4.0（基于 Campbell Biology 10th ed.）。

**图 11：减数分裂示意图 (Meiosis)**
- 判读：注意**同源染色体配对与交换（洗牌）**，以及**两轮分裂**导致**染色体数减半**。
- 幻灯片文字即是判读钥匙：*"Genomes fuse, shuffle and divide. End with the same genes… but a different set of alleles."*

### 2. Type I / Type II 的"独立分化两次"论证（课间答疑时重讲的关键点）
学生提问后老师专门重讲了一遍——**这是本讲最容易被漏掉的核心论证**：
> 反应中心的核心是两条蛋白。**最早它们是两条完全相同的蛋白**（同源二聚体）。后来它们各自分化成不同的蛋白，而**这件事独立发生了两次**：一次在 Type I 谱系，一次在 Type II 谱系。
> **我们怎么知道？因为 Type I 内部的两条蛋白彼此更相似，Type II 内部的两条蛋白彼此更相似，而不是 Type I 的某条与 Type II 的某条更相似。**

### 3. "Type I / Type II 命名毫无深意"（课后 Q&A）
学生问"Type I 是电子受体还是……？"老师回答：
- **两者既是受体也是供体**；
- Type I 是"把电子给出去"的那个；
- **"编号是发现的意外，它们只是被以那个顺序发现和描述的。"**

### 4. 蓝细菌的现实危害（老师的补充故事）
- 蓝细菌 = "blue-green algae"，就是新闻里说的**有毒藻华 (toxic algal blooms)**。
- **机制**：湖泊中营养盐过量释放（富营养化）→ 蓝细菌种群爆发 → 占领整个湖泊 → **产生毒素**。
- **故事**：有人带大型犬在湖边散步，狗下水游泳，**狗死了**。"非常非常毒。"
- 教学用意：让学生记住蓝细菌不是遥远的化石概念，**它们今天仍然极其常见、极其重要**。

### 5. "第一次污染事件"这一框架（老师的核心叙事）
- 老师反复用**污染**的比喻来描述 GOE："**这可以看作地球生命造成污染的第一个例子，是史上第一次重大污染灾难。**"
- 并明确类比人类："**就像我们今天创造新分子、释放到环境里、毒害其他东西一样，蓝细菌在它们的时代做了完全相同的事。**"
- 这是本讲的**思想主线之一**：生命不是被动适应地球，**生命主动改造（甚至破坏）地球**。

### 6. 自由基化学与日常生活的关联（老师花了很多时间）
- **抗氧化剂为什么"对身体好"**：因为它们**与高反应性分子反应、把损伤拦住**。这不是玄学，是明确的化学。
- **为什么绿色蔬菜比橙子更好**：光合生物制造氧 + 制造还原态铁，是**最容易受氧化胁迫的生物，比我们脆弱得多**，因此自带高浓度维生素 C。
- **双氧水漂发的化学**：与头发中的**黑色素 (melanin)** 反应，改变其化学性质从而改变颜色。
- **我们自己不太合成抗氧化剂**，主要靠饮食摄取；多种维生素本身就是抗氧化剂。

### 7. 纪录片片段（BBC《How to Grow a Planet》，主持人 Iain Stewart）
课上播放了完整片段，转写完整保留，值得记住的细节：
- 加拿大南部的**荒芜盐滩**最接近 30 亿年前的地球面貌；
- **唯一的关键差别**：那时**原始大气挡不住紫外线，UV 强度是今天的数百倍，陆地上什么都活不了**；
- 发生在 **30–25 亿年前**的产氧事件是"**地球生命史上最大的单一转折点**"，**而它完全由植物最早的祖先造成**；
- 南非 **Sishen 铁矿**：一次爆破 **20 万吨铁矿石**，"炸开了一个通往过去的横截面"；
- 铁矿石**又重又有金属光泽**，但**满是红色——因为它生锈了，因为它接触过氧**；
- 主持人把矿石磨粉、配成溶液、**通电电解**，看到气泡冒出——"**这些氧气被封在岩石里超过 25 亿年，现在第一次被释放出来**"；一小时收集了满满一试管，然后**把它吸进肺里**。
- 老师的点评：**"partly silly, but…"** ——手法夸张，但科学要点是对的：那些氧的确源自 25 亿年前生命的产氧。

### 8. 关于铁的溶解度（老师特别加重语气）
> "**Iron(II) 极易溶于水，Iron(III) 基本不溶。这一点非常非常重要，你们在课程后面还会回到这里。**"
这是理解 BIF、理解早期海洋化学、理解后续养分循环的**主控变量**。

### 9. 关于"什么是真核生物"的词源与分类学更新
- 老师做学生时，生物学被简单分成 prokaryote / eukaryote 两半；
- **今天不再这样用**——原核被拆成 Bacteria 和 Archaea，因为两者在分子层面（DNA 的使用方式、多种结构）有根本差异。

### 10. 内共生"婚姻"的双向性
- 教科书常只讲"细胞器丢了基因、失去自主"，老师额外强调**双向依赖**：
  - 细胞器给宿主 **ATP / 能量**；
  - 宿主给细胞器**矿物质和物理构建原料**；
  - 双向信号：**retrograde（细胞器→核）** 与 **anterograde（核→细胞器）**；
  - 我们**至今没有完全理解**这套通讯关系。

### 11. 关于 Loki's Castle 的两个纠正
- ⚠️ 老师课上说名字来自"某个日本卡通"——**这是口误**。Loki's Castle 得名于**北欧神话的洛基 (Loki)**（其烟囱结构形似城堡）。
- 老师同时给出了地理定位的几个说法（"北海""冰岛附近""北大西洋""挪威沿岸"）——**准确说法是北冰洋中脊 (Arctic Mid-Ocean Ridge)、挪威与格陵兰之间**。
- **方法论要点**（老师说对了且很重要）：**Lokiarchaeota 至今未被培养出来，全部证据来自宏基因组 DNA 序列**——所以"它能做吞噬作用"只是**推断**，不是观察。

### 12. Lynn Margulis 的科学社会学教训
老师用这个故事传递一个反复出现的主题：**"我的科学英雄们的共同点，就是他们提出想法时所有人都说他们在胡说八道。"** Margulis 还额外承受了 1960–70 年代科学界对女性的偏见。**好想法常常先被拒绝，然后才被接受。**

### 13. 林奈的错误
**Linnaeus 把真菌归为接近植物——完全错了。** 真菌与动物的关系比与植物近得多。这是"直觉分类 vs 分子系统发育"的经典对照案例。

### 14. 简约性原则的实际应用
在推断"先线粒体还是先叶绿体"时，老师明确说明这是在用 **Occam's razor / parsimony（最简约解释）**：另一个顺序不是不可能，但需要假设大量独立的丢失事件，因此我们选最简单的那个。⭐ **这是演化生物学的通用推理方法，本课后续多处会用。**

## 六、易错点 / 重点难点

1. **Type I / Type II 的编号没有生物学意义**——纯粹是发现顺序。别去背"I 一定是供体"这类死规则；两者**既是受体也是供体**，差别在**膜上的拓扑与电子流向**。
2. **不要背反应中心的详细化学**。老师明说：整门课**只有水裂解式 `2H₂O + Light → 4e⁻ + 4H⁺ + O₂`** 是真正必须掌握的反应式，类群名字也不会考。
3. **"Type I 和 Type II 独立分化两次"的证据**很容易漏：**是"每一类型内部的两条蛋白彼此更像"这条比较**，不是别的。
4. **蓝细菌 ≠ 藻类。** "Blue-green algae" 是历史误称，它们是**细菌**。
5. **LGT 之所以可能，关键在于细菌基因成串（操纵子）排列**——所以 6–12 个基因可以**一次性整块转移**。别以为需要多次巧合。
6. **"两个光系统串联"的意义是电位相加（约 1 V + 约 0.8 V ≈ 1.8 V）**，从而**跨过氧化水所需的高能垒**。H₂S 与 H₂O 化学相似但**易氧化得多**——这是"为什么早期光合用 H₂S 不用 H₂O"的答案。
7. **GOE 不是瞬时事件**：花了约 **500 Myr**，因为氧先被**海水中还原态 Fe/Mn 吸收**（形成 BIF），金属耗尽后才逸入大气。最终只到约 **0.05 atm**，远低于今天。
8. **Fe²⁺ 可溶 / Fe³⁺ 不可溶** —— 这是 BIF 沉积的机制核心，也是老师点名"课程后面还会回来"的知识点。
9. **休伦冰期的主因是甲烷被氧化掉**（强温室 → 弱温室），**不是"氧气本身导致降温"**。同时要记住幻灯片的星号：**大陆位置也起了作用**，只是不是主因。
10. **氧气是有毒的**——这是最反直觉的一点。毒性通过**芬顿反应**产生自由基实现；**铁在其中循环催化**，所以微量铁就能持续制造损伤。
11. **自由基的定义是"有未配对电子"**，不是"带电荷"。O₂•⁻ 恰好两者都有，容易混淆。
12. **氧的两大好处别只记一个**：① **臭氧层 → 允许生命登陆**；② **有氧呼吸 36 vs 2 ATP → 细胞可以变大**。第二条才是通往真核细胞的因果链。
13. **注意 36 ATP 是幻灯片给出的数字**（现代教科书常给 30–32），考试按课程给的数字答。
14. **内膜不是真核细胞的专利**——细菌（尤其蓝细菌）也有内膜。判定细胞器的细菌出身要靠：**双膜 + 自有 DNA + 自有核糖体（70S）+ 细菌式密码子使用**。
15. **"真核生物来自古菌还是细菌"是错误的二选一**——**宿主来自古菌，细胞器来自细菌，真核细胞是嵌合体。**
16. **Lokiarchaeota 尚未被培养**，全部证据来自宏基因组序列。"它可能能做吞噬作用"是推断而非观察——考试中若出现"证明了"这类措辞要警惕。
17. **Loki's Castle 得名于北欧神话的洛基**，不是日本卡通（老师课上口误）。
18. **共生的三种类型不要混**：parasitic（一方受害）/ commensal（一方不受影响）/ mutualistic（双方受益）。**Endosymbiosis 是"住在里面"这个空间关系，可以是上述任一类型，但真核细胞器的例子是互利的。**
19. **肠道细菌不是内共生**——它们住在身体里，不住在细胞里。老师当场纠正过这个答案。
20. **地衣不是"一种真菌"**，是真菌 + 藻类/蓝细菌的互利共生体。
21. **线粒体/叶绿体与草履虫-藻类共生的根本区别**：前者**不可逆、完全依赖**；后者**可逆、可分可合**。
22. **每种细胞器都源自单次内共生事件**（由系统发育树的汇聚推出）；**顺序是先线粒体、后叶绿体**，理由是**简约性**（Occam's razor），不是直接证据。
23. **动物和真菌比各自与植物更近**——Unikonts (动物+真菌) vs Bikonts (植物)。**林奈搞反了。**
24. **记住两个基因融合标志**：动物+真菌 = **三基因融合**（CAD 三个酶）；植物 = **二基因融合**（thymidylate synthase + dihydrofolate reductase）。**罕见事件的共享 = 强系统发育证据。**
25. **Plastid ≠ Chloroplast**。叶绿体是质体的一种；有的质体不做光合作用（例如根中感知重力的质体）。
26. **Mitosis 与 Meiosis 的功能差别**：mitosis = **均分，子细胞与母细胞相同**；meiosis = **减半 + 洗牌，产生"相同的基因、不同的等位基因组合"**。老师明说**不要求背 prophase/metaphase/anaphase/telophase 的细节**，但要理解**为什么真核生物需要这套机械**（多条线性染色体 vs 细菌的单一环状 DNA）。
27. **有性生殖的意义是产生遗传变异、让不同个体的有利等位基因得以组合**——不是"为了繁殖"（无性繁殖也能繁殖，而且更快）。
28. **时间数字要记牢**：~3.5 Ga 两类反应中心已分化；~3 Ga 叠层石/蓝细菌出现；~2.5 Ga 大氧化事件开始；~2.4 Ga 休伦冰期；~2 Ga 冰期结束、真核出现；**~1.9 Ga *Grypania spiralis***。

| Synapomorphy | 共有衍征 | 由共同祖先获得、为该支系共享的衍生性状，用于判定亲缘关系。 |
| Chromosome | 染色体 | 真核细胞中呈线性、成对存在的 DNA 结构（人类 23 对 / 46 条）。 |
| Mitosis | 有丝分裂 | 均等分配染色体、产生与母细胞相同的两个子细胞。 |
| Spindle | 纺锤体 | 有丝/减数分裂中牵引染色体的蛋白支架。 |
| Meiosis | 减数分裂 | 染色体减半并重组，产生"相同基因、不同等位基因组合"的配子。 |
| Bacterial conjugation | 细菌接合 | 细菌间通过接触转移 DNA，被称为"性，但不是我们所知的性"。 |
| Gene | 基因 | 编码功能产物的 DNA 序列单位。 |
| Allele | 等位基因 | 同一基因的不同版本；有性生殖改变的是等位基因组合而非基因本身。 |
| Genetic variation | 遗传变异 | 群体内基因型的差异，是自然选择作用的原材料。 |
| Linnaeus | 林奈 | 分类学奠基者，曾错误地把真菌归入接近植物的位置。 |
