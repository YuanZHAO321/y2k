## 二、核心概念

### （〇）元古宙的定义、分期与地位

**名称来源**：Proterozoic = 希腊语 *proteros* (earlier) + *zoe* (life)，即「**更早的生命**」。

**时间界限（两端都是靠事件定义的）**：
- **起点 2420 Ma**：以**首次全球性分布的冰川沉积 (first globally distributed glacial deposits)** 为标志——即 Huronian 冰期的沉积。⚠️ 注意：元古宙的**下界是用冰川沉积定义的**，这是本周一个容易被忽略的考点。
- **终点 539 Ma**：以**寒武纪大爆发 (Cambrian explosion)** 为标志，进入显生宙。

**在宙 (eon) 序列中的位置**：
- 非正式术语「**前寒武纪 (Precambrian)**」= 冥古宙 (Hadean) + 太古宙 (Archaean) + 元古宙 (Proterozoic)。元古宙是前寒武纪的**最后一个宙**。

**三个代 (eras)**——老师明确说这是**必须记住**的：

| 代 | 中文 | 大致时限 | 关键词 |
|---|---|---|---|
| **Palaeoproterozoic** | 古元古代 | ~2500–1600 Ma | GOE 大氧化事件、Huronian 冰期、Kenorland 裂解、Columbia 聚合 |
| **Mesoproterozoic** | 中元古代 | ~1600–1000 Ma（幻灯片标题写 1780–850 Ma，指「地球的中年期」这段稳定期） | 「无聊的十亿年」、Columbia→Rodinia、Grenville 造山、euxinic 海洋 |
| **Neoproterozoic** | 新元古代 | ~1000–539 Ma | Rodinia 裂解、NOE 第二次氧化、雪球地球、深俯冲开启 |

- 每个代下面还分若干**纪 (periods)**，划分依据是**生命与化学上的重大变化**。
- 🔑 **老师原话**：「你不需要背所有纪的名字，但你必须知道元古宙分成 Palaeo–Meso–Neo 三个代，因为每个代里都发生了重大的事。」

**元古宙的五大趋势（幻灯片 Overview 页，全周骨架）**：
1. **超大陆的聚合与裂解**——伴随地幔冷却与板块构造过程的演化；
2. **太阳光度 (solar luminosity) 上升**——从约 **70%** 升到约 **100%** 的今日水平；
3. **大气氧含量上升（并有波动）**——源自光合作用 + 有机碳在沉积岩中的埋藏 (burial of organic carbon)；
4. **海洋从还原态 (reducing) 变为有氧态 (aerobic)**——随海洋中生命的演化；
5. **古元古代与新元古代两次大冰期**——与超大陆的存在及大气 CO₂ 的抽减 (drawdown) 直接相关。

> 老师补充的心算提醒：这么多剧变听上去很夸张，但它们摊在 **20 亿年**里——「所以其实并不奇怪」。

### （一）元古宙岩石的分布、构造意义与经济价值

**为什么元古宙岩石比太古宙岩石保存得好得多？**
- 元古宙岩石往往**增生 (accreted) 在太古宙 Kenorland 克拉通的残余体边上**；
- 太古宙克拉通下面有巨大的**地幔龙骨 (mantle keel)**（Week 6 内容），提供了极强的**稳定性**，使得贴附其上的元古宙岩石不易被后期构造摧毁；
- 结果：地图上元古宙岩石（浅粉色）总是环绕太古宙岩石（红色）分布，**共同构成今天所有大陆的核心 (heart of all major continents)**。

**元古宙岩石记录的不是「一次事件」，而是「多次构造脉动」**（以澳大利亚为例）：
- **褐色 = 元古宙造山带 (orogens)**：代表元古宙期间**多次**大陆碰撞 → 造山 → 再裂解 → 再碰撞的循环。
- **黄色 = 沉积盆地 (sedimentary basins)**，包括两类成因：
  1. **裂谷盆地 (rift basins)**——大陆拉开时产生的伸展盆地；
  2. **沉降盆地 (subsidence basins)**——大陆碰撞形成山脉后，山体的**重量加载 (loading) 使地壳下沉**，在山前形成盆地，接收从山上剥蚀下来的沉积物（即前陆盆地概念）。
- 盆地中沉积的既有碎屑沉积物，也有**火山碎屑岩 (volcaniclastics)**。

**经济意义（Economic significance）**：
- 元古宙盆地是全球最重要的成矿层位之一：澳大利亚的元古宙岩石中赋存 **U（铀）、Pb（铅）、Cu（铜）、Au（金）** 等大量重要经济矿产。
- 老师说：这些矿床怎么形成，下学期 **A Sustainable Planet（与 Vicky）** 会详讲。

**英国的元古宙岩石（NW Scotland，苏格兰西北部）**：
- 与太古宙岩石（图上紫色）伴生，元古宙岩石为褐色。
- 时间跨度覆盖**整个元古宙**，两个端点标志物：
  - **Scourie dykes（斯库里岩墙群，2418–2375 Ma）** → 记录太古宙超大陆 **Kenorland 的裂解与破裂**（元古宙最早期）；
  - **Port Askaig Tillite（波特阿斯凯格冰碛岩，属 Argyll Group）** → 记录新元古代 **Marinoan 冰期 (645–635 Ma)**（元古宙最末期）。
- 这些岩石后来被多期造山事件变形与变质：**Grenville、Grampian、Caledonian 造山运动**。
- ⚠️ **老师特别提醒的一个「坑」**：同一次造山事件在不同大陆上被当地地质学家起了**不同的名字**（如 Grenville 在澳大利亚叫 Albany–Fraser belt，在南极叫 Bunger Hills）——「这让事情有点棘手」。

### （二）氧气革命 The Oxygen Revolution（本周第一大主线）

#### 1. 地球的「四次大气」

老师强调：地球大气**不是渐变演化，而是发生过整体性的替换 (wholesale shifts)**，研究者据此识别出**四种大气**：

| 序号 | 时期 | 成分与命运 |
|---|---|---|
| **第一大气** | ~4.5 Ga 地球初形成 | 捕获的原始 **He + H₂**；很快被巨型撞击（如月球形成事件）**吹散回太空** |
| **第二大气** | 冥古宙 Hadean | **H₂O、CO₂、CH₄、N₂**；高浓度温室气体使地球维持在 **Goldilocks Zone（宜居带温度）**，避免全程冰冻 |
| **第三大气** | 古元古代（GOE） | 第一次大规模**氧气注入** |
| **第四大气** | 新元古代（NOE） | 第二次氧气注入 → 基本形成**现代大气** |

- 🔑 今天地球大气最显著的特征就是**存在自由氧 (free oxygen)**；地球是太阳系中**唯一**大气含有可观自由氧的行星。

#### 2. 氧含量演化的三个阶段

整个元古宙，O₂ 从 **<0.1% PAL** 升到 **>50% PAL**（PAL = present atmospheric level，现代大气水平）。关键是：**这个上升不是匀速的，而是阶梯式的**，因此划分为三阶段：

| 阶段 | 时期 | 大气 | 浅海 | 深海 |
|---|---|---|---|---|
| **(I) Reducing stage 还原阶段** | 太古宙 | 无自由 O₂ | 无（可能有零星「oxygen oases 氧绿洲」） | 无 |
| **(II) Oxidizing stage 氧化阶段** | 古元古代（GOE） | 有 O₂ | 有 O₂ | **仍缺氧 (anoxic)** |
| **(III) Aerobic stage 有氧阶段** | 新元古代之后 | 有 O₂ | 有 O₂ | **有 O₂**（全地球系统贯通） |

> 🔑 判读要点：三阶段的区别**不只是量的多少，而是「氧气渗透到了地球系统的哪一层」**——大气 → 浅海 → 深海，逐层攻陷。

#### 3. 还原阶段的氧循环 vs 现代氧循环（对比图判读）

**还原阶段（太古宙）**：
- **增益 (Gain)：光解作用 (photolysis)**——大气中的水分子被（紫外）辐射劈开成 O₂ 和 H₂，**氢逃逸到太空**，氧留在大气中。
  - ⚠️ 转写中老师口误说成 "photosynthesis"，但幻灯片明确写 **photolysis**；从机制描述（"water is split through radiation"）也可确认是**光解**而非光合。
- **损失 (Loss)：火山作用 (volcanism)**（喷出还原性气体消耗 O₂）+ **风化作用 (weathering)**（当时贡献远小于今天）。
- **呼吸作用 (respiration) 的损失可忽略或根本不存在**——因为还没有会呼吸的生物（老师在这里放了一只小象的动画）。
- **后果**：没有 O₂ → **没有臭氧层 (ozone layer)** → 无法阻挡有害的紫外太阳辐射。若当时有任何屏蔽层，也必然是别的气体做的，绝不是氧。

**现代**：主要 O₂ 来源是**植物的光合作用 (photosynthesis)**；主要损失包括呼吸、氧化风化、火山还原性气体。

#### 4. (I) 太古宙还原阶段的证据

1. **BIF（条带状铁建造）的时间分布**——纵轴是 BIF 的相对丰度/形成速率，横轴 4 Ga 至今。
2. **氧化还原敏感的碎屑矿物 (redox-sensitive detrital minerals)** 在沉积岩中的**存留**，尤其是：
   - **晶质铀矿 (uraninite, UO₂)**
   - **黄铁矿 (pyrite, FeS₂)**
   - 🔑 **逻辑**：这两种矿物在含氧大气下会被迅速氧化分解；它们能作为**碎屑颗粒**在河流搬运中幸存下来并进入沉积岩，说明当时**大气中没有自由氧**。

#### 5. BIF 形成机制（本周高频考点，务必写透）

**前提条件**：海洋中必须存在一个**巨大的还原态铁 (reduced iron, Fe²⁺) 储库**。

**Fe²⁺ 从哪来？（两个来源，注意主次）**
- **(a) 陆地风化 + 河流搬运**：在**无氧大气**下，被风化的含铁矿物**不会被氧化**，铁以**还原态、可溶态**进入溶液，被河流带入海洋。（贡献确实存在）
- **(b) 海底火山活动 (submarine volcanic activity)**：在**无氧海洋**中，火山喷出的铁保持还原态。老师明确说 —— **这可能是远远更大的贡献者 (much larger contributor)**。

**BIF 如何沉淀？**
- 当还原态 Fe²⁺ **遇到海水中的自由氧**，被氧化成 **Fe³⁺**，形成**颗粒态氧化铁（如赤铁矿 hematite）**沉降堆积。

**⚠️ 老师特别强调的一个 caveat（易错点）**：
> **赤铁矿的存在并不必然意味着海洋是「富氧」的**——赤铁矿可以在**相当宽的氧浓度范围**内沉淀。有些太古宙 BIF 可能是在**极低氧**条件下形成的：当最早的产氧光合生物刚出现时，它们产生的那一点点氧会被**立刻消耗殆尽**，因此海洋中**不会有自由氧积累**。

### （三）GOE 大氧化事件 Great Oxidation Event (2.45–2.32 Ga)

**基本事实**：
- 大气 O₂ **快速**升至现代水平的 **1%–10%**；
- 发生在**大气与浅海**中，**深海仍缺氧**；
- 是一个**相对短暂的事件**，可能只持续约 **200 Ma**；
- 精确起止时间**有争议**——「取决于你把赌注押在哪一条证据上」。

#### GOE 的证据清单（幻灯片列全，逐条理解）

1. **红层 (Red beds) 首次出现于 ~2.3 Ga** —— 本周最直观的证据
   - 定义：含 **Fe³⁺-氧化物胶结物 (Fe³⁺-oxide cements)** 的**碎屑沉积岩**。
   - **陆相成因 (terrestrial origin)**：河流、泛滥平原等——照片中**很红的是泛滥平原泥岩 (floodplain muds)**，**稍红的是河道砂岩 (river channel deposits)**。
   - 成因：在**大气有 O₂ 的条件下发生风化**，含铁矿物氧化成赤铁矿，胶结物被染红。
   - 🔑 **推理**：红层在 ~2.3 Ga 之前**不出现**，说明此前大气氧极低；红层的出现**恰好接替了厚层 BIF**（两者有一小段重叠）。
2. **古土壤 (paleosols) 中铁的淋滤终止**——此前铁以还原、可溶的形式被淋滤走；有氧后铁被固定在原地。
3. **大规模碎屑晶质铀矿 (detrital uraninite) 沉积的终结**。
4. **蒸发岩硫酸盐 (evaporitic sulfate) 丰度增加**，包括**浅海环境的石膏 (gypsum) 质沉积**——有氧才能把还原态硫氧化成硫酸盐。
5. **黑色泥岩/页岩中的钼 (Molybdenum) 富集**——Mo 需要氧化风化才能从陆地释放进入海洋。
6. **质量无关硫同位素分馏 (mass-independent sulfur isotope fractionation, MIF) 的终止**——MIF 需要紫外线直达对流层的硫气体才会发生；**MIF 消失 = 臭氧层形成**。
7. **到 2316 ± 7 Ma，臭氧层 (ozone layer) 已经形成**（幻灯片给出的精确数字）。

> 💡 老师说：「我们不会逐条展开这些证据，但**如果你对这个话题感兴趣，下学期 tutorial 的 essay 完全可以写这个**——研究这些指标如何指示 GOE。」

#### 什么触发了古元古代的氧上升？

**核心公式（概念性方程，本周唯一的"公式"）**：

```
大气氧量的变化率 = 氧的产生速率 − 氧的消耗速率
Change in amount of oxygen per unit time = rate of production − rate of loss
```

**两条关键性质**：
- **消耗量取决于可用氧的多少（loss is dependent on how much oxygen is available）**——氧越多，消耗越快（负反馈）；
- **产生量与现有氧量无关（production is independent）**。

→ 因此要让氧**净增加**，只有两条路：**(a) 出现新的氧源**；**(b) 消耗过程被饱和/被削弱**。

**三大假说**：

**(1) 新氧源：蓝细菌 (cyanobacteria) 的产氧光合作用（photosystem II）**
- O₂ 是蓝细菌的**废弃产物 (waste product)**，改变了海洋的氧化还原状态 (redox state)。
- ⚠️ **这个解释的最大问题：滞后时间 (lag time)**——沉积岩证据显示，从产氧光合作用出现到 GOE，中间隔了**至少 200 Ma，可能长达 700 Ma**。
- 🔑 **化解滞后的经典论证（务必掌握）**：蓝细菌泵入海洋的氧，**全部被用来氧化那个巨大的还原铁储库**，生成了 BIF。**只有当这个铁储库被氧化殆尽之后**，才会有剩余的自由氧渗入大气。
  - **这正是 BIF–红层曲线图的威力所在**：厚层 BIF 的终结与红层的兴起在时间上**紧邻并略有重叠**——两件事在因果上是联系的。

**(2) 改变消耗过程：火山气体氧化还原状态的改变——从 H₂ 转向 H₂O**
- **机制**：火山若喷出大量 **H₂**，H₂ 会迅速夺取大气中的 O₂ 生成 H₂O，成为强大的氧汇；若火山改为喷出 **H₂O**，就不再消耗大气氧。
- **什么导致这种改变？** —— **从海底 (submarine) 火山作用转向陆上 (subaerial) 火山作用**。
  - **陆上火山喷出的气体还原性明显更弱（含水更多）**，海底火山喷出的气体还原性更强。
  - 而陆上火山增多本身又与**大陆出露面积增大**（超大陆、海平面相对下降）耦合——回到构造。

**(3) 大气甲烷 (CH₄) 的减少**——氧化 CH₄ 消耗氧，但同时也移除了强温室气体（见下文冰期部分）。

**结果**：无论具体原因为何，到约 **2.3–2.4 Ga**，**氧的产生已确定超过消耗**，大气氧快速上升。到约 **2 Ga**，**多细胞、需氧呼吸的真核生物 (multicellular oxygen-respiring eukaryotes)** 已出现在生物记录中。

### （四）元古宙的气候与冰期（本周第二大主线）

#### 1. 控制地表温度的三个因素（幻灯片核心）

```
地表温度取决于：
1. 太阳光度 (solar luminosity)   —— 随太阳年龄增加而增加
2. 反照率变化 (albedo)           —— 取决于陆块分布 = 板块构造！
3. 温室效应变化 (greenhouse effect) —— 取决于火山作用 = 板块构造！
```

🔑 **老师的核心论点**：三个因素中，**后两个都归结到板块构造**。所以「板块构造与大陆格局，在元古宙首尾两次气候事件中起了决定性作用」。

#### 2. 为什么元古宙大部分时间温度却相当稳定？（重要的"平衡"论证）

- 太阳光度**稳步上升**（70% → 100%），本应让地球越来越热；
- 但同时大气 **CO₂ 持续下降**，原因有二：
  1. **风化作用的抽减 (drawdown due to weathering) 增强**；
  2. **地幔冷却 → 岩浆活动减弱 → 火山输出的 CO₂ 减少**。
- **两者相互抵消**，因此元古宙大部分时间地表温度维持在相当恒定的水平。

> 🔑 **老师反复强调的元素方法论**：「**地球的运作从来不是关于绝对量，而是关于一个速率相对于另一个速率**（it's not about absolutes, it's how the rate of one thing compares to the rate of the other thing）。」——这句话是本周（乃至全课）的思维总纲。

- **但曲线两端有两次剧烈偏离**——元古宙**开头和结尾**的两次大冰期。
- 时间尺度的层次：**太阳光度在超长时间尺度上重要**；但在**百万至十亿年尺度**上，控制气候的是**反照率**与**温室效应**这类因素——也就是板块构造。

#### 3. 古元古代 Huronian 冰期 (2420–2220 Ma)

**命名与记录**：
- 得名于北美的 **Huronian Supergroup（休伦超群）**——一套**约 10 km 厚的连续冰川沉积序列**，记录了多次冰期幕。
- 北美记录到 **3 次冰期幕**；**第 4 次是全球性的**，包括在**南部非洲赤道古纬度 (equatorial palaeolatitudes)** 的冰成沉积，年龄 **2290–2250 Ma**。
- 🔑 **就是这些冰川沉积定义了元古宙的开始**。

**成因链条（幻灯片给出的标准解释，务必背下这条链）**：

**背景**：
- 太古宙**板块速度极快**，由**地幔柱 (mantle plumes)** 驱动的地幔环流带动大陆漂移，使陆块越并越大，最终在太古宙末—元古宙初形成超大陆 **Kenorland**；
- **超级地幔柱事件 (Superplume Event)** = 短命的地幔事件（≈100 Ma），大量超级地幔柱与较小地幔柱撞击岩石圈底部。
- Kenorland 形成后，**板块运动速度骤降**，**岩浆活动也随之大幅下降**（两张曲线图：上=板块速度，下=岩浆活动）。

**因果链（Palaeoproterozoic "Snowball Earth"）**：

```
缓慢移动的超大陆
  → 热量在大陆之下累积（无法在洋中脊等板块边界散失）
  → 大陆的热隆升 (thermal uplift)
    ＋
  全球洋底岩浆活动低
  → 洋底热沉降 (thermal subsidence)、大洋加深
  → 净效应：大陆相对海平面出露 (emergence of continents above sea level)，相对海平面下降
  → 暴露的超克拉通 (supercraton) 面积大 → 强烈的化学风化与剥蚀
  → 风化消耗大气 CO₂（drawdown）＋ 岩浆活动低（CO₂ 补给少）
  → 大气 CO₂ 骤降
  → 降温
```

**叠加因素（与 GOE 耦合）**：
```
GOE：蓝细菌产氧 → 大气氧化性增强
  → 氧化并移除大气中的 CH₄（甲烷是比 CO₂ 更强的温室气体）
  → 进一步强化降温
```

**最终**：`超大陆效应 + 弱太阳辐射（年轻太阳）` → **Snowball Earth（雪球地球）**

**⚠️ 老师的诚实声明（转写独有，非常重要）**：
> 「这是一个漂亮工整的故事，我也喜欢好故事……但**我必须对你们诚实：这套说法有很大一部分并没有被证实 (large parts of this are not substantiated)**。」具体两个软肋：
> 1. **岩浆活动是否真的下降到这个论证所要求的程度，论证并不很有说服力**；
> 2. **这套说法无法令人满意地解释古元古代冰期的「幕式 (episodic)」特征**——岩石记录显示它**不是一次事件，而是一系列事件**。
>
> 但老师同时表态：**冰期与 GOE 在时间上的重合是「一支冒烟的枪 (a massive smoking gun)」**——「我不相信这么强的巧合」，所以两者之间**一定有强联系**。

#### 4. 古气候指标 (Palaeoclimate indicators)

- 元古宙岩石**比太古宙保存得广泛得多**（即使被"煮"过、变形过），因此我们**有足够的岩石记录去找古气候指标**。
- 指标类型：**沉积岩中的沉积构造与岩相、化石、地球化学指标、同位素记录**。
- 幻灯片给出的两个对照实例：
  - **风成砂岩 (Aeolian sandstone)** ——例：美国犹他州 Navajo Sandstone → 指示**沙漠、干旱**环境；
  - **杂砾岩 / 冰碛岩 (Diamictite / glacial tillite)** ——例：**2.3 Ga 加拿大地盾 (Canadian Shield)** → 指示**冰川**环境。

**因果链**：

```
  → 火山活动复苏 (renewed volcanic activity)
  → 大气 CO₂ 上升
  → 退出冰期状态（exit from glacial conditions）
  → ……大陆继续离散 (the continents dispersed)
```

### （五）超大陆为什么必然裂解：造山带的一生 (The life and times of an orogenic belt)

🔑 **老师的金句**：**超大陆是「自身成功的受害者 (victims of their own success)」——它们本质上是不稳定的。**

**五步模型（这是本周最重要的一张卡通图，必须能自己画出来并复述）**：

1. **碰撞增厚 (Thickening during collision)**
   - 两个大陆碰撞时，**地壳与岩石圈地幔同时增厚**。
   - **为什么必然增厚？** 因为**大陆不能俯冲到另一个大陆之下**（陆壳太轻）。两个东西相互挤压又都下不去，就只能**变厚**。
   - 此时的岩石圈是**相对冷而强 (cool, strong)** 的。

2. **热量无法散失 → 岩石圈升温变弱**
   - 加厚的岩石圈盖住了下方的热，热出不去，岩石圈被"闷热"，**强度下降 (weaker)**。

3. **拆沉作用 (Delamination)**
   - 岩石圈根 (lithospheric root) 因**密度大于其下的软流圈 (asthenosphere)** 而**拆离沉落**；
   - 结果：**造山带之下的岩石圈地幔变薄**。

4. **热隆升 (Uplift)**
   - **温热的软流圈上涌取代了被拆掉的冷岩石圈根** → 岩石圈地幔底部与地壳底部温度升高 → **热驱动的隆升**。

5. **重力垮塌 → 陆内裂谷 → 超大陆解体**
   - 地壳被加热后**弱到无法支撑自身重量** → **重力垮塌 (gravitational collapse)** → **地壳伸展与减薄 (crustal extension and thinning)**
   - = **陆内裂谷作用 (intracontinental rifting)** → **超大陆破裂 (breakup)**

**岩石记录中怎么识别这个过程？（两大证据）**
1. **岩墙群 (dyke swarms)** ——伸展相关的岩浆侵入；
2. **裂谷盆地充填 (rift basin fills)** ——从邻近隆起区剥蚀而来的厚层元古宙沉积与火山序列。

### （六）大火成岩省 LIP 与 Kenorland 的裂解 (~2200 Ma 后)

**证据链**：全球各大陆地壳区域都记录到 **~2200 Ma 起大规模火山活动的开始**——这正是**用来给 Kenorland 破裂定年**的依据。

**大火成岩省 (Large Igneous Province, LIP) 的"管道系统"（剖面判读）**：
- **地表**：**溢流玄武岩 (flood basalts)** ——大面积铺开的玄武岩流；
- **地壳与岩石圈地幔深部**：
  - **岩床 (sills)** ——**平行于地层/地表**结晶的侵入体；
  - **岩墙 (dykes)** ——**以某个角度切穿 (cross-cut)** 地层的侵入体。
- **平面视图**：**放射状岩墙群 (radiating dyke swarms)** ——从主侵入体中心向外辐射。
- **岩墙群的定义**：**数以百计**的、**平行或线性排列**的岩墙，**几乎同时侵位**。
- **成因**：与**超级地幔柱 (superplume) 活动**相关。

**LIP 的意义（老师额外强调）**：
- LIP **不是"一座火山喷发"**，而是**全球尺度的、几乎同时发生的巨型岩浆事件**；
- 喷入大气的气体量巨大，导致**地球气候的重大转变**，因此**与显生宙多次大规模灭绝事件相关联**（Week 8+ 会讲）。

**⚠️ 保存学上的关键提醒（转写独有）**：
> 古元古代距今太久，**当时地表的溢流玄武岩早已被剥蚀殆尽**。今天在元古宙记录中我们能看到的，**只有当年深埋在岩石圈地幔与地壳深部的"管道"部分——岩墙与岩床**。「务必意识到我们实际看的是哪一部分。」
> - **苏格兰西北部的 Scourie dykes 正是这套系统的一部分。**

**趣味补充**：**岩墙群在金星 (Venus) 与火星 (Mars) 上也被发现过**。

### （七）中元古代：地球的中年期 (1780–850 Ma) 与「无聊的十亿年」

#### 1. Columbia (Nuna) 的聚合

- **2200 Ma 起**：晚太古宙超克拉通 Kenorland 破裂、大陆离散。
- **2000 Ma 起**：大陆开始**重新汇聚**，出现**活动的俯冲带 (active subduction zones)**，多条大型造山带形成。
  - 幻灯片标注的造山事件年龄：**2.1–2.0 Ga**、**1.9–1.8 Ga**、**1.85 Ga**、**Transamazonian Orogeny（跨亚马逊造山）**。
- **2000–1800 Ma**：**Columbia（又名 Nuna）** 的初始聚合。**到 ~1800 Ma，地球上第一个"真正的超大陆" Columbia 形成**。
  - 全球重建图定格在 **1650 Ma**，展示**碰撞型 (collisional)** 与**增生型 (accretionary)** 造山带的分布。
- **1800–1450 Ma**：更多陆块**增生到 Columbia 的边缘 (periphery)**。
  - ⚠️ 各陆块拼合的**precise 顺序至今是巨大争议 + 大量模拟工作的主题**。

#### 2. 1800 Ma 的 BIF 高峰——一条完整的因果链

```
Columbia 聚合期间大量岩浆活动
  → 大量 CO₂ 泵入大气
  → （变暖，海水溶氧下降等）
  → 海洋再次变为缺氧 (anoxic)
  → 还原铁重新在海洋中积累
  → 1800 Ma 出现 BIF 生产的高峰 (peak in BIF production)
```
🔑 **BIF 的出现 = 海洋缺氧的指示器**——这个反推逻辑在本周被用了三次（太古宙、1800 Ma、新元古代雪球期）。

#### 3. 「无聊的十亿年」The Boring Billion

- **术语来源**：由一位叫 **Holland** 的学者提出，**原本是半开玩笑 (tongue in cheek)**，结果这名字就"粘住"了。
- **含义**：从岩石记录看，这段时间地球处于**相对的环境、演化与岩石圈稳定 (relative environmental, evolutionary and lithospheric stability)**——与前后的古元古代、新元古代形成鲜明对比。
- 幻灯片另一处也称之为 **'Barren Billion'（贫瘠的十亿年）**。
- 🔑 **老师的立场（明确表态）**：「我会主张**中元古代根本一点也不无聊**」——这段大稳定期究竟该叫"无聊"，还是其实是**为新元古代及之后生命大辐射铺路的关键分水岭 (watershed)**，是近年被重新认真思考的问题。

#### 4. 中元古代的气候与海洋化学

- **气候**：Columbia **横跨赤道与温带气候带 (straddled equatorial and temperate climatic zones)**；
- **这个年龄的冰川沉积完全缺失** → 推断**气候与海洋相对温暖**。
- 老师玩笑：「其实是个挺舒服的地方可以回去待着——除了海洋是缺氧的这一点。」

#### 5. 关键谜题：海洋缺氧，为什么 1800 Ma 之后没有 BIF？

**现象**：BIF 记录在 **~1.8 Ga 之后消失**，直到 **~0.8 Ga** 才重新出现。

**答案：硫**
```
海洋不只是缺氧 (anoxic)，还富含硫化物 (sulfidic)
  → 二者兼具 = 「euxinic（欧克辛型／硫化缺氧）」海洋
  → 硫来自陆地的化学风化（有氧大气下的氧化风化把硫释放出来）
  → 海水中可溶的 Fe²⁺ 不再被氧化成赤铁矿，而是与硫结合
  → 沉淀为「沉积黄铁矿 (sedimentary pyrite, FeS₂)」而不是 BIF
```
- **幻灯片标注**：**Sedimentary pyrite (FeS₂) deposition <1800 Ma**；图上标 **dissolved H₂S**。
- 🔑 **本周最漂亮的一个"控制变量"推理**：`缺氧海洋 + 有硫 → 黄铁矿`；`缺氧海洋 + 无硫 → BIF`。这条规则在新元古代雪球期会再用一次（见下文）。

#### 6. Columbia 的裂解与 Rodinia 的聚合

- **1400–1200 Ma：Columbia 裂解**。
  - **证据：伸展相关的镁铁质岩墙群 (mafic dyke swarms)**。
  - 🔑 **课堂问答**：为什么这些岩墙是 **mafic（镁铁质）** 而不是 **felsic（长英质）**？
    → **因为岩浆直接来自地幔 (directly from the mantle)**，而不是来自大陆岩石的部分熔融——如果是熔融陆壳，产物会更 felsic。（老师点评：「记得 Bowen 那一套」——呼应 Week 4 的 Bowen 反应序列。）
- **~1100 Ma 起：重新聚合形成 Rodinia**。碰撞与增生在 **~1000 Ma（约十亿年前）** 结束。
- **Grenville Orogeny 格林维尔造山运动 (1085–985 Ma)**：
  - 形成一条**巨大的碰撞带**，从 **Baltica（波罗的地块）→ Laurentia（劳伦大陆，即北美）→ 整个美洲 → 澳大利亚 → 南极洲**；
  - **规模与今日的喜马拉雅—阿尔卑斯带相当，甚至大得多**；
  - **不同大陆上的别名**：澳大利亚称 **Albany–Fraser belt**，南极洲称 **Bunger Hills**——但**它们是同一条造山带**。
  - ⚠️ **今天看不到当年的山脉地形**（早已剥蚀殆尽）；我们之所以知道它存在，**是因为岩石中保存了那次碰撞的深部变质根 (deep metamorphic roots)**——**今天出露在地表的岩石，当年深埋在地壳内部**。

### （八）新元古代事件 (850–539 Ma)

**四大关键事件（幻灯片列表）**：
1. **Rodinia 的裂解**
2. **冷的深俯冲 (cold deep subduction) 的开启**
3. **第二次氧含量上升 (NOE)**
4. **新元古代冰期（雪球地球）**

#### 1. Rodinia 裂解与 Iapetus 洋的形成

**四阶段时间表（幻灯片）**：
1. **Rodinia 的形成：1100–850 Ma**
2. **Rodinia 的裂解：825–720 Ma**
3. **Pannotia 的形成：~630 Ma**（括号中，表示存在争议）
4. **Pannotia / Rodinia 的裂解：600–580 Ma**

**Iapetus 洋 (Iapetus Ocean)**：
- 随着 **Laurentia（劳伦大陆）** 从 Rodinia 其余部分裂离而张开；
- **留下来的部分被称为 Gondwana（冈瓦纳）**；
- 🔑 **英国地质的关键**：地图上**蓝星 = 苏格兰**，**红星 = 英格兰**——在这次裂解中，**苏格兰跟着 Laurentia 走了，英格兰留在另一侧**，两者"分道扬镳 (went their own merry way)"。这是下周（Week 8）的核心线索。
- **边界类型判读**：Divergent（离散，MOR 洋中脊）、Convergent（汇聚）、Transform（转换）三类。

**为什么"Rodinia 到底什么时候散的"这个争论重要？（不是抠字眼）**
> 人们总在试图判断地球史上的重大事件**彼此是否有因果关联**。如果主张 Rodinia **直到 600–580 Ma 之后才真正裂解**，那么这次裂解就可能**与开启显生宙、引发寒武纪大爆发的重大环境与生物变革相联系**。

#### 2. 元古宙板块构造的演化（**本周最重要的机制性图表**）

**核心命题**：**自 3 Ga 以来地幔持续冷却 (progressively cooled)**；**地幔温度是岩石圈行为的首要控制因素 (prime control)**，它决定了板块构造以何种方式进行。

**三个温度区间（ΔT = 相对今日地幔温度的超出量）**：

| ΔT | 时期 | 岩石圈行为 | 俯冲 | 驱动机制 |
|---|---|---|---|---|
| **ΔT > 200 °C** | 冥古宙、早太古宙 | 岩石圈**很弱**，强烈**内部变形**；大陆板块沿扩张中心**破碎** | **无俯冲**（被抑制） | **上升的地幔柱 (mantle plumes)** 穿透岩石圈；板块随地幔对流"漂移" = **bottom-up 自下而上** |
| **ΔT = 200–100 °C** | **~3200–2500 Ma** | 板块仍弱，因**熔体渗滤 (melt percolation)** 而内部变形 | **俯冲开始**：洋壳可沿**很浅的俯冲带**仰冲到陆壳之下 (under-thrust) | 俯冲驱动，但**浅、热、短命、高度幕式 (shallow, hot, short-lived, episodic)** |
| **ΔT < 100 °C** | **~750 Ma（新元古代）** | 现代样式 | **深俯冲 (deep subduction) 开启**——深达**数百公里** | **俯冲驱动 = top-down 自上而下**，由 **slab pull（板片拉力）** 主导；地幔环流由柱驱动转为俯冲驱动 |

🔑 **两个必须记住的转折点**：
- **~3.2–2.5 Ga**：俯冲**首次启动**（当地幔温度降到高于今日 200 °C 以下时）；
- **~750 Ma**：**现代式深俯冲**启动（地幔温度降到高于今日约 100 °C 时），**恰好与 Rodinia 裂解同时**——「这是板块运动驱动力的一次极其重大的转变，与太古宙相比是巨变」。

#### 3. NOE 新元古代氧化事件 Neoproterozoic Oxygenation Event (800–650 Ma)

**现象**：大气 O₂ **急剧上升**，从现代值的 **10%** 升到 **50%+**。

**争议点（老师明确列出）**：
- 是**突变**还是**渐变**——有争议；
- **上升何时开始**也不清楚；有人主张比 800 Ma **还早 100–200 Ma**（即 800 Ma 时已经到 50% 了）；
- **上升的原因也远未被充分理解**。

**两大可能机制**：

**(A) 构造样式的改变导致大气氧上升（三步链条，幻灯片编号）**
```
1. 深俯冲 (deep subduction) 在裂解中的超大陆边缘开启
  → 2. 阻碍了超大陆之下的地幔对流混合 (impeded convective mixing of the mantle beneath the supercontinent)
  → 3. 形成异常氧化的岩浆 (formation of oxidised magma)
  → 火山喷出的气体更加氧化
  → 由于「火山气体的氧化状态」是大气氧的主要汇 (prime sink) 之一
  → 更氧化的气体不再从大气中夺走氧
  → 大气氧净积累
```

**(B) 隆升山脉 → 强化风化 → 营养输入 → 光合爆发**
```
超大陆高耸 → 高剥蚀速率 → 大量沉积物与营养物质注入海洋
  → 刺激光合作用 (stimulate photosynthesis)
  → O₂ 产生 ＋ 有机碳埋藏 (burial of carbon)
```
- ⚠️ **这里必须注意的张力**：**氧化风化 (oxidative weathering) 本身是大气氧的重大汇**（要消耗氧）。这个论证成立的关键在于：**营养输入带来的光合产氧量，超过了风化过程消耗掉的氧量**——**又是一个"净平衡"论证**。

#### 4. 新元古代雪球地球 (Neoproterozoic Snowball Earth, 720–635 Ma)

**基本描述**：
- 在 **Rodinia 裂解过程中**，发生了**第二轮延长的冰期系列**；
- **冰盖在海平面高度一直延伸到赤道纬度 (ice sheets formed at sea level down to equatorial latitudes)**——这就是「雪球地球」；
- 每次冰期持续**数千万年 (10's Ma)**，之后紧跟着**炎热期**——形成**冷—热循环 (cold-hot cycles)**；
- **800–575 Ma 之间共 2–3 次雪球事件**；命名的冰期包括 **Sturtian（斯图特冰期）** 与 **Marinoan（马林诺冰期，645–635 Ma，英国 Port Askaig Tillite 即属此期）**；
- 🔑 **这些冷热循环被许多人认为为寒武纪生命大爆发铺平了道路 (paved way for the Cambrian explosion)**。

**证据**：
1. **冰成沉积 (glaciogenic deposits) 的全球分布**——图上**蓝星**标出分布点；关键在于这些点**在当时的古地理位置处于赤道**。
2. **冰碛物 (glacial till)**：**分选极差、棱角状的沉积物，由冰直接沉积** (poorly sorted, angular sediment deposited directly by ice)。
3. **坠石 (dropstone)**：冰筏搬运的坠石落入**冰前海相地层 (proglacial marine strata)**——实例：**纳米比亚 Ghaub Formation（高布组）**。
   - 判读要点：坠石会**压弯/刺穿下伏的细粒纹层**，是冰筏作用的判定性证据。
4. **BIF 的重新出现 (~0.8 Ga)**：
   ```
   冰盖覆盖 → 海洋再次缺氧 (anoxic)
     ＋ 冰盖覆盖陆地 → 无法从陆地剥蚀出硫进入海洋
     → 海洋缺氧但「不硫化」
     → 铁不再形成黄铁矿，而是形成 BIF
   ```
   🔑 **这正是中元古代那条规则的镜像应用**——**缺氧 + 有硫 = 黄铁矿；缺氧 + 无硫 = BIF**。

**「硬雪球」vs「雪泥球」之争（老师要求学生自己选边站）**：
- **共识**：赤道纬度存在冰川沉积——**这一点大家不争**。
- **分歧**：**海洋表面本身是否真的完全冻结？**
- **雪泥球 (Slushball Earth) 的证据**：岩石记录显示，**浮冰之下存在一个黑暗、高盐 (dark, briny) 的海洋，被潮汐 (tides) 与来自洋底的地热 (geothermal heat) 持续搅动**。
- 老师原话：「所以你得**自己决定：你是 slushballer 还是 hardballer**。」

#### 5. 雪球地球循环（完整因果闭环，本周最重要的一条链）

**① 触发 (Trigger)**
```
高耸、热浮力的大陆碎块全部分布在热带纬度（温暖、潮湿）
  → 强化的化学风化 (enhanced chemical weathering)
  → 强化的 CO₂ 抽减 (enhanced CO₂ drawdown)
  → 降温
＋ 强化风化 → 营养径流 (nutrient runoff) → 刺激光合作用
  → 藻华 (algal blooms) → 生物死亡后沉降海底被埋藏
  → 把碳锁死（碳汇）→ 进一步抽减 CO₂
  → 持续降温
```

**② 正反馈失控（跨过临界点 tipping point）**
```
冰雪覆盖 → 反照率 (albedo) 上升 → 地面吸收的阳光减少
  → 被冰覆盖的区域对全球平均温度与大气热收支的贡献下降
  → 全球降温 → 更多降雪结冰 → 反照率更高 → ……（正反馈）
  → 极端情形（hardballer 版本）：地球一路冻到赤道
```

**③ 负反馈救场（为什么地球没有永远冻住）**
```
冰期时 → 降水减少 → 侵蚀与风化减少 → CO₂ 消耗大幅下降
＋ 冰盖覆盖地面 → 无碳酸盐埋藏、无光合作用消耗 CO₂
＋ 火山仍在持续向大气泵入 CO₂
  → CO₂ 不断累积，最终「超调 (overshoot)」——可达现今水平的约 350 倍！
```

**④ 失控融化与热室地球**
```
温室增温融冰的速度 > 重启的 CO₂ 抽减降温速度
  → 失控融化 (runaway melting)
  → hot-house Earth（热室地球）
  → 标志性岩石：「盖帽碳酸盐岩 (cap carbonates)」直接覆盖在冰川沉积之上
```

**⑤ 回到冷态并循环**
```
极端风化（酸雨 acid rain）重新抽减 CO₂
  → 热室被冷却
  → 光合作用恢复，进一步把 CO₂ 拉回控制之下
  → 循环可以再来一遍
```

**⑥ 循环何时停止？**
> 只要裂解中的超大陆碎块**还停留在赤道附近**，这个循环就会反复发生——新元古代确实出现了**多次 冷—热—冷—热** 的循环。**直到超大陆彻底裂解并漂离赤道，循环才停止。**

#### 6. 替代假说：高地轴倾角 (High obliquity)

- **今天**：地球自转轴相对于**公转轨道面法线**倾斜 **23½°** → **冷的两极、热的赤道**。
- **假说**：如果过去地轴的**倾角 (obliquity) > 54°**，则会反过来——**热的两极、冷的赤道**。
- 于是**赤道出现冰川沉积就完全不需要"雪球"了**。
- **支持**：能解释新元古代低纬沉积中**观察到的强烈季节性 (strong observed seasonality)**。
- **致命弱点**：**没有明显的机制**能解释倾角如何在**奥陶纪 (Ordovician) 之前**变回今天的值。
- 老师："我喜欢这个想法，就因为一个理由"——它提醒你：**同一组观测（赤道冰川沉积）可以有完全不同的解释框架**。

> 🔑 这个"对照组"极有说服力地反证了：**冰期不是必然的，而是几个变量恰好同时失衡的产物。**

## 三、公式与图表

本周唯一的公式是概念性的氧收支方程，但**图表极多且是考试重点**，逐个梳理判读方法。

### 公式：大气氧收支方程

```
大气氧量的变化率 = 氧的产生速率 − 氧的消耗速率
d[O₂]/dt = production rate − loss rate
```

**符号与性质说明**：
- **production（产生）**：光解作用 (photolysis) + 产氧光合作用 (oxygenic photosynthesis)。**产生速率与现有 O₂ 浓度无关 (independent)**。
- **loss（消耗）**：火山还原性气体（尤其 H₂）、氧化风化 (oxidative weathering)、呼吸作用 (respiration)。**消耗速率取决于可用 O₂ 的多少 (dependent on how much oxygen is available)**——这是一个**负反馈**，也是为什么大气氧能被"缓冲"在某个水平。
- **推论**：要让 O₂ 净上升，只有两条路——**(a) 新的氧源；(b) 消耗过程被饱和或削弱**。GOE 与 NOE 的所有假说都可以归到这两类里。

## 六、易错点 / 重点难点

### A. 概念与数字上的易错点

1. **元古宙的下界是用「冰川沉积」定义的，不是用氧或生命定义的**。虽然 GOE 是元古宙最著名的事件，但 **2420 Ma 这个界线锚定在首次全球分布的冰成沉积上**。

2. **"% of present levels" ≠ "% of atmosphere"**。所有氧含量数字都是**相对现代大气水平 (PAL) 的百分比**。「<0.1%」意思是**不到今天氧含量的千分之一**，而不是"大气里有 0.1% 的氧"。老师在课上专门澄清过这一点（"so we're talking about relative to current levels"）。
   - ⚠️ 幻灯片 Overview 写 "<0.1% → >50%"，转写中老师有一处口误说 "from 1% up to about 50%"。**以幻灯片的 <0.1% 为准**；GOE 期间升至 **1–10% PAL**，NOE 期间从 **10%** 升至 **>50% PAL**。

3. **photolysis（光解）≠ photosynthesis（光合）**。太古宙的氧**增益**来自**水分子被辐射劈开、氢逃逸太空**的光解作用；光合作用是后来才成为主导的。老师口头把这两个词说混过，但幻灯片写的是 photolysis。

4. **BIF ≠ 富氧的证据**。BIF 指示的是"**海洋中有大量还原铁 + 有一定量氧化剂**"。**赤铁矿能在很宽的氧浓度范围沉淀**，因此 BIF 存在**不能**证明海洋高氧。反之，**BIF 的存在通常被用作"海洋（整体）缺氧"的指示器**（因为要维持巨大的溶解 Fe²⁺ 储库，海洋必须整体缺氧）。这个逻辑看似矛盾，关键是**分清"局部有微量氧化剂"与"整体缺氧"**。

5. **BIF 消失的两种截然不同的原因，别混**：
   - **~1.8 Ga 之后消失**：海洋**缺氧但富硫（euxinic）** → 铁去做**黄铁矿**了；
   - **GOE 之后厚层 BIF 减少**：海洋/大气**变氧化**，铁储库被耗尽；
   - **~0.8 Ga 重现**：海洋**又缺氧了（冰盖），但陆地被冰封所以无硫输入** → 铁重新做 **BIF**。
   - 🔑 记忆口诀：**缺氧+有硫 → 黄铁矿；缺氧+无硫 → BIF；有氧 → 红层/赤铁矿在陆上**。

6. **红层出现的年龄是 ~2.3 Ga（23 亿年），不是"两百三十万年"**——转写在这里明显口误说成 "two and a half million years ago"。

7. **GOE 的"滞后时间"是必考点**：产氧光合作用出现 → GOE 之间有 **至少 200 Ma、可能 700 Ma** 的滞后。**解释是"氧被巨大的还原铁储库吸收殆尽"**。别把这个滞后当成"证据不成立"。

8. **甲烷的双重角色**：GOE 中氧的上升**氧化并移除了 CH₄**。CH₄ **是比 CO₂ 更强的温室气体**，因此移除 CH₄ **强化了降温**。也就是说，**大氧化事件本身就是古元古代冰期的一个成因**——这是本周最漂亮的耦合。

9. **"消耗依赖于氧量，产生不依赖于氧量"**——这句非对称性是理解整个氧收支模型的钥匙。写论述题时应明确点出。

10. **subaerial vs submarine 火山与氧的关系方向别搞反**：**陆上 (subaerial) 火山气体还原性更弱（H₂O 多、H₂ 少）→ 消耗大气氧更少 → 有利于氧积累**。海底火山反之。

11. **Kenorland ≠ Columbia**。Kenorland 是**太古宙末形成的超克拉通/第一个超大陆**（2200 Ma 起裂解）；**Columbia (Nuna) 才是老师口中"地球上第一个真正的超大陆"**（1800 Ma 形成）。⚠️ 转写有一处把 "Columbia 的聚合不是一次完成的" 误说成 "kennel land 的聚合"——**1800–1450 Ma 的持续增生说的是 Columbia，不是 Kenorland**。

12. **三个超大陆的顺序与时间必须清楚**：
    ```
    Kenorland（太古宙末形成，2200 Ma 起裂解）
      → 离散
      → Columbia / Nuna（2000–1800 Ma 聚合；1800–1450 Ma 继续增生；1400–1200 Ma 裂解）
      → Rodinia（~1100 Ma 起聚合，~1000 Ma 完成，Grenville 造山 1085–985 Ma；825–720 Ma 裂解）
      → (Pannotia ~630 Ma，存疑) → 600–580 Ma 最终裂解 → 显生宙
    ```

13. **地幔温度的两个阈值别混**：
    - **ΔT 降到 200 °C 以下（~3.2–2.5 Ga）→ 俯冲开始**（但浅、热、幕式）；
    - **ΔT 降到 100 °C 以下（~750 Ma）→ 现代式深俯冲开始**，驱动力从 **plume-driven (bottom-up)** 变为 **subduction/slab-pull-driven (top-down)**。

14. **雪球地球中"正反馈"与"负反馈"必须分清**：
    - **正反馈 = 反照率反馈**（冰越多 → 越冷 → 冰更多），把地球推入冰封；
    - **负反馈 = 碳循环反馈**（冰封 → 风化停止 → 火山 CO₂ 累积 → 变暖），把地球拉出冰封。
    - **没有负反馈，地球会永远冻住**——这是为什么"雪球"没有变成"永久雪球"的答案。

15. **雪球的争议不在"赤道有没有冰川沉积"，而在"海洋表面有没有全冻"**。前者是共识，后者是 hardball vs slushball 之争。

16. **高倾角假说的致命弱点要能说出**：能解释低纬冰川与强季节性，但**没有机制解释倾角如何在奥陶纪前变回 23½°**。

17. **同一造山事件在不同大陆有不同名字**：Grenville（北美）= Albany–Fraser（澳）= Bunger Hills（南极）。写答案时若能点出这一点是加分项。

18. **元古宙的 LIP 我们只能看到"管道"**——地表溢流玄武岩已剥蚀殆尽，保存下来的是**岩墙与岩床**。回答"如何识别超大陆裂解"时要说 **dyke swarms + rift basin fills**，而不是"溢流玄武岩"。

19. **别把太阳光度当成元古宙气候的主控**。太阳光度在**超长时间尺度**上重要，但元古宙的两次冰期发生在**百万—十亿年尺度**上，主控是**反照率（陆块分布）与温室效应（火山）**——**两者都归结到板块构造**。

| pyrite | 黄铁矿 (FeS₂) | 同为氧化还原敏感矿物；在 euxinic 海洋中作为铁的主要沉淀相取代 BIF |
| red beds | 红层 | 含 Fe³⁺ 氧化物胶结物的陆相碎屑沉积岩，~2.3 Ga 首现，GOE 的标志性证据 |
| palaeosol | 古土壤 | 埋藏的古代土壤剖面；其中铁的行为记录当时大气氧含量 |
| evaporitic sulfate / gypsum | 蒸发岩硫酸盐 / 石膏 | 需要氧化条件才能大量形成，GOE 后在浅海丰度增加 |
| MIF (mass-independent fractionation) | 质量无关（硫同位素）分馏 | 需紫外线直达才发生；其终止 (2316±7 Ma) 标志臭氧层的形成 |
| ozone layer | 臭氧层 | 由 O₂ 生成，阻挡有害紫外辐射；GOE 之前不存在 |
| oxygen oasis | 氧绿洲 | GOE 之前浅海中零星的局部富氧微环境 |
| eukaryote | 真核生物 | ~2 Ga 出现多细胞、需氧呼吸的真核生物 |
| redox state | 氧化还原状态 | 描述体系中氧化剂/还原剂相对丰度；本周用于海洋与火山气体 |
| subaerial / submarine volcanism | 陆上 / 海底火山作用 | 陆上火山气体还原性更弱（H₂O 多），消耗大气氧更少 |
| solar luminosity | 太阳光度 | 元古宙期间从约 70% 升至 100% 今日水平 |
| albedo | 反照率 | 地表反射太阳辐射的比例；冰雪覆盖使其升高，构成雪球地球的正反馈 |
| CO₂ drawdown | CO₂ 抽减 | 化学风化与有机碳埋藏把 CO₂ 从大气中移除的过程 |
| chemical weathering | 化学风化 | 消耗大气 CO₂，是元古宙气候的主要制冷机制 |
| Huronian glacial event | 休伦冰期 | 2420–2220 Ma 的古元古代全球冰期，定义元古宙的开始 |
| Huronian Supergroup | 休伦超群 | 北美约 10 km 厚的连续冰川沉积序列，冰期得名于此 |
| Snowball Earth | 雪球地球 | 冰盖在海平面高度延伸至赤道纬度、持续数千万年的极端冰期状态 |
| Slushball Earth | 雪泥球地球 | 认为浮冰之下仍有被潮汐与地热搅动的液态海洋的折中假说 |
| supercontinentality | 超大陆性 | 超大陆存在本身对气候的一系列效应（热隆升、海退、强风化、低火山 CO₂） |
| supercraton | 超克拉通 | 由多个克拉通拼合而成的巨大稳定陆块 |
| thermal uplift / thermal subsidence | 热隆升 / 热沉降 | 地下热量积聚使地表上升 / 岩浆活动减少使洋底冷缩下沉 |
| diamictite / glacial tillite | 杂砾岩 / 冰碛岩 | 分选极差、棱角状、由冰直接沉积的沉积物，冰川环境的判定标志 |
| dropstone | 坠石 | 由冰筏搬运后落入海底细粒沉积中的砾石，会压弯下伏纹层 |
| Ghaub Formation | 高布组 | 纳米比亚的冰前海相地层，含著名坠石实例 |
| aeolian sandstone | 风成砂岩 | 风力搬运堆积的砂岩（如犹他州 Navajo Sandstone），指示干旱沙漠气候 |
| cap carbonate | 盖帽碳酸盐岩 | 直接覆盖在雪球期冰川沉积之上的碳酸盐岩，记录冰后极端热室与超高 CO₂ |
| Sturtian / Marinoan | 斯图特 / 马林诺冰期 | 新元古代两次主要雪球事件（Marinoan 645–635 Ma） |
| obliquity | 地轴倾角 | 今日 23½°；若曾 >54° 则两极热、赤道冷，是雪球地球的替代假说 |
| delamination | 拆沉作用 | 增厚的岩石圈根因密度大于软流圈而脱落沉入地幔 |
| gravitational collapse | 重力垮塌 | 被加热变弱的地壳无法支撑自重而伸展垮塌，导致陆内裂谷 |
| dyke swarm | 岩墙群 | 数百条几乎同时侵位的平行/放射状岩墙，超大陆裂解的关键岩石记录证据 |
| sill | 岩床 | 平行于层面侵位的板状火成岩体 |
| flood basalt | 溢流玄武岩 | 大面积铺开的玄武岩流；元古宙的已被剥蚀殆尽 |
| LIP (large igneous province) | 大火成岩省 | 短时间内形成的巨量岩浆事件，与超级地幔柱及显生宙大灭绝相关 |
| superplume | 超级地幔柱 | 短命（≈100 Ma）的巨型地幔上涌事件，撞击岩石圈底部 |
| mafic / felsic | 镁铁质 / 长英质 | 前者来自地幔直接熔融，后者来自陆壳熔融——判断岩浆源区的关键 |
| Kenorland | 肯诺兰 | 太古宙末形成的第一个超（克拉通）大陆，2200 Ma 起裂解 |
| Columbia (Nuna) | 哥伦比亚（努纳） | 2000–1800 Ma 聚合的"地球第一个真正的超大陆"，1400–1200 Ma 裂解 |
| Rodinia | 罗迪尼亚 | ~1100–1000 Ma 聚合的超大陆，825–720 Ma 裂解，与雪球地球同期 |
| Pannotia | 潘诺西亚 | ~630 Ma 可能存在的短命超大陆，存在与否有争议 |
| Transamazonian Orogeny | 跨亚马逊造山运动 | Columbia 聚合期的重要造山事件之一（2.1–2.0 Ga） |
| Laurentia / Baltica / Gondwana | 劳伦大陆 / 波罗的地块 / 冈瓦纳 | 古大陆名；Laurentia 裂离后留下的部分即 Gondwana |
| Iapetus Ocean | 亚匹特斯洋 | Rodinia 裂解时张开的大洋，苏格兰与英格兰因此分居两侧 |
| boring billion / barren billion | 无聊的十亿年 / 贫瘠的十亿年 | Holland 半开玩笑提出的中元古代别称，指其环境—演化—岩石圈的高度稳定 |
| euxinic | 硫化缺氧的 | 既缺氧又富硫化物的水体状态；使铁沉淀为黄铁矿而非 BIF |
| slab pull | 板片拉力 | 冷密的俯冲板片下沉产生的拉力，现代板块运动的主要驱动力 |
| deep subduction | 深俯冲 | 深达数百公里的现代式俯冲，~750 Ma 随地幔冷却而开启 |
| top-down / bottom-up convection | 自上而下 / 自下而上对流 | 俯冲驱动 vs 地幔柱驱动，两种截然不同的地幔环流模式 |
