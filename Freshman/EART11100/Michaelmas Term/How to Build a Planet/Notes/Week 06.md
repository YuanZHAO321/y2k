## 一、本周主题

本周是 **How to Build a Planet** 十周主线的**第 6 周**，正式进入**按地质年代顺序讲述地球历史**的阶段。前五周依次讲了宇宙起源、恒星与元素合成、地球系统概览、板块构造、矿物与岩石（岩石循环）；从本周起到圣诞节，课程转为**沿地质时间轴推进**：太古宙 (Archean, 本周) → 元古宙 (Proterozoic, Week 7) → 显生宙 (Phanerozoic) → 风化作用与新生代。

老师在开场明确了后半学期的**叙事视角**：
> 「地球的历史有 45 亿年之长，我们必然会略过很多细节，但会努力让你们感受到地球历史上发生的主要事件。我们特别强调**当时地球上存在的环境条件**，以及**地质过程如何影响气候与生命演化**。」

因此本周的内容不是孤立的岩石清单，而是一条**因果链**：
**地球很热 → 无法俯冲，只能盖着一层"停滞盖 (stagnant lid)" → 地幔柱驱动部分熔融 → 造出 TTG 花岗质地壳 → 大陆核 (craton) 与深根 (keel) 形成 → 大陆稳定、露出海面 → 侵蚀产生沉积物 → 无氧海洋+微生物 → 条带状铁建造 (BIF) → 地幔冷却 → 俯冲开始 (~3.0 Ga) → 碰撞造大陆 → 超大陆 (Kenorland) → 大氧化事件前夜**。

**上下文衔接**：
- **上游**：Hadean（冥古宙，由 Maren 讲）——只有矿物 (Jack Hills zircon, 最老约 4.4 Ga)，**没有岩石**。
- **本周起点**：4030 Ma，**岩石记录 (rock record) 开始**。
- **下游预告**：Week 7 元古宙——大氧化事件 (Great Oxidation Event)、雪球地球、元古宙末的第二波 BIF。

### 本周六大关键事件（讲义 "Key events in the Archean"）

1. **岩石记录始于 4030 Ma**（此前只有矿物）。
2. **大部分大陆地壳形成**（现今体积的 **60–70%**）。
3. **第一批大陆稳定化**（stabilised，即变得难以被摧毁）。
4. **构造样式从盖构造 (lid tectonics) 演化为板块构造的早期形式**。
5. **厚层沉积序列**首次沉积于深海与浅海陆架上。
6. **最早的生命出现**（微生物）。
7. **形成了一类此后再未形成过的富铁沉积岩**（BIF）——但它们是**当今世界铁矿的主要来源**。

### 讲义列出的 Learning Objectives（直接对应考点）

学完本课你应当能够：
1. 在世界地图上**识别重要的太古宙岩石产地**；
2. 描绘**大陆增长速率随时间的变化**，并解释为何今天大部分大陆地壳是在太古宙形成的；
3. 描述**地球构造样式在太古宙如何演化**，以及第一批稳定大陆如何形成；
4. 列出**与今日构造样式的关键差异**；
5. 列出**太古宙的主要岩石类型**；
6. 解释**海洋、大气与生命的演化如何导致 BIF 沉积**，并说明**为什么今天不再形成 BIF**。

## 二、核心概念

### 2.1 太古宙的定义与年代学框架

**名称**：**Archean**，来自希腊语「**beginning / origin**（开始、起源）」。

**拼写提醒（老师专门讲了一页）**：
- `Archean` 与 `Archaean` 两种拼法都有（多一个 a）；
- 同理 `Paleo-` 与 `Palaeo-`。
- 老师说：**现代文献主流用不带额外 a 的美式拼法**（Archean, Paleo-），他全程用这一套。考试两种都不算错，但要知道它们是同一个词。

**边界的定义**：

| 边界 | 年龄 | 依据 |
|---|---|---|
| **底界**（Hadean/Archean） | **4031 Ma**（讲义与 ICS 采用值；口头常说 4030 Ma） | **地球上现存最老的岩石** = Acasta 片麻岩的年龄 (4031 ± 3 Ma)。这是一个**以实物岩石定义**的边界。 |
| **顶界**（Archean/Proterozoic） | **2500 Ma** | **第一批全球性冰川沉积物 (first glacial deposits)** 出现 |

**关于顶界的重要澄清（老师口头强调）**：
> 「这**不是说**太古宙期间完全没有冰期，而是说**地球上第一次大规模冰川作用**发生在太古宙末、约 25 亿年前。」

**内部划分的现状**：
- 目前国际地层委员会 (International Commission on Stratigraphy, ICS) 把太古宙**均匀地**切成四个代 (eras)：Eoarchean / Paleoarchean / Mesoarchean / Neoarchean。
- **关键点**：这些界线是**纯粹按数字均分的 (GSSA, 全球标准年龄)，没有真实的地质事件作为"时间标记 (time markers)"**。
- 已有学者提出按具体事件重新划分的方案，将来太古宙内部的分期**很可能改为长度不均等的划分**。老师说：「这项工作还在进行中，我们不深究，只要知道它还没定下来。」

**时间尺度感**：太古宙从 40 亿年前到 25 亿年前，**长达 15 亿年，约占地球 45.67 亿年历史的三分之一**。

### 2.2 到哪里去找太古宙的岩石？

#### （1）首先排除海洋

**「今天海洋中最老的洋壳 < 300 Ma」**——这是本节的第一条铁律。

推理链：
- 洋壳全部是玄武质的，并且不断被**在洋中脊生成、在俯冲带销毁**；
- 洋底年龄图（红=0 Ma → 蓝紫=约 300 Ma）显示，最老的洋壳碎片也只有约 3 亿年；
- **推论**：研究洋中脊玄武岩 (MORB)、洋岛玄武岩等，**对太古宙一无所得**。必须去**大陆**上找。

#### （2）克拉通 (Craton) —— 大陆的"核"

**定义**：**Craton**，希腊语「**strength**（强度、力量）」——**大范围、构造上稳定的大陆岩石圈区域**。

世界大陆地质年代图（太古宙=深红，元古宙=较浅色包围带，显生宙=卡其色）读图要点：

1. **太古宙岩石在每一个大陆上都有出露**——无一例外；
2. **面积很小**——它们只占大陆地壳很小一部分的露头面积。老师直言：「这意味着**我们能拿来研究的信息很有限**。」
3. **总数约 35–40 个小块**；
4. **它们普遍被元古宙岩石所包围**（有时称 "belts" 活动带）。这些元古宙围岩**比太古宙岩石更容易变形**，因此常常强烈褶皱、强烈变质；
5. 克拉通**构造上极其稳定，高度抗改造**——老师的逻辑：「它们能从太古宙保存至今，**按定义就必然极难被再改造**。」

**因果小结**：克拉通 = 大陆的**核 (nuclei)**，因抗变形而保存；它们为什么抗变形，见 2.6 的**克拉通根 (keel)**。

#### （3）早/中/晚太古宙克拉通的分布

读图要点（注意图例花纹 ornaments）：
- **早太古宙（> 3500 Ma，图中黑色）**：极其稀少，只有零星碎块——**澳大利亚、南非、加拿大北部、格陵兰**，可能还有**中国**；
- **中太古宙、晚太古宙**：面积明显多得多。

**结论**：**地球上年龄大于 3500 Ma 的克拉通区域极少**；克拉通主体是中—晚太古宙的。这个观察后面会被用来讨论"是生长慢还是保存差"的问题（见 2.5）。

### 2.3 太古宙的岩石实例（必须记住的地点）

#### （1）Acasta Gneiss Complex —— 地球上最老的岩石

| 项目 | 内容 |
|---|---|
| 位置 | **加拿大西北部，Slave Craton（斯拉夫克拉通）** |
| 年龄 | **4030 – 3580 Ma**；定年样品：**4031 ± 3 Ma 的英云闪长质片麻岩 (tonalitic gneiss)** |
| 岩性 | **高级变质岩——片麻岩 (gneiss)** |
| 原岩 (protolith) | **侵入性长英质火成岩 (intrusive felsic igneous rock)** = **英云闪长岩 (tonalite)** |
| 伴生 | 一些**镁铁质 (mafic) 岩石** = **早期海底玄武质地壳的残余** |
| 野外景观（老师口述） | 加拿大那片地区**非常平坦、非常潮湿、冬天冻得结实，露头不多**，但能找到 |

**片麻岩 (gneiss) 的含义**：**极高级变质岩**——经历过非常高的温度与压力，在变质岩里已接近**压力—温度条件的上限**。所以我们今天看到的**不是原岩**，原岩已被变质作用改造。

**片麻岩的条带 (banding) 是怎么来的？（老师专门解释的易错点）**
> 「它们原本**不是**这样带状的。在变质**重结晶 (recrystallization)** 过程中，矿物按化学性质发生了**偏析 (segregation)**，深色矿物与浅色矿物分别聚集，形成这些细带。」
→ **片麻岩的条带是变质成因的，不是原始沉积层理。**

**英云闪长岩 (Tonalite) 的成分**：
- 富**石英 (quartz)** 和**长石 (feldspar)**——具体是**斜长石 (plagioclase)** + **富钠的碱性长石 (Na-rich alkali feldspar)**；
- 少量**角闪石 (amphibole)** 与**辉石 (pyroxene)**（富 Mg、Fe 的矿物）。

**命名趣闻（老师讲的故事）**：
> 「火成岩的名字都很古怪，通常是**以最早被发现和描述的地点命名**。Tonalite 就来自**奥地利的 Tonal 山谷 (Tonal Valley)**。不用太在意名字，我不会要求你们记住 tonalite 这个词。」

**记忆口诀（老师明确给的）**：
> **把这些岩石想成"花岗岩 + 玄武岩"的混合体**——浅色层原本是 tonalite（本质上就是花岗岩 granite），深色层/深色团块 (pods) 是玄武岩 (basalt)。
> 「所以在太古宙，我们**已经有了今天也能见到的岩石类型**：花岗岩和玄武岩。也许并不令人意外。」

**镁铁质 (mafic) 的含义复习**：mafic = **Mg + Fe 富集**；密度较大；矿物组合就是玄武岩里那些：**橄榄石 (olivine) + 辉石 (pyroxene) + 斜长石 (plagioclase feldspar)**。
**长英质 (felsic) 的含义复习**：富**长石 (feldspar)** 与 **硅 (silica，通常表现为石英)**。

#### （2）英国的太古宙岩石 —— Lewisian Gneiss

| 项目 | 内容 |
|---|---|
| 位置 | **英国西北部苏格兰 (NW Scotland)，赫布里底群岛 (Hebridean Islands)** |
| 名称 | **Lewisian gneiss complex（刘易斯片麻岩杂岩）** |
| 年龄 | **约 3 Ga（30 亿年，中太古宙）** |
| 岩性 | **高级变质岩，片麻岩** |

老师的评论（重要模式识别）：
> 「果不其然，它们**也是**高级变质岩，**也是**片麻岩，看起来跟 40 亿年的加拿大 Acasta 岩石非常相似——同样有浅色的花岗质层和深色的玄武质层与团块。
> **这非常普遍：你无论去哪里看这些极老的太古宙岩石，它们往往都是片麻岩、高级变质岩，且是花岗岩与玄武岩的混合体。**」

#### （3）Isua Supracrustal Belt —— 最老的沉积岩

| 项目 | 内容 |
|---|---|
| 位置 | **格陵兰西南部 (SW Greenland)** |
| 年龄 | **约 3810 – 3800 Ma** |
| 岩性 | **层状碳酸盐岩 (layered carbonate rocks)** |
| 意义 | **目前已知可供研究的最老沉积岩** |

**Supracrustal（表壳岩）的意思**：**在地表或近地表形成的岩石**，覆盖在深部形成的**基底 (basement)** 岩石之上。老师："supra 就是'在上面'，就是位于地壳顶部的那些岩石。"

**争议点 1——层理是不是原生的？**
这些岩石**变形非常强烈**，所以图上看到的"层"**不一定是原始沉积层理**，也可能是构造变形与加热造成的**变质层理**。

**争议点 2——叠层石 (stromatolites) 真伪**
- Isua 带内发现了**小型丘状构造 (mound-like structures)**，**高度仅 1–4 cm**；
- 有人认为这是**叠层石**——即**由蓝细菌 (cyanobacteria) 建造的微生物礁**；
- **主要疑点**：尺寸太小。地质记录中后来的叠层石以及现代叠层石都**大得多**。
- **结论**：**是否为微生物成因仍存疑**，这是"两处有争议的 Isua 叠层石产地"之一。

#### （4）Dresser Formation —— 学界公认的最早宏观化石

| 项目 | 内容 |
|---|---|
| 位置 | **西澳大利亚 Pilbara Craton（皮尔巴拉克拉通/地块）** |
| 层位 | **Dresser Formation** |
| 年龄 | **3490 Ma（约 34.9 亿年）** |
| 化石 | **叠层石 (stromatolites)**，尺度**与现代实例可比** |
| 地位 | **第一批被广泛接受的宏观生命证据 (first macroscopic fossils)** |

**现代类比**：**西澳大利亚的鲨鱼湾 (Shark Bay)** 有活的现代叠层石，是标准对照。

**老师原话**：「大家基本有共识，这就是地球上最古老生命的证据之一。我相信你们在配套课程 (How to Grow a Planet) 里已经讲过了，我们不多说。」

### 2.4 大陆地壳的"生长 vs 保存"问题

这是本周**最重要的方法论段落**——讲义原句：

> **「今天不同年龄的大陆地壳的面积分布，并不直接反映地壳随时间的生长量。」**
> (The aerial extent of continental crust of different ages today does not directly reflect the amount of crustal growth through time.)

#### 问题的提出

老师提出的开放式问题：
- 早期大陆是**很小**（只有那些克拉通核）？
- 还是**很大**（比今天还大，后来变小了）？
- 大陆主要是在**炎热的太古宙**长出来的，还是后来？

#### 一个天真的做法及其结果

**做法**：画一张全球地图，按地壳年龄着色（太古宙=绿 → 新生代=棕），然后**取平均**。
**结果**：**全球大陆地壳的平均年龄约 20 亿年 (2 Ga)**。
**问题**：这个平均值**无法直接翻译成生长史**，因为地壳形成之后还会被**破坏**。

#### 地壳被破坏的两条路径（老师讲得很细，务必掌握）

**路径 A：进入地幔的循环（真正的净损失）**
一块地壳形成后 → 可能成为**造山带 (mountain belt)** 的一部分 → **抬升 (uplift)** → 抬升后**重力上不稳定 (gravitationally unstable)** → **垮塌、侵蚀** → 变成**沉积物 (sediment)** → 河流带入海洋 → 沉积在**洋底** → 洋底最终**俯冲进入地幔** → 沉积物随之被**循环回地球内部**。

**路径 B：地壳内部再循环 (intra-crustal recycling)**
同一块地壳被**深埋** → 高压高温**强烈变质** → 若埋在造山带下、地壳极厚处，可被**熔融** → 形成**全新的火成岩**重新加入地壳。
→ 这块地壳**没有回到地幔**，而是**在大陆地壳内部被再加工**。

**关键结论**：**无论走哪条路，"原来那块地壳"都被摧毁了。**
所以我们看到的是**生长 (creation) 与破坏 (destruction) 的净平衡**，而不是生长本身。

> 老师的现代参照：「就目前我们所能判断的，**现今大陆地壳的破坏速率与形成速率大致相等**——这是我们最好的猜测。」

#### 大陆生长曲线图（Selected crustal growth models）—— 判读方法

**坐标轴**：
- **横轴**：年龄，单位十亿年 (Ga)，从**现今 = 0**（左）到**地球起源 4.5 Ga**（右）；
- **纵轴**：**已存在的大陆地壳百分比 (0–100%)**，其中 **100% = 今天的大陆地壳体积**；
- 图上用**竖虚线**标出**太古宙的起点与终点**，便于读出太古宙期间长了多少。

**两个端元 (end members)**：
| 端元 | 含义 | 需要的地质过程 |
|---|---|---|
| **最上方曲线** | **早太古宙时全部大陆地壳就已存在**，此后再无新地壳形成，体积恒定 | 需要一个**极早期、极高效**的一次性造壳过程 |
| **最下方曲线** | **太古宙结束时几乎没有大陆地壳**，此后以**越来越快**的速率增长（大部分在 2.5 Ga 之后长出） | 需要**近代大幅加速**的造壳过程 |

老师评论：「两个端元差别极大。要解释其中任何一个，你都得设想**与今天已知过程非常不同的、相当激进的地质过程**。」

**两组曲线**：
- **绿色 / 棕色一组**：太古宙末大陆地壳**最多只有约 40%**，此后生长更快；
- **红棕色一组**：太古宙末**超过 50%** 已经存在，此后生长更慢。

**老师的诚实表态与本课立场**：
> 「我不知道哪条对，我也不认为有人知道。我们对太古宙的认识仍然太不确定，无法锁定其中任何一条。**目前主流模型集中在这一条带内：太古宙结束时地球大陆地壳体积的约 60–70% 已经存在。**这就是本节课采用的口径。这仍是一个活跃争论的课题。」

**记忆口径**（讲义两处措辞略有差异，都要知道）：
- Key events 页：「**60–70% 现今体积**」在太古宙形成；
- Summary 页：「**65–70% 的现今大陆地壳在 3.0 Ga 时已就位**」。
→ 核心数字：**太古宙末约 2/3 的大陆地壳已存在**，且主要增长发生在 **3.0 Ga 之前**。

### 2.5 板块构造什么时候开始的？

**讲义原句**：「**关于板块构造何时开始，存在很大的不确定性与分歧。**」

**判断依据 (indicators of plate tectonics)**：
1. **与板块构造环境相关联的岩石序列 (rock sequences)**；
2. **地球化学证据 (geochemistry)**。

**方法论（老师讲得很清楚，是重要的思维方式）**：
> 人们寻找每一种证据的**首次出现时间 (first appearance time)**，然后论证："我今天在板块边界上看到**超高压变质 (ultra-high pressure metamorphism)** 的岩石；我能找到的最老的一例是 0.7 Ga；**所以板块构造一定是从那时开始的**。"

**结果（Korenaga 2013 汇总图）**：不同学者用不同证据给出的起始时间**从 4.2 Ga 一直排到约 1.0 Ga**——横跨 30 多亿年。

**老师的结论**：
> 「首先我们可以说：**我们真的不知道现代板块构造何时开始，至今没有共识。**」
（同时提醒：图上列的那些证据名称"你们不需要记，有些现在还看不懂"。）

**由此引出下一个问题**：**板块构造之前是什么？(What came before plate tectonics?)**

### 2.6 前板块构造时期：停滞盖构造 (Stagnant Lid Tectonics)

#### （1）为什么早期地球很热？（能量来源）

老师列举：
- **吸积 (accretion) 释放的能量**；
- **核幔分离 (core separation) 释放的重力势能**；
- **当时放射性同位素更多**（尚未衰变完），因此**放射性生热更强**。

→ 地球必须把这些热散出去，而**最有效的散热方式是对流 (convection)**。因此地球内部很快发育了**对流环 (convection cells)**，把热量从内部输送到外部散失。

#### （2）从岩浆洋到早期地壳

- 早期地球表面可能是**岩浆洋 (magma ocean)**——表面熔融。老师谨慎补充：「**可能不是全球性的**，未必覆盖整个地球表面，但至少是部分熔融的。」
- 冷却到一定程度后，形成一层**早期地壳**；
- 从证据判断，这层早期地壳是**玄武质的、镁铁质的 (basalt, mafic)**——就是 Acasta 野外照片里混在花岗质中的那些**深色玄武岩**；
- 于是形成结构：**薄的外壳（"皮"）+ 其下的对流环**。热量从深部对流到地壳底面，再**传导 (conduction)** 穿过地壳散失。

#### （3）停滞盖构造的定义

**讲义定义**：
> **Stagnant-lid convection（停滞盖对流）**——一个**不动的、以传导方式冷却的盖层 (immobile, conductively-cooled lid)**，其下的上地幔发育**非稳态对流环 (unsteady convection cells)**。
> 处于这种状态的行星常被称为 **single-lid / one-plate planets（单盖行星 / 单板块行星）**，讲义评价：「这可能是更好的描述。」

**特征关键词**：
- **小波长的地幔对流 (small wavelength mantle convection)**——对流环比今天小得多；
- **早期镁铁质地壳 (early mafic crust)** 覆于上地幔之上；
- **盖子不动**——老师原话：「地球被这层薄壳整个包起来，形成一个盖子，它**什么都不干，就待在那儿**，不像今天的板块那样到处跑。所以它是 stagnant（停滞的）。」

#### （4）水的关键作用（老师重点讲的机制）

**因果链**：
1. 当时地球上**已经有海洋**——水从地球内部**去气 (outgassed)** 出来、**凝结 (condensed)**，在洋壳外形成水层；
2. **水接触洋壳 → 使其水化 (hydration)**——化学蚀变，形成结构中含水的矿物（如**云母 mica、角闪石 amphibole**）；
3. **水化会降低岩石的熔点**——**水起了助熔剂 (flux) 的作用**；
4. → 一旦水被带进这层玄武质"盖"里，**它就能在比无水时更低的温度下熔融**。

这是"为什么停滞盖底部能熔出长英质岩浆"的关键前提。

#### （5）部分熔融与原始大陆的形成（讲义 "Partial melting and protocontinent development"）

**完整机制链（考试重点，务必按顺序记）**：

1. **无深俯冲；地幔环流是"自下而上 (bottom-up)"的**，由**深部地幔与地幔柱 (mantle plumes) 驱动**；
2. **地幔柱数量众多、规模更大、存续时间比现代地幔柱更长**——冷却主要靠上升的地幔柱完成；
3. 地幔柱**撞上停滞盖底部** → **部分熔融** → 产生**镁铁质熔岩（包括科马提岩 komatiites）与镁铁质侵入体**；
4. **洋底高原 (oceanic plateaus) 隆起并高出海平面**，地壳**增厚到 30–40 km**；
5. 加厚的（且已水化的）镁铁质下地壳**再次熔融** → 产生**长英质侵入体**：**TTG = tonalite–trondhjemite–granodiorite（英云闪长岩–奥长花岗岩–花岗闪长岩）**，即**富石英—长石的花岗质岩石**；
6. **TTG 就是最早的长英质大陆地壳，也是太古宙克拉通的主体成分**。

**关于 TTG（老师的态度值得注意）**：
> 「TTG，名字很难听。我把它放在这儿，只是因为**你读任何关于太古宙岩石的文献都几乎一定会碰到 TTG 这个缩写**。别为它烦恼——**它们本质上就是花岗岩**，只是三种花岗质岩石的组合。而它们可能构成了**最早的大陆**——非常小的大陆。」

**部分熔融的化学逻辑（回扣 Bowen 反应系列）**：
> 「如果你部分熔融地幔/岩石，**最先被萃取出来的是长英质组分**——那些低温就熔的东西。还记得几周前的 **Bowen's reaction series** 吗？**硅 (silica) 以及长石的组分——钠 (Na)、铝 (Al)、钾 (K)、钙 (Ca)——最先进入熔体**，这些熔体**有浮力**，会上升，形成花岗质侵入体。」

#### （6）Sagduction（垂向"下垂式俯冲"）—— 太古宙特有

**机制**：
- 熔融**萃取走了轻组分（轻元素）**；
- **残留物 (residue) 因此富铁、富重元素 → 密度大**；
- 密度大的残留物**开始下沉**，在大陆区之下形成**岩石圈滴落体 (lithospheric drips)**；
- 这被称为 **sagduction（下垂作用 / 下坠俯冲）**。

**关键区分（易错点）**：
> **Sagduction 是俯冲的一种早期形式，但被"俯冲"下去的不是板块 (plates)，而是从原始大陆根部"下垂、滴落"回地幔的物质。**

#### （7）克拉通根 / 龙骨 (Cratonic roots / keels) —— 大陆为何能保存数十亿年

**时间**：**中太古宙 (Mid-Archean)，克拉通根/龙骨形成**。

**结构剖面读图（讲义与老师口述）**：
从大洋 → 大陆边缘 → 大陆内部的横剖面：
- 洋壳 → 陆壳；
- **陆壳之下有一个显著增厚的区域 = 大陆龙骨 (continental keel)**；
- 这个增厚区由 **地壳 + 上地幔的一部分** 组成，后者称为**岩石圈地幔 (lithospheric mantle)**。

**地幔的力学二分（老师补充的复习点）**：
| 层 | 力学性质 | 是否对流 |
|---|---|---|
| **软流圈 (asthenosphere)** | 塑性 (plastic) | **对流** |
| **岩石圈地幔 (lithospheric mantle)** | **刚性 (rigid)** | **不对流**，"粘"在大陆地壳底部 |

**厚度对比（数字要记）**：
- **大陆之下的克拉通龙骨：可深达近 300 km**；
- **大洋区域：仅几十 km**。

**为什么龙骨 = 保存的关键（两条独立原因，老师讲得很明确）**：
1. **浮力 (buoyancy)**：龙骨使克拉通**整体偏轻，想浮在地幔之上**，因而不易被拖下去；
2. **难熔性 (refractory)**：**那部分地幔中"可熔的部分"已经被抽走去造大陆了**，剩下的很难再熔化。

**读图要点（克拉通根保存图）**：
- **棕色 = 龙骨/根保存完好的克拉通**；
- **蓝色 = 已丢失龙骨/根的克拉通**；
- **观察**：**根被部分丢失的地方，克拉通面积明显更小**。
- **结论（因果）**：**保住根 → 保住克拉通；丢了根 → 克拉通最终会被消耗掉、不复存在。**

#### （8）中太古宙的大陆漂移、增生与拼合

**讲义原句（核心因果）**：
> **太古宙的岩石圈不够刚性，无法承受深俯冲（没有板片拉力 slab pull）。**
> **上涌地幔柱的外流 (outflow) 推挤克拉通龙骨，使它们发生漂移。**
> **SCLM（次大陆岩石圈地幔）的形成提供了一个"可以被水平地幔流推动的把手"→ 从而驱动侧向运动 → 地体增生与拼合 (terrane accretion and amalgamation)。**

**构造图案**：
- 两个拼合的 **TTG 地体（图中粉色）**，其上覆盖**玄武岩（绿色）**，形成**穹隆—龙骨构造 (dome and keel structure)**；
- 强烈变形的 **TTG 片麻岩**；
- 洋底高原地壳（绿色）+ 新的 TTG 岩浆（黄色）；
- **致密的下地壳（蓝色）** + **裂陷与扩张 (rifting and spreading)**；
- 图上箭头标注**地体运动方向**。

**老师的口述版演化序列（次阶段图）**：
> 早期形成的克拉通 → 其下建立深部 SCLM 根 → 这些**小克拉通开始互相合并、互相碰撞** → 旁边有新克拉通区正在发育（新的岩石圈地幔根开始建立，红色符号表示正在熔融）→ **地壳被抬升到海平面之上** → **可以开始被侵蚀** → **沉积物被输送进海盆**。

### 2.7 太阳系中的构造样式谱系（Tectonic styles in the solar system）

**这是一张"演化谱系图"，判读方法（老师逐格讲解）**：

**坐标轴**：
- **纵轴（或一个方向）**：**岩石圈厚度与强度**——从「**无岩石圈 / 弱 (no lithosphere, weak)**」到「**厚岩石圈 / 强 (thick lithosphere, strong)**」；
- **横轴**：**时间**——从「**早期，条件炎热 (early, hot)**」到「**晚期，条件寒冷 (late, cold)**」。

**演化序列（顺序要记）**：

| 阶段 | 状态 | 太阳系类比 |
|---|---|---|
| 1 | **岩浆洋 (magma ocean)** | 极早期地球 |
| 2 | **早期停滞盖 (early stagnant lid)**：玄武质盖层，下部可能有部分熔融；熔体偶尔突破盖层形成**管道状构造 → 热管 (heat pipes)** | （类比木卫一 Io 式的热管散热） |
| 3 | **太古宙：滴落体 + 地幔柱 (drips and plumes)**，即 **sagduction** 阶段 | **太古宙地球；金星 (Venus)** |
| 4 | **现代板块构造** | **现今地球**（老师说"我们目前处在 3 与 5 之间") |
| 5 | **固定板块 + 固定地幔柱 (fixed plates and fixed plumes)**：地幔柱长期固定上涌，大陆根开始被**拆沉 (delamination)** | **火星 (Mars)** |
| 6 | **最终停滞盖 (late stagnant lid)**：行星彻底冷却、地幔近乎固结，**整个系统锁死** | 已冷却死亡的行星 |

**注意**：老师明确说 **地球尚未到达第 5 阶段**——「这是我们**还没有到达的**下一阶段，我们认为那是**火星上**的构造样式。」

#### 金星 (Venus)：太古宙地球的类比

讲义标题即：**「Venus: an analogue for the Archean Earth」**——基于金星停滞盖构造模型来类比太古宙构造。

**为什么金星是好类比（老师列的四条）**：
1. **大小与地球相近**；
2. **与太阳距离相近**；
3. **是岩质行星，成分很可能与地球相同**；
4. **金星表面年龄约 300 Ma 到 1 Ga**——**再造表面速率 (resurfacing rate) 与地球类似**；
5. 另有证据显示金星**低地区域可能存在一些小型构造块体 (small tectonic blocks)**——有人把它们类比为太古宙地球上的构造。

### 2.8 俯冲的开始（约 3.0 Ga）—— 本周的转折点

**讲义核心命题（加粗原句）**：
> **「到 3000 Ma 时，地幔已充分冷却，使岩石圈具备了足够的强度与刚性，俯冲才成为可能。」**

#### 支持"俯冲约在 3.0 Ga 开始"的关键证据（五条，重点背）

1. **大陆地壳形成速率放缓**（实为**破坏速率上升**）；
2. **地壳再循环的同位素证据**——**岩浆锆石 (magmatic zircons) 的 Rb-Sr、Hf、氧同位素比值**；
3. **TTG 花岗质岩的体积增加**；
4. **花岗岩由富 Na 型向富 K 型的相对转变**（Na-rich → K-rich granites）；
5. **大陆地壳成分由镁铁质向中性/长英质转变**。

#### 关于第 5 条的定量证据（数字要记）

| 时期 | 上部大陆地壳 **MgO 含量** |
|---|---|
| **早太古宙**（镁铁质上地壳） | **> 11 wt%** |
| **太古宙—元古宙界线附近**（已接近现代成分） | **~4 wt%** |
| **现今** | **2–3 wt%** |

**讲义结论**：早太古宙的**镁铁质上部大陆地壳被逐渐替换为长英质上部大陆地壳**，并在**太古宙—元古宙界线前后达到与今天大致相同的平均成分**。

#### 老师对生长曲线拐点的因果解读（极重要的思维方式）

读那条蓝色的大陆体积曲线：**3.0 Ga 之前梯度较陡（快速增长），3.0 Ga 处出现拐点 (inflection)，之后梯度变缓**。

老师提出的关键问句：
> 「**是"生长速率"变慢了，还是出现了一种"新的破坏地壳的方式"？**
> 人们提出：**这正是俯冲开始的时刻**——俯冲是一种**高效得多的地壳破坏方式**。所以实际上是**破坏速率上升**，从而**压低了大陆地壳的净增长率**。」

→ **这就是"现代板块构造大约在 30 亿年前的太古宙开始"的论证。**

#### 通往现代板块构造之路（讲义 "The road to modern plate tectonics"）

按时间顺序：
1. **冥古宙 / 早太古宙**：**俯冲被抑制**，岩浆作用由**上升地幔柱**驱动，地幔柱"**渗透 (percolated) 岩石圈**"；
2. **地幔冷却 → 岩石圈强度与刚性增加 → 俯冲成为可能**；
3. **早期俯冲很可能是幕式的、短命的 (episodic and short-lived)**——**因果链**：**板片弱 (weak slabs，因为地幔更热、板片更热更易弯曲) → 早期板片断离 (early slab break-off) → 失去板片拉力 (loss of slab-pull) → 俯冲停止**；
4. **造山带的构造样式变化很大**，取决于**变形单元的热状态 (thermal state)**；
5. **俯冲增强了大陆碰撞 → 造出更大的大陆**。

#### 岩石类型饼图的演化（读图要点）

| 时期 | 主导岩石 |
|---|---|
| **早太古宙** | **科马提岩 (komatiite) + 玄武岩 (basalt) + 花岗岩 (granite/TTG)** 三分 |
| **晚太古宙** | **以花岗质岩石为绝对主导**；**科马提岩基本不再形成** |

**因果**：地球已冷却到**部分熔融过程再也造不出科马提岩**的程度。

### 2.9 科马提岩 (Komatiite) —— 太古宙的"温度计"

> 转写稿中被自动识别成 "Camartyite / chromatite / chermatiite"，正确拼写是 **komatiite**。

| 项目 | 内容 |
|---|---|
| 命名 | 以地点命名——**南非的 Komati（科马提）河**，最早在那里被描述 |
| 类型 | **超镁铁质 (ultramafic)** 火山岩 |
| 时代 | **太古宙常见，太古宙之后基本消失** |
| 标志结构 | **鬣刺结构 (spinifex texture)**——**辉石 (pyroxene) 与橄榄石 (olivine) 的细长针状晶体** |
| 名字来源 | 因形似**澳大利亚的一种草 "spinifex"**（鬣刺草）而得名 |
| 关键化学 | **MgO > 11 wt%**（普通玄武岩仅约 3–4 wt%） |

**为什么科马提岩是关键证据（完整因果链，必考级别）**：

1. **Mg 是难熔的 (refractory)**；
2. 复习：**橄榄石 (olivine) 有富铁与富镁两个端元**；
3. **富镁橄榄石 (Mg-rich olivine) 的熔点极高——需要超过 1500 °C 才能熔化**；
4. 相比之下，**普通玄武岩约在 1200 °C 熔融**（Mg 少、Fe 多，熔点低）；
5. → **要熔出科马提岩，地幔必须非常热（> 1500 °C 级别）**；
6. → **太古宙之后不再出现科马提岩，说明地幔已经冷却，再也无法产生这种岩浆。**

**老师的双向论证（很漂亮的逻辑，值得学）**：
> 「我们**认为**地幔是热的，是因为有那么多能量来源在加热它。
> 我们**知道**它是热的，是因为**只有热地幔才能解释太古宙科马提岩的存在**。」

### 2.10 太古宙的沉积作用

#### 因果起点

**讲义链条**：
**发育深而有浮力的克拉通根 → 大陆变"硬" (stiffened) → 能够露出海平面 (emerge above sea level) 并支撑山脉 → 山脉被侵蚀 → 大量碎屑沉积物 (clastic sediments) 输入海洋 → 大陆为数千米厚的沉积台地序列 (sedimentary platform successions) 与浅而稳定的大陆架 (continental shelves) 提供了基底。**

#### 太古宙沉积岩类型（五大类，要记全）

| 类型 | 说明 |
|---|---|
| **火山成因单元 (Volcanogenic units)** | **火山碎屑岩 (volcaniclastics) 与熔岩 (lavas)** |
| **杂砂岩 (Greywackes)** | **砂与泥的混合物**，来自火山区的侵蚀产物（老师："greywacke 是个老名字，本质就是砂岩+泥岩的混合"） |
| **石英岩 (Quartzites)** | **结构成熟、富石英的砂岩，经重结晶** |
| **碳酸盐岩 (Carbonates)** | **以白云质 (dolomitic) 为主 = 化学成因 (chemogenic)**；**较晚才出现石灰岩 (limestone) = 生物成因 (biogenic)** |
| **燧石 (Chert) 与条带状铁建造 (BIFs, ironstones)** | **Chert = 非晶质二氧化硅 (amorphous silica)** |

#### 沉积物体积随时间变化图（读图要点）

**坐标**：纵轴 = 单位时间内各类沉积物的体积（可理解为**任一时刻各类沉积物的比例**）；横轴 = 从现今 0 到 4 Ga（太古宙起点）。

**判读结论**：
- **太古宙最初期：几乎全部沉积物都是火山成因的**（火山碎屑岩与熔岩）；
- **约 3 Ga 板块构造启动后：沉积物类型开始多样化**——出现杂砂岩、石英岩、白云岩/石灰岩，以及 **BIF**。

**因果**：**沉积物多样性的出现 = 大陆露出水面 + 侵蚀 + 板块构造启动 的直接后果。**

### 2.11 沉积物中的铁矿物

**背景事实**：**许多沉积岩含有百分之几的铁**——这正是沉积岩中常见的**黄、褐、红色**的来源。

| 矿物 | 化学式 | 类别 | 要点（老师口头补充） |
|---|---|---|---|
| **赤铁矿 Haematite/Hematite** | **Fe₂O₃** | 氧化物 | **最常见的铁氧化物**；BIF 中灰色/金属光泽层 |
| **磁铁矿 Magnetite** | **Fe₃O₄** | 氧化物 | **有磁性**；**铁同时以 Fe²⁺ 和 Fe³⁺ 两种氧化态存在** |
| **针铁矿 Goethite** | **FeO·OH** | 氢氧化物（羟基氧化物） | **通常不是原生矿物**，一般由**赤铁矿等既有铁矿物风化而成** |
| **黄铁矿 Pyrite** | **FeS₂** | 硫化物 | 即"**愚人金 (fool's gold)**"，漂亮的**黄色立方体** |
| **绿脱石/铁蛇纹石 Greenalite** | **Fe₂₋₃(Si₂O₅)(OH)₄** | **含水硅酸盐** | 因**常呈绿色**得名；**也可含两种氧化态的铁** |
| **菱铁矿 Siderite** | **FeCO₃** | 碳酸盐 | **成岩 (diagenetic) 成因**；**褐色** |

#### 什么是铁石 (ironstone)？

**定义（数字要记）**：**含铁量 > 15 wt% 的岩石就是 ironstone**，可作为**铁矿资源被开采**。

**四种形态（讲义列举 + 老师解释）**：
1. **富黄铁矿泥岩 (pyrite-rich mudstone)**；
2. **鲕状铁石 (oolitic ironstone)**——**鲕粒 (ooids/oolites)** 是**毫米级的小圆粒**，形成机制：**在近岸环境中被波浪与潮汐来回滚动**，在滚动中不断吸附铁质，形成**具同心层的圆形颗粒**；
3. **铁石结核 (ironstone concretion)**——**通常是次生的，在岩石的成岩作用 (diagenesis) 期间形成**；
4. **条带状铁建造 (Banded Iron Formation, BIF)**。

#### 红土 (Laterites) —— 另一类铁矿

- **富铁氧化物的土壤**（主要是 "**limonite 褐铁矿**"，即混合的**铁氢氧化物**）；
- **成因**：**富铁火成岩的强烈化学风化**；
- **环境**：**湿热的热带地区**，所有**可溶组分都被带走**，只留下**残余的富铁氧化物沉积**；
- **今日实例**：**巴西、西非**；
- **可作为铁资源开采，但重要性远不及 BIF**。

### 2.12 条带状铁建造 (Banded Iron Formations, BIFs) —— 本周压轴

#### （1）基本事实（数字密集，重点）

| 项目 | 内容 |
|---|---|
| **时代** | **全部是前寒武纪的 (all Precambrian)**；**主要集中在 3500 – 1900 Ma** |
| **条带尺度** | **毫米级**——每条带只有几毫米厚 |
| **深色/灰色金属光泽层** | **赤铁矿 (hematite)**；另一实例中**黑色层富磁铁矿 (magnetite)** |
| **浅色/黄色/橙红色层** | **主要是二氧化硅——但不是石英，而是非晶质的燧石 (chert)**；红色部分还混有其他富铁矿物 |
| **含铁量** | **20–30 wt% Fe**（远超 ironstone 的 15% 门槛） |
| **规模** | **厚可达数百米甚至数千米；面积可覆盖数千平方公里** |
| **经济地位** | **约占当今全球铁产量的 60%** |
| **全球分布** | **澳大利亚、南美、北美**等地都有大型矿床 |
| **现代类比** | **没有——今天地球上没有任何等价物在形成** |

**Chert 的关键说明（老师强调的易错点）**：
> 「那不是石英 (quartz)，是**非晶质形态的二氧化硅，叫 chert（燧石）**。**它不是结晶质的，是非晶质的，有点像玻璃**——**没有确定的晶体结构**。」

**资源含义（老师的警告）**：
> 「作为一种资源，**一旦我们把它们采完，就没有了**。它们不会再生成，在可预见的地质时间内地球上也不会有新的形成。」

#### （2）沉积环境的判读（负证据的用法，方法论要点）

**观察到的**：
- 形成于**沉积环境**，形成**大范围的层**；
- **看不到任何浅水沉积构造**；
- **没有由流水或波浪形成的构造 (no current or wave generated structures)**；
- **没有鲕粒 (no ooids)** → 说明**不是在有波浪作用的地方形成的**。

**推论（讲义原句）**：
> **它们沉积于浪基面 (wave base) 之下，水深 > 200 m。**
> 老师补充："**不算真正的深水，但肯定超过 200 米。**"

**沉积于何处**：**燧石与铁矿物沉淀在广阔的大陆架或浅海盆地上。**

#### （3）为什么 BIF 必须意味着"无氧海洋"（核心化学）

**关键事实**：
> **Fe²⁺ 在水中的溶解度比 Fe³⁺ 高出几个数量级 (orders of magnitude)。**

**推理链**：
1. **BIF 厚层堆积 → 海洋中必须曾有巨量的溶解铁**；
2. **海水要能大量溶铁，铁就必须以 Fe²⁺（亚铁）形式存在**；
3. **只要它变成 Fe³⁺（高价铁），就会立刻沉淀成铁矿物**；
4. → **必须让海洋保持还原状态**。

**实现方式（两条，讲义明确列出）**：
- **(a) 完全无氧的海洋 (oxygen-free ocean)**；或
- **(b) 分层的海洋 (stratified ocean)**——**下层缺氧含铁，上层含氧**。

**讲义/老师的升华**：
> 「所以 **BIF 立刻告诉了我们地球大气与海洋的氧化状态**——因为我们必须有办法让这么多铁溶解在水里，又必须在某个时刻把它沉淀出来。」
→ **BIF 是"用沉积岩反推古大气成分"的经典案例。**

#### （4）铁从哪里来？（两个来源，可以并存）

**来源 1：海底热液喷口 / 海底火山作用 (hydrothermal vents, volcanic)**

- **hydrothermal = 热水**；机制：岩浆靠近海底 → 海水下渗、循环、被加热 → **富集金属** → 从喷口**重新排入海洋，携带溶解态的铁**；
- **支持证据（重要的读图推理）**：把 **BIF 的丰度作为时间的函数**画出来（横轴 4 Ga → 1.5 Ga），会发现**BIF 的形成是"脉冲式的 (pulsed)"**——有些时期数量陡增，有些时期很少；
- **解释**：**地球的火山活动强度并非恒定**。**火山活动强 → 输入海洋的铁多 → BIF 多；火山活动平静 → 输入铁少 → BIF 少。**
- **讲义原句**：「铁的主要来源是**海底火山活动**，因此这些脉冲反映了**火山活动增强的时期**。」

**来源 2：大陆岩石的深度风化 (deep weathering of continental rocks)**

- **前提条件**：**当时大气中几乎没有氧**（老师："**如果当时有任何氧，铁就会变成 Fe³⁺，根本运不到海里，会立刻就地沉淀成富铁矿物**"）；
- **附加机制（讲义特有）**：当时**大气 CO₂ 含量更高** → **更高的 CO₂ 分压降低了地表水的 pH** → **提高了铁的淋滤 (leaching) 与搬运效率**；
- → **缺氧大气 → 风化释放的 Fe²⁺ 能以溶解态被河流搬运到海洋。**

**老师明确说明**：
> 「当然，**这两个过程完全可能同时在运行**。不必非此即彼。」

#### （5）Fe²⁺ 如何被氧化？—— 两种微生物机制

**共同点**：**两者都涉及光合作用 (photosynthesis)**——把**光能转化为化学能**以进行代谢。

**机制 A：不产氧的亚铁氧化型光合作用 (Anoxygenic Fe²⁺-oxidizing photosynthesis)**

- **在厌氧 (anaerobic) 条件下由细菌进行**；
- **反应式（讲义原文，含 OCR 断裂，整理后）**：

```
4Fe²⁺(aq) + CO₂ + 4H⁺ + light  →  CH₂O + 4Fe³⁺(aq) + H₂O
```

- **机制本质**：**Fe²⁺（亚铁离子）被直接氧化，充当电子供体 (electron donor)**；
- **不产生氧气 (no oxygen produced)**；
- **是氧化还原反应 (redox reaction)**，**释放少量能量供微生物代谢使用**；
- **空间结构（老师讲的卡通图）**：海底喷口向海水注入 Fe²⁺ → 在某个**光线仍能穿透的深度**存在一个界面，**微生物在此聚集，光合作用沿这条界面进行** → **绝大部分铁在这个深度就被处理掉了，很少能到达海面** → 红点表示沉淀出的铁矿物；
- **这个界面叫做「化学跃层 (chemocline)」**。

**机制 B：蓝细菌驱动的产氧光合作用 (Cyanobacterially driven O₂ production)**

- **反应式**：

```
H₂O + CO₂ + light  →  CH₂O + O₂
```

- **O₂ 是产氧光合作用的"废产物 (waste product)"**；
- **氧化铁的过程是非生物的 (abiotic)**：**独立地，氧与海水中的 Fe²⁺ 结合，生成三价铁的氧化物/氢氧化物沉淀**；
- **空间结构**：形成一条 **氧化还原跃层 (redoxcline)**——**Fe³⁺ 与 Fe²⁺ 沿这条界面分开**：下方是 Fe²⁺，**一旦遇到氧就被氧化并作为铁氧化物沉淀下来**；
- **时间标记**：**蓝细菌 (Cyanobacteria) 约 2750 Ma 出现**（讲义图注）。

**符号说明（老师专门澄清的易错点，很重要）**：
> 「在这类方程式里，你会看到**有机质——糖类、碳水化合物——被写成 CH₂O（甲醛 formaldehyde）**。**这不表示真的产生了甲醛**，它只是**最简单的有机分子，用来代表'可以产生有机分子'这件事**。」

**哪个机制更主流？**
老师："**目前我不知道有没有公认的偏好**。两个过程完全可能在太古宙的不同时段都运行过。但显然，**蓝细菌的出现大概是在中太古宙**（之后 B 机制才可能）。"

#### （6）BIF 形成的完整时序（讲义 "Formation of BIFs"）

1. **太古宙早期**：**缺氧海洋中，由不产氧光养生物 (anoxygenic phototrophs) 氧化 Fe²⁺**；
2. **蓝细菌出现之后**：**Fe²⁺ 的非生物氧化 (abiotic oxidation) 成为主导**；
3. **海洋浅水区的氧含量开始上升**；
4. **铁被氧化成不溶的 Fe³⁺ 化合物，作为赤铁矿 Fe₂O₃ 沉淀在海底**。

#### （7）BIF 的终结与大氧化事件 (Great Oxidation Event) —— 因果关键

**讲义原句（这是本周最重要的一条因果链）**：
> **「铁的氧化消耗掉了所有的氧——直到海水中的铁被'用完'为止，大气中的氧含量才开始上升（大氧化事件）。此后，铁在大陆上被氧化。」**

**展开理解**：
- 蓝细菌产的氧**并没有直接进入大气**，而是**被海水中巨量的 Fe²⁺ 当作"氧汇 (oxygen sink)"消耗掉**；
- **只有当海洋中的铁被消耗殆尽**，产出的氧才有富余积累到大气中；
- → **大氧化事件 (GOE)，约 2 Ga**（下周 Maren 详讲）；
- → **此后铁只能以 Fe³⁺ 存在，无法再以溶解态搬运**；
- → **BIF 停止形成，取而代之的是大陆上的红层 (continental red beds)**——含**氧化态铁**的红色岩石。

**老师原话**：「大约 20 亿年前，BIF 消亡，我们开始看到**大陆红层**。铁以红色岩石的形式**保存在大陆上**。」

#### （8）海洋化学状态随时间的演化（读图要点，重点图）

| 时期 | 海洋状态 |
|---|---|
| **太古宙 (Archean)** | **大体缺氧 (anoxic)、富铁 (ferruginous)** → **BIF 大量形成** |
| **元古宙 (Proterozoic)** | **仍然缺氧，但变为富硫 (sulphur-rich / sulfidic, euxinic)** |
| **元古宙末** | **短暂回到富铁缺氧状态 → 又出现一小段 BIF 沉积期** |
| **显生宙 (Phanerozoic) 开始，约 600 Ma** | **海洋才真正达到含氧 (oxic) 状态** |

**老师对元古宙末那一小段 BIF 复活的说明**：
> 「这与当时存在的一些**相当不寻常的条件**有关，**Maren 下周讲元古宙时可能会讲到**。」
（对应知识点：**雪球地球 Snowball Earth** 造成海洋重新分层缺氧。）

**为什么今天不可能形成 BIF（一句话回答，考试标准答案）**：
> **因为今天地壳与海洋中的铁绝大部分都以 Fe³⁺ 形式存在，不溶于水，无法在海洋中积累到形成 BIF 所需的浓度。**

### 2.13 大陆的组装：晚太古宙的超大陆问题

**主流说法**：晚太古宙时，各大陆可能**已拼合成一个超大陆**，例如 **Kenorland（肯诺兰），2750 – 2500 Ma**。

**两种替代观点（讲义列出）**：
1. **基于独特地质特征**：不是一个超大陆，而是**三个独立的大陆——Vaalbara、Superia、Nunavutia**；
2. **基于古地磁 (palaeomagnetic) 证据**：存在一个**单一、稳定的超大陆 Protopangaea（原始泛大陆），2700 – 600 Ma**。

> 老师在课上说："**大陆配置这一页我就跳过了**"——所以这一节属于**知道即可、不是重点**的内容，但名词要认识。

## 三、公式与图表

本课几乎没有计算，但**图表极多**，以下是必须掌握的判读要点。

### 3.1 反应式汇总

**(1) 不产氧的亚铁氧化型光合作用（anoxygenic photosynthesis）**

```
4Fe²⁺(aq) + CO₂ + 4H⁺ + light  →  CH₂O + 4Fe³⁺(aq) + H₂O
```

| 符号 | 含义 |
|---|---|
| `Fe²⁺(aq)` | 溶解态亚铁离子，**电子供体 (electron donor)**，**高溶解度** |
| `CO₂` | 碳源 |
| `light` | 能量来源（光合作用） |
| `CH₂O` | **有机质的代表性简写**（形式上是甲醛），**不代表真的产生甲醛** |
| `Fe³⁺(aq)` | 三价铁，**溶解度极低，会立即沉淀** |

**特征**：**不产生 O₂**；是**生物直接介导**的氧化。

**(2) 产氧光合作用（oxygenic photosynthesis, cyanobacteria）**

```
H₂O + CO₂ + light  →  CH₂O + O₂
```

**特征**：**O₂ 是废产物**；铁的氧化随后由**非生物过程 (abiotic)** 完成：`O₂ + Fe²⁺ → 三价铁氧化物/氢氧化物沉淀`。

### 3.2 必须记住的关键矿物化学式

| 矿物 | 化学式 |
|---|---|
| 赤铁矿 Haematite | **Fe₂O₃** |
| 磁铁矿 Magnetite | **Fe₃O₄** |
| 针铁矿 Goethite | **FeO·OH** |
| 黄铁矿 Pyrite | **FeS₂** |
| 绿脱石 Greenalite | **Fe₂₋₃(Si₂O₅)(OH)₄** |
| 菱铁矿 Siderite | **FeCO₃** |

> 「在你脑子里想象：**一个对流环在这样转，把地幔的热物质以地幔柱的形式带上来**……它**撞到停滞盖的底部**，而**这层盖的水化部分开始熔融**——那就是图上粉色的部分。**这些熔体有浮力，会上升，形成花岗质侵入体。地壳因此开始增厚**，向下压着底部的玄武质层，**甚至升出了早期海洋的水面，地表出现火山活动**。」

### 4.7 课后学生提问与老师的完整口头复述（极好的复习稿）

> 「你有了小小的大陆形成。**原始盖层的底部发生熔融，把轻元素抽走送进了上覆地壳。但底部因此变得很致密——比其下方的物质还密——因为轻元素都被抽走了。所以它开始下沉，形成一个个滴落体掉下去。这就是俯冲的一种早期形式，叫 sagduction（下垂式俯冲），因为它是'垂'下去的。**
> **然后这些小大陆被表层的对流带着到处移动。最终它们互相撞在一起，形成我们今天看到的那些更大的早期克拉通——我们今天看到的克拉通，就是当时那些小大陆的拼合体 (amalgamation)。**
> **它们进而形成更大的大陆块。最终事情开始变得更像现代俯冲：物质被迫下沉到这些大陆之下——因为这些大陆极难被摧毁，所以任何朝它们过来的东西都只能被迫往下走。**」

## 六、易错点 / 重点难点

1. **最老的"矿物" vs 最老的"岩石"**：Jack Hills 锆石约 **4.4 Ga（矿物，冥古宙）**；Acasta 片麻岩 **4031 Ma（岩石）**。**太古宙底界用的是岩石，不是矿物。**

2. **片麻岩的条带不是沉积层理**：它是**变质重结晶过程中矿物按化学性质偏析**形成的。同理，Isua 表壳岩的"层"到底是原生沉积层理还是变质层理，**本身就是争议点**。

3. **今天的太古宙露头面积 ≠ 当时的大陆面积**。中间隔着**保存与破坏**：俯冲进入地幔 vs **地壳内部再循环 (intra-crustal recycling)**。**这两条路径都摧毁原有地壳，但只有前者是净损失出大陆系统。**

4. **3.0 Ga 拐点的正确解读**：**不是生长变慢了，而是破坏变快了**（俯冲这个高效销毁机制上线）。写答案时要说"净增长率下降"而非"造壳变慢"。

5. **Sagduction ≠ Subduction**：sagduction **下沉的是大陆根部的致密残留物（滴落体）**，不是刚性板块；**没有板片拉力 (slab pull)**。

6. **早期俯冲为什么会"熄火"**：地幔更热 → **板片更热更弱 → 早期板片断离 (slab break-off) → 失去 slab pull → 俯冲停止**。所以早期俯冲是**幕式的、短命的**。

7. **Fe²⁺ 与 Fe³⁺ 的溶解度差异是整个 BIF 故事的化学枢纽**：**Fe²⁺ 溶解度比 Fe³⁺ 高几个数量级**。所有推理（无氧海洋、无氧大气、红层出现）都从这一条推出来。

8. **蓝细菌产的氧一开始去哪了？**——**被海水中的 Fe²⁺ 吃掉了**。**只有等海洋中的铁被"用完"，氧才能在大气中积累 → 大氧化事件。**这是本周最容易被问的因果题。

9. **BIF 中的白色/黄色层是 chert 不是 quartz**——**非晶质 (amorphous) 二氧化硅，没有晶体结构，像玻璃**。

10. **Ironstone 的定义门槛是 15 wt% Fe**；**BIF 含铁 20–30 wt%**；**别把这两个数字弄混**。

11. **BIF 的沉积深度靠"负证据"确定**：**没有波浪/水流构造、没有鲕粒 → 浪基面以下 → > 200 m**。这是"从缺失的构造反推环境"的典型题型。

12. **科马提岩为何是"地幔温度计"**：**MgO > 11 wt%**，**富镁橄榄石需 > 1500 °C 才熔**（普通玄武岩约 1200 °C）→ **必须有极热的地幔**；**太古宙之后消失 = 地幔已冷却**。

13. **停滞盖 (stagnant lid) 出现在演化序列的两端**：**早期停滞盖（热，薄弱盖层）** 与 **最终停滞盖（行星彻底冷却、锁死）** 是**完全不同的两个阶段**，不要混为一谈。

14. **地球目前不在"火星阶段"**：火星的"固定板块 + 固定地幔柱"是**地球尚未到达**的下一阶段。

15. **拼写与名称**：Archean/Archaean 同义；**Craton = 希腊语"强度"**；**Archean = 希腊语"起源"**；**Komatiite 来自南非 Komati 河**；**Spinifex 是澳大利亚的一种草**；**Tonalite 来自奥地利 Tonal 山谷**。

16. **元古宙末还有第二波 BIF**（对应雪球地球造成的海洋重新缺氧富铁），**不要以为 BIF 在 1.9 Ga 后就绝对没有了**。海洋直到约 **600 Ma（显生宙开始）才真正变为含氧**。

| **Heat pipe** | 热管 | 早期停滞盖阶段，部分熔体突破盖层形成的管状通道式散热结构。 |
| **Sagduction** | 下垂式俯冲 / 下坠作用 | 熔融残留物因密度大而从原始大陆根部下滴回地幔；是俯冲的早期替代形式，**没有板块、没有 slab pull**。 |
| **Lithospheric drip** | 岩石圈滴落体 | Sagduction 过程中沉入地幔的致密岩石圈团块。 |
| **Slab pull** | 板片拉力 | 俯冲板片自身重力提供的驱动力；太古宙岩石圈太弱，无法提供。 |
| **Slab break-off** | 板片断离 | 热而弱的早期俯冲板片易于断裂脱落，导致俯冲失去动力而停止。 |
| **Delamination** | 拆沉作用 | 大陆根部被剥离并沉入地幔（对应"固定板块+固定地幔柱"阶段，如火星）。 |
| **Terrane accretion / amalgamation** | 地体增生 / 拼合 | 小陆块互相碰撞合并形成更大克拉通的过程。 |
| **Dome and keel structure** | 穹隆—龙骨构造 | 太古宙特征构造：TTG 地体拼合并被玄武岩覆盖形成的穹隆与下凹相间图案。 |
| **Kenorland** | 肯诺兰 | 晚太古宙可能存在的超大陆，2750–2500 Ma。 |
| **Vaalbara / Superia / Nunavutia** | 瓦尔巴拉 / 苏必利亚 / 努纳武提亚 | 替代观点中晚太古宙的三个独立大陆。 |
| **Protopangaea** | 原始泛大陆 | 基于古地磁提出的单一稳定超大陆，2700–600 Ma。 |
| **Intra-crustal recycling** | 地壳内部再循环 | 已有地壳被深埋、变质、重熔并形成新火成岩重新加入地壳（未回到地幔）。 |
| **Greywacke** | 杂砂岩 | 砂与泥的混合沉积岩，多来自火山区侵蚀产物。 |
| **Quartzite** | 石英岩 | 结构成熟、富石英并经重结晶的砂岩。 |
| **Volcaniclastic** | 火山碎屑岩 | 由火山碎屑组成的沉积岩；太古宙初期沉积物几乎全是此类与熔岩。 |
| **Chemogenic / Biogenic** | 化学成因 / 生物成因 | 太古宙碳酸盐以白云质化学成因为主，石灰岩（生物成因）较晚出现。 |
| **Chert** | 燧石 | **非晶质 (amorphous) 二氧化硅**，无晶体结构，构成 BIF 的浅色层。 |
| **Haematite / Hematite** | 赤铁矿 | Fe₂O₃，最常见的铁氧化物，BIF 深灰金属光泽层的主要成分。 |
| **Magnetite** | 磁铁矿 | Fe₃O₄，有磁性，铁同时以 Fe²⁺ 与 Fe³⁺ 存在。 |
| **Goethite** | 针铁矿 | FeO·OH，铁的羟基氧化物，通常由既有铁矿物风化次生形成。 |
| **Pyrite** | 黄铁矿 | FeS₂，"愚人金"，黄色立方晶体，铁的硫化物。 |
| **Greenalite** | 绿脱石（铁蛇纹石） | Fe₂₋₃(Si₂O₅)(OH)₄，含水富铁硅酸盐，常呈绿色，含两种氧化态铁。 |
| **Siderite** | 菱铁矿 | FeCO₃，铁的碳酸盐，成岩成因，褐色。 |
| **Limonite** | 褐铁矿 | 混合的铁氢氧化物，红土 (laterite) 的主要成分。 |
| **Ironstone** | 铁石 | **含铁 > 15 wt%** 的岩石，可作为铁矿开采。 |
| **Ooid / Oolite** | 鲕粒 / 鲕状岩 | 近岸波浪潮汐反复滚动形成的毫米级同心层圆粒；**BIF 中没有鲕粒 → 说明是深水沉积**。 |
| **Concretion** | 结核 | 成岩作用期间在岩石内部次生形成的矿物团块。 |
| **Laterite** | 红土 | 湿热热带地区强烈化学淋滤后残留的富铁氧化物土壤，如巴西、西非。 |
| **Banded Iron Formation (BIF)** | 条带状铁建造 | 前寒武纪（主要 3500–1900 Ma）的毫米级赤铁矿/磁铁矿与燧石互层岩石，含铁 20–30 wt%，占全球铁产量约 60%，**今天不再形成**。 |
| **Wave base** | 浪基面 | 波浪扰动的最大深度；BIF 沉积于其下，即 > 200 m。 |
| **Chemocline** | 化学跃层 | 海洋中的化学界面；不产氧光合微生物在此聚集氧化 Fe²⁺。 |
| **Redoxcline** | 氧化还原跃层 | 分隔 Fe²⁺ 与 Fe³⁺（还原区与氧化区）的界面。 |
| **Anoxygenic photosynthesis** | 不产氧光合作用 | 厌氧细菌以 Fe²⁺ 为电子供体的光合作用，**不产 O₂**。 |
| **Oxygenic photosynthesis** | 产氧光合作用 | 蓝细菌的光合作用，H₂O + CO₂ + light → CH₂O + O₂，**O₂ 是废产物**。 |
| **Electron donor** | 电子供体 | 氧化还原反应中提供电子的物质；此处为 Fe²⁺。 |
| **Anoxic / Oxic / Ferruginous / Sulfidic** | 缺氧 / 含氧 / 富铁 / 富硫（的） | 描述海水氧化还原与化学状态：太古宙缺氧富铁 → 元古宙缺氧富硫 → 约 600 Ma 才含氧。 |
| **Great Oxidation Event (GOE)** | 大氧化事件 | 约 2 Ga，海洋铁被消耗殆尽后大气氧含量显著上升的事件；此后 BIF 停止、大陆红层出现。 |
| **Continental red beds** | 大陆红层 | GOE 之后在大陆上形成的含氧化铁（Fe³⁺）红色沉积岩。 |
| **Korenaga (2013)** | 科雷纳加 (2013) | 汇总板块构造起始时间各家意见的文献，估计从 4.2 Ga 到 1.0 Ga 不等。 |
| **Venus as Archean analogue** | 金星作为太古宙类比 | 金星大小、日距、成分与地球相近，表面年龄 300 Ma–1 Ga，低地存在小型构造块体，被用作太古宙停滞盖构造的类比。 |
