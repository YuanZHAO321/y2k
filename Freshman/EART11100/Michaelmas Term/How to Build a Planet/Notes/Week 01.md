## 二、核心概念

### 2.1 Λ-CDM 模型（大爆炸宇宙学标准模型）

**Λ-CDM = Lambda + Cold Dark Matter**，是当前大爆炸宇宙学的**标准模型 (The Standard Model)**，包含三种成分：

1. **Λ（宇宙学常数, cosmological constant）** —— 与**暗能量 (dark energy)** 相联系；
2. **CDM（冷暗物质, cold dark matter）**；
3. **普通物质 (ordinary / normal matter)**。

**Λ 的历史来源（老师讲的故事，很重要）**：
爱因斯坦 (Albert Einstein, 1879–1955) 提出广义相对论场方程后，把方程应用到整个宇宙，发现**方程给出的宇宙在坍缩 (collapsing)**。这对爱因斯坦是个"不令人满意的结果"——他希望宇宙是**稳定、固定的**（既不膨胀也不收缩）。于是他**人为引入了宇宙学常数 Λ**，作为一种"阻止宇宙坍缩的力"。

**Λ 的现代含义**：随着认识加深，我们现在知道除了普通物质和普通能量/力之外，还存在暗能量和冷暗物质。**Λ 实质上就是暗能量**——它不仅阻止宇宙坍缩，而且正是**驱动宇宙当前加速膨胀**的东西。

**为什么需要暗物质**：我们在宇宙中观测到的**引力效应**，无法仅用普通物质之间的相互作用来解释。必须存在别的东西在帮助**定义宇宙的结构**。暗物质的分布控制着所有恒星和星系在空间中的相互位置关系。

### 2.2 大爆炸 (The Big Bang), t = 0 s

- "大爆炸之前"，宇宙中**所有的物质、能量、光和空间**都被压缩在一个**不可思议地小、热、致密的点**中，这个点被称为**奇点 (singularity)**。老师补充：这个点是**亚原子尺度的，比中子或质子还小**。
- 某种**扰动 (perturbation)** 引发了巨大的"宇宙爆炸"。
- 空间、时间、能量、物质**同时在各处开始膨胀**。
- 时间的当前最佳估计：**13797 Ma = 13.797 十亿年 = 宇宙年龄**。（Ma = million years，百万年）

> 讲义原句：宇宙最初那些炽热致密的时刻被描述为 "The Big Bang"。

### 2.3 命名的问题："The Big Bang" 这个名字是误导性的

**关键概念**：**大爆炸理论讲的是宇宙的"演化 (evolution)"，而不是"创生 (creation)"**。

**名字的由来（老师强调的故事）**：
- **Fred Hoyle (1915–2001)**，英国天文学家，是他造出了 "The Big Bang" 这个短语。
- 讽刺的是：**Hoyle 本人反对大爆炸理论**，他支持**稳恒态宇宙 (steady state universe)**。他是带着**轻蔑 (dismissively)** 的态度这样称呼它的。
- 但这个词就这样**留了下来 (stuck)**。
- Hoyle 的真正学术贡献是**提出了恒星核合成理论 (stellar nucleosynthesis)**——下周会详细讲他的工作。

**老师反复强调的最重要澄清**：
> **「The Big Bang was neither big nor was it a bang.」（大爆炸既不"大"，也不是"爆炸"。）**

那种"从一个点发生巨大爆炸、然后所有东西被抛射到空间中去"的图像是**错误的**，应当避免。正确的图像是：

> **空间本身的拉伸 (a stretching of space itself)**，而**不是**某个东西**膨胀进入已有的空间中**。因为当时**根本没有空间**——空间本身必须被形成、被膨胀出来，才能让物体去占据。

### 2.4 葡萄干面团类比 (Raisin dough analogy)

这是本课解释空间膨胀的核心类比，出现了**两次**（讲膨胀本质时、讲哈勃定律时），必须掌握：

- 一团面团里混着葡萄干。
- **葡萄干 = 宇宙中的物体**（行星、恒星、星系，随你怎么想）。
- **面团 = 空间**，填充在物体之间。
- 把面团放进烤箱，面团发起来：**葡萄干本身不膨胀**（行星、恒星、星系大小不变），**但它们之间的空间在拉伸**。

**推论 1（我们自己不膨胀）**：我们和地球**不会**膨胀，因为它们被**强得多的力**束缚在一起——**引力和原子间的力**。膨胀的只是它们之间的空间。

**推论 2（哈勃定律的直观来源，老师用了具体数字）**：
设有三颗葡萄干，A 在原点，B 距 A **5 cm**，C 距 A **10 cm**。把面团从 **20 cm** 膨胀到 **40 cm**（即放大 2 倍）：
- B 与 A 的距离增加了 **5 cm**；
- C 与 A 的距离增加了 **10 cm**。

→ **越远的物体，退行速度越快**。膨胀的量正比于物体的距离。这就是哈勃定律的几何本质。

### 2.5 红移 (Redshift) —— 证据一

**观测来源**：**哈勃超深场 (Hubble Ultra Deep Field)**。哈勃望远镜**连续 10 天盯着同一片天空**。曝光时间越长，就能看到那片天区中**越来越多非常暗弱的天体**。

**关键观测**：那些**暗的（因而更远的）天体，其光谱偏红**。

→ 离我们**越远的星系，红移越显著**。

### 2.6 多普勒效应 (Doppler effect) —— 理解红移的类比

老师用**声波**来铺垫（这是 pre-reading 的内容）：

**静止情形**：一辆停着的急救车拉着警笛（"na-na nina" 的声音），声音以波的形式传播。**波峰之间的距离 = 波长 λ (lambda)**。车静止时，从任何位置听到的声音都一样——波长间隔相同，单位时间内到达的波峰数量相同。

**运动情形（车迎面驶来）**：车以**相同频率**发射声波，但因为车在动，**每一个脉冲的发出位置都比前一个更靠近观察者**。净效果是**波被压缩 → 波长减小 → 频率升高 → 音调 (pitch) 变高**。

**运动情形（车驶离）**：**波被拉伸 → 波长增加 → 频率降低 → 音调变低**。

**类推到光**：光也有波动性质。压缩或拉伸光的波长会改变其频率与波长。
- 星系**远离**我们 → 波长变长 → 向**红端**移动（**redshift**）；
- 星系**朝向**我们运动 → 波长变短 → 向**蓝端**移动（**blueshift**）。

**⚠️ 老师明确的重大澄清（易错点）**：
> **多普勒效应并不是理解宇宙学红移的完全准确方式。**因为**不是星系在运动，而是空间在膨胀**。

讲义原文表述：
> 「Doppler redshift is due to the light source moving relative to the observer, **BUT** astronomical redshifts are '**expansion redshifts**' due to the expansion of space itself.」

净效果上，星系确实表现为**被加速远离我们**，从而给出红移；但机制不同。

**电磁波谱要点**：
- 频率从左（高）到右（低），波长从左（短）到右（长）。
- **可见光波段：约 400 – 700 nm**（这是需要记的数字）。
- 关系式：**λ = c / f**，c = 真空中光速。

### 2.7 哈勃定律 (Hubble's Law) —— 膨胀的定量化

**Edwin Hubble (1889–1953)**：首先做出观测测量、证明宇宙在膨胀的天文学家。

**Henrietta Swan Leavitt (1868–1921)**：做了大量支持哈勃定律的**恒星观测工作**。她的贡献是基于**亮度（绝对亮度与视亮度）**的距离估算方法。

**用来测距的"标准烛光"天体**：
- **造父变星 (Cepheid Stars)**
- 螺旋星系 (Spiral Galaxies)
- 椭圆星系 (Elliptical Galaxies)
- 超新星 (Supernovae)

**哈勃定律**：

$$v = H_0 \, d$$

- **v** = 视速度 / 退行速度 (apparent speed, recessional velocity)
- **H₀** = **哈勃常数**，下标 0 表示**当今的**哈勃常数（老师强调：它是**会随时间变化的**）
- **d** = 距离

图上：纵轴是红移（可当作退行速度），横轴是距离（单位：百万秒差距 Mpc）。不同距离的天体落在**一条线性趋势线**上，**H₀ 就是这条线的斜率**。

**⚠️ 适用范围（老师特别指出）**：这个线性关系只在**红移 z < 0.2** 时成立。对更遥远的天体，该定律会失效。

**H₀ 的数值与"哈勃张力 (Hubble tension)"**：

| 测量方 | 方法 | H₀ 值 |
|---|---|---|
| **NASA & ESA — Gaia + Hubble** | 基于**造父变星**测量，反映**近邻宇宙** | **73.5 km s⁻¹ Mpc⁻¹** |
| **ESA Planck 任务** | 基于**宇宙微波背景辐射 (CMB)** 的模型，反映**大爆炸后 380,000 年的遥远原初宇宙** | **67.0 km s⁻¹ Mpc⁻¹** |

老师课上的口径：数值目前仍有争议，范围大约从 **74** 到 **65–67**，「**我们真正需要记住的就是哈勃常数约等于 70**」。

**这个差异说明什么**：
1. **物理含义**：早期宇宙的哈勃常数**更小** → 宇宙一直在膨胀，而且**膨胀速率随时间在增大**（加速膨胀）。
2. 讲义留下的开放问题：**「Could there be new physics underlying the foundations of the universe?」**（宇宙的基础之下是否存在新物理？）

**单位换算（老师专门做的直观化，很重要）**：
- 70 km s⁻¹ Mpc⁻¹ ≈ **20 km s⁻¹ per million light years**
- 即：一个距地球 **100 万光年**的星系，以 **20 km/s** 退行；
- **200 万光年** → **40 km/s**；
- **300 万光年** → **60 km/s**。
- 膨胀速率随着往宇宙深处走而增大。

### 2.8 由哈勃常数推算宇宙年龄（哈勃时间, Hubble time）

这是本周**唯一需要会推导的定量内容**，老师在课后又对提问的学生完整讲了一遍：

**推导**：

$$t = \frac{d}{v} \quad \text{（时间 = 距离 ÷ 速度）}$$

代入哈勃定律 $v = H_0 d$：

$$t = \frac{d}{H_0 d} = \frac{1}{H_0}$$

**距离项 d 消掉了**，得到 **t = 1/H₀**，这称为**哈勃时间 (Hubble time)**。

**数值计算（讲义给的完整式）**：

$$t = \frac{1}{H_0} = \frac{1}{71} \times 3.09 \times 10^{19}\ \text{s} = 4.3521127 \times 10^{17}\ \text{s} = 13.8\ \text{Ga}$$

其中 **3.09 × 10¹⁹** 是 **1 Mpc 对应的公里数**（做单位换算用），H₀ 取 **71 km s⁻¹ Mpc⁻¹**。得到秒数后再换算成年，即得 **≈ 13.8 Ga（十亿年）**。

> ⚠️ 转写稿此处口误说成 "13.8 million years"，**正确答案是 13.8 billion years (13.8 Ga)**，与讲义的 13797 Ma 一致。

### 2.9 基本粒子与四种基本力（理解各纪元的前置知识）

**三类基本粒子 (elementary particles)**——老师说「你们真正需要知道的是这三个」：

| 类别 | 说明 | 例子 |
|---|---|---|
| **夸克 (Quarks)** | 基本粒子，物质的主要组成成分；是**最早出现的有质量形式** | up, down 等（老师说命名不必记） |
| **轻子 (Leptons)** | 最"轻"的粒子；作用是**抵消强子的电荷** | **电子 (electrons)** |
| **玻色子 (Bosons)** | 一类奇特的基本粒子，能在其他基本粒子之间**交换电磁力**，因此又叫**"力粒子" (force particles)**；也能赋予质量 | **光子 (photon)**——最著名的玻色子，光的基本粒子，**无电荷、无质量**；**希格斯玻色子 (Higgs boson)** |

**强子 (Hadrons)**——注意：**强子不是基本粒子**，而是**复合粒子 (composite particles)**，由**两个或更多夸克**构成。我们熟悉的强子包括**质子 (protons)、中子 (neutrons)、原子核 (atomic nuclei)**——它们是**最重的物质形式**。

**形成次序的一个关键点（老师特意点出）**：
> 我们是**先形成了原子核，之后才形成电子**（Hadron Epoch 在 Lepton Epoch 之前）。因为强子带电，需要轻子来中和电荷。

**四种基本力 (four fundamental forces)**，按作用尺度与强度：

| 力 | 作用尺度 | 说明 |
|---|---|---|
| **强力 (Strong force)** | 原子尺度 (atomic scale) | **最强** |
| **电磁力 (Electromagnetic force)** | 原子与分子尺度，也在更大尺度以电场磁场形式存在 | |
| **弱力 (Weak force)** | 原子尺度 | 控制**原子的放射性衰变 (radioactive decay)** |
| **引力 (Gravity)** | 整个宇宙尺度——行星、恒星、星系的运动 | **最弱** |

**核心逻辑**：**每一个纪元 (epoch) 的开始，都以其中一种力的分离 (separation) 为标志。**

### 2.10 大爆炸后的纪元序列（本周的时间主线，必须记顺序）

⚠️ 时间轴是**对数刻度 (logarithmic scale)**——因为极早期发生了大量事情。老师提醒不要被视觉比例误导。

**总线索**：从奇点开始，宇宙持续**膨胀并冷却 (expansion and cooling)**；正是膨胀与冷却，才允许各种基本粒子和复合粒子依次形成。

---

**① 普朗克纪元 (Planck Epoch)：t ≤ 10⁻⁴³ s**

- 起点**不是 0 s，而是 10⁻⁴³ s**，这叫做**普朗克时间 (Planck time)**。
- 老师明确说明：**在 0 到 10⁻⁴³ s 之间，我们根本无法有任何关于"时间"的概念——时间不存在**。所以我们只能从这个点开始讲。
- 此期间**四种力全部统一 (unified) 为一种力**，量级相同、无法区分。
- 这是**量子引力时代 (Era of Quantum Gravity)**，或称**"万有理论" (Theory of Everything)**——量子场与引力场合而为一。
- **完全是推测性理论 (speculative theory)**。

---

**② 大统一纪元 (Grand Unification Epoch)：10⁻⁴³ s < t ≤ 10⁻³⁶ s**

- 标志事件：**引力 (gravitational force) 从其他力中分离出来**。
- **在 10⁻⁴³ s 时**：宇宙直径 **≤ 10⁻³⁵ m**，温度 **10³² K**。
- 老师坦言：我们**完全不知道**此时宇宙的物理性质——是固体？是气体？还是我们无法理解的某种东西？

---

**③ 电弱纪元 (Electroweak Epoch) / 暴胀 (Inflation)：10⁻³⁶ s < t ≤ 10⁻³² s**

- 标志事件：**强相互作用 (strong interaction) 分离出来**。
- **时空的暴胀 (Inflation of space-time)** 发生于此：
  - **暴胀比光速还快！**（老师和讲义都强调了感叹号）
  - 宇宙在 **10⁻³² s 之内**膨胀到**葡萄柚 (grapefruit) 大小**；
  - 直径增大了至少 **10²⁷ 倍**。
- **为什么需要暴胀理论（关键因果）**：用来解释**宇宙的均匀性 (homogeneity)**。宇宙相当均匀；如果没有这次剧烈暴胀，物质分布本会**更加不均匀 (heterogeneous)**。
- 老师明确：**这是理论，尚未被验证 (not been verified)**。

**④ 夸克纪元 (Quark Epoch)：10⁻¹² s < t ≤ 10⁻⁶ s**

- 标志事件：**电磁力与弱力分离** → **四种力至此全部彼此分立 (distinct)**。
- **到 10⁻¹² s 时，宇宙已冷却到 10¹⁵ K**。
- **夸克 (quarks)** 在此期间形成——基本粒子、物质的主要组成成分。
- **但此时夸克还没有相互结合**，只是处在一种**夸克等离子体 (quark plasma / quark-gluon plasma)** 中——**能量太高，夸克无法结合**。
- ✅ **这是理论从"推测"变为"可靠 (secure theory)"的分界线**：因为我们**在正确的能量和温度下做过实验**。
  - **CERN 的 Linac4 线性加速器**、**大型强子对撞机 (LHC)**。
  - LHC 的新配置可达 **6000 GeV（吉电子伏）** 的能量。
  - **在此之前的更早时间，我们没有任何实验或观测能确认理论。**

**⑤ 质量的出现：t ~ 10⁻¹² s —— 希格斯场 (Higgs Field)**

- 宇宙被一种**能量场**所弥漫，即**希格斯场 (Higgs field)**。
- **如果它不存在，所有粒子都将没有质量，并以光速运动。**
- 演化过程：
  - 大爆炸刚过时，**希格斯场为零**；
  - 随着宇宙冷却，**该场自发地生长 (grew spontaneously)**；
  - 其他粒子穿过这个场时，**与希格斯玻色子的相互作用赋予它们质量**。
- **希格斯玻色子 (Higgs Boson)** 是希格斯场中能量涨落的**可见表现形式**。
- **质量的定义**：质量是对力的一种**阻力 (resistance to force)**，或者说是对加速度的阻力（通过 **F = ma**）。
- **Peter Higgs** 提出希格斯玻色子并获**诺贝尔奖**。

**🎉 鸡尾酒会类比 (Cocktail party analogy)** —— 老师讲的完整故事：

> 曾有一位英国前科学部长设立奖金，奖励能解释清楚"希格斯场是什么"的人。

- **满屋子的宾客 = 希格斯场**；
- **屋里的人群簇 (clumps of guests) = 希格斯玻色子**；
- 一位**名人（影星等）走进房间** = 希格斯场被引入、某种重要的新事物发生了；
- 大家都涌过去围住这个名人 → 形成人群簇；
- **另一个粒子（不论是不是名人）穿过房间时被减慢**（遇到阻力），因为它必须**绕过、挤过**这些人群簇；
- 它无法直线穿过，必须绕行 → **需要额外的力去克服** → **由 F = ma，这就意味着存在质量**。
- **它获得了质量 (it has acquired mass)。**

**接续的物理**：随着温度下降，夸克开始在希格斯场的影响下相互作用、被**胶子 (gluons)** 粘在一起，从**夸克-胶子等离子体**过渡到**强子**。

**⑥ 强子纪元 (Hadron Epoch)：10⁻⁶ s < t ≤ 1 s —— 第一批"正常物质"形成**

- **到 10⁻⁶ s 时，宇宙已冷却到 3 × 10¹² K**。
- **第一批正常物质形成：夸克结合形成强子 (hadrons)，包括质子和中子。**
- **质子 (proton) = 2 个 up 夸克 + 1 个 down 夸克**；
- **中子 (neutron) = 1 个 up + 2 个 down 夸克**（老师说命名细节不必记，但图上有标注）。
- 中子和质子进一步结合成**原子核 (atomic nuclei)**。
- **实验前沿**：从夸克-胶子等离子体到强子的这个**相变边界**，全世界有多个实验在研究——**CERN 的 LHC**，以及**Brookhaven 的 RHIC**（相对论重离子对撞机；老师当场说"我忘了 RHIC 是什么，你们可以查一下"）。

**⑦ 轻子纪元 (Lepton Epoch)**

- 电子等轻子形成，用于抵消强子的电荷。（在时间轴上位于强子纪元与光子纪元之间。）

**⑧ 光子纪元 (Photon Epoch)：原初核合成 (Primordial nucleosynthesis)，3 min < t ≤ 20 min**

**⭐ 这是本周最重要的一段，因为它解释了氢、氦、锂的来源，并构成大爆炸理论的第三条观测证据。**

- **到 3 分钟时，宇宙已冷却到 10⁹ K**。
- 质子和中子通过**核聚变 (nuclear fusion)** 结合，形成简单元素：**氢 (hydrogen)、氦 (helium)、锂 (lithium)**。这个过程称为**大爆炸核合成 (Big Bang nucleosynthesis) / 原初核合成**。
- **到约 20 分钟时**，宇宙的温度和密度已降至**核聚变无法继续**的水平，过程停止。

**具体反应（老师逐步讲解的）**：
1. **质子 (proton)** 本质上就是 **H⁺ 离子**，即**氢原子核**（¹H 有 1 个质子）。
2. 质子 + 中子（高能下结合）→ **氘 (deuterium)**，氢的一种**新的稳定同位素**，**同时放出一个 γ 射线 (gamma ray)**。
3. **γ 射线是高能光子 (photon)** → **光正是在这些核反应中开始产生的**。
4. 氘再以各种方式结合 → **氦 (helium)**（氦有两种同位素）。

**同位素概念复习（老师顺带补充）**：**同位素 (isotopes) 是质子数相同、中子数不同的原子种类**。
- **氢是唯一一个给各同位素单独命名的元素**：
  - **氕 (protium)** = ¹H
  - **氘 (deuterium)** = ²H
  - **氚 (tritium)** = ³H

**⭐ 关键结论（考点）**：
- **原初核合成实际上停止在氦-4 (helium-4)，即质量数 4**。
- 由此，**宇宙的元素丰度被设定为：约 75% 氢 + 约 25% 氦 + 微量锂**。
- **这些丰度此后只被后续的恒星核合成 (stellar nucleosynthesis) 轻微改变过。**
- 老师解释因果：虽然太阳和其他恒星至今仍在核心中生成氢和氦，但大爆炸时产生的比例**实在太高**，所以整体丰度**基本没变**。
- **这一丰度观测与大爆炸理论吻合 → 是支持大爆炸理论的直接观测证据。**
- 附带一句：氦-4 的聚变过程**今天仍在太阳中进行**（下周详讲）。

**⑨ 复合 (Recombination) 与透明宇宙的出现：t ~ 380 kyr**

**因果链条（必须理解）**：

1. **之前的状态**：宇宙是由**自由（电离）原子核和电子**组成的**等离子体 (plasma)**，处于**强烈的光子轰击 (intense photon bombardment)** 之下（另外还有暗物质）。
2. **在"复合"之前，光子被困住 (trapped)，宇宙是不透明的 (opaque)**。
   - 老师的形象说法：如果我们能回望这个时期，**宇宙看起来是黑暗的**，没有光能逃逸出来。
3. **气体冷却后**，电子开始与原子核结合，形成**稳定的、电中性的氢原子和氦原子**。
4. **这个中性原子的形成过程称为「复合 (recombination)」**。
5. **一旦复合开始，光子（γ 射线）就能逃逸 → 宇宙变得透明 (transparent)。**
6. **⭐ 复合之后涌出的这些光子，就构成了宇宙微波背景 (Cosmic Microwave Background, CMB)。**

> ⚠️ 转写稿中老师有一处口误说「在大约三分钟后宇宙突然变得透明」——**正确的时间是 ~380 kyr（38 万年）**，讲义的标题也写作 "3 min < t ≤ 380 kyr"（即这个区间的**终点**才是透明化的时刻）。考试写 **380,000 年**。

**⑩ 宇宙微波背景 (Cosmic Microwave Background)：t ~ 380 kyr —— 证据二**

- **⭐ 定义性表述（讲义原话，值得背）**：
  > 「**用光子所能观测到的、最接近大爆炸的时刻，就是"光子退耦 (photon decoupling)"、宇宙变得透明的那一刻。**」

- **观测方式**：用能探测微波辐射的仪器观察天空，会发现**微波辐射从所有方向朝地球射来，并且在整个天空上是均匀的**——不论你看哪里都一样。
- **ESA Planck 探测器**测量了这种辐射的强度，得到了 CMB 图。

**CMB 图的判读**（见第三节）：
- 图是**整个天空（整个空间）**的投影，**颜色代表温度/强度变化**。
- **红/橙色 = 辐射更强 (more intense)、更热的区域**；**蓝色 = 更弥散 (diffuse)、更冷的区域**。
- **CMB 并非完全均匀**——在光子逃逸的那个时期，有些地方光子更集中，有些更弥散。
- **意义**：这告诉我们**大爆炸后 38 万年时宇宙的结构**，很可能与温度有关。这些微小起伏是后来结构形成的种子。

**⭐ 为什么是"微波"？（老师专门回到多普勒/红移来解释，也是学生提问点）**
1. 核反应中产生的是 **γ 射线**——位于电磁波谱的**高频、短波长**端。
2. 但**空间一直在膨胀**，所以这些光子被**红移 (redshifted)**。
3. 在漫长的时间里，它们的**波长被拉伸、频率下降**，从 γ 射线一路移到**微波**波段。
4. **所以：它们起初是高能 γ 光子，而我们现在观测到的是微波。**

**学生问答（转写稿独有）**：
- 问：这些微波以后还会变成射电波 (radio waves) 吗？
- 答：**「如果等得足够久，它们会被拉伸得更长。」**只是到那时能不能探测到、还有没有收音机来探测，是另一回事。

**⑪ 宇宙黑暗时期 (Cosmic Dark Ages)：380 kyr < t < 150 Myr**

- 此时宇宙中**所有的原子和光加起来只占其内容的 <5%**。

**暗物质的丝状结构 (filamentous pattern)**——老师讲的模拟图要点：

### 3.2 图表判读要点

**① 葡萄干面团图 (Raisin dough diagram)**
- 出现两次，第二次标注 "0 minutes" 与 "10 minutes later…"。
- **判读方法**：比较同一颗葡萄干在膨胀前后与参考点的距离增量。**距离翻倍时，增量正比于原始距离** → 越远的星系退行越快。
- **必须能口述的三点**：葡萄干 = 星系（不膨胀）；面团 = 空间（膨胀）；膨胀是空间的拉伸而非物体在空间中运动。

**② 电磁波谱图 (The electromagnetic spectrum)**
- **横轴**：左 = 高频 / 短波长；右 = 低频 / 长波长。
- **可见光段位于中间，400–700 nm**；短波长端为蓝/紫，长波长端为红。
- **判读方法**：光谱线**向右（红端）移动 = 红移 = 光源远离**；**向左（蓝端）移动 = 蓝移 = 光源靠近**。
- γ 射线在最左端（最高频、最短波长），微波和射电在最右端——**CMB 就是从最左端一路红移到右侧微波段**的。

**③ 三距离红移对比图（老师课后专门给一位学生讲过）**
- 图中画有 A、B、C 三个不同距离的观察—星系配置。
- **判读两个同时发生的变化**：
  1. **波长变长**：随距离增大，波峰之间的间距变宽（红移）；
  2. **振幅/强度变小**：随距离增大，光变暗弱 (fainter)、看不清楚。
- 下方彩色光谱条上的**黑色标记线**指示观测到光的位置——距离越大，黑线越往红端移。
- **结论**：**你观测的星系有多远，就决定了红移有多大**。

**④ 哈勃定律图 (Hubble's Law plot)**
- **纵轴** = 红移 / 退行速度（"你不必知道单位"）；**横轴** = 距离（百万秒差距 Mpc）。
- **判读方法**：数据点落在**通过原点的直线**上；**斜率 = H₀**；这就是 y = mx 形式，其中 y = v，x = d，m = H₀。
- **限制条件**：**z < 0.2** 时线性；更远处定律失效。

**⑤ 大爆炸时间轴（"Following the Big Bang" 图）—— 本周最重要的图**
- **横轴 = 时间，对数刻度**（下方标有"秒"，绿色带标"年"）。关键刻度：**10⁻⁴³ s → 10⁻³⁶ s → 10⁻¹² s → 10⁻⁶ s → 1 s → 3 min → 380 kyr**。
- **纪元顺序（务必按序记忆）**：Planck → Grand Unification → Electroweak → Quark → Hadron → Lepton → Photon。
- **黑色曲线 = 宇宙尺度（膨胀）**。判读要点：**膨胀速率不是恒定的**——在电弱纪元起始处有一段**极陡的暴胀 (inflation)**。
- **每个纪元的开始 = 一种力的分离**：Planck 末→引力分离；GUT 末→强力分离；Quark 纪元→电磁力与弱力分离。
- **右侧标注了"speculative theory"（推测性理论）与"secure theory"（可靠理论）的分界**：只有**电磁力/弱力分离**及其之后是 secure，因为 LHC 能达到相应能量与温度做实验；更早期没有实验或观测支撑。

**⑥ 四种力的示意图组**
- 四幅小图分别对应：强力（原子尺度）、电磁力（原子与分子、电磁场）、弱力（放射性衰变，原子尺度）、引力（行星恒星星系运动，宇宙尺度）。

**⑦ 暴胀对比图（"change in size without / with inflation"）**
- 两条曲线对比有无暴胀的宇宙尺度演化。判读：有暴胀者在极短时间内出现**近乎垂直的跃升**（10²⁷ 倍直径增长，10⁻³² s 内，达葡萄柚大小）。

**⑧ 质子/中子的夸克结构图**

**⑨ 温度—重子密度相图 (Phase diagram in the temperature–baryon density plane)**
- 展示**夸克-胶子等离子体**与**强子物质**之间的相变边界。
- 图上标出了正在研究该边界的实验装置：**LHC (CERN)**、**RHIC (Brookhaven)**。

**⑩ 原初核合成反应图**
- 左侧：**红色 = 质子**，**灰色 = 中子**。
- 主线：**p + n → 氘 (D) + γ**；再由氘的多种组合路径 → 氦的两种同位素。
- **判读关键**：所有路径**终止于 helium-4（质量数 4）**——核合成到此为止，这就是为什么宇宙里只有 H、He 和微量 Li。

**⑪ 复合 (recombination) 示意图**
- 左：**自由（电离）核 + 电子的等离子体**，处于强烈光子轰击下（还有暗物质）→ **光子被困，宇宙不透明 (opaque)**。
- 右：**电子被捕获形成中性原子（recombination）** → **宇宙变透明 (transparent)**，光子逃逸。
- 老师描述的颜色变化：**从绿色（等离子体）到黄色（中性原子）**。

**⑫ 宇宙微波背景图 (CMB map)**
- 椭圆投影 = **整个天空 / 整个空间**。
- **颜色 = 温度/强度变化**：**红/橙 = 更强、更热**；**蓝 = 更弥散、更冷**。
- **判读结论**：CMB **不是完全均匀的**——存在微小起伏，反映了 380 kyr 时宇宙的结构（温度不均）。

**⑬ 暗物质分布模拟图**
- 显示**丝状 (filamentous) 网络**，暗区为暗物质，亮区是新星系与恒星的形成处。
- **判读**：**星系形成于丝状结构的交叉点**（暗物质浓度最高处）。

**⑭ 暗物质—星系分布叠加图**
- 尺度标注 **~135 Mpc**；**红色星号 (*) = 银河系 (Milky Way)** 的位置。
- 左：暗物质分布模拟；右：同一区域今天实际观测到的星系分布叠加上去。
- **判读结论**：观测到的星系分布**能被暗物质分布的模拟所解释**——两者的丝状图案吻合。

**⑮ 密度—时间演化图（宇宙三阶段图）**
- **横轴** = 大爆炸以来的时间（**对数刻度，单位年**）；**纵轴** = 密度。
- **蓝线 = 辐射密度**（下降最快）；**红线 = 物质密度**（下降，但较慢）；**暗能量密度 ≈ 水平常数**。
- **两个交叉点**把宇宙历史分成三段（颜色区分）：**辐射主导 → 物质主导 → 暗能量主导（当前）**。

## 四、课堂补充（transcript 有而 slides 没有的内容）

**1. 老师对课程性质的澄清（学生课后提问："这门课只讲物理吗？"）**
> 「不不。**前两周我们做一些物理，之后就会更多是地质学了。**我们会转向发生在地球上的过程、**板块构造 (plate tectonics)**……我会尽量把物理讲得容易理解。」
→ 板块构造被老师称为**"地球的大理论 (the big theory of the Earth)"**，是第一学期 Build 部分的**根本理论支柱**。

**2. 为什么地球科学课要从宇宙讲起（老师的完整因果链）**
> 「我们要理解**构成地球的元素是怎么形成的**；要理解**恒星和星系怎么形成**；然后要理解**行星的形成**。我们需要在**非常不同的尺度**上理解事物，而我们从**宇宙尺度**开始。」

**3. Workshop 的目的**
> Workshop 的存在是为了**引入"地质时间 (geological time)"的概念**——因为它太浩瀚了，是个**很难理解的概念**；同时也用来展开讲座里提到的那些 **"big ideas"**。

**4. 关于两个 chapters 的关系（很好的框架性比喻）**
> Build 和 Grow **起点非常不同**（一个物理、一个生物），但到 12 月圣诞假期时，**两条线会收敛到今天 (converge to the present day)**。

**5. 爱因斯坦引入 Λ 的动机**（讲义只有一行"Λ 与暗能量相关"，故事全在转写里）
> 爱因斯坦的场方程给出的是一个**正在坍缩的宇宙**，这对他"不是个令人满意的结果"。他**想要一个稳定、固定的宇宙**（不膨胀也不收缩），所以引入 Λ 作为**阻止坍缩的力**。——注意这与今天的理解（Λ 是驱动加速膨胀的暗能量）相反，是概念史上的一个反转。

**6. Fred Hoyle 的态度与"Big Bang"一词的贬义起源**
> Hoyle「对膨胀宇宙和奇点这个想法不太满意」，于是**相当轻蔑地 (dismissively)** 称之为 "the Big Bang theory"。但这个词**留了下来**。他本人支持**稳恒态宇宙**，同时又是**恒星核合成理论的创立者**（下周会回到他的工作）。

**7. 「大爆炸既不大也不是爆炸」这句金句只在课堂上讲**
以及配套的强调：「**那时候根本没有空间**。空间必须被形成、被膨胀出来，才能让物体去占据。」

**8. 我们自己为什么不膨胀**
> 「我们和地球**不膨胀**，它被**强得多的力**——**引力、原子间的力**——束缚在一起。」

**9. 哈勃超深场的具体做法**
> 哈勃望远镜**连续 10 天**盯着同一片天空；随着曝光时间增加，**越来越多极暗的天体显现出来**；而**暗的（更远的）天体倾向于偏红**。

**10. 老师对哈勃常数单位的"翻译"**（讲义只给了 kms⁻¹Mpc⁻¹）
> 70 km/s/Mpc = **20 km/s per million light years**；并逐档给出 1、2、3 百万光年 → 20、40、60 km/s 的例子。

**11. 哈勃常数差异的物理解读（讲义只留了一个问句）**
> Planck 任务测的是**大爆炸后 38 万年的原初宇宙**，那时的哈勃常数**更小**。「**这告诉我们：宇宙一直在膨胀，但膨胀速率随时间在增大。**」而老师给的应试口径是：「**我们真正需要记住的就是哈勃常数约等于 70。**」

**12. 普朗克时间的哲学含义**
> 「在 0 到 10⁻⁴³ 秒之间，**我们根本无法有任何关于时间是什么的概念——时间不存在**。所以我们只能从这一点开始。」

**13. 我们对极早期宇宙的无知（老师非常坦率）**
> - 大统一纪元时的宇宙：「**它是固体？是气体？还是我们无法理解的东西？我们真的不知道它的物理性质。**」
> - 关于力的分离顺序：「**我们怎么知道这些？其实我们不知道 (Well, we don't)。**很多都是基于理论。」
> - 暴胀：「**这是一个理论，尚未被验证。**」
> - 宇宙的未来：「我们并不真正知道现在之后会发生什么。」
→ **这是一个重要的学科态度示范：明确区分 speculative theory 与 secure theory。**

**14. 暴胀的用途（因果解释，讲义未说透）**
> 「有时用这个理论来**解释宇宙的均匀性 (homogeneity)**。宇宙相当均匀。如果当时没有这次大暴胀，物质分布可能会**更加不均匀**。」

**15. LHC 的具体能力**
> 「**LHC 在新配置下可达 6000 GeV 的能量**」——正是靠这类实验，电磁力/弱力分离之后的理论才被称为 **secure theory**。
> ⚠️ 转写稿此处出现 "16 Kelvin" 显然是漏字，应为 **10¹⁶ K** 量级（讲义原图给出 10¹⁵ K 对应 10⁻¹² s）。

**16. 希格斯场的"悬赏"轶事**
> 「当年 Peter Higgs 获诺贝尔奖时，一位英国前科学部长设了一个奖，奖给**能解释清楚希格斯场是什么的人**。」——说明这个概念确实难。

**17. 老师对鸡尾酒会类比的完整二次讲解（课后回答学生）**
> 「这些是粒子，是派对上房间里的人。如果你给这个房间施加一个希格斯场，就意味着引入了希格斯玻色子，也就是这个名人。名人走进房间，所有人都看过去、围过来站在他周围，**实际上就是给了他质量**。别人如果想跟他说话，**必须绕过去，不能直穿过去**，因为那里聚集着人群（质量）。**要绕过这群人，就需要克服一个额外的力**，而这个力意味着有质量——**F = ma**，所以那必定是一个被创造出来的新质量。」
> 补充：「比如它们是夸克的话，它们就聚集在一起，可以形成一个有质量的粒子。」

**18. 强子/轻子形成次序的因果**
> 「**强子是带电粒子**……所以我们需要**轻子来抵消它们的电荷**。所以可以看到，**我们是先形成了一些原子核，之后才形成电子的。**」

**19. 光的诞生时刻**
> 「γ 射线是高能光子。**光正是在这些核反应过程中开始形成的。**」——这是一个很有画面感的因果点：光与元素同时诞生。

**20. 氢同位素的特殊性**
> 「**氢是唯一一个我们给同位素专门命名的元素**」——protium、deuterium、tritium。

**21. 学生提问一：CMB 的探测**
> 学生问 CMB 是什么样的信号。老师：「非常非常微弱、非常低能量的微波。我不清楚技术细节，但它必须是能探测极弱信号的东西。」并说明这些微波**只能用"它们来自那个时期"来解释**。

**22. 学生提问二：这些光子最初可见吗？以后会变成射电波吗？**
> 老师：「如果你当时就在宇宙里，是会有那么一个时刻的。它们起初是光子（γ 射线），但因为已经传播了这么久，波长被移动了。」
> 关于射电波：「**如果等得足够久，它们会被拉伸得更长。**至于那时你还能不能探测到，或者还有没有收音机去探测，就不好说了。」

**23. 学生提问三：哈勃常数怎么就能定出宇宙年龄？**（老师完整重讲了一遍代数，见 §2.8）
> 关键提示：「H₀ 是**速度对距离之比**，是**那条线的斜率/梯度**。」「y = mx，就是 v = H₀d。」「代进 t = d/v，**d 消掉**，得到 t = 1/H₀。」

**24. 时间轴是对数刻度的提醒**
> 「注意这是**对数刻度**，所以**极早期发生了非常多的事**——到这里我们才只到 10⁻¹² 秒。」

**25. 老师的诚实自嘲**
> 讲到 Brookhaven 的实验时：「**我忘了 RHIC 是什么了，你们可以自己查一下。**」（RHIC = Relativistic Heavy Ion Collider，相对论重离子对撞机）

## 六、易错点 / 重点难点

1. **⭐「大爆炸」是一个误导性的名字**——它既不"大"也不是"爆炸"，而且它描述的是宇宙的**演化 (evolution)**，不是**创生 (creation)**。不要写成"一个点在已有空间中爆炸"。正确表述：**空间本身的拉伸**。

2. **⭐ 红移不是真正的多普勒效应**。多普勒效应只是**类比/教学脚手架**。天文红移是 **"expansion redshift"（膨胀红移）**——**不是星系在动，是空间在膨胀**。老师在课上两次强调这一点。

3. **哈勃定律的适用范围**：仅在 **红移 z < 0.2** 时呈线性；对更遥远天体该定律失效。答题时若被问"这个定律总成立吗"，必须提到这个限制。

4. **H₀ 的下标 0 有含义**：表示**当今的**哈勃常数。**哈勃常数会随时间变化**（Planck 测的早期值 67.0 < Cepheid 测的当今值 73.5，正说明膨胀在加速）。不要把它当成永恒不变的常数。

5. **"哈勃时间"的推导中距离项 d 会消掉**——这是整个推导的关键一步，t = d/(H₀d) = 1/H₀。很多人推不出来是卡在这里。

6. **⚠️ 单位陷阱**：13.8 **Ga**（billion years，十亿年）不是 13.8 million years。转写稿中老师本人口误说成 million，讲义的 13797 **Ma** 才是正确的（13797 百万年 = 13.797 十亿年）。

7. **时间轴不是从 0 开始，而是从 10⁻⁴³ s（普朗克时间）开始**。0 到 10⁻⁴³ s 之间"时间"这一概念不成立。

8. **⭐ 纪元顺序容易记乱**，务必按序背：**Planck → Grand Unification → Electroweak（含 Inflation）→ Quark → Hadron → Lepton → Photon**（→ Recombination → Dark Ages）。

9. **每个纪元的开端 = 一种力的分离**，分离顺序：**引力（Planck 末）→ 强力（GUT 末）→ 电磁力与弱力分开（Quark 纪元）**。注意引力是**最先**分离的，也是**最弱**的力。

10. **强子不是基本粒子**。基本粒子只有**夸克、轻子、玻色子**三类；**强子（质子、中子、原子核）是由两个及以上夸克构成的复合粒子**。

11. **形成次序反直觉**：**原子核（强子）先于电子（轻子）形成**。

12. **⚠️ 复合 (recombination) 的时间是 ~380 kyr，不是 3 分钟**。转写稿里老师有此口误。讲义标题 "3 min < t ≤ 380 kyr" 指的是**区间**，透明化发生在区间的**终点**。

13. **"recombination"这个词本身有点误导**——电子和原子核其实是**第一次**结合，"再"结合只是历史遗留的命名。理解为"**中性原子的形成**"即可。

14. **CMB 为什么是微波**：它**出生时是 γ 射线**，是**宇宙膨胀造成的红移**把它一路拉伸到微波波段的。不要答成"它一开始就是微波"。

15. **⭐ 原初核合成停在 helium-4**——这是为什么早期宇宙只有 H、He 和微量 Li，而**没有更重的元素**。更重的元素要等**恒星核合成 (stellar nucleosynthesis)**（下周内容）。

16. **75% H / 25% He 是"质量丰度"，且此后几乎没变**——因为大爆炸产量太大，恒星后续的贡献只是"轻微改变"。

17. **三大观测证据必须能一口气说出**（老师在总结时逐条点名）：
    - **① 红移 (redshift)**
    - **② 宇宙微波背景 (cosmic microwave background)**
    - **③ 氢与氦的丰度 (abundance of hydrogen and helium)**

18. **Λ 的历史含义与现代含义相反**：爱因斯坦引入它是为了**阻止坍缩、维持静态宇宙**；今天它代表**暗能量、驱动加速膨胀**。

19. **"speculative theory" vs "secure theory" 的分界**在电磁力/弱力分离处（~10⁻¹² s）。更早的一切都是推测。这是老师明确要求区分的科学态度。

20. **暴胀比光速快**——听起来违反相对论，但**膨胀的是空间本身**，不是物体在空间中运动，所以不违反。

21. **普通物质只占 ~5%**（暗能量 68.5%、暗物质 26.6%、普通物质 4.9%）。三个数字的顺序和大致比例要记住。

22. **暗物质与暗能量的分工不能混**：**暗物质 → 提供质量、决定星系的空间结构（丝状网络，星系形成于交叉点）**；**暗能量 (=Λ) → 驱动加速膨胀**。

23. **三阶段的成因**：辐射与物质的密度会被膨胀**稀释**，而**暗能量密度恒定不变** → 所以暗能量必然从少数派逐渐变成主导者。这是个纯逻辑推论，要能讲清楚。

| Electromagnetic spectrum | 电磁波谱 | 从 γ 射线（短波高频）到射电波（长波低频）的全部电磁辐射；可见光为 400–700 nm |
| Hubble Ultra Deep Field | 哈勃超深场 | 哈勃望远镜连续 10 天曝光同一天区所得的图像，显示越远的天体越暗越红 |
| Hubble's Law | 哈勃定律 | v = H₀d，星系退行速度正比于距离（仅在 z < 0.2 时线性） |
| Hubble constant (H₀) | 哈勃常数 | 哈勃定律的斜率，约 70 km s⁻¹ Mpc⁻¹（≈20 km/s per Mly）；下标 0 表示当今值 |
| Hubble time | 哈勃时间 | t = 1/H₀，由哈勃常数估算的宇宙年龄，约 13.8 Ga |
| Cepheid star | 造父变星 | 亮度周期性变化的恒星，用其绝对与视亮度测定宇宙学距离（Leavitt 的工作） |
| Parsec / Megaparsec (Mpc) | 秒差距 / 百万秒差距 | 天文距离单位；1 Mpc = 3.09 × 10¹⁹ km |
| Light year | 光年 | 光在一年中走过的距离，另一种天文距离单位 |
| Planck time / epoch | 普朗克时间 / 纪元 | t ≤ 10⁻⁴³ s；此前"时间"概念不成立；四种力完全统一 |
| Theory of Everything | 万有理论 | 量子力学与引力统一的理论，对应普朗克纪元的物理状态 |
| Grand Unification Epoch | 大统一纪元 | 10⁻⁴³–10⁻³⁶ s；引力从其他力中分离；宇宙 ≤10⁻³⁵ m、10³² K |
| Electroweak Epoch | 电弱纪元 | 10⁻³⁶–10⁻³² s；强力分离；发生时空暴胀 |
| Inflation | 暴胀 | 10⁻³² s 内直径增大 ≥10²⁷ 倍至葡萄柚大小，快于光速；用以解释宇宙的均匀性 |
| Homogeneity | 均匀性 | 宇宙在大尺度上物质分布相当一致的性质，需靠暴胀理论解释 |
| Quark Epoch | 夸克纪元 | 10⁻¹²–10⁻⁶ s；电磁力与弱力分离，四力至此全部分立；10¹⁵ K |
| Quark | 夸克 | 基本粒子、物质的主要组成成分；质子 = uud，中子 = udd |
| Quark-gluon plasma | 夸克-胶子等离子体 | 能量过高、夸克尚未结合成强子时的物质状态 |
| Gluon | 胶子 | 把夸克粘合在一起的力载体粒子 |
| Lepton | 轻子 | 最轻的一类基本粒子（如电子），用于抵消强子的电荷 |
| Boson | 玻色子 | 传递电磁力的"力粒子"，包括光子与希格斯玻色子 |
| Photon | 光子 | 光的基本粒子，一种玻色子，无电荷无质量 |
| Hadron | 强子 | 由两个及以上夸克构成的**复合**粒子——质子、中子、原子核 |
| Hadron Epoch | 强子纪元 | 10⁻⁶–1 s；第一批"正常物质"形成；3 × 10¹² K |
| Higgs field | 希格斯场 | 弥漫宇宙的能量场，粒子与之相互作用而获得质量；若无它粒子皆以光速运动 |
| Higgs boson | 希格斯玻色子 | 希格斯场能量涨落的可见表现；鸡尾酒会类比中"走进房间的名人" |
| Mass | 质量 | 对力（或由 F = ma 对加速度）的阻力 |
| LHC (Large Hadron Collider) | 大型强子对撞机 | CERN 的加速器，新配置可达 6000 GeV，使夸克纪元的理论成为 secure theory |
| RHIC | 相对论重离子对撞机 | 美国 Brookhaven 的装置，研究夸克-胶子等离子体到强子的相变 |
| Photon Epoch | 光子纪元 | 3–20 min；原初核合成发生期；10⁹ K |
| Nuclear fusion | 核聚变 | 轻原子核结合成更重原子核并释放能量的过程 |
| Primordial / Big Bang nucleosynthesis | 原初核合成 / 大爆炸核合成 | 大爆炸后 3–20 分钟造出 H、He 与微量 Li 的过程，终止于 helium-4 |
| Isotope | 同位素 | 质子数相同、中子数不同的同一元素的不同原子种类 |
| Protium (¹H) | 氕 | 最普通的氢同位素，核内只有 1 个质子 |
| Deuterium (²H) | 氘 | 含 1 质子 + 1 中子的稳定氢同位素，由 p + n → D + γ 生成 |
| Tritium (³H) | 氚 | 含 1 质子 + 2 中子的氢同位素（氢是唯一给同位素单独命名的元素） |
| Gamma ray | γ 射线 | 高能光子，在原初核合成反应中产生，后被红移成今天的 CMB 微波 |
| Helium-4 | 氦-4 | 原初核合成的终点产物（质量数 4）；同样是今日太阳内的聚变产物 |
| Plasma | 等离子体 | 由自由（电离）原子核与电子组成的物质状态，光子被困其中，宇宙不透明 |
| Recombination | 复合 | ~380 kyr 时电子被原子核捕获形成中性原子的过程 |
| Opaque / Transparent universe | 不透明 / 透明宇宙 | 复合之前光子被困宇宙不透明；复合之后光子逃逸宇宙变透明 |
| Photon decoupling | 光子退耦 | 光子与物质脱离耦合、自由传播的时刻，是我们用光能观测到的最早时刻 |
| Cosmic Microwave Background (CMB) | 宇宙微波背景 | 复合后逃逸的光子，今天以均匀微波辐射形式从各方向到达地球；有微小温度起伏 |
| Planck mission | 普朗克任务 | ESA 的航天器任务，测绘 CMB 并据此给出 H₀ = 67.0 km s⁻¹ Mpc⁻¹ |
| Cosmic Dark Ages | 宇宙黑暗时期 | 380 kyr – 150 Myr；尚无恒星发光，暗物质与暗能量主导宇宙内容 |
| Filamentous pattern | 丝状结构 | 暗物质在宇宙中的网状分布；星系形成于其交叉点 |
| Milky Way | 银河系 | 地球所在的星系；在暗物质模拟图上以红色星号标出 |
| Radiation-dominated era | 辐射主导期 | 宇宙演化的第一阶段，辐射密度最高 |
| Matter-dominated era | 物质主导期 | 第二阶段，物质密度超过辐射密度 |
| Dark energy-dominated era | 暗能量主导期 | 当前阶段；暗能量密度恒定不被稀释，因而最终主导并导致加速膨胀 |
| Stratigraphic column | 地层柱 | 地质年代的标准分层序列；老师要求**必须背下其主要划分** |
| Plate tectonics | 板块构造 | 老师称之为"地球的大理论"，是本学期后续内容的核心理论框架 |
