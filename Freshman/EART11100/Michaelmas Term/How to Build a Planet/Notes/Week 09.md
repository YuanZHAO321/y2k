## 二、核心概念

### （一）中生代的框架：三个纪与它们的名字

#### 1. 时限与时长

| Period | 中文 | 时限 | 时长 | 名称来源 |
|---|---|---|---|---|
| **Triassic** | 三叠纪 | 251.9 – 201.4 Ma | **50.5 Myr** | 德国 "trias"（三）——三套特征岩层 |
| **Jurassic** | 侏罗纪 | 201.4 – 145.0 Ma | **56.4 Myr** | 瑞士 / 法国边境的 **Jura Mountains 汝拉山** |
| **Cretaceous** | 白垩纪 | 145.0 – 66.0 Ma | **79 Myr** | 拉丁文 **"creta" = chalk 白垩** |

- **Mesozoic 全长 ≈ 186 Myr（252 – 66 Ma）**。名字意为 **'Middle life'（中间的生命）**。
- 幻灯片上另出现 **174.7 / 161.5 Ma** 两个数字——这是**侏罗纪内部的世 (Epoch) 界线**（Early/Middle Jurassic ≈ 174.7 Ma，Middle/Late Jurassic ≈ 161.5 Ma），不是纪的界线，别记混。
- **英国的中生代地层分布**：东北部 → 中部 (Midlands) → 一直延伸到东南部。（第一张地图）

#### 2. 三叠纪命名的三套岩石（德国 + 整个西北欧）

老师明确列了三种：
1. **海相碳酸盐 (marine carbonates)** —— 德国的 **Muschelkalk**；
2. **红色砂岩 (red sandstones)** —— 德国的 **Buntsandstein**；
3. **蒸发岩 (evaporites)** —— 德国的 **Keuper**（转写作 "the coir"）。

**为什么蒸发岩重要（老师额外强调的构造意义）**：蒸发岩（岩盐、石膏）力学强度极低，是**极好的滑脱面 (detachment horizon)**——欧洲很多**大型逆冲断层 (thrusts)** 就沿着这些三叠系蒸发岩层滑动，造成各种复杂变形。「these evaporites… make wonderful detachment horizons for faults」。

#### 3. ⭐ 三套命名岩石如何反映古地理与气候（老师留的思考题答案）

| 纪 | 标志岩石 | 反映的环境 |
|---|---|---|
| Triassic | **红层砂岩 + 蒸发岩** | Pangaea 内陆的 **超级季风气候 (mega-monsoon)** 下的**极端干旱季**、内陆盐湖/萨勃哈；红色 = 氧化环境、陆相；蒸发岩 = 蒸发量 >> 降水量 |
| Jurassic | **汝拉山灰岩（浅海碳酸盐）** | Pangaea 开始解体、海平面上升 → **温暖的浅海陆表海 (epicontinental seas)** 广布 → 碳酸盐台地 |
| Cretaceous | **白垩 (chalk)** | 海平面达显生宙最高、**颗石藻 (coccolithophores) 大爆发** → 远洋钙质软泥 → 白垩（多佛白崖 Cliffs of Dover） |

> 这条线索本身就是本讲主线的缩影：**构造 → 海平面 → 沉积岩类型**。

### （二）Pangaea 与三叠纪古地理

- **形成**：晚石炭世 (late Carboniferous)，**Gondwana（南方大陆）与 Laurussia（北方大陆）碰撞** → **Variscan Orogeny 华力西造山运动** → 形成巨大的 **Variscan Orogen 山链**，并拼出单一超大陆 **Pangaea**。
  - 老师提醒定义：**orogeny 造山运动 = 两个都带陆壳的板块相互碰撞的造山事件**。
- **周边大洋**：
  - **Panthalassic Ocean 泛大洋** —— 包围 Pangaea 的巨型大洋；
  - **Paleotethys 古特提斯洋** —— 位于 Pangaea 内凹的"楔口"处（早期）；
  - **Neotethys 新特提斯洋** —— 三叠纪新生（见下）；
  - **Tethyan Trench 特提斯海沟** —— Paleotethys 板块俯冲带。
- **关键结论**：**超大陆的大小与所处纬度位置，直接控制了全球气候与大洋环流格局**——影响地表风场、影响降雨分布。这是本讲一切因果的起点。

### （三）显生宙大灭绝的成因之争：撞击 vs 火山

#### 1. 争论的历史与现状

- 三叠纪的**开始与结束都以大灭绝事件为界**：**P–T（二叠-三叠）** 与 **T–J（三叠-侏罗）**。
- 争论自 **1980 年代** 起（老师自嘲：「for you it seems like a long time ago, but for me it's like… ah, the 1980s, not that long ago」），主要两派：
  - **陨石撞击 (meteorite impacts)**
  - **大规模火山喷发 (massive volcanic eruptions)**
- **今日主流观点**：
  - 撞击**只**直接对应**白垩纪末 (K–Pg) 那一次**；
  - 其余绝大多数显生宙大灭绝的元凶是 **hyperthermals 超级热事件**。

#### 2. Hyperthermal 超级热事件（核心定义）

> **Hyperthermals = 地质历史上由大规模火山喷发驱动的、快速而极端的全球变暖事件。**

幻灯片关键图（务必会判读）：**显生宙属级灭绝幅度 (genus extinction magnitude) 曲线 vs LIP 的年龄与估算原始体积 vs 疑似撞击构造年龄**三者叠在同一时间轴上 → 直观显示 **LIP 的时间点与灭绝峰值高度吻合，而撞击构造大多对不上**。

#### 3. LIP 与地幔柱

- **Large Igneous Province (LIP) 大火成岩省** = 面积极大的火山岩省，一般认为与 **mantle plume 地幔柱（巨型热点）** 相关。
- 老师回顾早前课程："this sort of volcanism occurs over hot spots — very large hot spots — over mantle plumes."
- 中生代 LIP 的**今日全球分布**是本讲一张关键地图（Siberian Traps、CAMP、Wrangellia、Deccan 等）。

### （四）二叠-三叠 (P–T) 大灭绝：火山成因

#### 1. Siberian Traps 西伯利亚暗色岩 (252 Ma)

- **规模**：约 **3,000,000 km³** 熔岩 + 火山碎屑岩 + 侵入体，**分批 (in bursts) 在约 600 kyr 内喷出**。
- 是**整个显生宙保存下来的最大体积的陆内玄武质岩浆作用**。
- 被认为是 **PTB 大灭绝的终极成因 (ultimate cause)**。

#### 2. PTB 灭绝的严重程度

- **显生宙最严重的危机**：
  - **>90% 海洋物种** 灭绝；
  - **70% 陆生脊椎动物属 (land vertebrate genera)**；
  - **大部分陆地植被**。

#### 3. ⭐ 时序矛盾（Timing Problem）——本讲最重要的批判性思维点

老师说："as always with any cause and effect, **it's all about the timing**."

| 事件 | 年龄 |
|---|---|
| **PTB 主灭绝面 (main extinction horizon)** | **252.28 ± 0.08 Ma** |
| **溢流玄武岩 (flood basalts) 喷发** | **251.7 – 251.3 Ma** ← **晚于**灭绝 |
| **岩床杂岩体 (sill complex) 侵入** | **252.2 – 251.9 Ma** ← **早于**熔岩 |

**→ 结论（现今解释）**：把灭绝归因于**地表溢流玄武岩是错的**——**真正的扳机是喷发早期的岩床侵入**（即地幔柱的"管道系统 (plumbing system)"）。

**机制**：
- 这些岩床**侵入到富挥发分的沉积岩中**——具体是**泥岩 (mudrocks)、蒸发岩 (evaporites)、以及石炭纪形成的煤系 (coal measures)**；
- **接触变质 (contact metamorphism)** 使这些岩层释放出**巨量温室气体，尤其是甲烷 CH₄**；
- 老师的形象说法："it was the intrusion… that **tipped it over the edge**，and then all the volcanism that happened after **just made things extremely unpleasant and difficult to recover** —— 就像对着正在挣扎恢复的生命 **'sticking the boot in'（再踹一脚）**。"

#### 4. 另一个补充机制：Ignimbrite flare-up 熔结凝灰岩爆发期

- 定义：**强烈的酸性 (silicic) 火山作用**，由多次**破火山口式喷发 (caldera-forming eruptions)** 组成，合计喷出 **10³ – 10⁴ km³** 岩浆。
- 与**早三叠世 Paleo-Tethys 洋闭合过程中的俯冲带火山作用**相关。

### （五）⭐ LIP 诱发大灭绝的"标准模型" (Standard Model)

这是**贯穿整个显生宙（二叠、三叠、侏罗）的通用模型**，必须能完整背出因果链。老师说黑板系统 (Blackboard) 上另有一个视频专门讲这个模型。

#### 第 0 步：火山注入 (Injection)

喷发向大气注入：**H₂O（最多）、CO₂、SO₂、HF、HCl、火山灰 (Ash)**。
（老师明确排序：**水是最多的气体，CO₂ 次之，SO₂ 第三**。）

#### 第 1 步：温室气体 → 全球变暖

**直接 CO₂ 排放** + **岩浆接触变质煤层 / 富有机质泥岩 / 蒸发岩释放的甲烷 (m/m = metamorphosed)**
→ 大气温室气体激增 → **快速而极端的全球变暖**。

#### 第 2 步：SO₂ → 酸雨

**SO₂ + H₂O（大气中）→ H₂SO₄ 硫酸 → 酸雨 (acid rain)**

酸雨的具体危害（老师逐条讲）：
- **直接灼烧叶片** → 无法进行光合作用；
- **酸化地表水**（河流→湖泊）→ 某些生物无法呼吸；
- **酸化土壤** → **释放出铝 (Al) 等有毒元素** → 铝进入水系 → **对生物极度有毒**。

#### 第 3 步：陆地大灭绝

**极端变暖 + 酸雨 → 植被毁灭（土壤 pH 改变、光合受损）+ 干旱**
→ **可居住区域缩小 + 食物链断裂 + 极端高温的直接效应**
→ **陆地大灭绝 (terrestrial mass extinction)**

#### 第 4 步：剥蚀加剧 → 海洋崩溃（本模型最精彩的一环）

**植被覆盖减少（没有植物根系固土）+ 酸雨 → 大陆风化剥蚀急剧增强、表土被剥光**
→ **进入海洋的沉积物通量增加约 7 倍 (7-fold)**
→ ① **底栖生物 (benthos) 被沉积物直接淹没窒息**
→ ② 沉积物同时带来**大量营养盐 (nutrients)**
→ **海洋表层初级生产力暴增 (enhanced marine surface productivity)**
→ 叠加 **迟滞的大洋环流 (sluggish oceanic circulation)**（因水温升高、温度梯度减小）
→ 叠加 **水温升高 → 溶解氧降低**
→ **海洋缺氧 (ocean anoxia) + 酸化加剧**（缺氧深层水上涌带来 CO₂）
→ **可居住的水深带变得极窄甚至消失 (narrow to absent habitable depth zone)**
→ **海洋大灭绝 (marine mass extinction)**

> 老师补充术语：此时的**透光带 (photic zone) 变成 euxinic（静海的）**——**富硫化氢、贫氧**，"not a great place for life to attempt to exist"。
> 幻灯片图上标注 **OMZ = oxygen minimum zone（最小含氧带，200–1000 m 水深）**，灭绝时该带急剧扩张、上侵到浅水。

#### 环境影响的关键要素（幻灯片总结）
- **主要**：酸雨、快速极端变暖、海洋缺氧；
- **次要贡献**：**臭氧层破坏 (ozone depletion)**、**有毒金属中毒 (toxic metal poisoning)**。

### （六）早三叠世：P–T 灭绝之后的"漫长余波"

#### 1. 恶劣环境持续多久

- **进入三叠纪后仍持续约 6 Myr 的极差环境条件**，其间有**多次强烈全球变暖的脉冲**——对应**西伯利亚暗色岩持续的喷发脉冲**。

#### 2. 气候带的重组（古气候带图判读）

- **半干旱带 (semi-arid zones) 大幅扩张到 70° 纬度**（图上从赤道到高纬几乎全是 Arid / Warm Temperate，没有寒带）；
- **极区温度大幅升高 → 完全没有极地冰盖 (no polar ice caps)**；
- **热带地表温度升至致命水平**：
  - 部分模型预测**陆地 ~50–60 °C**；
  - **海表 ~40 °C**；
  - **对比现代**：现代赤道海表温度 **~28–30 °C，从不超过 32 °C**。
- 老师提醒：具体多热**取决于模型里放了哪些参数，是有争议的**。

#### 3. 灭绝余波的四大"化石证据指标"（⭐ 高频考点）

| 证据 | 含义 |
|---|---|
| **全球损失 90% 物种**，赤道带脊椎动物（鱼、海生爬行类、四足类 tetrapods）**清零** | 赤道成为 **"dead zone" 死区** |
| **约 10 Myr 的 "coal gap" 煤缺失期** | 全球**成煤植物群 (peat-forming floras) 终结**——地层中找不到这一段时间的煤 |
| **缺失后生动物造礁生物 (metazoan reef builders，如珊瑚)** | 海洋生态系远未恢复正常 |
| **缺失深海燧石 (deep-sea cherts)，持续约 10–15 Myr** | 硅质浮游生物（放射虫）生产力崩溃 |

#### 4. ⭐ 叠层石的"回归"——最有意思的一条

**持续的温室条件 → 风化增强 → 入海沉积物增加 → 营养盐增加 → 初级生产力增强 + 富营养化 (eutrophic)**
→ **有利于不依赖氧的叠层石型微生物 (stromatolitic microbes)，而不利于珊瑚和滤食生物 (filter feeders)**
→ 岩石记录中出现**一波波叠层石形态的回归**

老师原话："what we see in the rock record… is an interesting **return of stromatolitic forms which are really reminiscent of things that we haven't seen since the Cambrian and Precambrian**." —— 即**生态系统"退回"到前寒武纪的样子**。

#### 5. 恢复时间

**生物多样性直到中三叠世 (Middle Triassic) 才开始恢复到灭绝前水平** —— 老师强调这次的恢复期比其他任何事件都长得多。

### （七）Pangaea 对三叠-侏罗气候的控制：Mega-monsoon 超级季风

#### 1. 为什么会有超级季风

**成因组合**：**巨大陆块几乎对称地跨赤道分布 + 中央有温暖的赤道 Tethys 洋**。

- Pangaea 北半部 = **Laurasia**，南半部 = **Gondwana**，中间被**温暖的 Tethys 洋**隔开。
- 老师注：Laurasia 这个名字随你把哪些现代陆块算进去而有不同叫法，"let's just call it Laurasia"。

#### 2. 季风的定义与机制（⭐ 会画会讲）

> **Monsoonal climate 季风气候 = 风向发生季节性反转 (seasonal reversal of winds)，并伴有极端分明的干湿两季。**

**北半球夏季（= 南半球冬季）的环流**：
1. **Laurasia 受热升温** → 空气受热上升 → 陆上形成**低压 (L)**；
2. 同时 **Gondwana 处于冬季、变冷** → 形成**高压 (H)**；
3. **大气从 H → L 流动**，即气流**由南向北**；
4. 气流**越过温暖的 Tethys 洋时大量吸收水汽**；
5. 气流抵达 Laurasia、**撞上 Variscan 山脉抬升** → **强烈降水 (intense precipitation)**。

**北半球冬季**：整个格局**完全反转**（Laurasia 变冷高压、Gondwana 变热低压，风向反向）。

#### 3. 极区状况

- **极区有植被 (vegetated polar regions)** → 说明**即使有冰也只是季节性的、极其有限**。
- 老师坦言："**the jury is really out** about just how much polar ice there would have been" —— 但**岩石记录里的极区植被**是硬证据。

#### 4. ⭐ 季风强度的演化史（三阶段）与 Cimmerian 地体

| 阶段 | 事件 | 季风强度 |
|---|---|---|
| **二叠纪 (Permian)** | Pangaea 刚形成并**漂移到赤道之上** | 季风**开始出现 (initiated)** |
| **晚三叠世 (late Triassic)** | **Cimmerian 地体与 Laurasia 碰撞拼合**，**Neotethys 变得完全没有陆块阻挡** | 季风**大幅增强 (intensified)** |
| **侏罗纪 (Jurassic)** | Pangaea 向北漂移并**开始解体**，各块离开赤道 | 季风**减弱 (weakened)** |

**Cimmerian terranes 的迁移机制（老师讲得很细，考点）**：
- **Cimmerian 地体**包括**今天的土耳其 (Turkey)、伊朗 (Iran)** 等；
- 三叠纪之前，它们**附着在 Gondwana 的北缘**（= Paleotethys 洋的南岸）；
- 三叠纪期间，它们**裂离并向北 / 西北迁移**，奔向**华北、华南与 Laurasia**；
- **驱动力**：北边的 **Tethyan Trench 特提斯海沟**正在**俯冲消耗 Paleotethys 洋壳**（"oceans close at trenches and open at mid-ocean ridges"）；
- 与此同时，在 Cimmerian 地体**后方（南侧）新生了一个洋中脊扩张中心**；
- **结果**：**Paleotethys 洋完全闭合**，其**后方打开了 Neotethys 新特提斯洋**。

> 这是一个**经典的"地体裂离-漂移-拼贴"模型**：前方消减、后方新生。

### （八）三叠纪并非只有炎热干旱：Pluvial Intervals 雨期

老师特别强调的**易错点**：*"Don't get the idea that all greenhouse crises that cause global warming result in aridity — they can also result in periods of intense rainfall."*

> **Pluvial event 雨期 = 湿润度显著增强的时期。**

#### ⭐ Carnian Pluvial Episode (CPE) 卡尼期洪积事件（~230 Ma）

**触发**：**Wrangellia flood basalts 兰格利亚溢流玄武岩喷发 (~230 Ma)**（今天出露于**北美与阿拉斯加**，老师说"we can go and visit them"）。

**因果链**：
1. **双脉冲的气候变暖 (double pulse of climate warming)，全球平均升温约 7 °C**；
2. → **极高降雨量 (v. high rainfall)**；
3. → **大量陆源碎屑 (siliciclastic) 输入海洋**；
4. → **浅海礁体环境被沉积物淹没 (overwhelmed)**；
5. → **全球海相碳酸盐系统关闭 (shutdown of marine carbonate systems worldwide)** —— 岩石记录中**这一段时间全球缺失灰岩**（老师原话：the absence of limestones）；
6. → **强烈而广泛的大洋缺氧 (oceanic anoxia)**；
7. → **菊石类 (ammonoids)、海百合 (crinoids)、苔藓虫 (bryozoa)、牙形石 (conodonts) 的灭绝**。

> 注意：CPE 走的是**和早三叠世 P–T 后完全相同的因果模式**（升温 → 降水/风化 → 沉积物+营养盐入海 → 缺氧 → 灭绝）。这是本讲反复出现的"母模板"。

#### ⭐⭐ "Good news!!!" —— 大灭绝之后必有大创新

幻灯片上老师专门写了 **"Good news!!!"**：**Major extinctions are followed by major evolutionary innovations.**

CPE 灭绝之后紧接着出现的**五项重大演化创新**（必背）：
1. **恐龙的崛起 (rise of dinosaurs)**；
2. **第一批会飞的脊椎动物 (first flying vertebrate)**（翼龙）；
3. **针叶树主导的植物群 (conifer-dominated floras) 扩散至全球**；
4. **钙质超微浮游生物 (calcareous nannoplankton) 出现** —— **今天主宰全球碳循环**；
5. **早期哺乳动物 (early mammals)** —— 老师加一句："from our own selfish point of view"。

> **概念要点**：环境剧变**既是灭绝的原因，也是演化创新的机会**——空出的生态位让其他类群得以辐射。

### （九）Pangaea 的解体：三个阶段

**Pangaea 总共存在约 100 Myr**。

> 老师的旁注（学术八卦）：有人争论 Pangaea "从来没有真正作为单一实体存在过，只在某人的幻想里"，因为总有小块在拼上或撕下——"but let's not worry about the detail of that"。

**回顾早前课程的原理**：**超大陆本质上是不稳定的 (supercontinents by their very essence are unstable)，裂解是必然结果**（因为超大陆隔热、下方地幔积热 → 地幔柱上涌）。

| 阶段 | 时间 | 事件 |
|---|---|---|
| **Phase 1** | **早侏罗世开始** | **Laurasia 与 Gondwana 之间开始裂谷作用 (rifting)** |
| **Phase 2** | **早白垩世开始** | **Gondwana 解体**为非洲、南美、印度、南极、澳大利亚 |
| **Phase 3** | **早新生代 (Early Cenozoic)** | **Laurasia 裂解**：Laurentia（= 北美 + 格陵兰）自 Eurasia 裂离 |

#### Phase 1 详解：CAMP 与中大西洋的诞生

**裂谷位置**：Pangaea 的**正中央**——北美/欧洲（Laurussia）段与 Gondwana 之间。

**产物**：
- **多条失败裂谷 (multiple failed rifts)**；
- **雏形的中大西洋 (incipient Central Atlantic Ocean)** —— 老师强调此时**还没有洋壳形成**，只是裂谷；
- **CAMP 的岩浆侵位**。

**⭐ 如何在岩石记录中识别一次超大陆裂解？**（老师设问自答）
> **靠与裂谷伴生的火山作用**：**陆上（subaerial）玄武质熔岩的溢出 + 巨大的岩床 (sills) 与岩墙 (dykes) 网络的侵入**。

#### CAMP: Central Atlantic Magmatic Province 中大西洋岩浆省

- **地球上面积最广、体积最大的 LIP**（"most areally extensive and voluminous"）；
- 体积 **2–3 百万 km³**；
- **分 4 次爆发 (4 bursts) 喷出，202–220 Ma**（幻灯片与转写一致给出此区间；⚠️ 注意国际公认的 CAMP 主峰值年龄是约 201 Ma、与 T–J 界线同步，见易错点）；
- **今日分布**：横跨北美、南美、非洲的大片地区，以及英国（幻灯片上标出 UK 位置）；
- **典型露头照片**：**摩洛哥高阿特拉斯山 Agouim 地区 (Agouim High Atlas, Morocco) 的 CAMP 溢流玄武岩**。

#### CAMP 与 T–J（三叠-侏罗）灭绝事件

- 三叠纪末是 **"big five" 五大灭绝之一**，**海洋与陆地生物群双双受创**；
- **与 CAMP 的第一次喷发脉冲同步 (synchronous with the first pulse)**；
- 老师补充排名："**生态扰动程度在整个显生宙排第三 (third worst)**"；
- **海洋端的杀手：显著的海洋酸化 (ocean acidification)**
  → **选择性地杀死带钙质外壳的海洋生物**：**礁群落灭绝、菊石 (ammonites)、双壳类 (bivalves)、钙质微体化石、牙形石 (conodonts)** 全部重创；
  → 老师概括："**anything that makes its shell out of calcium carbonate was lost**"；
- **陆地端**：**大气 CO₂ 增加 4 倍 (four-fold)、全球升温约 5 °C** → **孢粉 (pollen & spores) 与脊椎动物的剧烈更替 (dramatic turnover)**；
- **两大"杀伤机制" (killing mechanisms)**：**全球变暖** + **海洋含氧量下降**。

#### 中大西洋海道 (Central Atlantic Seaway) 的打开

- **裂谷没有停下、没有失败**，继续发展；
- **到中侏罗世 (Mid-Jurassic)，开始形成真正的洋壳 (oceanic crust)**；
- 新洋盆连通了 **Tethys 洋 与 Panthalassic 洋** → 形成 **Central Atlantic Seaway 中大西洋海道**；
- **重大意义**：这是**全球大洋环流格局的根本改变**——赤道附近打通了东西向的环球水道。

#### 侏罗纪伸展 → 白垩纪沉积（含野外实习彩蛋）

- **侏罗纪的伸展作用形成了一系列裂谷盆地 (rift basins)**，这些盆地后来**接收了白垩纪的沉积**；
- 典型区域：**今天的地中海一带**；
- **老师的实习广告**：选读 Earth and Planetary Sciences 学位的同学，**二年级野外实习地是法国的 Barrême**，看的正是**沉积在侏罗纪伸展盆地中的白垩系沉积物**。"It's a wonderful trip, I'll be going on it."

### （十）白垩纪的板块格局

#### 中白垩世 (Mid-Cretaceous)
- **中大西洋持续加宽 (Central Atlantic widening)**；
- **Neotethys 仍在**，**Tethyan Trench 仍在活动**；
- **Gondwana 开始解体（早白垩世起）**：
  - **南美与非洲**自南 Gondwana 分离；
  - **印度**开始与**南极洲、澳大利亚**分离；
- **南大西洋开始打开，方向是"由南向北"拉链式张开 (opening from south to north)**。

#### 晚白垩世 (Late Cretaceous)
- **Tethyan Trench 持续俯冲消耗 Neotethys 板块**；
- **印度、非洲、澳大利亚持续向北漂移**；
- **印度与非洲随后快速冲向 Eurasia** → **最终导致 Neotethys 洋的闭合**（进入新生代 → 阿尔卑斯-喜马拉雅造山带，Week 10 内容）。

### （十一）Pangaea 解体对气候的影响：CO₂ 与温室世界

#### ⭐ 因果链（必背）

> **Pangaea 解体 → 活跃的海底扩张 (active sea-floor spreading) 增强 → 火山作用增加**
> → ① **火山直接释放 CO₂ 与 SO₂**
> → ② **俯冲带更快地再循环 (recycling) 被俯冲的碳酸盐岩** → **加速 CO₂ 生成**
> → **大气 CO₂ 激增 → 温室气候 (greenhouse climate)**

**② 的具体例子（老师亲口举的）**：**侏罗纪汝拉山那样的灰岩**，随着大洋闭合被带进俯冲带**再循环**，把碳以 CO₂ 形式重新排回大气。

#### 数值

| 时期 | 大气 CO₂ |
|---|---|
| **Jurassic** | **约为现今的 4 倍** |
| **Cretaceous** | **约为现今的 10 倍**（幻灯片总结页给出上限 **可达 16 倍**） |

#### 支持"扩张增强"的两条独立证据（幻灯片图，⭐ 判读要点）

1. **全球裂谷总长度 (global rift length) 曲线**：侏罗纪起显著增长，延续到白垩纪；
2. **火山岩生成量曲线（红色波动线）**：三叠纪起上升，白垩纪达高峰；
3. 二者与 **CO₂ 曲线** 高度同步。

#### 温室世界的其他表现

- **全球温度显著更暖、更湿润**；
- **陆块集中在低-中纬度** → **极-赤道温度梯度小 (small pole-equator thermal gradient)** → **无极地冰盖 (no polar ice)**；
- 幻灯片长时间尺度 CO₂ 曲线上，明确标注了 **"Mesozoic CO₂ high"** 与 **"Cenozoic CO₂ high"** 两个高值期（纵轴为 10²–10³ ppm 量级的对数坐标）。

### （十二）Pangaea 解体对海平面的影响

#### 机制（老师用了一个非常形象的比喻）

**解体 → ① 大量新生的洋中脊 = 巨大的"海底高地 (oceanic highs)"体积占据洋盆；② 陆块碎裂 → 大量新的被动大陆边缘 (passive margins)**
→ **洋盆容积被"垫高"** → **海平面上升**

老师原话："if you have a basin and you fill it with lots of highs, then **sea level is going to rise**."

#### 结果

- **整个侏罗纪与白垩纪，全球海平面（波动中）持续上升**，最终成为**显生宙最高**：**高出今日 >200 m**；
- **低地被淹没 → 海侵 (transgression)** → 形成**广阔而温暖的内陆海 (vast, warm inland seas)**；
- **裸露陆地面积只有今天的 60–70%**；
- **幻灯片图**：北美与欧洲的中生代古地理图，大片浅蓝色代表被淹没区；**红星标出英国的位置——英国当时完全淹没在这样一个温暖的浅海之下**。
- **这些温暖的浅海陆表海，正是接下来那位"主角"崛起的完美温床。**

### （十三）⭐ 钙质超微浮游生物：颗石藻 Coccolithophores 的崛起

老师用了戏剧化的引入："these huge warm inland seas provided a fantastic habitat that resulted in the rise of — wait for it — **the stars of today: the calcareous nannoplankton!**"

#### 1. 基本生物学

- **本质**：**单细胞藻类 (algal cell)**，外面包裹着一圈 **方解石板片 (calcite plates)**，每一片称为一个 **coccolith 颗石**；
- **尺寸**：单个颗石约 **0.002–0.004 mm（= 2–4 µm）**；SEM 照片比例尺为 **2 µm**；
- **模式生物**：**_Emiliania huxleyi_**（现代颗石藻，幻灯片作 *Emiliyana huxleyi*）——注意 SEM 图上**板片是互相叠瓦状搭接 (overlapping) 的**；
- **生活方式**：**浮游 (planktonic)**，生活在**大洋近表层水中**，属于**远洋带 (pelagic zone)**。

#### 2. 出现时间与扩张

- **首次出现于 Carnian Pluvial Episode 之后（晚三叠世）**，最初**只局限于陆表海 (epicontinental seas)** 的很小范围；
- 到白垩纪，因**广阔温暖的内陆海**而爆发式扩张。

#### 3. ⭐ 全球碳循环意义

- **今天海洋中被移除的碳酸盐，一半以上是由颗石藻提取的**；
- 它们把 **CO₂ 有效地从大气中移除并埋藏到海底** → **对全球碳循环有决定性调节作用**。

#### 4. ⭐ 白垩 (Chalk) 是怎么形成的（含"粪球"关键环节）

1. 颗石藻死亡 → **球状外壳解体，颗石散落**；
2. 颗石**在海底堆积成 coccolith ooze 颗石软泥**；
3. 软泥**成岩固结 (lithify) → 白垩 (chalk)**（英国多佛白崖）。

**老师自问自答的关键一环（高频考点）**：
> **问**：颗石只有 2 µm 那么小，按理说会一直悬浮在水柱中不下沉，它们**怎么可能沉到海底**？
>
> **答**：**颗石藻是草食性浮游动物 (herbivorous plankton) 的重要食物来源**。浮游动物**大量摄食**它们，然后**排出粪球 (faecal pellets)**——粪球把无数颗石**打包成一个大得多、沉降快得多的颗粒**，从而**沉降到海底泥中**。

> 幻灯片上的白垩 SEM（比例尺 2 mm 与更高倍）里能看到**成堆的颗石**，其中很多**原本就是粪球**。

#### 5. ⭐ 生物地层学价值（老师说"石油公司爱死它们了"）

颗石具备**理想化石带 (biozone) 的全部条件**：
- **分布极其广泛** (widespread)；
- **颗石形态从白垩纪到现代快速演化** (rapidly evolved)；
- 每种**存续时间短** (exist for short periods)；
→ **中生代到新生代的生物地层价值无与伦比 (unrivalled)**；**oil companies adore them**。

### （十四）⭐ 并非所有 LIP 都造成灭绝（尤其是白垩纪）

**关键观察**（幻灯片图判读）：
- 图上用**星号标出各 LIP 的年龄**，**红色 = 陆上 (subaerial)，蓝色 = 水下 (subaquatic)**；
- 另标出 **OAE = Oceanic Anoxic Events 大洋缺氧事件** 与 **X = Mass Extinction 大灭绝**；
- **白垩纪的多数 LIP 无法对应到任何大灭绝**，而且**白垩纪的 LIP 大多是海底 (subaquatic) 喷发**。

**→ 结论**：**"火山 → 大灭绝" 绝不是一个简单的一一对应关系。**

**是否产生生物危机，取决于以下 5 个因素（必背清单）**：
1. **大陆的构型 (configuration of continents)** —— 白垩纪各陆块已分散到不同纬度；
2. **喷发的纬度、体积、速率、持续时间 (latitude, volume, rate and duration)**；
3. **喷发发生在何处：陆上 vs 海底 (continent or ocean)**；
4. **生物群适应环境变化的能力 (ability of biota to adapt)**；
5. **事件之前既有的气候状态 (pre-existing climate)**。

**老师特别展开的第 4 点（非常漂亮的一个论证）**：
> 白垩纪**钙质超微浮游生物的兴起本身**，可能是**削弱了 LIP 喷发效果的关键缓冲器**：
> CO₂ 仍在被喷入大气，但如果**有大量生物在吸收 CO₂ 造硬壳、被吃掉、被埋藏**，那么**大气 CO₂ 与全球气候的收支就可能被维持在平衡状态**，火山的影响被抵消掉了。

> 这里老师说了一句"break"——**课程中场休息 5 分钟**。（下半场专讲 K–T。）

### （十五）K–T / K–Pg 大灭绝：最终一幕

老师开场吐槽：他想找一首关于小行星撞击的歌来放，"but when I started listening to the words… decided that's probably [not appropriate]. If anyone knows a good asteroid or meteorite impact song, let me know."

#### 0. 名称与规模

- **K–T = Cretaceous–Tertiary**（**K = Cretaceous 的缩写字母**，T = Tertiary 第三纪）；今多称 **K–Pg (Cretaceous–Paleogene)**；
- 这是**流行文化中最著名的灭绝事件**——因为它**灭掉了非鸟恐龙 (non-avian dinosaurs)**；
- **约 76% 的物种灭绝**。

#### 1. ⭐ 撞击说的两条核心证据

**证据一：全球性的铱异常黏土层 (worldwide iridium-rich clay layer)**
- 该黏土层**富含铱 (Ir) 与其他铂族元素 (platinum group elements)**；
- **在全球都能找到**，且**定年极精确：66 ± 0.1 Ma**；
- **论证逻辑**：铱在地表极稀有（大部分随铁沉入地核），主要富集于**地幔与某些陨石**中。
  - 若要用火山解释，必须找到一次**全球同步、把地幔铱带到地表、且完全没留下其他证据**的喷发——**极难设想**；
  - 而**陨石中铂族元素含量高**，且**单次事件**天然解释了**为什么定年如此精确**。

**证据二：冲击变质石英 (shock metamorphism of quartz)**
- 与该黏土层伴生的**石英颗粒内部出现位错/变形面 (planar deformation features)**；
- 这种变形是**冲击波/地震波高速穿过石英晶格**造成的；
- **只有陨石撞击级别的能量**才能产生。

#### 2. Chicxulub 陨石坑的发现

- 多年苦寻撞击点，**1991 年 Hildebrand 及其团队确认了 Chicxulub 陨石坑**；
- **位置**：**墨西哥尤卡坦半岛 (Yucatán Peninsula) 北部、墨西哥湾南缘**，**被第三纪沉积物埋藏**；
- **直径 180 km**，由**直径约 12 km 的小行星**撞击形成。

**背景对比（幻灯片"显生宙重大撞击"图）**：
- 陨石进入地球大气**时刻都在发生**，通常都是微小天体；
- **仅中生代就形成了至少 9 个直径 >20 km 的大型撞击坑**；
- **Chicxulub 的 180 km 即使按这个标准也是巨无霸**。

#### 3. ⭐⭐ 撞击的"分钟级编年史"（2016 年以来 IODP 高分辨率钻探成果）

老师说这是"the most astonishing and detailed anatomy of an impact event, from its first moments to its environmental consequences across the world"。

**由坑体形态反演的入射参数**：
- **来向：东北方 (from the northeast)**；
- **速度：12–20 km/s**；
- **入射角：45–60°（相当陡）**；
- **撞击目标：墨西哥湾的浅海**。

**撞击点的岩性（决定了后果的关键！）**：
- 表层为 **灰岩 (limestones)、泥岩 (mudstones)、蒸发岩 (evaporites)**；
- 撞击坑**向下挖穿沉积盖层、深入下伏花岗质岩石 (granitic rocks)**。
- **老师强调的因果**：撞在**碳酸盐 + 蒸发岩**上意味着**汽化后会向大气抛出巨量的 CO₂ 和 SO₂**。（若撞在别处，后果可能完全不同——运气极差。）

**时间线**：

| 时刻 | 事件 |
|---|---|
| **< 1 分钟** | **海水被完全汽化**；挖出**初始 100 km 宽的坑**；向大气抛出巨大的**富蒸气羽流 (vapour-rich plume)**（碎岩+气体）。**羽流核心温度 >10,000 °C**（对比：石膏约 800 °C 就分解，灰岩约 800 °C 也开始分解——远超所需） |
| **同时** | **冲击波以 >1000 km/h 向外传播**（老师："no chance of hopping in your car and outrunning that baby"）；热到足以在 **1500 km 外点燃野火** |
| **同时** | 抛入大气的物质：**425 Gt CO₂**（来自汽化灰岩）+ **325 Gt SO₂**（来自汽化蒸发岩）+ **约 1200 Gt 其他固体物质**，被抛到 **>25 km 高空** |
| **同时** | 触发 **约 11 级地震**——**比有历史记录以来最大地震强约 1000 倍**；变形一直**延伸到莫霍面 (Moho)**（"shook the Earth… certainly a long way down through the crust and into the mantle"） |
| **< 3 分钟** | **冲击熔岩 (impact melt rock) 形成 → 中央峰隆起并垮塌 → 形成峰环 (peak ring / central ring)** |
| **< 30 分钟** | **海水开始倒灌回撞击坑**，携带来自周边被摧毁陆地的物质（包括被烧焦的生物残骸） |
| **随后数小时** | 碎屑持续从天空落回、沉入这团极浑浊的水柱 → 形成 **suevite 击变角砾岩层（一层"毯子"）** |
| **数小时–1 天内** | **巨型海啸 (tsunami)**——被撞击排开的水**从墨西哥湾北岸反射回来**；海啸带回**木炭、燃烧的生物质、悬浮的未固结海底沉积物（包括白垩纪的浮游有孔虫 planktonic foraminifera）**，全部倾倒进坑内 |

> ⭐ **老师觉得最震撼的一点**：**这整套 suevite 层记录的就是"撞击后的第一天"**——"it's showing us **one particular day in time**, which I find the most astonishing part about this."

#### 4. 全球性证据：tektites 玻陨石

- 被抛入大气的**硅质碎屑沉积物在极高温中熔融 → 形成小玻璃球，落回地表 → tektites 玻陨石**；
- **今天大多已风化成黏土球 (clay balls)**，而非原来的玻璃球（幻灯片说明 "altered tektites or glass spherules"）；
- **全球验证的三条论据**：
  1. **全球各地同年龄地层中都有玻陨石与冲击石英**；
  2. **其化学成分与 Chicxulub 坑区的样品一致**；
  3. **沉积层厚度由近端 (proximal，图上紫色) 向远端 (distal) 系统变薄**。
- → 三者合起来证明这是**一次真正的全球性事件**。

#### 5. ⭐ 撞击的四大全球后果（幻灯片编号，必背）

1. **野火 (Wildfires)**：先由撞击羽流的高温直接点燃，随后由**抛射碎屑再入大气时的大气加热**点燃，**波及 1500 km 之外**（1500 km 外的沉积层中确有燃烧证据）。
2. **酸雨 (Acid rain)**：三个来源——**冲击加热大气生成的硝酸 (nitric acid)**、**汽化硫酸盐生成的硫酸 (sulfuric acid)**、以及**野火烟尘贡献的酸**。
   → **对植物和钙质浮游生物造成危机** → **危机沿食物链向上传导**（这些生物位于食物链底端）。
3. **降温 (Cooling)**：**硫、尘埃 (dust)、烟灰 (soot) 注入大气** → **全球温度下降超过 20 °C**，**气候扰乱持续约 30 年**。
   - 具体估计：**赤道热带的平均温度降到约 5 °C**！
4. **遮光 (Reduced light)**：尘埃与烟灰遮蔽阳光 → **光合作用的海洋浮游生物崩溃 (collapse in photosynthetic marine plankton)** → 食物链基础断裂。

#### 6. ⭐⭐ 老师专门讲的一个易错概念：降温与升温的**时间尺度竞争**

> "When we talk about injecting material up into the atmosphere, we like to think 'oh of course things warm up' — but actually **there are two things that happen**."

| 机制 | 过程 | 效果 | 时间尺度 |
|---|---|---|---|
| **SO₂ → 硫酸盐气溶胶 (sulfate particles)** | SO₂ 与水结合、凝结成微小硫酸盐颗粒 | **把太阳辐射反射回太空 → 降温** | **短期（数年–30 年）** |
| **CO₂（汽化灰岩释放）** | 温室气体 | **升温** | **长期** |

**→ 关键结论**：两种效应**方向相反、互相竞争**，**必须考虑它们各自作用的时间尺度**。"It's not just enough to think 'oh, it's this' — we have to balance the things out."
**在撞击后的前 30 年，降温 + 遮光效应占绝对主导。**

### （十六）⭐ 反方论证：Chicxulub 真的是主因吗？

**没有人质疑 K–T 界线上发生过撞击**（全球证据太硬），**但"撞击是恐龙灭绝的首要原因"并非普遍共识**。

#### 1. Keller 的论证：全部押在 "Transitional Unit" 上

反方代表是 **Gerta Keller 及其合作者**。争论**完全取决于 Chicxulub 坑内一套 75 cm 厚的砂岩单元**——称为 **Transitional Unit 过渡单元**。

**Chicxulub 坑内的地层顺序（自下而上，必须记住）**：
```
   ┌───────────────────────────────┐
   │  iridium-rich layer  铱异常层   │  ← 全球性，与灭绝事件对应
   ├───────────────────────────────┤
   │  Transitional Unit             │
   │  （75 cm 厚砂岩包）             │  ← 争议全在这里！
   │  底部：富玻陨石球粒层            │
   │   (spherule-rich layer)        │  ← 撞击后仅数小时的大气沉降
   ├───────────────────────────────┤
   │  suevite  击变角砾岩            │  ← 公认代表"撞击第一天"
   └───────────────────────────────┘
```

**Transitional Unit 的沉积学特征（幻灯片详列，是判读依据）**：
- **向上变细 (upward fining)**：由以砂为主 → 以粉砂为主；
- 伴随**撞击碎屑的粒度与丰度同步向上减小**；
- 含**薄层递变层理单元 (thin graded units)**；
- 含**薄层交错纹层单元，且有振荡流 (oscillatory flows) 的证据**；
- **最上部含细小的潜穴 (tiny burrows)：遗迹化石 _Chondrites_ 与 _Planolites_** ← **生物扰动 (bioturbation) 的直接证据**。

#### 2. 两种截然不同的时间解读

| 观点 | 解读 | 推论 |
|---|---|---|
| **Keller 一派** | 这套单元**不是单一事件层**，而是**多层叠加、含生物扰动、由多次事件构成** → 代表 **100–150 kyr 的时间** | 则**铱层（= 灭绝事件）与 Chicxulub 撞击相隔十几万年 → 撞击不是灭绝的原因** |
| **较新研究（幻灯片采纳）** | 通过计算**尘埃穿过大气与水柱的沉降速率**、以及**不断减弱的海啸/湖震 (seiches) 与持续的斜坡垮塌事件对沉积物的改造**，估算该单元**只代表约 6 年** | 则**撞击与灭绝同时**；并且由于顶部已被生物扰动，说明 **生命重返撞击点的速度快得惊人 (remarkably rapid)** |

> ⭐ 老师的总结："**how the formation of this [unit] and how long it took is absolutely crucial** to determining whether Chicxulub is the source of the demise of the non-avian dinosaurs — **and this argument is not over yet.**"

### （十七）Deccan Traps 德干暗色岩：另一个嫌疑人

#### 1. 基本数据

- **体积约 1,500,000 km³ 玄武岩**；
- **喷发时间 68–64 Ma**，其中 **约 80% 集中在紧邻 K–T 界线之前的一个喷发阶段**；
- 转写补充：**跨越 K–T 界线共喷发约 750 kyr**。

#### 2. 支持 Deccan 说的论据

- 时间上与灭绝**大致同期**；
- 确实造成了**全球变暖**与**海洋酸化**；
- 支持者认为喷发是**一系列"超级脉冲" (mega-pulses)**，**频率之快让生命根本来不及适应环境变化**。

#### 3. 反对 / 困难

- **"喷发是否真的是脉冲式的"本身就没有共识**；
- ⭐ **最大的硬伤：Deccan 无法解释那个定年极精确、全球同步的铱异常尖峰**。要采信 Deccan 说，就**必须另找一套办法解释铱**。

#### 4. ⭐⭐ 最诱人的假说：撞击触发了 Deccan 火山活动的"状态转变"？

- **定年证据显示：撞击后约 50 kyr 之内，Deccan 的喷发方式发生了明显改变——变得规模更大、更具幕式 (much more massive and episodic)**；
- **问题**：**像 Chicxulub 这样巨大撞击产生的地震活动，是否能触发火山活动方式的转变**，进而影响生命？
- **困难**：**地震如何引发火山活动，其机制目前并不清楚**——"people think it probably can, we just don't understand properly how."

#### 5. ⭐ 老师给出的调和结论（本讲的收尾观点，必背）

> **无论你是 "Deccan Trappist" 还是 "Impactist"**，有一点是清楚的：**撞击与 Deccan 火山作用都是在"推一个本已承压的生物群 (an already stressed biota)"**。

**晚白垩世的背景环境已经在恶化**：
1. **海平面正在下降 → 大陆架栖息地面积减少 (reduced area of continental shelf habitats)**；
2. **白垩纪最后 500 万年，全球气候已经在变冷 (cooling)**。

> **→ 综合解答**：在这样的背景环境条件下，**Chicxulub 与 Deccan（其一或二者叠加）成了压垮骆驼的最后一根/两根稻草**，生命"just couldn't cope"，于是发生了大灭绝。

### （十八）附加内容：其他白垩纪远洋沉积岩 —— 燧石 Cherts

（幻灯片位于总结页之后，属于补充/自学材料，但概念在实验课与考试中常出现）

#### 1. 燧石 (Chert) 的鉴定特征

- **非常坚硬 (very hard)**；
- **细晶质石英 (finely crystalline quartz)**；
- **由溶解-沉淀作用形成 (formed by solution precipitation)**；
- **外观常略带玻璃光泽 (slightly glassy)**；
- **贝壳状断口 (conchoidal fracture)**。

#### 2. 两大类型

| 类型 | 说明 |
|---|---|
| **原生燧石 (primary chert)** | **层状分布 (well bedded)**，由硅质软泥直接成岩 |
| **次生燧石 (secondary chert)** | 例如**白垩中的燧石结核 (flint nodules in chalk)**，是成岩期硅质再分配形成 |

#### 3. 硅的生物来源

- 造壳生物分泌的是**非晶质硅 = 蛋白石质硅 (opaline silica)，化学式 SiO₂·nH₂O**；
- **两大类群**：

| 类群 | 生态位 | 出现时间 | 分布 |
|---|---|---|---|
| **Diatoms 硅藻** | **浮游植物 (phytoplankton)**，漂浮的光合藻类 | **白垩纪以来 (Cretaceous onwards)** | **主要淡水**，部分高纬度海域 |
| **Radiolaria 放射虫** | **浮游动物 (zooplankton)**，浮游生活的微小动物 | **早寒武世以来 (early Cambrian onwards)** | **赤道海域常见** |

#### 4. ⭐ 与前寒武纪 BIF 中燧石的关键区别

**前寒武纪条带状铁建造 (BIFs) 中的燧石与氧化铁互层** —— 那里的**燧石是从过饱和海水中直接化学沉淀的，不是生物成因**。
（因为当时还没有分泌硅质骨骼的生物，海水硅浓度极高。这是 Week 6–7 的旧知识点在此的呼应。）

#### 5. 硅质软泥与原生燧石的形成过程

1. **放射虫与硅藻生活在大洋表层水中**，死后**下沉到海底**；
2. 被**埋藏并进入沉积物**；
3. **缓慢重结晶为石英 (quartz)** —— **通常需要几千万年 (tens of millions of years)**；
4. 最终产物为**层状燧石 (bedded chert)**。

**判读要点**：
- **薄片下看不见单个放射虫或硅藻的轮廓——因为它们已被完全重结晶**；
- **硅质软泥中的纹层 (laminae)** 反映**浮游生物生产力的季节变化**，和/或**陆源碎屑黏土的季节性输入**；
- 幻灯片提问："**Why is it red?**"（红色来自**细分散的氧化铁/赤铁矿**——氧化的深海远洋环境、沉积速率极慢，铁被充分氧化。）

### （十九）附加内容：碳酸盐补偿深度 CCD

#### 1. 定义与机制

> **CCD (Calcite Compensation Depth 碳酸盐补偿深度) = 碳酸钙的供给（形成并下沉的速率）与其溶解速率恰好相等的深度。**

**为什么 CaCO₃ 溶解度随深度增加？**
- **温度下降** + **压力增加** → **CaCO₃ 溶解度上升**。
- **CCD 之下，钙质壳全部溶解，无法保存**。

#### 2. ⭐ CCD 的核心作用

> **CCD 控制着大洋底部钙质软泥 (calcareous ooze) 与硅质软泥 (siliceous ooze) 的分布。**
> —— CCD 以上：钙质软泥（有孔虫、颗石）；CCD 以下：只剩硅质软泥或深海红黏土。

#### 3. 硅的对照情况

- **大部分蛋白石质硅在表层水中就溶解了**——原因：**表层水更暖**、**壳体的 Al/Si 比**、**极大的比表面积 (high surface area)**；
- **全球硅通量中只有约 3% 最终被埋藏进沉积物**。

#### 4. ⭐ CCD 在地质时间中的变化（两条重要历史）

1. **白垩纪 – 早始新世 (Cretaceous – early Eocene)，CCD 比今天浅得多**
   **原因链**：**强烈火山活动 → 大气 CO₂ 浓度高 → 海水 pCO₂ 高 → 表层水溶解 CO₂ 增加 → 海水更酸 → 碳酸盐更易溶 → CCD 变浅。**
2. **古生代与早中生代，即颗石藻演化出现之前**：因为没有钙质浮游生物提供沉积物，**硅质软泥可能沉积在比后来浅得多的水深**。

### （二十）⭐ 反方总论：反对"火山成因"的三条论据

（幻灯片专门用一页，针对 **End-Permian、End-Triassic、Early Jurassic OAE、K–T/K–Pg** 四个事件）

1. **时间尺度严重不匹配 (significant disparity in timescales)**
   - **LIP 岩浆作用持续约 1–5 Myr**；
   - 而**大灭绝发生在 <100 kyr 的尺度上**；
   - → 一个慢过程如何造成一个快事件？

2. **相对时序不对 (relative timing)**
   - 二者**并非在起点同步**；
   - **LIP 侵位可能早于大灭绝几十万年 (100 ka's prior)**；
   - 而在**最猛烈的喷发期间，生物圈却几乎没有出现负反馈的证据 (little evidence for negative feedback in the biosphere during voluminous eruptions)**。

3. **并非所有 LIP 事件都伴随显著的环境变化**（呼应第十四节）。

> **学习方法提示**：这一页与前面的"标准模型"页是**一对**——考试若问"评价 LIP 是否为显生宙大灭绝的主因"，要**两边都写**，再用第十四节的"5 个调节因素"和第十七节的"already stressed biota"作为综合结论。

### 7. LIP 诱发灭绝的"标准模型"流程图（3 张连续幻灯片）
**这是本讲最需要能"复述整张图"的图。**
- **第 1 张**：火山柱向大气注入 **H₂O、CO₂、SO₂、HF、Ash、HCl** → 温室气体 → 全球变暖；

（详见第十六节的 ASCII 柱状图）
**判读要点顺序（自下而上）**：suevite → 富球粒层 → Transitional Unit（向上变细、递变层理、振荡流交错纹层）→ 顶部生物扰动（_Chondrites_、_Planolites_）→ 铱异常层。

### 4. Orogeny 的定义被重新强调
"Remember, **an orogeny is just a mountain building event where two plates, each of which have got continental crust on them, collide with each other.**" —— 老师意识到这是大一必须夯实的定义。

### 5. 三叠纪的另一面：幸存者的再殖民
"**The Triassic is a time when the survivors of that massive extinction event started to spread and to recolonize the changed Earth**, or the environmental niches that were available."
→ 提醒：三叠纪的生物故事本质上是**灾后重建 + 生态位重新填充**的故事。

### 6. 关于 P–T 灭绝的"两步走"叙事（幻灯片只写要点）
老师把机制说得非常口语化也非常清楚：
- **岩床侵入（早期）= 扳机 (tipped it over the edge)**；
- **后续的溢流玄武岩 = 补刀 ("just sticking the boot in" for life which was attempting to recover)**。
→ 这个区分是本讲最关键的一个"新认识"，务必记住**不是熔岩、是岩床**。

### 7. 火山气体的排序（幻灯片没写）
老师明确给出：**水 (H₂O) 是最多的，CO₂ 次之，SO₂ 是第三多的**。并强调 **SO₂ 本身不是温室气体**，但影响巨大（酸雨 + 气溶胶降温）。

### 8. 酸雨的四条具体伤害路径（幻灯片只写 "acid rain"）
老师逐条展开：① 直接灼烧叶片使其无法光合；② 酸化地表水（河流→水体），某些生物无法呼吸；③ 酸化土壤；④ **土壤酸化释放出铝 (Al) → 进入水系 → 对生物剧毒**。第 ④ 条是幻灯片 "toxic metal poisoning" 的具体含义。

### 9. Euxinic 这个术语
老师用了 **euxinic**（转写作 "eugenic"）描述当时的透光带，并解释 = **"sulfur rich and oxygen poor"**。这是描述缺氧海洋的专业术语，幻灯片上没有。

### 10. Cimmerian 地体的完整迁移机制
幻灯片只有一句 "once the Cimmerian terranes had collided with Laurasia"，老师用了将近一整段讲**前方 Tethyan Trench 俯冲拉动、后方新洋中脊扩张推动**的完整模型，并点名 **Turkey、Iran** 是今天的 Cimmerian 地体，目的地是**华北、华南与 Laurasia**。这是幻灯片完全没有的关键机制。

### 11. "并非所有温室危机都导致干旱"的明确警告
"**Don't get the idea that all greenhouse crises that cause global warming result in aridity — they also can result in periods of intense rainfall.**" → 直接引出 Carnian Pluvial Episode。这是一个被明确点名的易错点。

### 12. Wrangellia 玄武岩的今天位置
"currently found up in — we can go and visit them in — **North America and Alaska**."（幻灯片只写了名字）

### 13. 关于 Pangaea 是否"真的存在过"的学术争论
老师提到有人主张 Pangaea "never really existed as a single entity except in someone's fantasy"，因为总有地体在拼贴与撕裂。他建议大一阶段"let's not worry about the detail of that"。→ 说明**超大陆是一个有用的近似模型，不是绝对事实**。

### 14. "怎么在岩石记录中识别超大陆裂解？"这一设问
幻灯片没有明确设问，老师却专门问了并自答：**看与裂谷伴生的火山作用——陆上玄武岩溢流 + 巨型岩床与岩墙网络**。这是很典型的考试问法。

### 15. 野外实习信息（Barrême, France）
二年级 Earth and Planetary Sciences 学位的野外实习地是**法国 Barrême**，看的是**沉积在侏罗纪伸展盆地中的白垩系沉积**。老师本人会带队。

### 16. 颗石藻的"沉降之谜"与粪球机制
幻灯片只有一句 bullet，老师却专门设问："if they're that little, surely — I can hear you say — **won't they just stay in suspension in the water column**?"，然后揭晓 **faecal pellets（粪球打包）** 机制。这是一个非常经典的考点。

### 17. 石油工业与颗石藻
"**Oil companies adore them**" —— 因为其生物地层分辨率无与伦比。幻灯片上只有 "biostratigraphic range" 几个字。

### 18. 白垩纪 LIP 未导致灭绝的"生物缓冲"解释
幻灯片只列了 "ability of biota to adapt"，老师把它展开成一个完整论证：**钙质超微浮游生物的兴起本身就是一个 CO₂ 汇**，因此白垩纪的 LIP 喷入的 CO₂ 被生物泵抵消掉了 → 碳收支维持平衡 → 没有崩溃。这是把本讲两条线（颗石藻 + LIP）串起来的精彩一笔。

### 19. K 是 Cretaceous 的缩写字母
老师提醒："**K is the abbreviation, the letter, that's used for Cretaceous**；T is Tertiary。" 因为 C 已被 Carboniferous 占用（德文 Kreide = 白垩）。

### 20. 铱异常论证的完整逻辑（幻灯片只有图）
老师完整讲了**为什么不能用火山解释铱**：需要一次**全球同步、把地幔铱送到地表、且不留其他痕迹**的喷发，"it's really hard to think of a way"。而陨石既解释了**铱的来源**，也解释了**为什么定年如此精确（单次事件）**。

### 21. Chicxulub 撞击的全部量化数据
幻灯片只有寥寥数语，**几乎全部数字都来自转写**：来向东北、12–20 km/s、45–60°、1 分钟内汽化海水、100 km 初始坑、羽流核心 >10,000 °C、爆风 >1000 km/h、野火 1500 km、425 Gt CO₂ / 325 Gt SO₂ / 1200 Gt 固体、抛至 >25 km 高空、11 级地震（≈ 历史最大地震的 1000 倍）、变形深达 Moho、3 分钟内峰环形成、30 分钟内海水倒灌、数小时 suevite、1 天内海啸。**这些是本讲最容易出细节题的地方。**

### 22. 撞击点岩性的"运气"因素
老师特意强调撞击点是**灰岩 + 泥岩 + 蒸发岩**——正因如此才释放出那么多 CO₂ 和 SO₂。"you can imagine… you're going to throw huge amounts of solid material and gases up into the atmosphere." 并给出分解温度参考：**石膏约 800 °C、灰岩约 800 °C 即分解，而羽流核心 >10,000 °C**。

### 23. "suevite = 撞击后第一天的记录"

## 六、易错点 / 重点难点

### A. 概念性易错点

1. **⭐ 中生代 ≠ 恐龙时代（就本课而言）**。本讲考的是**构造-气候-环境**，不是古生物。老师明确说 "Not this!"。

2. **⭐⭐ P–T 灭绝的元凶不是溢流玄武岩，而是早期的岩床侵入。**
   - 记住三个年龄的先后：**岩床 252.2–251.9 Ma → 主灭绝面 252.28 ± 0.08 Ma → 溢流玄武岩 251.7–251.3 Ma**；
   - 溢流玄武岩**晚于**灭绝，所以它是"补刀"不是"扳机"；
   - 机制关键词：**侵入到富挥发分的煤系 / 泥岩 / 蒸发岩 → 接触变质 → 释放甲烷**。

3. **⭐ 不是所有温室危机都造成干旱**——**Carnian Pluvial Episode 是极端多雨的**。老师专门警告过。

4. **⭐ 不是所有 LIP 都造成大灭绝**——尤其是白垩纪的（多为**海底喷发**）。要记住**5 个调节因素**。

5. **⭐⭐ 硫的双重效应与时间尺度竞争**——
   - **SO₂ → 硫酸 → 酸雨**（化学伤害）；
   - **SO₂ → 硫酸盐气溶胶 → 反射阳光 → 降温**（物理效应，短期）；
   - **CO₂ → 升温**（长期）。
   - 千万不要一看到"注入大气"就答"变暖"。

6. **大灭绝之后必有演化创新**——CPE 之后的五项创新是标准答案：**恐龙、飞行脊椎动物、针叶林、钙质超微浮游生物、早期哺乳动物**。

7. **Paleotethys 与 Neotethys 不是同一个洋**。Paleotethys 被 Tethyan Trench 消耗掉，Neotethys 在 Cimmerian 地体**后方**新生。方向别搞反：**Cimmerian 地体从 Gondwana 北缘裂离，向北/西北迁移**。

8. **Pangaea 解体三阶段的顺序与时间**：早侏罗（Laurasia/Gondwana 分离）→ 早白垩（Gondwana 内部解体）→ **早新生代**（Laurasia 内部解体，北美离开欧亚）。注意**第三阶段已经在中生代之后了**。

9. **海平面上升的机制是"洋盆被垫高"**，不是"水变多了"。关键词：**洋中脊体积增大 (oceanic highs) + 被动大陆边缘增多**。

10. **CCD 变浅 vs 变深的方向**：**CO₂ 高 → 海水酸 → 碳酸盐易溶 → CCD 变浅**（白垩纪–早始新世就是如此）。

11. **BIF 中的燧石是无机化学沉淀，不是生物成因**——因为前寒武纪还没有硅质骨骼生物。别和显生宙的放射虫/硅藻燧石混淆。

12. **硅藻 (Cretaceous onwards) 与放射虫 (early Cambrian onwards) 的出现时间与生态位不要混**：硅藻是**浮游植物、主要淡水**；放射虫是**浮游动物、赤道海域**。

13. **颗石的下沉靠粪球**，不是自己沉下去的。这个"反直觉"环节几乎必考。

14. **Deccan 说的致命弱点是"解释不了全球同步的铱尖峰"**，而不是"时间对不上"。

15. **K–Pg 的最终答案是"综合模型"**：**已经承压的生物群（海平面下降 + 已在变冷）+ 撞击 + Deccan**。不要只答一个。

### B. 转写中老师本人的口误 / 材料不一致（不是识别错误）

16. **CAMP 的年龄区间写反了**：幻灯片与转写都写 **"erupted in 4 bursts 202–220 Ma"** —— 正常写法应为 **220–202 Ma**（老的在前）。且国际公认 **CAMP 主脉冲约 201 Ma，与 T–J 界线 (201.4 Ma) 同步**，这才是"与第一次喷发脉冲同步"这句话的依据。**考试按讲义写 202–220 Ma 即可，但要理解真正的关键年龄是 ~201 Ma。**

17. **老师把 Gondwana 说成了 Pangaea**：讲超级季风起源时说 "monsoonal conditions were probably initiated sometime in the Permian **when Gondwana first formed**" —— 幻灯片写的是 **"once Pangaea was formed and had drifted over the equator"**。**以幻灯片为准：是 Pangaea 形成之后。**

20. **深海燧石缺失的时长**：转写老师先说 "10 million"，改口成 "**10 to 15 million years**"；幻灯片只说"缺失"。记 **~10–15 Myr** 即可。

| **Chalk** | 白垩 | 由颗石软泥固结形成的极细粒灰岩，如多佛白崖 |
| **Faecal pellet** | 粪球 | 浮游动物排出的粪粒，把微小颗石打包加速沉降——白垩形成的关键 |
| **Pelagic zone** | 远洋带 | 远离海底与海岸的开阔水体，颗石藻的生活区 |
| **Biozone / biostratigraphy** | 化石带 / 生物地层学 | 用化石延限划分对比地层；颗石因广布+短延限而价值无与伦比 |
| **Chert** | 燧石 | 极硬、细晶质石英、贝壳状断口的岩石，由溶解-沉淀形成 |
| **Flint nodule** | 燧石结核 | 白垩中的次生燧石团块 |
| **Opaline silica** | 蛋白石质硅 | SiO₂·nH₂O，硅质生物骨骼的非晶质原始成分 |
| **Diatom** | 硅藻 | 浮游植物，白垩纪起出现，主要淡水及高纬海域 |
| **Radiolaria** | 放射虫 | 浮游动物，早寒武世起出现，赤道海域常见 |
| **Siliceous ooze** | 硅质软泥 | 放射虫/硅藻壳堆积的深海软泥，数千万年后重结晶为层状燧石 |
| **BIF (Banded Iron Formation)** | 条带状铁建造 | 前寒武纪燧石与氧化铁互层，其燧石为无机化学沉淀 |
| **CCD (Calcite Compensation Depth)** | 碳酸盐补偿深度 | CaCO₃ 供给速率 = 溶解速率的深度，控制钙质/硅质软泥的海底分布 |
| **Neritic** | 浅海的 | 大陆架水深范围的沉积环境 |
| **Iridium anomaly** | 铱异常 | K–Pg 界线全球黏土层中的铂族元素尖峰，撞击说的头号证据 |
| **Platinum group elements** | 铂族元素 | 地表稀有、陨石中富集的一组元素，与铱一起构成撞击证据 |
| **Shock metamorphism** | 冲击变质 | 冲击波造成的矿物变形，冲击石英中的位错面是撞击的诊断特征 |
| **Chicxulub** | 希克苏鲁伯 | 墨西哥尤卡坦半岛北部埋藏的 180 km 撞击坑，1991 年 Hildebrand 确认 |
| **Peak ring** | 峰环 | 大型撞击坑中央峰隆起后垮塌形成的环状构造，3 分钟内形成 |
| **Suevite** | 击变角砾岩 | 撞击后数小时内沉降堆积的碎屑毯，记录了"撞击的第一天" |
| **Tektite** | 玻陨石 | 抛入大气熔融后落回地表的小玻璃球，今多已风化为黏土球 |
| **Transitional Unit** | 过渡单元 | Chicxulub 坑内 suevite 之上、铱层之下的 75 cm 砂岩包，是 K–Pg 争论的焦点 |
| **Bioturbation** | 生物扰动 | 生物挖掘搅动沉积物；Transitional Unit 顶部的 _Chondrites_、_Planolites_ 潜穴 |
| **_Chondrites_ / _Planolites_** | 丛藻迹 / 漫游迹 | 两种细小的遗迹化石，证明生命迅速重返撞击点 |
| **Seiche** | 湖震（振荡波） | 封闭水体中的驻波振荡，参与改造 Transitional Unit 沉积 |
| **Sulfate aerosol** | 硫酸盐气溶胶 | SO₂ 转化的微粒，反射阳光造成短期强烈降温（"撞击冬天"） |
| **Impact winter** | 撞击冬天 | 撞击后由尘埃、烟灰、硫酸盐造成的 >20 °C 降温期，持续约 30 年 |
| **Moho** | 莫霍面 | 地壳-地幔界面；Chicxulub 的变形深达此面 |
| **Non-avian dinosaurs** | 非鸟恐龙 | K–Pg 灭绝掉的恐龙类群（鸟类作为兽脚类的一支幸存） |
| **Greenhouse / Hothouse** | 温室 / 酷热室 | 无极地冰盖的温暖气候态；中生代在"冷温室-暖温室-酷热室"之间摆动 |
| **Pole-equator thermal gradient** | 极-赤道温度梯度 | 两极与赤道的温差；中生代因陆块居中低纬而梯度很小、无极冰 |
