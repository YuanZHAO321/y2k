## 二、核心概念

### （一）显生宙 Phanerozoic 的框架

#### 1. 名称与时限

- **Phanerozoic** = 希腊文 "visible life"（可见的生命）。
- 起始 **538.8 ± 0.2 Ma**，延续至今 → 时长约 **540 Myr**。
- 老师特别提示：**这个时长与冥古宙 (Hadean) 的时长相当**（冥古宙约 4567–4000 Ma）。也就是说，"看得见生命的全部历史" 只占地球史约 1/8。

#### 2. 三个代 (Eras) —— 时长极不均等

| Era | 中文 | 时限 | 时长 | 含义 |
|---|---|---|---|---|
| **Paleozoic** | 古生代 | 538.8 – 251.9 Ma | ≈ 287 Myr | ancient life 古老的生命 |
| **Mesozoic** | 中生代 | 251.9 – 66.0 Ma | ≈ 186 Myr | middle life 中间的生命 |
| **Cenozoic** | 新生代 | 66.0 Ma – 今 | ≈ 66 Myr | recent life 近代的生命 |

> **老师强调的易忽略点**：三个代的时间跨度**差别极大**——古生代近 300 Myr，新生代只有 66 Myr。看时间表时不要被"三等分"的视觉印象骗了。（转写此处老师口误把 Mesozoic 说成了 Phanerozoic，见易错点。）

#### 3. 寒武纪之底（= 显生宙之底）如何定义？

这是本节最"考点化"的一块：

- **旧定义（传统）**：以 **small shelly fossils（小壳化石，< a few mm）** 首次大量出现、变得广布为标志。
- **现行定义（GSSP）**：以 **遗迹化石 *Treptichnus pedum*** 的首次出现 (First Appearance Datum) 定义。
  - *Treptichnus pedum* 是**已知最早的复杂遗迹化石 (earliest complex trace fossil)**。
  - **遗迹化石 (trace fossil)** = 动物活动留下的痕迹（爬行、潜穴），**不保存动物本体**。所以我们其实**不知道造迹生物长什么样**——可能是节肢动物 (arthropod)，也可能是蠕虫状生物。
  - 它留下的是一条**结构相当复杂的潜穴 (burrow)**，被视为"第一种复杂动物"的证据。
- **老师的两点补充**（讲义上没有）：
  1. **用遗迹化石来定义一个大地质时期的底界是非常不寻常的**（通常用实体化石）。
  2. **这个定义本身有争议**——现在已有报道称 *T. pedum* 在**埃迪卡拉纪 (Ediacaran)** 地层中也有出现，即出现在寒武纪之下。

#### 4. 纪与纪的界线：大灭绝 (Mass Extinctions)

显生宙内部许多**纪 (period) 的界线是由生物组合的灭绝来定义的**，其中最剧烈的称为大灭绝。

**大灭绝的四条定义标准（讲义原文，四条要同时满足）：**
1. **30%+ 的物种 (species) 灭绝**；
2. **影响广泛多样的生态类型 (a wide variety of ecologies)**；
3. **全球性 (worldwide)**；
4. **在很短的时间内发生 (within a short period of time)**。

**主要成因（讲义列三条）：**
- **陨石撞击 (meteorite impacts)**；
- **重大全球气候变化 (major global climate changes)**；
- **大规模火成活动期 (periods of major igneous activity)**。
- 老师补充：**这些机制常常是叠加、协同作用的**（"some of these things may have worked together to initiate these mass extinctions"），不一定是单一元凶。

**关键数字**：**晚二叠世 (late Permian) 大灭绝**中，约 **84% 的属 (genera)** 灭绝——是显生宙最大的一次。

### （二）显生宙全球海平面变化 —— 本周的"物理引擎"

#### 1. 曲线本身

- 纵/横轴：时间自寒武纪至今；海平面高度以**现代海平面为零基准 (datum)**。
- **变化幅度**：从比今天**低约 100 m** 到比今天**高 200 m 以上**。
- **长波形态（老师用箭头标出的两个大周期）**：
  1. 寒武纪起海平面上升 → **奥陶纪末达极大值**（比今天高 >100 m）→ 长期下降 → 在 **二叠纪—三叠纪之交 (Permian–Triassic boundary) 达极小值**；
  2. 之后再次上升 → **白垩纪 (Cretaceous) 达第二个极大值** → 此后一路下降至今天。
- 曲线上还叠加了**大量短波长的抖动**（后面用 Milanković 等机制解释）。

#### 2. 长波长海平面变化的解释：超大陆的聚散

这是本周最核心的因果链之一，讲义与老师讲得完全一致：

> **超大陆聚合 (supercontinent assembly) → 海平面低；大陆最大离散 (maximum dispersal) → 海平面高。**

**机制一：造山缩短使陆壳面积减小**
- 大陆碰撞 → **orogeny（造山作用）** → 地壳**缩短、增厚 (thickening)** → **大陆面积减小**；
- 地球总大小不变、地球上的**水总量在整个地质历史中基本恒定** → 大陆面积减小意味着**洋盆面积增大** → 同样多的水摊在更大的盆里 → **海平面下降**。

**机制二：超大陆下方的热堆积（buoyancy）**
- 地球内部的热通过**对流 (convection)** 向外散失；超大陆像一床"隔热被"，把热**捕获 (trapped) 在其下方**；
- 热的堆积增加了超大陆的**浮力 (buoyancy)** → 超大陆整体**被抬升到更高海拔**；
- 陆地站得更高 → **相对海平面进一步下降**。

**对应到实例**：
- **Rodinia 破裂** → 海平面上升（寒武纪—奥陶纪的大海侵）；
- **奥陶纪、白垩纪 = 大陆最大离散 → 海平面最高**；
- **三叠纪 Pangaea 完整存在 → 海平面最低**。

#### 3. Eustatic（全球海平面）vs Relative（相对海平面）

这是本讲一个必须分清的概念对。

**Eustatic sea level (ESL) 全球海平面变化** —— 真正改变了**海水的质量或体积**、或**洋盆的体积**：
- (1) **气候相关**：大陆上水的储存形式（液态水 vs 冰）、**海水盐度 (salinity)**、**海水温度 (temperature)**；
- (2) **地质营力改变洋盆体积**：**大陆碰撞 (continental collision)**、**沉积作用 (sedimentation)**、**海底扩张 (sea floor spreading)**。

**Relative sea level change 相对海平面变化** —— **不改变**海水体积、也不改变洋盆，只是**陆地本身在上下运动**：
- 由 **陆地抬升 (uplift) 与沉降 (subsidence)**（垂向构造运动 vertical tectonics）造成；
- **是局部/区域效应**，在很宽的空间和时间尺度上变化。
- 老师的形象解释：设想一块陆壳从 t1 到 t2 被构造抬升。在 t1 你站在那里**会湿脚**，到 t2 你已经**站在海平面之上**了——"海平面下降了"，但**水一点没少，是地面升上去了**。

**讲义给出的综合定义（重要）**：
> **相对海平面 (relative sea level) = eustasy（全球海平面）+ subsidence rate（沉降速率）+ sediment supply rate（沉积物供给速率）三者的平衡。相对海平面上升 → 大陆被淹没 (flooding of continents)。**

#### 4. 各类机制的"振幅 vs 时间尺度"图（讲义中的关键图，老师逐块讲解）

坐标：**纵轴 = 海平面变化振幅（对数坐标，1 m → 1 km）；横轴 = 时间（1 yr → 100 Myr）**。图上是若干"机制场 (fields)"。

**短时间尺度组（10 ka – 100 ka，受地球轨道参数控制，即 Milanković cycles）**：

| 机制 | 振幅 | 说明 |
|---|---|---|
| **冰量 (volume of ice)** | **最大，~100 m 量级** | 水以冰的形式储存在大陆上（南极、格陵兰）→ 海平面降；冰融化 → 海平面升。老师联系现实：这正是我们担心全球变暖的原因。 |
| **盐度 (salinity)** | 较小 | 蒸发使海水变咸→密度增大→**体积略减**；稀释则体积略增。 |
| **温度 (thermal expansion)** | 较小 | 海水变暖→**热膨胀**→体积增；变冷→体积减。 |
| **陆上地下水与湖泊储水** | 最小 | 大陆上有大湖 → 水被"扣留"→ 海平面降；湖泊排干回海 → 海平面升。 |

> **老师点明为什么这几条被画在同一时间带**：它们**共同受地球轨道特征控制**（Milanković 周期，约 10–100 ka），所以时间尺度被绑在一起。

**长时间尺度组（1 Myr – 100 Myr，地质营力）**：

| 机制 | 说明 |
|---|---|
| **Continental collision 大陆碰撞** | 缩短地壳→减小陆壳总体积→洋盆变大→海平面降。 |
| **Sedimentation 沉积作用** | 造山带在重力上不稳定、快速侵蚀，大量沉积物进入洋盆→**部分填满盆地、排开海水**→海平面升。 |
| **SF spreading 海底扩张** | **最重要的一条**：全球**洋中脊总长度不是恒定的**，取决于当时大陆的分布。洋中脊多 / 扩张快时，地幔上涌的热与熔融**把洋底顶起来 (adds buoyancy, pushes up the seafloor)** → **洋盆变浅、海平面升高**。这一机制在 **~100 Myr** 尺度上起作用。 |

> **判读要领**：看到一个海平面变化，先看它的**振幅和持续时间**，就能大致锁定机制——百米级、万年尺度 = 冰量；百米级、亿年尺度 = 板块构造 / 海底扩张；米级 = 温度盐度。

#### 5. 我们怎么知道过去的海平面？（证据链，按时间深度排列）

| 证据 | 可追溯时限 | 说明 |
|---|---|---|
| **卫星测高 (satellite measurements)** | **< 10 yr** | 精度最高。 |
| **验潮仪 (tide gauges)** | **< 150 yr** | 有仪器记录以来。 |
| **岸线标志 (shoreline markers)**：热带珊瑚礁与环礁 (reefs and atolls)，由浅水造礁珊瑚形成 | **< 几百 ka**（老师说"10 万年或更久"） | 珊瑚只活在很浅的水里，测其今天的高程 + 定年 → 反推海平面。 |
| **有孔虫 (foraminifera) 碳酸钙壳的氧同位素 δ¹⁸O** | **< 200 Ma** | 有孔虫是**单细胞海洋生物**，生活在不同深度/环境，其 CaCO₃ 壳的氧同位素记录海水条件；洋盆内可用。 |
| **不整合面 (unconformities) 的跨洲对比** | **整个显生宙（最长的记录）** | **若不同大陆上的不整合面年龄相近，则推断是全球性过程（eustasy）造成的**。 |

> **测量的基本原理**：需要一个**固定基准 (fixed datum)**——例如**地心**——再测海面相对该点的位置。

#### 6. 海侵 / 海退与地层记录（判读方法，重点）

- **Transgression 海侵**：海平面上升 → 岸线**向陆地方向迁移 (migrates inland)** → 低地海岸平原、大陆边缘被淹没 → **浅海沉积覆盖在陆相沉积之上**。
- **Regression 海退**：海平面下降 → 岸线**向海盆方向迁移** → 陆上停止沉积、发生侵蚀 → **形成区域性不整合 (regional unconformities)**（因侵蚀或无沉积 non-deposition）。

**地层垂向序列的判读法（老师详细讲的小图）**：

- **海侵序列（正常粒序向上变深）**：
  `非海相/陆相沉积 (non-marine) → 砂质海滩 (sandy beach) → 浅海灰岩 (shallow-marine limestone) → 深海泥岩 (deep-marine mudstone)`
  → 越往上代表水越深 = **transgression**。
- **海退序列（反过来）**：
  `深海泥岩 → 浅海灰岩 → 砂质海滩 → 陆相沉积`
  → 越往上越浅 = **regression**，且**顶部常以不整合 (U/C) 收尾**（因为海退后陆上不再沉积，出现沉积间断，直到下一次海侵）。

#### 7. Supersequences（超层序）与大陆泛滥事件

- 做法：取一个大陆，做一条**从一侧边缘穿过内陆到另一侧边缘**的剖面，把**每个时间片上哪里在沉积**画出来。
- 结果：**大陆边缘几乎总在沉积，内陆则时有时无**；能识别出**整个大陆都没有沉积**的时段——这些时段对应**大不整合**。
- 由此把地层柱切成若干 **"supersequences"（超层序）**，尺度为 **10–100 Myr**，各有名称。**这项工作最早在北美大陆做出，后来在其他大陆也得到验证**（→ 支持是全球过程）。
- **解释**：
  - **全大陆无沉积（黄色不整合块）= 海平面低**；
  - **全大陆广泛沉积 = 海平面高 = 当时海底扩张强烈**（洋底被顶起）。
  - 讲义原文两句要点：
    - **10–100 Ma 尺度的 supersequences 归因于全球海平面变化**；
    - **250 Ma 尺度的海平面变化归因于超大陆的聚合与裂解**。
- **重要澄清（老师特别说明）**：大陆内部有沉积**不等于整个大陆被淹没**，更可能是当时存在大量**内陆海 (inland seas)**。
- 配套曲线：**flooded continental area（被淹大陆面积，10⁶ km²）随时间变化**——**不整合出现在被淹面积最小的时候**。

### （三）寒武纪 Cambrian —— 海侵、金属富集的海洋与生命大爆发

#### 1. 英国的古生代岩石分布（背景）

- 英国有**古生代各个纪的良好代表性露头**。
- **寒武系露头相当有限**，主要在三处：**北威尔士 (North Wales)**、**爱尔兰西部 (west of Ireland)**、**苏格兰西北部 (northwest Scotland)**。
- 老师提醒：讲义地图上**寒武系与石炭系用了同一种灰色**，容易看混。

#### 2. 寒武系底部不整合 —— 全球性事件

- **实例：Cambrian–Lewisian unconformity, Arkle, Sutherland（苏格兰）**。
  - 不整合面之上是**层状的寒武纪沉积岩**，之下是**太古宙/元古宙的高级变质岩 (high-grade metamorphic rocks，即 Lewisian)**。
- **老师的关键联系**：这条不整合面**就是你们在 workshop 里画过的那张大峡谷 (Grand Canyon) 照片上的同一条不整合面**——它是**全球性的 (a global one)**。

#### 3. 因果链：Rodinia 高地 → 极端风化 → 富金属海洋 → 生物矿化

这是本节最核心的推理链条，务必按顺序记住：

1. **新元古代 (Neoproterozoic) 时 Rodinia 超大陆地势很高 (sitting high)**（超大陆下热堆积→浮力抬升）；
2. 当时大气 **CO₂ 极高、O₂ 低**，在**雪球地球 (Snowball Earth) 事件之间的极热期**，气候为 **hothouse**；
   → **高温 + 高 CO₂ = 深部化学风化 (deep chemical weathering) 的理想配方**；
   → 造成寒武系底部不整合面上**强烈的风化 (intense weathering)** 特征；
3. **Rodinia 裂解 (break up) → 海平面上升 → 海侵 (transgression)**；
4. 海侵 + 强风化 → **大量金属离子（尤其 Ca²⁺）被侵蚀、搬运入海**；
   → 海洋变得 **anomalously metalliferous（异常富金属）**、**溶质丰富 (solute-rich)**、**富 Ca²⁺**；
5. 加上大气中 CO₂ 高 → 海水中溶解无机碳多；
   → **配齐了制造矿化硬体的全部原料** → **早寒武世生物开始出现矿化硬体（壳、骨骼等）**。

#### 4. Rodinia 裂解与被动大陆边缘

- 裂解 → 大量 **passive margin（被动大陆边缘）** 形成。
  - **passive margin 的含义（老师解释）**：这些边缘上**没有活动的地质过程**，只是随着大陆彼此远离被**被拖着走**。
- **生态意义（关键耦合点）**：新形成的边缘 = **过去不存在的全新生态位 (new ecological niches)**——**温暖、富金属的浅海陆架 (shallow marine shelves)**，可被生命开拓。

#### 5. 早寒武世的温室气候（证据）

**讲义给出的三类地质证据，支持一个"没有永久极地冰盖"的 greenhouse climate state**：
1. **蒸发岩 (evaporite) 与钙质结壳 (calcrete) 沉积跨越很宽的古纬度范围**；
2. **热带型土壤（红土 laterites）沉积在高古纬度地区**；
3. **过去 900 Myr 中大陆风化速率的最大值**出现在此时。

**模型结果（Cambrian sea surface temperatures 图）**：
- 色标 **15 °C – 35 °C**；
- **两极约 15 °C**，**赤道超过 35 °C**；
- **对比今天**：两极只有几度，赤道 SST 一般**不超过 30 °C**。
- → 寒武纪明显比今天热得多，且**极地—赤道温差小得多**。

#### 6. 晚寒武世古地理

- **Laurentia**（劳伦大陆，北美核心）；
- **Baltica**、**Siberia**、**Kazakhstan** 等中小陆块；
- **Gondwana**：巨大陆块，**从极地一直延伸到赤道**；
- **Panthalassic Ocean**：巨型泛大洋。
- 此时海平面持续上升 → 正在发生**海侵**。

#### 7. 寒武纪大爆发 (Cambrian Explosion) 的成因

**讲义提出的核心问题**：是什么因素导致了**大型复杂身体的构建**、**矿化骨骼材料的建造**，以及**代谢上昂贵的生活策略（如潜穴 burrowing、捕食 predation）**的发展？

**两条答案线**：
- **环境 (environment)**：
  - 深部风化导致**海水盐度/离子组成改变（尤其 Ca²⁺）**；
  - **大气与海洋氧化增强**——即 **NOE（Neoproterozoic Oxygenation Event，新元古代氧化事件）**。
- **生态 (ecology)**：
  - 成功的演化创新（**捕食 predation、运动能力 mobility**）本身产生**正反馈**——一方演化出捕食，另一方就必须演化出防御（壳），军备竞赛推动多样化。

#### 8. 生物矿化 (Biomineralization) 的三条关键认识

1. **"Worm-World"**：在**晚埃迪卡拉纪 (late Ediacaran)**，化石记录中出现**蠕虫状生物的微小锥形管状壳** → 这是**生物矿化的开端**（早于寒武纪）。
2. **生物矿化在寒武纪是在多个类群中"独立"发生的 (independently)**——在多样的**两侧对称动物 (bilaterians)** 和其他**后生动物 (metazoans)** 中各自出现，**不是从单一祖先继承来的**。
3. **顺序：先小后大**——**小的矿化部件**（要么是微小的完整骨骼，要么是大型动物身上的**单个骨片 sclerites**，即"铠甲碎片"）**更容易构建，先出现**；**完整的大型骨骼是后来才实现的**。

**谱系图判读**：图中**粗黑线代表各主要动物谱系的化石记录**；老师说**约有 13 条**这样的谱系线，**它们绝大多数都在寒武纪首次出现**。

### （四）奥陶纪 Ordovician（485.4 – 443.8 Ma）—— 最大离散、最高海平面、GOBE 与第一次大灭绝

#### 1. 古地理：大洋的开与合

- **奥陶纪初，Iapetus Ocean（古大西洋 / 雅皮特斯洋）宽度 > 4000 km**。
- 整个奥陶纪：**Iapetus Ocean 持续关闭**，同时 **Rheic Ocean（瑞亚克洋）与 Aegir Ocean（埃吉尔洋）持续张开**。
- **"洋宽度随时间"图的判读法**（老师专门讲）：
  - 横轴 = 奥陶纪时间轴；纵轴 = 各大洋宽度（0 → 约 8000 km）；
  - Iapetus 曲线下降、Rheic/Aegir 曲线上升；
  - **两组曲线交叉的中点 = 各主要大陆之间分离程度最大的时刻 = 洋面积最大的时刻**，此时主要大陆间相距 **3000–4000 km**。
- 参考点：图上以**红星标英格兰、蓝星标苏格兰**的位置（注意：此时**英格兰与苏格兰分属 Iapetus 洋两侧的不同大陆**，这正是 Iapetus 关闭 = Caledonian 造山的意义所在）。

#### 2. 海平面与气候

- **大陆最大离散 → 中奥陶世发生显著海侵 (pronounced transgression)**，海平面比今天高 **>100 m**；
- → 在各大陆边缘形成**大面积的热带大陆架 (tropical continental shelves)**；
- **整个奥陶纪气候总体温暖**，直到**晚奥陶世一次严重的冰川事件**为止。

#### 3. 两种指示炎热干旱的沉积物（讲义给了正式定义，要背）

- **Calcrete（钙质结壳）**：**干旱与半干旱地区形成的风化壳**；本质是**被 calcite（方解石）、dolomite（白云石）、gypsum（石膏）、halite（岩盐）和 ferric oxide（三价铁氧化物）胶结在一起的砂与粉砂**。
- **Evaporite（蒸发岩）**：主要是**层状 (bedded)** 的 **halite（岩盐 NaCl）、sylvite（钾盐 KCl）、gypsum（石膏）、anhydrite（硬石膏）以及各种钾盐**；由**盐水或淡水的浓缩溶液中析出固体矿物晶体**形成。**可以是海相，也可以是非海相（湖相 lacustrine）**。

> **两者共同的古气候含义（老师点明）**：**蒸发量 > 降水量 (evaporation exceeds precipitation)** 的炎热条件。

**古地理重建图判读**：图上用**黄色三角**标出 evaporite（另有少量 calcrete）在**奥陶纪时的古位置**（先在今天的大陆上找到它们，再把大陆复原到奥陶纪位置）。它们**从赤道一直延展到相当高的古纬度** → 说明当时**全球普遍炎热**。图中标出的大陆：**Laurentia、Siberia、Baltica、Gondwana**。

#### 4. GOBE：Great Ordovician Biodiversification Event（奥陶纪生物大辐射事件）

**核心区分（极重要，容易与寒武纪大爆发混淆）**：

| | Cambrian Explosion | GOBE |
|---|---|---|
| 多样性出现在哪个分类阶元 | **门 (phyla) 层级**——许多新的门出现 | **科 (family)、属 (genus)、种 (species) 层级** |
| 状态 | 门类齐了，但**科属种层级的多样性仍然很低** | 低层级多样性**大幅飙升** |

- GOBE **分两次爆发 (two bursts)** 发生（图上用**两颗星**标出）。
- 曲线判读：图上**蓝线 = "Modern fauna"（现代型动物群）**，**黑线 = "Paleozoic fauna"（古生代型动物群）**；寒武纪的属数并不多，属级多样性的暴涨主要发生在奥陶纪的 GOBE。

#### 5. GOBE 的生态表现：礁与泥丘 (Reefs and mud mounds)

- **造礁生物的根本转变：从微生物主导 → 后生动物主导 (microbial- to metazoan-dominated reefs)**。
  - 之前：**stromatolites（叠层石，微生物席）**；
  - 之后：**corals（珊瑚）、Bryozoa（苔藓虫，群体生活的小型无脊椎动物，建造碳酸盐骨架）、stromatoporoids（层孔虫，海绵类）**。
- **底栖生物群 (benthos) 的转变（讲义原句，重点）**：
  > **寒武纪的底栖群落以"到处挖洞的沉积食性者 (deposit-feeders burrowing away)"为主 → 被奥陶纪"悬浮食性者 (suspension-feeders)"取代，后者生活在具有复杂生态结构的群落中。**
- 同时出现大量 **mud mounds（泥丘）与 mound complexes（丘复合体）**。
- **驱动因素**：被动大陆边缘发育出的大片**浅海（图中浅蓝区）**给了造礁生物巨大的可开拓空间。

#### 6. GOBE 的成因（讲义列出三/四条）

1. **生境多样性 (diversity of habitats) 增加**——大陆离散造出大量新的浅海边缘；
2. **氧含量升高 (higher oxygen levels)**——大气与海洋的氧化；
3. **陨石撞击相关的环境变化**（这是本节最有意思的一条，老师详讲）：
   - **撞击可能通过制造一系列新的生境小生境 (habitat niches) 而加速了多样化**；
   - **频繁的撞击可能扰乱 (destabilized) 既有生态群落，使入侵种得以取代原有群落**——例如**底栖群落中腕足动物 (brachiopods) 取代三叶虫 (trilobites)**；
   - **低代谢速率的悬浮食性底栖生物更能承受、甚至受益于重大环境扰动**。
   - **证据**：已知撞击坑的年龄**集中在 GOBE 时段**，被认为与 **L-chondrite（L 型球粒陨石）母体小行星在 ~470 Ma 的解体事件** 有关。
   - **老师补充的数据点**：**L-chondrites 约占今天落到地球上陨石的 20%**。
   - 图题：*Ages of known impact craters potentially linked to the L-chondrite parent body breakup event*；标注 **"Increased meteorite flux — L-Chondrite asteroid break-up, ~470 Ma"**。

#### 7. 晚奥陶世的"准海洋型北半球" (quasi-oceanic Northern Hemisphere)

- 大陆全部位于**赤道附近或南极（Gondwana）**；
- **北半球约 95% 被 Panthalassic Ocean 占据**；
- 老师强调：**要体会这个泛大洋的尺度**——从北极和南极两个视角看的复原图能直观看出来。
- 图上标注：Siberia、Laurentia（赤道）、Baltica、Gondwana（南极）。

#### 8. 晚奥陶世 Hirnantian 冰期（赫南特冰期）

**基本参数（要记住）**：
- **时间：445 Ma**；
- **持续时间：仅约 0.5 Ma（50 万年）** —— 一次**相对短暂**的全球性冰期；
- **是显生宙的第一次大冰期**。

**地质证据：Tillite（冰碛岩）**
- **till（冰碛物）= 冰川搬运、冰融化后堆下的物质**；
- **tillite = 固结成岩 (lithified) 后的 till**；
- → **只有大量冰存在时才会有 tillite**；
- 图上以**黄点**标出 tillite 在 450 / 445 / 440 Ma 各时间片上的分布，**Gondwana 上的 tillite 高度集中在这 4–5 Myr 的窗口内**。

**多曲线综合图的判读（老师逐条讲，很典型的期末读图题）**：
| 曲线 | 在 Hirnantian 冰期附近的表现 |
|---|---|
| **全球属数 (green solid line)** | **大幅下跌**（= 大灭绝） |
| **大气 O₂** | 冰期前一路上升 → **突然骤降 → 略升 → 再降 → 冰期后回升**（剧烈震荡） |
| **海平面** | **持续下降，在冰期达到最低**（水被锁在大陆冰盖里） |
| **大气 CO₂** | 冰期前**高但在下降**；**穿过冰期本身 CO₂ 几乎没有明显变化**，且水平已经相当低 |

**CO₂ 的困境与"生物增强风化"假说（重点难点）**

老师专门花时间讲这个问题：
- **困境**：CO₂ 是主要温室气体，本应是温度的控制因子，但**记录里在冰期前后看不到明显的 CO₂ 变化**。
- **假说**：CO₂ 其实**被降低了**，只是现有记录没能分辨出来。机制是**生物增强的化学风化**：
  - 图：横轴 = 大气 CO₂（左→右增加），纵轴 = **全球风化量 (km³ rock/yr)**；
  - **abiotic（无生物）曲线**：风化速率随 CO₂ 上升而**缓慢增加**（酸性更强 → 化学风化更强）；
  - **biotic（有生物覆盖）曲线**：一旦把岩石表面**覆盖上 lichens（地衣）与 bryophytes（苔藓）等原始植物**，**风化速率大幅跃升**；
  - → **奥陶纪陆地上原始植物（地衣、苔藓）的扩张 → 强烈消耗 CO₂ → 全球降温 → 冰期**。
  - 讲义原文标注：*Enhanced chemical weathering of tropical Ordovician land masses / lichens and bryophytes that consumed CO₂*；配图为 *Weathering rates of siliciclastic rocks due to biotic versus abiotic mechanisms*。
- 老师的评价："**风化被生物增强这件事有点反直觉，但确实如此**"，并说这条曲线（指记录中的 CO₂ 曲线）**可能是不对的**。

#### 9. 晚奥陶世大灭绝的"两脉冲"模型（重要机制，必背）

大灭绝分**两次脉冲 (two pulses)**，图上用 **1st / 2nd** 标出：

**第一脉冲 (1st) —— 冰期开始时**
- 监测手段：**碳同位素 (carbon isotopes)**。老师的逻辑链：
  > **想扰动氧，最好的办法是扰动碳循环**——因为在地球上**氧与碳是紧密耦合的**；而监测碳循环最好的手段就是碳同位素。
- 观测：**到达第一次灭绝事件时，全球碳同位素记录发生重大变化** → 碳循环被扰动 → 连带影响氧。
- **物理杀伤机制**：**海平面快速下降约 100 m，抹除了大陆架上大片可居住的浅海带 (removed significant habitable belts of the shelf)**。

**第二脉冲 (2nd) —— 冰期结束时**
- 冰期期间，环境相对**稳定下来 (stabilized)**；深层海水中**逐渐积累了有毒的还原性水体（H₂S，硫化氢）**；
- **冰期结束、冰盖融化** → **大量冷而致密的冰融水加入海洋** → 因为**密度大而下沉到海底** → **把积存在底部的有毒 (H₂S) 水体顶了上来 (displaced)**；
- → 有毒水侵入浅海 → **第二次灭绝脉冲**；
- 同时**海平面急剧上升**。

> **总结记法**：**第一脉冲 = 海平面骤降（栖息地消失）+ 碳循环扰动；第二脉冲 = 冰融水翻转海洋、毒水上涌 (H₂S)。**

### （五）志留纪 Silurian（443.8 – 419.2 Ma）—— 中古生代的复苏

**四条要点（讲义）**：
1. **全球气候变暖，海平面下降，地球进入温室 (greenhouse) 阶段**；
2. **生物多样性持续恢复 (sustained recovery in biodiversity)**；
3. **陆生植物 (terrestrial plants) 演化**——具体是**维管植物 (vascular plants)**；
4. **第一批鱼类演化出现，礁体广泛发育**。

**构造背景（老师补充）**：此时大陆**已经过了最大离散点**，正开始踏上**重新聚合为超大陆的漫长道路**。

**礁的古纬度证据（很漂亮的一个对比图）**：
- 图 A：**今天**礁体的分布（红点）——**基本被限制在北纬 30° 到南纬 30° 之间**；
- 图 B：**志留纪化石礁的复原分布**——**同样被限制在几乎相同的古纬度带内**；
- → **结论：志留纪的礁与今天的礁在生态—纬度约束上高度相似**，都长在大陆边缘的浅海陆架上。
- **多样性数据**：一个志留纪礁体可包含 **13 个主要造礁生物类群、57 个物种**。

**另一条线索**：讲义有一张 *Changes in deposition of carbonate sediments over geological time* 图——碳酸盐沉积方式随地质时间的转变（微生物→后生动物主导的延续）。

### （六）志留纪—泥盆纪的大陆运动（444–359 Ma）

**三条主线（讲义）**：
1. **Laurentia + Baltica + Siberia 碰撞 = Laurasia**（劳亚大陆）；
   - ⚠️ 老师在课上把结果**口误说成了 "Laurentia"**；讲义写的是 **Laurasia**；这一时期文献中更常用的名字是 **Laurussia（劳俄大陆 / "Old Red Sandstone Continent"）**。三个名字指的是同一次拼合的产物，见易错点。
2. **发生数次造山运动 (orogenies) → 造山 (mountain building)**，其中最重要的是 **Caledonian Orogeny（加里东造山运动）**（Iapetus 洋关闭的直接结果）；老师还提到同期沿另一条带的 **Hercynian / Variscan orogeny**，并说"**你们不需要记住所有造山运动的名字**，重要的是知道**有一个重大的造山期**"。
3. **海平面下降 → 新出露的大陆遭受侵蚀 → 沉积厚层红层 (redbeds)**。

### （七）泥盆纪 Devonian（419.2 – 358.9 Ma）—— 老红砂岩与登陆

#### 1. Old Red Sandstone（ORS，老红砂岩）

- **沉积样式：Channel–floodplain cycles（河道—泛滥平原旋回）**，包括：
  - **红色氧化泥岩 (red oxidised mudstones)**；
  - **钙质结壳 (calcretes)**；
  - **河道充填 (channel fills)**。
- **古环境解读：ephemeral flow（间歇性/短暂水流）、semi-arid environment（半干旱环境）**。
- **红色的成因**：**陆相沉积物中的铁被氧化 (oxidised iron)** → 指示**干旱、强氧化的陆上环境，偶有地表水流**。
- **实例**：老师展示了**英格兰西南部 (southwest England)** 的泥盆系露头——地层**陡倾**，但可清楚看到一层层具特征红色的岩层。
- **沉积过程（老师的素描图讲解，与后面二叠纪红层通用）**：
  - 抬升的山体 → 暴风雨/山洪 (flash floods) → 最粗的碎屑在**山前形成砾岩 (conglomerates)**；
  - 较细的物质由**间歇性河流 (ephemeral rivers)** 带走 → 砂岩；
  - 最细的泥质被带到最远处；
  - 河流注入**湖泊**，湖泊干涸 → **蒸发岩**；
  - 同时有强烈的**风成作用 (wind action)** → **大型沙丘 (dunes)**，可保存于地层中。

#### 2. 遗迹化石作为古环境指示 (Trace fossils as palaeoenvironment indicators)

**为什么重要**：这种（干旱陆相）环境**很少保存完整的实体化石 (whole body fossils)**，但**遗迹化石常见**，能反推环境与造迹生物的行为。

讲义给的三个属名（要能对上号）：

| 遗迹化石 | 形态 | 造迹者 / 解释 |
|---|---|---|
| **Undichna** | 砂层表面上呈波状拖曳的痕迹，可见沉积物被沿轨迹推移 | **游泳的鱼 (swimming fish)** 鳍尖划出的痕迹 |
| **Diplichnites** | 一组横向排列的细小脊状痕（成对足迹列） | **节肢动物 (arthropods) 的行迹 (trackways)**，如**三叶虫 trilobites** |
| **Beaconites** | 具有细层理、呈 **U 形沟槽 (u-shaped furrow)** 的构造 | 某种潜穴生物的回填潜穴 |

> **老师的核心提醒**：**我们往往不知道这些造迹生物长什么样，但遗迹化石告诉我们当时的环境是什么样的。**

#### 3. 植物登陆与四足动物的起源

**时间线（讲义 + 转写）**：
- **晚志留世起**：**陆生节肢动物 (land arthropods)** 出现在**水边 (water margins)**；
- **志留纪**：**维管植物 (vascular plants) 首次保存**。
  - **老师给的定义**：**维管植物就是含 lignin（木质素）的植物，即"有木头"**。
  - **因果**：**一旦有了木质这种强力材料，植物就能长得高得多** → 出现**具根系的植物**，并在**泥盆纪变得更大**。
- **泥盆纪**：**能呼吸空气的鱼 (air-breathing fish) 演化** → **中泥盆世出现第一批四足动物 (tetrapods，即两栖类 amphibians)**；
  - 讲义配图：**Tiktaalik roseae**（提塔利克鱼，著名的"鱼—四足动物"过渡化石）；
  - 图轴标注：**Tetrapodomorph fish → Tetrapod amphibian**，跨越 **Givetian → Frasnian → Famennian**（泥盆纪的三个期）。
- **中石炭世**：出现 **羊膜卵 (amniotic egg) 与爬行动物 (reptiles)** → 脊椎动物彻底摆脱对水的繁殖依赖。

#### 4. 植被对大气与气候的反馈

> **讲义原句：Increased O₂, lowered CO₂ → global cooling（氧升高、CO₂ 降低 → 全球降温）**

**O₂–CO₂ 曲线的判读（老师逐段讲）**：
- **蓝线 = CO₂，红线 = O₂**；
- 志留纪（早期维管植物出现处）：**O₂ 上升、CO₂ 下降**；
- **今天 O₂ 占大气约 21%**；
- **石炭纪 O₂ 达到峰值，约 30%**。

#### 5. 根系演化如何改变了河流的形态（本讲最经典的"生物圈改造岩石圈"案例）

**观察事实**：**岩石记录中"曲流河 (meandering rivers)"的突然出现，与植物开始占领陆地在时间上同步。**

**推理**：
- **河道形态 (channel planform) 的主要控制因素是河岸的"强度" (the 'strength' of the banks)**。
- **Braided river（辫状河）**：沉积物**松软**、河岸无法约束水流 → 水流分成**多条河道**在地表铺开。
  - 实例：**Rangitata River, Canterbury Plains, New Zealand**。
- **Meandering river（曲流河）**：需要**坚固的河岸**才能维持**单一河道**。
  - 实例：**Río Socopo, Venezuelan Andes**。
- **今天陆生植物的根系使河岸具有黏聚性 (cohesive)** → 支持曲流形态。
- → **推论问题（讲义原文）：那么在陆生植物出现之前，河流是不是只有辫状的？**

> 这是本周最好用的"三圈耦合"例子：**biosphere（植物根系）→ geosphere（河岸强度、沉积构型）**，而且直接改写了整个陆相沉积记录的面貌。

### （八）石炭纪 Carboniferous（358.9 – 298.9 Ma）—— 冰室、煤与灰岩

#### 1. 古地理与气候（讲义四条）

- **晚古生代气候变冷**；
- **海退：海水从大陆上退出 (seas regressed from continents)**；
- **Laurussia（劳俄大陆）拼合于赤道与热带纬度** → **沼泽 (swamps) 发育 → 形成厚层煤 (thick coal deposits)**；
- **Gondwana 与 Siberia 位于较高纬度**，到**二叠纪时部分被冰盖覆盖**。
- **老师的关键补充**：此时**大陆基本上从一极连到另一极 (pole to pole)**，**像一道屏障一样阻挡洋流** → **屏障两侧的大洋连通性很差**。这对全球热量输送有重大影响。

#### 2. 大气氧化：O₂ 的峰值与"火窗口"

**O₂ 上升的三段式原因（讲义）**：
- **Ord–Sil（奥陶纪—志留纪）**：**陆生植物出现（光合作用）**；
- **Dev–Carb（泥盆纪—石炭纪）**：**有机质的埋藏 (burial of organic matter)**、**抗腐烂的木质素 (decay-resistant lignin) 的演化**、**森林与沼泽的大规模扩张**；
- **O₂ 下降的两个时期**：**早泥盆世**与**二叠纪末**；
- 根本调节因素：**陆地植被的变化，与气候及主要大陆的纬度位置相关**。

**"火窗口 (fire window)" —— 老师课上加的精彩内容（讲义上没有）**

> **在整个地球历史中，大气 O₂ 大体被限制在 15%–30% 之间。**
> - **低于 15%**：**木头无法燃烧**（无法维持燃烧）；
> - **高于 30%**：**木头一旦着火就无法熄灭**。
>
> → 石炭纪 O₂ 达到 ~30%，**几乎顶到了这个窗口的上边缘**：由**闪电或火山活动**点燃的火灾会演变成**全球性野火**，"基本上整个星球都会烧起来"。**这就是 O₂ 为什么不会继续升过 30% 的原因**（负反馈：氧越高，燃烧越多，越快消耗氧和有机碳）。

**巨型节肢动物**
- **Meganeura**：**翼展 70 cm 的巨型蜻蜓**；
- **Arthropleura**：巨型多足类（巨型马陆）。
- **传统解释**：石炭纪极高的大气 O₂ 支持了这些**巨型节肢动物 (megafauna)** 的体型（节肢动物靠气管系统被动扩散供氧，氧分压越高，体型上限越大）。
- ⚠️ **老师的谨慎态度**："some people have related this to the very high oxygen levels… **and I don't know if this is still the case**"——这是一个流行但**未必仍被完全接受**的解释。
- **石炭纪之后 O₂ 又开始下降**。

#### 3. 气候与海平面的旋回性（Cyclothems 的成因）

**讲义五条要点**：
- **石炭系地层显示强烈的旋回性 (strong cyclicity)**，响应于海平面变化；
- 海平面变化源自 **Gondwana 上极地冰盖的反复生长与消融**；
- **注意：这次冰期与"与现代相似的低大气 CO₂ 水平"同时发生**（→ 低 CO₂ 促成冰期，与奥陶纪那次形成对照）；
- **最广泛的冰川脉冲始于 Asbian 期，一直持续到中二叠世**；
- **海平面波动的周期性与 ~100 ka 的 Milanković 轨道偏心率 (orbital eccentricity) 周期相关**；
- **关键澄清（讲义特别写出，也是常见误解）**：**位于热带纬度的大陆是"间接地"通过海平面变化经历这次冰期的——它们本身并没有被冰川覆盖。**

#### 4. 石炭纪的两大标志性岩石

老师原话：**"石炭纪最出名的就是两种岩石：limestone 和 coal。"**

##### (a) 石炭纪灰岩 (Carboniferous Limestone)

- **形成条件（讲义原句）**：在**赤道纬度**，当**陆源碎屑输入 (siliciclastic input) 不太高**、且**海平面上升不太快**时，热带的沉积作用**以碳酸盐为主导**。
- **礁体的骨架群落 (framework community)**：由**微生物 (microbes)、海绵 (sponges)、苔藓虫 (bryozoans) 和珊瑚 (corals)** 组成的**包壳生物群 (encrusting biota)** 构建。
- **相组合（讲义列出的岩性序列，由浅到深/由礁到盆）**：
  - 厚层块状生物碎屑灰岩 (thickly bedded, massive, bioclastic limestones)；
  - 薄层生物碎屑灰岩夹燧石 (cherts) 与泥晶灰岩 (micritic limestones)，形成**泥丘 (mud mounds)**；
  - 灰岩砾岩与浊积岩 (limestone conglomerates and turbidites)，具**软沉积物变形构造 (soft-sediment deformation features)**；
  - 薄层含燧石细粒灰岩与暗色泥岩（最深水）。
- **礁与海平面的关系（老师）**：海平面上升时**礁能"跟上"上升速率而持续向上生长 (keep pace)**；海平面下降时**礁被暴露**。
- **今天的经济利用（英国实例）**：
  - **Coldstones Quarry, Greenhow, near Pateley Bridge, Yorkshire**；
  - **Tunstead Quarry, near Buxton, Derbyshire**（均在 **Peak District**）；
  - **主要用途：建筑骨料 (aggregate)**，另有其他工业用途。

##### (b) 晚石炭世煤系 (Coal Measures)

**煤是什么（讲义定义）**：
- **煤是植物成因的 (of vegetable origin)**；
- **岩石中 > 2/3 是固体有机质**；
- **含可见的植物残体 (visible plant remains)**；
- **从泥炭土壤到煤层之间存在所有过渡状态**。
- 实例：**Fossil Grove, Glasgow**（保存了原地直立的石炭纪树桩化石林）。

**煤化序列（按温度升高，必背）**：
> **Peat（泥炭）→ Lignite（褐煤）→ Bituminous Coal（烟煤）→ Anthracite（无烟煤）**
- **主要由温度控制，压力起次要作用**（老师明确说 "caused mainly by temperature but to some extent by pressure"）。
- **Peat = 最低级，Anthracite = 最高级**。

**成煤过程（七步因果链，讲义列点 + 老师讲解）**：
1. **植物物质在停滞水体中快速堆积**——例如**河流泛滥平原上的沼泽 (swamps) 或湖泊 (lakes)**；
2. **氧在氧化过程中被迅速耗尽**；
3. **水体变为缺氧 (anoxic)**，**部分分解的植物物质得以保存**（缺氧阻止木质腐烂）；
4. **洪水期河流周期性地把沉积物灌入沼泽**，把有机质**埋起来、与氧隔绝**（老师：被砂或泥"封"住）；
5. **在沉积物供给稀少的湖泊中，则堆积富有机质的泥**；
6. **埋藏与压实排出水分 → 形成泥炭 (peat)**；
7. **继续埋深 → 温度与压力升高 → 煤级 (grade) 提高**。

**现代类比 (modern analogue)**：
- **最接近的现代等价物是佛罗里达的 Everglades（大沼泽地）**；
- ⚠️ **老师的重要保留意见**："**今天并没有正在形成煤的地方**"，而且"**石炭纪的森林与现代森林非常不同，所以这并不是一个很好的类比**"。
- **石炭纪成煤沼泽植物的复原：成熟植株最高可达 30 m**。

### （九）Pangaea 的形成 —— 显生宙唯一的超大陆

- **形成方式**：**晚石炭世，两个超大陆 Laurussia 与 Gondwana 碰撞**；
- **造山事件：Variscan Orogeny（华力西造山运动），又称 Hercynian Orogeny（海西造山运动）**；
  - **命名趣闻（讲义写明）**：**Variscan 得名于日耳曼的 Varisci 部落**；
  - 产物：**Variscan Mountains（华力西山脉）**。
- **结果：形成唯一的超大陆 Pangaea**；
- **Pangaea 横跨赤道并向两极延伸 (straddled the equator and extended toward the poles)**；
- **对大洋环流的影响 (Effect on ocean circulation)**：从极到极的巨型陆块**阻断了纬向洋流**，是当时全球气候格局的主控因素之一。
- **核心提醒**：**Pangaea 是整个显生宙唯一的一次超大陆聚合**——它对应了海平面曲线的**最低点**（三叠纪）。

### （十）二叠纪 Permian —— 极端大陆性气候、沙漠与蒸发岩

#### 1. 高纬度环境

- 复原图：**早二叠世最深冰期条件下的 Gondwana 冰盖**；
- 老师补充：小地图显示**南极区 Gondwana 各冰体的位置与流动方向**（叠在今天大陆位置上表示）。

#### 2. 低纬度环境（讲义三条要点）

- **海平面处于最低点**，原因是**大陆全部拼合成超大陆 Pangaea**；
- **0–45° 纬度带为干旱与半干旱气候，季节性极端 (extreme seasonality)**——这是**巨大的大陆内部造成的"大陆性气候" (continental climate)**；
- **植物群更替**：**石炭纪的 pteridophytes（蕨类植物，靠孢子 spores 繁殖）被 gymnosperms（裸子植物，靠种子繁殖 seed-bearing）取代**。
  - **因果**：靠孢子繁殖需要潮湿环境；种子（尤其配合羊膜卵式的干燥适应）才适合干旱、季节性强的内陆——**气候变干直接筛选出了种子植物**。

#### 3. 二叠纪沙漠

- **背景事件：Carboniferous Rainforest Collapse（石炭纪雨林崩溃）**——留下了**大陆内部广袤的沙漠区**。
- **典型沉积序列（讲义原文的演进箭头）**：
  > **底砾岩与含砾砂岩（间歇性河流 ephemeral streams 沉积）→ 风成沙丘场 (aeolian dune fields) → 干盐湖沉积 (playa lake deposits)**
- **实例**：**Ballochmyle Quarry, Mauchline, Ayrshire（苏格兰）** 的**大尺度风成沙丘层理 (large scale aeolian dune bedding)**。
- **红层 (redbeds)** 同样广泛发育 → 指示**陆相 + 强氧化条件**。

#### 4. Zechstein Sea 与蒸发岩沉积（本讲最"化学"的一节）

**Zechstein Basin（蔡希施泰因盆地）基本事实**：
- **时代：晚二叠世 (late Permian)**；
- **蒸发岩厚度：1200 m（= 1.2 km）**；
- **地理范围**：从**英格兰北部**延伸经**北海**到**欧洲（德国、瑞典）**；英国境内相关的还有 **Cheshire Basin（柴郡盆地）**。
- **矿物分带 (zonation)**：**盆地边缘以硫酸盐与碳酸盐矿物为主；盆地中心以氯化钠与富钾盐类为主**。（→ 这正是蒸发结晶顺序在空间上的投影。）
- **经济意义（老师强调）**：**蒸发岩是重要的可开采资源，是包括英国在内许多国家化学工业的基础。**

**海水的化学组成（讲义按重量百分比递减排列，要背顺序）**：
> **海水通常含 3.5 wt% 的溶解盐类。**
> **Chloride (Cl⁻) > Sodium (Na⁺) > Sulphate (SO₄²⁻) > Magnesium (Mg²⁺) > Calcium (Ca²⁺) > Potassium (K⁺)**

**蒸发岩的沉淀顺序（随蒸发程度增加，必背）**：
> **carbonates（碳酸盐）→ Gypsum（石膏 CaSO₄·2H₂O）→ Halite（岩盐 NaCl）→ K- and Mg-salts（钾盐与镁盐）**
- **规律**：**溶解度最小的先沉淀**；**每种矿物沉淀出来的量取决于该组分在海水中的丰度**。

**定量结果（讲义的经典算题，要记住数字）**：
> **将 1000 m 深的海水完全蒸干，只剩下约 16.5 m 厚的盐类：**
> | 矿物 | 厚度 |
> |---|---|
> | **Carbonate（碳酸盐）** | **~0.1 m** |
> | **Gypsum（石膏）** | **~0.6 m** |
> | **Halite（岩盐）** | **~12.9 m** |
> | **Mg and K salts（镁盐与钾盐）** | **~2.9 m** |
> | **合计** | **~16.5 m** |

**老师用这个数字做的关键推算（非常重要的量级感）**：
> Zechstein 的蒸发岩厚 **1.2 km**；而 **1 km 海水只能产出十几米的蒸发岩**；
> → **必须有"许多许多千米"厚的海水被反复蒸干** → **单次蒸干绝无可能，必须有持续补给机制。**

**"Barred basin"（阻隔盆地）沉积模型 —— "蒸发皿 (evaporating dish)" 过程**

**三个必要条件（讲义原文，必背）**：
1. **Barrier（障壁）**——使水体能被蒸发到高盐度而不被自由的大洋水稀释；
2. **Mechanism to replenish brine（补充卤水的机制）**——周期性越过障壁补水，使蒸发能长期持续；
3. **Accommodation（可容空间）**——容纳厚层盐类堆积的空间。

**老师讲的三种模型变体**：
- **(i) 深盆—浅水 (deep basin, shallow water)**：起始为深盆但水浅，蒸发成盐层，然后**越过障壁周期性补水**，层层叠加 → 可积累**千米级**厚度；
- **(ii) 断陷补偿型**：盆地边缘发育**断层 (faults)**，盆地沿断层**持续沉降 (subside)** → 不断制造可容空间 → 积累巨厚蒸发岩（同样需要持续补水）；
- **(iii) 深盆—深水 (deep basin, deep sea)**：这种情况下**蒸发结晶主要发生在盆地边缘**，晶体必须被**搬运到盆地深部再沉积 (transported and re-deposited)**。
- **参照物**：**Death Valley, California（死谷）** 作为现代干盐湖/蒸发环境实例。

### （十一）尾声：进入中生代 Mesozoic（下周预告）

- **Mesozoic = "middle life"（中间的生命）**；
- **二叠纪—三叠纪界线 (Permian–Triassic boundary)**：以**过去 5 亿年中全球生物多样性最大的一次崩溃**开场，**重新导向了中生代与新生代的演化进程**。
- **三个纪的时长**：
  | 纪 | 时长 |
  |---|---|
  | **Triassic 三叠纪** | **50.6 Myr** |
  | **Jurassic 侏罗纪** | **56.3 Myr** |
  | **Cretaceous 白垩纪** | **79 Myr** |
- **命名由来（讲义特意列出，很好记也很可能被问）**：
  - **Triassic**：来自 *tri* = "three"，因为在**西北欧**普遍发育**三套截然不同的岩层**；
  - **Jurassic**：来自**瑞士与法国边界上的 Jura Mountains（汝拉山脉）**；
  - **Cretaceous**：来自拉丁文 ***Creta* = 白垩 (chalk)**，即"含白垩的"。

### 图 2：海平面变化机制的"振幅 vs 时间尺度"图

- **纵轴对数：1 m → 1 km 振幅；横轴：1 yr → 100 Myr**；
- **左上区（10–100 ka，百米振幅）= 冰量**；同区较小振幅 = **盐度、温度、陆上地下水与湖泊**；这一组**共同被 Milanković 轨道周期锁定**；

- **判读方法**：给你一个海平面变化的**振幅 + 持续时间**，就能定位到机制场。

### 图 3：海侵 / 海退的地层柱判读图

- 左：海平面高低轴；右：地层柱；

- **判读口诀**：**向上变深 = 海侵；向上变浅 + 不整合封顶 = 海退。**

### 图 4：大陆沉积/不整合的时空图（Supersequences）

- 横轴 = **穿越大陆的空间剖面（边缘—内陆—边缘）**；纵轴 = **时间**；

- **判读**：**黄色带 ↔ 被淹面积最小 ↔ 海平面最低 ↔ 海底扩张弱**。

### 图 5：奥陶纪各大洋宽度随时间变化图

- 横轴 = 奥陶纪时间；纵轴 = 洋宽（0 → ~8000 km）；

- **交叉点 = 大陆最大分离 = 洋面积最大 = 海平面最高**（3000–4000 km 的分离）。

### 图 6：晚奥陶世多参数综合图（Hirnantian）

五条曲线同框判读：**全球属数（骤降）／大气 O₂（剧烈震荡）／海平面（降至极小）／大气 CO₂（高但下降，穿越冰期无明显变化）／碳同位素 δ¹³C（第一次灭绝处发生重大偏移）**；蓝色竖带 = 冰期区间（445 Ma，历时 0.5 Myr）；箭头 1st / 2nd = 两次灭绝脉冲。

### 图 7：生物 vs 非生物风化速率图

- 横轴 = **大气 CO₂（左→右递增）**；纵轴 = **全球风化量 (km³ rock/yr)**；
- **两条曲线**：**abiotic（缓升）** 与 **biotic（显著更高）**；
- **含义**：**地衣与苔藓的出现使同样 CO₂ 水平下的风化速率大幅提高 → 加速消耗 CO₂ → 降温**。

### 图 8：显生宙 O₂ 与 CO₂ 曲线

- **红线 = O₂，蓝线 = CO₂**；
- 关键坐标：**今日 O₂ = 21%**；**石炭纪 O₂ 峰值 ≈ 30%**；**O₂ 的地质学界限 = 15%–30%（火窗口）**；
- **CO₂ 在石炭纪极低**（与现代相当）→ 支撑晚古生代大冰期。

### 图 9：礁的古纬度分布对比图

- 今天礁体（红点）**限于 30°N–30°S**；志留纪化石礁复原后**分布于相同古纬度带** → 生态约束跨越 4 亿年基本不变。

### 图 10：河流平面形态分类图

- **Braided（辫状）**：多河道，**河岸软**；实例 **Rangitata River, NZ**；
- **Meandering（曲流）**：单河道，**河岸强/黏聚**；实例 **Río Socopo, Venezuelan Andes**；
- **主控因素 = 河岸强度**；**植物根系 = 强度的来源**。

### 图 11：海水离子丰度柱状图与蒸发岩序列图

- 柱状图：**Cl > Na > SO₄ > Mg > Ca > K**（重量百分比递减）；
- 序列图：**carbonates → gypsum → halite → K/Mg salts**（蒸发程度递增方向）；

### 图 12：Barred basin 沉积模型图

三种几何：**浅水深盆 + 障壁**、**断层控制的持续沉降盆**、**深水深盆（边缘结晶 + 再搬运）**；三要素恒定：**barrier + brine replenishment + accommodation**。

## 四、课堂补充（transcript 有、slides 没有的内容）

1. **显生宙 ≈ 冥古宙的时长**——用这个类比感受"看得见的生命史"其实只占地球史的一小部分。
2. **用遗迹化石定义纪的底界非常反常**，而且 *Treptichnus pedum* 现在**在埃迪卡拉纪地层里也有报道**，这个 GSSP 定义本身存在争议。
3. **遗迹化石的本质**：只保存痕迹不保存本体，**我们不知道造迹生物长什么样**。
4. **水量恒定假设的明说**："**we've always had the same amount of water present on Earth at all times during geological history**"——这是海平面推理链的隐含前提，务必记住。
5. **超大陆下方"捕获对流热"的机制**：热被困在超大陆之下 → 增加浮力 → 超大陆整体抬高 → 海平面进一步相对下降。（这是机制二，讲义只写了一句，老师展开讲了。）
6. **相对海平面的"湿脚"例子**：t1 站在那儿会湿脚，t2 已在海面之上，**但水一滴没少**。
7. **海底扩张抬升洋底的物理原因**：上涌的热与熔融**给洋底增加浮力、把它顶起来**，从而抬高海平面——不是"洋壳变多了"，而是"洋底变浅了"。
8. **测海平面需要固定基准**，例如**地心**。
9. **有孔虫是单细胞生物**，生活在不同深度与位置，用其**碳酸钙壳的氧同位素**反演当时海水条件。
10. **不整合对比必须是跨大陆的大型不整合**，不能用局部不整合去推全球海平面。
11. **"大陆内部有沉积 ≠ 整个大陆被淹"**，更可能是**存在大量内陆海**。
12. **英国寒武系露头稀少**（北威尔士、爱尔兰西部、苏格兰西北），且讲义地图上**寒武系与石炭系配色相同**易混。
13. **寒武系底部不整合 = workshop 上画过的 Grand Canyon 那条不整合，是全球性的**——把 practical 和 lecture 明确挂钩。
14. **"Rodinia 时期高 CO₂、低 O₂、总体炎热，雪球地球之间是 hothouse"**——这是理解寒武纪富金属海洋的前提。
15. **passive margin 的通俗定义**："那些边缘上没有地质过程在进行，只是随着大陆彼此分开被拖着走"。
16. **早寒武世 SST 与今天的定量对比**：极地 15 °C（今天几度）、赤道 >35 °C（今天不超过 30 °C）。
17. **约 13 条主要动物谱系在寒武纪首次出现**（对应讲义的粗黑线图）。
18. **calcrete/evaporite 的古气候本质** = **蒸发量超过降水量**；要理解"先在今天的大陆上找到它们，再把大陆复原回古位置"这套方法。
19. **L-chondrites 占今天陨落陨石的约 20%**——这个数字讲义没有。
20. **"想扰动氧，最好的办法是扰动碳循环，因为地球上氧与碳紧密耦合；监测碳循环靠碳同位素。"** 这是理解晚奥陶世 O₂ 剧烈震荡的关键逻辑。
21. **"生物增强风化有点反直觉，但确实如此"**，而且老师明说**记录中那条 CO₂ 曲线可能是不对的**——提醒你古 CO₂ 代用指标本身有不确定性。
22. **"火窗口" 15%–30%** 的完整论证（低于 15% 木头烧不着，高于 30% 火灭不掉）——**这是讲义完全没有的高价值内容**。
23. **对"高氧造就巨虫"的保留态度**："我不确定这个说法现在是否还成立"。
24. **"石炭纪最出名的是两种岩石：limestone 和 coal。"**
25. **礁能"跟上"海平面上升 (keep pace)**，海平面下降时被暴露。
26. **今天地球上没有正在形成煤的地方**，Everglades 只是"最好的近似"，而且**石炭纪森林与现代森林差异很大，类比并不好**。
27. **石炭纪—二叠纪的大陆从极到极，像屏障一样阻断洋流**，两侧大洋连通性差。
28. **红层的成因素描图**（山体 → 山洪 → 山前砾岩 → 间歇河搬砂 → 远处泥 → 湖泊干涸出蒸发岩 → 风成沙丘），这套模型**泥盆纪 ORS 与二叠纪沙漠通用**。
29. **蒸发岩是英国等国化学工业的基础**，具有重大经济意义。
30. **1.2 km Zechstein 盐 vs 1 km 海水只出十几米盐**的量级推算——用来论证"必须有持续补给"。
31. **老师明确说不需要背下所有造山运动的名字**，重点是理解"有一个重大造山期"这件事。
32. **课程节奏**：中途有 5 分钟休息，后半段老师明显赶进度（"I'll rattle through the rest of it"）——后半段（志留纪之后）讲义信息密度高于课堂讲解，**复习时要以讲义为准补足**。

## 六、易错点 / 重点难点

### A. 老师口误 / 材料本身的错误（复习时按正确版本记）

1. **"at the end of the Paleozoic you had Rodinia"** —— 口误。**应为 at the end of the Proterozoic**（Rodinia 是新元古代超大陆）。
2. **"Phanerozoic extends from 250 to 66 million years"** —— 口误。**说的是 Mesozoic**（251.9–66.0 Ma）。Phanerozoic 是 538.8 Ma 至今。
3. **"Laurentia, Baltica and Siberia joined together to form a continent called Laurentia"** —— 口误。**产物是 Laurasia（讲义写法）/ Laurussia（更常用、老师后文自己也用了 "Laurussia"）**，绝不是 Laurentia（Laurentia 是其中一个原料）。
4. **"anhydrite which is hydrous calcium sulfate"** —— **讲义和口述都错了**。**Anhydrite 是无水硫酸钙 CaSO₄（an-hydrite = 无水）；含水的是 Gypsum 石膏 CaSO₄·2H₂O。**
5. **讲义拼写错误**：`Reic Ocean` → **Rheic Ocean**；`Rodina` → **Rodinia**；`Calendonian` → **Caledonian**；`Milanković` 有时写作 `Milankovic`；`Pangea/Pangaea` 混用；`Eva orite de osition` 是 PDF 转写破损，应为 **Evaporite deposition**。
6. **文件名 "Week 9"** —— 是原始材料命名遗留，**本周实为 Week 8**。

### B. 概念性易混淆点

7. **Cambrian Explosion vs GOBE**：**寒武纪大爆发出现的是"门 (phyla)"层级的新类型；GOBE 才是"科/属/种"层级多样性的暴涨**。二者不是同一件事，也不能互换。
8. **Eustatic vs Relative sea level**：**eustatic 改变了水量/水的体积/洋盆体积（全球性）；relative 只是陆地在上下动（局部性），水一点没变**。讲义还给了第三层定义——**relative sea level = eustasy + subsidence + sediment supply 的平衡**。
9. **超大陆聚合 → 海平面低**，不是高。两条机制：**造山缩短使陆壳面积减小 → 洋盆变大**；**下方热堆积 → 超大陆抬高**。
10. **海底扩张抬高海平面的原因是"洋底被顶起来变浅了"**，不是"水变多了"。
11. **Transgression 的地层是向上变深**（陆相→浅海→深海），**Regression 是向上变浅并以不整合收尾**。这两个方向常被记反。
12. **热带大陆在石炭纪冰期并未被冰川覆盖**——它们只是**间接地通过海平面变化**感受到冰期。这是讲义特意点出的常见误解。
13. **奥陶纪与石炭纪两次冰期的 CO₂ 情形不同**：
    - **Hirnantian**：记录中 **CO₂ 穿越冰期几乎没变**（这是个难题），只能靠"生物增强风化"假说来解释可能存在但未被记录到的 CO₂ 下降；
    - **晚古生代冰期**：**CO₂ 明确很低（与现代相当）**，与冰期成因一致。
14. **晚奥陶世大灭绝有两个脉冲，杀伤机制完全不同**：**1st = 海平面骤降 100 m 消灭陆架栖息带（伴碳循环扰动）；2nd = 冰融冷水下沉、把底层有毒 H₂S 水体顶上来。** 常见错误是只记住"冰期造成灭绝"。
15. **"火窗口" 15%–30%** 的两端含义别记反：**<15% 烧不着；>30% 灭不掉**。
16. **煤化序列的顺序与主控因素**：**Peat → Lignite → Bituminous → Anthracite**；**主要由温度控制**（压力次要）——不要写成"主要由压力控制"。
17. **蒸发岩沉淀顺序**：**碳酸盐 → 石膏 → 岩盐 → K/Mg 盐**（溶解度小的先出）。空间上体现为**盆缘硫酸盐/碳酸盐、盆心 NaCl 与钾盐**的分带。
18. **Barred basin 的三个必要条件缺一不可**：**barrier + brine replenishment + accommodation**。只有障壁而无补给，蒸干一次就没了，凑不出千米级盐层。
19. **"Pangaea 是显生宙唯一的超大陆"**——不要把 Rodinia（元古宙）也算进显生宙。
20. **Variscan = Hercynian**，是同一次造山的两个名字；它形成 Pangaea。**Caledonian** 则是更早的（志留—泥盆），由 **Iapetus 关闭**造成。别把两者搞混。
21. **生物矿化是多个类群独立起源的**，不是从一个共同祖先继承来的；而且**是先有小骨片/小壳，后有大骨骼**。
22. **Everglades 类比要打折扣**：今天没有正在成煤的环境，且石炭纪森林与现代森林差异很大。
23. **Milanković 100 ka 偏心率周期**控制石炭系旋回；短尺度（10–100 ka）海平面机制都被轨道参数绑在一起。
24. **同名不同物**：**Laurentia（劳伦，北美核心）≠ Laurussia/Laurasia（劳俄/劳亚，Laurentia+Baltica+Siberia 拼合体）**。
25. **奥陶纪三个洋的方向要记对**：**Iapetus 在关，Rheic 与 Aegir 在开。**

| **Small shelly fossils** | 小壳化石 | 毫米级的早期矿化化石，旧时用来定义寒武系底界。 |
| **Trace fossil** | 遗迹化石 | 生物活动留下的痕迹（爬痕、潜穴、足迹），不保存本体，但强烈指示古环境。 |
| **Mass extinction** | 大灭绝 | 30%+ 物种灭绝、跨多种生态、全球性、短期内发生的事件。 |
| **Genus / genera** | 属 | 分类阶元；晚二叠世灭绝中约 84% 的属消失。 |
| **Eustatic sea level (ESL)** | 全球海平面 | 由海水质量/体积或洋盆体积改变引起的全球性海平面变化。 |
| **Relative sea level** | 相对海平面 | 由陆地抬升/沉降（垂向构造）造成的局部海平面变化；水量不变。也可定义为 eustasy + 沉降 + 沉积供给的平衡。 |
| **Transgression** | 海侵 | 海平面上升、岸线向陆迁移；地层向上变深（陆相→浅海→深海）。 |
| **Regression** | 海退 | 海平面下降、岸线向海迁移；地层向上变浅并常以不整合收尾。 |
| **Unconformity (U/C)** | 不整合 | 沉积间断面；跨大陆同龄不整合被用作全球海平面变化的证据。 |
| **Supersequence** | 超层序 | 由大不整合限定的 10–100 Myr 尺度沉积旋回，最早在北美识别。 |
| **Seafloor spreading** | 海底扩张 | 洋中脊生成新洋壳；扩张强时洋底被顶高，海平面上升。 |
| **Orogeny** | 造山作用 | 大陆碰撞导致地壳缩短增厚、形成山脉。 |
| **Milanković cycles** | 米兰科维奇旋回 | 地球轨道参数（偏心率、斜率、岁差）驱动的 10–100 ka 尺度气候/海平面周期；石炭系旋回对应 ~100 ka 偏心率。 |
| **Foraminifera** | 有孔虫 | 单细胞海洋生物，其 CaCO₃ 壳的 δ¹⁸O 用于反演 <200 Ma 的海平面/温度。 |
| **Rodinia** | 罗迪尼亚超大陆 | 新元古代超大陆，地势高，其裂解引发寒武纪大海侵。 |
| **Snowball Earth** | 雪球地球 | 新元古代的全球性冰封事件；其间歇期为极热的温室期。 |
| **Laurentia** | 劳伦大陆 | 北美克拉通核心。 |
| **Baltica / Siberia / Kazakhstan** | 波罗的 / 西伯利亚 / 哈萨克斯坦陆块 | 古生代主要中小陆块。 |
| **Gondwana** | 冈瓦纳大陆 | 巨型南方大陆，古生代从极地延伸到赤道；晚奥陶世与晚古生代冰盖的载体。 |
| **Laurussia / Laurasia** | 劳俄大陆 / 劳亚大陆 | Laurentia + Baltica + Siberia 拼合而成（志留—泥盆），亦称老红砂岩大陆。 |
| **Pangaea** | 泛大陆 / 联合古陆 | 显生宙唯一的超大陆，晚石炭世由 Laurussia 与 Gondwana 碰撞形成，横跨赤道达两极。 |
| **Panthalassic Ocean** | 泛大洋 | 巨型古大洋；晚奥陶世占据北半球约 95%。 |
| **Iapetus Ocean** | 雅皮特斯洋 / 原大西洋 | 奥陶纪初宽 >4000 km，整个奥陶纪持续关闭，其闭合导致 Caledonian 造山。 |
| **Rheic Ocean / Aegir Ocean** | 瑞亚克洋 / 埃吉尔洋 | 奥陶纪持续张开的两个大洋。 |
| **Passive margin** | 被动大陆边缘 | 无活动构造过程的大陆边缘，随大陆漂移被动移动；提供大量新浅海生态位。 |
| **Biomineralization** | 生物矿化 | 生物构建矿化硬体（壳、骨骼）的过程；寒武纪在多个类群中独立发生。 |
| **Sclerite** | 骨片 / 硬片 | 大型动物体表的单个矿化"铠甲"部件，比完整骨骼更早出现。 |
| **Bilaterian / Metazoan** | 两侧对称动物 / 后生动物 | 生物矿化独立发生的主要类群范畴。 |
| **NOE (Neoproterozoic Oxygenation Event)** | 新元古代氧化事件 | 大气与海洋氧含量升高，是寒武纪大爆发的环境前提之一。 |
| **Cambrian Explosion** | 寒武纪大爆发 | 主要动物门 (phyla) 在寒武纪集中出现的事件。 |
| **GOBE (Great Ordovician Biodiversification Event)** | 奥陶纪生物大辐射事件 | 科/属/种层级多样性在奥陶纪的两次爆发式增长。 |
| **Calcrete** | 钙质结壳 | 干旱—半干旱区的风化壳，由方解石、白云石、石膏、岩盐、铁氧化物胶结砂粉砂而成；指示蒸发>降水。 |
| **Evaporite** | 蒸发岩 | 由浓缩盐水析出的层状盐类（岩盐、钾盐、石膏、硬石膏、钾盐类），可海相或湖相。 |
| **Laterite** | 红土 | 热带型土壤；出现在高古纬度指示当时全球炎热。 |
| **Stromatolite** | 叠层石 | 微生物席构建的层状碳酸盐建造，前 GOBE 时代的主要造礁者。 |
| **Bryozoa** | 苔藓虫 | 群体生活的小型无脊椎动物，建造碳酸盐骨架，GOBE 后重要造礁者。 |
| **Stromatoporoid** | 层孔虫 | 一类海绵，古生代重要造礁生物。 |
| **Brachiopod / Trilobite** | 腕足动物 / 三叶虫 | 奥陶纪底栖群落中腕足取代三叶虫，被认为与撞击扰动有关。 |
| **Deposit-feeder / Suspension-feeder** | 沉积食性者 / 悬浮食性者 | 寒武纪底栖以前者为主，奥陶纪转为后者主导，后者代谢率低、更抗扰动。 |
| **Mud mound** | 泥丘 | 由微生物/泥晶碳酸盐构成的丘状建造，GOBE 与石炭纪均常见。 |
| **L-chondrite** | L 型球粒陨石 | 占今天陨落陨石约 20%；其母体小行星约 470 Ma 解体，导致撞击通量激增，可能助推 GOBE。 |
| **Hirnantian glaciation** | 赫南特冰期 | 445 Ma、历时约 0.5 Myr 的显生宙首次大冰期，伴随两脉冲大灭绝。 |
| **Till / Tillite** | 冰碛物 / 冰碛岩 | 冰川搬运堆积的杂乱沉积物及其固结成岩产物，是冰川作用的直接证据。 |
| **Lichen / Bryophyte** | 地衣 / 苔藓 | 奥陶纪的原始陆地生物，大幅增强化学风化、消耗 CO₂，可能触发 Hirnantian 冰期。 |
| **H₂S bottom water** | 硫化氢底层水 | 冰期期间积累的有毒还原性深层水，冰融冷水下沉将其顶上，造成第二次灭绝脉冲。 |
| **Vascular plant** | 维管植物 | 含 lignin（木质素）的植物；木质提供强度使植物长高、生根。 |
| **Lignin** | 木质素 | 抗腐烂的高分子，其演化促成有机碳埋藏与 O₂ 升高，也是成煤的物质基础。 |
| **Tetrapod / Tetrapodomorph** | 四足动物 / 四足形类 | 由能呼吸空气的鱼演化而来；中泥盆世出现第一批两栖类。 |
| **Tiktaalik roseae** | 提塔利克鱼 | 著名的鱼—四足动物过渡化石。 |
| **Amniotic egg** | 羊膜卵 | 中石炭世出现，使爬行动物彻底摆脱对水体繁殖的依赖。 |
| **Old Red Sandstone (ORS)** | 老红砂岩 | 泥盆纪陆相红层，由河道—泛滥平原旋回、红色氧化泥岩、钙结壳和河道充填组成，指示半干旱间歇流环境。 |
| **Redbeds** | 红层 | 铁被氧化而呈红色的陆相沉积，指示干旱强氧化环境。 |
| **Undichna / Beaconites / Diplichnites** | （遗迹属名） | 分别为游泳鱼的划痕、U 形层状潜穴、节肢动物行迹。 |
| **Braided river / Meandering river** | 辫状河 / 曲流河 | 前者多河道、河岸软；后者单河道、需坚固河岸；根系使河岸黏聚，促成曲流化。 |
| **Channel planform** | 河道平面形态 | 河流在平面上的几何样式；主控因素是河岸强度。 |
| **Caledonian Orogeny** | 加里东造山运动 | 志留—泥盆纪，Iapetus 洋闭合造成的造山事件。 |
| **Variscan / Hercynian Orogeny** | 华力西 / 海西造山运动 | 晚石炭世 Laurussia 与 Gondwana 碰撞形成 Pangaea 的造山事件；得名于日耳曼 Varisci 部落。 |
| **Fire window** | 火窗口 | 大气 O₂ 被限制在约 15%–30%：低于 15% 木材不能燃烧，高于 30% 火无法熄灭。 |
| **Meganeura / Arthropleura** | 巨脉蜻蜓 / 节胸蜈蚣 | 石炭纪巨型节肢动物（前者翼展 70 cm），常被归因于高 O₂（老师对此持保留）。 |
| **Cyclicity / cyclothem** | 旋回性 / 旋回层 | 石炭系因 Gondwana 冰盖消长引起海平面波动而形成的重复地层序列。 |
| **Asbian** | 阿斯比期 | 石炭纪的一个期，最广泛的冰川脉冲自此开始，延续至中二叠世。 |
| **Peat → Lignite → Bituminous coal → Anthracite** | 泥炭→褐煤→烟煤→无烟煤 | 煤级序列，主要由温度（其次压力）控制。 |
| **Coal measures** | 煤系 | 石炭纪含煤地层，英国工业革命的资源基础。 |
| **Anoxic** | 缺氧的 | 沼泽水体氧被耗尽，阻止植物残体腐烂，是成煤的必要条件。 |
| **Pteridophyte / Gymnosperm** | 蕨类植物 / 裸子植物 | 前者靠孢子繁殖（石炭纪主导），二叠纪干旱化后被靠种子繁殖的后者取代。 |
| **Carboniferous Rainforest Collapse** | 石炭纪雨林崩溃 | 留下二叠纪大陆内部的广袤沙漠。 |
| **Aeolian dune** | 风成沙丘 | 风力堆积形成的大型交错层理沙丘，见于二叠纪沙漠（如 Ballochmyle Quarry）。 |
| **Playa lake** | 干盐湖 | 内陆间歇性湖泊，干涸后留下蒸发岩。 |
| **Zechstein Basin** | 蔡希施泰因盆地 | 晚二叠世盆地，从英格兰北部经北海至德国、瑞典，含 1200 m 厚蒸发岩。 |
| **Halite / Sylvite / Gypsum / Anhydrite** | 岩盐 / 钾盐 / 石膏 / 硬石膏 | NaCl / KCl / CaSO₄·2H₂O / CaSO₄（无水）。 |
| **Barred basin** | 阻隔盆地 | 蒸发岩沉积模型：需障壁、卤水补给、可容空间三要素（"蒸发皿"过程）。 |
| **Accommodation** | 可容空间 | 可以容纳沉积物堆积的空间，由沉降或海平面上升提供。 |
| **Continental flooding** | 大陆泛滥 | 海平面上升导致大陆被浅海/内陆海覆盖，可用被淹面积（10⁶ km²）量化。 |
| **Greenhouse / Icehouse state** | 温室态 / 冰室态 | 无永久极地冰盖 vs 存在大规模极地冰盖的两种地球气候状态。 |
