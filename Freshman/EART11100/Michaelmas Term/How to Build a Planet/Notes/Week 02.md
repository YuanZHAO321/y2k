## 二、核心概念

### 0. 回顾：大爆炸理论的三大支柱 (Three pillars of Big Bang theory)

老师开场花了几分钟复述 Week 1，务必记牢，因为本周所有内容都建立在此之上：

1. **宇宙膨胀的观测证据——宇宙学红移 (cosmological redshift)**。红移与距离的关系给出宇宙年龄约 **13.7 Ga**（课件用 13.7 billion years，口头用 13.65 Ga，两者都可）。
2. **氢和氦在宇宙中极为丰富**。原因是：与其他所有元素不同，今天观测到的氢氦丰度**几乎全部**是在**大爆炸核合成 (Big Bang Nucleosynthesis, BBN)** 期间产生的，而不是后来在恒星里造的。
3. **宇宙微波背景 (Cosmic Microwave Background, CMB) 的性质**。它是大爆炸的残余辐射：原本是**极短波长的伽马射线光子**，经过 130 多亿年的红移，波长被拉长到**微波波段**。CMB 标志着**宇宙变透明的那一刻**：温度降到氢原子核能俘获电子而**复合 (recombination)**，物质与光子**退耦**，光子得以自由逃逸。

> 因果链要记牢：温度下降 → 电子与氢核复合 → 光子不再被自由电子散射 → 宇宙透明 → 这批逃逸的光子红移至今 = CMB。

### 1. 宇宙黑暗时代 (Cosmic Dark Ages)：380 kyr < t < 150 Myr

**状态**：宇宙已经透明，但**还没有恒星**，所以是"黑"的。物质构成是一层弥散的"雾"：**约 75% 氢 + 25% 氦**，另外由**暗物质 (dark matter)** 主导质量。

**暗物质的关键性质**：所谓"暗"，意思是**这些质量不与辐射（光）发生可测量的相互作用**——它不发光、不吸光、不反光，只通过**引力**表现自己。

**结构形成的因果链（非常重要，考点）**：
1. 暗物质在自身引力作用下**成团 (clumping)**；
2. 团块连成**丝状结构 (filamentous pattern / cosmic web)**，丝与丝相交处形成**节点 (nodes/junctions)**；
3. **这套丝状网络最终决定了整个宇宙的大尺度结构**（即星系分布在哪里）；
4. 普通物质（氢、氦）落入这些引力势阱，**在丝状结构的交汇节点处堆积**，形成**盘状团块 (disk-shaped clumps)**；
5. 团块在自身引力下**收缩 → 密度升高 → 压力升高 → 温度升高**；
6. 质量达到**数百个太阳质量 (100s of solar masses)** 的团块，最先点燃成为第一批恒星。

课件配图是暗物质分布的数值模拟：暗区为暗物质，明亮的橙色斑点出现在丝状结构交点处，就是最早的恒星/星系诞生地。

**恒星平衡 (stellar equilibrium) 的建立**：核心温度升高到能**聚变氢核**（氢即 ¹H，只有一个质子，所以本质是质子相撞聚变并释放能量）→ 释放能量产生**气体压力 + 辐射压力**（向外）→ 与**引力**（向内）达成平衡 → 恒星停止塌缩，稳定在某个尺寸。这就是 **stellar equilibrium**。

时间点：**大爆炸后约 150 Myr**。

### 2. 第一代恒星：Population III (t ≈ 150 Myr)

**命名的坑**（老师专门提醒 "which is a bit confusing"）：**第一代恒星叫 Population III（第三星族），最年轻、金属最富的叫 Population I（第一星族）**。编号与时间顺序**相反**。原因是历史上先按观测到的恒星金属丰度分类，后来才倒推出更老的一代。

**Population III 的特征**：
- **超大质量**：> 100 solar masses（甚至 100+）；
- **极短寿命**：只有**几百万年 (a few million years)**；
- **成分几乎纯氢+氦**，即**金属丰度极低 (very low metal content)**（天文学里"metal"= 除 H、He 外的一切元素）；
- 在其内部第一次造出了重元素，并在燃料耗尽后通过**巨大的超新星爆发 (giant supernovae)** 把这些元素抛入太空；
- 这些被抛出的重元素被下一代恒星（**Population II**）继承，使后代恒星逐代**金属增丰**。

**观测现状（老师详细讲了这一段）**：
- **哈勃望远镜 (Hubble)** 看不到这么早。课件图横轴是宇宙年龄，标出 **HDF (Hubble Deep Field)** 与 **HUDF (Hubble Ultra Deep Field)** 两个实验的回溯极限：即使 HUDF 也只能看到大爆炸后**约 500 Myr**。
- **詹姆斯·韦布空间望远镜 (James Webb Space Telescope, JWST)**（老师说"我记得是 2021 年发射"）能看得更远，**其主要科学目标之一就是找到 Population III 星、验证"超大质量 + 极低金属丰度"这一理论预言**。
- 记录保持者例子：星系 **GLASS-z13**（"GLASS" 是望远镜上的观测项目名，"z13" 才是星系代号），我们看到的是它在**大爆炸后 300 Myr** 时的样子。老师补充：**今年又发现了两个更早的星系，约 290 Myr**。这些早期星系的光谱里**几乎看不到重元素证据，主要就是氢和氦**——与理论一致。

> 老师原话："they're seeing no evidence, very little evidence of heavy elements in these stars. They're principally made up of hydrogen and helium in their spectra."

### 3. 核合成总览：元素从哪来 (Nucleosynthesis overview)

**恒星的本质**：一大团**等离子体 (plasma)**，即高温电离气体，其中原子核可以相互碰撞并聚变。

**新的元素表示法（重要图，见第三节）**：不用周期表，而是画 **质子数 Z（纵轴）vs 中子数 N（横轴）** 的核素图 (chart of nuclides)。
- 质子数决定元素种类 → **每一行代表一种元素**；
- 质子数 + 中子数 = 质量数（近似原子质量）；
- 同一行、不同中子数的核素 = **同位素 (isotopes)**。例：2 质子 + 1 中子 = ³He；2 质子 + 2 中子 = ⁴He。
- 稳定核素排成一条**对角带**，称为**稳定谷 (valley of stability)** 或 **β 稳定线 (beta stability trend/line)**。

**四大来源（课件"Summary: The origin of elements in the periodic table"周期表配色图）**：

| 过程 | 产物范围 | 发生地 |
|---|---|---|
| **大爆炸核合成 (BBN)** | H、He（+痕量 Li） | 大爆炸后几分钟 |
| **恒星核合成 (stellar nucleosynthesis)** | 一直到 **Fe (Z=26)**；小质量星只到 C 左右 | 恒星核心的常规聚变 |
| **宇宙线散裂 (cosmic ray spallation)** | **Li、Be、部分 B** | 星际空间，高能宇宙线打碎较重原子核 |
| **超新星 / 中子俘获 (s-, r-process)** | Fe 以上的全部重元素 | 红巨星内部、超新星、中子星并合 |

**宇宙线散裂的机制**（老师专门解释了这个"异类"）：它**不是**把小核拼起来，而**恰恰相反**——高能宇宙线撞击较大的原子核，**把大核打碎 (spall off pieces)**，从而产生 Li、Be、B。"Spallation" 就是"崩碎/剥落"的意思。老师说这只解释这三种元素的丰度，不必深究；但**它解释了为什么太阳光谱里 Li、Be、B 的丰度异常低**（见第 12 点）。

### 4. 恒星生命周期取决于质量 (The life-cycle of a star depends on its mass)

**统摄性原理（贯穿全课的"恒星恒温器"）**：

```
收缩 → 核心 T 升高 → 促进聚变反应 → 膨胀
膨胀 → 核心 T 降低 → 抑制聚变反应 → 引力塌缩
```

老师把它讲成一个**内建的恒温器 (built-in thermostat)**：假如聚变速率偶然升高 → 核心产能增多 → 能量必须被处理，要么辐射到表面散掉，要么整个星体膨胀（气压+辐射压升高）→ 一旦膨胀，压力下降 → 温度下降 → 聚变速率回落。于是系统自动回到平衡。

**注意**：向外的力**有两个**——**气体压力 (gas pressure)** 和 **辐射压力 (radiation pressure)**。老师强调**光压 (light pressure) 本身就是让恒星膨胀的重要能量来源**，不只是核聚变直接释放的热能。

**两条演化路径（都从分子云开始）**：

起点：**分子云 (molecular cloud)**，即一团尘埃与气体。某种**触发事件 (trigger)** 让它开始收缩。

- **小质量星（~太阳质量）**：分子云 → **原恒星 (protostar)** → **主序星 (main sequence)** → **红巨星 (red giant)** → **行星状星云 (planetary nebula)** → **白矮星 (white dwarf)** →（→ 黑矮星 black dwarf）
- **大质量星（数十倍太阳质量）**：分子云 → 原恒星 → 主序星 → **红超巨星 (red supergiant)** → **超新星 (supernova)** → **中子星 (neutron star)** 或 **黑洞 (black hole)**

**关键结论**：*"it's really the processes that are going on in this sort of end phase for large stars which are generating most of the elements that you find in the periodic table."* 周期表上大多数元素来自大质量星的末期。

### 5. 氢燃烧 I：质子-质子链 (proton–proton chain)

**术语澄清（老师专门提醒的易错点）**："hydrogen burning" **不是**氢和氧燃烧的化学反应，而是**核聚变**。

**为什么必须是链式反应**：绝大多数聚变反应**只涉及两个粒子**，三体同时相撞极为罕见。所以要用 4 个氢造 1 个 ⁴He，**不可能四个一起撞**，必须分步进行——这就是"链 (chain)"的由来。课件图上左右两条对称的链同时进行。

**颜色编码（课件图）**：红 = 质子；灰 = 中子；白 = 正电子 (positron)；另外产物有 γ 光子和电子中微子 (electron neutrino)。

**分步机制**：

1. **p + p**：温度极高、能量足够，两个电离氢核克服**库仑势垒 (Coulomb barrier)** 相撞聚变。但两个质子在一起不稳定（互相排斥），于是**其中一个质子瞬间通过 β 衰变变成中子**，放出**一个正电子 + 一个中微子**，得到 **²H（氘, deuterium）**。（¹H 又叫 **protium 氕**，²H 叫 **deuterium 氘**。）
2. **正电子的命运**：正电子不稳定，立即与普通（负）电子**湮灭 (annihilate)**，产生 **γ 射线光子**——**这就是恒星发光的原因**。
3. **中微子的命运**：中微子可以**直接逃出恒星**，带走一部分能量。
4. **²H + ¹H → ³He + γ**：氘再俘获一个质子，放出 γ 光子，生成 ³He。
5. **³He + ³He → ⁴He + 2p**：两条链各产生一个 ³He，二者聚变生成稳定的 **⁴He**，并把 **2 个质子放回**恒星核心（可继续参与反应）。

**结论**：p-p 链产生 ³He 和 ⁴He（都是稳定同位素）；**这是维持恒星生命最重要的过程**，恒星一生的绝大部分时间靠它发光发热。

### 6. 氢燃烧 II：CNO 循环 (CNO cycle)

**适用条件**：**更热、质量更大的恒星**，且**核心中必须已经含有 C、N、O**——所以 **Population III 星里基本不会有 CNO 循环**（它们没有这些元素）。这是一个漂亮的因果点：**CNO 循环的存在本身就要求先有过一代恒星**。

**本质**：C、N、O 只是**催化剂 (catalyst)**，循环走完一圈它们又回来了；净效果仍然是 **4 个 ¹H → 1 个 ⁴He**。

**循环步骤（老师在休息时段又完整讲了一遍，说明他认为值得听懂，但明确说不考细节）**：
```
¹²C + ¹H → ¹³N + γ          （俘获质子，Z+1）
¹³N → ¹³C + e⁺ + ν          （β⁺ 衰变：质子→中子，Z−1，A 不变）
¹³C + ¹H → ¹⁴N + γ
¹⁴N + ¹H → ¹⁵O + γ
¹⁵O → ¹⁵N + e⁺ + ν          （β⁺ 衰变）
¹⁵N + ¹H → ¹²C + ⁴He        （放出一个 α 粒子，回到 ¹²C）
```
最后一步："net change is three... if you lose this, it goes down by four, and then if you add that, it makes it 12"——即 ¹⁵N 加一个质子变 ¹⁶O 状态后立刻放出 α（−4 个核子），回到 ¹²C，循环闭合。**α 粒子 = 氦核 = 2 质子 + 2 中子。**

**老师的考试提示（原话）**：*"I don't expect you to remember any of the details of that... you wouldn't be tested on that, but you should be aware that hydrogen burning is not the only way of forming helium, you can also form it by the CNO cycle."*

### 7. 能量从哪来：质量亏损与结合能 (mass defect & binding energy)

**核心事实**：**一个原子的质量总是略小于其组成中子、质子、电子质量之和**。这个差值就是**质量亏损 (mass defect, ΔM)**。

**物理意义**：这部分"消失"的质量被用来**把原子核束缚在一起**，即**结合能 (binding energy, E_b)**。

**公式**：
```
E_b = ΔM · c²
c = 光速 = 2.997925 × 10¹⁰ cm/s
```
（即爱因斯坦 E = mc²：质量与能量等价，质量可视为能量的一种形式。）

**⁴He 的具体数字（课件例题）**：4 个质子的质量之和 = **4.0324 amu**（原子质量单位），而 ⁴He 原子核的实际质量**略小于**这个数。差值以克计非常小，但换算成能量是**巨大的**——这正是恒星的能源。

**老师的延伸（H-bomb 那张图）**：地球上我们确实能做聚变——**热核武器 (thermonuclear devices)** 既用铀的**裂变 (fission)**，也用**聚变 (fusion)**。问题是**我们控制不了它**：*"although it would be a fantastic source of energy, as yet we can't really stabilize it."*（受控核聚变尚未实现。）

### 8. 恒星分类与赫罗图 (Hertzsprung–Russell diagram)

**光谱分类**：按颜色光谱把恒星分成 **O B A F G K M** 系列（课件写作 "O through to M"）。
- **蓝色 = 热（约 25,000 K），红色 = 冷（约 3,500 K）**。
- 老师强调这是**反直觉的易错点**：*"blue is hot, and red is cold, which is the opposite way around from what we usually remember things."*（日常生活中红=热、蓝=冷，天文学里正相反。）
- **表面温度与颜色相关，也与光度 (luminosity) 相关**。

**赫罗图 (H-R diagram) 的读法（务必掌握）**：
- **横轴：有效温度 (effective temperature, K)，注意坐标轴是反向的**——**左边热、右边冷**。
- **纵轴：光度 (luminosity)，对数坐标，跨越约 10 个数量级**，并以**太阳光度归一化**（太阳 L = 1，位于图中央）。比太阳暗的星在下方，比太阳亮的在上方。
- 图顶部标 O–M 光谱型；右侧的 "absolute magnitude 绝对星等" **老师说可以忽略**，那只是表达光度的另一种方式。
- **主序 (main sequence)**：把大量恒星画上去，会发现**约 90% 落在一条斜带上**——这就是主序。左上是**又大又热又亮**的主序星，右下是**又暗又冷**的主序星。
- 主序之外还有**矮星 (dwarfs)、巨星 (giants)、超巨星 (supergiants)**，但绝大多数星在主序上。

**最重要的物理判据（老师反复强调）**：
> **所有主序星都靠氢燃烧产能。一旦离开主序，恒星就改变了产能方式，开始燃烧越来越重的元素。**

### 9. 太阳级恒星的完整生命史（配合 H-R 图上的轨迹）

课件用四张连续的 H-R 图逐步画出太阳的演化轨迹，时间标注如下：

| 阶段 | 持续时间 | 物理过程 |
|---|---|---|
| **原恒星 (protostar)** | **~10 Myr** | 分子云被触发收缩，靠**引力能**加热，**尚无氢燃烧** |
| **主序 (main sequence)** | **~10 Gyr** | 核心氢燃烧；膨胀与收缩达成平衡；**一生中最长的阶段** |
| **红巨星 (red giant)** | **~2 Gyr** | 核心塌缩升温 → **壳层氢燃烧** → 星体膨胀 → 核心温度足够时**氦燃烧生成碳** |
| **变星 (variable) / 行星状星云 (planetary nebula)** | **~10 kyr** | 核心 He 耗尽 → He 壳层燃烧 → 脉动式燃烧 → 抛掉外层 |
| **白矮星 → 黑矮星 (white → black dwarf)** | **many Gyr** | 无聚变，辐射冷却；靠**电子简并压**支撑 |

**逐段详解（含老师口头补充）**：

**(a) 原恒星**：*"a protostar does not have any hydrogen burning going on inside of it. All the energy that's being produced is really gravitational energy as it begins to contract and heat up."* 只有到了主序，氢燃烧才被点燃。

**(b) 主序**：太阳现在约 **4.5 Ga（46 亿年）**，主序寿命约 100 亿年，所以**太阳大约走到主序的一半**（课件写 "~½ through life"）。

**(c) 向红巨星转变的因果链**：核心氢耗尽（核心只剩氦）→ **核心失去支撑而塌缩 → 核心温度升高** → 高温点燃**核心外的壳层氢燃烧** → 外层被推开、**星体急剧膨胀** → 表面积增大导致**表面变冷（偏红）但总光度大增（更亮）** → 在 H-R 图上**向右上方移动，离开主序** → 与此同时核心温度足够高时开始**氦燃烧生成碳 (C)**。

**(d) 变星与行星状星云**：核心 He 全部变成 C 后 → 转为 **He 壳层燃烧** → 随着 H 和 He 都在减少，燃烧变得**断续、脉动 (pulsed burning)**——"燃一阵，停一阵，再燃"，这就是**变星阶段 (variable stage)**，光度剧烈变化。引力开始压过日渐衰微的聚变，星体略微收缩。
每次脉动都会**把一层物质吹离表面**，最终形成由气体和尘埃组成的**行星状星云 (planetary nebula)**。
> **易错点（老师明确警告）**：**"planetary nebula" 与行星的形成毫无关系**（历史命名遗留，早期望远镜里看起来像行星圆面）。
课件例图：**猫眼星云 (Cat's Eye Nebula)**，可见一圈圈的尘埃气体环和侧向喷流——正是断续爆发的记录，中央那颗星就是残余的恒星核。

**(e) 太阳级恒星的核心壳层结构**：
> **太阳这种质量的恒星只能进行氢燃烧和氦燃烧，因此在周期表上造不出比碳更重的元素。**

最终结构（从内到外）：
```
核心：碳（C）—— 惰性堆积，不再燃烧
中层：氦燃烧壳
外层：氢燃烧壳
```

**(f) 白矮星与电子简并压 (electron degeneracy pressure)**：外层被抛尽后剩下裸露的核 → **不再有任何聚变反应**，只靠**辐射冷却 (radiative cooling)** 变成一个逐渐熄灭的"壳"。引力完全占上风，星体持续塌缩，密度暴涨；塌缩最终停止在**电子无法被压进原子核**的那一点——**电子简并压**顶住了引力。
- 尺寸：**约为主序星尺寸的 1/100**。
- 数据对比（课件）：白矮星 **天狼星 B (Sirius B)** 直径 **12,000 km**，地球直径 **12,742 km**——**白矮星差不多和地球一样大**；但密度 **d = 3 × 10⁶ g/cm³**，而地球平均密度 **d = 5.5 g/cm³**（约 55 万倍）。
- **黑矮星 (black dwarf)**：白矮星彻底冷却、不再发光后的终态。**白矮星与黑矮星的区别仅在于是否还在发光**（老师原话："The difference between black and white dwarfs really is just the amount of luminosity, whether it's producing any light or not."）。

### 10. 大质量恒星与元素合成的阶梯

**历史背景：B²FH 论文**
- 论文名 **"Synthesis of the Elements in Stars"**，作者 **Margaret Burbidge, Geoffrey Burbidge, William A. Fowler, Fred Hoyle**，因四人姓氏首字母缩写为 **B²FH**。
- **年份注意**：课件写 **1954**，老师口头说 **"published in 1956, 1957"**（学界公认是 **1957 年，Reviews of Modern Physics**）。考试若问，安全答法是"1950 年代中后期"。
- 老师提醒：**Fred Hoyle 就是上周提到的、创造 "Big Bang" 一词的那位**（而且他本人并不相信大爆炸理论，是带贬义地造了这个词）。
- 意义：*"much of this was set out nearly 70 years ago"*——恒星核合成的整个框架 70 年前就奠定了。

**燃烧阶梯：不同聚变反应所需的温度（课件完整列表）**

| 燃烧阶段 | 主要产物 | 点火温度 | 质量门槛 |
|---|---|---|---|
| **氢燃烧** (p–p chain) | ⁴He | ~4 × 10⁶ K | 所有主序星 |
| **氢燃烧** (CNO cycle) | ⁴He | 1.6 × 10⁷ K | 较大质量星 |
| **氦燃烧** (triple-alpha 三α过程) | ¹²C（及部分 ¹⁶O） | 2.3 × 10⁸ K | — |
| **碳燃烧** | ²⁰Ne, ²³Na, ²³Mg, ²⁴Mg, ¹⁶O | 9.3 × 10⁸ K | **> ~8 M☉** |
| **氖燃烧** | ¹⁶O, ²⁴Mg | 1.7 × 10⁹ K | **> ~8 M☉** |
| **氧燃烧** | ²⁸Si, ³²S, ²⁴Mg (+ ³¹P, ³¹S, ³⁰Si, ³⁰P) | 2.3 × 10⁹ K | **> ~10 M☉** |
| **硅燃烧** (alpha process) | ³²S, ³⁶Ar, ⁴⁰Ca, ⁴⁴Ti, ⁴⁸Cr, ⁵²Fe, ⁵⁶Ni → ⁵⁶Co → **⁵⁶Fe** | 4.1 × 10⁹ K | **> ~10 M☉** |

**三α过程 (triple-alpha process)**：⁴He 核就是一个 **α 粒子**（2 质子 + 2 中子）。把**三个 α 分步**加在一起 → **¹²C**。（这是"三体"问题的绕道解法：先 ⁴He+⁴He→⁸Be（极不稳定），再迅速 +⁴He→¹²C。）

**老师的考试提示（原话，非常明确）**：*"You don't need to remember the temperatures... don't try and learn the isotopes. Just be aware that we have these different phases of burning, and eventually we can generate elements as heavy as iron and nickel."* —— **要记的是"温度越来越高、燃烧越来越重、最终止于 Fe/Ni"这个逻辑，不是具体数字。**

### 11. 为什么一切止于铁：结合能曲线 (binding energy curve)

**核心原理（本周最重要的概念之一）**：
- **原子核的结合能（每核子结合能）是聚变的驱动力**。
- **比铁轻的元素聚变会释放能量**（生成每核子结合能更高的核）→ 恒星能靠它发电。
- **比铁重的元素裂变会释放能量**（同样是走向更高的每核子结合能）。
- **铁 (Fe) 处于结合能曲线的极大值——"maximum stability at Fe"**。

**推论（因果链）**：一旦核心堆积成铁，**再要聚变就必须净输入能量**，恒星再也无法靠聚变支撑自己 → 失去辐射压 → **核心灾难性塌缩 → 超新星爆发**。
> 老师原话：*"The reason why things stop at iron and nickel is that that's the point when the binding energy runs out... Once we get up to iron and nickel, then we actually need to have energy put in."*

**所以：要造出比铁重的元素，必须靠别的机制（见第 13 点的 s-/r-过程）。** 裂变可以把更重的核变成 Fe/Ni，但**你首先得有办法造出那些重核**。

**大质量星末期的洋葱壳结构 (shell structure)**：以 **25 M☉** 的星为例，从外到内依次是氢燃烧壳、氦燃烧壳、碳燃烧壳、氖燃烧壳、氧燃烧壳、硅燃烧壳，**核心堆积铁**。规律是**越往内越热、越重**（"shell structure builds outwards, hotter conditions in core"）。

**每一层的燃烧时间急剧缩短（震撼的数字，老师特别点出）**：
- **氢燃烧 ≈ 700 万年**
- **硅燃烧 ≈ 1 天！**
> *"really this is what the star might be in that last day. That's the structure that it might be before it runs out of fuel."* ——这张洋葱图画的是恒星**生命最后一天**的样子。

### 12. 超新星爆发 (supernova)

**观测实例（课件视频/动画）**：**KSN 2011d**，一颗**红超巨星 (red supergiant)** 的爆发，距离 **12 亿光年**，由**开普勒空间望远镜 (Kepler)** 于 **2011 年**捕捉到。
- 老师放了两遍动画并解说：右侧标尺是**以分钟计的时间**——**整个爆发过程在几个小时内完成**；先看到核心射出**物质喷流 (jets)**，然后开始爆炸，最后尺寸急剧膨胀。

**超新星的双重意义**：
1. **元素工厂**：极高温、极高中子通量的短暂环境，进行 r-过程核合成；
2. **播种机**：把重元素**抛撒到星际空间**，被下一代恒星形成时的气体所吸收 → 后代恒星金属丰度更高。

**残骸的命运（质量决定）**：
- 核心塌缩成**中子星 (neutron star)**；
- **若超过 25 个太阳质量 → 黑洞 (black hole)**。

**课件实例：蟹状星云 (Crab Nebula)**——**公元 1054 年**被观测记录的一次超新星的残骸，**中心是一颗中子星**。

### 13. 铁以上元素：s-过程与 r-过程 (slow and rapid neutron capture)

这是本周概念上最难、也最值得写透的一段。老师承认 *"this is quite a complicated diagram, so you might not get your head around it completely the first time."*

**舞台：扩展的核素图 (Z vs N)**，从最初只画到氟 (F) 扩展到覆盖整张周期表，质量数一直到 **184**。
- **黑色小方块 = 稳定同位素**，连成对角的**稳定谷 / β 稳定线**。例：镍 (Ni, Z=28) 那一行有若干个黑格。
- **黄色、绿色区域 = 不稳定同位素，会发生 β 衰变**。

**两种 β 衰变的方向（务必分清）**：
- **对角线左上侧 = 质子过剩 (proton excess)** → 质子太多 → **质子转变为中子**的 β 衰变（β⁺）→ 向右下方走回稳定谷；
- **对角线右下侧 = 中子过剩 (neutron excess)** → 中子太多 → **中子转变为质子**的 β 衰变（β⁻）→ 向左上方走回稳定谷。
> 记法：**β 衰变永远把核素"拉回"对角线上**（沿斜向轨迹）。

**幻数 (magic numbers)**：图上标出的 **2, 8, 20, 28, 50, 82, 126（中子）** 和 **28, 50, 82（质子）** 位置具有**特别高的稳定性**。
- **机制类比**：就像电子填满电子壳层会特别稳定一样，**中子和质子也有核壳层 (nuclear shells)**；壳层填满时核特别稳定。
- **后果 1**：这些位置在核素图上会造成 s-/r-过程路径的**偏折 (deflections)**；
- **后果 2**：**这些质量数附近的元素在宇宙中丰度偏高**——老师点名 **锶 (Sr) 附近、钡 (Ba) 附近、以及铅 (Pb)**。（转写把 barium 误听成 "arium/aerium"。）

**基本机制：中子俘获 (neutron capture)**
中子**不带电**，因此**不受库仑势垒阻挡**，可以直接靠近并被已存在的原子核俘获。**俘获一个中子 = 在图上向右水平移动一格**（N+1，Z 不变）。

**s-过程 (slow process, 慢中子俘获)**：
- **环境**：中子通量**中等**（核心里有过剩中子，但不算极端）；
- **节奏**：俘获一个中子后，**有足够时间**让新生的不稳定核先 β 衰变回稳定谷，然后再俘获下一个；
- **图上轨迹**：**右一格（俘获）→ 斜上一格（β 衰变）→ 右一格 → 斜上一格 …… 呈锯齿状紧贴稳定谷爬升**，净效果是**沿对角线向高质量走**；
- **时标**：**数万年 (tens of thousands of years)**；
- **上限**：**只能造到铅 (Pb)**。铅是极稳定的构型，**s-过程无法越过铅**。
- **发生地**：巨星（超大质量红巨星）内部。

**r-过程 (rapid process, 快中子俘获)**：
- **环境**：**中子密度极高、温度极高**（超新星爆发、可能还有**中子星并合 (neutron star merger)**）；
- **节奏**：**中子俘获速度远快于 β 衰变速度**——可能连续俘获 5、6 个中子之后才衰变；
- **图上轨迹**：先**大幅向右**冲进远离稳定谷的中子过剩区，再**斜向左上**衰变回来；如此反复，能到达**远高于 s-过程的质量**；
- **时标**：**秒到分钟**（超新星只给你"几个小时"的极高中子通量窗口）；
- **产物**：**铅以上的所有重元素（U、Th 等）只能靠 r-过程**。

**两者的相对贡献（考点）**：
> **铁以上的元素，大约一半由 s-过程产生，一半由 r-过程产生——两者同等重要。**
> 老师原话：*"They both add about the same amount of elements beyond the iron, so they are equally important."*

**发生地的不确定性（老师诚实地说明）**：s- 和 r- 过程"我们认为"发生在超大质量红巨星、中子星并合或超新星事件中，*"but there's some uncertainty about exactly which."*

**老师明说不考的**：**rp-process（快质子俘获）不用管**（"Don't worry about the R-P process."）。

**最终的元素来源总表（课件周期表配色图）**：
- **紫色 = 大爆炸**：H、He
- **小质量恒星**：到碳左右（视质量可稍高）
- **大质量恒星**：一般到铅
- **超新星**：所有更重的元素

### 14. 从第一代恒星到第一批星系 (Towards the formation of the first galaxies)

**因果链（完整背下来）**：
1. **超大质量 Population III 星发出强烈紫外辐射** → **使周围介质再电离 (re-ionized)**，即把电子从氢原子上剥离；
2. 这些恒星死亡时的**超新星激波 (shock waves)** → **压缩周围已电离的气体/分子云** → **触发一波恒星形成暴 (burst of star formation)**；
3. 恒星**核心塌缩形成黑洞 (black holes)**；
4. **到 250 Myr**：已存在至少 **400 个太阳质量**的黑洞；
5. **围绕这些黑洞持续的引力塌缩** → **到 400 Myr 形成第一批星系**。

> 老师的推论：几乎所有我们已知的星系中心都有黑洞，所以**黑洞可能是星系形成的必要条件**（"they might have kind of been necessary"）。

**课件实例：SSA 22**——一个尺度超过银河系三倍的区域，包含两个正在剧烈形成恒星的大星系和若干卫星星系，全部笼罩在一团氢气云中。

### 15. 星系的定义、并合与统计

**星系 (galaxy) 的定义（要背）**：
> **一个由引力束缚的系统，包含恒星、恒星遗迹 (stellar remnants)、星际气体、尘埃和暗物质。**
> 课件给的典型规模：~1 亿颗恒星（这是"小星系"的量级；银河系有千亿级）。

**星系并合 (galaxy merger)**：
- 星系一旦形成就会**碰撞、并合成更大的系统**；课件实例：**相撞中的 NGC 2207 与 IC 2163**。
- **几乎每个大星系中心都有一个超大质量黑洞 (supermassive black hole)**，课件给的量级是 **10 billion solar masses（100 亿太阳质量）**。

**星系数量随时间的变化（重要图）**：
- 横轴：大爆炸以来的时间（0 = 大爆炸，右端 = 现在）；纵轴：某一时刻的星系数量。
- **结论：过去星系数量更多，随时间减少**——**原因就是并合**（大鱼吃小鱼，总数下降但个头变大）。
- **哈勃超深场 (Hubble Ultra-Deep Field)** 图像：大爆炸后约 **800 Myr** 的宇宙，一张图里就有 **10,000 个星系**。
- 当今宇宙中**至少有 1000 亿 (100 billion) 个星系**。

**恒星形成率 (star formation rate, SFR) 随时间的变化（另一重要图）**：
- 纵轴 SFR 用**对数坐标**；横轴用**红移 (redshift)**，顶部另有时间刻度——**记住红移与时间相关**。
- **峰值出现在大爆炸后约 2–3 Gyr，即约 11,200 Ma（112 亿年前）**。
- 这个峰被称为 **"cosmic noon（宇宙正午）"**。
- **老师诚实地说：我们不知道为什么会有这个峰。** 但自那以后**恒星形成率一直在下降**。

**星系团 (galaxy clusters)**：
- 星系倾向于**成团 (clustered)**，团与团之间是密度较低的空间；团内星系**引力束缚**在一起。
- 课件实例：**MS 0735.6+7421**。
- **哈勃可见光图** vs **哈勃 + 钱德拉 X 射线天文台 (Chandra) + 甚大天线阵 (Very Large Array, 新墨西哥) 的合成图**：合成图显示星系之间**并非真空**，而是充满**星际介质 (interstellar medium)**——H₂、He 和尘埃，还有**带电粒子喷流 (jets of charged particles)**（图中红色部分是电离粒子）。
> **要点：星系之间不是空的。**

### 16. Part 2：银河系 (The Milky Way Galaxy)

**基本参数（约 13,200 Ma 形成，即约 132 亿年前）**：
- **1000–4000 亿 (100–400 billion) 颗恒星**
- **1000–4000 亿颗系外行星 (exoplanets)**
- 其中约 **3 亿 (300 million) 颗可能是类地、potentially habitable 的**

**形态与几何 (geography and geometry)**：
- 星系分为 **椭圆 (elliptical)、螺旋 (spiral)、不规则 (irregular)** 三类；**银河系是一个旋转的棒旋星系 (rotating, barred spiral galaxy)**。
- **盘 (disc)**：直径 **~100,000 光年**，厚度 **~1,000 光年**（即极扁的盘）。
- **核球 (bulge)**：靠近中心处隆起。
- **晕 (halo)**：包围整体的球形弥散区域，其中含有**球状星团 (globular star clusters)**。
- **中心的超大质量黑洞：人马座 A* (Sagittarius A\*)**。
- **太阳的位置：猎户臂 (Orion Arm)** 上（转写误作 "Orion's sperm"）。

**恒星族群的年龄与轨道分布（重要的因果对应）**：

| 位置 | 恒星年龄 | 轨道特征 |
|---|---|---|
| **盘 (disc)** | **年轻恒星** | **近圆轨道**，位于盘的中平面内 |
| **核球 (bulge)** | 较老 | **椭圆轨道，相对星系平面随机取向** |
| **晕 (halo) 的球状星团** | **最老的恒星** | 椭圆、随机取向 |

- **星系盘包含了银河系 200–400 billion 恒星中的绝大部分，以及几乎全部的气体和尘埃。**

**银河系形成的三步时间线（课件明确给了年代，要记）**：
1. **~13,200 Ma**：银河系起始于质量分布中的若干**过密区 (overdensities)**；**球状星团在这些过密区中被"播种"**。
2. **~11,500 Ma**：引力吸引使这些过密区**并合**，并**开始自转 (initiation of spinning)**；此时**内晕的恒星正在形成**。
3. **8,800 ± 1,700 Ma**：**角动量守恒 (conservation of angular momentum)** 导致气态星际介质**从球状塌缩成盘状**。

**老师的口头补充（很重要的因果解释）**：球状星团含有不同年龄、不同成分的恒星，**它们可能就是银河系形成之前就已存在的东西**——银河系可能是由若干含恒星的球状星团并合而成。并合 → 引力驱动 → 开始旋转、收缩成盘 → **在旋转过程中尘埃和气体主要沉降到星系平面上** → **所以盘上后来大量形成年轻恒星**。这完美解释了上面那张"年轻星在盘、老星在晕"的表。

### 17. 太阳在银河系中的位置与局部星际环境

**太阳的基本档案**：
- **Population I 星**，形成于 **~4600 Ma**；
- 位于**星系盘内，距银心约 27,000 光年**，**略高于星系中平面**；
- **化学成分（太阳光球 photosphere）**：**71.54% 氢，27.03% 氦，其余 60 多种元素合计不到 1%**；
- **这些重元素全部继承自更早世代的恒星** ("all inherited from older generations")；
- 最近的恒星：**比邻星 (Proxima Centauri)，4.25 光年**（课件配图为太阳 40 光年内的星图）。

**从太阳光谱丰度图能读出的三件事（老师专门讲的判读要点）**：
1. **H、He 丰度极高**（大爆炸的遗产）；
2. **Li、Be、B 丰度异常低**——因为它们**只能靠宇宙线散裂产生**，而不是恒星聚变；
3. **Fe 丰度显著偏高**，Ba、Pb 附近也有小峰——因为**幻数带来的核结构稳定性**。
> **结论：元素丰度曲线同时反映了 s-/r- 过程和原子核结构的稳定性（幻数）。**

**太阳绕行时不断变化的星际环境**：
- **本地泡 (Local Bubble)**：太阳目前所处的一个**密度极低的星际介质区域**，被**超新星雕刻 (sculpted by supernovae)** 而成。尺度约 **1,500 光年或更大**（课件配图中另一张更细的图约 500 光年跨度）。
  - **成因**：附近超新星的**激波把气体和尘埃吹扫出去**，留下一个低密度空腔。
  - 课件图中：**黑色 = 本地泡（极低密度）；灰色 = 典型星际介质（灰度反映尘埃与气体的量）；紫色壳状波纹 = 超新星产生的尘埃壳；橙色 = 当前正在形成恒星的区域；绿色 = Gum Nebula（一片高度电离的氢气区）；蓝色箭头 = 银心方向**；还标出了 **Vela SNR**（船帆座超新星遗迹）。
- **本地星际云 (Local Interstellar Cloud)**：太阳目前正在穿过的、密度**略高**的区域，其物质来自 **天蝎-半人马星协 (Scorpius–Centaurus Star Association)** 过去 **15 Myr** 内发生的数次超新星。

**⭐ 与地球科学的联系（本周最漂亮的一个跨学科证据，一定要记）**：
> **来自这些超新星的物质，已经在深海沉积物和月球土壤中被找到，定年为 3.2–1.5 Ma 和 8.7–6.5 Ma。**
（即通过 ⁶⁰Fe 等超新星特征核素，把"天文事件"直接写进了"地质记录"——这就是本课程"How to Build a Planet"把天文与地球连起来的方式。）

**总结句（老师的收尾）**：*"the important point there is that it's not just empty space between the stars. There's lots of variation as well in density and temperature."* ——**星际空间不是虚无，它在密度和温度上变化极大。**

## 三、公式与图表

### 公式

**1. 质能等价 / 结合能**
```
E_b = ΔM · c²
```
- **E_b** = binding energy 结合能（把核子束缚在核内所需的能量）
- **ΔM** = mass defect 质量亏损 = （组成粒子质量之和）−（原子实际质量）
- **c** = 光速 = **2.997925 × 10¹⁰ cm/s**

**含义**：原子的实际质量总小于其组成部分之和；这一"缺失"的质量就是被转化为结合能。**在聚变反应中，质量亏损被释放为能量**——恒星的全部能源。

**数值例（⁴He）**：4 个质子的质量和 = **4.0324 amu** > ⁴He 核实际质量。差值很小，但乘以 c² 后是巨大的能量。

**2. 质子-质子链（净反应）**
```
4 ¹H → ⁴He + 2e⁺ + 2ν + 能量(γ)
```
分步：
```
¹H + ¹H → ²H + e⁺ + ν      （其中一个 p 经 β 衰变变 n）
²H + ¹H → ³He + γ
³He + ³He → ⁴He + 2 ¹H
```

**3. CNO 循环（净反应相同，C/N/O 为催化剂）**
```
¹²C(p,γ)¹³N(β⁺ν)¹³C(p,γ)¹⁴N(p,γ)¹⁵O(β⁺ν)¹⁵N(p,α)¹²C
```

**4. 三α过程**
```
3 ⁴He → ¹²C   （⁴He 核 = α 粒子 = 2p + 2n）
```

### 图表判读

**图 1：核素图 (Chart of nuclides, Z vs N)** —— 本周最核心的图，出现两次（简版到 F，完整版到 A=184）
- **纵轴 = 质子数 Z（决定元素，每一行是一种元素）；横轴 = 中子数 N**。
- **Z + N = 质量数**；同一行不同列 = 同位素。
- **黑色方块 = 稳定同位素**，排成一条**对角带**：**稳定谷 / β 稳定线 (valley of stability / beta stability line)**。
- **黄/绿色 = 不稳定，会 β 衰变**。
- **左上方（对角线以上）= 质子过剩 (proton excess)** → β⁺ 衰变（p→n）；**右下方 = 中子过剩 (neutron excess)** → β⁻ 衰变（n→p）。**两者都朝对角线方向移动。**
- **箭头的方向语言（判读关键）**：
  - **向右水平走一格 = 俘获一个中子**（N+1，Z 不变）；
  - **斜向左上走 = β 衰变（中子过剩侧）**；
  - **红色箭头（沿对角线向上）= 恒星常规聚变，止于铁**；
  - **s-process 箭头 = 紧贴对角线的锯齿状路径，止于 Pb**；
  - **r-process 箭头 = 先大幅右冲、再斜向回归的路径，可越过 Pb**。
- **幻数线**：中子 **2, 8, 20, 28, 50, 82, 126**；质子 **28, 50, 82**——标出核壳层填满的位置，路径在此处发生偏折，对应宇宙丰度上的峰。
- **老师承认这图第一次看不懂很正常**，判读顺序建议：先找黑色对角线 → 分清左右两侧的过剩类型 → 再看两条箭头路径怎么绕。

**图 2：赫罗图 (Hertzsprung–Russell diagram)** —— 出现四次，逐步画出太阳的演化轨迹
- **横轴：有效温度 (K)，⚠️ 反向——左热（~25,000 K）右冷（~3,500 K）**；顶部标光谱型 **O B A F G K M**。
- **纵轴：光度 (luminosity)，对数坐标，约 10 个数量级，以太阳为 1**。右侧的"absolute magnitude 绝对星等"是光度的另一种表达，**老师说忽略即可**。
- **四个象限的物理含义**：
  - **左上**：大、亮、热的主序星
  - **右上**：大、亮、冷 → **巨星与超巨星**（体积大所以亮，表面冷所以红）
  - **右下**：小、暗、冷的主序星（红矮星）
  - **左下**：小、暗、热 → **白矮星**
- **主序 (main sequence)**：约 **90%** 的恒星落在这条从左上到右下的带上。**主序 = 靠氢燃烧产能**。太阳在带子中部。
- **太阳的演化轨迹（按时间标注读图）**：
  `原恒星 ~10 Myr（从右侧低温区向左下方掉到主序）→ 主序 ~10 Gyr（停留最久）→ 红巨星 ~2 Gyr（向右上方跑，变冷变亮）→ 变星/行星状星云 ~10 kyr（在右上方剧烈震荡）→ 白矮星（急坠到左下角）→ 黑矮星 many Gyr（在左下逐渐熄灭）`

**图 3：每核子结合能曲线 (binding energy per nucleon)**
- 横轴质量数，纵轴每核子结合能。
- **曲线在 Fe (A≈56) 处达到极大 —— "maximum stability at Fe"**。
- **左半支（A < 56）：聚变放能**；**右半支（A > 56）：裂变放能**。
- **这一张图就解释了：为什么恒星只能烧到铁，以及为什么铁核堆积必然导致超新星。**

**图 4：大质量星末期的洋葱壳结构 (shell structure)**
- 以 25 M☉ 星为例。**从外到内：H 燃烧壳 → He → C → Ne → O → Si 燃烧壳 → Fe 核**。
- 判读要点：**"shell structure builds outwards, hotter conditions in core"** —— 越向核心温度越高、燃烧的元素越重；每一层的燃料是内一层的产物。
- **时标急剧压缩：H 燃烧 ~7 Myr，Si 燃烧 ~1 天。这张图画的是恒星最后一天的样子。**

**图 5：暗物质分布模拟图**

## 六、易错点 / 重点难点

1. **Population 编号与年代顺序相反**：**Population III = 第一代（最老、金属最贫）**，Population I = 最新（金属最富，太阳属此类）。老师自己都说 "which is a bit confusing"。
2. **"Hydrogen burning" 不是化学燃烧**，是核聚变（H → He）。同理 "carbon burning"、"silicon burning" 全部指聚变。
3. **H-R 图横轴反向 + 蓝热红冷**：双重反直觉。**左 = 热 = 蓝；右 = 冷 = 红。** 纵轴光度是**对数**且以太阳为 1。
4. **"Planetary nebula 行星状星云与行星毫无关系"** —— 老师明确警告的历史命名陷阱。
5. **"Metal 金属"在天文语境中 = 除 H、He 外的一切元素**（包括 C、O、N）。所以"低金属丰度"不是指没有铁。
6. **s-过程 vs r-过程的区分点是"中子俘获速率 vs β 衰变速率"的相对快慢，不是绝对速度**。
   - s：慢，中子俘获后**来得及**衰变回稳定谷 → 锯齿状贴着对角线爬 → **止于 Pb** → 时标万年 → 巨星内部。
   - r：快，**来不及**衰变就连续俘获多个中子 → 冲进中子过剩区再折返 → **越过 Pb 造出 U、Th** → 时标秒到分钟 → 超新星 / 中子星并合。
   - **两者贡献各占一半。**
7. **为什么止于铁**：因为**每核子结合能在 Fe 处极大**。**记住"聚变放能只到铁"这个因果，而不是死记温度表。**
8. **Li、Be、B 是"异类"**：它们既不是 BBN 主产物、也不是恒星聚变产物，而是**宇宙线散裂 (cosmic ray spallation)** 的产物——**把大核打碎，而不是把小核拼起来**。这也解释了太阳丰度图上它们的深谷。
9. **恒星"恒温器"的方向不要弄反**：收缩→升温→聚变加快→膨胀；膨胀→降温→聚变变慢→收缩。**向外的力有两个：气压 + 辐射压。**
10. **原恒星阶段没有氢燃烧**，能量全部来自引力收缩。**氢燃烧点燃 = 进入主序的标志。**
11. **白矮星靠电子简并压支撑，不是靠聚变**——它内部已经完全没有核反应了。白矮星 vs 黑矮星的唯一区别是**还发不发光**。
12. **太阳级恒星只能造到碳**（氢燃烧 + 氦燃烧），造不出更重的元素。**Fe 以上的元素与太阳这类恒星无关。**
13. **α 粒子 = ⁴He 核 = 2 质子 + 2 中子**，三α过程就是"三个氦核变一个碳"。
14. **星系数量随时间"减少"而不是增加**——因为并合。但**恒星形成率**是另一条曲线，峰在 cosmic noon（大爆炸后 2–3 Gyr / 约 11,200 Ma 前）后下降。**两条曲线不要混。**
15. **星际空间不是真空**：星系之间、恒星之间都有星际介质，密度和温度变化极大（本地泡 vs 本地星际云就是例子）。
16. **幻数 (magic numbers) 的双重后果**：既造成核素图上 s-/r- 路径的偏折，也造成宇宙元素丰度曲线在 Fe、Sr、Ba、Pb 附近的峰。
17. **年代数字容易混**（建议做一张时间卡片背）：
    - **13,700 / 13,650 Ma** 大爆炸
    - **380 kyr** 复合、CMB 释放、宇宙变透明
    - **150 Myr** 第一代恒星 (Pop III)
    - **250 Myr** 已有 ≥400 M☉ 的黑洞
    - **290–300 Myr** JWST 已观测到的最早星系
    - **400 Myr** 第一批星系形成
    - **500 Myr** 哈勃 HUDF 的回溯极限
    - **800 Myr** 哈勃超深场图像的时代（一图 10,000 星系）
    - **~11,200 Ma 前（大爆炸后 2–3 Gyr）** 恒星形成率峰值 = cosmic noon
    - **13,200 Ma** 银河系起始（过密区 + 球状星团播种）
    - **11,500 Ma** 内晕恒星形成，过密区并合、开始自转
    - **8,800 ± 1,700 Ma** 星际介质塌缩成盘
    - **4,600 Ma** 太阳形成（Population I）
    - **4,567 Ma** 太阳系/地球形成（本周终点，Week 3 起点）
    - **1054 CE** 蟹状星云超新星被观测记录
    - **3.2–1.5 Ma & 8.7–6.5 Ma** 深海沉积物与月壤中找到的超新星物质年代
