# The Workshops — 课程总纲

> **适用范围**：EART11100 *Understanding the Earth* — Michaelmas Term, **The Workshops** 部分，共 7 个周单元（W1、W2、W3、W4、W5、W7、W10；**无 W6、W8、W9**，原始材料缺失）。
>
> **本文定位**：全课骨架与复习索引。各周的详细活动步骤、逐题解法、术语表请回看对应的 `Week 0X.md`；本文只做体系梳理、连接关系与材料诚实说明。

## 一、这门课在讲什么

**它不是一门知识课。**

按课程简介的定位，The Workshops 是 *Understanding the Earth* 内部的**动手活动模块**，目的不是讲授新内容，而是把 UtE 的学习内容与另外两门核心课——**The Natural Scientist's Toolkit**（定量方法、数据与图件判读、单位与量纲）与 **Practical and Professional Skills**（观察—记录—推断、制图规范、科学写作与不确定性表达）——**整合到同一次动手练习里**。同学期的姊妹课 **How to Build a Planet**（行星如何形成与演化）与 **How to Grow a Planet**（地球生命演化史）提供理论背景，Workshops 则提供"把理论用出来"的场地。

这一定位在材料里有非常明确的形式证据：**每一周的幻灯片都以 "aims + learning outcomes" 开场，并以 "Can you do what we set out to do?" 原样重复这几条收尾**（W1、W2、W3、W4 皆然）。也就是说，这门课的验收标准从来不是"你记住了什么"，而是**"你现在能不能做到这几件事"**——判断两块岩石孰老孰新、给不整合分类、画出一条事件序列、在地震图上定位震中、为某种材料选对定年方法、用变新符号标出层序方向。

因此，本课**不存在一条贯穿七周的知识主线**。它更像一组彼此独立的技能模块，共同点在于**训练方式**而非**主题内容**：W1–W4 是地层学技能链（有内在承接），W5 是地震学定量练习，W7 是演化推理，W10 是行星科学的量级估算。把它们强行串成一条线是误读；正确的读法是把它当作**三门核心课之间的连接组织（connective tissue）**。

## 三、这门课的"连接"作用（本节是重点）

这是本课最有价值、也最容易被忽略的信息：每一周的活动都是一次**跨课程接线**。以下逐条梳理，均基于周笔记中的实际内容。

### 1. W1–W4：把 UtE 的地层学理论接到 Practical Skills 的野外技能上

W1 给出四条地层学原理（原始水平律、叠覆律、切割律、包体律）与不整合三分类，**但它的产出不是定义，而是一条书面的地质事件序列**——幻灯片图注专门补了一句"应在事件 10 之后、11 之前加上 uplift 与 erosion"，明确指出**界面必须被展开成事件**。这是典型的 Practical Skills 式训练：观察 → 结构化记录 → 可辩护的推断。

W4 是 W1 的**直接补丁**。W1 讲叠覆律时就埋了一句 "A word of caution!"，W4 整周就在处理那个警告：**当地层被构造翻到陡倾甚至倒转，几何姿态给不出答案时，回到岩石内部去问它自己**。它的最终产出是一个**制图符号**（younging symbol，正常层序 vs 带回钩的倒转符号）——从观察到规范表达的闭环，正是 Practical Skills 的核心训练目标。

### 2. W2 + W3：把三门课在同一张图上叠起来（全课连接最密的一处）

这两周是本课"整合"定位最完整的示范：

- **UtE / How to Build a Planet 侧**：地质年代表的层级（Eon/Era/Period/Epoch/Age）、GSSP「金钉子」制度、生物带的五种定义方式。W3 甚至把 W2 的 GSSP 与层级两页**原样重放**，是刻意的复习点。
- **Chemistry of the Earth 侧**：放射性衰变、母体/子体同位素、半衰期、闭合温度；W3 Practice 3 给出的三个半衰期（¹⁴C 5,730 yr、²³⁸U 4,468 Ma、⁴⁰K 1,251 Ma）就是化学课内容的直接调用。
- **Intro Maths 侧**：年龄方程本身就是一道对数/指数运算题
  $$t=-\,t_{1/2}\cdot\frac{\ln f}{\ln 2},\qquad \lambda=\frac{\ln 2}{t_{1/2}}$$
  W3 的两道计算题（16.7% 剩余 → 14,798 yr；78.3% 剩余 → 1.577 Ga）考的正是"会不会正确使用自然对数、会不会用半衰期计数法做量级检验"。周笔记明确指出两个高频代错：忘了除以 $\ln 2$（偏大约 44%）、把 $\ln$ 写成 $\log_{10}$（偏小约 2.3 倍）。
- **Toolkit 侧**：γ 射线测井曲线判读（低 γ = 砂 / 高 γ = 泥）是纯粹的地球物理数据判读；活动一要求**用两种颜色的笔**分别画岩性对比线与生物地层对比线，其目的就是让两套线的**平行或斜交**直观显示岩性界面是否穿时 (diachronous)。

**这条连接的落点**是 W3 Practice 3 第 3 题的结论：**沉积岩本身不能被放射性定年，必须找夹在其中的火山灰层（等时、瞬时）或穿切的侵入体**，再配合 W1 的叠覆律与切割关系做"夹逼"。一道选择题，同时用到了地层学（相对）、同位素化学（绝对）、和逻辑约束三样东西——这就是这门课想要的效果。

### 3. W5：把构造理论接到定量计算与不确定性表达上

地震 workshop 的技能链是 **识波 → 读时 → 求距 → 定位**，每一环都对应不同课程：

- **识波**（P 在 Z 分量先跳、S 在水平分量后跳）——UtE 的地震学理论；
- **读时**——Toolkit 的**60 进制时间算术**：$16{:}15{:}05+235\,\mathrm{s}=16{:}19{:}00$，并区分**到时 (arrival time) / 走时 (travel time) / 记录起始时刻 (start time)** 三个易混量；
- **求距**——**图解法**而非套公式：在走时曲线上用"垂直卡尺"平移，使下端落在 P 曲线、上端落在 S 曲线，读出横坐标。核心物理是 $t_S-t_P=\Delta\left(\frac{1}{v_S}-\frac{1}{v_P}\right)$，**式中不含发震时刻**，所以不知道地震何时发生也能定距；
- **定位**——三个台站三个圆的几何综合。幻灯片措辞是 "locate the **region** in which the epicenter is located"——**要的是区域而非点**，这是 Practical Skills 式的**诚实的不确定性表达**。

后半周（灾害、烈度、液化、诱发地震）则把地球科学接到**社会与政策**：Risk = Hazard × Exposure × Vulnerability，同样的地震动在不同地点风险截然不同。

### 4. W7：把 How to Grow a Planet 的"发生了什么"接到"凭什么机制"

W7 是全课**唯一一次生命科学主题**，与 How to Grow a Planet 严格互补：那门课讲寒武纪大爆发、登陆、大灭绝这些**事件**，本周讲驱动这些事件的**机制**——变异 → 遗传 → 竞争与适合度 → 选择 → 适应 → 物种形成与系统发生。

它与 Practical Skills 的接口在幻灯片自己写的一句话上：**"there isn't necessarily a correct answer."** 11 道"为什么 X 有 Y 特征"的小组题（长颈鹿的脖子、斑马的条纹、辣椒的辣、鹿角、人脑…）不是要求答对，而是要求**列出多个竞争性假说、并说明每个假说需要什么判决性证据**——这正是 Toolkit 的假说检验训练与 Practical Skills 的科学写作态度的交汇点。

它同时是**古生物学的入门钩子**：化石只保存 morphology（表型），几乎从不保存 genome，所以古生物学做的事本质上是"从残缺的表型证据反推演化历史"。幻灯片末页直接给出后续课程指路（Palaeobiology / Ecology, evolution and conservation biology）。

### 5. W10：把整门课的产出当作输入，做一次总演练

收官周是唯一一次**把地球整体当作一个样本点**处理的课。它的结构是一个标准的归谬法：假设平庸原理成立 → 用德雷克方程推出银河系里应有约 15 万个文明 → 但我们从没见过任何证据 → 因此假设有问题 → 我们的太阳系可能有某些不寻常之处。

**德雷克方程的输入直接来自前面几周**：

$$N_C = N^{*}\, f_p\, n_e\, f_l\, f_i\, f_c\, f_L$$

- $f_l$（生命起源比例）的论据是 **W1–W3 的地质年代学**——地球约 4.5 Ga 形成，最早生命证据约 3.5–3.8 Ga，即"一旦可居住，生命几乎立刻出现"；
- $f_i$（智慧演化比例）的论据是 **W7 的演化**——智慧在地球上花了约 40 亿年，需要长期环境稳定 + 恰到好处的扰动；
- 全程的单位换算（1 AU ≈ 150 Gm、银河系 ≈ 90 Pm、宇宙年龄 ≈ 440 Ps）是 **Toolkit 的 SI 前缀训练**——Gilmour 刻意用秒而非年，就是为了强迫学生离开熟悉的直觉；
- 系外行星散点图的判读要点是**观测选择效应**：热木星在左上角堆积不是因为它们最多，而是因为径向速度法与凌星法都偏爱又大又近的行星；地球所在区域几乎空白，恰恰是因为"像地球这样的行星最难被发现"。

## 四、跨周的思维训练

抛开各周不同的主题，这门课反复训练的是同一组通用能力：

1. **由观察推断过程**。看到不整合线 → 推出抬升与侵蚀两次事件（W1）；看到交错层理的截切端 → 推出原始顶面（W4）；看到某种适应特征 → 推出选择压力（W7）。共同的句式是「我观察到 X，因为只有过程 Y 能产生 X，所以曾发生 Y」。

2. **多条独立证据交叉验证**。W1 的事件序列要求同时用叠覆、切割、包体三条原理互相约束；W3 要求岩性与生物两套对比线互相印证；W4 明确要求"穷举所有可用标志"并在冲突时按可靠性排序（geopetal > 交错层理 / sole marks > 粒序 > 波痕）；W5 需要三个台站才能唯一定位。**单一证据下结论是全课点名最多的错误。**

3. **量级估算与自洽性检验**。W3 的"半衰期计数法"（剩 50% = 1 个半衰期，25% = 2 个…）用于秒排除错误选项；W5 用 $T_S-T_P$ 是否等于 $t_S-t_P$ 自查时间算术；W10 要求亲手验算 $3\times10^{11}\times1\times2\times1\times0.5\times0.5\times10^{-6}=1.5\times10^5$。**算完必须回头检查量级**是三周共同的纪律。

4. **把定性问题转化为可计算的形式**。"震中在哪"→ S−P 到时差 → 圆的半径（W5）；"我们孤独吗"→ 七个可估参数的乘积（W10）；"这层岩石多老"→ 剩余母体百分比代入年龄方程（W3）。

5. **图解法与图件判读**。走时曲线的卡尺法、化石延限图取交集、γ 测井曲线的钟形/漏斗形、系外行星散点图的偏差识别——本课几乎没有"背公式套数字"的题，主要工具是图。

6. **区分"证据能支持什么"与"证据不能支持什么"**。岩石地层界面可以穿时，所以同一层砂岩不一定同龄（W2/W3）；化石缺失可能是时间缺失也可能是环境缺失（W3）；不是所有特征都是适应，可能是发育副产物或祖先遗留（W7）；地球生命起源得早可能只是幸存者偏差（W10）。

7. **诚实地表达不确定性**。W5 要求给出震中所在**区域**而非点；W7 明确宣告"未必存在正确答案"；W10 的德雷克方程被自觉地当作归谬法的中间步骤而非预测工具。

## 五、核心结论速查

> 标注 📎 者出自周笔记的「背景补充」——**是周 Agent 补足的背景知识，不是课堂原文**，仅供理解与自测，不应视为本课教授的内容。

**地层与时间（W1–W3）**

- 每一条不整合线，在事件序列里**至少要占两行**：uplift + erosion；nonconformity 还要更多。（W1，幻灯片图注明确点出）
- 褶皱、断层、变质、侵入、抬升、侵蚀**都是事件**，都要编号——不能只排岩层。（W1）
- 不整合三分类：角度不整合（产状有角度差，Siccar Point）/ 非整合（沉积岩覆于结晶基底，Manitou Springs 的**风化**花岗岩）/ 平行不整合（产状平行，Amroth）。（W1）
- 📎 nonconformity 与"后期侵入"的判别点：花岗岩**被风化**、砂岩含其碎屑 → nonconformity；花岗岩**烘烤**围岩、含捕虏体 → 侵入。（W1）
- **叠覆律的唯一前提是"未被倒转"**（幻灯片原文 "has not been overturned"）。（W2）
- **延限图取交集不是并集**；加入更多化石只会让年龄区间**变窄或不变，绝不会变宽**；精度由**延限最短**的类群决定。（W2）
- **GSSP 只定义单元的底界**，顶界由上覆单元的底界定义。（W2、W3）
- **Lithostratigraphy ≠ 时间**：岩性界面可以**穿时**，同一层砂岩在不同地点可能相差数百万年。（W2、W3）
- 五种 biozone：total range（1 个化石全延限）/ consecutive range（谱系中间段）/ partial range（用 A 的 LAD 与 C 的 FAD 切 B）/ assemblage（共存）/ acme（丰度峰值）。（W3，幻灯片原文）
- **年龄方程**：$t=-\,t_{1/2}\,\dfrac{\ln f}{\ln 2}$，其中 $f=N/N_0$ 为**母体剩余比例**。（W3，公式形式为 📎，题目与答案为原文）
- **选定年方法过三关**：材料对不对 → 量级对不对（📎 经验：目标年龄宜在 0.1–10 个半衰期内）→ **测的事件对不对**。（W3，第三关是 Practice 3 第 3 题的原文考点）
- **沉积岩不能直接放射性定年**——碎屑给的是源区年龄（只是沉积年龄的上限）；要绝对年龄找**火山灰中的锆石**做 U-Pb。（W3，原文答案）
- ⚠️ W3 Practice 3 第 3、4 题在地质上**不自洽**（"富含化石"却算出 1.58 Ga）——是命题的计算便利所致，不必强行串成一个情境。

**顶底判别（W4）**

- **交错层理**：被**削截 (angular)** 的一端 = 顶；**相切收敛 (asymptotic)** 的一端 = 底。（幻灯片图注给出这两个关键词；判读法则为 📎）
- **粒序层理**：正粒序下粗上细——但幻灯片唯一主动给出的警告是 **"be alert to the possibility of reverse grading"**，先判类型再用它。
- **Sole marks（flutes / furrows）**：凸模只保存在层的**底面**——看到凸起的那一面就是底。（构造名与图注为原文，判读原理为 📎）
- **Loading structures**：成因是 **"sand dumped rapidly on 'sloppy' muds"**（原文）——📎 砂向下陷（load casts 凸向底），泥向上刺（flame structures 尖端指向顶）。
- **陡倾 ≠ 倒转**；way-up（单层）≠ younging direction（整套序列）。

**地震（W5）**

- 幻灯片原文五条：地震波是弹性波；关注体波；P = primary/push–pull；S = secondary/shear/shake；**P 波比 S 波快约 70%**（📎 即 $v_P/v_S\approx\sqrt3$）。
- **到时 ≠ 走时 ≠ 记录起始时刻**——三个量必须分清。（原文任务 2 与 3 分别问前两者）
- **S−P 到时差不依赖发震时刻**，这是它能单独给出震中距的原因。（📎 原理，但幻灯片的整套任务建立其上）
- **定位至少需要 3 个台站**：1 个 → 一个圆，2 个 → 两个交点（歧义），3 个 → 唯一。（原文要求 "your 3 seismograph stations"）
- 📎 震级 (magnitude) 一次地震只有一个；烈度 (intensity) 每个地点一个。Risk = Hazard × Exposure × Vulnerability。

**演化（W7）**

- 演化的三要件（幻灯片高亮给出）：**Variation → Heredity → Selection**。
- **Fitness**（原文定义）：个体**相对于他者**留下**可存活后代**的能力——不是最强壮、不是活最久。
- **Natural selection**（原文）：由**整体环境 (the total environment)** 决定谁存活至繁殖；**"This need not necessarily involve a struggle between organisms."**
- **Adaptation** 的二分（原文定义内）：**genotypic adaptation**（跨世代、可遗传、是演化）vs **phenotypic adaptation / acclimatization**（个体一生内、不可遗传、不是演化）。**这是本周最可能被考的定义区分。**
- 📎 突变是随机的、选择是有方向的；选择作用于**表型**，改变的是**基因型频率**；不是所有特征都是适应。

**行星科学（W10）**

- **Principle of Mediocrity**（原文）：太阳系与地球没有特殊之处，我们从一个**随机的地点与时刻**观察宇宙——注意 "and time"，时间维度在结尾的 Resolutions 里会被攻击。
- **Fermi's Argument**：银河系约 10 万光年（≈ 90 Pm），0.01c 的自我复制探测器（Von Neumann probe）殖民全银河约需 **10⁷ 年**，而银河系已有约 10¹⁰ 年历史——**我们却一个都没见过**。
- **Drake 方程七项**及课上取值：$N^{*}=2\text{–}4\times10^{11}$、$f_p\approx1$、$n_e\approx2$、$f_l\approx1$、$f_i\approx0.5$、$f_c\approx0.5$、$f_L\approx10^{-6}$ → $N_C\approx150{,}000$。
- **生命需要的不是能量而是自由能**——即 **disequilibrium**（原文脚注：高低能量密度分区）。三例配对：黑烟囱微生物 = 化学不平衡；地表动物 = 化学不平衡（寄生于第三类）；绿色植物 = 辐射不平衡。（📎 答案思路）
- **德雷克方程不是用来算答案的**，它是把平庸原理翻译成可证伪预测的机器；150,000 是归谬法的中间步骤。
- **$f_p$ = 100% 与 Kepler 的 17% 不是一回事**：前者是"有任何行星"，后者是"有地球大小行星"（属 $n_e$ 的范畴）。
