# 🐛 千年虫计划 · Y2K Project

> **大二已死,大二永存。**

把大一地球科学(Earth Sciences)全年 **13 门子课程、112 个教学周、约 120 万词**的课件、讲义与课堂录音转写,交给一支 AI Agent 流水线逐周精读,产出一套**复习时可以不翻原材料**的中文学习笔记。

主流程已全部完成:**112 份周笔记 + 12 份课程总纲 + 1 份野外实习笔记**,共 125 份笔记。

---

## 📖 如何使用这套笔记

1. **按周复习**:每门课的 `Notes/Week NN.md` 是基石——逐周详尽笔记(约 1500–3000 字),覆盖 slides、讲义与课堂录音的全部内容。
2. **建立全局**:每门课根目录下的 `Course Notes.md` 是课程总纲——全课主线、各周关系、核心结论与重点难点,配合周笔记使用,不重复细节。
3. **先看勘误**:多数课程总纲附有**勘误表**(原材料中的知识性/数值错误、语音识别错词、PDF 转换丢失内容),全年累计 200+ 条——复习前先过一遍,避免被原材料带偏。
4. **不确定学习顺序?** 看 [`Freshman/order.md`](Freshman/order.md),13 门课的推荐顺序与每门课的定位理由都在里面。

## 📝 笔记体例

**语言**:中文为主,专业术语、定义、公式保留英文原文。

**周笔记**(每份约 1500–3000 字)固定七段结构:

1. **本周主题** — 一两句话定位本周在全课中的位置
2. **核心概念** — 解释完整,不只列名词
3. **公式与图表** — 公式保留原文并解释各项含义,关键图表用文字描述
4. **课堂补充** — transcript 中 slides 没有的口头讲解与强调重点
5. **Practical 要点** — 目的、方法步骤、关键结论
6. **易错点 / 重点难点**
7. **本周术语表** — 中英对照

**课程总纲**在此之上给出全课知识体系,并视课程情况附:勘误表、考试信息汇总、语法/公式速查、原材料转换丢失内容清单等。

## ⚙️ 制作方法

本项目由一个主控 Agent 调度数十个子 Agent 流水线完成,核心机制:

- **逐周精读**:每个教学周派 1 个子 Agent,通读该周全部材料**全文**——slides、讲义与课堂录音转写(transcript)同等地位,不跳读;同周的 Lecture 与 Practical 由同一个 Agent 配对处理。
- **先勘误后成文**:子 Agent 不盲信原材料——课件排错、周号错位、语音识别错词、PDF→md 转换丢失,都会核查并写进笔记与勘误表。
- **主控与内容隔离**:主控只做调度、追踪与 git 操作,不读任何材料与笔记正文,保证主对话不被百万词级的内容淹没。
- **反事实重放**:因材料出错而重做时,以「假如一开始拿到的就是正确材料」为准绳重建,严禁下游信息倒灌。
- **逐门停顿**:每完成一门课即 commit + push 并暂停,等用户确认后再进入下一门。

完整规则见 [`PLAN.md`](PLAN.md);材料清单、词数统计与配对裁定见 [`Freshman/manifest.md`](Freshman/manifest.md)。
